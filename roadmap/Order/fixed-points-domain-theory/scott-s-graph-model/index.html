    Scott's graph model

    Scott's graph model takes the powerset \(P(\omega)\) of the natural numbers, ordered by inclusion, as one universal domain (D. Scott, Data types as lattices, SIAM J. Comput. 5 (1976), §1). Its Scott topology has the sets \(\{y \mid n \in y\}\) as a subbasis, and its open sets are the sets "of finite character". A Scott-continuous map \(f : P(\omega) \to P(\omega)\) is therefore determined by its values on finite sets (Scott's Theorem 1.1). It is coded by its graph \(\{\langle n, m\rangle \mid m \in f(e_n)\}\), where \(e_n\) is the finite set given by the binary expansion of \(n\), and every set \(u\) acts as a function \(x \mapsto \{m \mid \exists n,\ e_n \subseteq x,\ \langle n, m\rangle \in u\}\). The graph theorem (Theorem 1.2) says that this application recovers every continuous function from its graph, that \(u \subseteq \operatorname{graph}(\operatorname{app} u)\), and which sets are graphs. So the continuous self-maps of \(P(\omega)\) form a retract of \(P(\omega)\): this is what makes \(P(\omega)\) a model of the untyped λ-calculus with β-conversion. The retraction is not onto, so η fails. Through self-application, the paradoxical combinator computes least fixed points (Theorem 2.5). Every second-countable \(T_0\) space embeds in \(P(\omega)\) (Theorem 1.6), and continuous maps into \(P(\omega)\) extend from subspaces (Theorem 1.5), which is why Scott called it universal.

    Here \(e_n\) is Scott's binary enumeration. The pairing \(\langle n, m\rangle\) is Mathlib's Nat.pair rather than Scott's Cantor pairing; the proofs use only that pairing is a bijection with \(n \le \langle n, m\rangle\).

    The model

    DefinitionThe n-th finite set of the graph model#✓fully proved

    MathlibExt.Order.ScottContinuity.GraphModel.finSet

    For \(n \in \mathbb{N}\), the finite set \(e_n \subseteq \mathbb{N}\) is read off the binary expansion of \(n\): \(k \in e_n\) if and only if the \(k\)-th binary digit of \(n\) is \(1\), so that \(n = \sum_{k \in e_n} 2^k\). Every finite subset of \(\mathbb{N}\) is \(e_n\) for exactly one \(n\), and every element of \(e_n\) is smaller than \(n\).

    This is Scott's enumeration of the finite sets (D. Scott, Data types as lattices, SIAM J. Comput. 5(3) (1976), 522–587, §1).

    def finSet (n : ℕ) : Set ℕ := (n.bitIndices.toFinset : Finset ℕ)

    TheoremElements of the n-th finite set are smaller than n#✓fully proved

    MathlibExt.Order.ScottContinuity.GraphModel.lt_of_mem_finSet

    If \(k \in e_n\), then \(k < n\): the binary digit \(2^k\) occurs in \(n\), so \(k < 2^k \le n\) (D. Scott, Data types as lattices, SIAM J. Comput. 5(3) (1976), 522–587, §1, where Scott notes that \(k \in e_n\) implies \(k < n\)).

    Scott's proof of the first recursion theorem uses this property of the enumeration (D. Scott, Data types as lattices, SIAM J. Comput. 5(3) (1976), 522–587, Appendix A, proof of Theorem 2.5 and the remark after it).

    theorem lt_of_mem_finSet {n k : ℕ} (hk : k ∈ finSet n) : k < n
    def finSet (n : ℕ) : Set ℕ := (n.bitIndices.toFinset : Finset ℕ)

    TheoremThe compact elements of P(ω) are the finite sets#✓fully proved

    MathlibExt.Order.ScottContinuity.GraphModel.isCompactElement_iff_finite

    A set \(s \subseteq \mathbb{N}\) is a compact element of the complete lattice \(P(\omega)\), that is, \(s \subseteq \bigcup S\) implies \(s \subseteq \bigcup S_0\) for a finite \(S_0 \subseteq S\), if and only if \(s\) is finite. The same holds in the powerset of any type, and the Lean statement is proved in that generality. Every set is the union of its finite subsets, so \(P(\omega)\) is an algebraic lattice whose compact elements are exactly the finite sets \(e_n\) (D. Scott, Data types as lattices, SIAM J. Comput. 5(3) (1976), 522–587, §1: each \(x\) is the limit of its finite subsets). Algebraic lattices are continuous lattices, the class of domains in D. Scott, Continuous Lattices (Oxford PRG-7, 1971). Mathlib calls algebraic lattices compactly generated (IsCompactlyGenerated), and already knows that \(P(\omega)\) is one.

    theorem isCompactElement_iff_finite {α : Type*} (s : Set α) :
    IsCompactElement s ↔ s.Finite

    DefinitionGraph of a function on P(ω)#✓fully proved

    MathlibExt.Order.ScottContinuity.GraphModel.graph

    For a function \(f : P(\omega) \to P(\omega)\), its graph is the set of codes $\(\operatorname{graph}(f) = \{\langle n, m\rangle \mid m \in f(e_n)\} \subseteq \mathbb{N},\)$ where \(e_n\) is the \(n\)-th finite set and \(\langle n, m\rangle\) is a pairing of natural numbers (D. Scott, Data types as lattices, SIAM J. Comput. 5(3) (1976), 522–587, §1, definition of \(\operatorname{graph}\)). Interpreted as an operation, \(\operatorname{graph}\) is λ-abstraction in the graph model.

    Scott uses the Cantor pairing \(\langle n, m\rangle = \tfrac12 (n+m)(n+m+1) + m\); here \(\langle n, m\rangle\) is Mathlib's Nat.pair, a different bijection \(\mathbb{N} \times \mathbb{N} \to \mathbb{N}\) that also satisfies \(n \le \langle n, m\rangle\).

    def graph (f : Set ℕ → Set ℕ) : Set ℕ := {k | k.unpair.2 ∈ f (finSet k.unpair.1)}
    def finSet (n : ℕ) : Set ℕ := (n.bitIndices.toFinset : Finset ℕ)

    DefinitionApplication in the graph model#✓fully proved

    MathlibExt.Order.ScottContinuity.GraphModel.app

    Every set \(u \subseteq \mathbb{N}\) acts as a function on \(P(\omega)\) by $\(\operatorname{app}(u, x) = \{m \mid \exists n,\ e_n \subseteq x \text{ and } \langle n, m\rangle \in u\}\)$ (D.     Continuity

    TheoremScott's characterisation theorem for P(ω)#✓fully proved

    MathlibExt.Order.ScottContinuity.GraphModel.mem_iff_exists_finset_of_scottContinuous

    Let \(f : P(\omega) \to P(\omega)\) be Scott-continuous, that is, preserve suprema (unions) of nonempty directed families. Then for all \(x \subseteq \mathbb{N}\) and \(m \in \mathbb{N}\), $\(m \in f(x) \iff m \in f(e) \text{ for some finite } e \subseteq x.\)$ So a continuous function is determined by its values on finite sets.

    Scott's Theorem 1.1 (D. Scott, Data types as lattices, SIAM J. Comput. 5(3) (1976), 522–587) states that \(f\) is continuous if and only if this holds; the page proves the forward direction, for Mathlib's notion of Scott continuity (ScottContinuous). The converse is not formalised here.

    theorem mem_iff_exists_finset_of_scottContinuous {f : Set ℕ → Set ℕ} (hf : ScottContinuous f)
    {x : Set ℕ} {m : ℕ} : m ∈ f x ↔ ∃ e : Finset ℕ, (e : Set ℕ) ⊆ x ∧ m ∈ f e

    TheoremApplication in P(ω) is Scott-continuous in its argument#✓fully proved

    MathlibExt.Order.ScottContinuity.GraphModel.scottContinuous_app_right

    For every \(u \subseteq \mathbb{N}\), the map \(x \mapsto \operatorname{app}(u, x)\) preserves unions of nonempty directed families, so it is Scott-continuous. In Scott's words, "every set of integers determines a continuous function" (D. Scott, Data types as lattices, SIAM J. Comput. 5(3) (1976), 522–587, §1, before Theorem 1.2).

    The proof uses that a finite subset of a directed union lies in one member of the family.

    theorem scottContinuous_app_right (u : Set ℕ) : ScottContinuous (app u)
    def app (u x : Set ℕ) : Set ℕ := {m | ∃ n, finSet n ⊆ x ∧ Nat.pair n m ∈ u}

    TheoremThe graph of a pointwise union#✓fully proved

    MathlibExt.Order.ScottContinuity.GraphModel.graph_sSup

    For every family \(F\) of functions \(P(\omega) \to P(\omega)\), the graph of the pointwise union is the union of the graphs: $\(\operatorname{graph}\Big(\bigsqcup F\Big) = \bigcup_{f \in F} \operatorname{graph}(f).\)$ So \(\operatorname{graph}\) is Scott-continuous, indeed completely join-preserving, for the pointwise order on functions.

    theorem graph_sSup (F : Set (Set ℕ → Set ℕ)) : graph (sSup F) = ⋃ f ∈ F, graph f
    def graph (f : Set ℕ → Set ℕ) : Set ℕ := {k | k.unpair.2 ∈ f (finSet k.unpair.1)}

    The graph theorem

    TheoremScott's graph theorem, part (i)#✓fully proved

    MathlibExt.Order.ScottContinuity.GraphModel.app_graph

    Every Scott-continuous \(f : P(\omega) \to P(\omega)\) is recovered from its graph: $\(\operatorname{app}(\operatorname{graph}(f), x) = f(x) \quad \text{for all } x \subseteq \mathbb{N}\)$ (D. Scott, Data types as lattices, SIAM J. Comput. 5(3) (1976), 522–587, Theorem 1.2 (i)). Read with \(\operatorname{app}\) as application and \(\operatorname{graph}\) as λ-abstraction, this is the β-rule of the graph model. Together with part (ii), it makes the continuous self-maps of \(P(\omega)\) a retract of \(P(\omega)\).

    theorem app_graph {f : Set ℕ → Set ℕ} (hf : ScottContinuous f) : app (graph f) = f
    def app (u x : Set ℕ) : Set ℕ := {m | ∃ n, finSet n ⊆ x ∧ Nat.pair n m ∈ u}

    MathlibExt.Order.ScottContinuity.GraphModel.subset_graph_app

    MathlibExt.Order.ScottContinuity.GraphModel.graph_app_eq_iff

    A set \(u \subseteq \mathbb{N}\) is the graph of the function it determines, \(\operatorname{graph}(\operatorname{app}(u, \cdot)) = u\), exactly when \(u\) is upward closed in the first coordinate: \(\langle k, m\rangle \in u\) and \(e_k \subseteq e_n\) imply \(\langle n, m\rangle \in u\) (D.     TheoremThe graph model is not extensional#✓fully proved

    MathlibExt.Order.ScottContinuity.GraphModel.exists_graph_app_ne

    There is a set \(u \subseteq \mathbb{N}\) with \(\operatorname{graph}(x \mapsto \operatorname{app}(u, x)) \ne u\). For instance \(u = \{\langle n_0, 0\rangle\}\) with \(e_{n_0} = \emptyset\) works: the graph of the constant function it determines also contains \(\langle n_1, 0\rangle\) for \(e_{n_1} = \{0\}\).

    So the retraction of \(P(\omega)\) onto the continuous functions is not a bijection, and the η-rule fails in \(P(\omega)\). Scott's conversion theorem validates only the rules α, β and ξ in \(P(\omega)\) (D. Scott, Data types as lattices, SIAM J. Comput. 5(3) (1976), 522–587, Theorem 2.2), and he notes that "the failure of (η) simply means that not every set in \(P\omega\) is the graph of a function" (Appendix A).

    theorem exists_graph_app_ne : ∃ u : Set ℕ, graph (app u) ≠ u
    def graph (f : Set ℕ → Set ℕ) : Set ℕ := {k | k.unpair.2 ∈ f (finSet k.unpair.1)}

    MathlibExt.Order.ScottContinuity.GraphModel.app_graph_diag

    For \(u \subseteq \mathbb{N}\), let \(d = \operatorname{graph}(x \mapsto \operatorname{app}(u, \operatorname{app}(x, x)))\), the denotation of \(\lambda x.\, u(x\,x)\). Then the self-application of \(d\) is the least fixed point of the continuous function \(\operatorname{app}(u, \cdot)\): $\(\operatorname{app}(d, d) = \bigcup_{k \ge 0} \operatorname{app}(u, \cdot)^k(\emptyset).\)$ Since the paradoxical combinator \(Y = \lambda u.(\lambda x.u(xx))(\lambda x.u(xx))\) sends \(u\) to \(\operatorname{app}(d, d)\), this says that \(Y\) computes least fixed points (D. Scott, Data types as lattices, SIAM J. Comput. 5(3) (1976), 522–587, Theorem 2.5, stated there for \(u\) the graph of a continuous \(f\); every \(u\) determines the continuous function \(\operatorname{app}(u, \cdot)\)).

    Scott's proof shows by β-conversion that \(\operatorname{app}(d, d)\) is a fixed point, and then by induction on the index \(l\) of finite sets \(e_l \subseteq d\) that \(\operatorname{app}(e_l, e_l)\) lies below every fixed point. The induction uses that \(k \in e_l\) implies \(k < l\) and that \(n \le \langle n, m\rangle\). The formal proof follows this argument.

    MathlibExt.Order.ScottContinuity.GraphModel.extendScott

    For a subset \(X\) of a topological space \(Y\) and any map \(f : X \to P(\omega)\), Scott's extension \(\bar f : Y \to P(\omega)\) is $\(\bar f(y) = \bigcup \Big\{ \bigcap \{ f(x) \mid x \in X \cap U \} \Bigm| U \text{ open},\ y \in U \Big\},\)$ with the empty intersection equal to \(\mathbb{N}\) (D. Scott, Data types as lattices, SIAM J. Comput. 5(3) (1976), Theorem 1.5, the formula for the extension). Equivalently, \(m \in \bar f(y)\) if and only if some open \(U \ni y\) has \(m \in f(x)\) for all \(x \in X \cap U\).

    Y → WithScott (Set ℕ) := fun y =>
  toScott {m | ∃ U : Set Y, IsOpen U ∧ y ∈ U ∧ ∀ x : X, (x : Y) ∈ U → m ∈ ofScott (f x)}

    MathlibExt.Order.ScottContinuity.GraphModel.exists_continuous_extend_withScott

    Let \(X\) be a subspace of a topological space \(Y\). Every continuous map \(f : X \to P(\omega)\), for the Scott topology, extends to a continuous map \(Y \to P(\omega)\), so \(P(\omega)\) is an injective space (D.
