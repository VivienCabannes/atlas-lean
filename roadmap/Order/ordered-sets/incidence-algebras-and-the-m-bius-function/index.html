    Incidence algebras and the Möbius function

    The Möbius function \(\mu\) of a locally finite poset is the inverse of its zeta function in the incidence algebra: \(\mu(s, s) = 1\) and \(\sum_{s \le u \le t} \mu(s, u) = 0\) for \(s < t\). It turns summation over order ideals into an invertible operation (Möbius inversion), is multiplicative on products, and equals an alternating count of chains (Philip Hall's theorem), which links it to the Euler characteristic of the order complex. Stanley, Enumerative Combinatorics, vol. 1, Sections 3.6 to 3.9, develops it in this order.

    The incidence algebra, the zeta and Möbius functions, one direction of Möbius inversion and the product theorem in algebra form are in Mathlib (IncidenceAlgebra, IncidenceAlgebra.mu, IncidenceAlgebra.moebius_inversion_bot, IncidenceAlgebra.mu_prod_mu); the pages below build on them.

    Möbius inversion and products

    TheoremMöbius inversion formula#✓fully proved

    MathlibExt.Order.IncidenceAlgebra.MoebiusInversion.moebius_inversion_iff

    Let \(P\) be a poset in which every principal order ideal \(\Lambda_t = \{s : s \le t\}\) is finite, let \(\mu\) be its Möbius function, and let \(f, g \colon P \to K\) take values in a ring \(K\). Then

    \[g(t) = \sum_{s \le t} f(s) \ \text{for all } t \in P \quad\Longleftrightarrow\quad f(t) = \sum_{s \le t} g(s)\, \mu(s, t) \ \text{for all } t \in P.\]

    No least element is assumed, so the formula applies to every finite poset. Stanley states it over a field; the proof only uses that \(\mu\) is a two-sided inverse of the zeta function, so any ring works. Mathlib's IncidenceAlgebra.moebius_inversion_bot proves the direction \(\Rightarrow\) for posets with a least element.

    theorem moebius_inversion_iff [DecidableEq α] [LocallyFiniteOrderBot α] (f g : α → 𝕜) :
    (∀ t, g t = ∑ s ∈ Iic t, f s) ↔ ∀ t, f t = ∑ s ∈ Iic t, g s * mu 𝕜 s t

    TheoremMöbius inversion formula, dual form#✓fully proved

    MathlibExt.Order.IncidenceAlgebra.MoebiusInversion.moebius_inversion_dual_iff

    Let \(P\) be a poset in which every principal dual order ideal \(V_s = \{t : t \ge s\}\) is finite, let \(\mu\) be its Möbius function, and let \(f, g \colon P \to K\) take values in a ring \(K\). Then

    \[g(s) = \sum_{t \ge s} f(t) \ \text{for all } s \in P \quad\Longleftrightarrow\quad f(s) = \sum_{t \ge s} \mu(s, t)\, g(t) \ \text{for all } s \in P.\]
    theorem moebius_inversion_dual_iff [DecidableEq α] [LocallyFiniteOrderTop α] (f g : α → 𝕜) :
    (∀ s, g s = ∑ t ∈ Ici s, f t) ↔ ∀ s, f s = ∑ t ∈ Ici s, mu 𝕜 s t * g t

    TheoremProduct theorem for the Möbius function#✓fully proved

    MathlibExt.Order.IncidenceAlgebra.MoebiusInversion.mu_prod_apply

    For locally finite posets \(P\) and \(Q\), the Möbius function of the direct product \(P \times Q\) is the product of the Möbius functions:

    \[\mu_{P \times Q}\big((s, t), (s', t')\big) = \mu_P(s, s')\, \mu_Q(t, t').\]

    Stanley states it for \((s, t) \le (s', t')\); both sides vanish otherwise, so it holds for all pairs. This is the pointwise form of Mathlib's IncidenceAlgebra.mu_prod_mu, which says that \(\mu_{P \times Q}\) is the tensor product \(\mu_P \otimes \mu_Q\) in the incidence algebra.

    theorem mu_prod_apply {𝕜 α β : Type*} [Ring 𝕜] [PartialOrder α] [PartialOrder β]
    [LocallyFiniteOrder α] [LocallyFiniteOrder β] [DecidableEq α] [DecidableEq β]
    [DecidableLE α] [DecidableLE β] (s s' : α) (t t' : β) :
    mu 𝕜 (s, t) (s', t') = mu 𝕜 s s' * mu 𝕜 t t'

    TheoremMöbius function of a Boolean algebra#✓fully proved

    MathlibExt.Order.IncidenceAlgebra.MoebiusInversion.mu_finset_of_subset

    In the Boolean algebra of finite subsets of a set, ordered by inclusion, the Möbius function is

    \[\mu(S, T) = (-1)^{|T \setminus S|} \qquad (S \subseteq T).\]

    Since \(|T \setminus S|\) is the length of the interval \([S, T]\), this says \(\mu(S, T) = (-1)^{\ell(S, T)}\). With it, Möbius inversion on a Boolean algebra is the principle of inclusion-exclusion.

    The Lean proof is a direct induction on \(T\) using \(\sum_{S \subseteq U \subseteq T} (-1)^{|U \setminus S|} = 0\) for \(S \ne T\).

    theorem mu_finset_of_subset {𝕜 ι : Type*} [Ring 𝕜] [DecidableEq ι] {S T : Finset ι}
    (h : S ⊆ T) : mu 𝕜 S T = (-1) ^ (T \ S).card

    Philip Hall's theorem

    DefinitionChains of length \(i\) between two elements#✓fully proved

    MathlibExt.Order.IncidenceAlgebra.PhilipHall.chainsBetween

    For elements \(a, b\) of a locally finite poset and \(i \in \mathbb{N}\), a chain of length \(i\) from \(a\) to \(b\) is a sequence \(a = t_0 < t_1 < \cdots < t_i = b\). In Lean it is a strictly increasing map \(\{0, \dots, i\} \to P\) with value \(a\) at \(0\) and \(b\) at \(i\). All such chains lie in the finite interval \([a, b]\), so they form a finite set.

    noncomputable def chainsBetween (a b : α) (i : ℕ) : Finset (Fin (i + 1) → α) :=
  (Fintype.piFinset fun _ => Icc a b).filter fun f =>
    StrictMono f ∧ f 0 = a ∧ f (Fin.last i) = b

    TheoremMembership in the chains between two elements#✓fully proved

    MathlibExt.Order.IncidenceAlgebra.PhilipHall.mem_chainsBetween

    A map \(f \colon \{0, \dots, i\} \to P\) is a chain of length \(i\) from \(a\) to \(b\) exactly when it is strictly increasing with \(f(0) = a\) and \(f(i) = b\). That its values lie in \([a, b]\), which the definition requires in order to make the set finite, is automatic.

    TheoremChains of length zero#✓fully proved

    MathlibExt.Order.IncidenceAlgebra.PhilipHall.chainCount_zero

    There is exactly one chain of length \(0\) from \(a\) to \(b\) if \(a = b\), and none otherwise: \(c_0(a, b) = \delta_{ab}\).

    theorem chainCount_zero [DecidableEq α] (a b : α) : chainCount a b 0 = if a = b then 1 else 0

    TheoremPhilip Hall's theorem#✓fully proved

    MathlibExt.Order.IncidenceAlgebra.PhilipHall.mu_eq_sum_chainCount

    Let \(a, b\) be elements of a locally finite poset and let \(c_i\) be the number of chains \(a = t_0 < t_1 < \cdots < t_i = b\) of length \(i\). Then

    \[\mu(a, b) = c_0 - c_1 + c_2 - c_3 + \cdots,\]

    a finite sum since \(c_i = 0\) once \(i \ge |[a, b]|\).

    Stanley states it for \(\mu_{\hat P}(\hat 0, \hat 1)\), where \(\hat P\) is a finite poset \(P\) with a least element \(\hat 0\) and a greatest element \(\hat 1\) adjoined. For \(a < b\) the interval \([a, b]\) is \(\hat P\) for \(P\) the open interval \((a, b)\); for \(a = b\) both sides equal \(1\). Since \(c_{i}\) counts the \((i-2)\)-dimensional faces of the order complex of \(P\) for \(i \ge 1\), the theorem says that \(\mu_{\hat P}(\hat 0, \hat 1)\) is the reduced Euler characteristic of that complex (Stanley, Proposition 3.8.6), which links the Möbius function to topology.

    Stanley's proof expands \(\mu = (1 + (\zeta - 1))^{-1}\) as a geometric series in the incidence algebra. The Lean proof is an induction on \(|[a, b]|\) from the recurrences for \(c_{i+1}\) and for \(\mu\).

    theorem mu_eq_sum_chainCount {𝕜 : Type*} [Ring 𝕜] [DecidableEq α] (a b : α) :
    mu 𝕜 a b = ∑ i ∈ range (Icc a b).card, (-1) ^ i * (chainCount a b i : 𝕜)
    noncomputable def chainCount (a b : α) (i : ℕ) : ℕ := (chainsBetween a b i).card

    MathlibExt.Order.IncidenceAlgebra.PhilipHall.mu_eq_sum_chainCount_of_card_le

    Lattices: Weisner and crosscut

    TheoremWeisner's theorem#✓fully proved

    MathlibExt.Order.IncidenceAlgebra.Lattice.sum_mu_top_of_inf_eq_bot

    Let \(L\) be a finite lattice with least element \(\hat 0\) and greatest element \(\hat 1\), and let \(a \in L\) with \(a \ne \hat 1\). Then

    \[\sum_{t \,:\, t \wedge a = \hat 0} \mu(t, \hat 1) = 0.\]

    It is a recurrence for \(\mu(\cdot, \hat 1)\) with, in general, far fewer terms than the defining one. The Lean proof writes the indicator of \(t \wedge a = \hat 0\) as \(\sum_{\hat 0 \le s \le t \wedge a} \mu(\hat 0, s)\) and exchanges the sums.

    theorem sum_mu_top_of_inf_eq_bot (𝕜 : Type*) [Ring 𝕜] {a : L} (ha : a ≠ ⊤) :
    ∑ t ∈ univ.filter (fun t => t ⊓ a = ⊥), mu 𝕜 t ⊤ = 0

    TheoremCrosscut theorem#✓fully proved

    MathlibExt.Order.IncidenceAlgebra.Lattice.mu_bot_top_eq_sum_crosscut

    Let \(L\) be a finite lattice with least element \(\hat 0\) and greatest element \(\hat 1\), and let \(X \subseteq L\) satisfy (a) \(\hat 1 \notin X\) and (b) every \(s \ne \hat 1\) in \(L\) lies below some \(t \in X\). Then

    \[\mu(\hat 0, \hat 1) = \sum_k (-1)^k N_k,\]

    where \(N_k\) is the number of \(k\)-element subsets of \(X\) whose meet is \(\hat 0\) (the meet of the empty subset is \(\hat 1\)). Typical choices of \(X\) are the coatoms of \(L\), or dually, for the dual statement, the atoms.

    theorem mu_bot_top_eq_sum_crosscut (𝕜 : Type*) [Ring 𝕜] (X : Finset L) (hX : ⊤ ∉ X)
    (hcover : ∀ s : L, s ≠ ⊤ → ∃ t ∈ X, s ≤ t) :
    mu 𝕜 (⊥ : L) ⊤ = ∑ k ∈ range (X.card + 1),
      (-1 : 𝕜) ^ k * ((X.powersetCard k).filter fun Y => Y.inf id = ⊥).card

    TheoremCrosscut theorem, summed over subsets#✓fully proved

    MathlibExt.Order.IncidenceAlgebra.Lattice.mu_bot_top_eq_sum_powerset

    Under the hypotheses of the crosscut theorem,

    \[\mu(\hat 0, \hat 1) = \sum_{Y \subseteq X,\ \bigwedge Y = \hat 0} (-1)^{|Y|},\]

    the meet of the empty subset being \(\hat 1\). Grouping the subsets by size gives the crosscut theorem. The proof expands \([\bigwedge Y = \hat 0] = \sum_{\hat 0 \le s \le \bigwedge Y} \mu(\hat 0, s)\): for \(s \ne \hat 1\) the subsets of \(X\) above \(s\) are the subsets of the nonempty set \(\{t \in X : s \le t\}\), whose signed count is \(0\), and only \(s = \hat 1\) survives.

    theorem mu_bot_top_eq_sum_powerset (𝕜 : Type*) [Ring 𝕜] (X : Finset L) (hX : ⊤ ∉ X)
    (hcover : ∀ s : L, s ≠ ⊤ → ∃ t ∈ X, s ≤ t) :
    mu 𝕜 (⊥ : L) ⊤ =
      ∑ Y ∈ X.powerset, if Y.inf id = ⊥ then (-1 : 𝕜) ^ Y.card else 0
