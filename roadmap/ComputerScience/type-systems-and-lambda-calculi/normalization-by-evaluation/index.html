    Cslib.Languages.LambdaCalculus.Stlc.Sem

    For a context \(\Gamma\), the semantic values of a simple type in \(\Gamma\) are defined by recursion on the type. At a base type \(b\) they are the neutral terms of type \(b\) in \(\Gamma\) (variables applied to zero or more normal arguments). At an arrow type \(A \Rightarrow B\) a semantic value is a family that, for every context \(\Delta\) and every renaming from \(\Gamma\) to \(\Delta\), maps semantic values of type \(A\) in \(\Delta\) to semantic values of type \(B\) in \(\Delta\).

    Because a semantic function acts after every renaming into a later context, reification under a binder needs no untyped weakening operation.

    Given a renaming \(\rho\) from a context \(\Gamma\) to a context \(\Delta\), a simple type \(A\) and a semantic value \(v\) of type \(A\) in \(\Gamma\), the renamed value is the semantic value of type \(A\) in \(\Delta\) defined by cases on \(A\).     DefinitionEvaluation into the Kripke semantic domain#✓fully proved

    Cslib.Languages.LambdaCalculus.Stlc.nbeEval

    Let \(t\) be a term of type \(T\) in context \(\Gamma\) and let \(\eta\) be a semantic environment interpreting every variable of \(\Gamma\) as a semantic value in context \(\Delta\). The evaluation \(\operatorname{ev}(t, \eta)\) is the semantic value of type \(T\) in context \(\Delta\) defined by recursion on \(t\): a variable \(x\) evaluates to \(\eta(x)\); an application \(f\,a\) evaluates to the semantic function \(\operatorname{ev}(f, \eta)\) applied, along the identity renaming of \(\Delta\), to \(\operatorname{ev}(a, \eta)\); and an abstraction \(\lambda b\) of type \(A \to B\), whose body \(b\) lies in the context \(\Gamma\) extended by \(A\), evaluates to the semantic function that sends a renaming \(\rho\) from \(\Delta\) to a context \(\Theta\) and a semantic value \(a\) of type \(A\) in \(\Theta\) to \(\operatorname{ev}(b, \eta')\), where \(\eta'\) sends the new variable to \(a\) and each variable \(x\) of \(\Gamma\) to \(\eta(x)\) renamed along \(\rho\).
