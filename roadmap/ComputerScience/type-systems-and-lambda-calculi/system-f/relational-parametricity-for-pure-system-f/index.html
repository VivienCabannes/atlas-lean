    The fundamental binary relational-parametricity theorem of pure System F.

    A syntactic-model adaptation of Reynolds' abstraction theorem (1983, Sections 3 and 8), following Wadler's related-environment formulation (1989, Section 6); see the module's provenance and model qualifications.

    theorem fundamental {n m : Nat} {Γ : Ctx n m} {t : Tm n m} {A : Ty n}
    (ht : Typing Γ t A) (ρ : Fin n → Rel) (σ τ : Fin m → Model)
    (hστ : ∀ i, ((Γ i).interpret ρ).holds (σ i) (τ i)) :
    (A.interpret ρ).holds (Tm.close σ t) (Tm.close τ t)

    Cslib.Languages.LambdaCalculus.SystemF.polymorphic_identity

    Every closed inhabitant acts as identity after every type instantiation.

    The conclusion is full-beta conversion in the existing erased term model, for an arbitrary locally closed input. It makes no CBV termination claim. This consumer specializes the free-theorem method of Wadler (1989, Figure 1) to the declared syntactic model; it applies to every typed inhabitant.

    theorem polymorphic_identity {t : Tm 0 0}
    (ht : Typing Fin.elim0 t polyIdType) (A : Ty 0) (x : Model) :
    BetaEq (Model.app (Tm.eraseModel (.tapp t A)) x) x
