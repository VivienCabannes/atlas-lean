    InductiveSmall-step call-by-value reduction in STLC#✓fully proved

    Cslib.Languages.LambdaCalculus.Stlc.Step

    One-step reduction on terms of type \(A\) in a context \(\Gamma\) is the least relation closed under three left-to-right call-by-value rules: if \(f\) reduces to \(f'\), then the application \(f\,a\) reduces to \(f'\,a\); if \(f\) is a value and \(a\) reduces to \(a'\), then \(f\,a\) reduces to \(f\,a'\); and if \(a\) is a value, then the application of the abstraction of \(b\) to \(a\) reduces to \(b[a]\), the result of substituting \(a\) for the newest free variable of \(b\).

    inductive Step {Base : Type u} : {Γ : List (Ty Base)} → {A : Ty Base} →
    Tm Γ A → Tm Γ A → Prop where
  | appFun {A B : Ty Base} {Γ : List (Ty Base)} {f f' : Tm Γ (A ⇒ B)} {a : Tm Γ A} :
      Step f f' → Step (.app f a) (.app f' a)
  | appArg {A B : Ty Base} {Γ : List (Ty Base)} {f : Tm Γ (A ⇒ B)} {a a' : Tm Γ A} :
      Value f → Step a a' → Step (.app f a) (.app f a')
  | beta {A B : Ty Base} {Γ : List (Ty Base)} {body : Tm (A :: Γ) B} {a : Tm Γ A} :
      Value a → Step (.app (.lam body) a) (Tm.instantiate body a)
    inductive Ty (Base : Type u) where
  | base : Base → Ty Base
  | arr : Ty Base → Ty Base → Ty Base
  deriving DecidableEq, Repr

    InductiveBig-step call-by-value evaluation in the simply typed lambda calculus#✓fully proved

    Cslib.Languages.LambdaCalculus.Stlc.Eval

    Fix a typing context \(\Gamma\). For terms \(t\) and \(v\) of the same type in context \(\Gamma\), the big-step evaluation relation \(t \Downarrow v\) is the least relation such that every lambda abstraction \(\lambda.\,b\) evaluates to itself, and an application \(f\,a\) evaluates to \(v\) whenever \(f \Downarrow \lambda.\,b\), \(a \Downarrow u\) and \(b[u] \Downarrow v\), where \(b[u]\) is the body \(b\) with its newest free variable replaced by \(u\).

    The application rule fixes a left-to-right order: first the function, then the argument, then the instantiated body.

    inductive Eval : {A : Ty Base} → Tm Γ A → Tm Γ A → Prop where
  | lam {A B : Ty Base} (body : Tm (A :: Γ) B) : Eval (.lam body) (.lam body)
  | app {A B : Ty Base} {f : Tm Γ (A ⇒ B)} {a : Tm Γ A}
      {body : Tm (A :: Γ) B} {va : Tm Γ A} {v : Tm Γ B} :
      Eval f (.lam body) →
      Eval a va →
      Eval (Tm.instantiate body va) v →
      Eval (.app f a) v
    inductive Ty (Base : Type u) where
  | base : Base → Ty Base
  | arr : Ty Base → Ty Base → Ty Base
