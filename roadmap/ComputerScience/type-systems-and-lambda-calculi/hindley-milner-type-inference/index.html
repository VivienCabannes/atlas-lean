    Cslib.HindleyMilner.toScheme

    DefinitionEvaluation of a type scheme#✓fully proved

    Cslib.HindleyMilner.Scheme.eval

    Given maps \(f\) and \(g\) from natural numbers to monotypes over \(B\), a type scheme \(\sigma\) over \(B\) evaluates to the monotype obtained by replacing each free type variable \(x\) of \(\sigma\) by \(f(x)\) and each bound variable \(i\) by \(g(i)\), keeping every base type \(b\) unchanged.   | node l r => node (Scheme.eval f g l) (Scheme.eval f g r)

    InductiveHindley–Milner typing#✓fully proved

    Cslib.HindleyMilner.HasType

    The syntax-directed Damas–Milner typing relation \(\Gamma \vdash e : \tau\) between a context \(\Gamma\), an expression \(e\) and a monotype \(\tau\) is the least relation closed under the following rules, where \(\Gamma, x : \sigma\) is \(\Gamma\) extended by the binding \(x : \sigma\) in front.

    • Variable: if the lookup of \(x\) in \(\Gamma\) gives the scheme \(\sigma\), then \(\Gamma \vdash x : \tau\) for every instance \(\tau\) of \(\sigma\), obtained by replacing each bound variable \(i\) of \(\sigma\) by a monotype \(t_i\).
    • Application: if \(\Gamma \vdash e_1 : \tau_1 \to \tau_2\) and \(\Gamma \vdash e_2 : \tau_1\), then \(\Gamma \vdash e_1\, e_2 : \tau_2\).
    • Abstraction: if \(\Gamma, x : \tau_1 \vdash e : \tau_2\), with \(\tau_1\) bound as a scheme without bound variables, then \(\Gamma \vdash \lambda x.\, e : \tau_1 \to \tau_2\).
    • Let: if \(\Gamma \vdash e_1 : \tau_1\) and \(\Gamma, x : \mathrm{gen}_\Gamma(\tau_1) \vdash e_2 : \tau_2\), then \(\Gamma \vdash \mathtt{let}\ x = e_1\ \mathtt{in}\ e_2 : \tau_2\), where \(\mathrm{gen}_\Gamma(\tau_1)\) binds the type variables of \(\tau_1\) that are not free in \(\Gamma\).
    inductive HasType : Ctx B → Expr → Ty B → Prop
  /-- A variable has every instance of its scheme. -/
