    Cslib.Languages.LambdaCalculus.Stlc.Var

    For a context \(\Gamma\) (a list of simple types) and a simple type \(A\), the variables of type \(A\) in \(\Gamma\) are generated by two rules: the variable \(0\) is a variable of type \(A\) in the context \(A :: \Gamma\) obtained by prepending \(A\) to \(\Gamma\), and if \(x\) is a variable of type \(A\) in \(\Gamma\), then for every simple type \(B\) the successor of \(x\) is a variable of type \(A\) in \(B :: \Gamma\).

    inductive Var {Base : Type u} : List (Ty Base) → Ty Base → Type u where
  | zero {A : Ty Base} {Γ : List (Ty Base)} : Var (A :: Γ) A
  | succ {A B : Ty Base} {Γ : List (Ty Base)} : Var Γ A → Var (B :: Γ) A
    inductive Ty (Base : Type u) where
  | base : Base → Ty Base
  | arr : Ty Base → Ty Base → Ty Base

    Cslib.Languages.LambdaCalculus.Stlc.Tm

    Let \(A\) and \(B\) range over simple types and \(\Gamma\) over contexts (lists of simple types); write \(A \Rightarrow B\) for the function type from \(A\) to \(B\) and \(A :: \Gamma\) for the context obtained by prepending \(A\) to \(\Gamma\). The terms of type \(A\) in context \(\Gamma\) are generated by three rules: every variable of type \(A\) in \(\Gamma\) is a term of type \(A\) in context \(\Gamma\); if \(f\) is a term of type \(A \Rightarrow B\) and \(a\) is a term of type \(A\), both in context \(\Gamma\), then the application \(f\,a\) is a term of type \(B\) in context \(\Gamma\); and if \(t\) is a term of type \(B\) in the context \(A :: \Gamma\), then the abstraction \(\lambda t\) is a term of type \(A \Rightarrow B\) in context \(\Gamma\).

    inductive Tm {Base : Type u} : List (Ty Base) → Ty Base → Type u where
  | var {A : Ty Base} {Γ : List (Ty Base)} : Var Γ A → Tm Γ A
  | app {A B : Ty Base} {Γ : List (Ty Base)} : Tm Γ (A ⇒ B) → Tm Γ A → Tm Γ B
  | lam {A B : Ty Base} {Γ : List (Ty Base)} : Tm (A :: Γ) B → Tm Γ (A ⇒ B)
    inductive Ty (Base : Type u) where
  | base : Base → Ty Base
  | arr : Ty Base → Ty Base → Ty Base
  deriving DecidableEq, Repr
