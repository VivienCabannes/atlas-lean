    DefinitionShifting raw terms#✓fully proved

    Cslib.Languages.LambdaCalculus.Stlc.RawTm.shift

    For natural numbers \(k\) (the amount) and \(c\) (the cutoff, \(0\) by default), shifting a raw term by \(k\) at cutoff \(c\) replaces a variable index \(n\) by \(n + k\) if \(c \le n\) and leaves it unchanged otherwise, shifts both sides of an application by \(k\) at cutoff \(c\), and sends \(\lambda A.\,t\) to \(\lambda A.\,t'\), where \(t'\) is \(t\) shifted by \(k\) at cutoff \(c + 1\).

  | .var n => .var (if cutoff ≤ n then n + amount else n)

  | .lam A body => .lam A (body.shift amount (cutoff + 1))

    DefinitionVariable lookup#✓fully proved

    Cslib.Languages.LambdaCalculus.Stlc.lookupVar

    Given a context \(\Gamma\), a list of types, and a natural number \(n\), looking up the de Bruijn index \(n\) in \(\Gamma\) either fails or returns a type \(A\) together with an intrinsic variable of type \(A\) in \(\Gamma\). It is defined by recursion: lookup fails in the empty context; index \(0\) in the context \(A :: \Gamma\), obtained by adding \(A\) at the front of \(\Gamma\), returns \(A\) with the zero variable; and index \(n + 1\) in \(B :: \Gamma\) looks up \(n\) in \(\Gamma\), fails if that fails, and otherwise returns the same type with the successor of the variable found.

    def lookupVar : (Γ : List (Ty Base)) → Nat →
    Option (Sigma fun A => Var Γ A)
  | [], _ => none
  | A :: _, 0 => some ⟨A, .zero⟩
  | _ :: Γ, n + 1 => do
      let ⟨A, x⟩ ← lookupVar Γ n
      pure ⟨A, .succ x⟩
    inductive Ty (Base : Type u) where
  | base : Base → Ty Base
  | arr : Ty Base → Ty Base → Ty Base
  deriving DecidableEq, Repr

    DefinitionErasure of intrinsically typed terms#✓fully proved

    Cslib.Languages.LambdaCalculus.Stlc.Tm.erase

    The erasure of an intrinsically typed term in a context \(\Gamma\) is the raw term defined by recursion: a variable becomes the raw variable whose index is its position in \(\Gamma\) (counting from \(0\) at the front); an application of \(f\) to \(a\) becomes the raw application of the erasure of \(f\) to the erasure of \(a\); and a lambda with parameter type \(B\) becomes the raw lambda annotated with \(B\) whose body is the erasure of its body. Erasure thus forgets all typing information except the binder annotations.

    DefinitionElaboration of raw STLC terms#✓fully proved

    Cslib.Languages.LambdaCalculus.Stlc.elaborate

    Assume equality of base types is decidable. Elaboration in a context \(\Gamma\) of simple types sends a raw term either to failure or to a checked term in \(\Gamma\) (a simple type together with an intrinsically typed term of that type in \(\Gamma\)), by recursion on the raw term. A variable with de Bruijn index \(n\) elaborates to the variable at position \(n\) of \(\Gamma\) (counting from \(0\) at the front), with the type stored there, and fails if \(\Gamma\) has at most \(n\) entries. A lambda with parameter type \(A\) and body \(b\) elaborates \(b\) in \(\Gamma\) extended by \(A\) at the front; if that gives type \(B\), it returns the lambda at type \(A \to B\), and otherwise it fails. An application of \(f\) to \(a\) elaborates \(f\) and \(a\) in \(\Gamma\), and succeeds, returning the application at type \(B\), exactly when \(f\) gets a function type \(A \to B\) and \(a\) gets type \(A\); otherwise it fails.
