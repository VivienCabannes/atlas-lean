    Cslib.Languages.LambdaCalculus.Stlc.Tm.denote

    Given an interpretation \(I\) of the base types, the denotation of a well-typed term \(t\) of type \(A\) in context \(\Gamma\) in an environment \(\eta\) for \(\Gamma\) is the element of the denotation of \(A\) defined by recursion on \(t\): a variable \(x\) denotes \(\eta(x)\), an application \(f\,a\) denotes the denotation of \(f\) applied to the denotation of \(a\) (both in \(\eta\)), and an abstraction \(\lambda.\,b\) denotes the function sending each value \(a\) of its argument type to the denotation of the body \(b\) in \(\eta\) extended by \(a\) for the newest variable.

    def denote (I : Base → Type v) : {Γ : List (Ty Base)} → {A : Ty Base} →
    Tm Γ A → Env I Γ → Ty.denote I A
  | _, _, .var x, η => η x
  | _, _, .app f a, η => denote I f η (denote I a η)
  | _, _, .lam body, η => fun a ↦ denote I body (Env.cons a η)
