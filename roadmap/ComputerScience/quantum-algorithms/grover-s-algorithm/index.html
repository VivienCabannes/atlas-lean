    Cslib.Grover.phaseOracle

    For a type \(\alpha\) and a finite set \(M \subseteq \alpha\) of marked elements, the phase oracle sends a real amplitude vector \(\psi\) on \(\alpha\) to the amplitude vector whose value at \(x\) is \(-\psi(x)\) if \(x \in M\) and \(\psi(x)\) if \(x \notin M\); that is, it negates exactly the amplitudes at the marked elements.

    def phaseOracle {α : Type*} [DecidableEq α] (marked : Finset α)
    (ψ : Amplitude α) : Amplitude α :=
  fun x => if x ∈ marked then -ψ x else ψ x

    DefinitionGrover step#✓fully proved

    Cslib.Grover.groverStep

    Let \(\alpha\) be a finite type and \(M \subseteq \alpha\) a set of marked elements. Write \(O_M\) for the phase oracle, which negates the amplitudes at the points of \(M\), and \(D\) for inversion about the mean, which sends an amplitude vector \(\varphi\) on \(\alpha\) to \(x \mapsto 2\bar\varphi - \varphi(x)\), where \(\bar\varphi\) is the arithmetic mean of the amplitudes of \(\varphi\). One Grover step sends a real amplitude vector \(\psi\) on \(\alpha\) to \(D(O_M \psi)\): phase inversion followed by inversion about the mean.

    noncomputable def groverStep {α : Type*} [Fintype α] [DecidableEq α]
    (marked : Finset α) (ψ : Amplitude α) : Amplitude α :=
  diffusion (phaseOracle marked ψ)
