    Lower bound for quantum search

    The hybrid argument of Bennett, Bernstein, Brassard and Vazirani: when the oracle marks an item \(y\), the final state of a \(T\)-query algorithm moves by at most twice the sum, over the queries, of the norm of the part of the oracle-free state that queries \(y\). Since these parts have total squared norm at most one at each query, Cauchy–Schwarz gives \(\sum_y \|\psi_T^y - \psi_T\|^2 \le 4T^2\), and an algorithm that finds every one of \(N\) items with probability at least \(1/2\) needs \(N \le 16T^2 + 4\), that is \(\Omega(\sqrt N)\) queries. Grover's algorithm attains this order.

    TheoremBBBV lower bound in the standard query model#✓fully proved

    Cslib.QuantumSearchLowerBound.card_le_of_forall_success

    Take the state space \(\ell^2(\iota \times W)\), with a query register \(\iota\) of \(N\) items and a finite workspace \(W\). Let an algorithm apply linear isometries \(U_0, \dots, U_T\) with \(T\) calls in between to the phase oracle marking \(y\), which negates the amplitudes of the basis states \(|y, w\rangle\), starting from a unit vector \(\psi_0\). If for every \(y\) measuring the query register of the final state gives \(y\) with probability at least \(1/2\), that is \(\sum_w |\psi_T^y(y, w)|^2 \ge 1/2\), then $\(N \le 16T^2 + 4 .\)$ Search therefore needs \(\Omega(\sqrt N)\) queries, the order attained by Grover's algorithm (Bennett, Bernstein, Brassard and Vazirani, Section 3.1, the query lower bound behind Theorem 3.5; see Lower bound for quantum search (BBBV) for how the two statements compare). Other final measurements, given by any linear maps \(Q_y\) with \(\sum_y \|Q_y v\|^2 \le \|v\|^2\), are covered by that abstract statement.

    TheoremLower bound for quantum search (BBBV)#✓fully proved

    Cslib.QuantumSearchLowerBound.mul_card_le_of_forall_success

    In the setting of the summed hybrid bound, let the final measurement be given by linear maps \(Q_y\) with \(\sum_y \|Q_y v\|^2 \le \|v\|^2\) (outcome \(y\) has probability \(\|Q_y v\|^2\)), and let \(\|\psi_0\| = 1\). If for every \(y\) the algorithm run with oracle \(O_y\) outputs \(y\) with probability at least \(p\), then $\(p\, N \le 8T^2 + 2 .\)$ For \(p = 1/2\) this is \(N \le 16T^2 + 4\), so \(T \ge \sqrt{N - 4}/4\): unstructured search needs \(\Omega(\sqrt N)\) queries.

    This is the query lower bound that Bennett, Bernstein, Brassard and Vazirani (Section 3.1) derive from Theorem 3.3 and Corollary 3.4 and use to prove Theorem 3.5 (relative to a random oracle, NP is not contained in BQTime\((o(2^{n/2}))\)). The forms differ: their final step bounds the error probability of an algorithm with \(T \le 2^{n/2}/20\) relative to a random oracle through the total variation estimate of Theorem 3.1, while the statement here concerns algorithms that succeed on every \(y\) and ends with a direct counting argument. Theorem 3.5 itself (an oracle separation of complexity classes) is not formalised. The hypothesis \(\|O_y v - v\| \le 2\|P_y v\|\) holds for the phase oracle and also for the standard oracle \(|z, b\rangle \mapsto |z, b \oplus [z = y]\rangle\) (with \(P_y\) the projection onto the basis states whose query register holds \(y\)), so the bound covers both.

    theorem mul_card_le_of_forall_success {ι : Type*} [Fintype ι] (U : ℕ → E →ₗᵢ[ℂ] E)

    (hP : ∀ v, ∑ y, ‖P y v‖ ^ 2 ≤ ‖v‖ ^ 2) (Q : ι → E →ₗ[ℂ] E)

    (hsucc : ∀ y, p ≤ ‖Q y (queryRun U (O y) ψ₀ T)‖ ^ 2) :
    p * Fintype.card ι ≤ 8 * T ^ 2 + 2

    TheoremHybrid argument#✓fully proved

    Cslib.QuantumSearchLowerBound.norm_queryRun_sub_queryRun_le

    For a linear isometry \(O\), the final states of a \(T\)-query algorithm run with oracle \(O\) and with no oracle satisfy $\(\|\psi_T^{O} - \psi_T\| \le \sum_{k < T} \|O\varphi_k - \varphi_k\|,\)$ where \(\varphi_k\) is the oracle-free state just before query \(k+1\). Each query can add at most the amount by which \(O\) moves the current oracle-free state, and later isometries do not amplify it. This is the accounting in the proof of Theorem 3.3 of Bennett, Bernstein, Brassard and Vazirani (the difference of final states is a sum of per-query errors carried forward by unitaries) and the statement that errors along a unitary evolution only add (Bernstein and Vazirani, Theorem 3.4.1).

    theorem norm_queryRun_sub_queryRun_le (U : ℕ → E →ₗᵢ[ℂ] E) (O : E →ₗᵢ[ℂ] E) (ψ₀ : E) (T : ℕ) :
    ‖queryRun U O ψ₀ T - queryRun U id ψ₀ T‖ ≤
      ∑ k ∈ range T, ‖O (queryRun U id ψ₀ k) - queryRun U id ψ₀ k‖
    def queryRun (U : ℕ → E →ₗᵢ[ℂ] E) (R : E → E) (ψ₀ : E) : ℕ → E
  | 0 => U 0 ψ₀
  | k + 1 => U (k + 1) (R (queryRun U R ψ₀ k))

    DefinitionRun of a query algorithm#✓fully proved

    Cslib.QuantumSearchLowerBound.queryRun

    A \(T\)-query algorithm is given by linear isometries \(U_0, U_1, \dots, U_T\) of a complex inner product space and an initial state \(\psi_0\). Run with an oracle map \(R\), its state after the \(k\)-th step is $\(\psi_0' = U_0\psi_0, \qquad \psi_{k+1}' = U_{k+1} R\, \psi_k',\)$ and its final state is \(\psi_T'\). The steps \(U_k\) do not depend on the oracle (Bennett, Bernstein, Brassard and Vazirani, Section 3.1). Using isometries rather than unitaries makes the results below apply to a slightly larger class of algorithms.

    def queryRun (U : ℕ → E →ₗᵢ[ℂ] E) (R : E → E) (ψ₀ : E) : ℕ → E
  | 0 => U 0 ψ₀
  | k + 1 => U (k + 1) (R (queryRun U R ψ₀ k))

    TheoremSummed hybrid bound#✓fully proved

    Cslib.QuantumSearchLowerBound.sum_norm_queryRun_sub_queryRun_sq_le

    Let \(O_y\), for \(y\) in a finite set of \(N\) items, be linear isometries and \(P_y\) maps with \(\|O_y v - v\| \le 2\|P_y v\|\) and \(\sum_y \|P_y v\|^2 \le \|v\|^2\) for all \(v\) (\(\|P_y v\|^2\) is the query magnitude of \(y\) in \(v\), Definition 3.2 of Bennett, Bernstein, Brassard and Vazirani). Then the final states of a \(T\)-query algorithm satisfy $\(\sum_y \|\psi_T^{y} - \psi_T\|^2 \le 4T^2 \|\psi_0\|^2,\)$ where \(\psi_T^y\) uses the oracle \(O_y\) and \(\psi_T\) uses none.

    Bennett et al. (Corollary 3.4) state the same accounting as a count: for unit \(\psi_0\), all but \(2T^2/\varepsilon^2\) items \(y\) satisfy \(\|\psi_T^y - \psi_T\| \le \varepsilon\). The summed form here implies a count of the same shape (with \(4T^2/\varepsilon^2\)) by Markov's inequality; that corollary is not formalised separately.

    theorem sum_norm_queryRun_sub_queryRun_sq_le {ι : Type*} [Fintype ι] (U : ℕ → E →ₗᵢ[ℂ] E)
    (O : ι → E →ₗᵢ[ℂ] E) (P : ι → E → E) (hOP : ∀ y v, ‖O y v - v‖ ≤ 2 * ‖P y v‖)
    (hP : ∀ v, ∑ y, ‖P y v‖ ^ 2 ≤ ‖v‖ ^ 2) (ψ₀ : E) (T : ℕ) :
    ∑ y, ‖queryRun U (O y) ψ₀ T - queryRun U id ψ₀ T‖ ^ 2 ≤ 4 * T ^ 2 * ‖ψ₀‖ ^ 2
    def queryRun (U : ℕ → E →ₗᵢ[ℂ] E) (R : E → E) (ψ₀ : E) : ℕ → E
  | 0 => U 0 ψ₀
  | k + 1 => U (k + 1) (R (queryRun U R ψ₀ k))
