    Deutsch–Jozsa and Bernstein–Vazirani algorithms

    Fourier sampling over \(\mathbb{Z}_2^n\): apply the \(n\)-qubit Hadamard transform to \(|0\cdots0\rangle\), query the phase oracle \(|x\rangle \mapsto (-1)^{f(x)}|x\rangle\) once, apply the Hadamard transform again and measure. The amplitude of \(|t\rangle\) is \(2^{-n}\sum_x (-1)^{f(x) + t\cdot x}\). When \(f(x) = s\cdot x + b\) the outcome is \(s\) with certainty (Bernstein–Vazirani), and the outcome \(0\cdots0\) separates constant from balanced functions with certainty (Deutsch–Jozsa), each with a single query, whereas a classical algorithm needs \(n\) evaluations to find \(s\).

    TheoremClassical evaluations: fewer than n never determine s#✓fully proved

    Cslib.BernsteinVazirani.exists_ne_zero_forall_bitDot_eq_zero

    For every set \(Q \subseteq \mathbb{Z}_2^n\) of fewer than \(n\) points there is \(u \neq 0\) with \(u\cdot x = 0\) for all \(x \in Q\) (the linear map \(u \mapsto (u\cdot x)_{x\in Q}\) has a nontrivial kernel). Hence \(x \mapsto s\cdot x\) and \(x \mapsto (s+u)\cdot x\) agree on \(Q\), and evaluations at the points of \(Q\) cannot tell \(s\) from \(s + u\).

    This is the counting fact behind the remark of Bernstein and Vazirani (Section 8.4, after Theorem 8.4.2) and Cleve, Ekert, Macchiavello and Mosca (after equation (3.7)) that a classical algorithm needs \(n\) evaluations. For an adaptive deterministic algorithm, apply it to the points the algorithm queries when every answer is \(0\) (the case \(s = 0\)): the algorithm then behaves identically for \(s = 0\) and \(s = u\). Only the counting fact is formalised; neither the adaptive argument nor a bound for randomised classical algorithms is.

    theorem exists_ne_zero_forall_bitDot_eq_zero (Q : Finset (Fin n → ZMod 2)) (hQ : Q.card < n) :
    ∃ u : Fin n → ZMod 2, u ≠ 0 ∧ ∀ x ∈ Q, bitDot u x = 0
    def bitDot (s x : Fin n → ZMod 2) : ZMod 2 := ∑ i, s i * x i

    TheoremAmplitudes of Fourier sampling#✓fully proved

    Cslib.BernsteinVazirani.fourierSample_apply

    For \(f : \mathbb{Z}_2^n \to \mathbb{Z}_2\), the amplitude of \(|t\rangle\) in \(H_n O_f H_n |0\cdots0\rangle\), where \(O_f |x\rangle = (-1)^{f(x)} |x\rangle\), is $\(2^{-n} \sum_{x} (-1)^{f(x) + t\cdot x} .\)$ This is equation (3.6) of Cleve, Ekert, Macchiavello and Mosca with the normalisation restored, and the special case of Fourier sampling with respect to \(g = (-1)^f\) in Bernstein and Vazirani (Theorem 8.4.2: outcome \(s\) with probability \(|\hat f(s)|^2\) for \(f(x) = g(x)/2^{n/2}\)).

    theorem fourierSample_apply (f : (Fin n → ZMod 2) → ZMod 2) (t : Fin n → ZMod 2) :

    TheoremBernstein–Vazirani algorithm#✓fully proved

    Cslib.BernsteinVazirani.fourierSample_of_affine

    If \(f(x) = s\cdot x + b\) for all \(x \in \mathbb{Z}_2^n\), then one query of Fourier sampling produces exactly the state \((-1)^b |s\rangle\), so measuring it returns the hidden string \(s\) with certainty.

    Bernstein and Vazirani (Section 8.4) state the parity problem with \(b = 0\) and an oracle that computes \(f\) into a register, which their algorithm calls twice (compute, then uncompute); the version here, with one call to the phase oracle and the extra constant \(b\), is the one of Cleve, Ekert, Macchiavello and Mosca (equations (3.7)–(3.9)). The phase oracle is what one call to the reversible oracle does to a target qubit in \(|0\rangle - |1\rangle\) (Phase kickback).

    theorem fourierSample_of_affine (s : Fin n → ZMod 2) (b : ZMod 2)
    (f : (Fin n → ZMod 2) → ZMod 2) (hf : ∀ x, f x = bitDot s x + b) :
    fourierSample f = signOfBit b • Pi.single s 1
    def bitDot (s x : Fin n → ZMod 2) : ZMod 2 := ∑ i, s i * x i

    TheoremDeutsch–Jozsa algorithm, balanced case#✓fully proved

    Cslib.BernsteinVazirani.fourierSample_zero_of_isBalanced

    If \(f : \mathbb{Z}_2^n \to \mathbb{Z}_2\) is balanced (it takes the values \(0\) and \(1\) equally often), the amplitude of \(|0\cdots0\rangle\) in \(H_n O_f H_n |0\cdots0\rangle\) is \(0\), so measuring never gives \(0\cdots0\). If \(f\) is constant, the outcome is \(0\cdots0\) with probability \(1\) (constant case). One query therefore decides with certainty whether a function promised to be constant or balanced is constant.

    This is the one-query form of Cleve, Ekert, Macchiavello and Mosca (Section 3, after equation (3.6)); the original algorithm of Deutsch and Jozsa (1992) used two calls to the reversible oracle, as Cleve et al. note. A deterministic classical algorithm needs \(2^{n-1} + 1\) evaluations in the worst case (Cleve et al., Section 3); that classical bound is not formalised here.

    theorem fourierSample_zero_of_isBalanced {f : (Fin n → ZMod 2) → ZMod 2}
    (hf : IsBalanced f) : fourierSample f 0 = 0
    def IsBalanced (f : (Fin n → ZMod 2) → ZMod 2) : Prop :=
  (univ.filter fun x => f x = 0).card = (univ.filter fun x => f x = 1).card

    DefinitionThe n-qubit Hadamard transform#✓fully proved

    Cslib.BernsteinVazirani.hadamard

    The Hadamard transform on \(n\) qubits is the matrix \(H_n\) indexed by \(\mathbb{Z}_2^n\) with entries $\((H_n)_{s,x} = 2^{-n/2} (-1)^{s\cdot x}, \qquad s\cdot x = \textstyle\sum_i s_i x_i \bmod 2 .\)$ It maps the basis state \(|x\rangle\) to \(2^{-n/2} \sum_s (-1)^{s\cdot x} |s\rangle\), the change of basis from the delta functions to the parity (character) basis of \(\mathbb{Z}_2^n\). Bernstein and Vazirani (Section 8.4, Theorem 8.4.1) build it as the tensor power of the one-qubit Hadamard gate; Cleve, Ekert, Macchiavello and Mosca (equation (3.1)) display it without the normalisation \(2^{-n/2}\).

    noncomputable def hadamard (n : ℕ) : Matrix (Fin n → ZMod 2) (Fin n → ZMod 2) ℂ :=
  Matrix.of fun s x => hadamardScale n * signOfBit (bitDot s x)
    noncomputable def hadamardScale (n : ℕ) : ℂ := ((Real.sqrt (2 ^ n) : ℝ) : ℂ)⁻¹

    Cslib.BernsteinVazirani.phase_kickback

    The reversible oracle \(|x\rangle|b\rangle \mapsto |x\rangle|b + f(x)\rangle\), applied to a state whose amplitude at \((x, b)\) is \(a(x)(-1)^b\) (target qubit in \(|0\rangle - |1\rangle\)), multiplies the amplitude at \((x, b)\) by \((-1)^{f(x)}\).
