    Cslib.Algorithms.Lean.ModularLinearEquation.modularLinearEquationSolver

    Given natural numbers \(a > 0\) and \(n > 0\) and an integer \(b\), the solver solves \(a x \equiv b \pmod{n}\) following CLRS. Let \(d = \gcd(a, n)\) and let \(y\) be the coefficient of \(a\) in the Bézout identity \(d = n u + a y\) computed by the extended Euclidean algorithm on \((n, a)\). If \(d \mid b\), it returns the array \([x_0, x_1, \dots, x_{d-1}]\), where \(x_i = \bigl((y \cdot (b / d)) \bmod n + i \cdot (n / d)\bigr) \bmod n\) and \(r \bmod n\) denotes the least nonnegative residue of \(r\); otherwise it returns the empty array.

    Its cost is \(6s + 1 + 4 + 3d\) when \(d \mid b\) and \(6s + 1\) otherwise, where \(s\) is the number of times the Euclidean algorithm, started from \((r, r') = (n, a)\), replaces \((r, r')\) by \((r' \bmod r, r)\) before \(r\) becomes \(0\): six arithmetic operations per such step, one divisibility test, four setup operations and three operations per returned residue.

    @[no_expose]
def modularLinearEquationSolver
    (a : Nat) (b : Int) (n : Nat) (_ha : 0 < a) (_hn : 0 < n) :
    TimeM Nat (Array Nat) :=
  let extended := countedXgcdAux n 1 0 a 0 1
  let d := extended.ret.1
  if (d : Int) ∣ b then
    let seed := (extended.ret.2.2 * (b / (d : Int))) % (n : Int)
    let stride := n / d
    let values := (List.range d).map (fun (i : Nat) =>
      ((seed + (i : Int) * (stride : Int)) % (n : Int)).toNat)
    ⟨values.toArray, extended.time + 1 + 4 + 3 * d⟩
  else
    ⟨#[], extended.time + 1⟩
    @[no_expose] private def countedXgcdAux
    (r : Nat) (s t : Int) (r' : Nat) (s' t' : Int) : TimeM Nat (Nat × Int × Int) :=
  if h : r = 0 then
    ⟨(r', s', t'), 0⟩
  else
    let q : Int := r' / r
    let next := countedXgcdAux (r' % r) (s' - q * s) (t' - q * t) r s t
    ⟨next.ret, next.time + 6⟩
termination_by r
decreasing_by exact Nat.mod_lt _ (Nat.pos_of_ne_zero h)

    TheoremCost bounds for the modular linear equation solver#✓fully proved

    Cslib.Algorithms.Lean.ModularLinearEquation.modularLinearEquationSolver_time_bounds

    Let \(a > 0\) and \(n > 0\) be natural numbers, \(b\) an integer and \(d = \gcd(a, n)\), and put \(c = 4 + 3d\) if \(d \mid b\) and \(c = 0\) otherwise. The cost \(T\) of the modular linear equation solver on \(a\), \(b\), \(n\) satisfies \(1 + c \le T \le 6(2 \lfloor \log_2 n \rfloor + 2) + 1 + c\).

    The cost counts arithmetic events, so this is the \(O(\log n + \gcd(a, n))\) bound of the source.

    theorem modularLinearEquationSolver_time_bounds
    (a : Nat) (b : Int) (n : Nat) (ha : 0 < a) (hn : 0 < n) :
    1 + (if (Nat.gcd a n : Int) ∣ b then 4 + 3 * Nat.gcd a n else 0)
      ≤ (modularLinearEquationSolver a b n ha hn).time ∧
    (modularLinearEquationSolver a b n ha hn).time
      ≤ 6 * (2 * Nat.log2 n + 2) + 1 +
        (if (Nat.gcd a n : Int) ∣ b then 4 + 3 * Nat.gcd a n else 0)
