    TheoremRadix-2 Cooley–Tukey splitting#✓fully proved

    MathlibExt.Analysis.Fourier.FastFourierTransformWanted.cooley_tukey

    For \(\omega \in \mathbb{C}\), \(f : \mathbb{N} \to \mathbb{C}\) and natural numbers \(N\) and \(k\), write \(D_N(\omega, f, k) = \sum_{j < N} \omega^{jk} f(j)\) for the discrete Fourier sum. Let \(n\) be a natural number and let \(\omega \in \mathbb{C}\) satisfy \(\omega^{2n} = 1\). Then for every \(f : \mathbb{N} \to \mathbb{C}\) and every natural number \(K\),

    \[D_{2n}(\omega, f, K) = D_n(\omega^2, f_0, K \bmod n) + \omega^K D_n(\omega^2, f_1, K \bmod n),\]

    where \(f_0(t) = f(2t)\), \(f_1(t) = f(2t + 1)\), and \(K \bmod n\) is the remainder of \(K\) on division by \(n\) (with \(K \bmod 0 = K\)). So a length-\(2n\) transform is two length-\(n\) transforms on the even and odd samples, combined with the twiddle factor \(\omega^K\).

    Proof: Split the range into even and odd indices, rewrite the powers, and use root-of-unity periodicity to reduce the frequency modulo \(n\), as in the section "The radix-2 DIT case" of Wikipedia, "Cooley–Tukey FFT algorithm".

    public theorem cooley_tukey (n : ℕ) (ω : ℂ) (hω : ω ^ (2 * n) = 1)
    (f : ℕ → ℂ) (K : ℕ) :
    dftSum (2 * n) ω f K =
      dftSum n (ω ^ 2) (fun t => f (2 * t)) (K % n) +
        ω ^ K * dftSum n (ω ^ 2) (fun t => f (2 * t + 1)) (K % n)
    def dftSum (N : ℕ) (ω : ℂ) (f : ℕ → ℂ) (k : ℕ) : ℂ :=
  ∑ j ∈ Finset.range N, ω ^ (j * k) * f j

    DefinitionOne FFT butterfly#✓fully proved

    Cslib.Algorithms.Lean.TimeM.fftButterfly

    For a commutative ring \(R\), an element \(\omega \in R\), vectors \(q, r \in R^m\), a state \((w, y)\) with \(w \in R\) and \(y \in R^{2m}\), and an index \(k < m\), the butterfly at \(k\) returns the state \((w \omega, y')\), where \(y'\) is obtained from \(y\) by setting entry \(k\) to \(q_k + w r_k\) and entry \(k + m\) to \(q_k - w r_k\), at a time cost of \(8\).

    def fftButterfly {m : Nat} (omega : R) (q r : Vector R m)

  let a := q[k.val]
  let b := r[k.val]
  let t := w * b

    DefinitionRadix-two fast Fourier transform#✓fully proved

    Cslib.Algorithms.Lean.TimeM.fft

    For a commutative ring \(R\), a natural number \(d\), an element \(\omega \in R\) and a vector \(x \in R^{2^d}\), the FFT of \(x\) with root \(\omega\) is defined by recursion on \(d\). For \(d = 0\) it returns \(x\) at cost \(0\). For \(d + 1\) it splits \(x\) into its even- and odd-indexed subvectors \(e, o \in R^{2^d}\) (cost \(4 \cdot 2^d\)), computes \(\omega^2\) (cost \(1\)), computes the FFTs \(q\) of \(e\) and \(r\) of \(o\) with root \(\omega^2\), writes a zero vector \(y \in R^{2^{d+1}}\) (cost \(2^{d+1}\)), and returns the vector part of the result of the butterfly pass with \(\omega\), \(q\) and \(r\) on \(y\). Its time cost is the sum of the costs of all these steps.

    The two transformed halves are stored once and combined with a running twiddle factor. No assumption on \(\omega\) is needed to run the algorithm; one is needed only for its correctness.

    def fft : (d : Nat) → R → Vector R (2 ^ d) → TimeM Nat (Vector R (2 ^ d))
  | 0, _, xs => pure xs
  | d + 1, omega, xs => do
      let halves ← fftSplit xs
      let square ← (⟨omega * omega, 1⟩ : TimeM Nat R)
      let q ← fft d square halves.1
      let r ← fft d square halves.2
      let out ← (⟨Vector.replicate (2 ^ d * 2) 0, 2 ^ d * 2⟩ :
        TimeM Nat (Vector R (2 ^ d * 2)))
      let combined ← fftButterflies omega q r out
      pure combined.2
