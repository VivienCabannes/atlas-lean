    DefinitionThe Miller–Rabin squaring loop#✓fully proved

    Cslib.Algorithms.Lean.MillerRabin.witnessLoop

    Fix a modulus \(n\). With no squarings remaining, the loop at the current value \(x\) reports a witness exactly when \(x \ne 1\), at no cost. With \(k + 1\) squarings remaining, it costs one modular multiplication and computes \(y = x^2 \bmod n\); it reports a witness if \(y = 1\), \(x \ne 1\) and \(x \ne n - 1\), and otherwise continues at \(y\) with \(k\) squarings remaining.

    Here \(x^2 \bmod 0 = x^2\), and \(n - 1\) is \(0\) when \(n = 0\).

    def witnessLoop (n : ℕ) : ℕ → ℕ → TimeM ℕ Bool
  | 0, x => pure (x != 1)
  | k + 1, x => do
      ✓
      let y := x * x % n
      if y = 1 ∧ x ≠ 1 ∧ x ≠ n - 1 then pure true else witnessLoop n k y

    DefinitionMiller–Rabin witness test#✓fully proved

    Cslib.Algorithms.Lean.MillerRabin.witness

    For natural numbers \(a\) and \(n\), write \(n - 1 = 2^t u\) with \(u\) odd (here \(n - 1\) is truncated at \(0\), and \(t = u = 0\) when \(n \le 1\)). The test sets \(x_0\) to the result of modular exponentiation of \(a\) to the power \(u\) modulo \(n\), which is \(a^u \bmod n\) when \(u > 0\) and \(1\) when \(u = 0\). For \(i = 1, \dots, t\) it computes \(x_i = x_{i-1}^2 \bmod n\) and returns true as soon as \(x_i = 1\), \(x_{i-1} \ne 1\) and \(x_{i-1} \ne n - 1\). If no such step occurs, it returns true exactly when \(x_t \ne 1\). Its cost is the cost of the modular exponentiation plus one for each squaring performed.

    For a base with \(0 < a < n\), the answer true proves that \(n\) is composite; outside that range the answer carries no such guarantee (for example, the test returns true for \(a = n = 2\)), as in CLRS, whose bases are drawn from \(1, \dots, n - 1\).

    def witness (a n : ℕ) : TimeM ℕ Bool := do
  let tu := twoAdicSplit (n - 1)
  let x ← modularExponentiation a tu.2 n
  witnessLoop n tu.1 x

    DefinitionThe Miller–Rabin test#✓fully proved

    Cslib.Algorithms.Lean.MillerRabin.millerRabin

    Given a natural number \(n\) and a list of bases \(a_1, \dots, a_s\), the test runs the witness test for \(n\) on each base in turn. It answers composite as soon as some base \(a_i\) is a witness to the compositeness of \(n\), and prime if none is (in particular on the empty list). Its cost is the sum of the costs of the witness tests it runs.

    This is CLRS MILLER-RABIN(n, s) with the bases given explicitly instead of drawn by RANDOM(1, n - 1). A composite answer is guaranteed correct only when every base lies in \(1, \dots, n - 1\).

    def millerRabin (n : ℕ) : List ℕ → TimeM ℕ Bool
  | [] => pure true
  | a :: as => do
      let w ← witness a n
      if w then pure false else millerRabin n as
    def witness (a n : ℕ) : TimeM ℕ Bool := do
