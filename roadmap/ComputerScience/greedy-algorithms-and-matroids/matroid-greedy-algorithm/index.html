    Cslib.Algorithms.Lean.TimeM.matroidGreedyScan

    Given an oracle \(O\) that accepts or rejects each finite subset of a type \(\alpha\), a finite set \(S \subseteq \alpha\) and a list \(e_1, \dots, e_n\) of elements of \(\alpha\), the greedy scan processes \(e_1, \dots, e_n\) in order, starting with \(S\) as the current set: it replaces the current set \(T\) by \(T \cup \{e_i\}\) if \(O\) accepts \(T \cup \{e_i\}\), and leaves it unchanged otherwise. It returns the final current set and charges one unit of time per element processed.

    def matroidGreedyScan (indep : Finset α → Bool) (S : Finset α) : List α → TimeM ℕ (Finset α)
  | [] => pure S
  | e :: es => do
      ✓
      if indep (insert e S) then matroidGreedyScan indep (insert e S) es
      else matroidGreedyScan indep S es

    Cslib.Algorithms.Lean.TimeM.matroidGreedy

    Given an oracle \(O\) that accepts or rejects each finite subset of a type \(\alpha\) and a list \(L\) of elements of \(\alpha\), the greedy algorithm starts from the empty set, processes the elements of \(L\) in order, adds an element \(e\) to the current set \(T\) when \(O\) accepts \(T \cup \{e\}\) and leaves \(T\) unchanged otherwise, and returns the final set. It charges one unit of time per element processed.

    def matroidGreedy (indep : Finset α → Bool) (es : List α) : TimeM ℕ (Finset α) :=
  matroidGreedyScan indep ∅ es

    DefinitionGreedy optimality#✓fully proved

    Cslib.Algorithms.Lean.TimeM.GreedyOptimal

    Let \(\alpha\) be a finite type and let \(\mathrm{indep}\) be an independence oracle on the finite subsets of \(\alpha\). The greedy algorithm is optimal for \(\mathrm{indep}\) when, for every weight function \(w : \alpha \to \mathbb{N}\) and every list \(L\) that contains every element of \(\alpha\) exactly once, in nonincreasing order of \(w\), the set \(T\) returned by the matroid greedy algorithm on \(L\) with oracle \(\mathrm{indep}\) satisfies \(\sum_{x \in I} w(x) \le \sum_{x \in T} w(x)\) for every finite set \(I\) independent under \(\mathrm{indep}\).

    Finiteness of \(\alpha\) keeps this from holding vacuously: on an infinite type no list contains every element.

    @[nolint unusedArguments]
def GreedyOptimal [Finite α] (indep : Finset α → Bool) : Prop :=
  ∀ (w : α → ℕ) (es : List α), es.Nodup → (∀ x, x ∈ es) →
    (es.Pairwise fun a b => w b ≤ w a) →
      ∀ I, indep I = true → ∑ x ∈ I, w x ≤ ∑ x ∈ (matroidGreedy indep es).ret, w x
    def matroidGreedy (indep : Finset α → Bool) (es : List α) : TimeM ℕ (Finset α) :=
  matroidGreedyScan indep ∅ es
