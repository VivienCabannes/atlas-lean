    Cslib.Algorithms.Lean.SortingNetworks.Bitonic.levels

    Given a list of comparators on \(\mathbb{N}\)-indexed wires, each a pair \((i, j)\) of wires, and a starting level \(\ell(x)\) for every wire \(x\), process the comparators in order, keeping a current level for each wire, initially \(\ell\): a comparator \((i, j)\) whose wires currently have levels \(a\) and \(b\) sets the current levels of both wires \(i\) and \(j\) to \(\max(a, b) + 1\) and leaves every other level unchanged. The result is the level of each wire after all the comparators, that is, when each comparator runs as early as possible, one level after the later of its two wires.

    def levels : List (ℕ × ℕ) → (ℕ → ℕ) → ℕ → ℕ
  | [], lv => lv
  | c :: ps, lv => levels ps fun x =>
      if x = c.1 ∨ x = c.2 then max (lv c.1) (lv c.2) + 1 else lv x

    DefinitionTabulated levels#✓fully proved

    Cslib.Algorithms.Lean.SortingNetworks.Bitonic.levelsTab

    Given a list \(ps\) of comparators and a table \(t\) of natural numbers \(t_0, \dots, t_{N-1}\), the tabulated levels are computed by processing the comparators in order: a comparator \((i, j)\) sets both entries \(t_i\) and \(t_j\) to \(\max(t_i, t_j) + 1\), where an entry outside the table reads as \(0\) and a write outside the table is ignored.

    Evaluating the levels directly re-reads both wires' earlier levels at every comparator, a cost exponential in the depth; this computes the same values in time proportional to the network size times \(N\).

    def levelsTab : List (ℕ × ℕ) → List ℕ → List ℕ
  | [], t => t
  | c :: ps, t =>
      levelsTab ps ((t.set c.1 (max (t.getD c.1 0) (t.getD c.2 0) + 1)).set c.2
        (max (t.getD c.1 0) (t.getD c.2 0) + 1))

    Cslib.Algorithms.Lean.SortingNetworks.Bitonic.influence

    Given a list \(ps\) of comparators on wires indexed by \(\mathbb{N}\) and an assignment \(S\) of a finite set of natural numbers to each wire, the influence sets after \(ps\) are computed by processing the comparators in order: a comparator \((i, j)\) replaces the current sets of both wires \(i\) and \(j\) by their union, and leaves the sets of all other wires unchanged.
