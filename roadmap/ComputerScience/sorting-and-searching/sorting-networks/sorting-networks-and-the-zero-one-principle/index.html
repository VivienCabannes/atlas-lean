    Cslib.Algorithms.Lean.SortingNetworks.comparator

    Let \(\alpha\) be a linear order, let \(n\) be a natural number, and let \(v\) assign a value \(v(k) \in \alpha\) to each wire \(k \in \{0, \dots, n - 1\}\). For wires \(i\) and \(j\), the comparator \((i, j)\) sends \(v\) to the assignment that has \(\min(v(i), v(j))\) on wire \(i\), \(\max(v(i), v(j))\) on wire \(j\) when \(j \ne i\), and \(v(k)\) on every other wire \(k\).

    def comparator (i j : Fin n) (v : Fin n → α) : Fin n → α :=
  fun k => if k = i then min (v i) (v j) else if k = j then max (v i) (v j) else v k

    DefinitionNetworks that sort#✓fully proved

    Cslib.Algorithms.Lean.SortingNetworks.Sorts

    A comparator network on \(n\) wires sorts inputs over a linearly ordered type \(\alpha\) if, for every input \(v\) assigning a value in \(\alpha\) to each wire, the output of running the network on \(v\) is monotone in the wire order: for all wires \(i \le j\), the output value on wire \(i\) is at most the output value on wire \(j\).

    def Sorts (net : Network n) (α : Type*) [LinearOrder α] : Prop :=
  ∀ v : Fin n → α, Monotone (run net v)

    Cslib.Algorithms.Lean.SortingNetworks.comparator_comp

    DefinitionBoolean sorting test#✓fully proved

    Cslib.Algorithms.Lean.SortingNetworks.sortsBool

    The Boolean sorting test of a comparator network on \(n\) wires returns true exactly when, for every assignment \(v\) of a Boolean value to each wire, the output \(w\) of the network on \(v\) satisfies \(w(i) \le w(j)\) for all wires \(i \le j\), where \(\mathrm{false} < \mathrm{true}\).

    It is computed by running the network on all \(2^n\) Boolean inputs.

    def sortsBool (net : Network n) : Bool :=
  decide (∀ v : Fin n → Bool, ∀ i j : Fin n, i ≤ j → run net v i ≤ run net v j)

    DefinitionSpread of a Boolean input#✓fully proved

    Cslib.Algorithms.Lean.SortingNetworks.spread

    For a Boolean input \(v\) on \(n\) wires, the spread of \(v\) is the input with natural-number values whose value on wire \(i < n\) is \(n + i\) if \(v(i)\) is true and \(i\) if \(v(i)\) is false.

    The values of the spread are pairwise distinct.

    def spread (v : Fin n → Bool) (i : Fin n) : ℕ := (if v i then n else 0) + i

    TheoremA Boolean input is a threshold of its spread#✓fully proved

    Cslib.Algorithms.Lean.SortingNetworks.decide_le_spread

    For every Boolean input \(v\) on \(n\) wires, applying the threshold map that sends a natural number \(k\) to true if \(n \le k\) and to false otherwise to the spread of \(v\) gives back \(v\): for every wire \(i\), the spread of \(v\) at \(i\) is at least \(n\) exactly when \(v(i)\) is true.

    Since the threshold map is monotone, \(v\) is a monotone image of its spread.

    theorem decide_le_spread (v : Fin n → Bool) : (fun k => decide (n ≤ k)) ∘ spread v = v
    def spread (v : Fin n → Bool) (i : Fin n) : ℕ := (if v i then n else 0) + i

    DefinitionRank among the values of an input#✓fully proved

    Cslib.Algorithms.Lean.SortingNetworks.rank

    For a map \(w\) from \(\{0, \dots, n-1\}\) to the natural numbers and an index \(i < n\), the rank of \(w(i)\) among the values of \(w\) is the number of indices \(j < n\) with \(w(j) < w(i)\). It is less than \(n\), so it is again an index in \(\{0, \dots, n-1\}\).

    DefinitionThe ranking permutation#✓fully proved

    Cslib.Algorithms.Lean.SortingNetworks.rankPerm

    For an injective map \(w\) from \(\{0, \dots, n-1\}\) to the natural numbers, the ranking permutation of \(w\) is the permutation of \(\{0, \dots, n-1\}\) that sends each \(i\) to the rank of \(w(i)\) among the values of \(w\), that is, to the number of indices \(j\) with \(w(j) < w(i)\). Since \(w\) is injective, this map is a bijection.

    The ranking permutation has the same relative order as \(w\).

    noncomputable def rankPerm {w : Fin n → ℕ} (hw : Function.Injective w) : Equiv.Perm (Fin n) :=
  Equiv.ofBijective (rank w) (Finite.injective_iff_bijective.1 (rank_injective hw))
