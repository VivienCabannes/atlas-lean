    Cslib.Algorithms.Lean.SortingNetworks.OddEven.runN_finalLayer

    Let \(\alpha\) be a linearly ordered type, \(k \in \mathbb{N}\) and \(f : \mathbb{N} \to \alpha\) an assignment of values to the wires. Running the final layer for \(k\) on \(f\) gives at a wire \(x\) the value \(\min(f(x), f(x + 1))\) if \(x\) is odd and \(\lfloor x / 2 \rfloor < 2^{k+1} - 1\); otherwise the value \(\max(f(x - 1), f(x))\) if \(x\) is even, \(x > 0\) and \((x - 2) / 2 < 2^{k+1} - 1\); and the value \(f(x)\) in all other cases.     theorem runN_finalLayer {α : Type*} [LinearOrder α] (k : ℕ) (f : ℕ → α) (x : ℕ) :
    runN (finalLayer k) f x =
      if x % 2 = 1 ∧ x / 2 < 2 ^ (k + 1) - 1 then min (f x) (f (x + 1))
      else if x % 2 = 0 ∧ 0 < x ∧ (x - 2) / 2 < 2 ^ (k + 1) - 1 then max (f (x - 1)) (f x)
      else f x
    def runN (ps : List (ℕ × ℕ)) (f : ℕ → α) : ℕ → α :=
