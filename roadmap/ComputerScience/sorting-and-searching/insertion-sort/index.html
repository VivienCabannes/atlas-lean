    Cslib.Algorithms.Lean.TimeM.insertionSortInsert

    Let \(a\) be an element of a linearly ordered type. Inserting \(a\) into the empty list returns \([a]\) at no cost. Inserting \(a\) into a list with head \(b\) and tail \(l\) first charges one unit for comparing \(a \le b\); if \(a \le b\) it returns \(a\) followed by \(b\) and \(l\), and otherwise it inserts \(a\) into \(l\), adding that cost, and returns \(b\) followed by the result.

    def insertionSortInsert (a : α) : List α → TimeM Nat (List α)
  | [] => pure [a]
  | b :: xs => TimeM.bind (compareLE a b) fun before =>
      if before then pure (a :: b :: xs)
      else TimeM.bind (insertionSortInsert a xs) fun tail => pure (b :: tail)
    abbrev compareLE (x y : α) : TimeM Nat Bool := do
  ✓ return decide (x ≤ y)

    Cslib.Algorithms.Lean.TimeM.insertionSort

    On a list over a linearly ordered type, insertion sort returns the empty list at no cost when the input is empty. On a list with head \(a\) and tail \(l\), it sorts \(l\) and then inserts \(a\) into the result by costed insertion; its cost is the cost of sorting \(l\) plus the cost of that insertion. Exactly one unit is charged for each order comparison.

    def insertionSort : List α → TimeM Nat (List α)
  | [] => pure []
  | a :: xs => TimeM.bind (insertionSort xs) (insertionSortInsert a)
