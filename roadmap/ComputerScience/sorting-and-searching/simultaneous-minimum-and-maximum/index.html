    Cslib.Algorithms.Lean.TimeM.minMax

    Given a list \(xs\) over a linearly ordered type, the paired algorithm returns no result when \(xs\) is empty and otherwise returns a pair (a candidate minimum and a candidate maximum), counting one unit of time for each comparison of elements. On a one-element list \([a]\) it returns \((a, a)\) without a comparison. On a longer list of odd length both candidates start at the first element without a comparison; on a list of even length they start at the smaller and the larger of the first two elements, found with one comparison. The remaining elements are then taken in consecutive pairs: one comparison orders the pair, its smaller member replaces the candidate minimum if it is strictly smaller (one comparison), and its larger member replaces the candidate maximum if it is strictly larger (one comparison).

    public def minMax {α : Type u} [LinearOrder α] (xs : List α) :
    TimeM Nat (Option (α × α)) :=
  match xs with
  | [] => pure none
  | [a] => pure (some (a, a))
  | a :: b :: rest =>
      if xs.length % 2 = 1 then
        some <$> scanPairs a a (b :: rest)
      else do
        let pair ← orderPair a b
        some <$> scanPairs pair.1 pair.2 rest
    @[no_expose] private def scanPairs {α : Type u} [LinearOrder α] (lo hi : α) :
    List α → TimeM Nat (α × α)
  | [] => pure (lo, hi)
  | [a] => do
      tick 1
      let lo' := if a < lo then a else lo
      tick 1
      let hi' := if hi < a then a else hi
      pure (lo', hi')
  | a :: b :: xs => do
      let pair ← orderPair a b
      tick 1
  ⋯

    Cslib.Algorithms.Lean.TimeM.minMax_eq_some_iff

    For every list \(xs\) over a linearly ordered type and all elements \(lo\) and \(hi\) of that type, the simultaneous minimum and maximum algorithm returns the pair \((lo, hi)\) on \(xs\) if and only if \(lo\) and \(hi\) both belong to \(xs\), \(lo \le x\) for every \(x\) in \(xs\), and \(x \le hi\) for every \(x\) in \(xs\).

    theorem minMax_eq_some_iff {α : Type u} [LinearOrder α] (xs : List α) (lo hi : α) :
    (minMax xs).ret = some (lo, hi) ↔
      lo ∈ xs ∧ hi ∈ xs ∧ (∀ x ∈ xs, lo ≤ x) ∧ (∀ x ∈ xs, x ≤ hi)

    Cslib.Algorithms.Lean.TimeM.minMax_time

    For every list of length \(n\) over a linearly ordered type, the simultaneous minimum and maximum algorithm makes no comparisons when \(n = 0\) and exactly \(\lceil 3n/2 \rceil - 2\) comparisons when \(n \ge 1\).

    This counts element-order decisions, not full RAM instructions or comparator bit complexity.

    theorem minMax_time {α : Type u} [LinearOrder α] (xs : List α) :
