    DefinitionBucket sort#✓fully proved

    Cslib.Algorithms.Lean.TimeM.bucketSort

    Let \(R\) be a linearly ordered field with a floor function and let \(x_1, \dots, x_n\) be an array of elements of \(R\) that all lie in \([0, 1)\). If \(n = 0\), bucket sort returns the empty array at zero cost. Otherwise it creates \(n\) empty buckets indexed by \(0, \dots, n - 1\), visits the entries in order and prepends each entry \(x\) to bucket \(\lfloor n x \rfloor\), sorts each bucket with insertion sort, and concatenates the sorted buckets in increasing order of index. The cost is \(n\) for creating the buckets, plus one per entry placed, plus one per bucket sorted together with the comparisons insertion sort makes on it, plus one per bucket and one per entry during concatenation.

    public def bucketSort {R : Type} [Field R] [LinearOrder R]
    [IsStrictOrderedRing R] [FloorRing R] (xs : Array R)
    (hx : ∀ x ∈ xs.toList, x ∈ Ico (0 : R) 1) : TimeM Nat (Array R) :=
  if hn : 0 < xs.size then do
    let initial : _root_.Vector (List R) xs.size := _root_.Vector.replicate xs.size []
    ✓[xs.size]
    let buckets ← placeBuckets xs hx hn initial
    let sorted ← buckets.mapM (m := TimeM Nat) (fun bucket => do
      ✓
      TimeM.insertionSort bucket)
    flattenBuckets sorted
  else pure #[]

    TimeM Nat (_root_.Vector (List R) xs.size) :=
