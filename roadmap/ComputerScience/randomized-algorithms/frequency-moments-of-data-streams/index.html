    Frequency moments of data streams

    A stream \(a_1, \dots, a_m\) of elements of \(\{1, \dots, n\}\) is read once by an algorithm with little memory. With \(m_i\) the number of occurrences of \(i\), the frequency moments are \(F_k = \sum_i m_i^k\) and \(F^*_\infty = \max_i m_i\). Alon, Matias and Szegedy showed that \(F_2\) can be approximated to within a factor \(1 \pm \lambda\) with probability \(1 - \varepsilon\) in \(O(\lambda^{-2} \log(1/\varepsilon)(\log n + \log m))\) bits: keep the linear sketch \(Z = \sum_i \varepsilon_i m_i\) for four-wise independent random signs \(\varepsilon_i\), so that \(\mathbb{E}[Z^2] = F_2\) and \(\operatorname{Var}(Z^2) \le 2 F_2^2\); average \(16/\lambda^2\) independent copies (Chebyshev) and take the median of \(O(\log(1/\varepsilon))\) such averages. For general \(k \ge 1\) the same scheme applies to \(X = m(r^k - (r-1)^k)\), where \(r\) counts the occurrences of a uniformly random stream element from its position on: \(\mathbb{E}[X] = F_k\) and \(\mathbb{E}[X^2] \le k n^{1-1/k} F_k^2\), giving \(O(k \lambda^{-2} \log(1/\varepsilon) n^{1-1/k}(\log n + \log m))\) bits. In contrast, \(F^*_\infty\) needs \(\Omega(n)\) bits and \(F_k\) for \(k \ge 6\) needs \(\Omega(n^{1-5/k})\) bits: an algorithm with \(s\) bits of memory yields a communication protocol for set disjointness in which the memory content is the message. The presentation follows N. Alon, Y. Matias and M. Szegedy, "The space complexity of approximating the frequency moments", J. Comput. System Sci. 58 (1999) 137–147 (STOC 1996).

    Proved here: the first two moments of both estimators, the inequality \(F_1 F_{2k-1} \le n^{1-1/k} F_k^2\), and the full median-of-means guarantee for \(F_2\). Not formalized: the space accounting of the upper bounds (an explicit four-wise independent family of \(O(n^2)\) sign vectors from BCH codes, reservoir sampling of the position when \(m\) is unknown) and the end-to-end probability statement for \(F_k\), \(k \ne 2\). The two space lower bounds are stated as wanted results in the public-randomness model, where the random seed is not charged to the memory; this is harmless because the source's reductions use the seed only as the public coin of a communication protocol (see the model).

    TheoremSuffix counts enumerate each multiplicity once#✓fully proved

    MathlibExt.Probability.Streaming.AMS.sum_suffixCount

    For every g : ℕ → ℝ and stream l, ∑_p g(r_p) = ∑ᵢ ∑_{r=1}^{mᵢ} g(r): the suffix counts of the positions holding symbol i are exactly 1, …, mᵢ.     TheoremThe AMS estimator is unbiased for F_k#✓fully proved

    MathlibExt.Probability.Streaming.AMS.average_basicEstimator

    For k ≥ 1 and every stream l of length m, the average of X = m (r_p^k - (r_p - 1)^k) over the m positions p is F_k = ∑ᵢ mᵢ^k: if p is uniform, E[X] = F_k (N. Alon, Y. Matias and M. Szegedy, J. Comput. System Sci. 58 (1999), proof of Theorem 2.1). For the empty stream both sides are 0.

    The sum telescopes: the positions holding symbol \(i\) have suffix counts \(1, \dots, m_i\), and \(\sum_{r=1}^{m_i} (r^k - (r-1)^k) = m_i^k\). The hypothesis \(k \ge 1\) is needed: for \(k = 0\) the estimator is identically \(0\).

    theorem average_basicEstimator [Fintype ι] (k : ℕ) (hk : 1 ≤ k) (l : List ι) :
    (1 / l.length : ℝ) * ∑ p, basicEstimator k l p = ∑ i, (l.count i : ℝ) ^ k

    DefinitionFour-wise independent random variables#✓fully proved

    MathlibExt.Probability.Streaming.AMS.FourWiseIndependent

    A family ε : ι → Ω → ℝ is four-wise independent under μ if every subfamily indexed by a finite set of at most four indices is mutually independent (N. Alon, Y. Matias and M. Szegedy, J. Comput. System Sci. 58 (1999), proof of Theorem 2.2, where the signs are drawn from an orthogonal array of strength 4).

    The source realizes such signs with an explicit set of \(O(n^2)\) vectors in \(\{-1,1\}^n\) (an orthogonal array of strength 4, from the parity-check matrices of BCH codes), so that the seed takes \(O(\log n)\) bits. Only the independence property is formalized here.

    def FourWiseIndependent (ε : ι → Ω → ℝ) (μ : Measure Ω) : Prop :=
  ∀ S : Finset ι, S.card ≤ 4 → iIndepFun (fun i : S => ε i) μ

    StructureRandomized streaming algorithm with s bits of memory#✓fully proved

    MathlibExt.Probability.Streaming.StreamingAlgorithm

    A one-pass algorithm over an alphabet \(\alpha\) whose state is one of \(2^s\) memory contents, given by an initial state, a transition reading one stream element, and a real output, all depending on a random seed \(r\) drawn uniformly from a finite nonempty set \(R\). This is the model of the source, Section 1, with one difference: the seed is not counted in the memory. That is the standard public-randomness (random-oracle) streaming model.

    The source's algorithms keep their random bits in memory or draw them during the pass, so they are special cases with the same memory. A space lower bound in this model is therefore at least as strong as the source's. The source's two lower bounds remain true in it, because their proofs use the seed only as the public coin of a communication protocol:

    • Proposition 3.1: Alice and Bob share \(r\). Alice runs the algorithm on the elements of \(x\) and sends the \(s\)-bit memory content; Bob finishes the run on \(y\). This is a one-way public-coin protocol for disjointness of cost \(s + O(1)\), and the disjointness lower bound holds for public-coin protocols.
    • Theorem 3.2: the multiparty bound (Proposition 3.3) is proved against a fixed input distribution. After amplifying by independent copies (seed space \(R^k\), memory \(ks\) bits, still an algorithm of this model) and averaging the error over that distribution, one seed can be fixed. That gives a deterministic protocol, so the size of \(R\) never enters.

    The statement is in the public-randomness model, where the random seed is not charged to the memory. That makes it at least as strong as the source's, and the source's proof still applies:

    • Alice and Bob share the seed as a public coin. Alice runs the algorithm on the elements of \(x\) and sends the \(s\)-bit memory content.
