    Cslib.Algorithms.Lean.TimeM.expectedTime

    Let \(A\) be an algorithm on inputs of a type \(\gamma\) whose running time \(T_A(x)\) on each input \(x\) is a natural number, and let \(D\) be a probability mass function on \(\gamma\). The expected running time of \(A\) under \(D\) is the extended nonnegative expectation \(\sum_{x \in \gamma} D(x)\, T_A(x) \in [0, \infty]\) of the running time, the sum taken over all inputs.

    Valuing the expectation in \([0, \infty]\) records a divergent expected time as \(\infty\); a real-valued integral would collapse it to \(0\).

    noncomputable def expectedTime (algo : γ → TimeM Nat β)
    (dist : PMF γ) : ℝ≥0∞ :=
  dist.expectENN (fun xs => ((algo xs).time : ℝ≥0∞))

    Cslib.Algorithms.Lean.TimeM.expectedTime_eq_of_time_eq

    Let \(A\) be an algorithm on inputs of a type \(\gamma\) whose running time \(T_A(x)\) on each input \(x\) is a natural number, let \(D\) be a probability mass function on \(\gamma\), and let \(c\) be a natural number. If \(T_A(x) = c\) for every input \(x\) in the support of \(D\), then the expected running time of \(A\) under \(D\) equals \(c\).

    Cslib.Algorithms.Lean.TimeM.expectedTime_uniformPermutation_toReal

    Let \(A\) be an algorithm on lists whose running time \(T_A(y)\) on each list \(y\) is a natural number, and let \(x = (x_0, \dots, x_{n-1})\) be a list of length \(n\). The expected running time of \(A\) when its input is \(x\) rearranged by a uniformly random permutation, converted from \([0, \infty]\) to a real number, equals

    \[\frac{1}{n!} \sum_{\sigma} T_A(x_{\sigma(0)}, \dots, x_{\sigma(n-1)}),\]

    the sum running over all permutations \(\sigma\) of \(\{0, \dots, n-1\}\) and computed in \(\mathbb{R}\).

    Every term of the average is a natural number, so the expected time is finite and the conversion loses nothing.
