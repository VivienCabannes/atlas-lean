    DefinitionFreivalds trial#✓fully proved

    Cslib.Algorithms.Lean.Matrix.freivaldsTrial

    Given \(n \times n\) matrices \(A\), \(B\), \(C\) over \(\mathbb{F}_2 = \mathbb{Z}/2\), stored as arrays of rows, and a seed \(r \in \mathbb{F}_2^n\), the trial computes the column vectors \(Br\), \(A(Br)\) and \(Cr\), each by accumulating matrix products into a zero column, and returns true exactly when \(A(Br) = Cr\). Its cost is the pair (number of scalar multiplications, number of scalar additions), each multiply-add step counting one of each.

    The coefficient domain is \(\mathbb{F}_2\) by intentional specialization, not by a restriction in the cited source.

    public def freivaldsTrial {n : Nat}
    (A B C : _root_.Vector (_root_.Vector (ZMod 2) n) n)
    (r : Fin n → ZMod 2) : TimeM (Nat × Nat) Bool := do
  let column := seedColumn r
  let initial := zeroColumn n
  let br ← rectangularMatrixAccumulate B column initial
  let abr ← rectangularMatrixAccumulate A br initial
  let cr ← rectangularMatrixAccumulate C column initial
  pure (decide (abr = cr))
    @[no_expose] private def seedColumn {n : Nat} (r : Fin n → ZMod 2) :
    _root_.Vector (_root_.Vector (ZMod 2) 1) n :=
  _root_.Vector.ofFn fun i => _root_.Vector.replicate 1 (r i)

    Let \(A\), \(B\), \(C\) be \(n \times n\) matrices over \(\mathbb{F}_2\) with \(AB \ne C\). Then twice the number of seeds \(r \in \mathbb{F}_2^n\) on which the Freivalds trial returns true is at most the number of all seeds in \(\mathbb{F}_2^n\); that is, at most half of the seeds accept.

    DefinitionFreivalds trial law#✓fully proved

    Cslib.Algorithms.Lean.Matrix.freivaldsTrialLaw

    For \(n \times n\) matrices \(A\), \(B\), \(C\) over \(\mathbb{F}_2 = \mathbb{Z}/2\mathbb{Z}\), given as arrays, the Freivalds trial law is the probability distribution on \(\{\mathrm{true}, \mathrm{false}\}\) of the value returned by the Freivalds trial on \(A\), \(B\), \(C\) with seed \(r\), where \(r\) is drawn uniformly from \(\mathbb{F}_2^n\).

    The seeds are exactly uniform; no pseudorandom generator or assumed error probability is involved.

    noncomputable def freivaldsTrialLaw {n : Nat}
    (A B C : _root_.Vector (_root_.Vector (ZMod 2) n) n) : PMF Bool :=
  (Cslib.Probability.PMF.uniformOfFintype (Fin n → ZMod 2)).map
    fun r => (freivaldsTrial A B C r).ret

    Cslib.Algorithms.Lean.Matrix.freivaldsRepeat

    Given \(n \times n\) matrices \(A\), \(B\), \(C\) over \(\mathbb{Z}/2\) and seeds \(r_0, \dots, r_{k-1} \in (\mathbb{Z}/2)^n\), run the Freivalds trial on \(A\), \(B\), \(C\) with each seed \(r_0, \dots, r_{k-1}\) in order, including the trials after a rejection, and return the conjunction of their results (true when \(k = 0\)).   (List.ofFn history).foldlM (repeatStep A B C) true

  let current ← freivaldsTrial A B C r
