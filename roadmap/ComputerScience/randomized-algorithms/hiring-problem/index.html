    DefinitionThe hire-assistant scan#✓fully proved

    Cslib.Algorithms.Lean.TimeM.hireAssistant

    Given candidates \(x_0, \dots, x_{n-1}\) in a linearly ordered type, the scan interviews them in order while keeping a current manager, initially none, which counts as below every candidate. Candidate \(i\) is hired exactly when \(x_i\) is strictly greater than the value of the current manager, and then becomes the new manager; ties keep the earlier manager. The scan returns the zero-based index of the final manager (none for the empty list) and the list of hired indices in the order they were hired, and its cost is the pair (number of interviews, number of hires).

    public def hireAssistant {α : Type u} [LinearOrder α] (xs : List α) :
    TimeM (Nat × Nat) (Option Nat × List Nat) :=
  let state : TimeM (Nat × Nat) (Option (α × Nat) × Array Nat) :=
    xs.zipIdx.foldlM (interview (α := α)) (none, #[])
  ⟨(state.ret.1.map Prod.snd, state.ret.2.toList), state.time⟩
    @[no_expose] private def interview {α : Type u} [LinearOrder α]
    (state : Option (α × Nat) × Array Nat) (candidate : α × Nat) :
    TimeM (Nat × Nat) (Option (α × Nat) × Array Nat) := do
  tick (1, 0)
  let winner := List.argAux (fun new old : α × Nat => old.1 < new.1) state.1 candidate
  if winner.map Prod.snd == some candidate.2 then
    tick (0, 1)
    pure (winner, state.2.push candidate.2)
  else
    pure (winner, state.2)

    Cslib.Algorithms.Lean.TimeM.hireAssistant_expectedHires

    Let \(x\) be a list of \(n\) pairwise distinct elements of a linearly ordered type, and rearrange its entries by a uniformly random permutation of the indices. The expected number of hires, valued in \([0, \infty]\), that the hire-assistant procedure (interview the entries in order, hiring each one strictly better than every earlier one) makes on the rearranged list equals \(\sum_{i=0}^{n-1} \frac{1}{i+1}\).
