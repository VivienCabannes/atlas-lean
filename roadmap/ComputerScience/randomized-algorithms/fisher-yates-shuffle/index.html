    Cslib.Algorithms.Lean.TimeM.randomlyPermute

    Given a vector \(x = (x_0, \dots, x_{n-1})\) and a draw history \(d\), which assigns to each position \(i < n\) a number \(d_i\) with \(0 \le d_i < n - i\), the Fisher–Yates computation processes the positions \(i = 0, 1, \dots, n - 1\) in increasing order and at position \(i\) swaps the entries at positions \(i\) and \(i + d_i\) of the current vector. It returns the final vector together with a cost pair in \(\mathbb{N} \times \mathbb{N}\): each retrieved draw adds \((1, 0)\) and each swap adds \((0, 1)\).

    public def randomlyPermute {α : Type u} {n : Nat} (xs : Vector α n)
    (draws : (i : Fin n) → Fin (n - i.val)) :
    Cslib.Algorithms.Lean.TimeM (Nat × Nat) (Vector α n) :=
  scan draws 0 xs

    (draws : (i : Fin n) → Fin (n - i.val)) (i : Nat) (xs : Vector α n) :

    Cslib.Algorithms.Lean.TimeM.randomlyPermuteDistribution

    For a vector \(x\) of length \(n\), this is the probability distribution on outcomes (a vector of length \(n\) together with a cost pair in \(\mathbb{N} \times \mathbb{N}\)) obtained by choosing a draw history \(d\) uniformly at random among all assignments of a number \(d_i\) with \(0 \le d_i < n - i\) to each position \(i < n\), and returning the result of the Fisher–Yates computation on \(x\) and \(d\).

    This models an ideal source of random draws, not an executable pseudorandom generator, and does not assume that the output permutation is uniform.

    public def randomlyPermuteDistribution {α : Type u} {n : Nat}
    (xs : Vector α n) : PMF (Cslib.Algorithms.Lean.TimeM (Nat × Nat) (Vector α n)) := by
  letI : Nonempty ((i : Fin n) → Fin (n - i.val)) := ⟨fun i => ⟨0, by omega⟩⟩
  exact (Cslib.Probability.PMF.uniformOfFintype ((i : Fin n) → Fin (n - i.val))).map
    (randomlyPermute xs)

    Cslib.Algorithms.Lean.TimeM.randomlyPermuteDistribution_apply

    Let \(x\) be a vector of length \(n\), and consider the draw histories \(d\), which assign to each position \(i < n\) a number \(d_i\) with \(0 \le d_i < n - i\). For every outcome \(o\) (a vector of length \(n\) together with a cost pair), the probability that the Fisher–Yates output distribution of \(x\) assigns to \(o\) equals the sum, over all draw histories \(d\) for which the Fisher–Yates computation on \(x\) and \(d\) yields exactly \(o\), of \(\prod_{i=0}^{n-1} \frac{1}{n - i}\).

    Distinct histories that yield the same outcome (for example when values of \(x\) repeat) add up, and an outcome that no history yields has probability \(0\).

    public theorem randomlyPermuteDistribution_apply {α : Type u} {n : Nat} (xs : Vector α n)

      ∑ draws : (i : Fin n) → Fin (n - i.val),
        if out = randomlyPermute xs draws
        then ∏ i : Fin n, ((n - i.val : Nat) : ENNReal)⁻¹ else 0

    TheoremPrefix probabilities of the Fisher–Yates shuffle#✓fully proved

    Cslib.Algorithms.Lean.TimeM.randomlyPermute_prefix_probability

    Let \(k \le n\) and let \(a_0, \dots, a_{k-1}\) be distinct elements of \(\{0, \dots, n - 1\}\). Run the Fisher–Yates computation on the vector \((0, 1, \dots, n - 1)\) with every draw history \(d\), which assigns to each position \(i < n\) a number \(d_i\) with \(0 \le d_i < n - i\), and give each history weight \(1/n!\). Then the total weight of the histories whose output vector has entry \(a_p\) at position \(p\) for every \(p < k\) equals \((n - k)!/n!\).

    There are exactly \(n!\) draw histories, so this is the probability of the prefix under a uniformly random history. The cases \(k = 0\) and \(k = n\) are included.

    public theorem randomlyPermute_prefix_probability {n k : Nat} (hkn : k ≤ n)
    (a : Fin k → Fin n) (hinj : Function.Injective a) :
    (∑ draws : (i : Fin n) → Fin (n - i.val),
      if ∀ p : Fin k,
        (randomlyPermute (Vector.ofFn fun q : Fin n => q) draws).ret[(Fin.castLE hkn p).val] = a p
      then (n.factorial : ENNReal)⁻¹ else 0) =
        ((n - k).factorial : ENNReal) / n.factorial
