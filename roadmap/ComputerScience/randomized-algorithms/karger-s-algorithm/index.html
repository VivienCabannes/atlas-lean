    DefinitionEdge contraction#✓fully proved

    Cslib.Algorithms.Lean.Karger.contract

    For a multigraph state \(G\) and a pair of vertices \(e = (a, b)\), the contraction of \(G\) along \(e\) deletes the first occurrence of \(b\) from the vertex list, replaces \(b\) by \(a\) in both endpoints of every edge, and then deletes every edge whose two endpoints are equal.

  verts := st.verts.erase e.2

    DefinitionSuccess probability of the contraction process#✓fully proved

    Cslib.Algorithms.Lean.Karger.successProb

    For a natural number \(k\), a number \(f\) of allowed contractions and a multigraph \(G\) with edge list \(E_G\), the probability \(P_k(f, G)\) that the contraction process on \(G\) returns \(k\) is defined by recursion on \(f\). If \(f = 0\), or \(G\) has at most two vertices, or \(G\) has no edges, then \(P_k(f, G)\) is \(1\) when \(G\) has exactly \(k\) edges and \(0\) otherwise. Otherwise \(P_k(f, G) = \frac{1}{|E_G|} \sum_{e \in E_G} P_k(f - 1, G/e)\), where \(G/e\) is the contraction of \(G\) along \(e\) and the sum runs over the edges with multiplicity.

    This models contracting a uniformly random edge while more than two vertices remain and counting the edges between the last two vertices.

    def successProb (k : ℕ) : ℕ → State V → ℚ
  | 0, st => if st.edges.length = k then 1 else 0
  | fuel + 1, st =>
      if st.verts.length ≤ 2 ∨ st.edges = [] then (if st.edges.length = k then 1 else 0)
      else (st.edges.map fun e => successProb k fuel (contract st e)).sum / st.edges.length

    Cslib.Algorithms.Lean.Karger.surviveProb

    For a map \(X\) from vertices to booleans, a fuel bound \(f\) and a multigraph \(G\), this is the probability that the contraction process on \(G\) (contract an edge chosen uniformly at random, counted with multiplicity, while more than two vertices and at least one edge remain, making at most \(f\) contractions) never contracts an edge whose endpoints \(X\) separates and ends with exactly two vertices on which \(X\) takes both values.

    Explicitly: if \(f = 0\), or \(G\) has at most two vertices, or \(G\) has no edges, the value is \(1\) when \(G\) has exactly two vertices and \(X\) is a cut of \(G\), and \(0\) otherwise. Otherwise it is the average over the edges \(e\) of \(G\), counted with multiplicity, of the value for fuel \(f - 1\) on the contraction of \(G\) along \(e\) when \(X\) agrees on the two endpoints of \(e\), and of \(0\) when it does not.

    def surviveProb (X : V → Bool) : ℕ → State V → ℚ
  | 0, st => if st.verts.length = 2 ∧ IsCut st X then 1 else 0

        (if st.verts.length = 2 ∧ IsCut st X then 1 else 0)
      else

            if X e.1 = X e.2 then surviveProb X fuel (contract st e) else 0).sum /
