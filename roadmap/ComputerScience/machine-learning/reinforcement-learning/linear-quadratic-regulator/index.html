    Linear quadratic regulator

    The linear quadratic regulator (LQR) controls the linear system \(x_{t+1} = A x_t + B u_t\) so as to minimize the quadratic cost \(\sum_t (x_t^\top Q x_t + u_t^\top R u_t)\). Recht (2019) uses it as the baseline on which to compare reinforcement learning methods: with known dynamics, dynamic programming solves it exactly. The cost-to-go is a quadratic form \(x^\top M_t x\), the optimal control is the linear state feedback \(u_t = -K_t x_t\), and the matrices are computed backwards by the Riccati recursion, a completion of squares in the control at each step. Here the deterministic version of the source's finite-horizon problem (4.1), with terminal cost, is solved in full, under the added assumption that \(R\) is positive definite; the infinite-horizon limit, the discrete algebraic Riccati equation and its stabilizing solution, and the unknown-dynamics problems of the source are not formalized.

    CSLibExt.MachineLearning.LinearQuadraticRegulator.riccatiGain

    For a cost-to-go matrix \(M\), the gain of the optimal linear control \(u = -Kx\) is

    \[ K = (R + B^\top M B)^{-1} B^\top M A . \]
    noncomputable def riccatiGain (A : Matrix σ σ ℝ) (B : Matrix σ ι ℝ) (R : Matrix ι ι ℝ)
    (M : Matrix σ σ ℝ) : Matrix ι σ ℝ :=
  (R + Bᵀ * M * B)⁻¹ * (Bᵀ * M * A)

    DefinitionRiccati update#✓fully proved

    CSLibExt.MachineLearning.LinearQuadraticRegulator.riccatiMap

    The Riccati update of a cost-to-go matrix \(M\) is

    \[ \mathcal{R}(M) = Q + A^\top M A - (A^\top M B)(R + B^\top M B)^{-1}(B^\top M A), \]

    the matrix of the optimal cost-to-go one step earlier (Bellman cost of the linear control). Its fixed points \(M = \mathcal{R}(M)\) are the solutions of the discrete algebraic Riccati equation (4.2) of the source, which describes the infinite-horizon problem; that limit is not formalized here.

    noncomputable def riccatiMap (A : Matrix σ σ ℝ) (B : Matrix σ ι ℝ) (Q : Matrix σ σ ℝ)
    (R : Matrix ι ι ℝ) (M : Matrix σ σ ℝ) : Matrix σ σ ℝ :=
  Q + Aᵀ * M * A - (Aᵀ * M * B) * (R + Bᵀ * M * B)⁻¹ * (Bᵀ * M * A)

    DefinitionOne-step Bellman cost#✓fully proved

    CSLibExt.MachineLearning.LinearQuadraticRegulator.bellmanCost

    For a state \(x\), a control \(u\) and a cost-to-go matrix \(M\),

    \[ \mathcal{B}_M(x, u) = x^\top Q x + u^\top R u + (Ax + Bu)^\top M (Ax + Bu), \]

    the stage cost plus the cost-to-go at the next state. It is the Q-function of the source's dynamic programming recursion, without the constant contributed by the noise.

    def bellmanCost (A : Matrix σ σ ℝ) (B : Matrix σ ι ℝ) (Q : Matrix σ σ ℝ) (R : Matrix ι ι ℝ)
    (M : Matrix σ σ ℝ) (x : σ → ℝ) (u : ι → ℝ) : ℝ :=
  x ⬝ᵥ (Q *ᵥ x) + u ⬝ᵥ (R *ᵥ u) + (A *ᵥ x + B *ᵥ u) ⬝ᵥ (M *ᵥ (A *ᵥ x + B *ᵥ u))

    TheoremCompletion of squares in the control#✓fully proved

    CSLibExt.MachineLearning.LinearQuadraticRegulator.bellmanCost_eq_add

    Let \(M\) and \(R\) be symmetric and let \(S = R + B^\top M B\) be invertible, with \(K\) the Riccati gain. Then for every state \(x\) and control \(u\),

    \[ \mathcal{B}_M(x, u) = \mathcal{B}_M(x, -Kx) + (u + Kx)^\top S\, (u + Kx). \]

    Proof: \(\mathcal{B}_M(x, u) = x^\top (Q + A^\top M A) x + u^\top S u + 2 u^\top g\) with \(g = B^\top M A x = S K x\); expand the square.

    theorem bellmanCost_eq_add {A : Matrix σ σ ℝ} {B : Matrix σ ι ℝ} {Q : Matrix σ σ ℝ}
    {R : Matrix ι ι ℝ} {M : Matrix σ σ ℝ} (hM : Mᵀ = M) (hR : Rᵀ = R)
    (hS : IsUnit (R + Bᵀ * M * B).det) (x : σ → ℝ) (u : ι → ℝ) :
    bellmanCost A B Q R M x u =
      bellmanCost A B Q R M x (-(riccatiGain A B R M *ᵥ x)) +
        (u + riccatiGain A B R M *ᵥ x) ⬝ᵥ
          ((R + Bᵀ * M * B) *ᵥ (u + riccatiGain A B R M *ᵥ x))
    def bellmanCost (A : Matrix σ σ ℝ) (B : Matrix σ ι ℝ) (Q : Matrix σ σ ℝ) (R : Matrix ι ι ℝ)
    (M : Matrix σ σ ℝ) (x : σ → ℝ) (u : ι → ℝ) : ℝ :=
  x ⬝ᵥ (Q *ᵥ x) + u ⬝ᵥ (R *ᵥ u) + (A *ᵥ x + B *ᵥ u) ⬝ᵥ (M *ᵥ (A *ᵥ x + B *ᵥ u))

    CSLibExt.MachineLearning.LinearQuadraticRegulator.bellmanCost_neg_gain

    Under the hypotheses of the completion of squares,

    \[ \mathcal{B}_M(x, -Kx) = x^\top \mathcal{R}(M)\, x, \]

    TheoremThe Riccati update preserves positive semidefiniteness#✓fully proved

    CSLibExt.MachineLearning.LinearQuadraticRegulator.riccatiMap_posSemidef

    If \(Q\) and \(M\) are positive semidefinite and \(R\) is positive definite, then the Riccati update \(\mathcal{R}(M)\) is positive semidefinite. It is symmetric, and \(x^\top \mathcal{R}(M) x = \mathcal{B}_M(x, -Kx)\) is a sum of nonnegative quadratic forms. In particular \(R + B^\top \mathcal{R}(M) B\) is positive definite, so the recursion can be continued.

    theorem riccatiMap_posSemidef {A : Matrix σ σ ℝ} {B : Matrix σ ι ℝ} {Q : Matrix σ σ ℝ}
    {R : Matrix ι ι ℝ} {M : Matrix σ σ ℝ} (hQ : Q.PosSemidef) (hR : R.PosDef)
    (hM : M.PosSemidef) : (riccatiMap A B Q R M).PosSemidef
    noncomputable def riccatiMap (A : Matrix σ σ ℝ) (B : Matrix σ ι ℝ) (Q : Matrix σ σ ℝ)
    (R : Matrix ι ι ℝ) (M : Matrix σ σ ℝ) : Matrix σ σ ℝ :=
  Q + Aᵀ * M * A - (Aᵀ * M * B) * (R + Bᵀ * M * B)⁻¹ * (Bᵀ * M * A)

    DefinitionRiccati recursion#✓fully proved

    CSLibExt.MachineLearning.LinearQuadraticRegulator.riccatiCostToGo

    Indexed by the number of remaining steps, the cost-to-go matrices of the finite-horizon problem with terminal cost \(Q_f\) are

    \[ M_0 = Q_f, \qquad M_{j+1} = \mathcal{R}(M_j), \]

    with \(\mathcal{R}\) the Riccati update.

    noncomputable def riccatiCostToGo (A : Matrix σ σ ℝ) (B : Matrix σ ι ℝ) (Q : Matrix σ σ ℝ)
    (R : Matrix ι ι ℝ) (Qf : Matrix σ σ ℝ) : ℕ → Matrix σ σ ℝ
  | 0 => Qf
  | j + 1 => riccatiMap A B Q R (riccatiCostToGo A B Q R Qf j)

    DefinitionFinite-horizon LQR cost#✓fully proved

    CSLibExt.MachineLearning.LinearQuadraticRegulator.lqrCost

    The cost of the control sequence \((u_t)\) from \(x_0\) over \(T\) steps is

    \[ J_T(x_0, u) = \sum_{t=0}^{T-1} \big(x_t^\top Q x_t + u_t^\top R u_t\big) + x_T^\top Q_f x_T \]

    along the states of the system. This is the deterministic version of the source's problem (4.1), \(\mathbb{E}\big[\tfrac12 \sum_{t=0}^{N} (x_t^\top Q x_t + u_t^\top R u_t) + \tfrac12 x_{N+1}^\top S x_{N+1}\big]\) with noise \(e_t\) in the dynamics: here there is no noise, the factors \(\tfrac12\) are dropped, \(T = N + 1\), and \(Q_f\) is the source's terminal cost \(S\). The source notes that the noise does not affect how the control actions are chosen.

    def lqrCost (A : Matrix σ σ ℝ) (B : Matrix σ ι ℝ) (Q : Matrix σ σ ℝ) (R : Matrix ι ι ℝ)
    (Qf : Matrix σ σ ℝ) (x₀ : σ → ℝ) (u : ℕ → ι → ℝ) (T : ℕ) : ℝ :=
  ∑ t ∈ Finset.range T, (lqrState A B x₀ u t ⬝ᵥ (Q *ᵥ lqrState A B x₀ u t) + u t ⬝ᵥ (R *ᵥ u t)) +
    lqrState A B x₀ u T ⬝ᵥ (Qf *ᵥ lqrState A B x₀ u T)
    def lqrState (A : Matrix σ σ ℝ) (B : Matrix σ ι ℝ) (x₀ : σ → ℝ) (u : ℕ → ι → ℝ) : ℕ → σ → ℝ
  | 0 => x₀
  | t + 1 => A *ᵥ lqrState A B x₀ u t + B *ᵥ u t

    TheoremEvery control sequence costs at least the Riccati value#✓fully proved

    CSLibExt.MachineLearning.LinearQuadraticRegulator.lqrCost_ge

    Let \(Q\) and \(Q_f\) be positive semidefinite and \(R\) positive definite. Then for every horizon \(T\), initial state \(x_0\) and control sequence \(u\),

    \[ x_0^\top M_T\, x_0 \le J_T(x_0, u), \]

    where \(M_T\) is given by the Riccati recursion.

    Proof: by induction on \(T\). The cost splits into the stage cost at \(x_0\) and the cost from \(x_1 = Ax_0 + Bu_0\) over \(T - 1\) steps, at least \(x_1^\top M_{T-1} x_1\) by induction; their sum is the one-step Bellman cost, which is at least \(x_0^\top \mathcal{R}(M_{T-1}) x_0\). Positive semidefiniteness is preserved by the update.

    theorem lqrCost_ge {A : Matrix σ σ ℝ} {B : Matrix σ ι ℝ} {Q : Matrix σ σ ℝ} {R : Matrix ι ι ℝ}

    ∀ (x₀ : σ → ℝ) (u : ℕ → ι → ℝ),
      x₀ ⬝ᵥ (riccatiCostToGo A B Q R Qf T *ᵥ x₀) ≤ lqrCost A B Q R Qf x₀ u T

    TheoremThe linear feedback attains the Riccati value#✓fully proved

    CSLibExt.MachineLearning.LinearQuadraticRegulator.lqrCost_feedback

    Under the hypotheses of the lower bound, for every horizon \(T\) and initial state \(x_0\) the linear state feedback

    \[ u_t = -K_{T-1-t}\, x_t, \qquad K_j = (R + B^\top M_j B)^{-1} B^\top M_j A, \]

    attains \(J_T(x_0, u) = x_0^\top M_T x_0\). With the lower bound, the linear feedback is optimal among all control sequences, and the optimal cost is the quadratic form of \(M_T\).

    Proof: by induction on \(T\), using the Bellman cost of the linear control at each step.

    theorem lqrCost_feedback {A : Matrix σ σ ℝ} {B : Matrix σ ι ℝ} {Q : Matrix σ σ ℝ}
    {R : Matrix ι ι ℝ} {Qf : Matrix σ σ ℝ} (hQ : Q.PosSemidef) (hR : R.PosDef)
    (hQf : Qf.PosSemidef) (T : ℕ) :
    ∀ x₀ : σ → ℝ, ∃ u : ℕ → ι → ℝ,
      lqrCost A B Q R Qf x₀ u T = x₀ ⬝ᵥ (riccatiCostToGo A B Q R Qf T *ᵥ x₀) ∧

    Related topics

    • Value iteration: dynamic programming for finite Markov decision processes; the Riccati recursion is value iteration for quadratic value functions.
    • Optimality of stationary policies: the finite-horizon DP algorithm for finite Markov decision processes; the Riccati recursion is its linear-quadratic case.
    • Positive-definite matrices: the positive semidefiniteness that keeps the recursion well defined.
    • Viscosity solutions of Hamilton–Jacobi equations: in continuous time the dynamic programming equation becomes the Hamilton–Jacobi–Bellman equation, whose value functions are viscosity solutions.
    • Controllability of linear systems: the Kalman rank condition is the classical hypothesis under which the infinite-horizon problem has a stabilising solution, and the controllability Gramian solves the minimum-energy problem.
    • Pole placement: the other classical way to compute a stabilising linear state feedback, by prescribing the closed-loop eigenvalues.
    • Recursive least squares: the estimator whose running estimates are plugged into the Riccati feedback by certainty equivalence.
