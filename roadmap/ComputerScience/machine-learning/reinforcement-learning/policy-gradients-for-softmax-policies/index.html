    Policy gradients for softmax policies

    Wanted results: the policy gradient theorem for softmax policies and the asymptotic global convergence of softmax policy gradient ascent (Agarwal, Kakade, Lee and Mahajan 2021, Section 5.1). Their proofs are deferred.

    DefinitionSoftmax policy objective#✓fully proved

    Cslib.Algorithms.Lean.MarkovDecision.softmaxObjective

    Let \(M\) be a Markov decision process with a finite set of states \(S\), a finite nonempty set of actions \(A\), real rewards \(r(s,a)\) and stochastic transition probabilities \(P(s,a,s')\), and let \(0 \le \gamma < 1\). For weights \(\mu\) on \(S\) and logits \(\theta\), the objective of softmax policy optimization is \(V^{\pi_\theta}(\mu) = \sum_{s_0} \mu(s_0)\, V^{\pi_\theta}(s_0)\).

    noncomputable def softmaxObjective (hM : M.Stochastic) (hγ0 : 0 ≤ γ) (hγ1 : γ < 1) (μ : S → ℝ)
    (θ : S → A → ℝ) : ℝ :=
  ∑ s₀, μ s₀ * stochValue M γ hM hγ0 hγ1 (softmax θ) s₀
    noncomputable def stochValue (M : MDP S A ℝ) (γ : ℝ) (hM : M.Stochastic) (hγ0 : 0 ≤ γ)
    (hγ1 : γ < 1) (π : StochasticPolicy S A) : S → ℝ :=
  mrpValue (policyKernel M π) (policyKernel_mem hM π) hγ0 hγ1 (policyReward M π)

    DefinitionSoftmax policy gradient#✓fully proved

    Cslib.Algorithms.Lean.MarkovDecision.softmaxPolicyGradient

    Let \(M\) be a Markov decision process with a finite set of states \(S\), a finite nonempty set of actions \(A\), real rewards \(r(s,a)\) and stochastic transition probabilities \(P(s,a,s')\), and let \(0 \le \gamma < 1\). For weights \(\mu\) and logits \(\theta\), the softmax policy gradient in the coordinate \((s,a)\) is \(\frac{1}{1-\gamma}\, d^{\pi_\theta}_\mu(s)\, \pi_\theta(a \mid s)\, A^{\pi_\theta}(s,a)\), where \(d^{\pi_\theta}_\mu(s) = \sum_{s_0} \mu(s_0) d^{\pi_\theta}_{s_0}(s)\). That this is the gradient of the objective is the wanted policy gradient theorem.

    noncomputable def softmaxPolicyGradient (hM : M.Stochastic) (hγ0 : 0 ≤ γ) (hγ1 : γ < 1)
    (μ : S → ℝ) (θ : S → A → ℝ) (s : S) (a : A) : ℝ :=
  (1 - γ)⁻¹ * (∑ s₀, μ s₀ * occupancy hM hγ0 hγ1 (softmax θ) s₀ s) * (softmax θ).prob s a *
    advantage hM hγ0 hγ1 (softmax θ) s a
    noncomputable def occupancy (π : StochasticPolicy S A) (s₀ s : S) : ℝ :=
  visitation (policyKernel_mem hM π) hγ0 hγ1 s₀ s

    Cslib.Algorithms.Lean.MarkovDecision.hasDerivAt_softmaxObjective

    Let \(M\) be a Markov decision process with a finite set of states \(S\), a finite nonempty set of actions \(A\), real rewards \(r(s,a)\) and stochastic transition probabilities \(P(s,a,s')\), and let \(0 \le \gamma < 1\). For weights \(\mu\), logits \(\theta\), a state \(s\) and an action \(a\),

    \[\frac{\partial V^{\pi_\theta}(\mu)}{\partial \theta(s,a)} = \frac{1}{1-\gamma}\, d^{\pi_\theta}_\mu(s)\, \pi_\theta(a \mid s)\, A^{\pi_\theta}(s,a).\]

    Recorded as a wanted theorem: its proof is deferred. The source derives it from the general policy gradient formula; dividing the performance difference lemma for \(\pi_\theta\) and a perturbed policy by the perturbation is another route.

    DefinitionSoftmax policy gradient ascent#✓fully proved

    Cslib.Algorithms.Lean.MarkovDecision.softmaxPGLogits

    Let \(M\) be a Markov decision process with a finite set of states \(S\), a finite nonempty set of actions \(A\), real rewards \(r(s,a)\) and stochastic transition probabilities \(P(s,a,s')\), and let \(0 \le \gamma < 1\). Gradient ascent on the softmax objective with step size \(\eta\) starts from \(\theta_0 = 0\) and updates \(\theta_{t+1} = \theta_t + \eta\, \nabla_\theta V^{\pi_{\theta_t}}(\mu)\), the gradient being written in the closed form of the softmax policy gradient.

    noncomputable def softmaxPGLogits (hM : M.Stochastic) (hγ0 : 0 ≤ γ) (hγ1 : γ < 1) (μ : S → ℝ)
    (η : ℝ) : ℕ → S → A → ℝ
  | 0 => 0
  | t + 1 => fun s a => softmaxPGLogits hM hγ0 hγ1 μ η t s a +
      η * softmaxPolicyGradient hM hγ0 hγ1 μ (softmaxPGLogits hM hγ0 hγ1 μ η t) s a
    noncomputable def softmaxPolicyGradient (hM : M.Stochastic) (hγ0 : 0 ≤ γ) (hγ1 : γ < 1)
    (μ : S → ℝ) (θ : S → A → ℝ) (s : S) (a : A) : ℝ :=
  (1 - γ)⁻¹ * (∑ s₀, μ s₀ * occupancy hM hγ0 hγ1 (softmax θ) s₀ s) * (softmax θ).prob s a *
    advantage hM hγ0 hγ1 (softmax θ) s a

    TheoremGlobal convergence of softmax policy gradient#●ready to prove

    Cslib.Algorithms.Lean.MarkovDecision.tendsto_stochValue_softmaxPGLogits

    Let \(M\) be a Markov decision process with a finite set of states \(S\), a finite nonempty set of actions \(A\), real rewards \(r(s,a)\) and stochastic transition probabilities \(P(s,a,s')\), and let \(0 \le \gamma < 1\). Assume the rewards lie in \([0,1]\), \(\mu\) is a probability distribution with \(\mu(s) > 0\) for every state, and \(0 < \eta \le (1-\gamma)^3/8\). Then the values of the softmax policy gradient iterates converge to the optimal value: \(V^{\pi_{\theta_t}}(s) \to V^*(s)\) as \(t \to \infty\), for every state \(s\). No rate is claimed; compare the dimension-free rate of natural policy gradient. The iteration here starts from \(\theta_0 = 0\), a special case: the source fixes no initialization, and its proof works from any \(\theta_0\). Recorded as a wanted theorem.

    public theorem_wanted tendsto_stochValue_softmaxPGLogits (hM : M.Stochastic) (hγ0 : 0 ≤ γ)
    (hγ1 : γ < 1) (hr : ∀ s a, 0 ≤ M.reward s a ∧ M.reward s a ≤ 1) (μ : S → ℝ)
    (hμ : ∀ s, 0 < μ s) (hμ1 : ∑ s, μ s = 1) {η : ℝ} (hη0 : 0 < η)
    (hη : η ≤ (1 - γ) ^ 3 / 8) (s : S) :
    Filter.Tendsto (fun t => stochValue M γ hM hγ0 hγ1
        (softmax (softmaxPGLogits hM hγ0 hγ1 μ η t)) s) Filter.atTop
      (nhds (optimalValue M γ hM hγ0 hγ1 s))
    noncomputable def stochValue (M : MDP S A ℝ) (γ : ℝ) (hM : M.Stochastic) (hγ0 : 0 ≤ γ)
    (hγ1 : γ < 1) (π : StochasticPolicy S A) : S → ℝ :=
  mrpValue (policyKernel M π) (policyKernel_mem hM π) hγ0 hγ1 (policyReward M π)
