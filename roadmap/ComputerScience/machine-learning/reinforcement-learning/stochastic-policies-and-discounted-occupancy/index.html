    The Markov reward process with transition matrix \(P\) on \(S\) and reward \(c : S \to \mathbb{R}\), viewed as a Markov decision process with a single action: the reward of the action in state \(s\) is \(c(s)\) and its transition probabilities are \(P(s, \cdot)\).     DefinitionValue of a Markov reward process#✓fully proved

    Cslib.Algorithms.Lean.MarkovDecision.mrpValue

    Let \(P\) be a row-stochastic matrix on a finite set \(S\) (nonnegative entries, each row summing to \(1\)) and let \(0 \le \gamma < 1\). The value of the reward \(c : S \to \mathbb{R}\) is the unique function \(V_c : S \to \mathbb{R}\) with

    \[V_c(s) = c(s) + \gamma \sum_{s'} P(s,s')\, V_c(s')\quad\text{for all } s,\]

    that is \(V_c = (I - \gamma P)^{-1} c\). It exists and is unique because the right-hand side is a \(\gamma\)-contraction in the sup metric.

    noncomputable def mrpValue (P : Matrix S S ℝ) (hP : P ∈ rowStochastic ℝ S) {γ : ℝ} (hγ0 : 0 ≤ γ)
    (hγ1 : γ < 1) (c : S → ℝ) : S → ℝ :=
  policyValue (mrpMDP P c) γ (mrpMDP_stochastic hP c) hγ0 hγ1 fun _ => ()

    DefinitionDiscounted state visitation#✓fully proved

    Cslib.Algorithms.Lean.MarkovDecision.visitation

    Let \(P\) be a row-stochastic matrix on a finite set \(S\) (nonnegative entries, each row summing to \(1\)) and let \(0 \le \gamma < 1\). The discounted state visitation of the Markov chain \(P\) from \(s_0\) is

    \[d_{s_0}(s) = (1 - \gamma) \sum_{t \ge 0} \gamma^t \Pr(s_t = s \mid s_0) = (1-\gamma)\,\bigl[(I - \gamma P)^{-1}\bigr]_{s_0 s}.\]

    It is defined as \(1 - \gamma\) times the value of the indicator reward of \(s\), and the series form is a theorem.

    noncomputable def visitation {P : Matrix S S ℝ} (hP : P ∈ rowStochastic ℝ S) {γ : ℝ}
