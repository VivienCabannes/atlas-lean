    Approximate policy iteration

    Error bounds for policy iteration with inexact policy evaluation, following Bertsekas's survey Approximate policy iteration: a survey and some new methods (J. Control Theory Appl. 9(3), 2011, Section 3). Each step evaluates the current policy up to a sup-norm error \(\delta\) and acts greedily on the estimate. If the method stops, the final policy is within \(2\gamma\delta/(1-\gamma)\) of optimal; in general the iterates come within \(2\gamma\delta/(1-\gamma)^2\) of optimal asymptotically, with an explicit geometric transient. Finite states and actions, discount \(0 \le \gamma < 1\), rewards maximized.

    TheoremError bound when approximate policy iteration stops#✓fully proved

    Cslib.Algorithms.Lean.MarkovDecision.optimalValue_sub_policyValue_le_of_greedy

    Let \(M\) be a Markov decision process with a finite set of states \(S\), a finite nonempty set of actions, real rewards and stochastic transition probabilities, let \(0 \le \gamma < 1\), and write \(V^*\) for the optimal value, \(V^\mu\) for the value of a deterministic policy \(\mu\), \(T\) for the Bellman optimality operator and \(T_\mu\) for the Bellman operator of \(\mu\). Suppose that \(\bar J : S \to \mathbb{R}\) estimates the value of \(\bar\mu\) to within \(\delta\), that is \(|\bar J(s) - V^{\bar\mu}(s)| \le \delta\) for every state \(s\), and that \(\bar\mu\) is greedy with respect to \(\bar J\), that is \(T_{\bar\mu} \bar J = T \bar J\) (approximate policy iteration has stopped at \(\bar\mu\)). Then for every state \(s\)

    \[0 \le V^*(s) - V^{\bar\mu}(s) \le \frac{2\gamma\delta}{1-\gamma}.\]

    The survey's proof (written there for costs) shows \(T V^{\bar\mu} \le T \bar J + \gamma\delta = T_{\bar\mu} \bar J + \gamma\delta \le V^{\bar\mu} + 2\gamma\delta\) by monotonicity and the constant-shift property of \(T\) and \(T_{\bar\mu}\), applies \(T\) repeatedly to get \(T^m V^{\bar\mu} \le V^{\bar\mu} + 2\gamma\delta(1 + \gamma + \dots + \gamma^{m-1})\), and lets \(m \to \infty\) by value iteration. The Lean proof ends instead with the contraction of \(T\): \(\|V^* - V^{\bar\mu}\|_\infty \le \gamma \|V^* - V^{\bar\mu}\|_\infty + 2\gamma\delta\).

    theorem optimalValue_sub_policyValue_le_of_greedy {μ : S → A} {J : S → ℝ} {δ : ℝ}
    (hJ : ∀ s, |J s - policyValue M γ hM hγ0 hγ1 μ s| ≤ δ)
    (hμ : policyBellman M γ μ J = bellman M γ J) (s : S) :
    0 ≤ optimalValue M γ hM hγ0 hγ1 s - policyValue M γ hM hγ0 hγ1 μ s ∧
      optimalValue M γ hM hγ0 hγ1 s - policyValue M γ hM hγ0 hγ1 μ s ≤
        2 * γ * δ / (1 - γ)
    noncomputable def policyValue (M : MDP S A ℝ) (γ : ℝ) (hM : M.Stochastic) (hγ0 : 0 ≤ γ)
    (hγ1 : γ < 1) (π : S → A) : S → ℝ :=
  ContractingWith.fixedPoint _ (policyBellman_contracting hM hγ0 hγ1 π)

    Cslib.Algorithms.Lean.MarkovDecision.policyValue_sub_policyValue_succ_le

    In the setting of Error bound when approximate policy iteration stops, let \(\mu\) be a deterministic policy, let \(J\) satisfy \(|J(s) - V^{\mu}(s)| \le \delta\) for every state \(s\), and let \(\mu'\) be greedy with respect to \(J\) (\(T_{\mu'} J = T J\)). Then for every state \(s\)

    \[V^{\mu}(s) - V^{\mu'}(s) \le \frac{2\gamma\delta}{1-\gamma}.\]

    With \(\delta = 0\) this is the Policy improvement theorem. It is the first step of the proof of the Error bound for approximate policy iteration.

    theorem policyValue_sub_policyValue_succ_le {μ μ' : S → A} {J : S → ℝ} {δ : ℝ}
    (hJ : ∀ s, |J s - policyValue M γ hM hγ0 hγ1 μ s| ≤ δ)
    (hμ' : policyBellman M γ μ' J = bellman M γ J) (s : S) :
    policyValue M γ hM hγ0 hγ1 μ s - policyValue M γ hM hγ0 hγ1 μ' s ≤ 2 * γ * δ / (1 - γ)
    noncomputable def policyValue (M : MDP S A ℝ) (γ : ℝ) (hM : M.Stochastic) (hγ0 : 0 ≤ γ)
    (hγ1 : γ < 1) (π : S → A) : S → ℝ :=
  ContractingWith.fixedPoint _ (policyBellman_contracting hM hγ0 hγ1 π)

    TheoremError bound for approximate policy iteration#✓fully proved

    Cslib.Algorithms.Lean.MarkovDecision.optimalValue_sub_policyValue_approxPI_le

    Let \(M\) be a Markov decision process with a finite set of states \(S\), a finite nonempty set of actions, real rewards and stochastic transition probabilities, and let \(0 \le \gamma < 1\). Let \(\mu_0, \mu_1, \dots\) be deterministic policies and \(J_0, J_1, \dots : S \to \mathbb{R}\) estimates of their values with \(|J_k(s) - V^{\mu_k}(s)| \le \delta\) for all \(k\) and \(s\), and suppose that each \(\mu_{k+1}\) is greedy with respect to \(J_k\) (\(T_{\mu_{k+1}} J_k = T J_k\)). Then for all \(k\) and every state \(s\)

    \[V^*(s) - V^{\mu_k}(s) \le \gamma^k\, \|V^* - V^{\mu_0}\|_\infty + \frac{2\gamma\delta}{(1-\gamma)^2}.\]

    The proof combines the one-step loss bound \(V^{\mu_k} - V^{\mu_{k+1}} \le 2\gamma\delta/(1-\gamma)\) with the recursion \(\|V^* - V^{\mu_{k+1}}\|_\infty \le \gamma \|V^* - V^{\mu_k}\|_\infty + 2\gamma\delta/(1-\gamma)\). Exact policy iteration is the case \(\delta = 0\); the asymptotic form is Asymptotic error bound for approximate policy iteration.

    theorem optimalValue_sub_policyValue_approxPI_le {μ : ℕ → S → A} {J : ℕ → S → ℝ} {δ : ℝ}
    (hJ : ∀ k s, |J k s - policyValue M γ hM hγ0 hγ1 (μ k) s| ≤ δ)
    (hμ : ∀ k, policyBellman M γ (μ (k + 1)) (J k) = bellman M γ (J k)) (k : ℕ) (s : S) :
    optimalValue M γ hM hγ0 hγ1 s - policyValue M γ hM hγ0 hγ1 (μ k) s ≤
      γ ^ k * dist (optimalValue M γ hM hγ0 hγ1) (policyValue M γ hM hγ0 hγ1 (μ 0)) +
        2 * γ * δ / (1 - γ) ^ 2
    noncomputable def policyValue (M : MDP S A ℝ) (γ : ℝ) (hM : M.Stochastic) (hγ0 : 0 ≤ γ)
    (hγ1 : γ < 1) (π : S → A) : S → ℝ :=
  ContractingWith.fixedPoint _ (policyBellman_contracting hM hγ0 hγ1 π)

    TheoremAsymptotic error bound for approximate policy iteration#✓fully proved

    Cslib.Algorithms.Lean.MarkovDecision.limsup_dist_optimalValue_policyValue_le

    Under the hypotheses of the Error bound for approximate policy iteration, and with at least one state,

    \[\limsup_{k\to\infty} \|V^* - V^{\mu_k}\|_\infty \le \frac{2\gamma\delta}{(1-\gamma)^2}.\]

    Approximate policy iteration need not converge: the policies may oscillate. The bound says that they eventually stay within \(2\gamma\delta/(1-\gamma)^2\) of optimal. The survey notes that the bound is tight in theory but usually conservative in practice. When the method stops, the sharper Error bound when approximate policy iteration stops applies.

    theorem limsup_dist_optimalValue_policyValue_le [Nonempty S] {μ : ℕ → S → A} {J : ℕ → S → ℝ}
    {δ : ℝ} (hJ : ∀ k s, |J k s - policyValue M γ hM hγ0 hγ1 (μ k) s| ≤ δ)
    (hμ : ∀ k, policyBellman M γ (μ (k + 1)) (J k) = bellman M γ (J k)) :
    limsup (fun k => dist (optimalValue M γ hM hγ0 hγ1) (policyValue M γ hM hγ0 hγ1 (μ k)))
      atTop ≤ 2 * γ * δ / (1 - γ) ^ 2
    noncomputable def policyValue (M : MDP S A ℝ) (γ : ℝ) (hM : M.Stochastic) (hγ0 : 0 ≤ γ)
    (hγ1 : γ < 1) (π : S → A) : S → ℝ :=
  ContractingWith.fixedPoint _ (policyBellman_contracting hM hγ0 hγ1 π)

    TheoremOne-sided contraction of a policy's Bellman operator#✓fully proved

    Cslib.Algorithms.Lean.MarkovDecision.policyBellman_sub_le

    Let \(M\) be a Markov decision process with finitely many states and stochastic transition probabilities, let \(\gamma \ge 0\) and let \(\pi\) be a deterministic stationary policy. If \(V(s') - W(s') \le m\) for every state \(s'\), then \(T_\pi V(s) - T_\pi W(s) \le \gamma m\) for every state \(s\).

    Unlike A policy's Bellman operator contracts by γ, this bound is one-sided, and \(m\) may be negative. Approximate policy iteration needs this form, because the loss of a step is bounded above but not below.

    theorem policyBellman_sub_le (hM : M.Stochastic) (hγ : 0 ≤ γ) (π : S → A) {V W : S → ℝ} {m : ℝ}
    (h : ∀ s', V s' - W s' ≤ m) (s : S) :
    policyBellman M γ π V s - policyBellman M γ π W s ≤ γ * m
    def policyBellman (M : MDP S A K) (γ : K) (π : S → A) (V : S → K) : S → K :=
  fun s => qValue M γ V s (π s)
