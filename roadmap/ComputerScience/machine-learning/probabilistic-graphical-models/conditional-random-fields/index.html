    Cslib.MachineLearning.GraphicalModels.ConditionalRandomField.ChainCRF

    Let \(S\) be a type of states, \(O\) a type of inputs and \(R\) a type of weights with a zero and a relation \(\le\). A linear-chain conditional random field consists of a unary potential \(\phi(x, t, s) \in R\) and a transition potential \(\psi(x, t, s, s') \in R\) from \(s\) to \(s'\), given for every observation sequence \(x \colon \mathbb{N} \to O\), every position \(t \in \mathbb{N}\) and all states \(s, s' \in S\), such that \(0 \le \phi(x, t, s)\) and \(0 \le \psi(x, t, s, s')\) always hold.

    Both potentials see the whole, possibly infinite, observation sequence \(x\), so path weights condition on all of \(x\), as the conditional probability \(p(y \mid x)\) of a label sequence \(y\) does in the standard definition. Nonnegativity makes the potentials unnormalized probabilities.

    structure ChainCRF (S O R : Type*) [Zero R] [LE R] where
  /-- The unary potential of a state at a position, as a function of the whole
  observation sequence. -/
  unary : (ℕ → O) → ℕ → S → R
  /-- The transition potential from the first state to the second at a step, as a function
  of the whole observation sequence (so edge features may depend jointly on the two
  states, the full input, and the position). -/
  trans : (ℕ → O) → ℕ → S → S → R
  /-- Unary potentials are nonnegative. -/
  unary_nonneg : ∀ (x : ℕ → O) (t : ℕ) (s : S), 0 ≤ unary x t s
  /-- Transition potentials are nonnegative. -/
  trans_nonneg : ∀ (x : ℕ → O) (t : ℕ) (s s' : S), 0 ≤ trans x t s s'
      unary : (ℕ → O) → ℕ → S → R

    DefinitionWeight of a label path in a chain CRF#✓fully proved

    Cslib.MachineLearning.GraphicalModels.ConditionalRandomField.pathWeight

    For a chain conditional random field with weights in a semiring, unary potentials \(u_t(s)\) and transition potentials \(\tau_t(s, s')\) given the observation stream \(x\), the unnormalized weight of a label path \(z = (z_0, \dots, z_t)\) is

    \[w_t(z) = u_0(z_0) \prod_{i=1}^{t} \tau_{i-1}(z_{i-1}, z_i)\, u_i(z_i),\]

    with the factors multiplied from left to right in increasing order of \(i\).

    def pathWeight : (t : ℕ) → (Fin (t + 1) → S) → R
  | 0, z => c.unary x 0 (z 0)
  | t + 1, z => pathWeight t (Fin.init z) * c.trans x t (z (Fin.last t).castSucc)
      (z (Fin.last (t + 1))) * c.unary x (t + 1) (z (Fin.last (t + 1)))

    Cslib.MachineLearning.GraphicalModels.ConditionalRandomField.forward

    For a chain conditional random field with a finite set of states, weights in a semiring, unary potentials \(u_t(s)\) and transition potentials \(\tau_t(s', s)\) given the observation stream \(x\), the forward variables are defined by \(\alpha_0(s) = u_0(s)\) and \(\alpha_{t+1}(s) = \left(\sum_{s'} \alpha_t(s')\, \tau_t(s', s)\right) u_{t+1}(s)\), the sum running over all states \(s'\).

    The forward variable \(\alpha_t(s)\) is the total weight of the label paths of length \(t + 1\) ending in \(s\).

    def forward : ℕ → S → R
  | 0, s => c.unary x 0 s
  | t + 1, s => (∑ s', forward t s' * c.trans x t s' s) * c.unary x (t + 1) s

    Cslib.MachineLearning.GraphicalModels.ConditionalRandomField.forward_eq

    Cslib.MachineLearning.GraphicalModels.ConditionalRandomField.viterbi

    Let \(c\) be a chain conditional random field with a finite nonempty set of states \(S\) and weights in a linearly ordered commutative semiring \(R\), and let \(x\) be an observation sequence. Write \(\phi_t(s)\) for the unary potential of \(c\) at \(x\) of state \(s\) at position \(t\), and \(\psi_t(s', s)\) for its transition potential from \(s'\) to \(s\) at step \(t\). The Viterbi variables \(V_t(s)\), for \(t \in \mathbb{N}\) and \(s \in S\), are defined by \(V_0(s) = \phi_0(s)\) and

    \[V_{t+1}(s) = \Big(\max_{s' \in S} V_t(s') \, \psi_t(s', s)\Big) \, \phi_{t+1}(s).\]

    Thus \(V_t(s)\) is the largest weight of a label path of length \(t + 1\) ending in \(s\).

    def viterbi : ℕ → S → R
  | 0, s => c.unary x 0 s
  | t + 1, s => Finset.univ.sup' Finset.univ_nonempty
      (fun s' => viterbi t s' * c.trans x t s' s) * c.unary x (t + 1) s

    by_cases ht : t = 0

      simp only [ite_true]
      exact mul_nonneg (hn.init _) (hn.emit _ _)
    · simp only [ht, ite_false]
      exact hn.emit _ _
  trans_nonneg _x _t s s' := hn.trans _ _
