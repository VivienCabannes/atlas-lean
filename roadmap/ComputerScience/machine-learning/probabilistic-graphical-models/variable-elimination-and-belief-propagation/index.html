    Cslib.MachineLearning.GraphicalModels.TreeModel

    For a type \(\alpha\) of values and \(n \in \mathbb{N}\), a pairwise tree model on the vertices \(0, \dots, n\) consists of a parent \(p(k + 1) \in \{0, \dots, k\}\) for each vertex \(k + 1\) with \(k < n\) (so vertex \(0\) is the root and every vertex comes after its parent), a unary factor \(\varphi_i : \alpha \to \mathbb{R}\) for each vertex \(i \le n\), and for each \(k < n\) a pairwise factor \(\psi_k(a, b) \in \mathbb{R}\) on the edge between vertex \(k + 1\) and its parent, defined for all \(a, b \in \alpha\), where \(a\) is the value at vertex \(k + 1\) and \(b\) the value at its parent.

    Cslib.MachineLearning.GraphicalModels.TreeModel.rootMessage

    Let \(\alpha\) be finite. The root message of a pairwise tree model \(m\) on the vertices \(0, \dots, n\) is the function \(r_m : \alpha \to \mathbb{R}\) defined by recursion on \(n\): if \(n = 0\), it is the unary factor of the root \(0\); if \(m\) is a model on the vertices \(0, \dots, n + 1\), it is \(r_{m'}\), where \(m'\) is the model on the vertices \(0, \dots, n\) obtained from \(m\) by eliminating the last vertex.

    Cslib.MachineLearning.GraphicalModels.TreeModel.belief

    The belief of each vertex of a tree model over a finite set of values, computed by sum-product message passing: the product of its unary factor, the messages from its subtree and the message from its parent.
