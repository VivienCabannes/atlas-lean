    DefinitionJoint distribution of a chain#✓fully proved

    Cslib.MachineLearning.GraphicalModels.Chain.joint

    For a chain of conditional distributions with values in a type \(\alpha\), write \(p_k(\cdot \mid x_0, \dots, x_{k-1})\) for the conditional distribution of variable \(k\) given the earlier ones. The joint distribution \(P_n : \alpha^n \to \mathbb{R}\) of the first \(n\) variables is defined by the chain rule: \(P_0 = 1\) and \(P_{n+1}(x_0, \dots, x_n) = P_n(x_0, \dots, x_{n-1}) \, p_n(x_n \mid x_0, \dots, x_{n-1})\).

  | n + 1, x => joint n (Fin.init x) * (c.cond n (Fin.init x)).weights (x (Fin.last n))

    TheoremThe ordered Markov property#✓fully proved

    Cslib.MachineLearning.GraphicalModels.BayesNet.cond_eq_cpt

    Let \(B\) be a Bayesian network on the nodes \(0, \dots, n - 1\) with values in a nonempty type \(\alpha\), and let \(P_m\) be the joint distribution of the first \(m\) nodes of \(B\) viewed as a chain of conditional distributions. For a node \(k < n\), write \(p_k(\cdot \mid z)\) for its conditional probability table at values \(z\) of its parents.
