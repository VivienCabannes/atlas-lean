    Cslib.MachineLearning.GraphicalModels.BayesNet.intervene

    The mechanism of node k is replaced by the point mass at a, and all incoming arrows to k are deleted (its parent set becomes ∅); every other node keeps its parents and its table. (The new table of k is the point mass on the empty parent set; the tables of the other nodes are transported along the equality of their parent sets.)

    noncomputable def intervene (k : Fin n) (a : α) : BayesNet α n where
  pa j := if j = k then ∅ else b.pa j
  cpt j z := if h : j = k then StdSimplex.single a
    else b.cpt j fun i => z ⟨i.1, by rw [if_neg h]; exact i.2⟩
