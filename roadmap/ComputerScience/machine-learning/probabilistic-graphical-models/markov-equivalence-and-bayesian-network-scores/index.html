    DefinitionSequential Pólya–Dirichlet prediction factor#✓fully proved

    Cslib.MachineLearning.GraphicalModels.BayesianDirichlet.predictive

    The sequential Pólya–Dirichlet prediction factor for the case x after the cases D: ∏_v (α_{v,c} + n_{v,c}) / (α_{v,j} + n_{v,j}), with c, j the family and parent values of x and n the counts in D. This is a genuine conditional probability only when Pa is a DAG; for arbitrary parent maps (e.g. cycles or self-parents) the factors over all cases need not sum to one.

    noncomputable def predictive [Fintype V] (Pa : V → Finset V)
    (α : (v : V) → Config σ (insert v (Pa v)) → ℝ) (D : List ((v : V) → σ v))
    (x : (v : V) → σ v) : ℝ :=
  ∏ v, (α v ((insert v (Pa v)).restrict x) + count D _ ((insert v (Pa v)).restrict x)) /
    ((∑ c with Finset.restrict₂ (subset_insert v (Pa v)) c = (Pa v).restrict x, α v c) +
      count D (Pa v) ((Pa v).restrict x))
    abbrev Config (σ : V → Type*) (S : Finset V) := (u : S) → σ u

    TheoremThe BD score is the sequential prediction product#✓fully proved

    Cslib.MachineLearning.GraphicalModels.BayesianDirichlet.seqProb_eq_bdScore

    The BD score is the sequential prediction product of the data (hence it does not depend on the order of the cases). This is an identity for all real hyperparameters. Positivity of the hyperparameters only makes every predictive denominator positive; it does not make this product a probability. The product is a genuine probability of the data only when Pa is a DAG with no self-parents: for cyclic parent maps the predictive factors over all cases need not sum to one.

    theorem seqProb_eq_bdScore [Fintype V] (Pa : V → Finset V)
    (α : (v : V) → Config σ (insert v (Pa v)) → ℝ) (D : List ((v : V) → σ v)) :
    seqProb Pa α D = bdScore D Pa α

    DefinitionBDe hyperparameters#✓fully proved

    Cslib.MachineLearning.GraphicalModels.BayesianDirichlet.bdeHyper

    BDe hyperparameters (Heckerman, Geiger and Chickering): ess times the weight ∑_{x ↦ c} p x of the configuration c of S. When ∑ x, p x = 1, p is a prior joint distribution and this is the prior probability of c.

    (c : Config σ S) : ℝ :=
  ess * ∑ x with S.restrict x = c, p x

    DefinitionBDe marginal likelihood of a variable set#✓fully proved

    Cslib.MachineLearning.GraphicalModels.BayesianDirichlet.margLik

    The (unnormalized) marginal likelihood of the data restricted to the variables S under the BDe Dirichlet prior on the joint values of S. p is treated as generalized weights here: the total Dirichlet mass over configurations is ess * ∑ x, p x, so the omitted normalizing factor is 1 / rising (ess * ∑ x, p x) D.length, the same for every S. When p is normalized (∑ x, p x = 1) this is 1 / rising ess D.length, and p is a prior joint distribution.

    noncomputable def margLik [Fintype V] (p : ((v : V) → σ v) → ℝ) (ess : ℝ)
    (D : List ((v : V) → σ v)) (S : Finset V) : ℝ :=
  ∏ c : Config σ S, rising (bdeHyper p ess S c) (count D S c)
    abbrev Config (σ : V → Type*) (S : Finset V) := (u : S) → σ u

    DefinitionCovered-edge reversal#✓fully proved

    Cslib.MachineLearning.GraphicalModels.BayesianDirichlet.CoveredReversal

    Pa' is obtained from Pa by reversing a covered edge x → y (Chickering 1995): x is a parent of y and y's other parents are exactly x's parents (Pa y = insert x (Pa x)); after the reversal y has parents Pa x and x has parents insert y (Pa x). Acyclicity is not required: the score identity holds for any parent-set maps (on a DAG, x ∉ Pa x and y ∉ Pa x hold automatically).

    def CoveredReversal (Pa Pa' : V → Finset V) : Prop :=
  ∃ x y, x ≠ y ∧ Pa y = insert x (Pa x) ∧
    Pa' = Function.update (Function.update Pa y (Pa x)) x (insert y (Pa x))
