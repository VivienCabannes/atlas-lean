    DefinitionWeighted majority vote#✓fully proved

    Cslib.MachineLearning.WeightedMajority.predict

    Let \(K\) be a field with a linear order. Given weights in \(K\) on \(n\) experts and a binary advice (true or false) from each expert, the weighted majority vote is true when the total weight of the experts advising false is at most the total weight of the experts advising true, and false otherwise. In particular ties go to true.

    def predict (w : Fin n → K) (advice : Fin n → Bool) : Bool :=
  decide (weightOn w advice false ≤ weightOn w advice true)
    def weightOn (w : Fin n → K) (advice : Fin n → Bool) (b : Bool) : K :=
  ∑ i ∈ univ.filter (fun i => advice i = b), w i

    DefinitionWeighted majority update#✓fully proved

    Cslib.MachineLearning.WeightedMajority.update

    Given a penalty factor \(\beta\) and weights \(w_0, \dots, w_{n-1}\) in a field \(K\), and a round with advice \(a \in \{\mathrm{true}, \mathrm{false}\}^n\) and outcome \(y\), the updated weight of expert \(i\) is \(w_i\) if \(a_i = y\) and \(\beta w_i\) otherwise: after the outcome is revealed, every expert that was wrong has its weight multiplied by \(\beta\).

    def update (β : K) (w : Fin n → K) (r : Round n) : Fin n → K :=
  fun i => if r.1 i = r.2 then w i else β * w i
    abbrev Round (n : ℕ) := (Fin n → Bool) × Bool

    Cslib.MachineLearning.WeightedMajority.weights

    For a penalty factor \(\beta\) in a field \(K\), the weights after a sequence of rounds \(r_1, \dots, r_k\) starting from weights \(w\) in \(K\) are obtained by applying the weighted majority update with penalty \(\beta\) for \(r_1\), then for \(r_2\), and so on up to \(r_k\); for the empty sequence they are \(w\).

    def weights (β : K) : List (Round n) → (Fin n → K) → Fin n → K
  | [], w => w
  | r :: rs, w => weights β rs (update β w r)

    DefinitionMistakes of the weighted majority algorithm#✓fully proved

    Cslib.MachineLearning.WeightedMajority.mistakes

    Let \(K\) be a field with a linear order, let \(\beta \in K\) be a penalty and let \(w\) be initial weights in \(K\) on \(n\) experts. The weighted majority algorithm processes a list of rounds in order: in each round it predicts the weighted majority vote of the experts' advice under the current weights, and then multiplies the weight of every expert whose advice differed from the true outcome by \(\beta\). Its number of mistakes is the number of rounds in which its prediction differs from the true outcome.

    def mistakes (β : K) : List (Round n) → (Fin n → K) → ℕ
  | [], _ => 0
  | r :: rs, w => (if predict w r.1 = r.2 then 0 else 1) + mistakes β rs (update β w r)
    abbrev Round (n : ℕ) := (Fin n → Bool) × Bool

    TheoremTotal weight after an update#✓fully proved

    Cslib.MachineLearning.WeightedMajority.total_update

    Let \(\beta\) be an element of a linearly ordered field \(K\), let \(w_0, \dots, w_{n-1} \in K\) be weights on \(n\) experts, and let \(r\) be a round with advice \(a \in \{\mathrm{true}, \mathrm{false}\}^n\) and outcome \(y\). If \(w'\) are the weights after the update with penalty \(\beta\) on \(r\), then \(\sum_{i < n} w'_i = \sum_{i < n} w_i - (1 - \beta) \sum_{i : a_i = \lnot y} w_i\): the experts that advised wrongly keep a \(\beta\) fraction of their weight.

    theorem total_update (β : K) (w : Fin n → K) (r : Round n) :
    total (update β w r) = total w - (1 - β) * weightOn w r.1 (!r.2)
    abbrev Round (n : ℕ) := (Fin n → Bool) × Bool

    TheoremA mistake costs weight#✓fully proved

    Cslib.MachineLearning.WeightedMajority.total_update_of_mistake

    Let \(K\) be a linearly ordered field, let \(\beta \in K\) with \(\beta \le 1\), let \(w\) be weights in \(K\) on \(n\) experts, and let \(r\) be a round on which the weighted majority vote under \(w\) differs from the true outcome. If \(W\) is the total weight of \(w\) and \(W'\) is the total weight after updating \(w\) on \(r\) with penalty \(\beta\), then \(2 W' \le (1 + \beta) W\).

    At least half of the weight was on the wrong side, and that side keeps only a \(\beta\) fraction of its weight.

    theorem total_update_of_mistake {β : K} (hβ1 : β ≤ 1) {w : Fin n → K} {r : Round n}
    (h : predict w r.1 ≠ r.2) : 2 * total (update β w r) ≤ (1 + β) * total w
    abbrev Round (n : ℕ) := (Fin n → Bool) × Bool

    TheoremTotal weight bound in terms of mistakes#✓fully proved

    Cslib.MachineLearning.WeightedMajority.total_weights_mul_le

    Let \(0 \le \beta \le 1\) in a linearly ordered field \(K\), let \(w\) be nonnegative weights in \(K\) on \(n\) experts, and let \(\rho\) be a sequence of rounds. Let \(M\) be the number of mistakes the weighted majority algorithm with penalty \(\beta\) makes on \(\rho\) starting from \(w\), and let \(W\) and \(W'\) be the total weights before and after \(\rho\). Then \(W' \cdot 2^M \le (1 + \beta)^M \cdot W\).

    theorem total_weights_mul_le {β : K} (hβ0 : 0 ≤ β) (hβ1 : β ≤ 1) :
    ∀ (rs : List (Round n)) (w : Fin n → K), (∀ i, 0 ≤ w i) →
    total (weights β rs w) * 2 ^ mistakes β rs w ≤ (1 + β) ^ mistakes β rs w * total w
    abbrev Round (n : ℕ) := (Fin n → Bool) × Bool
