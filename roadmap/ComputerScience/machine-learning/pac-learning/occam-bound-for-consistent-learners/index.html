    Occam bound for consistent learners

    DefinitionTrue error against a target labelling#✓fully proved

    Cslib.MachineLearning.PACLearning.trueError

    Let \(\mu\) be a distribution on a measurable space \(X\) of instances, \(c : X \to Y\) a target labelling and \(h : X \to Y\) a hypothesis. The true error of \(h\) against \(c\) is $\(\operatorname{err}_\mu(h) = \mu\{x \in X : h(x) \ne c(x)\} \in [0, \infty],\)$ the probability that \(h\) disagrees with the target on a fresh instance; Shalev-Shwartz and Ben-David write it \(L_{(\mathcal{D}, f)}(h)\). It is CSLib's 0-1 error of \(h\) under the joint distribution obtained by labelling \(\mu\) with \(c\) (see the bridge below).

    Valiant's 1984 definition is one-sided: examples are drawn from a distribution on the positive examples only, and the hypothesis must imply the target. Its two-sided variant, sketched in the same section, measures errors on both sides, as here.

    noncomputable def trueError (μ : Measure X) (c h : X → Y) : ℝ≥0∞ :=
  μ {x | h x ≠ c x}

    TheoremBridge from the true error to CSLib's error#✓fully proved

    Cslib.MachineLearning.PACLearning.trueError_eq_error_map

    If the target \(c\) is measurable and the disagreement set \(\{(x, y) : h(x) \ne y\}\) is measurable, then the true error of \(h\) against \(c\) under \(\mu\) equals CSLib's 0-1 error of \(h\) under the pushforward \(\mu \circ (x \mapsto (x, c(x)))^{-1}\) of \(\mu\) along the graph of \(c\): $\(\operatorname{err}_\mu(h) = \operatorname{error}_{\mu_c}(h), \qquad \mu_c = (x \mapsto (x, c(x)))_* \mu .\)$

    theorem trueError_eq_error_map (μ : Measure X) {c : X → Y} (hc : Measurable c) (h : X → Y)
    (hmeas : MeasurableSet {p : X × Y | h p.1 ≠ p.2}) :
    trueError μ c h = error (μ.map fun x => (x, c x)) h
    noncomputable def trueError (μ : Measure X) (c h : X → Y) : ℝ≥0∞ :=
  μ {x | h x ≠ c x}

    DefinitionThe realizable distribution family#✓fully proved

    Cslib.MachineLearning.PACLearning.realizableFamily

    For a concept class \(C\) of functions \(X \to Y\), the realizable family of \(C\) is the set of joint distributions \(D\) on \(X \times Y\) under which some concept \(h \in C\) has 0-1 error \(\operatorname{error}_D(h) = 0\). Under such a distribution the optimal error of \(C\) is \(0\), so CSLib's IsPACLearnable C (realizableFamily C) is PAC learnability in the realizable case. CSLib's IsPACLearnable is parameterized by a distribution family and does not fix this one.

    def realizableFamily (C : ConceptClass X Y) : Set (Measure (X × Y)) :=
  {D | ∃ h ∈ C, error D h = 0}

    Cslib.MachineLearning.PACLearning.map_graph_mem_realizableFamily

    If \(c : X \to Y\) is measurable and some \(h \in C\) with a measurable disagreement set has true error \(0\) against \(c\) under a distribution \(\mu\) on \(X\) (the realizability assumption of Shalev-Shwartz and Ben-David), then the labelled distribution \((x \mapsto (x, c(x)))_* \mu\) belongs to the realizable family of \(C\). This connects the textbook's pair (distribution on instances, labelling function) to CSLib's joint distributions.

    theorem map_graph_mem_realizableFamily (μ : Measure X) {C : ConceptClass X Y} {c : X → Y}
    (hc : Measurable c) {h : X → Y} (hC : h ∈ C)
    (hmeas : MeasurableSet {p : X × Y | h p.1 ≠ p.2}) (h0 : trueError μ c h = 0) :
    μ.map (fun x => (x, c x)) ∈ realizableFamily C

    TheoremA hypothesis survives \(m\) independent examples with probability \((1 - \operatorname{error})^m\)#✓fully proved

    Cslib.MachineLearning.PACLearning.pi_consistent_eq

    Let \(D\) be a probability distribution on labelled examples and \(h\) a hypothesis whose disagreement set \(\{(x, y) : h(x) \ne y\}\) is measurable. Under the product distribution \(D^m\) of \(m\) independent examples, $\(D^m\{S : h(x_i) = y_i \text{ for all } i < m\} = (1 - \operatorname{error}_D(h))^m ,\)$ where \(S = ((x_i, y_i))_{i<m}\). The event is the product of \(m\) copies of the agreement set.

    Here \(\operatorname{error}_D(h) = D\{(x, y) : h(x) \ne y\}\) is CSLib's 0-1 error of a hypothesis under a joint distribution \(D\) on labelled examples, and samples are CSLib's LabeledSamples.

    theorem pi_consistent_eq (D : Measure (X × Y)) [IsProbabilityMeasure D] (h : X → Y)
    (hmeas : MeasurableSet {p : X × Y | h p.1 ≠ p.2}) (m : ℕ) :
    Measure.pi (fun _ : Fin m => D) {S : LabeledSample X Y m | ∀ i, h (S i).1 = (S i).2} =
      (1 - error D h) ^ m

    TheoremUnion bound over a finite class (the Occam bound)#✓fully proved

    Cslib.MachineLearning.PACLearning.pi_exists_bad_consistent_le

    Let \(H\) be a finite set of hypotheses with measurable disagreement sets, \(D\) a probability distribution on labelled examples and \(\varepsilon \in [0, \infty]\). Then $\(D^m\{S : \text{the version space of } H \text{ at } S \text{ contains some } h \text{ with } \operatorname{error}_D(h) > \varepsilon\} \le |H|\,(1 - \varepsilon)^m ,\)$ where the version space (CSLib's VersionSpace) is the set of members of \(H\) that agree with every labelled example of \(S\). The event is the union, over the "bad" hypotheses of \(H\), of the events that each agrees with the sample.

    This is the realizable (noise-free) counterpart of the finite-class uniform deviation bound: it needs no concentration inequality and its sample size grows like \(\log |H| / \varepsilon\) instead of \(\log |H| / \varepsilon^2\).

    theorem pi_exists_bad_consistent_le (D : Measure (X × Y)) [IsProbabilityMeasure D]
    (H : Finset (X → Y)) (hmeas : ∀ h ∈ H, MeasurableSet {p : X × Y | h p.1 ≠ p.2}) (m : ℕ)
    (ε : ℝ≥0∞) :
    Measure.pi (fun _ : Fin m => D)
        {S | ∃ h ∈ VersionSpace (H : ConceptClass X Y) S, ε < error D h} ≤
      H.card * (1 - ε) ^ m
    Background
    Background
    • Uniform deviation of the empirical risk over a finite class: the agnostic version of the same union-bound argument, where Hoeffding's inequality replaces the exact probability \((1 - \operatorname{error})^m\) and the rate in \(\varepsilon\) is quadratic.

    For real \(\varepsilon \ge 0\) and every natural number \(m\), \((1 - \varepsilon)^m \le e^{-\varepsilon m}\), stated in \([0, \infty]\) with truncated subtraction (so the left side is \(0\) for \(\varepsilon > 1\) and \(m \ge 1\)); for \(\varepsilon \le 1\) it follows from \(1 - \varepsilon \le e^{-\varepsilon}\).

    Cslib.MachineLearning.PACLearning.ae_realizable_of_error_eq_zero

    If some \(h \in C\) with a measurable disagreement set has \(\operatorname{error}_D(h) = 0\), then \(m\) independent examples from \(D\) are almost surely realizable by \(C\) (CSLib's Realizable: some concept of \(C\) agrees with every labelled example), since \(h\) itself agrees with all of them with probability \((1 - 0)^m = 1\).

    Cslib.MachineLearning.PACLearning.pi_consistent_learner_error_gt_le

    Let \(H\) be a finite set of hypotheses with measurable disagreement sets, \(D\) a probability distribution under which some \(h \in H\) has error \(0\), and \(A\) a learner on samples of size \(m\) that is consistent with \(H\) in CSLib's sense (IsConsistent: on every sample realizable by \(H\), its output lies in the version space). Then for every \(\varepsilon\), $\(D^m\{S : \operatorname{error}_D(A(S)) > \varepsilon\} \le |H|\,(1 - \varepsilon)^m .\)$ The learner is only required to be consistent on realizable samples; the samples on which it is unconstrained have probability \(0\) by the previous statement.

    (H : Finset (X → Y)) (hmeas : ∀ h ∈ H, MeasurableSet {p : X × Y | h p.1 ≠ p.2})
    (hreal : ∃ h ∈ H, error D h = 0) {m : ℕ} (A : Learner X Y m)
    (hA : IsConsistent A (H : ConceptClass X Y)) (ε : ℝ≥0∞) :
    Measure.pi (fun _ : Fin m => D) {S | ε < error D (A S)} ≤ H.card * (1 - ε) ^ m

    Cslib.MachineLearning.PACLearning.pi_consistent_learner_error_gt_le_of_log_div_le

    Let \(H\) be a finite set of hypotheses with measurable disagreement sets, \(D\) a probability distribution satisfying the realizability assumption (some \(h \in H\) has error \(0\)), \(A\) a learner consistent with \(H\), and \(\varepsilon > 0\), \(\delta > 0\) and $\(m \ge \frac{\log(|H| / \delta)}{\varepsilon}.\)$ Then \(D^m\{S : \operatorname{error}_D(A(S)) > \varepsilon\} \le \delta\): with probability at least \(1 - \delta\) over \(m\) independent examples, the learner's hypothesis has error at most \(\varepsilon\). Consistent learners are the empirical risk minimizers of the realizable case, so this is the textbook corollary for ERM rules over a finite class, stated for consistent learners.

    theorem pi_consistent_learner_error_gt_le_of_log_div_le (D : Measure (X × Y))
    [IsProbabilityMeasure D] (H : Finset (X → Y))
    (hmeas : ∀ h ∈ H, MeasurableSet {p : X × Y | h p.1 ≠ p.2})
    (hreal : ∃ h ∈ H, error D h = 0) {m : ℕ} (A : Learner X Y m)
    (hA : IsConsistent A (H : ConceptClass X Y)) {ε δ : ℝ} (hε0 : 0 < ε) (hδ : 0 < δ)
    (hm : Real.log (H.card / δ) / ε ≤ m) :
    Measure.pi (fun _ : Fin m => D) {S | ENNReal.ofReal ε < error D (A S)} ≤

  if hS : Realizable (H : ConceptClass X Y) S then hS.choose else hH.choose
