    Single-linkage hierarchical clustering

    Single-linkage clustering at scale r puts two points in the same cluster when a chain of points joins them with every hop of length at most r. For a metric space the clusters are the connected components of the Vietoris–Rips complex at scale r, which is why G. Carlsson calls clustering the statistical counterpart of π₀ (Topology and data, Bull. AMS 46 (2009), §1 and §3.2). Letting r vary gives a nested family of partitions, the dendrogram, which is the same datum as the ultrametric u*(x, y), the smallest scale at which x and y are joined. G. Carlsson and F. Mémoli (Characterization, stability and convergence of hierarchical clustering methods, JMLR 11 (2010)) show that u* is the maximal subdominant ultrametric, that single linkage is functorial for distance non-increasing maps and stable under perturbation of the metric (Lemma 15, proved here; Gromov–Hausdorff stability, Prop. 26), and that it is the only hierarchical clustering method satisfying their three axioms (Thm. 18, proved here in both directions), in contrast with Kleinberg's impossibility theorem for flat clustering (their Thm. 1).

    MathlibExt.Topology.TDA.SLEquiv

    For a dissimilarity d : X → X → ℝ and a scale r, SLEquiv d r is the equivalence relation generated by d x y ≤ r: x and y are r-equivalent when they are joined by a finite chain x = x₀, x₁, …, x_k = y whose consecutive points satisfy d xᵢ xᵢ₊₁ ≤ r (up to the order of the arguments of d). Its classes are the single-linkage clusters at scale r (Carlsson and Mémoli, JMLR 11 (2010), Example 1; Carlsson, Topology and data, Bull. AMS 2009, §3.2).

    def SLEquiv (d : X → X → ℝ) (r : ℝ) : X → X → Prop :=
  EqvGen fun x y => d x y ≤ r

    MathlibExt.Topology.TDA.SLEquiv.map

    A distance non-increasing map f : (X, d) → (Y, e) (that is, e (f x) (f y) ≤ d x y) sends r-equivalent points to r-equivalent points, hence maps each cluster of X into a cluster of Y at every scale. This is Carlsson's functoriality of clustering (Carlsson, Topology and data, Bull. AMS 2009, Def. 3.2, there for distance-preserving maps) and the property behind condition (II) of the characterization of single linkage (Carlsson and Mémoli, JMLR 11 (2010), Thm. 18).

    theorem SLEquiv.map {Y : Type*} {d : X → X → ℝ} {e : Y → Y → ℝ} (f : X → Y)

    SLEquiv e r (f x) (f y)

    MathlibExt.Topology.TDA.slDist

    For a dissimilarity d, slDist d x y is the infimum of the scales r ≥ 0 at which x and y are r-equivalent, i.e. the infimum over chains x = x₀, …, x_k = y of the largest hop. On a finite set the infimum is attained and this is the ultrametric u* of Carlsson and Mémoli (JMLR 11 (2010), Example 7, equation (4)), the maximal sub-dominant ultrametric, which encodes the single-linkage dendrogram (Lemma 12 and Cor. 14 there).

    noncomputable def slDist (d : X → X → ℝ) (x y : X) : ℝ :=
  sInf {r : ℝ | 0 ≤ r ∧ SLEquiv d r x y}
    def SLEquiv (d : X → X → ℝ) (r : ℝ) : X → X → Prop :=

    MathlibExt.Topology.TDA.IsMetricFn

    d is symmetric, zero exactly on the diagonal and satisfies the triangle inequality, so (X, d) is a metric space in the sense of Carlsson and Mémoli, JMLR 11 (2010), §2 (their finite metric spaces). It overlaps CSLibExt's MetricTSP.IsMetricCost; MathlibExt cannot import CSLibExt, and Mathlib's metric classes are instance-based (one metric per type), which does not fit comparing several dissimilarities on one set.

    structure IsMetricFn {X : Type*} (d : X → X → ℝ) : Prop where
  /-- Symmetry. -/
  symm : ∀ x y, d x y = d y x
  /-- Zero on the diagonal. -/
  self : ∀ x, d x x = 0
  /-- Positive off the diagonal. -/
  pos : ∀ x y, x ≠ y → 0 < d x y
  /-- The triangle inequality. -/
  triangle : ∀ x y z, d x z ≤ d x y + d y z
