    TheoremSum of squared distances about the centroid#✓fully proved

    Cslib.MachineLearning.KMeans.sum_sq_eq

    Let \(x_i\) (\(i \in \iota\)) be points in a real inner product space \(E\), let \(s\) be a finite set of indices, and let \(\mu\) be the centroid of the points \(x_i\) with \(i \in s\). Then for every point \(c \in E\),

    \[ \sum_{i \in s} \|x_i - c\|^2 = \sum_{i \in s} \|x_i - \mu\|^2 + |s| \, \|\mu - c\|^2. \]

    Consequently the centroid minimizes the sum of squared distances to the points \(x_i\), \(i \in s\).

    theorem sum_sq_eq (x : ι → E) (s : Finset ι) (c : E) :
    ∑ i ∈ s, ‖x i - c‖ ^ 2 =
      ∑ i ∈ s, ‖x i - centroid x s‖ ^ 2 + s.card * ‖centroid x s - c‖ ^ 2
    noncomputable def centroid (x : ι → E) (s : Finset ι) : E :=
  (s.card : ℝ)⁻¹ • ∑ i ∈ s, x i

    Cslib.MachineLearning.LatentVariable.HardEM.softAssign

    Given weights \(w_1, \dots, w_K \in \mathbb{R}\), means \(\mu_1, \dots, \mu_K \in \mathbb{R}^d\) and a real \(v\), the common-variance responsibility of component \(k\) at a point \(x \in \mathbb{R}^d\) is

    \[ r_v(x, k) = \frac{w_k \, \mathcal{N}(x \mid \mu_k, vI)} {\sum_i w_i \, \mathcal{N}(x \mid \mu_i, vI)}, \]

    where, for \(v > 0\), \(\mathcal{N}(x \mid \mu, vI)\) is the isotropic Gaussian density with mean \(\mu\) and covariance \(vI\), and for \(v \le 0\) it is \(1\) if \(d = 0\) and \(0\) if \(d \ge 1\). A quotient with denominator \(0\) is \(0\).

    noncomputable def softAssign (w : Fin K → ℝ) (μ : Fin K → EuclideanSpace ℝ (Fin d)) (v : ℝ)
    (x : EuclideanSpace ℝ (Fin d)) (k : Fin K) : ℝ :=
  w k * isoGaussPDF (μ k) v.toNNReal x / ∑ i, w i * isoGaussPDF (μ i) v.toNNReal x
    noncomputable def isoGaussPDF (μ : EuclideanSpace ℝ (Fin d)) (v : ℝ≥0)
    (x : EuclideanSpace ℝ (Fin d)) : ℝ :=
  ∏ i, gaussianPDFReal (μ i) v (x i)
