    Cslib.MachineLearning.NMF.objective

    The NMF objective: the squared Frobenius distance ‖X - W H‖_F² = ∑ i j, (X i j - (W H) i j)² between the data X and the product W * H.

    (X : Matrix m n ℝ) (W : Matrix m k ℝ) (H : Matrix k n ℝ) : ℝ :=
  ∑ i, ∑ j, (X i j - (W * H) i j) ^ 2

    DefinitionLee–Seung multiplicative update of H#✓fully proved

    Cslib.MachineLearning.NMF.updateH

    The Lee–Seung multiplicative update of H (Lee and Seung 2001, Theorem 1): H a j ← H a j * (Wᵀ X) a j / (Wᵀ W H) a j. An entry with a zero denominator becomes 0 (Lean's x / 0 = 0).

    noncomputable def updateH [Fintype m] [Fintype k]
    (X : Matrix m n ℝ) (W : Matrix m k ℝ) (H : Matrix k n ℝ) : Matrix k n ℝ :=
  Matrix.of fun a j => H a j * (Wᵀ * X) a j / (Wᵀ * W * H) a j

    TheoremLee–Seung, H step#✓fully proved

    Cslib.MachineLearning.NMF.objective_updateH_le

    Lee–Seung, H step (Lee and Seung 2001, Theorem 1): for W, H ≥ 0, the multiplicative update of H does not increase ‖X - W H‖_F². The proof is the auxiliary-function argument: the quadratic term of the exact expansion is bounded by Lee and Seung's diagonal majorant (here through a weighted Cauchy–Schwarz inequality), and the update minimizes the majorant. X may have any sign.

    theorem objective_updateH_le [Fintype m] [Fintype n] [Fintype k]
    {X : Matrix m n ℝ} {W : Matrix m k ℝ} {H : Matrix k n ℝ}
    (hW : ∀ i a, 0 ≤ W i a) (hH : ∀ a j, 0 ≤ H a j) :
    objective X W (updateH X W H) ≤ objective X W H
    def objective [Fintype m] [Fintype n] [Fintype k]
    (X : Matrix m n ℝ) (W : Matrix m k ℝ) (H : Matrix k n ℝ) : ℝ :=
  ∑ i, ∑ j, (X i j - (W * H) i j) ^ 2
