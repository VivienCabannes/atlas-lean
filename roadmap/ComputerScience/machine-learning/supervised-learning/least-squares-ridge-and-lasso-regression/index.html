    Cslib.MachineLearning.LeastSquares.rss

    For a real design matrix \(X\) with \(m\) rows and columns indexed by a finite type \(\iota\), responses \(y \in \mathbb{R}^m\) and \(\theta \in \mathbb{R}^\iota\), the residual sum of squares is \(S(\theta) = (y - X\theta) \cdot (y - X\theta) = \sum_{k=1}^{m} (y_k - (X\theta)_k)^2\).

    noncomputable def rss (X : Matrix (Fin m) ι ℝ) (y : Fin m → ℝ) (θ : ι → ℝ) : ℝ :=
  (y - X *ᵥ θ) ⬝ᵥ (y - X *ᵥ θ)

    TheoremExpansion of the residual sum of squares#✓fully proved

    Cslib.MachineLearning.LeastSquares.rss_add

    Let \(X\) be a real design matrix with \(m\) rows and columns indexed by a finite type \(\iota\), let \(y \in \mathbb{R}^m\), and write \(S(\theta) = (y - X\theta) \cdot (y - X\theta)\) for the residual sum of squares. Then for all \(\theta, v \in \mathbb{R}^\iota\),

    \[S(\theta + v) = S(\theta) - 2\, v \cdot \bigl(X^\top (y - X\theta)\bigr) + (Xv) \cdot (Xv).\]
    theorem rss_add (X : Matrix (Fin m) ι ℝ) (y : Fin m → ℝ) (θ v : ι → ℝ) :
    rss X y (θ + v) =
      rss X y θ - 2 * (v ⬝ᵥ (Xᵀ *ᵥ (y - X *ᵥ θ))) + (X *ᵥ v) ⬝ᵥ (X *ᵥ v)
    noncomputable def rss (X : Matrix (Fin m) ι ℝ) (y : Fin m → ℝ) (θ : ι → ℝ) : ℝ :=
  (y - X *ᵥ θ) ⬝ᵥ (y - X *ᵥ θ)

    Cslib.MachineLearning.LeastSquares.rss_eq_of_normal

    Let \(X\) be a real design matrix with \(m\) rows and columns indexed by a finite type \(\iota\), let \(y \in \mathbb{R}^m\), write \(S\) for the residual sum of squares, and let \(\theta_0 \in \mathbb{R}^\iota\) solve the normal equations \(X^\top X \theta_0 = X^\top y\).     TheoremLeast-squares estimates exist#✓fully proved

    Cslib.MachineLearning.LeastSquares.exists_normal

    Let \(X\) be a real matrix with \(m\) rows and columns indexed by a finite set \(\iota\), and let \(y \in \mathbb{R}^m\). Then there is \(\theta \in \mathbb{R}^\iota\) with \(X^\top X \theta = X^\top y\): the normal equations always have a solution, whatever the rank of \(X\).

    The reason is that the range of \(X^\top X\) is contained in that of \(X^\top\) and the two matrices have the same rank, so their ranges coincide.

    theorem exists_normal (X : Matrix (Fin m) ι ℝ) (y : Fin m → ℝ) :
    ∃ θ, Xᵀ *ᵥ (X *ᵥ θ) = Xᵀ *ᵥ y

    TheoremLeave-one-out least squares: leverage and deleted residual#✓fully proved

    Cslib.MachineLearning.LeastSquares.leaveOneOut_leverage_residual

    Let X be a real design with rows x k = X k, responses y, Gram matrix G = Xᵀ X invertible, and fix a row i with leverage h = xᵢᵀ G⁻¹ xᵢ ≠ 1. Let G₋ᵢ = G - xᵢ xᵢᵀ be the Gram matrix without row i, β = G⁻¹ Xᵀ y the least-squares estimate, and β₋ᵢ = G₋ᵢ⁻¹ (Xᵀ y - yᵢ xᵢ) the estimate without row i. Then:

    • G₋ᵢ is invertible;
    • β₋ᵢ is a least-squares estimate of the data with row i deleted: it minimizes the residual sum of squares of the design and responses with row i set to zero, which is ∑ k ≠ i, (y k - xₖᵀ θ)²;
    • q = xᵢᵀ G₋ᵢ⁻¹ xᵢ satisfies q = h / (1 - h) and h = q / (1 + q);
    • the residuals eᵢ = yᵢ - xᵢᵀ β and e₋ᵢ = yᵢ - xᵢᵀ β₋ᵢ, both at the original row i, satisfy eᵢ = (1 - h) e₋ᵢ.

      X i ⬝ᵥ ((Xᵀ * X)⁻¹ *ᵥ X i) =
        X i ⬝ᵥ ((Xᵀ * X - vecMulVec (X i) (X i))⁻¹ *ᵥ X i) /

    Gaussian noise: least squares is maximum likelihood

    DefinitionGaussian likelihood of linear regression#✓fully proved

    Cslib.MachineLearning.LeastSquares.gaussLikelihood

    Let \(X\) be a real matrix with \(m\) rows and columns indexed by a finite set \(\iota\), let \(y \in \mathbb{R}^m\) and let \(v \ge 0\). The Gaussian likelihood with noise variance \(v\) is the function of \(\theta \in \mathbb{R}^\iota\) given by

    \[ L(\theta) = \prod_{k=1}^{m} \frac{1}{\sqrt{2 \pi v}} \exp\left(-\frac{(y_k - (X\theta)_k)^2}{2 v}\right). \]

    This is the likelihood of \(y\) when \(y_k = (X\theta)_k + \varepsilon_k\) with independent \(\varepsilon_k \sim N(0, v)\).

    For \(v = 0\) each factor is the zero function (with the convention \(1/0 = 0\)), not a Dirac kernel; the results about this likelihood assume \(v \neq 0\).

    noncomputable def gaussLikelihood (X : Matrix (Fin m) ι ℝ) (y : Fin m → ℝ) (v : ℝ≥0)
    (θ : ι → ℝ) : ℝ :=
  ∏ k, gaussianPDFReal ((X *ᵥ θ) k) v (y k)

Then for all \(\theta, \theta' \in \mathbb{R}^\iota\), \(L(\theta) \le L(\theta')\) if and only if \(\mathrm{RSS}(\theta') \le \mathrm{RSS}(\theta)\).

    TheoremExpansion of the ridge objective around a solution of its normal equations#✓fully proved

    Cslib.MachineLearning.LeastSquares.ridge_eq_of_normal

    Let \(X\) be a real matrix with \(m\) rows and columns indexed by a finite set \(\iota\), let \(y \in \mathbb{R}^m\) and \(\lambda \in \mathbb{R}\), and write \(\|\cdot\|\) for the Euclidean norm and \(R(\theta) = \|y - X\theta\|^2 + \lambda \|\theta\|^2\) for the ridge objective.
