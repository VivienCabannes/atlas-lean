    Rademacher complexity

    The empirical Rademacher complexity of a set \(A \subseteq \mathbb{R}^n\) of value vectors, \(R(A) = \frac1n \mathbb{E}_\sigma \sup_{a \in A} \sum_i \sigma_i a_i\), averaged over the \(2^n\) sign vectors, in the convention of Shalev-Shwartz and Ben-David (Section 26.1, equation (26.5)); Bartlett and Mendelson's convention \(\mathbb{E} \sup_a \lvert \frac2n \sum_i \sigma_i a_i \rvert\) differs by the absolute value and the factor \(2\). Its structural calculus (monotonicity, convex hulls, scaling, sums, translations and Lipschitz contraction), Massart's finite-class lemma and the resulting bound \(\sqrt{2 d \log(e n / d) / n}\) for classes of VC dimension \(d\) are proved; the risk bound that turns it into a generalization guarantee is recorded as a wanted statement.

    DefinitionEmpirical Rademacher complexity#✓fully proved

    Cslib.MachineLearning.Rademacher.rademacherComplexity

    For \(A \subseteq \mathbb{R}^n\),

    \[R(A) = \frac{1}{n}\, \frac{1}{2^n} \sum_{\sigma \in \{-1, 1\}^n} \sup_{a \in A} \sum_{i=1}^n \sigma_i a_i ,\]

    the expectation over independent uniform signs written as a finite average. When \(A = \{(f(x_1), \dots, f(x_n)) : f \in \mathcal{F}\}\) is the set of value vectors of a function class on a fixed sample, \(R(A)\) is the empirical Rademacher complexity of \(\mathcal{F}\) on that sample.

    This is the convention of Shalev-Shwartz and Ben-David (Section 26.1, equation (26.5)) and of Bartlett, Foster and Telgarsky. Bartlett and Mendelson (2002) use \(\mathbb{E} \sup_a \lvert \frac{2}{n} \sum_i \sigma_i a_i \rvert\) instead; the two agree up to the factor \(2\) when \(A\) is symmetric (\(A = -A\)). In the convention here, several of their structural inequalities become identities, because each sign has mean zero.

    noncomputable def rademacherComplexity (A : Set (Fin n → ℝ)) : ℝ :=
  (n : ℝ)⁻¹ * (((2 : ℝ) ^ n)⁻¹ * ∑ ε : Fin n → Bool, supCorr A ε)
    noncomputable def supCorr (A : Set (Fin n → ℝ)) (ε : Fin n → Bool) : ℝ :=
  sSup (signCorr ε '' A)

    TheoremConvex hull invariance#✓fully proved

    Cslib.MachineLearning.Rademacher.rademacherComplexity_convexHull

    For a nonempty bounded \(A \subseteq \mathbb{R}^n\), \(R(\operatorname{conv} A) = R(A)\): for each sign vector, the linear functional \(a \mapsto \sum_i \sigma_i a_i\) has the same supremum on \(A\) and on its convex hull. This is why voting methods and the convex hulls used in boosting cost nothing beyond their base class.

    theorem rademacherComplexity_convexHull {A : Set (Fin n → ℝ)} (hne : A.Nonempty)

    rademacherComplexity (convexHull ℝ A) = rademacherComplexity A

    TheoremMinkowski sums#✓fully proved

    Cslib.MachineLearning.Rademacher.rademacherComplexity_add

    For nonempty bounded \(A, B \subseteq \mathbb{R}^n\), \(R(A + B) = R(A) + R(B)\). Bartlett and Mendelson state the inequality \(R(\sum_i F_i) \le \sum_i R(F_i)\) in their absolute-value convention; without the absolute value the supremum of a sum over a product set splits exactly.

    TheoremTranslation invariance#✓fully proved

    Cslib.MachineLearning.Rademacher.rademacherComplexity_add_singleton

    For nonempty bounded \(A \subseteq \mathbb{R}^n\) and every \(v \in \mathbb{R}^n\), \(R(A + \{v\}) = R(A)\). In Bartlett and Mendelson's absolute-value convention the corresponding statement is the inequality \(R_n(F + h) \le R_n(F) + \lVert h \rVert_\infty / \sqrt{n}\). Translation invariance is what lets a risk bound use the costs \(\varphi(y, f(x))\) directly instead of the recentred costs \(\varphi(y, f(x)) - \varphi(y, 0)\).

    theorem rademacherComplexity_add_singleton {A : Set (Fin n → ℝ)} (hA : A.Nonempty)
    (hA' : Bornology.IsBounded A) (v : Fin n → ℝ) :
    rademacherComplexity (A + {v}) = rademacherComplexity A
    noncomputable def rademacherComplexity (A : Set (Fin n → ℝ)) : ℝ :=
  (n : ℝ)⁻¹ * (((2 : ℝ) ^ n)⁻¹ * ∑ ε : Fin n → Bool, supCorr A ε)

    TheoremThe contraction lemma#✓fully proved

    Cslib.MachineLearning.Rademacher.rademacherComplexity_coordMap_le

    Let \(A \subseteq \mathbb{R}^n\) be bounded and let \(\varphi_1, \dots, \varphi_n : \mathbb{R} \to \mathbb{R}\) be \(L\)-Lipschitz. Then

    \[R\big(\{(\varphi_1(a_1), \dots, \varphi_n(a_n)) : a \in A\}\big) \le L\, R(A).\]

    No condition \(\varphi_i(0) = 0\) is needed in this convention; this is exactly the form of Shalev-Shwartz and Ben-David's Lemma 26.9. The absolute-value versions assume \(\varphi_i(0) = 0\): Bartlett and Mendelson's Theorem 12.4 pays a factor \(2\), and Ledoux and Talagrand's comparison principle for contractions (§4.5) is stated with an absolute value for contractions vanishing at \(0\). The proof replaces one coordinate map at a time by \(x \mapsto L x\): pairing each sign vector with the one that differs at that coordinate, the sum of the two suprema can only grow (Shalev-Shwartz and Ben-David's proof of Lemma 26.9). With the margin loss this is the step from the complexity of a real-valued class to that of its ramp-loss class in margin bounds.

    theorem rademacherComplexity_coordMap_le {A : Set (Fin n → ℝ)} (hA : Bornology.IsBounded A)
    (φ : Fin n → ℝ → ℝ) {L : NNReal} (hφ : ∀ i, LipschitzWith L (φ i)) :
    rademacherComplexity (coordMap φ '' A) ≤ L * rademacherComplexity A
    noncomputable def rademacherComplexity (A : Set (Fin n → ℝ)) : ℝ :=
  (n : ℝ)⁻¹ * (((2 : ℝ) ^ n)⁻¹ * ∑ ε : Fin n → Bool, supCorr A ε)

    TheoremMassart's finite-class lemma#✓fully proved

    Cslib.MachineLearning.Rademacher.rademacherComplexity_le_of_finite

    Let \(A \subseteq \mathbb{R}^n\) be finite and nonempty, and let \(r \ge 0\) with \(\lVert a \rVert_2 \le r\) for every \(a \in A\). Then

    \[R(A) \le \frac{r \sqrt{2 \log \lvert A \rvert}}{n}.\]

    The proof bounds \(\exp(\lambda \cdot \text{average supremum})\) by Jensen's inequality, the maximum by the sum over \(A\), and each exponential moment by \(\prod_i \cosh(\lambda a_i) \le \exp(\lambda^2 \lVert a \rVert_2^2 / 2)\), then optimizes over \(\lambda > 0\).

    theorem rademacherComplexity_le_of_finite {A : Set (Fin n → ℝ)} (hA : A.Finite)
    (hne : A.Nonempty) {r : ℝ} (hr : 0 ≤ r) (hnorm : ∀ a ∈ A, ∑ i, a i ^ 2 ≤ r ^ 2) :
    rademacherComplexity A ≤ r * sqrt (2 * log A.ncard) / n
    noncomputable def rademacherComplexity (A : Set (Fin n → ℝ)) : ℝ :=
  (n : ℝ)⁻¹ * (((2 : ℝ) ^ n)⁻¹ * ∑ ε : Fin n → Bool, supCorr A ε)

    TheoremRademacher complexity of a VC class#✓fully proved

    Cslib.MachineLearning.Rademacher.rademacherComplexity_signPatterns_le

    Let \(n \ge 1\) and let \(\mathcal{A}\) be a nonempty family of subsets of the sample \(\{1, \dots, n\}\), for example the sets \(\{i : h(x_i) = 1\}\) cut out by the hypotheses \(h\) of a binary class. Let \(d\) be the VC dimension of \(\mathcal{A}\), and let \(A\) be the set of the \(\pm 1\) sign patterns of the members of \(\mathcal{A}\). Then

    \[R(A) \le \sqrt{\frac{2 \log \sum_{k=0}^{d} \binom{n}{k}}{n}}.\]

    Each sign pattern has Euclidean norm \(\sqrt{n}\), so Massart's lemma gives \(R(A) \le \sqrt{2 \log \lvert \mathcal{A} \rvert / n}\), and the Sauer–Shelah lemma of Mathlib (Finset.card_shatterer_le_sum_vcDim with Finset.card_le_card_shatterer) bounds \(\lvert \mathcal{A} \rvert\) by \(\sum_{k \le d} \binom{n}{k}\). With the counting bound \(\sum_{k \le d} \binom{n}{k} \le (en/d)^d\) this becomes the familiar \(O(\sqrt{d \log(n/d) / n})\) rate, stated explicitly.

    theorem rademacherComplexity_signPatterns_le {𝒜 : Finset (Finset (Fin n))} (h𝒜 : 𝒜.Nonempty)
    (hn : 0 < n) :
    rademacherComplexity (signPatterns 𝒜) ≤
      sqrt (2 * log (∑ k ∈ Iic 𝒜.vcDim, n.choose k : ℕ) / n)
    noncomputable def rademacherComplexity (A : Set (Fin n → ℝ)) : ℝ :=
  (n : ℝ)⁻¹ * (((2 : ℝ) ^ n)⁻¹ * ∑ ε : Fin n → Bool, supCorr A ε)

    TheoremRademacher complexity of a VC class, explicit rate#✓fully proved

    Cslib.MachineLearning.Rademacher.rademacherComplexity_signPatterns_le_vcDim

    Let \(\mathcal{A}\) be a nonempty family of subsets of the sample \(\{1, \dots, n\}\) with VC dimension \(d \ge 1\), and let \(A\) be the set of the \(\pm 1\) sign patterns of its members. Then

    \[R(A) \le \sqrt{\frac{2 d \log(e n / d)}{n}}.\]

    This is the bound in terms of \(\sum_{k \le d} \binom{n}{k}\) combined with the counting bound \(\sum_{k \le d} \binom{n}{k} \le (e n / d)^d\); the hypothesis \(d \ge 1\) excludes the trivial case, and \(d \le n\) holds automatically. Through a risk bound such as Bartlett and Mendelson's Theorem 8, it gives the \(O(\sqrt{d \log(n/d) / n})\) generalization rate of empirical risk minimization over a class of VC dimension \(d\).

    theorem rademacherComplexity_signPatterns_le_vcDim {𝒜 : Finset (Finset (Fin n))}
    (h𝒜 : 𝒜.Nonempty) (hd : 1 ≤ 𝒜.vcDim) :
    rademacherComplexity (signPatterns 𝒜) ≤
      sqrt (2 * 𝒜.vcDim * log (exp 1 * n / 𝒜.vcDim) / n)
    noncomputable def rademacherComplexity (A : Set (Fin n → ℝ)) : ℝ :=

    TheoremThe Rademacher risk bound#●ready to prove

    Cslib.MachineLearning.Rademacher.risk_le_empirical_add_rademacher

    Let \(P\) be a probability measure on \(X \times Y\), let \(\mathcal{F}\) be a finite class of functions \(X \to \mathcal{A}\), and let \(L \le \varphi\) be a loss and a dominating cost with \(0 \le L\) and \(\varphi \le 1\), measurable along every \(f \in \mathcal{F}\). For \(n \ge 1\) and \(0 < \delta < 1\), with probability at least \(1 - \delta\) over an i.i.d. sample \(S = ((X_i, Y_i))_{i \le n} \sim P^n\), every \(f \in \mathcal{F}\) satisfies

    \[\mathbb{E}_P\, L(Y, f(X)) \le \frac{1}{n} \sum_{i=1}^n \varphi(Y_i, f(X_i)) + 2\, \mathbb{E}_{S'}\, R\big(\varphi \circ \mathcal{F}|_{S'}\big) + \sqrt{\frac{8 \log(2/\delta)}{n}},\]

    where \(\varphi \circ \mathcal{F}|_{S'}\) is the set of cost vectors \((\varphi(Y'_i, f(X'_i)))_i\).

    This is Bartlett and Mendelson's Theorem 8 in the convention of this library: their proof (McDiarmid's inequality, then symmetrization with a ghost sample) ends with \(2\, \mathbb{E} \sup_h \frac{1}{n} \sum_i \sigma_i h(X_i, Y_i)\), which is the middle term above and is at most their \(R_n(\tilde\varphi \circ F)\); the recentring \(\tilde\varphi\) is unnecessary here by translation invariance. The finite class is a restriction that makes every quantity measurable; the source states the result for general classes. For \(\varphi = L\), Shalev-Shwartz and Ben-David's Theorem 26.5 (part 1) gives the same bound with the sharper deviation term \(\sqrt{2 \log(2/\delta)/n}\).
