    Cslib.MachineLearning.LatentVariable.ExpectationMaximization.sum_mul_log_sub_le

    Let \(Z\) be a finite set, let \(p : Z \to \mathbb{R}\) satisfy \(p(z) > 0\) for all \(z\), and let \(q\) be a probability distribution on \(Z\). Then \(\sum_{z \in Z} q(z) (\log p(z) - \log q(z)) \le \log \sum_{z \in Z} p(z)\).

    ∑ z, q z * (log (p z) - log (q z)) ≤ log (∑ z, p z)

    Cslib.MachineLearning.LatentVariable.ExpectationMaximization.sum_div_mul_log_sub

    Let \(Z\) be a finite nonempty set, let \(p : Z \to \mathbb{R}\) satisfy \(p(z) > 0\) for all \(z\), and write \(P = \sum_{z \in Z} p(z)\). Then

    \[\sum_{z \in Z} \frac{p(z)}{P} \left(\log p(z) - \log \frac{p(z)}{P}\right) = \log P,\]

    that is, the bound of Gibbs' inequality is attained at the distribution \(q = p / P\).

    theorem sum_div_mul_log_sub {p : Z → ℝ} (hp : ∀ z, 0 < p z) [Nonempty Z] :
    ∑ z, p z / (∑ z', p z') * (log (p z) - log (p z / ∑ z', p z')) = log (∑ z, p z)

    Cslib.MachineLearning.LatentVariable.ExpectationMaximization.posterior

    For a joint model \(p\) with finite latent space \(Z\), the posterior of the latent value \(z\) given the observation \(x\) at the parameter \(\theta\) is \(p_\theta(z \mid x) = p_\theta(x, z) / p_\theta(x)\), where \(p_\theta(x) = \sum_{z' \in Z} p_\theta(x, z')\) is the marginal (the quotient is read as \(0\) when the marginal is \(0\)).
