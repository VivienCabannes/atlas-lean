    DefinitionOne step of the Lamport clock algorithm#✓fully proved

    Cslib.Distributed.LamportClock.clockStep

    The state is a counter \(c(p) \in \mathbb{N}\) for each process \(p\) together with the timestamps assigned so far. An event \(e\) of process \(p\) gets the timestamp \(t = \max(c(p), s) + 1\), where \(s\) is the timestamp already assigned at the position that \(e\) receives from; \(s = 0\) if \(e\) is not a receipt or if no timestamp has been assigned at that position. The step sets \(c(p)\) to \(t\) and appends \(t\) to the timestamps.

    The timestamps are kept in an array, for constant-time append and lookup.

    def clockStep (st : (P → ℕ) × Array ℕ) (e : Event P) : (P → ℕ) × Array ℕ :=
  let t := max (st.1 e.proc) ((e.recvFrom.map fun i => st.2[i]?.getD 0).getD 0) + 1
  (Function.update st.1 e.proc t, st.2.push t)

    DefinitionLamport timestamps#✓fully proved

    Cslib.Distributed.LamportClock.timestamps

    The Lamport timestamps \(t_0, \dots, t_{n-1}\) of an execution \(e_0, \dots, e_{n-1}\) are computed by Lamport's clock algorithm. Every process keeps a counter, initially \(0\). For \(k = 0, \dots, n-1\) in turn, let \(c\) be the current counter of the process of \(e_k\), and let \(m = t_i\) if \(e_k\) receives the message sent by the event at position \(i\) with \(i < k\), and \(m = 0\) otherwise. Then \(t_k = \max(c, m) + 1\), and the counter of the process of \(e_k\) is set to \(t_k\).

    def timestamps (tr : List (Event P)) : List ℕ := (run tr).2.toList
