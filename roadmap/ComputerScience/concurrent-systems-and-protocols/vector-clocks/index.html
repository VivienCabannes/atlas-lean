    Cslib.Distributed.VectorClock.stamp

    Let \(P\) be the set of processes. Given the current vectors \(V_q \in \mathbb{N}^P\) of the processes \(q\) and the timestamps \(T_0, T_1, \dots\) assigned so far, the vector clock algorithm stamps an event \(e\) of process \(p\) as follows. Let \(m = T_i\) if \(e\) receives the message sent by the event at position \(i\) and \(T_i\) has been assigned, and \(m = 0\) otherwise. The stamp of \(e\) is the pointwise maximum of \(V_p\) and \(m\), with its \(p\)-entry increased by \(1\).

    def stamp (st : (P → P → ℕ) × Array (P → ℕ)) (e : Event P) : P → ℕ :=
  let base : P → ℕ := fun q =>
    max (st.1 e.proc q) ((e.recvFrom.map fun i => (st.2[i]?.getD 0) q).getD 0)
  Function.update base e.proc (base e.proc + 1)
    structure Event (P : Type*) where
  /-- The process the event belongs to. -/
  proc : P
  /-- The position of the sending event, for a receipt. -/
  recvFrom : Option ℕ

    Cslib.Distributed.VectorClock.clockStep

    The state of the algorithm holds a vector \(V_q \in \mathbb{N}^P\) for each process \(q\), where \(P\) is the set of processes, and the timestamps assigned so far, kept in an array for constant-time append and lookup. On an event \(e\) of process \(p\), the step replaces \(V_p\) by the stamp \(s\) of \(e\) computed from the current state, leaves the other vectors unchanged, and appends \(s\) to the timestamps.

    def clockStep (st : (P → P → ℕ) × Array (P → ℕ)) (e : Event P) :
    (P → P → ℕ) × Array (P → ℕ) :=
  (Function.update st.1 e.proc (stamp st e), st.2.push (stamp st e))
