    The channel names of the go-back-N protocol are \(\mathsf{acc}\) (accept a message from the user), \(\mathsf{del}\) (deliver a message to the user) and, for every natural number \(k\): \(\mathsf{send}\,k\) (sender to data channel, a frame with sequence number \(k\)), \(\mathsf{recv}\,k\) (data channel to receiver), \(\mathsf{ack}\,k\) (receiver to sender, the cumulative acknowledgement naming \(k\) as the next expected frame) and \(\mathsf{reply}\,k\) (receiver to the acknowledgement channel, in the lossy variant).

    Cslib.Algorithms.CCS.GoBackN.ackUpdate

    For a go-back-N sender with window base \(b\), \(c\) outstanding messages and next-frame offset \(o\), and an acknowledgement \(k\), let \(d = \max(k + 3 - b, 0) \bmod 3\). If \(1 \le d \le c\), the window slides: the new sender has base \(k\), \(c - d\) outstanding messages and next-frame offset \(\max(o - d, 0)\). Otherwise the sender is unchanged.
