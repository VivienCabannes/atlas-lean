    Byzantine generals problem

    StructureOral-message protocol#✓fully proved

    Cslib.Distributed.Byzantine.Impossibility.OralProtocol

    A synchronous oral-message protocol for a set \(G\) of generals, with orders in \(V\), local states in \(\sigma\) and messages in \(M\), consists of an initial state for each general in \(G\), used by the generals other than the commander; an initial state of the commander for each order in \(V\); a sending function giving, for each round \(r\), each general \(j\) in each state \(s\) and each general \(i\), the message in \(M\) that \(j\) sends to \(i\) in round \(r\); a transition function giving, for each round \(r\), each general \(i\) in each state \(s\) and each assignment of a message to every sender \(j\), the state of \(i\) after round \(r\); and a decision function giving the value in \(V\) that each general decides in each state.

    The commander is not part of the protocol: it is chosen when the protocol is run. In each round every general sends its messages from its current state and then moves to the state given by the transition function on the messages it received. Only the commander's initial state depends on the order.

    structure OralProtocol (G V σ M : Type*) where
  /-- The initial state of each general other than the commander. -/
  init : G → σ
  /-- The initial state of the commander, given its order. -/
  initCommander : V → σ
  /-- `send r j s i` is the message general `j`, in state `s`, sends to general `i` in round
  `r`. -/
  send : ℕ → G → σ → G → M
  /-- `recv r i s msg` is the state of general `i` after round `r`, from its state `s` and the
  message `msg j` it received from each general `j`. -/
  recv : ℕ → G → σ → (G → M) → σ
  /-- `decide i s` is the value general `i` decides in its final state `s`. -/
  decide : G → σ → V

For each round \(r\) and node \(k\), let \(s_r(k), s'_r(k) \in \sigma\) be two states and \(\mu_r(k), \mu'_r(k) : G \to M\) two families of received messages. Suppose that for every \(r\) and every node \(k\) satisfying \(L\), \(s_{r+1}(k)\) is the state to which general \(\rho(k)\) of \(P\) moves in round \(r\) from \(s_r(k)\) on the messages \(\mu_r(k)\), and \(s'_{r+1}(k)\) the one to which it moves from \(s'_r(k)\) on \(\mu'_r(k)\); that \(s_0(k) = s'_0(k)\) for every \(k\) satisfying \(L\); and that for every \(r\), if \(s_r(k) = s'_r(k)\) for all \(k\) satisfying \(L\), then \(\mu_r(k) = \mu'_r(k)\) for all \(k\) satisfying \(L\).     DefinitionExecutions of an oral-message protocol#✓fully proved

    Cslib.Distributed.Byzantine.Impossibility.OralProtocol.state

    Let \(P\) be an oral-message protocol for the generals \(G\), let \(c \in G\) be the commander, \(v\) its order and \(S \subseteq G\) a finite set of traitors, and let \(a_r(j, i)\) be the message a traitor \(j\) sends general \(i\) in round \(r\). The state of general \(i\) after \(r\) rounds is defined by recursion on \(r\). After \(0\) rounds it is the initial state of \(i\) for commander \(c\) and order \(v\). After \(r + 1\) rounds it is the state to which \(i\) moves by its code for round \(r\) from its state after \(r\) rounds, on receiving \(a_r(j, i)\) from each traitor \(j \in S\) and, from each other general \(j\), the message that \(P\) has \(j\) send to \(i\) in round \(r\) from the state of \(j\) after \(r\) rounds.

    def state (c : G) (v : V) (traitors : Finset G) (adv : ℕ → G → G → M) : ℕ → G → σ
  | 0, i => P.initState c v i
  | r + 1, i => P.recv r i (state c v traitors adv r i) fun j =>
      if j ∈ traitors then adv r j i else P.send r j (state c v traitors adv r j) i

Condition IC1 holds after \(T\) rounds when any two generals \(i\) and \(j\), neither of which is the commander or a traitor, decide the same value after \(T\) rounds of this execution.

    Cslib.Distributed.Byzantine.Impossibility.OralProtocol.Solves

    An oral-message protocol \(P\) for the generals \(G\) solves the Byzantine generals problem with commander \(c \in G\) and at most \(m\) traitors in \(T\) rounds if, for every order \(v\), every set of at most \(m\) traitors and every behaviour of the traitors (the message each traitor sends to each general in each round), conditions IC1 (agreement) and IC2 (validity) hold after \(T\) rounds.

    def Solves (c : G) (m T : ℕ) : Prop :=
  ∀ (v : V) (traitors : Finset G), traitors.card ≤ m → ∀ adv : ℕ → G → G → M,
    P.Agreement c v traitors adv T ∧ P.Validity c v traitors adv T

    TheoremNo protocol for three generals tolerates one traitor#✓fully proved

    Cslib.Distributed.Byzantine.Impossibility.OralProtocol.exists_violation_three

    Suppose there are at least two possible orders. For every oral-message protocol for three generals \(0\), \(1\), \(2\) with commander \(0\) and every number of rounds \(T\), there are an order \(v\), a general \(t\) and a behaviour of \(t\) such that, in the execution with order \(v\) in which \(t\) is the only traitor, the agreement condition (IC1) or the validity condition (IC2) fails after \(T\) rounds.

    This is the theorem of Pease, Shostak and Lamport, proved here by a commander version of the hexagon argument of Fischer, Lynch and Merritt.

    theorem exists_violation_three [Nontrivial V] (P : OralProtocol (Fin 3) V σ M) (T : ℕ) :
    ∃ (v : V) (t : Fin 3) (adv : ℕ → Fin 3 → Fin 3 → M),
      ¬ (P.Agreement 0 v {t} adv T ∧ P.Validity 0 v {t} adv T)

    DefinitionThree generals simulating a protocol#✓fully proved

    Cslib.Distributed.Byzantine.Impossibility.OralProtocol.simulate

    Let \(P\) be an oral-message protocol for the generals \(G\) with orders in \(V\), states \(\sigma\) and messages \(M\), let \(c \in G\), let \(\mathrm{grp} : G \to \{0, 1, 2\}\) split the generals into three groups and let \(\mathrm{rep} : \{0, 1, 2\} \to G\). The simulation of \(P\) with \(c\), \(\mathrm{grp}\) and \(\mathrm{rep}\) is the oral-message protocol for the generals \(\{0, 1, 2\}\) with orders in \(V\), whose states are families \((s(i))_{i \in G}\) of states of \(\sigma\) and whose messages are families \((\mu(j, i))_{j, i \in G}\) of messages of \(M\), defined as follows. A general other than the commander starts from the family of the initial states that \(P\) gives each general of \(G\) as a non-commander; the commander, with order \(v\), starts from the family of the initial states of the generals of \(G\) in \(P\) when \(c\) is the commander with order \(v\). In round \(r\), a general in state \(s\) sends every general the family whose entry \((j, i)\) is the message that general \(j\) of \(P\), in state \(s(j)\), sends to general \(i\) in round \(r\). In round \(r\), general \(g\) in state \(s\), having received \(\mu_h\) from each general \(h\), moves to the family that keeps \(s(i)\) for each \(i\) with \(\mathrm{grp}(i) \ne g\) and, for each \(i\) with \(\mathrm{grp}(i) = g\), holds the state to which general \(i\) of \(P\) moves in round \(r\) from \(s(i)\) on receiving \(\mu_{\mathrm{grp}(j)}(j, i)\) from each \(j \in G\). General \(g\) in final state \(s\) decides what general \(\mathrm{rep}(g)\) of \(P\) decides in state \(s(\mathrm{rep}(g))\).

    def simulate (c : G) (grp : G → Fin 3) (rep : Fin 3 → G) :
    OralProtocol (Fin 3) V (G → σ) (G → G → M) where
  init _ := P.init
  initCommander v := P.initState c v
  send r _ s _ j i := P.send r j (s j) i
  recv r g s msg i := if grp i = g then P.recv r i (s i) (fun j => msg (grp j) j i) else s i
  decide g s := P.decide (rep g) (s (rep g))

    TheoremSimulation reduces many generals to three#✓fully proved

    Cslib.Distributed.Byzantine.Impossibility.OralProtocol.solves_simulate

    Let \(P\) be an oral-message protocol for a finite set \(G\) of generals, let \(c \in G\) and \(m, T \in \mathbb{N}\), and suppose that \(P\) solves the Byzantine generals problem with commander \(c\) and at most \(m\) traitors in \(T\) rounds.
