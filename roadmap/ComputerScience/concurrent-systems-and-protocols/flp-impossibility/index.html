    FLP impossibility

    The theorem of Fischer, Lynch and Paterson (1985): in an asynchronous message-passing system no deterministic consensus protocol tolerates even one crash fault. The model on these pages is CSLib's (Cslib.FLP.Algorithm): no clocks and no bounds on speeds or message delays; a reliable, unordered message buffer, with every message to a process that is not faulty eventually delivered in a fair run; crash faults, a process being faulty in a run when from some time on a message to it is in flight and it receives nothing more; inputs delivered as messages in flight in the initial state; deterministic processes with write-once decisions. Pinned CSLib proves the theorem after Völzer's constructive proof; these pages state it and prove the original, stronger statement by the original bivalence proof, with its three lemmas.

    TheoremFLP impossibility of asynchronous consensus (CSLib form)#✓fully proved

    Cslib.Distributed.FLP.flp_impossibility

    With at least two processes, no deterministic asynchronous message-passing algorithm solves consensus tolerating \(f \ge 1\) crash faults. Solving consensus means, in CSLib's Cslib.FLP.Algorithm.Consensus: in every reachable state all decided values agree and each is the input of some process, and in every admissible run (fair, with at most \(f\) faulty processes) every process that is not faulty decides.

    Model. Asynchronous: no clocks, no bounds on relative speeds or message delays. Communication: a reliable unordered message buffer; a fair run delivers every message to a process that is not faulty. Failures: crash; a process is faulty in a run when from some time on a message to it is in flight and it receives nothing more. Processes are deterministic and a step is the receipt of one message. The proof is CSLib's (Cslib.FLP.Consensus.ge_one_not_exists), after Völzer's constructive proof; this page restates it.

    Relation to the source. The correctness condition is stronger than the one of Fischer, Lynch and Paterson, who require only partial correctness (agreement, and both decision values reachable) and that some process decides in every admissible run. An impossibility for a stronger requirement is a weaker theorem, so this is weaker than their Theorem 1; their statement is proved as FLP impossibility of asynchronous consensus, original form. With one process the hypothesis fails and consensus is trivial.

    theorem flp_impossibility [Fintype P] {f : ℕ} (hP : 2 ≤ card P) (hf : 1 ≤ f) :
    ¬ ∃ a : Algorithm P M S, a.Consensus f

    DefinitionValence of a state#✓fully proved

    Cslib.Distributed.FLP.Valent

    Valent a s b holds when some state reachable from s by the algorithm a has decided \(b\). In the terms of Fischer, Lynch and Paterson (1985, §3), \(b\) belongs to the set \(V\) of decision values of the configurations reachable from \(s\); \(s\) is bivalent when \(|V| = 2\) and \(b\)-valent when \(V = \{b\}\).

    def Valent (a : Algorithm P M S) (s : State P M S) (b : Bool) : Prop :=
  ∃ s', a.lts.CanReach s s' ∧ s'.Decided b

    TheoremCommutativity of disjoint schedules#✓fully proved

    Cslib.Distributed.FLP.mTr_comm

    If from a state \(s\) the schedule \(xs_1\) leads to \(s_1\) and the schedule \(xs_2\) leads to \(s_2\), and every message received in \(xs_1\) goes to a process of a set \(ps\) while every message received in \(xs_2\) goes to a process outside \(ps\), then \(xs_2\) can be applied to \(s_1\) and \(xs_1\) to \(s_2\), and both lead to the same state. This is Lemma 1 of Fischer, Lynch and Paterson (1985), in CSLib's model: schedules run by disjoint sets of processes do not interact.

    It strengthens CSLib's Cslib.FLP.CanReachVia.diamond (which CSLib attributes to Völzer's Proposition 1), which gives a common state reached by some schedules; here the same schedules are used, as in the source.

    theorem mTr_comm {ps : Set P} {xs₁ xs₂ : List (Action P M)} {s s₁ s₂ : State P M S}
    (hx₁ : xs₁.Forall (DestIn ps)) (h₁ : a.lts.MTr s xs₁ s₁)
    (hx₂ : xs₂.Forall (DestIn psᶜ)) (h₂ : a.lts.MTr s xs₂ s₂) :
    ∃ s', a.lts.MTr s₁ xs₂ s' ∧ a.lts.MTr s₂ xs₁ s'

    TheoremA bivalent initial state#✓fully proved

    Cslib.Distributed.FLP.exists_bivalent_start

    Let each decision value be decided in some reachable state, and let a decision be reachable from every reachable state without the participation of any one process (CSLib's PseudoTermination 1). Then some input assignment has a bivalent initial state. This is Lemma 2 of Fischer, Lynch and Paterson (1985), in CSLib's model.

    Proof. As in the source. Take inputs \(x_0\) and \(x_1\) from whose initial states false and true are reachable, order the processes, and let input \(k\) agree with \(x_1\) on the first \(k\) processes and with \(x_0\) on the others. If no initial state were bivalent, false would stay reachable from input \(k\) for every \(k\): inputs \(k\) and \(k + 1\) differ only at one process \(p\), and a decision reachable from input \(k\) without \(p\) is also reachable from input \(k + 1\), because \(p\)'s input is never read; if that decision were true, input \(k\) would be bivalent. Then false and true are both reachable from \(x_1\).

    Hypotheses. Fischer, Lynch and Paterson prove the lemma inside a proof by contradiction, assuming the protocol partially correct and totally correct in spite of one fault. Under CSLib's Consensus 1 the statement would be vacuous with two or more processes, since no such algorithm exists. It is stated under what the proof uses: both values decidable, and the termination property that follows from the contradiction hypothesis (Deciding runs give reachable decisions). Agreement and the number of processes are not needed. The hypotheses are jointly satisfiable, which the test module checks in Lean: in the algorithm on two processes in which each process decides the input bit it receives, both values can be decided and a decision is always reachable without any one process, and the lemma gives it a bivalent initial state. (That algorithm violates agreement, which this lemma does not assume.)

    theorem exists_bivalent_start [Fintype P]
    (hval : ∀ b, ∃ inp s, a.Reachable inp s ∧ s.Decided b) (hpt : a.PseudoTermination 1) :
    ∃ inp, Bivalent a (a.start inp)
    def Bivalent (a : Algorithm P M S) (s : State P M S) : Prop :=
  Valent a s false ∧ Valent a s true

    DefinitionReachability without an event#✓fully proved

    Cslib.Distributed.FLP.ReachWithout

    ReachWithout a m s t holds when \(t\) is reachable from \(s\) by a schedule that never receives the message \(m\). In Lemma 3 of Fischer, Lynch and Paterson (1985) these states form the set \(\mathcal{C}\) of configurations reachable from \(C\) without applying the event \(e = (p, m)\); since messages can be delayed arbitrarily, \(m\) stays in flight in all of them.

    def ReachWithout (a : Algorithm P M S) (m : Message P M) (s t : State P M S) : Prop :=
  ∃ xs, a.lts.MTr s xs t ∧ some m ∉ xs

    TheoremA bivalent configuration survives any pending event#✓fully proved

    Cslib.Distributed.FLP.exists_bivalent_recvMsg

    Let there be at least two processes, and let a satisfy agreement (no reachable state has decided two values) and CSLib's PseudoTermination 1 (a decision reachable from every reachable state without any one process). If a reachable state \(s\) is bivalent and the message \(m\) is in flight in \(s\), then some state \(t\) reachable from \(s\) without receiving \(m\) still has \(m\) in flight, and receiving \(m\) in \(t\) leads to a bivalent state. This is Lemma 3 of Fischer, Lynch and Paterson (1985), in CSLib's model: the event \(e\) of receiving \(m\) can be postponed until it no longer decides the outcome.

    Proof. As in the source. Suppose every state of \(\mathcal{D} = e(\mathcal{C})\) is univalent. Both values occur in \(\mathcal{D}\), so along a schedule in \(\mathcal{C}\) there are neighbours \(g_1 \to g_2\), by a step \(e'\), with \(e(g_1)\) and \(e(g_2)\) of different valences. If \(e'\) is received by a process other than the receiver \(p\) of \(m\), then \(e\) and \(e'\) commute and \(e(g_2)\) is reachable from \(e(g_1)\), which is impossible. If both are received by \(p\), take a decided state \(A\) reachable from \(g_1\) without \(p\) (pseudo-termination); by commutativity \(A\) reaches states below \(e(g_1)\) and below \(e(g_2)\), so \(A\) would be bivalent although it has decided.

    Hypotheses. As for A bivalent initial state, the lemma is stated under what its proof uses rather than under Consensus 1, under which it would be vacuous. With exactly two processes it is vacuous all the same: no algorithm satisfying agreement and PseudoTermination 1 on two processes has a reachable bivalent state. Each process alone can then reach a decision from every reachable state; by commutativity and agreement all these solo decisions from a state agree, and no step changes that common value, which is the decision of any decided state. For three or more processes the hypotheses can hold (informally, a Paxos-type algorithm in which any majority of the processes, in particular all but one, can complete a ballot satisfies them and has bivalent reachable states), but no such algorithm is formalized, so this is not checked in Lean. The argument for two processes is the reviewer's, not from a cited source.

    theorem exists_bivalent_recvMsg [Fintype P] (hP : 2 ≤ card P)
    (hag : ∀ inp s, a.Reachable inp s → s.Agreed) (hpt : a.PseudoTermination 1)
    {inp : P → Bool} {s : State P M S} (hr : a.Reachable inp s) (hb : Bivalent a s)
    {m : Message P M} (hm : m ∈ s.msgs) :
    ∃ t, ReachWithout a m s t ∧ m ∈ t.msgs ∧ Bivalent a (a.recvMsg m t)
    def Bivalent (a : Algorithm P M S) (s : State P M S) : Prop :=
  Valent a s false ∧ Valent a s true

    TheoremDeciding runs give reachable decisions#✓fully proved

    Cslib.Distributed.FLP.pseudoTermination_of_forall_decides

    If there are at least two processes and every admissible run of a with at most one faulty process decides (some process decides at some time), then a satisfies PseudoTermination 1: from every reachable state a decision can be reached using only the processes of any set that misses at most one process.

    This is the step at which the FLP proof uses its contradiction hypothesis: a fair run of the processes outside one process, from a reachable state, is admissible with at most one faulty process, so it decides. The run is built with CSLib's fair scheduler, as in CSLib's proof that consensus algorithms are pseudo-consensus algorithms (Cslib.FLP.PseudoConsensus.of_consensus), from which the argument is adapted.

    (hdec : ∀ inp ss xs, a.AdmissibleRun inp 1 ss xs → ∃ k b, (ss k).Decided b) :
    a.PseudoTermination 1

    TheoremFLP impossibility of asynchronous consensus, original form#✓fully proved

    Cslib.Distributed.FLP.flp_original

    Let there be at least two processes and let a be partially correct: no reachable state has decided two different values, and each value \(b\) is decided in some state reachable from some input. Then some admissible run with at most one faulty process never decides: no process decides at any time. This is Theorem 1 of Fischer, Lynch and Paterson ("no consensus protocol is totally correct in spite of one fault"), stated and proved in CSLib's model.

    Model. As in FLP impossibility of asynchronous consensus (CSLib form): asynchronous, a reliable unordered message buffer with fair delivery to processes that are not faulty, crash faults, deterministic processes. The model differs from that of Fischer, Lynch and Paterson in three respects: in their model a step may receive the null message, so a process can always take a step on its own, whereas here every step receives a message (a protocol can emulate spontaneous steps with messages to itself); a process holds its input in an input register there, whereas here the input is delivered to it as a message, in flight in the initial state; and a process is faulty there when it takes only finitely many steps, whereas here it is faulty when from some time on a message to it is in flight and it receives nothing more. The theorem is proved in this model, not transferred from theirs. The run produced has no faulty process.

    Strength. Partial correctness asks less than CSLib's consensus condition (no validity, and only some process must decide), so this statement implies the CSLib form for \(f = 1\). The hypotheses are satisfiable: in an algorithm where one fixed process decides its own input when it receives it and no other process ever decides, partial correctness holds (see the test module); there the theorem's run is, for instance, one in which that process never receives its input.

    Proof. As in the source. Suppose every admissible run decides. Then a decision is reachable from every reachable state without any one process; Lemma 2 gives a bivalent initial state; and Lemma 3, applied stage by stage with CSLib's fair scheduler, delivers every pending message while returning to a bivalent state at the end of each stage. The run so built is admissible and never decides, since a decided reachable state is not bivalent (by agreement).

    theorem flp_original [Fintype P] (hP : 2 ≤ card P) (a : Algorithm P M S)
    (hagree : ∀ inp s, a.Reachable inp s → s.Agreed)
    (hval : ∀ b, ∃ inp s, a.Reachable inp s ∧ s.Decided b) :
    ∃ inp ss xs, a.AdmissibleRun inp 1 ss xs ∧ ∀ k b, ¬ (ss k).Decided b

    Related topics

    • Two-phase commit: a commit protocol; by the theorem every asynchronous commit protocol has a "window of vulnerability" in which one slow or crashed process can block it.
    • Byzantine agreement: consensus in synchronous rounds, where crash faults are tolerable but Byzantine faults need \(n > 3m\).
    • Labelled transition systems: CSLib's model of an algorithm is a labelled transition system whose labels are message receipts.
    • Synchronous consensus with crash failures: with synchrony consensus tolerates crashes, but \(f\) crashes cost \(f + 1\) rounds.
    • Paxos consensus: in this asynchronous crash-failure setting Paxos keeps safety (at most one value chosen) unconditionally and gives up guaranteed termination, as the theorem requires.
