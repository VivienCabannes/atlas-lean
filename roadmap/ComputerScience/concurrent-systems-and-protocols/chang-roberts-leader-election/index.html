    DefinitionDelivering a message in the Chang–Roberts ring#✓fully proved

    Cslib.Distributed.ChangRoberts.deliver

    On a ring of \(n + 1\) processes with identifiers \(\mathrm{id}\), process \(k\) receives the oldest message in its channel in state \(s\). If the channel of \(k\) is empty there is no step. Otherwise let \(j\) be the origin of that message, which is removed from the channel: if \(\mathrm{id}(k) < \mathrm{id}(j)\), process \(k\) forwards it by appending \(j\) to the end of the channel of its successor on the ring; otherwise, if \(j = k\), process \(k\) declares itself leader; otherwise the message is discarded. Nothing else changes.

    def deliver (id : Fin (n + 1) → ℕ) (s : State n) (k : Fin (n + 1)) : Option (State n) :=
  match s.chan k with
  | [] => none
  | j :: rest =>
      let c := Function.update s.chan k rest
      if id k < id j then
        some ⟨Function.update c (succ k) (c (succ k) ++ [j]), s.leader⟩
      else if j = k then
        some ⟨c, Function.update s.leader k true⟩
      else
        some ⟨c, s.leader⟩

    StructureThe Chang–Roberts invariant#✓fully proved

    Cslib.Distributed.ChangRoberts.Inv

    Given identifiers \(\mathrm{id}\) on a ring of \(n + 1\) processes, a state satisfies the invariant when two conditions hold. First, for every message from origin \(j\) waiting in the channel of process \(k\), every process \(m \ne j\) that the message has already passed has a smaller identifier, \(\mathrm{id}(m) < \mathrm{id}(j)\); here \(m\) has been passed when its forward distance from \(j\) is less than the distance the message has travelled, which is the forward distance from \(j\) to \(k\) if \(k \ne j\), and \(n + 1\) (the whole ring) if \(k = j\). Second, for every leader \(i\) and every process \(m \ne i\), we have \(\mathrm{id}(m) < \mathrm{id}(i)\).

    structure Inv (id : Fin (n + 1) → ℕ) (s : State n) : Prop where
  msg : ∀ k j, j ∈ s.chan k → ∀ m, m ≠ j → gap j m < travelled j k → id m < id j
  leader : ∀ i, s.leader i = true → ∀ m, m ≠ i → id m < id i
