    Byzantine agreement

    Byzantine agreement (consensus with Byzantine faults) in the sense of Fischer, Lynch and Merritt: every process has an input, and the correct processes must decide the same value, which must be their common input when they all have the same one. The model on these pages is synchronous (lock-step rounds), with Byzantine failures (a faulty process may send anything to anyone, differently to each recipient), on a complete network of reliable links on which a receiver knows the sender of every message, without signatures. No deterministic protocol reaches Byzantine agreement when \(2 \le n \le 3m\), where \(n\) is the number of processes and \(m\) the number of faults.

    StructureSynchronous Byzantine agreement protocol#✓fully proved

    Cslib.Distributed.Byzantine.AgreementBound.AgreementProtocol

    A protocol for the processes G with inputs in V, local states σ and messages M. Process i starts in state init i x from its input x; in each round r every process j sends send r j s i to every process i, where s is its state, and then moves to recv r i s msg, where msg j is the message it received from j; at the end process i decides decide i s.

    Model. Synchronous lock-step rounds; every process sends one message to every process (itself included) in each round, over a complete network of reliable links; a receiver knows the sender of each message; there are no signatures. Protocols are deterministic, with one state type for all processes, which loses no generality (take a sum type). Faulty processes are modelled in Executions of a Byzantine agreement protocol.

    structure AgreementProtocol (G V σ M : Type*) where
  /-- The initial state of each process, given its input. -/
  init : G → V → σ
  /-- `send r j s i` is the message process `j`, in state `s`, sends to process `i` in round
  `r`. -/
  send : ℕ → G → σ → G → M
  /-- `recv r i s msg` is the state of process `i` after round `r`, from its state `s` and the
  message `msg j` it received from each process `j`. -/
  recv : ℕ → G → σ → (G → M) → σ
  /-- `decide i s` is the value process `i` decides in its final state `s`. -/

    Cslib.Distributed.Byzantine.AgreementBound.AgreementProtocol.state

    Q.state x faulty adv r i is the state of process i after r rounds of Q with inputs x and faulty processes faulty, where a faulty process j sends adv r j i to process i in round r. Correct processes follow the protocol.

    The messages of the faulty processes are an arbitrary function of the round, the sender and the recipient, and every theorem quantifies over all such functions. This loses nothing against an adaptive adversary: the function is chosen after the inputs and the set of faulty processes, and since protocols are deterministic these determine every message an adaptive adversary could react to.

    def state (x : G → V) (faulty : Finset G) (adv : ℕ → G → G → M) : ℕ → G → σ
  | 0, i => Q.init i (x i)
  | r + 1, i => Q.recv r i (state x faulty adv r i) fun j =>
      if j ∈ faulty then adv r j i else Q.send r j (state x faulty adv r j) i

    TheoremNo synchronous protocol reaches Byzantine agreement when \(3 \le n \le 3m\)#✓fully proved

    Cslib.Distributed.Byzantine.AgreementBound.AgreementProtocol.not_solves_of_card_le_three_mul

    Let there be at least two values and \(n\) processes with \(3 \le n \le 3m\). Then no deterministic synchronous protocol reaches Byzantine agreement with at most \(m\) faulty processes, in any number of rounds: for every protocol and every number of rounds \(T\) there are inputs, a set of at most \(m\) faulty processes and a behaviour of the faulty processes for which agreement or validity fails after \(T\) rounds.

    Model. Synchronous rounds; Byzantine failures (a faulty process sends arbitrary messages, chosen independently for each recipient and each round); a complete network of reliable point-to-point links on which a receiver knows the sender; no signatures; deterministic protocols.

    Relation to the source. This is the bound on the number of nodes in Theorem 1 of Fischer, Lynch and Merritt (1986), for the complete communication graph and for synchronous round-based protocols. Their theorem is stronger in two ways that are not formalized here: it holds in a much more general model (their Locality and Fault axioms, which cover asynchronous systems and arbitrary communication graphs), and it also requires the connectivity of the communication graph to be at least \(2m + 1\). The hypothesis \(3 \le n\) follows their standing assumption that graphs have at least three nodes. The case \(n = 2\) is proved separately (No synchronous protocol for two processes reaches Byzantine agreement with one fault); for \(n = 1\) the bound fails, since a single process deciding its own input tolerates one fault (see the test module). Fischer, Lynch and Merritt note that their impossibility results do not hold when the Fault axiom is weakened, for instance by unforgeable signatures (§2). For this problem signatures do not remove the whole range: with \(n \le 2m\) agreement remains impossible even with signatures, since the processes split into two groups of at most \(m\) with different inputs, and either group may be the faulty one behaving correctly, so validity forces each group to decide its own input in the same execution. Only the range \(2m < n \le 3m\) becomes solvable: with the signed-message algorithm SM(\(m\)) of Lamport, Shostak and Pease (§4, Theorem 2) every process can broadcast its input consistently, and the majority of the inputs received then satisfies agreement and validity. This paragraph is an argument written for this page from those two sources, not a statement found in either.

    Proof. By reduction to the commander version: a protocol reaching Byzantine agreement yields, with one extra round in which the commander sends its order, a protocol solving the Byzantine generals problem, which is impossible for \(3 \le n \le 3m\).

    theorem not_solves_of_card_le_three_mul [Fintype G] [Nontrivial V] {m : ℕ}
    (h3 : 3 ≤ Fintype.card G) (hm : Fintype.card G ≤ 3 * m) (T : ℕ) : ¬ Q.Solves m T

    Cslib.Distributed.Byzantine.AgreementBound.AgreementProtocol.not_solves_three

    Let there be at least two values. No deterministic synchronous protocol for three processes reaches Byzantine agreement with one faulty process, in any number of rounds.     Cslib.Distributed.Byzantine.AgreementBound.AgreementProtocol.not_solves_of_card_eq_two

    If there are exactly two processes and at least two values, no deterministic synchronous protocol reaches Byzantine agreement with at most \(m \ge 1\) faulty processes, in any number of rounds.

    Proof. Give the processes different inputs \(v \ne w\) and consider the run with no fault. If the second process is faulty and sends exactly what it sends in that run, the first cannot tell the two runs apart; being the only correct process, it must decide its own input \(v\) (validity), so it decides \(v\) in the fault-free run too. Symmetrically the second decides \(w\) there, contradicting agreement.

    Relation to the sources. Fischer, Lynch and Merritt assume throughout that graphs have at least three nodes, so this case is outside their Theorem 1; the argument here is an elementary indistinguishability argument written for this page, not taken from a cited source. The model is the one of Synchronous Byzantine agreement protocol.

    Cslib.Distributed.Byzantine.AgreementBound.AgreementProtocol.toOral

    The oral-message protocol with commander c built from Q: in round 0 the commander sends its order to every general, and every general takes the order it received from c as its input to Q (d if the message carries no order); in round r + 1 the generals run round r of Q. A general decides as in Q, or d before the first round. The default message m₀ replaces messages of the wrong kind, which only traitors send.

    def toOral (c : G) (d : V) (m₀ : M) :
    OralProtocol G V (Option V ⊕ σ) (Option V ⊕ M) where
  init _ := .inl none
  initCommander v := .inl (some v)
  send r j s i := match r, s with
    | 0, .inl o => .inl o
    | r + 1, .inr t => .inr (Q.send r j t i)
    | _, _ => .inl none
  recv r i s msg := match r, s with
    | 0, _ => .inr (Q.init i (orderOf d (msg c)))
    | r + 1, .inr t => .inr (Q.recv r i t fun j => msgOf m₀ (msg j))
    | _ + 1, .inl o => .inl o
  decide i s := match s with
    | .inr t => Q.decide i t
    | .inl _ => d
