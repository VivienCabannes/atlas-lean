    Cslib.Algorithms.Lean.Geometry.popNonLeft

    Let \(\Bbbk\) be a linearly ordered field, let \(p \in \Bbbk^2\), and write \(u \times v = u_1 v_2 - v_1 u_2\) for the cross product. Given a stack of points of \(\Bbbk^2\) listed top first, while the stack has at least two points, with top \(a\) and next point \(b\), and \((a - b) \times (p - b) \le 0\) (so \(b \to a \to p\) is not a strict left turn), remove \(a\). The result is the first stack reached that has fewer than two points or whose top two points \(a, b\) satisfy \((a - b) \times (p - b) > 0\); that stack is returned unchanged. Each test of the sign of \((a - b) \times (p - b)\) costs one unit, and nothing else is charged.

    def popNonLeft (p : 𝕜 × 𝕜) : List (𝕜 × 𝕜) → TimeM ℕ (List (𝕜 × 𝕜))
  | a :: b :: rest => do
      ✓
      if cross (a - b) (p - b) ≤ 0 then popNonLeft p (b :: rest) else pure (a :: b :: rest)
  | st => pure st
    def cross (p q : 𝕜 × 𝕜) : 𝕜 := p.1 * q.2 - q.1 * p.2

    Cslib.Algorithms.Lean.Geometry.chainScan

    Let \(\Bbbk\) be a field with a linear order. Given a stack \(S\) of points of \(\Bbbk^2\), listed top first, and a list of points \(p_1, \dots, p_n\) of \(\Bbbk^2\), the scan processes \(p_1, \dots, p_n\) in order: for each point \(p = p_i\) it removes the top \(a\) of the stack as long as the stack has a second element \(b\) with \((a_x - b_x)(p_y - b_y) - (p_x - b_x)(a_y - b_y) \le 0\), and then pushes \(p\). Starting from \(S\), the result is the final stack, top first. Each evaluation of this inequality costs one unit; nothing else is counted.

    def chainScan : List (𝕜 × 𝕜) → List (𝕜 × 𝕜) → TimeM ℕ (List (𝕜 × 𝕜))
  | st, [] => pure st
  | st, p :: ps => do
      let st' ← popNonLeft p st
      chainScan (p :: st') ps

    Let \(\Bbbk\) be a field with a linear order.
