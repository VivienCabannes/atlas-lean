    Cslib.IMP.ACmd

    An annotated command is built like an IMP command, from skip, assignments \(x := a\) of an arithmetic expression \(a\) to a variable \(x\) (a natural number), sequential composition \(C_1;\,C_2\) and conditionals \(\mathrm{if}\ b\ \mathrm{then}\ C_1\ \mathrm{else}\ C_2\) on a boolean expression \(b\), except that every while loop \(\{I\}\ \mathrm{while}\ b\ \mathrm{do}\ C\) also carries an assertion \(I\), its invariant.

    Cslib.IMP.ACmd.strip

    The IMP command \(\mathrm{strip}(C)\) underlying an annotated command \(C\) is obtained by deleting the invariant of every while loop: skip, assignments, sequential composition and conditionals are kept with their parts stripped, and \(\{I\}\ \mathrm{while}\ b\ \mathrm{do}\ C'\) becomes \(\mathrm{while}\ b\ \mathrm{do}\ \mathrm{strip}(C')\).

    def strip : ACmd → Cmd
  | .skip => .skip
  | .assign name value => .assign name value
  | .seq first second => .seq first.strip second.strip
  | .ite guard thenBranch elseBranch => .ite guard thenBranch.strip elseBranch.strip
  | .while _ guard body => .while guard body.strip
    inductive ACmd where
  | skip
  | assign (name : Nat) (value : AExp)
  | seq (first second : ACmd)
  | ite (guard : BExp) (thenBranch elseBranch : ACmd)
  | while (invariant : Assertion) (guard : BExp) (body : ACmd)

    DefinitionPrecondition of an annotated command#✓fully proved

    Cslib.IMP.ACmd.pre

    For an annotated command \(C\) and an assertion \(Q\) (the postcondition), the precondition \(\mathrm{pre}(C, Q)\) is the assertion computed backwards as follows: \(\mathrm{pre}(\mathrm{skip}, Q) = Q\); \(\mathrm{pre}(x := a, Q)\) holds in a state \(s\) iff \(Q\) holds in the state obtained from \(s\) by giving \(x\) the value of \(a\) in \(s\); \(\mathrm{pre}(C_1;\,C_2, Q) = \mathrm{pre}(C_1, \mathrm{pre}(C_2, Q))\); the precondition of \(\mathrm{if}\ b\ \mathrm{then}\ C_1\ \mathrm{else}\ C_2\) for \(Q\) holds in a state \(s\) iff \(\mathrm{pre}(C_1, Q)\) holds in \(s\) when \(b\) is true in \(s\), and \(\mathrm{pre}(C_2, Q)\) holds in \(s\) when \(b\) is false in \(s\); and the precondition of a loop \(\{I\}\ \mathrm{while}\ b\ \mathrm{do}\ C\) is its invariant \(I\), whatever \(Q\) is.

    def pre : ACmd → Assertion → Assertion
  | .skip, post => post
  | .assign name value, post => post.subst name value
  | .seq first second, post => first.pre (second.pre post)
  | .ite guard thenBranch elseBranch, post => fun state =>
      if guard.eval state = true then thenBranch.pre post state
      else elseBranch.pre post state
  | .while invariant _ _, _ => invariant
    inductive ACmd where
  | skip
  | assign (name : Nat) (value : AExp)
  | seq (first second : ACmd)
  | ite (guard : BExp) (thenBranch elseBranch : ACmd)
  | while (invariant : Assertion) (guard : BExp) (body : ACmd)

    Cslib.IMP.ACmd.vc

    For an annotated command \(C\) and an assertion \(Q\) (the postcondition), the verification condition \(\mathrm{vc}(C, Q)\) is the proposition defined as follows, where \(\mathrm{pre}\) is the precondition of an annotated command: \(\mathrm{vc}(\mathrm{skip}, Q)\) and \(\mathrm{vc}(x := a, Q)\) are true; \(\mathrm{vc}(C_1;\,C_2, Q)\) holds iff \(\mathrm{vc}(C_1, \mathrm{pre}(C_2, Q))\) and \(\mathrm{vc}(C_2, Q)\) hold; the verification condition of \(\mathrm{if}\ b\ \mathrm{then}\ C_1\ \mathrm{else}\ C_2\) for \(Q\) holds iff \(\mathrm{vc}(C_1, Q)\) and \(\mathrm{vc}(C_2, Q)\) hold; and for a loop \(\{I\}\ \mathrm{while}\ b\ \mathrm{do}\ C'\), the verification condition for \(Q\) holds iff every state satisfying \(I\) in which \(b\) is true satisfies \(\mathrm{pre}(C', I)\), every state satisfying \(I\) in which \(b\) is false satisfies \(Q\), and \(\mathrm{vc}(C', I)\) holds.

    def vc : ACmd → Assertion → Prop
  | .skip, _ => True
  | .assign _ _, _ => True
  | .seq first second, post => first.vc (second.pre post) ∧ second.vc post
  | .ite _ thenBranch elseBranch, post => thenBranch.vc post ∧ elseBranch.vc post
  | .while invariant guard body, post =>
      (∀ state, invariant state → guard.eval state = true → body.pre invariant state) ∧
      (∀ state, invariant state → guard.eval state = false → post state) ∧
      body.vc invariant
    inductive ACmd where
  | skip
  | assign (name : Nat) (value : AExp)
  | seq (first second : ACmd)
  | ite (guard : BExp) (thenBranch elseBranch : ACmd)
  | while (invariant : Assertion) (guard : BExp) (body : ACmd)

    Cslib.IMP.ACmd.vc_sound

    For an annotated command \(C\) and an assertion \(Q\), write \(\mathrm{pre}(C, Q)\) and \(\mathrm{vc}(C, Q)\) for the precondition and the verification condition of \(C\) for the postcondition \(Q\), and \(\mathrm{strip}(C)\) for the IMP command obtained from \(C\) by erasing its loop invariants.     Cslib.IMP.ACmd.vc_valid

    Let \(C\) be an annotated command, let \(\mathrm{strip}(C)\) be the IMP command obtained from \(C\) by erasing its loop invariants, and let \(P\), \(Q\) be assertions.
