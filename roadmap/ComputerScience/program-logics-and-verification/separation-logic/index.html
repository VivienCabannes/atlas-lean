    DefinitionSeparation-logic triple validity#✓fully proved

    Cslib.IMP.SepValid

    For heap assertions \(P\), \(Q\) and a heap command \(c\), the triple \(\lbrace P \rbrace\ c\ \lbrace Q \rbrace\) is valid (in the fault-avoiding sense) when, for every store \(s\) and heap \(h\) with \(P(s, h)\), the configuration \((c, s, h)\) is safe (no configuration reachable from it is stuck at a command other than \(\mathtt{skip}\)), and whenever \((c, s, h)\) reaches \((\mathtt{skip}, s', h')\) in finitely many heap steps, \(Q(s', h')\) holds.

    def SepValid (P : HAssertion) (c : HeapCmd) (Q : HAssertion) : Prop :=
  ∀ ⦃s h⦄, P s h → Safe (c, s, h) ∧
    ∀ ⦃s' h'⦄, HSteps (c, s, h) (.skip, s', h') → Q s' h'
    abbrev HAssertion := State → Heap → Prop

    Cslib.IMP.SepValid.whileLoop

    Let \(I\) be a heap assertion, \(b\) a Boolean expression and \(c\) a heap command.     TheoremPulling a store fact out of a separating conjunction#✓fully proved

    Cslib.IMP.star_and_left

    Let \(p\) be a predicate on stores and \(P\), \(R\) heap assertions. Write \(A \star B\) for the separating conjunction of heap assertions \(A\) and \(B\) (the heap splits into two disjoint parts satisfying \(A\) and \(B\), respectively, at the same store), and \(p \land P\) for the heap assertion that holds at store \(s\) and heap \(h\) when \(p(s)\) and \(P(s, h)\) both hold. Then \((p \land P) \star R = p \land (P \star R)\).

    This lets framed local triples be stated with the store facts kept outside the separating conjunction.

    theorem star_and_left {p : State → Prop} {P R : HAssertion} :
    ((fun s h => p s ∧ P s h) ⋆ R) = (fun s h => p s ∧ (P ⋆ R) s h)
