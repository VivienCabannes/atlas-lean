    For a list \(xs\) over a preorder and a natural number \(k\), \(k\) is the length of a longest strictly increasing subsequence of \(xs\) when some strictly increasing subsequence of \(xs\) has length \(k\) and every strictly increasing subsequence of \(xs\) has length at most \(k\).     For an element \(x\), lists \(s\) and \(zs\), and a natural number \(k\), the pair \((k, zs)\) is a table cell for \(x\) followed by \(s\) when \(zs\) is a subsequence (not necessarily contiguous) of \(s\), the list \(x\) followed by \(zs\) is strictly increasing (each element strictly less than every later one) and has length \(k\), and for every subsequence \(zs'\) of \(s\) such that \(x\) followed by \(zs'\) is strictly increasing, the list \(x\) followed by \(zs'\) has length at most \(k\).     Cslib.Algorithms.Lean.TimeM.patienceStep

    Given an array \(t\) of tails and an element \(x\) over a linear order, let \(i\) be the index returned by the lower-bound binary search for \(x\) in \(t\).   let i ← lowerBound tails x
  if h : i < tails.size then pure (tails.set i x h) else pure (tails.push x)
