    Cslib.Algorithms.Lean.TimeM.kadaneScan

    Given accumulators \(e, b\) in an additive monoid \(\alpha\) with a linear order, the scan over the empty list returns \(b\) at cost \(0\). Over a list with first element \(x\) and remaining elements \(L\), it sets \(e' = \max(x, e + x)\) and returns the result of the scan of \(L\) from the accumulators \(e'\) and \(\max(b, e')\), at cost \(3\) plus the cost of that scan.

    Here \(e\) is the best sum of a nonempty run ending at the last element read and \(b\) is the best sum of any nonempty run read so far.

    Cslib.Algorithms.Lean.TimeM.maxSubarraySum

    Let \(\alpha\) be a linearly ordered type with an additive monoid structure. On the empty list, Kadane's algorithm returns no value.     Cslib.Algorithms.Lean.TimeM.suffixScan

    Let \(\alpha\) be an additive monoid carrying a linear order. For a nonempty list \(x_1, \dots, x_n\) in \(\alpha\), this timed computation returns the pair \((x_1 + \dots + x_n, s)\), where \(s\) is the maximum of the suffix sums \(x_i + \dots + x_n\) over \(1 \le i \le n\).
