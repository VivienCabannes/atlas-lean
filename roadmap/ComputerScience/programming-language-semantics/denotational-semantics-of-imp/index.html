    Cslib.IMP.whileFun

    Given a Boolean expression \(b\) (the guard) and a binary relation \(B\) on states (the body relation), the functional sends a relation \(R\) on states to the relation that relates \(s\) to \(s'\) exactly when either \(b\) evaluates to false in \(s\) and \(s' = s\), or \(b\) evaluates to true in \(s\) and there is a state \(m\) with \(B\) relating \(s\) to \(m\) and \(R\) relating \(m\) to \(s'\).

    def whileFun (guard : BExp) (body : State → State → Prop)
    (R : State → State → Prop) : State → State → Prop :=
  fun s s' => (guard.eval s = false ∧ s' = s) ∨
    (guard.eval s = true ∧ ∃ m, body s m ∧ R m s')
    inductive BExp where
  | truth (value : Bool)
  | eq (left right : AExp)
  | le (left right : AExp)
  | not (body : BExp)
  | and (left right : BExp)
  deriving DecidableEq, Repr

    Cslib.IMP.whileOrderHom

    For a boolean guard \(b\) and a relation \(B\) between states (the body denotation), this is the map \(\Phi\) on relations between states, ordered by inclusion, where \(\Phi(R)\) relates \(s\) to \(s'\) exactly when either \(b\) is false in \(s\) and \(s' = s\), or \(b\) is true in \(s\) and there is a state \(m\) with \(B(s, m)\) and \(R(m, s')\).     DefinitionRelational denotational semantics of IMP#✓fully proved

    Cslib.IMP.Denote

    The denotation of an IMP command is a binary relation on states, defined by recursion on the command. The command \(\mathtt{skip}\) relates \(s\) to \(s'\) iff \(s' = s\). For a variable identifier \(x\) and an arithmetic expression \(a\), the assignment \(x := a\) relates \(s\) to \(s'\) iff \(s'\) is \(s\) with \(x\) updated to the value of \(a\) in \(s\). The sequence \(c_1; c_2\) relates \(s\) to \(s'\) iff there is a state \(m\) such that \(c_1\) relates \(s\) to \(m\) and \(c_2\) relates \(m\) to \(s'\). For a Boolean expression \(b\), the conditional \(\mathtt{if}\ b\ \mathtt{then}\ t\ \mathtt{else}\ e\) relates \(s\) to \(s'\) iff either \(b\) evaluates to true in \(s\) and \(t\) relates \(s\) to \(s'\), or \(b\) evaluates to false in \(s\) and \(e\) relates \(s\) to \(s'\). The denotation of \(\mathtt{while}\ b\ \mathtt{do}\ c\) is the least fixed point, for inclusion of relations, of the one-step unfolding functional of a while loop with guard \(b\) and body relation the denotation of \(c\).

    def Denote : Cmd → State → State → Prop
  | .skip => fun s s' => s' = s
  | .assign n a => fun s s' => s' = Function.update s n (a.eval s)
  | .seq c₁ c₂ => fun s s' => ∃ m, Denote c₁ s m ∧ Denote c₂ m s'
  | .ite b t e => fun s s' =>
      (b.eval s = true ∧ Denote t s s') ∨ (b.eval s = false ∧ Denote e s s')
  | .while b c => (whileOrderHom b (Denote c)).lfp
    inductive Cmd where
  | skip
  | assign (name : Nat) (value : AExp)
  | seq (first second : Cmd)
  | ite (guard : BExp) (thenBranch elseBranch : Cmd)
  | while (guard : BExp) (body : Cmd)
  deriving DecidableEq, Repr
