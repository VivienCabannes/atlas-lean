    Cslib.Languages.LambdaCalculus.ClosureConversion.Source.Eval

    Evaluation \(\rho \vdash t \Downarrow v\) of a raw term \(t\) to a source value \(v\) in an environment \(\rho\) (a list of source values, where variable \(n\) refers to the entry of \(\rho\) at index \(n\), counting from \(0\)) is the least relation closed under the following rules, a call-by-value environment semantics that ignores the type annotations of lambdas. A variable \(n\) evaluates to the entry of \(\rho\) at index \(n\), when that entry exists. A lambda \(\lambda. b\) evaluates to the closure of \(b\) over \(\rho\). If \(f\) evaluates in \(\rho\) to the closure of \(b\) over \(\rho'\), if \(\rho \vdash a \Downarrow v\), and if \(v :: \rho' \vdash b \Downarrow w\), where \(v :: \rho'\) is \(\rho'\) with \(v\) added at index \(0\), then \(\rho \vdash f\,a \Downarrow w\).

    InductiveBig-step semantics of the closure-conversion target#✓fully proved

    Cslib.Languages.LambdaCalculus.ClosureConversion.Target.Tm.Eval

    Evaluation \(\rho \vdash e \Downarrow v\) of a target term \(e\) to a target value \(v\) in an environment \(\rho\) (a list of values, where variable \(n\) refers to the entry of \(\rho\) at index \(n\), counting from \(0\)) is the least relation closed under the following rules. A variable \(n\) evaluates to the entry of \(\rho\) at index \(n\), when that entry exists. Code evaluates to itself: \(\rho \vdash \mathsf{code}\,b \Downarrow \mathsf{code}\,b\). If \(\rho \vdash f \Downarrow \mathsf{code}\,b\), \(\rho \vdash a \Downarrow v\) and \([v] \vdash b \Downarrow w\), then \(\rho \vdash f\,a \Downarrow w\); so a code body runs in the one-element environment \([v]\) and never sees \(\rho\). The unit term evaluates to the unit value. If \(\rho \vdash a \Downarrow v\) and \(\rho \vdash b \Downarrow w\), then \(\rho \vdash (a, b) \Downarrow (v, w)\). If \(\rho \vdash e \Downarrow (v, w)\), then \(\rho \vdash \mathsf{fst}\,e \Downarrow v\) and \(\rho \vdash \mathsf{snd}\,e \Downarrow w\). If \(\rho \vdash e \Downarrow v\) and \(v :: \rho \vdash b \Downarrow w\), where \(v :: \rho\) is \(\rho\) with \(v\) added at index \(0\), then \(\rho \vdash \mathsf{let}\ e\ \mathsf{in}\ b \Downarrow w\).

    InductiveWell-scoped target terms#✓fully proved

    Cslib.Languages.LambdaCalculus.ClosureConversion.Target.Tm.Scoped

    For a natural number \(m\), a target term \(e\) is scoped in \(m\) when every free variable of \(e\) is less than \(m\) and every code body in \(e\) is closed, that is, scoped in \(1\). Inductively: a variable \(i\) is scoped in \(m\) when \(i < m\); \(\mathsf{code}\,b\) is scoped in every \(m\) when \(b\) is scoped in \(1\); \(\mathsf{unit}\) is scoped in every \(m\); an application, a pair or a projection is scoped in \(m\) when its immediate subterms are; and \(\mathsf{let}\ e\ \mathsf{in}\ b\) is scoped in \(m\) when \(e\) is scoped in \(m\) and \(b\) is scoped in \(m + 1\).
