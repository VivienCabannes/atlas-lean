    Cslib.Languages.LambdaCalculus.Stlc.CPS.cbn

    Fix an answer type \(R\) and write \(C(A) = (A^\ast \to R) \to R\), where \(A^\ast\) is the call-by-name CPS translation of a simple type \(A\). A term \(t\) of type \(A\) in a context \(A_1, \dots, A_n\) is translated to a term \(\overline{t}\) of type \(C(A)\) in the context \(C(A_1), \dots, C(A_n)\), by recursion on \(t\): a variable \(x\) is translated to the variable at the same position; an abstraction by \(\overline{\lambda x.\, M} = \lambda k.\, k\,(\lambda x.\, \overline{M})\); and an application by \(\overline{M\,N} = \lambda k.\, \overline{M}\,(\lambda m.\, m\,\overline{N}\,k)\), where \(k\) and \(m\) are fresh variables.

    def cbn : {Γ : List (Ty Base)} → {A : Ty Base} →
    Tm Γ A → Tm (Γ.map (cbnComp R)) (cbnComp R A)
  | _, _, .var x => .var (cbnVar R x)
  | _, _, .lam body => .lam (.app (.var .zero) (Tm.weaken (.lam (cbn body))))
  | _, _, .app f a =>
      .lam (.app (Tm.weaken (cbn f))
        (.lam (.app (.app (.var .zero) (Tm.weaken (Tm.weaken (cbn a)))) (.var (.succ .zero)))))
    inductive Ty (Base : Type u) where
  | base : Base → Ty Base
  | arr : Ty Base → Ty Base → Ty Base
  deriving DecidableEq, Repr

    DefinitionLogical relation for the call-by-name CPS translation#✓fully proved

    Cslib.Languages.LambdaCalculus.Stlc.CPS.CbnRel

    Fix an answer type \(R\) and an interpretation \(I\) of the base types. Write \(D(A)\) for the set of values of a simple type \(A\) (\(D(b) = I(b)\) for a base type \(b\), and \(D(A \to B)\) is the set of functions from \(D(A)\) to \(D(B)\)), \(A^\ast\) for the call-by-name CPS translation of \(A\), and \(C(A) = (A^\ast \to R) \to R\). The relation \(a \sim_A a'\) between \(a \in D(A)\) and \(a' \in D(A^\ast)\) is defined by recursion on \(A\). At a base type \(b\), \(a \sim_b a'\) holds when \(a = a'\). At a function type, \(f \sim_{A \to B} g\) holds when for every \(a \in D(A)\) and every \(c \in D(C(A))\): if there is \(v\) with \(a \sim_A v\) and \(c\,k = k\,v\) for every \(k \in D(A^\ast \to R)\), then there is \(w\) with \(f\,a \sim_B w\) and \(g\,c\,k = k\,w\) for every \(k \in D(B^\ast \to R)\).

    def CbnRel (I : Base → Type v) : (A : Ty Base) → Ty.denote I A → Ty.denote I (cbnTy R A) → Prop
  | .base _, a, a' => a = a'
  | .arr A B, f, g => ∀ a (c : Ty.denote I (cbnComp R A)),
      (∃ v, CbnRel I A a v ∧ ∀ k, c k = k v) →
        ∃ w, CbnRel I B (f a) w ∧ ∀ k, g c k = k w
    inductive Ty (Base : Type u) where
  | base : Base → Ty Base
  | arr : Ty Base → Ty Base → Ty Base
  deriving DecidableEq, Repr
