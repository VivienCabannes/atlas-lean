    InductivePCF terms#✓fully proved

    Cslib.Languages.LambdaCalculus.PCF.Tm

    Write \(\mathsf{nat}\) for the ground type of natural numbers and \(A \Rightarrow B\) for the type of functions from \(A\) to \(B\). The intrinsically typed PCF terms of type \(A\) in a context \(\Gamma\) (a list of PCF types) are generated by the following rules: every variable of type \(A\) in \(\Gamma\) is a term of type \(A\); if \(t\) has type \(B\) in the context \(\Gamma\) extended by a newest variable of type \(A\), then \(\lambda t\) has type \(A \Rightarrow B\); if \(f\) has type \(A \Rightarrow B\) and \(a\) has type \(A\), then \(f\,a\) has type \(B\); \(\mathsf{zero}\) has type \(\mathsf{nat}\); if \(t\) has type \(\mathsf{nat}\), so do \(\mathsf{succ}\,t\) and \(\mathsf{pred}\,t\); if \(t\), \(s_1\) and \(s_2\) have type \(\mathsf{nat}\), so does the zero test \(\mathsf{ifz}\,t\,s_1\,s_2\); and if \(t\) has type \(A \Rightarrow A\), then the fixed point \(\mathsf{fix}\,t\) has type \(A\).

    inductive Tm : List Ty → Ty → Type where
  | var {Γ : List Ty} {A : Ty} : Var Γ A → Tm Γ A
  | lam {Γ : List Ty} {A B : Ty} : Tm (A :: Γ) B → Tm Γ (A ⇒ B)
  | app {Γ : List Ty} {A B : Ty} : Tm Γ (A ⇒ B) → Tm Γ A → Tm Γ B
  | zero {Γ : List Ty} : Tm Γ .nat
  | succ {Γ : List Ty} : Tm Γ .nat → Tm Γ .nat
  | pred {Γ : List Ty} : Tm Γ .nat → Tm Γ .nat
  /-- `ifz t s₁ s₂` is `s₁` when `t` is zero and `s₂` when `t` is a successor. -/
  | ifz {Γ : List Ty} : Tm Γ .nat → Tm Γ .nat → Tm Γ .nat → Tm Γ .nat
  /-- The fixed-point combinator: `fix t` unfolds to `t (fix t)`. -/
  | fix {Γ : List Ty} {A : Ty} : Tm Γ (A ⇒ A) → Tm Γ A

    DefinitionRenaming of PCF terms#✓fully proved

    Cslib.Languages.LambdaCalculus.PCF.Tm.rename

    Given a renaming \(\rho\) from a context \(\Gamma\) to a context \(\Delta\), the renaming along \(\rho\) of a PCF term of type \(A\) in context \(\Gamma\) is the term of type \(A\) in context \(\Delta\) obtained by replacing each variable \(x\) by \(\rho(x)\). Under a \(\lambda\)-binder, \(\rho\) is replaced by its lift, which sends the bound variable to itself and the successor of each variable \(x\) of \(\Gamma\) to the successor of \(\rho(x)\). Renaming leaves zero unchanged and commutes with application, successor, predecessor, the zero test and the fixed-point combinator.

    def rename : {Γ Δ : List Ty} → Ren Γ Δ → {A : Ty} → Tm Γ A → Tm Δ A
  | _, _, ρ, _, .var x => .var (ρ x)
  | _, _, ρ, _, .lam body => .lam (rename (Stlc.Var.lift ρ) body)
  | _, _, ρ, _, .app f a => .app (rename ρ f) (rename ρ a)
  | _, _, _, _, .zero => .zero
  | _, _, ρ, _, .succ t => .succ (rename ρ t)
  | _, _, ρ, _, .pred t => .pred (rename ρ t)
  | _, _, ρ, _, .ifz t s₁ s₂ => .ifz (rename ρ t) (rename ρ s₁) (rename ρ s₂)
  | _, _, ρ, _, .fix t => .fix (rename ρ t)
