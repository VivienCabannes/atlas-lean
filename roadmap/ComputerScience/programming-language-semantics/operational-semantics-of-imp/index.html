    DefinitionEvaluation of IMP arithmetic expressions#✓fully proved

    Cslib.IMP.AExp.eval

    The value of an arithmetic expression in a state \(\sigma : \mathbb{N} \to \mathbb{N}\) is the natural number defined by recursion on the expression: a constant \(n\) has value \(n\), the variable \(x_i\) with index \(i\) has value \(\sigma(i)\), and for arithmetic expressions \(a_1\) and \(a_2\), the expressions \(a_1 + a_2\), \(a_1 - a_2\) and \(a_1 \cdot a_2\) have as value the sum, the truncated difference and the product of the values of \(a_1\) and \(a_2\). The truncated difference of natural numbers \(m\) and \(n\) is \(\max(m - n, 0)\).

    def eval : AExp → State → Nat
  | .const value, _ => value
  | .var name, state => state name
  | .add left right, state => left.eval state + right.eval state
  | .sub left right, state => left.eval state - right.eval state
  | .mul left right, state => left.eval state * right.eval state
    inductive AExp where
  | const (value : Nat)
  | var (name : Nat)
  | add (left right : AExp)
  | sub (left right : AExp)
  | mul (left right : AExp)
  deriving DecidableEq, Repr

    DefinitionEvaluation of IMP Boolean expressions#✓fully proved

    Cslib.IMP.BExp.eval

    The truth value of a Boolean expression in a state \(\sigma : \mathbb{N} \to \mathbb{N}\) is defined by recursion on the expression: the constants true and false have values true and false; for arithmetic expressions \(a_1\) and \(a_2\), the comparison \(a_1 = a_2\) is true exactly when the values of \(a_1\) and \(a_2\) in \(\sigma\) are equal, and \(a_1 \le a_2\) is true exactly when the value of \(a_1\) is at most the value of \(a_2\); for Boolean expressions \(b\), \(b_1\) and \(b_2\), the negation \(\neg b\) is true exactly when \(b\) is false, and the conjunction \(b_1 \wedge b_2\) is true exactly when both \(b_1\) and \(b_2\) are true.

    def eval : BExp → State → Bool
  | .truth value, _ => value
  | .eq left right, state => decide (left.eval state = right.eval state)
  | .le left right, state => decide (left.eval state ≤ right.eval state)
  | .not body, state => !body.eval state
  | .and left right, state => left.eval state && right.eval state
    inductive BExp where
  | truth (value : Bool)
  | eq (left right : AExp)
  | le (left right : AExp)
  | not (body : BExp)
  | and (left right : BExp)
  deriving DecidableEq, Repr

    InductiveBig-step semantics of IMP#✓fully proved

    Cslib.IMP.BigStep

    The big-step relation says when running a command \(c\) from a state \(s\) terminates in a state \(t\); we then say that \(c\) takes \(s\) to \(t\). It is the least relation satisfying the following rules. The command \(\mathtt{skip}\) takes \(s\) to \(s\). The assignment \(x := a\) takes \(s\) to the state \(s[x \mapsto a(s)]\), which agrees with \(s\) except that \(x\) has the value \(a(s)\) of the arithmetic expression \(a\) in \(s\). If \(c_1\) takes \(s\) to \(u\) and \(c_2\) takes \(u\) to \(t\), then the sequence \(c_1 ; c_2\) takes \(s\) to \(t\). If the Boolean expression \(b\) is true in \(s\) and \(c_1\) takes \(s\) to \(t\), then \(\mathtt{if}\ b\ \mathtt{then}\ c_1\ \mathtt{else}\ c_2\) takes \(s\) to \(t\); if \(b\) is false in \(s\) and \(c_2\) takes \(s\) to \(t\), then it also takes \(s\) to \(t\). If \(b\) is false in \(s\), then the loop \(\mathtt{while}\ b\ \mathtt{do}\ c\) takes \(s\) to \(s\); if \(b\) is true in \(s\), \(c\) takes \(s\) to \(u\) and the loop takes \(u\) to \(t\), then the loop takes \(s\) to \(t\).

    inductive BigStep : Cmd → State → State → Prop
  | skip (state) : BigStep .skip state state
  | assign (state) (name) (value) :
      BigStep (.assign name value) state (Function.update state name (value.eval state))
  | seq {first second initial middle final}
      (firstStep : BigStep first initial middle)
      (secondStep : BigStep second middle final) :
      BigStep (.seq first second) initial final
  | iteTrue {guard thenBranch elseBranch initial final}
      (guardTrue : guard.eval initial = true)
      (branchStep : BigStep thenBranch initial final) :
      BigStep (.ite guard thenBranch elseBranch) initial final
  | iteFalse {guard thenBranch elseBranch initial final}
      (guardFalse : guard.eval initial = false)
      (branchStep : BigStep elseBranch initial final) :
      BigStep (.ite guard thenBranch elseBranch) initial final
  | whileFalse {guard body state}
      (guardFalse : guard.eval state = false) :
      BigStep (.while guard body) state state
  | whileTrue {guard body initial middle final}
      (guardTrue : guard.eval initial = true)
      (bodyStep : BigStep body initial middle)
      (loopStep : BigStep (.while guard body) middle final) :
      BigStep (.while guard body) initial final

    Cslib.IMP.Step

    The single-step relation \(\to\) on IMP configurations is the smallest relation satisfying the following rules, for all variables \(x\), arithmetic expressions \(a\), Boolean expressions \(b\), commands \(c, c_1, c_1', c_2\) and states \(\sigma, \sigma'\). Assignment: \((x := a, \sigma) \to (\mathtt{skip}, \sigma[x \mapsto v])\), where \(v\) is the value of \(a\) in \(\sigma\). Sequencing: \((\mathtt{skip}; c_2, \sigma) \to (c_2, \sigma)\), and if \((c_1, \sigma) \to (c_1', \sigma')\) then \((c_1; c_2, \sigma) \to (c_1'; c_2, \sigma')\). Conditional: \((\mathtt{if}\ b\ \mathtt{then}\ c_1\ \mathtt{else}\ c_2, \sigma)\) steps to \((c_1, \sigma)\) if \(b\) evaluates to true in \(\sigma\) and to \((c_2, \sigma)\) if it evaluates to false. Loop: \((\mathtt{while}\ b\ \mathtt{do}\ c, \sigma)\) steps to \((W, \sigma)\), where \(W\) is the command \(\mathtt{if}\ b\ \mathtt{then}\ (c; \mathtt{while}\ b\ \mathtt{do}\ c)\) \(\mathtt{else}\ \mathtt{skip}\).
