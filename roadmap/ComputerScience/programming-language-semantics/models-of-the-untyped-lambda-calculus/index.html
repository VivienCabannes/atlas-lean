    Models of the untyped lambda calculus

    A model of the untyped λ-calculus interprets every term as an element of one domain \(D\), in which application is a binary operation and λ-abstraction turns a function denoted by a term into an element. For the interpretation to respect β-conversion, every function denoted by a term must be recovered by applying its abstraction. Scott's insight was to use only Scott-continuous functions, for which this is possible (D. Scott, Continuous Lattices, Oxford PRG-7 (1971), §4; Data types as lattices, SIAM J. Comput. 5 (1976), §2).

    This topic interprets CSLib's locally nameless untyped λ-terms in Scott's graph model \(P(\omega)\). Abstraction takes the graph of the continuous function that the body denotes, and application is the graph-model application. Every term denotes a continuous function of its variables (Scott's Theorem 2.1). Full β-reduction, including reduction under λ, preserves denotations (the β and ξ parts of Theorem 2.2). The paradoxical combinator \(Y\) denotes the least-fixed-point operator (Theorem 2.5). The model is not trivial, since \(\lambda x.\lambda y.x\) and \(\lambda x.\lambda y.y\) get different denotations. It is not extensional: the η-rule fails in \(P(\omega)\). By contrast, η holds in Scott's inverse-limit model \(D_\infty \cong [D_\infty \to D_\infty]\).

    DefinitionDenotation of an untyped λ-term in the graph model#✓fully proved

    Cslib.LambdaCalculus.LocallyNameless.Untyped.GraphModel.denote

    Let \(\rho\) value the free variables and \(bs\) the bound variables (de Bruijn indices) of CSLib's locally nameless untyped λ-terms in \(P(\omega)\). The denotation \([\![M]\!]_{\rho, bs} \subseteq \mathbb{N}\) is defined by recursion on \(M\): - a bound variable \(i\) denotes \(bs(i)\), and a free variable \(x\) denotes \(\rho(x)\); - an application \(M\,N\) denotes \(\operatorname{app}([\![M]\!], [\![N]\!])\); - an abstraction \(\lambda.M\) denotes \(\operatorname{graph}(v \mapsto [\![M]\!]_{\rho, v \cdot bs})\).

    This is the semantics of application and λ-abstraction in Scott's language LAMBDA (D. Scott, Data types as lattices, SIAM J. Comput. 5(3) (1976), 522–587, §2), restricted to the pure λ-calculus.

    def denote (ρ : Var → Set ℕ) : Term Var → (ℕ → Set ℕ) → Set ℕ
  | .bvar i, bs => bs i
  | .fvar x, _ => ρ x
  | .abs M, bs => graph fun v => denote ρ M (consEnv v bs)
  | .app M N, bs => app (denote ρ M bs) (denote ρ N bs)
    def graph (f : Set ℕ → Set ℕ) : Set ℕ := {k | k.unpair.2 ∈ f (finSet k.unpair.1)}

    Cslib.LambdaCalculus.LocallyNameless.Untyped.GraphModel.scottContinuous_denote

    For every term \(M\) and valuation \(\rho\) of its free variables, the denotation \(bs \mapsto [\![M]\!]_{\rho, bs}\) is a Scott-continuous function of the values of the bound variables (D.     Cslib.LambdaCalculus.LocallyNameless.Untyped.GraphModel.app_denote_abs

    Applying the denotation of \(\lambda.M\) to \(v\) gives the denotation of \(M\) with the new bound variable valued by \(v\): $\(\operatorname{app}([\![\lambda.M]\!]_{\rho, bs}, v) = [\![M]\!]_{\rho, v \cdot bs}.\)$ This is Scott's graph theorem \(\operatorname{app}(\operatorname{graph}(f), \cdot) = f\), applied to the continuous function that the body denotes.

    theorem app_denote_abs (ρ : Var → Set ℕ) (M : Term Var) (bs : ℕ → Set ℕ) (v : Set ℕ) :
    app (denote ρ (.abs M) bs) v = denote ρ M (consEnv v bs)

    TheoremSubstitution lemma for opening#✓fully proved

    Cslib.LambdaCalculus.LocallyNameless.Untyped.GraphModel.denote_openRec

    Let \(s\) be a term whose denotation does not depend on the bound-variable valuation, for instance a locally closed term. Opening the bound variable \(i\) of \(M\) with \(s\) (CSLib's \(M⟦i ↝ s⟧\)) denotes \(M\) with index \(i\) valued by the denotation of \(s\): $\([\![M⟦i ↝ s⟧]\!]_{\rho, bs} = [\![M]\!]_{\rho, bs[i \mapsto [\![s]\!]_{\rho, bs}]}.\)$ This is the semantic counterpart of substitution, and the key lemma for the soundness of β.

    theorem denote_openRec (ρ : Var → Set ℕ) {s : Term Var}

    denote ρ (M⟦i ↝ s⟧) bs = denote ρ M (Function.update bs i (denote ρ s bs))

    TheoremSoundness of full β-reduction in the graph model#✓fully proved

    Cslib.LambdaCalculus.LocallyNameless.Untyped.GraphModel.denote_eq_of_fullBeta

    One step of full β-reduction, contracting a redex anywhere in a term, including under λ, preserves the denotation in \(P(\omega)\) under every valuation of free and bound variables. This is the β rule of Scott's conversion theorem together with the instance of the rule ξ that full β-reduction needs (D. Scott, Data types as lattices, SIAM J. Scott's ξ is the equivalence \(\forall x.\, \tau = \sigma \iff \lambda x.\tau = \lambda x.\sigma\); what is used here is its left-to-right direction (equal bodies give equal abstractions), applied to reduction under λ. The rule α is built into the locally nameless syntax.

    TheoremScott's first recursion theorem#✓fully proved

    Cslib.LambdaCalculus.LocallyNameless.Untyped.GraphModel.app_denote_Y

    In the graph model, the paradoxical combinator \(Y\) applied to any \(u \subseteq \mathbb{N}\) denotes the least fixed point \(\bigcup_k \operatorname{app}(u, \cdot)^k(\emptyset)\) of the continuous function determined by \(u\) (D. Scott, Data types as lattices, SIAM J. Comput. 5(3) (1976), 522–587, Theorem 2.5). So recursion is λ-definable in \(P(\omega)\), and the least fixed points given by the fixed-point theorem are the ones that \(Y\) computes.

    theorem app_denote_Y (ρ : Var → Set ℕ) (bs : ℕ → Set ℕ) (u : Set ℕ) :
    app (denote ρ Y bs) u = ⨆ k, (app u)^[k] ⊥
    def app (u x : Set ℕ) : Set ℕ := {m | ∃ n, finSet n ⊆ x ∧ Nat.pair n m ∈ u}

    What the model does and does not identify

    TheoremThe graph model separates λx.λy.x from λx.λy.y#✓fully proved

    Cslib.LambdaCalculus.LocallyNameless.Untyped.GraphModel.denote_K_ne_denote_KStar

    The closed normal forms \(K = \lambda x.\lambda y.x\) and \(K^* = \lambda x.\lambda y.y\) have different denotations in \(P(\omega)\): applied to \(\emptyset\) and then to \(\mathbb{N}\), they give \(\emptyset\) and \(\mathbb{N}\). So the model does not identify all terms. This rules out the degenerate one-point model, in which every equation holds.
