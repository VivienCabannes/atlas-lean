    StructureOutput of A-star search#✓fully proved

    Cslib.Algorithms.Lean.AStar.AStarResult

    An A result on \(n\) vertices consists of a Dijkstra result on \(n\) vertices (the underlying search, with its source, final keys and predecessor pointers) and a vector that assigns to each vertex \(v\) a value \(g(v) \in \mathbb{N} \cup \{\infty\}\). In the output of A from a source \(s\) with a consistent heuristic \(h\), the underlying search runs on the reduced weights, its keys are \(f(v) - h(s)\) where \(f = g + h\), and \(g(v)\) is the least weight of a path from \(s\) to \(v\), with \(\infty\) when there is none.

    structure AStarResult (n : ℕ) where

  /-- The best path weight `g v` from the source. -/
  g : Vector (Option ℕ) n

    DefinitionA* search#✓fully proved

    Cslib.Algorithms.Lean.AStar.aStar

    A* search. Given a directed graph \(G\) on the vertices \(\{0, \dots, n-1\}\) with natural edge weights \(w\), a heuristic \(h\) with natural values and a source vertex \(s\), A* runs Dijkstra's algorithm from \(s\) on the reduced weights \(w(u, v) + h(v) - h(u)\) at Dijkstra's cost, and returns Dijkstra's result (its distances \(g'\) and predecessor pointers) together with the path weights \(g(v) = g'(v) + h(s) - h(v)\), where both subtractions are truncated at \(0\) and \(g(v)\) is infinite when \(g'(v)\) is.

    For a consistent heuristic, Dijkstra's distances on the reduced weights are A*'s values \(f = g + h\) shifted by \(h(s)\).

  pure ⟨r, Vector.ofFn fun v => (r.distance.get v).map (· + h source - h v)⟩

    TheoremThe final keys of A*#✓fully proved

    Cslib.Algorithms.Lean.AStar.aStar_key

    The final keys of A*. Let \(G\) be a directed graph on the vertices \(\{0, \dots, n-1\}\) with natural edge weights \(w\), let \(h\) be a consistent heuristic with natural values and let \(s\) be a source vertex. If the path weight \(g(v)\) that A from \(s\) returns for a vertex \(v\) is finite, then the distance \(g'(v)\) that Dijkstra's algorithm from \(s\) computes for \(v\) on the reduced weights \(w(x, y) + h(y) - h(x)\) (subtraction truncated at \(0\)) is finite as well, and \(g(v) + h(v) = g'(v) + h(s)\); that is, the key \(g'(v)\) is A's value \(f(v) = g(v) + h(v)\) shifted down by \(h(s)\).

    theorem aStar_key (hc : Consistent graph weight h) {v : Fin n} {g : ℕ}
    (hv : (aStar graph weight h source).ret.g.get v = some g) :
    ∃ g', (dijkstra graph (reducedWeight weight h) source).ret.distance.get v = some g' ∧
      g + h v = g' + h source
