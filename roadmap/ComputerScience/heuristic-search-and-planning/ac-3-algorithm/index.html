    A binary constraint satisfaction problem with variables in \(X\) and values in \(D\) consists of a finite list of directed arcs \((x, y)\) with \(x, y \in X\), and, for all variables \(x, y\) and values \(a, b \in D\), a Boolean saying whether the arc \((x, y)\) allows \(x = a\) together with \(y = b\).

    Cslib.Algorithms.Lean.ArcConsistency.IsSolution

    Let \(P\) be a binary constraint satisfaction problem with variables \(X\) and values \(D\), and give each variable \(x\) a finite domain \(\mathrm{dom}(x) \subseteq D\). An assignment \(\sigma : X \to D\) is a solution of \(P\) within \(\mathrm{dom}\) when \(\sigma(x) \in \mathrm{dom}(x)\) for every variable \(x\) and, for every arc \((x, y)\) of \(P\), the arc \((x, y)\) allows the pair \((\sigma(x), \sigma(y))\).

    Given a binary CSP \(P\) and domains \(\mathrm{dom}\), an arc \((x, y)\) is consistent when for every value \(a \in \mathrm{dom}(x)\) there is a value \(b \in \mathrm{dom}(y)\) such that the arc \((x, y)\) allows \(x = a\) together with \(y = b\).

    DefinitionSymmetric binary CSP#✓fully proved

    Cslib.Algorithms.Lean.ArcConsistency.Symmetric

    A binary constraint satisfaction problem is symmetric when, for all variables \(x, y\) and values \(a, b\), the constraint on the ordered pair \((x, y)\) allows \(x = a\) together with \(y = b\) exactly when the constraint on \((y, x)\) allows \(y = b\) together with \(x = a\).

    The condition concerns the allowed pairs for every ordered pair of variables; it does not require the reverse of a listed arc to be listed.

    def Symmetric : Prop := ∀ x y a b, P.allowed x y a b = P.allowed y x b a

    Cslib.Algorithms.Lean.ArcConsistency.potential

    Let \(P\) be a binary constraint satisfaction problem with finitely many variables, \(\mathrm{dom}\) finite domains for its variables and \(q\) a queue of arcs. The potential of \(\mathrm{dom}\) and \(q\) is

    \[|q| + \sum_{x} |\mathrm{dom}(x)| \cdot \mathrm{indeg}(x),\]

    where \(|q|\) is the length of the queue, the sum runs over all variables \(x\), and \(\mathrm{indeg}(x)\) is the in-degree of \(x\) in \(P\).

    def potential [Fintype X] (dom : X → Finset D) (q : List (X × X)) : ℕ :=
  q.length + ∑ x, (dom x).card * indeg P x

    TheoremA shrinking revision lowers the potential#✓fully proved

    Cslib.Algorithms.Lean.ArcConsistency.potential_lt

    Let \(P\) be a binary constraint satisfaction problem with finitely many variables, \(\mathrm{dom}\) finite domains for its variables, \(x\) and \(y\) variables and \(q\) a queue of arcs. Suppose the revision \(R\) of the arc \((x, y)\) with respect to \(\mathrm{dom}\) differs from \(\mathrm{dom}(x)\), and let \(\mathrm{dom}'\) agree with \(\mathrm{dom}\) except that \(\mathrm{dom}'(x) = R\).       potential P dom ((x, y) :: q)

    DefinitionThe AC-3 algorithm#✓fully proved

    Cslib.Algorithms.Lean.ArcConsistency.ac3

    Given a binary CSP \(P\) with finitely many variables, domains \(\mathrm{dom}\) and a queue \(q\) of pairs of variables, AC-3 returns \(\mathrm{dom}\) when \(q\) is empty. Otherwise it removes the first pair \((x, y)\) of \(q\) and revises it: the revised domain of \(x\) consists of the values \(a \in \mathrm{dom}(x)\) for which some \(b \in \mathrm{dom}(y)\) has the arc \((x, y)\) allowing \(x = a\) together with \(y = b\). If the revised domain equals \(\mathrm{dom}(x)\), AC-3 continues from \(\mathrm{dom}\) with the rest of \(q\); otherwise it replaces the domain of \(x\) by the revised domain and continues with the rest of \(q\) followed by the arcs \((z, x)\) of \(P\) with \(z \ne y\), in the order of the arc list of \(P\). Each revision costs one unit of time.

    def ac3 [Fintype X] : (X → Finset D) → List (X × X) → TimeM ℕ (X → Finset D)
  | dom, [] => pure dom
  | dom, (x, y) :: q => do
      TimeM.tick 1
      if revise P dom x y = dom x then ac3 dom q
      else ac3 (Function.update dom x (revise P dom x y)) (q ++ requeue P x y)
termination_by dom q => potential P dom q
