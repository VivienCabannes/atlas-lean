    DefinitionAlpha-beta pruning#✓fully proved

    Cslib.Algorithms.Lean.AlphaBeta.alphaBeta

    For a player \(p\) to move and values \(a\) and \(b\) in a linear order, alpha-beta pruning with window \([a, b]\) returns the value of a leaf at a cost of one unit (one leaf evaluation), and on an inner node runs the alpha-beta scan of its children for \(p\) with window \([a, b]\).

    def alphaBeta : Bool → α → α → GameTree α → TimeM ℕ α
  | _, _, _, .leaf x => do
      TimeM.tick 1
      pure x
  | p, a, b, .node ts => alphaBetaList p a b ts
    inductive GameTree (α : Type u) where
  | leaf : α → GameTree α
  | node : List (GameTree α) → GameTree α

    DefinitionAlpha-beta scan of the children#✓fully proved

    Cslib.Algorithms.Lean.AlphaBeta.alphaBetaList

    Given the player \(p\) to move, values \(a\) and \(b\) in a linear order and a list of game trees (the children of a position), the scan runs alpha-beta pruning for the other player on the children in order, each time with the current bounds \(a\) and \(b\). The maximizer replaces \(a\) by \(\max(a, v)\), where \(v\) is the child's returned value, and stops as soon as \(b \le a\), returning the new \(a\); if it never stops early it returns the final \(a\) (\(a\) itself for an empty list). The minimizer replaces \(b\) by \(\min(b, v)\) and stops as soon as \(b \le a\), returning the new \(b\); if it never stops early it returns the final \(b\) (\(b\) itself for an empty list). The cost of the scan is the total cost of the children it evaluates.

    def alphaBetaList : Bool → α → α → List (GameTree α) → TimeM ℕ α
  | true, a, _, [] => pure a
  | false, _, b, [] => pure b
  | true, a, b, t :: ts => do
      let v ← alphaBeta false a b t
      let a' := max a v
      if b ≤ a' then pure a' else alphaBetaList true a' b ts
  | false, a, b, t :: ts => do
      let v ← alphaBeta true a b t
      let b' := min b v
      if b' ≤ a then pure b' else alphaBetaList false a b' ts
    inductive GameTree (α : Type u) where
  | leaf : α → GameTree α
  | node : List (GameTree α) → GameTree α

    The minimax value; from here on the order is bounded

    DefinitionMinimax value#✓fully proved

    Cslib.Algorithms.Lean.AlphaBeta.minimax

    Let values lie in a bounded linear order. The minimax value of a game tree with player \(p\) to move (the maximizer or the minimizer) is defined recursively: a leaf is worth the value it carries; an inner node is worth, for the maximizer, the maximum of the minimax values of its children with the minimizer to move, and for the minimizer, the minimum of the minimax values of its children with the maximizer to move. An inner node without children is worth \(\bot\) to the maximizer and \(\top\) to the minimizer.

    def minimax : Bool → GameTree α → α
  | _, .leaf x => x
  | p, .node ts => minimaxList p ts
    inductive GameTree (α : Type u) where
  | leaf : α → GameTree α
  | node : List (GameTree α) → GameTree α
