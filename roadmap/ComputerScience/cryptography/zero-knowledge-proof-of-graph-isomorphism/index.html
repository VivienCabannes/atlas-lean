    Zero-knowledge proof of graph isomorphism

    The zero-knowledge proof of Goldreich, Micali and Wigderson (J. ACM 1991, Protocol 2 and Theorem 2) that two graphs \(G_0\) and \(G_1\) on a common vertex set are isomorphic. The prover knows an isomorphism \(\varphi\) with \(G_1 = \varphi(G_0)\). In each round it sends a random relabelling \(H = \pi(G_1)\); the verifier sends a uniform bit \(\alpha\); the prover answers \(\pi\) if \(\alpha = 1\) and \(\pi \circ \varphi\) if \(\alpha = 0\); the verifier checks that the answer maps \(G_\alpha\) onto \(H\). If the graphs are not isomorphic, \(H\) cannot be isomorphic to both, so a cheating prover fails each round with probability at least \(\tfrac12\).

    Here one round is a Sigma protocol on Mathlib's simple graphs, with the general tools of zero-knowledge proofs: completeness, special soundness, soundness error \(\tfrac12\) per round and \(2^{-m}\) over \(m\) rounds against adaptive cheating provers, perfect honest-verifier zero knowledge, and, against an arbitrary verifier in one round, a rewinding simulator whose \(k\) attempts reproduce every test of the verifier's view within \(2^{-k}\). Not formalized: the composition of the simulation over \(m\) rounds and the perfect simulator in expected polynomial time of Theorem 2.

    DefinitionThe graph-isomorphism protocol as a Sigma protocol#✓fully proved

    Cslib.Crypto.Identification.GraphIso.sigma

    One round of the zero-knowledge proof of Goldreich, Micali and Wigderson for graph isomorphism, for simple graphs on a vertex type \(V\). A statement is a pair \((G_0, G_1)\); a witness is a permutation \(\varphi\) of \(V\) that maps \(G_0\) onto \(G_1\). The prover draws a uniform permutation \(\pi\) and commits to \(H = \pi(G_1)\). On the challenge \(\alpha\) it answers \(\pi\) if \(\alpha = 1\) and \(\pi \circ \varphi\) if \(\alpha = 0\). The verifier accepts an answer \(\sigma\) when \(\sigma\) maps the graph selected by \(\alpha\) onto \(H\).

    noncomputable def sigma :
    SigmaProtocol (SimpleGraph V × SimpleGraph V) (Equiv.Perm V) (Equiv.Perm V) (SimpleGraph V)
      Bool (Equiv.Perm V) where
  Rel x φ := x.1.map φ = x.2
  commit x _ π := x.2.map π
  respond _ φ π α := if α then π else π * φ
  verify x H α σ := decide ((pickGraph x α).map σ = H)

    TheoremCompleteness of the graph-isomorphism protocol#✓fully proved

    Cslib.Crypto.Identification.GraphIso.sigma_complete

    The graph-isomorphism protocol is complete: if \(\varphi\) maps \(G_0\) onto \(G_1\), then for all prover coins \(\pi\) and both challenges the honest answer is accepted. For \(\alpha = 1\) the answer \(\pi\) maps \(G_1\) onto \(H = \pi(G_1)\); for \(\alpha = 0\) the answer \(\pi \circ \varphi\) maps \(G_0\) onto \(\pi(\varphi(G_0)) = H\).

    DefinitionThe extractor#✓fully proved

    Cslib.Crypto.Identification.GraphIso.extract

    From answers \(\sigma\) to a challenge \(\alpha\) and \(\sigma'\) to a challenge \(\alpha'\), the extractor outputs \(\sigma_1^{-1} \circ \sigma_0\), where \(\sigma_0\) is the answer to the challenge \(0\) and \(\sigma_1\) the answer to the challenge \(1\) (that is, \(\sigma^{-1} \circ \sigma'\) if \(\alpha = 1\) and \(\sigma'^{-1} \circ \sigma\) otherwise).

    def extract (_x : SimpleGraph V × SimpleGraph V) (_H : SimpleGraph V) (α : Bool)
    (σ : Equiv.Perm V) (_α' : Bool) (σ' : Equiv.Perm V) : Equiv.Perm V :=
  if α then σ⁻¹ * σ' else σ'⁻¹ * σ
