    Zero-knowledge proofs

    Interactive proofs (Goldwasser, Micali and Rackoff, SIAM J. Comput. 1989) let a prover convince a probabilistic polynomial-time verifier of a statement, with completeness (true statements are accepted) and soundness (false statements are rejected with high probability, whatever the prover does). A proof is zero knowledge if everything the verifier sees can be produced by a simulator that knows only that the statement is true.

    This topic holds the general tools, for Sigma protocols (three-move public-coin protocols with a uniform challenge; the framework was already in the library): completeness, special soundness, the soundness error \(1/\lvert \mathrm{Ch} \rvert\) of one round and \(1/\lvert \mathrm{Ch} \rvert^m\) of \(m\) sequential rounds against adaptive cheating provers, honest-verifier zero knowledge, and the rewinding simulator of Goldwasser, Micali and Rackoff for an arbitrary (cheating) verifier in one round: each attempt succeeds with probability exactly \(1/\lvert \mathrm{Ch} \rvert\) and a successful attempt reproduces the real view exactly, so with \(k\) attempts every test of the view has probabilities within \((1 - 1/\lvert \mathrm{Ch} \rvert)^k\). The protocols themselves (graph isomorphism, quadratic residuosity, Schnorr) are in their own topics or in the last section. Not formalized: the composition of the simulation over \(m\) rounds, perfect simulation in expected polynomial time, and the general definitions of interactive proofs and zero knowledge as classes of languages (the interactive-proof class used for \(\mathsf{IP} = \mathsf{PSPACE}\) is linked below).

    Sigma protocols

    StructureA Sigma protocol#✓fully proved

    Cslib.Crypto.Identification.SigmaProtocol

    A Sigma protocol for a relation \(R(x, w)\) between statements \(x\) and witnesses \(w\) is a three-move public-coin protocol. The prover, holding \((x, w)\) and random coins \(k\), sends a commitment \(a = \mathrm{commit}(x, w, k)\); the verifier sends a uniformly random challenge \(e\) from a set \(\mathrm{Ch}\); the prover answers \(z = \mathrm{respond}(x, w, k, e)\); and the verifier accepts when \(\mathrm{verify}(x, a, e, z)\) holds. The identification schemes of Katz and Lindell have this shape.

    structure SigmaProtocol (X W K Cm Ch Z : Type*) where
  /-- The relation: `w` is a witness for the statement `x`. -/
  Rel : X → W → Prop
  /-- The prover's first message, from the statement, the witness and its coins. -/
  commit : X → W → K → Cm
  /-- The prover's answer to the challenge. -/
  respond : X → W → K → Ch → Z
  /-- The verifier's check on a transcript `(a, e, z)` for the statement `x`. -/
  verify : X → Cm → Ch → Z → Bool

    DefinitionSpecial soundness of a Sigma protocol#✓fully proved

    Cslib.Crypto.Identification.SigmaProtocol.SpecialSound

    A Sigma protocol is specially sound with an extractor if from any two accepting transcripts \((a, e, z)\) and \((a, e', z')\) for a statement \(x\) with the same commitment and different challenges \(e \ne e'\), the extractor computes a witness for \(x\).

    def SpecialSound (ext : X → Cm → Ch → Z → Ch → Z → W) : Prop :=
  ∀ x a e z e' z', e ≠ e' → P.verify x a e z = true → P.verify x a e' z' = true →
    P.Rel x (ext x a e z e' z')

    Cslib.Crypto.Identification.SigmaProtocol.HVZK

    A Sigma protocol is perfectly honest-verifier zero knowledge with a simulator, a function of the statement alone, if for every statement–witness pair in the relation the distribution of honest transcripts equals the simulator's output distribution.     DefinitionStatistical honest-verifier zero knowledge#✓fully proved

    Cslib.Crypto.Identification.SigmaProtocol.StatHVZK

    A Sigma protocol is statistically honest-verifier zero knowledge with a simulator and an error \(\varepsilon\) if for every statement–witness pair in the relation, no test of transcripts tells the honest transcripts from the simulated ones with advantage more than \(\varepsilon\).

    def StatHVZK (sim : X → PMF (Cm × Ch × Z)) (ε : ℝ) : Prop :=
  ∀ x w, P.Rel x w → ∀ D : Cm × Ch × Z → Bool,
    advantage ((P.transcript x w).map D) ((sim x).map D) ≤ ε
    noncomputable def advantage (G₀ G₁ : PMF Bool) : ℝ := |winProb G₀ - winProb G₁|

    TheoremSoundness error for false statements#✓fully proved

    Cslib.Crypto.Identification.SigmaProtocol.winProb_cheatGame_le

    For a specially sound Sigma protocol and a statement \(x\) with no witness at all, every cheating prover is accepted in the cheating experiment with probability at most \(1 / \lvert \mathrm{Ch} \rvert\): for each commitment it can answer at most one challenge.

    This is soundness for the language of true statements, not knowledge soundness: the hypothesis says that \(x\) is false, which is much stronger than saying that the prover does not know an existing witness. In the Schnorr setting with a generator of the order-\(q\) subgroup every statement has a witness, so the hypothesis never holds there, and this result does not model the impersonation attack of Katz and Lindell's Theorem 12.11.

    theorem winProb_cheatGame_le {ext : X → Cm → Ch → Z → Ch → Z → W} (hP : P.SpecialSound ext)
    {x : X} (hx : ∀ w, ¬ P.Rel x w) (a : R → Cm) (z : R → Ch → Z) :
    winProb (P.cheatGame x a z) ≤ 1 / Fintype.card Ch
    noncomputable def winProb (G : PMF Bool) : ℝ := (G true).toReal

    DefinitionAcceptance of m sequential rounds#✓fully proved

    Cslib.Crypto.Identification.SigmaProtocol.allAccept

    For a Sigma protocol, a statement \(x\), a prover whose commitment in a round is \(a(\ell)\) and whose answer to a challenge \(e\) is \(z(\ell, e)\), where \(\ell\) is the list of the challenges of the earlier rounds in order, and a sequence \(c_0, \dots, c_{m-1}\) of challenges, the verifier accepts all \(m\) rounds: round \(i\) checks the transcript \((a(c_0, \dots, c_{i-1}), c_i, z(c_0, \dots, c_{i-1}, c_i))\). For \(m = 0\) the verifier accepts.

    def allAccept (x : X) : (a : List Ch → Cm) → (z : List Ch → Ch → Z) → (m : ℕ) → (Fin m → Ch) →
    Bool
  | _, _, 0, _ => true
  | a, z, m + 1, c => P.verify x (a []) (c 0) (z [] (c 0)) &&
      allAccept x (fun l => a (c 0 :: l)) (fun l => z (c 0 :: l)) m (Fin.tail c)

    TheoremAt most one accepted challenge sequence#✓fully proved

    Cslib.Crypto.Identification.SigmaProtocol.allAccept_subsingleton

    Let a Sigma protocol be specially sound, and let \(x\) be a statement with no witness. Then for every \(m\) and every adaptive prover, two challenge sequences of length \(m\) that are both accepted in all rounds are equal. In the first round both challenges are answered for the same commitment, and two accepting transcripts with different challenges would give a witness; the remaining rounds follow by induction.

    theorem allAccept_subsingleton {ext : X → Cm → Ch → Z → Ch → Z → W} (hP : P.SpecialSound ext)
    {x : X} (hx : ∀ w, ¬ P.Rel x w) :
    ∀ (m : ℕ) (a : List Ch → Cm) (z : List Ch → Ch → Z) (c c' : Fin m → Ch),
      P.allAccept x a z m c = true → P.allAccept x a z m c' = true → c = c'

    TheoremOne rewinding attempt simulates the real view#✓fully proved

    Cslib.Crypto.Identification.SigmaProtocol.winProb_attemptDist

    Let a Sigma protocol have a perfect special honest-verifier zero-knowledge simulator and a finite challenge set \(\mathrm{Ch}\), and let \(x\) have a witness \(w\). For every verifier \(V^*\) and every test \(T\) of its view, $\(\Pr[\text{the attempt succeeds and } T \text{ holds}] = \frac{1}{\lvert \mathrm{Ch} \rvert} \Pr[T \text{ holds of the real view}],\)$ the left side for one rewinding attempt and the right side for the real view.
