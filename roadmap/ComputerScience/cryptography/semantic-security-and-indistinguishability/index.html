    Semantic security and indistinguishability

    Goldwasser and Micali's definition of secure encryption: a ciphertext must not help any efficient adversary compute any partial information on the plaintext (semantic security), and the technical condition that implies it, that encryptions of any two messages of equal length cannot be told apart (indistinguishability of encryptions). The two notions are equivalent (Goldreich, Foundations of Cryptography, Vol. II, Theorem 5.2.5).

    Here both are stated for public-key schemes in concrete form: one fixed scheme, adversaries given as functions of their random coins, an explicit error \(\varepsilon\) in place of Goldreich's \(1/p(n)\), and no bound on running time. The theorems that matter are per adversary: a distinguisher with advantage \(\varepsilon\) against the hardwired plaintexts gives semantic security with error \(\varepsilon\) against the given adversary, and a distinguisher with advantage \(\delta\) gives an adversary that beats every simulator by \(\delta/2\). Each transformation makes one call to the given adversary, so it carries over to efficient adversaries, which is what Goldreich's asymptotic Theorem 5.2.5 needs.

    Against unbounded adversaries, which this model allows, no correct public-key scheme has indistinguishable encryptions with an error below \(1\), or is semantically secure with an error below \(\tfrac12\): a distinguisher may decrypt with any secret key matching the public key. The all-adversary implications between the two definitions are proved too, but for public-key schemes they relate statements that are trivially true or false; they are labelled "all-adversary form".

    DefinitionThe indistinguishability experiment#✓fully proved

    Cslib.Crypto.PublicKey.SemanticSecurity.indExp

    Let \(S\) be a public-key encryption scheme with key generation \(\mathrm{Gen}\) and probabilistic encryption \(\mathrm{Enc}\). For a distribution of random coins on a type \(R\), a distinguisher \(D\), which maps a public key, a ciphertext and coins to a bit, and a message \(m\), the indistinguishability experiment draws a key pair \((pk, sk) \leftarrow \mathrm{Gen}\), coins \(r\) and a ciphertext \(c \leftarrow \mathrm{Enc}_{pk}(m)\), and outputs \(D(pk, c, r)\).

    noncomputable def indExp (coins : PMF R) (D : PK → C → R → Bool) (m : M) : PMF Bool :=
  S.gen.bind fun kp => coins.bind fun r => (S.enc kp.1 m).map fun c => D kp.1 c r

    DefinitionIndistinguishability of encryptions with error ε#✓fully proved

    Cslib.Crypto.PublicKey.SemanticSecurity.IndSecure

    A public-key encryption scheme, with a length function on its messages and a distribution of the adversary's coins, has indistinguishable encryptions with error \(\varepsilon\) if for every distinguisher \(D\) (a function of the public key, the ciphertext and the coins) and all messages \(m, m'\) of the same length, the distinguishing advantage of \(D\) between encryptions of \(m\) and \(m'\) is at most \(\varepsilon\).

    This is Goldreich's Definition 5.2.4 in concrete form: the error \(1/p(n)\) "for every positive polynomial \(p\) and all sufficiently large \(n\)" is replaced by one number \(\varepsilon\), and every function is an admissible distinguisher, where Goldreich quantifies over polynomial-size circuit families. In this concrete model every function counts as an adversary, so no correct public-key scheme with two distinct messages of the same length meets it with \(\varepsilon < 1\), deterministic or probabilistic (unattainability): a distinguisher may decrypt with any secret key matching the public key. With a small \(\varepsilon\) the definition therefore describes information-theoretic security; for public-key schemes the content lies in the per-adversary statements, such as indistinguishability implies semantic security, per adversary, which carry over to efficient adversaries.

    def IndSecure (len : M → ℕ) (coins : PMF R) (ε : ℝ) : Prop :=
  ∀ (D : PK → C → R → Bool) (m m' : M), len m = len m' → indAdvantage S coins D m m' ≤ ε
    noncomputable def indAdvantage (coins : PMF R) (D : PK → C → R → Bool) (m m' : M) : ℝ :=
  advantage (indExp S coins D m) (indExp S coins D m')

    Cslib.Crypto.PublicKey.SemanticSecurity.ssIdeal

    DefinitionSemantic security with error ε#✓fully proved

    Cslib.Crypto.PublicKey.SemanticSecurity.SemanticallySecure

    A public-key encryption scheme, with a length function on its messages and a distribution of the adversary's coins, is semantically secure with error \(\varepsilon\) (for a priori information in a type \(H\) and guesses in a type \(T\)) if for every adversary \(A\) there is an ideal adversary \(A'\) such that for every plaintext distribution \(X\), every function \(h\) and every target function \(f\), the probability that \(A\) wins the real experiment is at most \(\varepsilon\) more than the probability that \(A'\) wins the ideal experiment.

    The quantifiers are in Goldreich's order: \(A'\) may depend on \(A\) but not on \(X\), \(h\) or \(f\). Unlike Goldreich's definition, the real adversary \(A\) is not given the length of the plaintext (only \(A'\) is); this weakens the definition slightly and is harmless when ciphertexts reveal the length. The definition is concrete: one scheme, one error, and no complexity bound on \(A\) or \(A'\) (Goldreich requires both to be probabilistic polynomial time). In this concrete model every function counts as an adversary, so no correct public-key scheme with two distinct messages of the same length meets it with \(\varepsilon < \tfrac12\) (unattainability); the per-adversary statements carry the content for public-key schemes.

    def SemanticallySecure (len : M → ℕ) (coins : PMF R) (H T : Type*) [DecidableEq T] (ε : ℝ) :
    Prop :=
  ∀ A : PK → C → H → R → T, ∃ A' : ℕ → H → PMF T, ∀ (X : PMF M) (h : M → H) (f : M → T),
    winProb (ssReal S coins A X h f) ≤ winProb (ssIdeal len A' X h f) + ε
    noncomputable def winProb (G : PMF Bool) : ℝ := (G true).toReal

    Cslib.Crypto.PublicKey.SemanticSecurity.simulator

    TheoremIndistinguishability implies semantic security, per adversary#✓fully proved

    Cslib.Crypto.PublicKey.SemanticSecurity.winProb_ssReal_le

    Let \(A\) be an adversary, \(X\) a plaintext distribution, \(h\) and \(f\) functions on plaintexts and \(\varepsilon \ge 0\). Suppose that for every plaintext \(x\) in the support of \(X\) the distinguisher hardwiring \(x\) has advantage at most \(\varepsilon\) between encryptions of \(x\) and of the dummy message of length \(|x|\). Then the probability that \(A\) wins the real experiment is at most \(\varepsilon\) more than the probability that the simulator wins the ideal experiment.

    This is the concrete content of Goldreich's Proposition 5.2.6 and Claim 5.2.6.1: averaging over \(x\) replaces his choice of a plaintext maximizing the gap. Only the distinguishers built from \(A\), \(h\) and \(f\) are needed, each with one call to \(A\), so the statement carries over to efficient adversaries.

    theorem winProb_ssReal_le (len : M → ℕ) (coins : PMF R) (dummy : ℕ → M)

    (hind : ∀ x ∈ X.support,
      indAdvantage S coins (ssDistinguisher A h f x) x (dummy (len x)) ≤ ε) :
    winProb (ssReal S coins A X h f) ≤
      winProb (ssIdeal len (simulator S coins dummy A) X h f) + ε

    Cslib.Crypto.PublicKey.SemanticSecurity.winProb_ssReal_two_point

    Let \(D\) be a distinguisher and \(m \ne m'\) two messages of the same length. Take the two-point distribution on \(m\) and \(m'\) as plaintext distribution, no a priori information, and the target function \(f(x) = [x = m']\). Let \(A\) be the adversary that outputs \(D(pk, c, r)\). Then for every ideal adversary \(A'\), $\(\Pr[A \text{ wins}] - \Pr[A' \text{ wins}] = \tfrac12 \bigl(\Pr[D(\mathrm{Enc}(m')) = 1] - \Pr[D(\mathrm{Enc}(m)) = 1]\bigr),\)$ the probabilities being those of the real and ideal experiments and of the indistinguishability experiments for \(m'\) and \(m\). Indeed \(A'\) sees the same length and the same (empty) information for both messages, so it wins with probability exactly \(\tfrac12\). So a distinguisher with advantage \(\delta\) gives, with one call, an adversary that beats every simulator by \(\delta / 2\).

    Cslib.Crypto.PublicKey.SemanticSecurity.not_indSecure_of_correct

    Let a public-key scheme be correct, and let \(m \ne m'\) be messages of the same length. Then for every distribution of coins and every \(\varepsilon < 1\), the scheme does not have indistinguishable encryptions with error \(\varepsilon\) in this concrete model. The distinguisher that outputs \(1\) exactly when some secret key matching the public key decrypts the ciphertext to \(m'\) outputs \(1\) on every encryption of \(m'\) and never on an encryption of \(m\): by correctness, every key pair with that public key decrypts encryptions of \(m\) to \(m\). Its advantage is therefore \(1\).

    This holds for probabilistic as well as deterministic encryption: it is the reason the computational definitions restrict distinguishers to efficient ones.
