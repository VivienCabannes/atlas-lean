    Laplace and exponential mechanisms

    The two basic ways of achieving pure differential privacy (Dwork and Roth 2014, Sections 3.3 and 3.4). The Laplace mechanism answers a numeric query \(f\) by adding Laplace noise of scale \(\Delta f / \varepsilon\), where \(\Delta f\) is the \(\ell_1\)-sensitivity of \(f\): the most one individual can change \(f\). The exponential mechanism answers a query with an arbitrary range by sampling an output with probability proportional to \(\exp(\varepsilon u(x, r) / (2 \Delta u))\), for a utility score \(u\) of sensitivity \(\Delta u\); it loses at most \(O((\Delta u / \varepsilon) \log |R|)\) in utility with high probability. The Gaussian mechanism, which gives \((\varepsilon, \delta)\)-privacy with noise calibrated to the \(\ell_2\)-sensitivity, is recorded as a wanted result in differential privacy.

    Laplace mechanism

    DefinitionLaplace mechanism#✓fully proved

    Cslib.Crypto.Privacy.laplaceMechanism

    For a real-valued query \(f : X \to \mathbb{R}\) and a scale \(b\), the Laplace mechanism releases \(f(x) + Y\) with \(Y \sim \mathrm{Lap}(0, b)\), i.e. its output law is \(\mathrm{Lap}(f(x), b)\). The scale is calibrated as \(b = \Delta f / \varepsilon\), where \(\Delta f\) bounds the change of \(f\) between neighbours. The source defines it for \(f : X \to \mathbb{R}^k\) with independent noise on each coordinate; that form appears in the vector-valued theorem.

    noncomputable def laplaceMechanism {X : Type*} (f : X → ℝ) (b : ℝ) : X → Measure ℝ :=
  fun x ↦ laplaceMeasure (f x) b
    noncomputable def laplaceMeasure (m b : ℝ) : Measure ℝ :=
  volume.withDensity fun z ↦ ENNReal.ofReal (laplacePDFReal m b z)

    TheoremThe Laplace mechanism is differentially private#✓fully proved

    Cslib.Crypto.Privacy.laplaceMechanism_differentiallyPrivate

    Let \(f : X \to \mathbb{R}\) satisfy \(|f(x) - f(y)| \le \Delta\) for all neighbours \(x, y\), with \(\Delta > 0\), and let \(\varepsilon > 0\). The Laplace mechanism with scale \(\Delta / \varepsilon\) is \(\varepsilon\)-differentially private: the densities of the outputs on neighbouring databases differ by a factor of at most \(e^{|f(x) - f(y)| \varepsilon / \Delta} \le e^{\varepsilon}\). Any upper bound \(\Delta\) on the sensitivity works; the source uses the sensitivity itself.

    theorem laplaceMechanism_differentiallyPrivate {X : Type*} {Adj : X → X → Prop} {f : X → ℝ}
    {Δ ε : ℝ} (hΔ : 0 < Δ) (hε : 0 < ε) (hf : ∀ ⦃x y⦄, Adj x y → |f x - f y| ≤ Δ) :
    DifferentiallyPrivate Adj (laplaceMechanism f (Δ / ε)) ε 0
    def DifferentiallyPrivate (Adj : X → X → Prop) (M : X → Measure Ω) (ε : ℝ) (δ : ℝ≥0∞) : Prop :=
  ∀ ⦃x y : X⦄, Adj x y → ∀ S : Set Ω, MeasurableSet S →
    M x S ≤ ENNReal.ofReal (Real.exp ε) * M y S + δ

    TheoremThe Laplace mechanism for vector-valued queries#✓fully proved

    Cslib.Crypto.Privacy.laplaceMechanism_pi_differentiallyPrivate

    Let \(f : X \to \mathbb{R}^k\) have \(\ell_1\)-sensitivity at most \(\Delta > 0\): \(\sum_{i} |f(x)_i - f(y)_i| \le \Delta\) for all neighbours \(x, y\). For \(\varepsilon > 0\), releasing \(f(x) + (Y_1, \dots, Y_k)\) with \(Y_i\) independent \(\mathrm{Lap}(0, \Delta/\varepsilon)\) is \(\varepsilon\)-differentially private.

    The Lean proof fixes two neighbours \(x, y\) and views coordinate \(i\) as a mechanism on the two-point set \(\{x, y\}\) whose privacy loss is \(|f(x)_i - f(y)_i| \varepsilon / \Delta\); basic composition then bounds the joint loss by the sum, which is at most \(\varepsilon\). The source instead multiplies the coordinate density ratios directly; both arguments rest on the same pointwise bound.

    theorem laplaceMechanism_pi_differentiallyPrivate {X : Type*} {Adj : X → X → Prop} {k : ℕ}
    {f : X → Fin k → ℝ} {Δ ε : ℝ} (hΔ : 0 < Δ) (hε : 0 < ε)
    (hf : ∀ ⦃x y⦄, Adj x y → ∑ i, |f x i - f y i| ≤ Δ) :
    DifferentiallyPrivate Adj (fun x ↦ Measure.pi fun i ↦ laplaceMeasure (f x i) (Δ / ε)) ε 0
    def DifferentiallyPrivate (Adj : X → X → Prop) (M : X → Measure Ω) (ε : ℝ) (δ : ℝ≥0∞) : Prop :=
  ∀ ⦃x y : X⦄, Adj x y → ∀ S : Set Ω, MeasurableSet S →
    M x S ≤ ENNReal.ofReal (Real.exp ε) * M y S + δ

    Exponential mechanism

    DefinitionWeights of the exponential mechanism#✓fully proved

    Cslib.Crypto.Privacy.expMechWeight

    For a utility score \(u : X \times R \to \mathbb{R}\), a sensitivity bound \(\Delta\) and \(\varepsilon\), the exponential mechanism gives output \(r\) on database \(x\) the un-normalised weight \(\exp(\varepsilon u(x, r) / (2\Delta))\). Half of the privacy budget pays for the change of the normalising constant between neighbours.

    noncomputable def expMechWeight (ε Δ : ℝ) (u : X → R → ℝ) (x : X) (r : R) : ℝ :=
  Real.exp (ε * u x r / (2 * Δ))

    DefinitionOutput probabilities of the exponential mechanism#✓fully proved

    Cslib.Crypto.Privacy.expMechProb

    On a finite nonempty range \(R\), the exponential mechanism outputs \(r\) on database \(x\) with probability

    \[ p_x(r) = \frac{\exp(\varepsilon u(x, r) / (2\Delta))}{\sum_{r' \in R} \exp(\varepsilon u(x, r') / (2\Delta))}. \]
    noncomputable def expMechProb (ε Δ : ℝ) (u : X → R → ℝ) (x : X) (r : R) : ℝ :=
  expMechWeight ε Δ u x r / ∑ r', expMechWeight ε Δ u x r'
    noncomputable def expMechWeight (ε Δ : ℝ) (u : X → R → ℝ) (x : X) (r : R) : ℝ :=
  Real.exp (ε * u x r / (2 * Δ))

    DefinitionExponential mechanism#✓fully proved

    Cslib.Crypto.Privacy.expMechanism

    The exponential mechanism on a finite nonempty range \(R\) outputs \(r\) with probability proportional to \(\exp(\varepsilon u(x, r) / (2\Delta))\), where \(\Delta\) bounds the sensitivity \(\max_r \max_{x \sim y} |u(x, r) - u(y, r)|\) of the score in its database argument; the score may be arbitrarily sensitive in \(r\). The range must not depend on the database. It is the natural mechanism for selecting a best non-numeric answer, such as a price in an auction, where adding noise to the answer itself would destroy its value.

    noncomputable def expMechanism [MeasurableSpace R] (ε Δ : ℝ) (u : X → R → ℝ) (x : X) :
    Measure R :=
  ∑ r, ENNReal.ofReal (expMechProb ε Δ u x r) • Measure.dirac r
    noncomputable def expMechProb (ε Δ : ℝ) (u : X → R → ℝ) (x : X) (r : R) : ℝ :=
  expMechWeight ε Δ u x r / ∑ r', expMechWeight ε Δ u x r'

    TheoremOutput probabilities on neighbouring databases#✓fully proved

    Cslib.Crypto.Privacy.expMechProb_le_exp_mul

    If \(\varepsilon \ge 0\), \(\Delta > 0\) and \(|u(x, r) - u(y, r)| \le \Delta\) for all \(r\), then \(p_x(r) \le e^{\varepsilon} p_y(r)\) for every output \(r\): the weight of \(r\) changes by a factor at most \(e^{\varepsilon/2}\), and so does the normalising sum.

    theorem expMechProb_le_exp_mul {ε Δ : ℝ} (hε : 0 ≤ ε) (hΔ : 0 < Δ) {u : X → R → ℝ} {x y : X}

    expMechProb ε Δ u x r ≤ Real.exp ε * expMechProb ε Δ u y r

    TheoremUtility of the exponential mechanism#✓fully proved

    Cslib.Crypto.Privacy.expMechanism_utility

    Fix a database \(x\), \(\varepsilon > 0\) and \(\Delta > 0\), and let \(R_{\mathrm{OPT}}\) be the set of outputs attaining \(\mathrm{OPT}_u(x)\). For every \(t\),

    \[ \Pr\Big[u(x, M_E(x)) \le \mathrm{OPT}_u(x) - \frac{2\Delta}{\varepsilon}\Big(\ln \frac{|R|}{|R_{\mathrm{OPT}}|} + t\Big)\Big] \le e^{-t}. \]

    The outputs below a level \(c\) carry total weight at most \(|R| e^{\varepsilon c / (2\Delta)}\), while the normalising sum is at least \(|R_{\mathrm{OPT}}| e^{\varepsilon \mathrm{OPT}_u(x) / (2\Delta)}\).

    theorem expMechanism_utility {ε Δ : ℝ} (hε : 0 < ε) (hΔ : 0 < Δ) (u : X → R → ℝ) (x : X)
    (t : ℝ) :
    expMechanism ε Δ u x {r | u x r ≤ optUtility u x - 2 * Δ / ε *
      (Real.log (Fintype.card R / Nat.card {r : R // u x r = optUtility u x}) + t)}
      ≤ ENNReal.ofReal (Real.exp (-t))
    noncomputable def expMechanism [MeasurableSpace R] (ε Δ : ℝ) (u : X → R → ℝ) (x : X) :
    Measure R :=
  ∑ r, ENNReal.ofReal (expMechProb ε Δ u x r) • Measure.dirac r
