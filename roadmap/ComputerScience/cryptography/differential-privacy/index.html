    Differential privacy

    A randomized algorithm (a mechanism) is differentially private when changing one individual's data changes the probability of every output event by at most a factor \(e^\varepsilon\), up to an additive slack \(\delta\) (Dwork, McSherry, Nissim and Smith 2006; Dwork and Roth 2014, Chapter 2). The definition is stated here for an arbitrary neighbouring relation on databases, with the histogram relation \(\|x - y\|_1 \le 1\) of Dwork and Roth and the row (Hamming) relation as instances. Its basic properties are immunity to post-processing, graceful degradation for groups, and composition; the advanced composition theorem and the link with generalization in adaptive data analysis are recorded as wanted results.

    Definition

    DefinitionDifferential privacy#✓fully proved

    Cslib.Crypto.Privacy.DifferentiallyPrivate

    A mechanism is a map \(M : X \to \mathcal{M}(\Omega)\) sending a database \(x\) to the law \(M(x)\) of the released output. For a neighbouring relation \(\mathrm{Adj}\) on databases, \(\varepsilon \in \mathbb{R}\) and \(\delta \in [0, \infty]\), the mechanism is \((\varepsilon, \delta)\)-differentially private if for all \(x, y\) with \(\mathrm{Adj}(x, y)\) and every measurable \(S \subseteq \Omega\),

    \[ M(x)(S) \le e^{\varepsilon} M(y)(S) + \delta . \]

    With \(\delta = 0\) this is \(\varepsilon\)-differential privacy. Dwork and Roth state the definition for histogram databases \(x \in \mathbb{N}^{|\mathcal{X}|}\) with \(\|x - y\|_1 \le 1\), which is the relation histogramAdj; databases given as lists of rows use the Hamming relation hammingAdj. The probability is over the coins of the mechanism only: the database is fixed, not random.

    def DifferentiallyPrivate (Adj : X → X → Prop) (M : X → Measure Ω) (ε : ℝ) (δ : ℝ≥0∞) : Prop :=
  ∀ ⦃x y : X⦄, Adj x y → ∀ S : Set Ω, MeasurableSet S →
    M x S ≤ ENNReal.ofReal (Real.exp ε) * M y S + δ
    Background
    Background
    • Total variation distance between finite measures: for probability measures and a symmetric neighbouring relation, the case \(\varepsilon = 0\) of the definition says that \(M(x)\) and \(M(y)\) are at total variation distance at most \(\delta\).

    DefinitionNeighbouring histograms#✓fully proved

    Cslib.Crypto.Privacy.histogramAdj

    A database over a finite universe \(U\) of record types is a histogram \(x : U \to \mathbb{N}\), where \(x(u)\) counts the records of type \(u\). Two histograms are neighbours when \(\|x - y\|_1 = \sum_{u} |x(u) - y(u)| \le 1\): they differ by adding or removing at most one record.

    def histogramAdj {U : Type*} [Fintype U] (x y : U → ℕ) : Prop :=
  ∑ u, |(x u : ℤ) - y u| ≤ 1

    DefinitionNeighbouring row databases#✓fully proved

    Cslib.Crypto.Privacy.hammingAdj

    A database of \(n\) rows from a set \(U\) is a list \(S : \{0, \dots, n - 1\} \to U\). Two such databases are neighbours when they differ in at most one row, i.e. their Hamming distance is at most \(1\). This is the relation used for data sets of i.i.d. samples, for instance in adaptive data analysis.

    def hammingAdj {U : Type*} {n : ℕ} (S S' : Fin n → U) : Prop :=
  ∃ i, ∀ j, j ≠ i → S j = S' j

    TheoremPure differential privacy as a measure inequality#✓fully proved

    Cslib.Crypto.Privacy.differentiallyPrivate_zero_iff_le_smul

    A mechanism \(M\) is \(\varepsilon\)-differentially private if and only if \(M(x) \le e^{\varepsilon} M(y)\) as measures for all neighbours \(x, y\). This form is what makes pure differential privacy pass through integrals: \(\int f \, dM(x) \le e^{\varepsilon} \int f \, dM(y)\) for every nonnegative measurable \(f\).

    theorem differentiallyPrivate_zero_iff_le_smul :
    DifferentiallyPrivate Adj M ε 0 ↔
      ∀ ⦃x y : X⦄, Adj x y → M x ≤ ENNReal.ofReal (Real.exp ε) • M y

    TheoremPost-processing by a Markov kernel#✓fully proved

    Cslib.Crypto.Privacy.DifferentiallyPrivate.bind

    If \(M\) is \((\varepsilon, \delta)\)-differentially private and \(\kappa\) is a Markov kernel from \(\Omega\) to \(\Omega'\) (a randomized map applied to the output, using no access to the database), then \(x \mapsto \int \kappa(\omega, \cdot) \, dM(x)(\omega)\) is \((\varepsilon, \delta)\)-differentially private. A data analyst who only sees the output cannot increase the privacy loss.

    Dwork and Roth prove the deterministic case and write a randomized map as a convex combination of deterministic ones. The Lean proof instead integrates the event bound: for a measurable \(g : \Omega \to [0, 1]\), the layer-cake formula \(\int g \, d\mu = \int_0^1 \mu\{g > t\} \, dt\) turns \(\mu\{g > t\} \le e^{\varepsilon} \nu\{g > t\} + \delta\) into \(\int g \, d\mu \le e^{\varepsilon} \int g \, d\nu + \delta\), applied to \(g = \kappa(\cdot, S)\).

    theorem DifferentiallyPrivate.bind (h : DifferentiallyPrivate Adj M ε δ) (κ : Kernel Ω Ω')
    [IsMarkovKernel κ] : DifferentiallyPrivate Adj (fun x ↦ (M x).bind κ) ε δ

    Group privacy

    TheoremGroup privacy along a chain#✓fully proved

    Cslib.Crypto.Privacy.DifferentiallyPrivate.group

    If \(M\) is \(\varepsilon\)-differentially private and \(z_0, z_1, \dots, z_k\) is a chain of databases in which consecutive ones are neighbours, then for every measurable \(S\),

    \[ M(z_0)(S) \le e^{k \varepsilon} M(z_k)(S). \]

    Groups of \(k\) individuals correspond to such chains: the guarantee degrades linearly in the size of the group, which is what one wants, since replacing a whole population should change the answers.

    theorem DifferentiallyPrivate.group (h : DifferentiallyPrivate Adj M ε 0) {k : ℕ} {z : ℕ → X}
    (hz : ∀ i < k, Adj (z i) (z (i + 1))) {S : Set Ω} (hS : MeasurableSet S) :
    M (z 0) S ≤ ENNReal.ofReal (Real.exp (k * ε)) * M (z k) S
    def DifferentiallyPrivate (Adj : X → X → Prop) (M : X → Measure Ω) (ε : ℝ) (δ : ℝ≥0∞) : Prop :=
  ∀ ⦃x y : X⦄, Adj x y → ∀ S : Set Ω, MeasurableSet S →
    M x S ≤ ENNReal.ofReal (Real.exp ε) * M y S + δ

    TheoremGroup privacy for histograms#✓fully proved

    Cslib.Crypto.Privacy.DifferentiallyPrivate.group_histogram

    TheoremGroup privacy, approximate case#✓fully proved

    Cslib.Crypto.Privacy.DifferentiallyPrivate.group_approx

    If \(M\) is \((\varepsilon, \delta)\)-differentially private with \(\varepsilon \ge 0\), then along a chain of \(k\) neighbouring steps \(M(z_0)(S) \le e^{k\varepsilon} M(z_k)(S) + k e^{(k-1)\varepsilon}\delta\): the mechanism is \((k\varepsilon, k e^{(k-1)\varepsilon}\delta)\)-differentially private for groups of size \(k\).     TheoremAdaptive composition of pure differential privacy#✓fully proved

    Cslib.Crypto.Privacy.DifferentiallyPrivate.compProd

    Let \(M_1\) be \(\varepsilon_1\)-differentially private, and let the second mechanism be chosen after seeing the first output \(\omega\): a kernel \(M_2(x)(\omega, \cdot)\) such that for each \(\omega\) the mechanism \(x \mapsto M_2(x)(\omega, \cdot)\) is \(\varepsilon_2\)-differentially private.     TheoremAdaptive composition of approximate differential privacy, two mechanisms#✓fully proved

    Cslib.Crypto.Privacy.DifferentiallyPrivate.compProd_approx
