    DefinitionWinning the forgery game#✓fully proved

    Cslib.Crypto.PRF.MacWins

    A forger \(c\), an adaptive oracle algorithm with queries in \(M\), answers in \(T\) and output in \(M \times T\), wins against the tagging oracle \(O \colon M \to T\) when, run with oracle \(O\), it outputs a pair \((m, t)\) with \(O(m) = t\) and \(m\) is not among the queries it asks in that run.

    def MacWins (O : M → T) (c : OracleComp M T (M × T)) : Prop :=

    Cslib.Crypto.PRF.macGame

    Let \(K\) and \(R\) be finite nonempty types, let \(F \colon K \to M \to T\) be a keyed function, and let \(A\) be a forger: for coins \(r \in R\), \(A(r)\) is an adaptive oracle algorithm with queries in \(M\), answers in \(T\) and output in \(M \times T\).     DefinitionThe distinguisher built from a forger#✓fully proved

    Cslib.Crypto.PRF.macReduction

    For a list \(L\) of messages in \(M\) and a forger \(c\), an adaptive oracle algorithm with queries in \(M\), answers in \(T\) and output in \(M \times T\), the MAC reduction is the oracle algorithm with the same queries and answers and a Boolean output, defined by recursion on \(c\). If \(c\) stops with output \((m, t)\), it queries \(m\) and, on answer \(t'\), stops with output true exactly when \(t' = t\) and \(m \notin L\). If \(c\) queries \(x\) and continues with \(c_y\) on answer \(y\), it queries \(x\) and, on answer \(y\), continues as the MAC reduction of \(c_y\) with \(x\) added to \(L\).

    Started with the empty list, it runs the forger, logging its queries, then queries the forged message and accepts when the answer is the forged tag and the message is fresh.

    def macReduction (log : List M) : OracleComp M T (M × T) → OracleComp M T Bool
  | .pure p => query p.1 fun t => done (decide (t = p.2 ∧ p.1 ∉ log))
  | .liftBind x k => query x fun y => macReduction (x :: log) (k y)
    abbrev OracleComp (X : Type u) (Y : Type v) (α : Type w) : Type (max u v w) :=
  (OracleSig X Y).FreeM α

    TheoremThe MAC from a PRF, concrete security#✓fully proved

    Cslib.Crypto.PRF.macGame_le

    Let \(K\), \(M\), \(T\) and \(R\) be finite types with \(K\), \(T\) and \(R\) nonempty, let \(F \colon K \to M \to T\) be a keyed function, and let \(A\) be an adaptive chosen-message forger: for coins \(r \in R\), \(A(r)\) is an adaptive oracle algorithm with queries in \(M\), answers in \(T\) and output in \(M \times T\).     Cslib.Crypto.PRF.cpaAdvantage_le

    Let \(K\), \(X\) and \(R\) be nonempty finite sets, \(Y\) a finite additive commutative group, \(q\) a natural number and \(F \colon K \to X \to Y\) a keyed function, used in the scheme \(\mathrm{Enc}_k(m) = (r, F_k(r) + m)\) with uniform randomness \(r \in X\). For every CPA adversary \(A\) with coins in \(R\), the CPA advantage of \(A\) in the experiment whose encryption oracle answers at most \(q\) queries is at most the PRF advantage of \(F\) against the distinguisher built from \(A\) plus \(q / (2 |X|)\).

    This is the reduction of Katz and Lindell, Theorem 3.31, with the sharper statistical term \(q / (2 |X|)\) in place of \(q / |X|\).

    theorem cpaAdvantage_le (F : K → X → Y) (A : CPAAdversary X Y R) :
