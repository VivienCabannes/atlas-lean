    Encryption from hard-core predicates

    Goldreich's general form of probabilistic encryption (Foundations of Cryptography, Vol. II, Construction 5.3.13): from a collection of trapdoor permutations \(p_\alpha\) with a hard-core predicate \(b\), encrypt a bit \(\sigma\) as \((p_\alpha(r), \sigma \oplus b(r))\) for a uniform \(r\) in the domain; the owner of the trapdoor inverts \(p_\alpha\) and recovers \(\sigma\). If \(b\) is hard-core, encryptions of \(0\) and \(1\) cannot be told apart (Proposition 5.3.14); with the Goldreich–Levin theorem, which gives every one-way permutation a hard-core predicate, this yields public-key encryption from any trapdoor permutation (Theorem 5.3.15).

    Here the construction is formalized for one key distribution and a finite domain. The security theorem is per adversary: the advantage of any distinguisher between encryptions of \(0\) and \(1\) is exactly twice the prediction advantage of a predictor that calls it once, which carries over to efficient adversaries. The all-predictor forms ("if every predictor wins with probability at most \(\tfrac12 + \varepsilon\), then …") are also proved but are vacuous in this concrete model: an unbounded predictor inverts \(p_\alpha\) and always wins, so their hypothesis forces \(\varepsilon \ge \tfrac12\).

    The scheme

    DefinitionEncryption of one bit with a hard-core predicate#✓fully proved

    Cslib.Crypto.PublicKey.HardCoreEncryption.scheme

    Let key pairs \((\alpha, \tau)\) be drawn from a distribution, let \(p_\alpha\) be a permutation of a finite nonempty domain \(D\), let \(\mathrm{inv}_\tau\) be a function on \(D\) (the trapdoor inverse) and let \(b_\alpha\) be a predicate on \(D\). The public key is \(\alpha\) and the secret key is \((\alpha, \tau)\). A bit \(\sigma\) is encrypted as \((p_\alpha(r), \sigma \oplus b_\alpha(r))\) for a uniform \(r \in D\), and a ciphertext \((y, \varsigma)\) is decrypted as \(\varsigma \oplus b_\alpha(\mathrm{inv}_\tau(y))\).

    noncomputable def scheme (gen : PMF (I × T)) (p : I → D ≃ D) (inv : T → D → D)
    (b : I → D → Bool) : PKEScheme Bool I (I × T) (D × Bool) where
  gen := gen.map fun k => (k.1, k)
  enc α σ := (uniformOfFintype D).map fun r => (p α r, xor σ (b α r))
  dec k c := some (xor c.2 (b k.1 (inv k.2 c.1)))

    DefinitionThe hard-core experiment, distinguishing form#✓fully proved

    Cslib.Crypto.PublicKey.HardCoreEncryption.hcExp

    Draw a key pair \((\alpha, \tau)\), coins \(r\) and a uniform \(x \in D\). The distinguisher receives \(\alpha\), \(p_\alpha(x)\) and the bit \(b_\alpha(x)\) (world \(0\)) or its complement (world \(1\)), and the experiment outputs its answer.

    (A : I → D × Bool → R → Bool) (c : Bool) : PMF Bool :=
  gen.bind fun k => coins.bind fun r =>
    (uniformOfFintype D).map fun x => A k.1 (p k.1 x, xor c (b k.1 x)) r

    DefinitionThe hard-core prediction experiment#✓fully proved

    Cslib.Crypto.PublicKey.HardCoreEncryption.predictGame

    Draw a key pair \((\alpha, \tau)\), coins \(r\) and a uniform \(x \in D\); the predictor receives \(\alpha\) and \(p_\alpha(x)\) and wins when its output equals \(b_\alpha(x)\).   gen.bind fun k => coins.bind fun r =>
    (uniformOfFintype D).map fun x => P k.1 (p k.1 x) r == b k.1 x

    From a distinguisher \(A\): on \(\alpha\), \(y\) and coins \((r, c)\) with \(c\) a bit, run \(A\) on \((y, c)\) and output \(c\) if \(A\) answers \(1\), and the complement of \(c\) otherwise.

    Cslib.Crypto.PublicKey.HardCoreEncryption.winProb_inner

    Fix the key, the distinguisher's coins and the permutation. With a fair bit \(c\) and a uniform \(x\), the predictor built from \(A\) outputs \(b(x)\) with probability \(\tfrac12 + \tfrac12 \bigl(\Pr_x[A(p(x), b(x)) = 1] - \Pr_x[A(p(x), \lnot b(x)) = 1]\bigr)\).         predictor A α (q x) (r, c) == bα x) =
      1 / 2 + (winProb ((uniformOfFintype D).map fun x => A α (q x, xor false (bα x)) r) -
        winProb ((uniformOfFintype D).map fun x => A α (q x, xor true (bα x)) r)) / 2

    TheoremDistinguishing implies predicting#✓fully proved

    Cslib.Crypto.PublicKey.HardCoreEncryption.winProb_predictGame_predictor

    For every distinguisher \(A\), the predictor built from \(A\), with its coins, wins the prediction experiment with probability $\(\tfrac12 + \tfrac12 \bigl(\Pr[A = 1 \text{ in world } 0] - \Pr[A = 1 \text{ in world } 1]\bigr),\)$ the probabilities being those of the hard-core experiment. This exact identity is the step that Goldreich's proof of Proposition 5.3.14 obtains "analogously to the second proof of Theorem 3.4.1" (of his Volume I, not consulted here).

    theorem winProb_predictGame_predictor (gen : PMF (I × T)) (p : I → D ≃ D) (b : I → D → Bool)
    (coins : PMF R) (A : I → D × Bool → R → Bool) :
    winProb (predictGame gen p b (coins.bind fun r => fairCoin.map fun c => (r, c))
        (predictor A)) =
      1 / 2 +
        (winProb (hcExp gen p b coins A false) - winProb (hcExp gen p b coins A true)) / 2
    noncomputable def winProb (G : PMF Bool) : ℝ := (G true).toReal

    Cslib.Crypto.PublicKey.HardCoreEncryption.indAdvantage_eq_two_mul_predictAdvantage
