    Cslib.Algorithms.Lean.Deque

    A deque with elements in a type \(\alpha\) consists of two lists of elements of \(\alpha\), the front list and the back list. The front list holds the front part of the sequence in order and the back list holds the back part in reverse order.

    structure Deque (α : Type u) where
  front : List α
  back : List α

    DefinitionPop the front of a deque#✓fully proved

    Cslib.Algorithms.Lean.Deque.popFront

    Let \(d\) be a deque with front list \(f\) and back list \(b\), where \(b\) is stored in reverse order. If \(f\) has first element \(v\) and remaining list \(f'\), popping the front of \(d\) returns \(v\) together with the deque with front list \(f'\) and back list \(b\). If \(f\) is empty and the reverse of \(b\) has first element \(v\) and remaining list \(r\), it returns \(v\) together with the deque with front list \(r\) and empty back list. If both lists are empty, it returns no result.

    def popFront : Deque α → Option (α × Deque α)
  | ⟨value :: front', back⟩ => some (value, ⟨front', back⟩)
  | ⟨[], back⟩ =>
      match back.reverse with
      | [] => none
      | value :: rest => some (value, ⟨rest, []⟩)
    structure Deque (α : Type u) where
