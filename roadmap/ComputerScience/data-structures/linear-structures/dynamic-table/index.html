    DefinitionWell-formed dynamic table#✓fully proved

    Cslib.Algorithms.Lean.DynamicTable.WellFormed

    A dynamic table with slots \(s_0, \dots, s_{m-1}\) and item count \(n\) is well formed when, for every \(i < m\), slot \(s_i\) is occupied if and only if \(i < n\); that is, the occupied slots are exactly the first \(n\).

    The items held in the occupied slots are not constrained.

    public def WellFormed {α : Type u} (T : Table α) : Prop :=
  ∀ (i : Nat) (h : i < T.slots.size), (T.slots[i]).isSome ↔ i < T.num

    Cslib.Algorithms.Lean.DynamicTable.contents

    Let \(T\) be a dynamic table with slots \(s_0, \dots, s_{m-1}\), each empty or holding an item, and item count \(n \le m\). The contents of \(T\) is the array of the items held by the occupied slots among \(s_0, \dots, s_{n-1}\), in order; empty slots in this prefix are skipped.

    The insertion procedure never consults the contents.

    public def contents {α : Type u} (T : Table α) : Array α :=
  (T.slots.extract 0 T.num).filterMap id

    DefinitionTABLE-INSERT#✓fully proved

    Cslib.Algorithms.Lean.DynamicTable.tableInsert

    Let \(T\) be a dynamic table with slots \(s_0, \dots, s_{m-1}\) and item count \(n \le m\), and let \(x\) be an item. Inserting \(x\) into \(T\) proceeds as follows. If \(m = 0\), first replace the slots by a single empty slot. Then, if the table is full, that is, \(n\) equals the current capacity \(c\), allocate \(2c\) empty slots and copy the \(c\) old slots into the first \(c\) of them, at cost \(1\) per copied slot. Finally write \(x\) into slot \(n\), at cost \(1\), and set the item count to \(n + 1\). The result is the new table together with the total cost.

    Given a dynamic table \(T\) and an array \(x_0, \dots, x_{k-1}\) of items, the result of inserting the array into \(T\) is obtained by starting from \(T\) and inserting \(x_0, x_1, \dots, x_{k-1}\) one at a time with TABLE-INSERT, in array order.     TheoremAmortized cost of dynamic-table insertion#✓fully proved

    Cslib.Algorithms.Lean.DynamicTable.tableInsert_amortized

    For a dynamic table \(T\) with item count \(n\) and capacity (number of slots) \(m\), let \(\Phi(T) = 2n - m\), an integer that may be negative. If inserting an item \(x\) into \(T\) has cost \(c\) and returns the table \(T'\), then \(c + \Phi(T') - \Phi(T) \le 3\). Here the cost of an insertion is one unit for writing \(x\) plus one unit for each old slot copied when a full table is doubled.

    public theorem tableInsert_amortized {α : Type u} (T : Table α) (x : α) :
    ((tableInsert T x).time : Int) +
      (2 * ((tableInsert T x).ret.num : Int) - ((tableInsert T x).ret.slots.size : Int)) -
      (2 * (T.num : Int) - (T.slots.size : Int)) ≤ 3
    public structure Table (α : Type u) where
  slots : Array (Option α)
  num : Nat
  num_le : num ≤ slots.size
