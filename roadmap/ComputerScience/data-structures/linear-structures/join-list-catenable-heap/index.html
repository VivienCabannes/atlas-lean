    Cslib.Algorithms.Lean.CatenableHeap

    A catenable heap over a type \(\alpha\) is a persistent unsorted heap, represented as a join list (catenation tree): it is either the empty heap, an element of \(\alpha\) added in front of a catenable heap, or the join of two catenable heaps.

    inductive CatenableHeap (α : Type u) : Type u where
  /-- The empty heap. -/
  | empty : CatenableHeap α
  /-- The heap with `head` added in front of `tail`. -/
  | cons (head : α) (tail : CatenableHeap α) : CatenableHeap α
  /-- The join of two heaps, with the elements of `left` before those of `right`. -/
  | join (left right : CatenableHeap α) : CatenableHeap α

    DefinitionNaive flattening of a catenable heap#✓fully proved

    Cslib.Algorithms.Lean.CatenableHeap.toListNaive

    The naive flattening of a catenable heap is defined by recursion: the empty heap flattens to the empty list, the heap with an element \(x\) added in front of a heap \(t\) flattens to \(x\) followed by the naive flattening of \(t\), and the join of heaps \(l\) and \(r\) flattens to the naive flattening of \(l\) followed by that of \(r\).

    It is the reference against which the accumulating flattening is checked.

    def toListNaive : CatenableHeap α → List α
  | empty => []
  | cons head tail => head :: toListNaive tail
  | join left right => toListNaive left ++ toListNaive right

    DefinitionAccumulating flattening of a catenable heap#✓fully proved

    Cslib.Algorithms.Lean.CatenableHeap.toListAux

    Given a catenable heap \(h\) and a list \(s\), the accumulating flattening of \(h\) onto \(s\) is defined by recursion on \(h\): for the empty heap it is \(s\); for the heap with an element \(x\) added in front of a heap \(t\) it is \(x\) followed by the accumulating flattening of \(t\) onto \(s\); for the join of heaps \(l\) and \(r\) it is the accumulating flattening of \(l\) onto the accumulating flattening of \(r\) onto \(s\).

    Each node of \(h\) is visited once.

    def toListAux : CatenableHeap α → List α → List α
  | empty, acc => acc
  | cons head tail, acc => head :: toListAux tail acc
  | join left right, acc => toListAux left (toListAux right acc)
