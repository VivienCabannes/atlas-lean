    Cslib.Algorithms.Lean.LruCache

    For a type \(K\) of keys, a type \(V\) of values and a natural number \(c\), an LRU cache of capacity \(c\) is a list of key-value pairs in \(K \times V\), ordered from most to least recently used, whose keys are pairwise distinct and whose length is at most \(c\).

    public structure LruCache (K : Type u) (V : Type v) (cap : Nat) where
  /-- The stored key-value pairs, most recently used first. -/
  entries : List (K × V)
  /-- Keys are pairwise distinct. -/
  nodup_keys : (entries.map Prod.fst).Nodup
  /-- The cache holds at most `cap` entries. -/
  length_le : entries.length ≤ cap
      entries : List (K × V)

    Cslib.Algorithms.Lean.LruCache.eraseKey

    Given a key \(k\) and a list of key–value pairs, erasing \(k\) deletes every pair whose key is \(k\) and keeps the other pairs in their original order. When the keys in the list are pairwise distinct, at most one pair is deleted.

    def eraseKey {K : Type u} {V : Type v} [DecidableEq K] (k : K)
    (entries : List (K × V)) : List (K × V) :=
  entries.filter fun p => decide (p.1 ≠ k)

    Cslib.Algorithms.Lean.LruCache.get

    Looking up a key \(k\) in an LRU cache returns an optional value together with a cache. If the cache stores a binding \((k, v)\), the result is \(v\) together with the cache in which that binding is moved to the front and the other entries keep their order; otherwise the result is no value together with the unchanged cache.

    (cache : LruCache K V cap) (k : K) : Option V × LruCache K V cap :=
  match hf : cache.entries.find? (fun q => decide (q.1 = k)) with

        ⟨p :: eraseKey k cache.entries,
         nodup_keys_cons_eraseKey cache.nodup_keys (fst_of_find?_eq_some hf),

             exact List.mem_of_find?_eq_some hf
           have hlen := length_eraseKey_add_one hmem cache.nodup_keys
           have hle := cache.length_le
           simp only [List.length_cons]
           omega⟩)
  | none => (none, cache)

    DefinitionInsertion into an LRU cache#✓fully proved

    Cslib.Algorithms.Lean.LruCache.put

    Putting the binding \((k, v)\) into an LRU cache of capacity \(c\) removes any entry with key \(k\), places \((k, v)\) at the front as the most recently used entry, and then keeps only the first \(c\) entries, so the least recently used entries beyond the capacity are evicted.

    public def put {K : Type u} {V : Type v} {cap : Nat} [DecidableEq K]
    (cache : LruCache K V cap) (k : K) (v : V) : LruCache K V cap where
  entries := ((k, v) :: eraseKey k cache.entries).take cap
  nodup_keys := by
    rw [List.map_take]
    exact (nodup_keys_cons_eraseKey cache.nodup_keys rfl).sublist
      (List.take_sublist cap _)
  length_le := by
    rw [List.length_take]
    exact Nat.min_le_left cap _
