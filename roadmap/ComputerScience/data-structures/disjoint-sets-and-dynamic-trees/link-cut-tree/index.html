    Cslib.Algorithms.Lean.LinkCutTree.Adjacent

    Two vertices \(a\) and \(b\) are adjacent in a rooted tree \(t\) when they are joined by a parent-child edge of \(t\) in either direction: some node of \(t\) labelled \(a\) has a child labelled \(b\), or some node of \(t\) labelled \(b\) has a child labelled \(a\).

    This is the undirected edge relation that the structural operations of the link-cut tree are specified against.

    public def Adjacent (a b : V) : Tree V → Prop
  | .node r cs =>
      (r = a ∧ ∃ c ∈ cs, c.root = b) ∨ (r = b ∧ ∃ c ∈ cs, c.root = a) ∨
        AdjacentList a b cs

    Cslib.Algorithms.Lean.LinkCutTree.adjacentB

    For vertices \(a\), \(b\) and a rooted tree \(t\) with root \(r\) and child subtrees \(c_1, \dots, c_k\), the adjacency test of \(a\) and \(b\) in \(t\) returns true exactly when \(r = a\) and some \(c_i\) has root \(b\), or \(r = b\) and some \(c_i\) has root \(a\), or the adjacency test of \(a\) and \(b\) returns true in some \(c_i\).

    It returns true exactly when \(a\) and \(b\) are adjacent in \(t\), and it is the guard checked by the edge cut before it cuts.

    public def adjacentB (a b : V) : Tree V → Bool

        (decide (r = b) && cs.any (fun c => decide (c.root = a))) ||
        adjacentBList a b cs

    Cslib.Algorithms.Lean.LinkCutTree.graftAt

    For a vertex \(y\) and trees \(N\) and \(T\), grafting \(N\) at \(y\) in \(T\) attaches \(N\) as a new last child of the first node of \(T\) labelled \(y\) in preorder, keeping every existing node and edge; it returns nothing when \(y\) does not occur in \(T\). This is the tree surgery behind linking two trees: it adds exactly the edge from \(y\) to the root of \(N\).

    public def graftAt (y : V) (newChild : Tree V) : Tree V → Option (Tree V)
  | .node r cs =>
      if r = y then some (.node r (cs ++ [newChild]))
      else (graftAtList y newChild cs).map (.node r)
where
  graftAtList (y : V) (newChild : Tree V) :
      List (Tree V) → Option (List (Tree V))
    | [] => none
    | c :: cs =>
        match graftAt y newChild c with
        | some c' => some (c' :: cs)
        | none => (graftAtList y newChild cs).map (c :: ·)
