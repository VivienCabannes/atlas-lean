    DefinitionAccumulator preorder traversal#✓fully proved

    Cslib.Algorithms.Lean.EulerTourTree.Tree.verticesAux

    For a rooted ordered tree \(t\) with root \(r\) and child subtrees \(c_1, \dots, c_k\) (in order) and a list \(a\), the accumulator traversal \(T(t, a)\) is the list whose first entry is \(r\) and whose remaining entries are \(T(c_1, T(c_2, \dots, T(c_k, a) \dots))\); when \(k = 0\) the remaining entries are \(a\).

    The list \(T(t, a)\) equals the preorder vertex list of \(t\) followed by \(a\), so the preorder list is computed in linear time rather than by repeatedly appending child lists.

    def verticesAux : Tree V → List V → List V
  | .node r cs, acc => r :: cs.foldr (fun c acc => verticesAux c acc) acc
    inductive Tree (V : Type u) where
  | node (root : V) (children : List (Tree V)) : Tree V

    DefinitionEuler tour with an accumulator#✓fully proved

    Cslib.Algorithms.Lean.EulerTourTree.Tree.tourAux

    Let \(t\) be a tree with root \(r\) and child subtrees \(c_1, \dots, c_k\) in order, and let \(a\) be a list of vertices. For a list \(L\) of vertices, write \(r \cdot L\) for the list \(L\) with \(r\) put in front. The Euler tour of \(t\) with accumulator \(a\), written \(T(t, a)\), is \(r \cdot L_1\), where \(L_{k+1} = a\) and \(L_i = T(c_i, r \cdot L_{i+1})\) for \(i = k, \dots, 1\).

    It equals the Euler tour of \(t\) followed by \(a\), and computes the Euler tour without repeatedly concatenating the tours of the child subtrees.

    def tourAux : Tree V → List V → List V
  | .node r cs, acc =>
      r :: cs.foldr (fun c acc => tourAux c (r :: acc)) acc
    inductive Tree (V : Type u) where
  | node (root : V) (children : List (Tree V)) : Tree V
