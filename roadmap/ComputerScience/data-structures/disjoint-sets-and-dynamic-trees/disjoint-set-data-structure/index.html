    DefinitionUnion in a union-find forest#✓fully proved

    Cslib.Algorithms.Lean.UnionFind.union

    Let \(F\) be a union-find forest on \(n\) vertices: each vertex \(z\) has a parent \(p(z)\), where roots are their own parents, and a depth certificate \(d(z) \in \mathbb{N}\) with \(d(p(z)) < d(z)\) whenever \(p(z) \ne z\). Let \(x\) and \(y\) be vertices, and let \(r_x\) and \(r_y\) be the roots reached from \(x\) and \(y\) by following parent pointers. If \(r_x = r_y\), the union of \(x\) and \(y\) in \(F\) is \(F\) itself. Otherwise it is the forest obtained from \(F\) by linking \(r_x\) to \(r_y\): the parent of \(r_x\) becomes \(r_y\), all other parent pointers are unchanged, every vertex \(z\) whose root is \(r_x\) gets depth certificate \(d(z) + d(r_y) + 1\), and every other vertex keeps \(d(z)\).

    The operation is persistent: it returns a new forest and does not modify \(F\).

    public def union {n : Nat} (forest : Forest n) (x y : Fin n) : Forest n :=
  let fromRoot := find forest x
  let toRoot := find forest y
