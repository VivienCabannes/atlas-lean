    Cslib.Algorithms.Lean.FibonacciTree.Valid

    Let \(\alpha\) carry a relation \(\le\). A Fibonacci tree with stored degree \(d\), root \(r \in \alpha\) and list of children \(c\) is valid when every tree in \(c\) is valid, \(d\) equals the length of \(c\), and \(r \le x\) for every element \(x\) of the multiset represented by the tree (the root together with the elements of all children).

    DefinitionLinking two Fibonacci trees#✓fully proved

    Cslib.Algorithms.Lean.FibonacciTree.link

    Let \(s\) and \(t\) be Fibonacci trees over a linearly ordered type. If the root of \(s\) is at most the root of \(t\), the link of \(s\) and \(t\) is the tree with the root of \(s\), stored degree one more than that of \(s\), and children \(t\) followed by the children of \(s\). Otherwise it is the tree with the root of \(t\), stored degree one more than that of \(t\), and children \(s\) followed by the children of \(t\).

    @[expose] public def link [LinearOrder α] (left right : FibonacciTree α) : FibonacciTree α :=
  if left.root ≤ right.root then
    .node (left.degree + 1) left.root (right :: left.children)
  else
    .node (right.degree + 1) right.root (left :: right.children)
    public inductive FibonacciTree (α : Type u) where
  | node (degree : Nat) (root : α) (children : List (FibonacciTree α))
