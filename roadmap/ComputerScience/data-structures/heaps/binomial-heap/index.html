    InductiveValid binomial tree#✓fully proved

    Cslib.Algorithms.Lean.BinomialTree.Valid

    For a type \(\alpha\) with a relation \(\le\), validity of binomial trees over \(\alpha\) is defined inductively: the tree with stored rank \(r\), root \(a\) and list of children \(c_1, \dots, c_k\) is valid when every child \(c_i\) is valid, the ranks of \(c_1, \dots, c_k\) are exactly \(r - 1, r - 2, \dots, 0\) in this order, the multiset of elements of the tree (its root together with the elements of all its children) has exactly \(2^r\) members counted with multiplicity, and \(a \le x\) for every element \(x\) of the tree.

    public inductive Valid {α : Type u} [LE α] : BinomialTree α → Prop
  | node {rank : Nat} {root : α} {children : List (BinomialTree α)}
      (children_valid : ∀ child ∈ children, Valid child)
      (children_ranks : children.map BinomialTree.rank = (List.range rank).reverse)
      (card_elements : (elements (.node rank root children)).card = 2 ^ rank)
      (root_le : ∀ value ∈ elements (.node rank root children), root ≤ value) :
      Valid (.node rank root children)
    public inductive BinomialTree (α : Type u) where
  | node (rank : Nat) (root : α) (children : List (BinomialTree α))

    DefinitionLinking two binomial trees#✓fully proved

    Cslib.Algorithms.Lean.BinomialTree.link

    Over a linear order, the link of binomial trees \(s\) and \(t\) is defined as follows. If the root of \(s\) is at most the root of \(t\), it is the tree whose rank is one more than the rank of \(s\), whose root is the root of \(s\), and whose children are \(t\) followed by the children of \(s\). Otherwise it is the tree whose rank is one more than the rank of \(s\), whose root is the root of \(t\), and whose children are \(s\) followed by the children of \(t\). In particular, the root of \(s\) is kept when the two roots are equal.

    @[expose] public def link [LinearOrder α] (left right : BinomialTree α) : BinomialTree α :=
  if left.root ≤ right.root then
    .node (left.rank + 1) left.root (right :: left.children)
  else
    .node (left.rank + 1) right.root (left :: right.children)
    public inductive BinomialTree (α : Type u) where
  | node (rank : Nat) (root : α) (children : List (BinomialTree α))
