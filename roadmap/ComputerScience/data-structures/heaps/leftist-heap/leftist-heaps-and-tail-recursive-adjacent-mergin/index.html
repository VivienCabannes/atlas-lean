    def mergeAux [LinearOrder α] : Nat → LHeap α → LHeap α → LHeap α

    DefinitionTail-recursive adjacent merging with an accumulator#✓fully proved

    Cslib.Algorithms.Lean.LHeap.merge_adj2

    Tail-recursive merge_adj2 with accumulator, no use of List.append. Genuinely tail-recursive: uses an accumulator and reverse at base case. Does not use List.append (avoids append operator). Complexity model: only merge steps counted, so T_merge_adj2 acc ts = T_merge_adj ts should hold; accumulator reversal overhead is intentionally excluded per textbook convention that only merge calls are counted.

    def merge_adj2 [LinearOrder α] (acc : List (LHeap α)) (ts : List (LHeap α)) : List (LHeap α) :=
  match ts with
  | [] => acc.reverse
  | [t] => (t :: acc).reverse
  | t1 :: t2 :: ts' => merge_adj2 (t1.merge t2 :: acc) ts'
termination_by ts.length
    inductive LHeap (α : Type u) : Type u where
| E : LHeap α
| N : Nat → α → LHeap α → LHeap α → LHeap α
deriving DecidableEq
