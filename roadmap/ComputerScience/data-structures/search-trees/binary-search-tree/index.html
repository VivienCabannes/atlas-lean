    Cslib.Algorithms.Lean.BinarySearchTree.Mem

    A key \(x\) belongs to a binary tree \(T\) when it is the key of some node of \(T\): no key belongs to the empty tree, and \(x\) belongs to a node with key \(k\), left subtree \(L\) and right subtree \(R\) exactly when \(x\) belongs to \(L\), \(x = k\), or \(x\) belongs to \(R\).

    This membership does not use the search-tree ordering.

    public def Mem {α : Type u} (x : α) : BinaryTree α → Prop
  | .nil => False
  | .node key left right => Mem x left ∨ x = key ∨ Mem x right

    DefinitionInorder traversal of a binary tree with an accumulator#✓fully proved

    Cslib.Algorithms.Lean.BinarySearchTree.inorderAux

    For a binary tree \(t\) and a list \(s\), the accumulated traversal of the empty tree onto \(s\) is \(s\), and the accumulated traversal of a node with key \(k\), left subtree \(L\) and right subtree \(R\) onto \(s\) is the accumulated traversal of \(L\) onto the list consisting of \(k\) followed by the accumulated traversal of \(R\) onto \(s\).

    Unfolding the recursion, the result is the inorder traversal of \(t\) followed by \(s\).

    public def inorderAux {α : Type u} : BinaryTree α → List α → List α
  | .nil, suffix => suffix
  | .node key left right, suffix =>
      inorderAux left (key :: inorderAux right suffix)

    Cslib.Algorithms.Lean.BinarySearchTree.Ordered

    Let \(\alpha\) be a type with a relation \(<\). The empty tree is ordered, and a binary tree with root key \(k\), left subtree \(L\) and right subtree \(R\) is ordered when \(L\) and \(R\) are ordered, every key of \(L\) is less than \(k\), and \(k\) is less than every key of \(R\).

    public def Ordered {α : Type u} [LT α] : BinaryTree α → Prop

      Ordered left ∧ Ordered right ∧ All (· < key) left ∧ All (key < ·) right

    DefinitionSearch in a binary search tree#✓fully proved

    Cslib.Algorithms.Lean.BinarySearchTree.contains

    For a linearly ordered type \(\alpha\), a key \(x \in \alpha\) and a binary tree \(t\) with keys in \(\alpha\), the search for \(x\) in \(t\) returns a Boolean: false if \(t\) is empty, and if \(t\) is a node with key \(k\), left subtree \(L\) and right subtree \(R\), the search for \(x\) in \(L\) when \(x < k\), the search for \(x\) in \(R\) when \(k < x\), and true otherwise.

    Unlike the index of a key in a binary tree, which encodes the root-to-node path as a positive binary number, this search returns only whether the key was found.

    public def contains {α : Type u} [LinearOrder α] (x : α) : BinaryTree α → Bool
  | .nil => false
  | .node key left right =>
      if x < key then contains x left
      else if key < x then contains x right
      else true
