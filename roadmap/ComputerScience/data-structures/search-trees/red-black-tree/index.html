    The color erasure of a red-black tree is the binary tree obtained by forgetting the node colors: the empty tree goes to the empty binary tree, and a node with key \(k\) and subtrees \(l\) and \(r\) goes to the binary-tree node with key \(k\) whose subtrees are the color erasures of \(l\) and \(r\).

    DefinitionInorder traversal onto a suffix#✓fully proved

    Cslib.Algorithms.Lean.RedBlackTree.inorderAux

    For a red-black tree \(t\) and a list \(s\), this is the accumulator form of the binary-search-tree inorder traversal applied to the color erasure of \(t\): for the empty tree it returns \(s\), and for a node with key \(k\) and subtrees \(l\) and \(r\) it returns the result for \(l\) with suffix the list \(k\) followed by \(u\), where \(u\) is the result for \(r\) with suffix \(s\).
