    DefinitionAVL balance invariant#✓fully proved

    Cslib.Algorithms.Lean.AvlTree.Balanced

    The empty tree is balanced. A node with left subtree \(\ell\) and right subtree \(r\) is balanced when \(\ell\) and \(r\) are balanced and \(h(\ell) \le h(r) + 1\) and \(h(r) \le h(\ell) + 1\), where \(h\) denotes the height cached at the root of a tree (and \(0\) for the empty tree). Equivalently, at every node the balance factor \(h(\ell) - h(r)\) lies in \(\{-1, 0, 1\}\).

    public def Balanced : Tree α → Prop
  | .empty => True
  | .node _ left _ right =>
      Balanced left ∧ Balanced right ∧ height left ≤ height right + 1 ∧
        height right ≤ height left + 1
    public inductive Tree (α : Type u) where
  | empty : Tree α
  | node (height : Nat) (left : Tree α) (key : α) (right : Tree α) : Tree α
