    DefinitionValid skip list#✓fully proved

    Cslib.Algorithms.Lean.SkipList.Valid

    Let \(\alpha\) be a linearly ordered type. A skip list with keys in \(\alpha\) and values in \(\beta\) is valid when the keys of its bottom-level nodes are strictly increasing along the list and every node has a tower of positive height.

    public def Valid {α : Type u} {β : Type v} [LinearOrder α] (list : SkipList α β) : Prop :=

    DefinitionOne level of skip-list search#✓fully proved

    Cslib.Algorithms.Lean.SkipList.advanceAtLevel

    Let \(k\) be a search key, \(i\) a zero-based level and \(L\) a list of skip-list nodes. Let \(P\) be the longest prefix of \(L\) whose nodes all have keys less than \(k\). If some node of \(P\) has tower height greater than \(i\) (so it is visible at level \(i\)), advancing at level \(i\) returns the part of \(L\) after the last such node; otherwise it returns \(L\) unchanged.

    The returned suffix is the window that every lower level continues to scan.

    public def advanceAtLevel {α : Type u} {β : Type v} [LinearOrder α]
    (key : α) (index : Nat) (entries : List (Entry α β)) : List (Entry α β) :=
  (go entries).getD entries
where
  go : List (Entry α β) → Option (List (Entry α β))
    | [] => none
    | entry :: entries =>
        if entry.key < key then
          match go entries with
          | some suffix => some suffix
          | none => if index < entry.height then some entries else none
        else none
    public structure SkipList.Entry (α : Type u) (β : Type v) where
  key : α
  value : β
  height : Nat
deriving DecidableEq, Repr

    DefinitionSkip-list search window#✓fully proved

    Cslib.Algorithms.Lean.SkipList.searchWindow

    Let \(k\) be a key and let \(H\) be the greatest tower height in a skip list (\(H = 0\) if the list is empty or every tower has height \(0\)). Start with the full list of bottom-level nodes, and for each level \(i\) from \(H - 1\) down to \(0\) in turn (no levels when \(H = 0\)) replace the current list by the result of advancing at level \(i\): within the longest initial segment of the current list whose keys are all less than \(k\), take the last node whose tower height exceeds \(i\) and keep only the nodes after it, leaving the list unchanged if there is no such node. The search window for \(k\) is the list that remains after these steps.

    public def searchWindow {α : Type u} {β : Type v} [LinearOrder α]
    (key : α) (list : SkipList α β) : List (Entry α β) :=
  let maximumHeight :=
    list.entries.foldl (fun result entry => max result entry.height) 0
  go (List.range maximumHeight).reverse list.entries
where
  go : List Nat → List (Entry α β) → List (Entry α β)
    | [], entries => entries
    | index :: indices, entries =>
        go indices (advanceAtLevel key index entries)
    public structure SkipList (α : Type u) (β : Type v) where
  entries : List (SkipList.Entry α β)
deriving DecidableEq, Repr

    Cslib.Algorithms.Lean.SkipList.lookup

    The lookup of a key \(k\) in a skip list computes the search window for \(k\), the suffix of the bottom-level nodes reached by descending from the highest level to level \(0\), and returns the value of the first node in the window whose key is \(k\), or no value if the window has no such node.

    DefinitionSkip-list insertion#✓fully proved

    Cslib.Algorithms.Lean.SkipList.insert

    To insert key \(k\) with value \(v\) and requested height \(h\) into a skip list, scan its bottom-level nodes in order, keeping every node whose key is less than \(k\). At the first node whose key is not less than \(k\): if its key equals \(k\), its value is replaced by \(v\) and its tower height is kept; if its key is greater than \(k\), a new node with key \(k\), value \(v\) and tower height \(\max(1, h)\) is placed before it. If every key is less than \(k\), the new node is appended at the end.

    public def insert {α : Type u} {β : Type v} [LinearOrder α]
    (key : α) (value : β) (requestedHeight : Nat) (list : SkipList α β) : SkipList α β :=
  ⟨go list.entries⟩
where
  go : List (Entry α β) → List (Entry α β)
    | [] => [{ key, value, height := max 1 requestedHeight }]
    | entry :: entries =>
        if key < entry.key then
          { key, value, height := max 1 requestedHeight } :: entry :: entries
        else if entry.key < key then
          entry :: go entries
        else
          { entry with value := value } :: entries
    public structure SkipList (α : Type u) (β : Type v) where
  entries : List (SkipList.Entry α β)
deriving DecidableEq, Repr
