    Analysis of linear probing

    Knuth's analysis of hashing with linear probing (1963), his first analysis of an algorithm. Items are entered into a cyclic table of \(N\) cells, each into the first empty cell at or after its hash address, and all \(N^k\) hash sequences are equally likely. The quantities are the mean number of probes of an insertion (equivalently of an unsuccessful search), \(M(N, k)\), and of a successful search, \(T(N, k)\): exact formulas for finite \(N\) first, then their limits at a fixed load factor \(\alpha < 1\).

    Cslib.Algorithms.Lean.LinearProbing.displacementAux

    Let \(S\) be the set of occupied cells of a cyclic table of \(N\) cells \(0, \dots, N - 1\). Starting at cell \(h\), this counts the consecutive occupied cells \(h, h + 1, h + 2, \dots\) (indices modulo \(N\)) met before the first empty cell, examining at most a given number of cells (the budget). The recursion is on the budget; the displacement uses the budget \(N\).

  | _, 0 => 0
  | h, fuel + 1 => if h ∈ S then displacementAux S (finRotate N h) (fuel) + 1 else 0

    DefinitionDisplacement of a linear-probing insertion#✓fully proved

    Cslib.Algorithms.Lean.LinearProbing.displacement

    In a cyclic table of \(N\) cells whose occupied cells form \(S\), the displacement of an item with hash address \(h\) is the number of occupied cells \(h, h + 1, \dots\) (indices modulo \(N\)) that it passes over before it reaches an empty cell. It is computed by the scan with a probe budget with budget \(N\), so it is at most \(N\). When the table is not full it is the distance from \(h\) to the first empty cell.

    def displacement (S : Finset (Fin N)) (h : Fin N) : ℕ :=
  displacementAux S h N

    Cslib.Algorithms.Lean.LinearProbing.probes

    The number of probes of an insertion with hash address \(h\) into a cyclic table whose occupied cells form \(S\) is its displacement plus one. In Knuth's 1963 description of the algorithm, it is the number of times the comparison step "if \(x_j = 0\), set \(x_j = 1\) and stop" is executed: once for each occupied cell passed over, and once for the empty cell that receives the item.

    TheoremLinear probing commutes with rotations of the table#✓fully proved

    Cslib.Algorithms.Lean.LinearProbing.occupancy_map_rotate

    Rotate every hash address of a sequence by \(j\) cells, \(a_i \mapsto a_i + j \bmod N\). Then the occupied cells after linear probing are those of the original sequence rotated by \(j\) cells. Linear probing treats all cells of the cyclic table alike; this is the "circular symmetry" on which Knuth's 1963 proof of Lemma 1 and the 1998 analysis of linear probing rest.

    theorem occupancy_map_rotate (j : ℕ) (l : List (Fin N)) :
    occupancy (l.map (finRotate N ^ j)) = (occupancy l).image (finRotate N ^ j)
    def occupancy (l : List (Fin N)) : Finset (Fin N) :=
  l.foldl (fun S h => insert (insertCell S h) S) ∅

    Exact results

    TheoremRotational symmetry of linear probing#✓fully proved

    Cslib.Algorithms.Lean.LinearProbing.mul_card_not_mem_occupancy

    Let \(n \le N\) and let \(c\) be a cell of a cyclic table of \(N\) cells. Then

    \[N \cdot \#\{a \in \{0, \dots, N-1\}^n : \text{linear probing with } a \text{ leaves } c \text{ empty}\} = (N - n)\, N^n .\]

    Rotating the hash addresses is a bijection between the sequences that leave \(c\) empty and those that leave any other cell empty, so every cell is left empty by the same number of sequences. Each sequence leaves exactly \(N - n\) cells empty, since its \(n\) items occupy \(n\) cells. Summing over the \(N\) cells gives the identity. This is the circle argument of Knuth's 1963 proof of Lemma 1 and of Section 1 of his 1998 paper.

    theorem mul_card_not_mem_occupancy {n : ℕ} (hn : n ≤ N) (c : Fin N) :
    N * (Finset.univ.filter fun a : Fin n → Fin N => c ∉ occupancy (List.ofFn a)).card =
      (N - n) * N ^ n
    def occupancy (l : List (Fin N)) : Finset (Fin N) :=
  l.foldl (fun S h => insert (insertCell S h) S) ∅

    TheoremNumber of hash sequences that leave a given cell empty#✓fully proved

    Cslib.Algorithms.Lean.LinearProbing.card_not_mem_occupancy

    Let \(1 \le n \le N\) and let \(c\) be a cell of a cyclic table of \(N\) cells. Exactly \((N - n)\,N^{n-1}\) of the \(N^n\) hash sequences of \(n\) items leave \(c\) empty after linear probing, a fraction \((N - n)/N\). For \(N = 3\) and \(n = 2\), three of the nine sequences leave cell \(0\) empty; the Lean tests check this by enumeration.

    Knuth's 1998 paper states it for cell \(0\): "exactly \((m - n)/m\) of them will be confined". With \(N = n' + 1\) cells and \(c\) the last cell, a sequence leaving \(c\) empty never wraps around, so this is also Knuth's 1963 count of non-overflow sequences on \(n'\) cells; the graph proves that count separately, through Pollak's count of partial parking functions.

    theorem card_not_mem_occupancy {n : ℕ} (hn₁ : 1 ≤ n) (hn : n ≤ N) (c : Fin N) :
    (Finset.univ.filter fun a : Fin n → Fin N => c ∉ occupancy (List.ofFn a)).card =
      (N - n) * N ^ (n - 1)
    def occupancy (l : List (Fin N)) : Finset (Fin N) :=
  l.foldl (fun S h => insert (insertCell S h) S) ∅

    TheoremNumber of hash sequences without overflow#✓fully proved

    Cslib.Algorithms.Lean.LinearProbing.card_linSuccess

    Let \(0 < k \le n\). The number of hash sequences \(f : \{0, \dots, k-1\} \to \{0, \dots, n-1\}\) for which linear probing without wrap-around places all \(k\) items in a table of \(n\) cells (without overflow) is

    \[(n + 1 - k)(n + 1)^{k - 1}.\]

    This is Lemma 1 of Knuth's 1963 note, which writes the count as \((n+1)^k - k(n+1)^{k-1}\). His lemma holds for \(0 \le k \le n + 1\); the cases \(k = 0\) (one sequence) and \(k = n + 1\) (none) are not part of the Lean statement. For \(k = n\) the count \((n+1)^{n-1}\) is the number of parking functions of length \(n\).

    Knuth's proof is the circle argument: run the cyclic algorithm on \(n + 1\) cells; by rotational symmetry each cell is left empty by exactly a fraction \((n + 1 - k)/(n + 1)\) of the \((n+1)^k\) sequences, and the sequences leaving the last cell empty are exactly the non-overflow sequences on \(n\) cells. The Lean proof transfers Pollak's count of partial parking functions, which is proved by the same circle argument, along the equivalence between non-overflow sequences and partial parking functions. For the cyclic model of this topic the circle argument is proved directly, as rotational symmetry of linear probing and the number of sequences that leave a given cell empty.

    theorem card_linSuccess (k n : ℕ) (hk : 0 < k) (hkn : k ≤ n) :
    Nat.card {f : Fin k → Fin n // LinSuccess k n f} = (n + 1 - k) * (n + 1) ^ (k - 1)
    def LinSuccess (s t : ℕ) (f : Fin s → Fin t) : Prop :=
  (linOccAux s t f s).isSome

    DefinitionExpected cost of a linear-probing insertion#✓fully proved

    Cslib.Algorithms.Lean.LinearProbing.insertionCost

    Let \(N\) and \(n\) be natural numbers. Consider all \(N^{n+1}\) hash sequences \(a_1, \dots, a_{n+1}\) with values in the \(N\) cells of a cyclic table, each equally likely. For each of them, enter the first \(n\) items by linear probing and count the probes made by the last one. The expected cost is the average of this count, a rational number.

    This is \(M(N, n + 1)\) in Knuth's 1963 note, the mean number of comparisons needed to place the \((n+1)\)-th item. An unsuccessful search for a key whose hash address is \(a_{n+1}\) scans exactly the same cells (it stops at the first empty cell), so this is also the expected cost of an unsuccessful search in a table holding \(n\) items.

    The definition makes sense for every \(N\) and \(n\); the results about it assume \(n < N\), so that the table is not full.

    def insertionCost (N n : ℕ) : ℚ :=
  (∑ a : Fin n → Fin N, ∑ h : Fin N, (probes (occupancy (List.ofFn a)) h : ℚ)) /
    (N : ℚ) ^ (n + 1)
    def probes (S : Finset (Fin N)) (h : Fin N) : ℕ :=
  displacement S h + 1

    DefinitionExpected cost of a successful linear-probing search#✓fully proved

    Cslib.Algorithms.Lean.LinearProbing.successfulSearchCost

    For a table of \(N\) cells built from \(n\) uniformly random hash addresses, this is \(T(N, n) = \frac{1}{n} \sum_{i=0}^{n-1} M(N, i + 1)\), the average over the stored items of the expected cost of their insertion. Knuth's 1963 note (Section 7) observes that a search for an item makes as many comparisons as its insertion did, so this is the expected number of probes of a successful search for a uniformly chosen stored item. The definition takes that observation as the model; it does not formalize the search procedure itself.

    DefinitionKnuth's auxiliary sums for linear probing#✓fully proved

    Cslib.Algorithms.Lean.LinearProbing.knuthE

    For natural numbers \(r\), \(N\) and \(k\),

    \[E_r(N, k) = \sum_{j=0}^{k-1} \binom{r + j}{r} \frac{(k-1)(k-2)\cdots(k-j)}{N^j} = 1 + \binom{r+1}{r}\frac{k-1}{N} + \binom{r+2}{r}\frac{(k-1)(k-2)}{N^2} + \cdots,\]

    the sums in which Knuth's 1963 note expresses the exact mean costs of linear probing. For \(k = 0\) the sum is empty and equals \(0\). Writing \(\alpha = (k-1)/N\), each term is at most \(\binom{r+j}{r}\alpha^j\), so \(E_r(N, k) \le (1-\alpha)^{-(r+1)}\) when \(\alpha < 1\); this is the approximation of Section 8 of the note.

    def knuthE (r N k : ℕ) : ℚ :=
  ∑ j ∈ Finset.range k, ((r + j).choose r * (k - 1).descFactorial j : ℚ) / (N : ℚ) ^ j

    TheoremKnuth's exact mean insertion cost for linear probing#●ready to prove

    Cslib.Algorithms.Lean.LinearProbing.insertionCost_eq

    Let \(1 \le k \le N\). Enter \(k\) items into a cyclic table of \(N\) cells by linear probing, with independent uniform hash addresses. The expected number of probes made by the \(k\)-th item is

    \[M(N, k) = \frac{1}{2}\bigl(1 + E_1(N, k)\bigr), \qquad E_1(N, k) = \sum_{j=0}^{k-1} (j + 1)\frac{(k-1)(k-2)\cdots(k-j)}{N^j},\]

    with \(E_1\) one of Knuth's auxiliary sums. This is Theorem 2 of Knuth's 1963 note, first form. For example \(M(5, 4) = 257/125\), an entry of the note's table for \(N = 5\). The Lean statement indexes the cost by the number \(k - 1\) of items already present.

    This is a wanted statement: the proof (through the probability \(P(N, k, m)\) that the \(k\)-th item needs \(m\) comparisons, Theorem 1 of the note, and Abel's generalized binomial theorem) is not formalized. The Lean tests verify the instance \(N = 5\), \(k = 4\).

    Asymptotics at a fixed load factor

    TheoremLimit of Knuth's sums at a fixed load factor#✓fully proved

    Cslib.Algorithms.Lean.LinearProbing.tendsto_knuthE

    Let \(r\) be a natural number and \(0 \le \alpha < 1\). If \(n_N / N \to \alpha\) as \(N \to \infty\), then Knuth's sums satisfy

    \[E_r(N, n_N + 1) \longrightarrow \frac{1}{(1 - \alpha)^{r+1}} = \sum_{j \ge 0} \binom{r + j}{r}\alpha^j .\]

    This is the claim of Section 8 of Knuth's 1963 note that the approximation \(E_r(N, k) \approx (1-\alpha)^{-(r+1)}\), with \(\alpha = (k-1)/N\), becomes exact as \(N \to \infty\) for fixed \(\alpha\). The proof is dominated convergence for series (Tannery's theorem): the \(j\)-th term \(\binom{r+j}{r}\prod_{i<j}(n_N - i)/N\) tends to \(\binom{r+j}{r}\alpha^j\) and is eventually bounded by \(\binom{r+j}{r}\beta^j\) for a fixed \(\beta\) with \(\alpha < \beta < 1\). The Lean tests apply it to a half-full table, \(n_N = \lfloor N/2 \rfloor\) and \(\alpha = 1/2\), where \(E_1 \to 4\).

    With \(r = 1\) and \(r = 0\), this turns Knuth's exact formulas for insertions and for successful searches into the limits \(\frac12\bigl(1 + (1-\alpha)^{-2}\bigr)\) and \(\frac12\bigl(1 + (1-\alpha)^{-1}\bigr)\) stated in the unsuccessful-search limit and the successful-search limit.

    Let \(0 \le \alpha < 1\), and let a cyclic table of \(N\) cells hold \(n_N\) items, where \(1 \le n_N \le N\) for all large \(N\) and \(n_N / N \to \alpha\). Then the average cost of a successful search satisfies
