    DefinitionUniversal hash family#✓fully proved

    Cslib.Algorithms.Lean.UniversalHashing.IsUniversal

    A finite family \(H\) of functions from a set \(\alpha\) to \(\{0, 1, \dots, m - 1\}\) is universal if \(m > 0\), \(H\) is nonempty, and for all distinct keys \(x \ne y\) in \(\alpha\) the number of functions \(h \in H\) with \(h(x) = h(y)\), multiplied by \(m\), is at most \(|H|\); that is, \(x\) and \(y\) collide under at most a \(1/m\) fraction of the members of \(H\).

    Nonemptiness makes sense of choosing a member of \(H\) uniformly at random, the reading behind the bound.

    public def IsUniversal (H : Finset (α → Fin m)) : Prop :=
  0 < m ∧ H.Nonempty ∧ ∀ x y : α, x ≠ y → collisionCount H x y * m ≤ H.card
    public def collisionCount (H : Finset (α → Fin m)) (x y : α) : Nat :=
  (H.filter fun h => h x = h y).card

    DefinitionIndexed universal hash family#✓fully proved

    Cslib.Algorithms.Lean.UniversalHashing.IsUniversalOn

    Let \(s\) be a finite set of indices from a type \(\iota\), and let \(h\) assign to each index \(i \in \iota\) a function \(h_i\) from a set \(\alpha\) to \(\{0, 1, \dots, m - 1\}\). The family \(h\) is universal on \(s\) if \(m > 0\), \(s\) is nonempty, and for all distinct keys \(x \ne y\) in \(\alpha\) the number of indices \(i \in s\) with \(h_i(x) = h_i(y)\), multiplied by \(m\), is at most \(|s|\).

    Each index is counted separately, even when two indices give the same function; this is the form in which the classical counting arguments, including the one for the mod-prime family, are carried out. Nonemptiness is required because there is no uniform random choice from an empty family.

    public def IsUniversalOn {ι : Type v} (s : Finset ι) (h : ι → α → Fin m) : Prop :=
  0 < m ∧ s.Nonempty ∧
    ∀ x y : α, x ≠ y → (s.filter fun i => h i x = h i y).card * m ≤ s.card

    Cslib.Algorithms.Lean.UniversalHashing.modPrimeHash

    For natural numbers \(p\) and \(m\) with \(m > 0\) and elements \(a, b\) of \(\mathbb{Z}/p\mathbb{Z}\), the mod-prime hash function \(h_{a,b} \colon \mathbb{Z}/p\mathbb{Z} \to \{0, \dots, m - 1\}\) is \(h_{a,b}(x) = \operatorname{val}(ax + b) \bmod m\), where \(ax + b\) is computed in \(\mathbb{Z}/p\mathbb{Z}\) and \(\operatorname{val}(z)\) is the canonical natural-number representative of \(z\) (the residue in \(\{0, \dots, p - 1\}\) when \(p > 0\), and \(|z|\) when \(p = 0\)).   ⟨(a * x + b).val % m, Nat.mod_lt _ hm⟩
