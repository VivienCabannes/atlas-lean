    StructureOpen-addressing hash table#✓fully proved

    Cslib.Algorithms.Lean.OpenAddressing

    Let \(K\) be a type of keys, \(V\) a type of values, \(m\) a natural number, and \(p\) a probe sequence assigning to each key \(k\) and each \(i \in \mathbb{N}\) a slot \(p(k, i) \in \{0, \dots, m - 1\}\). An open-addressing hash table with \(m\) slots and probe sequence \(p\) consists of \(m\) slots, each either empty or holding a single pair \((k, v)\) with \(k \in K\) and \(v \in V\).

    No expected constant-time bound is claimed because the model supplies neither a probability distribution nor a uniform-hashing assumption about the probe sequence.

    public structure OpenAddressing (K : Type u) (V : Type v) (m : Nat)
    (probe : K → Nat → Fin m) where
  /-- The `m` slots, each empty or holding one key-value pair. -/
  slots : Vector (Option (K × V)) m

    DefinitionLinear-probing probe sequence#✓fully proved

    Cslib.Algorithms.Lean.OpenAddressing.linearProbe

    Given a hash function \(h : K \to \mathbb{N}\) and a number of slots \(m > 0\), the \(i\)-th probe of a key \(k\) is the slot \((h(k) + i) \bmod m\) in \(\{0, \dots, m - 1\}\).

    public def linearProbe {K : Type u} (hash : K → Nat) (m : Nat) (hm : 0 < m) :
    K → Nat → Fin m :=
  fun k i => ⟨(hash k + i) % m, Nat.mod_lt _ hm⟩

    DefinitionBounded lookup scan#✓fully proved

    Cslib.Algorithms.Lean.OpenAddressing.lookupAux

    Given a table with \(m\) slots and probe sequence \(p\), a key \(k\), a starting index \(s\) and a budget \(f\) of probes, examine the slots \(p(k, s), p(k, s + 1), \dots\) in order, for at most \(f\) probes. The scan returns the value bound to \(k\) in the first examined slot that holds a binding for \(k\), and returns no value if it first reaches an empty slot or exhausts the budget.

    This is the helper behind lookup, which starts at index \(0\) with budget \(m\).

    def lookupAux (table : OpenAddressing K V m probe) (key : K) (start : Nat) :
    Nat → Option V
  | 0 => none
  | fuel + 1 =>
      match table.slots.get (probe key start) with
      | none => none
      | some (k', value) =>
          if k' = key then some value else lookupAux table key (start + 1) fuel

    DefinitionBounded insertion scan#✓fully proved

    Cslib.Algorithms.Lean.OpenAddressing.insertAux

    Given a table with \(m\) slots and probe sequence \(p\), a key \(k\), a value \(v\), a starting index \(s\) and a budget \(f\) of probes, examine the slots \(p(k, s), p(k, s + 1), \dots\) in order, for at most \(f\) probes. At the first examined slot that is empty or holds a binding for \(k\), the scan returns the table with that slot overwritten by the binding \(k \mapsto v\) and every other slot unchanged; if all \(f\) examined slots hold bindings for other keys (in particular if \(f = 0\)), it fails and returns no table.

    This is the helper behind insertion, which starts at index \(0\) with budget \(m\).

    def insertAux (table : OpenAddressing K V m probe) (key : K) (value : V)
    (start : Nat) : Nat → Option (OpenAddressing K V m probe)
  | 0 => none
  | fuel + 1 =>
      match table.slots.get (probe key start) with
      | none =>
          some ⟨table.slots.set (probe key start).val (some (key, value))
            (probe key start).isLt⟩
      | some (k', _) =>
          if k' = key then
            some ⟨table.slots.set (probe key start).val (some (key, value))
              (probe key start).isLt⟩
          else
            insertAux table key value (start + 1) fuel

    DefinitionValid open-addressing tables#✓fully proved

    Cslib.Algorithms.Lean.OpenAddressing.Valid

    Let \(T\) be an open-addressing table with \(m\) slots and probe sequence \(p\), where \(p(k, i) \in \{0, \dots, m - 1\}\) is the slot visited by the \(i\)-th probe of key \(k\). Then \(T\) is valid when it satisfies two conditions. Probe-closedness: whenever slot \(j\) holds a binding \(k \mapsto v\), there is an \(i < m\) with \(p(k, i) = j\) such that the slots \(p(k, i')\) are occupied for all \(i' < i\); this is what lets a lookup stop at the first empty slot. Key uniqueness: if slots \(j_1\) and \(j_2\) hold bindings with the same key \(k\), then \(j_1 = j_2\); so each key has at most one binding and insertion genuinely replaces it.

    public def Valid (table : OpenAddressing K V m probe) : Prop :=
  (∀ (j : Fin m) (key : K) (value : V), table.slots.get j = some (key, value) →
    ∃ i < m, probe key i = j ∧
      ∀ i' < i, (table.slots.get (probe key i')).isSome) ∧
  (∀ (j₁ j₂ : Fin m) (key : K) (value₁ value₂ : V),
    table.slots.get j₁ = some (key, value₁) →
    table.slots.get j₂ = some (key, value₂) → j₁ = j₂)
    public structure OpenAddressing (K : Type u) (V : Type v) (m : Nat)
    (probe : K → Nat → Fin m) where
