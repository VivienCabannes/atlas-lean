    DefinitionSuffix array#✓fully proved

    Cslib.Algorithms.Lean.SuffixArray.suffixArray

    For a list \(s\) of length \(n\) over a linearly ordered alphabet, the suffix array of \(s\) is the list of the indices \(0, 1, \dots, n - 1\), sorted so that the suffixes of \(s\) starting at them appear in lexicographic order.

    Distinct indices below \(n\) give suffixes of different lengths, so these suffixes are pairwise distinct and the sorted order is unique.

    def suffixArray (s : List α) : List Nat :=
  (List.range s.length).mergeSort (fun i j => decide (suffix s i ≤ suffix s j))

    Cslib.Algorithms.Lean.SuffixArray.le_lcp_iff
