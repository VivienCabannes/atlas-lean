    Structurex-fast trie#✓fully proved

    Cslib.Algorithms.Lean.XFastTrie

    An x-fast trie over \(w\)-bit keys consists of a finite set of stored keys in \(\{0, \dots, 2^w - 1\}\) together with, for each level \(l \in \{0, \dots, w\}\), a finite set of natural numbers, intended to hold the \(l\)-bit prefixes of the stored keys.

    The classical per-level hash tables are modeled as finite sets, so no \(O(\log w)\) successor bound (or any other running-time bound) is claimed.

    public structure XFastTrie (w : Nat) where
  /-- The stored keys. -/
  contents : Finset (Fin (2 ^ w))
  /-- `levels l` holds the `l`-bit prefixes of the stored keys, for `l ≤ w`. -/
  levels : Fin (w + 1) → Finset Nat

    Cslib.Algorithms.Lean.XFastTrie.successor

    For an x-fast trie \(t\) over \(w\)-bit keys and a key \(x \in \{0, \dots, 2^w - 1\}\), the successor of \(x\) in \(t\) is the least stored key of \(t\) that is greater than \(x\) when some stored key is greater than \(x\); otherwise \(x\) has no successor in \(t\).

    It is computed directly from the stored key set rather than by the classical binary search over the levels, so no \(O(\log w)\) time bound is claimed.

    public def successor {w : Nat} (t : XFastTrie w) (x : Fin (2 ^ w)) :
    Option (Fin (2 ^ w)) :=
  if h : (t.contents.filter (fun y => x < y)).Nonempty then
    some ((t.contents.filter (fun y => x < y)).min' h)
  else
    none

    Cslib.Algorithms.Lean.YFastTrie

    A y-fast trie skeleton over \(w\)-bit keys consists of an x-fast trie over \(w\)-bit keys, whose stored keys are the representatives, together with a bucket \(B_r\), a finite set of keys, for every key \(r \in \{0, \dots, 2^w - 1\}\).
