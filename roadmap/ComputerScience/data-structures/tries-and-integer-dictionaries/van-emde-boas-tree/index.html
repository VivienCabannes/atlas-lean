    Cslib.Algorithms.Lean.VanEmdeBoas

    For a natural number \(m\), a two-level van Emde Boas tree over the universe \(\{0, \dots, m^2 - 1\}\) consists of a summary bit vector of length \(m\) and, for each \(i < m\), a cluster bit vector of length \(m\); bit \(j\) of cluster \(i\) records whether the element \(im + j\) is stored. Unlike the fully recursive van Emde Boas tree over universes of size \(2^{2^k}\), the summary and the clusters here are plain bit vectors, not van Emde Boas trees.

    public structure VanEmdeBoas (m : Nat) where
  /-- Bit `i` records whether cluster `i` contains a stored element. -/
  summary : Fin m → Bool
  /-- `clusters i j` records whether the element `i * m + j` is stored. -/
  clusters : Fin m → Fin m → Bool
