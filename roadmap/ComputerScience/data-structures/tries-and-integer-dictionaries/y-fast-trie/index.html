    Cslib.Algorithms.Lean.GroupedYFastTrie

    For natural numbers \(w\) and \(B\), a grouped y-fast trie over \(w\)-bit keys with group bound \(B\) consists of an x-fast trie over \(w\)-bit keys, which holds the representatives, and a list of groups, each a list of \(w\)-bit keys. The structure itself imposes no condition on these fields; the intended invariants (the representative trie is a valid x-fast trie whose keys are exactly the group maxima, every group is nonempty, strictly sorted and of length at most \(B\), and the groups are in increasing order) are imposed by the validity predicate.

    Each group is a sorted list standing in for a balanced search tree; no complexity bound is claimed.

    public structure GroupedYFastTrie (w B : Nat) where
  /-- The x-fast trie over representative keys (group maxima). -/
  reps : XFastTrie w
  /-- The groups, in increasing order. -/
  groups : List (List (Fin (2 ^ w)))
    public structure XFastTrie (w : Nat) where
  /-- The stored keys. -/
  contents : Finset (Fin (2 ^ w))
  /-- `levels l` holds the `l`-bit prefixes of the stored keys, for `l ≤ w`. -/
  levels : Fin (w + 1) → Finset Nat

    Cslib.Algorithms.Lean.GroupedYFastTrie.Valid

    A grouped y-fast trie \(t\) over keys in \(\{0, \dots, 2^w - 1\}\) with group bound \(B\) is valid when its representative trie is a valid x-fast trie; a key \(r\) is stored in the representative trie exactly when \(r\) is the last element of some group of \(t\); every group of \(t\) is nonempty, has at most \(B\) keys, and is strictly increasing; and the groups of \(t\) are ordered, that is, every key of an earlier group is smaller than every key of a later group.

    public def Valid {w B : Nat} (t : GroupedYFastTrie w B) : Prop :=
  t.reps.Valid ∧
    (∀ r, r ∈ t.reps.contents ↔ ∃ g ∈ t.groups, g.getLast? = some r) ∧
    (∀ g ∈ t.groups, g ≠ [] ∧ g.length ≤ B ∧ g.Pairwise (· < ·)) ∧
    GroupOrdered t.groups

    Cslib.Algorithms.Lean.GroupedYFastTrie.repGe

    For a grouped y-fast trie \(t\) and a key \(x\), the result is \(x\) itself if the membership test of the representative x-fast trie of \(t\) (a single probe of its deepest level) reports \(x\) as present. Otherwise it is the successor of \(x\) in the representative x-fast trie, that is, the least representative greater than \(x\), or nothing if there is none.

    When \(t\) is valid, the result is the least representative \(r\) with \(x \le r\), and nothing when there is no such representative.

    public def repGe {w B : Nat} (t : GroupedYFastTrie w B) (x : Fin (2 ^ w)) :
    Option (Fin (2 ^ w)) :=
  if t.reps.member x = true then some x else t.reps.successor x
