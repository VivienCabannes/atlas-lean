    Cslib.Algorithms.Lean.RadixTrie

    For types \(\alpha\) and \(\beta\), a radix trie with keys that are lists over \(\alpha\) and values in \(\beta\) is a node made of an optional value in \(\beta\) and a finite list of child edges, each a pair of a label, which is a list over \(\alpha\), and a radix trie (the subtree at the end of the edge).

    No invariant is built into the type: labels may be empty and sibling labels may share first symbols. The radix-trie invariant is imposed separately.

    DefinitionRadix trie lookup#✓fully proved

    Cslib.Algorithms.Lean.RadixTrie.lookup

    Looking up a key, a list over \(\alpha\), in a radix trie returns an optional value. At a node, the empty key returns the value stored at the node, if any. A nonempty key \(k\) with first symbol \(c\) goes to the first child edge whose label starts with \(c\). If there is no such edge, or its label \(\ell\) is not a prefix of \(k\), the lookup returns no value; otherwise it continues in the subtree of that edge with \(k\) minus its first \(|\ell|\) symbols.

    def lookup {α : Type u} {β : Type v} [DecidableEq α] :
    RadixTrie α β → List α → Option β
  | .node value _, [] => value
  | .node _ children, key@(_ :: _) => lookupChildren children key
where
  lookupChildren : List (List α × RadixTrie α β) → List α → Option β
    | [], _ => none
    | (label, child) :: rest, key@(c :: _) =>
        if label.head? = some c then
          if commonPrefix key label = label then
            lookup child (key.drop label.length)
          else none
        else lookupChildren rest key
    | _ :: _, [] => none
    inductive RadixTrie (α : Type u) (β : Type v) where
  | node : Option β → List (List α × RadixTrie α β) → RadixTrie α β

    DefinitionInsertion into a radix trie#✓fully proved

    Cslib.Algorithms.Lean.RadixTrie.insert

    Inserting a value \(v\) at a key \(k\) (a list of symbols) into a radix trie works as follows. If \(k\) is empty, the root's value becomes \(v\). Otherwise let \(c\) be the first symbol of \(k\). If no child edge of the root has a label starting with \(c\), a new edge labelled \(k\) leading to a leaf storing \(v\) is added after the existing edges. Otherwise take the first such edge, with label \(\ell\) and subtree \(s\), let \(q\) be the longest common prefix of \(k\) and \(\ell\), and replace that edge in place. If \(k = \ell = q\), the edge keeps label \(\ell\) and leads to \(s\) with its root value set to \(v\). If \(k = q\) but \(\ell\) is longer, the edge is labelled \(q\) and leads to a new node storing \(v\) whose only edge is the rest of \(\ell\) leading to \(s\). If \(\ell = q\) but \(k\) is longer, the edge keeps label \(\ell\) and leads to \(s\) with \(v\) inserted at the rest of \(k\). If both are longer than \(q\), the edge is labelled \(q\) and leads to a new node with no value and two edges: the rest of \(\ell\) leading to \(s\), then the rest of \(k\) leading to a leaf storing \(v\).
