    DefinitionTrie lookup#✓fully proved

    Cslib.Algorithms.Lean.Trie.lookup

    The lookup of a key (a list over \(\alpha\)) in a trie returns an optional value in \(\beta\), by recursion on the key. For the empty key it is the optional value stored at the root. For a key with first letter \(a\) followed by the key \(k\), it fails if no child of the root is labelled \(a\), and otherwise it is the lookup of \(k\) in the first child labelled \(a\).

    def lookup {α : Type u} {β : Type v} [DecidableEq α]
    (trie : Trie α β) : List α → Option β
  | [] =>
      match trie with
      | .node value _ => value
  | key :: keys =>
      match trie with
      | .node _ children =>
          match children.lookup key with
          | none => none
          | some child => lookup child keys
    inductive Trie (α : Type u) (β : Type v) where
  | node : Option β → List (α × Trie α β) → Trie α β

    DefinitionTrie insertion#✓fully proved

    Cslib.Algorithms.Lean.Trie.insert

    Inserting a value \(v\) at a key \(k\) (a list of letters) in a trie stores \(v\) at the node reached by following \(k\) from the root, replacing any value stored there. Along the way, a missing child is created as an empty trie and appended after its siblings, an existing child is updated in place, and all other values and children are unchanged.

    Cslib.Algorithms.Lean.Trie.insert · 17 lines 
    def insert {α : Type u} {β : Type v} [DecidableEq α]
    (trie : Trie α β) : List α → β → Trie α β
  | [], value =>
      match trie with
      | .node _ children => .node (some value) children
  | key :: keys, value =>
      match trie with
      | .node current children =>
          let child := (children.lookup key).getD empty
          .node current (childInsert key (insert child keys value) children)
where
  childInsert (key : α) (child : Trie α β) :
      List (α × Trie α β) → List (α × Trie α β)
    | [] => [(key, child)]
    | (key', child') :: children =>
        if key = key' then (key, child) :: children
        else (key', child') :: childInsert key child children
    inductive Trie (α : Type u) (β : Type v) where
  | node : Option β → List (α × Trie α β) → Trie α β

    Cslib.Algorithms.Lean.Trie.Valid

    Validity of tries is defined inductively: a trie node with optional value \(v\) and child list \(c\) is valid when the letters labelling the children in \(c\) are pairwise distinct and every child trie in \(c\) is valid.

    DefinitionEntries of a trie#✓fully proved

    Cslib.Algorithms.Lean.Trie.entries

    The entries of a trie are the list of its key-value pairs, where a key is a list of letters. If the root stores a value \(v\), the list begins with the pair consisting of the empty key and \(v\); it continues, for each child in the stored sibling order, with the entries \((k, w)\) of that child, in order, each rewritten as \((a k, w)\), where \(a\) is the letter labelling the child and \(a k\) is the key \(k\) with \(a\) prepended.

    def entries {α : Type u} {β : Type v} : Trie α β → List (List α × β)
  | .node value children =>
      (match value with
       | none => []
       | some result => [([], result)]) ++ childEntries children
where
  childEntries : List (α × Trie α β) → List (List α × β)
    | [] => []
    | (key, child) :: children =>
        child.entries.map (fun (keys, result) => (key :: keys, result)) ++
          childEntries children
    inductive Trie (α : Type u) (β : Type v) where
  | node : Option β → List (α × Trie α β) → Trie α β

    Cslib.Algorithms.Lean.Trie.delete

    Deleting a key \(k\) (a list of letters) from a trie \(t\) works by recursion on \(k\). If \(k\) is empty, the root of \(t\) loses its value and keeps its children. If \(k\) consists of a first letter \(a\) followed by a key \(k'\) and the root of \(t\) has no child at \(a\), then \(t\) is unchanged. Otherwise \(k'\) is deleted from the first child at \(a\). If the result has neither value nor children, every entry at \(a\) is removed from the root's child list; if not, the first entry at \(a\) is replaced by the result and any later entries at \(a\) are removed. The root's value and the other children, in their order, are kept.

    Deleting an absent key leaves every lookup unchanged.

    def delete {α : Type u} {β : Type v} [DecidableEq α] (trie : Trie α β) :
    List α → Trie α β
  | [] =>
      match trie with
      | .node _ children => .node none children
  | key :: keys =>
      match trie with
      | .node current children =>
          match children.lookup key with
          | none => .node current children
          | some child =>
              .node current (setChild key (delete child keys) children)
    inductive Trie (α : Type u) (β : Type v) where
  | node : Option β → List (α × Trie α β) → Trie α β
