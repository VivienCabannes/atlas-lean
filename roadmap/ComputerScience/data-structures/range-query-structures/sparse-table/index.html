    StructureSparse table#✓fully proved

    Cslib.Algorithms.Lean.SparseTable

    A sparse table over a type \(\alpha\) consists of an array of elements of \(\alpha\), called its data, and an array of arrays of elements of \(\alpha\), called its levels.

    The intended meaning is that level \(k\) stores the minima of the length-\(2^k\) slices of the data; data and levels are stored as arrays so that entry lookup is random access. Arbitrary values need not relate data and levels at all; validity ties every stored level to this specification, tables produced by the construction are valid, and query correctness is stated for valid tables.

    structure SparseTable (α : Type u) where
  data : Array α
  levels : Array (Array α)

    For a type \(\alpha\) with a minimum operation, the option minimum extends \(\min\) to optional values (elements of \(\alpha\) or none): on two elements \(a, b\) of \(\alpha\) it returns \(\min(a, b)\), and none is a neutral element on either side.

  | none, b => b
  | some a, none => some a
  | some a, some b => some (min a b)

    Cslib.Algorithms.Lean.SparseTable.omin_self

    For every linearly ordered type \(\alpha\) and every optional value \(a\) (an element of \(\alpha\) or none), the option minimum of \(a\) with itself is \(a\).

    DefinitionLevels of a sparse table#✓fully proved

    Cslib.Algorithms.Lean.SparseTable.level

    For a list \(a\) over a type with a minimum operation \(\min\), the levels of \(a\) are defined recursively: level \(0\) is \(a\), and if level \(k\) is \(\ell = (\ell_0, \dots, \ell_{m-1})\), then level \(k + 1\) is the list of the values \(\min(\ell_i, \ell_{i+2^k})\) for \(0 \le i < m - 2^k\) (empty when \(m \le 2^k\)).

    Over a linear order, element \(i\) of level \(k\) is the minimum of the \(2^k\) consecutive elements of \(a\) starting at index \(i\), and only start indices whose interval fits in \(a\) get an element.

    def level {α : Type u} [Min α] (a : List α) : Nat → List α
  | 0 => a
  | k + 1 => List.zipWith min (level a k) ((level a k).drop (2 ^ k))

    Cslib.Algorithms.Lean.SparseTable.nextLevel

    For a type with a minimum operation, an array \((r_0, \dots, r_{n-1})\) and a natural number \(k\), the next level is the array of length \(n - 2^k\) (empty when \(2^k \ge n\)) whose entry \(i\) is \(\min(r_i, r_{i + 2^k})\).

    The construction of a sparse table computes each level once from the previous one this way.

    def nextLevel {α : Type u} [Min α] (row : Array α) (k : Nat) : Array α :=
  Array.zipWith min row (row.extract (2 ^ k) row.size)

    DefinitionOne step of the sparse-table construction#✓fully proved

    Cslib.Algorithms.Lean.SparseTable.buildStep

    Work over a type with a minimum operation \(\min\). Given a pair \((r, L)\) of a current row \(r\) (an array of length \(|r|\)) and an array \(L\) of the rows recorded so far, and a natural number \(k\), the build step returns the pair \((r', L')\), where \(L'\) is \(L\) with \(r\) appended at the end, and \(r'\) is the array whose entry \(i\) is \(\min(r_i, r_{i+2^k})\) for each \(i\) with \(i + 2^k < |r|\).

    def buildStep {α : Type u} [Min α] (state : Array α × Array (Array α)) (k : Nat) :
    Array α × Array (Array α) :=
  (nextLevel state.1 k, state.2.push state.1)

    DefinitionBuilding a sparse table#✓fully proved

    Cslib.Algorithms.Lean.SparseTable.build

    For a list \(a\) of length \(n\) over a type with a minimum operation \(\min\), the sparse table built from \(a\) has data \(a\) and \(\lfloor \log_2 n \rfloor + 1\) stored rows, where \(\lfloor \log_2 0 \rfloor\) is taken to be \(0\). The rows are produced by iterating the build step for \(k = 0, 1, \dots, \lfloor \log_2 n \rfloor\), starting from the current row \(a\) and no recorded rows. So row \(0\) is \(a\), and entry \(i\) of row \(k + 1\) is \(\min(x_i, x_{i+2^k})\), where \(x\) is row \(k\) and \(i + 2^k\) is less than the length of \(x\). Each row is computed once, from its predecessor.

    def build {α : Type u} [Min α] (a : List α) : SparseTable α :=
  let data := a.toArray
  let final := (List.range (Nat.log2 a.length + 1)).foldl buildStep (data, #[])
  ⟨data, final.2⟩

    DefinitionValid sparse table#✓fully proved

    Cslib.Algorithms.Lean.SparseTable.Valid

    A sparse table over a type with a minimum operation, whose data is a list \(a\) of length \(n\), is valid when it has exactly \(m + 1\) levels, where \(m = \lfloor \log_2 n \rfloor\) for \(n \ge 1\) and \(m = 0\) for \(n = 0\), and for each \(k \le m\) its level \(k\) is the list \(L_k\) defined by \(L_0 = a\) and, for \(x = L_j\), \(L_{j+1}\) is the list of length \(|x| - 2^j\) (empty when \(2^j \ge |x|\)) whose entry \(i\) is \(\min(x_i, x_{i + 2^j})\). For a linear order, \(L_k\) is the list of minima of the length-\(2^k\) slices of \(a\).

    Tables produced by the construction are valid, an arbitrary value such as data \((1)\) with the single level \((99)\) is not, and query correctness is stated only for valid tables.

    def Valid {α : Type u} [Min α] (t : SparseTable α) : Prop :=
  t.levels.toList.map Array.toList =
    (List.range (Nat.log2 t.data.toList.length + 1)).map (level t.data.toList)

    Cslib.Algorithms.Lean.SparseTable.entry

    For a sparse table \(t\) and natural numbers \(k\) and \(i\), the entry of \(t\) at row \(k\) and index \(i\) is element \(i\) of the \(k\)-th stored row of \(t\) (both counted from \(0\)) when \(t\) has a \(k\)-th row and that row has an element at index \(i\); otherwise the entry is undefined.     Cslib.Algorithms.Lean.SparseTable.query

    For a sparse table \(t\) over a type with a minimum operation and natural numbers \(l, r\), the query over \([l, r)\) returns none when \(r \le l\). Otherwise, with \(k = \lfloor \log_2 (r - l) \rfloor\), it returns the option minimum (the minimum, with none as a neutral element on either side) of the entries of \(t\) at level \(k\) and indices \(l\) and \(r - 2^k\), in this order, where an entry not stored in \(t\) counts as none.
