    Cslib.Algorithms.Lean.KdTree.toListAux

    For a kd-tree \(t\) over points of \(\mathbb{Z}^d\) and a list \(\mathit{acc}\) of such points, the accumulator traversal of \(t\) onto \(\mathit{acc}\) is \(\mathit{acc}\) when \(t\) is empty, the point \(p\) followed by \(\mathit{acc}\) when \(t\) is a leaf holding \(p\), and, when \(t\) is a split node with left subtree \(L\) and right subtree \(R\), the traversal of \(L\) onto the traversal of \(R\) onto \(\mathit{acc}\).

    Threading the output suffix avoids repeatedly appending (and copying) left-subtree results.

    def toListAux : KdTree d → List (Fin d → Int) → List (Fin d → Int)
  | .empty, acc => acc
  | .leaf p, acc => p :: acc
  | .node _ _ left right, acc => left.toListAux (right.toListAux acc)

    DefinitionAccumulator range report of a kd-tree#✓fully proved

    Cslib.Algorithms.Lean.KdTree.reportAux

    Points are vectors in \(\mathbb{Z}^d\) with coordinates \(p_0, \dots, p_{d-1}\); the box \([lo, hi]\) consists of the points \(p\) with \(lo_i \le p_i \le hi_i\) for every \(i\). For a kd-tree \(t\) and a list \(acc\) of points, the accumulator report of \(t\) for \([lo, hi]\) onto \(acc\) is defined by recursion on \(t\). For the empty tree it is \(acc\). For a leaf \(p\) it is \(p\) followed by \(acc\) if \(p\) lies in the box, and \(acc\) otherwise. For a split node with axis \(a\), split value \(s\), left child \(L\) and right child \(R\), let \(acc'\) be \(acc\) if \(hi_a < s\) and the report of \(R\) onto \(acc\) otherwise; the result is \(acc'\) if \(s < lo_a\) and the report of \(L\) onto \(acc'\) otherwise.

    The accumulator avoids repeatedly appending the results of left subtrees, so building the output list costs work linear in the number of reported points; the traversal still visits every node that pruning does not cut, which can be the whole tree even for an empty report. No complexity bound is formalized.

    def reportAux : KdTree d → (Fin d → Int) → (Fin d → Int) →
    List (Fin d → Int) → List (Fin d → Int)
  | .empty, _, _, acc => acc
  | .leaf p, lo, hi, acc => if inBox lo hi p then p :: acc else acc
  | .node a s left right, lo, hi, acc =>
      let rightAcc := if hi a < s then acc else reportAux right lo hi acc
      if s < lo a then rightAcc else reportAux left lo hi rightAcc
    inductive KdTree (d : Nat) where
  | empty : KdTree d
  | leaf : (Fin d → Int) → KdTree d
  | node : Fin d → Int → KdTree d → KdTree d → KdTree d

    DefinitionKd-tree construction by median splits#✓fully proved

    Cslib.Algorithms.Lean.KdTree.build

    Let \(d \ge 1\), let \(a \in \{0, \dots, d-1\}\) be an axis and let \(P\) be a list of points in \(\mathbb{Z}^d\). The kd-tree built from \(P\) starting at axis \(a\) is the empty tree if \(P\) is empty and the leaf holding \(p\) if \(P = [p]\).
