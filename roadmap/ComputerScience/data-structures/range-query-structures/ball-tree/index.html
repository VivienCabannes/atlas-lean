    Cslib.Algorithms.Lean.BallTree

    For a dimension \(d\), a ball tree over the integer points \(\mathbb{Z}^d\) (functions \(\{0, \dots, d-1\} \to \mathbb{Z}\)) is either empty, a leaf holding one point, or a node holding a center point \(c \in \mathbb{Z}^d\), a natural number \(b\) (the squared-radius bound of the node's sphere) and two child ball trees.

    That the sphere around \(c\) actually contains the points below the node is a separate validity invariant, not part of this definition.

    inductive BallTree (d : Nat) where
  | empty : BallTree d
  | leaf : (Fin d → Int) → BallTree d
  | node : (Fin d → Int) → Nat → BallTree d → BallTree d → BallTree d

    DefinitionAccumulating traversal of a ball tree#✓fully proved

    Cslib.Algorithms.Lean.BallTree.toListAux

    For a ball tree \(T\) and a list \(A\) of points, the accumulating traversal returns \(A\) when \(T\) is empty, the point \(p\) followed by \(A\) when \(T\) is a leaf holding \(p\), and, when \(T\) is a node with children \(L\) and \(R\), the accumulating traversal of \(L\) whose accumulator is the accumulating traversal of \(R\) with accumulator \(A\).

    The result is the leaf points of \(T\), from left to right, followed by \(A\).

    def toListAux : BallTree d → List (Fin d → Int) → List (Fin d → Int)
  | .empty, acc => acc
  | .leaf p, acc => p :: acc
  | .node _ _ left right, acc => left.toListAux (right.toListAux acc)

    TheoremRelaxed triangle inequality for squared distance#✓fully proved

    Cslib.Algorithms.Lean.BallTree.distSq_le_two_mul

    For all points \(a, b, c \in \mathbb{Z}^d\), writing \(\delta(x, y)\) for the squared distance from \(x\) to \(y\), we have \(\delta(a, c) \le 2\,(\delta(a, b) + \delta(b, c))\).

    distSq a c ≤ 2 * (distSq a b + distSq b c)

    DefinitionAccumulating ball-tree search#✓fully proved

    Cslib.Algorithms.Lean.BallTree.searchAux

    Let \(d\) be a dimension and write \(\delta(x, y)\) for the squared distance from \(x\) to \(y\) in \(\mathbb{Z}^d\). For a ball tree \(T\) over \(\mathbb{Z}^d\), a query point \(q \in \mathbb{Z}^d\), a squared radius \(r \in \mathbb{N}\) and a list \(A\) of points, the accumulating search of \(T\) for \(q\) and \(r\) with accumulator \(A\) is \(A\) when \(T\) is empty; when \(T\) is a leaf holding \(p\), it is \(p\) followed by \(A\) if \(\delta(q, p) \le r\) and \(A\) otherwise; when \(T\) is a node with center \(c\), squared-radius bound \(b\) and children \(L\) and \(R\), it is \(A\) if \(2(b + r) < \delta(c, q)\), and otherwise the accumulating search of \(L\) for \(q\) and \(r\) whose accumulator is the accumulating search of \(R\) for \(q\) and \(r\) with accumulator \(A\).

    When \(T\) satisfies the bounding-sphere invariant, this pruning is sound by the relaxed triangle inequality \(\delta(x, z) \le 2(\delta(x, y) + \delta(y, z))\) for all \(x, y, z \in \mathbb{Z}^d\), and the result is the points of \(T\) within squared distance \(r\) of \(q\), from left to right, followed by \(A\).

    def searchAux : BallTree d → (Fin d → Int) → Nat →
    List (Fin d → Int) → List (Fin d → Int)
  | .empty, _, _, acc => acc
  | .leaf p, query, radius, acc =>
      if distSq query p ≤ radius then p :: acc else acc
  | .node center bound left right, query, radius, acc =>
      if 2 * (bound + radius) < distSq center query then acc
      else left.searchAux query radius (right.searchAux query radius acc)
    inductive BallTree (d : Nat) where
  | empty : BallTree d
  | leaf : (Fin d → Int) → BallTree d
  | node : (Fin d → Int) → Nat → BallTree d → BallTree d → BallTree d

    Cslib.Algorithms.Lean.BallTree.Valid

    Validity of a ball tree is defined inductively: the empty tree and every leaf are valid, and a node with center \(c\) and squared-radius bound \(b\) is valid when both of its subtrees are valid and every point in the point list of either subtree lies within squared Euclidean distance \(b\) of \(c\).

    inductive Valid : BallTree d → Prop where
  | empty : Valid .empty
  | leaf (p : Fin d → Int) : Valid (.leaf p)
  | node {center : Fin d → Int} {bound : Nat} {left right : BallTree d}
      (hLeft : Valid left) (hRight : Valid right)
      (hSphereLeft : ∀ p ∈ left.toList, distSq center p ≤ bound)
      (hSphereRight : ∀ p ∈ right.toList, distSq center p ≤ bound) :
      Valid (.node center bound left right)

    Cslib.Algorithms.Lean.BallTree.search_eq_filter

    For every ball tree \(T\) over \(\mathbb{Z}^d\) satisfying the bounding-sphere invariant, every query point \(q \in \mathbb{Z}^d\) and every \(r \in \mathbb{N}\), the search of \(T\) for \(q\) and \(r\) equals the list of points of \(T\), from left to right, filtered to the points \(p\) whose squared distance from \(q\) is at most \(r\), in their order.     Cslib.Algorithms.Lean.BallTree.build

    The ball tree built from a list of points of \(\mathbb{Z}^d\) is defined by recursion on the list. The empty list gives the empty tree and a one-point list \([p]\) gives the leaf \(p\). A list \(L = [x_1, \dots, x_n]\) with \(n \ge 2\) gives a node whose center is \(x_1\), whose bound is the squared radius of \(L\) around \(x_1\) (the largest squared distance from \(x_1\) to a point of \(L\)), whose left child is the tree built from the first \(\lfloor n/2 \rfloor\) points of \(L\), and whose right child is the tree built from the remaining points of \(L\).

    def build : List (Fin d → Int) → BallTree d
  | [] => .empty
  | [p] => .leaf p
  | pts@(x :: _ :: _) =>
      .node x (radiusSq x pts)
        (build (pts.take (pts.length / 2)))
        (build (pts.drop (pts.length / 2)))
