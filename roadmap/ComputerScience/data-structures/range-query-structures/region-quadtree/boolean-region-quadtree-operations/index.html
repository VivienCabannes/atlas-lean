    Cslib.Algorithms.Lean.QTree.Boolean.Qc

    A branch constructor that collapses four identical Boolean leaves. This is local compression, not recursive normalization of its arguments.

    def Qc : QTree Bool → QTree Bool → QTree Bool → QTree Bool → QTree Bool

      if x0 = x1 ∧ x1 = x2 ∧ x2 = x3 then .L x0

    Cslib.Algorithms.Lean.QTree.Boolean.get

    Boolean lookup with false on a nonleaf at scale zero. Leaves ignore coordinates; positive scales use the shared quadrant order.

    def get : Nat → QTree Bool → Nat → Nat → Bool

    Cslib.Algorithms.Lean.QTree.Boolean.qtUnion

    Boolean union, short-circuiting constant regions and compressing branches when both inputs are branches.

    def qtUnion : QTree Bool → QTree Bool → QTree Bool
  | .L true, _ => .L true
  | .L false, t => t
  | .Q _ _ _ _, .L true => .L true

    DefinitionDifference of Boolean quadtrees#✓fully proved

    Cslib.Algorithms.Lean.QTree.Boolean.qtDiff

    Ordered Boolean difference: cells in the first region but not the second. A full first region complements the second; an empty second returns the first.

    def qtDiff : QTree Bool → QTree Bool → QTree Bool
  | .L false, _ => .L false
  | .L true, t => neg t
  | .Q s0 s1 s2 s3, .L false => .Q s0 s1 s2 s3
  | .Q _ _ _ _, .L true => .L false
  | .Q s0 s1 s2 s3, .Q t0 t1 t2 t3 =>
      Qc (qtDiff s0 t0) (qtDiff s1 t1) (qtDiff s2 t2) (qtDiff s3 t3)
    inductive QTree (α : Type u) where
