    A cost function \(d\) assigning to each pair of vertices a value in a linearly ordered additive commutative monoid is metric when, for all vertices \(x\), \(y\), \(z\), it is symmetric, \(d(x, y) = d(y, x)\), zero on the diagonal, \(d(x, x) = 0\), nonnegative, \(0 \le d(x, y)\), and satisfies the triangle inequality \(d(x, z) \le d(x, y) + d(y, z)\).

    DefinitionPreorder walk with an accumulator#✓fully proved

    Cslib.Algorithms.Lean.MetricTSP.preorderWalkAux

    For a forest \(F\) and a list \(a\) of vertices, this is the timed computation defined as follows. On the empty forest it returns \(a\) at no cost. On a forest with first root \(v\), children forest \(C\) and sibling forest \(S\), it charges one time unit, walks \(S\) with accumulator \(a\) to get a list \(b\), walks \(C\) with accumulator \(b\) to get a list \(c\), and returns \(v\) followed by \(c\). It thus returns the vertices of \(F\) in preorder followed by \(a\), at one time unit per vertex of \(F\).

    The accumulator means no list is ever appended, so the untimed work is linear as well.

    def preorderWalkAux : Forest α → List α → TimeM ℕ (List α)
  | .nil, acc => pure acc
  | .cons v ch sib, acc => do
      ✓
      let b ← preorderWalkAux sib acc
      let a ← preorderWalkAux ch b
      pure (v :: a)
    inductive Forest (α : Type u) where
  | nil : Forest α
  | cons (v : α) (children siblings : Forest α) : Forest α
