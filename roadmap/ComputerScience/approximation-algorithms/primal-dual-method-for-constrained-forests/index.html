    Primal–dual method for constrained forests

    Goemans and Williamson (SIAM J. Comput. 24(2) (1995)) give one approximation algorithm for a whole class of network design problems: find a minimum-cost edge set meeting every cut \(\delta(S)\) with \(f(S) = 1\), for a proper function \(f\). Steiner trees, Steiner forests (generalized Steiner trees), \(T\)-joins, shortest paths and spanning trees are examples. The algorithm grows dual variables on the components that still need an edge, adds an edge when a dual constraint becomes tight, and finally deletes unneeded edges; its cost is at most \(2 - 2/|A|\) times the dual value (Theorem 2.4), so the integrality gap of the cut relaxation is at most \(2 - 2/|A|\).

    Recorded as wanted: the integrality-gap consequence. Not formalized: the algorithm, its running time, and the extensions in the later sections of the paper (for example §4, where the algorithm also returns a vertex set).

    DefinitionProper requirement function#✓fully proved

    MathlibExt.Combinatorics.Optimization.ConstrainedForest.IsProper

    A function \(f : 2^V \to \{0, 1\}\) is proper when

    1. (symmetry) \(f(S) = f(V \setminus S)\) for every \(S\), and
    2. (disjointness) if \(A\) and \(B\) are disjoint and \(f(A) = f(B) = 0\), then \(f(A \cup B) = 0\).

    The constrained forest problem asks for a minimum-cost edge set meeting \(\delta(S)\) whenever \(f(S) = 1\). Goemans and Williamson also assume \(f(V) = 0\), which the wanted theorem takes as a separate hypothesis.

    def IsProper (f : Finset V → Bool) : Prop :=
  (∀ S, f Sᶜ = f S) ∧
    ∀ A B, Disjoint A B → f A = false → f B = false → f (A ∪ B) = false

    DefinitionSteiner forest requirement#✓fully proved

    MathlibExt.Combinatorics.Optimization.ConstrainedForest.steinerForestRequirement

    For demand pairs \((s_1, t_1), \ldots, (s_p, t_p)\), \(f(S) = 1\) exactly when \(S\) contains one vertex of some pair but not the other. An edge set meets every cut with \(f(S) = 1\) exactly when it connects each \(s_i\) to \(t_i\) (the usual cut characterization of connectivity, not formalized here); its minimal such sets are Steiner forests, called generalized Steiner trees by Goemans and Williamson. The function is proper (symmetric by definition; a union of two sets separating no pair separates no pair), but that is not formalized here. With a single pair this is the shortest path problem, and with all pairs from a terminal set \(T\) the Steiner tree problem (their Table 1).

    def steinerForestRequirement (demands : List (V × V)) (S : Finset V) : Bool :=
  demands.any fun d => decide (d.1 ∈ S) != decide (d.2 ∈ S)

    MathlibExt.Combinatorics.Optimization.ConstrainedForest.exists_forest_cost_le_of_lp_feasible

    Let \(G\) be a finite simple graph with nonnegative edge costs \(c\), and \(f\) a proper requirement function with \(f(V) = 0\); put \(A = \{v : f(\{v\}) = 1\}\). For every feasible solution \(x \ge 0\) of the linear relaxation (\(x(\delta(S)) \ge 1\) whenever \(f(S) = 1\)) there is an edge set \(F\) meeting every cut \(\delta(S)\) with \(f(S) = 1\) and

    \[c(F) \le \left(2 - \frac{2}{|A|}\right) \sum_e c_e x_e .\]

    Recorded as wanted. Goemans and Williamson prove more (Theorem 2.4): their primal–dual algorithm grows a dual solution \(y\) on the active components and returns a forest \(F'\) with \(c(F') \le (2 - 2/|A|) \sum_S y_S \le (2 - 2/|A|) Z^*_{LP}\), in \(O(\min(n^2 \log n, mn\,\alpha(m, n)))\) time. The wanted statement keeps only the consequence they state on p. 297, that the ratio between the optimal values of (IP) and (LP) is at most \(2 - 2/|A|\). When \(|A| = 0\), Lean's convention \(2/0 = 0\) makes the factor \(2\); then \(f \equiv 0\) and \(F = \emptyset\) works. \(|A| = 1\) cannot occur for a proper \(f\) with \(f(V) = 0\).
