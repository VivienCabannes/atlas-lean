    DefinitionFM-index backward search#✓fully proved

    Cslib.Bioinformatics.Indexing.BWT.backwardSearch

    FM-index backward search: the half-open row interval [sp, ep) for a pattern, computed from the last column alone, processing the pattern from its last letter to its first. The interval for the suffix and C[c] are each computed once per letter, so a pattern of length m makes m recursive calls.

    def backwardSearch {α : Type*} [LinearOrder α] (L : List (WithBot α)) : List α → ℕ × ℕ
  | [] => (0, L.length)
  | c :: P =>
      let r := backwardSearch L P
      let base := countLess L c
      (base + rank L c r.1, base + rank L c r.2)
    def countLess {α : Type*} [LinearOrder α] (L : List (WithBot α)) (c : WithBot α) : ℕ :=
  L.countP (· < c)
