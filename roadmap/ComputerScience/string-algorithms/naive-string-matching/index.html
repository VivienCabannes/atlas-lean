    Cslib.Algorithms.Lean.TimeM.naiveMatches

    Let \(p = p_0 \cdots p_{m-1}\) be a pattern and \(t = t_0 \cdots t_{n-1}\) a text over an alphabet with a Boolean equality test. If \(m \le n\), the naive matcher handles the shifts \(s = 0, 1, \dots, n - m\) in turn: it compares \(p_i\) with \(t_{s+i}\) for \(i = 0, 1, \dots\) until a comparison fails or all \(m\) symbols are compared, and it reports \(s\) if no comparison failed. It returns the reported shifts in the order found, with cost the total number of symbol comparisons executed, failed comparisons included. If \(m > n\), it reports no shift at cost \(0\).

    public def naiveMatches [BEq α] (pattern text : List α) : TimeM Nat (List Nat) :=
  if pattern.length ≤ text.length then
    timedScan pattern (text.tails.take (text.length - pattern.length + 1)) 0
  else
    pure []

    Cslib.Algorithms.Lean.TimeM.naiveMatches_time_eq

    Let \(p = p_0 \cdots p_{m-1}\) be a pattern and \(t = t_0 \cdots t_{n-1}\) a text. If \(m \le n\), the number of symbol comparisons performed by the naive matcher on \(p\) and \(t\) is

    \[\sum_{s=0}^{n-m} \min(m, k_s + 1),\]

    where \(k_s\) is the least \(i < m\) such that \(p_i\) and \(t_{s+i}\) are unequal under the Boolean equality of the alphabet, and \(k_s = m\) if there is no such \(i\). If \(m > n\), the naive matcher performs no comparisons.

    theorem naiveMatches_time_eq [BEq α] (pattern text : List α) :
    (naiveMatches pattern text).time =
      if pattern.length ≤ text.length then
        ((text.tails.take (text.length - pattern.length + 1)).map fun suffix =>
          min pattern.length
            ((pattern.zip suffix).findIdx (fun pair => !(pair.1 == pair.2)) + 1)).sum
      else 0
