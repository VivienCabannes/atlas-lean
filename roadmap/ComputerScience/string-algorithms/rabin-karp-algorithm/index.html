    Cslib.Algorithms.Lean.TimeM.rabinKarpMatches

    Given a base \(d\), a modulus \(q > 0\), a pattern \(P = p_0 \dots p_{m-1}\) and a text \(T = t_0 \dots t_{n-1}\), both lists of natural numbers, this returns the list, in increasing order, of all shifts \(s\) with \(s + m \le n\) and \(t_{s+k} = p_k\) for every \(k < m\). For \(m \ge 1\) it computes by Horner's rule the residues modulo \(q\) of \(P\) and of the first length-\(m\) window of \(T\), read as base-\(d\) numerals, and updates the window residue by a rolling hash; symbols are compared at a shift only when the two residues agree, from left to right. If \(m > n\) it returns the empty list. The empty pattern returns every shift \(0, 1, \dots, n\) at cost \(0\).

    The cost counts each executed multiplication, addition, subtraction and modulus in computing the residues and \(d^{m-1} \bmod q\), and each borrow test, residue equality test and symbol equality test; shift-offset arithmetic and all other operations are free.

    public def rabinKarpMatches (d q : Nat) (pattern text : List Nat) (_hq : 0 < q) :
    TimeM Nat (List Nat) :=
  match pattern with
  | [] => pure (rkBoundaries text 0)
  | _ :: tail => do
      ✓
      let h ← rkHigh d q tail (1 % q)
      let initialized ← rkSetup d q pattern text 0 0
      match initialized with
      | none => pure []
      | some (p, t, incoming) => rkScan d q h p pattern text incoming t 0

    Cslib.Algorithms.Lean.TimeM.rabinKarpMatches_time_eq

    Let \(d\) be a base, \(q > 0\) a modulus and \(P\), \(T\) lists of natural numbers with \(0 < m \le |T|\), where \(m = |P|\), and put \(r = |T| - m\). Index lists from \(0\), write \(T_{s..}\) for the suffix of \(T\) starting at position \(s\), and for a list \(S\) with at least \(m\) entries put \(h(S) = \bigl(\sum_{i\lt m} S_i\, d^{m-1-i}\bigr) \bmod q\). Let \(B\) be the number of offsets \(s < r\) with \(h(T_{s..}) < (T_s \cdot (d^{m-1} \bmod q)) \bmod q\). For \(s \le r\) let \(c_s = m\) if \(P\) is a prefix of \(T_{s..}\), and otherwise \(c_s = j + 1\) for the least \(j\) with \(P_j \ne T_{s+j}\). Then Rabin–Karp matching of \(P\) in \(T\) with base \(d\) and modulus \(q\) has counted cost exactly

    \[(8m - 1) + (r + 1) + 7r + B + \sum_{s \le r,\ h(P) = h(T_{s..})} c_s.\]

    The terms count the setup, one hash comparison per alignment, the rolling hash updates, one extra addition per borrow, and the symbol comparisons that verify hash hits.

    theorem rabinKarpMatches_time_eq (d q : Nat) (pattern text : List Nat) (hq : 0 < q)
    (hpos : 0 < pattern.length) (hlen : pattern.length ≤ text.length) :
    let m := pattern.length
    let r := text.length - m
    let residue := fun suffix : List Nat => Nat.ofDigits d (suffix.take m).reverse % q
    let borrows := ((text.tails.take r).map fun suffix =>
      if residue suffix < suffix.head! * (d ^ (m - 1) % q) % q then 1 else 0).sum
    let verification := ((text.tails.take (r + 1)).map fun suffix =>
      if Nat.ofDigits d pattern.reverse % q = residue suffix then
        min m ((pattern.zip suffix).findIdx (fun pair => !(pair.1 == pair.2)) + 1) else 0).sum
    (rabinKarpMatches d q pattern text hq).time =
      (8 * m - 1) + (r + 1) + 7 * r + borrows + verification
