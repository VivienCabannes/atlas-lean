    Cslib.Algorithms.Lean.TimeM.kmpSearch

    For lists \(p\) (the pattern) and \(t\) (the text) over a type with a boolean equality, KMP search for \(p\) in \(t\) returns either a zero-based offset or no offset, together with a cost: the number of symbol comparisons it makes. If \(p\) is empty, it returns the offset \(0\) at cost \(0\). Otherwise it first builds the prefix table of \(p\), a list of entries each pairing a symbol with a failure value. The transition of a table from a state \(s\) on a symbol \(x\) is defined as follows. If \(s\) is less than the number of entries and \(x\) equals the symbol of entry \(s\) (counting from \(0\)), the result is \(s + 1\). Otherwise the result is \(0\) when \(s = 0\), and when \(s > 0\) it is the transition from the failure value of entry \(s - 1\) on \(x\). Starting from the empty table, each symbol \(x\) of \(p\) in turn is appended as a new entry, with failure value the transition of the current table on \(x\) from the state equal to its number of entries. The search then reads \(t\) from the left, starting in state \(0\) and moving to the transition of the table on each symbol read. The first time the state equals \(|p|\), after \(j\) symbols have been read, it returns the offset \(j - |p|\). If this never happens, it returns no offset. The cost counts every equality test between two symbols, both while the table is built and while \(t\) is scanned. List operations, array access and arithmetic cost nothing.

    When the boolean equality is lawful, the returned offset is the least offset at which \(p\) occurs in \(t\), and no offset is returned exactly when \(p\) does not occur in \(t\).

    public def kmpSearch [BEq α] (pattern text : List α) : TimeM Nat (Option Nat) :=
  match pattern with
  | [] => pure (some 0)
  | _ :: _ =>
      let table := timedBuildFrom default pattern
      let result := timedScan table.ret 0 0 text
      ⟨result.ret, table.time + result.time⟩
    private def timedBuildFrom [BEq α] (table : Array.PrefixTable α) :
    List α → TimeM Nat (Array.PrefixTable α)
  | [] => pure table
  | x :: xs =>
      let step := timedStep table x ⟨table.size, Nat.lt_succ_self _⟩
      let rest := timedBuildFrom (extendWith table x step.ret) xs
      ⟨rest.ret, step.time + rest.time⟩

    Array.mkPrefixTable_failure_spec

    Let \(p\) be a pattern of length \(n\) over a type with a lawful boolean equality, and write \(p_{\lt k}\) for its prefix of length \(k\). Each entry of the KMP prefix table of \(p\) pairs a symbol of \(p\) with a failure value. For every \(q < n\), the failure value \(f\) of entry \(q\) (counting from \(0\)) is the length of the longest proper prefix of \(p_{\lt q+1}\) that is also a suffix of \(p_{\lt q+1}\): \(f \le q\), \(p_{\lt f}\) is a suffix of \(p_{\lt q+1}\), and every \(k \le q\) such that \(p_{\lt k}\) is a suffix of \(p_{\lt q+1}\) satisfies \(k \le f\).

    theorem mkPrefixTable_failure_spec {α : Type u} [BEq α] [LawfulBEq α]
    (pattern : List α) (q : Nat) (hq : q < pattern.length) :
    let table := mkPrefixTable pattern.toArray
    let failure := (table.toArray[q]'(by
      change q < (mkPrefixTable pattern.toArray).size
      rw [mkPrefixTable_size]
      exact hq)).2
    failure ≤ q ∧
      (pattern.take failure).IsSuffix (pattern.take (q + 1)) ∧
      ∀ k, k ≤ q → (pattern.take k).IsSuffix (pattern.take (q + 1)) → k ≤ failure

    Array.mkPrefixTable_step_spec

    Let \(p\) be a pattern of length \(n\) over a type with a lawful boolean equality, and write \(p_{\lt k}\) for its prefix of length \(k\).
