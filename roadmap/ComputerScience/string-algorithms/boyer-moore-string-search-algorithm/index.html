    DefinitionBoyer–Moore preprocessing#✓fully proved

    Cslib.Algorithms.Lean.StringMatching.BoyerMoore.preprocess

    Given a pattern \(p = p_0 \cdots p_{m-1}\) over the alphabet \(\{0, \dots, \sigma - 1\}\), this computes a bad-character table \(B\) of length \(\sigma\) and a strong good-suffix table \(G\) of length \(m\). The table \(B\) starts with every entry equal to \(m\), and then for \(k = 0, 1, \dots, m - 2\) in turn the entry \(B_{p_k}\) is set to \(m - 1 - k\). For \(G\), let \(s_i\) be the length of the longest common suffix of \(p_0 \cdots p_i\) and \(p\), computed with the Z algorithm on the reversed pattern. The table \(G\) starts with every entry equal to \(m\); then for \(i = m - 1, \dots, 0\) in turn, if \(s_i = i + 1\), every entry \(G_j\) with \(j < m - 1 - i\) that still equals \(m\) is set to \(m - 1 - i\); finally, for \(i = 0, 1, \dots, m - 2\) in turn, the entry \(G_{m - 1 - s_i}\) is set to \(m - 1 - i\).

    The event cost includes table slots, copies, fill iterations and canonical Z events; it does not count machine instructions or unbounded-integer bit operations.

    Cslib.Algorithms.Lean.StringMatching.BoyerMoore.preprocess_goodSuffix

    Let \(p = p_0 \cdots p_{m-1}\) be a pattern over the alphabet \(\{0, \dots, \sigma - 1\}\), let \(G\) be the good-suffix table computed by the Boyer–Moore preprocessing of \(p\), and let \(i < m\). Call a positive integer \(e\) an admissible shift at \(i\) if \(p_{t - e} = p_t\) for every \(t < m\) with \(i < t\) and \(e \le t\), and \(p_{i - e} \ne p_i\) whenever \(e \le i\). Then \(1 \le G_i \le m\) and \(G_i\) is the least admissible shift at \(i\).

    After a mismatch at position \(i\), shifting by \(G_i\) keeps the matched suffix \(p_{i+1} \cdots p_{m-1}\) aligned where it overlaps and, when \(G_i \le i\), places the symbol \(p_{i - G_i} \ne p_i\) under the mismatched position.

    Let \(p = p_0 \cdots p_{m-1}\) be a nonempty pattern over the alphabet \(\{0, \dots, \sigma - 1\}\) and let \(G\) be the good-suffix table computed by the Boyer–Moore preprocessing of \(p\).     DefinitionBoyer–Moore matcher for all occurrences#✓fully proved

    Cslib.Algorithms.Lean.TimeM.boyerMooreMatches

    Let \(p = p_0 \cdots p_{m-1}\) and \(t = t_0 \cdots t_{n-1}\) be words over the alphabet \(\{0, \dots, \sigma - 1\}\). The matcher returns a list of offsets together with a cost. If \(m = 0\) it returns \(0, 1, \dots, n\) at cost \(n + 1\), and if \(n < m\) it returns the empty list at cost \(0\). Otherwise it charges \(m + n\) for converting \(p\) and \(t\) to arrays, computes the bad-character table \(B\) and the strong good-suffix table \(G\) of \(p\) with the Boyer–Moore preprocessing and charges the cost of that preprocessing, and then visits alignments \(s\), starting from \(s = 0\), as long as \(s + m \le n\). At each alignment it charges \(1\) and compares \(p_r\) with \(t_{s + r}\) for \(r = m - 1, m - 2, \dots, 0\), charging \(1\) per comparison and stopping at the first mismatch. If all \(m\) letters agree, it records \(s\), charges \(2\) and moves to the alignment \(s + G_0\). If the first mismatch is at position \(i\), it charges \(1\) and moves to the alignment \(s + \max(G_i, B_c - m + 1 + i)\), where \(c = t_{s + i}\) and the maximum is taken in the integers. Finally it charges \(1\) for each recorded offset and returns the recorded offsets in the order they were found.

    The result is every occurrence of \(p\) in \(t\), in increasing order and including overlaps. The cost counts these selected events, not machine instructions.

    public def boyerMooreMatches {σ : Nat} (pattern text : List (Fin σ)) :
    TimeM Nat (List Nat) :=
  Prod.fst <$> matchWithCounts pattern text
    @[no_expose] private def matchWithCounts {σ : Nat} (pattern text : List (Fin σ)) :

    Exact Boyer–Moore cost when the pattern repeats one letter and ends in another, which alone makes up the text. Let \(a \ne b\) be letters of the alphabet \(\{0, \dots, \sigma - 1\}\) and let \(m\) and \(n\) be natural numbers with \(2 \le m \le n\). Write \(a^{m-1}b\) for the word of \(m - 1\) copies of \(a\) followed by one \(b\), and \(b^n\) for the word of \(n\) copies of \(b\). The cost of the Boyer–Moore matcher with pattern \(a^{m-1}b\) and text \(b^n\) equals \(m + n + P + 4\lfloor n/m \rfloor\), where \(P\) is the cost of the Boyer–Moore preprocessing of the pattern \(a^{m-1}b\).

    On these inputs every alignment makes two character tests and is followed by a shift by \(m\).
