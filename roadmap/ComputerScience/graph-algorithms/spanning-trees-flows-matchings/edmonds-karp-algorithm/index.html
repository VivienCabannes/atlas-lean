    Cslib.Algorithms.Lean.EdmondsKarp.IsFeasible

    Let \(c\) be a capacity function assigning a natural number \(c(u, v)\) to each ordered pair of vertices, and let \(s\) and \(t\) be vertices. A flow \(f\) is feasible for \(c\), \(s\) and \(t\) when it is skew symmetric, \(f(u, v) = -f(v, u)\) for all \(u\) and \(v\); it respects the capacities, \(f(u, v) \le c(u, v)\) for all \(u\) and \(v\); and it is conserved: for every vertex \(v\) other than \(s\) and \(t\), the net flow \(\sum_w f(v, w)\) leaving \(v\) is \(0\).

    def IsFeasible {n : Nat} (capacity : Fin n → Fin n → Nat)
    (source sink : Fin n) (flow : Flow n) : Prop :=
  (∀ u v, flow u v = -flow v u) ∧
  (∀ u v, flow u v ≤ (capacity u v : Int)) ∧
  ∀ v, v ≠ source → v ≠ sink → flowValue v flow = 0

    Cslib.Algorithms.Lean.EdmondsKarp.residualGraph

    Let \(c\) be a capacity matrix assigning a natural number \(c(u, v)\) to each ordered pair of vertices among \(0, \dots, n - 1\), and let \(f\) be a flow on these vertices. The residual graph of \(c\) and \(f\) is the directed adjacency graph whose vertices \(0, \dots, n - 1\) are enumerated in increasing order and in which the adjacency list of \(u\) consists of the vertices \(v\) with \(f(u, v) < c(u, v)\), that is, with positive residual capacity \(c(u, v) - f(u, v)\), in increasing order.

    (flow : Flow n) : DirectedAdjacency (Fin n) where
  vertices := List.finRange n
  vertices_nodup := List.nodup_finRange n
  vertices_complete := List.mem_finRange
  adjacency u := (List.finRange n).filter fun v => decide (flow u v < capacity u v)

    DefinitionDistance-guided path reconstruction#✓fully proved

    Cslib.Algorithms.Lean.EdmondsKarp.pathFromDistances

    Let \(G\) be a directed graph with ordered adjacency lists, \(d\) a partial labelling of its vertices by natural numbers, \(t\) a vertex, and \(\equiv\) a given Boolean test on pairs of vertices (not required to be equality). The reconstruction from a vertex \(u\) with \(k\) steps left returns the one-element list \([u]\) when \(k = 0\) and \(u \equiv t\) holds, and fails when \(k = 0\) and \(u \equiv t\) fails. When \(k \ge 1\), it takes the first out-neighbour \(w\) of \(u\) in adjacency order with \(d(w) = k - 1\); it fails if there is none, and otherwise returns \(u\) followed by the reconstruction from \(w\) with \(k - 1\) steps left, failing if that fails.

    def pathFromDistances {V : Type*} [BEq V]
    (graph : DirectedAdjacency V) (distance : V → Option Nat) (sink : V) :
    Nat → V → Option (List V)
  | 0, current => if current == sink then some [current] else none
  | remaining + 1, current =>
      match (graph.adjacency current).find? fun next => distance next == some remaining with
      | none => none
      | some next =>
          (pathFromDistances graph distance sink remaining next).map (current :: ·)

    Cslib.Algorithms.Lean.EdmondsKarp.shortestPath

    Let \(G\) be a finite directed graph on the vertices \(\{0, \dots, n - 1\}\) with ordered adjacency lists, and let \(s\) be a source and \(t\) a sink. Run breadth-first search from \(t\) in the reverse graph of \(G\); it labels each vertex \(v\) from which \(t\) is reachable with the distance from \(v\) to \(t\) in \(G\). If \(s\) has no label, the search returns no path.
