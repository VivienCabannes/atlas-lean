    DefinitionLexicographic order on edge keys#✓fully proved

    Cslib.Algorithms.Lean.Kruskal.KeyLE

    For pairs of natural numbers \((w, i)\) and \((w', i')\), \((w, i) \preceq (w', i')\) holds when \(w < w'\), or \(w = w'\) and \(i \le i'\). This is the non-strict lexicographic order on \(\mathbb{N} \times \mathbb{N}\); Kruskal's algorithm applies it to keys (weight, input ordinal).

    public def KeyLE (left right : Nat × Nat) : Prop :=
  left.1 < right.1 ∨ (left.1 = right.1 ∧ left.2 ≤ right.2)

    Cslib.Algorithms.Lean.Kruskal.decodeAt

    Given natural numbers \(n\) and \(i\) and a raw edge with source \(s\), target \(t\) and weight \(w\), decoding at ordinal \(i\) returns the validated edge on the vertices \(\{0, \dots, n-1\}\) with ordinal \(i\), source \(s\), target \(t\) and weight \(w\) when \(s < n\) and \(t < n\), and returns no edge otherwise.

    public def decodeAt (n ordinal : Nat) (edge : RawEdge) : Option (WeightedEdge n) :=
  if hs : edge.source < n then
    if ht : edge.target < n then
      some {
        ordinal := ordinal
        source := ⟨edge.source, hs⟩
        target := ⟨edge.target, ht⟩
        weight := edge.weight

    else none
  else none

    Cslib.Algorithms.Lean.Kruskal.validEdgesFrom

    Given \(n\), a starting ordinal \(o\) and a list of raw edges \(e_0, e_1, \dots, e_{m-1}\), this returns, in input order, the weighted edges on the vertices \(\{0, \dots, n-1\}\) obtained from those \(e_k\) whose two endpoints are both less than \(n\); each keeps the endpoints and weight of \(e_k\) and carries the ordinal \(o + k\).     DefinitionConnectivity by a newest-first edge list#✓fully proved

    Cslib.Algorithms.Lean.Kruskal.ConnectedRev

    Connectivity of vertices \(u\) and \(v\) of \(\{0, \dots, n-1\}\) by a list of validated edges, read newest first, is defined by recursion on the list. By the empty list, \(u\) and \(v\) are connected exactly when \(u = v\). By a list whose first edge \(e\) has source \(a\) and target \(b\) and whose remaining edges form the list \(L\), the vertices \(u\) and \(v\) are connected when \(u\) and \(v\) are connected by \(L\), or \(u\) is connected to \(a\) and \(v\) is connected to \(b\) by \(L\), or \(u\) is connected to \(b\) and \(v\) is connected to \(a\) by \(L\).

    public def ConnectedRev {n : Nat} : List (WeightedEdge n) → Fin n → Fin n → Prop
  | [], left, right => left = right
  | edge :: edges, left, right =>
      ConnectedRev edges left right ∨
        (ConnectedRev edges left edge.source ∧
          ConnectedRev edges right edge.target) ∨
        (ConnectedRev edges left edge.target ∧
          ConnectedRev edges right edge.source)
