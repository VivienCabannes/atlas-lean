    Minimum cycle mean

    The minimum, over the directed cycles of a weighted digraph, of the average edge weight. Karp (1978) characterised it through the minimum weights \(F_k(v)\) of walks with exactly \(k\) edges from a fixed vertex, which the Bellman–Ford recurrence computes, giving an \(O(n|E|)\) algorithm; a negative cycle exists exactly when the minimum cycle mean is negative.

    DefinitionMinimum cycle mean of a weighted edge list#✓fully proved

    Cslib.Algorithms.Lean.BellmanFord.IsMinCycleMean

    For a list of weighted edge occurrences, a rational number \(\lambda\) is the minimum cycle mean when some directed cycle \(C\) has mean weight \(w(C)/|C| = \lambda\), the weight divided by the number of edges, and no directed cycle has a smaller mean weight. It is Karp's \(\lambda^*\); it exists exactly when the digraph has a cycle.

    def IsMinCycleMean {n : ℕ} (edges : List (Edge n)) (lam : ℚ) : Prop :=
  (∃ v cycle, IsDirectedCycle edges v cycle ∧ (pathWeight cycle : ℚ) / cycle.length = lam) ∧
    ∀ v cycle, IsDirectedCycle edges v cycle → lam ≤ (pathWeight cycle : ℚ) / cycle.length

    DefinitionMinimum weight of a walk with \(k\) edges#✓fully proved

    Cslib.Algorithms.Lean.BellmanFord.IsMinWalkWeight

    For a list of weighted edge occurrences, vertices \(s\) and \(v\) and a natural number \(k\), an integer \(x\) is the minimum weight of a walk with \(k\) edges from \(s\) to \(v\) when some walk ("edge progression") with exactly \(k\) edges from \(s\) to \(v\) has weight \(x\) and none has a smaller weight. This is Karp's \(F_k(v) = x\); when there is no such walk, \(F_k(v) = \infty\) and no \(x\) qualifies. Walks may repeat vertices and edges.

    def IsMinWalkWeight {n : ℕ} (edges : List (Edge n)) (s v : Fin n) (k : ℕ) (x : ℤ) : Prop :=
  (∃ walk, IsWeightedPath edges s v walk ∧ walk.length = k ∧ pathWeight walk = x) ∧
    ∀ walk, IsWeightedPath edges s v walk → walk.length = k → x ≤ pathWeight walk

    TheoremKarp's minimum cycle mean theorem#●ready to prove

    Cslib.Algorithms.Lean.BellmanFord.karp_minCycleMean

    Let a list of integer-weighted edge occurrences define a strongly connected digraph on \(n\) vertices, let \(\lambda^*\) be its minimum cycle mean, and let \(s\) be any vertex. With \(F_k(v)\) the minimum weight of a walk with \(k\) edges from \(s\) to \(v\), $\(\lambda^* = \min_{v} \max_{0 \le k \le n-1} \frac{F_n(v) - F_k(v)}{n - k} ,\)$ where a vertex with \(F_n(v) = \infty\) contributes \(+\infty\) to the minimum and an index with \(F_k(v) = \infty\) contributes \(-\infty\) to the maximum. The Lean statement gives the two inequalities: every vertex with \(F_n(v)\) finite has some \(k < n\) with \(F_k(v)\) finite and \((F_n(v) - F_k(v))/(n-k) \ge \lambda^*\), and some vertex with \(F_n(v)\) finite has \((F_n(v) - F_k(v))/(n-k) \le \lambda^*\) for all \(k < n\) with \(F_k(v)\) finite. Recorded as wanted.

    Karp's proof subtracts \(\lambda^*\) from every weight, which shifts both sides by \(\lambda^*\), and then proves the case \(\lambda^* = 0\) (his Lemma 2): with no negative cycles, \(\min_k F_k(v)\) over \(k < n\) is the shortest-path distance \(\pi(v)\), so each maximum is nonnegative, and following a shortest path to a vertex of a zero-weight cycle and then going round the cycle reaches a vertex \(v\) with \(F_n(v) = \pi(v)\). Karp allows real weights; integer weights are the case stated here. The values \(F_k(v)\) satisfy the Bellman–Ford recurrence \(F_k(v) = \min_{(u, v)} (F_{k-1}(u) + w(u, v))\), which gives Karp's \(O(n|E|)\) algorithm.
