    Cslib.Algorithms.Lean.DAGShortestPaths.run

    Let \(E\) be a list of integer-weighted directed edge occurrences on the vertices \(\{0, \dots, n-1\}\), let \(s\) be a source vertex, and let \(\sigma\) be a topological order of the directed graph obtained from \(E\) by forgetting weights. The relaxation starts from distance estimate \(0\) at \(s\), infinite estimates at every other vertex and no predecessor edges. It then takes the vertices \(u\) of \(\sigma\) in turn and relaxes each occurrence \(e\) in \(E\) from \(u\) to some \(v\) with weight \(c\), in the order of \(E\): if the estimate \(d\) at \(u\) is finite and the estimate at \(v\) is infinite or greater than \(d + c\), it sets the estimate at \(v\) to \(d + c\) and the predecessor of \(v\) to \(e\). The result records \(s\) as its source together with the final estimates and predecessors. Its cost counts one vertex visit per vertex of \(\sigma\), one edge relaxation per occurrence relaxed, and one distance update per estimate set.

    The original edge occurrences are retained, so every parallel occurrence is checked. The proof that \(\sigma\) is a topological order is not used by the computation.

    Cslib.Algorithms.Lean.DAGShortestPaths.dagShortestPaths

    Given a list \(E\) of integer-weighted edges on the vertices \(0, \dots, n-1\) and a source \(s\), run Kahn's topological sort on the directed graph obtained from \(E\) by forgetting weights. If it succeeds with order \(\sigma\), start from distance \(0\) at \(s\) and \(\infty\) elsewhere, relax the outgoing edge occurrences of each vertex in the order \(\sigma\), and return the resulting distances and predecessor edges. If it fails after processing the list \(P\) of vertices and leaving the list \(R\), return the error \((P, R)\). Only the relaxation pass is charged in the recorded cost.

    Failure preserves the sorter's processed and remaining lists; it does not return a cycle list.

    public def dagShortestPaths {n : Nat} (edges : List (Edge n)) (source : Fin n) :
    TimeM Cost (Except (List (Fin n) × List (Fin n)) (Distances n)) :=
  let buckets := bucketize edges
  match TopologicalSort.sort (bucketGraph buckets) with
  | .success order => do
      let result ← pass (fun vertex => buckets.get vertex) order (initialState source)
      pure (.ok result)
  | .failure processed remaining => pure (.error (processed, remaining))
