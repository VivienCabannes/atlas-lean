    Cslib.Algorithms.Lean.DirectedAdjacency

    A directed adjacency graph on a type \(V\) consists of a list of vertices that has no duplicates and contains every element of \(V\) (so \(V\) is finite), together with, for each vertex \(v\), an ordered list of the out-neighbors of \(v\), in which entries may repeat.

    structure DirectedAdjacency (V : Type u) where
  /-- The complete deterministic enumeration of vertices. -/
  vertices : List V
  /-- The vertex enumeration contains no duplicates. -/
  vertices_nodup : vertices.Nodup
  /-- Every vertex occurs in the enumeration. -/
  vertices_complete : ∀ vertex, vertex ∈ vertices
  /-- The ordered outgoing neighbors of each vertex. Entries may repeat. -/
  adjacency : V → List V
      vertices : List V
