    Cslib.Algorithms.Lean.TransitiveClosure.transitiveClosureStages

    Let \(A\) be a Boolean adjacency matrix on the vertices \(0, \dots, n-1\) and let \(k \le n\). The computation first builds the \(n \times n\) Boolean matrix \(T^{(0)}\) whose entry \((i, j)\) is true exactly when \(i = j\) or \(A_{ij}\) is true. Then, for \(p = 0, \dots, k - 1\), it builds a new matrix \(T^{(p+1)}\) from the saved matrix \(T^{(p)}\) by \(T^{(p+1)}_{ij} = T^{(p)}_{ij} \lor (T^{(p)}_{ip} \land T^{(p)}_{pj})\), and it returns \(T^{(k)}\). One time unit is charged for each cell assignment.

    @[no_expose]
def transitiveClosureStages {n : Nat} (adjacency : Fin n → Fin n → Bool)
    (pivots : Nat) (hpivots : pivots ≤ n) : TimeM Nat (Vector (Vector Bool n) n) := do
  let initial ← buildInitial adjacency n (by omega)
  runStages initial pivots hpivots

  | rows + 1, hrows => do
      let table ← buildInitial adjacency rows (by omega)
      let row ← initializeRow adjacency ⟨rows, by omega⟩ n (by omega)
      pure (table.push row)

    Cslib.Algorithms.Lean.TransitiveClosure.transitiveClosure

    Given a Boolean adjacency matrix \(A\) on the vertices \(0, 1, \dots, n-1\), the algorithm first builds the matrix \(t^{(0)}\) with \(t^{(0)}_{ij}\) true exactly when \(i = j\) or \(A_{ij}\) is true. Then, for \(k = 0, 1, \dots, n-1\) in turn, it builds a new matrix \(t^{(k+1)}\) with \(t^{(k+1)}_{ij} = t^{(k)}_{ij} \lor (t^{(k)}_{ik} \land t^{(k)}_{kj})\) for all \(i, j\), reading every operand from the saved matrix \(t^{(k)}\), and it returns \(t^{(n)}\). One time unit is charged for each cell assignment; reads, Boolean operations and matrix allocation are free.

    This is the saved-matrix recurrence of CLRS for the reflexive transitive closure.

    @[no_expose]
def transitiveClosure {n : Nat} (adjacency : Fin n → Fin n → Bool) :
    TimeM Nat (Fin n → Fin n → Bool) := do
  let final ← transitiveClosureStages adjacency n (by omega)
  pure fun i j => (final.get i).get j

    Let \(A\) be a Boolean adjacency matrix on the vertices \(0, \dots, n-1\), and for \(m \le n\) let \(T^{(m)}\) be the matrix produced by the staged transitive-closure computation on \(A\) after its first \(m\) pivot stages. For every \(k < n\) and all vertices \(i\) and \(j\),

    \[T^{(k+1)}_{ij} = T^{(k)}_{ij} \lor \bigl(T^{(k)}_{ik} \land T^{(k)}_{kj}\bigr).\]

    Every operand of stage \(k + 1\) is read from the complete matrix saved after stage \(k\).

    theorem transitiveClosureStages_succ_cell {n : Nat} (adjacency : Fin n → Fin n → Bool)
    (k : Nat) (hk : k < n) (i j : Fin n) :
    let previous := (transitiveClosureStages adjacency k (by omega)).ret
    ((transitiveClosureStages adjacency (k + 1) (by omega)).ret.get i).get j =
      ((previous.get i).get j ||
        ((previous.get i).get ⟨k, hk⟩ && (previous.get ⟨k, hk⟩).get j))

    Cslib.Algorithms.Lean.TransitiveClosure.transitiveClosure_transition_assignments

    Charge one time unit for each cell assignment. For every Boolean adjacency matrix on \(n\) vertices, let \(a\) be the cost of running the initialization of the saved-matrix transitive-closure algorithm followed by all \(n\) of its stages, and let \(b\) be the cost of running the initialization alone. Then \(a - b = n^3\), where the subtraction is subtraction of natural numbers, truncated at \(0\). That is, the \(n\) transition stages together perform exactly \(n^3\) cell assignments.

    theorem transitiveClosure_transition_assignments {n : Nat}
    (adjacency : Fin n → Fin n → Bool) :
    (transitiveClosureStages adjacency n (by omega)).time -
        (transitiveClosureStages adjacency 0 (by omega)).time = n ^ 3
