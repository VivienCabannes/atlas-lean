    DefinitionKahn's topological sort#✓fully proved

    Cslib.Algorithms.Lean.TopologicalSort.sort

    Run Kahn's algorithm with a first-in first-out queue on a finite directed graph \(G\) whose vertices are enumerated as \(v_1, \dots, v_n\). Initially every vertex is remaining, the counter of each vertex is its number of in-neighbours, and the queue holds the vertices with no in-neighbours in enumeration order. At each of \(n\) steps, if the queue is nonempty, its front vertex \(x\) is removed from the queue and from the remaining vertices and appended to the output; then each distinct out-neighbour \(y\) of \(x\) that is still remaining, taken in order of first occurrence in the adjacency list of \(x\), has its counter decreased by one and joins the back of the queue if that counter was \(1\). If no vertices remain after the \(n\) steps, the result is a success with the output list; otherwise it is a failure with the output list as the processed vertices and the remaining vertices in enumeration order.

    public def sort {α : Type u} [DecidableEq α] [Hashable α]
    (g : DirectedAdjacency α) : Result α :=
  let advance := fun (s : List α × (α → Nat) × Std.Queue α × List α) =>
    match s.2.2.1.dequeue? with
    | none => s
    | some (vertex, queue) =>
        let remaining := s.1.erase vertex
        let rec dedup (seen : α → Bool) : List α → List α
          | [] => []
          | target :: neighbors =>
              if seen target then dedup seen neighbors
              else target :: dedup (Function.update seen target true) neighbors
        let scan := dedup (fun _ => false) (g.adjacency vertex)
        let (degrees, queue) := scan.foldl (fun result v =>
              if v ∈ remaining && g.hasEdge vertex v then
                let old := result.1 v
                (Function.update result.1 v (old - 1),
                  if old == 1 then result.2.enqueue v else result.2)
              else
                result) (s.2.1, queue)
        (remaining, degrees, queue, s.2.2.2 ++ [vertex])
  let final := advance^[g.vertices.length]
    (g.vertices,
      indegreeWithin g g.vertices,
      Std.Queue.mk [] (g.vertices.filter fun v => indegreeWithin g g.vertices v == 0),
      [])
  if final.1.isEmpty then .success final.2.2.2 else .failure final.2.2.2 final.1

    DefinitionTopological order#✓fully proved

    Cslib.Algorithms.Lean.TopologicalSort.IsTopologicalOrder

    A list \(L\) of vertices of a finite directed graph \(G\) is a topological order of \(G\) when \(L\) has no duplicates, a vertex lies in \(L\) exactly when it lies in the vertex enumeration of \(G\), and for every edge \(u \to v\) of \(G\) the first position of \(u\) in \(L\) is strictly smaller than the first position of \(v\) in \(L\).

    public def IsTopologicalOrder {α : Type u} [DecidableEq α]
    (g : DirectedAdjacency α) (order : List α) : Prop :=
  order.Nodup ∧
  (∀ v, v ∈ order ↔ v ∈ g.vertices) ∧
  ∀ u v, g.Edge u v → order.idxOf u < order.idxOf v
