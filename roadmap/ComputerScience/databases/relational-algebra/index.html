    DefinitionTruth value of a selection condition#✓fully proved

    Cslib.Databases.Cond.eval

    The truth value of a selection condition on a tuple \(t\) is defined by recursion: the always-true condition holds; \(a = c\) holds when \(t\) is defined at \(a\) with value \(c\); \(a = b\) holds when \(t(a) = t(b)\) as possibly undefined values, so it also holds when \(t\) is undefined at both \(a\) and \(b\); a negation holds when the negated condition fails; and a conjunction holds when both conditions hold.

    def eval [DecidableEq D] : Cond A D → Tuple A D → Bool
  | tt, _ => true
  | eqConst a c, t => t a == some c
  | eqAttr a b, t => t a == t b
  | not c, t => !c.eval t
  | and c c', t => c.eval t && c'.eval t
    inductive Cond (A D : Type*)
  /-- The condition that always holds. -/
  | tt
  /-- `a = c` for an attribute `a` and a constant `c`. -/
  | eqConst (a : A) (c : D)

  | eqAttr (a b : A)
  /-- Negation. -/
  | not (c : Cond A D)

  | and (c c' : Cond A D)

    DefinitionAttributes of a selection condition#✓fully proved

    Cslib.Databases.Cond.attrs

    The set of attributes mentioned by a selection condition, defined by recursion: it is empty for the always-true condition; for the comparison \(a = d\) of an attribute \(a\) with a constant \(d\) it is \(\{a\}\); for the comparison \(a = b\) of attributes \(a\) and \(b\) it is \(\{a, b\}\); for the negation \(\neg \varphi\) of a condition \(\varphi\) it is the set of attributes of \(\varphi\); and for the conjunction \(\varphi \land \psi\) of conditions \(\varphi\) and \(\psi\) it is the union of the attributes of \(\varphi\) and of \(\psi\).

  | eqAttr a b => {a, b}
  | not c => c.attrs
  | and c c' => c.attrs ∪ c'.attrs
