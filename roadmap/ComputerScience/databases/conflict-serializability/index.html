    DefinitionPrecedence graph#✓fully proved

    Cslib.Databases.precedenceGraph

    The precedence (serialization) graph of a schedule \(s\) of \(n\) transactions is the directed adjacency graph whose vertices are the transactions \(0, \dots, n - 1\), listed in increasing order, and whose adjacency list at a transaction \(i\) lists, in increasing order, the transactions \(j\) such that there is a precedence edge from \(i\) to \(j\) in \(s\).

    def precedenceGraph (s : List (Op n X)) : DirectedAdjacency (Fin n) where
  vertices := List.finRange n
  vertices_nodup := List.nodup_finRange n
  vertices_complete := List.mem_finRange
  adjacency i := (List.finRange n).filter fun j => decide (PrecedenceEdge s i j)

    DefinitionSerialization of a schedule along a transaction order#✓fully proved

    Cslib.Databases.serialize

    For a list \(\sigma\) of transactions and a schedule \(s\), the serialization of \(s\) along \(\sigma\) sorts the operations of \(s\) by the position of the first occurrence of their transaction in \(\sigma\), where a transaction that does not occur in \(\sigma\) gets the length of \(\sigma\) as its position. The sort is stable: operations with the same position keep their relative order in \(s\).

    def serialize (order : List (Fin n)) (s : List (Op n X)) : List (Op n X) :=
  s.insertionSort fun a b => order.idxOf a.txn ≤ order.idxOf b.txn
