    DefinitionA functional dependency holds in a relation#✓fully proved

    Cslib.Databases.FD.HoldsIn

    Let \(A\) be a type of attributes and \(V\) a type of values. A functional dependency \(X \to Y\) on \(A\) holds in a relation \(r\), a set of tuples \(A \to V\), when any two tuples \(t, u \in r\) that agree on every attribute of \(X\) also agree on every attribute of \(Y\).

    InductiveDerivability with Armstrong's axioms#✓fully proved

    Cslib.Databases.Derives

    Let \(F\) be a finite set of functional dependencies over a set \(A\) of attributes. Derivability from \(F\) is the least property of functional dependencies over \(A\) such that, for all finite sets \(X\), \(Y\), \(Z\) of attributes: every dependency of \(F\) is derivable; \(X \to Y\) is derivable whenever \(Y \subseteq X\) (reflexivity); if \(X \to Y\) is derivable, then so is \(X \cup Z \to Y \cup Z\) (augmentation); and if \(X \to Y\) and \(Y \to Z\) are derivable, then so is \(X \to Z\) (transitivity).

    inductive Derives (F : Finset (FD A)) : FD A → Prop
  /-- The dependencies of `F` are derivable. -/
  | mem {f : FD A} : f ∈ F → Derives F f
  /-- Reflexivity: `X → Y` whenever `Y ⊆ X`. -/
  | refl {X Y : Finset A} : Y ⊆ X → Derives F ⟨X, Y⟩
  /-- Augmentation: from `X → Y` derive `X ∪ Z → Y ∪ Z`. -/
  | augment {X Y : Finset A} (Z : Finset A) : Derives F ⟨X, Y⟩ → Derives F ⟨X ∪ Z, Y ∪ Z⟩
  /-- Transitivity: from `X → Y` and `Y → Z` derive `X → Z`. -/
  | trans {X Y Z : Finset A} : Derives F ⟨X, Y⟩ → Derives F ⟨Y, Z⟩ → Derives F ⟨X, Z⟩
    structure FD (A : Type*) where
  /-- The determining attributes. -/
  lhs : Finset A
  /-- The determined attributes. -/
  rhs : Finset A
deriving DecidableEq

    DefinitionOne round of the attribute-closure algorithm#✓fully proved

    Cslib.Databases.closureStep

    For a finite set \(F\) of functional dependencies and a finite set \(Y\) of attributes, one closure round returns \(Y\) together with the right side of every dependency of \(F\) whose left side is contained in \(Y\), that is, the set \(Y \cup \bigcup \{R : (L \to R) \in F,\ L \subseteq Y\}\).

    DefinitionIterated closure rounds#✓fully proved

    Cslib.Databases.closureLoop

    Let \(F\) be a finite set of functional dependencies, \(n\) a natural number and \(Y\) a finite set of attributes. The loop returns \(Y\) if \(n = 0\) or if one closure round for \(F\) leaves \(Y\) unchanged; otherwise it returns the loop with \(n - 1\) rounds started from the result of one closure round applied to \(Y\). Thus it repeats closure rounds from \(Y\) until nothing changes, for at most \(n\) rounds.

    def closureLoop (F : Finset (FD A)) : ℕ → Finset A → Finset A
  | 0, Y => Y
  | n + 1, Y => if closureStep F Y = Y then Y else closureLoop F n (closureStep F Y)
