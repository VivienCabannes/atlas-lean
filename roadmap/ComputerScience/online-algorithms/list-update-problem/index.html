    DefinitionCost of move-to-front#✓fully proved

    Cslib.Algorithms.Lean.Online.ListUpdate.mtfCost

    Starting from a list \(L\), move-to-front serves a request sequence \(\sigma\) one request at a time: a request \(x\) costs the position of \(x\) in the current list, counting from \(1\) (an item not in the list costs its length plus one), and then \(x\) is moved to the front (inserted at the front if absent). The cost of move-to-front on \(\sigma\) from \(L\) is the sum of these access costs.

    def mtfCost : List α → List α → ℕ
  | _, [] => 0
  | L, x :: σ => accessCost L x + mtfCost (mtf L x) σ
    def accessCost (L : List α) (x : α) : ℕ := L.idxOf x + 1

    DefinitionInversion set of two lists#✓fully proved

    Cslib.Algorithms.Lean.Online.ListUpdate.invSet

    For lists \(M\) and \(L\), the inversion set is the set of pairs \((a, b)\) of items of \(M\) with \(a\) before \(b\) in \(M\) and \(b\) before \(a\) in \(L\), that is, the pairs that \(M\) and \(L\) order differently.     DefinitionOffline cost without free exchanges#✓fully proved

    Cslib.Algorithms.Lean.Online.ListUpdate.offlineCost

    Given lists \(L_0, L_1, L_2, \dots\), the offline cost of a request sequence \(\sigma = x_0 x_1 \cdots x_{m-1}\) is the sum over \(t < m\) of the access cost of \(x_t\) in \(L_t\) (its position, counting from \(1\)) plus the number of inversions between \(L_t\) and \(L_{t+1}\). That is, the algorithm serves request \(t\) with \(L_t\) and then rearranges it into \(L_{t+1}\), paying one for each pair of items whose relative order it changes.

    Adding free exchanges gives the offline cost with free exchanges.

    def offlineCost (L : ℕ → List α) : List α → ℕ
  | [] => 0
  | x :: σ => accessCost (L 0) x + inv (L 0) (L 1) + offlineCost (fun t => L (t + 1)) σ
    def accessCost (L : List α) (x : α) : ℕ := L.idxOf x + 1

    DefinitionFree move#✓fully proved

    Cslib.Algorithms.Lean.Online.ListUpdate.freeMove

    A free exchange (Sleator and Tarjan): right after accessing \(x\) in a list \(L\), move \(x\) forward to index \(j\) (indices counted from \(0\)), at no charge. If the index of \(x\) in \(L\) is at most \(j\), the list is unchanged, so \(x\) never moves backward for free; otherwise the result is obtained by erasing the first occurrence of \(x\) from \(L\) and inserting \(x\) back so that it has index \(j\).

    def freeMove (L : List α) (x : α) (j : ℕ) : List α :=
  if L.idxOf x ≤ j then L else (L.erase x).take j ++ x :: (L.erase x).drop j

    DefinitionOffline cost with free exchanges#✓fully proved

    Cslib.Algorithms.Lean.Online.ListUpdate.offlineCostFree

    Given lists \(L_0, L_1, L_2, \dots\), target indices \(J_0, J_1, J_2, \dots\) and a request sequence \(\sigma = x_0 x_1 \cdots x_{m-1}\), let \(L_t'\) be the list obtained from \(L_t\) by the free exchange that moves \(x_t\) forward to index \(J_t\) (counting from \(0\)); it equals \(L_t\) if \(x_t\) already has index at most \(J_t\). The offline cost with free exchanges of \(\sigma\) is the sum over \(t < m\) of the access cost of \(x_t\) in \(L_t\) (its position, counting from \(1\)) plus the number of inversions between \(L_t'\) and \(L_{t+1}\).

    This is the model of Sleator and Tarjan: the free exchange costs nothing, and each pair of items whose relative order changes from \(L_t'\) to \(L_{t+1}\) costs one. With no free moves it is the offline cost without free exchanges.

    def offlineCostFree (L : ℕ → List α) (J : ℕ → ℕ) : List α → ℕ
  | [] => 0
  | x :: σ => accessCost (L 0) x + inv (freeMove (L 0) x (J 0)) (L 1) +
      offlineCostFree (fun t => L (t + 1)) (fun t => J (t + 1)) σ
    def accessCost (L : List α) (x : α) : ℕ := L.idxOf x + 1

    Cslib.Algorithms.Lean.Online.ListUpdate.not_competitive

    Let \(M\) be a nonempty list of \(\ell\) distinct items and let \(A\) be a deterministic online list-update algorithm on the items of \(M\). Let \(c\), \(d\) and \(b\) be natural numbers with \(c (\ell + 1) < 2 \ell d\) (so \(d \ge 1\) and \(c / d < 2\ell / (\ell + 1) = 2 - 2/(\ell + 1)\)). Then there are a request sequence \(\sigma\), each request an item of \(M\), and lists \(L_0, L_1, L_2, \dots\), each a rearrangement of \(M\), with \(L_0 = M\), such that \(c \cdot C + d \cdot b < d \cdot K\), where \(C\) is the offline cost without free exchanges of \(L_0, L_1, \dots\) on \(\sigma\) and \(K\) is the cost of \(A\) on \(\sigma\) from its initial state.

    The offline lists make no free exchanges, so the same holds with the offline cost with free exchanges in place of \(C\).
