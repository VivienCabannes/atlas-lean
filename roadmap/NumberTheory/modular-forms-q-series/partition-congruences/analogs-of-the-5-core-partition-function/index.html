    Analogs of the 5-core partition function

    DefinitionRamanujan's general theta function at powers of q#✓fully proved

    MetaMathlibExt.ramanujanThetaPow

    For positive integers \(i\) and \(j\), \(f(q^i, q^j)\) is the integer power series \(\sum_{n \in \mathbb{Z}} q^{i n(n+1)/2 + j n(n-1)/2}\), that is, Ramanujan's \(f(a, b) = \sum_{n \in \mathbb{Z}} a^{n(n+1)/2} b^{n(n-1)/2}\) at \(a = q^i\) and \(b = q^j\).

    Since \(i, j \ge 1\), only integers \(n\) with \(|n| \le m\) contribute to the coefficient of \(q^m\), so each coefficient is a finite count.

    def ramanujanThetaPow (i j : ℕ+) : ℤ⟦X⟧ :=
  mk fun m => (((Finset.Icc (-(m : ℤ)) m).filter fun n =>
    ((i : ℕ) : ℤ) * (n * (n + 1) / 2) + ((j : ℕ) : ℤ) * (n * (n - 1) / 2) = m).card : ℤ)

    DefinitionThe 5-core counts#✓fully proved

    MetaMathlibExt.fiveCoreCount

    For a natural number \(n\), \(c_5(n)\) is the coefficient of \(q^n\) in the integer power series \(f_5^5 / f_1\), where \(f_k = \prod_{m \ge 1} (1 - q^{km})\) is the Euler product. The series \(f_5^5 / f_1\) is the generating function of 5-core partitions.

    noncomputable def fiveCoreCount (n : ℕ) : ℤ :=
  coeff n (qEulerProduct 5 ^ 5 * invOfUnit (pentagonalSeries ℤ) 1)
    noncomputable def qEulerProduct (k : ℕ) : ℤ⟦X⟧ :=
  ∏' m : ℕ, (1 - X ^ (k * (m + 1)))

    DefinitionThe φ-analog of the 5-core partition function#✓fully proved

    MetaMathlibExt.phiFiveCoreAnalog

    Let \(\varphi(q) = \sum_{n \in \mathbb{Z}} q^{n^2}\) be Ramanujan's theta function. For a natural number \(n\), \(\bar a_5(n)\) is the coefficient of \(q^n\) in the integer power series \(\varphi^5(-q^5)/\varphi(-q)\) (the denominator has constant term \(1\), so the quotient is a power series).

    noncomputable def phiFiveCoreAnalog (n : ℕ) : ℤ :=
  coeff n (expand 5 (by norm_num) (rescale (-1) (ramanujanThetaPow 1 1)) ^ 5 *
    invOfUnit (rescale (-1) (ramanujanThetaPow 1 1)) 1)

    TheoremGenerating function of the 5-core counts#✓fully proved

    MetaMathlibExt.mk_fiveCoreCount_mul
