    TheoremOverpartitions of \(5n\) modulo \(5\), explicit form#✓fully proved

    MetaMathlibExt.overpartition_mul_five_mod_five

    For every integer \(n \ge 1\), the number of pairs \((P, S)\), where \(P\) is a finite multiset of positive integers with sum \(5n\) and \(S\) is a finite set of natural numbers each belonging to \(P\), is congruent modulo \(5\) to \((-1)^n\) times the number of ordered triples \((x, y, z)\) of integers with \(x^2 + y^2 + z^2 = n\).

    These pairs encode the overpartitions of \(5n\): \(P\) is the multiset of parts and \(S\) is the set of overlined part sizes.

    public theorem overpartition_mul_five_mod_five
    (n : ℕ) (hn : 1 ≤ n) :
    Int.ModEq 5
      (Nat.card {
        p : Multiset ℕ × Finset ℕ //
          (∀ a ∈ p.1, 0 < a) ∧
          p.1.sum = 5 * n ∧
          ∀ a ∈ p.2, a ∈ p.1
      })
      (((-1 : ℤ) ^ n) * Nat.card {
        x : ℤ × ℤ × ℤ //
          x.1 ^ 2 + x.2.1 ^ 2 + x.2.2 ^ 2 = n
      })

    LemmaOverpartitions as pairs of a multiset and a set#✓fully proved

    Nat.Overpartition.natCard_eq_card_subtype

    For every natural number \(m\), the number of overpartitions of \(m\) equals the number of pairs \((P, S)\) in which \(P\) is a finite multiset of positive integers with sum \(m\) and \(S\) is a finite set of natural numbers each belonging to \(P\).

    public lemma natCard_eq_card_subtype (m : ℕ) :
    Nat.card (Nat.Overpartition m) =
      Nat.card { p : Multiset ℕ × Finset ℕ //
        (∀ a ∈ p.1, 0 < a) ∧ p.1.sum = m ∧ ∀ a ∈ p.2, a ∈ p.1 }

    MetaMathlibExt.eulerFunction_six_cube_nine_six_div_eq

    \[ \frac{E_6^3 E_9^6}{E_3^3 E_{18}^3} = \frac{E_6^8 E_9}{E_3^4 E_{18}^2} - q^3 \, \frac{E_{18}^6}{E_9^3}. \]

      E 6 ^ 8 * E 9 / (E 3 ^ 4 * E 18 ^ 2) - q ^ 3 * (E 18 ^ 6 / E 9 ^ 3)
