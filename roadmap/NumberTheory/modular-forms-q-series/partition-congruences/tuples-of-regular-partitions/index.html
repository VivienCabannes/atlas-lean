    DefinitionNumber of \(k\)-tuples of \(\ell\)-regular partitions#✓fully proved

    MetaMathlibExt.kTupleRegularPartitionCount

    For natural numbers \(\ell\), \(k\) and \(n\), the number \(T_{\ell,k}(n)\) is defined by recursion on \(k\): \(T_{\ell,0}(n)\) is \(1\) if \(n = 0\) and \(0\) otherwise, and

    \[T_{\ell,k+1}(n) = \sum_{i=0}^{n} r_\ell(i) \, T_{\ell,k}(n-i),\]

    where \(r_\ell(i)\) is the number of \(\ell\)-regular partitions of \(i\).

    Peeling off the first component in this way, \(T_{\ell,k}(n)\) counts the \(k\)-tuples \((\lambda_1, \dots, \lambda_k)\) of \(\ell\)-regular partitions of \(n_1, \dots, n_k\) with \(n_1 + \dots + n_k = n\).

    public def kTupleRegularPartitionCount (ℓ : ℕ) : ℕ → ℕ → ℕ
  | 0, n => if n = 0 then 1 else 0
  | k + 1, n => ∑ i ∈ Finset.range (n + 1),
      lRegularPartitionCount ℓ i * kTupleRegularPartitionCount ℓ k (n - i)

    DefinitionBounded bilateral series#✓fully proved

    MetaMathlibExt.boundedBilateralSeries

    Given functions \(e, w : \mathbb{Z} \to \mathbb{Z}\), the bounded bilateral series of \(e\) and \(w\) is the power series over \(\mathbb{Z}\) whose coefficient of \(q^n\), for each natural number \(n\), is the sum of \(w(m)\) over the integers \(m\) with \(-n-1 \le m \le n+1\) and \(e(m) = n\).

    It agrees with the bilateral series \(\sum_{m \in \mathbb{Z}} w(m) q^{e(m)}\) whenever \(e\) takes no negative values and, for every natural number \(n\), every integer \(m\) with \(e(m) = n\) satisfies \(|m| \le n + 1\), as holds for the quadratic exponents used in Lemmas 1, 3 and 5 of the source; it is not intended for other exponents.

    public def boundedBilateralSeries (exponent weight : ℤ → ℤ) : PowerSeries ℤ :=
  PowerSeries.mk fun n =>
    ∑ m ∈ Finset.Icc (-(n : ℤ) - 1) ((n : ℤ) + 1),
      if exponent m = (n : ℤ) then weight m else 0
