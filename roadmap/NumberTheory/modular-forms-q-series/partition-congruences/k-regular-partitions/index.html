    TheoremFor small \(n\) every partition is \((\ell, k)\)-regular#✓fully proved

    MetaMathlibExt.regularPartitionCount_of_lt

    Let \(\ell\), \(k\) and \(n\) be natural numbers with \(n < \ell\) and \(n < k\), and write \(b_{\ell,k}(n)\) for the number of \((\ell, k)\)-regular partitions of \(n\) (partitions none of whose parts is divisible by \(\ell\) or by \(k\)) and \(p(n)\) for the number of all partitions of \(n\). Then every partition of \(n\) is \((\ell, k)\)-regular, so \(b_{\ell,k}(n) = p(n)\).

    public theorem regularPartitionCount_of_lt {l k n : ℕ} (hl : n < l) (hk : n < k) :
    regularPartitionCount l k n = Fintype.card n.Partition
