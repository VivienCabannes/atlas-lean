    DefinitionFrobenius partitions with at most \(k\) repetitions#✓fully proved

    MetaMathlibExt.frobeniusPartitionRepCount

    For natural numbers \(k\) and \(n\), \(\varphi_k(n)\) is the number of generalized Frobenius partitions of \(n\) in which each integer appears at most \(k\) times in each row. Concretely, \(\varphi_k(n)\) is the number of pairs of functions \(m_1, m_2 \colon \{0, 1, \dots, n\} \to \{0, 1, \dots, k\}\) with \(\sum_i m_1(i) = \sum_i m_2(i)\) and \(\sum_i (i + 1)\, m_1(i) + \sum_i i\, m_2(i) = n\).

    Here a generalized Frobenius partition of \(n\) is a two-rowed array of nonnegative integers with \(r\) columns, both rows nonincreasing, whose entries sum to \(n - r\); its entries are at most \(n\), and \(m_1(i)\), \(m_2(i)\) count how often \(i\) appears in the top and bottom rows.

    public def frobeniusPartitionRepCount (k n : ℕ) : ℕ :=
  ((Finset.univ : Finset ((Fin (n + 1) → Fin (k + 1)) × (Fin (n + 1) → Fin (k + 1)))).filter
    fun p => ∑ i : Fin (n + 1), (p.1 i : ℕ) = ∑ i : Fin (n + 1), (p.2 i : ℕ) ∧
      ∑ i : Fin (n + 1), (p.1 i : ℕ) * ((i : ℕ) + 1) +
        ∑ i : Fin (n + 1), (p.2 i : ℕ) * (i : ℕ) = n).card

    MetaMathlibExt.ramanujanTheta_mul_of_mul_eq

    Let \(f(a,b) = \sum_{n \in \mathbb{Z}} a^{n(n+1)/2} b^{n(n-1)/2}\) be Ramanujan's general theta function. If \(a, b, c, d\) are complex numbers with \(a \ne 0\), \(|ab| < 1\) and \(ab = cd\), then

    \[f(a,b)\,f(c,d) = f(ad,bc)\,f(ac,bd) + a\,f(c/a, a^2bd)\,f(d/a, a^2bc).\]

    In each of the six theta functions the two arguments have product of modulus \(|ab|\) or \(|ab|^2\), which is less than \(1\), so every series converges.

    public theorem_wanted ramanujanTheta_mul_of_mul_eq {a b c d : ℂ} (ha : a ≠ 0)
    (hab : ‖a * b‖ < 1) (h : a * b = c * d) :
    ramanujanThetaRaw a b * ramanujanThetaRaw c d =
      ramanujanThetaRaw (a * d) (b * c) * ramanujanThetaRaw (a * c) (b * d) +
        a * ramanujanThetaRaw (c / a) (a ^ 2 * b * d) *
          ramanujanThetaRaw (d / a) (a ^ 2 * b * c)
    noncomputable def ramanujanThetaRaw (a b : ℂ) : ℂ :=
