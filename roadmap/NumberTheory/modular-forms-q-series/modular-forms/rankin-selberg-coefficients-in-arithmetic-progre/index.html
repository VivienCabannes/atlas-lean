    Rankin–Selberg coefficients in arithmetic progressions

    DefinitionNormalized Fourier coefficients of a cusp form#✓fully proved

    MetaMathlibExt.cuspFormNormalizedCoeff

    Let \(f\) be a cusp form of weight \(k \in \mathbb{Z}\) for \(\mathrm{SL}_2(\mathbb{Z})\), with \(q\)-expansion \(f(z) = \sum_{n \ge 0} a_f(n) e(nz)\), where \(e(z) = e^{2\pi i z}\). For each natural number \(n\), the normalized Fourier coefficient of \(f\) is the complex number \(\lambda_f(n) = a_f(n) / n^{(k-1)/2}\), where \(n^{(k-1)/2}\) is the real power.

    At \(n = 0\) the real power follows \(0^0 = 1\) and \(0^s = 0\) for \(s \ne 0\), and division by \(0\) gives \(0\).

    public noncomputable def cuspFormNormalizedCoeff {k : ℤ} (f : CuspForm 𝒮ℒ k) (n : ℕ) : ℂ :=
  (qExpansion 1 f).coeff n / (((n : ℝ) ^ (((k : ℝ) - 1) / 2) : ℝ) : ℂ)

    DefinitionNormalized Hecke eigenform#✓fully proved

    MetaMathlibExt.IsNormalizedHeckeEigenform

    Let \(f\) be a cusp form of weight \(k \in \mathbb{Z}\) for \(\mathrm{SL}_2(\mathbb{Z})\), with normalized Fourier coefficients \(\lambda_f\). Then \(f\) is a normalized Hecke eigenform when \(\lambda_f(1) = 1\) and, for all positive integers \(m\) and \(n\), \(\lambda_f(m) \lambda_f(n) = \sum_{d \mid \gcd(m, n)} \lambda_f(mn/d^2)\), the sum running over the positive divisors \(d\) of \(\gcd(m, n)\). The set of these forms is denoted \(H_k^*\).

    At level one this is equivalent to \(f\) being a simultaneous eigenform of all Hecke operators normalized by \(a_f(1) = 1\), where \(f(z) = \sum_{n \ge 0} a_f(n) e^{2\pi i n z}\) is the \(q\)-expansion of \(f\).

    public def IsNormalizedHeckeEigenform {k : ℤ} (f : CuspForm 𝒮ℒ k) : Prop :=
  cuspFormNormalizedCoeff f 1 = 1 ∧
    ∀ m n : ℕ, 0 < m → 0 < n →
      cuspFormNormalizedCoeff f m * cuspFormNormalizedCoeff f n =
        ∑ d ∈ (Nat.gcd m n).divisors, cuspFormNormalizedCoeff f (m * n / d ^ 2)
    public noncomputable def cuspFormNormalizedCoeff {k : ℤ} (f : CuspForm 𝒮ℒ k) (n : ℕ) : ℂ :=
  (qExpansion 1 f).coeff n / (((n : ℝ) ^ (((k : ℝ) - 1) / 2) : ℝ) : ℂ)

    DefinitionRankin–Selberg coefficients#✓fully proved

    MetaMathlibExt.rankinSelbergCoeff

    Let \(f\) be a cusp form of weight \(k \in \mathbb{Z}\) for \(\mathrm{SL}_2(\mathbb{Z})\), with normalized Fourier coefficients \(\lambda_f\). The Rankin–Selberg coefficients of \(f\) form the arithmetic function \(\lambda_{f \times f}\) with \(\lambda_{f \times f}(0) = 0\) and, for \(n \ge 1\), \(\lambda_{f \times f}(n) = \sum_{l^2 m = n} \lambda_f(m)^2\), the sum running over the pairs of positive integers \((l, m)\) with \(l^2 m = n\); equivalently, \(\lambda_{f \times f}(n)\) is the sum of \(\lambda_f(n/d)^2\) over the positive divisors \(d\) of \(n\) that are perfect squares.

    These are the Dirichlet coefficients of \(L(f \times f, s) = \zeta(2s) \sum_{n \ge 1} \lambda_f(n)^2 n^{-s}\). The \(w\)-th power of \(\lambda_{f \times f}\) under Dirichlet convolution is denoted \(\lambda_{w, f \times f}\).

    public noncomputable def rankinSelbergCoeff {k : ℤ} (f : CuspForm 𝒮ℒ k) : ArithmeticFunction ℂ :=
  ⟨fun n => ∑ d ∈ n.divisors with IsSquare d, cuspFormNormalizedCoeff f (n / d) ^ 2, by simp⟩
    public noncomputable def cuspFormNormalizedCoeff {k : ℤ} (f : CuspForm 𝒮ℒ k) (n : ℕ) : ℂ :=
  (qExpansion 1 f).coeff n / (((n : ℝ) ^ (((k : ℝ) - 1) / 2) : ℝ) : ℂ)

    TheoremSums of squared normalized coefficients at perfect powers in arithmetic progressions#●ready to prove

    MetaMathlibExt.sum_cuspFormNormalizedCoeff_pow_sq_arithmeticProgression

    Let \(f\) be a normalized Hecke eigenform of weight \(k \in \mathbb{Z}\) for \(\mathrm{SL}_2(\mathbb{Z})\), with normalized Fourier coefficients \(\lambda_f\), let \(j \ge 2\) be an integer, and put \(\delta = 92/597\) if \(j = 2\) and \(\delta = 92/(69(j-1)(j+3) + 247)\) if \(j \ge 3\). Then there are real numbers \(c_q > 0\), one for each prime \(q\), with the following property: for every \(\varepsilon > 0\) there is a real constant \(C\) such that for every prime \(q\), every natural number \(l\) coprime to \(q\) and every real \(x \ge 1\) with \(q \le x^{3\delta/4}\), \(\bigl|\sum_{n} \lambda_f(n^j)^2 - c_q x / \varphi(q)\bigr| \le C q x^{1 - 3\delta/2 + \varepsilon}\), where \(n\) runs over the integers \(1 \le n \le x\) with \(n \equiv l \pmod q\) and \(\varphi\) is Euler's totient function.

    Hua quotes this result from Zou et al. [52, Theorem 1]. The constant \(c_q\) is allowed to depend on \(q\), a weaker reading of the printed main term, whose constant does not depend on \(q\); the constant \(C\) depends only on \(f\), \(j\) and \(\varepsilon\).

    public theorem_wanted sum_cuspFormNormalizedCoeff_pow_sq_arithmeticProgression {k : ℤ}

    let δ : ℝ := if j = 2 then 92 / 597 else 92 / (69 * ((j : ℝ) - 1) * ((j : ℝ) + 3) + 247)

    MetaMathlibExt.sum_rankinSelbergCoeff_pow_arithmeticProgression

    Let \(f\) be a normalized Hecke eigenform of weight \(k \in \mathbb{Z}\) for \(\mathrm{SL}_2(\mathbb{Z})\), with Rankin–Selberg coefficients \(\lambda_{f \times f}\), let \(w \ge 2\) be an integer, write \(\lambda_{w, f \times f}\) for the \(w\)-fold Dirichlet convolution power of \(\lambda_{f \times f}\), and put \(\vartheta_w = 92/(247w + 10)\).     The printed hypothesis \(q \ll x^{\vartheta_w}\) is read as \(q \le x^{\vartheta_w}\), and the polynomial is allowed to depend on \(q\); the constant \(C\) depends only on \(f\), \(w\) and \(\varepsilon\).
