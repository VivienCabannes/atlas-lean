    Coefficients of mock theta functions

    DefinitionThe eighth-order mock theta function \(v(q)\)#✓fully proved

    MetaMathlibExt.mockThetaV

    The mock theta function \(v(q) = \sum_{n \ge 0} q^{(n+1)^2} (-q; q^2)_n / (q; q^2)_{n+1}\), where \((-q; q^2)_n = \prod_{k=0}^{n-1} (1 + q^{2k+1})\) and \((q; q^2)_{n+1} = \prod_{k=0}^{n} (1 - q^{2k+1})\), is taken as a power series in \(q\) with integer coefficients.

    The \(n\)th summand has order \((n+1)^2\), so the coefficient of \(q^m\) only involves the summands with \(n \le m\).

    public noncomputable def mockThetaV : ℤ⟦X⟧ :=
  PowerSeries.mk fun m => coeff m (∑ n ∈ Finset.range (m + 1),
    X ^ ((n + 1) ^ 2) * (∏ k ∈ Finset.range n, (1 + X ^ (2 * k + 1))) *
      invOfUnit (∏ k ∈ Finset.range (n + 1), (1 - X ^ (2 * k + 1))) 1)

    DefinitionThe sixth-order mock theta function \(\lambda\)#✓fully proved

    MetaMathlibExt.mockThetaLambda

    With \((a; b)_n = \prod_{k=0}^{n-1} (1 - a b^k)\), the mock theta function \(\lambda\) is the integer power series

    \[ \lambda(q) = \sum_{n \ge 0} \frac{(-1)^n q^n (q; q^2)_n}{(-q; q)_n}. \]

    public noncomputable def mockThetaLambda : ℤ⟦X⟧ :=
  PowerSeries.mk fun m => coeff m (∑ n ∈ Finset.range (m + 1),
    (-1) ^ n * X ^ n * (∏ k ∈ Finset.range n, (1 - X ^ (2 * k + 1))) *
      invOfUnit (∏ k ∈ Finset.range n, (1 + X ^ (k + 1))) 1)

    DefinitionRamanujan's theta function at monomial arguments#✓fully proved

    MetaMathlibExt.ramanujanThetaMonomial

    For an integer \(\varepsilon\) and natural numbers \(a\) and \(b\), \(f(\varepsilon q^a, \varepsilon q^b)\) is the integer power series in \(q\) whose coefficient of \(q^n\) is the sum of \(\varepsilon^{m^2}\) over the integers \(m\) with \(|m| \le n + 1\) and \(a \cdot m(m+1)/2 + b \cdot m(m-1)/2 = n\).

    When \(a + b \ge 1\) the exponent \(a \cdot m(m+1)/2 + b \cdot m(m-1)/2\) is at least \(|m|(|m|-1)/2\), so the bound \(|m| \le n + 1\) excludes no term and this is Ramanujan's \(f(c, d) = \sum_{m \in \mathbb{Z}} c^{m(m+1)/2} d^{m(m-1)/2}\) at \(c = \varepsilon q^a\) and \(d = \varepsilon q^b\); the definition is meant for \(a + b \ge 1\). Special cases are \(\psi(q) = f(q, q^3)\) and \(f(-q) = f(-q, -q^2)\), which equals \((q; q)_\infty = \prod_{k \ge 1} (1 - q^k)\).

    public def ramanujanThetaMonomial (ε : ℤ) (a b : ℕ) : ℤ⟦X⟧ :=
  PowerSeries.mk fun n => ∑ m ∈ Finset.Icc (-(n : ℤ) - 1) ((n : ℤ) + 1),
    if (a : ℤ) * (m * (m + 1) / 2) + (b : ℤ) * (m * (m - 1) / 2) = n then
      ε ^ (m.natAbs ^ 2) else 0

    TheoremInfinite family of congruences modulo 2 for \(v(q)\)#●ready to prove

    MetaMathlibExt.mockThetaV_congruences_mod_two

    Let \(P_v(n)\) be the coefficient of \(q^n\) in the eighth-order mock theta function \(v(q)\), and for \(k \ge 1\) let \(f_k = \prod_{m \ge 1} (1 - q^{km})\). Let \(p \ge 3\) be a prime whose Legendre symbol \(\left(\frac{-2}{p}\right)\) equals \(-1\), and let \(\alpha \ge 0\) be an integer. Then the integer power series \(f_1 \sum_{n \ge 0} P_v\bigl(2 p^{2\alpha} n + (3 p^{2\alpha} + 1)/4\bigr) q^n\) and \(f_2 f_4^2\) have congruent coefficients modulo \(2\). Moreover, for every \(n \ge 0\) and every \(j\) with \(1 \le j \le p - 1\), \(P_v\bigl(2 p^{2\alpha+2} n + 2 p^{2\alpha+1} j + (3 p^{2\alpha+2} + 1)/4\bigr) \equiv 0 \pmod 2\).

    The divisions by \(4\) are exact since \(p^2 \equiv 1 \pmod 8\). Since \(f_1\) has an inverse with integer coefficients, the first congruence says that \(\sum_{n \ge 0} P_v(2 p^{2\alpha} n + (3 p^{2\alpha} + 1)/4) q^n \equiv \psi(q) \psi(q^2) \pmod 2\), where \(\psi(q) = \sum_{n \ge 0} q^{n(n+1)/2}\), so that \(\psi(q) \psi(q^2) = f_2 f_4^2 / f_1\).

    public theorem_wanted mockThetaV_congruences_mod_two (p α : ℕ) [Fact p.Prime] (hp : 3 ≤ p)
    (hleg : legendreSym p (-2) = -1) :
    (∀ i, coeff i (𝔣 1 * PowerSeries.mk (fun n =>
        coeff (2 * p ^ (2 * α) * n + (3 * p ^ (2 * α) + 1) / 4) mockThetaV)) ≡
      coeff i (𝔣 2 * 𝔣 4 ^ 2) [ZMOD 2]) ∧
