    MetaMathlibExt.fixedDegreeMonic

    For a finite field \(F\) and a natural number \(n\), \(M_n\) is the finite set of monic polynomials of degree \(n\) over \(F\): the polynomials \(X^n + c_{n-1} X^{n-1} + \dots + c_1 X + c_0\) with \(c_0, \dots, c_{n-1} \in F\).

    public noncomputable def fixedDegreeMonic (F : Type*) [Field F] [Fintype F] [DecidableEq F]
    (n : ℕ) :
    Finset (Polynomial F) :=
  Finset.univ.image fun c : Fin n → F =>
    X ^ n + ∑ i : Fin n, C (c i) * X ^ (i : ℕ)

    Definition\(h\)-free polynomials#✓fully proved

    MetaMathlibExt.hFree

    Let \(F\) be a field and \(h\) a natural number. The set \(S_h\) of \(h\)-free polynomials over \(F\) consists of the monic polynomials \(f\) over \(F\) such that no monic irreducible polynomial \(P\) over \(F\) satisfies \(P^h \mid f\).

    The condition makes sense for every natural number \(h\); the paper's asymptotic theorems separately assume \(h \ge 2\).

    public def hFree (F : Type*) [Field F] (h : ℕ) : Set (Polynomial F) :=
  {f | f.Monic ∧ ∀ P ∈ monicIrreducible F, ¬P ^ h ∣ f}
    public def monicIrreducible (F : Type*) [Field F] : Set (Polynomial F) :=
  {P | P.Monic ∧ Irreducible P}

    MetaMathlibExt.omegaMult

    Let \(F\) be a field and \(k \in \mathbb{N}\). For a nonzero polynomial \(f\) over \(F\), \(\omega_k(f)\) is the number of distinct monic irreducible polynomials \(P\) dividing \(f\) whose multiplicity in \(f\) (the largest \(m\) with \(P^m \mid f\)) is exactly \(k\).     public noncomputable def omegaMult (F : Type*) [Field F] (k : ℕ) (f : Polynomial F) : ℕ := by
  classical
  exact if f = 0 then 0 else
    ((normalizedFactors f).toFinset.filter fun P => (normalizedFactors f).count P = k).card

    DefinitionDegree-nondecreasing functions#✓fully proved

    MetaMathlibExt.IsDegreeNondecreasing

    Let \(F\) be a field, \(U\) a set of polynomials over \(F\) and \(G\) a real-valued function on polynomials over \(F\). Then \(G\) is degree-nondecreasing on \(U\) when for all \(f_1, f_2 \in U\) with \(\deg f_2 \le \deg f_1\) we have \(G(f_2) \le G(f_1)\). Here \(\deg\) is the natural degree, with \(\deg 0 = 0\).

    In particular \(G\) takes the same value on members of \(U\) of equal degree. The natural degree is adequate because \(U\) will consist of monic, hence nonzero, polynomials.

    public def IsDegreeNondecreasing (F : Type*) [Field F] (U : Set (Polynomial F))
    (G : Polynomial F → ℝ) : Prop :=
  ∀ ⦃f₁ f₂ : Polynomial F⦄, f₁ ∈ U → f₂ ∈ U → f₂.natDegree ≤ f₁.natDegree →
    G f₂ ≤ G f₁

    MetaMathlibExt.HasNormalOrder

    Let \(F\) be a finite field, let \(U\) be a set of polynomials over \(F\), and let \(g, G\) be real-valued functions on polynomials over \(F\). For \(n \in \mathbb{N}\) let \(M_n\) be the set of monic polynomials of degree \(n\) over \(F\). Then \(g\) has normal order \(G\) on \(U\) when \(g\) and \(G\) are nonnegative on \(U\), \(G\) is degree-nondecreasing on \(U\) (for \(f_1, f_2 \in U\), \(\deg f_2 \le \deg f_1\) implies \(G(f_2) \le G(f_1)\), with \(\deg\) the natural degree), and for every real \(\varepsilon > 0\) the number of \(f \in U \cap M_n\) for which \((1 - \varepsilon)G(f) < g(f) < (1 + \varepsilon)G(f)\) fails is \(o(|U \cap M_n|)\) as \(n \to \infty\).

    The paper takes \(g, G : U \to \mathbb{R}_{\ge 0}\); here both are total real-valued functions, with nonnegativity imposed on \(U\).
