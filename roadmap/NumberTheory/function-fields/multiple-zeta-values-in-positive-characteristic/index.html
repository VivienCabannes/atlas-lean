    MathlibExt.NumberTheory.ZagierHoffmanPositiveCharWanted.ZagierHoffmanPositiveChar.ζ_A

    Let \(F\) be a finite field, \(A = F[t]\), and \(K_\infty = F((1/t))\) the completion of the rational function field \(F(t)\) at the place at infinity. For a natural number \(r\) and positive integers \(s_1, \dots, s_r\), the multiple zeta value is

    \[\zeta_A(s_1, \dots, s_r) = \sum \frac{1}{a_1^{s_1} \cdots a_r^{s_r}} \in K_\infty,\]

    where the sum runs over all \(r\)-tuples \((a_1, \dots, a_r)\) of monic polynomials in \(A\) with \(\deg a_1 > \deg a_2 > \dots > \deg a_r\).

    noncomputable def ζ_A {r : ℕ} (𝔰 : Fin r → ℕ+) : CompletionAtInfty F :=
  ∑' a : monicStrictAntiNatDegree F r, (∏ i, a.val i ^ (𝔰 i : ℕ))⁻¹
    abbrev monicStrictAntiNatDegree (r : ℕ) :=
  {a : Fin r → Polynomial F // StrictAnti (Polynomial.natDegree ∘ a) ∧ ∀ i, (a i).Monic}

    DefinitionDimension sequence for multiple zeta values#✓fully proved

    MathlibExt.NumberTheory.ZagierHoffmanPositiveCharWanted.ZagierHoffmanPositiveChar.d

    Let \(F\) be a finite field with \(q\) elements. The sequence \(d(w)\), for natural numbers \(w\), is defined by \(d(0) = 1\), \(d(w) = 2^{w-1}\) for \(1 \le w \le q - 1\), \(d(q) = 2^{q-1} - 1\), and \(d(w) = d(w - 1) + d(w - 2) + \dots + d(w - q)\) for \(w > q\).

    This is the sequence of Conjecture 1.5 and Theorems A and D of T. N. Dac, On Zagier-Hoffman's conjectures in positive characteristic.

    noncomputable def d (w : ℕ) : ℕ :=
  let q := Nat.card F
  if w = 0 then 1
  else if w ≤ q - 1 then 2 ^ (w - 1)
  else if w = q then 2 ^ (w - 1) - 1
  else ∑ i ∈ Finset.range q, d (w - (i + 1))

    Let \(F\) be a finite field with \(q\) elements, \(K = F(t)\), and \(w\) a positive integer. Let \(\mathcal{Z}_w\) be the \(K\)-vector space spanned by the multiple zeta values over \(F\) of weight \(w\), and let \(\mathcal{T}_w\) be the set of multiple zeta values \(\zeta_A(s_1, \dots, s_r)\) with \(r \ge 1\), positive integers \(s_1, \dots, s_r\) with sum \(w\), \(s_i \le q\) for \(1 \le i \le r - 1\), and \(s_r < q\).
