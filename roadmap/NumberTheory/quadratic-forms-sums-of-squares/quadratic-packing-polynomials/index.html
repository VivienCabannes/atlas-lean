    DefinitionQuadratic packing polynomial#✓fully proved

    MetaMathlibExt.IsQuadraticPackingPolynomial

    A real function \(P(x, y)\) of two real variables is a quadratic packing polynomial (QPP) on a set \(S \subseteq \mathbb{R}^2\) if it is a polynomial of total degree two, that is, \(P(x, y) = a x^2 + b x y + c y^2 + d x + e y + f\) for some real \(a, b, c, d, e, f\) with \(a, b, c\) not all zero, and \(P\) maps \(S\) bijectively onto the set \(\mathbb{N}_0 = \{0, 1, 2, \dots\}\) of natural numbers.

    public def IsQuadraticPackingPolynomial (S : Set (ℝ × ℝ)) (P : ℝ → ℝ → ℝ) : Prop :=
  (∃ a b c d e f : ℝ, (a ≠ 0 ∨ b ≠ 0 ∨ c ≠ 0) ∧
      ∀ x y, P x y = a * x ^ 2 + b * x * y + c * y ^ 2 + d * x + e * y + f) ∧
    Set.BijOn (fun p : ℝ × ℝ => P p.1 p.2) S (Set.range ((↑) : ℕ → ℝ))

    MetaMathlibExt.sectorStaircase

    For natural numbers \(m, n, i\), let \(l = \gcd(m - 1, n)\). The \(i\)-th staircase of the sector of slope \(n/m\) is \(J_i = \{(x, y) \in I(n/m) : nx - (m - 1)y = li\}\), where \(I(n/m)\) is the set of lattice points of that sector.

    If \(m = 0\), the slope \(n/m\) is read as \(0\) and \(l\) as \(\gcd(0, n) = n\).

    public def sectorStaircase (m n i : ℕ) : Set (ℝ × ℝ) :=
  {p | p ∈ sectorLatticePoints ((n : ℝ) / m) ∧
    (n : ℝ) * p.1 - ((m : ℝ) - 1) * p.2 = (Nat.gcd (m - 1) n : ℝ) * i}

    DefinitionStep difference#✓fully proved

    MetaMathlibExt.consecutiveStepDifference

    For natural numbers \(m, n\) and a real function \(P(x, y)\) of two real variables, let \(l = \gcd(m \mathbin{\dot-} 1, n)\), where \(m \mathbin{\dot-} 1\) is subtraction truncated at \(0\) (so \(l = n\) when \(m = 0\)). The step difference of \(P\) for the sector of slope \(n/m\) is \(k = P((m - 1)/l, n/l) - P(0, 0)\), with \(m - 1\) here the real difference and division by \(l = 0\) read as \(0\): the change \(P(x + (m - 1)/l, y + n/l) - P(x, y)\) of \(P\) between consecutive steps of a staircase of the sector, evaluated at the base point \((0, 0)\).

    For every polynomial of Stanton's form (Theorem 2 of the source) this difference does not depend on the base point, which is how the source defines \(k\).

    public noncomputable def consecutiveStepDifference (m n : ℕ) (P : ℝ → ℝ → ℝ) : ℝ :=
  P (((m : ℝ) - 1) / Nat.gcd (m - 1) n) ((n : ℝ) / Nat.gcd (m - 1) n) - P 0 0
