    Nicomachus's theorem and its generalizations

    DefinitionNicomachean defect#✓fully proved

    MetaMathlibExt.nicomacheanNu

    For a finite sequence \(\sigma = (a_1, \ldots, a_n)\) of elements of a commutative ring, the Nicomachean defect of \(\sigma\) is \(\nu(\sigma) = \left(\sum_{i=1}^n a_i\right)^2 - \sum_{i=1}^n a_i^3\).

    def nicomacheanNu {R : Type*} [CommRing R] (σ : List R) : R :=
  σ.sum ^ 2 - (σ.map (· ^ 3)).sum

    DefinitionThe Nicomachean progression factor#✓fully proved

    MetaMathlibExt.nicomacheanAlpha

    For rational numbers \(n\), \(s\) and \(a\), define

    \[\alpha(n, s, a) = 2n^2 + na - a^2 + \frac{n(n-1)(s - s^2)}{2} - (n-1)as.\]

    This is the second factor of \(\nu(S_m)\), where \(\nu(a_1, \dots, a_k) = (a_1 + \dots + a_k)^2 - (a_1^3 + \dots + a_k^3)\) is the Nicomachean defect, \(S = (a, a + s, \dots, a + (n-1)s)\), and \(S_m\) joins \(n\) copies of \(n\) with the translated progressions \(S, S + n, \dots, S + mn\).

    def nicomacheanAlpha (n s a : ℚ) : ℚ :=
  2 * n ^ 2 + n * a - a ^ 2 + n * (n - 1) * (s - s ^ 2) / 2 - (n - 1) * a * s

    TheoremSpecializations of the Nicomachean factor at \(s = 1, 2, 3\)#✓fully proved

    MetaMathlibExt.nicomacheanAlpha_one_two_three

    Let \(\alpha(n, s, a) = 2n^2 + na - a^2 + n(n-1)(s - s^2)/2 - (n-1)as\). For all rational numbers \(n\) and \(a\), \(\alpha(n, 1, a) = 2n^2 + a - a^2\), \(\alpha(n, 2, a) = n^2 + (1 - a)n - a^2 + 2a\) and \(\alpha(n, 3, a) = -(a + n - 3)(a + n)\).

    theorem nicomacheanAlpha_one_two_three (n a : ℚ) :
    nicomacheanAlpha n 1 a = 2 * n ^ 2 + a - a ^ 2 ∧
      nicomacheanAlpha n 2 a = n ^ 2 + (1 - a) * n - a ^ 2 + 2 * a ∧
      nicomacheanAlpha n 3 a = -(a + n - 3) * (a + n)
    def nicomacheanAlpha (n s a : ℚ) : ℚ :=
  2 * n ^ 2 + n * a - a ^ 2 + n * (n - 1) * (s - s ^ 2) / 2 - (n - 1) * a * s

Then \(\nu(\sigma(j_k, m_k)) = 0\) for every \(k\), and in the ring of formal power series over \(\mathbb{Z}\)

    \[ (X - 1)(1 - 6X + X^2)(1 + 6X + X^2) \sum_{k \ge 0} j_k X^k = X^4 + X^3 - 19X^2 - 5X - 2 \]

    and

    \[ (1 - X)(1 - 6X + X^2)(1 + 6X + X^2) \sum_{k \ge 0} m_k X^k = 6(1 + X)^2. \]

    For admissible \(j\) the square root is an integer and \(m = j + \sqrt{2j^2 + 3j + 2}\) is the positive root of \(\nu(\sigma(j, m)) = 0\) in \(m\), so these say that \((j_k)\) and \((m_k)\) have the generating functions \((x^4 + x^3 - 19x^2 - 5x - 2)/((x - 1)(1 - 6x + x^2)(1 + 6x + x^2))\) and \(6(1 + x)^2/((1 - x)(1 - 6x + x^2)(1 + 6x + x^2))\).
