    BinaryQuadraticForm.formIdeal

    Let \(D\) be a natural number, let \(K = \mathbb{Q}(i\sqrt{D}) \subseteq \mathbb{C}\) and let \(\mathcal{O}_K\) be its ring of integers.     DefinitionGauss-reduced binary quadratic forms#✓fully proved

    BinaryQuadraticForm.IsGaussReduced

    The integral binary quadratic form \(a x^2 + b x y + c y^2\) is Gauss reduced when \(a > 0\), its discriminant \(b^2 - 4ac\) is negative, \(|b| \le a \le c\), and \(b \ge 0\) whenever \(|b| = a\) or \(a = c\).

    For example, \(x^2 - x y + y^2\) is positive definite and satisfies \(|b| \le a \le c\), but it is not reduced, because \(|b| = a\) and \(b < 0\).

    def IsGaussReduced (a b c : ℤ) : Prop :=
  0 < a ∧ discrim a b c < 0 ∧ |b| ≤ a ∧ a ≤ c ∧
    ((|b| = a ∨ a = c) → 0 ≤ b)
