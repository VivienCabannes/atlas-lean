    Kronecker's class number sums

    DefinitionReduced forms of a given discriminant#✓fully proved

    MetaMathlibExt.reducedFormsOfDiscriminant

    For an integer \(d\), \(R(d)\) is the finite set of integer triples \((a, b, c)\) such that the binary quadratic form \(a x^2 + b x y + c y^2\) is Gauss reduced (that is, \(a > 0\), \(b^2 - 4ac < 0\), \(|b| \le a \le c\), and \(b \ge 0\) whenever \(|b| = a\) or \(a = c\)) and has discriminant \(b^2 - 4ac = d\). In particular \(R(d)\) is empty when \(d \ge 0\).

    The set is computed by a finite search: a reduced form satisfies \(-d = 4ac - b^2 \ge 3a^2\), so \(1 \le a \le \lfloor \sqrt{-d} \rfloor\) and \(|b| \le a\), and \(c = (b^2 - d) / (4a)\) is determined by \(a\) and \(b\).

    public def reducedFormsOfDiscriminant (d : ℤ) : Finset (ℤ × ℤ × ℤ) :=
  ((Finset.Icc (1 : ℤ) (Nat.sqrt (-d).toNat)).biUnion fun a =>
      (Finset.Icc (-a) a).image fun b => (a, b, (b ^ 2 - d) / (4 * a))).filter fun q =>
    BinaryQuadraticForm.IsGaussReduced q.1 q.2.1 q.2.2 ∧ discrim q.1 q.2.1 q.2.2 = d
    def IsGaussReduced (a b c : ℤ) : Prop :=
  0 < a ∧ discrim a b c < 0 ∧ |b| ≤ a ∧ a ≤ c ∧
    ((|b| = a ∨ a = c) → 0 ≤ b)

    MetaMathlibExt.gaussClassNumber

    For an integer \(d\), the Gauss class number \(h(d)\) is the number of integer triples \((a, b, c)\) with \(b^2 - 4ac = d\) for which the binary quadratic form \(ax^2 + bxy + cy^2\) is positive definite (\(a > 0\) and \(d < 0\)), reduced (\(|b| \le a \le c\), with \(b \ge 0\) whenever \(|b| = a\) or \(a = c\)) and primitive (\(\gcd(a, b, c) = 1\)).

    DefinitionUnweighted Hurwitz class number#✓fully proved

    MetaMathlibExt.unweightedHurwitzClassNumber

    For an integer \(d\), the unweighted Hurwitz class number \(H(d)\) is the number of elements of the set \(R(d)\) of reduced forms of discriminant \(d\), that is, the number of integer triples \((a, b, c)\), primitive or not, for which \(a x^2 + b x y + c y^2\) is a Gauss-reduced binary quadratic form of discriminant \(b^2 - 4ac = d\). Every reduced form is counted with weight \(1\); in particular \(H(d) = 0\) when \(d \ge 0\).

    This differs from the weighted Hurwitz class number, which counts forms equivalent to a multiple of \(x^2 + y^2\) or of \(x^2 + x y + y^2\) with weight \(1/2\) or \(1/3\) (the paper remarks that the literature uses several conventions).

    public def unweightedHurwitzClassNumber (d : ℤ) : ℕ :=
  (reducedFormsOfDiscriminant d).card

    DefinitionWeight of a reduced binary quadratic form#✓fully proved

    MetaMathlibExt.reducedFormWeight

    The weight of an integer triple \((a, b, c)\), standing for the form \(ax^2 + bxy + cy^2\), is \(1/2\) if \(a = c\) and \(b = 0\), \(1/3\) if \(a = b = c \ne 0\), and \(1\) otherwise.

    On reduced forms the weight is \(1/2\) for \(a(x^2 + y^2)\), \(1/3\) for \(a(x^2 + xy + y^2)\), and \(1\) for every other form.

    public def reducedFormWeight (q : ℤ × ℤ × ℤ) : ℚ :=
  if q.1 = q.2.2 ∧ q.2.1 = 0 then 1 / 2
  else if q.1 = q.2.1 ∧ q.2.1 = q.2.2 then 1 / 3 else 1

    DefinitionThe discriminant \(d(\alpha, g)\) attached to \(n = 2^\alpha g h^2\)#✓fully proved

    MetaMathlibExt.kroneckerDiscriminant

    For natural numbers \(\alpha\) and \(g\), let \(d(\alpha, g) = -8g\) if \(\alpha\) is odd; if \(\alpha\) is even, let \(d(\alpha, g) = -4g\) when \(g \equiv 1 \pmod 4\) and \(d(\alpha, g) = -g\) otherwise.

    In the paper \(n = 2^\alpha g h^2\) with \(g\) and \(h\) odd and \(g\) squarefree, so the last case is \(g \equiv 3 \pmod 4\); the paper writes \(d(n)\) for \(d(\alpha, g)\), the fundamental discriminant of \(\mathbb{Q}(\sqrt{-n})\).

    public def kroneckerDiscriminant (α g : ℕ) : ℤ :=
  if Even α then (if g % 4 = 1 then -4 * g else -g) else -8 * g

    DefinitionKronecker's class-number multiplier#✓fully proved

    MetaMathlibExt.kroneckerClassMultiplier

    For an integer \(d\) and a natural number \(h \ge 1\), \(\ell(d, h)\) is the product, over the primes \(p\) dividing \(h\), of

    \[\sum_{i=0}^{v} p^i - \left(\frac{d}{p}\right) \sum_{i=0}^{v-1} p^i,\]

    where \(v\) is the exponent of \(p\) in \(h\) and \(\left(\frac{d}{p}\right)\) is the Jacobi symbol; in particular \(\ell(d, 1) = 1\). Also \(\ell(d, 0) = 1\).

    In the paper \(h\) is odd, so each \(p\) is an odd prime, the symbol is the Legendre symbol, and the factor equals \(\frac{p^{v+1} - 1}{p - 1} - \left(\frac{d}{p}\right) \frac{p^v - 1}{p - 1}\).

    public def kroneckerClassMultiplier (d : ℤ) (h : ℕ) : ℤ :=
  ∏ p ∈ h.primeFactors,
    ((∑ i ∈ Finset.range (h.factorization p + 1), (p : ℤ) ^ i) -
      jacobiSym d p * ∑ i ∈ Finset.range (h.factorization p), (p : ℤ) ^ i)

    MetaMathlibExt.kroneckerFOdd_kroneckerFEven_eq_classNumber

    Let \(n = 2^\alpha g h^2\) with \(g\) and \(h\) odd natural numbers and \(g\) squarefree. Let \(d = -4g\) if \(\alpha\) is even and \(g \equiv 1 \pmod 4\), \(d = -g\) if \(\alpha\) is even and \(g \equiv 3 \pmod 4\), and \(d = -8g\) if \(\alpha\) is odd. Let \(L = \ell(d, h) \cdot h(d)\), where \(\ell(d, h)\) is Kronecker's class-number multiplier and \(h(d)\) is the Gauss class number of \(d\), and for even \(\alpha\) let \(t = 2^{\alpha/2}\). Then Kronecker's sums \(F_o\) and \(F_e\) satisfy:
