    DefinitionHurwitz rounding to the nearest Gaussian integer#✓fully proved

    MetaMathlibExt.hurwitzRound

    For a complex number \(z\), let \([z] = m + n i\), where \(m = \lfloor \operatorname{Re} z + 1/2 \rfloor\) and \(n = \lfloor \operatorname{Im} z + 1/2 \rfloor\); that is, the real and imaginary parts of \(z\) are rounded to the nearest integer, with halves rounded up. Then \([z]\) is a Gaussian integer nearest to \(z\).

    noncomputable def hurwitzRound (z : ℂ) : ℂ :=
  (⌊z.re + 1 / 2⌋ : ℂ) + (⌊z.im + 1 / 2⌋ : ℂ) * I

    DefinitionIterates of the Hurwitz algorithm#✓fully proved

    MetaMathlibExt.hurwitzIter

    For a complex number \(z\), the Hurwitz iterates are \(z_0 = z\) and \(z_{n+1} = (z_n - [z_n])^{-1}\) for \(n \ge 0\), where \([u]\) is the Gaussian integer nearest to \(u\), obtained by rounding the real and imaginary parts of \(u\) to the nearest integer with halves rounded up, and where the inverse of \(0\) is taken to be \(0\).

    noncomputable def hurwitzIter (z : ℂ) : ℕ → ℂ
  | 0 => z
  | n + 1 => (hurwitzIter z n - hurwitzRound (hurwitzIter z n))⁻¹
    noncomputable def hurwitzRound (z : ℂ) : ℂ :=
  (⌊z.re + 1 / 2⌋ : ℂ) + (⌊z.im + 1 / 2⌋ : ℂ) * I

    DefinitionConsecutive pairs of Hurwitz convergents#✓fully proved

    MetaMathlibExt.hurwitzPQ

    Let \(z\) be a complex number with Hurwitz partial quotients \(a_0, a_1, a_2, \dots\). This is the sequence whose term for \(n \ge 0\) is the pair of pairs of complex numbers \(((P_{n-1}, Q_{n-1}), (P_n, Q_n))\), where \(P_{-1} = 1\), \(Q_{-1} = 0\), \(P_0 = a_0\), \(Q_0 = 1\), and \(P_{n+1} = a_{n+1} P_n + P_{n-1}\) and \(Q_{n+1} = a_{n+1} Q_n + Q_{n-1}\) for \(n \ge 0\).

    noncomputable def hurwitzPQ (z : ℂ) : ℕ → (ℂ × ℂ) × (ℂ × ℂ)
  | 0 => ((1, 0), (hurwitzDigit z 0, 1))
  | n + 1 =>
    (((hurwitzPQ z n).2.1, (hurwitzPQ z n).2.2),
      (hurwitzDigit z (n + 1) * (hurwitzPQ z n).2.1 + (hurwitzPQ z n).1.1,
        hurwitzDigit z (n + 1) * (hurwitzPQ z n).2.2 + (hurwitzPQ z n).1.2))
    noncomputable def hurwitzDigit (z : ℂ) (n : ℕ) : ℂ :=
  hurwitzRound (hurwitzIter z n)

    TheoremRecursion for the Hurwitz convergents#✓fully proved

    MetaMathlibExt.hurwitzPQ_recursion

    Let \(z\) be a complex number with Hurwitz partial quotients \(a_n\), convergent numerators \(P_n\) and convergent denominators \(Q_n\). Then \(P_0 = a_0\), \(Q_0 = 1\), \(P_1 = a_1 a_0 + 1\) and \(Q_1 = a_1\), and for every \(n \ge 0\), \(P_{n+2} = a_{n+2} P_{n+1} + P_n\) and \(Q_{n+2} = a_{n+2} Q_{n+1} + Q_n\).

    theorem hurwitzPQ_recursion (z : ℂ) (n : ℕ) :
    hurwitzP z 0 = hurwitzDigit z 0 ∧ hurwitzQ z 0 = 1 ∧
      hurwitzP z 1 = hurwitzDigit z 1 * hurwitzDigit z 0 + 1 ∧
      hurwitzQ z 1 = hurwitzDigit z 1 ∧
      hurwitzP z (n + 2) = hurwitzDigit z (n + 2) * hurwitzP z (n + 1) + hurwitzP z n ∧
      hurwitzQ z (n + 2) = hurwitzDigit z (n + 2) * hurwitzQ z (n + 1) + hurwitzQ z n
    noncomputable def hurwitzP (z : ℂ) (n : ℕ) : ℂ :=
  (hurwitzPQ z n).2.1

    MetaMathlibExt.hurwitzQ_mul_sub_hurwitzP

    Let \(z\) be a complex number with Hurwitz iterates \(z_0 = z, z_1, z_2, \dots\), convergent numerators \(P_n\) and convergent denominators \(Q_n\). For every legal index \(n\) for \(z\),

    TheoremSums of four squares via Hurwitz continued fractions#●ready to prove

    MetaMathlibExt.hurwitz_four_squares

    Let \(w\), \(x\), \(y\) be natural numbers such that \(w\) is odd and not a perfect square, \(2x < w\), \(2y < w\) and \(w\) divides \(x^2 + y^2 + 1\). Expand \(z = (x + yi)/w\) by the Hurwitz algorithm, with convergent numerators \(P_n\) and convergent denominators \(Q_n\). Then there is exactly one natural number \(n\) such that \(n + 1\) is a legal index for \(z\), \(|Q_n| \le \sqrt{w} < |Q_{n+1}|\), and, if \(|Q_n| \ne \sqrt{w}\), \(w = |(x + yi) Q_n - w P_n|^2 + |Q_n|^2\).

    When it holds, the last identity is a representation of \(w\) as a sum of four squares.

    public theorem_wanted hurwitz_four_squares (w x y : ℕ) (hw : Odd w) (hsq : ¬ IsSquare w)
    (hx : 2 * x < w) (hy : 2 * y < w) (hmod : w ∣ x ^ 2 + y ^ 2 + 1) :
    let z : ℂ := (x + y * I) / w
    ∃! n, HurwitzLegal z (n + 1) ∧ ‖hurwitzQ z n‖ ≤ Real.sqrt w ∧
        Real.sqrt w < ‖hurwitzQ z (n + 1)‖ ∧
        (‖hurwitzQ z n‖ ≠ Real.sqrt w →
          (w : ℝ) = normSq ((x + y * I) * hurwitzQ z n - w * hurwitzP z n) +
            normSq (hurwitzQ z n))
    def HurwitzLegal (z : ℂ) (n : ℕ) : Prop :=
  ∀ j < n, hurwitzIter z j ≠ hurwitzDigit z j
