    DefinitionThe square theta series#✓fully proved

    MetaMathlibExt.squareThetaSeries

    The square theta series is the formal power series \(\theta(q) = \sum_{m \in \mathbb{Z}} q^{m^2}\) in \(\mathbb{Z}[[q]]\): for each \(n \ge 0\), its coefficient of \(q^n\) is the number of integers \(m\) with \(m^2 = n\).

    public noncomputable def squareThetaSeries : PowerSeries ℤ :=
  PowerSeries.mk fun n => (((Finset.Icc (-(n : ℤ)) n).filter fun m : ℤ => m ^ 2 = (n : ℤ)).card : ℤ)

    DefinitionTriangular theta series#✓fully proved

    MetaMathlibExt.triangularThetaSeries

    The triangular theta series is the formal power series \(\psi(q) = \sum_{m \ge 0} q^{m(m+1)/2}\) with integer coefficients: for each natural number \(n\), its coefficient of \(q^n\) is the number of natural numbers \(m\) with \(m(m+1)/2 = n\).

    public noncomputable def triangularThetaSeries : PowerSeries ℤ :=
  PowerSeries.mk fun n => (((Finset.range (n + 1)).filter fun m => m * (m + 1) / 2 = n).card : ℤ)

    DefinitionRepresentation numbers for sums of squares#✓fully proved

    MetaMathlibExt.sumOfSquaresRepCount

    For an integer \(k\) and a natural number \(n\), \(r_k(n)\) is the coefficient of \(q^n\) in \(\theta(q)^k\), where \(\theta(q) = \sum_{m \in \mathbb{Z}} q^{m^2}\). Since \(\theta\) has constant coefficient \(1\), it is a unit of \(\mathbb{Z}[[q]]\), so \(\theta^k\) is a power series for negative \(k\) as well.

    For \(k \ge 1\), \(r_k(n)\) is the number of ways to write \(n\) as an ordered sum of \(k\) squares of integers.

    public noncomputable def sumOfSquaresRepCount (k : ℤ) (n : ℕ) : ℤ :=
  PowerSeries.coeff n ((isUnit_squareThetaSeries.unit ^ k : (PowerSeries ℤ)ˣ) : PowerSeries ℤ)
    public theorem isUnit_squareThetaSeries : IsUnit squareThetaSeries
