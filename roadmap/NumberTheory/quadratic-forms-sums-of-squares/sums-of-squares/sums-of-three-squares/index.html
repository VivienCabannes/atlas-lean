    TheoremLegendre's three-square theorem#✓fully proved

    Nat.exists_three_squares_of_not_four_pow_mul_eight_mul_add_seven

    Every natural number \(n\) that is not of the form \(4^a (8b + 7)\) with natural numbers \(a, b\) is a sum of three squares: there are natural numbers \(x, y, z\) with \(x^2 + y^2 + z^2 = n\).

    theorem exists_three_squares_of_not_four_pow_mul_eight_mul_add_seven
    (n : Nat)
    (h : ¬ ∃ a b : Nat, n = 4 ^ a * (8 * b + 7)) :
    ∃ x y z : Nat, x ^ 2 + y ^ 2 + z ^ 2 = n

    Nat.threeSquareRepresentationCount

    For a natural number \(n\), \(r_3(n)\) is the number of ordered triples \((x, y, z)\) of integers in the interval \([-n, n]\) with \(x^2 + y^2 + z^2 = n\). Every integer solution of \(x^2 + y^2 + z^2 = n\) lies in this interval (also for \(n = 0\)), so \(r_3(n)\) is the number of all ordered integer solutions.

    TheoremLegendre-symbol recursion for three-square counts#✓fully proved

    MetaMathlibExt.r3_legendre_recursion

    For a natural number \(m\), let \(r_3(m)\) denote the number of ordered triples of integers \((x, y, z)\) with \(x^2 + y^2 + z^2 = m\). Let \(p \ge 3\) be a prime and let \(n \ge 1\) and \(\alpha \ge 0\) be natural numbers. Then

    \[ r_3(p^{2\alpha} n) = \left(\frac{p^{\alpha+1} - 1}{p - 1} - \left(\frac{-n}{p}\right) \frac{p^{\alpha} - 1}{p - 1}\right) r_3(n) - p \, \frac{p^{\alpha} - 1}{p - 1} \, r_3(n/p^2), \]

    where \(\left(\frac{-n}{p}\right)\) is the Legendre symbol, both quotients by \(p - 1\) are exact integer divisions, and the term \(r_3(n/p^2)\) is read as \(0\) when \(p^2\) does not divide \(n\).

    Proof: The route is an elementary p-neighbour double count using quaternionic descent and finite-field conic counts, followed by a two-step induction on the exponent.

    public theorem r3_legendre_recursion
    {p n α : ℕ} [Fact (Nat.Prime p)] (hp3 : 3 ≤ p) (hn : 1 ≤ n) :
    (Nat.threeSquareRepresentationCount (p ^ (2 * α) * n) : ℤ) =
      (((((p : ℤ) ^ (α + 1) - 1) / ((p : ℤ) - 1)) -
          legendreSym p (-(n : ℤ)) *
            (((p : ℤ) ^ α - 1) / ((p : ℤ) - 1))) *
          Nat.threeSquareRepresentationCount n -
        (p : ℤ) * (((p : ℤ) ^ α - 1) / ((p : ℤ) - 1)) *
          (if p ^ 2 ∣ n then Nat.threeSquareRepresentationCount (n / p ^ 2) else 0))
    def threeSquareRepresentationCount (n : ℕ) : ℕ :=
  ((((Finset.Icc (-(n : ℤ)) (n : ℤ)) ×ˢ (Finset.Icc (-(n : ℤ)) (n : ℤ))) ×ˢ
      (Finset.Icc (-(n : ℤ)) (n : ℤ))).filter
      (fun p : (ℤ × ℤ) × ℤ => p.1.1 ^ 2 + p.1.2 ^ 2 + p.2 ^ 2 = (n : ℤ))).card

    DefinitionHurwitz class number#●ready to state

    Nat.hurwitzClassNumber

    The Hurwitz class number is the function \(H\) from the natural numbers to the rationals given by \(H(0) = -1/12\); \(H(N) = 0\) if \(N \equiv 1\) or \(2 \pmod 4\); and, for \(N > 0\) with \(N \equiv 0\) or \(3 \pmod 4\), \(H(N)\) is the number of equivalence classes of positive-definite integral binary quadratic forms of discriminant \(-N\), primitive or not, where the class of a form equivalent to \(a (x^2 + y^2)\) for some positive integer \(a\) counts with weight \(1/2\), the class of a form equivalent to \(a (x^2 + x y + y^2)\) for some positive integer \(a\) counts with weight \(1/3\), and every other class counts with weight \(1\).
