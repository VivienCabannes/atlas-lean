    DefinitionDistance between subspaces#✓fully proved

    MathlibExt.NumberTheory.LinearSubspacesWanted.LinearSubspaces.distSubspaces

    For subspaces \(x\) and \(y\) of \(\mathbb{R}^d\), the distance \(\operatorname{dist}(x, y)\) is defined as follows. If \(\dim y \le \dim x\), it is the supremum, over all lines \(y'\) contained in \(y\), of the distance \(\operatorname{dist}(y', x)\) from the line \(y'\) to the subspace \(x\). If \(\dim y > \dim x\), it is the supremum, over all lines \(x'\) contained in \(x\), of the distance \(\operatorname{dist}(x', y)\) from the line \(x'\) to the subspace \(y\). A supremum over no lines is \(0\).

    def distSubspaces (x y : Submodule ℝ ℝᵈ) : ℝ :=
  if finrank ℝ y ≤ finrank ℝ x then
    ⨆ y' : {y' : ℙ ℝ ℝᵈ // y'.submodule ≤ y}, distLineSubspace y'.1 x
  else
    ⨆ x' : {x' : ℙ ℝ ℝᵈ // x'.submodule ≤ x}, distLineSubspace x'.1 y

    DefinitionDiophantine exponent#✓fully proved

    MathlibExt.NumberTheory.LinearSubspacesWanted.LinearSubspaces.diophantineExponent

    Let \(x\) be a subspace of \(\mathbb{R}^d\) and let \(k\) be a natural number. For subspaces \(v\) of \(\mathbb{R}^d\) write \(\operatorname{dist}(v, x)\) for the distance between the subspaces \(v\) and \(x\), and for a rational subspace \(v\) write \(H(v)\) for its height. The diophantine exponent \(\beta_k(x)\) of \(x\) for approximation by \(k\)-dimensional rational subspaces is the infimum, taken in \([0, \infty]\), of the set of real numbers \(\beta > 0\) for which there is a real number \(c > 0\) such that \(\operatorname{dist}(v, x) \ge c \, H(v)^{-\beta}\) for every \(k\)-dimensional rational subspace \(v\) of \(\mathbb{R}^d\). In particular \(\beta_k(x) = \infty\) when there is no such \(\beta\).

    def diophantineExponent (k : ℕ) (x : Submodule ℝ ℝᵈ) : ℝ≥0∞ :=
  sInf (.ofReal '' {β : ℝ | β > 0 ∧ ∃ c > 0, ∀ v : Submodule ℝ ℝᵈ, finrank ℝ v = k →
    (hv : IsRational v) → distSubspaces v x ≥ c * height v hv ^ (-β)})

    TheoremDirichlet's principle in Grassmann varieties#●ready to prove

    MathlibExt.NumberTheory.LinearSubspacesWanted.LinearSubspaces.theorem_1

    Let \(d\), \(l\) and \(k\) be natural numbers with \(d \ge 2\), \(0 < l < d\) and \(1 \le k \le l\), and for a subspace \(x\) of \(\mathbb{R}^d\) write \(\beta_k(x)\) for the diophantine exponent of \(x\) for approximation by \(k\)-dimensional rational subspaces. Then every \(l\)-dimensional subspace \(x\) of \(\mathbb{R}^d\) satisfies \(\beta_k(x) \ge \frac{d}{k(d - l)}\). Moreover, some \(l\)-dimensional subspace \(x\) of \(\mathbb{R}^d\) satisfies \(\beta_k(x) = \frac{d}{k(d - l)}\).
