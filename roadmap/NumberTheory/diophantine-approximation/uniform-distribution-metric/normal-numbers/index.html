    MetaMathlibExt.NormalNumber.digitSeq

    For natural numbers \(b\) and \(n\) and a real number \(x\), the \(n\)-th digit of \(x\) in base \(b\), counting from \(n = 0\) just after the radix point, is \(\lfloor b^{n+1} \{x\} \rfloor \bmod b\), where \(\{x\} = x - \lfloor x \rfloor\) is the fractional part of \(x\).

    For \(b \ge 2\) these are the digits of the base-\(b\) expansion of \(\{x\}\) that does not end in an infinite run of the digit \(b - 1\). The formula is intended only for bases \(b \ge 2\).

    noncomputable def digitSeq (b : ℕ) (x : ℝ) (n : ℕ) : ℕ :=
  ⌊(b : ℝ) ^ (n + 1) * Int.fract x⌋₊ % b

    DefinitionSimply normal numbers#✓fully proved

    MetaMathlibExt.NormalNumber.IsSimplyNormalInBase

    For a natural number \(b\) and a real number \(x\), write \(a_k\) for the \(k\)-th base-\(b\) digit of \(x\) after the radix point, counting from \(k = 0\). Then \(x\) is simply normal in base \(b\) if for every natural number \(d < b\) the proportion \(\#\{k < n : a_k = d\} / n\) tends to \(1/b\) as \(n \to \infty\).

    This predicate is intended for bases \(b \ge 2\).

    noncomputable def IsSimplyNormalInBase (b : ℕ) (x : ℝ) : Prop :=
  ∀ d : ℕ, d < b →
    Tendsto
      (fun n : ℕ =>
        (((Finset.range n).filter (fun k => digitSeq b x k = d)).card : ℝ) / n)
      atTop
      (nhds (1 / (b : ℝ)))
    noncomputable def digitSeq (b : ℕ) (x : ℝ) (n : ℕ) : ℕ :=
  ⌊(b : ℝ) ^ (n + 1) * Int.fract x⌋₊ % b

    MetaMathlibExt.NormalNumber.IsNormalInBase

    DefinitionDigits of the concatenation \(0.h_2(1)h_2(2)\ldots\)#✓fully proved

    MetaMathlibExt.campbellConcatDigit

    Let \(h_2\) be Campbell's sequence.
