    DefinitionInclusion-exclusion-like sum#✓fully proved

    MetaMathlibExt.inclExclLikeSum

    For a function \(F : \mathbb{R} \to \mathbb{Z}\) and real numbers \(x_1, \dots, x_n\), the inclusion-exclusion-like sum is the integer \(g^{(F)}(x_1, \dots, x_n) = \sum_T (-1)^{|T| - 1} F\left(\sum_{i \in T} x_i\right)\), where \(T\) ranges over the nonempty subsets of \(\{1, \dots, n\}\).

    public def inclExclLikeSum {n : ℕ} (F : ℝ → ℤ) (x : Fin n → ℝ) : ℤ :=
  ∑ T : Finset (Fin n) with T.Nonempty, (-1) ^ (T.card - 1) * F (∑ i ∈ T, x i)
