    DefinitionBeatty term#✓fully proved

    MetaMathlibExt.beattyTerm

    For a positive integer \(n\) and a real number \(\alpha\), the Beatty term \(b_n(\alpha)\) is the natural number \(\max(\lfloor n/\alpha \rfloor, 0)\): the \(n\)-th term \(\lfloor n \cdot (1/\alpha) \rfloor\) of the Beatty sequence of slope \(1/\alpha\), truncated at \(0\). Division by zero is read as \(0\), so \(b_n(0) = 0\).

    public noncomputable def beattyTerm (n : { n : ℕ // 0 < n }) (α : ℝ) : ℕ :=
  (beattySeq (1 / α) (n.val : ℤ)).toNat

    TheoremBeatty term as a natural-number floor#✓fully proved

    MetaMathlibExt.beattyTerm_eq_floor

    For every positive integer \(n\) and every real number \(\alpha\), the Beatty term \(b_n(\alpha)\) equals the natural-number floor of \(n/\alpha\): the largest natural number \(m\) with \(m \le n/\alpha\) when \(n/\alpha \ge 0\), and \(0\) when \(n/\alpha < 0\). Division by zero is read as \(0\), so \(n/0 = 0\).

    public theorem beattyTerm_eq_floor (n : { n : ℕ // 0 < n }) (α : ℝ) :
    beattyTerm n α = Nat.floor ((n.val : ℝ) / α)

    DefinitionAlmost Beatty sequence#✓fully proved

    MetaMathlibExt.IsAlmostBeattySequence

    Let \(\alpha\) be a real number. A sequence \((s_n)_{n \ge 1}\) of natural numbers indexed by the positive integers is an almost Beatty sequence for \(\alpha\) when \(0 < \alpha < 1\), the sequence is strictly increasing, \(s_n > 0\) for every \(n \ge 1\), and there is a natural number \(B\) with \(|s_n - b_n(\alpha)| \le B\) for every \(n \ge 1\), where \(b_n(\alpha)\) is the Beatty term, equal to \(\lfloor n/\alpha \rfloor\) once \(\alpha > 0\).

    public def IsAlmostBeattySequence (s : { n : ℕ // 0 < n } → ℕ) (α : ℝ) : Prop :=
  0 < α ∧ α < 1 ∧ StrictMono s ∧
    (∀ n, 0 < s n) ∧
      ∃ B : ℕ, ∀ n, ((s n : ℤ) - (beattyTerm n α : ℤ)).natAbs ≤ B
    public noncomputable def beattyTerm (n : { n : ℕ // 0 < n }) (α : ℝ) : ℕ :=
  (beattySeq (1 / α) (n.val : ℤ)).toNat

    DefinitionThree-way partition of the positive integers#✓fully proved

    MetaMathlibExt.IsPositiveNatThreeWayPartition

    Three sequences \(s_1, s_2, s_3\) of natural numbers indexed by the positive integers partition the positive integers when their ranges are pairwise disjoint, that is, \(s_i(m) \ne s_j(n)\) for all \(i \ne j\) and all positive integers \(m\) and \(n\), and the union of their ranges is exactly the set of positive integers: a natural number \(k\) is a value of some \(s_i\) if and only if \(k > 0\).

    public def IsPositiveNatThreeWayPartition (s1 s2 s3 : { n : ℕ // 0 < n } → ℕ) : Prop :=
  (∀ m n, s1 m ≠ s2 n) ∧
    (∀ m n, s1 m ≠ s3 n) ∧
      (∀ m n, s2 m ≠ s3 n) ∧
        ∀ k : ℕ, (∃ n, s1 n = k ∨ s2 n = k ∨ s3 n = k) ↔ 0 < k

    TheoremUspensky's theorem on Beatty partitions#✓fully proved

    MetaMathlibExt.uspensky_no_partition_into_three_or_more_beatty_sequences

    For a real number \(\alpha\) with \(0 < \alpha < 1\), let \(B_\alpha = \{\lfloor n/\alpha \rfloor : n \text{ an integer}, n \ge 1\}\) be its Beatty sequence. Let \(k \ge 3\) and let \(\alpha_1, \dots, \alpha_k\) be real numbers with \(0 < \alpha_i < 1\) for every \(i\). Then \(B_{\alpha_1}, \dots, B_{\alpha_k}\) do not partition the positive integers: it is not the case both that \(B_{\alpha_i} \cap B_{\alpha_j} = \emptyset\) for all \(i \ne j\) and that \(B_{\alpha_1} \cup \dots \cup B_{\alpha_k} = \{1, 2, 3, \dots\}\).

    No irrationality hypothesis is imposed on the \(\alpha_i\).

    theorem uspensky_no_partition_into_three_or_more_beatty_sequences
    (k : ℕ) (hk : 3 ≤ k) (α : Fin k → ℝ)
    (hαpos : ∀ i, 0 < α i) (hαlt : ∀ i, α i < 1) :
    ¬ ((Set.univ : Set (Fin k)).PairwiseDisjoint
        (fun i => {x : ℤ | ∃ n : ℤ, 0 < n ∧ beattySeq (1 / α i) n = x}) ∧
      (⋃ i, {x : ℤ | ∃ n : ℤ, 0 < n ∧ beattySeq (1 / α i) n = x}) =
        {x : ℤ | 0 < x})
    Sources

Hildebrand, Xiaomin Li, Junxian Li, and Yun Xie, Almost Beatty Partitions, Journal of Integer Sequences 22 (2019), Article 19.4.6, Theorem B (Uspensky's theorem), lines 234–236, https://cs.uwaterloo.ca/journals/JIS/VOL22/Hildebrand/hilde2.tex; first proved by Uspensky in 1927 (lines 238–244).

    TheoremBeatty's theorem and its converse#●ready to prove

    MetaMathlibExt.beatty_complementary_iff_irrational_inv_add_inv

    Let \(\alpha\) and \(\beta\) be positive real numbers. The set of the numbers \(\lfloor k\alpha\rfloor\) for positive integers \(k\) and the set of the numbers \(\lfloor k\beta\rfloor\) for positive integers \(k\) are disjoint and their union is the set of positive integers if and only if \(\alpha\) is irrational and \(\alpha^{-1} + \beta^{-1} = 1\).

    The hypothesis \(\beta > 0\) cannot be dropped: for irrational \(0 < \alpha < 1\) the number \(\beta\) with \(\alpha^{-1} + \beta^{-1} = 1\) is negative, and the two sets do not partition the positive integers.

    public theorem_wanted beatty_complementary_iff_irrational_inv_add_inv {α β : ℝ}
    (hα : 0 < α) (hβ : 0 < β) :
    (Disjoint {beattySeq α k | k > 0} {beattySeq β k | k > 0} ∧
        {beattySeq α k | k > 0} ∪ {beattySeq β k | k > 0} = {n : ℤ | 0 < n}) ↔
      (Irrational α ∧ α⁻¹ + β⁻¹ = 1)

    TheoremPolanco's floor identity for \(\lfloor (2 - \alpha) n \rfloor\)#●ready to prove

    MetaMathlibExt.beatty_floor_inv_sub_eq_floor_two_sub

    Let \(\alpha\) be an irrational real number with \(1 < \alpha < 2\), let \(\beta\) be a real number with \(\alpha^{-1} + \beta^{-1} = 1\), and write \(a_m = \lfloor m\alpha \rfloor\) and \(b_m = \lfloor m\beta \rfloor\) for integers \(m\) (so \(b_0 = 0\)).     TheoremIncrements of the \(\beta\)-Beatty counts between \(\lfloor n\alpha\rfloor\) and \(\lfloor n\beta\rfloor\)#●ready to prove

    MetaMathlibExt.beatty_card_compl_between_succ_sub

    Increments of the \(\beta\)-Beatty counts between \(\lfloor n\alpha\rfloor\) and \(\lfloor n\beta\rfloor\).
