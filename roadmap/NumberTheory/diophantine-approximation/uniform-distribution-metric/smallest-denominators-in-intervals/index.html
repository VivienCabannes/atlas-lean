    Smallest denominators in intervals

    DefinitionSmallest denominator in an interval#✓fully proved

    MetaMathlibExt.smallestDenominator

    For real numbers \(x\) and \(\delta\), the smallest denominator \(q_{\min}(x, \delta)\) is the least positive integer \(q\) for which there is an integer \(p\) with \(|x - p/q| < \delta/2\), that is, with \(p/q\) in the open interval \((x - \delta/2, x + \delta/2)\). If there is no such \(q\), which happens only when \(\delta \le 0\), then \(q_{\min}(x, \delta) = 0\).

    noncomputable def smallestDenominator (x δ : ℝ) : ℕ :=
  sInf {q : ℕ | 0 < q ∧ ∃ p : ℤ, |x - p / q| < δ / 2}

    MetaMathlibExt.exists_denominator_mem_window

    For every real number \(x\) and every real \(\delta > 0\) there are a positive integer \(q\) and an integer \(p\) with \(|x - p/q| < \delta/2\).

    Taking \(q > 1/\delta\) and \(p\) the integer nearest to \(qx\) gives \(|x - p/q| \le 1/(2q) < \delta/2\).

    theorem exists_denominator_mem_window (x : ℝ) {δ : ℝ} (hδ : 0 < δ) :
    ∃ q : ℕ, 0 < q ∧ ∃ p : ℤ, |x - p / q| < δ / 2

    MetaMathlibExt.smallestDenominator_eq_one

    For every real number \(x\) and every real \(\delta > 1\), the smallest denominator \(q_{\min}(x, \delta)\) equals \(1\).

    The open interval \((x - \delta/2, x + \delta/2)\) has length greater than \(1\), so it contains an integer.

    DefinitionDensity of the logarithmic smallest denominator#✓fully proved

    MetaMathlibExt.logSmallestDenominatorDensity

    The function \(\eta_{\log}\) on the real line is defined by \(\eta_{\log}(s) = \frac{6}{\pi^2} e^{2s}\) for \(s \le 0\), by \(\eta_{\log}(s) = \frac{6}{\pi^2}\left(-e^{2s} + 2 + 4s\right)\) for \(0 < s \le \log 2\), and by

    \[ \eta_{\log}(s) = \frac{6}{\pi^2}\left(-e^{2s} + 2 + 2e^{2s}\sqrt{\tfrac14 - e^{-2s}} - 4\log\left(\tfrac12 + \sqrt{\tfrac14 - e^{-2s}}\right)\right) \]

    for \(s > \log 2\).

    In the cited paper, \(\eta_{\log}\) is the density of the limit law, as \(\delta \to 0^+\), of \(\log q_{\min}(x, \delta) + \frac12 \log \delta\) for uniformly random \(x\), where \(q_{\min}(x, \delta)\) is the smallest denominator of a rational in \((x - \delta/2, x + \delta/2)\).

    noncomputable def logSmallestDenominatorDensity (s : ℝ) : ℝ :=
  6 / Real.pi ^ 2 *
    if s ≤ 0 then Real.exp (2 * s)
    else if s ≤ Real.log 2 then -Real.exp (2 * s) + 2 + 4 * s
    else -Real.exp (2 * s) + 2 + 2 * Real.exp (2 * s) * Real.sqrt (1 / 4 - Real.exp (-2 * s)) -
      4 * Real.log (1 / 2 + Real.sqrt (1 / 4 - Real.exp (-2 * s)))

    MetaMathlibExt.tendsto_integral_log_smallestDenominator_pow

    Let \(0 \le a \le b \le 1\) be real numbers and let \(n \ge 0\) be an integer. For real \(x\) and \(\delta > 0\) let \(q_{\min}(x, \delta)\) be the smallest positive integer \(q\) such that some rational \(p/q\) lies in the open interval \((x - \delta/2, x + \delta/2)\), and let \(\eta_{\log}\) be the log smallest denominator density. Then, as \(\delta \to 0^+\),

    \[ \int_a^b \bigl(\log q_{\min}(x, \delta) + \tfrac12 \log \delta\bigr)^n \, dx \to \mu_n \, (b - a), \]

    where \(\mu_n = \int_{-\infty}^{\infty} s^n \, \eta_{\log}(s) \, ds\).

    The moment \(\mu_n\) is an integral over the whole real line: \(\eta_{\log}\) has mass \(3/\pi^2\) on \((-\infty, 0]\), so integrating only over \(s \ge 0\) would give \(\mu_0 = 1 - 3/\pi^2\) instead of the correct limit \(1\).

    public theorem_wanted tendsto_integral_log_smallestDenominator_pow (a b : ℝ) (ha : 0 ≤ a)
