    MetaMathlibExt.norm_sum_exp_two_pi_I_le_of_iteratedDeriv_two

    Let \(a < b\) be integers, let \(\rho > 0\), and let \(f : \mathbb{R} \to \mathbb{R}\) be twice continuously differentiable, with either \(f''(t) \ge \rho\) for every \(t \in [a, b]\) or \(f''(t) \le -\rho\) for every \(t \in [a, b]\). Then

    \[\Bigl|\sum_{n=a}^{b} e(f(n))\Bigr| \le \bigl(|f'(b) - f'(a)| + 2\bigr) \Bigl(\frac{4}{\sqrt{\rho}} + 3\Bigr),\]

    where \(e(x) = e^{2\pi i x}\).

    Here \(f\) is \(C^2\) on all of \(\mathbb{R}\); every \(C^2\) function on \([a, b]\) extends to one, so this loses nothing.

    ‖∑ n ∈ Finset.Icc a b, Complex.exp (2 * Real.pi * Complex.I * (f n : ℂ))‖ ≤

    TheoremSquare roots of cubics with positive leading coefficient are uniformly distributed modulo one#●ready to prove

    MetaMathlibExt.exists_sqrt_cubic_equidistributed_mod_one

    Square roots of cubics with positive leading coefficient are uniformly distributed modulo one. Let \(q(t) = a t^3 + b t^2 + c t + d\) with real coefficients \(a, b, c, d\) and \(a > 0\), write \(\{x\} = x - \lfloor x \rfloor\) for the fractional part of a real \(x\), and let \(e(x) = e^{2\pi i x}\). Then there is an integer \(T \ge 1\) with three properties. First, \(q(t) > 0\) for every real \(t \ge T\). Second, the sequence \(\sqrt{q(T)}, \sqrt{q(T + 1)}, \dots\) is uniformly distributed modulo one: for all real \(\alpha, \beta\) with \(0 \le \alpha < \beta \le 1\),

    \[\lim_{N \to \infty} \frac{1}{N} \#\bigl\{0 \le n < N : \alpha \le \{\sqrt{q(T + n)}\} < \beta\bigr\} = \beta - \alpha.\]

    Third, there is a real constant \(C\) such that for every integer \(N \ge T\) and every nonzero integer \(\gamma\),

    \[\Bigl|\sum_{n=T}^{N} e\bigl(\gamma \sqrt{q(n)}\bigr)\Bigr| \le C \bigl(|\gamma|^{1/2} N^{3/4} + |\gamma| N^{1/2} + |\gamma|^{-1/2} N^{1/4} + 1\bigr).\]

    DefinitionSquare pyramidal number#✓fully proved

    MetaMathlibExt.squarePyramidalNumber

    For a natural number \(n\), the \(n\)-th square pyramidal number is \(P_n = 1^2 + 2^2 + \dots + n^2 = \sum_{i=1}^{n} i^2\) (so \(P_0 = 0\)).

    def squarePyramidalNumber (n : ℕ) : ℕ :=
  ∑ i ∈ Finset.Icc 1 n, i ^ 2

    DefinitionDistance from a square pyramidal number to the nearest square#✓fully proved

    MetaMathlibExt.squarePyramidalSquareDistance

    For a natural number \(n\), let \(P_n\) be the \(n\)-th square pyramidal number and \(s = \lfloor \sqrt{P_n} \rfloor\). The distance from \(P_n\) to the nearest square is

    \[a_n = \min\bigl(P_n - s^2, (s + 1)^2 - P_n\bigr).\]

    Since \(s^2 \le P_n < (s + 1)^2\), this is \(a_n = |P_n - y_n^2|\), where \(y_n^2\) is the square nearest to \(P_n\).

    No ties occur, since the midpoint \(m^2 + m + 1/2\) of two consecutive squares is never an integer.

    def squarePyramidalSquareDistance (n : ℕ) : ℕ :=
  min (squarePyramidalNumber n - Nat.sqrt (squarePyramidalNumber n) ^ 2)
    ((Nat.sqrt (squarePyramidalNumber n) + 1) ^ 2 - squarePyramidalNumber n)
    def squarePyramidalNumber (n : ℕ) : ℕ :=
  ∑ i ∈ Finset.Icc 1 n, i ^ 2

    TheoremThe distance from the square root of a square pyramidal number to the nearest integer is uniformly distributed#●ready to prove

    MetaMathlibExt.squarePyramidal_dist_nearest_square_root_equidistributed

    The distance from the square root of a square pyramidal number to the nearest integer is uniformly distributed. Let \(P_n\) be the \(n\)-th square pyramidal number, write \(\|x\| = |x - \operatorname{round}(x)|\) for the distance from a real \(x\) to the nearest integer, and let \((y_n)_{n \ge 0}\) be natural numbers such that \(|P_n - y_n^2| \le |P_n - z^2|\) for all natural numbers \(n\) and \(z\) (so \(y_n^2\) is a square nearest to \(P_n\)). Put \(d_n = |\sqrt{P_n} - y_n|\). Then \(d_n = \|\sqrt{P_n}\|\) and \(d_n \le 1/2\) for every \(n \ge 0\), and \((d_n)_{n \ge 1}\) is uniformly distributed in \([0, 1/2]\): for all real \(\alpha, \beta\) with \(0 \le \alpha < \beta \le 1/2\),

    \[\lim_{N \to \infty} \frac{1}{N} \#\{1 \le n \le N : \alpha \le d_n \le \beta\} = 2(\beta - \alpha).\]

    The source shows that \(y_n\) is unique, and takes the limit over real \(x \to \infty\), which is equivalent to the limit along integers \(N\).

          (Finset.Icc 1 N)).card : ℝ) / (N : ℝ)) atTop (nhds (2 * (β - α)))

    Power sums of the distance from the square root of a square pyramidal number to the nearest integer. Let \(P_n\) be the \(n\)-th square pyramidal number and write \(\|x\| = |x - \operatorname{round}(x)|\) for the distance from a real \(x\) to the nearest integer.     \[\Bigl|\sum_{1 \le n \le t} \|\sqrt{P_n}\|^k - \frac{t}{2^k (k + 1)}\Bigr| \le C_k t^{3/4},\]

    The source writes \(h(n) = \sqrt{n(n+1)(2n+1)/6}\), which is \(\sqrt{P_n}\).
