    n-Lagrange and n-Markoff spectra

    Definition\(n\)-Lagrange approximability#✓fully proved

    MetaMathlibExt.nLagrangeApproximability

    For a natural number \(n\) and a real number \(\xi\), the \(n\)-Lagrange approximability of \(\xi\) is the element of the extended reals

    \[\lambda_n(\xi) = \limsup_{s/t \to \xi} \frac{\gcd(t, n)}{t^2 \, |s/t - \xi|},\]

    where the limsup is over rational numbers \(s/t \ne \xi\), written in lowest terms with \(t > 0\), tending to \(\xi\). For \(n = 1\) this is the classical Lagrange approximability \(\lambda(\xi)\).

    noncomputable def nLagrangeApproximability (n : ℕ) (ξ : ℝ) : EReal :=
  limsup (fun q : ℚ => (((Nat.gcd q.den n : ℝ) / ((q.den : ℝ) ^ 2 * |(q : ℝ) - ξ|) : ℝ) : EReal))
    (comap ((↑) : ℚ → ℝ) (𝓝[≠] ξ))

    MetaMathlibExt.nLagrangeApproximability_one

    \[\lambda_1(\xi) = \limsup_{s/t \to \xi} \frac{1}{t^2 \, |s/t - \xi|},\]

    Definition\(n\)-Markoff approximability#✓fully proved

    MetaMathlibExt.nMarkoffApproximability

    For a natural number \(n\) and real numbers \(\xi\) and \(\xi'\), the \(n\)-Markoff approximability is the supremum in the extended reals

    \[\mu_n(\xi, \xi') = \sup_{(s,t) \ne 0} \frac{\gcd(t, n)\,|\xi - \xi'|}{|s - t\xi|\,|s - t\xi'|}\]

    over all pairs of integers \((s, t) \ne (0, 0)\). A term whose denominator is \(0\), which happens only when \(\xi\) or \(\xi'\) is rational, counts as \(0\).

    noncomputable def nMarkoffApproximability (n : ℕ) (ξ ξ' : ℝ) : EReal :=
  ⨆ st : {p : ℤ × ℤ // p ≠ 0},
    ((((Int.gcd st.1.2 n : ℝ) * |ξ - ξ'| /
      (|(st.1.1 : ℝ) - st.1.2 * ξ| * |(st.1.1 : ℝ) - st.1.2 * ξ'|) : ℝ)) : EReal)

    DefinitionThe \(n\)-Markoff spectrum#✓fully proved

    MetaMathlibExt.nMarkoffSpectrum

    For a natural number \(n\) and irrational numbers \(\xi \ne \xi'\), the \(n\)-Markoff approximability \(\mu_n(\xi, \xi')\) is the extended real number \(\sup_{(s, t) \in \mathbb{Z}^2 \setminus \{0\}} \gcd(t, n) \, |\xi - \xi'| / (|s - t\xi| \, |s - t\xi'|)\).     def nMarkoffSpectrum (n : ℕ) : Set ℝ :=
  {α | ∃ ξ ξ' : ℝ, Irrational ξ ∧ Irrational ξ' ∧ ξ ≠ ξ' ∧ nMarkoffApproximability n ξ ξ' = α}

    TheoremConvergents and the Lagrange approximability#●ready to prove

    MetaMathlibExt.convergent_quality_and_lagrange_limsup

    Let \(\xi\) be an irrational real number, with complete quotients \(\xi_0 = \xi\) and \(\xi_{k+1} = 1/\{\xi_k\}\), where \(\{x\}\) is the fractional part of \(x\), and digits \(a_k = \lfloor \xi_k \rfloor\), so that \(\xi = [a_0; a_1, a_2, \dots]\). For \(k \ge 1\) let \(c_k = a_k + [0; a_{k-1}, \dots, a_1] + \{\xi_k\}\), where the middle term is \(0\) when \(k = 1\). Then for every \(k \ge 1\) the convergent \(p/q = [a_0; a_1, \dots, a_{k-1}]\), written in lowest terms with \(q > 0\), satisfies \((-1)^k / (q^2 (p/q - \xi)) = c_k\). Moreover, the \(1\)-Lagrange approximability \(\lambda_1(\xi)\) equals \(\limsup_{k \to \infty} c_k\), taken in the extended reals.

    public theorem_wanted convergent_quality_and_lagrange_limsup (ξ : ℝ) (hξ : Irrational ξ) :
    let cq : ℕ → ℝ := fun k => (fun x : ℝ => (Int.fract x)⁻¹)^[k] ξ
    let a : ℕ → ℤ := fun k => ⌊cq k⌋
    let rev : ℕ → ℝ := fun k =>
      ((List.range (k - 1)).reverse.map (fun i => a (i + 1))).foldr
        (fun b acc => 1 / ((b : ℝ) + acc)) 0
    let cut : ℕ → ℝ := fun k => (a k : ℝ) + rev k + Int.fract (cq k)
    (∀ k : ℕ, 1 ≤ k →
        (-1 : ℝ) ^ k / (((ξ.convergent (k - 1)).den : ℝ) ^ 2 *
          ((ξ.convergent (k - 1) : ℝ) - ξ)) = cut k) ∧
      nLagrangeApproximability 1 ξ = limsup (fun k => ((cut k : ℝ) : EReal)) atTop
