    DefinitionHeight of a real algebraic number#✓fully proved

    MathlibExt.NumberTheory.OnApproximationOfRealsWanted.OnApproximationOfReals.height

    Let \(\alpha\) be a real algebraic number, let \(p\) be its monic minimal polynomial over \(\mathbb{Q}\), and let \(D\) be the least common multiple of the denominators of the nonzero coefficients of \(p\). The height \(H(\alpha)\) is the largest absolute value of a coefficient of the integer polynomial \(D p\). For a real number that is not algebraic over \(\mathbb{Q}\), the height is \(0\).

    Equivalently, \(H(\alpha)\) is the largest absolute value of a coefficient of the minimal polynomial of \(\alpha\) scaled to have coprime integer coefficients.

    noncomputable def height (α : ℝ) : ℕ :=
  -- Let `p` be the minimal polynomial of `α`, defined to be monic and over `ℚ`.
  letI p := minpoly ℚ α
  -- Now let `D` be the LCM of the denominators of the nonzero coefficients.
  letI D := Multiset.lcm (Multiset.map (fun i ↦ (p.coeff i).den) p.support.val)
  -- The height of `α` is the supremum of the finite set of `|n|`, where `n` runs
  -- through the numerators of the nonzero coefficients of `D * p`.
  Finset.sup p.support (fun i ↦ (D * p.coeff i).num.natAbs)

    DefinitionApproximation exponents admitting infinitely many solutions#✓fully proved

    MathlibExt.NumberTheory.OnApproximationOfRealsWanted.OnApproximationOfReals.ω_stars

    Let \(n\) be a natural number, \(\xi\) a real number, and \(H(\alpha)\) the height of a real algebraic number \(\alpha\). This is the set of real numbers \(\omega > 0\) for which there are infinitely many real algebraic numbers \(\alpha\) of degree at most \(n\) with \(0 < |\xi - \alpha| \le H(\alpha)^{-\omega - 1}\).

    When \(n \ge 1\) and \(\xi\) is irrational, this set contains the interval \((0, 1)\) by Dirichlet's theorem.

    def ω_stars (n : ℕ) (ξ : ℝ) : Set ℝ≥0 :=
  {ω : ℝ≥0 | 0 < ω ∧
    {α : AlgebraicDegLE n | 0 < ‖ξ - α.1‖ ∧ ‖ξ - α.1‖ ≤ (height α.1) ^ (- (ω : ℝ) - 1)}.Infinite}
    def AlgebraicDegLE (n : ℕ) : Type :=
  {α : ℝ // IsAlgebraic ℚ α ∧ Polynomial.natDegree (minpoly ℚ α) ≤ n}

    For a natural number \(n\) and a real number \(\xi\), let \(H(\alpha)\) denote the height of a real algebraic number \(\alpha\). The classical exponent \(\omega^*_n(\xi)\) is the supremum in \([0, \infty]\) of the set of real numbers \(\omega > 0\) for which there are infinitely many real algebraic numbers \(\alpha\) of degree at most \(n\) with \(0 < |\xi - \alpha| \le H(\alpha)^{-\omega - 1}\).
