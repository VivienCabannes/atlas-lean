    DefinitionResultant product for truncated logarithmic polynomials#✓fully proved

    MetaMathlibExt.truncatedLogResultantProduct

    For a natural number \(n\), let \(F_n(x) = 1 + x + \frac{x^2}{2} + \dots + \frac{x^n}{n}\), let \(L_n = \operatorname{lcm}(1, \dots, n)\), and let \(\tilde F_n = L_n F_n \in \mathbb{Z}[x]\). The integer \(\mathcal{P}_n\) is the resultant \(\operatorname{Res}(1 + x + \dots + x^{n-1}, \tilde F_n)\). For \(n \ge 1\) the polynomial \(1 + x + \dots + x^{n-1} = F_n'\) is monic, so \(\mathcal{P}_n = \prod_{\theta} \tilde F_n(\theta)\), the product over the roots \(\theta\) of \(F_n'\).

    public noncomputable def truncatedLogResultantProduct (n : ℕ) : ℤ :=
  resultant (∑ k ∈ Finset.range n, (X : ℤ[X]) ^ k) (scaledTruncatedLogPolynomial n)

    DefinitionAuxiliary product for truncated logarithmic discriminants#✓fully proved

    MetaMathlibExt.truncatedLogAuxProduct

    For a natural number \(m\), let \(f_m(x) = \sum_{k=0}^{m-1} x^k\) and \(g_m(x) = c_m + \sum_{j=1}^{m-1} \frac{x^j}{j}\) in \(\mathbb{Q}[x]\), where \(c_m = \frac{1}{m}\) for \(m \ge 1\) and \(c_0 = 0\). The rational number \(X(m)\) is the resultant \(\operatorname{Res}(f_m, g_m)\). For \(m \ge 1\), since \(f_m\) is monic with roots \(\omega^k\) for \(1 \le k \le m-1\), where \(\omega\) is a primitive \(m\)-th root of unity, this is \(X(m) = \prod_{k=1}^{m-1} g_m(\omega^k)\).

    public noncomputable def truncatedLogAuxProduct (m : ℕ) : ℚ :=
  resultant (∑ k ∈ Finset.range m, (X : ℚ[X]) ^ k)
    (C ((m : ℚ)⁻¹) + ∑ j ∈ Finset.Icc 1 (m - 1), C ((j : ℚ)⁻¹) * X ^ j)

    DefinitionExceptional primes for truncated logarithmic discriminants#✓fully proved

    MetaMathlibExt.truncatedLogExceptionalPrimes

    For a natural number \(m\), the exceptional set \(E_m\) is the set of primes \(\ell\) with \(m\ell \equiv 1 \pmod 4\) such that the \(\ell\)-adic valuation of the auxiliary product \(X(m)\) is positive or the \(\ell\)-adic valuation of the harmonic number \(Y(m) = H_m = 1 + \frac{1}{2} + \dots + \frac{1}{m}\) is positive.

    The source's display joins the two valuation conditions with "and", but its text ("all prime divisors of \(X(m)\) and \(Y(m)\)") and its table (\(E_3 = \{11\}\) with \(11 \nmid X(3) = 13/36\)) use the union.

    public def truncatedLogExceptionalPrimes (m : ℕ) : Set ℕ :=
  {ℓ | ℓ.Prime ∧ (0 < padicValRat ℓ (truncatedLogAuxProduct m) ∨
    0 < padicValRat ℓ (_root_.harmonic m)) ∧ m * ℓ % 4 = 1}
    public noncomputable def truncatedLogAuxProduct (m : ℕ) : ℚ :=
