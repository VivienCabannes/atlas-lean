    DefinitionThe cyclotomic box#✓fully proved

    MetaMathlibExt.cyclotomicBox

    For natural numbers \(p\) and \(N\), the box \(B(p, N)\) is the finite set of integer vectors \(a = (a_1, \dots, a_{p-1}) \in \mathbb{Z}^{p-1}\) with \(-N \le a_i \le N\) for every \(i\).

  Fintype.piFinset fun _ => Finset.Icc (-(N : ℤ)) N

    DefinitionMoments of the trace distance on the cyclotomic box#✓fully proved

    MetaMathlibExt.cyclotomicDistMoment

    Let \(p \ge 1\), \(N\) and \(k\) be natural numbers, and let \(K\) be a field generated over \(\mathbb{Q}\) by a primitive \(p\)-th root of unity, with fixed primitive \(p\)-th root of unity \(\omega \in K\). Let \(d\) be the trace metric on \(K\), given by \(d(\alpha, \beta) \ge 0\) and \(d(\alpha, \beta)^2 = \sum_{j=1}^{p-1} \mathrm{Tr}_{K/\mathbb{Q}}((\alpha - \beta) \omega^j)^2\). Let \(B(p, N)\) be the set of integer vectors \(a = (a_1, \dots, a_{p-1})\) with \(-N \le a_i \le N\) for all \(i\), and write \(\alpha_a = a_1 \omega + \dots + a_{p-1} \omega^{p-1}\). The \(k\)-th moment of \(d\) over \(B(p, N)\) is the real number

    \[ M_k(p, N) = \frac{1}{\lvert B(p, N) \rvert^2} \sum_{a \in B(p, N)} \sum_{b \in B(p, N)} d(\alpha_a, \alpha_b)^k. \]
    noncomputable def cyclotomicDistMoment (p : ℕ) [NeZero p] (K : Type*) [Field K] [CharZero K]
    [IsCyclotomicExtension {p} ℚ K] (N k : ℕ) : ℝ :=
  (∑ a ∈ cyclotomicBox p N, ∑ b ∈ cyclotomicBox p N,
      cyclotomicTraceDist p (cyclotomicLatticePoint K a) (cyclotomicLatticePoint K b) ^ k) /
    ((cyclotomicBox p N).card : ℝ) ^ 2
    def cyclotomicBox (p N : ℕ) : Finset (Fin (p - 1) → ℤ) :=
  Fintype.piFinset fun _ => Finset.Icc (-(N : ℤ)) N
