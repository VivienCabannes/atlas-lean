    TheoremThe ramified bound for \(n = 2^a\)#●ready to prove

    MetaMathlibExt.two_pow_ramified_bound

    Let \(a \ge 1\), let \(n = 2^a\), let \(x > 1\) be a natural number, let \(\omega_n\) be the number of distinct prime factors of \(x^n - 1\), and let \(s_1 = 2 < s_2 = 3 < s_3 = 5 < \cdots\) be the primes in increasing order. Then

    \[\min\Bigl(1 + 2n \prod_{i=1}^{\omega_n} s_i,\ 1 + \prod_{i=2}^{\omega_n + 1} s_i\Bigr) \le x^n.\]

    Equivalently, \(x\) is at least the smaller of the \(n\)-th roots of these two numbers, which is the form of the source. The source admits every positive integer \(x\); at \(x = 1\) the number \(x^n - 1 = 0\) has an empty prime factorization, so \(\omega_n = 0\) and the bound would read \(2 \le 1\).

    public theorem_wanted two_pow_ramified_bound {a x : ℕ} (ha : 0 < a) (hx : 1 < x) :
    min (1 + 2 * 2 ^ a * ∏ i ∈ Finset.range (x ^ 2 ^ a - 1).primeFactors.card, Nat.nth Nat.Prime i)
        (1 + ∏ i ∈ Finset.range (x ^ 2 ^ a - 1).primeFactors.card, Nat.nth Nat.Prime (i + 1)) ≤
      x ^ 2 ^ a

    TheoremRamified bound on the number of prime divisors of \(x^n - 1\)#●ready to prove

    MetaMathlibExt.ramified_bound_prime_divisors

    The ramified bound. Let n = ∏_{i=1}^m p_i^{a_i} with primes p_1 < ⋯ < p_m (the ordering the source fixes at the start of its Section 5), x > 1, ω_n = ω(x^n - 1), and, with p_0 := 1, let r_{i,j} be the i-th element (Nat.nth, 0-indexed here) of Π^j = {ρ prime : ρ ≡ 1 (mod p_j), ρ ≢ 1 (mod p_s) for j < s ≤ m}. Fix a prime factor p_α of n and write p_α = r_{b,τ} with τ ≤ m. As in hybrid_bound_prime_divisors, the source's x ≥ min_{k_0 + ⋯ + k_m = ω_n} max_t (1 + ∏_{j ≤ t} δ_α(j) ∏_{i ≤ k_j} r_{i,j})^{T(t)} is stated as the existence of a composition k (parts in ℕ, not ℤ⁺) meeting every bound after raising to the power ∏_{s ≤ t} p_s^{a_s}. The factors δ_α(j) are applied to the block products: if p_α ∣ x^n - 1, block τ with k_τ < b (1-indexed in the source, k_τ ≤ b here) has its largest factor r_{k_τ,τ} replaced by p_α, and block α gains the factor p_α^{a_α}; if p_α ∤ x^n - 1, block τ with k_τ ≥ b drops p_α and takes the next element instead. In the divisible case the composition also has k_τ > 0 (the source's δ_α(τ) is undefined at k_τ = 0). The source's worked example (n = 3, ω_3 = 10: x ≥ 4387 if 3 ∣ x^3 - 1, x ≥ 5423 otherwise) is reproduced exactly by this reading. Definitions follow the arXiv version (arXiv:2412.00010), whose statement matches the journal record.

    TheoremRamified bound on prime divisors of \(x^p - 1\) for prime \(p\)#●ready to prove

    MetaMathlibExt.prime_ramified_bound

    The p-ramified bound (Theorem 2 for prime n = p). For a prime p, x > 1 and ω_p = ω(x^p - 1), let r_{i,0} and r_{j,1} enumerate the primes ≢ 1 and ≡ 1 (mod p) (Nat.nth, 0-indexed here), p = r_{b,0}, R^0_k = ∏_{i < k} r_{i,0} and R^1_k = ∏_{j < ω_p - k} r_{j,1}. The source's minima over k ∈ [0, k') ∪ [k', ω_p) (with k' = b + 1) are stated as the existence of k < ω_p meeting both bounds, the second after raising to the p-th power; p^{-1} R^0_{k+1} is written as the product over {0, …, k} \ {b}. If p ∤ x^p - 1: k ≤ b gives 1 + R^0_k ≤ x, 1 + R^0_k R^1_k ≤ x^p, and k > b gives 1 + p^{-1} R^0_{k+1} ≤ x, 1 + p^{-1} R^0_{k+1} R^1_k ≤ x^p. If p ∣ x^p - 1: k ≤ b gives 1 + p R^0_{k-1} ≤ x, 1 + p^2 R^0_{k-1} R^1_k ≤ x^p, and k > b gives 1 + R^0_k ≤ x, 1 + p R^0_k R^1_k ≤ x^p.     public theorem_wanted prime_ramified_bound {p : ℕ} (hp : p.Prime) {x : ℕ} (hx : 1 < x) {b : ℕ}

    let ω := (x ^ p - 1).primeFactors.card
