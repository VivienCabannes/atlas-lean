    Rat.Place

    The set \(M_{\mathbb{Q}}\) of places of \(\mathbb{Q}\), which indexes the inequivalent normalised absolute values on \(\mathbb{Q}\). It consists of one infinite place, corresponding to the ordinary archimedean absolute value, and one finite place for each prime number \(p\), corresponding to the \(p\)-adic absolute value.

    inductive Place : Type where
  | infinite : Place
  | finite : (prime : Nat.Primes) → Place
  deriving DecidableEq

    DefinitionAbsolute value at a rational place#✓fully proved

    Rat.Place.absoluteValue

    For a place \(v\) of \(\mathbb{Q}\), the absolute value \(|\cdot|_v : \mathbb{Q} \to \mathbb{R}\) sends \(q \in \mathbb{Q}\) to the ordinary absolute value \(|q|\) when \(v\) is the infinite place. When \(v\) is the finite place at a prime \(p\), it sends \(q\) to the normalised \(p\)-adic absolute value \(|q|_p\), where \(|0|_p = 0\) and \(|q|_p = p^{-v_p(q)}\) for \(q \neq 0\), with \(v_p(q)\) the \(p\)-adic valuation of \(q\).

    noncomputable def absoluteValue : Place → AbsoluteValue ℚ ℝ
  | .infinite => Rat.AbsoluteValue.real
  | .finite prime =>
    haveI : Fact prime.1.Prime := ⟨prime.2⟩
    Rat.AbsoluteValue.padic prime.1
    inductive Place : Type where
  | infinite : Place
  | finite : (prime : Nat.Primes) → Place
  deriving DecidableEq

    Rat.Place.CompletedField

    TheoremEvery nontrivial absolute value on \(\mathbb{Q}\) is equivalent to that of a place#✓fully proved

    Rat.Place.exists_place_equiv

    Let \(f\) be a real-valued absolute value on \(\mathbb{Q}\) that is nontrivial, that is, \(f(x) \ne 1\) for some \(x \ne 0\). Then there is a place \(v\) of \(\mathbb{Q}\) such that \(f\) is equivalent to the absolute value \(|\cdot|_v\) attached to \(v\) (the ordinary absolute value at the infinite place, the \(p\)-adic absolute value at the prime \(p\)).

    Here two absolute values \(f\) and \(g\) on \(\mathbb{Q}\) are equivalent when \(f(x) \le f(y)\) holds exactly when \(g(x) \le g(y)\), for all \(x, y \in \mathbb{Q}\).

    theorem exists_place_equiv (f : AbsoluteValue ℚ ℝ) (hf : f.IsNontrivial) :
    ∃ v : Place, f ≈ v.absoluteValue
    inductive Place : Type where
  | infinite : Place
  | finite : (prime : Nat.Primes) → Place
  deriving DecidableEq

    TheoremThe embedding of \(\mathbb{Q}\) into its completion at a place is an isometry#✓fully proved

    Rat.Place.withAbsEmbedding_isometry

    Let \(v\) be a place of \(\mathbb{Q}\), let \(|\cdot|_v\) be the absolute value attached to \(v\), and let \(\mathbb{Q}_v\) be the completed field at \(v\). The canonical embedding of \(\mathbb{Q}\), equipped with the metric \(d(x, y) = |x - y|_v\), into \(\mathbb{Q}_v\) is an isometry: for all \(x, y \in \mathbb{Q}\), the distance between the images of \(x\) and \(y\) in \(\mathbb{Q}_v\) equals \(|x - y|_v\).
