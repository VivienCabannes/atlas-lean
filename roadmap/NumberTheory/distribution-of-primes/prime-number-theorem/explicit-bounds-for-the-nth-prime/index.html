    TheoremAxler's lower bound for the \(n\)th prime#●ready to prove

    MetaMathlibExt.axler_nth_prime_lower_bound

    For every integer \(n \ge 2\), the \(n\)th prime \(p_n\) (so that \(p_1 = 2\)) satisfies \(p_n > n \left(\log n + \log\log n - 1 + \frac{\log\log n - 2}{\log n} - \frac{(\log\log n)^2 - 6 \log\log n + 11.321}{2 \log^2 n}\right)\).

    theorem_wanted axler_nth_prime_lower_bound (n : ℕ) (hn : 2 ≤ n) :
    (n : ℝ) * (Real.log (n : ℝ) + Real.log (Real.log (n : ℝ)) - 1 +
      (Real.log (Real.log (n : ℝ)) - 2) / Real.log (n : ℝ) -
      ((Real.log (Real.log (n : ℝ))) ^ 2 - 6 * Real.log (Real.log (n : ℝ)) + 11.321) /
        (2 * (Real.log (n : ℝ)) ^ 2)) <
      (Nat.nth Nat.Prime (n - 1) : ℝ)
    Sources

    TheoremMandl's inequality for the sum of the first \(n\) primes#●ready to prove

    MetaMathlibExt.mandl_prime_sum_inequality

    Let \(p_k\) denote the \(k\)-th prime, so that \(p_1 = 2\). For every natural number \(n \ge 9\), twice the sum of the first \(n\) primes is at most \(n\) times the \(n\)-th prime: \(2(p_1 + \cdots + p_n) \le n \, p_n\).

    Dusart proved the inequality for every \(n \ge 9\), as quoted by Axler.

    theorem_wanted mandl_prime_sum_inequality (n : ℕ) (hn : 9 ≤ n) :
    2 * (∑ k ∈ Finset.range n, Nat.nth Nat.Prime k) ≤
      n * Nat.nth Nat.Prime (n - 1)
    Sources

    TheoremLower bound for the logarithm of the \(n\)-th prime#●ready to prove

    MetaMathlibExt.log_nthPrime_ge_log_add_loglog

    Let \(p_n\) denote the \(n\)-th prime, so that \(p_1 = 2\). For every integer \(n \ge 3\),

    \[\log p_n \ge \log n + \log\log n + \log\left(1 + \frac{\log\log n - 1}{\log n}\right).\]

    The paper states this for all positive integers \(n\); the right side is undefined at \(n = 1\) (where \(\log\log 1\) appears) and at \(n = 2\) (where the last logarithm's argument is about \(-0.9715\)), so \(n \ge 3\) is assumed.

    public theorem_wanted log_nthPrime_ge_log_add_loglog (n : ℕ) (hn : 3 ≤ n) :
    Real.log n + Real.log (Real.log n) +
        Real.log (1 + (Real.log (Real.log n) - 1) / Real.log n) ≤
      Real.log (Nat.nth Nat.Prime (n - 1) : ℝ)
