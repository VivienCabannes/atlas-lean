    GPY–Maynard sieve

    The Goldston–Pintz–Yıldırım (GPY) method finds several primes among \(n + h_1, \dots, n + h_k\), for an admissible set \(\{h_1, \dots, h_k\}\), by showing that the sum \(\sum_n (\sum_i \mathbf 1_{\mathbb P}(n + h_i) - \rho) w_n\) is positive for non-negative Selberg-type weights \(w_n\). Maynard's refinement lets the weights depend on the divisors of each \(n + h_i\) separately, \(w_n = (\sum_{d_i \mid n + h_i} \lambda_{d_1, \dots, d_k})^2\), which reduces the problem to the variational quantity \(M_k\). This topic proves the combinatorial and limiting part of that reduction and states Maynard's bounds on \(M_k\). The analytic input, Maynard's Proposition 4.1, is a hypothesis.

    DefinitionNumber of prime translates#✓fully proved

    MathlibExt.NumberTheory.GPYMaynard.primeShiftCount

    For a finite set \(H\) of natural numbers and \(n \in \mathbb N\), the number of prime translates is $\(\#\{h \in H : n + h \text{ is prime}\} = \sum_{h \in H} \mathbf 1_{\mathbb P}(n + h),\)$ the inner sum in the Goldston–Pintz–Yıldırım detecting sum \(S(N, \rho)\) of Maynard (2015), display (2.1). Shifts are natural numbers, as in Maynard's and GPY's definition of a \(k\)-tuple \(\{h_1, \dots, h_k\}\) of distinct non-negative integers.

    def primeShiftCount (H : Finset ℕ) (n : ℕ) : ℕ :=
  (H.filter fun h => (n + h).Prime).card

    TheoremGPY detection principle, finite form#✓fully proved

    MathlibExt.NumberTheory.GPYMaynard.exists_lt_primeShiftCount_of_sum_pos

    Let \(s\) be a finite set of natural numbers, \(w : \mathbb N \to \mathbb R\) with \(w_n \ge 0\) for \(n \in s\), \(H\) a finite set of shifts and \(\rho \in \mathbb R\). If $\(\sum_{n \in s} \Bigl(\sum_{h \in H} \mathbf 1_{\mathbb P}(n + h) - \rho\Bigr) w_n > 0,\)$ then some \(n \in s\) has more than \(\rho\) of the numbers \(n + h\), \(h \in H\), prime, that is at least \(\lfloor \rho + 1 \rfloor\) of them.

    This is the positivity argument stated after display (2.1) of Maynard (2015): a positive sum of terms \((\cdot)\, w_n\) with \(w_n \ge 0\) has a term with a positive first factor.

    theorem exists_lt_primeShiftCount_of_sum_pos (H : Finset ℕ) (s : Finset ℕ) (w : ℕ → ℝ)
    (hw : ∀ n ∈ s, 0 ≤ w n) (ρ : ℝ)
    (hpos : 0 < ∑ n ∈ s, ((primeShiftCount H n : ℝ) - ρ) * w n) :
    ∃ n ∈ s, ρ < primeShiftCount H n
    def primeShiftCount (H : Finset ℕ) (n : ℕ) : ℕ :=
  (H.filter fun h => (n + h).Prime).card

    TheoremGPY detection principle over dyadic ranges#✓fully proved

    MathlibExt.NumberTheory.GPYMaynard.infinite_lt_primeShiftCount_of_eventually_sum_pos

    Let \(w_N(n) \ge 0\) for all \(N, n \in \mathbb N\), let \(H\) be a finite set of shifts and \(\rho \in \mathbb R\). If, for all sufficiently large \(N\), $\(S(N, \rho) = \sum_{N \le n < 2N} \Bigl(\sum_{h \in H} \mathbf 1_{\mathbb P}(n + h) - \rho\Bigr) w_N(n) > 0,\)$ then infinitely many \(n\) have more than \(\rho\) of the \(n + h\) prime. This is the conclusion "if \(S(N, \rho) > 0\) for all large \(N\), there are infinitely many integers \(n\) for which at least \(\lfloor \rho + 1 \rfloor\) of the \(n + h_i\) are prime" in Section 2 of Maynard (2015).

    theorem infinite_lt_primeShiftCount_of_eventually_sum_pos (H : Finset ℕ) (w : ℕ → ℕ → ℝ)
    (hw : ∀ N n, 0 ≤ w N n) (ρ : ℝ)
    (hpos : ∀ᶠ N in atTop,
      0 < ∑ n ∈ Finset.Ico N (2 * N), ((primeShiftCount H n : ℝ) - ρ) * w N n) :
    {n : ℕ | ρ < primeShiftCount H n}.Infinite
    def primeShiftCount (H : Finset ℕ) (n : ℕ) : ℕ :=
  (H.filter fun h => (n + h).Prime).card

    TheoremFrom the asymptotics of \(S_1\) and \(S_2\) to infinitely many prime-rich translates#✓fully proved

    MathlibExt.NumberTheory.GPYMaynard.infinite_lt_primeShiftCount_of_tendsto

    Let \(w_N(n) \ge 0\) and set $\(S_1(N) = \sum_{N \le n < 2N} w_N(n), \qquad S_2(N) = \sum_{N \le n < 2N} \Bigl(\sum_{h \in H} \mathbf 1_{\mathbb P}(n + h)\Bigr) w_N(n).\)$ If \(B(N) > 0\) for all large \(N\), \(S_1(N)/B(N) \to I\), \(S_2(N)/B(N) \to J\) and \(\rho I < J\), then infinitely many \(n\) have more than \(\rho\) of the \(n + h\) prime.

    This is the limiting step of the proof of Proposition 4.2 in Maynard (2015): \(S = S_2 - \rho S_1\) is eventually positive because \((S_2 - \rho S_1)/B \to J - \rho I > 0\), display (4.4). Maynard's sums (4.2)–(4.3) also restrict \(n\) to a residue class \(v_0 \bmod W\); here that restriction is part of the weights \(w_N\). No sign condition on \(I\) is needed.

    A test in MathlibExtTest checks that the hypotheses can hold non-trivially: with \(H = \{0\}\), \(w_N(n) = \mathbf 1_{\mathbb P}(n)\) and \(B = S_1\), which is positive for \(N \ge 2\) by Bertrand's postulate, both ratios are eventually \(1\) and the conclusion is the infinitude of the primes.

    theorem infinite_lt_primeShiftCount_of_tendsto (H : Finset ℕ) (w : ℕ → ℕ → ℝ)
    (hw : ∀ N n, 0 ≤ w N n) (B : ℕ → ℝ) (hB : ∀ᶠ N in atTop, 0 < B N) (I J ρ : ℝ)
    (hS₁ : Tendsto (fun N => (∑ n ∈ Finset.Ico N (2 * N), w N n) / B N) atTop (𝓝 I))
    (hS₂ : Tendsto (fun N => (∑ n ∈ Finset.Ico N (2 * N),
      (primeShiftCount H n : ℝ) * w N n) / B N) atTop (𝓝 J))
    (hρ : ρ * I < J) :
    {n : ℕ | ρ < primeShiftCount H n}.Infinite
    def primeShiftCount (H : Finset ℕ) (n : ℕ) : ℕ :=
  (H.filter fun h => (n + h).Prime).card

    TheoremMaynard's reduction for one weight profile#✓fully proved

    MathlibExt.NumberTheory.GPYMaynard.infinite_lt_primeShiftCount_of_maynard_asymptotics

    Let \(\theta, \rho \in \mathbb R\), \(I > 0\) and \(J \in \mathbb R\) with \(\rho < \tfrac{\theta}{2} \cdot \tfrac{J}{I}\), and let \(\delta_0 > 0\). Suppose that for every \(\delta \in (0, \delta_0)\) there are weights \(w_N(n) \ge 0\) and a normalisation \(B(N)\), positive for large \(N\), with $\(\frac{S_1(N)}{B(N)} \to I, \qquad \frac{S_2(N)}{B(N)} \to \Bigl(\frac{\theta}{2} - \delta\Bigr) J,\)$ where \(S_1, S_2\) are the sums of the limiting step. Then infinitely many \(n\) have more than \(\rho\) of the \(n + h\), \(h \in H\), prime.

    The hypothesis is the shape of Maynard's Proposition 4.1. If the primes have level of distribution \(\theta\), \(R = N^{\theta/2 - \delta}\) and \(F\) is a smooth profile, Proposition 4.1 gives \(S_1 = (1 + o(1))\, B\, I_k(F)\) and \(S_2 = (1 + o(1))\, B\, \tfrac{\log R}{\log N} \sum_m J_k^{(m)}(F)\) with \(B = \varphi(W)^k N (\log R)^k / W^{k+1}\); since \(\log R / \log N = \theta/2 - \delta\), this is the hypothesis with \(I = I_k(F)\) and \(J = \sum_m J_k^{(m)}(F)\). The asymptotics are assumed, not proved: nothing about the distribution of primes is formalised here.

    theorem infinite_lt_primeShiftCount_of_maynard_asymptotics (H : Finset ℕ) (θ ρ I J : ℝ)
    (hI : 0 < I) (hρ : ρ < θ / 2 * (J / I)) (δ₀ : ℝ) (hδ₀ : 0 < δ₀)
    (hasym : ∀ δ : ℝ, 0 < δ → δ < δ₀ → ∃ (w : ℕ → ℕ → ℝ) (B : ℕ → ℝ),
      (∀ N n, 0 ≤ w N n) ∧ (∀ᶠ N in atTop, 0 < B N) ∧
      Tendsto (fun N => (∑ n ∈ Finset.Ico N (2 * N), w N n) / B N) atTop (𝓝 I) ∧
      Tendsto (fun N => (∑ n ∈ Finset.Ico N (2 * N),
        (primeShiftCount H n : ℝ) * w N n) / B N) atTop (𝓝 ((θ / 2 - δ) * J))) :
    {n : ℕ | ρ < primeShiftCount H n}.Infinite
    def primeShiftCount (H : Finset ℕ) (n : ℕ) : ℕ :=
  (H.filter fun h => (n + h).Prime).card

    TheoremMaynard's Proposition 4.2, reduction to the asymptotics of Proposition 4.1#✓fully proved

    MathlibExt.NumberTheory.GPYMaynard.infinite_lt_primeShiftCount_of_lt_maynardM

    Let \(H\) be a finite set of shifts, \(k \in \mathbb N\), \(\theta > 0\) and \(\rho \in \mathbb R\). If $\(\rho < \frac{\theta\, M_k}{2},\)$ and for every admissible profile \(F\) and every \(\delta \in (0, \delta_0)\) there are weights \(w_N \ge 0\) and \(B(N) > 0\) (for large \(N\)) with \(S_1/B \to I_k(F)\) and \(S_2/B \to (\theta/2 - \delta) \sum_m J_k^{(m)}(F)\), then infinitely many \(n\) have more than \(\rho\) of the \(n + h\) prime. Taking \(\rho = m\) gives \(m + 1\) primes. Under Elliott–Halberstam, with \(\theta = 1 - \varepsilon\), the condition is essentially \(M_k > 2m\); with the Bombieri–Vinogradov level \(\theta = \tfrac12 - \varepsilon\) it is essentially \(M_k > 4m\). In the intended application \(H\) is admissible with \(\#H = k\); the Lean statement does not tie \(k\) to \(H\), and the hypothesis can only hold if \(\delta_0 \le \theta/2\) (for \(k \ge 1\) a limit of non-negative sums cannot be negative).

    Relation to the source. This is the first conclusion of Maynard (2015), Proposition 4.2, with \(r_k = \lceil \theta M_k / 2 \rceil\) replaced by "more than \(\rho\)" for every \(\rho < \theta M_k / 2\); the two are equivalent. The asymptotics are taken as hypotheses, and the weights in them are unconstrained: for each profile \(F\) and each \(\delta\), some non-negative weights must achieve the two limits. This abstracts Maynard's Proposition 4.1, which gives such limits for smooth \(F\) with his sieve weights. The hypotheses are satisfiable for every admissible profile, smooth or not: if \(H\) is admissible with \(\#H = k\), \(\theta\) is a level of distribution and \(\delta_0 \le \theta/2\), then \(c = (\theta/2 - \delta)\, \sum_m J_k^{(m)}(F) / I_k(F)\) lies in \((0, \theta M_k/2)\); Maynard's argument for a smooth near-optimal profile gives, for large \(N\), some \(n_1 \in [N, 2N)\) with more than \(c\) primes among the \(n_1 + h\), the Chinese remainder theorem gives \(n_0 \in [N, 2N)\) with none, and the weights \(\alpha \mathbf 1_{n_1} + \beta \mathbf 1_{n_0}\) in the right proportion achieve both limits exactly. A non-degenerate satisfiability test of the limiting step is in the test module (see the limiting step). The second conclusion of Proposition 4.2, \(\liminf_n (p_{n + r_k - 1} - p_n) \le \max_{i, j} (h_i - h_j)\), is the bridge to prime gaps.

    The proof picks, by the definition of the supremum, a profile \(F\) with \(\rho < \tfrac{\theta}{2} \sum_m J_k^{(m)}(F) / I_k(F)\) and applies the reduction for one profile. It needs no upper bound on the ratios: a real supremum of a nonempty set that exceeds \(2\rho/\theta\) is exceeded by an element of the set, and admissible profiles exist.

    theorem infinite_lt_primeShiftCount_of_lt_maynardM (H : Finset ℕ) (k : ℕ) (θ ρ : ℝ)
    (hθ : 0 < θ)
    (hρ : ρ < θ * maynardM k / 2) (δ₀ : ℝ) (hδ₀ : 0 < δ₀)
    (hasym : ∀ F, IsMaynardProfile k F → ∀ δ : ℝ, 0 < δ → δ < δ₀ →
      ∃ (w : ℕ → ℕ → ℝ) (B : ℕ → ℝ),
      (∀ N n, 0 ≤ w N n) ∧ (∀ᶠ N in atTop, 0 < B N) ∧
      Tendsto (fun N => (∑ n ∈ Finset.Ico N (2 * N), w N n) / B N) atTop
        (𝓝 (maynardI k F)) ∧
      Tendsto (fun N => (∑ n ∈ Finset.Ico N (2 * N),
        (primeShiftCount H n : ℝ) * w N n) / B N) atTop
        (𝓝 ((θ / 2 - δ) * ∑ m, maynardJ k m F))) :
    {n : ℕ | ρ < primeShiftCount H n}.Infinite
    noncomputable def maynardM (k : ℕ) : ℝ :=
  sSup (maynardRatio k '' {F | IsMaynardProfile k F})

    TheoremPrime-rich translates give short gaps between the \(j\)-th and \((j+m)\)-th primes#✓fully proved

    MathlibExt.NumberTheory.GPYMaynard.frequently_nth_prime_add_sub_le_of_infinite

    Let \(p_0 = 2 < p_1 = 3 < \cdots\) be the primes, indexed from \(0\). Let \(H\) be a finite set of natural numbers with \(b \le a + D\) for all \(a, b \in H\). If infinitely many \(n\) have more than \(m\) of the \(n + h\), \(h \in H\), prime, then $\(p_{j + m} - p_j \le D \quad \text{for infinitely many } j,\)$ that is \(\liminf_j (p_{j+m} - p_j) \le D\). This is the step "In particular, \(\liminf_n (p_{n + r_k - 1} - p_n) \le \max_{1 \le i, j \le k} (h_i - h_j)\)" of Maynard (2015), Proposition 4.2, with \(r_k - 1 = m\).

    Proof idea: if \(n + a\) is the least prime among the \(n + h\) and \(j\) is its index, then the \(m + 1\) primes among the \(n + h\) lie in \([p_j, p_j + D]\), so \(p_{j+m} \le p_j + D\); and \(j \to \infty\) as \(n \to \infty\).

    theorem frequently_nth_prime_add_sub_le_of_infinite (H : Finset ℕ) (m D : ℕ)
    (hD : ∀ a ∈ H, ∀ b ∈ H, b ≤ a + D)
    (hinf : {n : ℕ | (m : ℝ) < primeShiftCount H n}.Infinite) :
    ∃ᶠ j in atTop, Nat.nth Nat.Prime (j + m) - Nat.nth Nat.Prime j ≤ D

    DefinitionMaynard's simplex#✓fully proved

    MathlibExt.NumberTheory.GPYMaynard.maynardSimplex

    For \(k \in \mathbb N\), $\(\mathcal R_k = \Bigl\{(x_1, \dots, x_k) \in [0, \infty)^k : \sum_{i=1}^{k} x_i \le 1\Bigr\},\)$ the set on which Maynard's profiles \(F\) are supported (Maynard (2015), Proposition 4.1). The constraint \(\sum_i x_i \le 1\) reflects the support condition \(\prod_i d_i < R\) on the sieve weights \(\lambda_{d_1, \dots, d_k}\).

    def maynardSimplex (k : ℕ) : Set (Fin k → ℝ) :=
  {x | (∀ i, 0 ≤ x i) ∧ ∑ i, x i ≤ 1}

    MathlibExt.NumberTheory.GPYMaynard.maynardI

    DefinitionAdmissible profiles for \(M_k\)#✓fully proved

    MathlibExt.NumberTheory.GPYMaynard.IsMaynardProfile

    A function \(F : \mathbb R^k \to \mathbb R\) is an admissible profile if it is measurable and bounded, vanishes outside Maynard's simplex \(\mathcal R_k\), and satisfies \(I_k(F) \ne 0\) and \(J_k^{(m)}(F) \ne 0\) for every \(m\).

    Relation to the source. Maynard (2015), Proposition 4.2, takes the set \(\mathcal S_k\) of Riemann-integrable \(F : [0, 1]^k \to \mathbb R\) supported on \(\mathcal R_k\) with \(I_k(F) \ne 0\) and \(J_k^{(m)}(F) \ne 0\). Every such function is bounded, and it agrees almost everywhere with a Borel-measurable function, which has the same \(I_k\) and \(J_k^{(m)}\) (slices of a null set are null for almost every value of the other coordinates). A Riemann-integrable function need not itself be Borel-measurable, which is the notion of measurability used here, so this class contains an a.e.-equivalent of each element of \(\mathcal S_k\) (extended by \(0\) outside the cube) rather than \(\mathcal S_k\) itself. It is larger in the other direction, since it contains bounded measurable functions that are not a.e. equal to any Riemann-integrable one.

    def IsMaynardProfile (k : ℕ) (F : (Fin k → ℝ) → ℝ) : Prop :=
  Measurable F ∧ (∃ C : ℝ, ∀ x, |F x| ≤ C) ∧ (∀ x ∉ maynardSimplex k, F x = 0) ∧
    maynardI k F ≠ 0 ∧ ∀ m, maynardJ k m F ≠ 0
    def maynardSimplex (k : ℕ) : Set (Fin k → ℝ) :=
  {x | (∀ i, 0 ≤ x i) ∧ ∑ i, x i ≤ 1}

    TheoremAdmissible profiles exist#✓fully proved

    MathlibExt.NumberTheory.GPYMaynard.exists_isMaynardProfile

    For every \(k \in \mathbb N\), the indicator of the box \([0, \tfrac{1}{k+1}]^k\) is an admissible profile: it is bounded and measurable, it vanishes outside Maynard's simplex because \(k \cdot \tfrac{1}{k+1} \le 1\), and \(I_k\) and every \(J_k^{(m)}\) are positive on it.     DefinitionMaynard's variational quantity \(M_k\)#✓fully proved

    MathlibExt.NumberTheory.GPYMaynard.maynardM

    $\(M_k = \sup_{F} \frac{\sum_{m=1}^{k} J_k^{(m)}(F)}{I_k(F)},\)$ the supremum over admissible profiles (Maynard (2015), Proposition 4.2). If the primes have level of distribution \(\theta\), then every admissible \(k\)-tuple has infinitely many translates containing at least \(\lceil \theta M_k / 2 \rceil\) primes; see the reduction.

    Relation to the source. The Lean supremum is taken over bounded Borel-measurable profiles rather than Maynard's Riemann-integrable ones; the Lean class contains an a.e.-equivalent, with the same ratio, of each of Maynard's profiles, so once the ratios are bounded the Lean \(M_k\) is at least Maynard's. The two suprema agree: by the Cauchy–Schwarz inequality in \(t_m\), \(J_k^{(m)}(F) \le I_k(F)\), so each \(J_k^{(m)}\) is the square of the \(L^2\) norm of a linear operator of norm at most \(1\), and \(I_k\) and the \(J_k^{(m)}\) are continuous for the \(L^2\) norm on \(\mathcal R_k\); and finite combinations of indicators of boxes inside \(\mathcal R_k\), which are Riemann-integrable, are dense in \(L^2(\mathcal R_k)\). This comparison is not formalised. The same bound shows that the ratios are at most \(k\), so the supremum is finite; the Lean definition, a real sSup, would take the junk value \(0\) only for an empty or unbounded set of ratios; the set is nonempty by the existence of admissible profiles, and its boundedness is the unformalised Cauchy–Schwarz bound above.

  sSup (maynardRatio k '' {F | IsMaynardProfile k F})
