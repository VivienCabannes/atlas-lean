    Almost primes of almost prime index

    DefinitionAlmost primes of almost prime index#✓fully proved

    MetaMathlibExt.almostPrimeIndexSet

    For natural numbers \(k_1, \dots, k_m\) with \(m \ge 1\), the set \(N_{k_1 \cdots k_m}\) of natural numbers is defined by recursion on \(m\): \(N_{k_1}\) is the set of \(k_1\)-almost primes (the \(n \ne 0\) with exactly \(k_1\) prime factors counted with multiplicity), and for \(m \ge 2\), \(N_{k_1 \cdots k_m}\) is the set of the \(i\)th \(k_1\)-almost primes, in increasing order and counted from \(1\), for \(i \ge 1\) in \(N_{k_2 \cdots k_m}\). When there are fewer than \(i\) \(k_1\)-almost primes (only for \(k_1 = 0\), where \(1\) is the only one), the \(i\)th one is taken to be \(0\).

    public def almostPrimeIndexSet (k : ℕ) : List ℕ → Set ℕ
  | [] => {n | Nat.IsAlmostPrime k n}
  | j :: L => {n | ∃ i ∈ almostPrimeIndexSet j L, 1 ≤ i ∧ n = Nat.nth (Nat.IsAlmostPrime k) (i - 1)}

    TheoremDusart's bounds for the \(n\)th prime#●ready to prove

    MetaMathlibExt.nth_prime_dusart_bounds

    For \(n \ge 1\) let \(p_n\) denote the \(n\)th prime, so that \(p_1 = 2\), and let \(\log\) be the natural logarithm. For every natural number \(n \ge 2\),

    \[ p_n \ge n (\log n + \log \log n - 1) \]

    and

    \[ p_n \ge n \left( \log n + \log \log n - 1 + \frac{\log \log n - 2.25}{\log n} \right), \]

    \[ p_n \le n (\log n + \log \log n - 0.9484). \]

    TheoremCrişan–Erban expansion of the semiprime counting function#●ready to prove

    MetaMathlibExt.semiprime_count_asymptotic_expansion

    A semiprime is a product of exactly two primes counted with multiplicity; for real \(x\) let \(N_2(x)\) be the number of semiprimes at most \(x\). Let \(\beta\) be the Meissel–Mertens constant, \(\gamma\) the Euler–Mascheroni constant and \(\log\) the natural logarithm. There are real constants \(c_0, c_1, c_2, \dots\) with \(c_0 = \beta\) and

    \[ c_1 = \beta - 1 - \gamma - \sum_{p} \frac{\log p}{p (p - 1)}, \]

    the sum running over all primes \(p\), such that for every natural number \(N\), as \(x \to \infty\),

    \[ N_2(x) = \frac{x}{\log x} \sum_{n=0}^{N-1} \frac{n! \, (\log \log x + c_n)}{\log^n x} + O_N\left( \frac{x \log \log x}{\log^{N+1} x} \right). \]

    The paper calls the \(c_n\) explicit but displays only \(c_0\) and \(c_1\); the remaining constants are only asserted to exist.
