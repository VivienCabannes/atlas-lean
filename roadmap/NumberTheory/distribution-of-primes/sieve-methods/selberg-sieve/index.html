    Selberg sieve

    Selberg's \(\Lambda^2\) sieve bounds the number of elements of a finite set free of a given set of primes by replacing the indicator \(\mathbf 1_{(n, P) = 1}\) with the square \((\sum_{d \mid (n, P)} \lambda_d)^2\), \(\lambda_1 = 1\), and then optimising the quadratic form in the \(\lambda_d\).

    TheoremSelberg's \(\Lambda^2\) inequality, pointwise#✓fully proved

    MathlibExt.SelbergSieve.indicator_coprime_le_sq_sum

    Let \(P \ne 0\) and let \(\lambda : \mathbb N \to \mathbb R\) satisfy \(\lambda_1 = 1\). For every \(n \in \mathbb N\), $\(\mathbf 1_{\gcd(P, n) = 1} \le \Bigl(\sum_{d \mid P,\ d \mid n} \lambda_d\Bigr)^2 .\)$ If \(\gcd(P, n) = 1\) the only common divisor is \(d = 1\) and the right side is \(\lambda_1^2 = 1\); otherwise the right side is a square. This is the computation after display (2.1) of Heath-Brown's lectures, which shows that the \(\Lambda^2\) weights \(\mu^+(d) = \sum_{[d_1, d_2] = d} \lambda_{d_1} \lambda_{d_2}\) satisfy the upper-bound sieve condition (1.6). Heath-Brown takes \(P = \Pi(\mathcal P, z)\) squarefree; the inequality holds for every \(P \ne 0\).

    Mathlib states the same fact in Möbius form as BoundingSieve.upperMoebius_lambdaSquared.

    theorem indicator_coprime_le_sq_sum (P : ℕ) (hP : P ≠ 0) (lam : ℕ → ℝ) (h1 : lam 1 = 1)
    (n : ℕ) :
    (if Nat.Coprime P n then (1 : ℝ) else 0) ≤
      (∑ d ∈ P.divisors, if d ∣ n then lam d else 0) ^ 2

    TheoremSelberg's \(\Lambda^2\) upper bound sieve, finite form#✓fully proved

    MathlibExt.SelbergSieve.card_filter_coprime_le_sum_lambda_sq

    Let \(A\) be a finite set of natural numbers, \(P \ne 0\) and \(\lambda : \mathbb N \to \mathbb R\) with \(\lambda_1 = 1\). Then $\(\#\{n \in A : \gcd(P, n) = 1\} \le \sum_{d \mid P} \sum_{e \mid P} \lambda_d \lambda_e \, \#\{n \in A : \operatorname{lcm}(d, e) \mid n\}.\)$ The bound holds for every choice of the real numbers \(\lambda_d\); Selberg's method then chooses them, subject to \(\lambda_1 = 1\) and \(\lambda_d = 0\) for large \(d\), to minimise the main term. In Heath-Brown's notation this is the first two lines of (1.7) for the weights (2.1), with \(\#\mathcal A_d\) for the multiples of \(d\) in \(A\).

    theorem card_filter_coprime_le_sum_lambda_sq (A : Finset ℕ) (P : ℕ) (hP : P ≠ 0)
    (lam : ℕ → ℝ) (h1 : lam 1 = 1) :
    ((A.filter fun n => Nat.Coprime P n).card : ℝ) ≤
      ∑ d ∈ P.divisors, ∑ e ∈ P.divisors,
        lam d * lam e * ((A.filter fun n => Nat.lcm d e ∣ n).card : ℝ)

    MathlibExt.SelbergSieve.levelSum

    For a bounding sieve whose sifting primes have product \(P\), with multiplicative density function \(\nu\), and a natural number \(R\), the level-\(R\) Selberg sum is \(G = \sum_{l \mid P,\ l \le R} g(l)\), where \(g(l) = \nu(l) \prod_{p \mid l} (1 - \nu(p))^{-1}\), the product running over the primes \(p\) dividing \(l\).

    noncomputable def levelSum (s : BoundingSieve) (R : ℕ) : ℝ :=
  ∑ l ∈ levelSet s R, s.selbergTerms l

    DefinitionNormalized Selberg coefficients#✓fully proved

    MathlibExt.SelbergSieve.levelY

    Let \(s\) be a bounding sieve with density function \(\nu\) and Selberg terms \(g(l) = \nu(l) \prod_{p \mid l} (1 - \nu(p))^{-1}\), the product running over the primes \(p\) dividing \(l\), and let \(R\) be a natural number. Write \(D_R\) for the level set of \(s\) at level \(R\) (the divisors of the sifting product of \(s\) that are at most \(R\)) and \(G(R) = \sum_{l \in D_R} g(l)\) for the level sum. The normalized Selberg coefficient of \(s\) at level \(R\) is the function on natural numbers given by \(y_l = \mu(l)\, g(l) / G(R)\) for \(l \in D_R\) and \(y_l = 0\) otherwise, where \(\mu\) is the Möbius function.

    noncomputable def levelY
    (s : BoundingSieve) (R l : ℕ) : ℝ :=
  if l ∈ levelSet s R then
    ((ArithmeticFunction.moebius l : ℤ) : ℝ) * s.selbergTerms l /
      levelSum s R
  else 0
    def levelSet (s : BoundingSieve) (R : ℕ) : Finset ℕ :=
  s.prodPrimes.divisors.filter fun l ↦ l ≤ R

    DefinitionSelberg sieve weights#✓fully proved

    MathlibExt.SelbergSieve.levelWeights

    Let \(s\) be a bounding sieve with sifting product \(P\) (the product of its sifting primes) and density function \(\nu\), let \(R\) be a natural number, and let \(y_m\) denote the normalized Selberg coefficients of \(s\) at level \(R\). For a natural number \(d\), the level-\(R\) Selberg weight of \(s\) at \(d\) is

    \[\lambda_d = \nu(d)^{-1} \sum_{m \mid P,\ d \mid m} \mu(m/d)\, y_m,\]

    where \(\mu\) is the Möbius function, \(m\) runs over the divisors of \(P\), and \(\nu(d)^{-1}\) is read as \(0\) when \(\nu(d) = 0\).

    noncomputable def levelWeights
    (s : BoundingSieve) (R d : ℕ) : ℝ :=
  (s.nu d)⁻¹ * ∑ m ∈ s.prodPrimes.divisors,
    if d ∣ m then ((ArithmeticFunction.moebius (m / d) : ℤ) : ℝ) *
      levelY s R m else 0

    TheoremSelberg's upper bound with the optimal level weights#✓fully proved

    MathlibExt.SelbergSieve.siftedSum_le_totalMass_div_levelSum_add_errSum

    Take a bounding sieve: a finite weighted set to be sifted by the primes dividing a squarefree \(P\), with total weight approximated by \(X\), density function \(\nu\) and remainders \(r_d = A_d - \nu(d) X\). Let \(R \ge 1\) be a natural number, \(\lambda_d\) the level-\(R\) Selberg weights and \(\Lambda_d = \sum_{\operatorname{lcm}(d_1, d_2) = d} \lambda_{d_1} \lambda_{d_2}\). Then the sifted sum \(S\) satisfies $\(S \le \frac{X}{G(R)} + \sum_{d \mid P} |\Lambda_d|\, |r_d|,\)$ where \(G(R)\) is the level sum.

    This is Heath-Brown's inequality (2.5), \(S(\mathcal A, \mathcal P; z) \le X\, G(\xi, z)^{-1} + \sum_{d \mid \Pi(\mathcal P, z),\, d < y} |\mu^+(d)|\, |R_d|\), with the support condition \(\lambda_d = 0\) for \(d > R\) in place of (2.4)'s \(\lambda_d = 0\) for \(d \ge \xi\), and Mathlib's \(\nu(d)\) in place of \(\omega(d)/d\).

    theorem siftedSum_le_totalMass_div_levelSum_add_errSum (s : BoundingSieve) (R : ℕ)
    (hR : 1 ≤ R) :
    s.siftedSum ≤ s.totalMass / levelSum s R +
      s.errSum (BoundingSieve.lambdaSquared (levelWeights s R))
    noncomputable def levelSum (s : BoundingSieve) (R : ℕ) : ℝ :=
  ∑ l ∈ levelSet s R, s.selbergTerms l
