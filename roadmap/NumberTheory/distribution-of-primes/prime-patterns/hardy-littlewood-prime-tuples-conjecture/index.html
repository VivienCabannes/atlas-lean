    DefinitionEuler factors of the Hardy–Littlewood singular series#✓fully proved

    MetaMathlibExt.hardyLittlewoodEulerFactor

    For an \(m\)-tuple \(b\) of integers and a natural number \(p\), the Euler factor of \(b\) at \(p\) is the real number

    \[\left(\frac{p}{p-1}\right)^{m-1} \frac{p - v_p(b)}{p - 1},\]

    where \(v_p(b)\) is the number of residue classes modulo \(p\) that contain an entry of \(b\), the exponent \(m - 1\) is truncated at \(0\) (so it is \(0\) when \(m = 0\)), and division by \(0\) gives \(0\).

    noncomputable def hardyLittlewoodEulerFactor (m : ℕ) (b : Fin m → ℤ) (p : ℕ) : ℝ :=
  ((p : ℝ) / ((p : ℝ) - 1)) ^ (m - 1) *
    (((p : ℝ) - (hardyLittlewoodResidueCount m b p : ℝ)) / ((p : ℝ) - 1))
    def hardyLittlewoodResidueCount (m : ℕ) (b : Fin m → ℤ) (p : ℕ) : ℕ :=
  (Finset.univ.image (fun i => (b i) % (p : ℤ))).card

    DefinitionThe Hardy–Littlewood singular series#✓fully proved

    MetaMathlibExt.hardyLittlewoodSingularSeries

    For an \(m\)-tuple \(b\) of integers, the singular series \(\mathfrak{S}(b)\) is the product over all primes \(p\) of the Euler factors

    \[\left(\frac{p}{p-1}\right)^{m-1} \frac{p - v_p(b)}{p - 1},\]

    where \(v_p(b)\) is the number of residue classes modulo \(p\) that contain an entry of \(b\) and the exponent \(m - 1\) is truncated at \(0\). The product is the limit in \(\mathbb{R}\) of the products over finite sets \(S\) of primes, with the sets \(S\) directed by inclusion; this limit may be \(0\) (for instance when some Euler factor is \(0\)), and \(\mathfrak{S}(b)\) is \(1\) when the limit does not exist.

    noncomputable def hardyLittlewoodSingularSeries (m : ℕ) (b : Fin m → ℤ) : ℝ :=
  ∏' (p : ℕ), (if Nat.Prime p then hardyLittlewoodEulerFactor m b p else 1)
    noncomputable def hardyLittlewoodEulerFactor (m : ℕ) (b : Fin m → ℤ) (p : ℕ) : ℝ :=
  ((p : ℝ) / ((p : ℝ) - 1)) ^ (m - 1) *
    (((p : ℝ) - (hardyLittlewoodResidueCount m b p : ℝ)) / ((p : ℝ) - 1))

    DefinitionAdmissible finite sets of integers#✓fully proved

    MetaMathlibExt.IsAdmissibleFinset

    A finite set \(H\) of integers is admissible if for every prime \(p\) there is a residue class \(r\) modulo \(p\) that contains no element of \(H\).

    A tuple of integers is called Hardy–Littlewood admissible when, for every prime \(p\), its entries meet fewer than \(p\) residue classes modulo \(p\); this holds exactly when its set of entries is admissible.

    def IsAdmissibleFinset (H : Finset ℤ) : Prop :=
  ∀ p : ℕ, p.Prime → ∃ r : ZMod p, ∀ h ∈ H, (h : ZMod p) ≠ r

    MetaMathlibExt.hardyLittlewoodResidueCount_ne_iff

    Let \(b = (b_1, \dots, b_m)\) be an \(m\)-tuple of integers, let \(p\) be a prime, and let \(v_p(b)\) be the number of residue classes modulo \(p\) that contain an entry of \(b\).     MetaMathlibExt.hardyLittlewoodPrimeTupleConjecture

    Let \(m \ge 1\) and let \(b = (b_1, \dots, b_m)\) be an admissible \(m\)-tuple of pairwise distinct integers. Then the singular series \(\mathfrak{S}(b)\) is nonzero, and the prime-tuple count \(P(x; b)\), the number of integers \(n\) with \(1 \le n \le x\) such that \(n + b_1, \dots, n + b_m\) are all prime, satisfies

    \[P(x; b) \sim \mathfrak{S}(b) \int_2^x \frac{du}{(\log u)^m}\]

    as the natural number \(x\) tends to infinity.
