    DefinitionSubpower bound#✓fully proved

    WantedExt.NumberTheory.Polymath8b.SubpowerBound

    For functions \(f, g : \mathbb{R} \to \mathbb{R}\), \(f\) is bounded by \(g\) up to subpower losses if for every real \(\delta > 0\) we have \(f(x) = O(x^{\delta} g(x))\) as \(x \to \infty\).

    def SubpowerBound (f g : ℝ → ℝ) : Prop :=
  ∀ δ : ℝ, 0 < δ → Asymptotics.IsBigO atTop f (fun x ↦ x ^ δ * g x)

    DefinitionSupport in a dyadic interval#✓fully proved

    WantedExt.NumberTheory.Polymath8b.DyadicSupport

    A finitely supported sequence \(\alpha : \mathbb{N} \to \mathbb{R}\) is supported in the dyadic interval at scale \(N \in \mathbb{R}\) if every \(n\) with \(\alpha(n) \ne 0\) satisfies \(n \ge 1\) and \(N \le n \le 2N\).

    def DyadicSupport (α : ℕ →₀ ℝ) (N : ℝ) : Prop :=
  ∀ n ∈ α.support, 1 ≤ n ∧ N ≤ (n : ℝ) ∧ (n : ℝ) ≤ 2 * N

    DefinitionDivisor–logarithm bound for a family of sequences#✓fully proved

    WantedExt.NumberTheory.Polymath8b.DivisorLogBound

    A family \((\alpha_x)_{x \in \mathbb{R}}\) of finitely supported sequences \(\alpha_x : \mathbb{N} \to \mathbb{R}\) satisfies the divisor–logarithm bound if there are a real number \(C > 0\) and natural numbers \(k\) and \(l\) such that for all sufficiently large real \(x\) and all integers \(n \ge 1\),

    \[|\alpha_x(n)| \le C \, \tau(n)^k (\log x)^l,\]

    where \(\tau(n)\) is the number of positive divisors of \(n\). The constants \(C\), \(k\) and \(l\) depend neither on \(x\) nor on \(n\).

    def DivisorLogBound (α : ℝ → ℕ →₀ ℝ) : Prop :=
  ∃ C : ℝ, ∃ k l : ℕ, 0 < C ∧ ∀ᶠ x : ℝ in atTop,
    ∀ n : ℕ, 1 ≤ n → |α x n| ≤
      C * (n.divisors.card : ℝ) ^ k * Real.log x ^ l

    DefinitionSiegel–Walfisz hypothesis for a family of sequences#✓fully proved

    WantedExt.NumberTheory.Polymath8b.SiegelWalfisz

    Let \((\beta_x)_{x \in \mathbb{R}}\) be a family of finitely supported sequences \(\beta_x : \mathbb{N} \to \mathbb{R}\) and let \(M : \mathbb{R} \to \mathbb{R}\). The family satisfies the Siegel–Walfisz hypothesis at scale \(M\) if for every real \(A \ge 1\) there are a real number \(C > 0\) and a natural number \(k\) such that, for all sufficiently large real \(x\) and all natural numbers \(q \ge 1\), \(r \ge 1\) and \(a\) with \(\gcd(a, q) = 1\),

    \[|\Delta(\beta_x^{(r)}; a \bmod q)| \le C \, \tau(qr)^k \, M(x) / (\log x)^A.\]

    Here \(\beta_x^{(r)}\) is the sequence equal to \(\beta_x(n)\) when \(\gcd(n, r) = 1\) and to \(0\) otherwise, \(\Delta(\cdot\,; a \bmod q)\) is the discrepancy in the residue class of \(a\) modulo \(q\), and \(\tau(m)\) is the number of positive divisors of \(m\).

    def SiegelWalfisz (β : ℝ → ℕ →₀ ℝ) (M : ℝ → ℝ) : Prop :=
  ∀ A : ℝ, 1 ≤ A → ∃ C : ℝ, ∃ k : ℕ, 0 < C ∧
    ∀ᶠ x : ℝ in atTop, ∀ q r a : ℕ, (h1q : 1 ≤ q) → 1 ≤ r → Nat.Coprime a q →
      |discrepancy ((β x).filter (fun n ↦ Nat.Coprime n r)) ⟨q, h1q⟩ a| ≤
        C * ((q * r).divisors.card : ℝ) ^ k * M x / Real.log x ^ A
    noncomputable def discrepancy {𝕜 : Type*} [Field 𝕜] [CharZero 𝕜] (α : ℕ →₀ 𝕜)
    (q : ℕ+) (a : ℕ) : 𝕜 :=
  α.sum (fun n v ↦ if 0 < n ∧ n % q = a % q then v else 0) -
    α.sum (fun n v ↦ if 0 < n ∧ Nat.Coprime n q then v else 0) / (Nat.totient (q : ℕ) : 𝕜)

    DefinitionElliott–Halberstam estimate at level \(\theta\)#✓fully proved

    WantedExt.NumberTheory.Polymath8b.ElliottHalberstamAt

    For a real number \(\theta\), the Elliott–Halberstam estimate at level \(\theta\) is the following statement. Let \(Q : \mathbb{R} \to \mathbb{N}\) be such that \(Q(x) = O(x^{\delta} x^{\theta})\) as \(x \to \infty\) for every real \(\delta > 0\), and let \(A \ge 1\) be real. Then there is a real number \(C > 0\) such that for all sufficiently large real \(x\), the averaged discrepancy of \(\Lambda_x\) up to \(Q(x)\) is at most \(C x / (\log x)^A\). Here \(\Lambda_x\) is the sequence equal to the von Mangoldt function \(\Lambda(n)\) for integers \(n \ge 1\) with \(x \le n \le 2x\) and to \(0\) otherwise, and the averaged discrepancy of a sequence \(\alpha\) up to \(Q\) is \(\sum_{q=1}^{Q} \Delta^*(\alpha; q)\), where \(\Delta^*(\alpha; q)\) is the largest absolute value of the discrepancy of \(\alpha\) in a residue class modulo \(q\) coprime to \(q\).

    def ElliottHalberstamAt (θ : ℝ) : Prop :=
  ∀ Q : ℝ → ℕ, SubpowerBound (fun x ↦ (Q x : ℝ)) (fun x ↦ x ^ θ) →
    ∀ A : ℝ, 1 ≤ A → ∃ C : ℝ, 0 < C ∧ ∀ᶠ x : ℝ in atTop,
      averagedDiscrepancy (dyadicVonMangoldt x) (Q x) ≤ C * x / Real.log x ^ A
    def SubpowerBound (f g : ℝ → ℝ) : Prop :=
  ∀ δ : ℝ, 0 < δ → Asymptotics.IsBigO atTop f (fun x ↦ x ^ δ * g x)

    DefinitionGeneralized Elliott–Halberstam estimate at level \(\theta\)#✓fully proved

    WantedExt.NumberTheory.Polymath8b.GeneralizedElliottHalberstamAt

    For a real number \(\theta\), the generalized Elliott–Halberstam estimate at level \(\theta\) is the following statement. Let \(\varepsilon > 0\) be real, let \(N, M : \mathbb{R} \to \mathbb{R}\), and let \((\alpha_x)_{x \in \mathbb{R}}\) and \((\beta_x)_{x \in \mathbb{R}}\) be families of finitely supported sequences \(\mathbb{N} \to \mathbb{R}\). Assume that for all sufficiently large real \(x\) we have \(N(x) > 0\) and \(M(x) > 0\), \(\alpha_x\) is supported in the dyadic interval at scale \(N(x)\) and \(\beta_x\) is supported in the dyadic interval at scale \(M(x)\); that for every real \(\delta > 0\), as \(x \to \infty\), \(x^{\varepsilon} = O(x^{\delta} N(x))\), \(N(x) = O(x^{\delta} x^{1 - \varepsilon})\), \(x^{\varepsilon} = O(x^{\delta} M(x))\) and \(M(x) = O(x^{\delta} x^{1 - \varepsilon})\); that \(N(x) M(x) = O(x)\) and \(x = O(N(x) M(x))\) as \(x \to \infty\); that both families satisfy the divisor–logarithm bound; and that \((\beta_x)\) satisfies the Siegel–Walfisz hypothesis at scale \(M\). Let \(Q : \mathbb{R} \to \mathbb{N}\) be such that \(Q(x) = O(x^{\delta} x^{\theta})\) as \(x \to \infty\) for every real \(\delta > 0\), and let \(A \ge 1\) be real. Then there is a real number \(C > 0\) such that for all sufficiently large real \(x\), the averaged discrepancy of the multiplicative convolution \(\alpha_x \star \beta_x\) up to \(Q(x)\) is at most \(C x / (\log x)^A\).

    def GeneralizedElliottHalberstamAt (θ : ℝ) : Prop :=
  ∀ ε : ℝ, 0 < ε → ∀ N M : ℝ → ℝ, ∀ α β : ℝ → ℕ →₀ ℝ,
    (∀ᶠ x : ℝ in atTop, 0 < N x ∧ 0 < M x ∧
      DyadicSupport (α x) (N x) ∧ DyadicSupport (β x) (M x)) →
    SubpowerBound (fun x ↦ x ^ ε) N →
    SubpowerBound N (fun x ↦ x ^ (1 - ε)) →
    SubpowerBound (fun x ↦ x ^ ε) M →
    SubpowerBound M (fun x ↦ x ^ (1 - ε)) →
    Asymptotics.IsTheta atTop (fun x ↦ N x * M x) (fun x ↦ x) →
    DivisorLogBound α → DivisorLogBound β → SiegelWalfisz β M →
    ∀ Q : ℝ → ℕ, SubpowerBound (fun x ↦ (Q x : ℝ)) (fun x ↦ x ^ θ) →
      ∀ A : ℝ, 1 ≤ A → ∃ C : ℝ, 0 < C ∧ ∀ᶠ x : ℝ in atTop,
        averagedDiscrepancy (convolution (α x) (β x)) (Q x) ≤ C * x / Real.log x ^ A
    def DyadicSupport (α : ℕ →₀ ℝ) (N : ℝ) : Prop :=
  ∀ n ∈ α.support, 1 ≤ n ∧ N ≤ (n : ℝ) ∧ (n : ℝ) ≤ 2 * N
