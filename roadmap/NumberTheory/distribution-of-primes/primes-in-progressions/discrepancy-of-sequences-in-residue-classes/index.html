    Discrepancy of sequences in residue classes

    DefinitionDiscrepancy in a residue class#✓fully proved

    MathlibExt.NumberTheory.PrimeDistribution.discrepancy

    Let \(K\) be a field of characteristic zero, let \(\alpha : \mathbb{N} \to K\) be finitely supported, let \(q\) be a positive integer and let \(a\) be a natural number. The discrepancy of \(\alpha\) in the residue class of \(a\) modulo \(q\) is

    \[\Delta(\alpha; a \bmod q) = \sum_{\substack{n \ge 1 \\ n \equiv a \pmod{q}}} \alpha(n) - \frac{1}{\varphi(q)} \sum_{\substack{n \ge 1 \\ \gcd(n, q) = 1}} \alpha(n),\]

    where \(\varphi\) is Euler's totient function. The value \(\alpha(0)\) does not contribute.

    noncomputable def discrepancy {𝕜 : Type*} [Field 𝕜] [CharZero 𝕜] (α : ℕ →₀ 𝕜)
    (q : ℕ+) (a : ℕ) : 𝕜 :=
  α.sum (fun n v ↦ if 0 < n ∧ n % q = a % q then v else 0) -
    α.sum (fun n v ↦ if 0 < n ∧ Nat.Coprime n q then v else 0) / (Nat.totient (q : ℕ) : 𝕜)

    MathlibExt.NumberTheory.PrimeDistribution.discrepancy_single

    Let \(K\) be a field of characteristic zero, let \(n\) be a positive integer, let \(v \in K\), let \(q\) be a positive integer and let \(a \in \mathbb{N}\). Let \(e\) be the sequence with value \(v\) at index \(n\) and \(0\) at every other index. Then the discrepancy of \(e\) at modulus \(q\) and residue \(a\) equals \(A - B/\varphi(q)\), where \(A = v\) if \(n \equiv a \pmod{q}\) and \(A = 0\) otherwise, \(B = v\) if \(\gcd(n, q) = 1\) and \(B = 0\) otherwise, and \(\varphi\) is Euler's totient function.

    theorem discrepancy_single {𝕜 : Type*} [Field 𝕜] [CharZero 𝕜] (n : ℕ) (hn : 0 < n)
    (v : 𝕜) (q : ℕ+) (a : ℕ) :
    discrepancy (Finsupp.single n v) q a =
      (if n % q = a % q then v else 0) -
        (if Nat.Coprime n q then v else 0) / (Nat.totient (q : ℕ) : 𝕜)

    MathlibExt.NumberTheory.PrimeDistribution.primitiveDiscrepancy

    For a finitely supported sequence \(\alpha : \mathbb{N} \to \mathbb{R}\) and a positive integer \(q\), the primitive discrepancy of \(\alpha\) modulo \(q\) is the maximum, over the residue classes \(a\) modulo \(q\) that are coprime to \(q\), of \(|\Delta(\alpha; a \bmod q)|\), where \(\Delta(\alpha; a \bmod q)\) is the discrepancy of \(\alpha\) in the residue class of \(a\) modulo \(q\).

    noncomputable def primitiveDiscrepancy (α : ℕ →₀ ℝ) (q : ℕ+) : ℝ :=
  ⨆ a : (ZMod (q : ℕ))ˣ, |discrepancy α q a.val.val|

    MathlibExt.NumberTheory.PrimeDistribution.averagedDiscrepancy

    For a finitely supported real sequence \(\alpha\) indexed by \(\mathbb{N}\) and a natural number \(Q\), the averaged discrepancy of \(\alpha\) up to \(Q\) is the sum \(\sum_{q=1}^{Q} \Delta^*(\alpha; q)\), where \(\Delta^*(\alpha; q)\) is the primitive discrepancy of \(\alpha\) at modulus \(q\).

    The sum is not divided by \(Q\).

    noncomputable def averagedDiscrepancy (α : ℕ →₀ ℝ) (Q : ℕ) : ℝ :=

    Let \(R\) be a semiring and let \(\alpha, \beta \colon \mathbb{N} \to R\) be finitely supported. Their convolution \(\alpha \star \beta\) is the finitely supported sequence whose value at \(n\) is \(\sum_{a, b \ge 1,\ ab = n} \alpha(a)\beta(b)\); the values of \(\alpha\) and \(\beta\) at index \(0\) are discarded.

    TheoremCoefficients of the multiplicative convolution#✓fully proved

    MathlibExt.NumberTheory.PrimeDistribution.convolution_apply

    Let \(R\) be a semiring and let \(\alpha, \beta \colon \mathbb{N} \to R\) be finitely supported, with convolution \(\alpha \star \beta\). For every \(n \in \mathbb{N}\),

    \[(\alpha \star \beta)(n) = \sum_{a} \sum_{b} [ab = n]\, \alpha(a)\beta(b),\]

    where \(a\) ranges over the positive indices with \(\alpha(a) \ne 0\), \(b\) ranges over the positive indices with \(\beta(b) \ne 0\), and \([ab = n]\) is \(1\) if \(ab = n\) and \(0\) otherwise.

    theorem convolution_apply {R : Type*} [Semiring R] (α β : ℕ →₀ R) (n : ℕ) :
    convolution α β n =
      (α.filter (fun a ↦ 0 < a)).sum (fun a u ↦
        (β.filter (fun b ↦ 0 < b)).sum (fun b v ↦ if a * b = n then u * v else 0))
    noncomputable def convolution {R : Type*} [Semiring R] (α β : ℕ →₀ R) : ℕ →₀ R :=
