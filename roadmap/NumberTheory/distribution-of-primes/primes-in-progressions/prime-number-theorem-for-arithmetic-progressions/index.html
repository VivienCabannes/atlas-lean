    Nat.primeCountingMod

    For natural numbers \(X\), \(q\) and \(a\), \(\pi(X; q, a)\) is the number of primes \(p \le X\) with \(p \equiv a \pmod q\). The modulus \(q = 1\) is allowed, and for \(q = 0\) the congruence means \(p = a\).

    def primeCountingMod (X q a : ℕ) : ℕ :=
  ((X.primesLE.filter fun p => p ≡ a [MOD q]).card)

    TheoremPrime counting modulo one#✓fully proved

    Nat.primeCountingMod_one

    For all natural numbers \(X\) and \(a\), the number \(\pi(X; 1, a)\) of primes \(p \le X\) with \(p \equiv a \pmod 1\) equals \(\pi(X)\), the number of primes \(p \le X\).

    Modulus one imposes no residue condition.

    theorem primeCountingMod_one (X a : ℕ) :
    primeCountingMod X 1 a = Nat.primeCounting X

    TheoremResidue-class prime count as a filtered range#✓fully proved

    Nat.primeCountingMod_eq_card_filter_range

    For all natural numbers \(n\), \(q\) and \(a\), the number \(\pi(n; q, a)\) of primes \(p \le n\) with \(p \equiv a \pmod q\) equals the number of integers \(p\) with \(0 \le p \le n\) such that \(p\) is prime and \(p \equiv a \pmod q\).

    theorem primeCountingMod_eq_card_filter_range (n q a : ℕ) :
    Nat.primeCountingMod n q a
      = ((Finset.range (n + 1)).filter
        fun p => Nat.Prime p ∧ Nat.ModEq q p a).card

    TheoremWeak prime number theorem in arithmetic progressions#✓fully proved

    Chebyshev.weakPNT_arithmeticProgression

    Let \(q\) and \(a\) be natural numbers with \(a < q\) and \(\gcd(a, q) = 1\), let \(\Lambda\) be the von Mangoldt function and let \(\varphi\) be Euler's totient function. Then, as \(N \to \infty\) through the natural numbers,

    \[ \frac{1}{N} \sum_{\substack{0 \le n < N \\ n \equiv a \pmod{q}}} \Lambda(n) \to \frac{1}{\varphi(q)}. \]
    public theorem weakPNT_arithmeticProgression {q a : ℕ}
    (ha : Nat.Coprime a q) (ha_lt : a < q) :
    Filter.Tendsto
      (fun N : ℕ =>
        (∑ n ∈ Finset.range N,
            if n % q = a then ArithmeticFunction.vonMangoldt n else 0) / (N : ℝ))
      Filter.atTop (nhds (1 / (Nat.totient q : ℝ)))

    TheoremPrime number theorem in arithmetic progressions#✓fully proved

    MathlibExt.NumberTheory.PrimeNumberTheoremAPWanted.prime_number_theorem_arithmetic_progression

    Let \(q \ge 2\) and \(a\) be natural numbers with \(\gcd(a, q) = 1\), and for each natural number \(n\) let \(N(n)\) be the number of primes \(p \le n\) with \(p \equiv a \pmod q\). Then \(N(n) \log n / n \to 1 / \varphi(q)\) as \(n \to \infty\), where \(\varphi\) is Euler's totient function and \(\log\) is the natural logarithm.

    public theorem prime_number_theorem_arithmetic_progression :
    ∀ (q a : ℕ), 2 ≤ q → Nat.Coprime a q →
      Filter.Tendsto
        (fun n : ℕ =>
          (((Finset.range (n + 1)).filter fun p => Nat.Prime p ∧ Nat.ModEq q p a).card : ℝ) *
            Real.log (n : ℝ) / (n : ℝ))
        Filter.atTop (nhds (1 / (Nat.totient q : ℝ)))
