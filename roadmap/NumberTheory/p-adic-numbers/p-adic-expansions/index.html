    PadicInt.padicDigit

    Let \(p\) be a prime and \(a \in \mathbb{Z}_p\), and for each \(n \ge 0\) let \(a_n\) be the unique natural number with \(a_n < p^n\) and \(a \equiv a_n \pmod{p^n \mathbb{Z}_p}\). The \(n\)-th \(p\)-adic digit of \(a\) is the natural number \((a_{n+1} - a_n)/p^n\).

    Since \(a_n \le a_{n+1}\) and \(p^n\) divides \(a_{n+1} - a_n\), this quotient is exact.

    noncomputable def padicDigit (a : ℤ_[p]) (n : Nat) : Nat :=
  (a.appr (n + 1) - a.appr n) / p ^ n

    PadicInt.exists_padicDigit_eq

    Let \(p\) be a prime. For every sequence \((b_n)_{n \ge 0}\) of natural numbers with \(b_n < p\) for all \(n\), there is a \(p\)-adic integer \(a \in \mathbb{Z}_p\) whose \(n\)-th \(p\)-adic digit is \(b_n\) for every \(n \ge 0\).

    The witness is the \(p\)-adic limit of the partial sums \(\sum_{k=0}^{n-1} b_k p^k\), which are its approximations modulo \(p^n\).

    theorem exists_padicDigit_eq (b : ℕ → ℕ) (hb : ∀ n, b n < p) :
    ∃ a : ℤ_[p], ∀ n, padicDigit a n = b n
    noncomputable def padicDigit (a : ℤ_[p]) (n : Nat) : Nat :=
  (a.appr (n + 1) - a.appr n) / p ^ n
