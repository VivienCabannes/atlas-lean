    TheoremPartial-fraction bound for the cosecant#●ready to prove

    MetaMathlibExt.one_div_sin_pi_lt

    For every real number \(x\) with \(0 < x < 1\),

    \[\frac{1}{\sin(\pi x)} < \frac{1}{\pi}\left(\frac{1}{x} + \frac{2x}{1 - x^2}\right).\]

    That is, the first two terms of the partial-fraction expansion of \(\pi / \sin(\pi x)\) bound it from above.

    public theorem_wanted one_div_sin_pi_lt (x : ℝ) (hx₀ : 0 < x) (hx₁ : x < 1) :
    1 / Real.sin (Real.pi * x) < (1 / Real.pi) * (1 / x + 2 * x / (1 - x ^ 2))

    TheoremBound for a weighted sum of absolute sines#●ready to prove

    MetaMathlibExt.sum_abs_sin_mul_div_lt

    Let \(K\) be a positive integer, let \(\xi\) be a real number, and let \(\gamma\) be the Euler–Mascheroni constant. Then

    \[ \sum_{y=1}^{K} \frac{|\sin(y\xi)|}{y} < \frac{2}{\pi}\left(\log(K + 1) + \gamma + \log 2\right) + \frac{3}{\pi(K + 1)} \]

    and

    \[ \sum_{y=1}^{K} \frac{|\sin(y\xi)|}{y} < \frac{2}{\pi}\log K + \frac{2}{\pi}(\gamma + \log 2) + \frac{5}{\pi K}. \]

    The second bound is the form (3.1) of the first, obtained from \(\log(K + 1) < \log K + 1/K\).

    public theorem_wanted sum_abs_sin_mul_div_lt (K : ℕ) (hK : 1 ≤ K) (ξ : ℝ) :
    ∑ y ∈ Icc 1 K, |Real.sin (y * ξ)| / y <
        (2 / Real.pi) * (Real.log (K + 1) + Real.eulerMascheroniConstant + Real.log 2) +
          3 / (Real.pi * (K + 1)) ∧
      ∑ y ∈ Icc 1 K, |Real.sin (y * ξ)| / y <
        (2 / Real.pi) * Real.log K +
          (2 / Real.pi) * (Real.eulerMascheroniConstant + Real.log 2) + 5 / (Real.pi * K)

    TheoremTrigonometric polynomials bounding the indicator of an arc#●ready to prove

    MetaMathlibExt.exists_trigPoly_minorant_majorant

    Let \(a \le b\) be real numbers with \(b - a < 1\) and let \(K \ge 1\) be an integer. Let \(\chi(x) = 1\) if \(a \le x - n \le b\) for some integer \(n\), and \(\chi(x) = 0\) otherwise. Then there are complex numbers \(\alpha_-(k)\) and \(\alpha_+(k)\), for \(k \in \mathbb{Z}\), with \(\alpha_\pm(0) = b - a \pm \frac{1}{K+1}\), such that for every real \(x\) the trigonometric polynomials \(S_\pm(x) = \sum_{k=-K}^{K} \alpha_\pm(k) e^{2\pi i k x}\) are real and satisfy \(S_-(x) \le \chi(x) \le S_+(x)\).

    Only the constant coefficients and the pointwise bounds are stated; no bounds on the coefficients \(\alpha_\pm(k)\) with \(k \ne 0\) are asserted.

    public theorem_wanted exists_trigPoly_minorant_majorant (a b : ℝ) (hab : a ≤ b)
    (hlen : b - a < 1) (K : ℕ) (hK : 1 ≤ K) :
    ∃ αm αp : ℤ → ℂ,
      αm 0 = ((b - a - 1 / (K + 1) : ℝ) : ℂ) ∧ αp 0 = ((b - a + 1 / (K + 1) : ℝ) : ℂ) ∧
      ∀ x : ℝ,
        let Sm := ∑ k ∈ Icc (-(K : ℤ)) K, αm k * exp (2 * Real.pi * I * k * x)
        let Sp := ∑ k ∈ Icc (-(K : ℤ)) K, αp k * exp (2 * Real.pi * I * k * x)
        let ind : ℝ := Set.indicator {y : ℝ | ∃ n : ℤ, a ≤ y - n ∧ y - n ≤ b} 1 x
        Sm.im = 0 ∧ Sp.im = 0 ∧ Sm.re ≤ ind ∧ ind ≤ Sp.re
