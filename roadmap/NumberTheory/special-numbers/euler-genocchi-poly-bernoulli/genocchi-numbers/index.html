    DefinitionGenerating function of the Genocchi numbers#✓fully proved

    MetaMathlibExt.genocchiPowerSeries

    The Genocchi power series is the formal power series \(\frac{2x}{e^x + 1} = 2x \cdot (e^x + 1)^{-1}\) in \(\mathbb{Q}[[x]]\), where \(e^x = \sum_{n \ge 0} x^n / n!\) is the exponential power series and \((e^x + 1)^{-1}\) is the inverse of \(e^x + 1\) among formal power series. It is the exponential generating function of the Genocchi numbers \(G_n\), that is, \(\frac{2x}{e^x + 1} = \sum_{n \ge 0} G_n \frac{x^n}{n!}\).

    This retains the standard convention \(\frac{2x}{e^x + 1}\) stated by Chen and used independently by Kida; the sign-changed variant consumes only even-index terms, where the conventions agree.

    public noncomputable def genocchiPowerSeries : PowerSeries ℚ :=
  2 * PowerSeries.X * (PowerSeries.exp ℚ + 1)⁻¹

    MetaMathlibExt.genocchiNumber_eq_bernoulli

    For every natural number \(n\), the Genocchi number \(G_n\), defined by \(\frac{2x}{e^x + 1} = \sum_{m \ge 0} G_m \frac{x^m}{m!}\), satisfies \(G_n = 2(1 - 2^n) B_n\), where \(B_n\) is the \(n\)-th Bernoulli number with the convention \(B_1 = -\tfrac{1}{2}\).

    theorem genocchiNumber_eq_bernoulli (n : ℕ) :
    genocchiNumber n = 2 * (1 - (2 : ℚ) ^ n) * bernoulli n

    DefinitionThe Zerroukhat–Khaldi sum \(U(m, k)\)#✓fully proved

    MathlibExt.NumberTheory.GenocchiExplicitWanted.zerroU

    For natural numbers \(m\) and \(k\), define the rational number

    \[U(m, k) = \sum_{j=0}^{m} (-1)^{k+j+m} \frac{(k+j-1)!}{2^{k+j-1}} S(m, j),\]

    where \(S(m, j)\) is the Stirling number of the second kind and, in the term with \(k = j = 0\), \(k + j - 1\) is read as \(0\), so that this term is \((-1)^m S(m, 0)\).

    def zerroU (m k : ℕ) : ℚ :=
  ∑ j ∈ Finset.range (m + 1),
    (-1 : ℚ) ^ (k + j + m) * ((k + j - 1).factorial : ℚ) /
      2 ^ (k + j - 1) * (Nat.stirlingSecond m j : ℚ)
