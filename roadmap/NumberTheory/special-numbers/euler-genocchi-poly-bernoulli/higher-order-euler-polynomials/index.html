    DefinitionEuler polynomials#✓fully proved

    MathlibExt.NumberTheory.EulerPolynomialFormulasWanted.eulerPoly

    Let \(B_m(x)\) denote the \(m\)-th Bernoulli polynomial. For \(n \ge 0\), the Euler polynomial \(E_n(x)\) is the polynomial with rational coefficients \(E_n(x) = \frac{2}{n + 1} \left(B_{n+1}(x) - 2^{n+1} B_{n+1}(x/2)\right)\).

    noncomputable def eulerPoly (n : ℕ) : ℚ[X] :=
  (2 / (n + 1 : ℚ)) • (Polynomial.bernoulli (n + 1) -
    (2 : ℚ) ^ (n + 1) •
      (Polynomial.bernoulli (n + 1)).comp (C (1 / 2) * X))

    DefinitionGeneralized Stirling polynomial#✓fully proved

    MathlibExt.NumberTheory.EulerPolynomialFormulasWanted.genStirlingPoly

    For natural numbers \(n\) and \(k\), the generalized Stirling polynomial \(S(n, k, x)\) is the polynomial in \(x\) with rational coefficients

    \[S(n, k, x) = \frac{1}{k!} \sum_{j=0}^{k} \binom{k}{j} (-1)^{k-j} (x + j)^n.\]
    noncomputable def genStirlingPoly (n k : ℕ) : ℚ[X] :=
  (1 / (Nat.factorial k : ℚ)) •
    ∑ j ∈ Finset.range (k + 1),
      ((Nat.choose k j : ℚ) * (-1) ^ (k - j)) •
        (X + C (j : ℚ)) ^ n

    DefinitionFuel-bounded recurrence for the Euler numbers of order α#✓fully proved

    MathlibExt.NumberTheory.EulerPolynomialFormulasWanted.eulerNumGenAux

    Let \(E_m(x)\) denote the Euler polynomial. For a complex number \(\alpha\), the complex numbers \(a_\alpha(f, n)\), for natural numbers \(f\) (the fuel) and \(n\), are defined by \(a_\alpha(0, n) = 1\), \(a_\alpha(f + 1, 0) = 1\) and \(a_\alpha(f + 1, n + 1) = -\alpha \, a_\alpha(f, n) + \frac{\alpha}{2} \sum_{k=0}^{n} \binom{n}{k} a_\alpha(f, k) \, E_{n-k}(0)\).

    Whenever \(n \le f\), \(a_\alpha(f, n)\) equals the Euler number of order \(\alpha\), \(E_n^{(\alpha)}(0)\).

    noncomputable def eulerNumGenAux (α : ℂ) : ℕ → ℕ → ℂ
  | 0, _ => 1
  | _ + 1, 0 => 1
  | fuel + 1, n + 1 =>
      -α * eulerNumGenAux α fuel n + (α / 2) *
        ∑ k ∈ Finset.range (n + 1),
          (Nat.choose n k : ℂ) * eulerNumGenAux α fuel k *
            (((eulerPoly (n - k)).eval (0 : ℚ) : ℚ) : ℂ)
