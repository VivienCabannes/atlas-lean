    Let \(G(t)\) be the inverse, in the ring \(\mathbb{Q}[[t]]\) of formal power series, of the series \(\sum_{n \ge 0} \frac{(-1)^n}{n + 1} t^n\), which is invertible because its constant coefficient is \(1\).

    DefinitionBernoulli numbers of the second kind#✓fully proved

    MetaMathlibExt.bernoulliSecond

    For a natural number \(n\), the Bernoulli number of the second kind \(B_n^*\) is the rational number \(n!\) times the coefficient of \(t^n\) in \(G(t) \in \mathbb{Q}[[t]]\), the inverse of the formal power series \(\sum_{k \ge 0} \frac{(-1)^k}{k + 1} t^k\). Thus \(G(t) = \sum_{n \ge 0} B_n^* t^n / n!\).

    Analytically \(G(t) = t / \log(1 + t)\); this is Roman's normalization, with \(B_0^* = 1\), \(B_1^* = 1/2\) and \(B_2^* = -1/6\).

    public noncomputable def bernoulliSecond (n : ℕ) : ℚ :=
  (n.factorial : ℚ) * (PowerSeries.coeff n) bernoulliSecondPowerSeries
    public noncomputable def bernoulliSecondPowerSeries : PowerSeries ℚ :=
  (PowerSeries.mk fun n => (-1 : ℚ) ^ n / (n + 1))⁻¹
