    2-adic valuations of harmonic number differences

    DefinitionWeighted binary digit sum#✓fully proved

    MetaMathlibExt.weightedBinaryDigitSum

    For a natural number \(n\), the weighted binary digit sum of \(n\) is \(a(n) = \sum_i i \cdot 2^i\), where \(i\) runs over the indices of the \(1\) bits in the binary expansion of \(n\). Equivalently, if \(n = 2^{a_1} + \dots + 2^{a_t}\) with distinct exponents \(a_1, \dots, a_t\), then \(a(n) = a_1 2^{a_1} + \dots + a_t 2^{a_t}\); in particular \(a(0) = 0\).

    public def weightedBinaryDigitSum (n : ℕ) : ℕ :=
  ∑ i ∈ Finset.range (Nat.log 2 n + 1), if Nat.testBit n i then i * 2 ^ i else 0

    MetaMathlibExt.padicValRat_two_harmonic_sub_neg

    Let \(H_k = \sum_{j=1}^{k} 1/j\) be the \(k\)-th harmonic number (so \(H_0 = 0\)) and let \(\nu_2\) denote the \(2\)-adic valuation on the rational numbers. For all natural numbers \(m\) and \(n\) with \(m + 2 \le n\), the \(2\)-adic valuation \(\nu_2(H_n - H_m)\) is negative; that is, \(H_n - H_m\) is not a \(2\)-adic integer.

    In particular \(H_n - H_m\) is not an integer.

    public theorem_wanted padicValRat_two_harmonic_sub_neg (m n : ℕ)
    (h : m + 2 ≤ n) :
    padicValRat 2 (harmonic n - harmonic m) < 0

    Let \(H_k = \sum_{j=1}^{k} 1/j\) be the \(k\)-th harmonic number (so \(H_0 = 0\)) and let \(\nu_2\) denote the \(2\)-adic valuation on the rational numbers. Let \(n\) and \(a\) be natural numbers such that the binary digit of \(n\) in position \(a\) is \(1\), that is, \(2^a\) occurs in the binary expansion of \(n\). Then exactly \(2^a\) of the natural numbers \(m < n\) satisfy \(\nu_2(H_n - H_m) = -a\).

    The source theorem also locates these values of \(m\) in intervals determined by the partial sums of the binary expansion of \(n\); that refinement is not part of this statement.

    public theorem_wanted card_filter_padicValRat_two_harmonic_sub (n a : ℕ)
    (ha : Nat.testBit n a = true) :
    ((Finset.range n).filter
      (fun m => padicValRat 2 (harmonic n - harmonic m) = -(a : ℤ))).card
      = 2 ^ a

    TheoremPiecewise formula for the 2-adic valuation of \(H_n - H_{n-m}\)#●ready to prove

    MetaMathlibExt.padicValRat_two_harmonic_sub_piecewise

    Let \(H_k = \sum_{j=1}^{k} 1/j\) be the \(k\)-th harmonic number and let \(\nu_2\) denote the \(2\)-adic valuation on the rational numbers (for a positive integer it is the exponent of \(2\) in its factorization). Let \(m\) and \(n\) be natural numbers with \(1 \le m \le n\), and put \(M = \lceil \log_2(m + 1) \rceil\) and \(j = \lfloor (n - m) / 2^M \rfloor\). If \(2^M j + m \le n \le 2^M (j + 1) - 1\), then \(\nu_2(H_n - H_{n-m}) = 1 - M\). If \(2^M (j + 1) \le n \le 2^M (j + 1) + m - 1\), then \(\nu_2(H_n - H_{n-m}) = -M - \nu_2(j + 1)\).

    public theorem_wanted padicValRat_two_harmonic_sub_piecewise (m n : ℕ)
    (hm : 1 ≤ m) (hmn : m ≤ n) :
    (2 ^ (Nat.clog 2 (m + 1)) * ((n - m) / 2 ^ (Nat.clog 2 (m + 1))) + m ≤ n ∧
        n + 1 ≤ 2 ^ (Nat.clog 2 (m + 1)) * ((n - m) / 2 ^ (Nat.clog 2 (m + 1)) + 1) →
      padicValRat 2 (harmonic n - harmonic (n - m))
        = -(Nat.clog 2 (m + 1) : ℤ) + 1) ∧
    (2 ^ (Nat.clog 2 (m + 1)) * ((n - m) / 2 ^ (Nat.clog 2 (m + 1)) + 1) ≤ n ∧
        n + 1 ≤ 2 ^ (Nat.clog 2 (m + 1)) * ((n - m) / 2 ^ (Nat.clog 2 (m + 1)) + 1) + m →
      padicValRat 2 (harmonic n - harmonic (n - m))
        = -(Nat.clog 2 (m + 1) : ℤ)
          - (((n - m) / 2 ^ (Nat.clog 2 (m + 1)) + 1).factorization 2 : ℤ))
