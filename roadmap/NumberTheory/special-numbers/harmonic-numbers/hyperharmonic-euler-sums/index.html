    DefinitionGeneralized hyperharmonic numbers#✓fully proved

    MetaMathlibExt.generalizedHyperharmonic

    For natural numbers \(n\) and \(k\) and a complex number \(r\), the generalized hyperharmonic number \(H_n^{[r]}(k)\) is \(0\) when \(k > n\); when \(k \le n\) it is the elementary symmetric polynomial of degree \(n - k\) in \(r, r + 1, \ldots, r + n - 1\) divided by \(n!\), that is,

    \[H_n^{[r]}(k) = \frac{1}{n!} \sum_{0 \le j_1 < \cdots < j_{n-k} < n} \prod_{i=1}^{n-k} (r + j_i).\]

    The source defines \(H_n^{[r]}(k)\) in (2.4) by \((-1)^k k! \, H_n^{[r]}(k) = D_x^k \binom{n+r-x-1}{n}\) at \(x = 0\), where \(D_x^k\) is the \(k\)-th derivative in \(x\); the explicit form above follows from it. For \(r = 1\) it is the depth-\(k\) multiple harmonic number, and for \(r \notin \{0, -1, \ldots, 1 - n\}\) it equals \(\binom{n+r-1}{n} \sum_{1 \le i_1 < \cdots < i_k \le n} \prod_{j=1}^{k} 1/(i_j + r - 1)\), see (2.10).

    noncomputable def generalizedHyperharmonic (n k : ℕ) (r : ℂ) : ℂ :=
  if k ≤ n then
    (∑ s ∈ (Finset.range n).powersetCard (n - k), ∏ j ∈ s, (r + j)) / n.factorial
  else 0

    MetaMathlibExt.oddMultipleHarmonic

    For natural numbers \(k\) and \(n\), the depth-\(k\) odd harmonic number is the real number

    \[O_n(k) = \sum_{1 \le i_1 < \cdots < i_k \le n} \prod_{j=1}^{k} \frac{1}{i_j - 1/2}.\]

    In particular \(O_n(0) = 1\) (the empty product) and \(O_n(k) = 0\) for \(k > n\) (the empty sum).
