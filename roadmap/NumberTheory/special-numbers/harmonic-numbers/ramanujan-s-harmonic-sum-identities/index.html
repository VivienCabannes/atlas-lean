    MathlibExt.NumberTheory.Ramanujan.Part1Ch2.Entry1.ramanujan_part1_ch2_entry1_general

    For every natural number \(n\),

    \[\sum_{k=1}^{n} \frac{1}{n+k} = \frac{n}{2n+1} + \sum_{k=1}^{n} \frac{1}{(2k)^3 - 2k}.\]

    This is Ramanujan's Entry 1 of Chapter 2 without the hypothesis \(n \ge 1\); at \(n = 0\) both sides are \(0\).

    theorem ramanujan_part1_ch2_entry1_general (n : ℕ) :
    ∑ k ∈ Finset.Icc 1 n, (1 : ℝ) / ((n : ℝ) + (k : ℝ)) =
      (n : ℝ) / (2 * (n : ℝ) + 1) + ∑ k ∈ Finset.Icc 1 n, (1 : ℝ) /
          ((2 * (k : ℝ)) ^ 3 - 2 * (k : ℝ))

    MathlibExt.NumberTheory.Ramanujan.Part1Ch2.Entry6.ramanujan_part1_ch2_entry6_general

    For all natural numbers \(n\) and \(r\), the following identity holds in \(\mathbb{Q}\):

    \[ \sum_{j=n+1}^{A(n, r)} \frac{1}{j} = r + 2 \sum_{k=0}^{r-1} (r - k) \sum_{j=a_k}^{A(n, k)} \frac{1}{(3j)^3 - 3j}, \]

    where \(A(n, k)\) is the tripling sequence of Entry 6, \(a_0 = 1\) and \(a_k = A(n, k - 1) + 1\) for \(k \ge 1\), and a sum over an empty range is \(0\). For \(r = 0\) both sides are \(0\).

    theorem ramanujan_part1_ch2_entry6_general (n r : ℕ) :
    ∑ j ∈ Finset.Icc (n + 1) (A n r), (1 : ℚ) / ((j : ℕ) : ℚ)
    = (r : ℚ) + 2 * ∑ k ∈ Finset.range r, (((r - k : ℕ)) : ℚ) *
        ∑ j ∈ Finset.Icc (if k = 0 then 1 else A n (k - 1) + 1) (A n k),
          (1 : ℚ) / ((3 * ((j : ℕ) : ℚ)) ^ 3 - 3 * ((j : ℕ) : ℚ))
    def A (n k : ℕ) : ℕ := 3 ^ k * n + (3 ^ k - 1) / 2
