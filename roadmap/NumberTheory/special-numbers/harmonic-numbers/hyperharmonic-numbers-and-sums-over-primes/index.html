    Hyperharmonic numbers and sums over primes

    DefinitionHyperharmonic numbers#✓fully proved

    MetaMathlibExt.hyperharmonic

    The hyperharmonic numbers \(h_n^{(r)} \in \mathbb{Q}\) of order \(r\) and index \(n\), for natural numbers \(r\) and \(n\), are defined by recursion on \(r\): \(h_n^{(0)} = 1/n\) for \(n \ge 1\), \(h_0^{(0)} = 0\), and

    \[h_n^{(r+1)} = \sum_{k=1}^{n} h_k^{(r)}.\]

    Thus \(h_0^{(r)} = 0\) for every order \(r\), and \(h_n^{(1)} = 1 + 1/2 + \dots + 1/n\) is the \(n\)-th harmonic number \(H_n\). This is the definition of Conway and Guy.

    public def hyperharmonic : ℕ → ℕ → ℚ
  | 0, n => 1 / n
  | r + 1, n => ∑ k ∈ Icc 1 n, hyperharmonic r k

    DefinitionSigned iterated partial sums#✓fully proved

    MetaMathlibExt.signedIteratedPartialSum

    Let \((b_n)_{n \ge 0}\) be a real sequence and fix a choice of signs, either alternating, \(\varepsilon_k = (-1)^{k-1}\), or constant, \(\varepsilon_k = 1\). The signed iterated partial sums \(S^{(r)}_n\) of \(b\), for orders \(r \in \mathbb{N}\) and \(n \in \mathbb{N}\), are defined by \(S^{(0)}_n = 0\), \(S^{(1)}_n = b_n\) and, for \(r \ge 1\),

    \[S^{(r+1)}_n = \sum_{k=1}^{n} \varepsilon_k \, S^{(r)}_k.\]

    The value \(0\) at order \(0\) is a convention and is not used.

    With \(b_n = H_n^{(p)} = \sum_{j=1}^{n} j^{-p}\), constant signs give the generalized hyperharmonic numbers \(H_n^{(p,r)}\) and alternating signs give the type I alternating ones \(H_n^{(p,r,1)}\); with \(b_n = \bar H_n^{(p)} = \sum_{j=1}^{n} (-1)^{j-1} j^{-p}\), constant signs give type II, \(H_n^{(p,r,2)}\), and alternating signs give type III, \(H_n^{(p,r,3)}\).

    public noncomputable def signedIteratedPartialSum (alt : Bool) (b : ℕ → ℝ) : ℕ → ℕ → ℝ
  | 0, _ => 0
  | 1, n => b n
  | r + 2, n => ∑ k ∈ Icc 1 n, (if alt then (-1 : ℝ) ^ (k - 1) else 1) *
      signedIteratedPartialSum alt b (r + 1) k

    DefinitionLi's coefficients \(a(r, m, j)\)#✓fully proved

    MetaMathlibExt.liCoeffA

    The rational numbers \(a(r, m, j)\), for natural numbers \(r\), \(m\), \(j\), are defined by recursion on \(r\). For all \(m\) and \(j\), \(a(0, m, j) = 0\); moreover \(a(1, 0, 0) = 1\) and \(a(1, m, j) = 0\) for \((m, j) \ne (0, 0)\). For \(r \ge 1\) the values of order \(r + 1\) are as follows. First,

    \[a(r+1, r, 0) = -\sum_{m=0}^{r-1} \frac{a(r, m, r-m-1)}{r-m}.\]

    For \(0 \le m \le r - 1\) and \(1 \le \ell \le r - m\),

    \[a(r+1,m,\ell) = \sum_{j=\ell-1}^{r-1-m} \frac{a(r,m,j)}{j+1} \binom{j+1}{j-\ell+1} B_{j-\ell+1}.\]

    For \(0 \le m \le r - 1\),

    \[a(r+1, m, 0) = -\sum_{y=0}^{m} \sum_{j=\max(0, m-y-1)}^{r-1-y} a(r, y, j)\, D(m, j, y),\]

    where

    \[D(m, j, y) = \frac{1}{j+1} \sum_{\ell=\max(0, m-y-1)}^{j} \binom{j+1}{j-\ell} B_{j-\ell} \binom{\ell+1}{m-y} (-1)^{1+\ell-m+y}.\]

    All other values \(a(r+1, m, \ell)\) are \(0\). Here \(B_n\) are the Bernoulli numbers with \(B_1 = 1/2\), that is, the numbers determined by \(\sum_{j=0}^{k} \binom{k+1}{j} B_j = k + 1\) for all \(k \ge 0\).

    Li writes \(D(r, m, j, y)\); the value does not depend on \(r\).

  | 0, _, _ => 0
  | 1, m, j => if m = 0 ∧ j = 0 then 1 else 0
  | r + 2, m, l =>
    if m = r + 1 ∧ l = 0 then
      -∑ m' ∈ range (r + 1), liCoeffA (r + 1) m' (r - m') / ((r + 1 - m' : ℕ) : ℚ)

          bernoulli' (j - i) * ((i + 1).choose (m - y) : ℚ) * (-1) ^ (1 + i + y - m)
    else 0
