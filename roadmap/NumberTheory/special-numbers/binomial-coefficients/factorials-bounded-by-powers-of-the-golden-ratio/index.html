    Factorials bounded by powers of the golden ratio

    DefinitionGolden factorial exponent#✓fully proved

    MetaMathlibExt.goldenFactorialExponent

    For a natural number \(n\), the golden factorial exponent \(\alpha(n)\) is the least positive integer \(m\) with \(n! \le \varphi^m\), where \(\varphi\) is the golden ratio. This is the sequence OEIS A214048.

    Equivalently \(\alpha(n)\) is the positive integer \(m\) with \(\varphi^{m-1} \le n! \le \varphi^m\); the number \(n!\) is never a power of \(\varphi\) for \(n \ge 2\), and \(\alpha(1) = 1\).

    public noncomputable def goldenFactorialExponent (n : ℕ) : ℕ :=
  sInf {m : ℕ | 1 ≤ m ∧ (n.factorial : ℝ) ≤ goldenRatio ^ m}

    TheoremEvery factorial is at most a positive power of the golden ratio#✓fully proved

    MetaMathlibExt.exists_goldenRatio_pow_ge_factorial

    Let \(\varphi\) be the golden ratio. For every natural number \(n\) there is an integer \(m \ge 1\) with \(n! \le \varphi^m\).

    Thus the set of positive integers \(m\) with \(n! \le \varphi^m\), whose least element is the golden factorial exponent of \(n\), is nonempty.

    DefinitionKurepa's partial integral#✓fully proved

    MetaMathlibExt.kurepaPartialIntegral

    For a natural number \(n\) and a real number \(x\), Kurepa's partial integral is

    \[K_n(x) = \int_0^x e^{-t} \sum_{k=0}^{n-1} t^k \, dt,\]

    an oriented integral, so for \(x < 0\) it is minus the integral over \([x, 0]\).

    The paper writes it as \(!n(x) = \int_0^x e^{-t} \frac{t^n - 1}{t - 1} \, dt\); the geometric sum agrees with \(\frac{t^n - 1}{t - 1}\) for \(t \ne 1\), and the singularity at \(t = 1\) is removable.

    public noncomputable def kurepaPartialIntegral (n : ℕ) (x : ℝ) : ℝ :=
  ∫ t in (0 : ℝ)..x, Real.exp (-t) * ∑ k ∈ Finset.range n, t ^ k

    TheoremExistence of the Lambert sequences#✓fully proved

    MetaMathlibExt.exists_lambertSequence

    Let \(h(y) = y e^y\) be the Lambert map. For every natural number \(n \ge 4\) and every real number \(c\) with \(0 < c \le 1\) there is a real number \(a \ge n - 1\) with

    \[h\left(-\frac{a}{n-1}\right) = -\frac{1}{n-1} \, c^{1/(n-1)}.\]

    Equivalently, \(a = -(n-1) \, W_{-1}\left(-\frac{1}{n-1} c^{1/(n-1)}\right)\), where \(W_{-1}\) is the lower real branch of the Lambert W function. With \(c = 4/7\) this is the paper's \(a_n\), and with \(c = 4/(7m)\) for an integer \(m \ge 1\) it is the paper's \(A_{n,m}\).

    public theorem exists_lambertSequence {n : ℕ} (hn : 4 ≤ n) {c : ℝ} (hc0 : 0 < c)
    (hc1 : c ≤ 1) :
    ∃ a : ℝ, (n : ℝ) - 1 ≤ a ∧
      lambertMap (-a / ((n : ℝ) - 1)) = -(1 / ((n : ℝ) - 1)) * c ^ (1 / ((n : ℝ) - 1))
    public noncomputable def lambertMap (y : ℝ) : ℝ :=
  y * Real.exp y
