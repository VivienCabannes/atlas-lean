    TheoremUnique integer coordinates of powers of \(u + v^{1/N}\)#●ready to prove

    MetaMathlibExt.existsUnique_radical_expansion_coeffs

    Let \(N\) be a natural number with at least two distinct prime divisors, let \(u, v\) be coprime positive integers such that \(x^N - v\) is irreducible over \(\mathbb{Q}\), and let \(\theta = v^{1/N}\) be the positive real \(N\)-th root of \(v\). Then for every natural number \(n\) there is exactly one tuple of integers \((a_0, \dots, a_{N-1})\) with \((u + \theta)^n = \sum_{i=0}^{N-1} a_i \theta^i\).

    (hirr : Irreducible (Polynomial.X ^ N - Polynomial.C (v : ℚ))) (n : ℕ) :
    ∃! a : Fin N → ℤ, ((u : ℝ) + (v : ℝ) ^ (1 / (N : ℝ))) ^ n =
      ∑ i : Fin N, (a i : ℝ) * ((v : ℝ) ^ (1 / (N : ℝ))) ^ (i : ℕ)

    TheoremGcd of the coefficients of \((u + \sqrt{v})^n\)#●ready to prove

    MetaMathlibExt.gcd_sqrt_expansion_coeffs

    Let \(u, v\) be coprime positive integers with \(\sqrt{v}\) irrational, let \(a_n, b_n\) (for natural \(n\)) be integers with \((u + \sqrt{v})^n = a_n + b_n \sqrt{v}\) for every \(n \ge 1\), and let \(D_n \ge 0\) be the greatest common divisor of \(a_n\) and \(b_n\). Then for every \(n \ge 1\): (a) if \(u^2 - v\) is odd, then \(D_n = 1\); (b) if \(u^2 - v \equiv 2 \pmod 4\), then \(D_{2n-1} = 2^{n-1}\) and \(D_{2n} = 2^n\); (c) if \(u^2 - v \equiv 4 \pmod 8\), then \(D_{3n-2} = 2^{3n-3}\), \(D_{3n-1} = 2^{3n-2}\) and \(D_{3n} = 2^{3n}\); (d) if \(u^2 - v \equiv 0 \pmod 8\), then \(D_n = 2^{n-1}\).

    public theorem_wanted gcd_sqrt_expansion_coeffs {u v : ℕ} (hu : 0 < u) (hv : 0 < v)
    (huv : u.Coprime v) (hirr : Irrational (Real.sqrt v)) (a b : ℕ → ℤ)
    (hab : ∀ n, 1 ≤ n → ((u : ℝ) + Real.sqrt v) ^ n = a n + b n * Real.sqrt v) :
    (Odd ((u : ℤ) ^ 2 - v) → ∀ n, 1 ≤ n → Int.gcd (a n) (b n) = 1) ∧
    (((u : ℤ) ^ 2 - v) % 4 = 2 → ∀ n, 1 ≤ n →
      Int.gcd (a (2 * n - 1)) (b (2 * n - 1)) = 2 ^ (n - 1) ∧
        Int.gcd (a (2 * n)) (b (2 * n)) = 2 ^ n) ∧
    (((u : ℤ) ^ 2 - v) % 8 = 4 → ∀ n, 1 ≤ n →
      Int.gcd (a (3 * n - 2)) (b (3 * n - 2)) = 2 ^ (3 * n - 3) ∧
        Int.gcd (a (3 * n - 1)) (b (3 * n - 1)) = 2 ^ (3 * n - 2) ∧
        Int.gcd (a (3 * n)) (b (3 * n)) = 2 ^ (3 * n)) ∧
    (((u : ℤ) ^ 2 - v) % 8 = 0 → ∀ n, 1 ≤ n → Int.gcd (a n) (b n) = 2 ^ (n - 1))

    TheoremGcd of the coefficients of \((u + v^{1/p})^n\) for an odd prime \(p\)#●ready to prove

    Let \(p\) be an odd prime, let \(u, v\) be coprime positive integers such that \(\theta = v^{1/p}\), the positive real \(p\)-th root of \(v\), is irrational, and let \(a_{n,i}\) (for natural \(n\) and \(0 \le i \le p - 1\)) be integers with \((u + \theta)^n = \sum_{i=0}^{p-1} a_{n,i} \theta^i\) for every \(n \ge 1\).
