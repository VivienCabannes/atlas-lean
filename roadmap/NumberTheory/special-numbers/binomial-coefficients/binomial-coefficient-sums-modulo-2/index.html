    DefinitionRun lengths of a digit list#✓fully proved

    MetaMathlibExt.bitRunLengths

    Given a list \(b_1, \dots, b_k\) of natural numbers (binary digits) and a natural number \(c\), this is the list, in order of occurrence, of the lengths of the maximal runs of \(1\)s in the sequence consisting of \(c\) ones followed by \(b_1, \dots, b_k\), where every digit other than \(1\) ends a run.

    public def bitRunLengths : List ℕ → ℕ → List ℕ
  | [], c => if c = 0 then [] else [c]
  | b :: bs, c =>
    if b = 1 then bitRunLengths bs (c + 1)
    else if c = 0 then bitRunLengths bs 0 else c :: bitRunLengths bs 0

    DefinitionBinary run lengths#✓fully proved

    MetaMathlibExt.binaryRunLengths

    For a natural number \(n\), the binary run lengths of \(n\) form the list of the lengths of the maximal runs of \(1\)s in the binary expansion of \(n\), in the order in which the runs occur when the digits are read from the least significant one. This is the paper's list \(\mathcal{L}(n)\), whose order does not matter there; for \(n = 0\) the list is empty.

    public def binaryRunLengths (n : ℕ) : List ℕ :=
  bitRunLengths (Nat.digits 2 n) 0

    DefinitionRun length transform#✓fully proved

    MetaMathlibExt.runLengthTransform

    For a sequence \(S : \mathbb{N} \to \mathbb{Z}\), the run length transform of \(S\) is the sequence \(T : \mathbb{N} \to \mathbb{Z}\) given by \(T(n) = \prod_{\ell \in \mathcal{L}(n)} S(\ell)\), where \(\mathcal{L}(n)\) is the list of the lengths of the maximal runs of \(1\)s in the binary expansion of \(n\), so that each run contributes one factor.

    public def runLengthTransform (S : ℕ → ℤ) (n : ℕ) : ℤ :=
  ((binaryRunLengths n).map S).prod
    public def binaryRunLengths (n : ℕ) : List ℕ :=
  bitRunLengths (Nat.digits 2 n) 0

    MetaMathlibExt.linearRecurrence_eq_companion_pow

    Let \(r\) be a natural number, let \(d_0, \dots, d_r\) be integers, and let \(S : \mathbb{N} \to \mathbb{Z}\) satisfy \(S(0) = 1\) and \(S(m + 1) = d_0 S(m) + d_1 S(m - 1) + \dots + d_r S(m - r)\) for every \(m \ge r\). Let \(\gamma(1)\) be the \((r + 1) \times (r + 1)\) integer matrix with rows and columns indexed by \(0, \dots, r\) whose row \(i < r\) has a \(1\) in column \(i + 1\) and zeros elsewhere, and whose last row is \((d_r, d_{r-1}, \dots, d_0)\). With \(v = (1, 0, \dots, 0)\) and \(w = (S(0), \dots, S(r))^{T}\), we have \(S(n) = v \, \gamma(1)^n \, w\) for every natural number \(n\).

    The values \(S(1), \dots, S(r)\) are arbitrary.

    public theorem_wanted linearRecurrence_eq_companion_pow (r : ℕ) (d : Fin (r + 1) → ℤ)

    S n = Pi.single 0 1 ⬝ᵥ
      ((Matrix.of fun i j : Fin (r + 1) =>
          if (i : ℕ) < r then (if (j : ℕ) = i + 1 then 1 else 0) else d (Fin.rev j)) ^ n *ᵥ
        fun i => S i)
