    factorialProd

    For a list \(L\) of natural numbers and a natural number \(n\), the product of scaled factorials of \(L\) at \(n\) is \(\prod_{a \in L} (an)!\), the product of the factorials \((an)!\) over the entries \(a\) of \(L\), counted with multiplicity; for the empty list it is \(1\).

    def factorialProd (L : List ℕ) (n : ℕ) : ℕ :=
  (L.map fun a => Nat.factorial (a * n)).prod

    DefinitionIntegral factorial ratio#✓fully proved

    IsIntegralFactorialRatio

    For lists \(A = (a_1, \dots, a_k)\) and \(B = (b_1, \dots, b_l)\) of natural numbers, the pair \((A, B)\) is an integral factorial ratio when every \(a_i\) and every \(b_j\) is positive, \(a_1 + \dots + a_k = b_1 + \dots + b_l\), and for every natural number \(n\) the product \((b_1 n)! \cdots (b_l n)!\) divides \((a_1 n)! \cdots (a_k n)!\); equivalently, the quotient \(\frac{(a_1 n)! \cdots (a_k n)!}{(b_1 n)! \cdots (b_l n)!}\) is a natural number.

    def IsIntegralFactorialRatio (A B : List ℕ) : Prop :=
  (∀ a ∈ A, 0 < a) ∧ (∀ b ∈ B, 0 < b) ∧ A.sum = B.sum ∧
    ∀ n : ℕ, factorialProd B n ∣ factorialProd A n
    def factorialProd (L : List ℕ) (n : ℕ) : ℕ :=
  (L.map fun a => Nat.factorial (a * n)).prod

    isIntegralFactorialRatio_iff

    For lists \(A\) and \(B\) of natural numbers, \((A, B)\) is an integral factorial ratio if and only if every entry of \(A\) is positive, every entry of \(B\) is positive, the entries of \(A\) and the entries of \(B\) have the same sum, and for every natural number \(n\) the product \(\prod_{b \in B} (bn)!\) divides \(\prod_{a \in A} (an)!\).
