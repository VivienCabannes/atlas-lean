    DefinitionGlaisher–Kinkelin constant#✓fully proved

    MetaMathlibExt.glaisherKinkelinConstant

    The Glaisher–Kinkelin constant is the real number

    \[A = \exp\left(\frac{1}{12} - \operatorname{Re} \zeta'(-1)\right),\]

    where \(\zeta'\) is the complex derivative of the Riemann zeta function \(\zeta\). Since \(\zeta'(-1)\) is real, \(\log A = \frac{1}{12} - \zeta'(-1)\).

    public noncomputable def glaisherKinkelinConstant : ℝ :=
  Real.exp (1 / 12 - (deriv riemannZeta (-1 : ℂ)).re)

    DefinitionFactorial-product constants#✓fully proved

    MetaMathlibExt.factorialProductConstant

    For a natural number \(k \ge 1\), the constant \(F_k\) is the positive real number defined by

    \[\log F_k = \frac{k}{4} \log(2\pi) - \frac{k^2+1}{k} \log A + \frac{1 - \log k}{12k} - \sum_{\nu=1}^{k-1} \frac{\nu}{k} \log \Gamma\left(\frac{\nu}{k}\right),\]

    where \(A\) is the Glaisher–Kinkelin constant and \(\Gamma\) is the gamma function. For \(k = 0\) the definition gives \(F_0 = 1\).

    The constant \(F_k\) appears in the asymptotic formula for \(\prod_{\nu=1}^{n} (k\nu)!\) as \(n \to \infty\); that formula is a separate statement.

    public noncomputable def factorialProductConstant (k : ℕ) : ℝ :=
  Real.exp ((k : ℝ) / 4 * Real.log (2 * Real.pi) -
    ((k : ℝ) ^ 2 + 1) / k * Real.log glaisherKinkelinConstant +
    (1 - Real.log k) / (12 * k) -
    ∑ ν ∈ Finset.Ico 1 k, (ν : ℝ) / k * Real.log (Real.Gamma ((ν : ℝ) / k)))
    public noncomputable def glaisherKinkelinConstant : ℝ :=
  Real.exp (1 / 12 - (deriv riemannZeta (-1 : ℂ)).re)

    MetaMathlibExt.factorialProductComparison

    For a natural number \(k\), the comparison function \(P_k \colon \mathbb{R} \to \mathbb{R}\) is defined by

    \[P_k(x) = (k^k)^{x(x+1)/2} \left(\frac{2\pi k x}{e}\right)^{x/2} x^{(3k+1)/(12k)}.\]
    public noncomputable def factorialProductComparison (k : ℕ) (x : ℝ) : ℝ :=
  ((k : ℝ) ^ k) ^ (x * (x + 1) / 2) * (2 * Real.pi * k / Real.exp 1 * x) ^ (x / 2) *
    x ^ ((3 * (k : ℝ) + 1) / (12 * k))

    DefinitionComparison function for products of binomial coefficients#✓fully proved

    MetaMathlibExt.binomialProductComparison

    For natural numbers \(a\) and \(b\), let \(c = a - b\) if \(b \le a\) and \(c = 0\) otherwise. The comparison function \(P_{a,b} \colon \mathbb{R} \to \mathbb{R}\) is defined by

    \[P_{a,b}(x) = \left(\frac{a^a}{b^b c^c}\right)^{x(x+1)/2} x^{(1/a - a/(bc))/12 - 1/4} \Big/ \left(\frac{2\pi}{e} \cdot \frac{bc}{a} \cdot x\right)^{x/2}.\]
    public noncomputable def binomialProductComparison (a b : ℕ) (x : ℝ) : ℝ :=
  ((a : ℝ) ^ a / ((b : ℝ) ^ b * ((a - b : ℕ) : ℝ) ^ (a - b))) ^ (x * (x + 1) / 2) *
    x ^ ((1 / (a : ℝ) - a / (b * ((a - b : ℕ) : ℝ))) / 12 - 1 / 4) /
    (2 * Real.pi / Real.exp 1 * (b * ((a - b : ℕ) : ℝ) / a) * x) ^ (x / 2)
