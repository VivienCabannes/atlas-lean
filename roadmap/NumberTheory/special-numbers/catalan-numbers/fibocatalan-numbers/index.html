    MetaMathlibExt.fibonacciFactorial

    For a natural number \(n\), the Fibonacci factorial \(F_n!\) is the rational number \(F_n! = F_1 F_2 \cdots F_n\), the product of the first \(n\) Fibonacci numbers (where \(F_1 = F_2 = 1\) and \(F_{k+2} = F_{k+1} + F_k\)); in particular \(F_0! = 1\), the empty product.

    Values are taken in \(\mathbb{Q}\) so that quotients of Fibonacci factorials are exact rather than truncated by natural-number division.

    def fibonacciFactorial : ℕ → ℚ
  | 0 => 1
  | n + 1 => fibonacciFactorial n * (Nat.fib (n + 1) : ℚ)

    DefinitionLucas polynomials in \(s\) and \(t\)#✓fully proved
