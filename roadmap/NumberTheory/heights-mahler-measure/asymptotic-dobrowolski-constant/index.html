    DefinitionDobrowolski scale#✓fully proved

    MathlibExt.NumberTheory.AsymptoticDobrowolski.dobrowolskiScale

    For a natural number \(d\), the Dobrowolski scale is

    \[\left(\frac{\log \log d}{\log d}\right)^3,\]

    with natural logarithms and the conventions \(\log 0 = 0\) and \(x / 0 = 0\), so that it is \(0\) for \(d \le 1\).

    It is used only for degrees \(d \ge 3\) in the definition of asymptotic Dobrowolski coefficients.

    noncomputable def dobrowolskiScale (d : ℕ) : ℝ :=
  (Real.log (Real.log d) / Real.log d) ^ 3

    DefinitionAsymptotic Dobrowolski coefficients#✓fully proved

    MathlibExt.NumberTheory.AsymptoticDobrowolski.IsAsymptoticDobrowolskiCoefficient

    A real number \(c\) is an asymptotic Dobrowolski coefficient if for every \(\varepsilon > 0\) there is a natural number \(D \ge 3\) such that every nonzero algebraic number \(\alpha \in \mathbb{C}\) that is not a root of unity and whose minimal polynomial over \(\mathbb{Q}\) has degree \(d \ge D\) satisfies

    \[1 + (c - \varepsilon) \left(\frac{\log \log d}{\log d}\right)^3 \le M(\alpha),\]

    where \(M(\alpha)\) is the Mahler measure of \(\alpha\).

    The degree threshold \(D\) may depend on \(\varepsilon\) but is uniform over all such \(\alpha\).

    def IsAsymptoticDobrowolskiCoefficient (c : ℝ) : Prop :=
  ∀ ε : ℝ, 0 < ε → ∃ D : ℕ, 3 ≤ D ∧
    ∀ α : ℂ, IsAlgebraic ℚ α → α ≠ 0 → ¬IsOfFinOrder α →
      D ≤ (minpoly ℚ α).natDegree →
        1 + (c - ε) * dobrowolskiScale (minpoly ℚ α).natDegree ≤
          algebraicMahlerMeasure α
    noncomputable def dobrowolskiScale (d : ℕ) : ℝ :=
  (Real.log (Real.log d) / Real.log d) ^ 3

    DefinitionAsymptotic Dobrowolski constant#✓fully proved

    MathlibExt.NumberTheory.AsymptoticDobrowolski.asymptoticDobrowolskiConstant

    The asymptotic Dobrowolski constant is the supremum, in the extended real numbers \([-\infty, +\infty]\), of the set of all real asymptotic Dobrowolski coefficients.

    The supremum would be \(-\infty\) if there were no coefficient and is \(+\infty\) if the coefficients are unbounded above; neither attainment nor a finite upper bound is assumed.

    noncomputable def asymptoticDobrowolskiConstant : EReal :=
  sSup {x : EReal | ∃ c : ℝ, IsAsymptoticDobrowolskiCoefficient c ∧ x = c}
