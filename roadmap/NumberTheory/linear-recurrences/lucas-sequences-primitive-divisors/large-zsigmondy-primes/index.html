    DefinitionLarge Zsigmondy prime#✓fully proved

    MetaMathlibExt.IsLargeZsigmondyPrime

    Let \(a\), \(b\), \(n\) and \(p\) be natural numbers. Then \(p\) is a large Zsigmondy prime for \((a, b, n)\) when \(p\) is a primitive prime divisor of the term \(a^n - b^n\) of the integer sequence \((a^m - b^m)_{m \ge 0}\), that is, \(n \ge 1\), \(p\) is prime, \(p\) divides \(a^n - b^n\) and \(p\) divides no \(a^m - b^m\) with \(1 \le m < n\), and moreover \(p^2\) divides \(a^n - b^n\) or \(p > n + 1\).

    def IsLargeZsigmondyPrime (a b n p : ℕ) : Prop :=
  IntegerSequence.IsPrimitivePrimeDivisor (fun m => (a : ℤ) ^ m - (b : ℤ) ^ m) n p ∧
    ((p : ℤ) ^ 2 ∣ (a : ℤ) ^ n - (b : ℤ) ^ n ∨ n + 1 < p)
    def IsPrimitivePrimeDivisor (a : ℕ → ℤ) (m u : ℕ) : Prop :=
  Nat.Prime u ∧ IsPrimitiveDivisor a m u

There is a large Zsigmondy prime for \((a, b, n)\) if and only if none of the following holds: \(n = 2\) and \(a + b = 2^s\) or \(a + b = 3 \cdot 2^s\) for some natural number \(s\); \(n = 4\) and \((a, b) \in \{(2, 1), (3, 1)\}\); \(n = 6\) and \((a, b) \in \{(2, 1), (3, 1), (3, 2), (5, 1), (5, 4)\}\); \(n = 10\) and \((a, b) \in \{(2, 1), (3, 2)\}\); \(n = 12\) and \((a, b) = (2, 1)\); \(n = 18\) and \((a, b) = (2, 1)\).
