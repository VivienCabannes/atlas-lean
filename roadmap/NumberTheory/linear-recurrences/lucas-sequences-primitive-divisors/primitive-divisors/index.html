    IntegerSequence.IsPrimitiveDivisor

    Let \((a_s)_{s \ge 0}\) be a sequence of integers and let \(m\) and \(u\) be natural numbers. Then \(u\) is a primitive divisor of \(a_m\) when \(m \ge 1\), \(u \ge 2\), \(u\) divides \(a_m\), and \(u\) divides no \(a_s\) with \(1 \le s < m\).

    def IsPrimitiveDivisor (a : ℕ → ℤ) (m u : ℕ) : Prop :=
  1 ≤ m ∧ 2 ≤ u ∧ (u : ℤ) ∣ a m ∧ ∀ s : ℕ, 1 ≤ s → s < m → ¬ (u : ℤ) ∣ a s

    LucasSequence.IsPrimitiveDivisor

    Let \(u_0, u_1, u_2, \dots\) be a sequence of integers and let \(D\) be an integer (for a Lucas pair \((\alpha, \beta)\), the discriminant \(D = (\alpha - \beta)^2\)). A natural number \(p\) is a primitive divisor of \(u_n\) when \(n \ge 1\), \(p\) is prime, \(p\) divides \(u_n\), and \(p\) does not divide \(D \, u_1 u_2 \cdots u_{n-1}\) (for \(n = 1\) the product is empty, and the condition is that \(p\) does not divide \(D\)).

    def IsPrimitiveDivisor (u : ℕ → ℤ) (discriminant : ℤ) (n p : ℕ) : Prop :=
  0 < n ∧ p.Prime ∧ (p : ℤ) ∣ u n ∧
    ¬(p : ℤ) ∣ discriminant * ∏ k ∈ Finset.Ico 1 n, u k

    TheoremPrimitive divisors of Fibonacci numbers#✓fully proved

    MetaMathlibExt.exists_isPrimitiveDivisor_fib

    Write \(F_j\) for the \(j\)-th Fibonacci number. For every natural number \(n \ge 7\) with \(n \ne 12\), \(F_n\) has a primitive divisor with respect to the discriminant \(5\): there is a prime \(p\) that divides \(F_n\) but does not divide \(5 F_1 F_2 \cdots F_{n-1}\).

    This is the Fibonacci case of Carmichael's theorem on Lucas sequences, with \(\alpha = (1 + \sqrt{5})/2\) and \(\beta = (1 - \sqrt{5})/2\), so that \((\alpha - \beta)^2 = 5\).

    theorem exists_isPrimitiveDivisor_fib {n : Nat} (hn : 7 ≤ n) (hne : n ≠ 12) :
    ∃ p, LucasSequence.IsPrimitiveDivisor (fun k => (Nat.fib k : Int)) (5 : Int) n p

    MetaMathlibExt.somer_eventually_has_primitive_prime_divisor

    Let \(P\) and \(Q\) be integers with \(Q \ne 0\), and let \((u_n)_{n \ge 0}\) be the integer sequence with \(u_0 = 0\), \(u_1 = 1\) and \(u_{n+2} = Pu_{n+1} - Qu_n\) (the Lucas sequence of the first kind). Suppose the sequence is nondegenerate: whenever complex numbers \(\alpha\) and \(\beta\) satisfy \(\alpha + \beta = P\), \(\alpha\beta = Q\) and \(\beta \ne 0\), no power \((\alpha / \beta)^k\) with \(k \ge 1\) equals \(1\). Then for all sufficiently large \(n\) the term \(u_n\) has a primitive prime divisor: a prime \(p\) that divides \(u_n\) but divides no \(u_m\) with \(0 < m < n\).

    Nondegeneracy also excludes the double-root case \(\alpha = \beta\).
