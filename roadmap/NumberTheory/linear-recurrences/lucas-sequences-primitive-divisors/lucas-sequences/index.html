    MetaMathlibExt.LucasSequenceParams.IsCoprime

    Lucas sequence parameters \((P, Q)\) are coprime when there exist integers \(x\) and \(y\) with \(xP + yQ = 1\).

    This additional condition is imposed in some applications of Lucas sequences.

    def LucasSequenceParams.IsCoprime (params : LucasSequenceParams) : Prop :=
  ∃ x y : ℤ, x * params.p + y * params.q = 1

    DefinitionLucas sequence \(U(P, Q)\)#✓fully proved

    MetaMathlibExt.lucasU

    For Lucas sequence parameters \((P, Q)\), the Lucas sequence \(U(P, Q)\) is the integer sequence \((U_n)_{n \ge 0}\) with \(U_0 = 0\), \(U_1 = 1\) and \(U_{n+2} = P U_{n+1} - Q U_n\) for every natural number \(n\).

    def lucasU (params : LucasSequenceParams) : ℕ → ℤ
  | 0 => 0
  | 1 => 1
  | n + 2 => params.p * lucasU params (n + 1) - params.q * lucasU params n
    structure LucasSequenceParams where
  p : ℤ
  q : ℤ
  q_ne_zero : q ≠ 0

    DefinitionCompanion Lucas sequence \(V(P, Q)\)#✓fully proved

    MetaMathlibExt.lucasV

    For Lucas sequence parameters \((P, Q)\), the companion Lucas sequence \(V(P, Q)\) is the integer sequence \((V_n)_{n \ge 0}\) with \(V_0 = 2\), \(V_1 = P\) and \(V_{n+2} = P V_{n+1} - Q V_n\) for every natural number \(n\).

    def lucasV (params : LucasSequenceParams) : ℕ → ℤ
  | 0 => 2
  | 1 => params.p
  | n + 2 => params.p * lucasV params (n + 1) - params.q * lucasV params n
    structure LucasSequenceParams where
  p : ℤ
  q : ℤ
  q_ne_zero : q ≠ 0

    TheoremBinet formulas for Lucas sequences over any field#✓fully proved

    MetaMathlibExt.lucas_binet_formulas_of_field

    Let \(P\) and \(Q\) be integers with \(Q \ne 0\), let \(U_n = U_n(P, Q)\) and \(V_n = V_n(P, Q)\) be the associated Lucas sequences, and let \(\alpha\) and \(\beta\) be elements of a field \(K\) with \(\alpha + \beta = P\) and \(\alpha \beta = Q\) in \(K\). If \(\alpha \ne \beta\), then for every natural number \(n\), \(U_n = (\alpha^n - \beta^n) / (\alpha - \beta)\) and \(V_n = \alpha^n + \beta^n\) in \(K\). If \(\beta = \alpha\), then for every natural number \(n\), \(U_n = n \alpha^{n-1}\) and \(V_n = 2 \alpha^n\) in \(K\), where \(\alpha^{n-1}\) is read as \(1\) when \(n = 0\). Here the integers \(U_n\), \(V_n\), \(P\), \(Q\) and \(n\) are mapped into \(K\).

    No assumption on the characteristic of \(K\) is made; for example \(K\) may be \(\mathbb{Z}/p\mathbb{Z}\) for a prime \(p\), where the coefficient \(n\) of the double-root formula is read modulo \(p\).

    theorem lucas_binet_formulas_of_field
    {K : Type*} [Field K]
    (params : LucasSequenceParams) (alpha beta : K)
    (hsum : alpha + beta = (params.p : K))
    (hprod : alpha * beta = (params.q : K)) :
    (alpha ≠ beta → ∀ n : ℕ,
      (lucasU params n : K) = (alpha ^ n - beta ^ n) / (alpha - beta) ∧
      (lucasV params n : K) = alpha ^ n + beta ^ n) ∧
    (beta = alpha → ∀ n : ℕ,
      (lucasU params n : K) = (n : K) * alpha ^ (n - 1) ∧
      (lucasV params n : K) = 2 * alpha ^ n)
