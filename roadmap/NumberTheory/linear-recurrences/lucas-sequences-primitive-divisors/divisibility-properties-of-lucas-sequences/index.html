    MetaMathlibExt.lucasU_mod_two

    Let \(U = U(P, Q)\) be the Lucas sequence with integer parameters \(P\) and \(Q \ne 0\), let \(D = P^2 - 4Q\), and suppose \(2 \nmid \gcd(P, Q)\). Then \(U\) is periodic modulo \(2\) from index \(1\) on: there is \(k > 0\) with \(U_{n+k} \equiv U_n \pmod 2\) for every \(n \ge 1\). If \(P\) is odd and \(Q\) is even, then \(U_n\) is odd for every \(n \ge 1\). If \(P\) is even and \(Q\) is odd, then for every \(n \ge 0\), \(2 \mid U_n\) if and only if \(2 \mid n\); moreover \(2 \mid D\). If \(P\) and \(Q\) are both odd, then for every \(n \ge 0\), \(2 \mid U_n\) if and only if \(3 \mid n\).

    The periodicity need not start at \(n = 0\): for \(P = 1\) and \(Q = 2\), \(U\) is \(0, 1, 1, 1, \dots\) modulo \(2\).
