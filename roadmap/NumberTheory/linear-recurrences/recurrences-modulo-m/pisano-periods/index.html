    TheoremFulton–Morris theorem on Pisano periods equal to the modulus#✓fully proved

    MetaMathlibExt.fulton_morris_pisano_fixed_point

    Write \(F_t\) for the \(t\)-th Fibonacci number. Let \(m > 1\) be a natural number and let \(\pi\) be a positive integer with \(F_\pi \equiv 0 \pmod{m}\) and \(F_{\pi+1} \equiv 1 \pmod{m}\) such that \(\pi \le t\) for every positive integer \(t\) with \(F_t \equiv 0 \pmod{m}\) and \(F_{t+1} \equiv 1 \pmod{m}\); that is, \(\pi\) is the Pisano period of \(m\). Then \(\pi = m\) if and only if \(m = 24 \cdot 5^{\lambda - 1}\) for some integer \(\lambda \ge 1\).

    theorem fulton_morris_pisano_fixed_point
    (m period : ℕ) (hm : 1 < m) (hperiod : 0 < period)
    (hreturn : Nat.ModEq m (Nat.fib period) 0 ∧
      Nat.ModEq m (Nat.fib (period + 1)) 1)
    (hleast : ∀ t : ℕ, 0 < t →
      Nat.ModEq m (Nat.fib t) 0 → Nat.ModEq m (Nat.fib (t + 1)) 1 →
      period ≤ t) :
    period = m ↔ ∃ lambda : ℕ, 0 < lambda ∧ m = 24 * 5 ^ (lambda - 1)

    DefinitionPisano period#✓fully proved

    MathlibExt.NumberTheory.Recurrences.FibonacciSumDivisibilityWanted.pisanoPeriod

    For a natural number \(n\), the Pisano period \(\pi(n)\) is the minimal period of the pair \((0, 1)\) under the Fibonacci step \((a, b) \mapsto (b, a + b)\) on \(\mathbb{Z}/n\mathbb{Z} \times \mathbb{Z}/n\mathbb{Z}\): the least \(k \ge 1\) such that \(k\) applications of the step map \((0, 1)\) back to \((0, 1)\), or \(0\) if there is no such \(k\) (as for \(n = 0\), where \(\mathbb{Z}/0\mathbb{Z} = \mathbb{Z}\)).

    noncomputable def pisanoPeriod (n : ℕ) : ℕ :=
  Function.minimalPeriod
    (fun p : ZMod n × ZMod n => (p.2, p.1 + p.2)) (0, 1)
