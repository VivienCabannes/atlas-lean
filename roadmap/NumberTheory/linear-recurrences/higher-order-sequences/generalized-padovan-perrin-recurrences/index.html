    DefinitionGeneralized Padovan–Perrin recurrence#✓fully proved

    MetaMathlibExt.padovanPerrinRecurrence

    Let \(R\) be a commutative semiring, \(k_1, k_2 \in R\) and \(p, s \in \mathbb{N}\). The \(([k]; p; s)\)-generalized Padovan–Perrin recurrence is the linear recurrence of order \(s + p\) with coefficients \(c_i = [i = 0] \, k_2 + [i = p] \, k_1\) for \(0 \le i < s + p\), where \([\cdot]\) is \(1\) if the condition holds and \(0\) otherwise: a sequence \(v \colon \mathbb{N} \to R\) solves it when \(v_{n+s+p} = \sum_{i=0}^{s+p-1} c_i v_{n+i}\) for every \(n \ge 0\). For \(s > 0\) this reads \(v_{n+s+p} = k_1 v_{n+p} + k_2 v_n\), that is, \(v_n = k_1 v_{n-s} + k_2 v_{n-s-p}\) for \(n \ge s + p\) (equation (1)).

    def padovanPerrinRecurrence [CommSemiring R] (k₁ k₂ : R) (p s : ℕ) : LinearRecurrence R :=
  ⟨s + p, fun i => (if (i : ℕ) = 0 then k₂ else 0) + (if (i : ℕ) = p then k₁ else 0)⟩

    DefinitionPadovan–Perrin coefficients#✓fully proved

    MetaMathlibExt.padovanPerrinRho

    Let \(R\) be a commutative semiring, let \(k_1, k_2 \in R\) and let \(p, s, n\) be natural numbers. The coefficient \(\rho(n, s + p)\) attached to \(k_1, k_2, p, s\) is \(0\) when \(n < s + p\); when \(n \ge s + p\) it is the sum of \(\binom{a + b}{a} k_1^a k_2^b\) over all pairs of natural numbers \(a, b \le n\) with \(s a + (s + p) b = n - (s + p)\). For \(s > 0\) the bounds \(a, b \le n\) hold automatically.

    For \(s > 0\) this is the coefficient \(\rho(n, r)\), \(r = s + p\), of the paper's general formula (12) for the recurrence \(v_n = k_1 v_{n-s} + k_2 v_{n-s-p}\). The paper's Proposition 4 prints the constraint as \(s a + (s + p) b = n - (s + p - 1)\), which contradicts its own normalization \(\rho(s + p, s + p) = 1\) for \(s \ge 2\); the constraint used here is the one of formula (12).

    def padovanPerrinRho [CommSemiring R] (k₁ k₂ : R) (p s n : ℕ) : R :=
  if n < s + p then 0 else
    ∑ ab ∈ (Finset.range (n + 1) ×ˢ Finset.range (n + 1)).filter
        (fun ab => s * ab.1 + (s + p) * ab.2 = n - (s + p)),
      (Nat.choose (ab.1 + ab.2) ab.1 : R) * k₁ ^ ab.1 * k₂ ^ ab.2
