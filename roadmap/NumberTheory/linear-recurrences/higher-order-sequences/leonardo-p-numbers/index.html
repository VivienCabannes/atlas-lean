    DefinitionForward evaluation of the \(H(p)\) recurrence#✓fully proved

    MathlibExt.NumberTheory.LeonardoPWanted.hSeqForward

    For a natural number \(p\), a function \(s : \mathbb{Z} \to \mathbb{Z}\) and \(n \in \mathbb{N}\), this is the list of the \(2p + n + 1\) values at \(-p, -p+1, \dots, p+n\) (the entry at position \(i\) is the value at \(i - p\)) of the sequence \(H\) that equals \(s\) on \([-p, p]\) and continues by the \(H(p)\) recurrence \(H(t) = H(t-1) + H(t-p) - H(t-2p-1)\) for \(t > p\). Each step appends one value to the previous list, so evaluation takes polynomial time.

    For \(p = 0\), where this rule is circular, every appended value is \(0\).

    def hSeqForward (seedA : ℤ → ℤ) (p : ℕ) : ℕ → List ℤ
  | 0 => (List.range (2 * p + 1)).map fun i => seedA ((i : ℤ) - p)
  | n + 1 =>
      let prev := hSeqForward seedA p n
      prev ++ [prev.getD (2 * p + n) 0 + prev.getD (p + 1 + n) 0 -
        prev.getD n 0]
