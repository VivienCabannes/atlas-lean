    MathlibExt.NumberTheory.Recurrences.HigherFibonacciWalksWanted.IsHigherFibRecurrence

    A sequence \(F : \mathbb{Z} \to \mathbb{Q}\) satisfies the \(m\)-step Fibonacci recurrence if \(F_n = F_{n-1} + F_{n-2} + \dots + F_{n-m}\) for every integer \(n\), that is, \(F_n = \sum_{i=0}^{m-1} F_{n-i-1}\). For \(m = 0\) this says \(F_n = 0\) for all \(n\).

    def IsHigherFibRecurrence (m : ℕ) (F : ℤ → ℚ) : Prop :=
  ∀ n : ℤ, F n = ∑ i ∈ Finset.range m, F (n - (i : ℤ) - 1)

    MathlibExt.NumberTheory.Recurrences.HigherFibonacciWalksWanted.weightedHigherFibSum

    For a sequence \(F : \mathbb{Z} \to \mathbb{Q}\), a natural number \(m\), integers \(N\) and \(l\), and a rational number \(q\), \(S(m,N,l,q) = \sum_{k=0}^{N} q^k F_{k+l}\); for \(N < 0\) this is the empty sum \(0\).

    The order \(m\) is carried explicitly to match the paper notation, although the sum itself only uses \(F\), \(N\), \(l\), and \(q\).
