    MetaMathlibExt.gibonacciGeneratingValue

    For integers \(a\) and \(b\) and a rational number \(x\), the value of the Gibonacci generating function at \(x\) is the rational number

    \[G^{(a,b)}(x) = \frac{(b - a)x + a}{1 - x - x^2}.\]

    It is the generating function of the Gibonacci sequence \((G_n)_{n \ge 0}\) with \(G_0 = a\), \(G_1 = b\) and \(G_{n+2} = G_{n+1} + G_n\).

    public def gibonacciGeneratingValue (a b : ℤ) (x : ℚ) : ℚ :=
  (((b : ℚ) - (a : ℚ)) * x + (a : ℚ)) / (1 - x - x ^ 2)
