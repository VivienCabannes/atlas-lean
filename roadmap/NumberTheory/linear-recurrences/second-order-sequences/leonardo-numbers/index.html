    DefinitionGeneralized Leonardo numbers#✓fully proved

    MetaMathlibExt.genLeonardo

    For an integer \(k\), the generalized Leonardo numbers \(L_{k,0}, L_{k,1}, L_{k,2}, \ldots\) are the integers defined by \(L_{k,0} = L_{k,1} = 1\) and \(L_{k,n+2} = L_{k,n+1} + L_{k,n} + k\) for all \(n \ge 0\).

    The paper takes \(k\) positive; here \(k\) may be any integer.

    public def genLeonardo (k : ℤ) : ℕ → ℤ
  | 0 => 1
  | 1 => 1
  | n + 2 => genLeonardo k (n + 1) + genLeonardo k n + k

    DefinitionDual generalized Leonardo numbers#✓fully proved

    MetaMathlibExt.genLeonardoCompanion

    For an integer \(k\), let \(L_{k,n}\) denote the generalized Leonardo numbers. The dual generalized Leonardo numbers \(M_{k,n}\), for natural numbers \(n\), are defined by \(M_{k,0} = 1 - k\) and \(M_{k,n+1} = L_{k,n} + L_{k,n+2}\), so that \(M_{k,n} = L_{k,n-1} + L_{k,n+1}\) for \(n \ge 1\).

    This agrees with the paper's Definition 2.1, which sets \(M_{k,0} = 1 - k\), \(M_{k,1} = k + 3\), and \(M_{k,n+1} = M_{k,n} + M_{k,n-1} + 2k\) for \(n \ge 1\).

    public def genLeonardoCompanion (k : ℤ) : ℕ → ℤ

    MetaMathlibExt.genLeonardo_sq_sum_diff

    For every integer \(k\) and all natural numbers \(m\), \(n\) with \(1 \le n < m\), the generalized Leonardo numbers \(L_{k,n}\) satisfy

    \[L_{k,m+n}^2 - L_{k,m-n}^2 = (L_{k,2m+1} + k)(L_{k,2n-1} + k) - 2k (L_{k,m+n} - L_{k,m-n})\]

    and

    \[L_{k,m+n}^2 + L_{k,m-n-1}^2 = (L_{k,2m} + k)(L_{k,2n} + k) - 2k (L_{k,m+n} + L_{k,m-n-1}) - 2k^2.\]

    In the second identity the last term inside the parentheses is \(L_{k,m-n-1}\). The paper as printed shows \(L_{k,m-n}\) there, which is false: at \(k = 1\), \(m = 3\), \(n = 1\) the printed identity reads \(82 = 78\). The reading used here agrees with the paper's outline derivation.

    public theorem_wanted genLeonardo_sq_sum_diff (k : ℤ) (m n : ℕ)
    (hn : 1 ≤ n) (hmn : n < m) :
    (genLeonardo k (m + n) ^ 2 - genLeonardo k (m - n) ^ 2
      = (genLeonardo k (2 * m + 1) + k) * (genLeonardo k (2 * n - 1) + k)
        - 2 * k * (genLeonardo k (m + n) - genLeonardo k (m - n))) ∧
    (genLeonardo k (m + n) ^ 2 + genLeonardo k (m - n - 1) ^ 2
      = (genLeonardo k (2 * m) + k) * (genLeonardo k (2 * n) + k)
        - 2 * k * (genLeonardo k (m + n) + genLeonardo k (m - n - 1))
        - 2 * k ^ 2)

    TheoremBinomial identities with steps three and four for generalized Leonardo numbers#●ready to prove

    MetaMathlibExt.genLeonardo_binomial_steps

    Let \(k\) be an integer, and let \(L_{k,n}\) and \(M_{k,n}\) denote the generalized Leonardo numbers and the dual generalized Leonardo numbers. For all natural numbers \(n\) and \(r\),

    \[\sum_{i=0}^{n} \binom{n}{i} L_{k,3i+r} = 2^n L_{k,2n+r},\]
    \[\sum_{i=0}^{n} \binom{n}{i} M_{k,3i+r} = 2^n M_{k,2n+r},\]
    \[\sum_{i=0}^{n} \binom{n}{i} L_{k,4i+r} = 3^n L_{k,2n+r} + k\,(3^n - 2^n),\]

    and

    \[\sum_{i=0}^{n} \binom{n}{i} M_{k,4i+r} = 3^n M_{k,2n+r} + 2k\,(3^n - 2^n).\]

    Part (iv) of the paper's Theorem 3.4 prints the last term of the fourth identity as \(k\,(3^n - 2^n)\), which is false at \(k = n = 1\), \(r = 0\); the coefficient \(2k\) is the correct one, as in parts (ii) of Theorems 3.1–3.3.

    public theorem_wanted genLeonardo_binomial_steps (k : ℤ) (n r : ℕ) :
    (∑ i ∈ Finset.range (n + 1), (Nat.choose n i : ℤ) * genLeonardo k (3 * i + r)
      = 2 ^ n * genLeonardo k (2 * n + r)) ∧
    (∑ i ∈ Finset.range (n + 1), (Nat.choose n i : ℤ) * genLeonardoCompanion k (3 * i + r)
      = 2 ^ n * genLeonardoCompanion k (2 * n + r)) ∧
    (∑ i ∈ Finset.range (n + 1), (Nat.choose n i : ℤ) * genLeonardo k (4 * i + r)
      = 3 ^ n * genLeonardo k (2 * n + r) + k * (3 ^ n - 2 ^ n)) ∧
