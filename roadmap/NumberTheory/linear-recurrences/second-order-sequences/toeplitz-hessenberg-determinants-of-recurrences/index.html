    TheoremTrudi's formula as a generating function#●ready to prove

    MetaMathlibExt.toeplitzHessenberg_det_generatingFunction

    Let \(K\) be a field and \(a_0, a_1, a_2, \dots\) a sequence in \(K\) with \(a_0 \ne 0\). For \(n \ge 1\) let \(A_n\) be the \(n \times n\) Toeplitz–Hessenberg matrix whose \((i, j)\) entry is \(a_{i-j+1}\) if \(j \le i + 1\) and \(0\) otherwise. In the ring of formal power series over \(K\), let \(f(x) = \sum_{n \ge 1} \det(A_n) x^n\), \(g(x) = \sum_{i \ge 1} a_i x^i\) and \(h(x) = a_0^{-1} g(-a_0 x)\). Then \(f(x)(1 + h(x)) = -h(x)\), that is, \(f(x) = -h(x)/(1 + h(x))\).

    public theorem_wanted toeplitzHessenberg_det_generatingFunction {K : Type*} [Field K]
    (a : ℕ → K) (ha0 : a 0 ≠ 0) :
    PowerSeries.mk (fun n => if n = 0 then 0 else
        Matrix.det (fun i j : Fin n =>
          if (j : ℕ) ≤ (i : ℕ) + 1 then a ((i : ℕ) + 1 - (j : ℕ)) else 0)) *
      (1 + PowerSeries.C (a 0)⁻¹ *
        PowerSeries.rescale (-a 0) (PowerSeries.mk fun i => if i = 0 then 0 else a i)) =
    -(PowerSeries.C (a 0)⁻¹ *
        PowerSeries.rescale (-a 0) (PowerSeries.mk fun i => if i = 0 then 0 else a i))

    TheoremGenerating function of Toeplitz–Hessenberg determinants with entries \((bk + c)d^k\)#●ready to prove

    MetaMathlibExt.toeplitzHessenberg_det_linear_mul_pow_generatingFunction

    Let \(R\) be a commutative ring and \(a, b, c, d \in R\). Put \(t_0 = a\) and \(t_k = (bk + c) d^k\) for \(k \ge 1\), and for \(n \ge 1\) let \(u_n\) be the determinant of the \(n \times n\) matrix whose \((i, j)\) entry is \(t_{i-j+1}\) if \(j \le i + 1\) and \(0\) otherwise. Then the formal power series \(u(x) = \sum_{n \ge 1} u_n x^n\) over \(R\) satisfies

    \[u(x) \bigl(1 + d(2a - b - c) x + a d^2 (a - c) x^2\bigr) = d x (b + c + a c d x).\]

    Since the second factor on the left has constant term \(1\), this says \(u(x) = dx(b + c + acdx)/(1 + d(2a - b - c)x + ad^2(a - c)x^2)\).

    public theorem_wanted toeplitzHessenberg_det_linear_mul_pow_generatingFunction
    {R : Type*} [CommRing R] (a b c d : R) :
    PowerSeries.mk (fun n => if n = 0 then 0 else
        Matrix.det (fun i j : Fin n =>
          if (j : ℕ) ≤ (i : ℕ) + 1 then
            (if (i : ℕ) + 1 - (j : ℕ) = 0 then a
              else (b * (((i : ℕ) + 1 - (j : ℕ) : ℕ) : R) + c) * d ^ ((i : ℕ) + 1 - (j : ℕ)))
          else 0)) *
      (1 + PowerSeries.C (d * (2 * a - b - c)) * X +
        PowerSeries.C (a * d ^ 2 * (a - c)) * X ^ 2) =
    PowerSeries.C d * X * (PowerSeries.C (b + c) + PowerSeries.C (a * c * d) * X)

    TheoremComposition-sum formulas for \(F_{2n}\), \(F_{3n-1}\) and \(P_{n-1}\)#●ready to prove

    MetaMathlibExt.fib_pell_composition_sums

    Let \(F_k\) be the Fibonacci numbers and \(P_k\) the Pell numbers. For every \(n \ge 1\), with each sum running over all compositions \((c_1, \dots, c_r)\) of \(n\) (tuples of positive integers with \(c_1 + \dots + c_r = n\)), \(F_{2n} = \sum \prod_{i=1}^{r} c_i\), \(F_{3n-1} = 2^{n-1} \sum \prod_{i=1}^{r} \frac{2 c_i - 1}{2^{c_i - 1}}\) and \(P_{n-1} = 2^{n-1} \sum \prod_{i=1}^{r} \frac{c_i - 1}{2^{c_i - 1}}\).

    In the last sum only compositions with no part equal to \(1\) contribute; the source writes it as a multinomial sum over \(2s_1 + 3s_2 + \dots + n s_{n-1} = n\).

    public theorem_wanted fib_pell_composition_sums (n : ℕ) (hn : 1 ≤ n) :
    (Nat.fib (2 * n) : ℚ) =
        ∑ c : Composition n, ∏ i : Fin c.length, (c.blocksFun i : ℚ) ∧
      (Nat.fib (3 * n - 1) : ℚ) = 2 ^ (n - 1) *
        ∑ c : Composition n, ∏ i : Fin c.length,
          (2 * (c.blocksFun i : ℚ) - 1) / 2 ^ (c.blocksFun i - 1) ∧
      (pellNumber (n - 1) : ℚ) = 2 ^ (n - 1) *
        ∑ c : Composition n, ∏ i : Fin c.length,
          ((c.blocksFun i : ℚ) - 1) / 2 ^ (c.blocksFun i - 1)
    def pellNumber : ℕ → ℕ
  | 0 => 0
  | 1 => 1
  | n + 2 => 2 * pellNumber (n + 1) + pellNumber n

    TheoremFibonacci subsequences \(F_{\ell n + m}\) that are Toeplitz–Hessenberg determinants#●ready to prove

    MetaMathlibExt.fib_mul_add_eq_toeplitzHessenberg_det_iff

    For complex numbers \(a, b, c, d\) and \(n \ge 1\), let \(u_n(a, b, c, d)\) be the determinant of the \(n \times n\) matrix whose entry in row \(i\) and column \(j\) is \(a\) if \(j = i + 1\), is \((bp + c) d^p\) with \(p = i - j + 1\) if \(j \le i\), and is \(0\) if \(j > i + 1\). Let \(F_k\) be the Fibonacci numbers and let \(\ell \ge 1\) and \(m \ge 0\) be integers. There are complex numbers \(a, b, c, d\) with \(F_{\ell n + m} = u_n(a, b, c, d)\) for every \(n \ge 1\) if and only if \((\ell, m) = (1, 3)\) or \((\ell, m) = (2, 0)\), that is, exactly for the sequences \(F_{n+3}\) and \(F_{2n}\).

    In the source's terms, \(F_{n+3}\) and \(F_{2n}\) are the only good sequences among the \(F_{\ell n + m}\).

    public theorem_wanted fib_mul_add_eq_toeplitzHessenberg_det_iff (ℓ m : ℕ) (hℓ : 1 ≤ ℓ) :
    (∃ a b c d : ℂ, ∀ n : ℕ, 1 ≤ n →
      (Nat.fib (ℓ * n + m) : ℂ) =
        Matrix.det (fun i j : Fin n =>
          if (j : ℕ) ≤ (i : ℕ) + 1 then
            (if (i : ℕ) + 1 - (j : ℕ) = 0 then a
              else (b * (((i : ℕ) + 1 - (j : ℕ) : ℕ) : ℂ) + c) * d ^ ((i : ℕ) + 1 - (j : ℕ)))
          else 0)) ↔
      (ℓ = 1 ∧ m = 3) ∨ (ℓ = 2 ∧ m = 0)

    TheoremPell and Pell–Lucas numbers as composition sums with \(\sqrt 2\) weights#●ready to prove

    MetaMathlibExt.pell_pellLucas_composition_sums_sqrt_two

    Let \(P_n\) be the Pell numbers and \(Q_n\) the Pell–Lucas numbers (\(Q_0 = Q_1 = 2\), \(Q_{k+2} = 2Q_{k+1} + Q_k\)). For every \(n \ge 1\), with \(c\) running over the compositions of \(n\) (ordered tuples of positive integers with sum \(n\)) and the products running over the parts \(j\) of \(c\), the real number

    \[\sum_c \prod_{j \in c} (j - 1) (\sqrt 2)^{j-2}\]

    equals \(\sqrt 2\, P_{n-1}\) for odd \(n\) and \(Q_{n-1}/2\) for even \(n\) (identity (10)), and

    \[\sum_c \prod_{j \in c} \frac{j + 1}{(\sqrt 2)^j}\]

    equals \(P_{n+1}/\sqrt 2\) for odd \(n\) and \(Q_{n+1}/4\) for even \(n\) (identity (11)).

    In the source both are multinomial sums; the weight of the first vanishes on parts \(1\), so its sum runs over the compositions of \(n\) without parts \(1\).

    public theorem_wanted pell_pellLucas_composition_sums_sqrt_two (n : ℕ) (hn : 1 ≤ n) :
    ∑ c : Composition n, ∏ i : Fin c.length,
        ((c.blocksFun i : ℝ) - 1) * Real.sqrt 2 ^ (c.blocksFun i - 2) =
      (if Odd n then Real.sqrt 2 * (pellNumber (n - 1) : ℝ)
        else (pellLucas (n - 1) : ℝ) / 2) ∧
    ∑ c : Composition n, ∏ i : Fin c.length,
        ((c.blocksFun i : ℝ) + 1) / Real.sqrt 2 ^ c.blocksFun i =
      (if Odd n then (pellNumber (n + 1) : ℝ) / Real.sqrt 2
        else (pellLucas (n + 1) : ℝ) / 4)

    For numbers \(a_0, a_1, \dots, a_n\), let \(\det(a_0; a_1, \dots, a_n)\) be the determinant of the \(n \times n\) matrix whose \((i, j)\) entry is \(a_{i-j+1}\) if \(j \le i + 1\) and \(0\) otherwise, so that \(a_0\) fills the superdiagonal.
