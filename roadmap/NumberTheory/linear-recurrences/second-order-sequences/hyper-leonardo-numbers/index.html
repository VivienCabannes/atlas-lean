    Hyper-Leonardo numbers

    DefinitionHyper-Leonardo numbers#✓fully proved

    MetaMathlibExt.hyperLeonardo

    Let \(Le_n\) be the Leonardo numbers, defined by \(Le_0 = Le_1 = 1\) and \(Le_{n+2} = Le_{n+1} + Le_n + 1\). The hyper-Leonardo numbers are the integers \(Le^{(r)}_n\), for \(r, n \ge 0\), defined by \(Le^{(0)}_n = Le_n\) and \(Le^{(r+1)}_n = \sum_{k=0}^{n} Le^{(r)}_k\).

    def hyperLeonardo : ℕ → ℕ → ℤ
  | 0, n => genLeonardo 1 n
  | r + 1, n => ∑ k ∈ Finset.range (n + 1), hyperLeonardo r k
    public def genLeonardo (k : ℤ) : ℕ → ℤ
  | 0 => 1
  | 1 => 1
  | n + 2 => genLeonardo k (n + 1) + genLeonardo k n + k

    TheoremGenerating function of the Leonardo numbers#●ready to prove

    MetaMathlibExt.leonardo_generatingFunction

    Let \(Le_n\) be the Leonardo numbers (\(Le_0 = Le_1 = 1\) and \(Le_{n+2} = Le_{n+1} + Le_n + 1\)), and let \(L(t) = \sum_{n \ge 0} Le_n t^n\) in the ring \(\mathbb{Z}[[t]]\) of formal power series.       PowerSeries.mk (fun n => genLeonardo 1 n) * ((1 - X - X ^ 2) * (1 - X)) =
        2 * (1 - X) - (1 - X - X ^ 2)
