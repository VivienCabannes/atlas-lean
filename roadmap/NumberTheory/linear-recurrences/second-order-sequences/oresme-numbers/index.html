    Let \(O_m = m/2^m\) denote the Oresme numbers. For every natural number \(n\), \(\sum_{k=0}^{n} O_k O_{n-k} = \frac{(n+1) n (n-1)}{6 \cdot 2^n}\).

    public theorem_wanted oresme_convolution_self (n : ℕ) :
    ∑ k ∈ Finset.range (n + 1), ((k : ℚ) / 2 ^ k) * (((n - k : ℕ) : ℚ) / 2 ^ (n - k)) =
      ((n : ℚ) + 1) * n * ((n : ℚ) - 1) / (6 * 2 ^ n)
