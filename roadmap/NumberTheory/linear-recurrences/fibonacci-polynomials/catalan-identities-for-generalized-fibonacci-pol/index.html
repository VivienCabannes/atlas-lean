    TheoremExplicit formula for Fibonacci-type generalized Fibonacci polynomials#●ready to prove

    MetaMathlibExt.gfp_fib_eq_sum_choose

    Let \(d\) and \(g\) be polynomials with integer coefficients, and let \(F_n\) be the generalized Fibonacci polynomials defined by \(F_0 = 0\), \(F_1 = 1\) and \(F_{n+2} = d F_{n+1} + g F_n\). Then for every \(n \ge 1\),

    \[F_n = \sum_{i=0}^{\lfloor (n-1)/2 \rfloor} \binom{n-i-1}{i} d^{n-2i-1} g^i.\]

    The source quotes this formula from Flórez and Saunders.

    public theorem_wanted gfp_fib_eq_sum_choose (d g : ℤ[X]) {n : ℕ} (hn : 1 ≤ n) :
    generalizedFibonacciPolynomial 0 1 d g n =
      ∑ i ∈ range ((n - 1) / 2 + 1), ((n - i - 1).choose i : ℤ[X]) * d ^ (n - 2 * i - 1) * g ^ i
    noncomputable def generalizedFibonacciPolynomial
    (p0 p1 d g : Polynomial ℤ) : ℕ → Polynomial ℤ
  | 0 => p0
  | 1 => p1
  | (n + 2) =>
    d * generalizedFibonacciPolynomial p0 p1 d g (n + 1) +
      g * generalizedFibonacciPolynomial p0 p1 d g n

    TheoremExplicit formula for Lucas-type generalized Fibonacci polynomials#●ready to prove

    MetaMathlibExt.gfp_lucas_eq_sum_choose

    Let \(\alpha\) and \(p_0\) be integers with \(\alpha p_0 = 2\), let \(p_1\) and \(g\) be polynomials with integer coefficients, and put \(d = \alpha p_1\). Let \(L_n\) be the generalized Fibonacci polynomials defined by \(L_0 = p_0\), \(L_1 = p_1\) and \(L_{n+2} = d L_{n+1} + g L_n\). Then for every \(n \ge 1\), writing \(c_i = \lfloor n \binom{n-i}{i} / (n-i) \rfloor\),

    \[\alpha L_n = \sum_{i=0}^{\lfloor n/2 \rfloor} c_i \, d^{n-2i} g^i.\]

    The quotient \(n \binom{n-i}{i} / (n-i)\) is always an integer, so the floor does not change it; the source writes the coefficient as \(\frac{n}{n-i} \binom{n-i}{i}\) and quotes the formula from Flórez and Saunders.

      ∑ i ∈ range (n / 2 + 1),

    TheoremAlternating sum of shifted binomial coefficients#●ready to prove

    MetaMathlibExt.alternating_sum_choose_mul_choose_sub

    Let \(\ell\), \(n\), \(j\) and \(s\) be natural numbers with \(1 \le \ell \le n\), \(j \ge 1\) and \(\ell j + s \le n\). Then

    \[\sum_{i=0}^{\ell} (-1)^i \binom{\ell}{i} \binom{n-i}{\ell j+s} = \binom{n-\ell}{\ell(j-1)+s}.\]

    The paper states this for \(\lfloor (1-s)/\ell \rfloor \le j \le \lfloor (n-s)/\ell \rfloor\); only \(j \ge 1\) is stated here, since for \(j \le 0\) the right side can have a negative lower index. For \(j \ge 1\) the bound \(j \le \lfloor (n-s)/\ell \rfloor\) is the condition \(\ell j + s \le n\).

    public theorem_wanted alternating_sum_choose_mul_choose_sub {ℓ n j s : ℕ} (hℓ : 1 ≤ ℓ)
    (hℓn : ℓ ≤ n) (hj : 1 ≤ j) (hjn : ℓ * j + s ≤ n) :
    ∑ i ∈ range (ℓ + 1), (ℓ.choose i : ℤ) * (-1) ^ i * ((n - i).choose (ℓ * j + s) : ℤ) =
      ((n - ℓ).choose (ℓ * (j - 1) + s) : ℤ)

    TheoremGenerating function of the floor-exponent binomial sums#●ready to prove

    MetaMathlibExt.floorPowBinomialSum_generatingFunction

    Let \(R\) be a commutative ring, \(t \in R\) and \(\ell \ge 1\) an integer, and for \(n \ge 0\) let \(T_\ell(n; t) = \sum_{i=0}^{n} \binom{n}{i} t^{\lfloor i/\ell \rfloor}\). Then in the ring \(R[[x]]\) of formal power series,

    \[\Big(\sum_{n \ge 0} T_\ell(n; t)\, x^n\Big) \big((1-x)^\ell - t x^\ell\big) = \sum_{k=0}^{\ell-1} \Big(\sum_{i=0}^{k} (-1)^i \binom{i+\ell-k-1}{i}\Big) x^k.\]

    So the generating function of the \(T_\ell(n; t)\) is this polynomial divided by the series \((1-x)^\ell - t x^\ell\), which is invertible since its constant term is \(1\).

        ((1 - PowerSeries.X) ^ ℓ - PowerSeries.C t * PowerSeries.X ^ ℓ) =
      ∑ k ∈ range ℓ, PowerSeries.C (∑ i ∈ range (k + 1),
        (-1 : R) ^ i * ((i + ℓ - k - 1).choose i : R)) * PowerSeries.X ^ k

    MetaMathlibExt.gfp_fib_binomial_sum_eq_integral

    Let \(d\) and \(g\) be polynomials with integer coefficients, let \(F_m\) be the generalized Fibonacci polynomials with \(F_0 = 0\), \(F_1 = 1\) and \(F_{m+2} = d F_{m+1} + g F_m\), and let \(x\) be a real number with \(d(x)^2 + 4 g(x) \ge 0\) and \(g(x) \ne 0\). Let \(\Phi \colon \mathbb{Z} \to \mathbb{R}\) satisfy \(\Phi(m) = F_m(x)\) for \(m \ge 0\) and \(\Phi(m+2) = d(x) \Phi(m+1) + g(x) \Phi(m)\) for every integer \(m\). Then for every real \(k \ge 2\) and every integer \(n \ge 1\),

    \[\sum_{i=0}^{n} (-1)^{n+1} \binom{n}{i} (k+1)^i (k-1)^{n-i} g(x)^i \, \Phi(n-2i) = n \int_{-k}^{k} \Big(y \sqrt{d(x)^2 + 4 g(x)} + d(x)\Big)^{n-1} dy.\]
