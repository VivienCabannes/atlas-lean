    MetaMathlibExt.rFibonacciPolynomial

    Let \(R\) be a commutative semiring, let \(r\) be a natural number and let \(x, y \in R\). The \(r\)-Fibonacci polynomials \(U^{(r)}_n(x, y) \in R\), \(n \ge 0\), are defined by \(U^{(r)}_0 = 0\), \(U^{(r)}_k = x^{k-1}\) for \(1 \le k \le r\), and \(U^{(r)}_{n+1} = x \, U^{(r)}_n + y \, U^{(r)}_{n-r}\) for \(n \ge r\).

    These are the initial values and recurrence displayed for \(\xi_n = m^{n-1} U_n\) in the paper, at \(m = 1\).

    public def rFibonacciPolynomial {R : Type*} [CommSemiring R] (r : ℕ) (x y : R) : ℕ → R
  | 0 => 0
  | n + 1 =>
    if n < r then x ^ n
    else x * rFibonacciPolynomial r x y n + y * rFibonacciPolynomial r x y (n - r)
termination_by n => n
decreasing_by all_goals omega

    MetaMathlibExt.rLucasPolynomial

    Let \(R\) be a commutative semiring, let \(r\) and \(s\) be natural numbers and let \(x, y \in R\). The \(r\)-Lucas polynomials of type \(s\) are the sequence \(V_n = V^{(r,s)}_n(x, y)\), \(n \ge 0\), of elements of \(R\) given by \(V_0 = s + 1\), \(V_k = x^k\) for \(1 \le k \le r\), and \(V_{n+1} = x V_n + y V_{n-r}\) for \(n \ge r\).

    The paper takes \(1 \le s \le r\); the definition makes sense for every natural number \(s\).

  | 0 => (s : R) + 1
