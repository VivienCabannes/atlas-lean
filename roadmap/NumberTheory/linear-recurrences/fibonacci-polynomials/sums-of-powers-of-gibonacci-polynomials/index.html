    MetaMathlibExt.gibonacciPoly_mul_sub_sq

    Let \(f_i\) and \(\ell_i\) be the Fibonacci and Lucas polynomials in \(\mathbb{Z}[x]\), defined by \(f_0 = 0\), \(f_1 = 1\), \(\ell_0 = 2\), \(\ell_1 = x\) and \(g_{i+2} = x g_{i+1} + g_i\) for \(g = f, \ell\). For all natural numbers \(k \le n\),

    \[ f_{n+k} f_{n-k} - f_n^2 = (-1)^{n+k+1} f_k^2 \quad\text{and}\quad \ell_{n+k} \ell_{n-k} - \ell_n^2 = (-1)^{n+k} (x^2 + 4) f_k^2 \]

    in \(\mathbb{Z}[x]\).

    The source quotes this lemma from Koshy.

    public theorem_wanted gibonacciPoly_mul_sub_sq {n k : ℕ} (hk : k ≤ n) :
    𝔣 (n + k) * 𝔣 (n - k) - 𝔣 n ^ 2 = (-1) ^ (n + k + 1) * 𝔣 k ^ 2 ∧
      𝔩 (n + k) * 𝔩 (n - k) - 𝔩 n ^ 2 = (-1) ^ (n + k) * (X ^ 2 + 4) * 𝔣 k ^ 2

    MetaMathlibExt.tsum_inv_pow_gibonacciPoly_sub_odd

    Let \(x > 0\) be real, and let \(g_n\) denote either the Fibonacci polynomials, given by \(g_0 = 0\) and \(g_1 = 1\), or the Lucas polynomials, given by \(g_0 = 2\) and \(g_1 = x\), both satisfying \(g_{n+2} = x g_{n+1} + g_n\) and evaluated at \(x\). Let \(k\) be an odd natural number and \(\lambda\) a positive integer. Then

    \[\sum_{n=0}^{\infty} \left(\frac{1}{g_{2n+1}^{\lambda}} - \frac{1}{g_{2n+1+2k}^{\lambda}}\right) = \sum_{r=1}^{k} \frac{1}{g_{2r-1}^{\lambda}}.\]

    The source quotes this lemma from Koshy as the sum over \(n \ge (k + 1)/2\) of \(1/g_{2n-k}^{\lambda} - 1/g_{2n+k}^{\lambda}\); here the summation index is shifted to start at \(0\).

    public theorem_wanted tsum_inv_pow_gibonacciPoly_sub_odd {x : ℝ} (hx : 0 < x)
    {g : ℕ → ℤ[X]} (hg : g = 𝔣 ∨ g = 𝔩) {k lam : ℕ} (hk : Odd k) (hlam : 0 < lam) :
    ∑' n : ℕ, (1 / aeval x (g (2 * n + 1)) ^ lam - 1 / aeval x (g (2 * n + 1 + 2 * k)) ^ lam) =

    TheoremEven powers of Fibonacci polynomials at \(n \pm k\)#●ready to prove

    MetaMathlibExt.fibPoly_pow_even_sub

    Let \(f_i \in \mathbb{Z}[x]\) be the Fibonacci polynomials, defined by \(f_0 = 0\), \(f_1 = 1\) and \(f_{i+2} = x f_{i+1} + f_i\). For all natural numbers \(k \le n\) and every natural number \(m\),

    \[ (x^2 + 4)^{m-1} \bigl(f_{n+k}^{2m} - f_{n-k}^{2m}\bigr) = \sum_{j=0}^{m-1} \binom{2m}{j} (-1)^{(n+k+1)j} f_{2k(m-j)} f_{2n(m-j)} \]

    in \(\mathbb{Z}[x]\), where for \(m = 0\) the exponent \(m - 1\) is read as \(0\) (both sides are then \(0\)).

    public theorem_wanted fibPoly_pow_even_sub {n k : ℕ} (hk : k ≤ n) (m : ℕ) :
    (X ^ 2 + 4) ^ (m - 1) * (𝔣 (n + k) ^ (2 * m) - 𝔣 (n - k) ^ (2 * m)) =
      ∑ j ∈ Finset.range m, ((2 * m).choose j : ℤ[X]) * (-1) ^ ((n + k + 1) * j) *
        𝔣 (2 * k * (m - j)) * 𝔣 (2 * n * (m - j))
