    DefinitionEuler numbers#✓fully proved

    MathlibExt.NumberTheory.FiniteSumsFibLucasWanted.eulerSecNumber

    For a natural number \(n\), the Euler number \(E_n \in \mathbb{Q}\) is \(0\) when \(n\) is odd, and when \(n = 2k\) is even it is the even-index Euler number \(E_{2k}\), where \(E_0 = 1\) and \(\sum_{i=0}^{k} \binom{2k}{2i} E_{2i} = 0\) for \(k \ge 1\). The first values are \(E_0 = 1\), \(E_2 = -1\), \(E_4 = 5\).

    These are the Euler (secant) numbers, with exponential generating function \(2/(e^t + e^{-t})\).

    DefinitionGenocchi–Lucas coefficients#✓fully proved

    MathlibExt.NumberTheory.FiniteSumsFibLucasWanted.genLucasCoeff

    For a natural number \(n\), the Genocchi–Lucas coefficient is the real number

    \[ c_n = \sum_{k=0}^{n} \sqrt{5}^{\,k} \binom{n}{k} G_k \frac{L_{n-k+1}}{n-k+1} + 2 \sqrt{5}^{\,n+1} \frac{G_{n+1}}{n+1}, \]

    where \(G_k\) are the Genocchi numbers and \(L_k\) the Lucas numbers.

    These are the inner coefficients of the corrected Theorem 11 of Bensaci, Boumahdi and Khaldi, "Finite Sums Involving Fibonacci and Lucas Numbers"; the paper's printed coefficient omits the last term.

    noncomputable def genLucasCoeff (n : ℕ) : ℝ :=
  (∑ k ∈ Finset.range (n + 1), (Real.sqrt 5) ^ k *
      (Nat.choose n k : ℝ) * (genocchiNumber k : ℝ) *
      ((lucasNumber (n - k + 1) : ℝ) / (n - k + 1 : ℕ))) +
    2 * (Real.sqrt 5) ^ (n + 1) *
      ((genocchiNumber (n + 1) : ℝ) / (n + 1 : ℕ))
    public noncomputable def genocchiNumber (n : ℕ) : ℚ :=
