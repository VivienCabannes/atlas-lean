    Perrin numbers that are Perrin squares

    DefinitionPerrin sequence at negative indices#✓fully proved

    MetaMathlibExt.perrinNeg

    The Perrin sequence \(R_k\), given by \(R_0 = 3\), \(R_1 = 0\), \(R_2 = 2\) and \(R_{k+3} = R_{k+1} + R_k\), extends uniquely to all integers \(k\) by running the recurrence backward. This defines the integers \(R_{-n}\) for natural numbers \(n\): \(R_0 = 3\), \(R_{-1} = -1\), \(R_{-2} = 1\) and \(R_{-(n+3)} = R_{-n} - R_{-(n+2)}\) for every \(n \ge 0\).

    public def perrinNeg : ℕ → ℤ
  | 0 => 3
  | 1 => -1
  | 2 => 1
  | n + 3 => perrinNeg n - perrinNeg (n + 2)

    MetaMathlibExt.one_div_partialQuotient_bound_lt_abs_sub

    Let \(x\) be an irrational real number with continued fraction expansion \([a_0; a_1, a_2, \dots]\), where \(a_0 = \lfloor x \rfloor\), and with convergents \(p_k / q_k\). Let \(M \ge 1\) and \(N \ge 0\) be integers with \(q_N \le M < q_{N+1}\), and let \(a\) be a real number with \(a \ge a_j\) for every \(0 \le j \le N + 1\). Then

    \[\left|x - \frac{p}{q}\right| > \frac{1}{(a + 2) q^2}\]

    for all integers \(p\) and \(q\) with \(0 < q < M\).

    The source takes \(a\) to be the maximum of \(a_0, \dots, a_{N+1}\); since the bound weakens as \(a\) grows, the two forms are equivalent.

    public theorem_wanted one_div_partialQuotient_bound_lt_abs_sub {x : ℝ} (hx : Irrational x)
