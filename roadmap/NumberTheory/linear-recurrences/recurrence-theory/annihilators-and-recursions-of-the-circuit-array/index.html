    Annihilators and recursions of the circuit array

    DefinitionAnnihilator of a sequence#✓fully proved

    MetaMathlibExt.AnnihilatesSeq

    Let \(K\) be a semiring, \(p = \sum_i a_i X^i \in K[X]\) and \(G \colon \mathbb{N} \to K\) a sequence, and let \(E\) be the translation operator \(E(G_s) = G_{s+1}\). The operator \(p(E)\) annihilates \(G\) when \(\sum_i a_i G_{s+i} = 0\) for every \(s \ge 0\).

    def AnnihilatesSeq {K : Type*} [Semiring K] (p : K[X]) (G : ℕ → K) : Prop :=
  ∀ s : ℕ, p.sum (fun i a => a * G (s + i)) = 0

    MetaMathlibExt.annihilatesSeq_sum_prod_and_mul

    DefinitionDelta-wye resistance function#✓fully proved

    MetaMathlibExt.circuitDelta

    For elements \(x\), \(y\), \(z\) of a field \(K\), the delta-wye resistance function is \(\Delta(x, y, z) = \frac{xy}{x + y + z}\).

    Division follows the convention \(a / 0 = 0\), so \(\Delta(x, y, z) = 0\) when \(x + y + z = 0\).

    def circuitDelta {K : Type*} [Field K] (x y z : K) : K :=
  x * y / (x + y + z)

    DefinitionThe Y-Δ resistance function#✓fully proved

    MetaMathlibExt.circuitY

    For elements \(a\), \(b\), \(c\) of a field \(K\), the \(Y\)-\(\Delta\) resistance function is \(Y(a, b, c) = (ab + bc + ca)/a\).

    When \(a = 0\) the value is \(0\), by the convention \(x/0 = 0\).

    def circuitY {K : Type*} [Field K] (a b c : K) : K :=
  (a * b + b * c + c * a) / a

    MetaMathlibExt.circuitBaseEdge

    Let \(K\) be a field. For a triangle with left, right and base resistances \(L\), \(R\), \(B\) in \(K\), its top arm is \(\Delta(L, R, B)\), its bottom-right arm is \(\Delta(R, B, L)\) and its bottom-left arm is \(\Delta(B, L, R)\), where \(\Delta(x, y, z) = xy/(x + y + z)\).
