    TheoremDivisibility runs have logarithmic length#●ready to prove

    MetaMathlibExt.divRun_length_le_log

    There is a real constant \(C > 0\) such that for every natural number \(B \ge 2\), all integers \(x, y, a, b, c \in [-B, B]\) with \((x, y) \ne (0, 0)\) and \((a, b, c) \ne (0, 0, 0)\), and every natural number \(L\) such that \((x, y, a, b, c)\) has a divisibility run of length at least \(L\), we have \(L \le C \log B\). Here a divisibility run of length at least \(L\) means that for every \(i < L\) the Gibonacci number \(P_i\) with \(P_0 = x\), \(P_1 = y\) is nonzero and divides the generalized Tribonacci number \(Q_i\) with \(Q_0 = a\), \(Q_1 = b\), \(Q_2 = c\).

    In the paper's notation this is \(E(B) \le C \log B\), where \(E(B)\) is the maximal run length over these configurations.
