    Kronecker symbol and quadratic characters

    DefinitionFundamental discriminant#✓fully proved

    MetaMathlibExt.IsFundamentalDiscriminant

    An integer \(D\) is a fundamental discriminant if either \(D\) is squarefree and \(D \equiv 1 \pmod 4\), or \(D = 4m\) for some squarefree integer \(m\) with \(m \equiv 2 \pmod 4\) or \(m \equiv 3 \pmod 4\).

    With this definition \(D = 1\) is a fundamental discriminant and \(D = 0\) is not.

    public def IsFundamentalDiscriminant (D : ℤ) : Prop :=
  (Squarefree D ∧ D % 4 = 1) ∨
    ∃ m : ℤ, D = 4 * m ∧ Squarefree m ∧ (m % 4 = 2 ∨ m % 4 = 3)

    DefinitionKronecker symbol at two#✓fully proved

    MetaMathlibExt.kroneckerAtTwo

    For an integer \(D\), the Kronecker symbol of \(D\) at \(2\) is \(0\) if \(D\) is even, \(1\) if \(D \equiv \pm 1 \pmod 8\), and \(-1\) if \(D \equiv \pm 3 \pmod 8\).

    public def kroneckerAtTwo (D : ℤ) : ℤ :=
  if D % 2 = 0 then 0
  else if D % 8 = 1 ∨ D % 8 = 7 then 1
  else -1

    DefinitionKronecker symbol at a prime#✓fully proved

    MetaMathlibExt.kroneckerAtPrime

    For an integer \(D\) and a natural number \(p\), the Kronecker symbol of \(D\) at \(p\) is the Kronecker symbol of \(D\) at two if \(p = 2\), the Legendre symbol \(\left(\frac{D}{p}\right)\) if \(p\) is an odd prime, and \(0\) if \(p\) is not prime.

    public def kroneckerAtPrime (D : ℤ) (p : ℕ) : ℤ :=
  if p = 2 then kroneckerAtTwo D
  else if h : p.Prime then @legendreSym p (Fact.mk h) D
  else 0

    DefinitionKronecker symbol#✓fully proved

    MetaMathlibExt.kroneckerSym

    For an integer \(D\) and a natural number \(n\), the Kronecker symbol \(\left(\frac{D}{n}\right)\) is defined as follows. If \(n = 0\), it is \(1\) when \(D = \pm 1\) and \(0\) otherwise. If \(n \ge 1\) and \(n = p_1 p_2 \cdots p_k\) is the factorization of \(n\) into primes, listed with multiplicity, it is the product of the Kronecker symbols of \(D\) at the primes \(p_1, \ldots, p_k\) (the empty product \(1\) when \(n = 1\)).

    public def kroneckerSym (D : ℤ) (n : ℕ) : ℤ :=
  if n = 0 then if D.natAbs = 1 then 1 else 0
  else (n.primeFactorsList.map (kroneckerAtPrime D)).prod
    public def kroneckerAtPrime (D : ℤ) (p : ℕ) : ℤ :=
  if p = 2 then kroneckerAtTwo D
  else if h : p.Prime then @legendreSym p (Fact.mk h) D
  else 0

    TheoremQuadratic Dirichlet character of a fundamental discriminant#✓fully proved

    MetaMathlibExt.quadraticDirichletCharacter

    Let \(D\) be a fundamental discriminant. Then there is a unique integer-valued Dirichlet character \(\chi\) modulo \(|D|\) such that \(\chi(n \bmod |D|) = \left(\frac{D}{n}\right)\) for every natural number \(n\), where \(\left(\frac{D}{n}\right)\) is the Kronecker symbol.

    theorem quadraticDirichletCharacter (D : ℤ)
    (hD : IsFundamentalDiscriminant D) :
    ∃! χ : DirichletCharacter ℤ D.natAbs,
      ∀ n : ℕ, χ (n : ZMod D.natAbs) = kroneckerSym D n

    TheoremKronecker symbol at odd numbers for integers congruent to 3 mod 4#✓fully proved

    MetaMathlibExt.chi4_mul_jacobiSym_natAbs_eq_kroneckerSym_of_odd_of_three_mod_four

    Let \(\chi_4\) be the nontrivial Dirichlet character modulo \(4\), so \(\chi_4(n) = 1\) for \(n \equiv 1 \pmod 4\) and \(\chi_4(n) = -1\) for \(n \equiv 3 \pmod 4\). Let \(D\) be an integer with \(D \equiv 3 \pmod 4\) and let \(p\) be an odd natural number. Then \(\chi_4(p) \cdot \left(\frac{p}{|D|}\right) = \left(\frac{D}{p}\right)\), where \(\left(\frac{p}{|D|}\right)\) is the Jacobi symbol and \(\left(\frac{D}{p}\right)\) is the Kronecker symbol.

    For \(D > 0\) the factor \(\chi_4(p)\) is the sign from quadratic reciprocity; for \(D < 0\) it is the value \(\left(\frac{-1}{p}\right) = \chi_4(p)\).

    public theorem chi4_mul_jacobiSym_natAbs_eq_kroneckerSym_of_odd_of_three_mod_four
    (D : ℤ) (p : ℕ) (hp_odd : Odd p) (h3 : D % 4 = 3) :
    (ZMod.χ₄ p : ℤ) * jacobiSym (p : ℤ) D.natAbs = kroneckerSym D p
