    MetaMathlibExt.IsKDescendant

    Let \(R\) be a digraph on \(\mathbb{Z}\), let \(k \in \mathbb{N}\) and let \(m, n \in \mathbb{Z}\). Then \(n\) is a \(k\)-descendant of \(m\) in \(R\) when there is a directed walk of exactly \(k\) edges from \(m\) to \(n\), that is, integers \(m = x_0, x_1, \dots, x_k = n\) such that \(R\) has an edge \(x_{i-1} \to x_i\) for every \(1 \le i \le k\).

    def IsKDescendant (R : ℤ → ℤ → Prop) : ℕ → ℤ → ℤ → Prop
  | 0, m, n => n = m
  | k + 1, m, n => ∃ x, IsKDescendant R k m x ∧ R x n
