    DefinitionLeast absolute inverse#✓fully proved

    MathlibExt.NumberTheory.ModInverseSwitchingWanted.IsLeastAbsInverse

    For integers \(x\) and \(a\) and a natural number \(n\), \(x\) is the least absolute inverse of \(a\) modulo \(n\) when \(xa \equiv 1 \pmod{n}\) and \(-n < 2x \le n\), that is, when \(x\) is an inverse of \(a\) modulo \(n\) in the half-open interval \(-n/2 < x \le n/2\).

    For even \(n\) the endpoint \(n/2\) is included and \(-n/2\) is excluded; this is also the choice the Euclidean recurrence produces.

    def IsLeastAbsInverse (x a : ℤ) (n : ℕ) : Prop :=
  x * a ≡ 1 [ZMOD (n : ℤ)] ∧ -(n : ℤ) < 2 * x ∧ 2 * x ≤ (n : ℤ)

    DefinitionEuclidean switching data#✓fully proved

    MathlibExt.NumberTheory.ModInverseSwitchingWanted.IsEuclidSwitchSeq

    A natural number \(N\), a sequence \(r_0, r_1, \dots\) of natural numbers and a sequence \(s_0, s_1, \dots\) of integers form Euclidean switching data when \(N \ge 1\); \(r_0 > r_1 > \cdots > r_{N+1} = 1\), with \(r_0, \dots, r_{N+1}\) all positive; for each \(i = 1, \dots, N\) there is a positive integer \(q_i\) with \(r_{i-1} = q_i r_i + r_{i+1}\); \(s_{N+1} = 1\); and \(s_{i+1} r_{i-1} + s_i r_i = 1\) for each \(i = 1, \dots, N\).

    These are the remainders \(r_i\) of the Euclidean algorithm on \((r_0, r_1)\) and the inverses \(s_i\) of \(r_i\) modulo \(r_{i-1}\) in §3 of Konstantogiannis, "The Euclidean Algorithm as a Sequence of Modular Inverse Switching Formulas" (Equations (4), (5) and (6)).

    def IsEuclidSwitchSeq (r : ℕ → ℕ) (s : ℕ → ℤ) (N : ℕ) : Prop :=
  0 < N ∧
    (∀ i : ℕ, i ≤ N + 1 → 0 < r i) ∧
    (∀ i : ℕ, i ≤ N → r (i + 1) < r i) ∧
    r (N + 1) = 1 ∧
    (∀ i : ℕ, 1 ≤ i → i ≤ N → ∃ q : ℕ, 0 < q ∧
      r (i - 1) = q * r i + r (i + 1)) ∧
    s (N + 1) = 1 ∧
    ∀ i : ℕ, 1 ≤ i → i ≤ N →
      s (i + 1) * (r (i - 1) : ℤ) + s i * (r i : ℤ) = 1

    Let \(m\) and \(n\) be coprime positive integers, and let \(x\) and \(y\) be integers with \(xm + yn = 1\). Then \(xm \equiv 1 \pmod{n}\) and \(yn \equiv 1 \pmod{m}\); that is, \(x\) is an inverse of \(m\) modulo \(n\) and \(y\) is an inverse of \(n\) modulo \(m\).
