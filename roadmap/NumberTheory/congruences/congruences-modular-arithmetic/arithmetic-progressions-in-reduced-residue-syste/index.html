    Arithmetic progressions in reduced residue systems

    DefinitionThe reduced residue system \(R_m(n)\)#✓fully proved

    MetaMathlibExt.reducedResidueWindow

    For an integer \(m\) and a natural number \(n\), the reduced residue system \(R_m(n)\) modulo \(n\) is the finite set \(R_m(n) = \{a \in \mathbb{Z} : m + 1 \le a \le m + n,\ \gcd(a, n) = 1\}\).

    public def reducedResidueWindow (m : ℤ) (n : ℕ) : Finset ℤ :=
  (Finset.Icc (m + 1) (m + n)).filter fun a => Int.gcd a n = 1

    DefinitionLongest progression with a given common difference#✓fully proved

    MetaMathlibExt.longestAPLengthWithDiff

    For an integer \(m\) and natural numbers \(n\) and \(d\), let \(R_m(n)\) be the set of integers \(a\) with \(m + 1 \le a \le m + n\) and \(\gcd(a, n) = 1\). Then \(f_m(d, n)\) is the supremum of the natural numbers \(s\) for which some integer \(b\) has \(b + i d \in R_m(n)\) for every natural number \(i < s\). For \(d > 0\) every such \(s\) is at most \(n\), so \(f_m(d, n)\) is the length of the longest arithmetic progression with common difference \(d\) contained in \(R_m(n)\); the paper uses it only for \(d > 0\), and for \(d = 0\) the definition gives \(0\).

    public noncomputable def longestAPLengthWithDiff (m : ℤ) (n d : ℕ) : ℕ :=
  sSup {s : ℕ | ∃ b : ℤ, ∀ i < s, b + i * d ∈ reducedResidueWindow m n}
    public def reducedResidueWindow (m : ℤ) (n : ℕ) : Finset ℤ :=
  (Finset.Icc (m + 1) (m + n)).filter fun a => Int.gcd a n = 1

    DefinitionLength of the longest arithmetic progression in a reduced residue system#✓fully proved

    MetaMathlibExt.longestAPLength

    For an integer \(m\) and a natural number \(n\), let \(R_m(n)\) be the reduced residue system of the integers \(a\) with \(m + 1 \le a \le m + n\) and \(\gcd(a, n) = 1\). Then \(f_m(n)\) is the largest natural number \(s\) for which there are an integer \(b\) and a positive integer \(d\) such that \(b, b + d, \dots, b + (s - 1)d\) all lie in \(R_m(n)\). So it is the length of the longest arithmetic progression with positive common difference contained in \(R_m(n)\), where a single term counts as a progression of length \(1\), and \(f_m(n) = 0\) when \(R_m(n)\) is empty.

    public noncomputable def longestAPLength (m : ℤ) (n : ℕ) : ℕ :=
  sSup {s : ℕ | ∃ b : ℤ, ∃ d : ℕ, 0 < d ∧ ∀ i < s, b + i * d ∈ reducedResidueWindow m n}
    public def reducedResidueWindow (m : ℤ) (n : ℕ) : Finset ℤ :=
  (Finset.Icc (m + 1) (m + n)).filter fun a => Int.gcd a n = 1

    DefinitionLongest progression in the absolute least reduced residues#✓fully proved

    MetaMathlibExt.absLeastAPLength

    For a natural number \(n\), let \(R(n)\) be the set of integers \(a\) with \(1 - \lceil n/2 \rceil \le a \le n - \lceil n/2 \rceil\) and \(\gcd(a, n) = 1\), the system of absolute least reduced residues modulo \(n\). Then \(g(n)\) is the largest \(s \ge 0\) for which there are an integer \(b\) and a positive integer \(d\) with \(b + i d \in R(n)\) for every \(0 \le i < s\): the length of the longest arithmetic progression with positive common difference contained in \(R(n)\). Equivalently, \(g(n) = f_{-\lceil n/2 \rceil}(n)\), where \(f_m(n)\) is the same length for the set \(R_m(n)\) of integers \(a\) with \(m + 1 \le a \le m + n\) and \(\gcd(a, n) = 1\).

    public noncomputable def absLeastAPLength (n : ℕ) : ℕ :=
  longestAPLength (-⌈(n : ℚ) / 2⌉) n
    public noncomputable def longestAPLength (m : ℤ) (n : ℕ) : ℕ :=
  sSup {s : ℕ | ∃ b : ℤ, ∃ d : ℕ, 0 < d ∧ ∀ i < s, b + i * d ∈ reducedResidueWindow m n}

    TheoremThe reduced residue system \(R_{-3}(5)\)#✓fully proved

    MetaMathlibExt.mem_reducedResidueWindow_neg_three_five

    The reduced residue system \(R_{-3}(5)\) of the integers \(a\) with \(-2 \le a \le 2\) and \(\gcd(a, 5) = 1\) is \(\{-2, -1, 1, 2\}\): an integer \(a\) lies in \(R_{-3}(5)\) if and only if \(a\) is one of \(-2\), \(-1\), \(1\), \(2\).

    Since \(\lceil 5/2 \rceil = 3\), this is the system \(R(5) = R_{-\lceil 5/2 \rceil}(5)\) of absolute least reduced residues modulo \(5\).

    public theorem mem_reducedResidueWindow_neg_three_five (a : ℤ) :
    a ∈ reducedResidueWindow (-3) 5 ↔ a = -2 ∨ a = -1 ∨ a = 1 ∨ a = 2
