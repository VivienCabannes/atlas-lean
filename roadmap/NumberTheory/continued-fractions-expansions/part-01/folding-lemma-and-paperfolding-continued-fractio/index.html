    Folding lemma and paperfolding continued fractions

    DefinitionValue of a finite continued fraction#✓fully proved

    MetaMathlibExt.finiteContFrac

    For a finite list \(a_0, a_1, \dots, a_t\) of integers (possibly zero or negative), the value \([a_0; a_1, \dots, a_t]\) is the rational number \(a_0 + 1/(a_1 + 1/(\cdots + 1/a_t))\), computed from the right: the empty list has value \(0\), and the list \(a_0, a_1, \dots, a_t\) has value \(a_0 + v^{-1}\), where \(v\) is the value of the list \(a_1, \dots, a_t\). In particular \([a] = a + 0^{-1} = a\); here and at any vanishing intermediate denominator, \(0^{-1}\) is taken to be \(0\).

    public def finiteContFrac (l : List ℤ) : ℚ :=
  l.foldr (fun (a : ℤ) (x : ℚ) => (a : ℚ) + x⁻¹) 0

    DefinitionInterleaving creases into a Cloitre word#✓fully proved

    MetaMathlibExt.cloitreCreaseInterleave

    Given a sequence \(c : \mathbb{N} \to \mathbb{N}\) and a start index \(j\), the crease interleaving of a finite word \(w\) of natural numbers reads \(w\) from left to right as letters \((2)\) and \((1, 1)\) and inserts \(c_j, c_{j+1}, c_{j+2}, \dots\) after the successive letters. Precisely, the empty word gives the empty word; a word \(2, w'\) gives \(2, c_j\) followed by the interleaving of \(w'\) from index \(j + 1\); a word \(1, 1, w'\) gives \(1, 1, c_j\) followed by the interleaving of \(w'\) from index \(j + 1\); and any other nonempty word \(a, w'\) gives \(a\) followed by the interleaving of \(w'\) from the same index \(j\).

    The last case is unreachable on the approximants \(A_k\) of Cloitre's sequence.

    public def cloitreCreaseInterleave (c : ℕ → ℕ) : ℕ → List ℕ → List ℕ
  | _, [] => []
  | j, 2 :: l => 2 :: c j :: cloitreCreaseInterleave c (j + 1) l
  | j, 1 :: 1 :: l => 1 :: 1 :: c j :: cloitreCreaseInterleave c (j + 1) l
  | j, a :: l => a :: cloitreCreaseInterleave c j l
