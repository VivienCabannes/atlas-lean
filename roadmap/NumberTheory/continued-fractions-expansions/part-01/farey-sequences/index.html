    Farey.fareyFinset

    For a natural number \(n\), the Farey set \(F_n\) of order \(n\) is the finite set of rationals \(a/d\) with \(a\) and \(d\) natural numbers, \(1 \le d \le n\) and \(0 \le a \le d\).

    Equivalently, \(F_n\) consists of the rationals \(q\) with \(0 \le q \le 1\) whose denominator in lowest terms is at most \(n\). In particular \(F_0\) is empty.

    def fareyFinset (n : ℕ) : Finset ℚ :=
  ((Finset.Icc 1 n).biUnion fun d : ℕ =>
    ((Finset.Icc 0 d).image fun a : ℕ => ((a : ℤ) /. (d : ℤ) : ℚ)))
