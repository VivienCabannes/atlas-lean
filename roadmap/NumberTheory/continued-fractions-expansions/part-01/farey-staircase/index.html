    Farey staircase

    DefinitionFarey staircase#✓fully proved

    MetaMathlibExt.fareyStaircase

    For a natural number \(n\) and a real number \(x\), the Farey staircase of order \(n\) is \(A_n(x) = \frac{1}{n} \sum_{k=1}^{n} \lfloor kx \rfloor / k\), the average of the first \(n\) lower rational approximations \(\lfloor kx \rfloor / k\) of \(x\). For \(n = 0\) the sum is empty and \(A_0(x) = 0\).

    public noncomputable def fareyStaircase (n : ℕ) (x : ℝ) : ℝ :=
  (n : ℝ)⁻¹ * ∑ k ∈ Finset.Icc 1 n, (⌊(k : ℝ) * x⌋ : ℝ) / k
