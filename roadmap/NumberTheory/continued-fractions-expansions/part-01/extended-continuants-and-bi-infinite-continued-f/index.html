    DefinitionForward branch of the extended continuant#✓fully proved

    MetaMathlibExt.extendedContinuantFwd

    For an integer sequence \(x : \mathbb{Z} \to \mathbb{Z}\) and an integer \(b\), the forward branch with start index \(b\) is the sequence \((F_n)_{n \ge 0}\) of integers defined by \(F_0 = 0\), \(F_1 = 1\) and \(F_{n+2} = x_{b+n} F_{n+1} + F_n\). Its value \(F_n\) is the extended continuant \(K_{n-2}(x)_b\).

    public def extendedContinuantFwd (x : ℤ → ℤ) (b : ℤ) : ℕ → ℤ
  | 0 => 0
  | 1 => 1
  | n + 2 => x (b + n) * extendedContinuantFwd x b (n + 1) + extendedContinuantFwd x b n

    DefinitionBackward branch of the extended continuant#✓fully proved

    MetaMathlibExt.extendedContinuantBwd

    For an integer sequence \(x : \mathbb{Z} \to \mathbb{Z}\) and an integer \(b\), the backward branch with start index \(b\) is the sequence \((B_m)_{m \ge 0}\) of integers defined by \(B_0 = 1\), \(B_1 = 0\) and \(B_{m+2} = -x_{b-1-m} B_{m+1} + B_m\). Its value \(B_m\) is the extended continuant \(K_{-1-m}(x)_b\) of negative order \(-1-m\).

    public def extendedContinuantBwd (x : ℤ → ℤ) (b : ℤ) : ℕ → ℤ
  | 0 => 1
  | 1 => 0
  | m + 2 => -x (b - 1 - m) * extendedContinuantBwd x b (m + 1) + extendedContinuantBwd x b m

    MetaMathlibExt.extendedContinuant

    Let \(x : \mathbb{Z} \to \mathbb{Z}\) be a bi-infinite integer sequence and \(b\) an integer.   if 0 ≤ a + 2 then extendedContinuantFwd x b (a + 2).toNat
  else extendedContinuantBwd x b (-1 - a).toNat

    TheoremRecurrence for extended continuants#✓fully proved

    MetaMathlibExt.extendedContinuant_recurrence

    For every bi-infinite integer sequence \(x : \mathbb{Z} \to \mathbb{Z}\) and all integers \(a\) and \(b\), the extended continuants \(K_a(x)_b\) of order \(a\) with start index \(b\) satisfy \(K_a(x)_b = x_{b+a} K_{a-1}(x)_b + K_{a-2}(x)_b\).

    For \(a \le -1\) this is the paper's backward recurrence of Definition 4.

    public theorem extendedContinuant_recurrence (x : ℤ → ℤ) (a b : ℤ) :
    extendedContinuant x a b =

    TheoremTerms of a \(1\)-silent sequence#●ready to prove

    MetaMathlibExt.oneSilent_terms

    Let \(x, y, z : \mathbb{Z} \to \mathbb{Z}\) be bi-infinite integer sequences and write \(K_a(x)_b\) for the extended continuant of order \(a\) with start index \(b\). Suppose that for every natural number \(i\), \(K_i(x)_0 = K_i(y)_0\), \(K_{i-1}(x)_1 = K_{i-1}(y)_1\), \(K_{-i-2}(x)_0 = K_i(z)_0\) and \(K_{-i-3}(x)_1 = K_{i-1}(z)_1\). Then \(x_n = y_n\) for every \(n \ge 0\), \(x_{-n} = -z_n\) for every \(n \ge 1\), and \(z_0 = 0\).

    In the paper's terms the hypotheses say that the raw convergents \(k_i = K_i(x)_0 / K_{i-1}(x)_1\) of \(x\) are strictly equivalent (equal numerators and equal denominators) to the raw convergents \(c_i\) of \(y\), and \(k_{-i-2}\) to the raw convergents \(d_i\) of \(z\), for all \(i \ge 0\).
