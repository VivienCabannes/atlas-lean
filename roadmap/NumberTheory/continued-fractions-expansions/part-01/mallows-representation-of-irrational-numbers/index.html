    DefinitionMallows' insertion rule#✓fully proved

    MetaMathlibExt.mallowsInsert

    Let \(n_1/m_1\) and \(n_2/m_2\) be fractions, given as pairs of natural numbers (numerator, denominator). Mallows' insertion rule inserts between them the ordered pair of fractions \(\langle (n_1 + n_2)/(m_1 + m_2),\ (n_1 + 2n_2)/(m_1 + 2m_2) \rangle\) if \(n_1\) is even, and \(\langle (2n_1 + n_2)/(2m_1 + m_2),\ (n_1 + n_2)/(m_1 + m_2) \rangle\) if \(n_1\) is odd. The rule is applied to adjacent fractions \(n_1/m_1 < n_2/m_2\).

    def mallowsInsert (a b : ℕ × ℕ) : (ℕ × ℕ) × (ℕ × ℕ) :=
  if a.1 % 2 = 0 then ((a.1 + b.1, a.2 + b.2), (a.1 + 2 * b.1, a.2 + 2 * b.2))
  else ((2 * a.1 + b.1, 2 * a.2 + b.2), (a.1 + b.1, a.2 + b.2))

    Let \(a_1, a_2, \ldots, a_k\) be a finite list of fractions, each fraction \(n/m\) recorded as the pair \((n, m)\) of natural numbers.     DefinitionMallows levels#✓fully proved

    MetaMathlibExt.mallowsLevel

    Fractions \(n/m\) are written as pairs \((n, m)\) of natural numbers. Start from the list \(\langle 0/1, 1/1\rangle\) and refine it repeatedly, each refinement step inserting between every two adjacent entries the pair of fractions given by Mallows' insertion rule. For \(i \ge 1\), \(MT_i\) is the list of the fractions inserted at the \(i\)-th step: the fractions that Mallows' rule inserts between adjacent entries of the list obtained after \(i - 1\) steps, taken from left to right, two for each adjacent pair.

    After \(k\) steps the list has \(3^k + 1\) entries, so \(MT_i\) has \(2 \cdot 3^{i-1}\) entries.

  mallowsInserted (mallowsRefine^[i] [(0, 1), (1, 1)])
