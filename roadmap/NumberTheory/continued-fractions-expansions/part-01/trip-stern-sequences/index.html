    StructureTRIP-Stern tree#✓fully proved

    MetaMathlibExt.TripSternTree

    A TRIP-Stern tree with node values in a type \(\alpha\) consists of a root seed in \(\alpha\) together with two maps from \(\alpha\) to \(\alpha\), the left transition and the right transition. No condition is imposed on the seed or on the two transitions; in the source the seed is \((1,1,1)\) and the left and right transitions are induced by the maps \(F_0\) and \(F_1\) defined there.

    DefinitionNode selected by a binary path#✓fully proved

    MetaMathlibExt.TripSternTree.nodeAtPath

    Let \(T\) be a TRIP-Stern tree with seed \(s\), left transition \(L\) and right transition \(R\). A binary path is a finite sequence of steps, each left or right. The node of \(T\) selected by a path \((b_1, \dots, b_k)\) is obtained by starting at \(s\) and applying, for \(i = 1, \dots, k\) in order, \(L\) if \(b_i\) is a left step and \(R\) if \(b_i\) is a right step.

    def TripSternTree.nodeAtPath {α : Type _} (T : TripSternTree α)
    (path : List Bool) : α :=
  path.foldl (fun node bit =>
    if bit then T.rightTransition node else T.leftTransition node) T.seed

    DefinitionNodes at a given depth of a TRIP-Stern tree#✓fully proved

    MetaMathlibExt.TripSternTree.nodesAtDepth

    Let \(T\) be a TRIP-Stern tree and \(n\) a natural number. The set of nodes of \(T\) at depth \(n\) is the set of all values \(y\) such that some binary path of length \(n\) selects \(y\) in \(T\).

    def TripSternTree.nodesAtDepth {α : Type _} (T : TripSternTree α)
    (n : ℕ) : Set α :=
  { y | ∃ path : List Bool, path.length = n ∧ T.nodeAtPath path = y }

    TheoremMembership in a level of a TRIP-Stern tree#✓fully proved

    MetaMathlibExt.TripSternTree.nodeMembershipAtDepth

    For every TRIP-Stern tree \(T\), natural number \(n\) and node value \(y\), \(y\) lies in the set of nodes of \(T\) at depth \(n\) if and only if there is a binary path of length \(n\) whose selected node in \(T\) is \(y\).

    theorem TripSternTree.nodeMembershipAtDepth {α : Type _} (T : TripSternTree α)
    (n : ℕ) (y : α) :
    y ∈ T.nodesAtDepth n ↔
      ∃ path : List Bool, path.length = n ∧ T.nodeAtPath path = y

    DefinitionLeft-most node of a TRIP-Stern tree#✓fully proved

    MetaMathlibExt.TripSternTree.leftmostNode

    Let \(T\) be a TRIP-Stern tree with seed \(s\) and left transition \(L\). The left-most node of \(T\) at depth \(n\) is \(L^n(s)\), the result of applying \(L\) \(n\) times to \(s\); that is, it is \(s\) at depth \(0\), and at depth \(n + 1\) it is \(L\) applied to the left-most node at depth \(n\).

    def TripSternTree.leftmostNode {α : Type _} (T : TripSternTree α) : ℕ → α
  | 0 => T.seed
  | n + 1 => T.leftTransition (T.leftmostNode n)

    DefinitionRightmost node of a TRIP-Stern tree#✓fully proved

    MetaMathlibExt.TripSternTree.rightmostNode

    For a TRIP-Stern tree \(T\) and a natural number \(n\), the rightmost node of \(T\) at depth \(n\) is obtained from the seed of \(T\) by applying the right transition of \(T\) exactly \(n\) times: at depth \(0\) it is the seed, and at depth \(n + 1\) it is the image of the rightmost node at depth \(n\) under the right transition.

    def TripSternTree.rightmostNode {α : Type _} (T : TripSternTree α) : ℕ → α
  | 0 => T.seed
  | n + 1 => T.rightTransition (T.rightmostNode n)
