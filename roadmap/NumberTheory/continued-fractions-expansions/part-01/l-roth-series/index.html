    MetaMathlibExt.lurothDigit

    For a real number \(x\), the first Lüroth digit of \(x\) is the natural number \(d_1(x) = \lfloor 1/x \rfloor + 1\), where \(\lfloor \cdot \rfloor\) is the floor truncated at \(0\) and \(1/0 = 0\). For \(x \in (0, 1]\) this is the usual digit and is at least \(2\); for \(x \le 0\) and for \(x > 1\) it equals \(1\).

    noncomputable def lurothDigit (x : ℝ) : ℕ :=
  ⌊1 / x⌋₊ + 1

    DefinitionLüroth digits#✓fully proved

    MetaMathlibExt.lurothDigitSeq

    For a real number \(x\) and \(n \ge 1\), the \(n\)-th Lüroth digit of \(x\) is \(d_n(x) = d_1(L^{n-1}(x))\), where \(d_1\) is the first Lüroth digit, \(L\) is the Lüroth map and \(L^{n-1}\) is its \((n-1)\)-fold iterate (\(L^0\) is the identity).

    The digit sequence is indexed from \(0\): its term of index \(k\) is \(d_1(L^k(x)) = d_{k+1}(x)\).

    noncomputable def lurothDigitSeq (x : ℝ) (k : ℕ) : ℕ :=
  lurothDigit (lurothMap^[k] x)
    noncomputable def lurothDigit (x : ℝ) : ℕ :=
  ⌊1 / x⌋₊ + 1

    TheoremZero-one law for weighted products of consecutive Lüroth digits#●ready to prove

    MetaMathlibExt.volume_lurothWeightedProduct_ge_zero_one

    Let \(m \ge 1\), let \(t_0, \dots, t_{m-1}\) be positive reals, let \(T = \max_i t_i\) and let \(\ell\) be the number of indices \(j\) with \(t_j = T\). Let \((\Psi(n))_{n \ge 0}\) be a sequence of positive reals for which there is \(c > 1\) with \(\Psi(n) \ge c\) for all sufficiently large \(n\) (equivalently, \(\liminf_n \Psi(n) > 1\)). Write \(d_k(x)\) for the \(k\)-th Lüroth digit of \(x\) and let \(E\) be the set of \(x \in (0, 1]\) such that \(\prod_{i=0}^{m-1} d_{n+i+1}(x)^{t_i} \ge \Psi(n)\) for infinitely many \(n\). If the series \(\sum_{n \ge 0} (\log \Psi(n))^{\ell - 1} / \Psi(n)^{1/T}\) converges then \(E\) has Lebesgue measure \(0\), and if it diverges then \(E\) has Lebesgue measure \(1\).

    The paper quotes this result from Brown-Sarre, Robert and Hussain (its reference [2]).

    public theorem_wanted volume_lurothWeightedProduct_ge_zero_one {m : ℕ} (hm : 0 < m)
    (t : Fin m → ℝ) (ht : ∀ i, 0 < t i) (Ψ : ℕ → ℝ) (hΨ : ∀ n, 0 < Ψ n)
    (hlim : ∃ c : ℝ, 1 < c ∧ ∀ᶠ n in atTop, c ≤ Ψ n) :
    let T := ⨆ i, t i
    let ℓ := (Finset.univ.filter fun j => t j = T).card
    let E := {x ∈ Set.Ioc (0 : ℝ) 1 |
      ∃ᶠ n in atTop, Ψ n ≤ ∏ i : Fin m, (lurothDigitSeq x (n + i) : ℝ) ^ t i}
    (Summable (fun n => Real.log (Ψ n) ^ (ℓ - 1) / Ψ n ^ (1 / T)) → volume E = 0) ∧
      (¬ Summable (fun n => Real.log (Ψ n) ^ (ℓ - 1) / Ψ n ^ (1 / T)) → volume E = 1)
    noncomputable def lurothDigitSeq (x : ℝ) (k : ℕ) : ℕ :=
  lurothDigit (lurothMap^[k] x)

    MetaMathlibExt.volume_lurothConsecutiveDigits_zero_one
