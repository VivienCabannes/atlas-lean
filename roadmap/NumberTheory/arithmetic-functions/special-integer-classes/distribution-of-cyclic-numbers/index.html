    DefinitionLeft-hand approximation for cyclic numbers near squares#✓fully proved

    MetaMathlibExt.oppermannCyclicLeftApproximation

    Let \(\gamma\) be the Euler–Mascheroni constant and, for real \(x\), let \(L(x) = \log \log \log (x^2)\). The left-hand approximation is the function of the real variable \(x\) given by

    \[ \frac{x}{e^{\gamma} L(x)} \left(1 - \frac{\gamma}{L(x)}\right). \]

    Here \(\log y\) means \(\log |y|\), with \(\log 0 = 0\), and a quotient by \(0\) is \(0\), so the expression is defined for every real \(x\). J. E. Cohen conjectures that, at \(x = n\), it is asymptotic to the number of cyclic numbers in \([n^2 - n, n^2]\).

    noncomputable def oppermannCyclicLeftApproximation (x : ℝ) : ℝ :=
  x / (Real.exp Real.eulerMascheroniConstant *
    Real.log (Real.log (Real.log (x ^ 2)))) *
    (1 - Real.eulerMascheroniConstant /
      Real.log (Real.log (Real.log (x ^ 2))))

    MetaMathlibExt.cyclicNumbers_variance_div_mean_rpow_tendsto

    Let \(c_1 < c_2 < \cdots\) be the cyclic numbers in increasing order, so \(c_1 = 1\). For \(n \ge 1\) let \(m(c,n) = \frac{1}{n} \sum_{i=1}^{n} c_i\) be the mean of \(c_1, \dots, c_n\), and for \(n \ge 2\) let \(v(c,n) = \frac{1}{n-1} \sum_{i=1}^{n} (c_i - m(c,n))^2\) be their variance. Then for every real \(b\), as \(n \to \infty\), \(v(c,n) / m(c,n)^b\) tends to \(\infty\) if \(b < 2\), to \(1/3\) if \(b = 2\), and to \(0\) if \(b > 2\).

    public theorem_wanted cyclicNumbers_variance_div_mean_rpow_tendsto :
    let c : ℕ → ℝ := fun n => (Nat.nth IsCyclicNumber (n - 1) : ℝ)
    let mean : ℕ → ℝ := fun n => (∑ i ∈ Finset.Icc 1 n, c i) / n
    let var : ℕ → ℝ := fun n => (∑ i ∈ Finset.Icc 1 n, (c i - mean n) ^ 2) / (n - 1)
    ∀ b : ℝ,
      (b < 2 → Tendsto (fun n => var n / mean n ^ b) atTop atTop) ∧
      (b = 2 → Tendsto (fun n => var n / mean n ^ b) atTop (𝓝 (1 / 3))) ∧
      (2 < b → Tendsto (fun n => var n / mean n ^ b) atTop (𝓝 0))

    MetaMathlibExt.sum_pow_cyclicNumbers_isEquivalent

    Let \(k \ge 1\) be an integer. Let \(c_n\) be the \(n\)-th cyclic number (\(c_1 = 1\)), let \(C(x)\) be the number of cyclic numbers \(m \le x\), and let \(\gamma\) be the Euler–Mascheroni constant. Then, as \(n \to \infty\) through the natural numbers,

    \[ \sum_{i=1}^{n} c_i^k \sim \frac{n c_n^k}{k+1} \sim \frac{n^{k+1} e^{k\gamma} (\log \log \log n)^k}{k+1}, \]

    and, as \(x \to \infty\) through the real numbers,

    \[ \sum_{m \le x,\ m \text{ cyclic}} m^k \sim \frac{C(x)\, c_{C(x)}^k}{k+1} \sim \frac{C(x)\, x^k}{k+1} \sim \frac{x^{k+1}}{(k+1) e^{\gamma} \log \log \log x} \left(1 - \frac{\gamma}{\log \log \log x}\right). \]
