    TheoremPrime-power bound for primitive non-deficient numbers#✓fully proved

    MetaMathlibExt.primitive_nondeficient_prime_power_bound

    Let \(\sigma(m)\) denote the sum of the divisors of \(m\). Let \(n\) be a positive integer that is non-deficient, \(\sigma(n) \ge 2n\), and primitive, meaning that every divisor \(m\) of \(n\) with \(m < n\) is deficient, \(\sigma(m) < 2m\). Let \(k\) be the number of distinct prime factors of \(n\) and \(R\) their product. Then \(n\) has a prime factor \(p\) with \(p^{v_p(n) + 1} < 2kR\), where \(v_p(n)\) is the exponent of \(p\) in \(n\).

    theorem primitive_nondeficient_prime_power_bound
    (n : ℕ) (hn : n ≠ 0)
    (hnondef : 2 * n ≤ ∑ d ∈ Nat.divisors n, d)
    (hprim : ∀ m ∈ Nat.divisors n, m < n → ∑ d ∈ Nat.divisors m, d < 2 * m) :
    ∃ p ∈ n.primeFactors,
      p ^ (n.factorization p + 1) < 2 * n.primeFactors.card * ∏ q ∈ n.primeFactors, q

    DefinitionNon-deficient number#✓fully proved

    MathlibExt.NumberTheory.PrimitiveNondeficientWanted.IsNondeficient

    A natural number \(n\) is non-deficient when \(n \ne 0\) and \(\sigma(n) \ge 2n\), where \(\sigma(n)\) is the sum of the positive divisors of \(n\).

    Positivity is part of the notion: \(0\) has no divisors in this convention, so the inequality alone would make \(0\) non-deficient.

    def IsNondeficient (n : ℕ) : Prop :=
  n ≠ 0 ∧ 2 * n ≤ ∑ d ∈ Nat.divisors n, d

    DefinitionPrimitive non-deficient number#✓fully proved

    MathlibExt.NumberTheory.PrimitiveNondeficientWanted.IsPrimitiveNondeficient

    A natural number \(n\) is primitive non-deficient when it is non-deficient and every proper divisor \(m\) of \(n\) (a divisor with \(m < n\)) is deficient, that is, \(\sigma(m) < 2m\), where \(\sigma(m)\) is the sum of the positive divisors of \(m\).

    def IsPrimitiveNondeficient (n : ℕ) : Prop :=
  IsNondeficient n ∧
    ∀ m ∈ Nat.divisors n, m < n → ∑ d ∈ Nat.divisors m, d < 2 * m

    DefinitionAbundancy index#✓fully proved

    MathlibExt.NumberTheory.PrimitiveNondeficientWanted.abundancyIndex

    For a natural number \(n\), the abundancy index is the rational number \(h(n) = \sigma(n)/n\), where \(\sigma(n)\) is the sum of the positive divisors of \(n\).

    At \(n = 0\) this gives \(h(0) = 0\), since division by zero is \(0\) in \(\mathbb{Q}\); the abundancy index is only meaningful for positive \(n\).

    noncomputable def abundancyIndex (n : ℕ) : ℚ :=
  ((∑ d ∈ Nat.divisors n, d : ℕ) : ℚ) / (n : ℚ)

    DefinitionProduct of \(p/(p-1)\) over the prime factors#✓fully proved

    MathlibExt.NumberTheory.PrimitiveNondeficientWanted.abundancySup

    For a natural number \(n\), let \(H(n) = \prod_p p/(p-1)\) in \(\mathbb{Q}\), the product over the distinct primes \(p\) dividing \(n\). For \(n = 0\) the product is empty (\(0\) is taken to have no prime factors), so \(H(0) = 1\).

    noncomputable def abundancySup (n : ℕ) : ℚ :=
  ∏ p ∈ n.primeFactors, (p : ℚ) / ((p : ℚ) - 1)
