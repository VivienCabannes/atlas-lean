    DefinitionCoprimality density of a graph#✓fully proved

    MetaMathlibExt.coprimalityDensity

    Let \(k\) be a natural number and let \(E\) be a set of ordered pairs \((a, b)\) of vertices in \(\{1, \dots, k\}\), the edge set of a graph \(G\). For \(F \subseteq E\) let \(v(F)\) be the number of distinct vertices that occur in some pair of \(F\). The coprimality density of \(G\) is the real number

    \[A_G = \prod_p \sum_{F \subseteq E} \frac{(-1)^{|F|}}{p^{v(F)}},\]

    the product running over all primes \(p\).

    When every edge \((a, b)\) has \(a < b\), this is the Arias de Reyna–Heyman form of the asymptotic density of the \(k\)-tuples \((n_1, \dots, n_k)\) of positive integers with \(\gcd(n_a, n_b) = 1\) for every edge \((a, b)\) of \(G\).

    public noncomputable def coprimalityDensity {k : ℕ} (E : Finset (Fin k × Fin k)) : ℝ :=
  ∏' p : Nat.Primes, ∑ F ∈ E.powerset,
    (-1 : ℝ) ^ F.card /
      ((p : ℕ) : ℝ) ^ (univ.filter fun i : Fin k => ∃ e ∈ F, e.1 = i ∨ e.2 = i).card

    TheoremDirichlet series of the coprimality indicator#●ready to prove

    MetaMathlibExt.coprimality_dirichlet_series_eq

    Let \(k \ge 2\), let \(E\) be a set of pairs \((a, b)\) with \(1 \le a < b \le k\), let \(G\) be the graph on \(\{1, \dots, k\}\) with edge set \(E\), and let \(J\) be a vertex cover of \(G\), that is, every edge of \(E\) has an endpoint in \(J\). Let \(\delta_G(n_1, \dots, n_k)\) be \(1\) if \(\gcd(n_a, n_b) = 1\) for every \((a, b) \in E\), and \(0\) otherwise. For \(L \subseteq J\) let \(N(L)\) be the set of vertices adjacent to some vertex of \(L\). Then for all complex numbers \(s_1, \dots, s_k\) with \(\operatorname{Re} s_i > 1\) for every \(i\),

    \[\sum_{n_1, \dots, n_k \ge 1} \frac{\delta_G(n_1, \dots, n_k)}{n_1^{s_1} \cdots n_k^{s_k}} = \zeta(s_1) \cdots \zeta(s_k) \prod_p \sum_{L} \prod_{\ell \in L} p^{-s_\ell} \prod_{i \in (J \setminus L) \cup (N(L) \setminus J)} \left(1 - p^{-s_i}\right),\]

    where \(\zeta\) is the Riemann zeta function, the product runs over all primes \(p\), and the sum over all independent sets \(L \subseteq J\) of \(G\), that is, subsets of \(J\) such that no edge of \(E\) has both endpoints in \(L\).

    public theorem_wanted coprimality_dirichlet_series_eq {k : ℕ} (hk : 2 ≤ k)

    (J : Finset (Fin k)) (hJ : ∀ e ∈ E, e.1 ∈ J ∨ e.2 ∈ J)
    (s : Fin k → ℂ) (hs : ∀ i, 1 < (s i).re) :
    ∑' n : Fin k → ℕ, (coprimalityIndicator E (fun i => n i + 1) : ℂ) /
        ∏ i, ((n i + 1 : ℕ) : ℂ) ^ s i =
