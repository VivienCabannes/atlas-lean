    DefinitionFermat unit function#✓fully proved

    MetaMathlibExt.fermatUnitFunction

    The Fermat unit function \(u_M\) is the integer-valued arithmetic function with \(u_M(l) = 1\) when \(l = 2^n - 1\) for some integer \(n \ge 1\), and \(u_M(l) = 0\) otherwise (in particular \(u_M(0) = 0\)). Equivalently, \(u_M(l) = 1\) exactly when \(l \ge 1\) and \(l + 1\) is a power of \(2\).

    def fermatUnitFunction : ArithmeticFunction ℤ :=
  ⟨fun l => if l ≠ 0 ∧ 2 ^ Nat.log 2 (l + 1) = l + 1 then 1 else 0, by simp⟩

    TheoremThe Möbius–Fermat and von Mangoldt–Fermat functions at \(1\) and off the Fermat semigroup#●ready to prove

    MetaMathlibExt.mobiusFermat_one_and_vanishing

    The Möbius–Fermat and von Mangoldt–Fermat functions at \(1\) and off the Fermat semigroup. Let \(u_M\) be the Fermat unit function and let \(\mu_M\) be an integer-valued arithmetic function with \(\mu_M * u_M = \varepsilon\), where \(*\) is Dirichlet convolution and \(\varepsilon\) is its identity, with \(\varepsilon(1) = 1\) and \(\varepsilon(l) = 0\) for \(l \ne 1\); thus \(\mu_M\) is the Dirichlet inverse of \(u_M\), the Möbius–Fermat function. Let \(\Lambda_M = \mu_M * u_M'\), computed with real values, where \(u_M'(l) = u_M(l) \log l\). Then \(\mu_M(1) = 1\) and \(\Lambda_M(1) = 0\), and \(\mu_M(l) = \Lambda_M(l) = 0\) for every natural number \(l\) outside the Fermat semigroup, the multiplicative submonoid of \(\mathbb{N}\) generated by the numbers \(2^n - 1\) with \(n \ge 2\).

    public theorem_wanted mobiusFermat_one_and_vanishing (μ : ArithmeticFunction ℤ)
    (hμ : μ * fermatUnitFunction = 1) :
    μ 1 = 1 ∧
      ((μ : ArithmeticFunction ℝ) * (fermatUnitFunction : ArithmeticFunction ℝ).pmul log) 1 = 0 ∧
      ∀ l : ℕ, l ∉ Submonoid.closure {x : ℕ | ∃ n, 2 ≤ n ∧ x = 2 ^ n - 1} →
        μ l = 0 ∧
          ((μ : ArithmeticFunction ℝ) * (fermatUnitFunction : ArithmeticFunction ℝ).pmul log) l
            = 0
    def fermatUnitFunction : ArithmeticFunction ℤ :=
  ⟨fun l => if l ≠ 0 ∧ 2 ^ Nat.log 2 (l + 1) = l + 1 then 1 else 0, by simp⟩
