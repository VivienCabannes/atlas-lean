    DefinitionSquarefree part#✓fully proved

    MetaMathlibExt.squareSplitU

    For a natural number \(n \ge 1\) with prime factorization \(n = \prod_p p^{e_p}\), its squarefree part is \(u(n) = \prod_p p^{e_p \bmod 2}\), the product of the primes dividing \(n\) to an odd power. By convention \(u(0) = 1\).

    public def squareSplitU (n : ℕ) : ℕ :=
  n.factorization.prod fun p e => p ^ (e % 2)

    DefinitionSquare-splitting convolution#✓fully proved

    MetaMathlibExt.squareSplitConv

    For complex arithmetic functions \(f\) and \(g\), the square-splitting \(A\)-convolution of Narkiewicz type is the arithmetic function \(f \star g\) given by \((f \star g)(n) = \sum_{d \in A(n)} f(d)\, g(n/d)\) for \(n \ge 1\) and \((f \star g)(0) = 0\). Here \(A(n) = \{u_1 v_1^2 : u_1 \mid u(n),\ v_1 \mid v(n)\}\) is the square-splitting divisor set of \(n\), where \(u(n)\) is the squarefree part of \(n\) and \(n = u(n) v(n)^2\).

    public noncomputable def squareSplitConv (f g : ArithmeticFunction ℂ) :
    ArithmeticFunction ℂ :=
  ⟨fun n => if n = 0 then 0 else ∑ d ∈ squareSplitDivisors n, f d * g (n / d), by simp⟩
    public def squareSplitDivisors (n : ℕ) : Finset ℕ :=
  ((squareSplitU n).divisors ×ˢ (squareSplitV n).divisors).image fun x => x.1 * x.2 ^ 2

    TheoremRing axioms for the square-splitting convolution#●ready to prove

    MetaMathlibExt.squareSplitConv_commRing_axioms

    For all complex arithmetic functions \(f\), \(g\) and \(h\), the square-splitting convolution \(\star\) satisfies \(f \star g = g \star f\), \((f \star g) \star h = f \star (g \star h)\), \(f \star (g + h) = f \star g + f \star h\) and \(\varepsilon \star f = f\), where \(\varepsilon\) is the arithmetic function with \(\varepsilon(1) = 1\) and \(\varepsilon(n) = 0\) for \(n \ne 1\).

      squareSplitConv 1 f = f

    Let \(\star\) be the square-splitting convolution. For all complex arithmetic functions \(f\) and \(g\), every squarefree natural number \(u\) and every natural number \(v \ge 1\),
