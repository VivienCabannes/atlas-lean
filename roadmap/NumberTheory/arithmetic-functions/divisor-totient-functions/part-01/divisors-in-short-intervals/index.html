    DefinitionLetendre's saving exponent#✓fully proved

    MetaMathlibExt.letendreXi

    For real numbers \(\theta\) and \(\eta\), Letendre's saving exponent \(\xi(\theta, \eta)\) is defined as follows. If \(\eta \le \theta^2\), then \(\xi(\theta, \eta) = 1\). Otherwise, if \(\theta \le 1/2\), then \(\xi(\theta, \eta) = \theta^2/\eta\) when \(2\eta \le \theta\) and \(\xi(\theta, \eta) = 4(\theta - \eta)\) when \(2\eta > \theta\); and if \(\theta > 1/2\), then \(\xi(\theta, \eta) = (1 - \theta)^2/((1 - \theta)^2 + \eta - \theta^2)\) when \(2\eta \le 3\theta - 1\) and \(\xi(\theta, \eta) = 4(\theta - \eta)\) when \(2\eta > 3\theta - 1\).

    public noncomputable def letendreXi (θ η : ℝ) : ℝ :=
  if η ≤ θ ^ 2 then 1
  else if θ ≤ 1 / 2 then (if 2 * η ≤ θ then θ ^ 2 / η else 4 * (θ - η))
  else if 2 * η ≤ 3 * θ - 1 then (1 - θ) ^ 2 / ((1 - θ) ^ 2 + η - θ ^ 2)
  else 4 * (θ - η)
