    DefinitionResidue counts of the shifted floor sequence#✓fully proved

    MetaMathlibExt.shiftedFloorResidueCount

    For a natural number \(n\), real numbers \(\alpha\) and \(\nu\), an integer \(r\) and a natural number \(m\), the count \(\mathcal N_{n,\alpha,\nu,r,m}\) is the number of integers \(k\) with \(1 \le k \le n\) such that \(\lfloor (n - \nu)/k + \alpha \rfloor \equiv r \pmod m\).     public noncomputable def shiftedFloorResidueCount (n : ℕ) (α ν : ℝ) (r : ℤ)
    (m : ℕ) : ℕ :=
  ((Finset.Icc 1 n).filter
    (fun k : ℕ => ⌊((n : ℝ) - ν) / (k : ℝ) + α⌋ ≡ r [ZMOD m])).card
