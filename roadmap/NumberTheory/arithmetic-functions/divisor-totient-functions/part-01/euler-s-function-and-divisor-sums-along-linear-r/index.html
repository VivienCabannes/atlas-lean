    TheoremLower bound for Euler's function and upper bound for the sum of divisors#●ready to prove

    MetaMathlibExt.totient_div_gg_and_sigma_div_ll_log_log

    Let \(\varphi\) be Euler's totient function and \(\sigma(n)\) the sum of the positive divisors of \(n\). There is a constant \(C > 0\) such that \(\varphi(n)/n \ge C/\log\log n\) for every integer \(n \ge 3\), and there is a constant \(C'\) such that \(\sigma(n)/n \le C' \log\log n\) for every integer \(n \ge 3\).

    public theorem_wanted totient_div_gg_and_sigma_div_ll_log_log :
    (∃ C : ℝ, 0 < C ∧ ∀ n : ℕ, 3 ≤ n →

      ∃ C : ℝ, ∀ n : ℕ, 3 ≤ n →
        (ArithmeticFunction.sigma 1 n : ℝ) / n ≤ C * Real.log (Real.log n)
