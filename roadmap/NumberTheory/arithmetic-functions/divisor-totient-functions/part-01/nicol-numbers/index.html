    Nicol numbers

    DefinitionNicol numbers#✓fully proved

    MetaMathlibExt.IsNicolNumber

    A Nicol number is a positive integer \(n\) that divides \(\varphi(n) + \sigma(n)\), where \(\varphi\) is Euler's totient function and \(\sigma(n)\) is the sum of the positive divisors of \(n\).

    def IsNicolNumber (n : ℕ) : Prop :=
  0 < n ∧ n ∣ Nat.totient n + ∑ d ∈ n.divisors, d
