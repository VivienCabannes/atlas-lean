    Let \(a, b \in \mathbb{Z}\) with \(4a^3 + 27b^2 \ne 0\), and for \(u, v \in \mathbb{Q}\) let \(H(u, v) = \max(|U|, |V|, |W|)\), where \(U, V, W\) are coprime integers with \((U : V : W) = (u : v : 1)\). Consider the rational solutions \((u, v)\) of \(v^2 = u^3 + au + b\). (a) If \(a = \pm 1\) and \(b \notin \{0, 1, -1\}\), every solution has \(H(u, v) \ge (|b|/5)^{1/3}\). (b) If \(a \notin \{0, 1, -1\}\) and \(b = -1\), every solution has \(H(u, v) \ge (|a|/5)^{1/3}\). (c) If \(a \notin \{0, 1, -1\}\) and \(b = 1\), every solution with \(H(u, v) < (|a|/5)^{1/3}\) is \((0, 1)\) or \((0, -1)\).

        ¬ Height.mulHeight ![u, v, 1] < (|(b : ℝ)| / 5) ^ ((1 : ℝ) / 3)) ∧
      (a ≠ 0 → a ≠ 1 → a ≠ -1 → b = -1 → ∀ u v : ℚ, v ^ 2 = u ^ 3 + a * u + b →
