    DefinitionThe Zeckendorf-adic integers#✓fully proved

    MetaMathlibExt.zeckAdic

    The Zeckendorf-adic integers \(\mathbb{X}\) are the digit sequences \(x = (x_k)_{k \ge 0}\) with \(x_k \in \{0, 1\}\) such that \(x_0 = x_1 = 0\) and no two consecutive digits are both \(1\), that is, \(x_k x_{k+1} = 0\) for every \(k\).

    Digit \(k \ge 2\) carries the weight \(F_k\) (with \(F_1 = F_2 = 1\)). The unused digits \(x_0\) and \(x_1\) keep the paper's indexing, in which \(\mathbb{X} = \{x \in \{0,1\}^{\mathbb{N}_{\ge 2}} : x_k x_{k+1} = 0 \text{ for all } k \ge 2\}\).

    public def zeckAdic : Set (ℕ → Bool) :=
  {x | x 0 = false ∧ x 1 = false ∧ ∀ k, x k = false ∨ x (k + 1) = false}

    DefinitionThe Zeckendorf odometer#✓fully proved

    MetaMathlibExt.zeckOdometer

    The odometer is the map \(T\) on digit sequences \(x = (x_k)_{k \in \mathbb{N}}\) with \(x_k \in \{0, 1\}\) defined as follows. If \(x_k = x_{k+1} = 0\) for some \(k \ge 2\), let \(k\) be the least such index; then \(T(x)_j = 0\) for \(j < k\), \(T(x)_k = 1\) and \(T(x)_j = x_j\) for \(j > k\). If there is no such \(k\), then \(T(x)\) is the zero sequence.

    On a Zeckendorf-adic integer, where digit \(k \ge 2\) carries the weight of the Fibonacci number \(F_k\), the map \(T\) is addition of \(1\), and \(x + r\) denotes \(T^r(x)\) for \(r \in \mathbb{N}\).

    public noncomputable def zeckOdometer (x : ℕ → Bool) : ℕ → Bool :=
  open Classical in
  if h : ∃ k, 2 ≤ k ∧ x k = false ∧ x (k + 1) = false then
    fun j => if j < Nat.find h then false else if j = Nat.find h then true else x j
  else fun _ => false
