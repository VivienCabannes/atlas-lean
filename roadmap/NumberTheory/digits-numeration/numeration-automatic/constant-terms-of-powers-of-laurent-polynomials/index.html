    DefinitionCartier operator \(\Lambda_k\) on Laurent polynomials#✓fully proved

    MetaMathlibExt.laurentCartier

    Let \(R\) be a semiring and \(f\) a Laurent polynomial in \(r\) variables with coefficients in \(R\). For a natural number \(k > 0\), \(\Lambda_k f\) keeps the terms of \(f\) whose exponents are all multiples of \(k\) and substitutes \(x_s^k \mapsto x_s\) for each variable, so that the coefficient of \(x^j\) in \(\Lambda_k f\) is the coefficient of \(x^{kj}\) in \(f\) for every \(j \in \mathbb{Z}^r\). For \(k = 0\) it is set to \(\Lambda_0 f = 0\) (the paper uses only positive \(k\)).

    public noncomputable def laurentCartier {R : Type*} [Semiring R] {r : ℕ} (k : ℕ)
    (f : AddMonoidAlgebra R (Fin r → ℤ)) : AddMonoidAlgebra R (Fin r → ℤ) :=
  if hk : k = 0 then 0 else
    .ofCoeff (Finsupp.comapDomain (fun j => k • j) f.coeff
      (fun _ _ _ _ h => smul_right_injective (Fin r → ℤ) hk h))

    DefinitionDegree of a Laurent polynomial#✓fully proved

    MetaMathlibExt.laurentDeg

    Let \(R\) be a semiring and let \(f\) be a Laurent polynomial in \(r\) variables \(x_1, \dots, x_r\) with coefficients in \(R\). Kohen's degree \(\deg f\) of \(f\) is the largest absolute value \(|j_i|\) of a single exponent, taken over all \(i\) and all exponent vectors \(j \in \mathbb{Z}^r\) whose monomial \(x^j\) has nonzero coefficient in \(f\), and is \(0\) if there is no such exponent (in particular for the zero polynomial). For example, over \(\mathbb{Z}\) in two variables \(x, y\) one has \(\deg(5x^{-3}y^{-2} + 2xy^{-1}) = 3\).

    public def laurentDeg {R : Type*} [Semiring R] {r : ℕ}
    (f : AddMonoidAlgebra R (Fin r → ℤ)) : ℕ :=
  f.coeff.support.sup fun j => Finset.univ.sup fun i => (j i).natAbs
