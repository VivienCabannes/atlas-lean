    Dirichlet convolutions of digit sums

    DefinitionDigit-sum arithmetic function#✓fully proved

    MetaMathlibExt.digitSumArith

    For a natural number \(q\), \(s_q\) is the arithmetic function that sends \(n\) to \(s_q(n)\), the sum of the digits of \(n\) in base \(q\). Its \(k\)-th Dirichlet power is the \(k\)-fold Dirichlet convolution \(s_q^{(k)}\), so \(s_q^{(1)} = s_q\) and \(s_q^{(k)} = s_q * s_q^{(k-1)}\) for \(k \ge 2\).

    For \(q \le 1\) the base-\(q\) digit expansion is degenerate and \(s_q(n) = n\).

    def digitSumArith (q : ℕ) : ArithmeticFunction ℕ :=
  ⟨fun n => (Nat.digits q n).sum, by simp⟩

    MetaMathlibExt.digitSumArith_sq_apply

    For natural numbers \(q\) and \(n\), the Dirichlet square \(s_q^{(2)} = s_q * s_q\) of the base-\(q\) digit-sum function \(s_q\) satisfies \(s_q^{(2)}(n) = \sum_{de = n} s_q(d) \, s_q(e)\), where the sum runs over the pairs \((d, e)\) of positive integers with \(de = n\) (there are none for \(n = 0\), and then both sides are \(0\)).

    DefinitionDelange's function#✓fully proved

    MetaMathlibExt.trollopeDelangeIntegral

    For a natural number \(q\), Delange's function in base \(q\) is the function of a real number \(x\) given by \(g(x) = \int_0^x \left(\lfloor q t \rfloor - q \lfloor t \rfloor - \frac{q - 1}{2}\right) dt\), where \(\lfloor \cdot \rfloor\) is the floor function.

    noncomputable def trollopeDelangeIntegral (q : ℕ) (x : ℝ) : ℝ :=
  ∫ t in (0 : ℝ)..x, ((⌊(q : ℝ) * t⌋ : ℝ) - q * ⌊t⌋ - ((q : ℝ) - 1) / 2)
