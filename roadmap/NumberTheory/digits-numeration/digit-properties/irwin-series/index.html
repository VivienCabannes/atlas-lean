    MetaMathlibExt.digitCount

    For natural numbers \(b\), \(d\) and \(n\), the digit count of \(d\) in \(n\) is the number of occurrences of the digit \(d\) in the minimal base-\(b\) representation of \(n\) (its base-\(b\) digits without leading zeros). The representation of \(0\) is empty, so \(0\) has digit count \(0\).

    For the degenerate bases, the representation of \(n \ne 0\) is the single digit \(n\) when \(b = 0\) and a string of \(n\) ones when \(b = 1\).

    public def digitCount (b d n : ℕ) : ℕ :=
  (Nat.digits b n).count d

    DefinitionIrwin sum#✓fully proved

    MetaMathlibExt.irwinSum

    DefinitionIrwin measure#✓fully proved

    MetaMathlibExt.irwinMeasure

    Let \(b\), \(d\) and \(k\) be natural numbers with \(d < b\). For a finite string \(X\) of base-\(b\) digits (of any length, including the empty string, with leading zeros allowed), read most significant digit first, let \(|X|\) be its length and \(n(X)\) the integer it represents.     public noncomputable def irwinMeasure (b d k : ℕ) (hd : d < b) : Measure ℝ :=
  Measure.sum (fun X : {X : List (Fin b) // X.count ⟨d, hd⟩ = k} =>
    stringAtom b X.1)
