    TheoremStructure of four-digit Kaprekar dynamics in odd bases#✓fully proved

    MetaMathlibExt.four_digit_kaprekar_structural_classification

    Let \(B > 3\) be an odd integer. For a pair of natural numbers \(d = (d_1, d_2)\), let \(K(d) = (a - e, b - c)\), where \(a \ge b \ge c \ge e\) are the four numbers \(d_1 - 1, B - 1, B - 1, B - d_1\) if \(d_2 = 0\), and \(d_1, d_2 - 1, B - d_2 - 1, B - d_1\) if \(d_2 \ne 0\), sorted in decreasing order (subtraction is truncated at \(0\)). Let \(X_B\) be the set of pairs with \(1 \le d_1 < B\) and \(d_2 \le d_1\), and let \(T_B\) be the set of pairs in \(X_B\) with \(0 < d_2 < d_1\) and \(d_1\), \(d_2\) both odd. Let \(\mathcal{P}\) be the set of two-element sets \(S\) of subsets of \(\mathbb{Z}/B\mathbb{Z}\) such that every \(C \in S\) has the form \(\{x, -x\}\) with \(x \ne 0\). For a set \(S\) of subsets of \(\mathbb{Z}/B\mathbb{Z}\) let \(2S = \{2C : C \in S\}\), where \(2C = \{2y : y \in C\}\), and for \(d \in T_B\) let \(\Phi(d) = \{\{u, -u\}, \{v, -v\}\}\), where \(u\) and \(v\) are the residues of \((d_1 + d_2)/2\) and \((d_1 - d_2)/2\) modulo \(B\). Then \(K\) maps \(T_B\) into itself, the third iterate \(K^3\) maps \(X_B\) into \(T_B\), \(S \mapsto 2S\) maps \(\mathcal{P}\) into itself, \(\Phi\) is a bijection from \(T_B\) onto \(\mathcal{P}\), and \(\Phi(K(d)) = 2\,\Phi(d)\) for every \(d \in T_B\).

    Here a pair \((d_1, d_2) \in X_B\) stands for the four-digit base-\(B\) numbers whose digits, sorted as \(a \ge b \ge c \ge e\), satisfy \(a - e = d_1\) and \(b - c = d_2\); the four numbers listed above are the base-\(B\) digits of their Kaprekar image, so \(K\) is the Kaprekar map on these pairs.

    DefinitionKaprekar difference#✓fully proved

    MetaMathlibExt.kaprekarDiff

    Let \(l\) be a list of \(k\) natural numbers and let \(a_0 \le a_1 \le \dots \le a_{k-1}\) be its entries in increasing order. The Kaprekar difference of \(l\) is \(\alpha_M - \alpha_L\), where \(\alpha_M = \sum_{i\lt k} a_i 10^i\) and \(\alpha_L = \sum_{i\lt k} a_{k-1-i} 10^i\). When the entries are decimal digits, \(\alpha_M\) is the number written with the digits of \(l\) in descending order and \(\alpha_L\) is the number written with them in ascending order (leading zeros allowed).

    public def kaprekarDiff (l : List ℕ) : ℕ :=
  Nat.ofDigits 10 (List.insertionSort (· ≤ ·) l) - Nat.ofDigits 10 (List.insertionSort (· ≥ ·) l)

    DefinitionKaprekar map#✓fully proved

    MetaMathlibExt.kaprekarMap

    For natural numbers \(n\) and \(\alpha\), take the decimal digits of \(\alpha\) (without leading zeros, and no digits at all for \(\alpha = 0\)) and, if there are fewer than \(n\) of them, pad them with leading zeros to a string of exactly \(n\) digits. The Kaprekar map sends \(\alpha\) to the Kaprekar difference \(\alpha_M - \alpha_L\) of this digit string: the number with these digits in descending order minus the number with them in ascending order. For \(\alpha < 10^n\) this is the Kaprekar transformation on the set \(D_n\) of \(n\)-digit strings; for \(\alpha \ge 10^n\) nothing is padded and all digits of \(\alpha\) are used.

    public def kaprekarMap (n α : ℕ) : ℕ :=
  kaprekarDiff (Nat.digits 10 α ++ List.replicate (n - (Nat.digits 10 α).length) 0)
    public def kaprekarDiff (l : List ℕ) : ℕ :=
  Nat.ofDigits 10 (List.insertionSort (· ≤ ·) l) - Nat.ofDigits 10 (List.insertionSort (· ≥ ·) l)

    DefinitionThe four-digit Kaprekar map in difference coordinates#✓fully proved

    MetaMathlibExt.kaprekarFourDigitStep

    For a base \(B\) and a pair of natural numbers \((d_1, d_2)\), the map \(K_B\) forms the list of four digits \([d_1 - 1, B - 1, B - 1, B - d_1]\) if \(d_2 = 0\) and \([d_1, d_2 - 1, B - d_2 - 1, B - d_1]\) if \(d_2 > 0\), sorts it decreasingly as \(a_1 \ge a_2 \ge a_3 \ge a_4\), and sets \(K_B(d_1, d_2) = (a_1 - a_4, a_2 - a_3)\). Subtraction of natural numbers is truncated at \(0\); for \(1 \le d_1 < B\) and \(0 \le d_2 \le d_1\) no truncation occurs.

    For such \((d_1, d_2)\) the list holds the digits of the Kaprekar difference (largest minus smallest arrangement) of any four-digit base-\(B\) string with difference coordinates \((d_1, d_2)\), as in paper displays (5) and (6).

    public def kaprekarFourDigitStep (B : ℕ) (d : ℕ × ℕ) : ℕ × ℕ :=
  match List.insertionSort (· ≥ ·)
    (if d.2 = 0 then [d.1 - 1, B - 1, B - 1, B - d.1]
      else [d.1, d.2 - 1, B - d.2 - 1, B - d.1]) with
  | [a, b, c, e] => (a - e, b - c)
  | _ => (0, 0)

    DefinitionProjective order of 2#✓fully proved

    MetaMathlibExt.projectiveOrderTwo

    For a natural number \(n\), the projective order of \(2\) modulo \(n\) is the least \(m > 0\) with \(2^m \equiv 1\) or \(2^m \equiv -1 \pmod{n}\),

    \[\lambda(n) = \min \{m > 0 : 2^m \equiv \pm 1 \pmod{n}\},\]

    and \(\lambda(n) = 0\) when no such \(m\) exists, which happens exactly when \(n\) is even (including \(n = 0\), where congruence modulo \(0\) is equality of integers). For odd \(n\) these are the terms of OEIS A003558, which lists \(\lambda(2k + 1)\) at index \(k\).

    public noncomputable def projectiveOrderTwo (n : ℕ) : ℕ :=
  sInf {m : ℕ | 0 < m ∧ ((2 : ZMod n) ^ m = 1 ∨ (2 : ZMod n) ^ m = -1)}
