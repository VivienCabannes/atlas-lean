    For natural numbers \(b\) and \(m\), let \(k\) be the base-\(b\) logarithm of \(m\) rounded down, that is, the largest \(k\) with \(b^k \le m\) when \(b \ge 2\) and \(m \ge 1\), and \(k = 0\) otherwise. The most significant digit of \(m\) in base \(b\) is \(\lfloor m / b^k \rfloor\). When \(b \ge 2\) and \(m \ge 1\) this is the leading digit of the base-\(b\) expansion of \(m\).

    public def commaMsd (b m : Nat) : Nat :=
  m / b ^ Nat.log b m

    DefinitionComma candidate digits#✓fully proved

    MetaMathlibExt.IsCommaCandidate

    Let \(b\) and \(n\) be natural numbers and let \(y\) be a digit with \(0 \le y < b\). Put \(m = n + b\,(n \bmod b) + y\), where \(n \bmod b\) is the remainder of \(n\) on division by \(b\). Then \(y\) is a comma candidate for \(n\) in base \(b\) if \(m > 0\) and the most significant base-\(b\) digit of \(m\) equals \(y\).

    For such a candidate \(y\) in base \(b \ge 2\), the difference \(m - n = b\,(n \bmod b) + y\) is written with the base-\(b\) digits \(n \bmod b\) and \(y\): the last digit of \(n\) followed by the leading digit of \(m\).

    public def IsCommaCandidate (b n : Nat) (y : Fin b) : Prop :=
  let m := n + b * (n % b) + y.val
  0 < m ∧ commaMsd b m = y.val
    public def commaMsd (b m : Nat) : Nat :=
  m / b ^ Nat.log b m

    DefinitionComma successor#✓fully proved

    MetaMathlibExt.IsCommaSucc

    Let \(b\), \(n\) and \(m\) be natural numbers. Then \(m\) is the comma successor of \(n\) in base \(b\) if there is a comma candidate digit \(y < b\) for \(n\) in base \(b\) such that \(m = n + b\,(n \bmod b) + y\) and no digit \(y' < y\) is a comma candidate for \(n\) in base \(b\).

    Taking the least candidate \(y\) makes \(m\) the smallest possible next term.

    public def IsCommaSucc (b n m : Nat) : Prop :=
  ∃ y : Fin b, IsCommaCandidate b n y ∧ m = n + b * (n % b) + y.val ∧
    ∀ y' : Fin b, y'.val < y.val → ¬ IsCommaCandidate b n y'
    public def IsCommaCandidate (b n : Nat) (y : Fin b) : Prop :=
  let m := n + b * (n % b) + y.val
  0 < m ∧ commaMsd b m = y.val

    DefinitionInfinite comma sequences#✓fully proved

    MetaMathlibExt.IsInfiniteCommaSeq

    Let \(b\) and \(v\) be natural numbers and let \(a : \mathbb{N} \to \mathbb{N}\) be a sequence. Then \(a\) is an infinite comma sequence in base \(b\) starting at \(v\) if \(b \ge 2\), \(v > 0\), \(a_1 = v\), and for every \(n \ge 1\) the term \(a_{n+1}\) is the comma successor of \(a_n\) in base \(b\).

    Indexing starts at \(1\); the value \(a_0\) is unconstrained.

    public def IsInfiniteCommaSeq (b v : Nat) (a : Nat → Nat) : Prop :=
  2 ≤ b ∧ 0 < v ∧ a 1 = v ∧ ∀ n, 1 ≤ n → IsCommaSucc b (a n) (a (n + 1))

    MetaMathlibExt.commaChild_parent_eq

    Fix a base \(b \ge 2\) and a natural number \(n\). Call \(n\) a comma-child of \(k\) if \(n = k + b\,(k \bmod b) + y\) for some comma candidate digit \(y\) of \(k\) in base \(b\).
