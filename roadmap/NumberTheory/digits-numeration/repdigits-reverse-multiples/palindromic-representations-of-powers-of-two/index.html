    DefinitionMinimum palindromic base#✓fully proved

    MetaMathlibExt.minPalindromicBase

    For a natural number \(N\), \(b(N)\) is the smallest base \(b \ge 2\) in which \(N\) is a palindrome, that is, in which the base-\(b\) digits of \(N\) read the same forwards and backwards. Such a base exists: \(0\) has no digits and is a palindrome in every base, and for \(N \ge 1\) the number \(N\) is written with the single digit \(N\) in base \(N + 1\).

    public noncomputable def minPalindromicBase (N : ℕ) : ℕ :=
  sInf {b | 2 ≤ b ∧ (Nat.digits b N).Palindrome}

    DefinitionBinomial form#✓fully proved

    MetaMathlibExt.HasBinomialForm

    A natural number \(N\) has a base-\(b\) representation in binomial form if there are natural numbers \(\alpha \ge 1\) and \(k \ge 1\) such that the base-\(b\) digits of \(N\), from the most significant to the least significant, are \(\alpha\binom{k}{k}, \alpha\binom{k}{k-1}, \dots, \alpha\binom{k}{0}\).

    The one-digit case \(k = 0\) is excluded as degenerate.

    public def HasBinomialForm (b N : ℕ) : Prop :=
  ∃ α k : ℕ, 1 ≤ α ∧ 1 ≤ k ∧ Nat.digits b N = (List.range (k + 1)).map fun i => α * k.choose i

    TheoremThree-digit palindromic powers of two#●ready to prove

    MetaMathlibExt.three_digit_palindrome_two_pow_iff

    Let \(n\) be a natural number, let \(b \ge 2\) be a base, and let \(c = 2^n \bmod b\). The base-\(b\) representation of \(2^n\) is a palindrome with exactly three digits if and only if \(b^2 + 1 \le 2^n \le b^3 - 1\), \(c \ne 0\), and \(\frac{1}{b} \lfloor 2^n / b \rfloor - \frac{b - 1}{b} \le c \le \frac{1}{b} \lfloor 2^n / b \rfloor\).

    public theorem_wanted three_digit_palindrome_two_pow_iff (n b : ℕ) (hb : 2 ≤ b) :

      b ^ 2 + 1 ≤ 2 ^ n ∧ 2 ^ n ≤ b ^ 3 - 1 ∧ 2 ^ n % b ≠ 0 ∧
        ((2 ^ n / b : ℕ) : ℚ) / b - ((b : ℚ) - 1) / b ≤ ((2 ^ n % b : ℕ) : ℚ) ∧
        ((2 ^ n % b : ℕ) : ℚ) ≤ ((2 ^ n / b : ℕ) : ℚ) / b

    TheoremThree-digit representations of powers of two with outer digits one#●ready to prove

    MetaMathlibExt.one_c_one_two_pow_iff

    Let \(n\) be a natural number and \(b \ge 2\) a base. There is a digit \(c \ne 2\) such that the base-\(b\) representation of \(2^n\) is \((1, c, 1)_b\), that is, \(2^n = 1 + cb + b^2\) with \(0 \le c < b\), if and only if (i) \(2^n - 1 = kb\) for some natural number \(k\) with \(b \le k \le 2b - 1\), and (ii) it is not the case that \(n\) is even and \(b = 2^{n/2} - 1\).

      (∃ k, 2 ^ n - 1 = k * b ∧ b ≤ k ∧ k ≤ 2 * b - 1) ∧ ¬ (Even n ∧ b = 2 ^ (n / 2) - 1)
