    MetaMathlibExt.IsPermutiple

    Let \(n\), \(b\) and \(d_0, \dots, d_k\) be natural numbers and let \(\sigma\) be a permutation of \(\{0, \dots, k\}\). The numeral \((d_k, \dots, d_0)_b\) is an \((n, b, \sigma)\)-permutiple when \(d_j < b\) for every \(j\) and

    \[\sum_{j=0}^k d_j b^j = n \sum_{j=0}^k d_{\sigma(j)} b^j,\]

    that is, \((d_k, \dots, d_0)_b = n \cdot (d_{\sigma(k)}, \dots, d_{\sigma(0)})_b\).

    public def IsPermutiple (n b : ℕ) {k : ℕ} (d : Fin (k + 1) → ℕ) (σ : Equiv.Perm (Fin (k + 1))) :
    Prop :=
  (∀ j, d j < b) ∧ ∑ j, d j * b ^ (j : ℕ) = n * ∑ j, d (σ j) * b ^ (j : ℕ)

    MetaMathlibExt.permutipleCarry

    Let \(n\), \(b\) and \(d_0, \dots, d_k\) be natural numbers and let \(\sigma\) be a permutation of \(\{0, \dots, k\}\). The carries of the single-digit multiplication \(n \cdot (d_{\sigma(k)}, \dots, d_{\sigma(0)})_b\), where \((e_k, \dots, e_0)_b\) denotes the base-\(b\) numeral \(\sum_{j=0}^{k} e_j b^j\), are the natural numbers \(c_0, c_1, c_2, \dots\) defined by \(c_0 = 0\), \(c_{j+1} = \lfloor (n d_{\sigma(j)} + c_j) / b \rfloor\) for \(0 \le j \le k\), and \(c_{j+1} = 0\) for \(j > k\). Division by \(b = 0\) is taken to give \(0\).

    public def permutipleCarry (n b : ℕ) {k : ℕ} (d : Fin (k + 1) → ℕ)
    (σ : Equiv.Perm (Fin (k + 1))) : ℕ → ℕ
  | 0 => 0
  | j + 1 => if h : j < k + 1 then (n * d (σ ⟨j, h⟩) + permutipleCarry n b d σ j) / b else 0

    DefinitionEdge set of the graph of a numeral#✓fully proved

    MetaMathlibExt.permutipleGraphEdges

    Let \(b\) be a base, let \(d_0, \dots, d_k\) be natural numbers, the digits of the base-\(b\) numeral \((d_k, \dots, d_0)_b = \sum_{j=0}^{k} d_j b^j\), and let \(\sigma\) be a permutation of \(\{0, \dots, k\}\). The graph \(G\) of these digits with digit permutation \(\sigma\) has edge set

    DefinitionEdges of the mother graph#✓fully proved

    MetaMathlibExt.IsMotherGraphEdge

    Let \(n\) and \(b\) be natural numbers. For natural numbers \(x\) and \(y\), the pair \((x, y)\) is an edge of the \((n, b)\)-mother graph \(M\) when \(x < b\), \(y < b\) and

    \[\lambda(x + (b - n) y) \le n - 1,\]

    where \(\lambda(z)\) is the least non-negative residue of the integer \(z\) modulo \(b\), and \(b - n\) and \(n - 1\) are computed in the integers.

    public def IsMotherGraphEdge (n b x y : ℕ) : Prop :=
  x < b ∧ y < b ∧ ((x : ℤ) + ((b : ℤ) - n) * y) % b ≤ (n : ℤ) - 1

    \[c_{j+1} = \left\lfloor \frac{n \hat d_j - d_j + c_j}{b} \right\rfloor \quad (0 \le j \le k)\]

      ((n : ℤ) * dh ⟨j, h⟩ - d ⟨j, h⟩ + hoeySloaneCarry n b d dh j) / b

    MetaMathlibExt.IsHoeySloaneWord

    Let \(n\) and \(b\) be natural numbers.       hoeySloaneCarry n b d dh (k + 1) = 0
