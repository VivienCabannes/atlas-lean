    DefinitionPalindromes in an arithmetic progression#✓fully proved

    MetaMathlibExt.palindromeAPCount

    For natural numbers \(b\), \(m\), \(q\) and \(r\), \(A_b(m, q, r)\) is the number of base-\(b\) palindromes \(n\) with \(1 \le n \le m\) and \(n \equiv r \pmod q\), where a natural number is a base-\(b\) palindrome when its string of base-\(b\) digits reads the same in both directions.

    public def palindromeAPCount (b m q r : ℕ) : ℕ :=
  ((Finset.Icc 1 m).filter fun n => (Nat.digits b n).Palindrome ∧ n ≡ r [MOD q]).card

    DefinitionPalindromic half copy#✓fully proved

    MetaMathlibExt.palindromicHalfCopy

    For natural numbers \(b\) and \(m \ge 1\), write \(m = (a_k a_{k-1} \cdots a_0)_b\) for the base-\(b\) digits of \(m\). The palindromic half copy of \(m\) is \(C_b(m) = \sum_{j=0}^{k} a_{\max(j, k - j)} b^j\): the \(b\)-adic palindrome with the same number of digits as \(m\) whose upper digits \(a_k, \dots, a_{\lceil k/2 \rceil}\) are those of \(m\) and whose lower digits mirror them. For \(m = 0\), which has no digits, \(C_b(0) = 0\).

    public def palindromicHalfCopy (b m : ℕ) : ℕ :=
  ∑ j ∈ Finset.range (Nat.digits b m).length,
    (Nat.digits b m).getD (max j ((Nat.digits b m).length - 1 - j)) 0 * b ^ j

    DefinitionDigit-sum congruence count#✓fully proved

    MetaMathlibExt.digitSumCongruenceCount

    For natural numbers \(b\), \(k\), \(q\), \(x\), \(y\) and an integer \(r\), \(N_b(k, q, r, x, y)\) is the number of tuples \((x_1, \dots, x_k)\) of natural numbers with \(x \le x_1 < y\) and \(x_i < b\) for \(2 \le i \le k\) such that \(x_1 + \dots + x_k \equiv r \pmod q\). The count is meant for \(k \ge 1\); for \(k = 0\) it is defined to equal its value for \(k = 1\), the number of natural numbers \(x_1\) with \(x \le x_1 < y\) and \(x_1 \equiv r \pmod q\).

    public def digitSumCongruenceCount (b k q : ℕ) (r : ℤ) (x y : ℕ) : ℕ :=
  ((Finset.Ico x y ×ˢ Fintype.piFinset fun _ : Fin (k - 1) => Finset.range b).filter
    fun p => ((p.1 + ∑ i, p.2 i : ℕ) : ℤ) ≡ r [ZMOD q]).card

    TheoremPalindromes in residue classes modulo a divisor of the base#●ready to prove

    MetaMathlibExt.palindromeAPCount_of_dvd_base

    Let \(b \ge 2\), \(m \ge 1\) and \(q \ge 1\) be natural numbers with \(q \mid b\). Write \(m = (a_k a_{k-1} \cdots a_0)_b\) in base \(b\), with leading digit \(a_k\). Write \(A_b(m, q, r)\) for the number of base-\(b\) palindromes \(n\) with \(1 \le n \le m\) and \(n \equiv r \pmod q\), \(C_b(m)\) for the palindromic half copy of \(m\), and \([P]\) for \(1\) if \(P\) holds and \(0\) otherwise. Put

    \[\alpha = \frac{b^{\lceil k/2 \rceil} + b^{\lfloor k/2 \rfloor} - 2}{b - 1}, \quad S = \sum_{i=1}^{\lfloor k/2 \rfloor} a_{k-i} b^{\lfloor k/2 \rfloor - i}, \quad \delta = [C_b(m) \le m].\]

    Then, as rational numbers,

    \[A_b(m, q, 0) = \left(\frac{b}{q} - 1\right) \alpha + \left\lfloor \frac{a_k - 1}{q} \right\rfloor b^{\lfloor k/2 \rfloor} + [a_k \equiv 0 \pmod q] (S + \delta),\]

    and for every natural number \(r\) with \(r \bmod q > 0\),

    \[A_b(m, q, r) = \frac{b \alpha}{q} + \left\lceil \frac{a_k - (r \bmod q)}{q} \right\rceil b^{\lfloor k/2 \rfloor} + [a_k \equiv r \pmod q] (S + \delta).\]

    TheoremPalindromes in residue classes modulo a divisor of the base minus one#●ready to prove

    MetaMathlibExt.palindromeAPCount_of_modEq_one

    Let \(b \ge 2\), \(m \ge 1\) and \(q \ge 1\) be natural numbers with \(b \equiv 1 \pmod q\), and let \(r\) be a natural number with \(r < q\). Write \(m = (a_k a_{k-1} \cdots a_0)_b\) in base \(b\). Write \(A_b(m, q, r)\) for the number of base-\(b\) palindromes \(n\) with \(1 \le n \le m\) and \(n \equiv r \pmod q\), \(C_b(m)\) for the palindromic half copy of \(m\), \([P]\) for \(1\) if \(P\) holds and \(0\) otherwise, and \(t \bmod d\) for the least nonnegative residue of an integer \(t\) modulo a positive integer \(d\). For \(j \ge 0\) define integers \(s_j\) and \(r_j\) as follows. If \(q\) is even and \(2j \ne k\), let \(s_j = a_{k-j} \bmod (q/2)\) and \(r_j = \bigl(\lfloor r/2 \rfloor - \sum_{i=0}^{j-1} a_{k-i}\bigr) \bmod (q/2)\). If \(q\) is odd and \(2j \ne k\), let \(s_j = a_{k-j} \bmod q\) and \(r_j = \bigl(\frac{q+1}{2} r - \sum_{i=0}^{j-1} a_{k-i}\bigr) \bmod q\). If \(2j = k\), let \(s_j = a_{k-j} \bmod q\) and \(r_j = \bigl(r - 2 \sum_{i=0}^{k/2-1} a_{k-i}\bigr) \bmod q\). Put \(\delta = [C_b(m) \le m] \, [r_{\lfloor k/2 \rfloor} = s_{\lfloor k/2 \rfloor}]\) and

    \[m_1^* = \sum_{j=0}^{\lfloor (k-1)/2 \rfloor} \left( \frac{2 a_{k-j} b^{\lfloor (k-1)/2 \rfloor - j} - 2 s_j}{q} + [r_j < s_j] \right),\]
    \[m_2^* = \sum_{j=0}^{\lfloor k/2 \rfloor - 1} \frac{a_{k-j} (b - 1) b^{\lfloor k/2 \rfloor - j - 1}}{q},\]
    \[m_3^* = \sum_{j=0}^{\lfloor k/2 \rfloor - 1} \left( \frac{a_{k-j} (b + 1) b^{\lfloor k/2 \rfloor - j - 1} - 2 s_j}{q} + [r_j < s_j] \right).\]
