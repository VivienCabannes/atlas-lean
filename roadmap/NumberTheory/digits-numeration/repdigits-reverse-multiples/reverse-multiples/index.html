    TheoremSloane's endpoint formula for reverse multiples#✓fully proved

    MetaMathlibExt.sloane_reverse_multiple_endpoint

    Let \(g\) and \(k\) be integers with \(2 \le k < g\), and let \(N = (a_n a_{n-1} \cdots a_0)_g\) have base-\(g\) digits \(a_0, \dots, a_n \in \{0, \dots, g - 1\}\), with units digit \(a_0\) and leading digit \(a_n \ne 0\). Suppose \(N\) is a \((g, k)\) reverse multiple, that is, \(k N = (a_0 a_1 \cdots a_n)_g\), and that \(a_0 + a_n = g\). Then \((k + 1) a_n = g\); in particular \(k + 1\) divides \(g\) and \(a_n = g / (k + 1)\).

    theorem sloane_reverse_multiple_endpoint
    (g k a₀ aLast : ℕ) (digits : List ℕ)
    (hk : 2 ≤ k) (hkg : k < g)
    (hdigits : ∀ d ∈ digits, d < g)
    (hunits : digits.head? = some a₀)
    (hleading : digits.getLast? = some aLast)
    (hleading_ne : aLast ≠ 0)
    (hreverse : k * Nat.ofDigits g digits = Nat.ofDigits g digits.reverse)
    (hendpoint_sum : a₀ + aLast = g) :
    (k + 1) * aLast = g ∧ aLast = g / (k + 1) ∧ k + 1 ∣ g

    TheoremSutcliffe's theorem on two- and three-digit reverse multiples#✓fully proved

    MetaMathlibExt.sutcliffe_two_to_three_digit_reverse_multiple

    Let \(g\) and \(k\) be integers with \(2 \le k < g\), and let \(a\) and \(b\) be base-\(g\) digits, \(0 \le a, b < g\), with \(a \ne 0\), such that \((a\,b)_g\) is a \((g, k)\) reverse multiple, that is, \(k (a g + b) = b g + a\). Then \(a + b < g\), so \(a + b\) is a base-\(g\) digit, and \((a\,(a + b)\,b)_g\) is again a \((g, k)\) reverse multiple, that is, \(k (a g^2 + (a + b) g + b) = b g^2 + (a + b) g + a\).

    This is the forward implication of Sutcliffe's theorem; the converse is not included.

    theorem sutcliffe_two_to_three_digit_reverse_multiple
    (g k a b : ℕ)
    (hk : 2 ≤ k) (hkg : k < g)
    (ha : a ≠ 0) (hag : a < g) (hbg : b < g)
    (hreverse : k * (a * g + b) = b * g + a) :
    a + b < g ∧
      k * (a * g ^ 2 + (a + b) * g + b) =
        b * g ^ 2 + (a + b) * g + a

    DefinitionYoung graph of a labeled directed graph#✓fully proved

    MetaMathlibExt.youngGraph

    Let \(G\) be a labeled directed graph with vertex set \(V\), edge set \(E\) and label set \(L\), let \(P\) be a predicate on \(V\) and let \(\prec\) be a binary relation on \(V\). The Young graph of \(G\) with respect to \(P\) and \(\prec\) is the labeled directed graph with label set \(L\) whose vertices are the vertices of \(G\) that are retained with respect to \(P\) and \(\prec\), whose edges are the edges of \(G\) whose source and target are both retained, and in which each edge has the same source, target and label as in \(G\).

    def youngGraph {V E L : Type _} (G : LabeledDigraph V E L)
    (pivot : V → Prop) (precedes : V → V → Prop) :
    LabeledDigraph { v : V // isYoungRetained pivot precedes v }
      { e : E // isYoungRetained pivot precedes (G.src e) ∧
        isYoungRetained pivot precedes (G.tgt e) } L :=
  G.restrict (isYoungRetained pivot precedes)

    TheoremCarry equations for reverse multiples, general form#✓fully proved

    MetaMathlibExt.young_reverse_multiple_carry_path_iff_general

    Let \(g, k, n\) be natural numbers with \(2 \le k < g\), and let \(a_0, \dots, a_{n-1}\) be natural numbers with \(a_i < g\) for every \(i\). Then \(k \sum_{i\lt n} a_i g^i = \sum_{i\lt n} a_{n-1-i} g^i\) if and only if there is a unique sequence of natural numbers \(r_0, \dots, r_n\) with \(r_0 = 0\), \(r_n = 0\) and, for every \(i < n\), \(r_{i+1} < k\) and \(k a_i + r_i = a_{n-1-i} + r_{i+1} g\).

    No hypothesis is placed on \(n\) or on the end digits \(a_0\) and \(a_{n-1}\); in particular \(n\) may be \(0\).

    theorem young_reverse_multiple_carry_path_iff_general
    (g k n : ℕ) (hgk : 2 ≤ k) (hkg : k < g)
    (a : Fin n → ℕ) (hdigit : ∀ i, a i < g) :
    k * (∑ i, a i * g ^ i.val) = ∑ i, a (Fin.rev i) * g ^ i.val ↔
      ∃! r : Fin (n + 1) → ℕ,
        r ⟨0, Nat.succ_pos n⟩ = 0 ∧ r (Fin.last n) = 0 ∧
          ∀ i : Fin n, r i.succ < k ∧
            k * a i + r i.castSucc = a (Fin.rev i) + r i.succ * g

    TheoremYoung's theorem on reverse multiples#✓fully proved

    MetaMathlibExt.young_reverse_multiples_equiv_pivot_paths

    Let \(g\) and \(k\) be natural numbers with \(2 \le k < g\). A \((g, k)\) reverse multiple is a list of base-\(g\) digits \(d_1, d_2, \dots, d_n\), most significant first, with \(n \ge 2\), \(d_1 \ne 0\), \(d_n \ne 0\) and \(d_i < g\) for every \(i\), such that \(k\) times the number \(\sum_{i=1}^{n} d_i g^{n-i}\) equals the number \(\sum_{i=1}^{n} d_{n+1-i} g^{n-i}\) whose digits are those of the first in reverse order. Consider the graph whose nodes are pairs \((r, s)\) of natural numbers, with an edge labeled \((a, b)\) from \((r, s)\) to \((r', s')\) whenever \(k b + s = a + s' g\) and \(k a + r' = b + r g\). A path is a sequence of nodes \(v_0, \dots, v_m\) together with a sequence of labels \(\ell_1, \dots, \ell_m\) such that \(m \ge 1\), \(v_0 = (0, 0)\), both coordinates of every node are less than \(k\), both coordinates of every label are less than \(g\), both coordinates of \(\ell_1\) are nonzero, and for each \(j\) the label \(\ell_j\) labels an edge from \(v_{j-1}\) to \(v_j\). A node \((r, s)\) is an even pivot if \(r = s\), and an odd pivot if for some \(c < g\) there is an edge labeled \((c, c)\) from \((r, s)\) to \((s, r)\).

    Then there is a bijection from the \((g, k)\) reverse multiples with an even number of digits to the paths whose last node is an even pivot, and a bijection from the \((g, k)\) reverse multiples with an odd number of digits to the paths whose last node is an odd pivot. Under both bijections, a reverse multiple \(d_1, \dots, d_n\) is sent to a path with labels \((d_1, d_n), (d_2, d_{n-1}), \dots, (d_h, d_{n+1-h})\), where \(h = \lfloor n/2 \rfloor\); in the odd case, if \((r, s)\) is the last node of that path, there is an edge labeled \((d_{h+1}, d_{h+1})\) from \((r, s)\) to \((s, r)\).

    theorem young_reverse_multiples_equiv_pivot_paths
    (g k : ℕ) (hk : 2 ≤ k) (hkg : k < g) :
    let digitValue := fun digits : List ℕ =>
      digits.foldl (fun value digit => value * g + digit) 0
    let IsReverseMultiple := fun digits : List ℕ =>
      (∃ first middle last,
          digits = first :: middle ++ [last] ∧ first ≠ 0 ∧ last ≠ 0) ∧
        (∀ digit ∈ digits, digit < g) ∧
        k * digitValue digits = digitValue digits.reverse
    let Transition := fun (source : ℕ × ℕ) (label : ℕ × ℕ) (target : ℕ × ℕ) =>
      k * label.2 + source.2 = label.1 + target.2 * g ∧
        k * label.1 + target.1 = label.2 + source.1 * g
    let IsPath := fun path : List (ℕ × ℕ) × List (ℕ × ℕ) =>
      path.2.length = path.1.length + 1 ∧
        path.2.head? = some (0, 0) ∧
        (∀ node ∈ path.2, node.1 < k ∧ node.2 < k) ∧
        (∀ label ∈ path.1, label.1 < g ∧ label.2 < g) ∧
        (∃ first rest,
          path.1 = first :: rest ∧ first.1 ≠ 0 ∧ first.2 ≠ 0) ∧
        List.Forall₂
          (fun label endpoints => Transition endpoints.1 label endpoints.2)
          path.1 (path.2.zip path.2.tail)
    let EvenReverseMultiples :=
      {digits : List ℕ // IsReverseMultiple digits ∧ Even digits.length}
    let OddReverseMultiples :=
      {digits : List ℕ // IsReverseMultiple digits ∧ Odd digits.length}
    let PathsToEvenPivots :=
      {path : List (ℕ × ℕ) × List (ℕ × ℕ) //
        IsPath path ∧ ∃ r, path.2.getLast? = some (r, r)}
    let PathsToOddPivots :=
      {path : List (ℕ × ℕ) × List (ℕ × ℕ) //
        IsPath path ∧
          ∃ r s middle,
            path.2.getLast? = some (r, s) ∧ middle < g ∧
              Transition (r, s) (middle, middle) (s, r)}
    ∃ evenCorrespondence : EvenReverseMultiples ≃ PathsToEvenPivots,
      ∃ oddCorrespondence : OddReverseMultiples ≃ PathsToOddPivots,
        (∀ reverseMultiple,
          (evenCorrespondence reverseMultiple).1.1 =
            List.zip
              (reverseMultiple.1.take (reverseMultiple.1.length / 2))
              (reverseMultiple.1.reverse.take (reverseMultiple.1.length / 2))) ∧
        (∀ reverseMultiple,
          (oddCorrespondence reverseMultiple).1.1 =
              List.zip
                (reverseMultiple.1.take (reverseMultiple.1.length / 2))
                (reverseMultiple.1.reverse.take (reverseMultiple.1.length / 2)) ∧
            ∃ middle r s,
              (reverseMultiple.1.drop (reverseMultiple.1.length / 2)).head? =
                some middle ∧
              (oddCorrespondence reverseMultiple).1.2.getLast? = some (r, s) ∧
              Transition (r, s) (middle, middle) (s, r))
