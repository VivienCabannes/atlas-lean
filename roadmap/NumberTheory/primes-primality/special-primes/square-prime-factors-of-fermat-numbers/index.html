    TheoremSquared prime factors of Fermat numbers via Wieferich primes and orders#●ready to prove

    MetaMathlibExt.sq_dvd_fermatNumber_iff_wieferich_orderOf

    Let \(F_n = 2^{2^n} + 1\) be the \(n\)-th Fermat number. For every natural number \(n\) and every odd prime \(p\), \(p^2\) divides \(F_n\) if and only if \(p\) is a Wieferich prime (to base \(2\)) and the multiplicative order of \(2\) modulo \(p\) is \(2^{n+1}\).

    This follows from the criterion that a prime \(p\) dividing \(F_n\) satisfies \(p^2 \mid F_n\) exactly when \(2^{p-1} \equiv 1 \pmod{p^2}\), since an odd prime \(p\) divides \(F_n\) exactly when the order of \(2\) modulo \(p\) is \(2^{n+1}\).

    MetaMathlibExt.gcd_pow_pow_add_one

    For natural numbers \(a\), \(b\) and \(k\) write \(F_k(a, b) = a^{b^k} + 1\), and let \(a, b \ge 2\) and \(m\), \(n\) be natural numbers. If \(n < m\) and \(a\) and \(b\) are both even, then \(\gcd(F_m(a, b), F_n(a, b)) = 1\). If \(n < m\), \(a\) is odd and \(b\) is even, then \(\gcd(F_m(a, b), F_n(a, b)) = 2\). If \(n \le m\) and \(b\) is odd, then \(\gcd(F_m(a, b), F_n(a, b)) = F_n(a, b)\).

    The source assumes \(a, b > 2\) and \(0 \le n \le m\); its proof uses only \(a, b \ge 2\) and treats \(m > n\) ("Since \(m > n\)"), and the first two cases fail for \(m = n\): for \(a = b = 4\) and \(m = n = 0\) the gcd is \(\gcd(5, 5) = 5\), and for \(a = 3\), \(b = 4\) and \(m = n = 0\) it is \(\gcd(4, 4) = 4\).

    public theorem_wanted gcd_pow_pow_add_one {a b m n : ℕ} (ha : 2 ≤ a) (hb : 2 ≤ b) :
    (n < m → Even a → Even b → Nat.gcd (a ^ b ^ m + 1) (a ^ b ^ n + 1) = 1) ∧
      (n < m → Odd a → Even b → Nat.gcd (a ^ b ^ m + 1) (a ^ b ^ n + 1) = 2) ∧
      (n ≤ m → Odd b → Nat.gcd (a ^ b ^ m + 1) (a ^ b ^ n + 1) = a ^ b ^ n + 1)

    TheoremSquared prime factors of generalized Fermat numbers#●ready to prove

    MetaMathlibExt.sq_dvd_pow_pow_add_one_wieferich

    For natural numbers \(a\), \(b\) and \(n\) write \(F_n(a, b) = a^{b^n} + 1\). Let \(a, b \ge 2\), let \(n\) be a natural number, let \(p\) be an odd prime coprime to \(ab\), and write \(\operatorname{ord}_p(a)\) for the multiplicative order of \(a\) modulo \(p\). If \(p^2\) divides \(F_n(a, b)\), then \(a^{p-1} \equiv 1 \pmod{p^2}\) (that is, \(p\) is a Wieferich prime to base \(a\)) and \(\operatorname{ord}_p(a)\) divides \(2b^n\).       (a ^ (p - 1) ≡ 1 [MOD p ^ 2] → orderOf (a : ZMod p) = 2 * b ^ n →
