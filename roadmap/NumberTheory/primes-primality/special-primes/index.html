    DefinitionFortunate numbers#✓fully proved

    MetaMathlibExt.IsFortunateNumber

    Write \(q\#\) for the primorial of a natural number \(q\), the product of all primes \(p \le q\). For natural numbers \(q\) and \(m\), \(m\) is the Fortunate number of \(q\) when \(q\) is prime, \(m > 1\), \(q\# + m\) is prime, and \(q\# + k\) is not prime for any \(k\) with \(1 < k < m\).

    def IsFortunateNumber (q m : ℕ) : Prop :=
  q.Prime ∧ 1 < m ∧ (primorial q + m).Prime ∧
    ∀ k, 1 < k → k < m → ¬ (primorial q + k).Prime

    TheoremGandhi's formula for the \(n\)th prime#✓fully proved

    MathlibExt.NumberTheory.PrimeCounting.GandhiNthPrimeFormulaWanted.gandhi_nthPrimeFormula

    For \(i \ge 1\) let \(p_i\) be the \(i\)th prime, so that \(p_1 = 2\), and for \(n \ge 1\) let \(P_{n-1} = p_1 p_2 \cdots p_{n-1}\), the empty product \(1\) when \(n = 1\). Let \(\mu\) be the Möbius function. Then for every \(n \ge 1\),

    \[p_n = \left\lfloor 1 - \log_2 \left( -\frac{1}{2} + \sum_{d \mid P_{n-1}} \frac{\mu(d)}{2^d - 1} \right) \right\rfloor.\]

    DefinitionGeneralized Fermat number#✓fully proved

    MetaMathlibExt.generalizedFermatNumber

    For an even natural number \(b\) and a positive integer \(n\), the generalized Fermat number is \(F_n(b) = b^{2^n} + 1\) (also written \(F_{b,n}\)).

    def generalizedFermatNumber (b n : ℕ) (_hb : Even b) (_hn : 0 < n) : ℕ :=
  b ^ (2 ^ n) + 1
