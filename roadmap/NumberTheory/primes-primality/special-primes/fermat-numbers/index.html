    DefinitionFermat prime#✓fully proved

    MetaMathlibExt.IsFermatPrime

    A natural number \(p\) is a Fermat prime if \(p\) is prime and \(p = 2^{2^k} + 1\) for some natural number \(k\), that is, \(p\) is a prime Fermat number.

    def IsFermatPrime (p : ℕ) : Prop :=
  Nat.Prime p ∧ ∃ k : ℕ, p = Nat.fermatNumber k

    TheoremPreperiod and period of Fermat numbers modulo an odd prime#✓fully proved

    Nat.fermatNumber_mod_prime_exact_preperiod_period

    Let \(p\) be an odd prime and write the multiplicative order of \(2\) modulo \(p\) as \(2^v w\) with \(v, w\) natural numbers and \(w\) odd. Let \(k\) be the multiplicative order of \(2\) modulo \(w\) (so \(k = 1\) when \(w = 1\)), and let \(F_m = 2^{2^m} + 1\) be the \(m\)-th Fermat number. Then the sequence \(n \mapsto F_{v+n} \bmod p\) is periodic with period \(k\); for every \(h < v\), the sequence \(n \mapsto F_{h+n} \bmod p\) has no positive period; and every positive period of the sequence \(n \mapsto F_{v+n} \bmod p\) is divisible by \(k\).

    theorem fermatNumber_mod_prime_exact_preperiod_period (p v w : ℕ)
    (hp : p.Prime) (hp2 : p ≠ 2)
    (hord : orderOf (2 : ZMod p) = 2 ^ v * w) (hw : Odd w) :
    let k := orderOf (2 : ZMod w);
      Function.Periodic (fun n : ℕ => (Nat.fermatNumber (v + n) : ZMod p)) k ∧
        (∀ h < v, ¬ ∃ kp : ℕ, 0 < kp ∧
          Function.Periodic (fun n : ℕ => (Nat.fermatNumber (h + n) : ZMod p)) kp) ∧
        (∀ kp : ℕ, 0 < kp →
          Function.Periodic (fun n : ℕ => (Nat.fermatNumber (v + n) : ZMod p)) kp → k ∣ kp)

    TheoremTwo of \(F_0, \dots, F_p\) are congruent modulo \(p\)#●ready to prove

    MetaMathlibExt.fermatNumber_modEq_exists_repeat

    Write \(F_n = 2^{2^n} + 1\). For every positive integer \(p\) there are natural numbers \(i < j \le p\) with \(F_i \equiv F_j \pmod p\).

    This is the pigeonhole principle; \(p\) need not be prime.

    public theorem_wanted fermatNumber_modEq_exists_repeat (p : ℕ) (hp : 0 < p) :
    ∃ i j, i < j ∧ j ≤ p ∧ Nat.fermatNumber i ≡ Nat.fermatNumber j [MOD p]

    TheoremUniqueness of the \(2\)-adic decomposition of the index of \(2\)#●ready to prove

    MetaMathlibExt.existsUnique_twoAdic_index_of_two

    Let \(p\) be an odd prime and write \(p - 1 = 2^r u\) with \(u\) odd. Then there is exactly one pair \((s, t)\) of natural numbers with \(s \le r\) and \(t \mid u\) such that \(g^{2^s t} = 2\) for some primitive root \(g\) modulo \(p\) (an element of order \(p - 1\) in \(\mathbb{Z}/p\mathbb{Z}\)).

    Since \(2^s t\) divides \(p - 1\), it lies in \(\{1, \dots, p - 1\}\), so it is the index \(\operatorname{ind}_g(2)\) of \(2\) with respect to \(g\).
