    Nat.IsCarmichaelNumber

    A natural number \(n\) is a Carmichael number if \(n > 1\), \(n\) is not prime, and \(a^n \equiv a \pmod{n}\) for every natural number \(a\).

    def Nat.IsCarmichaelNumber (n : ℕ) : Prop :=
  1 < n ∧ ¬n.Prime ∧ ∀ a : ℕ, a ^ n ≡ a [MOD n]

    A natural number \(n\) is a Carmichael number if and only if \(n > 1\), \(n\) is not prime, and \(x^n = x\) for every element \(x\) of \(\mathbb{Z}/n\mathbb{Z}\).

    TheoremKorselt's criterion#✓fully proved

    Nat.isCarmichaelNumber_iff_korselt

    A natural number \(n > 1\) is a Carmichael number if and only if \(n\) is squarefree, \(p - 1\) divides \(n - 1\) for every prime divisor \(p\) of \(n\), and \(n\) is not prime.

    theorem Nat.isCarmichaelNumber_iff_korselt (n : ℕ) (hn : 1 < n) :
    Nat.IsCarmichaelNumber n ↔
      Squarefree n ∧
        (∀ p : ℕ, p.Prime → p ∣ n → (p - 1) ∣ (n - 1)) ∧ ¬n.Prime
    def Nat.IsCarmichaelNumber (n : ℕ) : Prop :=

    MetaMathlibExt.exists_carmichael_prime_cardFactors_between_of_heathBrown

    Assume Heath-Brown's conjecture in the following form: there is a real constant \(C\) such that for every natural number \(d \ge 2\) and every natural number \(c\) coprime to \(d\) there is a prime \(p \equiv c \pmod{d}\) with \(p \le C d (\log d)^2\). Let \(1 < \theta < 2\), and let \(\gamma > 0\) be such that for all sufficiently large real \(y\), the number of primes \(q\) with \(y^\theta / \log y \le q \le y^\theta\) such that every prime divisor of \(q - 1\) is at most \(y\) is at least \(\gamma y^\theta / \log(y^\theta)\). Then there is a real \(Y\) such that for every real \(y > Y\) there is a Carmichael number \(n\) with \(e^{(\gamma/4) y^\theta \log y} \le n \le e^{e^{19 \theta y}}\) whose number of prime factors counted with multiplicity, \(\Omega(n)\), is prime.
