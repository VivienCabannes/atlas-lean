    AbbreviationPartial density#✓fully proved

    Set.partialDensity

    Let \(\beta\) be a preorder in which every set \(\{x \in \beta \mid x \le b\}\) is finite, let \(S, A \subseteq \beta\) and \(b \in \beta\), and write \(A_{\lt b} = \{x \in A \mid x < b\}\). The partial density of \(S\) relative to \(A\) at \(b\) is the proportion \(\lvert S \cap A_{\lt b} \rvert / \lvert A_{\lt b} \rvert\) of elements of \(A_{\lt b}\) that lie in \(S\), taken to be \(0\) when \(A_{\lt b}\) is empty. By default \(A = \beta\).

    @[inline]
noncomputable abbrev partialDensity {β : Type*} [Preorder β] [LocallyFiniteOrderBot β]
    (S : Set β) (A : Set β := Set.univ) (b : β) : ℝ :=
  ((S ∩ A) ∩ Iio b).ncard / (A ∩ Iio b).ncard

    DefinitionDensity of a set#✓fully proved

    Set.HasDensity

    Let \(\beta\) be a preorder in which every set \(\{x \in \beta \mid x \le b\}\) is finite, let \(S, A \subseteq \beta\) and \(\alpha \in \mathbb{R}\), and write \(\beta_{\lt b} = \{x \in \beta \mid x < b\}\). The set \(S\) has density \(\alpha\) relative to \(A\) if the partial density \(\lvert S \cap A \cap \beta_{\lt b} \rvert / \lvert A \cap \beta_{\lt b} \rvert\), taken to be \(0\) when the denominator is \(0\), tends to \(\alpha\) as \(b \to \infty\) in \(\beta\).

    By default \(A = \beta\); for \(\beta = \mathbb{N}\) this is the natural density of \(S\).

    def HasDensity {β : Type*} [Preorder β] [LocallyFiniteOrderBot β]
    (S : Set β) (α : ℝ) (A : Set β := Set.univ) : Prop :=
  Tendsto (fun (b : β) => S.partialDensity A b) atTop (𝓝 α)

    DefinitionTwo-sided partial density#✓fully proved

    Set.intPartialDensity

    For a set \(S\) of integers and a natural number \(N\), the two-sided partial natural density of \(S\) at \(N\) is \(\lvert S \cap [-N, N] \rvert / (2N + 1)\), where \([-N, N]\) is the set of integers \(m\) with \(-N \le m \le N\).

    noncomputable def intPartialDensity (S : Set ℤ) (N : ℕ) : ℝ :=
  open scoped Classical in
  (((Finset.Icc (-(N : ℤ)) (N : ℤ)).filter (fun m => m ∈ S)).card : ℝ) /
    (2 * (N : ℝ) + 1)

    DefinitionLogarithmic density#✓fully proved

    Set.HasLogDensity

    A set \(A\) of natural numbers has logarithmic density \(d \in \mathbb{R}\) if \(\frac{1}{\log n} \sum_{k \in A,\, k \le n} \frac{1}{k}\) tends to \(d\) as \(n \to \infty\), where \(\log\) is the natural logarithm, the term \(1/k\) for \(k = 0\) is taken to be \(0\), and the whole expression is taken to be \(0\) when \(\log n = 0\).

    Logarithmic density is a weaker notion than natural density: if a set has natural density \(d\), then it also has logarithmic density \(d\), but the converse is false.

    def Set.HasLogDensity (A : Set ℕ) (d : ℝ) : Prop :=
  open scoped Classical in
  Tendsto (fun n : ℕ => (∑ k ≤ n with k ∈ A, (k : ℝ)⁻¹ / .log n : ℝ)) atTop (𝓝 d)
