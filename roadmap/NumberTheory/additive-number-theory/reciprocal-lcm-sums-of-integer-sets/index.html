    DefinitionLogarithmic gcd moment#✓fully proved

    MetaMathlibExt.gcdLogarithmicMoment

    For a set \(A\) of natural numbers and a real number \(x\), the logarithmic gcd moment of \(A\) up to \(x\) is the sum of \(\gcd(n, m)/(nm)\) over all ordered pairs \((n, m)\) with \(n, m \in A\), \(1 \le n \le x\) and \(1 \le m \le x\).

    When \(A \cap [1, x]\) is nonempty, dividing by \(\big(\sum_{n \in A,\ 1 \le n \le x} 1/n\big)^2\) gives the expected value of \(\gcd(n, m)\) for \(n\) and \(m\) drawn independently from \(A \cap [1, x]\), each with probability proportional to \(1/n\).

    public noncomputable def gcdLogarithmicMoment (A : Set ℕ) (x : ℝ) : ℝ :=
  ∑ n ∈ naturalsInSetUpTo A x,
    ∑ m ∈ naturalsInSetUpTo A x,
      (Nat.gcd n m : ℝ) / ((n : ℝ) * (m : ℝ))
    public noncomputable def naturalsInSetUpTo (A : Set ℕ) (x : ℝ) : Finset ℕ :=
  open Classical in (Finset.Icc 1 ⌊x⌋₊).filter (fun n => n ∈ A)

    DefinitionGcd defect#✓fully proved

    MetaMathlibExt.lcmDefect

    For a set \(A\) of natural numbers and a real number \(x\), let \(S_A(x) = \sum_{n \in A,\ 1 \le n \le x} 1/n\) be the harmonic sum of \(A\) up to \(x\), and let \(G_A(x)\) be the sum of \(\gcd(n, m)/(nm)\) over all ordered pairs \((n, m)\) with \(n, m \in A\), \(1 \le n \le x\) and \(1 \le m \le x\).     MetaMathlibExt.primeProductLayer

    For a set \(\mathcal{P}\) of natural numbers and \(k \in \mathbb{N}\), \(\mathcal{P}^{[k]}\) is the set of squarefree natural numbers \(n\) whose prime divisors all lie in \(\mathcal{P}\) and which have exactly \(k\) distinct prime divisors; that is, the products of exactly \(k\) distinct primes from \(\mathcal{P}\).
