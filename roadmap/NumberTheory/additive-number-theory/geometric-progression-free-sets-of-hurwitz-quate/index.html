    TheoremNumber of Hurwitz quaternions of a given norm#●ready to prove

    MetaMathlibExt.card_hurwitz_norm_eq

    A Hurwitz quaternion is a quaternion \(q = x_0 + x_1 i + x_2 j + x_3 k\) whose rational coordinates \(x_0, x_1, x_2, x_3\) are either all integers or all halves of odd integers, and its norm is \(\mathrm{Nm}(q) = x_0^2 + x_1^2 + x_2^2 + x_3^2\). For every positive integer \(N\), the number of Hurwitz quaternions of norm \(N\) is \(24 \sum_{d \mid N,\ d \text{ odd}} d\), that is, \(24\) times the sum of the odd divisors of \(N\).

    public theorem_wanted card_hurwitz_norm_eq (N : ℕ) (hN : 0 < N) :
    (Set.ofPred fun q : Quaternion ℚ => q ∈ 𝐇 ∧ Quaternion.normSq q = (N : ℚ)).ncard =
      24 * ∑ d ∈ N.divisors with Odd d, d

    TheoremCounting Hurwitz quaternions of bounded norm#●ready to prove

    MetaMathlibExt.card_hurwitz_norm_le_asymptotic

    A Hurwitz quaternion is a quaternion whose four rational coordinates are either all integers or all halves of odd integers; its norm is the sum of the squares of its coordinates. For a natural number \(N\) let \(S(N)\) be the set of nonzero Hurwitz quaternions of norm at most \(N\).

    (a) There is a real constant \(C\) such that \(\bigl| |S(N)| - \pi^2 N^2 \bigr| \le C N \log N\) for every natural number \(N \ge 2\).

    (b) For every positive integer \(M\) there is a real constant \(C\) such that, for every natural number \(N \ge 2\), the number \(c_M(N)\) of Hurwitz quaternions whose norm is a positive integer \(n \le N\) coprime to \(M\) satisfies

    \[\Bigl| c_M(N) - \pi^2 N^2 \cdot \frac{\varphi(2M)}{M} \prod_{p \mid M} \Bigl(1 - \frac{1}{p^2}\Bigr) \Bigr| \le C N \log N,\]

    where \(\varphi\) is Euler's totient function and the product runs over the primes \(p\) dividing \(M\).

    public theorem_wanted card_hurwitz_norm_le_asymptotic :
    (∃ C : ℝ, ∀ N : ℕ, 2 ≤ N →
      |((𝐒 N).ncard : ℝ) - Real.pi ^ 2 * (N : ℝ) ^ 2| ≤ C * N * Real.log N) ∧
    ∀ M : ℕ, 0 < M → ∃ C : ℝ, ∀ N : ℕ, 2 ≤ N →
      |((Set.ofPred fun q : Quaternion ℚ => q ∈ 𝐇 ∧
            ∃ n : ℕ, Quaternion.normSq q = (n : ℚ) ∧ 0 < n ∧ n ≤ N ∧ n.Coprime M).ncard : ℝ) -
          Real.pi ^ 2 * (N : ℝ) ^ 2 * ((Nat.totient (2 * M) : ℝ) / M) *
            ∏ p ∈ M.primeFactors, (1 - 1 / (p : ℝ) ^ 2)| ≤ C * N * Real.log N

    TheoremDensity of Hurwitz quaternions whose norm has prescribed prime exponents#●ready to prove

    MetaMathlibExt.density_hurwitz_norm_valuations_in

    A Hurwitz quaternion is a quaternion whose four rational coordinates are either all integers or all halves of odd integers; its norm is the sum of the squares of its coordinates. For a natural number \(N\) let \(S(N)\) be the set of nonzero Hurwitz quaternions of norm at most \(N\). Let \(A\) be a set of natural numbers, let \(G\) be the set of positive integers \(n\) such that for every prime \(p\) the exponent \(\nu_p(n)\) of \(p\) in \(n\) lies in \(A\), and let \(H_G\) be the set of Hurwitz quaternions whose norm lies in \(G\). Then the ratio \(|H_G \cap S(N)| / |S(N)|\) tends, as \(N \to \infty\), to

    \[\frac{6}{\pi^2} \Bigl( \sum_{k \in A} 2^{-2k} \Bigr) \prod_{p > 2} \Bigl( \sum_{k \in A} p^{-k} - \frac{1}{p} \sum_{k \in A} p^{-2k} \Bigr),\]

    the product running over the odd primes \(p\). Here \(6/\pi^2 = 1/\zeta(2)\).

    public theorem_wanted density_hurwitz_norm_valuations_in (A : Set ℕ) :
    Filter.Tendsto
      (fun N : ℕ => ρ (𝐒ᴳ (Set.ofPred fun n : ℕ =>
        0 < n ∧ ∀ p : ℕ, p.Prime → n.factorization p ∈ A)) N)
      Filter.atTop
      (nhds (6 / Real.pi ^ 2 * (∑' k : A, 1 / (2 : ℝ) ^ (2 * (k : ℕ))) *
        ∏' p : {p : ℕ // p.Prime ∧ 2 < p},
          (∑' k : A, 1 / ((p : ℕ) : ℝ) ^ (k : ℕ) -
            1 / ((p : ℕ) : ℝ) * ∑' k : A, 1 / ((p : ℕ) : ℝ) ^ (2 * (k : ℕ)))))

    TheoremDensity of Hurwitz quaternions with norm in Rankin's greedy set#●ready to prove

    MetaMathlibExt.density_hurwitz_norm_in_rankin_greedy

    A Hurwitz quaternion is a quaternion whose four rational coordinates are either all integers or all halves of odd integers; its norm is the sum of the squares of its coordinates. For a natural number \(N\) let \(S(N)\) be the set of nonzero Hurwitz quaternions of norm at most \(N\). Let \(G\) be the set of positive integers \(n\) such that, for every prime \(p\), the base-\(3\) digits of the exponent \(\nu_p(n)\) of \(p\) in \(n\) include no \(2\) (this is Rankin's greedy set of positive integers avoiding 3-term geometric progressions), and let \(H_G\) be the set of Hurwitz quaternions whose norm lies in \(G\). With \(f(x) = \prod_{i \ge 0} \bigl(1 + x^{-3^i}\bigr)\), the ratio \(|H_G \cap S(N)| / |S(N)|\) tends, as \(N \to \infty\), to

    \[\frac{6}{\pi^2} \, f(4) \prod_{p > 2} \Bigl( f(p) - \frac{f(p^2)}{p} \Bigr),\]

    the product running over the odd primes \(p\).

    The paper writes this constant as \((f(2^2)/\zeta(2)) \prod_{p > 2} (f(p) - f(p^2)/p)\), using \(1/\zeta(2) = 6/\pi^2\), and gives its value as approximately \(0.782643\).

            (∏' i : ℕ, (1 + 1 / (((p : ℕ) : ℝ) ^ 2) ^ (3 ^ i))) / ((p : ℕ) : ℝ))))

    TheoremMany disjoint geometric progressions among Hurwitz quaternions#●ready to prove

    MetaMathlibExt.disjoint_progressions_hurwitz_card

    A Hurwitz quaternion is a quaternion whose four rational coordinates are either all integers or all halves of odd integers; its norm is the sum of the squares of its coordinates. For a natural number \(N\) let \(S(N)\) be the set of nonzero Hurwitz quaternions of norm at most \(N\). Fix a Hurwitz quaternion \(R\) of norm \(2\), and for a natural number \(N\) let \(E(N)\) be the set of triples \((bR^{3n}, bR^{3n+1}, bR^{3n+2})\), where \(n\) is a natural number and \(b\) is a Hurwitz quaternion whose norm is an odd integer at most \(N / 2^{3n+2}\). Then for every \(N\), every triple in \(E(N)\) has the form \((a, aR, aR^2)\) with all three entries in \(S(N)\), and two distinct triples in \(E(N)\) have no entry in common. Moreover there is a real constant \(C\) such that

    \[\Bigl| |E(N)| - \frac{\pi^2 N^2}{21} \Bigr| \le C N (\log N)^2\]

    for every natural number \(N \ge 2\).

    public theorem_wanted disjoint_progressions_hurwitz_card (R : Quaternion ℚ) (hR : R ∈ 𝐇)
    (hR2 : Quaternion.normSq R = 2) :
    let E : ℕ → Set (Quaternion ℚ × Quaternion ℚ × Quaternion ℚ) := fun N =>
      Set.ofPred fun t => ∃ n : ℕ, ∃ b ∈ 𝐇, ∃ m : ℕ, Odd m ∧
        Quaternion.normSq b = (m : ℚ) ∧ (m : ℚ) ≤ (N : ℚ) / 2 ^ (3 * n + 2) ∧
        t = (b * R ^ (3 * n), b * R ^ (3 * n + 1), b * R ^ (3 * n + 2))
    (∀ N : ℕ, ∀ t ∈ E N,
      (t.1 ∈ 𝐒 N ∧ t.2.1 ∈ 𝐒 N ∧ t.2.2 ∈ 𝐒 N ∧ t.2.1 = t.1 * R ∧ t.2.2 = t.1 * R ^ 2) ∧
      ∀ t' ∈ E N, t ≠ t' →
        Disjoint ({t.1, t.2.1, t.2.2} : Set (Quaternion ℚ)) {t'.1, t'.2.1, t'.2.2}) ∧
    ∃ C : ℝ, ∀ N : ℕ, 2 ≤ N →
      |((E N).ncard : ℝ) - Real.pi ^ 2 * (N : ℝ) ^ 2 / 21| ≤ C * N * Real.log N ^ 2

Let \(\mathcal{G}\) be a set of quaternions such that a quaternion \(q\) lies in \(\mathcal{G}\) if and only if \(q\) is a nonzero Hurwitz quaternion and there are no \(a \in \mathcal{G}\) and Hurwitz quaternion \(r \ne 0\) with \(\mathrm{Nm}(r) \ne 1\), \(ar \in \mathcal{G}\) and \(q = ar^2\) (this recursion on the norm characterizes the quaternion greedy set). Let \(p\) be a prime and \(Q\) a Hurwitz quaternion of norm \(p^2\) that cannot be written as \(Q = UR^2\) with \(U\) a Hurwitz unit and \(R\) a Hurwitz quaternion of norm \(p\). Then \(Q \in \mathcal{G} \setminus S(G^*_3)\) and \(Q^2 \in S(G^*_3) \setminus \mathcal{G}\).
