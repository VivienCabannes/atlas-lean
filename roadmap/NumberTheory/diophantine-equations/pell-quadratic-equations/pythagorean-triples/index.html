    DefinitionAmato's cathetus parameter set#✓fully proved

    MetaMathlibExt.amatoCathetusParams

    For a natural number \(x\), let \(n\) be the exponent of \(2\) in \(x\) (taken to be \(0\) for \(x = 0\)). The set \(C(x)\) consists of the natural numbers \(d\) with \(d \le x\) and \(d \mid x^2\) such that, if \(x\) is even, \(d = 2^s l\) for some natural numbers \(s\) and \(l\) with \(1 \le s \le n - 1\) and \(l \mid x^2\).

    This is the definition as printed in the source: for odd \(x\) it is \(D(x) = \{d \in \mathbb{N} : d \le x,\ d \mid x^2\}\), and for even \(x = 2^n k\) with \(k\) odd it is \(D(x) \cap P(x)\) with \(P(x) = \{2^s l : l \mid x^2,\ s \in \{1, \dots, n - 1\}\}\).

    def amatoCathetusParams (x : ℕ) : Set ℕ :=
  {d | d ≤ x ∧ d ∣ x ^ 2 ∧
    (Even x → ∃ s l : ℕ, 1 ≤ s ∧ s ≤ padicValNat 2 x - 1 ∧ l ∣ x ^ 2 ∧ d = 2 ^ s * l)}

    DefinitionAmato's product of triples#✓fully proved

    MetaMathlibExt.pythagoreanTripleMul

    For a commutative ring \(R\), the product of two triples \((x, y, z)\) and \((x', y', z')\) in \(R^3\) is

    \[(x, y, z) \star (x', y', z') = (x x',\ y z' + z y',\ y z' + z y' + (z - y)(z' - y')).\]

    This is the source's product (4); its operation (12) on integral triples is the same formula.

    def pythagoreanTripleMul {R : Type*} [CommRing R] (u v : R × R × R) : R × R × R :=
  (u.1 * v.1, u.2.1 * v.2.2 + u.2.2 * v.2.1,
    u.2.1 * v.2.2 + u.2.2 * v.2.1 + (u.2.2 - u.2.1) * (v.2.2 - v.2.1))

    Together with the closure of \(E\) under \(\star\) (stated separately), this makes \(E\) an infinite commutative group under \(\star\) with identity \((1, 0, 1)\).
