    Sums of consecutive squares

    DefinitionThe sum of consecutive squares equation#✓fully proved

    MetaMathlibExt.SoCSEq

    Integers \(a\), \(b\), \(c\) satisfy the sum of consecutive squares (SoCS) equation when \(2\,b(b+1)(2b+1) = a(a+1)(2a+1) + c(c+1)(2c+1)\).

    With \(P_n = n(n+1)(2n+1)/6\) this is \(P_a + P_c = 2P_b\) multiplied by \(6\). For \(a < b < c\) it is equivalent to \((a+1)^2 + (a+2)^2 + \dots + b^2 = (b+1)^2 + (b+2)^2 + \dots + c^2\), since \(P_n - P_{n-1} = n^2\). No order or sign condition on \(a\), \(b\), \(c\) is imposed.

    public def SoCSEq (a b c : ℤ) : Prop :=
  2 * (b * (b + 1) * (2 * b + 1))
    = a * (a + 1) * (2 * a + 1) + c * (c + 1) * (2 * c + 1)
