    DefinitionThe Pell interpolation function u#✓fully proved

    MetaMathlibExt.pellU

    For integers \(D\), \(\alpha\), \(\beta\), the function \(u : \mathbb{R} \to \mathbb{R}\) is \(u(x) = ((\alpha + \beta\sqrt D)^x + (\alpha - \beta\sqrt D)^x)/2\), where \(\sqrt D\) is the real square root (zero when \(D < 0\)) and \((\cdot)^x\) is the real power.

    public noncomputable def pellU (D α β : ℤ) (x : ℝ) : ℝ :=
  ((α + β * Real.sqrt D) ^ x + (α - β * Real.sqrt D) ^ x) / 2

    TheoremPell solutions are signed powers of the fundamental solution#●ready to prove

    MetaMathlibExt.pell_solutions_eq_signed_powers

    Let \(D\) be an integer and let \((\alpha, \beta)\) be a fundamental solution of \(x^2 - Dy^2 = 1\), that is, an integer solution with \(\alpha > 1\) and \(\beta > 0\) such that \(\alpha \le x\) for every integer solution \((x, y)\) with \(x > 1\) (one exists only when \(D\) is positive and not a square). For \(n \ge 0\) let \(u_n, v_n\) be the integers with \(u_n + v_n\sqrt D = (\alpha + \beta\sqrt D)^n\). Then integers \(x, y\) satisfy \(x^2 - Dy^2 = 1\) if and only if \(x = i\,u_n\) and \(y = j\,v_n\) for some integer \(n \ge 0\) and some signs \(i, j \in \{1, -1\}\).

    public theorem_wanted pell_solutions_eq_signed_powers {D : ℤ} {a : Pell.Solution₁ D}
    (ha : Pell.IsFundamental a) (x y : ℤ) :
    x ^ 2 - D * y ^ 2 = 1 ↔
      ∃ n : ℕ, ∃ i j : ℤ, (i = 1 ∨ i = -1) ∧ (j = 1 ∨ j = -1) ∧
        x = i * (a ^ n).x ∧ y = j * (a ^ n).y

    MetaMathlibExt.pell_solutions_in_rotated_square

    Let \(D\) be an integer and let \((\alpha, \beta)\) be a fundamental solution of \(x^2 - Dy^2 = 1\), that is, an integer solution with \(\alpha > 1\) and \(\beta > 0\) such that \(\alpha \le x\) for every integer solution \((x, y)\) with \(x > 1\) (one exists only when \(D\) is positive and not a square).     TheoremLargest intercept norm of a shifted Pell curve#●ready to prove

    MetaMathlibExt.pell_shifted_intercepts_max

    DefinitionThe \(L^1\) norm along a shifted Pell curve#✓fully proved

    MetaMathlibExt.pellShiftedNorm

    For integers \(D\), \(\alpha\), \(\beta\), \(a\), \(b\), \(i\) and \(j\), put \(\varepsilon = \alpha + \beta \sqrt{D}\) and \(\bar\varepsilon = \alpha - \beta \sqrt{D}\), and let \(u(x) = (\varepsilon^x + \bar\varepsilon^x) / 2\) and \(v(x) = (\varepsilon^x - \bar\varepsilon^x) / (2 \sqrt{D})\) for real \(x\).
