    DefinitionGeneralized Markov triple#✓fully proved

    MetaMathlibExt.IsGenMarkovTriple

    For a natural number \(k\), a \(k\)-generalized Markov triple is a triple \((a, b, c)\) of positive integers satisfying the \(k\)-generalized Markov equation \(\mathrm{GME}(k)\):

    \[a^2 + b^2 + c^2 + k(bc + ca + ab) = (3 + 3k)abc.\]

    For \(k = 0\) these are the classical Markov triples.

    public def IsGenMarkovTriple (k a b c : ℕ) : Prop :=
  0 < a ∧ 0 < b ∧ 0 < c ∧
    a ^ 2 + b ^ 2 + c ^ 2 + k * (b * c + c * a + a * b) = (3 + 3 * k) * a * b * c
