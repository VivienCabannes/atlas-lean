    TheoremPowers of three plus one that are perfect squares#✓fully proved

    Nat.eq_zero_of_three_pow_succ_add_one_eq_sq

    For natural numbers \(y\) and \(z\), if \(3^{y+1} + 1 = z^2\), then \(y = 0\).

    theorem eq_zero_of_three_pow_succ_add_one_eq_sq {y z : ℕ}
    (h : 3 ^ (y + 1) + 1 = z ^ 2) : y = 0
    Sources

    TheoremSolutions of \(p^x + (p + a)^y = z^2\) for odd primes \(p\) and \(p + a\)#●ready to prove

    MathlibExt.NumberTheory.ExponentialDiophantineWanted.pow_add_pow_eq_sq

    Let \(p\) be a prime with \(p \ne 2\) and \(p \ne 3\), and let \(a\) be a natural number such that \(p + a\) is prime, \(a \equiv 0 \pmod 4\) and \(p\) divides \(a + 1\). If natural numbers \(x\), \(y\) and \(z\) satisfy \(p^x + (p + a)^y = z^2\), then \(x = 0\), \(y = 1\) and \(z^2 = p + a + 1\).

    theorem_wanted pow_add_pow_eq_sq (p a x y z : ℕ)

    (hpa : (p + a).Prime) (ha4 : a % 4 = 0)
    (hap : p ∣ a + 1) (h : p ^ x + (p + a) ^ y = z ^ 2) :
    x = 0 ∧ y = 1 ∧ z ^ 2 = p + a + 1

    TheoremTerai's conjecture when \(c\) is prime and \(b \equiv \pm 5 \pmod 8\)#●ready to prove

    MetaMathlibExt.terai_pythagorean_of_prime_of_mod_eight

    Let \(a, b, c\) be natural numbers with \(a^2 + b^2 = c^2\), \(\gcd(a, b, c) = 1\), \(b \equiv \pm 5 \pmod 8\) (that is, \(b\) is \(3\) or \(5\) modulo \(8\)) and \(c\) prime. Then for all positive integers \(x, y, z\), the equation \(x^2 + b^y = c^z\) holds if and only if \((x, y, z) = (a, 2, 2)\).

    This case of the conjecture is due to Yuan and Wang. Terai's conjecture (the paper's Conjecture 1) also assumes \(a\) even, which follows here since \(b\) is odd.

    theorem_wanted terai_pythagorean_of_prime_of_mod_eight {a b c : ℕ} (habc : a ^ 2 + b ^ 2 = c ^ 2)
    (hgcd : Nat.gcd (Nat.gcd a b) c = 1) (hb : b % 8 = 3 ∨ b % 8 = 5) (hc : c.Prime)
    {x y z : ℕ} (hx : 0 < x) (hy : 0 < y) (hz : 0 < z) :
    x ^ 2 + b ^ y = c ^ z ↔ (x, y, z) = (a, 2, 2)
    Sources
    Sources
    • Jing Zhang and Yuan Li, On the Equation (-1)^α p^x + (-1)^β (2^k(2p - 1))^y = z^2 for Prime Pairs (p, 2p - 1), INTEGERS 24 (2024), Article A64, Lemma 6 and Conjecture 1.
