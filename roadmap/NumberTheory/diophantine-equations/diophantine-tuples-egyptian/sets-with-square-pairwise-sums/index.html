    DefinitionFamilies whose pairwise sums are squares#✓fully proved

    MathlibExt.NumberTheory.TwoSetsSumsetSquaresWanted.PairwiseSumsSquares

    Let \(\alpha\) be a type with an addition and a multiplication, and let \((a_i)_{i \in I}\) and \((b_j)_{j \in J}\) be families in \(\alpha\) indexed by arbitrary types \(I\) and \(J\). They have all pairwise sums square when, for every \(i \in I\) and \(j \in J\), the sum \(a_i + b_j\) is a square in \(\alpha\), that is, \(a_i + b_j = c \cdot c\) for some \(c \in \alpha\).

    def PairwiseSumsSquares {ι κ α : Type*} [Add α] [Mul α]
    (a : ι → α) (b : κ → α) : Prop :=
  ∀ i j, IsSquare (a i + b j)

    DefinitionSemi-magic matrix of squares#✓fully proved

    MathlibExt.NumberTheory.TwoSetsSumsetSquaresWanted.IsSemiMagicRoots

    A \(3 \times 3\) integer matrix \(E = (e_{ij})\) has semi-magic squares when the matrix \((e_{ij}^2)\) of its squared entries is semi-magic: there is an integer \(S\) such that \(\sum_{j=1}^{3} e_{ij}^2 = S\) for every row \(i\) and \(\sum_{i=1}^{3} e_{ij}^2 = S\) for every column \(j\).

    def IsSemiMagicRoots (e : Fin 3 → Fin 3 → ℤ) : Prop :=
  ∃ S : ℤ,
    (∀ i : Fin 3, ∑ j : Fin 3, (e i j) ^ 2 = S) ∧
      ∀ j : Fin 3, ∑ i : Fin 3, (e i j) ^ 2 = S
