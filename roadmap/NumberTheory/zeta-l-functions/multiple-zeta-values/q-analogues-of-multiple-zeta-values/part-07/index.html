    DefinitionPartial sums of SZ-star qMZVs#✓fully proved

    MetaMathlibExt.szStarQMZVPartial

    For an index \(k = (k_1, \dots, k_r)\) of natural numbers and a bound \(M \in \mathbb{N}\), the partial sum is the formal power series in \(q\) over \(\mathbb{Q}\)

    \[ \sum_{M \ge m_1 \ge \dots \ge m_r > 0} \prod_{j=1}^{r} \frac{q^{m_j k_j}}{(1 - q^{m_j})^{k_j}}; \]

    for the empty index it is \(1\).

    public noncomputable def szStarQMZVPartial : List ℕ → ℕ → ℚ⟦X⟧
  | [], _ => 1
  | k :: ks, M => ∑ m ∈ Finset.Icc 1 M, (X ^ m * (1 - X ^ m)⁻¹) ^ k * szStarQMZVPartial ks m

    DefinitionSZ-star qMZVs#✓fully proved

    MetaMathlibExt.szStarQMZV

    For an index \(k = (k_1, \dots, k_r)\) of natural numbers, the SZ-star qMZV \(\zeta_q^{SZ,\star}(k)\) is the formal power series in \(q\) over \(\mathbb{Q}\)

    \[ \zeta_q^{SZ,\star}(k_1, \dots, k_r) = \sum_{m_1 \ge \dots \ge m_r > 0} \prod_{j=1}^{r} \frac{q^{m_j k_j}}{(1 - q^{m_j})^{k_j}}, \]

    with \(\zeta_q^{SZ,\star}(\varnothing) = 1\). Precisely, its coefficient of \(q^N\) is defined as the coefficient of \(q^N\) in the partial sum over \(N \ge m_1 \ge \dots \ge m_r > 0\). For \(k_1 \ge 1\) the summands with \(m_1 > N\) have \(q\)-adic order \(> N\), so this is the coefficient of \(q^N\) in the full sum; for \(k_1 = 0\) the full sum is not a formal power series and the value is a junk value.

    public noncomputable def szStarQMZV (k : List ℕ) : ℚ⟦X⟧ :=
  PowerSeries.mk fun N => coeff N (szStarQMZVPartial k N)

    DefinitionThe map from TBZ words to SZ indices#✓fully proved

    MetaMathlibExt.tbzToSZ

    Words in the letters \(\bar{1}\) and \(k \in \mathbb{N}\) are sent to formal \(\mathbb{Q}\)-linear combinations of finite sequences of natural numbers (SZ indices) letter by letter: the empty word goes to the empty index with coefficient \(1\), and a word \(x w\) with first letter \(x\) goes to the image of \(w\) with a new first entry prepended to each index, where \(\bar{1}\) contributes the entry \(1\) and a letter \(k\) contributes the sum of the two terms obtained with the entries \(k\) and \(k - 1\) (subtraction truncated at \(0\), so the letter \(0\) gives the entry \(0\) with coefficient doubled). This is the map \(U_{\mathrm{TBZ}}\) on words.

    public noncomputable def tbzToSZ : List (Option ℕ) → (List ℕ →₀ ℚ)
  | [] => Finsupp.single [] 1
  | none :: w => (tbzToSZ w).mapDomain (List.cons 1)
  | some k :: w => (tbzToSZ w).mapDomain (List.cons k) + (tbzToSZ w).mapDomain (List.cons (k - 1))

    DefinitionThe map \(V_{TBZ}\) from SZ indices to TBZ words#✓fully proved

    MetaMathlibExt.szToTBZ

    For an index \(k = (k_1, \dots, k_r)\) of natural numbers, \(V_{TBZ}(k)\) is the formal \(\mathbb{Q}\)-linear combination of TBZ words (words in the letters \(\bar 1\) and \(j \ge 1\); write \(z_a\) for the one-letter word \(a\)) obtained by replacing each letter \(k_i = 0\) by \(z_1 - z_{\bar 1}\) and each letter \(k_i \ge 1\) by \(\sum_{j=1}^{k_i} (-1)^{k_i - j} z_{j'}\), where \(j' = \bar 1\) for \(j = 1\) and \(j' = j\) otherwise, and multiplying out by concatenation of words. The empty index goes to the empty word with coefficient \(1\).

    public noncomputable def szToTBZ : List ℕ → (List (Option ℕ) →₀ ℚ)
  | [] => Finsupp.single [] 1
  | 0 :: k => (szToTBZ k).mapDomain (List.cons (some 1)) - (szToTBZ k).mapDomain (List.cons none)
  | (a + 1) :: k => ∑ j ∈ Finset.Icc 1 (a + 1),
      ((-1 : ℚ) ^ (a + 1 - j)) •
        (szToTBZ k).mapDomain (List.cons (if j = 1 then none else some j))

    MetaMathlibExt.tbzQMZV_eq_sum_tbzQMZV_szToTBZ_szDual

    Let \(w\) be a TBZ word: each letter is either \(\bar 1\) or a natural number \(k \ge 1\), and the first letter is not the number \(1\).
