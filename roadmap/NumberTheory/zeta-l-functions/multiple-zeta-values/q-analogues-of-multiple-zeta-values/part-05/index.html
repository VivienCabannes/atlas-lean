    DefinitionWeighted quasi-shuffle product#✓fully proved

    MetaMathlibExt.weightedQuasiShuffle

    Let \(A\) be an alphabet and let \(d\) assign to any two letters \(a, b \in A\) a finite formal \(\mathbb{Q}\)-linear combination \(d(a, b) = \sum_c d(a, b)_c \, c\) of letters. The weighted quasi-shuffle product \(u \ast v\) of two words over \(A\) is the finite formal \(\mathbb{Q}\)-linear combination of words defined by recursion on total length: \(\mathbf{1} \ast w = w \ast \mathbf{1} = w\) for the empty word \(\mathbf{1}\), and for letters \(a, b\) and words \(u, v\), \(a u \ast b v = a (u \ast b v) + b (a u \ast v) + \sum_c d(a, b)_c \, c (u \ast v)\), where prefixing a letter is extended linearly to combinations of words.

    public noncomputable def weightedQuasiShuffle {α : Type*} (d : α → α → (α →₀ ℚ)) :
    List α → List α → (List α →₀ ℚ)
  | [], v => Finsupp.single v 1
  | a :: u, [] => Finsupp.single (a :: u) 1
  | a :: u, b :: v =>
      (weightedQuasiShuffle d u (b :: v)).mapDomain (a :: ·) +
        (weightedQuasiShuffle d (a :: u) v).mapDomain (b :: ·) +
        (d a b).sum fun c x => x • (weightedQuasiShuffle d u v).mapDomain (c :: ·)
termination_by u v => u.length + v.length
