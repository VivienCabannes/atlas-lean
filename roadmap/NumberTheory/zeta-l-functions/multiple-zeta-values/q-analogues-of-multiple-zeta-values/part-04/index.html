    DefinitionEulerian q-series#✓fully proved

    MetaMathlibExt.eulerianQSeries

    For natural numbers \(k\) and \(m \ge 1\), the Eulerian \(q\)-series is

    \[ \sum_{n \ge 1} \frac{n^{k-1}}{(k-1)!} \, q^{mn}, \]

    the inner sum of a bi-bracket; here \(k - 1\) is read as \(0\) when \(k = 0\). For \(m = 0\) the series is defined to be \(0\).

    For \(k, m \ge 1\) it equals \(P_k(q^m)/(1 - q^m)^k\), where \(P_k\) is the \(k\)-th Eulerian polynomial.

    public noncomputable def eulerianQSeries (k m : ℕ) : ℚ⟦X⟧ :=
  PowerSeries.mk fun e =>
    if 0 < e ∧ m ∣ e then ((e / m : ℕ) : ℚ) ^ (k - 1) / (k - 1).factorial else 0

    DefinitionPartial sums of bi-brackets#✓fully proved

    MetaMathlibExt.biBracketPartial

    For pairs \((k_1, d_1), \dots, (k_r, d_r)\) of natural numbers and a bound \(M \in \mathbb{N}\), the partial bi-bracket is the \(q\)-series

    \[ \sum_{M > m_1 > \dots > m_r > 0} \, \prod_{j=1}^{r} \frac{m_j^{d_j}}{d_j!} E_{k_j}(m_j), \]

    where \(E_k(m) = \sum_{n \ge 1} \frac{n^{k-1}}{(k-1)!} q^{mn}\) is the Eulerian \(q\)-series (with \(k - 1\) read as \(0\) when \(k = 0\)). For \(r = 0\) it is \(1\).

  | (k, d) :: kd, M => ∑ m ∈ Finset.Ioo 0 M,

    DefinitionBi-brackets#✓fully proved

    MetaMathlibExt.biBracket

    For integers \(k_1, \dots, k_r \ge 1\) and \(d_1, \dots, d_r \ge 0\), the bi-bracket is the \(q\)-series

    \[ g(k_1, \dots, k_r; d_1, \dots, d_r) = \sum_{m_1 > \dots > m_r > 0} \, \sum_{n_1, \dots, n_r > 0} \, \prod_{j=1}^{r} \frac{m_j^{d_j}}{d_j!} \frac{n_j^{k_j - 1}}{(k_j - 1)!} \, q^{m_1 n_1 + \dots + m_r n_r}, \]

    and \(g(\varnothing; \varnothing) = 1\). The summands with \(m_1 > N\) have \(q\)-adic order greater than \(N\), so the coefficient of \(q^N\) is that of the finite partial sum over \(m_1 \le N\); this is how the series is defined.

    The same formula, with \(k_j - 1\) read as \(0\), defines a value when some \(k_j = 0\).

    public noncomputable def biBracket (kd : List (ℕ × ℕ)) : ℚ⟦X⟧ :=
  PowerSeries.mk fun N => coeff N (biBracketPartial kd (N + 1))
