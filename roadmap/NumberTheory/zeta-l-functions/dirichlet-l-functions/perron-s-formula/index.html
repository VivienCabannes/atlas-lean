    PerronKernel.perronKernel

    For real numbers \(y\), \(c\) and \(T\), the truncated Perron kernel is the complex number

    \[K(y, c, T) = \frac{1}{2\pi}\int_{-T}^{T} \frac{y^{c+it}}{c+it}\,dt,\]

    where \(y^s\) is the principal complex power of \(y\) viewed as a complex number.

    Writing \(s = c + it\), this is \(\frac{1}{2\pi i}\int_{c-iT}^{c+iT} \frac{y^s}{s}\,ds\) along the vertical segment.

    noncomputable def perronKernel (y c T : ℝ) : ℂ :=
  (1 / (2 * Real.pi)) * ∫ t : ℝ in (-T)..T,
    (y : ℂ) ^ ((c : ℂ) + t * Complex.I) / ((c : ℂ) + t * Complex.I)

    DefinitionPerron remainder#✓fully proved

    PerronKernel.perronRemainder

    For a real number \(y\) and a complex number \(s\), the Perron remainder is \(R_y(s) = \log y \cdot E_1(s \log y)\), where \(E_1(u) = \int_0^1 e^{tu}\,dt\) is the averaging operator and \(\log\) is the real logarithm (extended by \(\log 0 = 0\) and \(\log y = \log |y|\) for \(y < 0\)).

    The function \(R_y\) is entire, and for \(y > 0\) it agrees with \((y^s - 1)/s\) for \(s \neq 0\).

    noncomputable def perronRemainder (y : ℝ) (s : ℂ) : ℂ :=
  Real.log y * E1 (s * Real.log y)
    noncomputable def E1 (u : ℂ) : ℂ := ∫ t : ℝ in (0:ℝ)..1, Complex.exp (t * u)
