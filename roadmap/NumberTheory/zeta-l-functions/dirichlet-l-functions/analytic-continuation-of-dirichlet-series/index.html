    abelContinuation

    For \(f : \mathbb{N} \to \mathbb{C}\) with partial sums \(A(n) = \sum_{k=1}^{n} f(k)\), the Abel continuation of \(f\) is the function \(F_f : \mathbb{C} \to \mathbb{C}\) given by

    \[F_f(s) = s \int_1^\infty A(\lfloor t \rfloor)\, t^{-s-1}\, dt,\]

    where the integral is taken to be \(0\) when the integrand is not integrable on \((1, \infty)\).

    def abelContinuation (f : ℕ → ℂ) (s : ℂ) : ℂ :=
  s * ∫ t : ℝ in Set.Ioi (1 : ℝ), abelSummatory f t * (t : ℂ) ^ (-(s + 1))

    DefinitionLinear asymptotic Dirichlet continuation#✓fully proved

    linearAsymptoticDirichletContinuation

    For \(a : \mathbb{N} \to \mathbb{C}\) and \(\rho \in \mathbb{C}\), the linear asymptotic Dirichlet continuation of \(a\) with constant \(\rho\) is the function \(L_{a,\rho} : \mathbb{C} \to \mathbb{C}\) given by \(L_{a,\rho}(s) = \rho\,\zeta(s) + F_{a-\rho}(s)\), where \(\zeta\) is the Riemann zeta function and \(F_{a-\rho}\) is the Abel continuation of the sequence \(n \mapsto a(n) - \rho\).

    For \(\rho \neq 0\) the term \(\rho\,\zeta(s)\) carries the pole at \(s = 1\), and \(F_{a-\rho}\) continues the remainder. At \(s = 1\) the formula uses the finite value that Mathlib assigns to \(\zeta(1)\).

    def linearAsymptoticDirichletContinuation (a : ℕ → ℂ) (ρ s : ℂ) : ℂ :=
  ρ * riemannZeta s + abelContinuation (fun n => a n - ρ) s
