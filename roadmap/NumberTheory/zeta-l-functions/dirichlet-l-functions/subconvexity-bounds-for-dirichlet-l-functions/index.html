    Subconvexity bounds for Dirichlet L-functions

    DefinitionCentral-value exponents on a set of levels#✓fully proved

    MathlibExt.NumberTheory.DirichletSubconvexity.IsCentralValueExponentOn

    Let \(S\) be a set of natural numbers and \(\theta\) a real number. Then \(\theta\) is a central-value exponent on \(S\) if \(\theta \ge 0\) and for every \(\varepsilon > 0\) there are a real number \(C > 0\) and a natural number \(Q\) such that for every positive \(q \in S\) with \(q \ge Q\) and every primitive Dirichlet character \(\chi\) modulo \(q\), the analytically continued Dirichlet \(L\)-function satisfies \(|L(1/2, \chi)| \le C q^{\theta + \varepsilon}\).

    The constants \(C\) and \(Q\) may depend on \(\varepsilon\), but not on the level or the character.

    def IsCentralValueExponentOn (levels : Set ℕ) (θ : ℝ) : Prop :=
  0 ≤ θ ∧
    ∀ ε : ℝ, 0 < ε →
      ∃ C : ℝ, 0 < C ∧ ∃ Q : ℕ, ∀ q : ℕ, Q ≤ q → ∀ hq : 0 < q, q ∈ levels →
        letI : NeZero q := ⟨hq.ne'⟩
        ∀ χ : DirichletCharacter ℂ q, χ.IsPrimitive →
          ‖χ.LFunction (1 / 2 : ℂ)‖ ≤ C * Real.rpow (q : ℝ) (θ + ε)

    DefinitionAdmissible exponents for Dirichlet central values#✓fully proved

    MathlibExt.NumberTheory.DirichletSubconvexity.IsDirichletSubconvexityExponent

    A real number \(\theta\) is an admissible conductor-aspect exponent for primitive Dirichlet characters if it is a central-value exponent on the set of all natural numbers: \(\theta \ge 0\), and for every \(\varepsilon > 0\) there are a real number \(C > 0\) and a natural number \(Q\) such that for every positive integer \(q \ge Q\) and every primitive Dirichlet character \(\chi\) modulo \(q\), the analytically continued Dirichlet \(L\)-function satisfies \(|L(1/2, \chi)| \le C q^{\theta + \varepsilon}\).

    TheoremThe Dirichlet subconvexity exponent is nonnegative#✓fully proved

    MathlibExt.NumberTheory.DirichletSubconvexity.dirichletSubconvexityExponent_nonneg
