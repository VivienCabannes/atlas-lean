    TheoremRobin's criterion for the Riemann hypothesis#●ready to prove

    MetaMathlibExt.robin_criterion_for_riemann_hypothesis

    The Riemann hypothesis holds if and only if \(\sigma(n) < e^{\gamma}\, n \log\log n\) for every natural number \(n > 5040\), where \(\sigma(n)\) is the sum of the positive divisors of \(n\), \(\gamma\) is the Euler–Mascheroni constant, and \(\log\) is the natural logarithm.

    theorem_wanted robin_criterion_for_riemann_hypothesis :
    RiemannHypothesis ↔
      ∀ n : ℕ, 5040 < n →
        (ArithmeticFunction.sigma 1 n : ℝ) <
          Real.exp Real.eulerMascheroniConstant * n * Real.log (Real.log n)

    DefinitionRobin exceptional set#✓fully proved

    MetaMathlibExt.robinExceptionalSet

    For a real number \(x\), the Robin exceptional set up to \(x\) is the set of natural numbers \(n\) with \(7! = 5040 < n \le x\) that fail Robin's inequality, that is, with \(\sigma(n) \ge e^\gamma n \log\log n\), where \(\sigma(n)\) is the sum of the divisors of \(n\) and \(\gamma\) is the Euler–Mascheroni constant. Its cardinality is the counting function \(N_R(x)\).

    public noncomputable def robinExceptionalSet (x : ℝ) : Finset ℕ := by
  classical
  exact (Finset.Ioc 5040 ⌊x⌋₊).filter fun n =>
    Real.exp Real.eulerMascheroniConstant * n * Real.log (Real.log n) ≤
      (ArithmeticFunction.sigma 1 n : ℝ)

    DefinitionThe real extension of the harmonic numbers#✓fully proved

    MetaMathlibExt.harmonicExtension

    For a real number \(x\), let

    \[H(x) = \int_0^1 \frac{t^x - 1}{t - 1}\,dt,\]

    where \(t^x\) is the real power and the integral is the Lebesgue integral over \([0, 1]\), taken to be \(0\) when the integrand is not integrable.

    This extends the harmonic numbers: \(H(n) = 1 + \frac{1}{2} + \cdots + \frac{1}{n}\) for every natural number \(n\).

    noncomputable def harmonicExtension (x : ℝ) : ℝ :=
  ∫ t in (0 : ℝ)..1, (t ^ x - 1) / (t - 1)
