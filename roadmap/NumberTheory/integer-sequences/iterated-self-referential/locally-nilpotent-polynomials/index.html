    DefinitionWeakly locally nilpotent polynomial at a point#✓fully proved

    MetaMathlibExt.IsWeaklyLocallyNilpotentAt

    Let \(u \in \mathbb{Z}[x]\) and \(r \in \mathbb{Z}\), and let \(A\) be a set of natural numbers. Write \(u^{(m)}\) for the \(m\)-fold iterate of \(u\) as a map \(\mathbb{Z} \to \mathbb{Z}\). Then \(u\) is weakly locally nilpotent at \(r\) outside \(A\) if for every prime \(p \notin A\) there is \(m \ge 1\) such that \(p\) divides \(u^{(m)}(r)\). For \(A = \emptyset\) this is called locally nilpotent at \(r\).

    Only the primes in \(A\) matter, so \(A\) is usually taken to be a set of primes.

    public def IsWeaklyLocallyNilpotentAt (u : ℤ[X]) (r : ℤ) (A : Set ℕ) : Prop :=
  ∀ p : ℕ, p.Prime → p ∉ A → ∃ m, 0 < m ∧ (p : ℤ) ∣ (fun x => u.eval x)^[m] r
