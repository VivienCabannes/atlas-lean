    DefinitionCompatible semiprimes#✓fully proved

    MetaMathlibExt.IsCompatibleSemiprimePair

    Natural numbers \(p, q, r, s\) form a compatible semiprime pair, and the semiprimes \(pq\) and \(rs\) are called compatible, when \(p, q, r, s\) are primes with \(2(r + s) = p + q\) and \(2rs = 3pq + 1\); equivalently, \(r\) and \(s\) are the roots of \(2x^2 - (p + q)x + 3pq + 1 = 0\).

    def IsCompatibleSemiprimePair (p q r s : ℕ) : Prop :=
  p.Prime ∧ q.Prime ∧ r.Prime ∧ s.Prime ∧ 2 * (r + s) = p + q ∧ 2 * (r * s) = 3 * (p * q) + 1

    TheoremBounds for the arithmetic derivative#●ready to prove

    MetaMathlibExt.arithmeticDerivative_bounds

    Let \(n \ge 2\) be a natural number, let \(p\) be the least prime factor of \(n\), and let \(\Omega(n)\) be the number of prime factors of \(n\) counted with multiplicity. Then the arithmetic derivative \(D(n)\) satisfies

    \[\Omega(n) \, n^{(\Omega(n) - 1)/\Omega(n)} \le D(n) \le \frac{n \log_p n}{p},\]

    and each of the two inequalities is an equality if and only if \(n\) is a prime power.

    public theorem_wanted arithmeticDerivative_bounds (n : ℕ) (hn : 2 ≤ n) :
    let om : ℝ := n.primeFactorsList.length
    let p : ℝ := n.minFac
    let lower : ℝ := om * (n : ℝ) ^ ((om - 1) / om)
    let upper : ℝ := n * Real.logb p n / p
    lower ≤ arithmeticDerivative n ∧ (arithmeticDerivative n : ℝ) ≤ upper ∧
      (lower = arithmeticDerivative n ↔ IsPrimePow n) ∧
      ((arithmeticDerivative n : ℝ) = upper ↔ IsPrimePow n)
    def arithmeticDerivative (n : ℕ) : ℕ :=
  ∑ p ∈ n.primeFactors, n.factorization p * (n / p)
