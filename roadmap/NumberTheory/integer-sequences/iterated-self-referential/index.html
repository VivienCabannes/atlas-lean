    TheoremClosed form for Golomb-like sequences#✓fully proved

    MetaMathlibExt.golomb_like_closed_form

    Let \(y\) and \(z\) be integers of opposite parity with \(y \ge 2\) and \(z \ge 2 - y\), and put \(c = (y + z - 1)/2\). There is exactly one strictly increasing function \(f\) from the positive integers to the positive integers such that \(f(1) = (y + z + 1)/2\) and \(f(f(n)) = yn + z\) for every positive integer \(n\). Moreover, for every such \(f\), every natural number \(k\) and every integer \(j\) with \(-c\,y^k \le j < c\,y^k\), the rational number

    \[m = \frac{(y+1)\,c}{y-1}\, y^k - \frac{z}{y-1} + j\]

    is a positive integer and

    \[f(m) = \frac{2c}{y-1}\, y^{k+1} - \frac{z}{y-1} + \frac{(y+1)\,j}{2} + \frac{(y-1)\,|j|}{2}.\]

    Proof: The construction tiles the positive integers by the source's blocks and verifies the two slope regimes, followed by strong-induction uniqueness, as in Cloitre–Sloane–Vandermast, Theorem Th1 and equations (Eq48a), (Eq48).

    There exist sequences of integers \((a_k)\), \((b_k)\), \((c_k)\), \((d_k)\) indexed by \(k \in \mathbb{N}\) with the following property.     DefinitionThe EKG sequence#✓fully proved

    MetaMathlibExt.IsEKGSequence

    A sequence \(a_0, a_1, a_2, \dots\) of natural numbers is an EKG sequence when \(a_0 = 1\), \(a_1 = 2\), and for every \(n \ge 0\) the term \(a_{n+2}\) is positive, differs from each of \(a_0, \dots, a_{n+1}\), satisfies \(\gcd(a_{n+1}, a_{n+2}) > 1\), and satisfies \(a_{n+2} \le m\) for every positive integer \(m\) that differs from each of \(a_0, \dots, a_{n+1}\) and has \(\gcd(a_{n+1}, m) > 1\). Thus every term from \(a_2\) on is the least positive integer not used before that shares a factor greater than \(1\) with the previous term.

    The indexing starts at \(0\), so the source's \(a_1 = 1\) and \(a_2 = 2\) are \(a_0\) and \(a_1\) here. The sequence begins \(1, 2, 4, 6, 3, 9, 12, 8, 10, 5, \dots\)

    public def IsEKGSequence (a : ℕ → ℕ) : Prop :=
  a 0 = 1 ∧
    a 1 = 2 ∧
      ∀ n : ℕ,
        0 < a (n + 2) ∧
          (∀ i : ℕ, i < n + 2 → a i ≠ a (n + 2)) ∧
            Nat.gcd (a (n + 1)) (a (n + 2)) > 1 ∧
              ∀ m : ℕ,
                0 < m →
                  (∀ i : ℕ, i < n + 2 → a i ≠ m) →
                    Nat.gcd (a (n + 1)) m > 1 → a (n + 2) ≤ m
