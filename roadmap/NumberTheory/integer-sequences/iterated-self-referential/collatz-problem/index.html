    DefinitionIterates of the Collatz map#✓fully proved

    Nat.collatzIterate

    Let \(T : \mathbb{N} \to \mathbb{N}\) be the Collatz map, which sends \(n\) to \(n / 2\) if \(n\) is even and to \(3n + 1\) if \(n\) is odd. For natural numbers \(k\) and \(n\), the \(k\)-th Collatz iterate of \(n\) is \(T^k(n)\), the result of applying \(T\) to \(n\) exactly \(k\) times: \(T^0(n) = n\) and \(T^{k+1}(n) = T(T^k(n))\).

    def collatzIterate : ℕ → ℕ → ℕ
  | 0, n => n
  | k + 1, n => collatzStep (collatzIterate k n)
    def collatzStep (n : ℕ) : ℕ :=
  if n % 2 = 0 then n / 2 else 3 * n + 1

    DefinitionCollatz stopping time#✓fully proved

    Nat.collatzStoppingTime

    Let \(T : \mathbb{N} \to \mathbb{N}\) be the Collatz map, which sends \(n\) to \(n / 2\) if \(n\) is even and to \(3n + 1\) if \(n\) is odd, and let \(T^k\) denote its \(k\)-fold iterate, with \(T^0(n) = n\). For a natural number \(n\), the Collatz stopping time of \(n\) is undefined if \(n = 0\) or if \(T^k(n) \ne 1\) for every \(k \in \mathbb{N}\); otherwise it is the least \(k \in \mathbb{N}\) with \(T^k(n) = 1\).

    In the Collatz literature this quantity is often called the total stopping time.

    noncomputable def collatzStoppingTime (n : ℕ) : Option ℕ :=
  if n = 0 then none
  else if ∃ k : ℕ, collatzIterate k n = 1 then
    some (sInf {k : ℕ | collatzIterate k n = 1})
  else
    none
    def collatzIterate : ℕ → ℕ → ℕ
  | 0, n => n
  | k + 1, n => collatzStep (collatzIterate k n)

    MetaMathlibExt.qShift

    For a power series \(x = \sum_n x_n q^n \in \mathbb{F}_2[[q]]\), its shift is the power series \(\sum_n x_{n+1} q^n\), obtained by discarding the constant term of \(x\) and dividing by \(q\). In particular, the shift of \(qy\) is \(y\) for every \(y \in \mathbb{F}_2[[q]]\).

  PowerSeries.mk fun n => coeff (n + 1) x

    MetaMathlibExt.qCollatz

    For a power series \(y = \sum_n y_n q^n \in \mathbb{F}_2[[q]]\), write \(y/q\) for the power series \(\sum_n y_{n+1} q^n\): the constant term of \(y\) is discarded and the rest is divided by \(q\). For power series \(A, B \in \mathbb{F}_2[[q]]\), the map \(T_{A,B} : \mathbb{F}_2[[q]] \to \mathbb{F}_2[[q]]\) is defined by \(T_{A,B}(x) = x/q\) if the constant term of \(x\) is \(0\), and \(T_{A,B}(x) = (Ax + B)/q\) otherwise.

    When \(A\) and \(B\) have constant term \(1\), the numerator \(Ax + B\) has constant term \(0\) whenever \(x\) has constant term \(1\), so in that case the division by \(q\) is exact.

    noncomputable def qCollatz (A B x : PowerSeries (ZMod 2)) : PowerSeries (ZMod 2) :=
  if constantCoeff x = 0 then qShift x else qShift (A * x + B)
