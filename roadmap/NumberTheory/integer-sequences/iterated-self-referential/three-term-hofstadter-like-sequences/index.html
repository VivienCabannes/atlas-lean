    MetaMathlibExt.threeTermHofstadterLookup

    Given computed terms \(B(1), \dots, B(m)\), a choice of whether the sequence is padded, and an integer \(j\), the value at index \(j\) is \(B(j)\) when \(1 \le j \le m\), is \(0\) when \(j \le 0\) and the sequence is padded, and is undefined otherwise (for \(j \le 0\) in the unpadded case, and for \(j > m\)).

    def threeTermHofstadterLookup (pad : Bool) (xs : Array ℤ) (j : ℤ) : Option ℤ :=
  if j ≤ 0 then (if pad then some 0 else none) else xs[(j - 1).toNat]?

    DefinitionNext term of the three-term Hofstadter-like recurrence#✓fully proved

    MetaMathlibExt.threeTermHofstadterNext

    Given computed terms \(B(1), \dots, B(m)\), padded with \(0\) at nonpositive indices or not, the next term is \(B(m + 1) = B(m + 1 - B(m)) + B(m + 1 - B(m - 1)) + B(m + 1 - B(m - 2))\). It is undefined when one of the values it uses, \(B(m)\), \(B(m - 1)\), \(B(m - 2)\) or one of the three summands, sits at an undefined index: a nonpositive index in the unpadded case, or an index above \(m\).

    def threeTermHofstadterNext (pad : Bool) (xs : Array ℤ) : Option ℤ :=
  let n : ℤ := xs.size + 1
  (threeTermHofstadterLookup pad xs (n - 1)).bind fun b₁ =>
  (threeTermHofstadterLookup pad xs (n - 2)).bind fun b₂ =>
  (threeTermHofstadterLookup pad xs (n - 3)).bind fun b₃ =>
  (threeTermHofstadterLookup pad xs (n - b₁)).bind fun v₁ =>
  (threeTermHofstadterLookup pad xs (n - b₂)).bind fun v₂ =>
  (threeTermHofstadterLookup pad xs (n - b₃)).map fun v₃ => v₁ + v₂ + v₃
    def threeTermHofstadterLookup (pad : Bool) (xs : Array ℤ) (j : ℤ) : Option ℤ :=
  if j ≤ 0 then (if pad then some 0 else none) else xs[(j - 1).toNat]?

    DefinitionComputing further terms of a three-term Hofstadter-like sequence#✓fully proved

    MetaMathlibExt.threeTermHofstadterExtend

    Given terms \(B(1), \dots, B(m)\), padded with \(0\) at nonpositive indices or not, and a natural number \(k\), this is the list \(B(1), \dots, B(m + k)\) obtained by computing \(B(m + 1), \dots, B(m + k)\) one after another from \(B(n) = B(n - B(n-1)) + B(n - B(n-2)) + B(n - B(n-3))\). It is undefined if one of these terms cannot be computed because the formula refers to an undefined index (a nonpositive index in the unpadded case, or an index not yet computed).

    def threeTermHofstadterExtend (pad : Bool) : ℕ → Array ℤ → Option (Array ℤ)
  | 0, xs => some xs
  | k + 1, xs =>
    match threeTermHofstadterNext pad xs with
    | none => none
    | some v => threeTermHofstadterExtend pad k (xs.push v)

    DefinitionInitial segment of a three-term Hofstadter-like sequence#✓fully proved

    MetaMathlibExt.threeTermHofstadterPrefix

    Let \(x_1, \dots, x_m\) be integers (\(m \ge 0\)) and let \(B\) be the padded or the unpadded three-term Hofstadter-like sequence with initial conditions \(x_1, \dots, x_m\): \(B(i) = x_i\) for \(1 \le i \le m\), the padded sequence has \(B(i) = 0\) for every \(i \le 0\) while the unpadded one is undefined there, and for \(n > m\)

    \[B(n) = B(n - B(n-1)) + B(n - B(n-2)) + B(n - B(n-3)),\]

    which is defined only when every value of \(B\) on the right-hand side is defined and the indices \(n - B(n-1)\), \(n - B(n-2)\), \(n - B(n-3)\) are less than \(n\). For a natural number \(k\), the initial segment is the list \(B(1), \dots, B(m + k)\), the initial conditions followed by the next \(k\) terms; it is undefined when one of \(B(m + 1), \dots, B(m + k)\) is undefined.

    def threeTermHofstadterPrefix (pad : Bool) (init : List ℤ) (k : ℕ) : Option (Array ℤ) :=
  threeTermHofstadterExtend pad k init.toArray
    def threeTermHofstadterExtend (pad : Bool) : ℕ → Array ℤ → Option (Array ℤ)
  | 0, xs => some xs
  | k + 1, xs =>
    match threeTermHofstadterNext pad xs with
    | none => none

    DefinitionThree-term Hofstadter-like sequence#✓fully proved

    MetaMathlibExt.threeTermHofstadterTerm

    Let \(x_1, \dots, x_m\) be integers (\(m \ge 0\)), the initial conditions, and choose whether the sequence is padded. The sequence \(B\) has \(B(i) = x_i\) for \(1 \le i \le m\); the padded sequence has \(B(i) = 0\) for every integer \(i \le 0\), while the unpadded one is undefined at every \(i \le 0\). For \(n > m\),

    \[B(n) = B(n - B(n-1)) + B(n - B(n-2)) + B(n - B(n-3)),\]

    which is defined only when every value of \(B\) on the right-hand side is defined and the indices \(n - B(n-1)\), \(n - B(n-2)\), \(n - B(n-3)\) are less than \(n\); once a term is undefined, the sequence stops and every later term is undefined. The term at a natural number index \(j\) is \(B(j)\) when this is defined and undefined otherwise; in particular the term at index \(0\) is \(0\) for the padded sequence and undefined for the unpadded one.

    def threeTermHofstadterTerm (pad : Bool) (init : List ℤ) (j : ℕ) : Option ℤ :=
  (threeTermHofstadterPrefix pad init (j - init.length)).bind fun xs =>
    threeTermHofstadterLookup pad xs j
    def threeTermHofstadterPrefix (pad : Bool) (init : List ℤ) (k : ℕ) : Option (Array ℤ) :=
  threeTermHofstadterExtend pad k init.toArray

    MetaMathlibExt.ThreeTermHofstadterEndsAfter

    Take integer initial conditions \(B(1), \dots, B(m)\), and either pad the sequence with \(B(n) = 0\) for every \(n \le 0\) or leave it unpadded. Continue it by \(B(n) = B(n - B(n-1)) + B(n - B(n-2)) + B(n - B(n-3))\) for \(n > m\), where a term cannot be computed if this formula refers to an undefined index: a nonpositive index in the unpadded case, or an index not yet computed. For a natural number \(T\), the sequence has exactly \(T\) terms when \(T \ge m\), the terms \(B(1), \dots, B(T)\) can all be computed, and \(B(T + 1)\) cannot.

    def ThreeTermHofstadterEndsAfter (pad : Bool) (init : List ℤ) (T : ℕ) : Prop :=
  ∃ xs, threeTermHofstadterPrefix pad init (T - init.length) = some xs ∧ xs.size = T ∧
    threeTermHofstadterNext pad xs = none
    def threeTermHofstadterPrefix (pad : Bool) (init : List ℤ) (k : ℕ) : Option (Array ℤ) :=
  threeTermHofstadterExtend pad k init.toArray
