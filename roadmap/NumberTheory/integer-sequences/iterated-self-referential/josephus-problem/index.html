    Josephus problem

    DefinitionJosephus survivor function#✓fully proved

    MetaMathlibExt.josephus

    For natural numbers \(k\) and \(n\), the Josephus function \(J_k(n)\) is defined by recursion on \(n\): \(J_k(0) = 0\) and \(J_k(n+1) = ((J_k(n) + k - 1) \bmod (n+1)) + 1\), where subtraction of natural numbers is truncated at \(0\).

    For \(k \ge 2\) and \(n \ge 1\), \(J_k(n)\) is the one-based position of the sole survivor when every \(k\)-th person is eliminated from a circle of \(n\) people; the value \(J_k(0) = 0\) only anchors the recursion.

    public def josephus (k : Nat) : Nat → Nat
  | 0 => 0
  | (n + 1) => ((josephus k n + k - 1) % (n + 1)) + 1

    MetaMathlibExt.baseThreeHalvesDigits

    The base-\(3/2\) digit list of a natural number \(N\), least significant digit first, is defined by recursion on \(N\): the list of \(0\) is empty, and for \(N \ge 1\) it is the digit \(d = 2N \bmod 3\) followed by the base-\(3/2\) digit list of \((2N - d)/3\).

    public def baseThreeHalvesDigits : ℕ → List ℕ
  | 0 => []
  | N + 1 =>
    let d := 2 * (N + 1) % 3
    d :: baseThreeHalvesDigits ((2 * (N + 1) - d) / 3)
  termination_by N => N
  decreasing_by omega
