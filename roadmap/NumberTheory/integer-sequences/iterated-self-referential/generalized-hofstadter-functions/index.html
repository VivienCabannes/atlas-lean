    DefinitionFuel-bounded generalized Hofstadter recursion#✓fully proved

    MetaMathlibExt.hofstadterFAux

    For natural numbers \(k\), \(p\) and \(n\), the value \(A_k(p, n)\) is defined by recursion on the fuel \(p\), which bounds the recursion depth: \(A_k(0, n) = 0\) and \(A_k(p + 1, n) = n - g^k(n - 1)\), where \(g^k\) is the \(k\)-fold iterate of the function \(g(m) = A_k(p, m)\) and both subtractions are truncated at \(0\).

    def hofstadterFAux (k : ℕ) : ℕ → ℕ → ℕ
  | 0, _ => 0
  | p + 1, n => n - (hofstadterFAux k p)^[k] (n - 1)
