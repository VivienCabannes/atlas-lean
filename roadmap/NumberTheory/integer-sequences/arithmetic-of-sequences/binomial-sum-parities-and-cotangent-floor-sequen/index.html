    TheoremFried's alternating binomial identity#●ready to prove

    MetaMathlibExt.fried_alternating_binomial_identity

    For integers \(a\) and \(b\) let \(\binom{a}{b}\) be the binomial coefficient when \(a, b \ge 0\) (so \(0\) when \(b > a\)), and \(0\) when \(a < 0\) or \(b < 0\). For natural numbers \(n\), \(r\), \(s\) with \(r \le n\) and \(s \le 2r\), with all arguments computed in the integers,

    \[\sum_{k=0}^{n} (-1)^k \binom{n}{k} \binom{2n-2r}{n-k} \binom{n-k}{n-2r+s} \binom{2r-k-s}{n-s} = (-1)^n \binom{n}{2r-n} \binom{2n-2r}{n-s}.\]
    public theorem_wanted fried_alternating_binomial_identity (n r s : ℕ) (hr : r ≤ n)
    (hs : s ≤ 2 * r) :
    let C : ℤ → ℤ → ℤ := fun a b => if 0 ≤ a ∧ 0 ≤ b then (a.toNat.choose b.toNat : ℤ) else 0
    ∑ k ∈ Finset.range (n + 1),
        (-1) ^ k * C n k * C (2 * n - 2 * r) (n - k) * C (n - k) (n - 2 * r + s) *
          C (2 * r - k - s) (n - s) =
      (-1) ^ n * C n (2 * r - n) * C (2 * n - 2 * r) (n - s)

    TheoremThe Bala–Somos parity conjectures#●ready to prove

    MetaMathlibExt.bala_somos_partition_parity

    For a natural number \(k\) let \(p(k)\) be the number of partitions of \(k\). For natural numbers \(m\) and \(N\) let \(b_m(N) = \sum_{k=1}^{N} k^{2m+1} p(k) p(N-k)\) and \(a(N) = \sum_{j=0}^{N} c(j)\, p(N-j)\), where \(c(0) = 0\) and \(c(j) = \sum_{d \mid j,\ d \text{ odd}} (-1)^{j/d - 1}\) for \(j \ge 1\). Then for all \(m \ge 1\) and \(n \ge 1\): (a) if \(n\) is odd, then \(n\) divides \(b_m(n)\); (b) \(n\) divides \(b_m(2n)\), and \(b_m(2n)/n\) is odd if and only if \(n\) and \(p(n)\) are both odd; (c) \(a(n)\) is odd if and only if \(n\) and \(p(n)\) are both odd; (d) twice the fractional part of the rational number \(b_1(n)/n\) equals \(1\) if and only if \(n\) is even and \(n/2\) and \(p(n/2)\) are both odd.

    Here \(c(j)\) is the coefficient of \(x^j\) in \(\sum_{k \ge 1} x^{2k-1}/(1 + x^{2k-1})\), so \(a(N)\) is the coefficient of \(x^N\) in \(\bigl(\sum_{k \ge 1} x^{2k-1}/(1 + x^{2k-1})\bigr) \prod_{k \ge 1} 1/(1 - x^k)\) (A305123). The paper calls the left side of (d) \(c(n)\), a different sequence from the coefficients \(c(j)\) above.

    public theorem_wanted bala_somos_partition_parity (m n : ℕ) (hm : 1 ≤ m) (hn : 1 ≤ n) :
    let p : ℕ → ℕ := fun k => Fintype.card (Nat.Partition k)
    let b : ℕ → ℕ → ℕ := fun m n => ∑ k ∈ Finset.Icc 1 n, k ^ (2 * m + 1) * p k * p (n - k)
    let a : ℕ → ℤ := fun n => ∑ j ∈ Finset.range (n + 1),
      (∑ d ∈ j.divisors.filter Odd, (-1 : ℤ) ^ (j / d - 1)) * p (n - j)
    (Odd n → n ∣ b m n) ∧
      (n ∣ b m (2 * n) ∧ (Odd (b m (2 * n) / n) ↔ Odd n ∧ Odd (p n))) ∧
      (Odd (a n) ↔ Odd n ∧ Odd (p n)) ∧
      (2 * Int.fract ((b 1 n : ℚ) / n) = 1 ↔ Even n ∧ Odd (n / 2) ∧ Odd (p (n / 2)))
