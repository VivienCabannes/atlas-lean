    DefinitionGeneralized Sylvester sequence#✓fully proved

    Nat.generalizedSylvester

    For a natural number \(n\), the generalized Sylvester sequence \((s_k(n))_{k \ge 0}\) is the sequence of natural numbers defined by \(s_0(n) = n + 1\) and \(s_{k+1}(n) = s_k(n)^2 - s_k(n) + 1\) for \(k \ge 0\).

    The source indexes the sequence from one: its \(s_1(n)\) is \(s_0(n)\) here.

    def generalizedSylvester (n : ℕ) : ℕ → ℕ
  | 0 => n + 1
  | k + 1 => generalizedSylvester n k ^ 2 - generalizedSylvester n k + 1
