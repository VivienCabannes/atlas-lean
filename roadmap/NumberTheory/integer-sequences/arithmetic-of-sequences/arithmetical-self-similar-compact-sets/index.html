    Arithmetical self-similar compact sets

    DefinitionSelf-similar compact set#✓fully proved

    MetaMathlibExt.IsSelfSimilarCompactSet

    Let \(\mu\) be a natural number and \(\rho\) a real number. A set \(K \subseteq \mathbb{R}\) is a self-similar compact set of module \(\mu\) and ratio \(\rho\) when \(\rho > 1\), \(K\) is nonempty and compact, \(K \subseteq [0, \infty)\), \(K\) is well ordered by the reverse order \(x \preceq y \iff x \ge y\) (every nonempty subset of \(K\) has a largest element), and \(\rho K^{(\mu)} = K\), where \(K^{(\mu)}\) is the \(\mu\)-th derived set of \(K\) (the operation \(A \mapsto A'\) taking a set to its set of accumulation points, applied \(\mu\) times) and \(\rho K^{(\mu)} = \{\rho x : x \in K^{(\mu)}\}\).

    public def IsSelfSimilarCompactSet (K : Set ℝ) (μ : ℕ) (ρ : ℝ) : Prop :=
  1 < ρ ∧ K.Nonempty ∧ IsCompact K ∧ K ⊆ Set.Ici 0 ∧ K.WellFoundedOn (· > ·) ∧
    ρ • derivedSet^[μ] K = K

    DefinitionLayers of the iterated derived sets#✓fully proved

    MetaMathlibExt.selfSimilarLayer

    For a set \(K \subseteq \mathbb{R}\) and a natural number \(u\), let \(K^{(u)}\) be the \(u\)-th derived set of \(K\) (the derived set, i.e. the set of accumulation points, iterated \(u\) times, with \(K^{(0)} = K\)). The layer of \(K\) of index \(u\) is \(T_u = K^{(u)} \setminus K^{(u+1)}\), the set of points of \(K^{(u)}\) that are isolated in \(K^{(u)}\).

    public def selfSimilarLayer (K : Set ℝ) (u : ℕ) : Set ℝ :=
  derivedSet^[u] K \ derivedSet^[u + 1] K
