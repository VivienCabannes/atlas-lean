    DefinitionBinomial-power sequences#✓fully proved

    MetaMathlibExt.binomialPowerSeq

    For natural numbers \(r\), \(s\) and \(n\), the binomial-power number \(A_{r,s}(n)\) is the natural number

    \[A_{r,s}(n) = \sum_{k=0}^{n} \binom{n}{k}^r \binom{n+k}{k}^s.\]

    Special cases include the central Delannoy numbers (\(r = s = 1\)), the Apéry numbers (\(r = s = 2\)) and the Franel numbers of order \(r\) (\(s = 0\)).

    def binomialPowerSeq (r s n : ℕ) : ℕ :=
  ∑ k ∈ Finset.range (n + 1),
    (Nat.choose n k) ^ r * (Nat.choose (n + k) k) ^ s

    DefinitionDold realizable sequences#✓fully proved

    MetaMathlibExt.doldRealizable

    An integer sequence \((a(n))_{n \ge 0}\) is Dold realizable when, for every integer \(n \ge 1\), the Möbius transform \(\sum_{d \mid n} \mu(d)\, a(n/d)\) is divisible by \(n\) and non-negative, where \(\mu\) is the Möbius function and \(d\) runs over the positive divisors of \(n\).

    The divisibility condition alone is the classical Dold condition.

    def doldRealizable (a : ℕ → ℤ) : Prop :=
  ∀ n : ℕ, 0 < n →
    (n : ℤ) ∣ ∑ d ∈ Nat.divisors n,
      (⇑ArithmeticFunction.moebius d) * a (n / d) ∧
    0 ≤ ∑ d ∈ Nat.divisors n,
      (⇑ArithmeticFunction.moebius d) * a (n / d)
    Sources

    DefinitionDold sequences#✓fully proved

    MetaMathlibExt.IsDoldSequence

    A sequence \(a_0, a_1, a_2, \dots\) of integers is a Dold sequence when for every integer \(m \ge 1\) there is an \(m \times m\) matrix \(A\) with integer entries such that \(a_n = \operatorname{tr}(A^n)\) for every \(n\) with \(1 \le n \le m\). The term \(a_0\) is not constrained.

    def IsDoldSequence (a : ℕ → ℤ) : Prop :=
  ∀ m : ℕ, 1 ≤ m →
    ∃ A : Matrix (Fin m) (Fin m) ℤ,
      ∀ n : ℕ, 1 ≤ n → n ≤ m → a n = Matrix.trace (A ^ n)
    Sources
    Sources
    • Wójcik, Binomial Transform and Dold Sequences, Lemma 3; this equivalent trace characterization is taken here as the definition.

    DefinitionFermat sequence#✓fully proved

    MetaMathlibExt.fermatSequence

    Given a sequence \(b : \mathbb{N} \to \mathbb{C}\), the Fermat sequence generated by \(b\) is the sequence \(a : \mathbb{N} \to \mathbb{C}\) given by \(a_n = \sum_{m \mid n} m \, b_m\) for \(n \ge 1\), the sum running over the positive divisors \(m\) of \(n\), and \(a_0 = 0\).

    The source defines the sequence only for positive indices; the value \(a_0 = 0\) comes from summing over the empty set of divisors of \(0\).

    public def fermatSequence (b : ℕ → ℂ) : ℕ → ℂ :=
  fun n => ∑ m ∈ Nat.divisors n, (m : ℂ) * b m

    DefinitionAlmost realizable sequences#✓fully proved

    MetaMathlibExt.IsAlmostRealizableSeq

    A sequence \(a\) of natural numbers \(a(0), a(1), \dots\) is almost realizable when there is an integer \(m \ge 1\) such that the integer sequence \((m\, a(n))_{n \ge 0}\) is Dold realizable: for every \(n \ge 1\), the sum \(\sum_{d \mid n} \mu(d)\, m\, a(n/d)\) over the positive divisors \(d\) of \(n\), where \(\mu\) is the Möbius function, is non-negative and divisible by \(n\).

    This is Miska and Ward's notion that some positive integer multiple of \(a\) is realizable. The value \(a(0)\) is not used.

  ∃ m : ℕ, 0 < m ∧ doldRealizable fun n => ((m * a n : ℕ) : ℤ)

    TheoremBinomial coefficients at multiples of a prime divisor#●ready to prove

    MetaMathlibExt.choose_mul_prime_modEq_choose_div

    Let \(p\) be a prime and let \(n \ge 1\) be an integer divisible by \(p\). Then for every integer \(\lambda \ge 0\) with \(\lambda p \ne n\),
