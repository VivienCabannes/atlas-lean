    DefinitionThe (k, l)-Göbel sequence#✓fully proved

    MetaMathlibExt.gobelSequence

    For natural numbers \(k\) and \(l\), the \((k, l)\)-Göbel sequence is the sequence of rational numbers \(g_{k,l}(n)\), \(n \ge 0\), given by \(g_{k,l}(0) = 0\), \(g_{k,l}(1) = l\) and, for \(n \ge 1\),

    \[g_{k,l}(n + 1) = \frac{g_{k,l}(n) \bigl(n + g_{k,l}(n)^{k-1}\bigr)}{n + 1},\]

    where \(k - 1\) is truncated subtraction, so the exponent is \(0\) when \(k = 0\).

    The paper indexes from \(n = 1\) and takes \(k, l \ge 2\) (Lemma 5 also admits \(k, l \ge 1\)); the value at \(n = 0\) is a convention and plays no role.

    public def gobelSequence (k l : ℕ) : ℕ → ℚ
  | 0 => 0
  | 1 => l
  | n + 2 => gobelSequence k l (n + 1) * ((n + 1 : ℚ) + gobelSequence k l (n + 1) ^ (k - 1))
      / (n + 2)

    MetaMathlibExt.gobelSequence_asymptotic_expansion

    Let \(k, l \ge 2\) be natural numbers and let \(g_{k,l}\) be the \((k, l)\)-Göbel sequence. There are a real number \(C > 1\) and real numbers \(a_1, a_2, \dots\) such that for every natural number \(R\), as \(n \to \infty\),

    \[g_{k,l}(n) - C^{k^n} n^{1/(k-1)} \Bigl(1 + \sum_{r=1}^{R} \frac{a_r}{n^r}\Bigr) = O\Bigl(\frac{C^{k^n} n^{1/(k-1)}}{n^{R+1}}\Bigr).\]

    In other words, \(g_{k,l}(n) \sim C^{k^n} n^{1/(k-1)} \bigl(1 + \sum_{r \ge 1} a_r / n^r\bigr)\) as an asymptotic expansion, generalizing Zagier's asymptotic for Göbel's sequence.

    MetaMathlibExt.gobelSequence_padic_key_properties

    Let \(p\) be a prime, let \(N \ge 1\) be a natural number, let \(r = \nu_p(N!)\), where \(\nu_p\) is the \(p\)-adic valuation on \(\mathbb{Q}\) (with \(\nu_p(0) = 0\)), and write \(g_{k,l}\) for the \((k, l)\)-Göbel sequence. Write \(\mathbb{Z}_{(p)}\) for the set of rational numbers \(x\) with \(\nu_p(x) \ge 0\), and for an integer \(s\) write \(x \in p^s \mathbb{Z}_{(p)}\) when \(x = 0\) or \(\nu_p(x) \ge s\). Then: (1) for all natural numbers \(k, l \ge 1\), if \(p > N\) then \(g_{k,l}(N) \in \mathbb{Z}_{(p)}\); (2) for all natural numbers \(k, l \ge 1\) and \(1 \le n \le N\), if \(g_{k,l}(n) \notin \mathbb{Z}_{(p)}\) then \(g_{k,l}(n + 1) \notin \mathbb{Z}_{(p)}\); (3) if \(p \le N\), then for all natural numbers \(k_1, k_2 \ge r\) with \(k_1 \equiv k_2 \pmod{\varphi(p^r)}\), where \(\varphi\) is Euler's totient function, all \(l \ge 1\) and all \(1 \le n \le N\): \(g_{k_1,l}(n) \in \mathbb{Z}_{(p)}\) if and only if \(g_{k_2,l}(n) \in \mathbb{Z}_{(p)}\), and in that case \(g_{k_1,l}(n) - g_{k_2,l}(n) \in p^{r - \nu_p(n!)} \mathbb{Z}_{(p)}\); (4) if \(p \le N\), then for all natural numbers \(k, l_1, l_2 \ge 1\) with \(l_1 \equiv l_2 \pmod{p^r}\) and all \(1 \le n \le N\): \(g_{k,l_1}(n) \in \mathbb{Z}_{(p)}\) if and only if \(g_{k,l_2}(n) \in \mathbb{Z}_{(p)}\), and in that case \(g_{k,l_1}(n) - g_{k,l_2}(n) \in p^{r - \nu_p(n!)} \mathbb{Z}_{(p)}\).

It is defined by \(g_{k,p,r}(0) = F\), \(g_{k,p,r}(1) = 2 \bmod p^r\) and, for \(n \ge 2\), as follows. If \(g_{k,p,r}(n-1) = F\) then \(g_{k,p,r}(n) = F\). Otherwise let \(g_{k,p,r}(n-1) = a\) and let \(N\) be the least nonnegative residue of \((n-1)a + a^k\) modulo \(p^{r - \nu_p((n-1)!)}\), with \(a^k\) computed by modular exponentiation.
