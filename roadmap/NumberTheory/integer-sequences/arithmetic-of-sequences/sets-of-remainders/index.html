    DefinitionThe remainder-set constant#✓fully proved

    MetaMathlibExt.remainderConstant

    The remainder-set constant is \(c = \sum_{p} \frac{1}{p(p+1)} \prod_{q < p} \left(1 - \frac{1}{q}\right)\), where \(p\) runs over all primes and, for each \(p\), \(q\) runs over the primes less than \(p\).

    Numerically, \(c \approx 0.2296\).

    public noncomputable def remainderConstant : ℝ :=
  ∑' p : Nat.Primes, (1 / ((p : ℝ) * ((p : ℝ) + 1))) *
    ∏ q ∈ (Finset.range p).filter Nat.Prime, (1 - 1 / (q : ℝ))

    MetaMathlibExt.remainderCount_asymptotic

    Let \(s(n)\) be the number of distinct remainders \(n \bmod k\) with \(1 \le k \le \lfloor n/2 \rfloor\) and let \(c\) be the remainder-set constant. Then, as \(n \to \infty\) over the natural numbers, \(s(n) - cn = O\bigl(n / (\log n \cdot \log \log n)\bigr)\), and \(s(n)/n \to c\).

    MetaMathlibExt.remainderCount_consecutive_differences

    Let \(s(n)\) be the number of distinct remainders \(n \bmod k\) with \(1 \le k \le \lfloor n/2 \rfloor\).     DefinitionIterated remainder sets#✓fully proved

    MetaMathlibExt.iteratedRemainderSet

    For a natural number \(n\), the iterated remainder sets \(S_j(n)\), \(j \ge 0\), are defined by \(S_0(n) = \{1, \dots, \lfloor n/2 \rfloor\}\) and, for \(j \ge 0\), \(S_{j+1}(n) = \{n \bmod k : k \in S_j(n),\ k \ne 0\}\).

  | j + 1, n => ((iteratedRemainderSet j n).erase 0).image (n % ·)

    TheoremMaximal Pierce length via iterated remainder sets#●ready to prove

    MetaMathlibExt.pierce_maxLength_eq_succ_iff

    Let \(n \ge 3\) and \(t\) be natural numbers, let \(P(n)\) be the maximal Pierce length of \(n\) and let \(S_j(n)\) be the iterated remainder sets of \(n\). Then the following are equivalent: \(P(n) = t + 1\); \(S_t(n) = \{0\}\); \(S_t(n)\) has exactly one element and \(S_{t+j}(n) = \emptyset\) for every \(j \ge 1\).

    This corrects the index of the printed lemma, \(P(n) = t \iff S_{t+1}(n) = \{0\}\), which fails for every \(n \ge 3\): for example \(P(5) = 3\), \(S_2(5) = \{0\}\) and \(S_4(5) = \emptyset\). The paper derives the lemma from its Lemma 18 (\(r \in S_j(n)\) if and only if \(a_{j+1} = r\) for some \(\lfloor n/2 \rfloor + 1 \le a \le n\), where \(a_0 = a\) and \(a_{i+1} = n \bmod a_i\)), which gives the index \(P(n) - 1\). Lemma 18, and hence this lemma, needs \(n \ge 3\): \(P(2) = 1\) but \(S_0(2) = \{1\}\).

    public theorem_wanted pierce_maxLength_eq_succ_iff (n t : ℕ) (hn : 3 ≤ n) :
    (PierceExpansion.maxLength n = t + 1 ↔ iteratedRemainderSet t n = {0}) ∧
      (PierceExpansion.maxLength n = t + 1 ↔ (iteratedRemainderSet t n).card = 1 ∧
        ∀ j, 1 ≤ j → iteratedRemainderSet (t + j) n = ∅)
    noncomputable def maxLength (n : ℕ) : ℕ :=
  (Finset.Icc 1 n).sup (length n)
