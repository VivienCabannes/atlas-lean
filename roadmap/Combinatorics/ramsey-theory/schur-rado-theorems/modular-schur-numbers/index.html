    DefinitionSum-free sets modulo \(m\)#✓fully proved

    MetaMathlibExt.IsSumFreeMod

    For natural numbers \(m\) and \(l\), a set \(A\) of integers is \(l\)-sum-free modulo \(m\) if there are no \(x_1, \dots, x_l, y \in A\) (repetitions allowed) with \(x_1 + \dots + x_l \equiv y \pmod{m}\).

    def IsSumFreeMod (m l : ℕ) (A : Set ℤ) : Prop :=
  ∀ x : Fin l → ℤ, (∀ i, x i ∈ A) → ∀ y ∈ A, ¬ (∑ i, x i ≡ y [ZMOD m])

    DefinitionSum-free partitions modulo \(m\)#✓fully proved

    MetaMathlibExt.HasSumFreePartitionMod

    For natural numbers \(m\), \(k\), \(l\) and \(n\), the range \(\{1, \dots, n\}\) admits a partition into \(k\) classes that are \(l\)-sum-free modulo \(m\) if there is a coloring \(c\) of the natural numbers with \(k\) colors such that, for each color \(j\), the set of integers \(a\) with \(1 \le a \le n\) and \(c(a) = j\) is \(l\)-sum-free modulo \(m\). Classes may be empty; for \(k = 0\) there is no coloring, so the property fails for every \(n\), including \(n = 0\).

    def HasSumFreePartitionMod (m k l n : ℕ) : Prop :=
  ∃ c : ℕ → Fin k, ∀ j : Fin k,
    IsSumFreeMod m l {x : ℤ | ∃ a : ℕ, 1 ≤ a ∧ a ≤ n ∧ c a = j ∧ x = a}
    def IsSumFreeMod (m l : ℕ) (A : Set ℤ) : Prop :=

    DefinitionModular Schur number#✓fully proved

    MetaMathlibExt.modularSchurNumber

    For natural numbers \(m\), \(k\) and \(l\), the generalized Schur number modulo \(m\), written \(S_m(k, l)\), is the largest natural number \(n\) such that \(\{1, \dots, n\}\) admits a partition into \(k\) (possibly empty) classes that are each \(l\)-sum-free modulo \(m\); it is \(0\) when there is no largest such \(n\).

    For \(m \ge 1\) and \(k \ge 1\) such a largest \(n\) exists, since \(n = 0\) is admissible and every admissible \(n\) is at most \(m - 1\).

    noncomputable def modularSchurNumber (m k l : ℕ) : ℕ :=
  sSup {n : ℕ | HasSumFreePartitionMod m k l n}
    def HasSumFreePartitionMod (m k l n : ℕ) : Prop :=
  ∃ c : ℕ → Fin k, ∀ j : Fin k,
    IsSumFreeMod m l {x : ℤ | ∃ a : ℕ, 1 ≤ a ∧ a ≤ n ∧ c a = j ∧ x = a}

    TheoremSolutions of a linear congruence#●ready to prove

    MetaMathlibExt.linear_congruence_solutions

    Let \(a\) and \(b\) be integers, let \(m\) be a positive integer, and let \(d = \gcd(a, m)\). The congruence \(a x \equiv b \pmod{m}\) has an integer solution if and only if \(d \mid b\). If \(d \mid b\), then exactly \(d\) of the numbers \(x \in \{0, 1, \dots, m - 1\}\) are solutions. Moreover, if \(x_0\) is a solution, then an integer \(x\) is a solution if and only if \(x \equiv x_0 + u \cdot (m / d) \pmod{m}\) for some integer \(u\) with \(0 \le u \le d - 1\).
