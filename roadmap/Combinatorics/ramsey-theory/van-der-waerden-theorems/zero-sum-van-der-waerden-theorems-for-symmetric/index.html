    Zero-sum van der Waerden theorems for symmetric functions

    Definition\(m\)-vanishing family#✓fully proved

    MetaMathlibExt.IsMVanishingFamily

    Let \(n\) be a natural number and let \(F = (f^{(l)})_{l \ge 0}\) be a family of functions \(f^{(l)} : (\mathbb{Z}/n\mathbb{Z})^l \to M\) into a type \(M\) with a zero element. For a natural number \(m\), \(F\) is \(m\)-vanishing if for every sequence \(a_0, a_1, a_2, \dots\) of elements of \(\mathbb{Z}/n\mathbb{Z}\) there are a length \(l > 1\) and a start \(s \ge 0\) such that \(f^{(l)}(a_{s+jl}, a_{s+jl+1}, \dots, a_{s+jl+l-1}) = 0\) for every \(j < m\); that is, the sequence contains \(m\) consecutive blocks of a common length \(l > 1\) on each of which \(f^{(l)}\) vanishes.

    public def IsMVanishingFamily {n : ℕ} {M : Type*} [Zero M] (m : ℕ)
    (F : (l : ℕ) → (Fin l → ZMod n) → M) : Prop :=
  ∀ a : ℕ → ZMod n, ∃ l, 1 < l ∧ ∃ s, ∀ j < m, F l (fun i => a (s + j * l + i)) = 0

    DefinitionThe sum-plus-product family \(F_c\)#✓fully proved

    MetaMathlibExt.sumAddMulProdFamily

    For \(c \in \mathbb{Z}/n\), the family \(F_c\) over \(\mathbb{Z}/n\) sends a block \((b_1, \dots, b_l)\) of elements of \(\mathbb{Z}/n\), of any length \(l \ge 0\), to \(b_1 + \dots + b_l + c\, b_1 b_2 \cdots b_l\), where an empty sum is \(0\) and an empty product is \(1\).

    public def sumAddMulProdFamily {n : ℕ} (c : ZMod n) (l : ℕ) (b : Fin l → ZMod n) :
    ZMod n :=
  ∑ i, b i + c * ∏ i, b i
