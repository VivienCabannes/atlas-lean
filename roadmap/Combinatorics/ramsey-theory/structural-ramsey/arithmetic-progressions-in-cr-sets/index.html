    DefinitionThick set in a commutative semigroup#✓fully proved

    MetaMathlibExt.IsAddThick

    A subset \(A\) of a commutative semigroup \((S, +)\) is thick when for every finite set \(E \subseteq S\) there is an \(x \in S\) with \(E + x \subseteq A\), that is, \(e + x \in A\) for every \(e \in E\).

    def IsAddThick (A : Set S) : Prop :=
  ∀ E : Finset S, ∃ x : S, ∀ e ∈ E, e + x ∈ A

    DefinitionJ-sets in commutative semigroups#✓fully proved

    MetaMathlibExt.IsJSet

    Let \(S\) be a commutative semigroup and let \(\mathbb{N} = \{0, 1, 2, \dots\}\). A set \(A \subseteq S\) is a \(J\)-set when for every finite set \(F\) of sequences \(f \colon \mathbb{N} \to S\) there are \(a \in S\) and a nonempty finite set \(H \subseteq \mathbb{N}\) such that \(a + \sum_{n \in H} f(n) \in A\) for every \(f \in F\).

    def IsJSet (A : Set S) : Prop :=
  ∀ F : Finset (ℕ → S), ∃ a : S, ∃ H : List ℕ, H.Nodup ∧ H ≠ [] ∧
    ∀ f ∈ F, (H.map f).foldl (· + ·) a ∈ A

    DefinitionCR-set#✓fully proved

    MetaMathlibExt.IsCRSet

    A subset \(A\) of a commutative semigroup \((S, +)\) is a CR-set (combinatorially rich) when for every natural number \(n\), including \(n = 0\), there is a natural number \(r\) such that for every \(r \times n\) matrix \((m_{ij})\) with entries in \(S\) there are a nonempty set \(\alpha \subseteq \{1, \ldots, r\}\) and an element \(s \in S\) such that \(s + \sum_{i \in \alpha} m_{ij} \in A\) for every column \(j \in \{1, \ldots, n\}\).

    The paper takes \(n \ge 1\). Allowing \(n = 0\) adds the requirement that \(S\) be nonempty, the paper's implicit convention: over an empty \(S\) every case \(n \ge 1\) holds vacuously (take \(r = 1\); there is no matrix), so without it \(\emptyset\) would be a CR-set of the empty semigroup. Over a nonempty \(S\) the two definitions agree.

    def IsCRSet (A : Set S) : Prop :=
  ∀ n : ℕ, ∃ r : ℕ, ∀ M : Fin r → Fin n → S, ∃ α : Finset (Fin r), α.Nonempty ∧
    ∃ s : S, ∀ j, (α.toList.map fun i => M i j).foldl (· + ·) s ∈ A

    DefinitionEssential CR-set#✓fully proved

    MetaMathlibExt.IsEssentialCRSet

    Let \((S, +)\) be a commutative semigroup, and add ultrafilters on \(S\) by the rule that \(E \in p + q\) if and only if \(\{x \in S : \{y \in S : x + y \in E\} \in q\} \in p\).     DefinitionFamilies with the Ramsey property#✓fully proved

    MetaMathlibExt.IsRamseyFamily

    Let \(S\) be a set. A collection \(F\) of subsets of \(S\) is a family with the Ramsey property when \(F\) is nonempty, \(\emptyset \notin F\), \(F\) is closed under supersets (if \(A \in F\) and \(A \subseteq B\), then \(B \in F\)), and whenever \(A \cup B \in F\), then \(A \in F\) or \(B \in F\).

    def IsRamseyFamily (F : Set (Set S)) : Prop :=
  F.Nonempty ∧ ∅ ∉ F ∧ (∀ A B, A ∈ F → A ⊆ B → B ∈ F) ∧
    ∀ A B, A ∪ B ∈ F → A ∈ F ∨ B ∈ F

    MetaMathlibExt.betaFamily_isSubsemigroup_iff
