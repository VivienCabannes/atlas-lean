    DefinitionPiecewise syndetic subsets of a semigroup#✓fully proved

    MetaMathlibExt.IsMulPiecewiseSyndetic

    A set \(D\) in a semigroup \(S\) is piecewise syndetic when there is a finite set \(G \subseteq S\) such that for every finite set \(F \subseteq S\) there is \(x \in S\) with \(Fx \subseteq \bigcup_{t \in G} t^{-1} D\), where \(Fx = \{fx : f \in F\}\) and \(t^{-1} D = \{s \in S : ts \in D\}\).

    def IsMulPiecewiseSyndetic (D : Set S) : Prop :=
  ∃ G : Finset S, ∀ F : Finset S, ∃ x : S, ∀ f ∈ F, ∃ t ∈ G, t * (f * x) ∈ D

    DefinitionJ-sets in a semigroup#✓fully proved

    MetaMathlibExt.IsMulJSet

    A set \(D\) in a semigroup \(S\) is a \(J\)-set when for every nonempty finite set \(F\) of sequences \(f : \mathbb{N} \to S\), where \(\mathbb{N} = \{0, 1, 2, \dots\}\), there are an integer \(m \ge 1\), elements \(a_1, \dots, a_{m+1} \in S\) and indices \(t_1 < \dots < t_m\) in \(\mathbb{N}\) such that \(a_1 f(t_1) a_2 f(t_2) \cdots a_m f(t_m) a_{m+1} \in D\) for every \(f \in F\).

    def IsMulJSet (D : Set S) : Prop :=
  ∀ F : Finset (ℕ → S), F.Nonempty → ∃ (m : ℕ) (a : Fin (m + 2) → S) (t : Fin (m + 1) → ℕ),
    StrictMono t ∧ ∀ f ∈ F,
      (List.ofFn fun j : Fin m => a j.succ.castSucc * f (t j.succ)).foldl (· * ·)
          (a 0 * f (t 0)) * a (Fin.last (m + 1)) ∈ D

    DefinitionCentral sets in a semigroup#✓fully proved

    MetaMathlibExt.IsCentralSet

    Let \(S\) be a semigroup and let \(\beta S\) be the set of ultrafilters on \(S\), with the product for which \(D \in pq\) exactly when \(\{x \in S : \{y \in S : xy \in D\} \in q\} \in p\). A two-sided ideal of \(\beta S\) is a set \(I \subseteq \beta S\) with \(rq \in I\) and \(qr \in I\) for all \(q \in I\) and \(r \in \beta S\). A set \(D \subseteq S\) is central when some \(p \in \beta S\) with \(pp = p\) lies in every nonempty two-sided ideal of \(\beta S\) and has \(D \in p\).

    Equivalently, \(D \in p\) for a minimal idempotent \(p\), that is, an idempotent of the smallest two-sided ideal \(K(\beta S)\), which is itself a nonempty two-sided ideal lying in all of them.

    def IsCentralSet (D : Set S) : Prop :=
  ∃ p : Ultrafilter S, p * p = p ∧
    (∀ I : Set (Ultrafilter S), I.Nonempty → (∀ q ∈ I, ∀ r, r * q ∈ I ∧ q * r ∈ I) → p ∈ I) ∧
    D ∈ p

    DefinitionC-sets in a semigroup#✓fully proved

    MetaMathlibExt.IsCSet

    Let \(S\) be a semigroup and let \(\beta S\) be the set of ultrafilters on \(S\), with the product for which \(D \in pq\) exactly when \(\{x \in S : \{y \in S : xy \in D\} \in q\} \in p\). Let \(J(S)\) be the set of ultrafilters on \(S\) all of whose members are \(J\)-sets. A set \(D \subseteq S\) is a \(C\)-set when \(D \in p\) for some \(p \in J(S)\) with \(pp = p\).

    def IsCSet (D : Set S) : Prop :=
  ∃ p : Ultrafilter S, p * p = p ∧ (∀ B ∈ p, IsMulJSet B) ∧ D ∈ p
