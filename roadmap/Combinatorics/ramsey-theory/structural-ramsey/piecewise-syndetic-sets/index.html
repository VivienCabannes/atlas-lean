    MetaMathlibExt.latticeCube

    For \(t, m \in \mathbb{N}\) and \(a \in \mathbb{N}^t\), the lattice cube with least corner \(a\) and side \(m\) is the set of points \(x \in \mathbb{N}^t\) such that \(a_i \le x_i < a_i + m\) for every coordinate \(i\); it is a subcube of size \(m^t\).

    def latticeCube {t : ℕ} (a : Fin t → ℕ) (m : ℕ) : Set (Fin t → ℕ) :=
  Set.univ.pi fun i => Set.Ico (a i) (a i + m)

    Let \(t \in \mathbb{N}\). A set \(A \subseteq \mathbb{N}^t\) is piecewise syndetic if there is \(d \in \mathbb{N}\) such that, writing \([0, d] = \{0, 1, \dots, d\}\), for every \(m \in \mathbb{N}\) the set \(A + [0, d]^t = \{y + z : y \in A,\ z \in [0, d]^t\}\) contains a lattice cube of side \(m\).

    def IsPiecewiseSyndetic {t : ℕ} (A : Set (Fin t → ℕ)) : Prop :=
  ∃ d : ℕ, ∀ m : ℕ, ∃ a : Fin t → ℕ,

    DefinitionGap size#✓fully proved

    MetaMathlibExt.cubeGapSize

    For a set \(S \subseteq \mathbb{N}^t\), the gap size \(\operatorname{gs}(S)\) is the least \(d \ge 1\) such that \(S\) is \(d\)-dense in some subcube of \(\mathbb{N}^t\) that contains \(S\). If no such \(d\) exists (for instance when \(S\) is unbounded, so that no subcube contains it), the value is \(0\).

    For \(t = 1\), the gap size of a finite set with at least two points is the largest difference between consecutive elements, and a one-point set has gap size \(1\) (Definition 1). The paper defines \(\operatorname{gs}\) only for finite sets; when \(t \ge 1\), every finite set has positive gap size.

    public noncomputable def cubeGapSize {t : ℕ} (S : Set (Fin t → ℕ)) : ℕ :=
  sInf {d : ℕ | 0 < d ∧ ∃ (a : Fin t → ℕ) (m : ℕ), S ⊆ latticeCube a m ∧
    IsDenseInCubes d S (latticeCube a m)}
