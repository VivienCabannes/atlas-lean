    MetaMathlibExt.arndtCompositionCount

    For a set \(S\) of natural numbers and natural numbers \(n\) and \(k\), \(a_S(n, k)\) is the number of \(k\)-tuples \((c_1, \dots, c_k)\) of positive integers such that \(c_1 + \dots + c_k = n\), every \(c_i\) lies in \(S\), and \(c_{2i-1} > c_{2i}\) for every \(i\) with \(2i \le k\). These tuples are the Arndt compositions of \(n\) with \(k\) parts in \(S\).

    def arndtCompositionCount (S : ℕ → Prop) [DecidablePred S] (n k : ℕ) : ℕ :=
  ((Finset.Nat.antidiagonalTuple k n).filter fun c =>
    (∀ i, 0 < c i ∧ S (c i)) ∧
      ∀ i j : Fin k, (i : ℕ) % 2 = 0 → (j : ℕ) = i + 1 → c j < c i).card

    DefinitionGenerating function of Arndt compositions with parts in a set#✓fully proved

    MetaMathlibExt.arndtGF

    An Arndt composition is a finite sequence \((\sigma_1, \dots, \sigma_k)\) of positive integers such that \(\sigma_{2i-1} > \sigma_{2i}\) for every \(i\) with \(2i \le k\). For a set \(S\) of natural numbers, let \(a_S(n, k)\) be the number of Arndt compositions of \(n\) with \(k\) parts, all in \(S\). The bivariate generating function of these compositions, by weight (\(x\)) and number of parts (\(y\)), is the power series \(A_S(x, y) = \sum_{n \ge 0} \left(\sum_{k=0}^{n} a_S(n, k)\, y^k\right) x^n\) in \(\mathbb{Z}[y][[x]]\).

    noncomputable def arndtGF (S : ℕ → Prop) [DecidablePred S] : PowerSeries (Polynomial ℤ) :=
  PowerSeries.mk fun n =>
    ∑ k ∈ Finset.range (n + 1), (arndtCompositionCount S n k : Polynomial ℤ) * Polynomial.X ^ k
