    DefinitionSigned count of compositions#✓fully proved

    MetaMathlibExt.compositionOddMinusEven

    For a natural number \(N\) and a property \(P\) of compositions of \(N\), the signed count of the compositions of \(N\) satisfying \(P\) is the number of them with an odd number of parts minus the number with an even number of parts. Equivalently, it is the sum of \((-1)^{\ell(c) + 1}\) over all compositions \(c\) of \(N\) satisfying \(P\), where \(\ell(c)\) is the number of parts of \(c\).

    public noncomputable def compositionOddMinusEven (N : ℕ) (P : Composition N → Prop) : ℤ :=
  ∑ c : Composition N, if P c then (-1) ^ (c.length + 1) else 0

    DefinitionHuang's placement condition for small parts#✓fully proved

    MetaMathlibExt.IsHuangSmallPartPlacement

    Let \(k\) be a natural number. A finite sequence \((a_0, \dots, a_{\ell - 1})\) of natural numbers satisfies the placement condition for \(k\) when every entry \(a_i < k\) has a preceding entry and a following entry, the preceding entry satisfies \(a_{i-1} \ge k\), and the following entry \(a_{i+1}\) is either the last entry (that is, \(i + 2 = \ell\)) or satisfies \(a_{i+1} > k\).

    public def IsHuangSmallPartPlacement (k : ℕ) (L : List ℕ) : Prop :=
  ∀ (i a : ℕ), L[i]? = some a → a < k →
    0 < i ∧ (∃ b, L[i - 1]? = some b ∧ k ≤ b) ∧
      ∃ c, L[i + 1]? = some c ∧ (i + 2 = L.length ∨ k < c)
