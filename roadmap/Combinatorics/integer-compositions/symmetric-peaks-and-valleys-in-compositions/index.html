    Symmetric peaks and valleys in compositions

    DefinitionNumber of symmetric peaks#✓fully proved

    MetaMathlibExt.symmetricPeakCount

    For a finite word \(w = w_1 w_2 \cdots w_m\) of natural numbers, a symmetric peak is a factor \(w_i w_{i+1} w_{i+2}\) of three consecutive letters with \(w_i = w_{i+2} < w_{i+1}\). The number of symmetric peaks of \(w\) is the number of indices \(i\) with \(1 \le i \le m - 2\) at which \(w\) has a symmetric peak (overlapping peaks all count); it is \(0\) when \(m < 3\).

    def symmetricPeakCount : List ℕ → ℕ
  | a :: b :: c :: t => (if a = c ∧ a < b then 1 else 0) + symmetricPeakCount (b :: c :: t)
  | _ => 0

    DefinitionSum of the heights of symmetric peaks#✓fully proved

    MetaMathlibExt.symmetricPeakHeightSum

    For a finite word \(w = w_1 w_2 \cdots w_m\) of natural numbers, a symmetric peak is a factor \(w_i w_{i+1} w_{i+2}\) of three consecutive letters with \(w_i = w_{i+2} < w_{i+1}\), and its height is \(w_{i+1} - w_i\). The symmetric peak height sum of \(w\) is the sum of the heights of the symmetric peaks of \(w\) over all indices \(i\) with \(1 \le i \le m - 2\) at which one occurs; it is \(0\) when \(m < 3\).

    def symmetricPeakHeightSum : List ℕ → ℕ
  | a :: b :: c :: t =>
      (if a = c ∧ a < b then b - a else 0) + symmetricPeakHeightSum (b :: c :: t)
  | _ => 0

    DefinitionNumber of symmetric valleys of a word#✓fully proved

    MetaMathlibExt.symmetricValleyCount

    For a word \(w = w_1 w_2 \cdots w_\ell\) of natural numbers, a symmetric valley is a position \(i\) with \(1 < i < \ell\) such that \(w_{i-1} = w_{i+1}\) and \(w_i < w_{i-1}\), that is, a factor \(a\,b\,a\) with \(b < a\). The symmetric valley count of \(w\) is the number of such positions; in particular it is \(0\) when \(\ell < 3\).

    def symmetricValleyCount : List ℕ → ℕ
  | a :: b :: c :: t => (if a = c ∧ b < a then 1 else 0) + symmetricValleyCount (b :: c :: t)
  | _ => 0

    MetaMathlibExt.symmetricValleyDepthSum

    For a word \(w = w_1 w_2 \cdots w_\ell\) of natural numbers, a symmetric valley is a position \(i\) with \(1 < i < \ell\) such that \(w_{i-1} = w_{i+1}\) and \(w_i < w_{i-1}\); its depth is \(w_{i-1} - w_i\). The symmetric valley depth sum of \(w\) is the sum of the depths of all its symmetric valleys; in particular it is \(0\) when \(\ell < 3\).

    TheoremExpected symmetric peaks and valleys in geometric words#●ready to prove

    MetaMathlibExt.integral_symmetricPeakValley_geometric

    Let \(n \ge 2\), let \(0 < p < 1\) and \(q = 1 - p\), and let \(X_1, \dots, X_n\) be independent random variables, each geometric on \(\{0, 1, 2, \dots\}\) with \(\Pr(X_i = k) = q^k p\), and consider the word \(X_1 X_2 \cdots X_n\). The expected number of its symmetric peaks is \(p^2 q (n - 2)/(1 - q^3)\), the expected number of its symmetric valleys is \(p^2 \left(\frac{1}{1 - q^2} - \frac{1}{1 - q^3}\right)(n - 2)\), the expected sum of the heights of its symmetric peaks is \(p q (n - 2)/(1 - q^3)\), and the expected sum of the depths of its symmetric valleys is \(q \left(\frac{p}{1 - q^3} - \frac{1}{(1 + q)^2}\right)(n - 2)\).

    public theorem_wanted integral_symmetricPeakValley_geometric (n : ℕ) (hn : 2 ≤ n)
    (p : unitInterval) (hp0 : p ≠ 0) (hp1 : p ≠ 1) :

    ∫ x, (symmetricPeakCount (List.ofFn x) : ℝ) ∂μ = p ^ 2 * q / (1 - q ^ 3) * (n - 2) ∧
      ∫ x, (symmetricValleyCount (List.ofFn x) : ℝ) ∂μ =
