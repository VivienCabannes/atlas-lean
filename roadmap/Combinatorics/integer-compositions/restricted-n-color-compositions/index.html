    DefinitionSplitting a ternary string at its zeros, with a prefix#✓fully proved

    MathlibExt.Combinatorics.Enumerative.NColorCompositionsWanted.splitZerosAux

    For strings \(w\) and \(a\) over \(\{0, 1, 2\}\), write \(w = s_0 \, 0 \, s_1 \, 0 \cdots 0 \, s_m\) where \(m\) is the number of \(0\)s in \(w\) and each \(s_i\) is a (possibly empty) string without \(0\). The result is the list of strings \(a s_0, s_1, \dots, s_m\), in this order, where \(a s_0\) is the concatenation of \(a\) and \(s_0\).

    def splitZerosAux : List (Fin 3) → List (Fin 3) → List (List (Fin 3))
  | [], acc => [acc]
  | x :: xs, acc =>
      if x = 0 then acc :: splitZerosAux xs [] else
        splitZerosAux xs (acc ++ [x])

    MathlibExt.Combinatorics.Enumerative.NColorCompositionsWanted.splitZeros

    For a string \(w\) over \(\{0, 1, 2\}\), the list of the segments of \(w\) obtained by cutting at every \(0\): the part before the first \(0\), the parts between consecutive \(0\)s and the part after the last \(0\), in order and including empty parts.     DefinitionAdmissible ternary strings#✓fully proved

    MathlibExt.Combinatorics.Enumerative.NColorCompositionsWanted.TernaryAdmissible

    For natural numbers \(b\) and \(n\), the strings \(w\) over \(\{0, 1, 2\}\) of length \(n - 1\) (truncated subtraction, so length \(0\) when \(n = 0\)) such that every segment of \(w\) obtained by cutting at its zeros (before the first zero, between consecutive zeros and after the last zero, empty segments included) either consists only of \(1\)s and has length at least \(b - 1\), or consists only of \(2\)s and has length at least \(b\). In particular an empty segment is allowed exactly when \(b \le 1\).

    This is the segment form of the conditions in Theorem 2 of Hopkins and Wang (no \(12\) or \(21\) subwords, run-length bounds, and separation of successive zeros).

    def TernaryAdmissible (b n : ℕ) : Type :=
  { w : List (Fin 3) // w.length = n - 1 ∧
    ∀ seg ∈ splitZeros w,
      ((∀ x ∈ seg, x = 1) ∧ b - 1 ≤ seg.length) ∨
        ((∀ x ∈ seg, x = 2) ∧ b ≤ seg.length) }
    def splitZeros (w : List (Fin 3)) : List (List (Fin 3)) :=
  splitZerosAux w []

    MathlibExt.Combinatorics.Enumerative.NColorCompositionsWanted.TwoTypeComp

    For a natural number \(n\), \(C^*_{1,2}(n)\) is the set of compositions of \(n\) whose parts are \(1_1\), \(1_2\) (two types of part of size \(1\)) and \(2\), such that no two adjacent parts are parts \(1\) of the same type.

    MathlibExt.Combinatorics.Enumerative.NColorCompositionsWanted.ccoAllowed_eq_sum

    Let \(b \ge 1\) and \(n \ge 1\) be natural numbers, and let \(\operatorname{cco}_{b,b+1}(n)\) be the number of \(n\)-color compositions of \(n\) in which every part has color \(b\) or \(b+1\). Then

    \[\operatorname{cco}_{b,b+1}(n) = \sum_{m=1}^{n} \sum_{i=0}^{n-bm} \binom{i+m-1}{m-1} \binom{m}{n-bm-i},\]

    where the upper limit \(n - bm\) is read as \(0\) when \(bm > n\), and every term with \(bm + i > n\) is \(0\).

    theorem_wanted ccoAllowed_eq_sum (b n : ℕ) (hb : 1 ≤ b) (hn : 1 ≤ n) :
    ccoAllowed b n =
      ∑ m ∈ Finset.Icc 1 n,
        ∑ i ∈ Finset.Icc 0 (n - b * m),
          if b * m + i ≤ n then
            Nat.choose (i + m - 1) (m - 1) *
              Nat.choose m (n - b * m - i)
          else 0
