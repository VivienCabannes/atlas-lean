    MetaMathlibExt.sum_count_eq_sum_card_parts_count_ge

    Let \(n\) and \(k\) be natural numbers with \(k \ge 1\). The total number of times the part \(k\) occurs, counted with multiplicity, over all partitions of \(n\) equals the sum, over all partitions \(\lambda\) of \(n\), of the number of distinct parts of \(\lambda\) that occur at least \(k\) times in \(\lambda\).

    DefinitionMultisets of parts with a given size sum#✓fully proved

    MetaMathlibExt.multisetsWithSizeSum

    For a list \(L\) of pairs of natural numbers, where the size of a pair \((k, j)\) is \(k\), and a natural number \(n\), this is the finite set of multisets of pairs defined by recursion on \(L\). For the empty list it is the set containing only the empty multiset when \(n = 0\), and the empty set otherwise. For a list with head \(c\) of size \(k\) and tail \(L'\), it is the set of all multisets obtained by adding \(i\) copies of \(c\) to a member of the set for \(L'\) and \(n - ik\), where \(i\) ranges over the natural numbers with \(i \le n\) and \(ik \le n\).

    When every pair in \(L\) has positive size, this is exactly the set of multisets whose elements all lie in \(L\) and whose sizes, counted with multiplicity, sum to \(n\).

    public def multisetsWithSizeSum : List (ℕ × ℕ) → ℕ → Finset (Multiset (ℕ × ℕ))
  | [], n => if n = 0 then {0} else ∅
  | c :: cs, n => (Finset.range (n + 1)).biUnion fun i =>
      if i * c.1 ≤ n then
        (multisetsWithSizeSum cs (n - i * c.1)).image (Multiset.replicate i c + ·)
      else ∅
