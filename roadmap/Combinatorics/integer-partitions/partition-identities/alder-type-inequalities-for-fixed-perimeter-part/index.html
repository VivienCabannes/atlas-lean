    DefinitionPrepending a part to a multiset#✓fully proved

    MetaMathlibExt.symConsEmbedding

    For natural numbers \(m\) and \(k\), the map that sends a multiset \(t\) of \(k\) natural numbers to the multiset obtained from \(t\) by adding one copy of \(m\) is injective, so it embeds the multisets of size \(k\) into all multisets of natural numbers.

    With \(m\) the largest part, it builds the partitions of a given perimeter from their largest part and their remaining parts.

    public def symConsEmbedding (m k : ℕ) : Sym ℕ k ↪ Multiset ℕ :=
  ⟨fun t => m ::ₘ (t : Multiset ℕ),
    fun _ _ h => Sym.coe_injective ((Multiset.cons_inj_right m).mp h)⟩

    DefinitionPartitions with fixed perimeter#✓fully proved

    MetaMathlibExt.fixedPerimeterPartitions

    The perimeter of a partition is its largest part plus its number of parts minus \(1\). For a natural number \(n\), the partitions with perimeter \(n\) form the finite set of all finite multisets \(s\) of positive integers whose largest element plus number of elements (counted with multiplicity) equals \(n + 1\).

    The set is enumerated directly: for each number of parts \(k = 1, \dots, n\) the largest part is \(n + 1 - k\), and it is prepended to a multiset of \(k - 1\) parts from \(1, \dots, n + 1 - k\), so the \(2^{n-1}\) partitions with perimeter \(n\) (for \(n \ge 1\)) are listed without filtering or deduplication.

    MetaMathlibExt.fixedPerimeterPartitions · 16 lines 
    public def fixedPerimeterPartitions (n : ℕ) : Finset (Multiset ℕ) :=
  (Finset.Icc 1 n).disjiUnion
    (fun k => ((Finset.Icc 1 (n + 1 - k)).sym (k - 1)).map (symConsEmbedding (n + 1 - k) (k - 1)))
    (by
      intro k hk k' hk' hkk'
      simp only [Function.onFun]
      rw [Finset.disjoint_left]
      intro s hs hs'
      simp only [Finset.mem_map] at hs hs'
      obtain ⟨t, -, rfl⟩ := hs
      obtain ⟨t', -, h⟩ := hs'
      change (n + 1 - k') ::ₘ (t' : Multiset ℕ) = (n + 1 - k) ::ₘ (t : Multiset ℕ) at h
      have := congrArg Multiset.card h
      simp only [Multiset.card_cons, Sym.card_coe] at this
      simp only [Finset.mem_coe, Finset.mem_Icc] at hk hk'
      omega)

    TheoremMembership in the partitions with fixed perimeter#✓fully proved

    MetaMathlibExt.mem_fixedPerimeterPartitions

    Let \(n\) be a natural number and \(s\) a finite multiset of natural numbers. Then \(s\) is a partition with perimeter \(n\) if and only if every element of \(s\) is positive and the largest element of \(s\) (taken to be \(0\) if \(s\) is empty) plus the number of elements of \(s\), counted with multiplicity, equals \(n + 1\).

    public theorem mem_fixedPerimeterPartitions {n : ℕ} {s : Multiset ℕ} :
    s ∈ fixedPerimeterPartitions n ↔ (∀ x ∈ s, 0 < x) ∧ s.sup + Multiset.card s = n + 1

    DefinitionPartitions into d-distinct parts#✓fully proved

    MetaMathlibExt.IsDDistinctParts

    Let \(d\) be a natural number. A finite multiset \(s\) of natural numbers has \(d\)-distinct parts when no element occurs in \(s\) more than once and any two elements \(x < y\) of \(s\) satisfy \(x + d \le y\).

    public def IsDDistinctParts (d : ℕ) (s : Multiset ℕ) : Prop :=
  s.Nodup ∧ ∀ x ∈ s, ∀ y ∈ s, x < y → x + d ≤ y
