    TheoremPartitions with unique subsums except one#●ready to prove

    MetaMathlibExt.exists_partition_unique_subsums_but_one_iff

    The partitions of \(m\) contained in a partition \(\lambda\) are the distinct sub-multisets of the parts of \(\lambda\) with sum \(m\). Let \(v \ge 1\). There are a natural number \(n\) and a partition \(\lambda\) of \(n\) that contains exactly \(v\) partitions of some \(m\) with \(v \le m \le n - v\) and exactly one partition of every positive integer \(m' < n\) other than \(m\) if and only if \(v = 1\) or \(v = 2\).

    The hypothesis \(v \ge 1\) is needed: for \(v = 0\) the partition \((2)\) of \(2\) qualifies with \(m = 1\), since it contains no partition of \(1\).

    public theorem_wanted exists_partition_unique_subsums_but_one_iff (v : ℕ) (hv : 1 ≤ v) :
    (∃ n : ℕ, ∃ p : n.Partition,
      let c : ℕ → ℕ := fun m => (p.parts.powerset.toFinset.filter fun s => s.sum = m).card
      ∃ m, v ≤ m ∧ m ≤ n - v ∧ c m = v ∧ ∀ m', 0 < m' → m' < n → m' ≠ m → c m' = 1) ↔
      v = 1 ∨ v = 2

    DefinitionNumber of subpartitions with a given sum#✓fully proved

    MetaMathlibExt.subpartitionCount

    For a multiset \(\lambda\) of natural numbers and \(m \in \mathbb{N}\), the number of partitions of \(m\) contained in \(\lambda\) is the number of distinct sub-multisets of \(\lambda\) whose elements sum to \(m\).

    Sub-multisets are counted as multisets, not by the positions of their parts: the paper's example counts \((1)\) once in \((1^5, 2)\).

    def subpartitionCount (l : Multiset ℕ) (m : ℕ) : ℕ :=
  (l.powerset.toFinset.filter fun s => s.sum = m).card

    DefinitionPerfect partition#✓fully proved

    MetaMathlibExt.IsPerfectPartition

    Let \(n\) be a natural number. A multiset \(\lambda\) of natural numbers is a perfect partition of \(n\) when its elements are positive, they sum to \(n\), and for every integer \(m\) with \(1 \le m \le n\) exactly one partition of \(m\) is contained in \(\lambda\), that is, exactly one sub-multiset of \(\lambda\) has sum \(m\) (equal sub-multisets are counted once).

    def IsPerfectPartition (n : ℕ) (l : Multiset ℕ) : Prop :=
  (∀ a ∈ l, 0 < a) ∧ l.sum = n ∧ ∀ m ∈ Finset.Icc 1 n, subpartitionCount l m = 1
    def subpartitionCount (l : Multiset ℕ) (m : ℕ) : ℕ :=
  (l.powerset.toFinset.filter fun s => s.sum = m).card

    DefinitionDouble-perfect partitions of higher order#✓fully proved

    MetaMathlibExt.IsDoublePerfectOfOrder

    A double-perfect partition of \(N\) of order \(r\) is a finite multiset \(\lambda\) of positive integers with sum \(N\) such that, for every integer \(m\) with \(1 \le m \le N\), the number of distinct sub-multisets of \(\lambda\) with sum \(m\) is \(2\) if \(r + 1 \le m \le N - r - 1\) and \(1\) otherwise. Their set is denoted \(U_r(N)\); order \(1\) gives the double-perfect partitions.

    def IsDoublePerfectOfOrder (r N : ℕ) (l : Multiset ℕ) : Prop :=
  (∀ a ∈ l, 0 < a) ∧ l.sum = N ∧
    ∀ m ∈ Finset.Icc 1 N,
      subpartitionCount l m = if r + 1 ≤ m ∧ m + r + 1 ≤ N then 2 else 1
    def subpartitionCount (l : Multiset ℕ) (m : ℕ) : ℕ :=
  (l.powerset.toFinset.filter fun s => s.sum = m).card

    MetaMathlibExt.IsTypeADoublePerfect

    Let \(r\) and \(N\) be natural numbers. A multiset \(\lambda\) of natural numbers is a Type-A double-perfect partition of \(N\) of order \(r\) when \(\lambda\) is a double-perfect partition of \(N\) of order \(r\) and there is a perfect partition \(\beta\) of \(N - r - 1\) (read as \(0\) when \(N \le r\)) such that \(\lambda\) is \(\beta\) with \(r + 1\) parts equal to \(1\) added, or \(\beta\) with one part equal to \(r + 1\) added.     (l = β + Multiset.replicate (r + 1) 1 ∨ l = β + {r + 1})

    DefinitionMacMahon's partition of an ordered factorization#✓fully proved

    MetaMathlibExt.perfectPartitionOfFactorization

    To a finite sequence \((a_1, \dots, a_k)\) of natural numbers, read as the ordered factorization \(a_1 a_2 \cdots a_k\), attach the multiset of parts \((1^{a_1-1}, a_1^{a_2-1}, (a_1a_2)^{a_3-1}, \dots, (a_1\cdots a_{k-1})^{a_k-1})\), where \(x^e\) denotes \(e\) parts equal to \(x\) and an exponent \(a_i - 1\) is read as \(0\) when \(a_i = 0\). In particular the empty sequence gives the empty multiset.

    For factors \(a_i \ge 2\) this is MacMahon's bijection (1): for each \(n \ge 0\), it maps the ordered factorizations of \(n + 1\) into such factors onto the perfect partitions of \(n\).

    def perfectPartitionOfFactorization : List ℕ → Multiset ℕ
  | [] => 0
  | a :: as => Multiset.replicate (a - 1) 1 + (perfectPartitionOfFactorization as).map (a * ·)

    DefinitionTruncated recursion for ordered factorizations#✓fully proved

    MetaMathlibExt.orderedFactorizationCountAux

    For natural numbers \(k\) and \(n\), define \(f_k(n)\) by recursion on \(k\): \(f_0(n) = 0\), \(f_{k+1}(1) = 1\), and for \(n \ne 1\), \(f_{k+1}(n)\) is the sum of \(f_k(d)\) over the proper divisors \(d\) of \(n\), that is, the divisors \(d\) of \(n\) with \(1 \le d < n\) (there are none when \(n = 0\)).

    def orderedFactorizationCountAux : ℕ → ℕ → ℕ

  | k + 1, n => if n = 1 then 1 else ∑ d ∈ n.properDivisors, orderedFactorizationCountAux k d

    TheoremDouble-perfect partitions from perfect partitions#●ready to prove

    MetaMathlibExt.isDoublePerfect_one_iff

    Let \(N > 3\). A multiset \(\lambda\) of natural numbers is a double-perfect partition of \(N\) of order \(1\) if and only if there is a perfect partition \(\beta\) of \(N - 2\) such that either \(1\) occurs exactly once in \(\beta\) and \(\lambda\) is \(\beta\) with two more parts equal to \(1\), or \(2\) is not a part of \(\beta\) and \(\lambda\) is \(\beta\) with one more part equal to \(2\).

    public theorem_wanted isDoublePerfect_one_iff (N : ℕ) (hN : 3 < N) (l : Multiset ℕ) :
