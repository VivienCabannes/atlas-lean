    DefinitionLit cells of a weakly increasing bargraph#✓fully proved

    MetaMathlibExt.litCellsIncreasing

    For a partition \(p\) of \(n\), the number of lit cells of \(p\), drawn as a weakly increasing bargraph, is defined as the largest part of \(p\) plus the number of parts of \(p\) minus the number of distinct parts of \(p\) (the largest part of the empty partition is \(0\)).

    public def litCellsIncreasing {n : ℕ} (p : Nat.Partition n) : ℕ :=
  p.parts.sup + p.parts.card - p.parts.dedup.card

    DefinitionLit cells of a weakly decreasing bargraph#✓fully proved

    MetaMathlibExt.litCellsDecreasing

    Let \(p\) be a partition of \(n\) with \(\ell\) parts \(x_1 \ge x_2 \ge \cdots \ge x_\ell\). The number of lit cells of \(p\), drawn as a weakly decreasing bargraph, is defined as \(\max_{1 \le i \le \ell} (x_i + i - 1)\), and as \(0\) when \(p\) has no parts. It is the largest part of the image of \(p\) under Prodinger's bijection \(x_i \mapsto x_i + i - 1\).

    public def litCellsDecreasing {n : ℕ} (p : Nat.Partition n) : ℕ :=
  ((decreasingParts p).mapIdx fun i x => x + i).foldr max 0

    DefinitionTriangular \(q\)-binomial coefficient#✓fully proved

    MetaMathlibExt.triangularQBinomial

    For natural numbers \(r\) and \(s\), the triangular \(q\)-binomial coefficient \(t[r, s] \in \mathbb{Z}[[q]]\) is the power series whose coefficient of \(q^n\) is the number of partitions of \(n\) with exactly \(s\) parts \(x_1 \ge \dots \ge x_s\) that fit in the staircase with column heights \(r, r - 1, \dots, r - s + 1\), that is, with \(x_i + (i - 1) \le r\) for \(1 \le i \le s\).

    public noncomputable def triangularQBinomial (r s : ℕ) : ℤ⟦X⟧ :=
  mk fun n => ((Finset.univ.filter fun p : Nat.Partition n =>
    p.parts.card = s ∧ ∀ i < s, (decreasingParts p).getD i 0 + i ≤ r).card : ℤ)

    MetaMathlibExt.triangularQBinomial_recursion

    The triangular \(q\)-binomial coefficients \(t[r, s] \in \mathbb{Z}[[q]]\) satisfy the recursion \(t[r, s] = q^s \sum_{i=0}^{s} t[r - 1, i]\) for all natural numbers \(r \ge 1\) and \(s \le r\), together with the initial conditions \(t[1, 1] = q\), \(t[2, 1] = q(1 + q)\), \(t[r, 0] = 1\) for every \(r\), and \(t[r, s] = 0\) whenever \(r < s\).

    TheoremLit cells when only the first column is lit#●ready to prove

    MetaMathlibExt.litCellsDecreasing_firstColumn_generatingFunction

    For a partition \(p\) of \(n\) with \(\ell \ge 1\) parts \(x_1 \ge x_2 \ge \cdots \ge x_\ell\), say that only the first column of its weakly decreasing bargraph is lit when the number of lit cells of \(p\) equals its largest part \(x_1\), that is, when \(x_i + i - 1 \le x_1\) for \(1 \le i \le \ell\). Let \(F(q) \in \mathbb{Z}[[q]]\) be the power series whose coefficient of \(q^n\) is the sum of \(x_1\) over the partitions of \(n\) in which only the first column is lit and \(x_1 \ge 2\). For \(r \ge 0\) let \(T_q(r)\) be the generating function of partitions contained in the triangle with column heights \(r, r - 1, \ldots, 1\). Then
