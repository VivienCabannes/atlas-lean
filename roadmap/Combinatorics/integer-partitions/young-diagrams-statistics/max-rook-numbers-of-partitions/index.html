    DefinitionMax-rook number of a board#✓fully proved

    MetaMathlibExt.boardMaxRookNumber

    For a finite board \(B \subseteq \mathbb{N} \times \mathbb{N}\), whose cell \((i, j)\) lies in row \(i\) and column \(j\), the max-rook number of \(B\) is the largest size of a subset of \(B\) that contains at most one cell of each row and at most one cell of each column, that is, the largest number of non-attacking rooks that can be placed on \(B\).

    def boardMaxRookNumber (B : Finset (ℕ × ℕ)) : ℕ :=
  (B.powerset.filter fun S =>
    (S.image Prod.fst).card = S.card ∧ (S.image Prod.snd).card = S.card).sup Finset.card

    DefinitionFerrers board of a partition#✓fully proved

    MetaMathlibExt.partitionFerrersBoard

    Let \(p\) be a partition of \(n\), and number rows and columns from \(0\). The Ferrers board of \(p\) is the finite set of cells \((i, j) \in \mathbb{N} \times \mathbb{N}\) such that the \((i+1)\)-st largest part of \(p\) exceeds \(j\), that is, such that more than \(i\) parts of \(p\), counted with multiplicity, exceed \(j\).

    def partitionFerrersBoard {n : ℕ} (p : Nat.Partition n) : Finset (ℕ × ℕ) :=
  ((Finset.range n) ×ˢ (Finset.range n)).filter fun c =>
    c.1 < (p.parts.filter (c.2 < ·)).card

    DefinitionMax-rook number of a partition#✓fully proved

    MetaMathlibExt.partitionMaxRookNumber

    The max-rook number \(R(\pi)\) of a partition \(\pi\) of \(n\) is the largest number of non-attacking rooks on the Ferrers board of \(\pi\): the largest number of cells of the board, no two in the same row and no two in the same column.

    def partitionMaxRookNumber {n : ℕ} (p : Nat.Partition n) : ℕ :=
  boardMaxRookNumber (partitionFerrersBoard p)
