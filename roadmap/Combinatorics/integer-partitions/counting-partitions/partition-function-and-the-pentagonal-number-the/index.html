    TheoremPartition generating function with unit weights#✓fully proved

    MetaMathlibExt.mk_partitionFunction_eq_genFun

    Let \(p(n)\) be the number of partitions of \(n\). Over the integers, \(\sum_{n \ge 0} p(n)\, x^n\) equals the weighted partition generating function \(\sum_{n \ge 0} \sum_{\lambda} \prod_{i} f(i, c_i(\lambda))\, x^n\) with all weights \(f(i, c) = 1\), where \(\lambda\) runs over the partitions of \(n\), \(i\) over the distinct parts of \(\lambda\), and \(c_i(\lambda)\) is the number of times \(i\) occurs in \(\lambda\).

    theorem mk_partitionFunction_eq_genFun :
    PowerSeries.mk (fun n => ((partitionFunction n : ℕ) : ℤ))
      = Nat.Partition.genFun (fun _ _ => (1 : ℤ))
    def partitionFunction (n : ℕ) : ℕ :=
  Fintype.card (Nat.Partition n)

    MetaMathlibExt.mk_partitionFunction_mul_pentagonalSeries

    Let \(p(n)\) be the number of partitions of \(n\). Over the integers, \(\left(\sum_{n \ge 0} p(n)\, x^n\right) \cdot \sum_{k \in \mathbb{Z}} (-1)^k x^{k(3k-1)/2} = 1\). By the pentagonal number theorem the second factor equals \(\prod_{i \ge 1} (1 - x^i)\).

    theorem mk_partitionFunction_mul_pentagonalSeries :
    PowerSeries.mk (fun n => ((partitionFunction n : ℕ) : ℤ)) *
      PowerSeries.pentagonalSeries ℤ = 1

    TheoremEuler's pentagonal recurrence for the partition function#✓fully proved

    MetaMathlibExt.pentagonal_number_theorem

    Let \(p(n)\) be the number of partitions of \(n\), and for an integer \(k\) let \(g(k) = k(3k - 1)/2\) be the generalized pentagonal number of \(k\). For every natural number \(n \ge 1\), \(p(n) = \sum_{k} (-1)^{k+1}\, p(n - g(k))\), where the sum runs over the nonzero integers \(k\) with \(g(k) \le n\).

    theorem pentagonal_number_theorem (n : ℕ) (hn : 1 ≤ n) :
    (partitionFunction n : ℤ) =
      ∑ m ∈ Finset.filter (fun m : ℕ => 1 ≤ m) (Finset.range (n + 1)),
        (((-1 : ℤ) ^ (m + 1) *
          (if pentagonal (m : ℤ) ≤ n
            then (partitionFunction (n - pentagonal (m : ℤ)) : ℤ)
            else 0)) +
          ((-1 : ℤ) ^ (m + 1) *
            (if pentagonal (-(m : ℤ)) ≤ n
              then (partitionFunction (n - pentagonal (-(m : ℤ))) : ℤ)
              else 0)))
    def partitionFunction (n : ℕ) : ℕ :=
  Fintype.card (Nat.Partition n)
