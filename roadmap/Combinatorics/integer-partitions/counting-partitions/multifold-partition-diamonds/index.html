    DefinitionDescent set of a permutation#✓fully proved

    MetaMathlibExt.permDescentSet

    For a permutation \(\tau\) of \(\{0, 1, \dots, d - 1\}\), the descent set is \(\mathrm{Des}(\tau) = \{p \in \{1, \dots, d - 1\} : \tau(p - 1) > \tau(p)\}\). If \(\tau\) is read as the permutation \(p \mapsto \tau(p - 1) + 1\) of \(\{1, \dots, d\}\), this is the usual descent set: the positions \(p\), numbered from \(1\), where the value at \(p\) exceeds the value at \(p + 1\).

    public def permDescentSet {d : ℕ} (τ : Equiv.Perm (Fin d)) : Finset ℕ :=
  ((Finset.range (d - 1)).filter fun j => permValueAt τ (j + 1) < permValueAt τ j).map
    ⟨(· + 1), add_left_injective 1⟩

    DefinitionMultifold partition diamonds with given fold and link sums#✓fully proved

    MetaMathlibExt.IsMultifoldDiamond

    Let \(d_1, \dots, d_M\) be natural numbers, let \(L_k = \sum_{m=1}^{k} (d_m + 1)\) for \(0 \le k \le M\) be the link positions, let \(c = L_M + 1\), and let \(i\) and \(j\) be natural numbers. A function \(b : \mathbb{N} \to \mathbb{N}\) is a multifold partition diamond with fold sum \(i\) and link sum \(j\) when the following hold: for every \(k\) with \(0 \le k < M\) and every \(f\) with \(1 \le f \le d_{k+1}\), we have \(b(L_k) \le b(L_k + f) \le b(L_{k+1})\); the sum of \(b(p)\) over the positions \(p < c\) different from \(L_0, \dots, L_M\) is \(i\); and \(b(L_0) + \dots + b(L_M) = j\).

    This models the paper's \(P\)-partitions (order-preserving maps to \(\mathbb{Z}_{\ge 0}\)) of the poset in which, for each \(k < M\), the folds at positions \(L_k + 1, \dots, L_k + d_{k+1}\) lie above the link at \(L_k\) and below the link at \(L_{k+1}\). In particular, when every \(d_k \ge 1\), \(b(0)\) is the smallest of \(b(0), \dots, b(c - 1)\).

    public def IsMultifoldDiamond (ds : List ℕ) (i j : ℕ) (b : ℕ → ℕ) : Prop :=
  (∀ k ∈ Finset.range ds.length, ∀ f ∈ Finset.Icc 1 (ds.getD k 0),
      b (diamondLinkPos ds k) ≤ b (diamondLinkPos ds k + f) ∧
        b (diamondLinkPos ds k + f) ≤ b (diamondLinkPos ds (k + 1))) ∧
    (∑ p ∈ (Finset.range (diamondSize ds)).filter (· ∉ diamondLinks ds), b p) = i ∧
    (∑ p ∈ diamondLinks ds, b p) = j
    public def diamondLinkPos (ds : List ℕ) (k : ℕ) : ℕ := ((ds.take k).map (· + 1)).sum

    DefinitionNumber of multifold partition diamonds#✓fully proved

    MetaMathlibExt.multifoldDiamondCount

    Let \(d_1, \dots, d_M\) be natural numbers. Put \(L_k = \sum_{m=1}^{k} (d_m + 1)\) for \(0 \le k \le M\) and \(c = L_M + 1\). A multifold partition diamond of shape \((d_1, \dots, d_M)\) is a sequence \((b_0, \dots, b_{c-1})\) of nonnegative integers such that \(b_{L_{k-1}} \le b_{L_{k-1} + f} \le b_{L_k}\) for all \(1 \le k \le M\) and \(1 \le f \le d_k\). The parts \(b_{L_0}, \dots, b_{L_M}\) are its links and the other parts are its folds; its link sum is \(\sum_{k=0}^{M} b_{L_k}\) and its fold sum is the sum of its folds. This is the number of multifold partition diamonds of shape \((d_1, \dots, d_M)\) with fold sum \(i\) and link sum \(j\).

    Every part of such a diamond is at most \(i + j\), so this number is finite.

    public def multifoldDiamondCount (ds : List ℕ) (i j : ℕ) : ℕ :=
  ((Finset.univ : Finset (Fin (diamondSize ds) → Fin (i + j + 1))).filter fun a =>
    IsMultifoldDiamond ds i j (diamondPart a)).card
    public def diamondSize (ds : List ℕ) : ℕ := diamondLinkPos ds ds.length + 1

    Let \(d \ge 1\).
