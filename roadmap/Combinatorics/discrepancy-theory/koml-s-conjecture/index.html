    DefinitionDiscrepancy of a real matrix#✓fully proved

    MatrixDiscrepancy.discrepancy

    For a real \(m \times n\) matrix \(A\), the discrepancy of \(A\) is the infimum, over all sign vectors \(x \in \{-1, 1\}^n\), of the maximum norm \(\|Ax\|_\infty = \max_i |(Ax)_i|\) (which is \(0\) when \(m = 0\)), taken in \([0, \infty]\).

    def discrepancy (A : Matrix (Fin m) (Fin n) ℝ) : ENNReal :=
  ⨅ x : Fin n → Fin 2, ENNReal.ofReal ‖A.mulVec (fun j => signValue (x j))‖
    def signValue (s : Fin 2) : ℝ := if s = 0 then -1 else 1

    MatrixDiscrepancy.komlosConstant

    The Komlós constant is the supremum, over all integers \(n \ge 1\), of the Komlós constant in dimension \(n\), namely the supremum of the discrepancy of \(A\) over all real \(n \times n\) matrices \(A\) whose columns all have Euclidean norm at most \(1\). It is taken in \([0, \infty]\).

    MatrixDiscrepancy.discrepancy_attained

    For every real \(m \times n\) matrix \(A\), including the cases \(m = 0\) and \(n = 0\), there is a sign vector \(x \in \{-1, 1\}^n\) such that the discrepancy of \(A\) equals \(\|Ax\|_\infty\).

    DefinitionUniform discrepancy bound for vectors in the unit ball#✓fully proved

    MatrixDiscrepancy.UniformRectangularBound

    The statement that there is a real constant \(C > 0\) such that for all natural numbers \(n\) and \(d\) and all vectors \(v_1, \dots, v_n \in \mathbb{R}^d\) of Euclidean norm at most \(1\), writing \(v_{ij}\) for the \(j\)-th coordinate of \(v_i\), there are signs \(\varepsilon_1, \dots, \varepsilon_n \in \{-1, 1\}\) with \(\left|\sum_{i=1}^{n} \varepsilon_i v_{ij}\right| \le C\) for every coordinate index \(j\).

    def UniformRectangularBound : Prop :=
  ∃ C : ℝ, 0 < C ∧
    ∀ (n d : ℕ) (v : Fin n → Fin d → ℝ),
      (∀ i, ∑ j, (v i j) ^ 2 ≤ 1) →
        ∃ epsilon : Fin n → ℝ,
          (∀ i, epsilon i = 1 ∨ epsilon i = -1) ∧
          ∀ j, |∑ i, epsilon i * v i j| ≤ C
