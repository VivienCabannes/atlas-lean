    DefinitionFamilies containing a sunflower#✓fully proved

    MathlibExt.Combinatorics.ErdosProblem857WeakSunflowerWanted.ContainsKSunflower

    Let \(n\) and \(k\) be natural numbers. A family \(F\) of subsets of \(\{0, \dots, n-1\}\) contains a \(k\)-sunflower if some subfamily \(T \subseteq F\) with exactly \(k\) members satisfies \(A \cap B = C \cap D\) for all \(A, B, C, D \in T\) with \(A \ne B\) and \(C \ne D\), that is, all pairwise intersections of distinct members of \(T\) are equal.

    def ContainsKSunflower {n : ℕ} (k : ℕ) (F : Finset (Finset (Fin n))) : Prop :=
  ∃ (T : Finset (Finset (Fin n))), T ⊆ F ∧ T.card = k ∧
    ∀ ⦃a⦄, a ∈ T → ∀ ⦃b⦄, b ∈ T → a ≠ b → ∀ ⦃c⦄, c ∈ T → ∀ ⦃d⦄, d ∈ T → c ≠ d → a ∩ b = c ∩ d

    DefinitionErdős–Szemerédi sunflower conjecture for \(k \ge 4\)#✓fully proved

    MathlibExt.Combinatorics.ErdosProblem857WeakSunflowerWanted.conjecture

    The proposition asserts that for every natural number \(k \ge 4\) there is a real number \(c\) with \(0 < c < 2\) such that, for all sufficiently large \(n\), every \(k\)-sunflower-free family of subsets of \(\{0, \dots, n-1\}\) has at most \(c^n\) members.

    The bound is required only for large \(n\) because for \(2^n < k\) the family of all subsets of \(\{0, \dots, n-1\}\) is \(k\)-sunflower-free. The case \(k = 3\), proved by Naslund and Sawin, is omitted.

    def conjecture : Prop :=
  ∀ k : ℕ, 4 ≤ k →
    ∃ c : ℝ, 0 < c ∧ c < 2 ∧
      ∀ᶠ n : ℕ in Filter.atTop,
        ∀ F : Finset (Finset (Fin n)),
          IsKSunflowerFree k F →
            (F.card : ℝ) ≤ c ^ n
    def IsKSunflowerFree {n : ℕ} (k : ℕ) (F : Finset (Finset (Fin n))) : Prop :=
  ¬ ContainsKSunflower (n := n) k F

    DefinitionSunflower#✓fully proved

    MathlibExt.Combinatorics.ImprovedBoundsSunflowerLemmaWanted.Set.IsSunflower

    Let \(r \in \mathbb{N}\) and let \(S\) be a family of subsets of a type \(X\). Then \(S\) is an \(r\)-sunflower if \(S\) has exactly \(r\) members (its cardinality is taken to be \(0\) when \(S\) is infinite) and any two distinct members \(A \ne B\) of \(S\) satisfy \(A \cap B = \bigcap S\), the intersection of all members of \(S\).

    def IsSunflower (r : ℕ) (S : Set (Set X)) : Prop :=
  S.ncard = r ∧ S.Pairwise (fun A B ↦ A ∩ B = ⋂₀ S)

    DefinitionBounded-size set systems#✓fully proved

    MathlibExt.Combinatorics.ImprovedBoundsSunflowerLemmaWanted.Set.IsSystem

    Let \(w \in \mathbb{N}\) and let \(\mathcal{F}\) be a family of subsets of a type \(X\). Then \(\mathcal{F}\) is a \(w\)-set system if every member \(A \in \mathcal{F}\) has at most \(w\) elements, where the size of an infinite set is taken to be \(0\).

    def IsSystem (w : ℕ) (ℱ : Set (Set X)) : Prop := ∀ A ∈ ℱ, A.ncard ≤ w

    DefinitionSunflower lower bound#✓fully proved

    MathlibExt.Combinatorics.ImprovedBoundsSunflowerLemmaWanted.ImprovedBoundsSunflowerLemma.lowerBound

    For natural numbers \(r\) and \(w\) and a real number \(C\), the lower bound is the real number

    \[\left(C\, r^3 \log_{1.9} w \, \log_{1.9}(\log_{1.9} w)\right)^w,\]

    where \(\log_{1.9} x = \ln x / \ln 1.9\), with the convention \(\ln 0 = 0\).

    Following the authors, logarithms are taken to base \(1.9\); see the paragraph directly after Theorem 1.4 of Alweiss, Lovett, Wu, and Zhang, Improved bounds for the sunflower lemma.

    noncomputable def lowerBound (r : ℕ) (C : ℝ) (w : ℕ) : ℝ :=
  (C * r ^ 3 * logb 1.9 w * logb 1.9 (logb 1.9 w)) ^ w

    MathlibExt.Combinatorics.ImprovedBoundsSunflowerLemmaWanted.ImprovedBoundsSunflowerLemma.theorem_1_4

    Let \(C\) be the sunflower constant, a real number not depending on \(r\) or \(w\). Let \(r \ge 3\) and \(w \ge 2\) be natural numbers, let \(X\) be a finite type, and let \(\mathcal{F}\) be a \(w\)-set system of subsets of \(X\), that is, every member of \(\mathcal{F}\) has at most \(w\) elements. If \(\mathcal{F}\) has at least

    \[\left(C\, r^3 \log_{1.9} w \, \log_{1.9}(\log_{1.9} w)\right)^w\]

    members, then some subfamily \(S \subseteq \mathcal{F}\) is an \(r\)-sunflower: \(S\) has exactly \(r\) members and any two distinct members of \(S\) intersect in \(\bigcap S\).

    This is Theorem 1.4 (main theorem, sunflowers); logarithms are to base \(1.9\), as in the paper. We require \(w \ge 2\), as the paper assumes \(\log \log w > 0\).
