    DefinitionSet order#✓fully proved

    MetaMathlibExt.setLT

    For subsets \(A\) and \(B\) of \(\{0, \dots, n-1\}\), \(A\) precedes \(B\) in the set order, written \(A < B\), if \(|A| > |B|\), or \(|A| = |B|\) and \(b(A) < b(B)\), where \(b(A) = \sum_{i \in A} 2^i\) is the binary code of \(A\).

    public def setLT (n : ℕ) (A B : Finset (Fin n)) : Prop :=
  B.card < A.card ∨ (A.card = B.card ∧ binRep n A < binRep n B)
    public def binRep (n : ℕ) (A : Finset (Fin n)) : ℕ :=
  ∑ i ∈ A, 2 ^ (i : ℕ)

    DefinitionSort key of a subset#✓fully proved

    MetaMathlibExt.setKey

    For a subset \(A\) of \(\{0, \dots, n-1\}\), the sort key of \(A\) is the natural number \((n - |A|) \cdot 2^n + b(A)\), where \(b(A) = \sum_{i \in A} 2^i\) is the binary code of \(A\).

    Since \(b(A) < 2^n\), comparing sort keys as numbers agrees with the set order: larger sets come first, and sets of the same size are ordered by binary code.

    public def setKey (n : ℕ) (A : Finset (Fin n)) : ℕ :=
  (n - A.card) * 2 ^ n + binRep n A
    public def binRep (n : ℕ) (A : Finset (Fin n)) : ℕ :=
  ∑ i ∈ A, 2 ^ (i : ℕ)

    MetaMathlibExt.IsCanonical

    A family \(U\) of subsets of \(\{0, \dots, n-1\}\) is canonical, the canonical representative of its isomorphism class, if for every permutation \(\sigma\) of \(\{0, \dots, n-1\}\) the string \(s(U)\) is lexicographically at most the string \(s(\sigma(U))\) of the permuted family \(\sigma(U)\).

    public def IsCanonical (n : ℕ) (U : Finset (Finset (Fin n))) : Prop :=
  ∀ σ : Equiv.Perm (Fin n), famString n U ≤ famString n (permImage n σ U)

    TheoremOrderly generation of union-closed families#✓fully proved

    MetaMathlibExt.orderly_canonical_prefix

    Let \(n\), \(k\) and \(m\) be natural numbers with \(1 \le m \le k\), and let \(A_1, \dots, A_k\) be nonempty subsets of \(\Omega_n = \{0, \dots, n-1\}\) with \(A_i < A_j\) in the set order whenever \(i < j\). Suppose the family \(U = \{\emptyset, A_1, \dots, A_k\}\) is union-closed, every element of \(\Omega_n\) lies in some member of \(U\), \(U \ne \{\Omega_n, \emptyset\}\), and \(U\) is canonical. Then the prefix family \(\{\emptyset, A_1, \dots, A_m\}\) is canonical.

    The hypotheses that \(U\) is union-closed, covers \(\Omega_n\) and differs from \(\{\Omega_n, \emptyset\}\) are not used in the proof. The string of \(U\) lists the sort keys of \(A_1, \dots, A_k\) in order, so the string of the prefix family is a prefix of it, and a permutation that made the prefix family's string smaller would make the string of \(U\) smaller.

    public theorem orderly_canonical_prefix
