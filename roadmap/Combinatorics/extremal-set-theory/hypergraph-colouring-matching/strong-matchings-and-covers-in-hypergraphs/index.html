    MathlibExt.Combinatorics.StronglyMaximalMatchingAMR29Problem0084Wanted.IsStronglyMaximal

    For a hypergraph with edge set \(E\), a set \(M\) is a strongly maximal matching (Aharoni) when \(M\) is a matching of \(E\) and every matching \(M'\) of \(E\) satisfies \(|M' \setminus M| \le |M \setminus M'|\), comparing the cardinalities as cardinal numbers.

    def IsStronglyMaximal {V : Type} (E M : Set (Finset V)) : Prop :=
  IsMatching E M ∧ ∀ M', IsMatching E M' → Cardinal.mk ↥(M' \ M) ≤ Cardinal.mk ↥(M \ M')

    Let \(E\) be a set of finite subsets of a type \(V\), the edges of a hypergraph. A set \(X \subseteq V\) is a (vertex) cover of \(E\) if it meets every edge: every \(e \in E\) contains some \(v \in X\).

    MathlibExt.Combinatorics.StronglyMinimalCoverOpenGardenProblem690Wanted.IsStronglyMinimalCover

    Let \(E\) be a set of finite subsets of a type \(V\), the edges of a hypergraph. A set \(X \subseteq V\) is a strongly minimal cover of \(E\) (Aharoni) if \(X\) is a cover of \(E\), that is, it meets every edge in \(E\), and \(|X \setminus X'| \le |X' \setminus X|\), as cardinals, for every cover \(X'\) of \(E\).

    TheoremAharoni's strongly minimal cover conjecture is false#●ready to prove

    MathlibExt.Combinatorics.StronglyMinimalCoverOpenGardenProblem690Wanted.boundedEdgesStronglyMinimalCover_refuted

    There are a type \(V\), a set \(E\) of finite subsets of \(V\) (the edges of a hypergraph) and a natural number \(k\) such that every edge in \(E\) is nonempty and has at most \(k\) elements, but no strongly minimal cover of \(E\) exists. Here a cover of \(E\) is a set \(X \subseteq V\) that meets every edge in \(E\), and a cover \(X\) is strongly minimal if \(|X \setminus X'| \le |X' \setminus X|\), as cardinals, for every cover \(X'\) of \(E\).

    Hollom and Randall Shaw (Section 3.4) show that the graph on \(\mathbb{N}\) whose edges are the pairs \(\{u, v\}\) with \(2u \le v\) has no strongly minimal vertex cover, so already hypergraphs with all edges of size \(2\) need not have a strongly minimal cover.
