    DefinitionUnimodularly equivalent sets#✓fully proved

    MetaMathlibExt.UnimodularlyEquivalent

    Two sets \(P, Q \subseteq \mathbb{R}^2\) are unimodularly equivalent when some affine unimodular map sends \(P\) onto \(Q\): there are a \(2 \times 2\) integer matrix \(M\) with \(\det M = 1\) or \(\det M = -1\) and an integer vector \(u \in \mathbb{Z}^2\) such that \(\{M x + u : x \in P\} = Q\).

    In the paper's notation, where \(T\) is the map and \(P_1\) and \(P_2\) are the two sets, the displayed condition \(T(P_1) = T(P_2)\) is a typo for \(T(P_1) = P_2\).

    def UnimodularlyEquivalent (P Q : Set (ℝ × ℝ)) : Prop :=
  ∃ (M : Matrix (Fin 2) (Fin 2) ℤ) (u : ℤ × ℤ), (M.det = 1 ∨ M.det = -1) ∧
    unimodularMap M u '' P = Q
