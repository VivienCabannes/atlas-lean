    Faces of convex polytopes

    A convex polytope is the convex hull \(P = \operatorname{conv} s\) of a finite set \(s\) of points. Its faces are the empty set and the sets of points of \(P\) at which a linear functional attains its maximum over \(P\); they include \(P\) itself. Ordered by inclusion they form the face lattice of \(P\), a finite lattice whose isomorphism class is the combinatorial type of \(P\). Every face is the convex hull of the points of \(s\) it contains, so there are finitely many. The face numbers \(f_k\) count the faces of each dimension, and the vertices and edges form the graph of the polytope.

    DefinitionFaces of a convex polytope#✓fully proved

    MathlibExt.Geometry.Polytope.faces

    Let \(s\) be a finite set of points in a real normed space \(E\) (for example \(\mathbb{R}^n\)) and let \(P = \operatorname{conv} s\). A face of \(P\) is either the empty set or a set of the form $\(F = \{x \in P : \ell(x) \ge \ell(y) \text{ for all } y \in P\}\)$ for a continuous linear functional \(\ell\) on \(E\): the points where \(\ell\) attains its maximum over \(P\). The zero functional gives \(F = P\), so \(P\) is a face of itself; the empty set is a face by convention. In Lean, faces s is the set of all \(F\) with IsExposed ℝ (convexHull ℝ s) F, which is exactly this definition.

    Using continuous functionals loses nothing in a normed space. Every linear functional on the finite-dimensional span of \(s\) is continuous and, by the Hahn–Banach theorem, extends to a continuous linear functional on \(E\) with the same values on \(P\). So these are exactly the faces of the standard definition: the intersections of \(P\) with a valid inequality \(\ell(x) \le c\) (taking \(c = \max_P \ell\)) for an arbitrary linear functional \(\ell\). For polytopes, exposed and extreme subsets also coincide.

    The normed-space hypothesis matters. On a vector space with a coarser topology the continuous dual can be trivial, for instance \(\mathbb{R}\) with the indiscrete topology. Only \(\emptyset\) and \(P\) would then be "faces" in this sense, so the definition is stated for normed spaces only.

    def faces (s : Finset E) : Set (Set E) :=
  {F | IsExposed ℝ (convexHull ℝ (s : Set E)) F}

    TheoremA face of a polytope is the convex hull of the vertices it contains#✓fully proved

    MathlibExt.Geometry.Polytope.eq_convexHull_inter_of_mem_faces

    Let \(s\) be a finite set of points and \(F\) a face of \(P = \operatorname{conv} s\). Then $\(F = \operatorname{conv}(F \cap s).\)$ In particular every face of a polytope is again a polytope, spanned by some of the given points.

    The proof writes a point \(x \in F\) as a convex combination \(x = \sum_{y \in s} w_y\, y\). If \(\ell\) is a functional exposing \(F\) with maximum \(M = \ell(x)\), then \(\sum_y w_y (M - \ell(y)) = 0\) with every term nonnegative, so every \(y\) with \(w_y > 0\) satisfies \(\ell(y) = M\), that is, lies in \(F\).

    theorem eq_convexHull_inter_of_mem_faces {s : Finset E} {F : Set E} (hF : F ∈ faces s) :
    F = convexHull ℝ (F ∩ (s : Set E))
    def faces (s : Finset E) : Set (Set E) :=
  {F | IsExposed ℝ (convexHull ℝ (s : Set E)) F}

    TheoremA polytope has finitely many faces#✓fully proved

    MathlibExt.Geometry.Polytope.faces_finite

    For every finite set \(s\), the set of faces of \(P = \operatorname{conv} s\) is finite: each face is \(\operatorname{conv} T\) for a subset \(T \subseteq s\), so there are at most \(2^{|s|}\) of them. This makes the face numbers, which are counts of faces, meaningful.

    TheoremFaces cut out by a functional#✓fully proved

    MathlibExt.Geometry.Polytope.isExposed_convexHull_of_forall_le

    Let \(s\) be a finite set, \(T \subseteq s\), and \(\ell\) a continuous linear functional with \(\ell(y) \le V\) for all \(y \in s\), \(\ell(y) = V\) for all \(y \in T\), and \(\ell(y) < V\) for \(y \in s \setminus T\). Then \(\operatorname{conv} T\) is a face of \(\operatorname{conv} s\). (For \(T = \emptyset\) the face is empty.) This is how faces of a polytope are produced from its vertex set alone: the face cut out by \(\ell\) is the convex hull of the vertices where \(\ell\) is maximal.

    theorem isExposed_convexHull_of_forall_le (s : Finset E) (T : Set E) (l : StrongDual ℝ E)
    (V : ℝ) (hle : ∀ y ∈ s, l y ≤ V) (hT : ∀ y ∈ T, y ∈ s ∧ l y = V)
    (hTs : ∀ y ∈ s, l y = V → y ∈ T) :
    IsExposed ℝ (convexHull ℝ (s : Set E)) (convexHull ℝ T)

    TheoremA face of a face of a polytope is a face of the polytope#✓fully proved

    MathlibExt.Geometry.Polytope.mem_faces_of_isExposed

    Let \(s\) be finite, \(F\) a face of \(P = \operatorname{conv} s\), and \(G\) a face of \(F\) (an exposed subset of \(F\)). Then \(G\) is a face of \(P\). Together with the converse (a face of \(P\) contained in \(F\) is a face of \(F\), Mathlib's IsExposed.mono), the faces of \(F\) are exactly the faces of \(P\) contained in \(F\), so the face lattice of \(F\) is the interval \([\emptyset, F]\) of the face lattice of \(P\); that lattice isomorphism is not formalized here.

    For general convex sets the corresponding statement about exposed subsets is false (Mathlib's IsExposed file gives a counterexample built from a cube and a triangle). For polytopes it holds: if \(\ell_1\) exposes \(F\) in \(P\) and \(\ell_2\) exposes \(G\) in \(F\), then for \(\varepsilon > 0\) small enough the functional \(\ell_1 + \varepsilon \ell_2\) is maximal on the points of \(s\) exactly at those in \(G\), because \(\ell_1\) has a positive gap below its maximum on the finitely many points of \(s\) outside \(F\). Since \(G = \operatorname{conv}(G \cap s)\), this functional exposes \(G\) in \(P\).

    theorem mem_faces_of_isExposed {s : Finset E} {F G : Set E} (hF : F ∈ faces s)
    (hG : IsExposed ℝ F G) : G ∈ faces s
    def faces (s : Finset E) : Set (Set E) :=
  {F | IsExposed ℝ (convexHull ℝ (s : Set E)) F}

    TheoremIntersections of faces are faces#✓fully proved

    MathlibExt.Geometry.Polytope.inter_sInter_mem_faces

    Let \(s\) be finite, \(P = \operatorname{conv} s\), and let \(A\) be any family of faces of \(P\). Then \(P \cap \bigcap_{F \in A} F\) is a face of \(P\); for the empty family it is \(P\) itself. Since there are only finitely many faces, this reduces to finite intersections, where the sum of the exposing functionals exposes the intersection.

    theorem inter_sInter_mem_faces (s : Finset E) (A : Set (Set E)) (hA : A ⊆ faces s) :
    convexHull ℝ (s : Set E) ∩ ⋂₀ A ∈ faces s
    def faces (s : Finset E) : Set (Set E) :=
  {F | IsExposed ℝ (convexHull ℝ (s : Set E)) F}

    DefinitionFace lattice of a polytope#✓fully proved

    MathlibExt.Geometry.Polytope.FaceLattice

    For a finite set \(s\), the face lattice \(L(P)\) of \(P = \operatorname{conv} s\) is the set of all faces of \(P\), including \(\emptyset\) and \(P\), ordered by inclusion. It is a finite complete lattice: the meet of a family of faces is their intersection (with \(P\), for the empty family), and the join is the meet of all common upper bounds. Its bottom element is the empty face and its top element is \(P\). The isomorphism class of \(L(P)\) is the combinatorial type of \(P\).

    The Lean development proves that \(L(P)\) is a finite complete lattice with these bottom and top elements. It does not yet prove the further properties of face lattices of \(d\)-polytopes listed in the ICM report (graded of length \(d + 1\), atomic, coatomic, Eulerian).

    def FaceLattice (s : Finset E) : Type _ := {F : Set E // F ∈ faces s}
    def faces (s : Finset E) : Set (Set E) :=
  {F | IsExposed ℝ (convexHull ℝ (s : Set E)) F}

    DefinitionDimension of a polytope#✓fully proved

    MathlibExt.Geometry.Polytope.dim

    The dimension of \(P = \operatorname{conv} s\) is the dimension of its affine hull, that is, of the linear subspace parallel to \(\operatorname{aff} P = \operatorname{aff} s\). A \(d\)-polytope is a polytope of dimension \(d\).

    Degenerate case: in Lean the empty polytope (\(s = \emptyset\)) gets dimension \(0\), not the usual \(-1\), because the direction of the empty affine subspace is the zero subspace. Statements that need \(P \ne \emptyset\) assume it explicitly.

    noncomputable def dim (s : Finset E) : ℕ :=
  Module.finrank ℝ (affineSpan ℝ (convexHull ℝ (s : Set E))).direction

    DefinitionFace numbers of a polytope#✓fully proved

    MathlibExt.Geometry.Polytope.faceNumber

    For a finite set \(s\) and \(k \ge 0\), the face number \(f_k(P)\) of \(P = \operatorname{conv} s\) is the number of nonempty faces of \(P\) whose affine hull has dimension \(k\). Thus \(f_0\) counts the vertices, \(f_1\) the edges and, for a \(d\)-polytope, \(f_{d-1}\) the facets, while \(f_d = 1\) counts \(P\) itself. The vector \((f_0, f_1, \dots, f_{d-1})\) is the f-vector of \(P\).

    The empty face, of dimension \(-1\) with the convention \(f_{-1} = 1\), is not counted by this function. The count is finite because a polytope has finitely many faces.

    noncomputable def faceNumber (s : Finset E) (k : ℕ) : ℕ :=
  {F | F ∈ faces s ∧ F.Nonempty ∧ Module.finrank ℝ (affineSpan ℝ F).direction = k}.ncard
    def faces (s : Finset E) : Set (Set E) :=

    DefinitionSimplicial polytope#✓fully proved

    MathlibExt.Geometry.Polytope.IsSimplicial

    The polytope \(P = \operatorname{conv} s\) of dimension \(d\) is simplicial if every facet of \(P\) (a nonempty face of dimension \(d - 1\)) contains exactly \(d\) vertices of \(P\), that is, is a \((d-1)\)-simplex. Cyclic polytopes, and the convex hull of finitely many points in general position, are simplicial; their boundary complexes are simplicial spheres.

    Degenerate case: a polytope of dimension \(0\) (a point, or the empty polytope, which Lean also gives dimension \(0\)) has no facets in this sense and is simplicial vacuously.

    def IsSimplicial (s : Finset E) : Prop :=
  ∀ F ∈ faces s, F.Nonempty →
    Module.finrank ℝ (affineSpan ℝ F).direction + 1 = dim s →
      (F ∩ (convexHull ℝ (s : Set E)).extremePoints ℝ).ncard = dim s
    def faces (s : Finset E) : Set (Set E) :=
  {F | IsExposed ℝ (convexHull ℝ (s : Set E)) F}

    DefinitionThe graph of a polytope#✓fully proved

    MathlibExt.Geometry.Polytope.graph

    The graph of \(P = \operatorname{conv} s\) has the vertices (extreme points) of \(P\) as its vertices, and two distinct vertices \(u, v\) are adjacent when the segment \([u, v]\) is a face of \(P\), that is, an edge. Every one-dimensional face of a polytope is such a segment between two vertices, so this is the 1-skeleton of \(P\). By Steinitz's theorem, the graphs of 3-polytopes are exactly the 3-connected planar graphs.

    def graph (s : Finset E) : SimpleGraph ((convexHull ℝ (s : Set E)).extremePoints ℝ) where
  Adj u v := u ≠ v ∧ IsExposed ℝ (convexHull ℝ (s : Set E)) (segment ℝ (u : E) v)
  symm := ⟨fun u v h => ⟨h.1.symm, by rw [segment_symm]; exact h.2⟩⟩
  loopless := ⟨fun u h => h.1 rfl⟩

    TheoremBalinski's theorem#●ready to prove

    MathlibExt.Geometry.Polytope.GraphWanted.balinski

    Let \(s\) be a nonempty finite set of points in \(\mathbb{R}^n\) and let \(P = \operatorname{conv} s\) have dimension \(d\). Then the graph of \(P\) is \(d\)-connected: it has more than \(d\) vertices, and it stays connected after deleting any set of fewer than \(d\) vertices.

    The polytope need not be full-dimensional; \(d\) is the dimension of its affine hull. Nonemptiness is needed, since the graph of the empty polytope has no vertex. For \(d = 3\) this is the 3-connectivity half of the easy direction of Steinitz's theorem.

    theorem_wanted balinski {n d : ℕ} (s : Finset (EuclideanSpace ℝ (Fin n))) (hs : s.Nonempty)
    (hd : dim s = d) :
    @SimpleGraph.IsVertexConnected _ (extremePoints_finite s).fintype d (graph s)

    TheoremSteinitz's theorem#●ready to prove

    MathlibExt.Geometry.Polytope.GraphWanted.steinitz

    A finite simple graph \(G\) is the graph of a 3-dimensional convex polytope if and only if \(G\) is planar and 3-connected.

    In Lean: for a finite vertex type, \(G\) is planar (has a crossing-free straight-line drawing in the plane) and 3-vertex-connected (has more than 3 vertices and stays connected after deleting any two vertices) if and only if there is a finite set \(s \subset \mathbb{R}^3\) whose convex hull has nonempty interior and whose polytope graph is isomorphic to \(G\). Planarity with straight-line edges is equivalent to topological planarity for finite simple graphs by Fáry's theorem, and the 3-connectivity condition forces at least 4 vertices, as for the tetrahedron.

    The direction from polytopes to graphs is the easy one: planarity comes from a Schlegel diagram or a stereographic projection, and 3-connectivity is the case \(d = 3\) of Balinski's theorem. The hard direction constructs a polytope from a 3-connected planar graph.

    theorem_wanted steinitz {V : Type*} [Fintype V] (G : SimpleGraph V) :
    (G.IsPlanar ∧ G.IsVertexConnected 3) ↔
      ∃ s : Finset (EuclideanSpace ℝ (Fin 3)),
        (interior (convexHull ℝ (s : Set (EuclideanSpace ℝ (Fin 3))))).Nonempty ∧
          Nonempty (G ≃g graph s)
