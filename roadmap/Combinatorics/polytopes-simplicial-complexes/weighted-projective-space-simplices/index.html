    DefinitionWeighted projective space simplex#✓fully proved

    MetaMathlibExt.weightedSimplex

    For a tuple \(q = (q_1, \dots, q_n)\) of natural numbers, the weighted projective space simplex \(\Delta_{(1,q)}\) is the convex hull in \(\mathbb{R}^n\) of the standard basis vectors \(e_1, \dots, e_n\) and the vector \(-(q_1 e_1 + \dots + q_n e_n)\), whose \(i\)th coordinate is \(-q_i\).

    public def weightedSimplex {n : ℕ} (q : Fin n → ℕ) : Set (Fin n → ℝ) :=
  convexHull ℝ (Set.range (fun i : Fin n => Pi.single i (1 : ℝ)) ∪
    {fun i => -(q i : ℝ)})

    DefinitionDilate of a set#✓fully proved

    MetaMathlibExt.polytopeDilate

    For a natural number \(t\) and a set \(P \subseteq \mathbb{R}^\iota\) of real vectors indexed by a type \(\iota\), the dilate of \(P\) by \(t\) is the set \(tP = \{t y : y \in P\} \subseteq \mathbb{R}^\iota\).

    Only natural-number factors \(t \ge 0\) are used, matching the paper's nonnegative integral dilations.

    public def polytopeDilate {ι : Type*} (t : ℕ) (P : Set (ι → ℝ)) : Set (ι → ℝ) :=
  {x | ∃ y ∈ P, x = fun i => (t : ℝ) * y i}

    DefinitionLattice points of a set#✓fully proved

    MetaMathlibExt.IsLatticePoint

    Let \(P \subseteq \mathbb{R}^\iota\) for an index set \(\iota\). An integer vector \(x \in \mathbb{Z}^\iota\) is a lattice point of \(P\) when \(x\), viewed as a real vector coordinate by coordinate, lies in \(P\); thus the lattice points of \(P\) are the points of \(P \cap \mathbb{Z}^\iota\).

    DefinitionInteger decomposition property#✓fully proved

    MetaMathlibExt.HasIDP

    A set \(P \subseteq \mathbb{R}^\iota\), for a finite index set \(\iota\), has the integer decomposition property (IDP) if for every integer \(m \ge 1\), every lattice point \(w \in \mathbb{Z}^\iota\) of the dilate \(mP = \{m y : y \in P\}\) is a sum \(w = x_1 + \dots + x_m\) of \(m\) lattice points \(x_1, \dots, x_m \in \mathbb{Z}^\iota\) of \(P\).

    This is the height-by-height version of the paper's cone definition; for a convex lattice polytope, the height-\(m\) slice of the cone is \(mP\). It also implements the paper's intended \((m,w)\), correcting its displayed \((k,w)\) typo.

    public def HasIDP {ι : Type*} [Fintype ι] (P : Set (ι → ℝ)) : Prop :=
  ∀ m : ℕ, 1 ≤ m → ∀ w : ι → ℤ, IsLatticePoint (polytopeDilate m P) w →
    ∃ x : Fin m → ι → ℤ,
      (∀ k, IsLatticePoint P (x k)) ∧ (∀ i, ∑ k, x k i = w i)
    public def IsLatticePoint {ι : Type*} (P : Set (ι → ℝ)) (x : ι → ℤ) : Prop :=
  (fun i => (x i : ℝ)) ∈ P

    DefinitionReflexive polytopes#✓fully proved

    MetaMathlibExt.IsReflexive

    Let \(P \subseteq \mathbb{R}^n\), with coordinates indexed by a finite set of size \(n\), and write \(tP = \{t y : y \in P\}\). Then \(P\) is reflexive when there is a lattice point \(c\) in the interior of \(P\) such that, for every integer \(t \ge 1\), the lattice points in the interior of \(tP\) are exactly the points \(c + y\) with \(y\) a lattice point of \((t-1)P\).

    This is the interior-point characterisation of reflexivity, stated height by height; it is not the divisibility criterion for weighted simplices.

    public def IsReflexive {ι : Type*} [Fintype ι] (P : Set (ι → ℝ)) : Prop :=
  ∃ c : ι → ℤ, IsLatticePoint (interior P) c ∧
    ∀ t : ℕ, 1 ≤ t → ∀ x : ι → ℤ,
      IsLatticePoint (interior (polytopeDilate t P)) x ↔
        ∃ y : ι → ℤ, IsLatticePoint (polytopeDilate (t - 1) P) y ∧
          x = fun i => c i + y i
    public def IsLatticePoint {ι : Type*} (P : Set (ι → ℝ)) (x : ι → ℤ) : Prop :=
  (fun i => (x i : ℝ)) ∈ P

    MetaMathlibExt.ehrhart

    For a finite index set \(\iota\), a set \(P \subseteq \mathbb{R}^\iota\) and a natural number \(t\), the Ehrhart function \(L_P(t)\) is the number of integer vectors \(x \in \mathbb{Z}^\iota\) lying in the dilate \(tP = \{t y : y \in P\}\), with the convention that \(L_P(t) = 0\) when there are infinitely many such vectors.

    No boundedness of \(P\) is needed for the definition. On \(\mathbb{R}^d\) it agrees with the lattice-point enumerator of \(P\) at the real dilate \(t\).

  Set.ncard {x : ι → ℤ | IsLatticePoint (polytopeDilate t P) x}

    DefinitionThe \(h^*\)-polynomial#✓fully proved

    MetaMathlibExt.IsHStarPolynomial

    The \(h^*\)-polynomial. Let \(P \subseteq \mathbb{R}^n\), with coordinates indexed by a finite set of size \(n\), and let \(L_P(t)\) be the number of lattice points of the dilate \(tP = \{t y : y \in P\}\) (taken to be \(0\) if there are infinitely many). A polynomial \(h \in \mathbb{Z}[z]\) is an \(h^*\)-polynomial of \(P\) when

    \[\Big(\sum_{t \ge 0} L_P(t)\, z^t\Big) (1 - z)^{n+1} = h(z)\]

    as formal power series with integer coefficients.

    The exponent uses the ambient dimension \(n\), which is \(\dim P\) when \(P\) is full dimensional, and \(h^*\) is characterised by this identity rather than by the explicit formula for weighted simplices.

    public def IsHStarPolynomial {ι : Type*} [Fintype ι]
    (P : Set (ι → ℝ)) (h : Polynomial ℤ) : Prop :=
  PowerSeries.mk (fun t => (ehrhart P t : ℤ)) *
      (1 - PowerSeries.X) ^ (Fintype.card ι + 1) = (h : PowerSeries ℤ)
    public noncomputable def ehrhart {ι : Type*} [Fintype ι]
    (P : Set (ι → ℝ)) (t : ℕ) : ℕ :=
  Set.ncard {x : ι → ℤ | IsLatticePoint (polytopeDilate t P) x}

    DefinitionUnimodal polynomials#✓fully proved

    MetaMathlibExt.IsUnimodal

    A polynomial \(p = \sum_k a_k z^k \in \mathbb{Z}[z]\) of degree \(n\) (with \(n = 0\) for \(p = 0\)) is unimodal when there is an index \(t \le n\) such that \(a_0 \le a_1 \le \dots \le a_t\) and \(a_t \ge a_{t+1} \ge \dots \ge a_n\).

    The paper considers polynomials with nonnegative coefficients; the order condition itself is stated over \(\mathbb{Z}\).

    public def IsUnimodal (p : Polynomial ℤ) : Prop :=
  ∃ t : ℕ, t ≤ p.natDegree ∧
    (∀ i j : ℕ, i ≤ j → j ≤ t → p.coeff i ≤ p.coeff j) ∧
    (∀ i j : ℕ, t ≤ i → i ≤ j → j ≤ p.natDegree → p.coeff j ≤ p.coeff i)

    DefinitionThe integer \(\ell\) of support data#✓fully proved

    MetaMathlibExt.setupEll

    For tuples \(r = (r_1, \dots, r_d)\) and \(x = (x_1, \dots, x_d)\) of natural numbers, let \(L = \operatorname{lcm}(r_1, \dots, r_d)\), with \(L = 1\) when \(d = 0\).
