    DefinitionThe h-star coefficients of a polynomial#✓fully proved

    MetaMathlibExt.hStarCoeff

    Let \(f\) be a complex polynomial of degree \(d\), with \(d = 0\) for the zero polynomial. For a natural number \(i\), the \(i\)-th \(h^*\)-coefficient of \(f\) is

    \[h^*_i(f) = \sum_{j=0}^{i} (-1)^j \binom{d+1}{j} f(i-j),\]

    the coefficient of \(t^i\) in the power series \((1-t)^{d+1} \sum_{k \ge 0} f(k)\, t^k\).

    public def hStarCoeff (f : Polynomial ℂ) (i : ℕ) : ℂ :=
  ∑ j ∈ Finset.range (i + 1),
    (-1 : ℂ) ^ j * (Nat.choose (f.natDegree + 1) j : ℂ) * f.eval (i - j : ℂ)

    DefinitionInterlacing lists#✓fully proved

    MetaMathlibExt.ListInterlaces

    Let \(r\) be a binary relation on a type \(\alpha\) and let \(d \ge 0\). A list \((a_1, \dots, a_d)\) interlaces a list \((b_1, \dots, b_{d+1})\) with respect to \(r\) when \(b_1 \mathrel{r} a_1 \mathrel{r} b_2 \mathrel{r} \cdots \mathrel{r} a_d \mathrel{r} b_{d+1}\), that is, \(b_k \mathrel{r} a_k\) and \(a_k \mathrel{r} b_{k+1}\) for \(1 \le k \le d\). Two lists interlace only when the second has exactly one more entry than the first; in particular the empty list interlaces every one-element list.

    public def ListInterlaces {α : Type*} (r : α → α → Prop) : List α → List α → Prop
  | [], [_] => True
  | a :: as, b :: b' :: bs => r b a ∧ r a b' ∧ ListInterlaces r as (b' :: bs)
  | _, _ => False

    DefinitionAlternating lists of equal length#✓fully proved

    MetaMathlibExt.ListAlternates

    Let \(r\) be a binary relation on a type \(\alpha\) and let \(n \ge 0\). A list \((a_1, \dots, a_n)\) alternates with a list \((b_1, \dots, b_n)\) with respect to \(r\) when \(a_1 \mathrel{r} b_1 \mathrel{r} a_2 \mathrel{r} \cdots \mathrel{r} a_n \mathrel{r} b_n\), that is, \(a_k \mathrel{r} b_k\) for \(1 \le k \le n\) and \(b_k \mathrel{r} a_{k+1}\) for \(1 \le k < n\). Two empty lists alternate, and lists of different lengths never alternate.

    This equal-length companion of interlacing is used only for the same-degree clauses in Fisk's Leibniz rule.

    public def ListAlternates {α : Type*} (r : α → α → Prop) : List α → List α → Prop
  | [], [] => True
  | [a], [b] => r a b
  | a :: a' :: as, b :: bs => r a b ∧ r b a' ∧ ListAlternates r (a' :: as) bs
  | _, _ => False
