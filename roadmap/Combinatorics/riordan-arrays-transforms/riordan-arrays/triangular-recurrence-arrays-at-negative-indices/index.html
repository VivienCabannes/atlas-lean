    MetaMathlibExt.TriangularRecurrence.array

    Given integer parameters \((\alpha, \beta, \gamma; \alpha', \beta', \gamma')\), the array \(a_{n,k} \in \mathbb{Q}\), \(n, k \ge 0\), is defined by \(a_{0,k} = \delta_{k,0}\) and, for \(n \ge 1\), by the recurrence (1) \(a_{n,k} = (\alpha n + \beta k + \gamma)\, a_{n-1,k} + (\alpha' n + \beta' k + \gamma')\, a_{n-1,k-1}\), where \(a_{n-1,-1} = 0\).

    public def array (P : TriangularRecurrence) : ℕ → ℕ → ℚ

      (P.α' * (n + 1) + P.β' * (k + 1) + P.γ') * array P n k

    MetaMathlibExt.TriangularRecurrence.negPosAux

    For integer parameters \((\alpha, \beta, \gamma; \alpha', \beta', \gamma')\) and \(p, k \ge 0\), put \(n = -(p + 1)\). The rational numbers \(c_{p,k}\) are defined by recursion on \(p\) and then on \(k\) through \(c_{p,k} = (r - (\alpha'(n+1) + \beta' k + \gamma')\, s) / (\alpha(n+1) + \beta k + \gamma)\), where \(r = c_{p-1,k}\) if \(p \ge 1\), \(r = 1\) if \(p = k = 0\), and \(r = 0\) if \(p = 0 < k\); and \(s = c_{p,k-1}\) if \(k \ge 1\), \(s = 0\) if \(k = 0\). Division by \(0\) gives \(0\).

    public def negPosAux (P : TriangularRecurrence) : ℕ → ℕ → ℚ

    MetaMathlibExt.TriangularRecurrence.negPos

    Let \(a_{n,k}\) (\(n, k \ge 0\)) be the triangular array of a triangular recurrence with parameters \((\alpha, \beta, \gamma; \alpha', \beta', \gamma')\). Its negative-positive numbers \(a^{NP}_{n,k} \in \mathbb{Q}\), for \(n, k \in \mathbb{Z}\), are defined by \(a^{NP}_{n,k} = a_{n,k}\) for \(n, k \ge 0\), \(a^{NP}_{n,k} = 0\) for \(k < 0\), and, for \(n < 0 \le k\), recursively by

    \[ a^{NP}_{n,k} = \frac{a^{NP}_{n+1,k} - (\alpha'(n+1) + \beta' k + \gamma')\, a^{NP}_{n,k-1}} {\alpha(n+1) + \beta k + \gamma}, \]

    where division by \(0\) gives \(0\).

    public def negPos (P : TriangularRecurrence) : ℤ → ℤ → ℚ
  | .ofNat n, .ofNat k => P.array n k
  | .negSucc p, .ofNat k => P.negPosAux p k
  | _, .negSucc _ => 0
