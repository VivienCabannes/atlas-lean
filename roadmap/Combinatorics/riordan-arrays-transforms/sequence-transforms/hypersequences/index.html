    DefinitionHypersequence#✓fully proved

    MetaMathlibExt.hypersequence

    Let \((a_n)_{n \ge 0}\) be a sequence in an additive commutative monoid. Its hypersequence of generation \(r\), written \(a^{(r)}_n\), is defined by recursion on \(r\): \(a^{(0)}_n = a_n\) and \(a^{(r+1)}_n = \sum_{k=0}^{n} a^{(r)}_k\) for all natural numbers \(r\) and \(n\). Thus each generation is the sequence of partial sums of the previous one.

    public def hypersequence {R : Type*} [AddCommMonoid R] (a : ℕ → R) : ℕ → ℕ → R
  | 0, n => a n
  | r + 1, n => ∑ k ∈ range (n + 1), hypersequence a r k
