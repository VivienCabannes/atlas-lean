    Necklaces over a group with identity product

    TheoremCounting necklaces with identity product#✓fully proved

    MetaMathlibExt.identity_product_necklace_count

    Let \(G\) be a finite group and \(n \ge 1\). For an \(n\)-tuple \(x = (x_0, \dots, x_{n-1}) \in G^n\) let its necklace be the set of its \(n\) cyclic rotations \((x_m, x_{m+1}, \dots, x_{m+n-1})\), \(0 \le m < n\), with indices taken mod \(n\). Then the number of necklaces of tuples \(x\) with \(x_0 x_1 \cdots x_{n-1} = 1\) is

    \[\frac{1}{n} \sum_{d \mid n} \varphi(n/d) \, r_{n/d}(G) \, |G|^{d-1},\]

    where \(\varphi\) is Euler's totient function and \(r_k(G)\) is the number of \(g \in G\) with \(g^k = 1\).

    theorem identity_product_necklace_count (G : Type*) [Group G] [Fintype G]
  [DecidableEq G] (n : ℕ) (hn : 0 < n) :
  (Set.ncard
  { O : Set (Fin n → G) | ∃ x : Fin n → G, (List.ofFn x).prod = 1 ∧ O =
  { y | ∃ m : ℕ, m < n ∧ ∀ i : Fin n, y i = x ⟨(i.val + m) % n, Nat.mod_lt _ hn⟩ } } : ℚ) =
  (1 / (n : ℚ)) * Finset.sum (Nat.divisors n)
  (fun d => (Nat.totient (n / d) : ℚ) * (Fintype.card { g : G // g ^ (n / d) = 1 } : ℚ) *
  ((Fintype.card G : ℚ) ^ (d - 1)))

    DefinitionRotation orbit of a tuple#✓fully proved

    MetaMathlibExt.tupleRotationOrbit

    Let \(x = (x_0, \dots, x_{n-1})\) be a tuple of length \(n\) with entries in a type \(\alpha\), and let \(\sigma\) be the cyclic rotation of \(\{0, \dots, n-1\}\) that sends \(i\) to \(i + 1\) for \(i < n - 1\) and sends \(n - 1\) to \(0\). The rotation orbit of \(x\) is the set of tuples \(x \circ \sigma^m\) for \(m \in \mathbb{N}\), that is, of the cyclic shifts \((x_m, x_{m+1}, \dots, x_{m+n-1})\) of \(x\), with indices taken modulo \(n\).

    def tupleRotationOrbit {α : Type*} {n : ℕ} (x : Fin n → α) : Set (Fin n → α) :=
  {y | ∃ m : ℕ, y = x ∘ ⇑((finRotate n) ^ m)}

    TheoremTotient-weighted divisor sum identity#●ready to prove

    MetaMathlibExt.sum_div_mul_eq_sum_totient_mul

    Let \(f\) and \(g\) be functions from the natural numbers to the rational numbers such that \(g(k) = \sum_{d \mid k} f(d)\) for every positive integer \(k\), where sums over \(d \mid k\) run over the positive divisors \(d\) of \(k\). Then for every positive integer \(k\),

    \[\sum_{d \mid k} \frac{k}{d} \, f(d) = \sum_{d \mid k} \varphi\left(\frac{k}{d}\right) g(d),\]

    where \(\varphi\) is Euler's totient function.

    public theorem_wanted sum_div_mul_eq_sum_totient_mul (f g : ℕ → ℚ)
    (hfg : ∀ k, 0 < k → g k = ∑ d ∈ k.divisors, f d) (k : ℕ) (hk : 0 < k) :
    ∑ d ∈ k.divisors, ((k / d : ℕ) : ℚ) * f d =
      ∑ d ∈ k.divisors, (Nat.totient (k / d) : ℚ) * g d
