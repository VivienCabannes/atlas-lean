    For natural numbers \(p\), \(q\) and \(n\), \(|S^{p/q}_n|\) is the number of \((p, q)\)-Schreier sets with maximum \(n\), that is, of subsets \(F \subseteq \{1, \dots, n\}\) with \(n \in F\) and \(p|F| \le qx\) for every \(x \in F\) (equivalently, \(p|F| \le q \min F\)).

    def schreierCount (p q n : ℕ) : ℕ :=
  ((Finset.Icc 1 n).powerset.filter fun F => n ∈ F ∧ ∀ x ∈ F, p * F.card ≤ q * x).card

    DefinitionPadovan-like sequence for Schreier sets#✓fully proved

    MetaMathlibExt.schreierPadovan

    For natural numbers \(p\) and \(q\), the sequence \(a_{p,q,n}\), \(n \ge 0\), is defined as follows. If \(q \ge 1\) and \(n \ge p + q\), then \(a_{p,q,n} = a_{p,q,n-q} + a_{p,q,n-p-q}\). Otherwise, if \(p \ge q\), then \(a_{p,q,n} = 0\) for \(n < p - q\) and \(a_{p,q,n} = 1\) for \(n \ge p - q\); and if \(p < q\), then \(a_{p,q,n} = 1\) for \(n < 2p\) and \(a_{p,q,n} = 2\) for \(n \ge 2p\).

    def schreierPadovan (p q : ℕ) : ℕ → ℕ
  | n =>
    if _h : p + q ≤ n ∧ 0 < q then
      schreierPadovan p q (n - q) + schreierPadovan p q (n - p - q)
    else if q ≤ p then (if n + q < p then 0 else 1) else (if n < 2 * p then 1 else 2)
  decreasing_by all_goals omega

    DefinitionSequences satisfying a polynomial#✓fully proved

    MetaMathlibExt.SatisfiesPoly

    Let \(P = c_0 + c_1 x + \dots + c_r x^r\) be a real polynomial, where \(r\) is the degree of \(P\) (and \(r = 0\) for \(P = 0\)). A real sequence \((a_n)_{n \ge 0}\) satisfies \(P\) if \(c_0 a_n + c_1 a_{n-1} + \dots + c_r a_{n-r} = 0\) for every \(n \ge r\).

    def SatisfiesPoly (P : Polynomial ℝ) (a : ℕ → ℝ) : Prop :=
  ∀ n, P.natDegree ≤ n → ∑ i ∈ Finset.range (P.natDegree + 1), P.coeff i * a (n - i) = 0
