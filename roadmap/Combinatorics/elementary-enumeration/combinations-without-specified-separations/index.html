    MetaMathlibExt.restrictedCombinations

    For a finite set \(Q\) of natural numbers and \(n, k \ge 0\), the restricted combinations are the \(k\)-element subsets \(s\) of \(\{1, \dots, n\}\) such that \(b - a \notin Q\) for all \(a, b \in s\) with \(a < b\). Since only distinct elements are compared, whether \(0 \in Q\) makes no difference.

    public def restrictedCombinations (Q : Finset ℕ) (n k : ℕ) : Finset (Finset ℕ) :=
  ((Finset.Icc 1 n).powersetCard k).filter fun s => ∀ a ∈ s, ∀ b ∈ s, a < b → b - a ∉ Q

    DefinitionThe \((1,t)\)-bonacci polynomials#✓fully proved

    MetaMathlibExt.oneTBonacciPolynomial

    Fix a natural number \(s\) and put \(t = s + 1\). The \((1,t)\)-bonacci polynomials \(f^{(t)}_n(x)\), \(n \ge 0\), are the polynomials with natural-number coefficients defined by \(f^{(t)}_0(x) = 1\) and, for every \(n \ge 0\), \(f^{(t)}_{n+1}(x) = f^{(t)}_n(x) + x \, f^{(t)}_{n-s}(x)\) if \(s \le n\) and \(f^{(t)}_{n+1}(x) = f^{(t)}_n(x)\) if \(n < s\).

    Equivalently, \(f^{(t)}_n(x) = f^{(t)}_{n-1}(x) + x \, f^{(t)}_{n-t}(x) + \delta_{n,0}\) with \(f^{(t)}_n(x) = 0\) for \(n < 0\).

    public noncomputable def oneTBonacciPolynomial (s : ℕ) : ℕ → Polynomial ℕ
  | 0 => 1
  | n + 1 =>
    oneTBonacciPolynomial s n +
      Polynomial.X * (if s ≤ n then oneTBonacciPolynomial s (n - s) else 0)
termination_by n => n
