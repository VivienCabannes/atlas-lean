    TheoremTotal number of descents over parking functions#✓fully proved

    MetaMathlibExt.total_descents_over_parking_functions

    Let \(n\) be a natural number. A descent of a function \(f \colon \{0, \dots, n-1\} \to \{0, \dots, n-1\}\) is an index \(i\) with \(i + 1 < n\) and \(f(i) > f(i+1)\). Summed over all parking functions \(f \colon \{0, \dots, n-1\} \to \{0, \dots, n-1\}\) of length \(n\), the number of descents is \(\binom{n}{2} (n+1)^{n-2}\), which is \(0\) for \(n < 2\).

    Parking functions are taken in threshold form: for each \(k < n\), at most \(n - k\) of the values \(f(i)\) are at least \(k\). This is equivalent to the source's sorted-preference formulation.

    theorem total_descents_over_parking_functions (n : ℕ) :
    (∑ f : Fin n → Fin n,
      if IsParkingFunction n f
      then
        (Finset.univ.filter fun p : Fin n × Fin n =>
          p.2.1 = p.1.1 + 1 ∧ f p.1 > f p.2).card
      else 0) =
    Nat.choose n 2 * (n + 1) ^ (n - 2)
    def IsParkingFunction (n : ℕ) (f : Fin n → Fin n) : Prop :=
  IsPartialParkingFunction n n f

    TheoremDescent generating function of parking functions#●ready to prove

    MetaMathlibExt.parkingFunction_descent_genFun

    Write a sequence of length \(n\) as \((a_1, \dots, a_n)\); its descents are the \(j \in \{1, \dots, n-1\}\) with \(a_j > a_{j+1}\), and \(\operatorname{des}\) is their number. A parking function \(f\) of length \(n\) is read as the sequence \(a_j = f(j-1) + 1\). Let \(PF_n\) be the set of parking functions of length \(n\), \(PF^{\uparrow}_n\) the set of nondecreasing ones, and \(d(n, j)\) the number of \(\alpha \in PF_n\) with \(\operatorname{des}(\alpha) = j\). For every \(n \ge 1\), in the polynomial ring \(\mathbb{N}[y]\),

    \[\sum_{\alpha \in PF_n} y^{\operatorname{des}(\alpha)} = \sum_{j=0}^{n-1} d(n, j)\, y^j = \sum_{\beta \in PF^{\uparrow}_n} \sum_{\pi} y^{\operatorname{des}(\pi)},\]

    where, for each \(\beta\), \(\pi\) runs over the rearrangements of \(\beta\): the sequences of length \(n\) with the same multiset of entries as \(\beta\).

    The paper prints the middle sum from \(j = 1\); it is read from \(j = 0\) (at \(n = 1\) the printed middle sum is \(0\) while the other two sides are \(1\)). At \(n = 0\) the left side is \(1\) and the middle sum is empty, so \(n \ge 1\) is assumed, as in the paper.

    public theorem_wanted parkingFunction_descent_genFun (n : ℕ) (hn : 1 ≤ n) :
    ∑ f ∈ pfSet n, (Polynomial.X : Polynomial ℕ) ^ (desSet f).card =
      ∑ j ∈ Finset.range n,
        Polynomial.C ((pfSet n).filter (fun f => (desSet f).card = j)).card *
          Polynomial.X ^ j ∧
    ∑ j ∈ Finset.range n,
        Polynomial.C ((pfSet n).filter (fun f => (desSet f).card = j)).card *
          Polynomial.X ^ j =
      ∑ β ∈ ndpfSet n, ∑ w ∈ Finset.univ.filter
        (fun w : Fin n → Fin n => Finset.univ.val.map w = Finset.univ.val.map β),
          (Polynomial.X : Polynomial ℕ) ^ (desSet w).card

    TheoremRecursion for parking functions with a given descent set#●ready to prove

    MetaMathlibExt.parkingFunction_descentSet_recursion

    The descent set of a word \(w = (w_1, \dots, w_\ell)\) is \(\{i : 1 \le i \le \ell - 1,\ w_i > w_{i+1}\}\), and \(d(J; n)\) denotes the number of parking functions of length \(n\) with descent set \(J\). Let \(n \in \mathbb{N}\), let \(I \subseteq \{1, \dots, n - 1\}\) be nonempty with largest element \(m\), and let \(I^- = I \setminus \{m\}\). Then

    \[d(I; n) = \sum_{\beta} \sum_{X} d_X(I^-) - d(I^-; n),\]

    where \(\beta\) runs over the nondecreasing parking functions of length \(n\), \(X\) runs over the distinct sub-multisets of size \(m\) of the multiset of entries of \(\beta\), and \(d_X(I^-)\) is the number of words of length \(m\) whose multiset of letters is \(X\) and whose descent set is \(I^-\).

          Finset.univ.val.map w = X ∧ desSet w = I.erase (I.max' hne))).card : ℤ) -
