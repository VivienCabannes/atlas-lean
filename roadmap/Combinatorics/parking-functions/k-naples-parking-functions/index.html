    DefinitionThe \(k\)-Naples rule#✓fully proved

    MetaMathlibExt.naplesSpot

    On the spots \(1, \dots, n\), when the spots in a list \(O\) of natural numbers are occupied, a car preferring \(a\) parks in \(a\) if \(a\) is free; otherwise in the first free spot among those of \(a - 1, \dots, a - k\) that are at least \(1\), checked in decreasing order; otherwise in the first free spot among \(a + 1, \dots, n\), checked in increasing order. The car cannot park if none of these is free, or if \(a\) is not one of the spots \(1, \dots, n\).

    public def naplesSpot (n k : ℕ) (occ : List ℕ) (a : ℕ) : Option ℕ :=
  if ¬ (1 ≤ a ∧ a ≤ n) then none else
  if a ∉ occ then some a else
    match ((List.range k).map fun j => a - (j + 1)).find? (fun s => decide (1 ≤ s ∧ s ∉ occ)) with
    | some s => some s
    | none => (List.range' (a + 1) (n - a)).find? (fun s => decide (s ∉ occ))

    MetaMathlibExt.naplesPark

    Starting from a list of occupied spots, cars with preferences \(a_1, \dots, a_m \in \mathbb{N}\) arrive in order, and each takes the spot given by the \(k\)-Naples rule on the spots \(1, \dots, n\) for the spots occupied when it arrives.
