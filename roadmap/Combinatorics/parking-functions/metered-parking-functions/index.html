    DefinitionOutcome of the metered parking scheme#✓fully proved

    MetaMathlibExt.meteredOutcome

    Let \(t, n \in \mathbb{N}\), number the \(n\) spots \(0, \dots, n-1\), and let \(a_0, a_1, \dots, a_{m-1}\) be a list of preferences in \(\mathbb{N}\). Cars arrive in order, and car \(i\) parks in the least spot \(s\) with \(a_i \le s < n\) that is not taken by one of the previous \(t\) cars (cars \(\max(0, i - t), \dots, i - 1\)) that parked; if there is no such spot, car \(i\) fails. The outcome is the list whose \(i\)-th entry is the spot of car \(i\), or a failure marker if car \(i\) fails. Thus after car \(j\) arrives, car \(j - t\) leaves, and only the cars among the last \(t\) entries of the outcome so far occupy spots.

    public def meteredOutcome (t n : ℕ) (prefs : List ℕ) : List (Option ℕ) :=
  prefs.foldl
    (fun out a => out ++ [(List.range' a (n - a)).find?
      (fun s => decide (s ∉ (out.drop (out.length - t)).filterMap id))])

    DefinitionOne step of the lace decomposition#✓fully proved

    MetaMathlibExt.laceStep

    Given a list of blocks (each a list of natural numbers) and a natural number \(a\): if the last block is \((p)\) with \(a = p\), or the last block has at least two entries and ends with \(e\) where \(a = e + 1\), then \(a\) is appended to the last block; otherwise, including when there is no block, a new block \((a)\) is added at the end.

    Applied to a list of laces, where a lace is \((p)\) or \((p, p, p+1, \dots, p+\ell-2)\) for some natural number \(p\) and some length \(\ell \ge 2\), this extends the last lace exactly when the result is again a lace.

    public def laceStep (acc : List (List ℕ)) (a : ℕ) : List (List ℕ) :=
  match acc.getLast? with
  | some [p] => if a = p then acc.dropLast ++ [[p, a]] else acc ++ [[a]]
  | some l@(_ :: _ :: _) =>
      if a = l.getLastD 0 + 1 then acc.dropLast ++ [l ++ [a]] else acc ++ [[a]]
  | _ => acc ++ [[a]]

    DefinitionLace decomposition#✓fully proved

    MetaMathlibExt.laceDecomposition

    A lace is a sequence of natural numbers of the form \((p)\) or \((p, p, p+1, \dots, p+\ell-2)\) for some natural number \(p\) and some length \(\ell \ge 2\).
