    Lucky cars in parking functions

    TheoremExpected number of lucky cars in weakly increasing parking functions#✓fully proved

    MetaMathlibExt.expected_lucky_spots_weakly_increasing_parking_functions

    Let \(n \ge 1\). Number cars and spots from \(0\), and encode a weakly increasing parking function of length \(n\) as a nondecreasing map \(a : \{0, \dots, n-1\} \to \{0, \dots, n-1\}\) with \(a(i) \le i\) for every \(i\). The average, over all such maps \(a\), of the number of indices \(i\) with \(a(i) = i\) equals \(\frac{3n}{n+2}\). Here car \(i\) parks in spot \(i\) and is lucky exactly when \(a(i) = i\), so this number counts both the lucky cars and the lucky spots.

    theorem expected_lucky_spots_weakly_increasing_parking_functions
    (n : ℕ) (hn : 0 < n) :
    let parkingFunctions := Finset.univ.filter fun a : Fin n → Fin n =>
      Monotone a ∧ ∀ i, (a i).val ≤ i.val
    (∑ a ∈ parkingFunctions,
        ((Finset.univ.filter fun i : Fin n => a i = i).card : ℚ)) /
      (parkingFunctions.card : ℚ) = ((3 : ℚ) * n) / (n + 2)

    Number the \(n\) spots \(0, \dots, n-1\).     DefinitionLucky-car polynomial#✓fully proved

    MathlibExt.Combinatorics.Enumerative.LuckyCarsWanted.luckyGenPoly

    For \(n \in \mathbb{N}\), \(f_n \in \mathbb{Q}[x]\) is the polynomial

    \[f_n(x) = \frac{1}{n+1} \prod_{i=0}^{n-1} \bigl((n+1-i)\,x + i\bigr).\]

    Equivalently, \(f_n(x) = \frac{1}{n+1} \prod_{i=1}^{n} \bigl((n+2-i)\,x + (i-1)\bigr)\).

    MathlibExt.Combinatorics.Enumerative.LuckyCarsWanted.card_parking_lucky_on

    Number the cars and spots \(0, \dots, n-1\), and let \(L\) and \(U\) be disjoint sets of cars. The number of parking functions of length \(n\) in which every car in \(L\) is lucky and no car in \(U\) is lucky equals

    \[\prod_{i \in L} (n + 1 - i) \cdot \prod_{i \in U} i \cdot (n + 1)^{n - |L| - |U| - 1},\]

    where the power is taken in \(\mathbb{Q}\), so the exponent may be negative.

    In the paper's numbering of cars from \(1\), the factors are \(n + 2 - i\) and \(i - 1\).

    theorem_wanted card_parking_lucky_on (n : ℕ) (L U : Finset (Fin n))
    (hLU : Disjoint L U) :
    (Nat.card { f : Fin n → Fin n // IsParkingFunction n f ∧
        (∀ i ∈ L, IsLuckyCar f i) ∧
          (∀ i ∈ U, ¬ IsLuckyCar f i) } : ℚ) =
      (∏ i ∈ L, ((n + 1 - i.val : ℕ) : ℚ)) *
        (∏ i ∈ U, (i.val : ℚ)) *
        ((n + 1 : ℚ)) ^ ((n : ℤ) - L.card - U.card - 1)

    MathlibExt.Combinatorics.Enumerative.LuckyCarsWanted.expected_descFactorial_luckyCount

    Let \(n \ge 1\) and \(\ell \in \mathbb{N}\), let \(X(f)\) be the number of lucky cars of a parking function \(f\) of length \(n\), and let \(P_n(x) = \frac{1}{n+1} \prod_{i=0}^{n-1} \bigl((n+1-i)x + i\bigr) \in \mathbb{Q}[x]\). Then

    \[\frac{1}{(n+1)^{n-1}} \sum_f X(f)\bigl(X(f)-1\bigr)\cdots\bigl(X(f)-\ell+1\bigr) = \frac{P_n^{(\ell)}(1)}{(n+1)^{n-1}},\]

    where \(f\) runs over the parking functions of length \(n\) and \(P_n^{(\ell)}\) is the \(\ell\)-th derivative of \(P_n\).
