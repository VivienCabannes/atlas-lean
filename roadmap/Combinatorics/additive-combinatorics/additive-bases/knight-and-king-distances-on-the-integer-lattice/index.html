    MetaMathlibExt.knightMoves

    For integers \(a\) and \(b\), the \((a,b)\)-knight's move set is

    \[N_{a,b} = \{(\pm a, \pm b), (\pm b, \pm a)\} \subset \mathbb{Z}^2,\]

    the finite set of the points \((a, b)\), \((-a, b)\), \((a, -b)\), \((-a, -b)\), \((b, a)\), \((-b, a)\), \((b, -a)\) and \((-b, -a)\).

    public def knightMoves (a b : ℤ) : Finset (ℤ × ℤ) :=
  {(b, a), (a, b), (-a, b), (-b, a), (-b, -a), (-a, -b), (a, -b), (b, -a)}

    DefinitionPiece distance on the integer lattice#✓fully proved

    MetaMathlibExt.pieceDistance

    Let \(A \subseteq \mathbb{Z}^2\) be a finite set of moves and, for \(h \ge 1\), let \(hA = \{a_1 + \dots + a_h : a_1, \dots, a_h \in A\}\) be its \(h\)-fold sumset. The piece distance of a point \(p \in \mathbb{Z}^2\) for \(A\) is the natural number that is \(0\) if \(p = (0,0)\) and otherwise the infimum of the set of integers \(h \ge 1\) with \(p \in hA\), where the infimum of the empty set is taken to be \(0\).

    Points other than the origin that are not a sum of moves from \(A\) therefore have distance \(0\).

    public noncomputable def pieceDistance (A : Finset (ℤ × ℤ)) (p : ℤ × ℤ) : ℕ :=
  if p = 0 then 0 else sInf {h : ℕ | 1 ≤ h ∧ p ∈ h • A}

    DefinitionMax-norm ball#✓fully proved

    MetaMathlibExt.maxNormBall

    For a natural number \(h\), the max-norm ball \(B_h \subset \mathbb{Z}^2\) is the product of two copies of the integer interval \(\{-h, \dots, h\}\), that is, the set of lattice points \((x, y)\) with \(\max(|x|, |y|) \le h\).

    public def maxNormBall (h : ℕ) : Finset (ℤ × ℤ) :=
  Finset.Icc (-(h : ℤ)) h ×ˢ Finset.Icc (-(h : ℤ)) h
