    Sum-free sets in abelian groups

    DefinitionSum-free set#✓fully proved

    MetaMathlibExt.IsSumFreeSet

    Let \(G\) be a set with an addition. A subset \(S \subseteq G\) is sum-free if \(x + y \notin S\) for all \(x, y \in S\), where \(x = y\) is allowed; that is, \(S\) contains no Schur triple \(x + y = z\) with \(x, y, z \in S\).

    public def IsSumFreeSet {G : Type*} [Add G] (S : Set G) : Prop :=
  ∀ x ∈ S, ∀ y ∈ S, x + y ∉ S

    DefinitionDistinct sum-free sets#✓fully proved

    MetaMathlibExt.IsDistinctSumFreeSet

    Let \(G\) be a set with an addition. A subset \(S \subseteq G\) is distinct sum-free if there are no pairwise distinct \(x, y, z \in S\) with \(x + y = z\), that is, if \(S\) contains no distinct Schur triple.

    public def IsDistinctSumFreeSet {G : Type*} [Add G] (S : Set G) : Prop :=
  ∀ x ∈ S, ∀ y ∈ S, x ≠ y → x + y ≠ x → x + y ≠ y → x + y ∉ S

    MetaMathlibExt.largestSumFreeCard

    Let \(G\) be a set with an addition and \(S \subseteq G\).     DefinitionNumber of distinct Schur triples#✓fully proved

    MetaMathlibExt.distinctSchurTripleCount

    For a subset \(F\) of a set \(G\) with an addition, this is the number of ordered pairs \((x, y)\) with \(x, y \in F\) such that \(x\), \(y\) and \(x + y\) are pairwise distinct and \(x + y \in F\), that is, the number of ordered distinct Schur triples \((x, y, x + y)\) in \(F\). If there are infinitely many such pairs, the value is \(0\) by convention.

    public noncomputable def distinctSchurTripleCount {G : Type*} [Add G] (F : Set G) : ℕ :=
  {xy : G × G | xy.1 ∈ F ∧ xy.2 ∈ F ∧ xy.1 ≠ xy.2 ∧ xy.1 + xy.2 ≠ xy.1 ∧
    xy.1 + xy.2 ≠ xy.2 ∧ xy.1 + xy.2 ∈ F}.ncard

    DefinitionGroups of type I(p)#✓fully proved

    MetaMathlibExt.IsTypeOneGroup

    Let \(G\) be a finite set and \(p\) a natural number. \(G\) is of type \(\mathrm{I}(p)\) if \(p\) is the smallest prime with \(p \equiv 2 \pmod 3\) dividing \(|G|\): that is, \(p\) is prime, \(p \equiv 2 \pmod 3\), \(p\) divides \(|G|\), and \(p \le q\) for every prime \(q\) with \(q \equiv 2 \pmod 3\) that divides \(|G|\).

    Only the order of \(G\) is used; in the paper \(G\) is a finite abelian group.

    public def IsTypeOneGroup (G : Type*) [Fintype G] (p : ℕ) : Prop :=
  p.Prime ∧ p % 3 = 2 ∧ p ∣ Fintype.card G ∧
    ∀ q : ℕ, q.Prime → q % 3 = 2 → q ∣ Fintype.card G → p ≤ q

    MetaMathlibExt.largestSumFreeCard_univ_eq

    Let \(G\) be a finite abelian group of order \(n\), and let \(\mu(G)\) be the largest size of a sum-free subset of \(G\). If \(G\) is of type \(\mathrm{I}(p)\) for a natural number \(p\), then \(\mu(G) = n\left(\frac{1}{3} + \frac{1}{3p}\right)\).     DefinitionEdges of the distinct link graph#✓fully proved

    MetaMathlibExt.DistinctLinkAdj

    Let \(G\) be a set with an addition and \(S \subseteq G\). Two elements \(x, y \in G\) are adjacent in the distinct link graph of \(S\) if \(x \ne y\) and there is some \(s \in S\), different from both \(x\) and \(y\), with \(x + y = s\), \(x + s = y\) or \(y + s = x\). In an abelian group this says exactly that \(\{x, y, s\}\) is a distinct Schur triple for some \(s \in S\). In the paper's graph \(L^*_S[B]\) with vertex set \(B\), these are the edges between distinct vertices; the relation itself does not depend on \(B\).

    public def DistinctLinkAdj {G : Type*} [Add G] (S : Set G) (x y : G) : Prop :=
  x ≠ y ∧ ∃ s ∈ S, x ≠ s ∧ y ≠ s ∧ (x + y = s ∨ x + s = y ∨ y + s = x)

    DefinitionLoops of the distinct link graph#✓fully proved

    MetaMathlibExt.DistinctLinkLoop

    Let \(G\) be a set with an addition and \(S \subseteq G\). An element \(x \in G\) carries a loop in the distinct link graph of \(S\) if there are distinct \(s, s' \in S\), both different from \(x\), with \(s + s' = x\), \(x + s = s'\) or \(x + s' = s\). In an abelian group this says exactly that \(\{x, s, s'\}\) is a distinct Schur triple for some distinct \(s, s' \in S\).

    public def DistinctLinkLoop {G : Type*} [Add G] (S : Set G) (x : G) : Prop :=
  ∃ s ∈ S, ∃ s' ∈ S, s ≠ s' ∧ x ≠ s ∧ x ≠ s' ∧ (s + s' = x ∨ x + s = s' ∨ x + s' = s)

    DefinitionIndependent sets of the distinct link graph#✓fully proved

    MetaMathlibExt.IsDistinctLinkIndep

    Let \(G\) be a set with an addition and let \(S, B, I \subseteq G\).     TheoremGreen–Ruzsa structure lemma#●ready to prove

    MetaMathlibExt.exists_addMonoidHom_zmod_of_large_sumFree
