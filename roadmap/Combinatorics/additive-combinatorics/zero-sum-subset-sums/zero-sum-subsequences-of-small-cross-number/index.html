    Zero-sum subsequences of small cross number

    TheoremZero-sum subsequences of cross number at most one (Geroldinger; Elledge–Hurlbert)#●ready to prove

    MetaMathlibExt.exists_zero_sum_cross_number_le_one

    Let \(\Gamma\) be a finite abelian group of order \(|\Gamma|\). Every sequence \(g_1, \dots, g_{|\Gamma|}\) of \(|\Gamma|\) elements of \(\Gamma\) has a nonempty zero-sum subsequence with cross number at most one: there is a nonempty set \(S \subseteq \{1, \dots, |\Gamma|\}\) of indices with \(\sum_{i \in S} g_i = 0\) and \(\sum_{i \in S} 1/\operatorname{ord}(g_i) \le 1\), where \(\operatorname{ord}(g_i)\) is the order of \(g_i\).

    public theorem_wanted exists_zero_sum_cross_number_le_one {Γ : Type*} [AddCommGroup Γ]
    [Fintype Γ] (g : Fin (Fintype.card Γ) → Γ) :
    ∃ s : Finset (Fin (Fintype.card Γ)), s.Nonempty ∧ ∑ i ∈ s, g i = 0 ∧
      ∑ i ∈ s, (1 : ℚ) / addOrderOf (g i) ≤ 1

    TheoremLemke–Kleitman theorem#●ready to prove

    MetaMathlibExt.ZMod.exists_zero_sum_cross_number_le_one

    For every positive integer \(n\), every sequence \(g_1, \dots, g_n\) of \(n\) elements of \(\mathbb{Z}/n\mathbb{Z}\) has a nonempty zero-sum subsequence with cross number at most one: there is a nonempty set \(S \subseteq \{1, \dots, n\}\) of indices with \(\sum_{i \in S} g_i = 0\) and \(\sum_{i \in S} 1/\operatorname{ord}(g_i) \le 1\), where \(\operatorname{ord}(g_i)\) is the additive order of \(g_i\). The theorem is due to Lemke and Kleitman and to Chung.

    DefinitionGood sequences in a finite abelian group#✓fully proved

    MetaMathlibExt.IsGoodSequence

    Let \(\Gamma\) be a finite abelian group, written additively, and let \(g = (g_1, \dots, g_t)\) be a sequence of \(t\) elements of \(\Gamma\). The sequence \(g\) is good if there is a nonempty set \(S \subseteq \{1, \dots, t\}\) of indices with \(\sum_{i \in S} g_i = 0\) whose cross number \(\sum_{i \in S} 1/|g_i|\) is at most \(1\), where \(|g_i|\) is the order of \(g_i\).

    ∑ i ∈ s, (1 : ℚ) / addOrderOf (g i) ≤ 1

    DefinitionProbability that a random sequence is good#✓fully proved

    MetaMathlibExt.goodSequenceProb

    Let \(\Gamma\) be a finite abelian group and \(t \ge 0\) an integer. A sequence \(g_1, \dots, g_t\) in \(\Gamma\) is good if some nonempty set \(S \subseteq \{1, \dots, t\}\) of indices has \(\sum_{i \in S} g_i = 0\) and \(\sum_{i \in S} 1/\operatorname{ord}(g_i) \le 1\), where \(\operatorname{ord}(g_i)\) is the order of \(g_i\). The good-sequence probability of \(\Gamma\) at length \(t\) is the number of good sequences of length \(t\) in \(\Gamma\) divided by \(|\Gamma|^t\), that is, the probability that a uniformly random sequence of length \(t\) in \(\Gamma\) is good.

    DefinitionHalf-good threshold#✓fully proved

    MetaMathlibExt.halfGoodThreshold

    For a finite abelian group \(\Gamma\), \(P_{1/2}(\Gamma)\) is the least \(t \ge 0\) such that a uniformly random sequence of \(t\) elements of \(\Gamma\) is good (has a nonempty zero-sum subsequence with cross number at most one) with probability at least \(1/2\), that is, such that at least half of the \(|\Gamma|^t\) sequences of length \(t\) are good. If no such \(t\) exists, \(P_{1/2}(\Gamma)\) is defined to be \(0\).

  sInf {t : ℕ | (1 : ℝ) / 2 ≤ goodSequenceProb Γ t}

    TheoremHalf-good threshold of a group of order at most two#✓fully proved

    MetaMathlibExt.halfGoodThreshold_eq_one_of_card_le_two

    If \(\Gamma\) is a finite abelian group with at most two elements, then its half-good threshold \(P_{1/2}(\Gamma)\) equals \(1\).

    The empty sequence is not good, while the one-term sequence \((0)\) is good, so a uniformly random sequence of length one is good with probability at least \(1/|\Gamma| \ge 1/2\).

    DefinitionThreshold functions#✓fully proved

    MetaMathlibExt.IsThresholdFunction

    Let \(P : \mathbb{N} \times \mathbb{N} \to \mathbb{R}\), where \(P(k, s)\) is read as the probability of an event in the \(k\)-th space when \(s\) random elements are chosen. A function \(t : \mathbb{N} \to \mathbb{R}\) is a threshold function for \(P\) if \(t(k) > 0\) for all sufficiently large \(k\) and, for every function \(f : \mathbb{N} \to \mathbb{N}\), \(P(k, f(k)) \to 1\) as \(k \to \infty\) whenever \(t = o(f)\), and \(P(k, f(k)) \to 0\) as \(k \to \infty\) whenever \(f = o(t)\).

    The source's thresholds are positive functions; since little-o ignores sign, without the positivity condition \(-t\) would be a threshold function whenever \(t\) is.

    def IsThresholdFunction (P : ℕ → ℕ → ℝ) (t : ℕ → ℝ) : Prop :=
  (∀ᶠ k in Filter.atTop, 0 < t k) ∧ ∀ f : ℕ → ℕ,
    (t =o[Filter.atTop] (fun k => (f k : ℝ)) →
        Filter.Tendsto (fun k => P k (f k)) Filter.atTop (nhds 1)) ∧
      ((fun k => (f k : ℝ)) =o[Filter.atTop] t →
        Filter.Tendsto (fun k => P k (f k)) Filter.atTop (nhds 0))

    DefinitionLagarias–Saks pebbling step#✓fully proved

    MetaMathlibExt.PebblingStep

    Let \(G\) be a simple graph on a vertex set \(V\), and let \(w\) assign a natural-number cost \(w(uv)\) to each unordered pair of vertices \(\{u, v\}\). For configurations \(C, C' : V \to \mathbb{N}\), there is a pebbling step from \(C\) to \(C'\) if there is an edge \(uv\) of \(G\) with \(0 < w(uv) \le C(u)\) such that \(C'\) is obtained from \(C\) by removing \(w(uv)\) pebbles from \(u\) and adding one pebble to \(v\).

    Each edge has one cost, used in both directions. The source's costs are positive, and the step requires \(w(uv) > 0\), so a zero cost never creates a pebble for free.

    def PebblingStep {V : Type*} [DecidableEq V] (G : SimpleGraph V) (w : Sym2 V → ℕ)
    (C C' : V → ℕ) : Prop :=
  ∃ u v, G.Adj u v ∧ 0 < w s(u, v) ∧ w s(u, v) ≤ C u ∧
    C' = Function.update (Function.update C u (C u - w s(u, v))) v (C v + 1)

    DefinitionSolvable pebbling configurations#✓fully proved

    MetaMathlibExt.PebblingSolvable

    Let \(G\) be a simple graph on a vertex set \(V\) with natural-number edge costs \(w\). A configuration \(C : V \to \mathbb{N}\) of pebbles is solvable if for every target vertex \(r\) there is a finite, possibly empty, sequence of pebbling steps on \(G\) with costs \(w\) leading from \(C\) to a configuration with at least one pebble on \(r\).

    def PebblingSolvable {V : Type*} [DecidableEq V] (G : SimpleGraph V) (w : Sym2 V → ℕ)
    (C : V → ℕ) : Prop :=
  ∀ r : V, ∃ C', Relation.ReflTransGen (PebblingStep G w) C C' ∧ 1 ≤ C' r

    DefinitionProbability that a random pebbling configuration is solvable#✓fully proved

    MetaMathlibExt.solvableConfigurationProb

    Let \(G\) be a simple graph on a finite vertex set \(V\) with \(n\) vertices, let \(w\) assign a natural-number cost to each unordered pair of vertices, and let \(t \ge 0\) be an integer. A configuration of \(t\) pebbles is a function \(C : V \to \mathbb{N}\) with \(\sum_{v \in V} C(v) = t\). The value is the number of configurations of \(t\) pebbles that are solvable with respect to \(G\) and \(w\), divided by the number of all configurations of \(t\) pebbles; that is, the probability that a configuration of \(t\) pebbles chosen uniformly at random is solvable. If there are no configurations of \(t\) pebbles (\(V\) empty and \(t > 0\)), the value is \(0\).

    For \(n \ge 1\) there are \(\binom{n + t - 1}{t}\) configurations of \(t\) pebbles (the space \(D_{G,t}\) of the source).

    noncomputable def solvableConfigurationProb {V : Type*} [Fintype V] [DecidableEq V]

  ({C : V → ℕ | ∑ v, C v = t ∧ PebblingSolvable G w C}.ncard : ℝ) /
    ({C : V → ℕ | ∑ v, C v = t}.ncard : ℝ)

    DefinitionGrid graph#✓fully proved

    MetaMathlibExt.gridGraph

    For natural numbers \(d\) and \(k\), the \(d\)-dimensional grid \(P_k^d = \square_{i\lt d} P_k\) is the simple graph on \(\{0, \dots, k-1\}^d\) in which \(x\) and \(y\) are adjacent when there is a coordinate \(i\) with \(x_j = y_j\) for all \(j \ne i\) and \(|x_i - y_i| = 1\). For \(k = 2\) this is the \(d\)-cube \(Q_d\).

    def gridGraph (d k : ℕ) : SimpleGraph (Fin d → Fin k) where
  Adj x y := ∃ i, (∀ j, j ≠ i → x j = y j) ∧ ((x i : ℕ) + 1 = y i ∨ (y i : ℕ) + 1 = x i)
  symm := ⟨fun _ _ ⟨i, h1, h2⟩ => ⟨i, fun j hj => (h1 j hj).symm, h2.symm⟩⟩
  loopless := ⟨fun _ ⟨_, _, h2⟩ => by omega⟩

    DefinitionGrid edge costs#✓fully proved

    MetaMathlibExt.gridCost

    Let \(d\) and \(k\) be natural numbers and let \(w_0, \dots, w_{d-1}\) be natural numbers. The grid cost with cost \(w_i\) in coordinate \(i\) assigns to each unordered pair \(\{x, y\}\) of points of \(\{0, \dots, k-1\}^d\) the sum of the \(w_i\) over the coordinates \(i\) with \(x_i \ne y_i\). On an edge of the grid exactly one coordinate differs, so an edge in coordinate \(i\) costs \(w_i\).

    def gridCost {d k : ℕ} (w : Fin d → ℕ) : Sym2 (Fin d → Fin k) → ℕ :=
  Sym2.lift ⟨fun x y => ∑ i, if x i = y i then 0 else w i, fun x y =>
    Finset.sum_congr rfl fun i _ => by simp only [eq_comm]⟩
