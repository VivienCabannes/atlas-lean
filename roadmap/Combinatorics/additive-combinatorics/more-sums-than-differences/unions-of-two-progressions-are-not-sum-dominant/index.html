    DefinitionMSTD set#✓fully proved

    MetaMathlibExt.IsMSTDSet

    A finite set \(A\) of real numbers is an MSTD set (more sums than differences) when its difference set has fewer elements than its sumset: \(|A - A| < |A + A|\), where \(A + A = \{a + b : a, b \in A\}\) and \(A - A = \{a - b : a, b \in A\}\).

    def IsMSTDSet (A : Finset ℝ) : Prop :=
  (A - A).card < (A + A).card
