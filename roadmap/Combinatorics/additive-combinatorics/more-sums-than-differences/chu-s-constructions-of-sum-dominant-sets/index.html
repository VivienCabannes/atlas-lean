    DefinitionSets given by consecutive differences#✓fully proved

    MetaMathlibExt.setOfConsecutiveDifferences

    For an integer \(a\) and natural numbers \(g_1, \dots, g_r\), the set \((a \mid g_1, \dots, g_r)\) is the finite set of integers \(\{a, a + g_1, a + g_1 + g_2, \dots, a + g_1 + \dots + g_r\}\); for \(r = 0\) it is \(\{a\}\).

    When every \(g_i\) is positive, the differences between consecutive elements of this set, listed from the smallest element to the largest, are \(g_1, \dots, g_r\); a zero gap repeats a partial sum, which the set records once.

    public def setOfConsecutiveDifferences : ℤ → List ℕ → Finset ℤ
  | a, [] => {a}
  | a, g :: l => insert a (setOfConsecutiveDifferences (a + g) l)

    MetaMathlibExt.setOfConsecutiveDifferences_cons

    For an integer \(a\) and natural numbers \(g_1, \dots, g_r\) (\(r \ge 0\)), write \((a \mid g_1, \dots, g_r)\) for the set of partial sums \(\{a, a + g_1, \dots, a + g_1 + \dots + g_r\}\). Then for every natural number \(g\), \((a \mid g, g_1, \dots, g_r) = \{a\} \cup (a + g \mid g_1, \dots, g_r)\).

    When \(g > 0\), the new element \(a\) is smaller than every element of \((a + g \mid g_1, \dots, g_r)\).

    public theorem setOfConsecutiveDifferences_cons (a : ℤ) (g : ℕ) (l : List ℕ) :
    setOfConsecutiveDifferences a (g :: l) = insert a (setOfConsecutiveDifferences (a + g) l)
