    MathlibExt.Combinatorics.ManyThreeTermProgressionsErdosProblem179Wanted.HasAP

    A finite set \(A \subseteq \mathbb{N}\) contains a \(k\)-term arithmetic progression when there are natural numbers \(a\) and \(d \ge 1\) with \(a + i d \in A\) for every natural number \(i < k\), that is, \(a, a + d, \dots, a + (k - 1) d\) all lie in \(A\). For \(k = 0\) this holds vacuously.

    def HasAP (A : Finset ℕ) (k : ℕ) : Prop :=
  ∃ a d : ℕ, 0 < d ∧ ∀ i < k, a + i * d ∈ A

    DefinitionNumber of \(k\)-term arithmetic progressions in a set#✓fully proved

    MathlibExt.Combinatorics.ManyThreeTermProgressionsErdosProblem179Wanted.apCount

    For a finite set \(A \subseteq \mathbb{N}\) and a natural number \(k\), \(\mathrm{AP}_k(A)\) is the number of pairs \((a, d)\) of natural numbers with \(a \in A\) and \(1 \le d \le \max A\) such that \(a + i d \in A\) for every natural number \(i < k\). For \(k \ge 2\) the conditions \(a \in A\) and \(d \le \max A\) follow from the others, so \(\mathrm{AP}_k(A)\) counts the \(k\)-term progressions \(a, a + d, \dots, a + (k - 1) d\) in \(A\) with \(d \ge 1\).

    def apCount (A : Finset ℕ) (k : ℕ) : ℕ :=
  ((A ×ˢ Finset.Icc 1 (A.sup id)).filter (fun p => ∀ i < k, p.1 + i * p.2 ∈ A)).card

    DefinitionThe progression threshold \(F_k(N, \ell)\)#✓fully proved

    MathlibExt.Combinatorics.ManyThreeTermProgressionsErdosProblem179Wanted.apThreshold

    For natural numbers \(k\), \(\ell\) and \(N\), \(F_k(N, \ell)\) is the least natural number \(m\) such that every \(N\)-element set \(A \subseteq \mathbb{N}\) with \(\mathrm{AP}_k(A) \ge m\) contains an \(\ell\)-term arithmetic progression, where \(\mathrm{AP}_k(A)\) is the number of pairs \((a, d)\) with \(a \in A\), \(1 \le d \le \max A\) and \(a + i d \in A\) for all \(i < k\) (for \(k \ge 2\), the number of \(k\)-term progressions in \(A\) with \(d \ge 1\)); if no such \(m\) exists, \(F_k(N, \ell) = 0\).

    For \(k \ge 2\) such an \(m\) always exists, since an \(N\)-element set has at most \(N^2\) \(k\)-term progressions.

    noncomputable def apThreshold (k ℓ N : ℕ) : ℕ :=
  sInf {m : ℕ | ∀ A : Finset ℕ, A.card = N → m ≤ apCount A k → HasAP A ℓ}
    def apCount (A : Finset ℕ) (k : ℕ) : ℕ :=

    MathlibExt.Combinatorics.ManyThreeTermProgressionsErdosProblem179Wanted.threeAPThresholdForFourAPLittleO_holds

    As \(N \to \infty\) over the natural numbers, \(F_3(N, 4) / N^2 \to 0\), that is, \(F_3(N, 4) = o(N^2)\), where \(F_3(N, 4)\) is the least natural number \(m\) such that every \(N\)-element set \(A \subseteq \mathbb{N}\) containing at least \(m\) three-term arithmetic progressions \(a, a + d, a + 2d\) with \(d \ge 1\) contains a \(4\)-term arithmetic progression.

    Write \(F_k(N, \ell)\) for the same threshold with \(k\)-term progressions in place of three-term ones and \(\ell\)-term progressions in place of \(4\)-term ones. Fox and Pohoata bound \(F_k(N, \ell)\) above by \((r_\ell(N) / N)^{O(1)} N^2\), where \(r_\ell(N)\) is the largest size of a subset of \(\{1, \dots, N\}\) without \(\ell\)-term progressions; since \(r_\ell(N) = o(N)\) by Szemerédi's theorem, this bound is \(o(N^2)\). erdosproblems.com/179 records \(F_k(N, \ell) \le N^2 / (\log \log N)^{C_\ell}\) for a constant \(C_\ell\) depending only on \(\ell\).
