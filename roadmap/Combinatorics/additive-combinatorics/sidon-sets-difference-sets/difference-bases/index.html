    DefinitionDifference basis number of an abelian group#✓fully proved

    MetaMathlibExt.groupDiffBasisNumber

    For an abelian group \(G\) and \(g \in \mathbb{N}\), a \(g\)-difference basis of \(G\) is a finite set \(A \subseteq G\) such that every \(x \in G\) equals \(a - a'\) for at least \(g\) ordered pairs \((a, a') \in A \times A\). The difference basis number \(\eta_g(G)\) is the least size of a \(g\)-difference basis of \(G\), and \(0\) if \(G\) has none.

    There is no \(g\)-difference basis when \(G\) is infinite and \(g \ge 1\), or when \(G\) is finite and \(g > |G|\), since each element is \(a - a'\) for at most \(|A| \le |G|\) pairs; in these cases the value \(0\) is a convention. When \(G\) is finite and \(g \le |G|\), the set \(A = G\) is a \(g\)-difference basis, so \(\eta_g(G)\) is a true minimum. This is the paper's \(\eta_g(S)\) with \(S = G\).

    public noncomputable def groupDiffBasisNumber (g : ℕ) (G : Type*) [AddCommGroup G]
    [DecidableEq G] : ℕ :=
  sInf {k | ∃ A : Finset G, A.card = k ∧ ∀ x : G, g ≤ subRepCount A x}
    public def subRepCount {G : Type*} [AddCommGroup G] [DecidableEq G] (A : Finset G) (x : G) :
    ℕ :=
  ((A ×ˢ A).filter fun p => p.1 - p.2 = x).card
