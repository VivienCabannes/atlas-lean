    DefinitionGeneralized Bose set#✓fully proved

    MetaMathlibExt.boseSet

    Let \(F\) be a finite field with \(q\) elements, \(K\) a field extension of \(F\), \(h\) and \(b\) natural numbers and \(\theta \in K\). The generalized Bose set \(\mathrm{Bose}_h(q, b)\) is the set of residues \(a \in \mathbb{Z}/(q^h - 1)\mathbb{Z}\) such that \(\theta^a = \theta^b + v\) for some \(v \in F\), where \(\theta^a\) is computed with the least nonnegative representative of \(a\) (for \(h = 0\) the modulus is \(0\), \(a\) ranges over \(\mathbb{Z}\) and \(\theta^a\) means \(\theta^{|a|}\)).

    In the paper \(K\) has degree \(h\) over \(F\) and \(\theta\) generates \(K^\times\); the definition does not need these assumptions.

    public def boseSet (F : Type*) {K : Type*} [Field F] [Fintype F] [Field K] [Algebra F K]
    (h : ℕ) (θ : K) (b : ℕ) : Set (ZMod (Fintype.card F ^ h - 1)) :=
  {a | ∃ v : F, θ ^ a.val = θ ^ b + algebraMap F K v}

    TheoremMembership in a Bose set#✓fully proved

    MetaMathlibExt.mem_boseSet

    Let \(F\) be a finite field with \(q\) elements, let \(K\) be a field extension of \(F\), let \(\theta \in K\), and let \(h\) and \(b\) be natural numbers.     DefinitionGeneralized Singer set#✓fully proved

    MetaMathlibExt.singerSet

    Let \(F\) be a finite field with \(q\) elements, let \(K\) be a field extension of \(F\), let \(\theta \in K\), let \(h\) and \(b\) be natural numbers, and put \(M = (q^{h+1} - 1)/(q - 1)\). The generalized Singer set \(\mathrm{Singer}_h(q, b)\) is the set of residues \(a \in \mathbb{Z}/M\mathbb{Z}\) such that \(\theta^a = u\theta^b + v\) for some \(u, v \in F\), where \(\theta^a\) means \(\theta\) raised to the least nonnegative representative of \(a\).

    The construction is intended for \([K : F] = h + 1\) and \(\theta\) a generator of \(K^\times\); the definition itself does not assume either.

    public def singerSet (F : Type*) {K : Type*} [Field F] [Fintype F] [Field K] [Algebra F K]
    (h : ℕ) (θ : K) (b : ℕ) :
    Set (ZMod ((Fintype.card F ^ (h + 1) - 1) / (Fintype.card F - 1))) :=
  {a | ∃ u v : F, θ ^ a.val = algebraMap F K u * θ ^ b + algebraMap F K v}

    DefinitionAffine equivalence of sets of residues#✓fully proved

    MetaMathlibExt.ZModAffinelyEquivalent

    For a natural number \(M\), sets \(A_1, A_2 \subseteq \mathbb{Z}/M\mathbb{Z}\) are affinely equivalent, written \(A_1 \sim A_2\), if there are a unit \(d\) of \(\mathbb{Z}/M\mathbb{Z}\) and an element \(s \in \mathbb{Z}/M\mathbb{Z}\) such that \(A_2 = \{d a + s : a \in A_1\}\).

    public def ZModAffinelyEquivalent {M : ℕ} (A₁ A₂ : Set (ZMod M)) : Prop :=
  ∃ d s : ZMod M, IsUnit d ∧ A₂ = (fun a => d * a + s) '' A₁

    For natural numbers \(h\) and \(n\), \(R_h(n)\) is the largest number of elements of a \(B_h\)-set of natural numbers contained in \(\{1, \dots, n\}\). If no \(B_h\)-set is contained in \(\{1, \dots, n\}\) (for example when \(n = 0\)), then \(R_h(n) = 0\).

    public noncomputable def bhMaxCard (h n : ℕ) : ℕ :=

    AdditiveCombinatorics.IsBhSet (A : Set ℕ) h ∧ A.card = k}
    public def IsBhSet {G : Type*} [AddCommSemigroup G] (A : Set G) (h : ℕ) : Prop :=

    ∀ (l₁ l₂ : List G),
      (∀ x ∈ l₁, x ∈ A) →
      (∀ x ∈ l₂, x ∈ A) →
      l₁.length = h →
      l₂.length = h →
      ∀ (e₁ : l₁ ≠ []) (e₂ : l₂ ≠ []),
