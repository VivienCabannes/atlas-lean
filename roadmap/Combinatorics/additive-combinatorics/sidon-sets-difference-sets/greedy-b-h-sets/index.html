    MathlibExt.Combinatorics.GreedyBhFourthWanted.IsNextGreedyBh

    Let \(h\) and \(a\) be natural numbers and \(A\) a set of natural numbers. Then \(a\) is the next greedy \(B_h\) choice after \(A\) if \(a\) is greater than every element of \(A\), the set \(A \cup \{a\}\) is a \(B_h\)-set, and for every natural number \(b < a\) that is greater than every element of \(A\), the set \(A \cup \{b\}\) is not a \(B_h\)-set.

    def IsNextGreedyBh (h : ℕ) (A : Set ℕ) (a : ℕ) : Prop :=
  (∀ x ∈ A, x < a) ∧ AdditiveCombinatorics.IsBhSet (insert a A) h ∧
    ∀ b : ℕ, (∀ x ∈ A, x < b) → b < a →
      ¬AdditiveCombinatorics.IsBhSet (insert b A) h
    public def IsBhSet {G : Type*} [AddCommSemigroup G] (A : Set G) (h : ℕ) : Prop :=
  A.Nonempty ∧ 0 < h ∧
    ∀ (l₁ l₂ : List G),
      (∀ x ∈ l₁, x ∈ A) →
      (∀ x ∈ l₂, x ∈ A) →
      l₁.length = h →
      l₂.length = h →
      ∀ (e₁ : l₁ ≠ []) (e₂ : l₂ ≠ []),
        sumNE l₁ e₁ = sumNE l₂ e₂ → l₁.Perm l₂

    MathlibExt.Combinatorics.GreedyBhFourthWanted.IsFourthGreedyBh

    For natural numbers \(h\) and \(a\), we say that \(a\) is the fourth positive element \(a_4(h)\) of the greedy \(B_h\)-set if \(1\) is the next greedy \(B_h\) choice after \(\{0\}\), \(h + 1\) is the next greedy \(B_h\) choice after \(\{0, 1\}\), \(h^2 + h + 1\) is the next greedy \(B_h\) choice after \(\{0, 1, h + 1\}\), and \(a\) is the next greedy \(B_h\) choice after \(\{0, 1, h + 1, h^2 + h + 1\}\).

    def IsFourthGreedyBh (h a : ℕ) : Prop :=
  IsNextGreedyBh h {0} 1 ∧
    IsNextGreedyBh h {0, 1} (h + 1) ∧
    IsNextGreedyBh h {0, 1, h + 1} (h ^ 2 + h + 1) ∧
    IsNextGreedyBh h {0, 1, h + 1, h ^ 2 + h + 1} a

    MathlibExt.Combinatorics.GreedyBhFourthWanted.fourthValue

    For a natural number \(h\), the value \(v(h)\) is \((h^3 + 3h^2 + 3h + 1)/2\) if \(h\) is odd and \((h^3 + 2h^2 + 3h + 2)/2\) if \(h\) is even.

    Both numerators are even, so the divisions are exact.

    def fourthValue (h : ℕ) : ℕ :=
  if Odd h then (h ^ 3 + 3 * h ^ 2 + 3 * h + 1) / 2
