    A set \(A \subseteq \mathbb{N}\) is a weak Sidon set (or well spread) if sums of two distinct elements of \(A\) are distinct: whenever \(a, b, c, d \in A\) satisfy \(a < b\), \(c < d\) and \(a + b = c + d\), then \(a = c\).

    public def IsWeakSidonSet (A : Set ℕ) : Prop :=
  ∀ a ∈ A, ∀ b ∈ A, ∀ c ∈ A, ∀ d ∈ A, a < b → c < d → a + b = c + d → a = c

    DefinitionIdeal generated by a property#✓fully proved

    MetaMathlibExt.generatedIdeal

    Let \(P\) be a property of subsets of \(\mathbb{N}\). The ideal generated by \(P\) is the family of all sets \(A \subseteq \mathbb{N}\) that are contained in the union of finitely many sets with property \(P\). The empty union is allowed, so the empty set always belongs to it.

    public def generatedIdeal (P : Set ℕ → Prop) : Set (Set ℕ) :=
  {A | ∃ (n : ℕ) (S : Fin n → Set ℕ), (∀ j, P (S j)) ∧ A ⊆ ⋃ j, S j}

    DefinitionGap-lacunary set#✓fully proved

    MetaMathlibExt.IsGapLacunarySet

    A set \(A \subseteq \mathbb{N}\) is gap-lacunary (called lacunary in the source) if it is infinite and, writing \(A(n)\) for its \(n\)-th element in increasing order (counting from \(n = 0\)), the gaps \(A(n+1) - A(n)\) tend to infinity as \(n \to \infty\).

    This differs from Hadamard lacunarity, where consecutive elements grow by a factor at least \(q > 1\).

    public def IsGapLacunarySet (A : Set ℕ) : Prop :=
  A.Infinite ∧
    Tendsto (fun n => Nat.nth (· ∈ A) (n + 1) - Nat.nth (· ∈ A) n) atTop atTop

    DefinitionAlmost thin set#✓fully proved

    MetaMathlibExt.IsAlmostThinSet

    A set \(A \subseteq \mathbb{N}\) is almost thin if it is infinite and, writing \(A(n)\) for its \(n\)-th element in increasing order (counting from \(n = 0\)), there is a real number \(\alpha < 1\) such that \(A(n)/A(n+1) \le \alpha\) for all sufficiently large \(n\).

    Since the ratios \(A(n)/A(n+1)\) lie in \([0, 1]\), this is equivalent to \(\limsup_{n \to \infty} A(n)/A(n+1) < 1\).

    public def IsAlmostThinSet (A : Set ℕ) : Prop :=
  A.Infinite ∧ ∃ α : ℝ, α < 1 ∧
    ∀ᶠ n in atTop, (Nat.nth (· ∈ A) n : ℝ) / Nat.nth (· ∈ A) (n + 1) ≤ α

    DefinitionVan der Waerden ideal#✓fully proved

    MetaMathlibExt.vanDerWaerdenIdeal

    The van der Waerden ideal \(W\) consists of the sets \(A \subseteq \mathbb{N}\) for which there is an \(n > 0\) such that \(A\) contains no arithmetic progression \(a, a + r, \dots, a + (n - 1) r\) of \(n\) terms with \(a \in \mathbb{N}\) and \(r > 0\).

    public def vanDerWaerdenIdeal : Set (Set ℕ) :=
  {A | ∃ n > 0, ∀ a r : ℕ, 0 < r → ∃ j < n, a + r * j ∉ A}

    DefinitionThe ideal of sets avoiding large difference sets#✓fully proved
