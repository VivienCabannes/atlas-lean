    Polynomial Freiman–Ruzsa theorem

    AbbreviationThe vector space \(\mathbb{F}_2^n\)#✓fully proved

    MathlibExt.Combinatorics.ConjectureOfMartonWanted.ConjectureOfMarton.F

    For a natural number \(n\), \(\mathbb{F}_2^n\) is the space of functions from \(\{0, \dots, n - 1\}\) to the field \(\mathbb{F}_2 = \mathbb{Z}/2\mathbb{Z}\) with two elements, the \(n\)-dimensional vector space over \(\mathbb{F}_2\).

    TheoremPolynomial Freiman–Ruzsa theorem over \(\mathbb{F}_2\)#●ready to prove

    MathlibExt.Combinatorics.ConjectureOfMartonWanted.ConjectureOfMarton.theorem_1_2

    Let \(n\) be a natural number, let \(A\) be a nonempty subset of \(\mathbb{F}_2^n\), and let \(K\) be a real number such that the sumset \(A + A = \{a + b : a, b \in A\}\) satisfies \(|A + A| \le K |A|\). Then there is a subgroup \(H\) of \(\mathbb{F}_2^n\) with \(|H| \le |A|\) such that \(A\) is covered by at most \(2K^{12}\) cosets of \(H\): there is a finite set \(T \subseteq \mathbb{F}_2^n\) with \(|T| \le 2K^{12}\) and \(A \subseteq T + H\).

    The set \(A\) must be nonempty, which the paper leaves implicit.

    public theorem_wanted theorem_1_2 (A : Set (F n)) (K : ℝ) (h₀ : A.Nonempty) (h : (A + A).ncard ≤ K * A.ncard) :
    ∃ H : AddSubgroup (F n), Nat.card H ≤ A.ncard ∧ CovByVAdd (F n) (2 * K ^ 12) A H
    abbrev F := Fin n → ZMod 2

    DefinitionPolynomial Freiman–Ruzsa conjecture over \(\mathbb{F}_2\)#✓fully proved

    MathlibExt.Combinatorics.PolynomialFreimanRuzsaBinaryWanted.conjecture

    There are real polynomials \(P\) and \(Q\), with \(P(K) > 0\) and \(Q(K) > 0\) for every real \(K \ge 1\), such that for every \(n \in \mathbb{N}\), every nonempty finite set \(A \subseteq \mathbb{F}_2^n\) and every real \(K \ge 1\) with \(|A + A| \le K|A|\), there is a subset \(A' \subseteq A\) with \(|A| / P(K) \le |A'|\) and \(|\operatorname{span}(A')| \le Q(K)\,|A'|\), where \(\operatorname{span}(A')\) is the \(\mathbb{F}_2\)-linear span of \(A'\).

    The problem is recorded as OWR-12177-008. It was proved by Gowers, Green, Manners and Tao (arXiv:2311.05762).

    def conjecture : Prop :=
  ∃ P Q : Polynomial ℝ,
    (∀ K : ℝ, 1 ≤ K → 0 < P.eval K ∧ 0 < Q.eval K) ∧
    ∀ (n : ℕ) (A : Finset (Fin n → ZMod 2)) (K : ℝ),
      1 ≤ K →
      A.Nonempty →
      ((((A.product A).image (fun p => p.1 + p.2)).card : ℝ)) ≤ K * (A.card : ℝ) →
      ∃ A' : Finset (Fin n → ZMod 2), A' ⊆ A ∧
        (A.card : ℝ) / P.eval K ≤ (A'.card : ℝ) ∧
        (Nat.card ↥(Submodule.span (ZMod 2) (↑A' : Set (Fin n → ZMod 2))) : ℝ) ≤
          Q.eval K * (A'.card : ℝ)

    MathlibExt.Combinatorics.PolynomialFreimanRuzsaBinaryWanted.conjecture_holds

    The polynomial Freiman–Ruzsa conjecture over \(\mathbb{F}_2\) holds: there are real polynomials \(P\) and \(Q\), with \(P(K) > 0\) and \(Q(K) > 0\) for every real \(K \ge 1\), such that for every \(n \in \mathbb{N}\), every nonempty finite set \(A \subseteq \mathbb{F}_2^n\) and every real \(K \ge 1\) with \(|A + A| \le K|A|\), there is a subset \(A' \subseteq A\) with \(|A| / P(K) \le |A'|\) and \(|\operatorname{span}(A')| \le Q(K)\,|A'|\), where \(\operatorname{span}(A')\) is the \(\mathbb{F}_2\)-linear span of \(A'\).

    Gowers, Green, Manners and Tao prove that such a set \(A\) is covered by polynomially many (in \(K\)) cosets of a subspace of size at most \(|A|\); the densest of these cosets gives the subset \(A'\).

    DefinitionAdmissible asymptotic coset-cover exponents#✓fully proved

    MathlibExt.Combinatorics.PolynomialFreimanRuzsaBinaryWanted.IsAsymptoticCosetCoverExponent

    A real number \(C\) is an admissible asymptotic coset-cover exponent if for every real \(\varepsilon > 0\) there is a real \(K_0 \ge 1\) such that for every real \(K \ge K_0\), every \(n \in \mathbb{N}\) and every nonempty finite set \(A \subseteq \mathbb{F}_2^n\) with \(|A + A| \le K|A|\), there is an \(\mathbb{F}_2\)-linear subspace \(H\) of \(\mathbb{F}_2^n\) with \(|H| \le |A|\) such that \(A\) is covered by at most \(K^{C + \varepsilon}\) translates of \(H\): there is a finite set \(F \subseteq \mathbb{F}_2^n\) with \(|F| \le K^{C + \varepsilon}\) and \(A \subseteq F + H\).

    This makes the source's bound of \(K^{C + o(1)}\) translates uniform: once \(K\) is large enough, the same bound works in every dimension and for every nonempty set of doubling at most \(K\).

    def IsAsymptoticCosetCoverExponent (C : ℝ) : Prop :=
  ∀ ε : ℝ, 0 < ε →
    ∃ K₀ : ℝ, 1 ≤ K₀ ∧
      ∀ K : ℝ, K₀ ≤ K →
        ∀ (n : ℕ) (A : Finset (BinaryAmbientSpace n)), A.Nonempty →
          ((A + A).card : ℝ) ≤ K * (A.card : ℝ) →
            ∃ H : Submodule (ZMod 2) (BinaryAmbientSpace n),
              Nat.card H ≤ A.card ∧
                CovByVAdd (BinaryAmbientSpace n) (Real.rpow K (C + ε))
                  (A : Set (BinaryAmbientSpace n)) (H : Set (BinaryAmbientSpace n))
    abbrev BinaryAmbientSpace (n : ℕ) := Fin n → ZMod 2

    DefinitionThe Marton coset-cover exponent#✓fully proved

    MathlibExt.Combinatorics.PolynomialFreimanRuzsaBinaryWanted.martonPFRCoverExponent

    Call a real number \(C\) an admissible asymptotic coset-cover exponent if for every \(\varepsilon > 0\) there is \(K_0 \ge 1\) such that for every real \(K \ge K_0\), every \(n \in \mathbb{N}\) and every nonempty finite set \(A \subseteq \mathbb{F}_2^n\) with \(|A + A| \le K|A|\), there is a subspace \(H\) of \(\mathbb{F}_2^n\) with \(|H| \le |A|\) such that \(A\) is covered by at most \(K^{C + \varepsilon}\) translates of \(H\). The Marton coset-cover exponent is the infimum in \(\mathbb{R}\) of the set of admissible exponents, with the convention that this infimum is \(0\) when the set is empty or unbounded below.
