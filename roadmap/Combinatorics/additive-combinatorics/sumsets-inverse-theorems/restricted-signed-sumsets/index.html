    DefinitionRestricted sumset#✓fully proved

    MetaMathlibExt.restrictedSumset

    For a natural number \(h\) and a finite subset \(A\) of an additive commutative monoid \(G\), the restricted sumset \(h^{\wedge} A\) is the set of all sums \(\sum_{a \in B} a\) with \(B\) an \(h\)-element subset of \(A\), that is, the sums of \(h\) distinct elements of \(A\). In particular \(0^{\wedge} A = \{0\}\).

    The source works in the integers; here \(G\) is an arbitrary additive commutative monoid.

    public def restrictedSumset {G : Type*} [AddCommMonoid G] [DecidableEq G] (h : ℕ)
    (A : Finset G) : Finset G :=
  (A.powersetCard h).image (fun B => ∑ a ∈ B, a)

    DefinitionRestricted signed sumset#✓fully proved

    MetaMathlibExt.restrictedSignedSumset

    For a natural number \(h\) and a finite set \(A\) of integers, the restricted signed sumset \(h^{\wedge}_{\pm} A\) is the set of all integers \(\sum_{a \in B} a - 2 \sum_{a \in N} a\), where \(B\) ranges over the \(h\)-element subsets of \(A\) and \(N\) ranges over the subsets of \(B\). These are the sums of the elements of \(B\) in which the elements of \(N\) are given a negative sign.

    public def restrictedSignedSumset (h : ℕ) (A : Finset ℤ) : Finset ℤ :=
  ((A.powersetCard h).sigma (fun B => B.powerset)).image
    (fun p => ∑ a ∈ p.1, a - 2 * ∑ a ∈ p.2, a)
