    Possible sizes of h-fold sumsets

    DefinitionTrivial elements of an \(h\)-fold sumset#✓fully proved

    MetaMathlibExt.sumsetTrivialElements

    Let \(G\) be an additive commutative monoid, let \(h, k \in \mathbb{N}\) and let \(a \colon \mathbb{N} \to G\) list the set \(A = \{a_0, a_1, \dots, a_{k-1}\}\); write \(n x\) for the \(n\)-fold sum \(x + \dots + x\). The trivial elements of the \(h\)-fold sumset \(hA\) form the finite set that is empty when \(k = 0\) and otherwise consists of \(h a_0\) together with the sums \((h - i) a_j + i a_{j+1}\) for all natural numbers \(i \le h\) and \(j\) with \(j + 1 < k\). An element of \(hA\) that is not trivial is called nontrivial.

    These are the sums obtained by moving one summand at a time from each element to the next. When \(k \ge 1\) and \(a_0 < a_1 < \dots < a_{k-1}\) in a linearly ordered additive group (the paper's setting) they form an increasing list of \(hk - h + 1\) distinct sums; for an arbitrary \(a\) they may coincide (for example \(a = 0\) and \(h = k = 2\) give a single element). The sum \(h a_0\) is listed separately so that for \(k = 1\) the single sum \(h a_0\) is trivial, as in the paper's list.

    public def sumsetTrivialElements {G : Type*} [AddCommMonoid G] [DecidableEq G]
    (h k : ℕ) (a : ℕ → G) : Finset G :=
  if k = 0 then ∅
  else insert (h • a 0) ((Finset.range (k - 1) ×ˢ Finset.range (h + 1)).image
    fun p => (h - p.2) • a p.1 + p.2 • a (p.1 + 1))

    TheoremCharacterization of the trivial elements#✓fully proved

    MetaMathlibExt.mem_sumsetTrivialElements_iff

    Let \(G\) be an additive commutative monoid, \(a_0, a_1, \ldots\) a sequence in \(G\), and \(h, k\) natural numbers. An element \(x \in G\) is a trivial element of the \(h\)-fold sumset of \(a_0, \ldots, a_{k-1}\) if and only if either \(k > 0\) and \(x = h a_0\), or \(x = (h - i)a_j + i a_{j+1}\) for some natural numbers \(j\) and \(i\) with \(j + 1 < k\) and \(i \le h\).

    MetaMathlibExt.card_nsmul_notMem_Icc_of_isAddTorsionFree

    Let \(G\) be a torsion-free additive commutative group and let \(h\) and \(k \ge 4\) be natural numbers. For every \(k\)-element set \(A \subseteq G\), the \(h\)-fold sumset \(hA\) (the set of sums of \(h\) elements of \(A\)) does not satisfy \(hk - h + 2 \le |hA| \le hk - 1\).

    Equivalently, writing \(R_G(h, k)\) for the set of sizes \(|hA|\) of \(k\)-element sets \(A \subseteq G\), \(R_G(h, k) \cap [hk - h + 2, hk - 1] = \emptyset\). The interval is empty for \(h \le 1\).
