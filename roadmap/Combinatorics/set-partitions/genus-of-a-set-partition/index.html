    Genus of a set partition

    DefinitionIncreasing-cycle permutation#✓fully proved

    MetaMathlibExt.IsIncreasingCyclePerm

    A permutation \(\tau\) of \(\{0, \dots, n-1\}\) is an increasing-cycle permutation when, for all \(x\) and \(y\) in \(\{0, \dots, n-1\}\) such that \(\tau(x) \le x\) and \(y\) lies in the same cycle of \(\tau\) as \(x\), we have \(\tau(x) \le y\). That is, whenever \(\tau(x) \le x\), the value \(\tau(x)\) is the least element of the cycle of \(x\); equivalently, each cycle of \(\tau\) runs through its elements in increasing order and returns from the largest to the least.

    Set partitions of \(\{0, \dots, n-1\}\) correspond bijectively to increasing-cycle permutations, the blocks being the cycles (fixed points give singleton blocks), and partitions are counted through this encoding.

    def IsIncreasingCyclePerm {n : ℕ} (τ : Perm (Fin n)) : Prop :=
  ∀ x y, τ x ≤ x → τ.SameCycle x y → τ x ≤ y

    DefinitionGenus of a set partition#✓fully proved

    MetaMathlibExt.setPartitionGenus

    Let \(\sigma\) be the cyclic permutation \(i \mapsto i + 1 \pmod n\) of \(\{0, \dots, n-1\}\). For a permutation \(\tau\) of \(\{0, \dots, n-1\}\), thought of as encoding the set partition whose blocks are its cycles, let \(|\alpha|\) be the number of cycles of \(\tau\) and \(c\) the number of cycles of \(\sigma \circ \tau^{-1}\), fixed points counted as cycles in both. The genus of \(\tau\) is the integer part of \(\frac{1}{2} \max(0,\ n + 1 - |\alpha| - c)\).

    For \(n \ge 1\) the number \(n + 1 - |\alpha| - c\) is nonnegative and even, so the genus is the number \(g\) with \(-2g = |\alpha| - 1 - n + c\); for \(n = 0\) the genus is \(0\).

    def setPartitionGenus {n : ℕ} (τ : Perm (Fin n)) : ℕ :=
  (n + 1 - τ.partition.parts.card - (finRotate n * τ⁻¹).partition.parts.card) / 2

    DefinitionNumber of set partitions of given type and genus#✓fully proved

    MetaMathlibExt.partitionGenusCount

    For natural numbers \(n\) and \(g\) and a multiset \(\alpha\) of natural numbers, \(C_{n,[\alpha]}^{(g)}\) is the number of increasing-cycle permutations \(\tau\) of \(\{0, \dots, n-1\}\) whose multiset of cycle lengths, fixed points counted as cycles of length \(1\), is \(\alpha\) and whose genus is \(g\).

    Through the encoding of set partitions by increasing-cycle permutations, this is the number of set partitions of \(\{0, \dots, n-1\}\) of type \([\alpha]\) (multiset of block sizes \(\alpha\)) and genus \(g\).

    def partitionGenusCount (n : ℕ) (α : Multiset ℕ) (g : ℕ) : ℕ :=
  #{τ : Perm (Fin n) | IsIncreasingCyclePerm τ ∧ τ.partition.parts = α ∧
    setPartitionGenus τ = g}

    Let \(g \ge 1\), and for \(k \ge 0\) let \(C_{2k,[2^k]}^{(g)}\) be the number of genus-\(g\) set partitions of \(\{0, \dots, 2k-1\}\) into \(k\) blocks of size \(2\).     TheoremGenus of two-block partitions#●ready to prove

    MetaMathlibExt.twoBlock_oneFace_and_genus

    Let \(\sigma\) be the cyclic permutation \(i \mapsto i + 1 \pmod n\) of \(\{0, \dots, n-1\}\), and let \(\tau\) be an increasing-cycle permutation of \(\{0, \dots, n-1\}\) with exactly two cycles, fixed points counted as cycles (so \(\tau\) encodes a set partition into two blocks). Then \(\sigma \circ \tau^{-1}\) has exactly one cycle of length at least \(2\). Moreover, for every \(x_0\) in \(\{0, \dots, n-1\}\), if \(B\) is the cycle of \(\tau\) containing \(x_0\) and \(s\) is the number of elements of \(B\) fixed by \(\sigma \circ \tau^{-1}\), then the genus \(g\) of \(\tau\) satisfies \(g + 1 + s = |B|\).

    Taking \(x_0\) in each of the two blocks, of sizes \(p\) and \(n - p\), and writing \(s_1\) and \(s_2\) for the corresponding values of \(s\), gives \(g = p - s_1 - 1 = (n - p) - s_2 - 1\).

    public theorem_wanted twoBlock_oneFace_and_genus {n : ℕ} (τ : Perm (Fin n))
    (hτ : IsIncreasingCyclePerm τ) (h2 : τ.partition.parts.card = 2) (x₀ : Fin n) :
    (finRotate n * τ⁻¹).cycleType.card = 1 ∧
      setPartitionGenus τ + 1 + #{x | τ.SameCycle x₀ x ∧ (finRotate n * τ⁻¹) x = x} =
        #{x | τ.SameCycle x₀ x}

    TheoremGenus count of two-block partitions#●ready to prove

    MetaMathlibExt.partitionGenusCount_twoBlocks

    Let \(n\), \(p\) and \(g\) be natural numbers with \(2 \le p < n\). The number \(C_{n,[p,\,n-p]}^{(g)}\) of genus-\(g\) set partitions of \(\{0, \dots, n-1\}\) into two blocks of sizes \(p\) and \(n - p\) equals

    \[\frac{n}{g+1} \binom{p-1}{g} \binom{n-p-1}{g}\]

    when \(n \ne 2p\), and half of this number when \(n = 2p\).

    public theorem_wanted partitionGenusCount_twoBlocks (n p g : ℕ) (hp : 2 ≤ p) (hpn : p < n) :
    (partitionGenusCount n {p, n - p} g : ℚ) =
      (if n = 2 * p then 1 / 2 else 1) *
        ((n : ℚ) / (g + 1) * ((p - 1).choose g : ℚ) * ((n - p - 1).choose g : ℚ))
    def partitionGenusCount (n : ℕ) (α : Multiset ℕ) (g : ℕ) : ℕ :=
