    MetaMathlibExt.mergedSameBlock

    Let \(P\) be a set partition of \(\{0, \dots, n-1\}\) and let \(i, j, x, y \in \{0, \dots, n-1\}\). Then \(x\) and \(y\) lie in the same block after merging the blocks of \(i\) and \(j\) if either \(x\) and \(y\) lie in the same block of \(P\), or each of \(x\) and \(y\) lies in the block of \(i\) or in the block of \(j\). For singleton blocks \(\{i\}\) and \(\{j\}\) this joins them into the block \(\{i, j\}\).

    def mergedSameBlock {n : ℕ} (P : SetPartition n) (i j x y : Fin n) : Prop :=
  P.part x = P.part y ∨ ((x ∈ P.part i ∨ x ∈ P.part j) ∧ (y ∈ P.part i ∨ y ∈ P.part j))

  Finpartition (Finset.univ : Finset (Fin n))

    DefinitionCrossing after merging two blocks#✓fully proved

    MetaMathlibExt.mergedHasCrossing

    Let \(P\) be a set partition of \(\{0, \dots, n-1\}\) and let \(i, j \in \{0, \dots, n-1\}\). The partition obtained from \(P\) by merging the blocks of \(i\) and \(j\) has a crossing if there are \(a < b < c < d\) in \(\{0, \dots, n-1\}\) such that \(a\) and \(c\) lie in one of its blocks and \(b\) and \(d\) lie in a different one of its blocks.

    def mergedHasCrossing {n : ℕ} (P : SetPartition n) (i j : Fin n) : Prop :=
  ∃ a b c d : Fin n, a < b ∧ b < c ∧ c < d ∧ mergedSameBlock P i j a c ∧
    mergedSameBlock P i j b d ∧ ¬ mergedSameBlock P i j a b
    abbrev SetPartition (n : ℕ) :=
  Finpartition (Finset.univ : Finset (Fin n))

    DefinitionMarriageable singles partition#✓fully proved

    MetaMathlibExt.IsMarriageableSingles

    A set partition \(P\) of \(\{0, \dots, n-1\}\) is a marriageable singles partition if it has two distinct singleton blocks \(\{i\}\) and \(\{j\}\) such that the partition obtained from \(P\) by joining them into the block \(\{i, j\}\) has no crossing.

    def IsMarriageableSingles {n : ℕ} (P : SetPartition n) : Prop :=
  ∃ i j : Fin n, i ≠ j ∧ P.part i = {i} ∧ P.part j = {j} ∧ ¬ mergedHasCrossing P i j

    For integers \(a\) and \(b\), the zero-extended binomial coefficient \(\binom{a}{b}\) is the usual binomial coefficient of \(a\) and \(b\) when \(a \ge 0\) and \(b \ge 0\), and \(0\) otherwise.

    This is the convention under which the paper's formulas "give \(0\)" in the degenerate cases (for example \(\binom{-1}{0} = 0\) in the count of noncrossing partitions of a one-element set with one block and no singleton block).

  if 0 ≤ a ∧ 0 ≤ b then a.toNat.choose b.toNat else 0

    DefinitionLanes with a common point#✓fully proved

    MetaMathlibExt.lanesMeet

    The standard road intersection of size \(n\) has entries \(E_0, \dots, E_{n-1}\) and exits \(X_0, \dots, X_{n-1}\) on a circle, with \(E_i\) at position \(2i\) and \(X_j\) at position \(2j + 1\); the lane \(E_iX_j\) is the chord from \(E_i\) to \(X_j\). Two lanes \(E_iX_j\) and \(E_{i'}X_{j'}\) have a common point if \(i = i'\), or \(j = j'\), or exactly one of the positions \(2i'\) and \(2j' + 1\) lies strictly between \(2i\) and \(2j + 1\) (that is, the chords cross).

    def lanesMeet {n : ℕ} (ℓ ℓ' : Fin n × Fin n) : Prop :=
  ℓ.1 = ℓ'.1 ∨ ℓ.2 = ℓ'.2 ∨
    (let lo := min (2 * ℓ.1.val) (2 * ℓ.2.val + 1)
     let hi := max (2 * ℓ.1.val) (2 * ℓ.2.val + 1)
     ((lo < 2 * ℓ'.1.val ∧ 2 * ℓ'.1.val < hi) ↔ ¬ (lo < 2 * ℓ'.2.val + 1 ∧ 2 * ℓ'.2.val + 1 < hi)))

    DefinitionMaximal set of lanes#✓fully proved

    MetaMathlibExt.IsMaximalSetOfLanes

    In the standard road intersection of size \(n\), the lane \(E_iX_j\) joins the entry \(E_i\) to the exit \(X_j\), for \(i, j \in \{0, \dots, n-1\}\). Given a set \(A\) of allowed lanes, a set \(S\) of lanes is a maximal set of lanes (MSL) among \(A\) if \(S \subseteq A\), no two distinct lanes of \(S\) have a common point, and every lane of \(A\) not in \(S\) has a common point with some lane of \(S\). The standard road intersection allows every lane; the restricted one forbids the U-turns \(E_iX_i\).

    def IsMaximalSetOfLanes {n : ℕ} (allowed S : Finset (Fin n × Fin n)) : Prop :=
  S ⊆ allowed ∧ (∀ ℓ ∈ S, ∀ ℓ' ∈ S, ℓ ≠ ℓ' → ¬ lanesMeet ℓ ℓ') ∧
    ∀ ℓ ∈ allowed, ℓ ∉ S → ∃ ℓ' ∈ S, lanesMeet ℓ ℓ'
