    DefinitionSurjective restricted-growth strings#✓fully proved

    MetaMathlibExt.IsSurjectiveRestrictedGrowthString

    A word \(w = w_0 w_1 \cdots w_{n-1}\) of length \(n\) with letters in \(\{0, 1, \dots, k-1\}\) is a surjective restricted-growth string if every letter \(0, \dots, k-1\) occurs in \(w\) and, for every position \(i\) and every letter \(m < w_i\), some position \(j < i\) has \(w_j = m\).

    def IsSurjectiveRestrictedGrowthString {n k : ℕ} (w : Fin n → Fin k) : Prop :=
  Function.Surjective w ∧
    ∀ i : Fin n, ∀ m : Fin k,
      m.val < (w i).val → ∃ j : Fin n, j.val < i.val ∧ w j = m

    TheoremPeak generating function for set partitions#✓fully proved

    MetaMathlibExt.peak_generating_function_set_partitions

    Let \(k \ge 1\). Work in the fraction field of the ring \(\mathbb{Z}[q][[x]]\) of power series in \(x\) with coefficients in \(\mathbb{Z}[q]\). For a word \(w = w_0 \cdots w_{n-1}\), let \(\mathrm{pk}(w)\) be the number of positions \(a\) with \(a + 2 < n\) and \(w_a < w_{a+1} > w_{a+2}\), and let \(W_{n,k}\) be the set of surjective restricted-growth strings of length \(n\) with letters in \(\{0, \dots, k-1\}\). Let \(t = 1 + x^2 (1-q)/2\), let \(U_m = U_m(t)\) for \(m \in \mathbb{Z}\), where \(U_m\) is the Chebyshev polynomial of the second kind extended to negative indices by its recurrence (so \(U_{-1} = 0\) and \(U_{-2} = -1\)), and let \(R_j = (U_j - U_{j-1})/(U_{j-1} - U_{j-2})\). Then

    \[\sum_{n \ge 0} \sum_{w \in W_{n,k}} q^{\mathrm{pk}(w)} x^n = x^k (1-q)^k \prod_{j=1}^{k} \frac{1 + x + x^2 (1-q) - R_j}{1 + x (1-q) - R_j}.\]

    Set partitions of \(\{1, \dots, n\}\) with \(k\) blocks are encoded by the strings in \(W_{n,k}\), and \(\mathrm{pk}(w)\) counts the peaks of the encoded partition. Division is total in the fraction field, so the statement carries no nonvanishing hypotheses.

    Proof: Following Mansour and Shattuck, Lemmas 2.1, 2.2, and 2.6 and Theorem 2.7, the proof combines first-occurrence decompositions with the Chebyshev recurrence.

    TheoremTotal number of peaks over set partitions#✓fully proved

    MetaMathlibExt.total_peaks_canonical

    For natural numbers \(n\) and \(k\), call a word \(\pi = \pi_1 \cdots \pi_n\) on the alphabet \(\{0, \dots, k-1\}\) a restricted growth word if it uses every letter and, for every position \(i\), every letter smaller than \(\pi_i\) occurs among \(\pi_1, \dots, \pi_{i-1}\); these words encode the partitions of \([n]\) into \(k\) blocks. A peak of \(\pi\) is a position \(i\) with \(1 < i < n\) and \(\pi_{i-1} < \pi_i > \pi_{i+1}\). Then the total number of peaks, summed over all restricted growth words of length \(n\) on \(k\) letters, equals

    \[\binom{k}{2} S(n-1, k) + \sum_{j=2}^{k} \left(j \binom{j}{2} - \binom{j+1}{3}\right) \sum_{i=3}^{n-k} j^{i-3}\, S(n-i, k),\]

    where \(S(m, k)\) is the Stirling number of the second kind, \(n - 1\) is read as \(0\) when \(n = 0\), and the inner sum is empty when \(n - k < 3\).

    MetaMathlibExt.total_peaks_canonical · 17 lines 
    theorem total_peaks_canonical (n k : ℕ)
    : (∑ f ∈ Finset.univ.filter (fun f : Fin n → Fin k =>
          Function.Surjective f ∧
          ∀ i : Fin n, ∀ m : Fin k,
            m.val < (f i).val → ∃ j : Fin n, j.val < i.val ∧ f j = m),
        (Finset.univ.filter (fun i : Fin n =>
          i.val ≠ 0 ∧
          if h : i.val + 1 < n then
            (f ⟨i.val - 1, lt_of_le_of_lt (Nat.sub_le i.val 1) i.isLt⟩).val <
                (f i).val ∧
              (f ⟨i.val + 1, h⟩).val < (f i).val
          else False)).card) =
      Nat.choose k 2 * Nat.stirlingSecond (n - 1) k +
        ∑ j ∈ Finset.Icc 2 k,
          (j * Nat.choose j 2 - Nat.choose (j + 1) 3) *
            ∑ i ∈ Finset.Icc 3 (n - k),
              j ^ (i - 3) * Nat.stirlingSecond (n - i) k

    DefinitionNon-symmetric peaks of a word#✓fully proved

    MetaMathlibExt.nonSymmetricPeakCount

    For a word \(w = w_1 w_2 \cdots w_\ell\) of natural numbers, a non-symmetric peak is a position \(i\) with \(1 < i < \ell\) such that \(w_{i-1} < w_i\), \(w_{i+1} < w_i\) and \(w_{i-1} \ne w_{i+1}\). The non-symmetric peak count of \(w\) is the number of such positions; in particular it is \(0\) when \(\ell < 3\).

    A peak with \(w_{i-1} = w_{i+1}\) is a symmetric peak instead.

    def nonSymmetricPeakCount : List ℕ → ℕ
  | a :: b :: c :: t =>
      (if a < b ∧ c < b ∧ a ≠ c then 1 else 0) + nonSymmetricPeakCount (b :: c :: t)
  | _ => 0

    Fix \(k \in \mathbb{N}\) and, for each \(n\), let \(P_{n,k}\) be the set of surjective restricted-growth strings of length \(n\) with letters in \(\{0, \dots, k-1\}\); these encode the partitions of \(\{1, \dots, n\}\) into exactly \(k\) blocks. For \(w \in P_{n,k}\) let \(\operatorname{sp}(w)\) be the number of symmetric peaks of \(w\). In the ring \(\mathbb{Z}[[x]]\) of formal power series let \(F_k(x) = \sum_{n \ge 0} |P_{n,k}| x^n\).     \[ \sum_{n \ge 0} \Big(\sum_{w \in P_{n,k}} \operatorname{sp}(w)\Big) x^n = \max(k - 1, 0)\, x F_k(x) + F_k(x) \sum_{m=1}^{k} \binom{m}{2} \frac{x^3}{1 - m x}, \]

    where \(1/(1 - m x)\) is the inverse of \(1 - m x\) in \(\mathbb{Z}[[x]]\).
