    TheoremMean number of short chords in linear \(k\)-chord diagrams#✓fully proved

    MetaMathlibExt.mean_short_chords_in_linear_k_chord_diagrams

    Let \(k \ge 1\) and \(n \ge 0\) be integers. A linear \(k\)-chord diagram of length \(kn\) is a set of \(n\) subsets of \(\{0, 1, \dots, kn - 1\}\), each with \(k\) elements, whose union is \(\{0, 1, \dots, kn - 1\}\); it is therefore a partition of this set into \(n\) blocks of size \(k\), its chords. A chord is short when it consists of \(k\) consecutive integers \(\{i, i + 1, \dots, i + k - 1\}\). The number of short chords, averaged over all linear \(k\)-chord diagrams of length \(kn\), equals

    \[ \frac{n\,(kn - k + 1)}{\binom{kn}{k}}, \]

    where for \(n = 0\) the denominator \(\binom{0}{k}\) is \(0\) and the quotient is read as \(0\), which is the mean over the single empty diagram.

    For \(n \ge 1\) there are \(kn - k + 1\) sets of \(k\) consecutive integers in \(\{0, \dots, kn - 1\}\). This is the mean theorem, distinct from the same paper's asymptotic Poisson distribution of short chords.

    theorem mean_short_chords_in_linear_k_chord_diagrams
    (k n : ℕ) (hk : 0 < k) :
    let diagrams :=
      ((Finset.range (k * n)).powerset.powerset.filter fun D =>
        D.card = n ∧
          (∀ B ∈ D, B.card = k) ∧
          D.biUnion id = Finset.range (k * n))
    (diagrams.sum fun D =>
        ((((Finset.range (k * n - (k - 1))).filter fun i =>
          Finset.Ico i (i + k) ∈ D).card : ℝ))) /
      diagrams.card =
        (Nat.choose (k * n) k : ℝ)⁻¹ * n * (k * n - (k - 1))

    DefinitionLinear chord diagrams#✓fully proved

    MetaMathlibExt.IsLinearChordDiagram

    A linear chord diagram on the \(2n\) vertices \(0, \dots, 2n-1\), laid out on a line, is encoded by a map \(\sigma\) from \(\{0, \dots, 2n-1\}\) to itself that is a fixed-point-free involution: \(\sigma(i) \ne i\) and \(\sigma(\sigma(i)) = i\) for every vertex \(i\). Vertex \(i\) is joined by a chord to \(\sigma(i)\).

    def IsLinearChordDiagram (n : ℕ) (σ : Fin (2 * n) → Fin (2 * n)) : Prop :=
  ∀ i, σ i ≠ i ∧ σ (σ i) = i

    DefinitionEndpoints of short chords#✓fully proved

    MetaMathlibExt.IsShortChordVertex

    Let \(\sigma\) be a map from \(\{0, \dots, 2n-1\}\) to itself (for a linear chord diagram, vertex \(i\) is joined by a chord to \(\sigma(i)\)). A vertex \(i\) is an endpoint of a short chord of \(\sigma\) when \(\sigma(i) = i - 1\) or \(\sigma(i) = i + 1\), that is, when \(i\) is joined to an adjacent vertex.

    def IsShortChordVertex {n : ℕ} (σ : Fin (2 * n) → Fin (2 * n)) (i : Fin (2 * n)) : Prop :=
  (σ i : ℕ) + 1 = i ∨ (i : ℕ) + 1 = σ i

    DefinitionBubbles#✓fully proved

    MetaMathlibExt.IsBubble

    Let \(\sigma\) be a map from \(\{0, \dots, 2n-1\}\) to itself (for a linear chord diagram, vertex \(i\) is joined by a chord to \(\sigma(i)\)). For natural numbers \(a\) and \(p\), the vertices \(a, a+1, \dots, a+p-1\) form a bubble of size \(p\) in \(\sigma\) when \(p \ge 1\), \(a + p \le 2n\), none of these vertices is an endpoint of a short chord of \(\sigma\), the vertex \(a - 1\) is an endpoint of a short chord unless \(a = 0\), and the vertex \(a + p\) is an endpoint of a short chord unless \(a + p = 2n\).

    So a bubble is a maximal run of consecutive vertices containing no endpoint of a short chord.

    def IsBubble {n : ℕ} (σ : Fin (2 * n) → Fin (2 * n)) (a p : ℕ) : Prop :=
  0 < p ∧ a + p ≤ 2 * n ∧
    (∀ i : Fin (2 * n), a ≤ (i : ℕ) → (i : ℕ) < a + p → ¬ IsShortChordVertex σ i) ∧
    (∀ i : Fin (2 * n), (i : ℕ) + 1 = a → IsShortChordVertex σ i) ∧
    (∀ i : Fin (2 * n), (i : ℕ) = a + p → IsShortChordVertex σ i)

    DefinitionBubble counts#✓fully proved

    MetaMathlibExt.bubbleCount

    For natural numbers \(n\) and \(p\), \(B_{n,p}\) is the total number of bubbles of size \(p\) in all linear chord diagrams on \(2n\) vertices: the sum, over all linear chord diagrams \(\sigma\) on the vertices \(0, \dots, 2n-1\), of the number of vertices \(a\) such that the vertices \(a, a+1, \dots, a+p-1\) form a bubble of size \(p\) in \(\sigma\). In particular \(B_{n,0} = 0\).

    def bubbleCount (n p : ℕ) : ℕ :=
  ∑ σ ∈ Finset.univ.filter (IsLinearChordDiagram n),
    ((Finset.range (2 * n)).filter (fun a => IsBubble σ a p)).card

    MetaMathlibExt.bubbleCount_formal_contour_integral

    Let \(G(s, w, y)\) be the power series in \(\mathbb{Q}[[s, w, y]]\) given by

    \[G = \left(1 - \frac{y^2}{1 - sy + y^2}\right)^{-2} \left(\frac{1}{1 - wsy + w^2y^2} - 1\right),\]

    and write \([s^a w^p y^m]\,G\) for its coefficient of \(s^a w^p y^m\). For integers \(n, p \ge 0\) let \(B_{n,p}\) be the total number of bubbles of size \(p\) in all linear chord diagrams on \(2n\) vertices. Then for all integers \(n, p \ge 0\) (including \(n = 0\))

    \[\sum_{k \ge 0} \frac{(2k)!}{2^k\, k!}\, [s^{2k} w^p y^{2n}]\,G = B_{n,p} \quad\text{and}\quad \sum_{k \ge 0} \frac{(2k)!}{2^k\, k!}\, [s^{2k} w^p y^{2n+1}]\,G = 0.\]

The literal integrals diverge.

    MetaMathlibExt.bubbleCount_formal_laplace_closed_form

    In \(\mathbb{Q}[[t, w, y]]\) let \(D = 1 - w(1 - wy)\) and let \(I(t, w, y)\) be the power series

    \[I = \frac{(1-w)^2 (1-wy)^2}{(1+w^2y)\,D^2} \exp\!\left(\frac{y}{2}\left(\frac{tw}{1+w^2y}\right)^2\right) + \left(\frac{(2 - w(y+2)(1 + y(1 - w(2-wy))))\,wy}{D^2} + \frac{(1-wy)\,t^2 w y^3}{D}\right) \exp\!\left(\frac{t^2 y}{2}\right),\]

    \[\sum_{m \ge 0} m!\, [t^m w^p y^n]\,I = B_{n,p}.\]

    Let \(B_{n,p}\) be the total number of bubbles of size \(p\) over all linear chord diagrams on \(2n\) vertices. Let \(x\) be a real number with \(0 < x \le 2\), and let \((p_n)_{n \ge 0}\) be natural numbers with \(p_0 = 0\), \(p_n \le 2n - 2\) for every \(n \ge 1\), and \(p_n / (n - 1) \to x\) as \(n \to \infty\). Then

    \[\frac{(n-1)\,B_{n,p_n}}{\sum_{p=1}^{2n-2} B_{n,p}} \to \frac{e\,(6-x)}{2\,(4e-2)}\,e^{-x/2}\]

    as \(n \to \infty\). The sum in the denominator leaves out the bubble sizes \(2n - 1\) and \(2n\); a bubble of size \(2n\) is a whole diagram without short chords.

    The paper writes \(B_{n,x(n-1)}\); since \(x(n-1)\) need not be an integer, the limit is read along integer sizes \(p_n\) with \(p_n/(n-1) \to x\), the scaling the paper's proof uses.
