    Finpartition.cardProd

    For a partition \(P\) of a finite set \(s\), a commutative monoid \(R\) and a function \(f : \mathbb{N} \to R\), the block-size product of \(f\) over \(P\) is \(\prod_{B \in P} f(|B|)\), the product over the blocks \(B\) of \(P\) of \(f\) applied to the cardinality of \(B\).

    def cardProd {R : Type*} [CommMonoid R] (P : Finpartition s) (f : ℕ → R) : R :=
  ∏ B ∈ P.parts, f B.card

    TheoremMonoid homomorphisms preserve block-size products#✓fully proved

    Finpartition.cardProd_mapMonoidHom

    Let \(P\) be a partition of a finite set \(s\), let \(R\) and \(S\) be commutative monoids, let \(f : \mathbb{N} \to R\), and let \(g : R \to S\) be a monoid homomorphism. Then \(g\bigl(\prod_{B \in P} f(|B|)\bigr) = \prod_{B \in P} g(f(|B|))\), where both products run over the blocks \(B\) of \(P\).

    theorem cardProd_mapMonoidHom {R S : Type*} [CommMonoid R] [CommMonoid S]
    (P : Finpartition s) (f : ℕ → R) (g : R →* S) :
    g (P.cardProd f) = P.cardProd (g ∘ f)

    DefinitionPull-back of a finite partition along a map#✓fully proved

    Finpartition.comap

    The pull-back of a partition P of the finite type β along a map f : α → β: the blocks are the nonempty preimages f ⁻¹' B of the blocks B of P.

    def comap (f : α → β) (P : Finpartition (univ : Finset β)) : Finpartition (univ : Finset α) :=
  ofExistsUnique ((P.parts.image fun B ↦ univ.filter fun a ↦ f a ∈ B).erase ∅)
    (fun _ _ ↦ subset_univ _)
    (fun a _ ↦ by
      obtain ⟨B, ⟨hB, hfa⟩, hu⟩ := P.existsUnique_mem (mem_univ (f a))
      refine ⟨univ.filter fun x ↦ f x ∈ B, ⟨?_, by simp [hfa]⟩, ?_⟩
      · exact mem_erase.2 ⟨ne_empty_of_mem (a := a) (by simp [hfa]), mem_image_of_mem _ hB⟩
      · rintro C ⟨hC, haC⟩
        obtain ⟨B', hB', rfl⟩ := mem_image.1 (mem_erase.1 hC).2
        have : B' = B := hu B' ⟨hB', by simpa using haC⟩
        rw [this])
    (by simp)
