    Noncrossing pair partitions and the Catalan count

    A pair partition of \(\{1, \dots, n\}\) is a set partition all of whose blocks have two elements; it is noncrossing if no two blocks \(\{a, c\}\) and \(\{b, d\}\) interleave as \(a < b < c < d\). There are \(C_k = \frac{1}{k+1}\binom{2k}{k}\) noncrossing pair partitions of \(\{1, \dots, 2k\}\) and none on an odd number of points. This is the combinatorial core of the moment method for Wigner matrices, where the Wigner words that survive in \(\frac{1}{N}\mathbb{E}\operatorname{tr} X_N^{k}\) are indexed by noncrossing pair partitions, and of the free central limit theorem, whose limit moments count the same partitions; both identify the limit law as the semicircle distribution.

    The proof encodes a pair partition by its partner map, a nested fixed-point-free involution, and splits off the block containing the first point: if \(1\) is paired with \(j + 2\), the \(j\) points inside that arc and the points to its right carry independent noncrossing pairings. This gives the Catalan recursion \(M(n+1) = \sum_{j<n} M(j)\,M(n-1-j)\).

    NoncrossingPartition.IsPairPartition

    A set partition \(P\) of \(\{0, \dots, n-1\}\) (a Finpartition of Fin n) is a pair partition if every block of \(P\) has exactly two elements. A pair partition exists only when \(n\) is even, and for \(n = 2k\) the pair partitions are the perfect matchings of \(2k\) points; the noncrossing ones are counted by the Catalan number \(C_k\).

    def IsPairPartition {n : ℕ} (P : SetPartition n) : Prop := ∀ b ∈ P.parts, b.card = 2
    abbrev SetPartition (n : ℕ) :=
  Finpartition (Finset.univ : Finset (Fin n))

    NoncrossingPartition.IsNCMatching

    A function \(f : \mathbb{N} \to \mathbb{N}\) is a noncrossing perfect matching of \(\{0, \dots, n-1\}\) if it maps \(\{0, \dots, n-1\}\) to itself, has no fixed point there, is an involution there (\(f(f(i)) = i\)), is the identity from \(n\) on, and its arcs \(\{a, f(a)\}\) are nested or disjoint: whenever \(a < b < f(a)\), also \(a < f(b) < f(a)\).

    The nested condition is equivalent to the absence of two interleaved arcs \(a < b < f(a) < f(b)\), the crossing condition of a noncrossing partition restricted to blocks of size two. Fixing \(f\) to be the identity outside \(\{0, \dots, n-1\}\) makes two matchings equal exactly when they agree on \(\{0, \dots, n-1\}\).

    structure IsNCMatching (n : ℕ) (f : ℕ → ℕ) : Prop where
  lt : ∀ i < n, f i < n
  ne : ∀ i < n, f i ≠ i
  invol : ∀ i < n, f (f i) = i
  nested : ∀ a b, a < b → b < f a → a < f b ∧ f b < f a
  fix : ∀ i, n ≤ i → f i = i

    NoncrossingPartition.splitEquiv

    Let \(n = j + m + 2\). The noncrossing perfect matchings \(f\) of \(\{0, \dots, n-1\}\) with \(f(0) = j + 1\) are in bijection with pairs \((g, h)\) of noncrossing perfect matchings of \(\{0, \dots, j-1\}\) and of \(\{0, \dots, m-1\}\):

    • \(g(i) = f(i + 1) - 1\) is the matching of the \(j\) points \(1, \dots, j\) strictly inside the arc \(\{0, j+1\}\), shifted down by one;
    • \(h(i) = f(i + j + 2) - (j + 2)\) is the matching of the \(m\) points \(j + 2, \dots, n - 1\) to the right of the arc, shifted down by \(j + 2\).

    The noncrossing condition is what makes this work: a point strictly inside the arc \(\{0, f(0)\}\) is matched inside it, and so a point to its right is matched to its right. The inverse glues \(g\) and \(h\) back around the arc \(\{0, j+1\}\).

    TheoremCatalan recursion for noncrossing matchings#✓fully proved

    NoncrossingPartition.card_ncMatching_succ

    Writing \(M(n)\) for the number of noncrossing perfect matchings of \(\{0, \dots, n-1\}\), $\(M(n + 1) = \sum_{j=0}^{n-1} M(j)\, M(n - 1 - j).\)$ The point \(0\) is matched to some \(j + 1\) with \(0 \le j < n\), and splitting off the arc \(\{0, j + 1\}\) leaves independent noncrossing matchings of the \(j\) points inside it and of the \(n - 1 - j\) points to its right.

    This is the recursion that Anderson, Guionnet and Zeitouni use for all noncrossing partitions (cut at the largest element in the block of \(1\)), restricted to pairings.

    theorem card_ncMatching_succ (n : ℕ) :
    Nat.card (NCMatching (n + 1)) =
      ∑ j ∈ range n, Nat.card (NCMatching j) * Nat.card (NCMatching (n - 1 - j))
    def NCMatching (n : ℕ) := {f : ℕ → ℕ // IsNCMatching n f}

    TheoremCounting noncrossing perfect matchings#✓fully proved

    NoncrossingPartition.card_ncMatching

    The number of noncrossing perfect matchings of \(\{0, \dots, n-1\}\) is \(C_{n/2}\) when \(n\) is even and \(0\) when \(n\) is odd; in particular there is exactly one (empty) matching of the empty set.

    Proof: by strong induction from the Catalan recursion. For \(n + 1 = 2k + 1\) odd, in each term \(M(j)M(2k - 1 - j)\) one of \(j\) and \(2k - 1 - j\) is odd, so the sum vanishes. For \(n + 1 = 2k + 2\), only even \(j = 2a\) contribute, giving \(\sum_{a=0}^{k} C_a C_{k-a} = C_{k+1}\), Segner's recursion for the Catalan numbers (Mathlib's catalan_succ).

    theorem card_ncMatching (n : ℕ) :
    Nat.card (NCMatching n) = if n % 2 = 0 then catalan (n / 2) else 0
    def NCMatching (n : ℕ) := {f : ℕ → ℕ // IsNCMatching n f}

    DefinitionPartner map of a pair partition#✓fully proved

    NoncrossingPartition.pairPartner

    For a set partition \(P\) of \(\{0, \dots, n-1\}\) and \(i < n\), the partner of \(i\) is \(\bigl(\sum_{x \in B(i)} x\bigr) - i\), where \(B(i)\) is the block of \(i\); for \(i \ge n\) it is \(i\). When \(P\) is a pair partition, \(B(i) = \{i, j\}\) with \(j \ne i\), so the partner of \(i\) is \(j\). The sum formula makes the map total without choosing an element.

    def pairPartner (P : SetPartition n) (i : ℕ) : ℕ :=
  if h : i < n then (∑ x ∈ P.part ⟨i, h⟩, (x : ℕ)) - i else i

    NoncrossingPartition.pairPartitionEquivNCMatching

    The partner map is a bijection from the noncrossing pair partitions of \(\{0, \dots, n-1\}\) to the noncrossing perfect matchings of \(\{0, \dots, n-1\}\), with inverse the pair partition of a matching.

    The two noncrossing conditions agree: two blocks \(\{a, c\}\) and \(\{b, d\}\) of a pair partition cross (\(a < b < c < d\)) exactly when the partner map \(f\) has \(a < b < f(a) < f(b)\), and the nested condition fails at \((a, b)\) exactly when \(f(b) < a\) (a crossing \(f(b) < a < b < f(a)\)) or \(f(b) > f(a)\).

    NoncrossingPartition.card_noncrossing_pairPartition_two_mul

    For every \(k \ge 0\), the number of noncrossing partitions of \(\{1, \dots, 2k\}\) all of whose blocks have two elements is $\(C_k = \frac{1}{k+1}\binom{2k}{k},\)$ Mathlib's catalan k.
