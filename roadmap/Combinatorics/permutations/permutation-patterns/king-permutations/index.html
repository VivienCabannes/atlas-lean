    MetaMathlibExt.IsKingPerm

    A permutation \(\sigma\) of \(\{0, 1, \dots, n - 1\}\) is a king permutation if adjacent entries never differ by exactly \(1\): for every position \(i\) with \(i + 1 < n\), neither \(\sigma(i + 1) = \sigma(i) + 1\) nor \(\sigma(i) = \sigma(i + 1) + 1\). Equivalently, \(|\sigma(i + 1) - \sigma(i)| > 1\) for all adjacent positions \(i\) and \(i + 1\).

    def IsKingPerm {n : ℕ} (σ : Equiv.Perm (Fin n)) : Prop :=
  ∀ i j : Fin n, (j : ℕ) = i + 1 → (σ i : ℕ) + 1 ≠ σ j ∧ (σ j : ℕ) + 1 ≠ σ i
