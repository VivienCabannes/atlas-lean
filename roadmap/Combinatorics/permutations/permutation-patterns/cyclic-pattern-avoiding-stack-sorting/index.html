    MetaMathlibExt.SameRelativeOrder

    Two finite sequences \(s = s_1 \cdots s_\ell\) and \(p = p_1 \cdots p_m\) of natural numbers have the same relative order if \(\ell = m\) and, for all \(1 \le i, j \le m\), \(s_i < s_j\) holds if and only if \(p_i < p_j\).

    def SameRelativeOrder (s p : List ℕ) : Prop :=
  s.length = p.length ∧
    ∀ i < p.length, ∀ j < p.length, (s.getD i 0 < s.getD j 0 ↔ p.getD i 0 < p.getD j 0)

    DefinitionRestricted stack-sorting from a given stack#✓fully proved

    MetaMathlibExt.restrictedStackSortAux

    Fix a property of finite sequences of natural numbers, called bad. Given an input sequence \(\pi\) and a stack (listed from top to bottom), read \(\pi\) from left to right. Before pushing the next entry \(x\), pop the least number \(k\) of entries from the top of the stack such that the remaining stack with \(x\) pushed on top, read from top to bottom, is not bad (if there is no such \(k\), the whole stack is popped and \(x\) is pushed anyway); popped entries are appended to the output in the order they are removed. When the input is exhausted, the remaining stack is appended to the output from top to bottom. The map returns this output.

    def restrictedStackSortAux (bad : List ℕ → Prop) [DecidablePred bad] :
    List ℕ → List ℕ → List ℕ
  | [], st => st
  | x :: xs, st =>
      let k := ((List.range (st.length + 1)).find? fun k => !decide (bad (x :: st.drop k))).getD
        st.length
      st.take k ++ restrictedStackSortAux bad xs (x :: st.drop k)

    DefinitionWest's stack-sorting map#✓fully proved

    MetaMathlibExt.westStackSort

    For a finite sequence \(\pi\) of natural numbers, \(s(\pi)\) is computed with a stack that starts empty. The entries of \(\pi\) are read from left to right; before the next entry \(x\) is pushed, the fewest entries are popped from the top of the stack so that the stack with \(x\) on top, read from top to bottom, avoids the pattern \(21\), and the popped entries are appended to the output in the order in which they are popped. After the last entry has been pushed, the stack is emptied from top to bottom onto the output.

    def westStackSort (π : List ℕ) : List ℕ :=
  restrictedStackSortAux (fun st => ContainsPatternSeq st [2, 1]) π []

    DefinitionCyclic-pattern-avoiding stack-sorting map#✓fully proved

    MetaMathlibExt.cyclicStackSort

    For a finite sequence \(\sigma\) of natural numbers, the map \(s_{[\sigma]}\) sends a finite sequence \(\pi\) of natural numbers to the output of the following procedure. Read \(\pi\) from left to right, starting with an empty stack. Before pushing the next entry \(x\), pop the fewest entries from the top of the stack such that the stack with \(x\) pushed on top, read from top to bottom, contains no rotation of \(\sigma\) as a pattern (if even the stack holding only \(x\) contains one, the whole stack is popped and \(x\) is pushed anyway); popped entries are appended to the output in the order they are removed. Once \(\pi\) is exhausted, the remaining stack is appended to the output from top to bottom. Here a sequence \(w\) contains \(p = p_1 \cdots p_m\) as a pattern when some subsequence \(w_1' \cdots w_m'\) of \(w\) satisfies \(w_i' < w_j' \iff p_i < p_j\) for all \(1 \le i, j \le m\).

    def cyclicStackSort (σ π : List ℕ) : List ℕ :=
  restrictedStackSortAux (fun st => ∃ p ∈ σ.cyclicPermutations, ContainsPatternSeq st p) π []

    DefinitionConsecutive-cyclic-pattern-avoiding stack-sorting map#✓fully proved

    MetaMathlibExt.consecutiveCyclicStackSort

    For a sequence \(\sigma\), the map \(s^{[\sigma]}\) sends a sequence \(\pi\) of natural numbers to the output of the following stack procedure. Read \(\pi\) from left to right, starting with an empty stack. Before pushing the next entry \(x\), pop the fewest entries from the top of the stack, sending them to the output in the order they are removed, so that the stack with \(x\) on top, read from top to bottom, contains no rotation of \(\sigma\) as a consecutive pattern (a block of adjacent entries with the same length and relative order as the rotation); if no number of pops achieves this, pop the whole stack. Then push \(x\). When the input is exhausted, pop the stack from top to bottom onto the output.

  restrictedStackSortAux

    DefinitionStandardization#✓fully proved

    MetaMathlibExt.standardizeSeq

    The standardization \(\mathrm{st}(s)\) of a finite sequence \(s = s_1 s_2 \cdots s_k\) of natural numbers is obtained by replacing each entry \(s_i\) by the number of indices \(j\) with \(s_j \le s_i\). When the entries of \(s\) are distinct, this number is the rank of \(s_i\): the \(r\)th smallest entry becomes \(r\).

    def standardizeSeq (s : List ℕ) : List ℕ :=
  s.map fun x => (s.filter (· ≤ x)).length

    DefinitionHeads of runs of consecutive integers#✓fully proved

    MetaMathlibExt.consecutiveRunHeads

    Given an optional previous entry \(y\) and a sequence \(s_1 s_2 \cdots s_\ell\) of natural numbers, this lists, in order, the entries \(s_i\) with \(s_i \ne s_{i-1} + 1\), where \(s_0 = y\); if there is no previous entry, \(s_1\) is always listed. With no previous entry, these are the minima \(a\) of the maximal blocks \(a, a + 1, \dots, a + k\) of adjacent consecutive integers of the sequence.

    def consecutiveRunHeads : Option ℕ → List ℕ → List ℕ
  | _, [] => []
  | none, x :: xs => x :: consecutiveRunHeads (some x) xs
  | some y, x :: xs => (if x = y + 1 then [] else [x]) ++ consecutiveRunHeads (some x) xs

    DefinitionReduction of a sequence#✓fully proved

    MetaMathlibExt.reductionSeq

    The reduction \(\operatorname{red}(s)\) of a finite sequence \(s\) of natural numbers is obtained in two steps. First, every maximal block of adjacent entries of the form \(a, a + 1, \ldots, a + k\) is replaced by its first entry \(a\). Then the resulting sequence is standardized: each of its entries \(x\) is replaced by the number of its entries that are at most \(x\), which for distinct entries is the rank of \(x\).

    def reductionSeq (s : List ℕ) : List ℕ :=
  standardizeSeq (consecutiveRunHeads none s)
    def standardizeSeq (s : List ℕ) : List ℕ :=
  s.map fun x => (s.filter (· ≤ x)).length

    DefinitionPush order of the superimpose operation#✓fully proved

    MetaMathlibExt.superimposePush

    For finite sequences \(a\) and \(b\) of natural numbers, \(\mathrm{push}(a, b)\) is the sequence obtained by taking the first entry of \(b\), then the next two entries of \(a\) (only one if just one is left), and repeating; once one of the two sequences is exhausted, the remaining entries of the other follow in order.

    For finite sequences \(\sigma_1\) and \(\sigma_2\) with reversals \(\mathrm{rev}\,\sigma_1\) and \(\mathrm{rev}\,\sigma_2\), the sequence \(\mathrm{push}(\mathrm{rev}\,\sigma_1, \mathrm{rev}\,\sigma_2)\) is the order in which the superimpose operation \(\mathrm{si}(\sigma_1, \sigma_2)\) pushes the entries of \(\sigma_1\) and \(\sigma_2\) onto its stack.

    def superimposePush : List ℕ → List ℕ → List ℕ
  | a, [] => a
  | a, y :: b => if a = [] then y :: b else y :: (a.take 2 ++ superimposePush (a.drop 2) b)

    DefinitionThe permutation \(\xi_n\)#✓fully proved

    MetaMathlibExt.xiPermutation

    For a natural number \(n\), \(\xi_n\) is the sequence listing the elements of \(\{1, \dots, n\}\) whose parity differs from that of \(n\) in increasing order, followed by the elements with the same parity as \(n\) in increasing order. Thus \(\xi_n = 1, 3, \dots, n-1, 2, 4, \dots, n\) for even \(n\), and \(\xi_n = 2, 4, \dots, n-1, 1, 3, \dots, n\) for odd \(n\).

    def xiPermutation (n : ℕ) : List ℕ :=
  (List.range' 1 n).filter (fun i => i % 2 ≠ n % 2) ++
    (List.range' 1 n).filter (fun i => i % 2 = n % 2)
