    MetaMathlibExt.IsWeakAscentSeq

    A word \(a_1 a_2 \cdots a_n\) over \(\mathbb{N}\) is a weak ascent sequence if either \(n = 0\), or \(a_1 = 0\) and \(a_i \le 1 + \operatorname{wasc}(a_1 \cdots a_{i-1})\) for every \(2 \le i \le n\), where \(\operatorname{wasc}(u)\) is the number of weak ascents of \(u\), that is, of positions \(j\) with \(u_j \le u_{j+1}\).

    public def IsWeakAscentSeq (w : List ℕ) : Prop :=
  (∀ h : 0 < w.length, w[0]'h = 0) ∧

    MetaMathlibExt.ContainsPattern

    A word \(w\) over \(\mathbb{N}\) contains a pattern \(p\) (another word over \(\mathbb{N}\)) if \(w\) has a subsequence \(s\), not necessarily contiguous, of the same length as \(p\) that is order-isomorphic to \(p\): for all positions \(i\) and \(j\), \(s_i < s_j\) if and only if \(p_i < p_j\).

    public def ContainsPattern (w p : List ℕ) : Prop :=
  ∃ s : List ℕ, s.Sublist w ∧ s.length = p.length ∧
    ∀ i < p.length, ∀ j < p.length, (s.getD i 0 < s.getD j 0 ↔ p.getD i 0 < p.getD j 0)
