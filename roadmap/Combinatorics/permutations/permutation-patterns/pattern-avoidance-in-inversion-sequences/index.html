    DefinitionContainment of a length-3 pattern#✓fully proved

    MetaMathlibExt.InvSeqContainsPattern

    A sequence \(e = e_0 e_1 \cdots e_{n-1}\) of natural numbers contains the length-3 pattern \(p = p_0 p_1 p_2\) of natural numbers when there are positions \(i_0 < i_1 < i_2\) in \(\{0, \dots, n - 1\}\) such that, for all \(a, b \in \{0, 1, 2\}\), \(e_{i_a} < e_{i_b}\) if and only if \(p_a < p_b\); that is, the subsequence \(e_{i_0} e_{i_1} e_{i_2}\) is order-isomorphic to \(p\).

    def InvSeqContainsPattern {n : ℕ} (e : Fin n → ℕ) (p : Fin 3 → ℕ) : Prop :=
  ∃ f : Fin 3 ↪o Fin n, ∀ a b, e (f a) < e (f b) ↔ p a < p b

    DefinitionNumber of inversion sequences avoiding a set of patterns#✓fully proved

    MetaMathlibExt.invSeqAvoidCount

    An inversion sequence of length \(n\) is a sequence \(e = e_0 e_1 \cdots e_{n-1}\) of natural numbers with \(e_i \le i\) for every \(i\). It contains a length-3 pattern \(p = p_0 p_1 p_2\) (a triple of natural numbers) when some subsequence \(e_a e_b e_c\) with \(a < b < c\) is order-isomorphic to \(p\). For a set \(B\) of length-3 patterns, \(|I_n(B)|\) is the number of inversion sequences of length \(n\) that contain no pattern of \(B\).

    noncomputable def invSeqAvoidCount (B : Set (Fin 3 → ℕ)) (n : ℕ) : ℕ :=
  Nat.card {e : Fin n → ℕ // (∀ i, e i ≤ i) ∧ ∀ p ∈ B, ¬ InvSeqContainsPattern e p}
