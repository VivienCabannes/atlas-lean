    MetaMathlibExt.wordRunStart

    Position \(i\) of a word \(w = w_0 w_1 \cdots w_{m-1}\) of natural numbers starts a run when \(i = 0\) or the letter before it is larger, that is, \(w_{i-1} > w_i\). Runs are the maximal contiguous weakly increasing subwords, so these are exactly the positions where a run begins.

    def wordRunStart {m : ℕ} (w : Fin m → ℕ) (i : Fin m) : Prop :=
  i.val = 0 ∨ ∃ j : Fin m, j.val + 1 = i.val ∧ w i < w j

    DefinitionFlattened words#✓fully proved

    MetaMathlibExt.IsFlattenedWord

    A word \(w = w_1 w_2 \cdots w_m\) of natural numbers is flattened when the leading letters of its runs, read left to right, are weakly increasing. Here a run is a maximal contiguous weakly increasing subword, so position \(i\) starts a run when \(i = 1\) or \(w_{i-1} > w_i\); the condition is that \(w_i \le w_j\) whenever \(i < j\) and both positions start runs.

    def IsFlattenedWord {m : ℕ} (w : Fin m → ℕ) : Prop :=
  ∀ i j : Fin m, i < j → wordRunStart w i → wordRunStart w j → w i ≤ w j

  i.val = 0 ∨ ∃ j : Fin m, j.val + 1 = i.val ∧ w i < w j

    DefinitionType \(B\) set partitions#✓fully proved

    MetaMathlibExt.IsTypeBSetPartition

    For a natural number \(n\), a set partition \(P\) of the integer interval \([-n, n] = \{-n, \dots, n\}\) is of type \(B\) if for every block \(\beta\) of \(P\) the set \(-\beta = \{-x : x \in \beta\}\) is again a block of \(P\), and exactly one block \(\beta\) of \(P\) satisfies \(-\beta = \beta\).

    def IsTypeBSetPartition {n : ℕ} (P : Finpartition (Finset.Icc (-(n : ℤ)) n)) : Prop :=
  (∀ b ∈ P.parts, b.image (fun x => -x) ∈ P.parts) ∧
    ∃! b, b ∈ P.parts ∧ b.image (fun x => -x) = b

    MetaMathlibExt.flattenedPermRunCount_recursion

    Let \(f_{n,k}\) be the number of flattened partitions of length \(n\) with exactly \(k\) runs. For all \(n \ge 1\) and \(k \ge 2\),

    \[ f_{n,k} = \sum_{m=1}^{n-2} \left( \binom{n-1}{m} - 1 \right) f_{m,k-1}, \]

    where the sum is empty when \(n \le 2\). Moreover \(f_{n,1} = 1\) for every \(n \ge 1\), and \(f_{n,k} = 0\) whenever \(2 \le n \le k\).
