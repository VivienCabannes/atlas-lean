    DefinitionNumber of left-to-right maxima#✓fully proved

    MetaMathlibExt.permLeftToRightMaxCount

    For a permutation \(\sigma\) of \(\{0, 1, \dots, n-1\}\), \(\mathrm{lmax}(\sigma)\) is the number of positions \(i\) such that \(\sigma(j) < \sigma(i)\) for every position \(j < i\), that is, the number of entries larger than every entry to their left.

    def permLeftToRightMaxCount (σ : Equiv.Perm (Fin n)) : ℕ :=
  (Finset.univ.filter fun i : Fin n => ∀ j : Fin n, j < i → σ j < σ i).card

    TheoremNumber of positions with two successors#✓fully proved

    MetaMathlibExt.card_filter_add_two_lt

    For every natural number \(n\), exactly \(n - 2\) of the positions \(i \in \{0, 1, \dots, n-1\}\) satisfy \(i + 2 < n\), where \(n - 2\) is truncated subtraction (it is \(0\) when \(n < 2\)).

    These are the positions at which a permutation of \(\{0, 1, \dots, n-1\}\) can have a double ascent, a double descent, a peak or a valley.

    theorem card_filter_add_two_lt (n : ℕ) :
    (Finset.univ.filter fun i : Fin n => i.val + 2 < n).card = n - 2

    MetaMathlibExt.ite_isDoubleAscentAt_add_ite_isDoubleDescentAt_add_ite_isPeakAt_add_ite_isValleyAt

    Let \(\sigma\) be a permutation of \(\{0, 1, \dots, n-1\}\) and let \(i\) be a position. If \(i + 2 < n\), then \(i\) is exactly one of a double ascent, a double descent, a peak or a valley of \(\sigma\); otherwise \(i\) is none of them. That is, the number of these four properties that \(i\) has is \(1\) when \(i + 2 < n\) and \(0\) otherwise.

    theorem ite_isDoubleAscentAt_add_ite_isDoubleDescentAt_add_ite_isPeakAt_add_ite_isValleyAt

    ((if IsDoubleAscentAt σ i then 1 else 0) + (if IsDoubleDescentAt σ i then 1 else 0) +
        (if IsPeakAt σ i then 1 else 0) + (if IsValleyAt σ i then 1 else 0) : ℕ) =
      if i.val + 2 < n then 1 else 0
