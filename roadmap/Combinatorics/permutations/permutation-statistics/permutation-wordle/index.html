    MetaMathlibExt.permuteAlong

    Let \(I\) be a subset of \(\{0, \dots, n-1\}\) with \(k\) elements, listed in increasing order as \(i_0 < i_1 < \dots < i_{k-1}\), let \(\sigma\) be a permutation of \(\{0, \dots, k-1\}\), and let \(g\) be a map from \(\{0, \dots, n-1\}\) to itself. Applying \(\sigma\) to \(g\) along \(I\) gives the map that takes the value \(g(i_j)\) at \(i_{\sigma(j)}\) for every \(j < k\) and agrees with \(g\) outside \(I\).

    def permuteAlong {n k : ℕ} (I : Finset (Fin n)) (h : I.card = k) (σ : Equiv.Perm (Fin k))
    (g : Fin n → Fin n) : Fin n → Fin n :=
  fun i => if hi : i ∈ I then g (I.orderIsoOfFin h (σ.symm ((I.orderIsoOfFin h).symm ⟨i, hi⟩))).1
    else g i

    MetaMathlibExt.permWordleNextGuess

    Let \(S\) be a strategy, that is, a permutation \(S_m\) of \(\{0, \dots, m-1\}\) for every \(m\), let \(\pi\) be a permutation of \(\{0, \dots, n-1\}\) (the secret), and let \(g\) be a map from \(\{0, \dots, n-1\}\) to itself (the current guess). Let \(I\) be the set of incorrect positions, the \(k\) with \(g(k) \ne \pi(k)\), and let \(m\) be the number of elements of \(I\). The next guess agrees with \(g\) at every position outside \(I\) and permutes the entries of \(g\) on \(I\) by \(S_m\): writing \(I = \{i_0 < i_1 < \dots < i_{m-1}\}\), it takes the value \(g(i_j)\) at \(i_{S_m(j)}\) for every \(j < m\).

    def permWordleNextGuess {n : ℕ} (S : (m : ℕ) → Equiv.Perm (Fin m)) (π : Equiv.Perm (Fin n))
    (g : Fin n → Fin n) : Fin n → Fin n :=
  permuteAlong (Finset.univ.filter fun k => g k ≠ π k) rfl (S _) g

    MetaMathlibExt.permWordleGuess

    Let \(S\) be a strategy, that is, a permutation \(S_m\) of \(\{0, \dots, m-1\}\) for every \(m\), and let \(\pi\) be a permutation of \(\{0, \dots, n-1\}\). The guesses \(\gamma_1, \gamma_2, \dots\) of permutation Wordle with strategy \(S\) and secret \(\pi\) are the maps from \(\{0, \dots, n-1\}\) to itself defined recursively: \(\gamma_1\) is the identity, and \(\gamma_{r+1}\) is the guess that one round of the game with strategy \(S\) and secret \(\pi\) produces from \(\gamma_r\).     def permWordleGuess {n : ℕ} (S : (m : ℕ) → Equiv.Perm (Fin m)) (π : Equiv.Perm (Fin n)) :
    ℕ → Fin n → Fin n
  | 0 => id
  | r + 1 => permWordleNextGuess S π (permWordleGuess S π r)
