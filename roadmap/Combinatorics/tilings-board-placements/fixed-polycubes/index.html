    DefinitionFace adjacency of lattice cells#✓fully proved

    MetaMathlibExt.faceAdjacent

    Two lattice cells \(x, y \in \mathbb{Z}^d\) are face adjacent when there is an axis \(k\) such that \(x_j = y_j\) for every axis \(j \ne k\) and \(|x_k - y_k| = 1\).

    def faceAdjacent (d : ℕ) (x y : latticeCell d) : Prop :=
  ∃ k : Fin d, (∀ j : Fin d, j ≠ k → x j = y j) ∧ (y k = x k + 1 ∨ x k = y k + 1)

    DefinitionPolycube#✓fully proved

    MetaMathlibExt.isPolycubeCells

    A finite set \(S\) of lattice cells in \(\mathbb{Z}^d\) is a polycube when it is nonempty and any two cells \(x, y \in S\) are joined by a finite sequence of cells of \(S\), starting at \(x\) and ending at \(y\), in which consecutive cells are face adjacent.

    def isPolycubeCells (d : ℕ) (S : Finset (latticeCell d)) : Prop :=
  S.Nonempty ∧ ∀ x ∈ S, ∀ y ∈ S,
    Relation.ReflTransGen
      (fun a b : latticeCell d => faceAdjacent d a b ∧ a ∈ S ∧ b ∈ S) x y

    DefinitionCanonical position of a cell set#✓fully proved

    MetaMathlibExt.isCanonicalCells

    A finite set \(S\) of lattice cells in \(\mathbb{Z}^d\) is in canonical position when, for every axis \(k\), every cell \(x \in S\) has \(x_k \ge 0\) and some cell \(x \in S\) has \(x_k = 0\); that is, the minimum of each coordinate over \(S\) is \(0\).

    def isCanonicalCells (d : ℕ) (S : Finset (latticeCell d)) : Prop :=
  ∀ k : Fin d, (∃ x ∈ S, x k = 0) ∧ ∀ x ∈ S, 0 ≤ x k

    DefinitionProper dimension#✓fully proved

    MetaMathlibExt.properDimension

    The proper dimension of a finite set \(S\) of lattice cells in \(\mathbb{Z}^d\) is the number of axes \(k\) on which \(S\) varies, that is, for which there are cells \(x, y \in S\) with \(x_k \ne y_k\).

    noncomputable def properDimension (d : ℕ) (S : Finset (latticeCell d)) : ℕ :=
  Nat.card { k : Fin d // ∃ x ∈ S, ∃ y ∈ S, x k ≠ y k }

    MetaMathlibExt.fixedPolycube

    For natural numbers \(d\) and \(n\), the fixed \(n\)-cell polycubes in dimension \(d\) are represented by the finite sets \(S\) of lattice cells in \(\mathbb{Z}^d\) that are polycubes (nonempty and connected through face adjacency), have exactly \(n\) cells, and are in canonical position (the minimum of each coordinate over \(S\) is \(0\)).

    def fixedPolycube (d n : ℕ) : Type :=
  { S : Finset (latticeCell d) // isPolycubeCells d S ∧ S.card = n ∧ isCanonicalCells d S }

    TheoremLunnon's dimension decomposition for fixed polycubes#✓fully proved

    MetaMathlibExt.lunnon_fixed_polycube_dimension_decomposition

    Let \(d\) and \(n\) be natural numbers with \(n > 1\), let \(A_d(n)\) be the number of fixed \(n\)-cell polycubes in dimension \(d\), and for each \(i\) let \(\mathrm{DX}(n,i)\) be the number of fixed \(n\)-cell polycubes proper in dimension \(i\). Then

    \[A_d(n) = \sum_{i=1}^{n-1} \binom{d}{i} \, \mathrm{DX}(n,i).\]

    The hypothesis \(n > 1\) is needed: the printed formula omits its domain and fails at \(n = 1\), where the single cell is a polycube proper in dimension \(0\) and so is counted only by the \(i = 0\) term, which the sum excludes. For \(n > 1\) that term vanishes, since \(\mathrm{DX}(n,0) = 0\).

    theorem lunnon_fixed_polycube_dimension_decomposition
    (d n : ℕ) (hn : 1 < n) :
    fixedPolycubeCount d n =
      Finset.sum (Finset.Ico 1 n) (fun i => Nat.choose d i * properFixedPolycubeCount n i)
    noncomputable def fixedPolycubeCount (d n : ℕ) : ℕ :=
  Nat.card (fixedPolycube d n)
