    Let \(e_1 = (1, 0)\) and \(e_2 = (1/2, \sqrt{3}/2)\), and write \(p(i, j) = i e_1 + j e_2\) for integers \(i, j\). A unit triangle is a triple \((i, j, d)\) of integers \(i, j\) and a boolean \(d\): for \(d\) false it is the upward triangle \((i, j)\) with vertices \(p(i, j)\), \(p(i + 1, j)\), \(p(i, j + 1)\), and for \(d\) true it is the downward triangle \((i, j)\) with vertices \(p(i + 1, j)\), \(p(i, j + 1)\), \(p(i + 1, j + 1)\).

    MathlibExt.Combinatorics.CentralLozengeOneThirdAMR122Problem0001Wanted.InHexagon

    Let \(e_1 = (1, 0)\), \(e_2 = (1/2, \sqrt{3}/2)\) and \(p(i, j) = i e_1 + j e_2\), and call the triangles with vertices \(p(i, j), p(i + 1, j), p(i, j + 1)\) and \(p(i + 1, j), p(i, j + 1), p(i + 1, j + 1)\) the upward and the downward unit triangle \((i, j)\). For integers \(a, b, c\), the upward unit triangle \((i, j)\) lies in the \(a, b, c\) hexagon when \(0 \le j \le b + c - 1\), \(-c \le i \le a - 1\) and \(0 \le i + j \le a + b - 1\), and the downward unit triangle \((i, j)\) lies in it when \(0 \le j \le b + c - 1\), \(-c \le i \le a - 1\) and \(-1 \le i + j \le a + b - 2\).

    These are exactly the unit triangles whose three vertices lie in the region of points \(i e_1 + j e_2\) with \(0 \le j \le b + c\), \(-c \le i \le a\) and \(0 \le i + j \le a + b\). For \(a, b, c \ge 0\) this region is the (possibly degenerate) semiregular hexagon with side lengths \(a, b, c, a, b, c\) and vertices \(0\), \(a e_1\), \(a e_1 + b e_2\), \((a - c) e_1 + (b + c) e_2\), \(-c e_1 + (b + c) e_2\) and \(-c e_1 + c e_2\).

    def InHexagon (a b c : ℤ) : LatticeTriangle → Prop
  | (i, j, false) => 0 ≤ j ∧ j ≤ b + c - 1 ∧ -c ≤ i ∧ i ≤ a - 1 ∧ 0 ≤ i + j ∧ i + j ≤ a + b - 1
  | (i, j, true) => 0 ≤ j ∧ j ≤ b + c - 1 ∧ -c ≤ i ∧ i ≤ a - 1 ∧ -1 ≤ i + j ∧ i + j ≤ a + b - 2

    DefinitionUnit triangles sharing an edge#✓fully proved

    MathlibExt.Combinatorics.CentralLozengeOneThirdAMR122Problem0001Wanted.SharesEdge

    The relation between unit triangles \(s\) and \(t\) that holds exactly when \(s\) is an upward triangle \((i, j)\) and \(t\) is one of the downward triangles \((i, j)\), \((i - 1, j)\) and \((i, j - 1)\). These are the three downward triangles that share an edge with the upward triangle \((i, j)\); the relation never holds with \(s\) downward or \(t\) upward.

    def SharesEdge : LatticeTriangle → LatticeTriangle → Prop
  | (i, j, false), (i', j', true) =>
    (i', j') = (i, j) ∨ (i', j') = (i - 1, j) ∨ (i', j') = (i, j - 1)
  | _, _ => False

    DefinitionDual honeycomb graph of a hexagon#✓fully proved

    MathlibExt.Combinatorics.CentralLozengeOneThirdAMR122Problem0001Wanted.hexagonGraph

    For integers \(a, b, c\), the dual graph of the \(a, b, c\) hexagon is the simple graph whose vertices are the unit triangles lying in the \(a, b, c\) hexagon, two of them being adjacent when one is an upward unit triangle \((i, j)\) and the other is one of the downward unit triangles \((i, j)\), \((i - 1, j)\) and \((i, j - 1)\), that is, when they share an edge.

    Its perfect matchings are the lozenge tilings of the hexagon (a lozenge is the union of the two triangles of a matching edge).

    def hexagonGraph (a b c : ℤ) : SimpleGraph {t : LatticeTriangle // InHexagon a b c t} :=
  SimpleGraph.fromRel fun s t => SharesEdge s.1 t.1

    MathlibExt.Combinatorics.CentralLozengeOneThirdAMR122Problem0001Wanted.centralLozengeOneThird

    Let \(e_1 = (1, 0)\) and \(e_2 = (1/2, \sqrt{3}/2)\), write \(p(i, j) = i e_1 + j e_2\), and call the triangles with vertices \(p(i, j), p(i + 1, j), p(i, j + 1)\) and \(p(i + 1, j), p(i, j + 1), p(i + 1, j + 1)\) the upward and the downward unit triangle \((i, j)\). The statement that for every integer \(n \ge 1\), with \(a = c = 2n - 1\) and \(b = 2n\), in the semiregular hexagon with side lengths \(a, b, c, a, b, c\) and vertices \(0\), \(a e_1\), \(a e_1 + b e_2\), \((a - c) e_1 + (b + c) e_2\), \(-c e_1 + (b + c) e_2\) and \(-c e_1 + c e_2\), three times the number of perfect matchings of the dual honeycomb graph of the hexagon (whose vertices are the unit triangles inside the hexagon and whose edges join triangles sharing an edge) that contain the edge joining the upward unit triangle \((0, 2n - 1)\) and the downward unit triangle \((-1, 2n - 1)\) equals the number of all perfect matchings of that graph.

    These two triangles are the innermost ones: the edge they share has the center of the hexagon as its midpoint. Since perfect matchings of the dual graph are lozenge tilings, the statement says that the central location is covered by a lozenge in exactly one third of the lozenge tilings.

    def centralLozengeOneThird : Prop :=
  ∀ n : ℕ, 1 ≤ n →
    3 * Nat.card {M : (hexagonGraph (2 * n - 1) (2 * n) (2 * n - 1)).Subgraph //
        M.IsPerfectMatching ∧ ∀ s t, s.1 = (0, 2 * (n : ℤ) - 1, false) →
          t.1 = (-1, 2 * (n : ℤ) - 1, true) → M.Adj s t} =
      Nat.card {M : (hexagonGraph (2 * n - 1) (2 * n) (2 * n - 1)).Subgraph // M.IsPerfectMatching}

    MathlibExt.Combinatorics.CentralLozengeOneThirdAMR122Problem0001Wanted.centralLozengeOneThird_holds

    Let \(e_1 = (1, 0)\) and \(e_2 = (1/2, \sqrt{3}/2)\), write \(p(i, j) = i e_1 + j e_2\), and call the triangles with vertices \(p(i, j), p(i + 1, j), p(i, j + 1)\) and \(p(i + 1, j), p(i, j + 1), p(i + 1, j + 1)\) the upward and the downward unit triangle \((i, j)\). For every integer \(n \ge 1\), let \(a = c = 2n - 1\) and \(b = 2n\), and consider the semiregular hexagon with side lengths \(a, b, c, a, b, c\) and vertices \(0\), \(a e_1\), \(a e_1 + b e_2\), \((a - c) e_1 + (b + c) e_2\), \(-c e_1 + (b + c) e_2\) and \(-c e_1 + c e_2\), and its dual honeycomb graph, whose vertices are the unit triangles inside the hexagon and whose edges join triangles sharing an edge. Three times the number of perfect matchings of this graph that contain the edge joining the upward unit triangle \((0, 2n - 1)\) and the downward unit triangle \((-1, 2n - 1)\) equals the number of all its perfect matchings. These two triangles are the innermost ones, so, since perfect matchings of the dual graph are lozenge tilings, the central location of the hexagon is covered by a lozenge in exactly one third of its lozenge tilings.

    Resolved true by Ciucu and Krattenthaler and, independently, by Helfgott and Gessel.
