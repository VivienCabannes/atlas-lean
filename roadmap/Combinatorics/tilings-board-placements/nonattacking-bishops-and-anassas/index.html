    DefinitionNonattacking placements#✓fully proved

    MetaMathlibExt.nonattackingPlacements

    Let \(B\) be a board, that is, a finite set of squares \((i, j) \in \mathbb{Z}^2\), let \(M\) be a list of basic moves \(v \in \mathbb{Z}^2\), and let \(k\) be a natural number. The nonattacking placements of \(k\) pieces with basic moves \(M\) on \(B\) are the \(k\)-element subsets \(S \subseteq B\) such that for all distinct squares \(p, q \in S\) and every move \(v \in M\), the difference \(q - p\) is not parallel to \(v\), that is, \((q_1 - p_1) v_2 \ne (q_2 - p_2) v_1\).

    public def nonattackingPlacements (B : Finset (ℤ × ℤ)) (M : List (ℤ × ℤ)) (k : ℕ) :
    Finset (Finset (ℤ × ℤ)) :=
  (B.powersetCard k).filter fun S =>
    ∀ p ∈ S, ∀ q ∈ S, p ≠ q → ∀ v ∈ M, (q.1 - p.1) * v.2 ≠ (q.2 - p.2) * v.1

    MetaMathlibExt.extStirlingSecond

    Knuth's extended Stirling number of the second kind at integers \(n\) and \(k\) is the natural number equal to the Stirling number of the second kind \(S(n, k)\) if \(n \ge 0\) and \(k \ge 0\), equal to the unsigned Stirling number of the first kind \(c(-k, -n)\) if \(n < 0\) and \(k < 0\), and equal to \(0\) otherwise. Here \(c(j, i)\) is the number of permutations of \(j\) elements with exactly \(i\) cycles.

    public def extStirlingSecond (n k : ℤ) : ℕ :=
  if 0 ≤ n ∧ 0 ≤ k then Nat.stirlingSecond n.toNat k.toNat
  else if n < 0 ∧ k < 0 then Nat.stirlingFirst (-k).toNat (-n).toNat
  else 0

    MetaMathlibExt.santosBeta

    For natural numbers \(i\), \(p\), \(q\) and a complex number \(z\), Santos's coefficient \(\beta_i(p, q, z)\) is the complex number

    \[ \beta_i(p, q, z) = 2^{-2q} \sum_{b=\max(0, i-p)}^{q} 2^b \binom{2q-b}{q} \sum_{a=0}^{b} \binom{p+b-q-z}{a} \binom{q+z}{b-a} \binom{a-q}{p+b-i}, \]

    where \(\binom{w}{n} = w(w-1)\cdots(w-n+1)/n!\) for complex \(w\) and natural \(n\).

    public noncomputable def santosBeta (i p q : ℕ) (z : ℂ) : ℂ :=
  1 / 2 ^ (2 * q) *
    ∑ b ∈ Icc (i - p) q, 2 ^ b * ((2 * q - b).choose q : ℂ) *
      ∑ a ∈ range (b + 1),
        Ring.choose ((p : ℂ) + b - q - z) a * Ring.choose ((q : ℂ) + z) (b - a) *
          Ring.choose ((a : ℂ) - q) (p + b - i)
