    Fence tilings and bi-periodic Fibonacci numbers

    DefinitionBi-periodic Fibonacci numbers squared#✓fully proved

    MetaMathlibExt.biPeriodicFibonacciSq

    For elements \(a\) and \(b\) of a field \(K\), the bi-periodic Fibonacci numbers squared \(q^2_n \in K\) (\(n \ge 0\)) are defined by \(q^2_0 = 0\), \(q^2_1 = 1\), \(q^2_2 = a^2\) and, for \(n \ge 3\),

    \[ q^2_n = \frac{a}{b}(ab+1)\,q^2_{n-1} + (ab+1)\,q^2_{n-2} - \frac{a}{b}\,q^2_{n-3} \]

    if \(n\) is even, and

    \[ q^2_n = \frac{b}{a}(ab+1)\,q^2_{n-1} + (ab+1)\,q^2_{n-2} - \frac{b}{a}\,q^2_{n-3} \]

    if \(n\) is odd.

    Division by zero gives \(0\), so the sequence is defined for all \(a\) and \(b\).

    def biPeriodicFibonacciSq {K : Type*} [Field K] (a b : K) : ℕ → K
  | 0 => 0
  | 1 => 1
  | 2 => a ^ 2
  | n + 3 =>
    if Even (n + 3) then
      a / b * (a * b + 1) * biPeriodicFibonacciSq a b (n + 2) +
        (a * b + 1) * biPeriodicFibonacciSq a b (n + 1) - a / b * biPeriodicFibonacciSq a b n
    else
      b / a * (a * b + 1) * biPeriodicFibonacciSq a b (n + 2) +
        (a * b + 1) * biPeriodicFibonacciSq a b (n + 1) - b / a * biPeriodicFibonacciSq a b n

    DefinitionFence tilings of a board#✓fully proved

    MetaMathlibExt.fenceTilings

    Number the half-cells of an \(n\)-board \(0, \dots, 2n - 1\). The tilings of the \(n\)-board by half-squares and \((1/2, 1/2)\)-fences are encoded as the sets \(F\) of fence positions \(k < 2n - 2\) (the fence at \(k\) has posts on half-cells \(k\) and \(k + 2\)) whose posts are pairwise disjoint, that is, \(k + 2 \notin F\) for every \(k \in F\).

    def fenceTilings (n : ℕ) : Finset (Finset ℕ) :=
  (range (2 * n - 2)).powerset.filter fun F => ∀ k ∈ F, k + 2 ∉ F

    DefinitionWeight of a fence tiling#✓fully proved

    MetaMathlibExt.fenceTilingWeight

    Let \(a\), \(b\) be elements of a commutative semiring, let \(n \ge 0\), and let \(F\) be a finite set of natural numbers (fence positions; the fence at \(k\) has posts on half-cells \(k\) and \(k + 2\)). The weight of \(F\) on the \(n\)-board is the product, over the half-cells \(h \in \{0, \dots, 2n - 1\}\) that neither lie in \(F\) nor equal \(k + 2\) for some \(k \in F\), of \(a\) if \(\lfloor h/2 \rfloor\) is even (a half-square in the odd cell \(\lfloor h/2 \rfloor + 1\)) and of \(b\) otherwise (a half-square in an even cell).

    def fenceTilingWeight {R : Type*} [CommSemiring R] (a b : R) (n : ℕ) (F : Finset ℕ) : R :=
  ∏ h ∈ range (2 * n) \ (F ∪ F.image (· + 2)), if h / 2 % 2 = 0 then a else b

    DefinitionWeighted count of fence tilings#✓fully proved

    MetaMathlibExt.fenceTilingSum

    Let \(a\), \(b\) be elements of a commutative semiring and \(n \ge 0\). The weighted number \(S_n\) of tilings of an \(n\)-board by half-squares and \((1/2, 1/2)\)-fences is the sum, over all fence tilings \(F\) of the \(n\)-board, of the weight of \(F\), in which a half-square weighs \(a\) in an odd cell and \(b\) in an even cell and fences weigh \(1\).

    def fenceTilingSum {R : Type*} [CommSemiring R] (a b : R) (n : ℕ) : R :=
  ∑ F ∈ fenceTilings n, fenceTilingWeight a b n F
    def fenceTilings (n : ℕ) : Finset (Finset ℕ) :=
  (range (2 * n - 2)).powerset.filter fun F => ∀ k ∈ F, k + 2 ∉ F

    MetaMathlibExt.noBifenceTilingSum

    Let \(a\), \(b\) be elements of a commutative semiring and \(n \ge 0\). Two fences at positions \(k\) and \(k + 1\) form a bifence.     MetaMathlibExt.noFreeBifenceTilingSum

    For elements \(a\), \(b\) of a commutative semiring and \(n \ge 0\), number the cells of an \(n\)-board \(1, \dots, n\) and its \(2n\) half-cells \(0, \dots, 2n - 1\), half-cell \(h\) lying in cell \(\lfloor h/2 \rfloor + 1\).
