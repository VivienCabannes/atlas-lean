    For subsets \(X\) and \(Y\) of a group \(G\), the pair \((X, Y)\) is a tiling (or factorisation) of \(G\) if every \(g \in G\) can be written as \(g = xy\) with \(x \in X\) and \(y \in Y\) for exactly one pair \((x, y)\).

    def IsTiling {G : Type*} [Group G] (X Y : Set G) : Prop :=
  ∀ g : G, ∃! p : X × Y, (p.1 : G) * (p.2 : G) = g

    MathlibExt.Combinatorics.FangXiaTilingWanted.Combinatorics.FangXiaTilingProblem.PartitionShape.contentSumAux

    For a natural number \(i\) and a list of natural numbers \(a_0, \dots, a_{k-1}\), this is the integer \(\sum_{j=0}^{k-1} a_j\,(a_j - 2(i + j) - 1)\); the empty list gives \(0\).

    With \(i = 0\) and the row lengths of a partition, this is twice the content sum of the partition.

    def contentSumAux : ℕ → List ℕ → ℤ
  | _, [] => 0
  | i, a :: as => (a : ℤ) * ((a : ℤ) - 2 * (i : ℤ) - 1) + contentSumAux (i + 1) as

    DefinitionTwice the content sum of a partition#✓fully proved

    MathlibExt.Combinatorics.FangXiaTilingWanted.Combinatorics.FangXiaTilingProblem.PartitionShape.contentSum

    For a partition \(\lambda\) of \(n\) with row lengths \(\lambda_0 \ge \lambda_1 \ge \dots \ge \lambda_{k-1}\), this is the integer \(\sum_{i=0}^{k-1} \lambda_i\,(\lambda_i - 2i - 1)\).

    This is twice the content sum \(\sum_{(i,j) \in \lambda} (j - i)\) of the Young diagram of \(\lambda\) (rows \(i\) and columns \(j\) counted from \(0\)), so it is nonnegative exactly when the content sum is. It is the row-length formula from the remark after Theorem 1.4 of Fang–Xia, whose one-indexed terms are \(\lambda_i\,(\lambda_i - 2i + 1)\).

    def contentSum {n : ℕ} (lam : PartitionShape n) : ℤ :=
  contentSumAux 0 lam.parts

    MathlibExt.Combinatorics.FangXiaTilingWanted.Combinatorics.FangXiaTilingProblem.IsPartitionTransitive

    Let \(\lambda\) be a partition of \(n\) with row lengths \(\lambda_0 \ge \dots \ge \lambda_{k-1}\). A set \(Y\) of permutations of \(\{0, \dots, n-1\}\) is \(\lambda\)-transitive, in the sense of Martin and Sagan, if there is a positive integer \(r\) such that for any two ordered set partitions \(P = (P_0, \dots, P_{k-1})\) and \(Q = (Q_0, \dots, Q_{k-1})\) of \(\{0, \dots, n-1\}\) of shape \(\lambda\), exactly \(r\) permutations \(\sigma \in Y\) satisfy \(\sigma(P_i) = Q_i\) for every \(i\).

    def IsPartitionTransitive {n : ℕ} (Y : Set (Equiv.Perm (Fin n)))
    (lam : PartitionShape n) : Prop :=
  ∃ r : ℕ, 0 < r ∧

    TheoremFang–Xia: tilings by transpositions and λ-transitivity#●ready to prove

    MathlibExt.Combinatorics.FangXiaTilingWanted.Combinatorics.FangXiaTilingProblem.fang_xia_partition_transitive_of_tiling

    Let \(S_n\) be the symmetric group on \(\{0, \dots, n-1\}\), let \(T_n \subseteq S_n\) consist of the identity and all transpositions, and let \(Y \subseteq S_n\) be such that \((T_n, Y)\) is a tiling of \(S_n\): every \(g \in S_n\) can be written as \(g = xy\) with \(x \in T_n\) and \(y \in Y\) for exactly one pair \((x, y)\). Let \(\lambda\) be a partition of \(n\) with row lengths \(\lambda_0 \ge \dots \ge \lambda_{k-1}\) such that \(\sum_{i=0}^{k-1} \lambda_i\,(\lambda_i - 2i - 1) \ge 0\) (equivalently, the content sum of the Young diagram of \(\lambda\) is nonnegative). Then \(Y\) is \(\lambda\)-transitive: there is a positive integer \(r\) such that for any two ordered set partitions \(P = (P_0, \dots, P_{k-1})\) and \(Q = (Q_0, \dots, Q_{k-1})\) of \(\{0, \dots, n-1\}\) with \(|P_i| = |Q_i| = \lambda_i\) for every \(i\), exactly \(r\) permutations \(\sigma \in Y\) satisfy \(\sigma(P_i) = Q_i\) for every \(i\).
