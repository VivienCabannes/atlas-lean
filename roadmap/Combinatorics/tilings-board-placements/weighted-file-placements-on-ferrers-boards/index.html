    For a list \(b = (b_1, \ldots, b_n)\) of natural numbers, the cells of the Ferrers board with column heights \(b\) are the pairs \((i, r)\) of natural numbers with \(i < n\) and \(r < b_{i+1}\); columns and rows are numbered from \(0\), so column \(i\) has height \(b_{i+1}\).

    DefinitionThe \(m\)-weight of a file placement#✓fully proved

    MetaMathlibExt.filePlacementWeight

    For a natural number \(m\) and a finite set \(F\) of cells \((i, j)\) (column \(i\), row \(j\)), let \(f_j\) be the number of cells of \(F\) in row \(j\).     DefinitionSingleton boards#✓fully proved

    MetaMathlibExt.IsSingletonBoard

    For natural numbers \(h\) and \(m\), write \(\lfloor h \rfloor_m\) for the largest multiple of \(m\) that is at most \(h\). A list \(b = (b_1, \ldots, b_n)\) of natural numbers is a singleton board for \(m\) when it is weakly increasing (the column heights of a Ferrers board) and, for every \(1 \le i < n\), \(b_i - \lfloor b_i \rfloor_m \ne 0\) implies \(\lfloor b_i \rfloor_m < \lfloor b_{i+1} \rfloor_m\).

    def IsSingletonBoard (m : ℕ) (b : List ℕ) : Prop :=
  b.Pairwise (· ≤ ·) ∧ ∀ i < b.length - 1,
    b.getD i 0 % m ≠ 0 → b.getD i 0 / m * m < b.getD (i + 1) 0 / m * m

    TheoremLevel-number factorization of the \(m\)-level rook polynomial#●ready to prove

    MetaMathlibExt.levelRookNumber_factorization_levels

    Let \(m \ge 1\) and let \(B = (b_1, \dots, b_n)\) be a Ferrers board, that is \(b_1 \le \dots \le b_n\), with \(b_i \le mn\) for every \(i\). Number the rows from \(0\) at the bottom, so that column \(i\) has the cells in rows \(0, \dots, b_i - 1\), and for \(1 \le j \le n\) let \(l_j\) be the number of cells of \(B\) whose row \(r\) satisfies \(\lfloor r/m \rfloor = n - j\) (the \(j\)-th level from the top).
