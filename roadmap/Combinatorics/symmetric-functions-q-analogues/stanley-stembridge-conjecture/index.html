    MathlibExt.Combinatorics.StanleyStembridgeEPositivityAMR156Problem0022Wanted.IsThreePlusOneFree

    A partially ordered set \(P\) is \((3+1)\)-free when there are no elements \(a, b, c, d \in P\) with \(a < b < c\) such that \(d\) is incomparable to each of \(a\), \(b\) and \(c\) (neither \(d \le x\) nor \(x \le d\) for \(x = a, b, c\)).

    def IsThreePlusOneFree (P : Type*) [PartialOrder P] : Prop :=
  ¬ ∃ a b c d : P, a < b ∧ b < c ∧ (¬ a ≤ d ∧ ¬ d ≤ a) ∧ (¬ b ≤ d ∧ ¬ d ≤ b) ∧
    (¬ c ≤ d ∧ ¬ d ≤ c)

    DefinitionIncomparability graph of a poset#✓fully proved

    MathlibExt.Combinatorics.StanleyStembridgeEPositivityAMR156Problem0022Wanted.incomparabilityGraph

    The incomparability graph \(\operatorname{inc}(P)\) of a partially ordered set \(P\) is the simple graph on \(P\) in which two distinct elements \(x\) and \(y\) are adjacent when they are incomparable, that is, neither \(x \le y\) nor \(y \le x\).

    def incomparabilityGraph (P : Type*) [PartialOrder P] : SimpleGraph P :=
  SimpleGraph.fromRel fun x y => ¬ x ≤ y ∧ ¬ y ≤ x

    DefinitionChromatic symmetric function in as many variables as vertices#✓fully proved

    MathlibExt.Combinatorics.StanleyStembridgeEPositivityAMR156Problem0022Wanted.chromaticSymmetricPoly

    For a simple graph \(G\) on a finite vertex set \(V\) with \(n = |V|\) elements, \(X_G\) is the polynomial with integer coefficients in the variables \(x_0, \dots, x_{n-1}\) given by \(X_G = \sum_{\kappa} \prod_{v \in V} x_{\kappa(v)}\), where \(\kappa\) ranges over the proper colourings \(\kappa : V \to \{0, \dots, n - 1\}\) of \(G\), that is, the maps with \(\kappa(u) \ne \kappa(v)\) whenever \(u\) and \(v\) are adjacent.

    noncomputable def chromaticSymmetricPoly {V : Type*} [Fintype V] (G : SimpleGraph V) :
    MvPolynomial (Fin (Fintype.card V)) ℤ :=
  ∑ κ ∈ Finset.univ.filter (fun κ : V → Fin (Fintype.card V) => ∀ u v, G.Adj u v → κ u ≠ κ v),
    ∏ v, MvPolynomial.X (κ v)

    Definition\(e\)-positive polynomials#✓fully proved

    MathlibExt.Combinatorics.StanleyStembridgeEPositivityAMR156Problem0022Wanted.IsEPositive

    A polynomial \(f\) with integer coefficients in the \(n\) variables \(x_0, \dots, x_{n-1}\) is \(e\)-positive when \(f = \sum_{\lambda} c_\lambda e_\lambda\) for some natural numbers \(c_\lambda\), where \(\lambda = (\lambda_1, \dots, \lambda_k)\) ranges over the partitions of \(n\) and \(e_\lambda = e_{\lambda_1} \cdots e_{\lambda_k}\) is the product of the elementary symmetric polynomials \(e_{\lambda_i}\) in \(x_0, \dots, x_{n-1}\).

    def IsEPositive {n : ℕ} (f : MvPolynomial (Fin n) ℤ) : Prop :=
  ∃ c : Nat.Partition n → ℕ, f = ∑ p : Nat.Partition n,
    (c p : MvPolynomial (Fin n) ℤ) * (p.parts.map fun i => MvPolynomial.esymm (Fin n) ℤ i).prod
