    MathlibExt.gaussBinom

    Let \(R\) be a semiring and \(Q \in R\). For natural numbers \(M\) and \(k\), the Gaussian binomial coefficient \(\binom{M}{k}_Q \in R\) is defined recursively by \(\binom{M}{0}_Q = 1\), \(\binom{0}{k+1}_Q = 0\) and \(\binom{M+1}{k+1}_Q = \binom{M}{k}_Q + Q^{k+1} \binom{M}{k+1}_Q\).

    def gaussBinom {R : Type*} [Semiring R] (Q : R) (M : ℕ) : ℕ → R
  | 0 => 1
  | k + 1 =>
      match M with
      | 0 => 0
      | M + 1 => gaussBinom Q M k + Q ^ (k + 1) * gaussBinom Q M (k + 1)

    TheoremEhrenborg–Readdy expansion of the Gaussian coefficient#✓fully proved

    MetaMathlibExt.gaussian_pair_sorted_expansion

    Let \(n\) and \(k\) be natural numbers and let \(W\) be the set of words \(v = v_0 v_1 \cdots v_{n-1}\) over the alphabet \(\{0, 1\}\) with exactly \(k\) letters equal to \(1\). For a word \(v\), let \(\operatorname{inv}(v)\) be the number of pairs \(i < j\) with \(v_i > v_j\); call \(v\) pair-sorted when \(v_{2i} \le v_{2i+1}\) for every \(i\) with \(2i + 1 < n\); and let \(\operatorname{asc}_{\mathrm{odd}}(v)\) be the number of \(i\) with \(2i + 1 < n\) and \(v_{2i} < v_{2i+1}\). Then, in the polynomial ring \(\mathbb{N}[q]\),

    \[\sum_{v \in W} q^{\operatorname{inv}(v)} = \sum_{v \in W,\ v \text{ pair-sorted}} q^{\operatorname{inv}(v)} (1 + q)^{\operatorname{asc}_{\mathrm{odd}}(v)}.\]

    The left side is MacMahon's inversion generating polynomial of \(W\), which equals the Gaussian coefficient \(\binom{n}{k}_q\). Positions are numbered from \(0\), so the pairs \((v_{2i}, v_{2i+1})\) are the source's pairs of positions \((1, 2), (3, 4), \ldots\), and \(\operatorname{asc}_{\mathrm{odd}}\) counts its odd ascents.

    MetaMathlibExt.gaussian_pair_sorted_expansion · 18 lines 
    theorem gaussian_pair_sorted_expansion (n k : ℕ) :
  let words : Finset (Fin n → Fin 2) :=
    Finset.univ.filter
      (fun v => (Finset.univ.filter (fun i : Fin n => v i = (1 : Fin 2))).card = k);
  let inv : (Fin n → Fin 2) → ℕ :=
    fun v => (Finset.univ.filter
      (fun p : Fin n × Fin n => p.1 < p.2 ∧ v p.1 > v p.2)).card;
  let pairSorted : (Fin n → Fin 2) → Bool :=
    fun v => decide (∀ j j' : Fin n, j.val % 2 = 0 →
      j'.val = j.val + 1 → v j ≤ v j');
  let ascOdd : (Fin n → Fin 2) → ℕ :=
    fun v => (Finset.univ.filter
      (fun j : Fin n => j.val % 2 = 0 ∧
        ∃ j' : Fin n, j'.val = j.val + 1 ∧ v j < v j')).card;
  Finset.sum words (fun v => (Polynomial.X : Polynomial ℕ) ^ inv v) =
    Finset.sum (words.filter (fun v => pairSorted v = true))
      (fun v => (Polynomial.X : Polynomial ℕ) ^ inv v *
        ((1 : Polynomial ℕ) + Polynomial.X) ^ ascOdd v)
