    For \(n \in \mathbb{N}\), \(\theta^{(n)}\) is the Young diagram of the near-hook partition \((n + 2, 2, 1^n)\) of \(2n + 4\): its rows have lengths \(n + 2\) and \(2\), followed by \(n\) rows of length \(1\).

    DefinitionFirst-quadrant paths \(\mathcal{P}_n\)#✓fully proved

    MetaMathlibExt.firstQuadrantPaths

    For \(n \in \mathbb{N}\), \(\mathcal{P}_n\) is the set of words \((s_1, \dots, s_{2n+2})\) of \(2n + 2\) steps, each one of \(N = (0, 1)\), \(S = (0, -1)\), \(E = (1, 0)\) and \(W = (-1, 0)\) in \(\mathbb{Z}^2\), such that every partial sum \(s_1 + \dots + s_k\) with \(0 \le k \le 2n + 2\) has both coordinates nonnegative and the total \(s_1 + \dots + s_{2n+2}\) equals \((n, n)\).

    These are the walks of Guy, Krattenthaler and Sagan.

    def firstQuadrantPaths (n : ℕ) : Set (List (ℤ × ℤ)) :=
  {w | w.length = 2 * n + 2 ∧ (∀ s ∈ w, s = (0, 1) ∨ s = (0, -1) ∨ s = (1, 0) ∨ s = (-1, 0)) ∧
    (∀ k, 0 ≤ (w.take k).sum.1 ∧ 0 ≤ (w.take k).sum.2) ∧ w.sum = ((n : ℤ), (n : ℤ))}

    MetaMathlibExt.nearHookTableauToPathPsi

    Let \(n \in \mathbb{N}\) and let \(T\) be a semistandard Young tableau of shape \(\theta^{(n)}\), with rows and columns numbered from \(0\); call row \(0\) of \(\theta^{(n)}\) the arm and column \(0\) the leg. Then \(\psi(T)\) is the word \((s_1, \dots, s_{2n+2})\) of steps in \(\mathbb{Z}^2\) in which \(s_i\) is \(E = (1, 0)\) if \(i + 2\) is an entry of \(T\) in the arm; otherwise \(s_i\) is \(N = (0, 1)\) if \(i + 2\) is an entry of \(T\) in the leg; otherwise \(s_i\) is \(S = (0, -1)\) if \(2\) is an entry of \(T\) in the arm, and \(W = (-1, 0)\) if not.

    For a standard Young tableau, the last two cases are those where \(i + 2\) is the entry of the heart, the cell in row \(1\) and column \(1\), and \(2\) is then an entry of the arm or of the leg.

    def nearHookTableauToPathPsi (n : ℕ) (T : SemistandardYoungTableau (nearHookTheta n)) :
    List (ℤ × ℤ) :=
  (List.range (2 * n + 2)).map fun k =>
    if ∃ j < n + 2, T 0 j = k + 3 then (1, 0)
    else if ∃ i < n + 2, T i 0 = k + 3 then (0, 1)
    else if ∃ j < n + 2, T 0 j = 2 then (0, -1) else (-1, 0)

    MetaMathlibExt.nearHookTableauToPathXi

    Let \(n \in \mathbb{N}\) and let \(T\) be a semistandard Young tableau of shape \(\theta^{(n)}\), with rows and columns numbered from \(0\); call row \(0\) of \(\theta^{(n)}\) the arm and the cell in row \(1\) and column \(1\) the heart, and let \(H\) be the entry of \(T\) in the heart. Then \(\xi(T)\) is the word \((s_1, \dots, s_{2n+2})\) of steps in \(\mathbb{Z}^2\) given as follows, where \(E = (1, 0)\), \(N = (0, 1)\), \(S = (0, -1)\) and \(W = (-1, 0)\). If \(i + 2 < H\), then \(s_i\) is \(E\) if \(i + 1\) is an entry of \(T\) in the arm and \(N\) otherwise. If \(i + 2 = H\), then \(s_i\) is \(S\) if \(i + 1\) is an entry of \(T\) in the arm and \(W\) otherwise. If \(i + 2 > H\), then \(s_i\) is \(E\) if \(i + 2\) is an entry of \(T\) in the arm and \(N\) otherwise.

    For a standard Young tableau the inspected value is never \(1\) or \(H\), so it lies in exactly one of the arm and the leg, column \(0\); "otherwise" then means that it lies in the leg.

    def nearHookTableauToPathXi (n : ℕ) (T : SemistandardYoungTableau (nearHookTheta n)) :
    List (ℤ × ℤ) :=
  (List.range (2 * n + 2)).map fun k =>
    if k + 3 < T 1 1 then (if ∃ j < n + 2, T 0 j = k + 2 then (1, 0) else (0, 1))
    else if k + 3 = T 1 1 then (if ∃ j < n + 2, T 0 j = k + 2 then (0, -1) else (-1, 0))
    else if ∃ j < n + 2, T 0 j = k + 3 then (1, 0) else (0, 1)
