    FinPoset.linearExtensions

    Let \(\alpha\) be a finite poset with \(n\) elements. Its linear extensions are represented as rank functions: the set of linear extensions of \(\alpha\) is the finite set of all maps \(\sigma : \alpha \to \{0, 1, \dots, n-1\}\) that are bijective and monotone, meaning that \(x \le y\) implies \(\sigma(x) \le \sigma(y)\).

    noncomputable def linearExtensions (α : Type*) [Fintype α] [PartialOrder α] :
    Finset (α → Fin (Fintype.card α)) := by
  classical
  exact Finset.univ.filter fun σ => Function.Bijective σ ∧ Monotone σ

    FinPoset.linExtOrderIso

    Let \(\alpha\) be a finite poset with \(n\) elements, and fix a linear order on \(\alpha\) extending its partial order (one exists by Szpilrajn's extension theorem; it is chosen once and for all). This is the order isomorphism from \(\alpha\) with that linear order onto \(\{0, 1, \dots, n-1\}\) with its usual order.

    noncomputable def linExtOrderIso (α : Type*) [Fintype α] [PartialOrder α] :
    LinearExtension α ≃o Fin (Fintype.card α) := by
  have : Fintype (LinearExtension α) := inferInstanceAs (Fintype α)
  have hcard : Fintype.card (LinearExtension α) = Fintype.card α :=

  exact (Fintype.orderIsoFinOfCardEq (LinearExtension α) rfl).symm.trans
