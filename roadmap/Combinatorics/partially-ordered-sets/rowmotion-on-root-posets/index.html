    MathlibExt.Combinatorics.RootPosetRowmotionHomomesyWanted.IsHomomesic

    Let \(X\) be a type, \(\sigma \colon X \to X\) a map, \(f \colon X \to \mathbb{Q}\) a function and \(c \in \mathbb{Q}\). Then \(f\) is homomesic under \(\sigma\) with average \(c\) when \(X\) is finite, \(\sigma\) is bijective, and for every \(x \in X\) and every \(k > 0\) with \(\sigma^k(x) = x\) the average \(\frac{1}{k} \sum_{i=0}^{k-1} f(\sigma^i(x))\) equals \(c\).

    def IsHomomesic {α : Type*} (σ : α → α) (f : α → ℚ) (c : ℚ) : Prop :=
  Finite α ∧
  Function.Bijective σ ∧
  ∀ (x : α) (k : ℕ), 0 < k → Nat.iterate σ k x = x →
    (Finset.sum (Finset.range k) (fun i => f (Nat.iterate σ i x))) / (k : ℚ) = c

    DefinitionRowmotion on antichains#✓fully proved

    MathlibExt.Combinatorics.RootPosetRowmotionHomomesyWanted.IsAntichainRowmotion

    For a partially ordered set \(P\), a map \(\rho\) from the finite antichains of \(P\) to themselves is antichain rowmotion when \(\rho\) is bijective and, for every finite antichain \(A\), \(\rho(A)\) is the set of minimal elements of the complement of the down-set of \(A\): an element \(x \in P\) lies in \(\rho(A)\) exactly when \(x \not\le a\) for all \(a \in A\) and every \(y \le x\) with \(y \not\le a\) for all \(a \in A\) equals \(x\).

    def IsAntichainRowmotion (P : Type*) [PartialOrder P]
    (rhoPrime : PosetAntichain P → PosetAntichain P) : Prop :=
  Function.Bijective rhoPrime ∧
  ∀ (A : PosetAntichain P) (x : P),
    x ∈ (rhoPrime A).val ↔
      ((¬ ∃ a ∈ A.val, x ≤ a) ∧
        ∀ (y : P), (¬ ∃ a ∈ A.val, y ≤ a) → y ≤ x → y = x)
    def PosetAntichain (P : Type*) [PartialOrder P] :=
  { s : Finset P // IsAntichain (· ≤ ·) (s : Set P) }

    TheoremAntichain size is homomesic under type-A rowmotion#●ready to prove

    MathlibExt.Combinatorics.RootPosetRowmotionHomomesyWanted.conjecture_holds

    Let \(n\) be a natural number and let \(P\) be a finite partially ordered set that is a type-A root poset of rank \(n\): there is a bijection \(a \mapsto (i_a, j_a)\) from \(P\) onto the set of pairs \((i, j)\) of integers with \(0 \le i \le j < n\) such that \(a \le b\) holds exactly when \([i_a, j_a] \subseteq [i_b, j_b]\), that is, \(i_b \le i_a\) and \(j_a \le j_b\). Let \(\rho\) be a bijection of the set of finite antichains of \(P\) such that, for every antichain \(A\), \(\rho(A)\) is the set of minimal elements of the complement of the down-set of \(A\). Then the set of finite antichains of \(P\) is finite, \(\rho\) is bijective, and for every antichain \(A\) and every \(k > 0\) with \(\rho^k(A) = A\),

    \[\frac{1}{k} \sum_{i=0}^{k-1} |\rho^i(A)| = \frac{n}{2}.\]

    This is the type-A case of Panyushev's conjecture on antichain orbits in root posets, which Armstrong, Stump, and Thomas proved for all crystallographic root systems.
