    DefinitionPoset matrix#✓fully proved

    MetaMathlibExt.IsPosetMatrix

    An \(n \times n\) Boolean matrix \(M\), with rows and columns indexed by \(\{0, \dots, n-1\}\), is an upper-triangular \((0, 1)\)-poset matrix when its entries strictly below the main diagonal are false (\(M_{ij}\) is false whenever \(j < i\)), its diagonal entries \(M_{ii}\) are true, and its true entries are transitive: if \(M_{ij}\) and \(M_{jk}\) are true, then \(M_{ik}\) is true.

    def IsPosetMatrix (n : ℕ) (M : Matrix (Fin n) (Fin n) Bool) : Prop :=
  (∀ i j : Fin n, (j : ℕ) < (i : ℕ) → M i j = false) ∧
    (∀ i : Fin n, M i i = true) ∧
    (∀ i j k : Fin n, M i j = true → M j k = true → M i k = true)

    TheoremBlock decomposition of a poset matrix#●ready to prove

    MetaMathlibExt.isPosetMatrix_block_iff_directSum_ordinalSum

    Let \(m, k \ge 1\) and let \(M\) be a poset matrix of order \(m + k\), a Boolean matrix with rows and columns indexed by \(0, \dots, m + k - 1\). Then \(M_{ij}\) is false for all \(i < m \le j\) if and only if there are poset matrices \(A\) of order \(m\) and \(B\) of order \(k\) such that \(M\) is their direct sum: \(M_{ij} = A_{ij}\) for \(i, j < m\), \(M_{m+i, m+j} = B_{ij}\) for \(i, j < k\), and every other entry of \(M\) is false. Likewise \(M_{ij}\) is true for all \(i < m \le j\) if and only if there are poset matrices \(A\) of order \(m\) and \(B\) of order \(k\) such that \(M\) is their ordinal sum: the same diagonal blocks, \(M_{ij}\) true for all \(i < m \le j\), and \(M_{ij}\) false for all \(j < m \le i\).

    Only one block length is stated; the version with several lengths \(n_1 < \dots < n_r\) follows by iterating it.

    TheoremDirect and ordinal sums of poset matrices represent sums of posets#●ready to prove

    MetaMathlibExt.directSum_ordinalSum_represents

    A poset matrix \(M\) of order \(n\), a Boolean matrix with rows and columns indexed by \(0, \dots, n - 1\), represents a partial order \(P\) when there is a bijection \(e\) from \(\{0, \dots, n - 1\}\) to \(P\) such that \(e(i) \le e(j)\) if and only if \(M_{ij}\) is true. Let \(A\) and \(B\) be poset matrices of orders \(m\) and \(k\) representing partial orders \(P\) and \(Q\). Let \(A \oplus B\) and \(A \boxplus B\) be the matrices \(N\) of order \(m + k\) with \(N_{ij} = A_{ij}\) for \(i, j < m\), \(N_{m+i, m+j} = B_{ij}\) for \(i, j < k\), and \(N_{ij}\) false for all \(j < m \le i\), where \(N_{ij}\) for \(i < m \le j\) is false in \(A \oplus B\) and true in \(A \boxplus B\). Then \(A \oplus B\) is a poset matrix representing the disjoint sum \(P + Q\), in which no element of \(P\) is comparable with an element of \(Q\), and \(A \boxplus B\) is a poset matrix representing the ordinal sum \(P \oplus Q\), in which every element of \(P\) lies below every element of \(Q\).

    Only sums of two terms are stated; sums of \(r\) terms follow by iterating.

    TheoremBlock properties decide connectedness of the represented poset#●ready to prove

    MetaMathlibExt.connected_or_disconnected_of_block_property

    Let \(M\) be a poset matrix of order \(n\), a Boolean matrix with rows and columns indexed by \(0, \dots, n - 1\), that represents a partial order \(P\): there is a bijection \(e\) from \(\{0, \dots, n - 1\}\) to \(P\) such that \(e(i) \le e(j)\) if and only if \(M_{ij}\) is true. Let \(1 \le r < n\). If \(M_{ij}\) is true for all \(i < r \le j\) (the block of \(1\)s property of length \(r\)), then \(P\) is connected: every subset \(S\) of \(P\) such that \(x \in S \iff y \in S\) whenever \(x \le y\) is empty or all of \(P\). If \(M_{ij}\) is false for all \(i < r \le j\) (the block of \(0\)s property of length \(r\)), then \(P\) is disconnected: some nonempty subset \(S\) of \(P\) with nonempty complement satisfies \(x \in S \iff y \in S\) whenever \(x \le y\).

    Since a relabeling of \(M\) represents the same poset, this also covers matrices that satisfy a block property after relabeling.

    TheoremArity of quasi-full rooted trees#●ready to prove

    MetaMathlibExt.quasiFullTree_arity

    Let \(P\) be a finite partial order with \(n \ge 3\) elements that is a rooted tree: \(P\) has a least element and, for every \(x \in P\), the elements below \(x\) form a chain. For a natural number \(t\), call \(P\) quasi-full \(t\)-ary when every \(x \in P\) is covered by exactly \(\min(|U_x| - 1, t)\) elements of \(P\), where \(U_x = \{y \in P : x \le y\}\). Then (i) if \(P\) is quasi-full \((n - 1)\)-ary, it is quasi-full \(t\)-ary for every \(t \ge n\); and (ii) if \(P\) is quasi-full \(t\)-ary for some \(t \le n - 2\), it is not quasi-full \(t'\)-ary for any \(t' \ge n\).

    The source states this for poset matrices representing quasi-full \(t\)-ary rooted trees; both parts depend only on the represented poset.

    Let \(n, t \ge 2\) and let \(M\) and \(M'\) be poset matrices of order \(n\), Boolean matrices with rows and columns indexed by \(0, \dots, n - 1\). Let \(0 = l_0 < l_1 < \dots < l_t = n\) be such that the gaps \(l_{k+1} - l_k\) are nondecreasing in \(k\). Suppose that for every \(k \le t\), \(M_{ij}\) is false for all \(i < l_k \le j\), and that for every \(k < t\) there is \(s \ge 1\) with \(l_k + s < l_{k+1}\) such that \(M_{ij}\) is true for all \(i, j\) with \(l_k \le i < l_k + s \le j < l_{k+1}\). Suppose the same of \(M'\) with a sequence \(0 = l'_0 < l'_1 < \dots < l'_t = n\) whose gaps are nondecreasing. If \(l_k \ne l'_k\) for some \(k\), then \(M\) and \(M'\) are not relabeling equivalent: there is no permutation \(\sigma\) of \(\{0, \dots, n - 1\}\) with \(M'_{ij} = M_{\sigma(i) \sigma(j)}\) for all \(i, j\).
