    First and second moment methods

    The first moment method shows that a nonnegative integer count \(X\) is \(0\) with high probability when \(\mathbb E X \to 0\); the second moment method shows that \(X > 0\) with high probability when \(\operatorname{Var} X = o((\mathbb E X)^2)\). For a count \(X = \sum_i 1_{A_i}\) of events with a dependency graph, \(\operatorname{Var} X \le \mu + \Delta\), which reduces thresholds for subgraph containment in \(G(n,p)\) to estimating the correlation sum \(\Delta\).

    TheoremFirst moment method#✓fully proved

    MathlibExt.Probability.Combinatorics.SecondMomentMethod.measureReal_one_le_le_integral

    Let \(X \ge 0\) be an integrable random variable on a finite measure space. Then $\(\Pr[X \ge 1] \le \mathbb E X .\)$ For a count \(X\) with values in \(\mathbb N\) this reads \(\Pr[X \neq 0] \le \mathbb E X\): if \(\mathbb E X \to 0\) along a sequence of random structures, then \(X = 0\) with high probability. This is Markov's inequality at level \(1\) (Mathlib's mul_meas_ge_le_integral_of_nonneg), and it gives the lower half of every threshold, for example \(p \ll 1/n\) for triangles in \(G(n, p)\).

    theorem measureReal_one_le_le_integral [IsFiniteMeasure μ] {X : Ω → ℝ} (hX0 : 0 ≤ᵐ[μ] X)
    (hXi : Integrable X μ) : μ.real {ω | 1 ≤ X ω} ≤ ∫ ω, X ω ∂μ

    TheoremSecond moment method#✓fully proved

    MathlibExt.Probability.Combinatorics.SecondMomentMethod.measureReal_eq_zero_le_variance_div_sq

    Let \(X\) be a square-integrable real random variable on a probability space with \(\mathbb E X \neq 0\). Then $\(\Pr[X = 0] \le \frac{\operatorname{Var} X}{(\mathbb E X)^2} .\)$ On the event \(X = 0\) one has \(|X - \mathbb E X| = |\mathbb E X|\), so this is Chebyshev's inequality at distance \(|\mathbb E X|\). Consequently, if \(\operatorname{Var} X = o((\mathbb E X)^2)\) along a sequence, then \(X \neq 0\) with high probability; for a nonnegative count this means that some counted event occurs.

    The source states the lemma for nonnegative \(X\); the proof does not use nonnegativity, and the Lean statement drops it.

    theorem measureReal_eq_zero_le_variance_div_sq [IsProbabilityMeasure μ] {X : Ω → ℝ}
    (hX : MemLp X 2 μ) (hmean : μ[X] ≠ 0) :
    μ.real {ω | X ω = 0} ≤ variance X μ / (μ[X]) ^ 2

    TheoremSecond moment method, Cauchy–Schwarz form#✓fully proved

    MathlibExt.Probability.Combinatorics.SecondMomentMethod.sq_integral_le_integral_sq_mul_measureReal_pos

    Let \(X \ge 0\) be a square-integrable random variable on a probability space. Then $\((\mathbb E X)^2 \le \mathbb E[X^2] \cdot \Pr[X > 0],\)$ that is, \(\Pr[X > 0] \ge (\mathbb E X)^2 / \mathbb E[X^2]\) whenever \(\mathbb E[X^2] > 0\). It follows from Cauchy–Schwarz applied to \(X = X \cdot 1_{X > 0}\), and it is the case \(\theta = 0\) of the Paley–Zygmund inequality, from which the Lean proof takes it. It is slightly sharper than the Chebyshev form: it gives \(\Pr[X = 0] \le \operatorname{Var} X / \mathbb E[X^2]\).

    theorem sq_integral_le_integral_sq_mul_measureReal_pos [IsProbabilityMeasure μ] {X : Ω → ℝ}
    (hX0 : 0 ≤ᵐ[μ] X) (hX : MemLp X 2 μ) :
    (∫ ω, X ω ∂μ) ^ 2 ≤ (∫ ω, X ω ^ 2 ∂μ) * μ.real {ω | 0 < X ω}

    DefinitionNumber of events that occur#✓fully proved

    MathlibExt.Probability.Combinatorics.SecondMomentMethod.count

    For events \(A_i\) indexed by a finite set, the count of those that occur at \(\omega\) is $\(X(\omega) = \sum_i 1_{A_i}(\omega).\)$ Counts of copies of a fixed subgraph in \(G(n,p)\), of monochromatic cliques, or of sets contained in a random subset are all of this form.

    noncomputable def count (A : ι → Set Ω) (ω : Ω) : ℝ :=
  ∑ i, (A i).indicator (fun _ => (1 : ℝ)) ω

    MathlibExt.Probability.Combinatorics.SecondMomentMethod.expectedCount

    For events \(A_i\) indexed by a finite set, \(\mu = \sum_i \Pr[A_i]\), which is \(\mathbb E X\) for the count \(X = \sum_i 1_{A_i}\) by linearity of expectation.

    DefinitionCorrelation sum over dependent pairs#✓fully proved

    MathlibExt.Probability.Combinatorics.SecondMomentMethod.dependentPairSum

    For events \(A_i\) indexed by a finite set and a graph \(G\) on the indices (a dependency graph), $\(\Delta = \sum_{(i, j) \,:\, i \sim_G j} \Pr[A_i \cap A_j],\)$ the sum running over ordered adjacent pairs. With this convention \(\operatorname{Var} X \le \mu + \Delta\) (variance bound); Zhao's notes write \(\Delta\) over unordered pairs \(i < j\), for which the same bound needs \(2\Delta\). The ordered convention agrees with the \(\Delta\) of Janson's inequalities.

    noncomputable def dependentPairSum (μ : Measure Ω) (A : ι → Set Ω) (G : SimpleGraph ι)
    [DecidableRel G.Adj] : ℝ :=
  ∑ i, ∑ j, if G.Adj i j then μ.real (A i ∩ A j) else 0

    TheoremVariance of a count of events with a dependency graph#✓fully proved

    MathlibExt.Probability.Combinatorics.SecondMomentMethod.variance_sum_indicator_le

    Let \(A_i\) be measurable events indexed by a finite set and let \(G\) be a graph on the indices such that \(\Pr[A_i \cap A_j] = \Pr[A_i] \Pr[A_j]\) whenever \(i \neq j\) are not adjacent. Then the count \(X = \sum_i 1_{A_i}\) satisfies $\(\operatorname{Var} X \le \mu + \Delta,\)$ where \(\mu = \sum_i \Pr[A_i] = \mathbb E X\) and \(\Delta\) is the correlation sum over ordered adjacent pairs. Expanding \(\operatorname{Var} X = \sum_{i,j} \operatorname{Cov}(1_{A_i}, 1_{A_j})\), the diagonal contributes at most \(\mu\), adjacent pairs at most \(\Pr[A_i \cap A_j]\) each, and non-adjacent pairs nothing. Only pairwise independence of non-adjacent events is needed, which is weaker than the mutual independence required by the Lovász local lemma.

    theorem variance_sum_indicator_le [IsProbabilityMeasure μ] (A : ι → Set Ω)
    (hA : ∀ i, MeasurableSet (A i)) (G : SimpleGraph ι) [DecidableRel G.Adj]
    (hind : ∀ i j, i ≠ j → ¬ G.Adj i j → μ.real (A i ∩ A j) = μ.real (A i) * μ.real (A j)) :
    variance (count A) μ ≤ expectedCount μ A + dependentPairSum μ A G
    noncomputable def count (A : ι → Set Ω) (ω : Ω) : ℝ :=
  ∑ i, (A i).indicator (fun _ => (1 : ℝ)) ω

    TheoremSecond moment method for counts of events#✓fully proved

    MathlibExt.Probability.Combinatorics.SecondMomentMethod.measureReal_forall_not_mem_le

    Let \(A_i\) be measurable events indexed by a finite set and \(G\) a dependency graph for them in the pairwise sense of the variance bound. If \(\mu = \sum_i \Pr[A_i] > 0\), then $\(\Pr[\text{no } A_i \text{ occurs}] \le \frac{\mu + \Delta}{\mu^2},\)$ with \(\Delta\) the correlation sum over ordered adjacent pairs. Hence along a sequence with \(\mu \to \infty\) and \(\Delta = o(\mu^2)\) some \(A_i\) occurs with high probability. Applied to the copies of a balanced graph \(H\) in \(G(n, p)\) this gives the upper half of the threshold \(n^{-1/m(H)}\) (Zhao, Theorem 4.18); Janson's inequality improves the polynomial bound to an exponential one.

    theorem measureReal_forall_not_mem_le [IsProbabilityMeasure μ] (A : ι → Set Ω)
    (hA : ∀ i, MeasurableSet (A i)) (G : SimpleGraph ι) [DecidableRel G.Adj]
    (hind : ∀ i j, i ≠ j → ¬ G.Adj i j → μ.real (A i ∩ A j) = μ.real (A i) * μ.real (A j))
    (hμ : 0 < expectedCount μ A) :
    μ.real {ω | ∀ i, ω ∉ A i} ≤
      (expectedCount μ A + dependentPairSum μ A G) / expectedCount μ A ^ 2
    noncomputable def expectedCount (μ : Measure Ω) (A : ι → Set Ω) : ℝ :=
  ∑ i, μ.real (A i)
