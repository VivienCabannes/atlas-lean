    CSLibExt.Combinatorics.RandomThreeSat.Clause

    A 3-clause on \(n\) variables is a pair \((S, p)\) of a three-element set \(S\) of variables among the \(n\) and a polarity \(p\) assigning a Boolean value to every variable, with \(p\) equal to false at every variable outside \(S\). This normalization gives each clause in the usual sense (a three-element variable set with one of \(2^3\) polarity patterns) exactly one representative.

    def Clause (n : ℕ) :=
  { p : Finset (Fin n) × (Fin n → Bool) //
    p.1.card = 3 ∧ ∀ i : Fin n, i ∉ p.1 → p.2 i = false }

    DefinitionSatisfiability probability of random 3-SAT#✓fully proved

    CSLibExt.Combinatorics.RandomThreeSat.satProb

    For natural numbers \(n\) and \(m\), the satisfiability probability \(p(n, m)\) is the number of satisfiable formulas with \(m\) clauses on \(n\) variables divided by the number of all such formulas, that is, the probability that a uniformly random formula with \(m\) clauses on \(n\) variables is satisfiable. When there are no such formulas, which happens exactly when \(n < 3\) and \(m > 0\), the quotient is taken to be \(0\); this affects only finitely many \(n\) in any asymptotic statement.

    noncomputable def satProb (n m : ℕ) : ℝ :=
  (Fintype.card { F : Formula n m // Satisfiable F } : ℝ) /
    (Fintype.card (Formula n m) : ℝ)

    DefinitionUpper threshold cutoff#✓fully proved

    CSLibExt.Combinatorics.RandomThreeSat.IsUpperCutoff

    A real number \(\rho\) is an upper threshold cutoff for random 3-SAT when, for every real \(r > \rho\), the probability that a uniformly random formula with \(\lfloor r n \rfloor\) clauses on \(n\) variables is satisfiable tends to \(0\) as \(n \to \infty\) (when \(r n < 0\) the formula has no clauses); equivalently, such a formula is unsatisfiable with probability tending to \(1\).

    Literature upper bounds on the threshold are exactly cutoffs in this sense.

    def IsUpperCutoff (ρ : ℝ) : Prop :=
  ∀ r : ℝ, ρ < r →

    CSLibExt.Combinatorics.RandomThreeSat.upperThreshold

    The upper threshold is the infimum, in the real numbers, of the set of upper threshold cutoffs: the reals \(\rho\) such that, for every real \(r > \rho\), the probability that a uniformly random formula with \(\lfloor rn \rfloor\) clauses on \(n\) variables (no clauses when \(rn < 0\)) is satisfiable tends to \(0\) as \(n \to \infty\).     CSLibExt.Combinatorics.RandomThreeSat.clauseSat_restrict_iff

    Let \(A\) assign a Boolean value to every natural-number variable, and let \(c\) be a 3-clause on the \(n\) variables \(0, \dots, n - 1\).
