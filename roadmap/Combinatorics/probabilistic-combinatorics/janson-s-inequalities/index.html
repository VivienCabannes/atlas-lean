    Janson's inequalities

    A random subset \(R\) of a finite ground set contains each element independently; for sets \(S_1, \dots, S_k\), Janson's inequalities bound the probability that no \(S_i\) is contained in \(R\) by \(e^{-\mu + \Delta/2}\), and by \(e^{-\mu^2/(2\Delta)}\) when \(\Delta \ge \mu\). They give exponentially small non-existence probabilities where the second moment method gives only polynomial ones; with \(G(n,p)\) as the random subset of the edges of \(K_n\) they bound, for example, the probability that \(G(n,p)\) is triangle-free.

    DefinitionLaw of a random subset with independent elements#✓fully proved

    MathlibExt.Probability.Combinatorics.RandomSubset.randomSubsetLaw

    Let \(\alpha\) be a finite set and \(p : \alpha \to [0, 1]\). The random subset \(R \subseteq \alpha\) contains each element \(a\) independently with probability \(p(a)\). In Lean, a subset is encoded by its indicator \(\omega : \alpha \to \mathrm{Bool}\), and the law of \(R\) is the product of the Bernoulli laws \(\mathrm{Ber}(p(a))\) on the coordinates. The binomial random graph \(G(n, p)\) is the case where \(\alpha\) is the set of pairs of vertices and \(p\) is constant.

    noncomputable def randomSubsetLaw [Fintype α] (p : α → I) : Measure (α → Bool) :=
  Measure.pi fun a => bernoulliMeasure true false (p a)

    DefinitionThe event that a random subset contains a given set#✓fully proved

    MathlibExt.Probability.Combinatorics.RandomSubset.containsEvent

    For a finite set \(S \subseteq \alpha\), the event \(\{S \subseteq R\}\): the indicators \(\omega\) with \(\omega(a) = \mathrm{true}\) for every \(a \in S\).     def containsEvent (S : Finset α) : Set (α → Bool) :=

    TheoremProbability that a random subset contains a given set#✓fully proved

    MathlibExt.Probability.Combinatorics.RandomSubset.randomSubsetLaw_real_containsEvent

    If the random subset \(R\) contains each element \(a\) independently with probability \(p(a)\), then for every finite \(S\), $\(\Pr[S \subseteq R] = \prod_{a \in S} p(a).\)$ For \(G(n, p)\) and the edge set \(S\) of a fixed copy of a graph \(H\) this is \(p^{e(H)}\), the starting point of every first and second moment computation for subgraph counts.

    theorem randomSubsetLaw_real_containsEvent [Fintype α] (p : α → I) (S : Finset α) :
    (randomSubsetLaw p).real (containsEvent S) = ∏ a ∈ S, (p a : ℝ)

    DefinitionJanson's correlation sum Δ#✓fully proved

    MathlibExt.Probability.JansonInequalityWanted.jansonDelta

    For a random subset \(R\) with independent elements and sets \(S_1, \dots, S_k\), $\(\Delta = \sum_{(i,j) \,:\, i \neq j,\ S_i \cap S_j \neq \emptyset} \Pr[S_i \subseteq R \text{ and } S_j \subseteq R],\)$ over ordered pairs. Events \(A_i\), \(A_j\) with disjoint \(S_i\), \(S_j\) depend on disjoint sets of coordinates and are independent, so \(\Delta\) is the correlation sum of the dependency graph "\(S_i \cap S_j \neq \emptyset\)".

    noncomputable def jansonDelta (p : α → I) (S : ι → Finset α) : ℝ :=
  ∑ i, ∑ j, if i ≠ j ∧ ¬ Disjoint (S i) (S j) then
    (randomSubsetLaw p).real (containsEvent (S i) ∩ containsEvent (S j)) else 0
    noncomputable def randomSubsetLaw [Fintype α] (p : α → I) : Measure (α → Bool) :=

    TheoremFirst Janson inequality#●ready to prove

    MathlibExt.Probability.JansonInequalityWanted.janson_inequality

    Let \(R\) be a random subset of a finite set that contains each element \(a\) independently with probability \(p(a)\), let \(S_1, \dots, S_k\) be subsets and \(A_i = \{S_i \subseteq R\}\). With μ \(= \sum_i \Pr[A_i]\) and Δ the sum of \(\Pr[A_i \cap A_j]\) over ordered pairs \(i \neq j\) with \(S_i \cap S_j \neq \emptyset\), $\(\Pr[\text{no } A_i \text{ occurs}] \le e^{-\mu + \Delta/2}.\)$ When \(\Delta = o(\mu)\) and every \(\Pr[A_i] = o(1)\) this matches the Harris lower bound \(\prod_i (1 - \Pr[A_i]) = e^{-(1+o(1))\mu}\). For triangles in \(G(n, p)\) it gives \(\Pr[G(n,p) \text{ is triangle-free}] \le e^{-(1+o(1)) \binom n3 p^3}\) for \(p = o(n^{-1/2})\).

    Zhao's Setup 7.10 chooses each element independently; the proof there (Boppana–Spencer with Warnke's modification) uses the Harris inequality for independent boolean variables and so covers element-dependent probabilities, as stated here.

    theorem_wanted janson_inequality (p : α → I) (S : ι → Finset α) :
    (randomSubsetLaw p).real {ω | ∀ i, ω ∉ containsEvent (S i)} ≤
      Real.exp (-jansonMu p S + jansonDelta p S / 2)

    TheoremSecond Janson inequality#●ready to prove

    MathlibExt.Probability.JansonInequalityWanted.janson_inequality_of_le

    In the setting of the first Janson inequality, if \(\Delta \ge \mu\) then $\(\Pr[\text{no } A_i \text{ occurs}] \le e^{-\mu^2/(2\Delta)}.\)$ It is proved by applying the first inequality to a random subfamily of the events, each kept with probability \(q = \mu/\Delta\).

    theorem_wanted janson_inequality_of_le (p : α → I) (S : ι → Finset α)
    (h : jansonMu p S ≤ jansonDelta p S) :
    (randomSubsetLaw p).real {ω | ∀ i, ω ∉ containsEvent (S i)} ≤
      Real.exp (-(jansonMu p S ^ 2 / (2 * jansonDelta p S)))

    DefinitionThe event that a random subset avoids a given set#✓fully proved

    MathlibExt.Probability.Combinatorics.RandomSubset.avoidEvent

    For a finite set \(S \subseteq \alpha\), the event \(\{S \cap R = \emptyset\}\): the indicators \(\omega\) with \(\omega(a) = \mathrm{false}\) for every \(a \in S\). It is a decreasing event, the complement-side counterpart of the event that \(R\) contains \(S\); for the random graph it says that a vertex set spans no edge.

    def avoidEvent (S : Finset α) : Set (α → Bool) :=
  {ω | ∀ a ∈ S, ω a = false}

    TheoremProbability that a random subset avoids a given set#✓fully proved

    MathlibExt.Probability.Combinatorics.RandomSubset.randomSubsetLaw_real_avoidEvent

    If the random subset \(R\) contains each element \(a\) independently with probability \(p(a)\), then for every finite \(S\), $\(\Pr[S \cap R = \emptyset] = \prod_{a \in S} \bigl(1 - p(a)\bigr).\)$ For \(G(n, p)\) and the pairs inside a \(k\)-set this is \((1-p)^{\binom k2}\), the probability that the \(k\)-set is independent.

    theorem randomSubsetLaw_real_avoidEvent [Fintype α] (p : α → I) (S : Finset α) :
    (randomSubsetLaw p).real (avoidEvent S) = ∏ a ∈ S, (1 - (p a : ℝ))
    noncomputable def randomSubsetLaw [Fintype α] (p : α → I) : Measure (α → Bool) :=
