    DefinitionCircular Eulerian numbers#✓fully proved

    MetaMathlibExt.circularEulerian

    For natural numbers \(n\) and \(m\), the circular Eulerian number \(C_{n,m}\) is the number of permutations \(\sigma\) of \(\{0, 1, \dots, n-1\}\) such that \(n \ge 1\), all points lie in a single cycle of \(\sigma\) (for any two points \(i\) and \(j\) there is an integer \(k\) with \(\sigma^k(i) = j\)), and \(\sigma\) has exactly \(m\) excedances, that is, exactly \(m\) points \(i\) with \(\sigma(i) > i\). In particular \(C_{0,m} = 0\) for every \(m\), and the identity permutation of a single point counts as circular.

    For \(n \ge 2\) the permutations with a single cycle through all points are exactly the \(n\)-cycles.

    def circularEulerian (n m : ℕ) : ℕ :=
  (Finset.univ.filter (fun σ : Equiv.Perm (Fin n) =>
    (0 < n ∧ ∀ i j : Fin n, σ.SameCycle i j) ∧
      excedanceCount n σ = m)).card
    def excedanceCount (n : ℕ) (σ : Equiv.Perm (Fin n)) : ℕ :=
  (Finset.univ.filter (fun i : Fin n => i < σ i)).card

    DefinitionExcedance and cycle generating function of a permutation family#✓fully proved

    MetaMathlibExt.permExcedanceCycleEGF

    Let \(R\) be a commutative \(\mathbb{Q}\)-algebra, let \(x, q \in R\), and for each \(n\) let \(P_n\) be a set of permutations of \(\{0, 1, \dots, n-1\}\). The excedance and cycle exponential generating function of the family \((P_n)\) is the formal power series in \(u\) over \(R\)

    \[\sum_{n \ge 0} \frac{1}{n!} \Big(\sum_{\sigma \in P_n} x^{e(\sigma)} q^{c(\sigma)}\Big) u^n,\]

    where \(e(\sigma)\) is the number of excedances of \(\sigma\) (points \(i\) with \(\sigma(i) > i\)) and \(c(\sigma)\) its number of cycles, fixed points counted as cycles of length one.

    With \(q = 1\) this is the paper's \(P(x, u)\), and for general \(q\) its \(q\)-analogue \(P(q, x, u)\).

    noncomputable def permExcedanceCycleEGF {R : Type*} [CommRing R] [Algebra ℚ R]
    (P : ∀ n, Equiv.Perm (Fin n) → Prop) [∀ n, DecidablePred (P n)] (x q : R) :
    PowerSeries R :=
  PowerSeries.mk fun n => ((n.factorial : ℚ)⁻¹) •
    ∑ σ ∈ Finset.univ.filter (P n), x ^ excedanceCount n σ * q ^ cycleQuotientCount σ
