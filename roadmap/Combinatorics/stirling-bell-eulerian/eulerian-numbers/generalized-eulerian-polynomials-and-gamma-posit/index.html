    DefinitionGenerating function of the generalized Eulerian polynomials#✓fully proved

    MetaMathlibExt.generalizedEulerianSeries

    For rational numbers \(q\), \(t\), \(x\), \(y\) with \(x \ne y\), this is the formal power series in \(z\) over \(\mathbb{Q}\)

    \[\mathcal{P}(q, t; x, y; z) = \left(\frac{x - y}{x e^{yz} - y e^{xz}}\right)^q e^{(x+y)qtz}.\]

    Here the base has constant term \(1\), and its \(q\)-th power is the binomial series \((1 + u)^q = \sum_{n \ge 0} \binom{q}{n} u^n\) with \(u\) the base minus \(1\). For \(x = y\) the denominator is zero and the formula above does not apply.

    noncomputable def generalizedEulerianSeries (q t x y : ℚ) : PowerSeries ℚ :=
  (binomialSeries ℚ q).subst
      (C (x - y) * (C x * rescale y (exp ℚ) - C y * rescale x (exp ℚ))⁻¹ - 1) *
    rescale ((x + y) * q * t) (exp ℚ)

    DefinitionGeneralized Eulerian polynomials#✓fully proved

    MetaMathlibExt.generalizedEulerianP

    For rational numbers \(q, t, x, y\) and \(n \ge 0\), the generalized Eulerian polynomial \(P_n(q, t; x, y)\) is \(n!\) times the coefficient of \(z^n\) in the formal power series over \(\mathbb{Q}\)

    \[\mathcal{P}(q, t; x, y; z) = \left(\frac{x - y}{x e^{yz} - y e^{xz}}\right)^q e^{(x + y) q t z},\]

    where the \(q\)-th power is the binomial series \((1 + u)^q = \sum_{k \ge 0} \binom{q}{k} u^k\) applied to \(u = \frac{x - y}{x e^{yz} - y e^{xz}} - 1\). When \(x \ne y\) the quotient has constant term \(1\), so \(u\) has constant term \(0\); for \(x = y\) the formula is degenerate and the value of \(P_n\) is a formal convention.

    noncomputable def generalizedEulerianP (q t x y : ℚ) (n : ℕ) : ℚ :=
  (n.factorial : ℚ) * coeff n (generalizedEulerianSeries q t x y)
    noncomputable def generalizedEulerianSeries (q t x y : ℚ) : PowerSeries ℚ :=
  (binomialSeries ℚ q).subst
      (C (x - y) * (C x * rescale y (exp ℚ) - C y * rescale x (exp ℚ))⁻¹ - 1) *
    rescale ((x + y) * q * t) (exp ℚ)

    TheoremExponential generating function of excedances over cyclic permutations#●ready to prove

    MetaMathlibExt.cyclicExcedanceEGF_eq

    Let \(x \ne 1\) be a rational number. For \(n \ge 1\) let \(C_n(x) = \sum_{m=0}^{n} C_{n,m} x^m\), where the circular Eulerian number \(C_{n,m}\) is the number of permutations \(w\) of \(\{0, 1, \dots, n-1\}\) whose points all lie in a single cycle and which have exactly \(m\) excedances, that is, points \(i\) with \(w(i) > i\). Then, as formal power series in \(z\) over \(\mathbb{Q}\),

    \[\sum_{n \ge 1} C_n(x) \frac{z^n}{n!} = z + \log \frac{x - 1}{x e^z - e^{xz}},\]

    where the quotient has constant term \(1\) and \(\log\) is the formal logarithm of a power series with constant term \(1\).

    public theorem_wanted cyclicExcedanceEGF_eq (x : ℚ) (hx : x ≠ 1) :
    PowerSeries.mk (fun n ↦ if n = 0 then 0 else
        (∑ m ∈ Finset.range (n + 1), (circularEulerian n m : ℚ) * x ^ m) / (n.factorial : ℚ)) =
      X + logOf (C (x - 1) * (C x * exp ℚ - rescale x (exp ℚ))⁻¹)
    def circularEulerian (n m : ℕ) : ℕ :=
  (Finset.univ.filter (fun σ : Equiv.Perm (Fin n) =>

    TheoremThe gamma coefficients of the generalized Eulerian polynomials have nonnegative integer coefficients#●ready to prove

    MetaMathlibExt.generalizedEulerianP_gamma_nonneg

    The gamma coefficients of the generalized Eulerian polynomials have nonnegative integer coefficients. Fix \(n \ge 0\) and let \(P_n(q, t; x, y)\) be the generalized Eulerian polynomial. There are natural numbers \(c_{k,i,j}\), for \(k, i, j \ge 0\), such that, writing \(\gamma_{n,k}(q, t) = \sum_{i=0}^{n} \sum_{j=0}^{n} c_{k,i,j} q^i t^j\), for all rational numbers \(q, t, x, y\) with \(x \ne y\),

    \[ P_n(q, t; x, y) = \sum_{k=0}^{\lfloor n/2 \rfloor} \gamma_{n,k}(q, t) x^k y^k (x + y)^{n - 2k}. \]

    That is, the gamma coefficients \(\gamma_{n,k}\) are polynomials in \(q\) and \(t\) with nonnegative integer coefficients.

    public theorem_wanted generalizedEulerianP_gamma_nonneg (n : ℕ) :
    ∃ c : ℕ → ℕ → ℕ → ℕ, ∀ q t x y : ℚ, x ≠ y →
      generalizedEulerianP q t x y n =
        ∑ k ∈ Finset.range (n / 2 + 1),
          (∑ i ∈ Finset.range (n + 1), ∑ j ∈ Finset.range (n + 1),
            (c k i j : ℚ) * q ^ i * t ^ j) * x ^ k * y ^ k * (x + y) ^ (n - 2 * k)
    noncomputable def generalizedEulerianP (q t x y : ℚ) (n : ℕ) : ℚ :=
  (n.factorial : ℚ) * coeff n (generalizedEulerianSeries q t x y)
