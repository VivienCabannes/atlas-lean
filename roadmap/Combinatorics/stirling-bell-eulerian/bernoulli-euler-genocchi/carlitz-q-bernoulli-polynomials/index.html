    DefinitionThe \(q\)-analogue of a real number#✓fully proved

    MetaMathlibExt.qBracket

    For real numbers \(q\) and \(x\), the \(q\)-analogue of \(x\) is

    \[[x]_q = \frac{q^x - 1}{q - 1},\]

    where \(q^x\) is the real power; we write \([x]\) when \(q\) is fixed. When \(q = 1\) the denominator is \(0\) and the quotient is taken to be \(0\).

    public noncomputable def qBracket (q x : ℝ) : ℝ :=
  (q ^ x - 1) / (q - 1)

    DefinitionCarlitz-type sequences#✓fully proved

    MetaMathlibExt.IsCarlitzTypeWith

    For real \(q\), a sequence of functions \(T_n : \mathbb{R} \to \mathbb{R}\), \(n \ge 0\), is Carlitz-type with associated real sequence \((a_k)_{k \ge 0}\) if for every natural number \(n\) and every real \(x\), \(T_n(x) = (q - 1)^{-n} \sum_{k=0}^{n} (-1)^{n-k} \binom{n}{k} a_k q^{kx}\).

    public def IsCarlitzTypeWith (q : ℝ) (T : ℕ → ℝ → ℝ) (a : ℕ → ℝ) : Prop :=
  ∀ n x, T n x = ((q - 1) ^ n)⁻¹ *
    ∑ k ∈ range (n + 1), (-1 : ℝ) ^ (n - k) * (n.choose k : ℝ) * a k * q ^ ((k : ℝ) * x)

    DefinitionCarlitz \(q\)-polynomials \(\eta_n\)#✓fully proved

    MetaMathlibExt.carlitzEtaPoly

    For real \(q\), write \([y] = (q^y - 1)/(q - 1)\) and let \(a_0 = 1\) and \(a_k = k/[k]\) for \(k \ge 1\). For natural \(n\) and real \(x\), Carlitz's \(q\)-polynomial is \(\eta_n(x) = (q - 1)^{-n} \sum_{k=0}^{n} (-1)^{n-k} \binom{n}{k} a_k q^{kx}\); that is, \((\eta_n)\) is the Carlitz-type sequence with associated sequence \((a_k)\). Its values at \(0\) are written \(\eta_n = \eta_n(0)\).

    public noncomputable def carlitzEtaPoly (q : ℝ) (n : ℕ) (x : ℝ) : ℝ :=
  ((q - 1) ^ n)⁻¹ * ∑ k ∈ range (n + 1), (-1 : ℝ) ^ (n - k) * (n.choose k : ℝ) *
    (if k = 0 then 1 else (k : ℝ) / qBracket q k) * q ^ ((k : ℝ) * x)
    public noncomputable def qBracket (q x : ℝ) : ℝ :=
  (q ^ x - 1) / (q - 1)

    TheoremSymbolic recurrence for Carlitz-type sequences#●ready to prove

    MetaMathlibExt.carlitzType_symbolic_recurrence

    Let \(q > 0\) with \(q \ne 1\), write \([x] = (q^x - 1)/(q - 1)\), let \(r\) be a natural number, let \(P\) be a real polynomial and let \((a_k)\) be a real sequence with \([k + r]\, a_k = P(k)\) for every natural number \(k\). If \((T_n)\) is a Carlitz-type sequence with associated sequence \((a_k)\) and \(t_n = T_n(0)\), then for every natural number \(n\) greater than the degree of \(P\) (taken to be \(0\) when \(P = 0\)), \(q^r \sum_{j=0}^{n} \binom{n}{j} q^j t_j = t_n\), which in umbral notation reads \(q^r (q t + 1)^n = t^n\).
