    DefinitionEntries of the α-Stirling matrix#✓fully proved

    MetaMathlibExt.alphaStirlingEntry

    Let \(R\) be a commutative ring and let \(\alpha_0, \alpha_1, \alpha_2, \dots\) be a sequence in \(R\) (\(\alpha_0\) is never used). The α-Stirling entries \(s_{i,j} \in R\), for \(i, j \ge 0\), are defined recursively by \(s_{i,0} = \alpha_1\) for all \(i\), \(s_{0,j} = 0\) for \(j \ge 1\), and \(s_{i+1,j+1} = s_{i,j} + \alpha_{j+2} s_{i,j+1}\) for all \(i, j \ge 0\).

    These are the entries of the paper's matrix \(S_\alpha(n)\) with indices shifted to start at \(0\). Writing \(\hat S_{i,j}\) for the entries of \(S_\alpha(n)\) in the paper's \(1\)-based indexing, the first column is \(\alpha_1\), the rest of the first row is \(0\), and \(\hat S_{i,j} = \hat S_{i-1,j-1} + \alpha_j \hat S_{i-1,j}\) for \(i, j \ge 2\).

    def alphaStirlingEntry (α : ℕ → R) : ℕ → ℕ → R
  | _, 0 => α 1
  | 0, _ + 1 => 0
  | i + 1, j + 1 => alphaStirlingEntry α i j + α (j + 2) * alphaStirlingEntry α i (j + 1)

    MetaMathlibExt.shiftedAlphaStirlingEntry

    Let \(R\) be a commutative ring and let \(\alpha = (\alpha_j)_{j \ge 1}\) be a sequence in \(R\). The entries \(\mathsf{S}_{i,j} \in R\) of the shifted \(\alpha\)-Stirling matrix of \(\alpha\), for natural numbers \(i\) and \(j\) counted from \(0\), are defined by \(\mathsf{S}_{i,0} = \alpha_1\) for all \(i\), \(\mathsf{S}_{0,j} = \alpha_1\) for all \(j\), and

    \[\mathsf{S}_{i+1,j+1} = \mathsf{S}_{i+1,j} + \alpha_{j+2} \mathsf{S}_{i,j+1}.\]

    The paper indexes from \(1\): its entry \((i, j)\) is \(P_{i,j} = \mathsf{S}_{i-1,j-1}\) for \(i, j \ge 1\). In this indexing the first row and the first column equal \(\alpha_1\), and \(P_{i,j} = P_{i,j-1} + \alpha_j P_{i-1,j}\) for \(i, j \ge 2\).

    def shiftedAlphaStirlingEntry (α : ℕ → R) : ℕ → ℕ → R
  | _, 0 => α 1
  | 0, _ + 1 => α 1
  | i + 1, j + 1 =>
      shiftedAlphaStirlingEntry α (i + 1) j + α (j + 2) * shiftedAlphaStirlingEntry α i (j + 1)

    MetaMathlibExt.alphaUpperEntry

    Let \(R\) be a commutative ring and let \(\alpha_0, \alpha_1, \alpha_2, \dots\) be a sequence in \(R\) (\(\alpha_0\) is never used). The α-upper entries \(u_{i,j} \in R\), for \(i, j \ge 0\), are defined recursively by \(u_{0,j} = 1\) for all \(j\), \(u_{i,0} = 0\) for \(i \ge 1\), and \(u_{i+1,j+1} = u_{i+1,j} + \alpha_{i+1} u_{i,j} + (\alpha_{j+2} - \alpha_{i+1}) u_{i,j+1}\) for all \(i, j \ge 0\).

    These are the entries of the paper's matrix \(\mathsf{U}_\alpha(n)\) with indices shifted to start at \(0\); in the paper's \(1\)-based indexing the first row is \(1\), the rest of the first column is \(0\), and \(\mathsf{U}_{i,j} = \mathsf{U}_{i,j-1} + \alpha_{i-1} \mathsf{U}_{i-1,j-1} + (\alpha_j - \alpha_{i-1}) \mathsf{U}_{i-1,j}\) for \(i, j \ge 2\).

    def alphaUpperEntry (α : ℕ → R) : ℕ → ℕ → R
  | 0, _ => 1
  | _ + 1, 0 => 0
  | i + 1, j + 1 =>
      alphaUpperEntry α (i + 1) j + α (i + 1) * alphaUpperEntry α i j +
        (α (j + 2) - α (i + 1)) * alphaUpperEntry α i (j + 1)
