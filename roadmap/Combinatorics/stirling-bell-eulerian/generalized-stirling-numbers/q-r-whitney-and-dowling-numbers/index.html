    MetaMathlibExt.QRWhitney.qBrack

    For a complex number \(q\) and a natural number \(n\), the q-integer \([n]_q\) is the finite geometric sum \([n]_q = \sum_{i=0}^{n-1} q^i\).

    Taking the sum rather than \((1 - q^n)/(1 - q)\) as the definition avoids any singularity at \(q = 1\).

    def qBrack (q : ℂ) (n : ℕ) : ℂ :=
  Finset.sum (Finset.range n) (fun i => q ^ i)

    MetaMathlibExt.QRWhitney.whitneyFirst

    Let \(m, r, q\) be complex numbers with \(q \ne 0\), and for a natural number \(j\) let \([j]_q = \sum_{i=0}^{j-1} q^i\) be the q-integer. The (q, r)-Whitney numbers of the first kind \(w(n, k) = w_{m,r,q}(n, k)\), for natural numbers \(n\) and \(k\), are defined by \(w(0, 0) = 1\), \(w(0, k + 1) = 0\) and, for all \(n\) and \(k\),

    \[w(n + 1, 0) = -q^{-n} (m [n]_q + r) \, w(n, 0),\]
    \[w(n + 1, k + 1) = q^{-n} \bigl( w(n, k) - (m [n]_q + r) \, w(n, k + 1) \bigr).\]
    noncomputable def whitneyFirst (m r q : ℂ) [NeZero q] : ℕ → ℕ → ℂ
  | 0 => fun | 0 => 1 | _ + 1 => 0
  | n + 1 => fun
    | 0 => (q ^ n)⁻¹ * (0 - (m * qBrack q n + r) * whitneyFirst m r q n 0)
    | k + 1 =>
      (q ^ n)⁻¹ *
        (whitneyFirst m r q n k -
          (m * qBrack q n + r) * whitneyFirst m r q n (k + 1))
    def qBrack (q : ℂ) (n : ℕ) : ℂ :=
  Finset.sum (Finset.range n) (fun i => q ^ i)

    MetaMathlibExt.QRWhitney.whitneySecond

    For complex numbers \(m\), \(r\), \(q\), the \((q, r)\)-Whitney numbers of the second kind \(W_{m,r,q}(n, k)\), indexed by natural numbers \(n\) and \(k\), are defined by \(W_{m,r,q}(0, 0) = 1\), \(W_{m,r,q}(0, k + 1) = 0\), \(W_{m,r,q}(n + 1, 0) = r \, W_{m,r,q}(n, 0)\) and

    \[ W_{m,r,q}(n + 1, k + 1) = q^k \, W_{m,r,q}(n, k) + (m [k + 1]_q + r) \, W_{m,r,q}(n, k + 1), \]

    where \([j]_q = 1 + q + \dots + q^{j-1}\) is the \(q\)-integer.

    def whitneySecond (m r q : ℂ) : ℕ → ℕ → ℂ

  | n + 1 => fun
    | 0 => r * whitneySecond m r q n 0
    | k + 1 =>
      q ^ k * whitneySecond m r q n k +
        (m * qBrack q (k + 1) + r) * whitneySecond m r q n (k + 1)
    def qBrack (q : ℂ) (n : ℕ) : ℂ :=
  Finset.sum (Finset.range n) (fun i => q ^ i)
