    TheoremOrthogonality relation for Stirling numbers#✓fully proved

    MetaMathlibExt.sum_signedStirlingFirst_mul_stirlingSecond

    Write \(c(n,k)\) for the unsigned Stirling numbers of the first kind, \(s(n,k) = (-1)^{n-k} c(n,k)\) for the signed ones, and \(S(k,m)\) for the Stirling numbers of the second kind. For all natural numbers \(n\) and \(m\),

    \[\sum_{k=0}^{n} s(n,k)\, S(k,m) = \delta_{nm},\]

    where \(\delta_{nm}\) is \(1\) if \(n = m\) and \(0\) otherwise.

    theorem sum_signedStirlingFirst_mul_stirlingSecond (n m : ℕ) :
    ∑ k ∈ Finset.range (n + 1), signedStirlingFirst n k * (Nat.stirlingSecond k m : ℤ) =
      if n = m then 1 else 0
    def signedStirlingFirst : ℕ → ℕ → ℤ :=
  fun n k => (-1 : ℤ) ^ (n - k) * (Nat.stirlingFirst n k : ℤ)

    TheoremStirling matrices are mutually inverse and lower triangular#✓fully proved

    MetaMathlibExt.stirlingMatrices_mutualInverse_and_lowerTriangular

    Let \(N\) be a natural number, and let \(A\) and \(B\) be the \(N \times N\) integer matrices with rows and columns indexed by \(0, 1, \dots, N-1\) and entries \(A_{ij} = (-1)^{i-j} c(i,j)\) and \(B_{ij} = S(i,j)\), where \(c(i,j)\) is the unsigned Stirling number of the first kind and \(S(i,j)\) the Stirling number of the second kind. Then \(AB = BA = I\), and \(A_{ij} = B_{ij} = 0\) whenever \(i < j\).

    theorem stirlingMatrices_mutualInverse_and_lowerTriangular (N : ℕ) :
    let s : Matrix (Fin N) (Fin N) ℤ := fun i j =>
      (-1 : ℤ) ^ (i.1 - j.1) * (Nat.stirlingFirst i.1 j.1 : ℤ)
    let S : Matrix (Fin N) (Fin N) ℤ := fun i j =>
      (Nat.stirlingSecond i.1 j.1 : ℤ)
    s * S = 1 ∧ S * s = 1 ∧
      (∀ i j, i < j → s i j = 0) ∧
      (∀ i j, i < j → S i j = 0)

    DefinitionStrictly upper triangular matrix \(Q^{(N)}(n)\)#✓fully proved

    MetaMathlibExt.stirlingQMatrix

    For natural numbers \(N\) and \(n\), \(Q^{[N]}(n)\) is the \(n \times n\) matrix with rational entries

    \[Q^{[N]}(n)_{i,j} = \frac{(-1)^{j-i+1}\, i^{N-1}}{(i-1)!\,(j-i-1)!} \quad (1 \le i < j \le n)\]

    and \(Q^{[N]}(n)_{i,j} = 0\) for \(1 \le j \le i \le n\). Here \(N - 1\) is truncated subtraction, so \(Q^{[0]}(n) = Q^{[1]}(n)\).

    public def stirlingQMatrix (N n : ℕ) : Matrix (Fin n) (Fin n) ℚ :=
  Matrix.of fun a b =>
    if a.val + 1 ≤ b.val then
      (-1 : ℚ) ^ (b.val - a.val + 1) * ((a.val + 1 : ℕ) : ℚ) ^ (N - 1) /
        ((a.val.factorial : ℚ) * ((b.val - a.val - 1).factorial : ℚ))
    else 0
