    TheoremAlzer–Richards derivative identity for powers of \(1 - f\)#●ready to prove

    MetaMathlibExt.sum_iteratedDeriv_pow_one_sub

    Let \(r, j, n \ge 0\) be integers and let \(f \colon \mathbb{R} \to \mathbb{R}\) be \(r\) times continuously differentiable. Writing \(g^{(i)}\) for the \(i\)-th derivative of a function \(g\) and taking powers of \(f\) pointwise, for every real \(x\)

    \[ \sum_{k=0}^{n} (-1)^{k+1} \binom{n+1}{k+1} \bigl(f^{k+1+j}\bigr)^{(r)}(x) = \sum_{k=0}^{r} \binom{r}{k} \bigl(f^j\bigr)^{(k)}(x) \, \bigl((1-f)^{n+1} - 1\bigr)^{(r-k)}(x). \]
    theorem_wanted sum_iteratedDeriv_pow_one_sub {f : ℝ → ℝ} {r : ℕ} (hf : ContDiff ℝ r f)
    (j n : ℕ) (x : ℝ) :
    ∑ k ∈ range (n + 1), (-1 : ℝ) ^ (k + 1) * ((n + 1).choose (k + 1) : ℝ) *
        iteratedDeriv r (fun y => f y ^ (k + 1 + j)) x =
      ∑ k ∈ range (r + 1), (r.choose k : ℝ) * iteratedDeriv k (fun y => f y ^ j) x *
        iteratedDeriv (r - k) (fun y => (1 - f y) ^ (n + 1) - 1) x

    TheoremAlternating Stirling sums with \(\binom{n+1}{k+1}\) give Bernoulli numbers#●ready to prove

    MetaMathlibExt.sum_choose_div_choose_mul_stirlingSecond_eq_bernoulli

    Write \(S(n, k)\) for the Stirling numbers of the second kind and \(B_n\) for the Bernoulli numbers, with \(B_1 = -1/2\). Let \(n\) be a natural number. Then for every natural number \(r \le n\),

    \[ \sum_{k=0}^{n} (-1)^k \frac{\binom{n+1}{k+1}}{\binom{r+k}{k}} S(r+k, k) = B_r, \]

    and

    \[ \sum_{k=0}^{n} (-1)^k \frac{\binom{n+1}{k+1}}{\binom{n+1+k}{k}} S(n+1+k, k) = B_{n+1} - (-1/2)^{n+1} (n+1)!. \]

    The case \(r = n\) is Muthumalai's formula.

    theorem_wanted sum_choose_div_choose_mul_stirlingSecond_eq_bernoulli (n : ℕ) :
    (∀ r ≤ n, ∑ k ∈ range (n + 1), (-1 : ℚ) ^ k *
        (((n + 1).choose (k + 1) : ℚ) / ((r + k).choose k : ℚ)) *
          (Nat.stirlingSecond (r + k) k : ℚ) = bernoulli r) ∧
      ∑ k ∈ range (n + 1), (-1 : ℚ) ^ k *
          (((n + 1).choose (k + 1) : ℚ) / ((n + 1 + k).choose k : ℚ)) *
            (Nat.stirlingSecond (n + 1 + k) k : ℚ) =
        bernoulli (n + 1) - (-1 / 2 : ℚ) ^ (n + 1) * ((n + 1).factorial : ℚ)

    TheoremAlzer–Richards identity for Euler numbers#●ready to prove

    MetaMathlibExt.sum_eulerNumber_mul_sum_centralPowerSum

    Let \(n \ge 1\) be an integer. For integers \(k, i \ge 0\) let \(T(k, i) = 2^{-k} \sum_{j=0}^{k} \binom{k}{j} (k-2j)^i\) (with \(0^0 = 1\)), and let \(E_k\) be the Euler numbers: \(E_k = 0\) for odd \(k\), and for even \(k\) they are given by \(E_0 = 1\) and \(E_{2m} = -\sum_{s=0}^{m-1} \binom{2m}{2s} E_{2s}\) for \(m \ge 1\). Then

    \[ \sum_{k=0}^{n-1} \binom{n}{k} E_k \sum_{\nu=0}^{n+1} \binom{n+1}{\nu} T(\nu, n-k) + (2^{n+1} - 1) E_n = \sum_{k=0}^{n} \binom{n+1}{k+1} T(k, n). \]

    With these conventions \(1/\cosh x = \sum_{k \ge 0} E_k x^k / k!\).

    theorem_wanted sum_eulerNumber_mul_sum_centralPowerSum {n : ℕ} (hn : 1 ≤ n)
    (T : ℕ → ℕ → ℚ)
    (hT : ∀ k n, T k n = (∑ j ∈ range (k + 1), (k.choose j : ℚ) * ((k : ℚ) - 2 * j) ^ n) / 2 ^ k) :
    ∑ k ∈ range n, (n.choose k : ℚ) * ((if k % 2 = 1 then 0 else chapter5EulerEven (k / 2) : ℤ) : ℚ) *
        ∑ ν ∈ range (n + 2), ((n + 1).choose ν : ℚ) * T ν (n - k) +
      (2 ^ (n + 1) - 1) * ((if n % 2 = 1 then 0 else chapter5EulerEven (n / 2) : ℤ) : ℚ) =
    ∑ k ∈ range (n + 1), ((n + 1).choose (k + 1) : ℚ) * T k n

  Nat.strongRec (motive := fun _ => ℤ)
    (fun m previous =>
      if m = 0 then 1
      else -∑ k : Fin m,
        (Nat.choose (2 * m) (2 * k.val) : ℤ) * previous k.val k.isLt) n

    TheoremAlzer–Richards identity for Fubini numbers#●ready to prove

    MetaMathlibExt.sum_fubiniNumber_mul_sum_alternatingStirling

    Let \(n \ge 1\) be an integer, let \(a(k)\) be the \(k\)-th Fubini (ordered Bell) number and \(S(r, j)\) the Stirling numbers of the second kind, and for integers \(r, k \ge 0\) let \(A(r, k) = \sum_{j=0}^{k} (-1)^j \binom{k}{j} j! \, S(r, j)\). Then

    \[ \sum_{k=0}^{n-1} \binom{n}{k} a(k) \sum_{\nu=0}^{n+1} \binom{n+1}{\nu} A(n-k, \nu) + (2^{n+1} - 1) a(n) = \sum_{k=0}^{n} \binom{n+1}{k+1} A(n, k). \]
    theorem_wanted sum_fubiniNumber_mul_sum_alternatingStirling {n : ℕ} (hn : 1 ≤ n)
    (A : ℕ → ℕ → ℤ)
    (hA : ∀ r k, A r k = ∑ j ∈ range (k + 1),
      (-1 : ℤ) ^ j * (k.choose j : ℤ) * (j.factorial : ℤ) * (Nat.stirlingSecond r j : ℤ)) :
    ∑ k ∈ range n, (n.choose k : ℤ) * fubiniNumber k *
        ∑ ν ∈ range (n + 2), ((n + 1).choose ν : ℤ) * A (n - k) ν +
      (2 ^ (n + 1) - 1) * fubiniNumber n =
    ∑ k ∈ range (n + 1), ((n + 1).choose (k + 1) : ℤ) * A n k
    def fubiniNumber : Nat → Nat :=
  fun n => ∑ k ∈ Finset.range (n + 1), Nat.stirlingSecond n k * Nat.factorial k
