    DefinitionCapacity of a word#✓fully proved

    MetaMathlibExt.wordCapacity

    The capacity of a word \(w = w_1 \cdots w_n\) of natural numbers, viewed as a bargraph, is

    \[\mathrm{cap}(w) = \sum_{i=1}^{n} \max\Bigl(0, \min\bigl(\max_{j < i} w_j, \max_{j > i} w_j\bigr) - w_i\Bigr),\]

    the number of cells of water held above the columns, where an empty maximum is \(0\). In particular the first and last columns hold no water.

    public def wordCapacity {n : ℕ} (w : Fin n → ℕ) : ℕ :=
  ∑ i : Fin n,
    (min ((Finset.univ.filter (· < i)).sup w) ((Finset.univ.filter (i < ·)).sup w) - w i)

    DefinitionCatalan words#✓fully proved

    MetaMathlibExt.catalanWords

    For a natural number \(n\), the set \(\mathcal{A}_n\) of Catalan words of length \(n\) consists of the words \(w = w_1 w_2 \cdots w_n\) of positive integers with \(w_1 = 1\) and \(w_{i+1} \le w_i + 1\) for \(1 \le i < n\); for \(n = 0\) it contains only the empty word.

    Every letter of a Catalan word of length \(n\) is at most \(n\), so \(\mathcal{A}_n\) is finite.

    public def catalanWords (n : ℕ) : Finset (Fin n → ℕ) :=
  (Fintype.piFinset fun _ : Fin n => Finset.Icc 1 n).filter fun w =>
    (∀ i : Fin n, i.val = 0 → w i = 1) ∧ ∀ i j : Fin n, j.val = i.val + 1 → w j ≤ w i + 1
