    TheoremDejean's theorem on repetition thresholds#●ready to prove

    MetaMathlibExt.dejean_repetition_threshold

    For a natural number \(n\) and a real number \(r\), call an infinite word \(w = w_0 w_1 w_2 \cdots\) over the alphabet \(\{0, \dots, n-1\}\) \(r^+\)-free if for all natural numbers \(s\), \(\ell\) and \(p\) with \(0 < p \le \ell\) such that \(w_{s+i+p} = w_{s+i}\) for every natural number \(i\) with \(i + p < \ell\), we have \(\ell / p \le r\); that is, no factor of \(w\) has exponent strictly greater than \(r\). Let \(\mathrm{RT}(n)\), the repetition threshold, be the infimum of the set of real numbers \(r > 1\) for which there is an infinite \(r^+\)-free word over \(\{0, \dots, n-1\}\). Then \(\mathrm{RT}(2) = 2\), \(\mathrm{RT}(3) = 7/4\), \(\mathrm{RT}(4) = 7/5\), and \(\mathrm{RT}(n) = n/(n-1)\) for every \(n \ge 5\).

    This is a proved result (Dejean's conjecture of 1972): the last cases were proved in 2011 by Currie and Rampersad and, independently, by Rao.

    Paper: James D. Currie, Lucas Mol, and Narad Rampersad, "The Number of Threshold Words on n Letters Grows Exponentially for Every n ≥ 27", Journal of Integer Sequences 23 (2020), Article 20.3.1.

    public theorem_wanted dejean_repetition_threshold :
    let IsRPlusFree : (n : ℕ) → ℝ → (ℕ → Fin n) → Prop :=
      fun n r w =>
        ∀ start len p : ℕ, 0 < p → p ≤ len →
          (∀ i : ℕ, i + p < len → w (start + i + p) = w (start + i)) →
            (len : ℝ) / (p : ℝ) ≤ r;
    let RT : ℕ → ℝ :=
      fun n => sInf { r : ℝ | 1 < r ∧ ∃ w : ℕ → Fin n, IsRPlusFree n r w };
    RT 2 = 2 ∧ RT 3 = (7 : ℝ) / 4 ∧ RT 4 = (7 : ℝ) / 5 ∧
      ∀ n : ℕ, 5 ≤ n → RT n = (n : ℝ) / ((n - 1 : ℕ) : ℝ)

    TheoremExponential lower bound for ternary abelian-cube-free words#✓fully proved

    MetaMathlibExt.abelianCubeFree

    An abelian cube is a word \(xyz\) with \(x\), \(y\), \(z\) nonempty such that each letter occurs equally often in \(x\), \(y\) and \(z\). Let \(a_n\) be the number of words of length \(n\) over \(\{0, 1, 2\}\) that contain no abelian cube as a factor. Then \(2^{n/24} = O(a_n)\) as \(n \to \infty\): there is a constant \(C\) such that \(2^{n/24} \le C a_n\) for all sufficiently large \(n\).

    theorem abelianCubeFree :
    Asymptotics.IsBigO Filter.atTop (fun n : ℕ => (2 : ℝ) ^ ((n : ℝ) / 24))
      (fun n : ℕ => ((Set.ncard {w : List (Fin 3) | w.length = n ∧
        ¬ ∃ p x y z s : List (Fin 3), w = p ++ x ++ y ++ z ++ s ∧
          x ≠ [] ∧ y ≠ [] ∧ z ≠ [] ∧
          ∀ a : Fin 3, x.count a = y.count a ∧ y.count a = z.count a}) : ℝ))

    TheoremKurosaki's words are \((7/4)^+\)-power-free#✓fully proved

    MetaMathlibExt.kurosaki_phi_pow_power_free

    On the alphabet \(\{1, 2, 3\}\), let \(\sigma\) be the permutation that swaps \(1\) and \(2\) and fixes \(3\), let \(\rho\) be the permutation that swaps \(2\) and \(3\) and fixes \(1\), and for a finite word \(w\) let \(\varphi(w) = \sigma(w)\,w\,\rho(w)\), where \(\sigma(w)\) and \(\rho(w)\) apply the permutation to each letter of \(w\). Call \(p \ge 1\) a period of a finite word \(u = u_0 u_1 \cdots\) when \(u_i = u_{i+p}\) for every \(i\) with \(i + p < |u|\). For every \(n \ge 1\), every factor \(u\) of the word \(\varphi^n(2)\) and every period \(p\) of \(u\) satisfy \(4|u| \le 7p\); that is, every factor of \(\varphi^n(2)\) has exponent at most \(7/4\).

    theorem kurosaki_phi_pow_power_free :
    let sigma : Fin 3 → Fin 3 := fun a => if a.val = 0 then 1 else if a.val = 1 then 0 else 2;
    let rho : Fin 3 → Fin 3 := fun a => if a.val = 1 then 2 else if a.val = 2 then 1 else 0;
    let phiW : List (Fin 3) → List (Fin 3) := fun a => (List.map sigma a) ++ a ++ (List.map rho a);
    let W : Nat → List (Fin 3) := fun n => Nat.rec (motive := fun _ => List (Fin 3)) [(1 : Fin 3)]
      (fun _ ih => phiW ih) n;
    ∀ n : Nat, 1 ≤ n → ∀ w l1 l2 : List (Fin 3), W n = l1 ++ w ++ l2 → ∀ p : Nat, 0 < p →
      (∀ i : Nat, i + p < List.length w → w[i]? = w[i + p]?) → 4 * List.length w ≤ 7 * p
