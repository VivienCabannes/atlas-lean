    The Fibonacci substitution sends each letter of the binary alphabet \(\{0, 1\}\) to a finite binary word: it maps \(0\) to \(01\) and \(1\) to \(0\).

    The letters \(0\) and \(1\) are represented by the Booleans false and true.

    def fibSubst : Bool → List Bool
  | false => [false, true]
  | true => [false]

    DefinitionFibonacci morphism#✓fully proved

    MetaMathlibExt.fibMorph

    The Fibonacci morphism \(\varphi\) extends the Fibonacci substitution \(\sigma\), which maps \(0\) to \(01\) and \(1\) to \(0\), to finite binary words by concatenation: \(\varphi\) maps the empty word to the empty word, and \(\varphi(bw) = \sigma(b)\varphi(w)\) for every letter \(b\) and every finite binary word \(w\).

    def fibMorph : List Bool → List Bool
  | [] => []
  | b :: w => fibSubst b ++ fibMorph w
    def fibSubst : Bool → List Bool
  | false => [false, true]
  | true => [false]

    MetaMathlibExt.fibWord

    The finite Fibonacci words \(f_n\), for natural numbers \(n\), are the words in the letters \(0\) and \(1\) defined by \(f_0 = 0\) and \(f_{n+1} = \varphi(f_n)\), where \(\varphi\) is the Fibonacci morphism, which replaces each letter \(0\) by \(01\) and each letter \(1\) by \(0\).

    The first words are \(0\), \(01\), \(010\), \(01001\), \(01001010\), and so on.

    MetaMathlibExt.fibInf

    Let \(f_0 = 0\) and let \(f_{k+1}\) be the image of \(f_k\) under the Fibonacci morphism (\(0 \mapsto 01\), \(1 \mapsto 0\)), so that \(f_0, f_1, f_2, \ldots\) are the finite Fibonacci words \(0, 01, 010, 01001, \ldots\). The one-sided infinite Fibonacci word is the infinite binary word whose letter at index \(n\) (indices start at \(0\)) is the letter of \(f_{n+2}\) at index \(n\).

    Each \(f_k\) is a prefix of \(f_{k+1}\) and \(f_{n+2}\) has more than \(n\) letters, so this word is the limit of the finite Fibonacci words.

    def fibInf (n : ℕ) : Bool :=
  (fibWord (n + 2)).getD n false

    TheoremKimberling's set modulo 2 is the Fibonacci word#✓fully proved

    MetaMathlibExt.kimberling_set_mod_two_fibonacci_word

    Let \(K\) be the set of natural numbers obtained from \(1\) by finitely many applications of the maps \(x \mapsto 2x\) and \(x \mapsto 4x - 1\). Let \(S\) be a strictly increasing sequence of natural numbers whose set of values is \(K\), and let \(w\) be the binary sequence with \(w(n) = 1\) if \(S(n + 1)\) is odd and \(w(n) = 0\) if \(S(n + 1)\) is even. Let \(\varphi\) be the morphism of binary words with \(\varphi(0) = 01\) and \(\varphi(1) = 0\). Then for every \(k \ge 0\), the first \(|\varphi^k(0)|\) terms \(w(0) w(1) \cdots\) of \(w\) spell the word \(\varphi^k(0)\). In other words, \(S\) modulo \(2\) with its first term dropped is the infinite Fibonacci word.

    The source gives a third proof of this theorem of Kimberling, via a transducer construction; Allouche and Shallit also reproved it.
