    MetaMathlibExt.FractalSequence

    A regular fractal sequence is a sequence \((x_n)_{n \ge 0}\) of positive integers together with a position array \((p_i(j))_{i, j \ge 0}\) of natural numbers such that: for every \(i \ge 0\), the strictly increasing sequence \(p_i(0) < p_i(1) < \cdots\) lists exactly the positions \(n\) with \(x_n = i + 1\) (so every positive integer occurs infinitely often); for all \(i\) and \(n\) with \(x_n = i + 2\), some \(m < n\) has \(x_m = i + 1\); for all \(h\), \(i\) and \(j\) with \(h < i\), exactly one \(k\) satisfies \(p_i(j) < p_h(k) < p_i(j + 1)\); and for every \(j\), \(p_i(j)\) is strictly increasing in \(i\).

    Source JIS VOL25/Kimberling, https://cs.uwaterloo.ca/journals/JIS/VOL25/Kimberling/kimber16.tex, lines 103–219.

    Source positive value i + 1 is represented directly as the natural i + 1, and pos i j is the zero-based position of its j-th occurrence.

  pos : ℕ → ℕ → ℕ
  /-- Occurrence positions for a fixed value increase strictly. -/
  pos_strict : ∀ i, StrictMono (pos i)
  /-- Every recorded occurrence position contains the corresponding value. -/
  pos_sound : ∀ i j, seq (pos i j) = i + 1
  /-- Every occurrence of a value appears in its position row. -/
  pos_complete : ∀ i n, seq n = i + 1 → ∃ j, pos i j = n
  /-- Source condition (F2), shifted to zero-based value indices. -/
  cond_F2 : ∀ n i, seq n = i + 2 → ∃ m, m < n ∧ seq m = i + 1

  between consecutive positions of a larger value. -/
  cond_F3 : ∀ h i j, h < i → ∃! k, pos i j < pos h k ∧ pos h k < pos i (j + 1)
  /-- Regularity: every column of the position array increases strictly. -/
  pos_column_strict : ∀ j, StrictMono (fun i => pos i j)

    Let \((x_n)_{n \ge 0}\) be a regular fractal sequence. Then for every positive integer \(k\) there are infinitely many \(n\) with \(x_n = k\).
