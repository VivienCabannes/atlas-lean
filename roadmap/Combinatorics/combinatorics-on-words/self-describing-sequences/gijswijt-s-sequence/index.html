    DefinitionCurling number#✓fully proved

    MetaMathlibExt.curlingNumber

    The curling number \(\mathcal{C}(S)\) of a finite string \(S\) of natural numbers is the largest integer \(k\) such that \(S = X Y^k\) for some strings \(X\) and \(Y\) with \(Y\) nonempty; for the empty string \(\varepsilon\) it is \(\mathcal{C}(\varepsilon) = 1\).

    public def curlingNumber (S : List ℕ) : ℕ :=
  ((Finset.range (S.length + 1)).filter fun k => ∃ l < S.length + 1, 1 ≤ l ∧
      k * l ≤ S.length ∧
        S.drop (S.length - k * l) = (List.replicate k (S.drop (S.length - l))).flatten).sup id ⊔ 1

    DefinitionPrefixes of the \(m\)th order Gijswijt sequence#✓fully proved

    MetaMathlibExt.gijswijtPrefix

    Let \(m\) and \(n\) be natural numbers. The list of the first \(n\) terms of the \(m\)th order sequence \(A^{(m)}\) is defined by recursion on \(n\): for \(n = 0\) it is the empty list, and the list for \(n + 1\) is the list \(P\) for \(n\) followed by the term \(\max(m, \mathcal{C}(P))\), where \(\mathcal{C}(P)\) is the curling number of \(P\) (the largest \(k\) with \(P = XY^k\) for strings \(X\), \(Y\) with \(Y\) nonempty, and \(1\) for the empty string). For \(m \ge 1\) the first term is therefore \(A^{(m)}(1) = m\); the case \(m = 1\) is Gijswijt's sequence.

    public def gijswijtPrefix (m : ℕ) : ℕ → List ℕ
  | 0 => []
  | n + 1 => gijswijtPrefix m n ++ [max m (curlingNumber (gijswijtPrefix m n))]
    public def curlingNumber (S : List ℕ) : ℕ :=
  ((Finset.range (S.length + 1)).filter fun k => ∃ l < S.length + 1, 1 ≤ l ∧
      k * l ≤ S.length ∧
        S.drop (S.length - k * l) = (List.replicate k (S.drop (S.length - l))).flatten).sup id ⊔ 1

    DefinitionFirst occurrence of a value in a Gijswijt sequence#✓fully proved

    MetaMathlibExt.gijswijtFirstOccurrence

    For natural numbers \(m\) and \(n\), the first occurrence of \(n\) in the \(m\)th order Gijswijt sequence \(A^{(m)}\) is the least position \(k \ge 1\) with \(A^{(m)}(k) = n\), and it is \(0\) if \(n\) does not occur in \(A^{(m)}\).

    public noncomputable def gijswijtFirstOccurrence (m n : ℕ) : ℕ :=
  sInf {k | 1 ≤ k ∧ gijswijtTerm m k = n}
    public def gijswijtTerm (m k : ℕ) : ℕ :=
  (gijswijtPrefix m k).getLastD 0

    DefinitionBlock lengths of the higher-order Gijswijt sequences#✓fully proved

    MetaMathlibExt.gijswijtBlockLength

    For a natural number \(m\), write \(A^{(m)}(k)\) for the \(k\)th term of the \(m\)th order sequence. The block lengths \(\beta^{(m)}(t)\) are defined by \(\beta^{(m)}(0) = 0\), \(\beta^{(m)}(1) = 1\) and, for \(t \ge 1\), \(\beta^{(m)}(t+1)\) is the least \(k > (m+1)\,\beta^{(m)}(t)\) with \(A^{(m)}(k+1) = m\), or \(0\) if there is no such \(k\).

    This matches the paper's recursion \(B_{t+1} = (B_t)^{m+1} S_t\) for the blocks \(B_t\): the glue string \(S_t\) is the run of terms after position \((m+1)\,\beta^{(m)}(t)\) up to the next \(m\).

    public noncomputable def gijswijtBlockLength (m : ℕ) : ℕ → ℕ
  | 0 => 0
  | 1 => 1
  | t + 2 => sInf {k | (m + 1) * gijswijtBlockLength m (t + 1) < k ∧ gijswijtTerm m (k + 1) = m}
    public def gijswijtTerm (m k : ℕ) : ℕ :=
  (gijswijtPrefix m k).getLastD 0

    DefinitionGlue strings of a Gijswijt sequence#✓fully proved

    MetaMathlibExt.gijswijtGlue

    For natural numbers \(m\) and \(t\), the glue string \(S^{(m)}_t\) is the block \(B^{(m)}_{t+1}\) of the \(m\)th order Gijswijt sequence with its first \((m+1)\,\beta^{(m)}(t)\) elements removed, where \(\beta^{(m)}(t)\) is the length of the block \(B^{(m)}_t\).

    public noncomputable def gijswijtGlue (m t : ℕ) : List ℕ :=
  (gijswijtBlock m (t + 1)).drop ((m + 1) * gijswijtBlockLength m t)
    public noncomputable def gijswijtBlock (m t : ℕ) : List ℕ :=
  gijswijtPrefix m (gijswijtBlockLength m t)

    DefinitionBlock words#✓fully proved

    MetaMathlibExt.gijswijtBlockWord

    For natural numbers \(m\) and \(u\) and exponents \(a_1, a_2, \ldots\), the block word of order \(m\) is the concatenation \(B_{u-1}^{a_{u-1}} \cdots B_2^{a_2} B_1^{a_1}\), where \(B_i = B_i^{(m)}\) is the \(i\)th block of the \(m\)th order Gijswijt sequence and \(B_i^{a_i}\) is \(a_i\) copies of \(B_i\) in a row. Only \(a_1, \ldots, a_{u-1}\) are used, and the word is empty when \(u \le 1\).

    public noncomputable def gijswijtBlockWord (m u : ℕ) (a : ℕ → ℕ) : List ℕ :=
  ((List.range (u - 1)).reverse.map fun i =>
    (List.replicate (a (i + 1)) (gijswijtBlock m (i + 1))).flatten).flatten
    public noncomputable def gijswijtBlock (m t : ℕ) : List ℕ :=
