    MetaMathlibExt.greedySubsumfreeBelow

    For natural numbers \(x\), \(y\) and \(z\) (the source takes \(x < y < z\)), let \(S_{x,y,z}\) consist of \(x\), \(y\), \(z\) and every natural number \(n > z\) that is not a sum \(a + b + c\) of members \(a < b < c\) of \(S_{x,y,z}\) smaller than \(n\). This definition gives, for each natural number \(m\), the finite set of members of \(S_{x,y,z}\) below \(m\).

    public def greedySubsumfreeBelow (x y z : ℕ) : ℕ → Finset ℕ
  | 0 => ∅
  | m + 1 =>
    let s := greedySubsumfreeBelow x y z m
    if m = x ∨ m = y ∨ m = z ∨
        (z < m ∧ ¬ ∃ a ∈ s, ∃ b ∈ s, ∃ c ∈ s, a < b ∧ b < c ∧ a + b + c = m) then
      insert m s
    else s
