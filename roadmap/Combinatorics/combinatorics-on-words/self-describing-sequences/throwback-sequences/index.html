    TheoremKozar's conjecture on the throwback sequence#✓fully proved

    MetaMathlibExt.kozar_throwback_recurrence

    For a sequence \(Y = (Y_0, Y_1, Y_2, \dots)\) of natural numbers, the throwback step produces the sequence \(Y'\) with \(Y'_i = Y_{i+1}\) for \(i < Y_0\), \(Y'_{Y_0} = Y_0\), and \(Y'_i = Y_i\) for \(i > Y_0\): the leading term \(Y_0\) moves to index \(Y_0\), the terms \(Y_1, \dots, Y_{Y_0}\) shift one place to the left, and all later terms stay in place. Let \(X\) be the sequence with \(X_i = i + 3\) (that is, \(3, 4, 5, \dots\)), and let \(T_k\) be the leading term of the sequence obtained from \(X\) by \(k\) throwback steps. Then for every natural number \(n \ge 3\) and every natural number \(N\) there is \(k \ge N\) with \(T_k = n\); that is, every \(n \ge 3\) equals \(T_k\) for infinitely many \(k\).

    This is Kozar's conjecture for OEIS A357081. Darnell and Dribus prove a more general recurrence theorem for every sequence of distinct positive integers.

    theorem kozar_throwback_recurrence :
    let throwbackStep : (ℕ → ℕ) → (ℕ → ℕ) := fun Y i =>
      if i < Y 0 then Y (i + 1) else if i = Y 0 then Y 0 else Y i
    let X : ℕ → ℕ := fun i => i + 3
    let T : ℕ → ℕ := fun k => (Nat.iterate throwbackStep k X) 0
    ∀ n : ℕ, 3 ≤ n → ∀ N : ℕ, ∃ k : ℕ, N ≤ k ∧ T k = n

    DefinitionThrowback operation#✓fully proved

    MetaMathlibExt.throwback

    Let \(s = (s_0, s_1, s_2, \dots)\) be a sequence of elements of a set \(A\), each element \(a\) carrying a weight \(w(a) \in \mathbb{N}\). The throwback \(\tau_w(s)\) moves the leader \(s_0\) to index \(w(s_0)\), moves the entries at indices \(1, \dots, w(s_0)\) one place left and leaves later entries in place: \(\tau_w(s)_i = s_{i+1}\) for \(i < w(s_0)\), \(\tau_w(s)_{w(s_0)} = s_0\), and \(\tau_w(s)_i = s_i\) for \(i > w(s_0)\).

    With \(A = \mathbb{N}\) and \(w\) the identity, this is the throwback \(\tau\) of Darnell and Dribus on sequences of positive integers. With \(A = \mathbb{N}\), the initial arrangement \(s_i = i\) and weights \(w(i) = x_i\) for a sequence \(X = (x_0, x_1, \dots)\), it tracks the original index of each term, so repeated values stay distinguishable.

    public def throwback {α : Type*} (w : α → ℕ) (s : ℕ → α) : ℕ → α := fun i =>
  if i < w (s 0) then s (i + 1) else if i = w (s 0) then s 0 else s i

    DefinitionPartial placement sequences#✓fully proved

    MetaMathlibExt.partialPlacement

    Let \(X = (x_0, x_1, \dots)\) be a sequence of natural numbers; the source takes \(X\) strictly increasing with positive terms. The partial placement sequences \(P_n(X)\), for \(n \ge 0\), are indexed by positions \(z \in \mathbb{Z}\), and each position is either empty or holds a term of \(X\). \(P_0(X)\) holds \(x_0\) at the multiples of \(x_0 + 1\) and is empty elsewhere. \(P_{n+1}(X)\) agrees with \(P_n(X)\) at the filled positions of \(P_n(X)\) and fills some of its empty (open) positions with \(x_{n+1}\), as follows. Let \(s\) be the least natural number that is an open position of \(P_n(X)\) (\(s = 0\) if there is none), and let \(d = x_{n+1} - (n + 1) + 1 = x_{n+1} - n\), an integer. An open position \(z\) of \(P_n(X)\) receives \(x_{n+1}\) exactly when \(d\) divides the signed number of open positions of \(P_n(X)\) between \(s\) and \(z\), where open positions in \([s, z)\) count \(+1\) and those in \([z, s)\) count \(-1\); all other open positions stay empty. When \(d > 0\) and \(P_n(X)\) has an open position \(\ge 0\), this places \(x_{n+1}\) at \(s\) and then, in both directions, at every \(d\)-th open position.

    public noncomputable def partialPlacement (X : ℕ → ℕ) : ℕ → ℤ → Option ℕ
  | 0 => fun z => if ((X 0 : ℤ) + 1) ∣ z then some (X 0) else none
  | n + 1 => fun z =>
      let P := partialPlacement X n
      let s : ℤ := (sInf {p : ℕ | P p = none} : ℕ)
      let openCount : ℤ := (((Finset.Ico s z).filter fun w => P w = none).card : ℤ) -
        (((Finset.Ico z s).filter fun w => P w = none).card : ℤ)
      if P z = none ∧ ((X (n + 1) : ℤ) - (n + 1) + 1) ∣ openCount then some (X (n + 1))
      else P z

    TheoremLimiting frequencies in throwback sequences#●ready to prove

    MetaMathlibExt.throwbackSequence_limiting_frequency

    Let \(X = (x_0, x_1, \dots)\) be a sequence of pairwise distinct positive integers with throwback sequence \(T(X) = (t_0, t_1, \dots)\), and for a natural number \(w\) let \(\sigma(w)\) be the number of indices \(i\) with \(x_i < w\). Then for every index \(j\), writing \(x = x_j\), the number of \(k < N\) with \(t_k = x\), divided by \(N\), converges as \(N \to \infty\) to

    \[f(x) = \frac{1}{x - \sigma(x) + 1} \prod_{w} \frac{w - \sigma(w)}{w - \sigma(w) + 1},\]

    where the product runs over the values \(w < x\) taken by \(X\).

    For a term \(w\) of \(X\), \(\sigma(w)\) is the index of \(w\) in the increasing rearrangement of \(X\).

    TheoremMinimal complete blocks of partial placements match configurations#●ready to prove

    MetaMathlibExt.partialPlacement_minimal_complete_blocks_iff_configurations

    Let \(X = (x_0, x_1, \dots)\) be a strictly increasing sequence of positive integers, let \(\tau\) be the throwback, let \(n \ge 0\), and write \(P_n(X)_z\) for the entry, possibly empty, of the partial placement sequence \(P_n(X)\) at position \(z \in \mathbb{Z}\). The minimal complete block at \(z\) is the word \(P_n(X)_z, P_n(X)_{z+1}, \dots, P_n(X)_{z+L-1}\), empty positions included, where \(L\) is the least length for which these positions contain every \(x_i\) with \(i \le n\) (\(L = 0\) if there is no such length). Then for all natural numbers \(k\) and \(l\), the minimal complete blocks at \(k\) and at \(l\) are equal if and only if each of \(x_0, \dots, x_n\) occupies the same positions in \(\tau^k(X)\) as in \(\tau^l(X)\). Moreover, for every \(z \in \mathbb{Z}\) the minimal complete block at \(z\) equals the minimal complete block at some natural number \(k\).
