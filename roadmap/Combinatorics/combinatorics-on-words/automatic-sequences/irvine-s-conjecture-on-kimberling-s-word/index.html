    Irvine's conjecture on Kimberling's word

    DefinitionKimberling's morphism#✓fully proved

    MetaMathlibExt.kimberlingMorphism

    Kimberling's morphism \(h\) sends each letter of the alphabet \(\{0, 1\}\) to a finite word over \(\{0, 1\}\), by \(h(1) = 110\) and \(h(0) = 11\).

    The letters \(0\) and \(1\) are represented by the Boolean values false and true.

    public def kimberlingMorphism : Bool → List Bool
  | true => [true, true, false]
  | false => [true, true]

    DefinitionKimberling's blocks#✓fully proved

    MetaMathlibExt.kimberlingBlock

    Let \(h\) be Kimberling's morphism on the alphabet \(\{0, 1\}\), given by \(h(1) = 110\) and \(h(0) = 11\) and extended to finite words by concatenation. For each natural number \(n\), the \(n\)-th Kimberling block is the finite word \(K_n = h^n(1)\), the \(n\)-th iterate of \(h\) applied to the one-letter word \(1\). Thus \(K_0 = 1\), \(K_1 = 110\) and \(K_2 = 11011011\).

    public def kimberlingBlock (n : ℕ) : List Bool :=
  morphIterate kimberlingMorphism n [true]
    public def morphIterate {A : Type*} (f : A → List A) : Nat → List A → List A
  | 0, w => w
  | n + 1, w => morphExtend f (morphIterate f n w)

    TheoremEach Kimberling block is a prefix of the next#✓fully proved

    MetaMathlibExt.kimberlingBlock_prefix_succ

    DefinitionKimberling's word#✓fully proved

    MetaMathlibExt.kimberlingWord

    Let \(K_n\) be the \(n\)-th Kimberling block, a finite word over \(\{0, 1\}\). Kimberling's word \(k = k_1 k_2 k_3 \cdots = 1101101111\cdots\) (OEIS A285431) is the infinite word over \(\{0, 1\}\) whose letter \(k_{i+1}\), for \(i \ge 0\), is the \((i+1)\)-th letter of \(K_m\), where \(m = \lfloor \log_2 i \rfloor + 1\) for \(i \ge 1\) and \(m = 1\) for \(i = 0\). The block \(K_m\) has length at least \(2^m > i\), so this letter exists.

    Every block \(K_n\) is a prefix of \(k\), so \(k\) is the common extension of the blocks.

    public def kimberlingWord (i : ℕ) : Bool :=
  (kimberlingBlock (Nat.log 2 i + 1)).getD i false
    public def kimberlingBlock (n : ℕ) : List Bool :=
  morphIterate kimberlingMorphism n [true]

    DefinitionTable of Gutkovskiy's sequence#✓fully proved

    MetaMathlibExt.gutkovskiyTable

    The Gutkovskiy tables \(T_0, T_1, \dots\) are finite lists of natural numbers, indexed from \(0\), defined by \(T_0 = [0]\) and, for \(n \ge 0\), \(T_{n+1}\) is \(T_n\) with the entry \((n + 1) - T_n[\lfloor T_n[n]/2 \rfloor]\) appended at the end. Here \(T_n[j]\) is the entry of \(T_n\) at index \(j\), or \(0\) if \(T_n\) has fewer than \(j + 1\) entries, and the subtraction is truncated at \(0\).

    \(T_n\) has \(n + 1\) entries and lists the terms \(g_0, \dots, g_n\) of Gutkovskiy's sequence, so each step reads only values already computed.

    public def gutkovskiyTable : ℕ → Array ℕ
  | 0 => #[0]
  | n + 1 =>
    let a := gutkovskiyTable n
    a.push ((n + 1) - a.getD (a.getD n 0 / 2) 0)

    DefinitionGutkovskiy's sequence#✓fully proved

    MetaMathlibExt.gutkovskiy

    Gutkovskiy's sequence (OEIS A286389) is the sequence of natural numbers \(g_0, g_1, \dots\) with \(g_0 = 0\) and \(g_n = n - g_{\lfloor g_{n-1}/2 \rfloor}\) for \(n \ge 1\) (subtraction of natural numbers, truncated at \(0\)).

    Formally, \(g_n\) is defined as \(T_n[n]\), the entry at index \(n\) of the Gutkovskiy table \(T_n\), and the recurrence is proved from the table.

    public def gutkovskiy (n : ℕ) : ℕ :=
  (gutkovskiyTable n).getD n 0
    public def gutkovskiyTable : ℕ → Array ℕ
  | 0 => #[0]
  | n + 1 =>
    let a := gutkovskiyTable n
    a.push ((n + 1) - a.getD (a.getD n 0 / 2) 0)
