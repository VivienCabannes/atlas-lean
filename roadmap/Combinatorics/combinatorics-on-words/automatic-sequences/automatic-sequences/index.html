    MetaMathlibExt.baseWordValueLSD

    For a natural number \(k\), the value of a finite word \(d_0 d_1 \cdots d_{m-1}\) of digits \(d_i \in \{0, 1, \dots, k-1\}\) is the natural number \(\sum_{i < m} d_i k^i\), so the first digit is the least significant one; the empty word has value \(0\).

    def baseWordValueLSD {k : Nat} (ds : List (Fin k)) : Nat :=
  ds.foldr (fun d acc => d.val + k * acc) 0

    DefinitionAutomatic sequences via finite automata#✓fully proved

    MetaMathlibExt.IsKAutomaticSequence

    Let \(k\) be a natural number and \(B\) a finite alphabet. A sequence \(w : \mathbb{N} \to B\) is \(k\)-automatic when \(k \ge 2\) and there is a deterministic finite automaton with output, consisting of a nonempty finite set of states \(Q\), an initial state \(s \in Q\), a transition map \(\delta : Q \times \{0, 1, \dots, k-1\} \to Q\) and an output map \(\tau : Q \to B\), such that for every \(n \in \mathbb{N}\) and every finite word \(d_0 d_1 \cdots d_{m-1}\) of digits in \(\{0, 1, \dots, k-1\}\) with \(\sum_{i < m} d_i k^i = n\), the automaton started in \(s\) and reading \(d_0, d_1, \dots, d_{m-1}\) in this order (least significant digit first) stops in a state \(t\) with \(\tau(t) = w(n)\).

    def IsKAutomaticSequence {B : Type} [Fintype B] (k : Nat) (w : Nat → B) : Prop :=
  2 ≤ k ∧
    ∃ q : Nat, 0 < q ∧
      ∃ start : Fin q,
        ∃ trans : Fin q → Fin k → Fin q,
          ∃ out : Fin q → B,
            ∀ n : Nat, ∀ ds : List (Fin k),
              baseWordValueLSD ds = n → out (ds.foldl trans start) = w n
    def baseWordValueLSD {k : Nat} (ds : List (Fin k)) : Nat :=
  ds.foldr (fun d acc => d.val + k * acc) 0

    DefinitionCodings of prolongable uniform fixed points#✓fully proved

    MetaMathlibExt.IsCodingOfProlongableKUniformFixedPoint

    Let \(k\) be a natural number and \(B\) a finite alphabet. A sequence \(w : \mathbb{N} \to B\) is a coding of a prolongable \(k\)-uniform fixed point when \(k \ge 2\) and there are a nonempty finite alphabet \(A\), a map \(f\) sending each letter of \(A\) to a word of length exactly \(k\) over \(A\), a letter \(a \in A\) with \(f(a) = a\alpha\) for some nonempty word \(\alpha\) over \(A\), a sequence \(u : \mathbb{N} \to A\) and a map \(g : A \to B\) such that \(u(0) = a\), the letter of \(f(u(n))\) at position \(j\) (counted from \(0\)) is \(u(kn + j)\) for all \(n \in \mathbb{N}\) and \(j < k\), and \(w(n) = g(u(n))\) for all \(n \in \mathbb{N}\).

    The conditions on \(u\) say that \(u\) begins with \(a\) and is fixed by \(f\) applied letter by letter.

    def IsCodingOfProlongableKUniformFixedPoint {B : Type} [Fintype B] (k : Nat)
    (w : Nat → B) : Prop :=
  2 ≤ k ∧
    ∃ q : Nat, 0 < q ∧
      ∃ f : Fin q → List (Fin q), (∀ a : Fin q, (f a).length = k) ∧
        ∃ a : Fin q, ∃ tl : List (Fin q), tl ≠ [] ∧ f a = a :: tl ∧
          ∃ u : Nat → Fin q, u 0 = a ∧
            (∀ n : Nat, ∀ j : Nat, j < k → (f (u n)).getD j a = u (k * n + j)) ∧
              ∃ g : Fin q → B, ∀ n : Nat, w n = g (u n)

    DefinitionThe \(k\)-kernel of a sequence#✓fully proved

    MetaMathlibExt.kKernel

    For a natural number \(k\) and a sequence \(a\) indexed by \(\mathbb{N}\), the \(k\)-kernel of \(a\) is the set of all sequences \(n \mapsto a(k^e n + r)\) with \(e, r \in \mathbb{N}\) and \(r < k^e\).

    public def kKernel (k : ℕ) {Δ : Type*} (a : ℕ → Δ) : Set (ℕ → Δ) :=
  {b | ∃ e : ℕ, ∃ r : ℕ, r < k ^ e ∧ b = fun n => a (k ^ e * n + r)}
