    DefinitionTribonacci representation#✓fully proved

    MetaMathlibExt.IsTribonacciRepr

    Let \(T_n\) be the Tribonacci numbers, \(T_0 = T_1 = 0\), \(T_2 = 1\) and \(T_{n+3} = T_{n+2} + T_{n+1} + T_n\). A list \(w = (w_0, \dots, w_{\ell-1})\) of natural numbers, read least significant digit first, is a Tribonacci representation of a natural number \(n\) when every digit \(w_i\) is \(0\) or \(1\), no three consecutive entries of \(w\) are all equal to \(1\), and \(n = \sum_{i=0}^{\ell-1} w_i T_{i+3}\). Leading zeros (trailing entries of \(w\)) are allowed.

    public def IsTribonacciRepr (w : List ℕ) (n : ℕ) : Prop :=
  (∀ d ∈ w, d ≤ 1) ∧ ¬ [1, 1, 1] <:+: w ∧
    ∑ i ∈ Finset.range w.length, w.getD i 0 * tribonacci (i + 3) = n
    def tribonacci : ℕ → ℕ
  | 0 => 0
  | 1 => 0
  | 2 => 1
  | n + 3 => tribonacci (n + 2) + tribonacci (n + 1) + tribonacci n

    DefinitionTribonacci value of a digit word#✓fully proved

    MetaMathlibExt.tribonacciValue

    Let \(T_0 = T_1 = 0\), \(T_2 = 1\) and \(T_{k+3} = T_{k+2} + T_{k+1} + T_k\) be the Tribonacci numbers. The Tribonacci value of a finite word \(w\) of natural-number digits \(w_0, w_1, \dots, w_{\ell-1}\), listed from the least significant digit, is \([w]_T = \sum_{i=0}^{\ell-1} w_i T_{i+3}\), so the digits weigh \(1, 2, 4, 7, 13, \dots\).     For a Tribonacci representation \(w\) of \(n\), the value of \(w\) followed by a new least significant digit \(0\) is the Tribonacci successor \(\mathrm{out}(n)\).

    public def tribonacciValue (w : List ℕ) : ℕ :=
  ∑ i ∈ Finset.range w.length, w.getD i 0 * tribonacci (i + 3)
