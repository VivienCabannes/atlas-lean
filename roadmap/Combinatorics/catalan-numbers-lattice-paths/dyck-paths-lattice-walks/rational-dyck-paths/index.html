    MetaMathlibExt.IsDyckHeightAtMostTwo

    A Dyck word has height at most \(2\) when no prefix of it has more than two more up steps \(U\) than down steps \(D\).

    public def IsDyckHeightAtMostTwo (p : DyckWord) : Prop :=
  ∀ i ≤ p.toList.length, (p.toList.take i).count U ≤ (p.toList.take i).count D + 2

    DefinitionBlock word of a Dyck path of height at most \(2\)#✓fully proved

    MetaMathlibExt.dyckHeightTwoBlockWord

    For a Dyck word \(P = P_0 P_1 \cdots P_{2n-1}\) of semilength \(n\), with steps indexed from \(0\), the block word of \(P\) is the Boolean word of length \(n - 1\) (empty when \(n = 0\)) whose entry \(i\), for \(0 \le i < n - 1\), is true exactly when \(P_{2i+1} = U\).

    When \(P\) has height at most \(2\) and \(n \ge 1\), it factorizes as \(P = U X_1 \cdots X_{n-1} D\) with each \(X_{i+1} = P_{2i+1} P_{2i+2}\) a \(1\)-peak \(UD\) or a \(0\)-valley \(DU\), so entry \(i\) is true for a \(1\)-peak and false for a \(0\)-valley.

    public def dyckHeightTwoBlockWord (p : DyckWord) : List Bool :=
  (List.range (p.semilength - 1)).map fun i => decide (p.toList[2 * i + 1]? = some U)

    DefinitionMaximal runs of a Boolean word#✓fully proved

    MetaMathlibExt.boolRuns

    The run decomposition of a Boolean word is the list, from left to right, of its maximal runs of equal consecutive letters, each recorded as the pair (letter, length of the run).

    public def boolRuns : List Bool → List (Bool × ℕ)
  | [] => []
  | b :: l =>
    match boolRuns l with
    | [] => [(b, 1)]
    | (c, m) :: rest => if b = c then (c, m + 1) :: rest else (b, 1) :: (c, m) :: rest

    DefinitionValleys following a run#✓fully proved

    MetaMathlibExt.runFollowingValleys

    Let \(R = ((b_0, m_0), \dots, (b_{k-1}, m_{k-1}))\) be a list of pairs of a Boolean letter and a natural number, read as the maximal runs of a block word in which the letter \(\mathrm{false}\) stands for a \(0\)-valley \(DU\). For \(i \in \mathbb{N}\), the number of \(0\)-valleys immediately after run \(i\) is \(m_{i+1}\) if \(i + 1 < k\) and \(b_{i+1} = \mathrm{false}\), and \(0\) otherwise.

    public def runFollowingValleys (R : List (Bool × ℕ)) (i : ℕ) : ℕ :=
  match R[i + 1]? with
  | some (false, v) => v
  | _ => 0

    DefinitionThe rational Dyck path run condition#✓fully proved

    MetaMathlibExt.IsTildeRationalRuns

    Let \(r, s \in \mathbb{N}\) and let \(R\) be a list of runs, each a pair (letter, length) with a Boolean letter. For the run at position \(i\), let \(v_i\) be the length of the run at position \(i + 1\) if that run exists and has letter false, and \(v_i = 0\) otherwise. Then \(R\) satisfies the rational run condition for \(q = r/s\) when every run of letter true, say of length \(p\) at position \(i\), has \(p \le r\) and \(p s \le r v_i\).

    Applied to the maximal runs of the block word of a Dyck path, this says that every block of \(p\) consecutive \(1\)-peaks has \(p \le r\) and is followed by \(v\) consecutive \(0\)-valleys with \(p s \le r v\), that is, \(v \ge \lceil p s / r \rceil\) when \(r \ge 1\).

    public def IsTildeRationalRuns (r s : ℕ) (R : List (Bool × ℕ)) : Prop :=
  ∀ i < R.length, (R.getD i (false, 0)).1 = true →
    (R.getD i (false, 0)).2 ≤ r ∧ (R.getD i (false, 0)).2 * s ≤ r * runFollowingValleys R i
    public def runFollowingValleys (R : List (Bool × ℕ)) (i : ℕ) : ℕ :=
  match R[i + 1]? with
  | some (false, v) => v
  | _ => 0

    DefinitionThe \(Q\)-bonacci run condition#✓fully proved

    MetaMathlibExt.IsQBonacciRuns

    Let \(r, s \in \mathbb{N}\) and let \(R\) be a list of runs, each a pair (letter, length) with a Boolean letter. For the run at position \(i\), let \(v_i\) be the length of the run at position \(i + 1\) if that run exists and has letter false, and \(v_i = 0\) otherwise. Then \(R\) satisfies the \(Q\)-bonacci run condition for \(q = r/s\) when every run of letter true, say of length \(p\) at position \(i\), has \(p \le r\) and also \(p s \le r v_i\), except that \(p s \le r v_i\) may fail when both this run is the last run of letter true in \(R\) and either \(p = r\) or \(v_i = 0\).

    Applied to the maximal runs of the block word of a Dyck path, the runs of letter true are the blocks of \(p\) consecutive \(1\)-peaks and \(v_i\) counts the \(0\)-valleys that follow them: every block but the last needs \(p s \le r v_i\), and the last block, of \(p_k\) peaks followed by \(v_k\) valleys, needs it only when \(p_k < r\) and \(v_k \ne 0\).

    public def IsQBonacciRuns (r s : ℕ) (R : List (Bool × ℕ)) : Prop :=
  ∀ i < R.length, (R.getD i (false, 0)).1 = true →
    (R.getD i (false, 0)).2 ≤ r ∧
      ((R.getD i (false, 0)).2 * s ≤ r * runFollowingValleys R i ∨
        ((∀ j < R.length, i < j → (R.getD j (false, 0)).1 = false) ∧
          ((R.getD i (false, 0)).2 = r ∨ runFollowingValleys R i = 0)))
    public def runFollowingValleys (R : List (Bool × ℕ)) (i : ℕ) : ℕ :=
  match R[i + 1]? with
  | some (false, v) => v
  | _ => 0

    MetaMathlibExt.tildeRationalDyckPaths

    For natural numbers \(r\), \(s\) and \(n\), \(\tilde R_n^{r/s}\) is the finite set of Dyck paths of semilength \(n\) and height at most \(2\) that satisfy the following run condition. For \(n \ge 1\) such a path factors as \(U X_1 \cdots X_{n-1} D\) with each \(X_i\) either a \(1\)-peak \(UD\) or a \(0\)-valley \(DU\), and its block word \(X_1 \cdots X_{n-1}\) (empty for \(n = 0\)) splits into maximal runs of equal blocks.   Finset.univ.filter fun p =>
