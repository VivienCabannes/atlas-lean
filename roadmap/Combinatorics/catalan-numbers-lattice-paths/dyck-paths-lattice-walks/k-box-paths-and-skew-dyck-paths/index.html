    MetaMathlibExt.IsSkewDyckWord

    A word \(w\) in the steps \(U\), \(D\), \(L\) is a skew Dyck word when neither \(UL\) nor \(LU\) occurs in \(w\) as two consecutive letters, the number of \(U\)s in \(w\) equals the number of \(D\)s and \(L\)s together, and no prefix of \(w\) has more \(D\)s and \(L\)s together than \(U\)s.

    public def IsSkewDyckWord (w : List SkewDyckStep) : Prop :=
  ¬ [U, L] <:+: w ∧ ¬ [L, U] <:+: w ∧ w.count U = w.count D + w.count L ∧
    ∀ i ≤ w.length, (w.take i).count D + (w.take i).count L ≤ (w.take i).count U
    public inductive SkewDyckStep
  | U
  | D
  | L
  deriving DecidableEq

    For words \(f\) and \(w\) over the skew Dyck steps \(U\), \(D\), \(L\), the factor count of \(f\) in \(w\) is the number of suffixes of \(w\), including \(w\) itself and the empty suffix, that begin with \(f\).     MetaMathlibExt.boxWord

    Let \(k \ge 0\) and let \(a = (a_1, \dots, a_n)\) be a list of natural numbers with \(n \ge 1\). The box word of \(k\) and \(a\) is the word in the skew Dyck steps

    \[ U^{a_1} D^k L D \; U^{a_2} D^k L D \; \cdots \; U^{a_{n-1}} D^k L D \; U^{a_n} D^k L, \]

    that is, the blocks \(U^{a_i} D^k L D\) for \(i < n\) followed by \(U^{a_n} D^k L\). For the empty list it is \(D^k L\).

    public def boxWord (k : ℕ) (a : List ℕ) : List SkewDyckStep :=
  (a.dropLast.flatMap fun x => List.replicate x U ++ List.replicate k D ++ [L, D]) ++
    List.replicate (a.getLastD 0) U ++ List.replicate k D ++ [L]
    public inductive SkewDyckStep
  | U
  | D
  | L
  deriving DecidableEq

    Definition\(k\)-Dyck words#✓fully proved

    MetaMathlibExt.IsKDyckWord

    A word \(w\) over the Booleans is a \(k\)-Dyck word when the number of letters \(\mathrm{true}\) in \(w\) is \(k\) times the number of letters \(\mathrm{false}\), and every prefix of \(w\) contains at least \(k\) times as many letters \(\mathrm{true}\) as letters \(\mathrm{false}\).

    Reading \(\mathrm{true}\) as the step \(U = (1,1)\) and \(\mathrm{false}\) as the step \(D^{(k)} = (k,-k)\), this says that the path ends on the \(x\)-axis and never goes below it.

    public def IsKDyckWord (k : ℕ) (w : List Bool) : Prop :=
  w.count true = k * w.count false ∧
    ∀ i ≤ w.length, k * (w.take i).count false ≤ (w.take i).count true
