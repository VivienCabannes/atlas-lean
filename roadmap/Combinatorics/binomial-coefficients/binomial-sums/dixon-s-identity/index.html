    TheoremDixon's alternating cubic binomial sum#✓fully proved

    MetaMathlibExt.dixon_alternating_cubic_binomial_sum

    For every natural number \(n\), \(\sum_{k=0}^{2n} (-1)^k \binom{2n}{k}^3 = (-1)^n \binom{2n}{n} \binom{3n}{2n}\).

    Mikić attributes the identity to A. C. Dixon, "On the sum of the cubes of the coefficients in a certain expansion by the binomial theorem", Messenger of Mathematics 20 (1891), 79--80. This is the specialization of Dixon's three-parameter identity in which all three parameters equal \(n\); the three-parameter identity is not stated.

    theorem dixon_alternating_cubic_binomial_sum (n : ℕ) :
    ∑ k ∈ Finset.range (2 * n + 1),
      (-1 : ℤ) ^ k * (Nat.choose (2 * n) k : ℤ) ^ 3 =
      (-1 : ℤ) ^ n * (Nat.choose (2 * n) n : ℤ) *
        (Nat.choose (3 * n) (2 * n) : ℤ)

    TheoremShift identity for the inverse factorial#✓fully proved

    MetaMathlibExt.invFact_shift

    For every integer \(n\), the inverse factorial of \(n\) equals \(n + 1\) times the inverse factorial of \(n + 1\), as rational numbers.

    For \(n \ge 0\) this is \(1/n! = (n+1)/(n+1)!\). For \(n < 0\) both sides are \(0\): the inverse factorial vanishes at negative integers, and the factor \(n + 1\) is \(0\) at \(n = -1\).

    public theorem invFact_shift (n : ℤ) : invFact n = (n + 1) * invFact (n + 1)
    public def invFact (n : ℤ) : ℚ :=
  if 0 ≤ n then 1 / (n.natAbs.factorial : ℚ) else 0

    MetaMathlibExt.dixonSummand

    Write \(\binom{n}{m}\) for the integer binomial coefficient of integers \(n\) and \(m\). For integers \(a_1, a_2, a_3\) and \(k\), the Dixon summand is the rational number \((-1)^k \binom{2a_1}{a_1 + k} \binom{2a_2}{a_2 + k} \binom{2a_3}{a_3 + k}\).

    public def dixonSummand (a₁ a₂ a₃ k : ℤ) : ℚ :=
  (-1 : ℚ) ^ k.natAbs * intBinom (2 * a₁) (a₁ + k) *

    DefinitionBound of the Dixon summation window#✓fully proved

    MetaMathlibExt.dixonBound

    For integers \(a_1, a_2, a_3\), the Dixon bound is \(\max(|a_1|, |a_2|, |a_3|)\).

    Every integer \(k\) whose term in Dixon's alternating sum is nonzero satisfies \(|k|\) at most this bound, so summing over \(k\) from minus the bound to the bound covers the whole sum.

    public def dixonBound (a₁ a₂ a₃ : ℤ) : ℤ :=
  max (|a₁|) (max (|a₂|) (|a₃|))

    DefinitionThe Dixon sum \(\upsilon_3\)#✓fully proved

    MetaMathlibExt.upsilon₃

    For integers \(a_1, a_2, a_3\), let \(B = \max(|a_1|, |a_2|, |a_3|)\). Then \(\upsilon_3(a_1, a_2, a_3)\) is the rational number

    \[\upsilon_3(a_1, a_2, a_3) = \sum_{k=-B}^{B} (-1)^k \prod_{i=1}^{3} \binom{2a_i}{a_i + k},\]

    where for integers \(n\) and \(k\) the binomial coefficient \(\binom{n}{k}\) is the ordinary one when \(0 \le k \le n\) and is \(0\) otherwise.

    Every summand with \(|k| > B\) is zero, so this is the alternating sum over all integers \(k\).

    public def upsilon₃ (a₁ a₂ a₃ : ℤ) : ℚ :=
  ∑ k ∈ Finset.Icc (-(dixonBound a₁ a₂ a₃)) (dixonBound a₁ a₂ a₃),
    dixonSummand a₁ a₂ a₃ k
    public def dixonBound (a₁ a₂ a₃ : ℤ) : ℤ :=
  max (|a₁|) (max (|a₂|) (|a₃|))

    TheoremDixon's summation theorem#✓fully proved

    MetaMathlibExt.dixon_summation

    For an integer \(m\) write \(m!\) for the extended factorial and \(\frac{1}{m!}\) for the inverse factorial; both are \(0\) when \(m < 0\). For all integers \(a_1, a_2, a_3\), the Dixon sum \(\Upsilon_3(a_1, a_2, a_3)\) equals

    \[ (2a_1)!\,(2a_2)!\,(2a_3)!\,(a_1 + a_2 + a_3)! \cdot \frac{1}{(a_1 + a_2)!} \cdot \frac{1}{(a_1 + a_3)!} \cdot \frac{1}{(a_2 + a_3)!} \cdot \frac{1}{a_1!} \cdot \frac{1}{a_2!} \cdot \frac{1}{a_3!}. \]

    Proof: a Wilf–Zeilberger pair. For \(a = a_1 \ge 0\) and \(b = a_2 \ge 0\) the normalized summand in \(c = a_3\) has the certificate ratio \(R(c, k) = -\frac{(a + k)(b + k)}{2(c - k + 1)(a + b + c + 1)}\); induction on \(c\) telescopes over the fixed window \([-a, a]\). Negative arguments make both sides zero.

    public theorem dixon_summation (a₁ a₂ a₃ : ℤ) :
  upsilon₃ a₁ a₂ a₃ =
    extFact (2 * a₁) * extFact (2 * a₂) * extFact (2 * a₃) *
      extFact (a₁ + a₂ + a₃) * invFact (a₁ + a₂) * invFact (a₁ + a₃) *
      invFact (a₂ + a₃) * invFact a₁ * invFact a₂ * invFact a₃
    public def upsilon₃ (a₁ a₂ a₃ : ℤ) : ℚ :=
  ∑ k ∈ Finset.Icc (-(dixonBound a₁ a₂ a₃)) (dixonBound a₁ a₂ a₃),
    dixonSummand a₁ a₂ a₃ k
