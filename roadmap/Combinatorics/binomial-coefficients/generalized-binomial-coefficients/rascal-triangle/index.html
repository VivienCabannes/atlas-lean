    DefinitionRascal numbers on the integers#✓fully proved

    MathlibExt.Combinatorics.Enumerative.RascalNumbersWanted.rascalZ

    For integers \(n\) and \(k\), the Rascal number \(R_{n,k}\) is \(k(n-k) + 1\) if \(0 \le k \le n\), and \(0\) otherwise.

    Gibbs and Miceli define \(R_{n,k}\) by the diamond recurrence of Angorro et al., with value \(0\) outside \(0 \le k \le n\); Angorro et al. proved that it equals \(k(n-k) + 1\) in that range.

    def rascalZ (n k : ℤ) : ℤ :=
  if 0 ≤ k ∧ k ≤ n then k * (n - k) + 1 else 0
