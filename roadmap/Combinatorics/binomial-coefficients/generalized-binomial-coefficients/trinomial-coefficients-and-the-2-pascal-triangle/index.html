    DefinitionTrinomial transform#✓fully proved

    MetaMathlibExt.trinomialTransformSequence

    Let \(R\) be a semiring and \(a \colon \mathbb{N} \to R\) a sequence. The trinomial transform of \(a\) is the sequence \(b \colon \mathbb{N} \to R\) given by

    \[b_n = \sum_{i=0}^{2n} T(n, i)\, a_i,\]

    where \(T(n, i)\) is the trinomial coefficient, the coefficient of \(X^i\) in \((1 + X + X^2)^n\), regarded as an element of \(R\).

    noncomputable def trinomialTransformSequence {R : Type*} [Semiring R]
    (a : ℕ → R) (n : ℕ) : R :=
  ∑ i ∈ Finset.range (2 * n + 1), (trinomialCoefficient n i : R) * a i
    noncomputable def trinomialCoefficient (n k : ℕ) : ℕ :=

    MetaMathlibExt.trinomialCoefficient_alternating_sums_mod_three_five

    Write \(\binom{n}{k}_2\) for the trinomial coefficient, the coefficient of \(x^k\) in \((1+x+x^2)^n\), and \(L_m\) for the Lucas numbers (\(L_0 = 2\), \(L_1 = 1\), \(L_{m+2} = L_{m+1} + L_m\)). Let \(n\) and \(x\) be natural numbers.

    If \(x < 3\), then \(3 \sum_{k=0}^{2n} (-1)^{k+x} \binom{n}{3k+x}_2\) equals \((-1)^n 2^{n+1} + 1\) when \(n \equiv x \pmod 3\), and \((-1)^{n+1} 2^n + 1\) otherwise.

    If \(x < 5\), let \(S = 5 \sum_{k=0}^{2n} (-1)^{k+x} \binom{n}{5k+x}_2\). Then \(S = 2 (-1)^n L_{2n} + 1\) when \(n \equiv x \pmod 5\), \(S = (-1)^{n+1} L_{2n+1} + 1\) when \(n \equiv x \pm 1 \pmod 5\), and \(S = (-1)^n L_{2n-1} + 1\) when \(n \ge 1\) and \(n \equiv x \pm 2 \pmod 5\).

    The paper does not bound \(x\); the last case excludes \(n = 0\), where it would need \(L_{-1}\).
