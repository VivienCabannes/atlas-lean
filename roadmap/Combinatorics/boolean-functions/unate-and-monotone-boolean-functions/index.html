    DefinitionConcatenation of two Boolean functions#✓fully proved

    MetaMathlibExt.boolFunConcat

    The concatenation \(g \,\|\, h\) of two \(n\)-variable Boolean functions \(g\) and \(h\) is the \((n+1)\)-variable function whose truth table is that of \(g\) followed by that of \(h\): its value at \((x_1, x_2, \dots, x_{n+1})\) is \(g(x_2, \dots, x_{n+1})\) if \(x_1 = 0\) and \(h(x_2, \dots, x_{n+1})\) if \(x_1 = 1\). Equivalently, \((g \,\|\, h)(x) = \bar{x}_1 g(x_2, \dots, x_{n+1}) \oplus x_1 h(x_2, \dots, x_{n+1})\).

    public def boolFunConcat {n : ℕ} (g h : (Fin n → Bool) → Bool) :
    (Fin (n + 1) → Bool) → Bool :=
  fun x => cond (x 0) (h (Fin.tail x)) (g (Fin.tail x))
