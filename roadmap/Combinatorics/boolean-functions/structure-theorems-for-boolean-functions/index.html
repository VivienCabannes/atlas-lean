    Structure theorems for Boolean functions

    Theorems saying that a Boolean function f : {-1, 1}ⁿ → {-1, 1} with a simple Fourier spectrum or few influential coordinates is close to a simple function: Friedgut–Kalai–Naor (degree-1 concentration forces a dictator), Friedgut's junta theorem (small total influence forces a junta), the Level-1 Inequality and Majority Is Stablest.

    TheoremFriedgut–Kalai–Naor (FKN) Theorem#●ready to prove

    BooleanCube.fkn_theorem

    There is a universal constant \(C\) such that for every \(n \ge 1\): if \(f : \{-1, 1\}^n \to \{-1, 1\}\) has degree-1 Fourier weight \(\mathbf{W}^1[f] = \sum_{|S| = 1} \hat f(S)^2 \ge 1 - \delta\), then \(f\) is \(C\delta\)-close to a dictator \(\chi_i\) or a negated dictator \(-\chi_i\) for some coordinate \(i\).

    The source writes the closeness as \(O(\delta)\); Theorem 5.33 in Section 5.4 of the same source improves it to \(\delta/4 + O(\delta^2 \log(2/\delta))\). The hypothesis \(n \ge 1\) is implicit in the source.

    theorem_wanted fkn_theorem :
    ∃ C : ℝ, ∀ (n : ℕ), 0 < n → ∀ f : BoolCube n → ℝ, (∀ x, f x = 1 ∨ f x = -1) →
      ∀ δ : ℝ, 1 - δ ≤ ∑ S with S.card = 1, boolFourierCoeff n f S ^ 2 →
        ∃ i : Fin n, boolDist f (fun x => cubeVal (x i)) ≤ C * δ ∨
          boolDist f (fun x => -cubeVal (x i)) ≤ C * δ
    abbrev BoolCube (n : ℕ) : Type := Fin n → Bool

    TheoremFriedgut's Junta Theorem#✓fully proved

    BooleanCube.friedgut_junta_theorem

    There is a universal constant \(C\) such that for every \(f : \{-1, 1\}^n \to \{-1, 1\}\) and every \(0 < \varepsilon \le 1\), \(f\) is \(\varepsilon\)-close to a function \(g : \{-1, 1\}^n \to \{-1, 1\}\) that depends only on the coordinates in a set \(J\) with \(|J| \le \exp(C\, \mathbf{I}[f] / \varepsilon)\). Functions of small total influence are close to juntas.

    The Lean proof takes \(C = 180\). It applies the explicit form with \(\varepsilon/2\), which gives \(|J| \le 4\,u^3\, 9^{\lceil 2u \rceil}\) for \(u = \mathbf{I}[f]/\varepsilon\). A nonempty \(J\) forces \(u > 1/10\), and then \(4u^3 9^{\lceil 2u\rceil} \le e^{19u + 16} \le e^{180 u}\).

    theorem friedgut_junta_theorem :
    ∃ C : ℝ, ∀ (n : ℕ) (f : BoolCube n → ℝ), (∀ x, f x = 1 ∨ f x = -1) →
      ∀ ε : ℝ, 0 < ε → ε ≤ 1 →
        ∃ (J : Finset (Fin n)) (g : BoolCube n → ℝ),
          (J.card : ℝ) ≤ Real.exp (C * boolTotalInfluence f / ε) ∧
          (∀ x, g x = 1 ∨ g x = -1) ∧
          (∀ x y : BoolCube n, (∀ i ∈ J, x i = y i) → g x = g y) ∧
          boolDist f g ≤ ε
    abbrev BoolCube (n : ℕ) : Type := Fin n → Bool

    TheoremLevel-1 Inequality#✓fully proved

    BooleanCube.level_one_inequality

    There is a universal constant \(C\) such that every \(f : \{-1, 1\}^n \to \{0, 1\}\) with mean \(\alpha = \mathbb{E}[f] \le 1/2\) satisfies

    \[\mathbf{W}^1[f] = \sum_{|S| = 1} \hat f(S)^2 \le C\, \alpha^2 \log(1/\alpha).\]

    Small subsets of the cube have little degree-1 Fourier weight. In additive combinatorics this is Chang's inequality. For \(\alpha = 0\) both sides are \(0\). The Lean proof takes \(C = 2e\): it is the Level-k Inequality at \(k = 1\), whose hypothesis \(1 \le 2 \ln(1/\alpha)\) holds since \(\alpha \le 1/2\) and \(\ln 2 > 1/2\). This is the route of the source's Section 9.5; its Section 5.4 proof uses a tail bound for linear forms instead.

    theorem level_one_inequality :
    ∃ C : ℝ, ∀ (n : ℕ) (f : BoolCube n → ℝ), (∀ x, f x = 0 ∨ f x = 1) →
      𝔼 x, f x ≤ 1 / 2 →
        ∑ S with S.card = 1, boolFourierCoeff n f S ^ 2 ≤
          C * (𝔼 x, f x) ^ 2 * Real.log (1 / 𝔼 x, f x)
    abbrev BoolCube (n : ℕ) : Type := Fin n → Bool

    TheoremMajority Is Stablest#●ready to prove

    BooleanCube.majority_is_stablest

    Fix \(0 < \rho < 1\). For every \(\varepsilon > 0\) there is \(\tau > 0\) such that every \(f : \{-1, 1\}^n \to [-1, 1]\) with \(\mathbb{E}[f] = 0\) and \(\mathrm{Inf}_i[f] \le \tau\) for all \(i\) satisfies

    \[\mathrm{Stab}_\rho[f] \le \frac{2}{\pi} \arcsin \rho + \varepsilon = 1 - \frac{2}{\pi} \arccos\rho + \varepsilon.\]

    The source writes the error as \(o_\tau(1)\). The bound is tight: it is the limit of \(\mathrm{Stab}_\rho[\mathrm{Maj}_n]\) over odd \(n\) (Theorem 2.45). The theorem gives the Unique-Games hardness of approximating Max-Cut beyond the Goemans–Williamson ratio (Khot–Kindler–Mossel–O'Donnell) and the optimal noise stability of majority among low-influence voting rules.

    theorem_wanted majority_is_stablest {ρ : ℝ} (hρ0 : 0 < ρ) (hρ1 : ρ < 1) {ε : ℝ} (hε : 0 < ε) :
    ∃ τ : ℝ, 0 < τ ∧ ∀ (n : ℕ) (f : BoolCube n → ℝ), (∀ x, |f x| ≤ 1) →
      𝔼 x, f x = 0 → (∀ i, boolInfluence f i ≤ τ) →
        boolNoiseStab ρ f ≤ 2 / Real.pi * Real.arcsin ρ + ε
    abbrev BoolCube (n : ℕ) : Type := Fin n → Bool

    TheoremNoise stability of a coordinate Laplacian#✓fully proved

    BooleanCube.boolNoiseStab_derivative_le

    Let \(f : \{-1, 1\}^n \to \{-1, 1\}\) and let \(L_i f(x) = (f(x) - f(x^{\oplus i}))/2\) be its \(i\)-th coordinate Laplacian. Then

    \[\mathrm{Stab}_{1/3}[L_i f] = \sum_{S \ni i} 3^{-|S|}\, \hat f(S)^2 \le \tfrac13\, \mathrm{Inf}_i[f]^{3/2}.\]

    Since \(\mathrm{Stab}_{1/3}[L_i f] = \tfrac13\, \mathrm{Inf}^{(1/3)}_i[f]\), this is Corollary 9.12 restated for \(L_i f\) instead of \(D_i f\). It is the form in which the proof of Theorem 9.28 uses the corollary.

    theorem boolNoiseStab_derivative_le {f : BoolCube n → ℝ} (hf : ∀ x, f x = 1 ∨ f x = -1)
    (i : Fin n) :
    boolNoiseStab (1 / 3) (fun x => (f x - f (flipCoord x i)) / 2) ≤
      boolInfluence f i * Real.sqrt (boolInfluence f i) / 3
    abbrev BoolCube (n : ℕ) : Type := Fin n → Bool

    TheoremFew coordinates have large influence#✓fully proved

    BooleanCube.card_influential_le

    For \(f : \{-1, 1\}^n \to \mathbb{R}\) with \(\mathbf{I}[f] > 0\), \(\varepsilon > 0\) and \(k \in \mathbb{N}\), the set \(J = \{j : \mathrm{Inf}_j[f] \ge \varepsilon^2 / (\mathbf{I}[f]^2 9^k)\}\) has

      boolTotalInfluence f ^ 3 * 9 ^ k / ε ^ 2

    TheoremFriedgut's junta theorem, explicit form#✓fully proved

    BooleanCube.exists_junta_boolDist_le

    Let \(f : \{-1, 1\}^n \to \{-1, 1\}\) and \(\varepsilon > 0\). There are a set \(J\) of coordinates with

    \[|J| \le \frac{\mathbf{I}[f]^3\; 9^{\lceil \mathbf{I}[f]/\varepsilon \rceil}}{\varepsilon^2}\]

    and a Boolean function \(h\) depending only on the coordinates in \(J\) with \(\mathrm{dist}(f, h) \le 2\varepsilon\).

    Take \(k = \lceil \mathbf{I}[f]/\varepsilon \rceil\), so that the weight above degree \(k\) is at most \(\varepsilon\), and the spectral part of Friedgut's argument. Then \(\|f - f^{\subseteq J}\|_2^2 = \sum_{S \not\subseteq J} \hat f(S)^2 \le 2\varepsilon\), where \(f^{\subseteq J} = \sum_{S \subseteq J} \hat f(S) \chi_S\), and \(h = \mathrm{sgn}(f^{\subseteq J})\) is \(2\varepsilon\)-close to \(f\). When \(\mathbf{I}[f] = 0\), \(f\) is constant and \(J = \emptyset\). The source sharpens \(2\varepsilon\) to \(\varepsilon\) with Exercise 3.34.

    theorem exists_junta_boolDist_le {f : BoolCube n → ℝ} (hf : ∀ x, f x = 1 ∨ f x = -1) {ε : ℝ}
    (hε : 0 < ε) :
    ∃ (J : Finset (Fin n)) (h : BoolCube n → ℝ),
      (J.card : ℝ) ≤ boolTotalInfluence f ^ 3 * 9 ^ ⌈boolTotalInfluence f / ε⌉₊ / ε ^ 2 ∧
      (∀ x, h x = 1 ∨ h x = -1) ∧
      (∀ x y : BoolCube n, (∀ i ∈ J, x i = y i) → h x = h y) ∧
      boolDist f h ≤ 2 * ε
    abbrev BoolCube (n : ℕ) : Type := Fin n → Bool

    TheoremSpectral part of Friedgut's argument#✓fully proved

    BooleanCube.sum_sq_not_subset_le_of_influence

    Let \(f : \{-1, 1\}^n \to \{-1, 1\}\) with \(\mathbf{I}[f] > 0\), let \(\varepsilon > 0\) and \(k \in \mathbb{N}\), and put

    \[\tau = \frac{\varepsilon^2}{\mathbf{I}[f]^2\, 9^k}, \qquad J = \{j : \mathrm{Inf}_j[f] \ge \tau\}.\]

    Then \(\sum_{|S| \le k,\ S \not\subseteq J} \hat f(S)^2 \le \varepsilon\): the Fourier spectrum of \(f\) is \(\varepsilon\)-concentrated on \(\{S : S \subseteq J\} \cup \{S : |S| > k\}\).

    The proof sums Corollary 9.12, in the form \(\sum_{S \ni j} 3^{-|S|} \hat f(S)^2 \le \tfrac13 \mathrm{Inf}_j[f]^{3/2} \le \mathrm{Inf}_j[f]^{3/2}\), over the coordinates \(j \notin J\): the left side counts every set that leaves \(J\) with weight at least \(3^{-k}\), and the right side is at most \(\sqrt\tau\, \mathbf{I}[f] = 3^{-k} \varepsilon\).

    theorem sum_sq_not_subset_le_of_influence {f : BoolCube n → ℝ} (hf : ∀ x, f x = 1 ∨ f x = -1)
    (hI : 0 < boolTotalInfluence f) {ε : ℝ} (hε : 0 < ε) (k : ℕ) :
    ∑ S with S.card ≤ k ∧
        ¬S ⊆ Finset.univ.filter
          (fun j => ε ^ 2 / (boolTotalInfluence f ^ 2 * 9 ^ k) ≤ boolInfluence f j),
      boolFourierCoeff n f S ^ 2 ≤ ε
    abbrev BoolCube (n : ℕ) : Type := Fin n → Bool

    TheoremLevel-k Inequalities#✓fully proved

    BooleanCube.level_k_inequality

    Let \(f : \{-1, 1\}^n \to \{0, 1\}\) have mean \(\alpha = \mathbb{E}[f]\) and let \(k \ge 1\) be an integer with \(k \le 2 \ln(1/\alpha)\). Then

    \[\mathbf{W}^{\le k}[f] = \sum_{|S| \le k} \hat f(S)^2 \le \Big(\frac{2e}{k} \ln(1/\alpha)\Big)^k \alpha^2 .\]

    Indicators of small sets have little Fourier weight at low degrees. The proof combines \(\rho^k\, \mathbf{W}^{\le k}[f] \le \mathrm{Stab}_\rho[f]\) with the Small-Set Expansion Theorem \(\mathrm{Stab}_\rho[f] \le \alpha^{2/(1+\rho)} \le \alpha^{2(1-\rho)}\), at \(\rho = k / (2\ln(1/\alpha))\).

    theorem level_k_inequality {f : BoolCube n → ℝ} (hf : ∀ x, f x = 0 ∨ f x = 1) {k : ℕ}
    (hk : 1 ≤ k) (hkα : (k : ℝ) ≤ 2 * Real.log (1 / 𝔼 x, f x)) :
    ∑ S with S.card ≤ k, boolFourierCoeff n f S ^ 2 ≤
      (2 * Real.exp 1 / k * Real.log (1 / 𝔼 x, f x)) ^ k * (𝔼 x, f x) ^ 2
    abbrev BoolCube (n : ℕ) : Type := Fin n → Bool

    TheoremFourier expansion of the coordinate derivative#✓fully proved

    BooleanCube.stableInfluence_third_le

    Let \(f : \{-1, 1\}^n \to \{-1, 1\}\) and let \(i\) be a coordinate. The \(1/3\)-stable influence of \(i\),

    \[\mathrm{Inf}^{(1/3)}_i[f] = \mathrm{Stab}_{1/3}[D_i f] = \sum_{S \ni i} (1/3)^{|S| - 1}\, \hat f(S)^2,\]

    satisfies \(\mathrm{Inf}^{(1/3)}_i[f] \le \mathrm{Inf}_i[f]^{3/2}\). If the influence of \(i\) is small, its stable influence is much smaller. The bound is tight for a dictator, where both sides are \(1\).

    The derivative \(D_i f\) takes values in \(\{-1, 0, 1\}\) and is nonzero exactly where \(i\) is pivotal, so \(\|D_i f\|_{4/3}^2 = \Pr[D_i f \ne 0]^{3/2} = \mathrm{Inf}_i[f]^{3/2}\). The bound is then small-set expansion, \(\mathrm{Stab}_\rho[g] \le \|g\|_{1+\rho}^2\), at \(\rho = 1/3\).
