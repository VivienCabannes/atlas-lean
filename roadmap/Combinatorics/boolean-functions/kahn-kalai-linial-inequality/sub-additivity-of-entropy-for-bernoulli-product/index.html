    TheoremSub-additivity (tensorization) of entropy#✓fully proved

    StatMech.Probability.esd_subadditivity

    Sub-additivity (tensorization) of entropy for the Bernoulli(p) product measure on {0, 1}^n (see S. Boucheron, G. Lugosi, P. Massart, Concentration Inequalities, 2013, Theorem 4.10): for nonnegative g, Ent(g) ≤ ∑ₑ 𝔼[Entₑ(g)].

    theorem esd_subadditivity {n : ℕ} {p : ℝ} (hp0 : 0 < p) (hp1 : p < 1)
    (g : (Fin n → Bool) → ℝ) (hg : ∀ ω, 0 ≤ g ω) :
    esd_ent (OSSS.bernoulliWeight p) g
      ≤ ∑ e : Fin n, OSSS.expect (OSSS.bernoulliWeight p) (esd_entCoord p g e)
