    DefinitionSelf-dual monotone Boolean functions#✓fully proved

    MetaMathlibExt.IsSelfDualMonotone

    A Boolean function \(f \colon \{0,1\}^n \to \{0,1\}\) is self-dual monotone when it is monotone, that is, \(f(x) \le f(y)\) for all \(x, y \in \{0,1\}^n\) with \(x_i \le y_i\) for every \(i < n\), and it equals its dual, that is, \(f = f^\star\), where \(f^\star(x) = \lnot f(\bar x)\) and \(\bar x\) is the coordinatewise complement of \(x\).

    def IsSelfDualMonotone (n : Nat) (f : (Fin n → Bool) → Bool) : Prop :=
  (∀ x y : Fin n → Bool, (∀ i, x i ≤ y i) → f x ≤ f y) ∧ f = booleanFunctionDual n f
    def booleanFunctionDual (n : Nat) (f : (Fin n → Bool) → Bool) : (Fin n → Bool) → Bool :=
  fun x => !(f (booleanVectorComplement n x))

    DefinitionConcatenation of a list of Boolean functions#✓fully proved

    MetaMathlibExt.booleanCubeConcat

    Let \(n\) and \(k\) be natural numbers and let \(W = (W_0, W_1, \dots, W_{m-1})\) be a finite list of Boolean functions on \(n\) variables. The concatenation \(W_0 \cdot W_1 \cdots W_{m-1}\) on \(n + k\) variables is the Boolean function that sends \((x_0, \dots, x_{n-1}, y_0, \dots, y_{k-1})\) to \(W_i(x_0, \dots, x_{n-1})\), where \(i = \sum_{j < k} y_j 2^j\) is the number whose binary digits are the last \(k\) variables (true counted as \(1\) and false as \(0\)), and to false when \(i \ge m\).

    public def booleanCubeConcat (n k : ℕ) (W : List ((Fin n → Bool) → Bool)) :
    (Fin (n + k) → Bool) → Bool :=
  fun x => (W.getD (∑ j : Fin k, if x (Fin.natAdd n j) then 2 ^ (j : ℕ) else 0) fun _ => false)
    fun i => x (Fin.castAdd k i)

    TheoremWeights of monotone Boolean functions and their duals (Lemma 8)#●ready to prove

    MetaMathlibExt.monotoneBooleanFunction_weight_dual

    Order \(\{0,1\}\) by \(0 < 1\), inputs in \(\{0,1\}^n\) coordinatewise and Boolean functions on \(\{0,1\}^n\) pointwise. For such a function \(f\), let \(f^*(x) = \lnot f(\bar x)\) be its dual, where \(\bar x\) is the coordinatewise complement of \(x\), and let \(\ell(f)\) be the number of \(x \in \{0,1\}^n\) with \(f(x) = 1\). Let \(b\) be a monotone Boolean function on \(\{0,1\}^n\). Then: if \(b \le b^*\), then \(2\ell(b) \le 2^n\); if \(2\ell(b) = 2^n\) and \(b \le b^*\), then \(b = b^*\); if \(b = b^*\), then \(2\ell(b) = 2^n\); and \(\ell(b^*) = 2^n - \ell(b)\). Moreover, the number of monotone Boolean functions \(f\) on \(\{0,1\}^n\) with \(2\ell(f) < 2^n\) equals the number of those with \(2\ell(f) > 2^n\).

    For \(n \ge 1\) the comparisons of \(2\ell\) with \(2^n\) are the paper's comparisons of \(\ell\) with \(2^{n-1}\); written this way the statement also covers \(n = 0\).
