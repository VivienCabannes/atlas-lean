    DefinitionPartial Hadamard matrices#✓fully proved

    MathlibExt.Combinatorics.PartialHadamard.IsPartialHadamard

    Read a bit \(b \in \{0, 1\}\) as the sign \(\sigma(b)\), where \(\sigma(0) = -1\) and \(\sigma(1) = 1\). An \(n \times t\) matrix \(M\) with entries in \(\{0, 1\}\) is a partial Hadamard matrix when its rows are pairwise orthogonal as sign vectors: for all distinct rows \(i \ne i'\), \(\sum_{j < t} \sigma(M_{ij}) \sigma(M_{i'j}) = 0\).

    def IsPartialHadamard {n t : ℕ} (M : Fin n → Fin t → Fin 2) : Prop :=
  ∀ i i' : Fin n, i ≠ i' →
    ∑ j : Fin t, signVal (M i j) * signVal (M i' j) = 0
    def signVal (b : Fin 2) : ℤ := if b = 0 then -1 else 1

    DefinitionDe Launey–Levin leading term#✓fully proved

    MathlibExt.Combinatorics.PartialHadamard.leadingTerm

    For natural numbers \(n\) and \(t\), the de Launey–Levin leading term is the real number \(A_{n,4t} = 2^{4nt + (n-1)^2} (8\pi t)^{-n(n-1)/4}\), where the power of \(8\pi t\) is the real power function and \(n - 1\) in the exponent of \(2\) is truncated subtraction of natural numbers, so that \((n-1)^2 = 0\) when \(n = 0\).

    noncomputable def leadingTerm (n t : ℕ) : ℝ :=
  (2 : ℝ) ^ (4 * n * t + (n - 1) ^ 2) *
    (8 * Real.pi * t) ^ (-((n * (n - 1) : ℝ) / 4))

    DefinitionAdmissible exponents for the partial Hadamard leading term#✓fully proved

    MathlibExt.Combinatorics.PartialHadamard.IsLeadingAdmissible

    For natural numbers \(n\) and \(m\), let \(N_{n,m}\) be the number of \(n \times m\) partial Hadamard matrices, and for natural numbers \(n\) and \(t\) let \(A_{n,4t} = 2^{4nt + (n-1)^2} (8\pi t)^{-n(n-1)/4}\) be the de Launey–Levin leading term. A real number \(\alpha\) is admissible for the leading term when, for all sequences \((n_k)\) and \((t_k)\) of natural numbers with \(n_k \ge 2\) for every \(k\) and \(t_k / n_k^{\alpha} \to \infty\) as \(k \to \infty\), the ratio \(N_{n_k, 4t_k} / A_{n_k, 4t_k}\) tends to \(1\).

    The catalogue constant \(C_{23c}\) also allows corrected asymptotic formulas below the cubic scale; this predicate is its precise leading-term specialization, whose exact threshold the source records as \(3\).
