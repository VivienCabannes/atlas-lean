    TheoremCasorati–Weierstrass theorem#✓fully proved

    MathlibExt.Analysis.Complex.CasoratiWeierstrass.casoratiWeierstrass

    Let \(c \in \mathbb{C}\), \(r > 0\), and let \(f : \mathbb{C} \to \mathbb{C}\) be holomorphic on the punctured disc \(0 < |z - c| < r\) and not meromorphic at \(c\) (that is, \(c\) is neither a removable singularity nor a pole of \(f\)). Then the image of the punctured disc \(0 < |z - c| < r\) under \(f\) is dense in \(\mathbb{C}\).

    theorem casoratiWeierstrass

    (hf : DifferentiableOn ℂ f (Metric.ball c r \ {c}))
    (hess : ¬ MeromorphicAt f c) :
    Dense (f '' (Metric.ball c r \ {c}))

    Let \(c \in \mathbb{C}\), let \(r > 0\), and let \(f : \mathbb{C} \to \mathbb{C}\) be holomorphic on the punctured disc \(\{z \in \mathbb{C} : 0 < |z - c| < r\}\).     TheoremLooman–Menchoff theorem#✓fully proved

    MetaMathlibExt.looman_menchoff

    Let \(s \subseteq \mathbb{C}\) be open and let \(f : \mathbb{C} \to \mathbb{C}\) be continuous on \(s\). Write \(u = \operatorname{Re} f\) and \(v = \operatorname{Im} f\) as functions of \(z = x + iy\), and suppose that at every \(z \in s\) the partial derivatives \(u_x(z)\), \(u_y(z)\), \(v_x(z)\), \(v_y(z)\) exist and satisfy the Cauchy–Riemann equations \(u_x(z) = v_y(z)\) and \(u_y(z) = -v_x(z)\). Then \(f\) is complex differentiable on \(s\).

    Proof: Baire category gives a square with uniform axis-wise Lipschitz bounds on the exceptional set. A Goursat rectangle estimate and Morera's theorem eliminate that set.

    theorem looman_menchoff : ∀ {s : Set ℂ} {f : ℂ → ℂ} {ux uy vx vy : ℂ → ℝ},
    IsOpen s →
    ContinuousOn f s →
    (∀ z ∈ s, HasDerivAt (fun t : ℝ => (f (z + (t : ℂ))).re) (ux z) 0) →
    (∀ z ∈ s, HasDerivAt (fun t : ℝ => (f (z + (t : ℂ) * Complex.I)).re) (uy z) 0) →
    (∀ z ∈ s, HasDerivAt (fun t : ℝ => (f (z + (t : ℂ))).im) (vx z) 0) →
    (∀ z ∈ s, HasDerivAt (fun t : ℝ => (f (z + (t : ℂ) * Complex.I)).im) (vy z) 0) →
    (∀ z ∈ s, ux z = vy z) →
    (∀ z ∈ s, uy z = -(vx z)) →
    DifferentiableOn ℂ f s

    TheoremResidue theorem on a disc#●ready to prove

    MathlibExt.Analysis.Complex.ResidueTheoremWanted.residueTheorem_closedBall

    Let \(c\in\mathbb{C}\) and \(R>0\), and let \(S\) be a finite set of points of the open disc \(\{z:|z-c|\lt R\}\). For each \(s\in S\) let \(r_s>0\) be such that the closed disc \(\{z:|z-s|\le r_s\}\) lies in \(\{z:|z-c|\lt R\}\) and contains no point of \(S\) other than \(s\). Let \(f:\mathbb{C}\to\mathbb{C}\) be complex differentiable on \(\{z:|z-c|\le R\}\setminus S\) and integrable on the circle \(|z-c|=R\) and on each circle \(|z-s|=r_s\). Then, with all circles oriented counterclockwise,

    \[\oint_{|z-c|=R} f(z)\,dz=\sum_{s\in S}\oint_{|z-s|=r_s} f(z)\,dz.\]

    Each integral on the right is \(2\pi i\) times the residue of \(f\) at \(s\).

    (hS : ∀ s ∈ S, s ∈ Metric.ball c R)
    (hrad : ∀ s ∈ S, 0 < rad s ∧ Metric.closedBall s (rad s) ⊆ Metric.ball c R ∧
      ∀ s' ∈ S, s' ≠ s → s' ∉ Metric.closedBall s (rad s))
    (hf : DifferentiableOn ℂ f (Metric.closedBall c R \ ↑S))
    (hint : CircleIntegrable f c R)
    (hintS : ∀ s ∈ S, CircleIntegrable f s (rad s)) :

    TheoremSchwarz reflection principle#✓fully proved

    MetaMathlibExt.schwarz_reflection

    Let \(f : \mathbb{C} \to \mathbb{C}\) be holomorphic on the open upper half-plane \(\{z : \operatorname{Im} z > 0\}\), continuous on the closed upper half-plane \(\{z : \operatorname{Im} z \ge 0\}\), and real-valued on the real axis. Then there is an entire function \(g\) that agrees with \(f\) on the closed upper half-plane and satisfies \(g(\bar z) = \overline{g(z)}\) for every \(z \in \mathbb{C}\).

    theorem schwarz_reflection :
  ∀ (f : ℂ → ℂ),
    DifferentiableOn ℂ f {z | 0 < z.im} →
      ContinuousOn f {z | 0 ≤ z.im} →
        (∀ z : ℂ, z.im = 0 → (f z).im = 0) →
          ∃ g : ℂ → ℂ,
            DifferentiableOn ℂ g Set.univ ∧
              (∀ z : ℂ, 0 ≤ z.im → g z = f z) ∧
                ∀ z : ℂ, g (star z) = star (g z)
