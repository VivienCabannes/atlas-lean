    MathlibExt.Analysis.DirichletSpacePolynomialDensityWanted.IsDirichletDense

    A set \(S\) of elements of the Dirichlet space \(\mathcal{D}\) is dense in the Dirichlet norm when for every \(u \in \mathcal{D}\) and every real \(\varepsilon > 0\) there is \(h \in S\) with

    \[|h(0) - u(0)|^2 + \int_{|z| < 1} |h'(z) - u'(z)|^2 \, dA(z) < \varepsilon,\]

    where \(A\) is Lebesgue (area) measure on \(\mathbb{C}\).

    def IsDirichletDense (S : Set DirichletSpace) : Prop :=
  ∀ u : DirichletSpace, ∀ ε : ℝ, 0 < ε →
