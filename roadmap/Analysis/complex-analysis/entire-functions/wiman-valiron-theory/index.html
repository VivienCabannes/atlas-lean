    Complex.wimanTaylorCoefficient

    For a function \(f : \mathbb{C} \to \mathbb{C}\) and \(n \in \mathbb{N}\), the \(n\)th Taylor coefficient of \(f\) at the origin is \(a_n = f^{(n)}(0) / n!\), where \(f^{(n)}\) is the \(n\)th iterated complex derivative of \(f\).

    Here the derivative at a point where a function is not complex differentiable is taken to be \(0\). For an entire function these are the coefficients of its Taylor series at \(0\).

    def wimanTaylorCoefficient (f : ℂ → ℂ) (n : ℕ) : ℂ :=
  iteratedDeriv n f 0 / (n.factorial : ℂ)

    DefinitionWiman term#✓fully proved

    Complex.wimanTerm

    For a function \(f : \mathbb{C} \to \mathbb{C}\), a real number \(r\) and a natural number \(n\), the Wiman term of \(f\) at radius \(r\) and index \(n\) is the real number \(|a_n| \, |r|^n\), where \(a_n = f^{(n)}(0) / n!\) is the \(n\)th Taylor coefficient of \(f\) at the origin. It is the modulus of the \(n\)th Taylor term of \(f\) on the circle of radius \(|r|\).

    Using \(|r|\) makes a negative input denote the same radius as its absolute value, so the Wiman term is always nonnegative.

    def wimanTerm (f : ℂ → ℂ) (r : ℝ) (n : ℕ) : ℝ :=
  ‖wimanTaylorCoefficient f n‖ * |r| ^ n
    def wimanTaylorCoefficient (f : ℂ → ℂ) (n : ℕ) : ℂ :=
  iteratedDeriv n f 0 / (n.factorial : ℂ)
