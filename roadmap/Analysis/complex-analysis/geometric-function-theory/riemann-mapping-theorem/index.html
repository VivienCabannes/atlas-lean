    Riemann mapping theorem

    TheoremRiemann mapping theorem#✓fully proved

    MathlibExt.Analysis.Complex.RiemannMappingWanted.riemannMapping_normalized

    Let \(U\) be a simply connected open subset of \(\mathbb{C}\) with \(U \ne \mathbb{C}\), and let \(z_0 \in U\). Then there is a function \(f : \mathbb{C} \to \mathbb{C}\), holomorphic on \(U\), that maps \(U\) bijectively onto the open unit disc \(\{w : |w| < 1\}\), with \(f(z_0) = 0\) and \(f'(z_0)\) a positive real number. It is unique on \(U\): every function \(g : \mathbb{C} \to \mathbb{C}\) with the same four properties agrees with \(f\) at every point of \(U\).

    public theorem riemannMapping_normalized
    {U : Set ℂ} (hUo : IsOpen U) (hUc : IsSimplyConnected U) (hU : U ≠ Set.univ)
    {z₀ : ℂ} (hz₀ : z₀ ∈ U) :
    ∃ f : ℂ → ℂ, DifferentiableOn ℂ f U ∧ Set.BijOn f U (Metric.ball (0 : ℂ) 1) ∧
      f z₀ = 0 ∧ (deriv f z₀).im = 0 ∧ 0 < (deriv f z₀).re ∧
      ∀ g : ℂ → ℂ, DifferentiableOn ℂ g U → Set.BijOn g U (Metric.ball (0 : ℂ) 1) →
        g z₀ = 0 → (deriv g z₀).im = 0 → 0 < (deriv g z₀).re →
        Set.EqOn f g U

    MathlibExt.Analysis.Complex.InjectiveDiskMapExtremalDerivWanted.AdmissibleFamily

    For a set \(\Omega \subseteq \mathbb{C}\), the admissible family of \(\Omega\) is the set of functions \(f : \mathbb{C} \to \mathbb{C}\) that are complex differentiable on \(\Omega\), injective on \(\Omega\), satisfy \(f(0) = 0\), and map \(\Omega\) into the open unit disc \(\{z \in \mathbb{C} : |z| < 1\}\).

    def AdmissibleFamily (Ω : Set ℂ) : Set (ℂ → ℂ) :=
  {f | DifferentiableOn ℂ f Ω ∧ Set.InjOn f Ω ∧ f 0 = 0 ∧ Set.MapsTo f Ω unitDisk}
    abbrev unitDisk : Set ℂ := Metric.ball (0 : ℂ) 1

    MathlibExt.Analysis.Complex.InjectiveDiskMapExtremalDerivWanted.exists_mem_admissibleFamily_norm_deriv_eq_sSup

    Let \(D\) be the open unit disc \(\{z \in \mathbb{C} : |z| < 1\}\), let \(\Omega \subseteq D\) be open and connected with \(0 \in \Omega\), and let \(F\) be the family of functions \(f\) that are holomorphic and injective on \(\Omega\), map \(\Omega\) into \(D\), and satisfy \(f(0) = 0\). Then some \(g \in F\) attains the supremum of \(|f'(0)|\) over \(F\):

    \[|g'(0)| = \sup_{f \in F} |f'(0)|.\]
