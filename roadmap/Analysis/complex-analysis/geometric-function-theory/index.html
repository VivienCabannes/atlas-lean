    TheoremBloch's theorem#✓fully proved

    MathlibExt.Analysis.Complex.BlochWanted.bloch

    There is a constant \(B > 0\) with the following property. Let \(f : \mathbb{C} \to \mathbb{C}\) be holomorphic on the open unit disc \(\mathbb{D} = \{z : |z| < 1\}\) with \(f'(0) = 1\). Then there are an open connected set \(V \subseteq \mathbb{D}\) and a point \(w \in \mathbb{C}\) such that \(f\) is injective on \(V\) and \(f(V)\) is the open disc \(\{\zeta : |\zeta - w| < B\}\).

    theorem bloch
    : ∃ B : ℝ, 0 < B ∧
      ∀ f : ℂ → ℂ, DifferentiableOn ℂ f (Metric.ball (0 : ℂ) 1) → deriv f 0 = 1 →
        ∃ V : Set ℂ, ∃ w : ℂ,
          IsOpen V ∧ V ⊆ Metric.ball (0 : ℂ) 1 ∧ IsConnected V ∧
            Set.InjOn f V ∧ f '' V = Metric.ball w B

    TheoremNonconstant holomorphic functions of modulus one on the unit circle cover the unit disc#●ready to prove

    MathlibExt.Analysis.Complex.UnimodularBoundaryImageContainsDiscWanted.ball_subset_image_of_norm_eq_one_on_sphere

    Let \(U\subseteq\mathbb{C}\) be a connected open set containing the closed unit disc \(\{z:|z|\le 1\}\), and let \(f:\mathbb{C}\to\mathbb{C}\) be holomorphic on \(U\) and non-constant on \(U\). If \(|f(z)|=1\) whenever \(|z|=1\), then every \(w\) with \(|w|<1\) is \(f(z)\) for some \(z\in U\); that is, \(f(U)\) contains the open unit disc.

    The connectedness of \(U\) is added to the source statement, which asks only for an open set: for \(U=\{z:|z|<2\}\cup\{z:|z-10|<1\}\), with \(f=1\) on the first disc and \(f(z)=z\) on the second, \(f\) is non-constant and holomorphic on \(U\) and has modulus one on the unit circle, but \(f(U)\) does not contain the open unit disc.

    public theorem_wanted ball_subset_image_of_norm_eq_one_on_sphere {f : ℂ → ℂ} {U : Set ℂ}

    (hf : DifferentiableOn ℂ f U)
    (hnonconst : ∃ z₁ ∈ U, ∃ z₂ ∈ U, f z₁ ≠ f z₂)
    (hboundary : ∀ z, z ∈ Metric.sphere (0 : ℂ) 1 → ‖f z‖ = 1) :
    Metric.ball (0 : ℂ) 1 ⊆ f '' U
