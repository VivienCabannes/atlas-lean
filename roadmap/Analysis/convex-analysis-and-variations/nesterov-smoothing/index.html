    Nesterov smoothing

    Many nonsmooth convex functions are maxima of linear functions over a convex set, \(f_0(x) = \max_{u \in Q} (\langle A x, u\rangle - \varphi(u))\). Subtracting \(\mu\) times a strongly convex prox-function \(d\) of \(Q\) inside the maximum gives a function \(f_\mu\) that is uniformly within \(\mu \max_Q d\) of \(f_0\) and has a Lipschitz gradient with constant \(\|A\|^2/(\mu\sigma)\). Minimising \(f_\mu\) with an optimal method for smooth functions then solves the nonsmooth problem in \(O(1/\varepsilon)\) iterations, against \(O(1/\varepsilon^2)\) for subgradient methods (Nesterov, 2005).

    DefinitionNesterov's smoothed max-type function#✓fully proved

    MathlibExt.Analysis.Convex.NesterovSmoothing.smoothedMax

    Let \(E, F\) be real inner product spaces, \(A : E \to F\) a continuous linear map, \(Q \subseteq F\), \(\varphi, d : F \to \mathbb{R}\) and \(\mu \ge 0\). The smoothed max-type function is

    \[ f_\mu(x) = \sup_{u \in Q} \big(\langle A x, u\rangle - \varphi(u) - \mu\, d(u)\big), \]

    and \(f_0(x) = \sup_{u \in Q} (\langle A x, u\rangle - \varphi(u))\) is the nonsmooth function it approximates. In the source, \(Q\) is bounded, closed and convex, \(\varphi\) is continuous and convex, and \(d\) is a prox-function of \(Q\) (continuous and strongly convex, with minimum \(0\)), so the supremum is a maximum. The Lean definition is a supremum in \(\mathbb{R}\): it is meaningful only when the values are bounded above (for instance \(Q\) compact with \(\varphi, d\) continuous on \(Q\)), and it equals \(0\) when \(Q\) is empty. The source uses general norms and their duals on finite-dimensional spaces; the definition here uses inner products.

    Many nonsmooth convex functions have this form, for example \(\|x\|_1 = \max_{\|u\|_\infty \le 1} \langle x, u\rangle\) and \(\max_i x_i = \max_{u \in \Delta} \langle x, u\rangle\) over the simplex; with \(d(u) = \frac{1}{2}\|u\|^2\) the first gives a sum of Huber functions.

    noncomputable def smoothedMax (A : E →L[ℝ] F) (φ d : F → ℝ) (Q : Set F) (μ : ℝ) (x : E) : ℝ :=
  sSup ((fun u => inner ℝ (A x) u - φ u - μ * d u) '' Q)

    TheoremUniform approximation by the smoothed function#✓fully proved

    MathlibExt.Analysis.Convex.NesterovSmoothing.smoothedMax_le_and_le

    Let \(Q \subseteq F\) be compact and nonempty, \(\varphi\) and \(d\) continuous on \(Q\) with \(d \ge 0\) on \(Q\), \(\mu \ge 0\), and \(D = \sup_{u \in Q} d(u)\). Then for every \(x \in E\),

    \[ f_\mu(x) \le f_0(x) \le f_\mu(x) + \mu D, \]

    where \(f_\mu\) is the smoothed max-type function. The source assumes in addition that \(Q\) and \(\varphi\) are convex and \(d\) strongly convex with \(\min_Q d = 0\); the inequality needs only \(d \ge 0\), so the statement here has weaker hypotheses. Combined with the Lipschitz bound \(\|A\|^2/(\mu\sigma)\) on \(\nabla f_\mu\) and an optimal method for smooth functions, the choice \(\mu \sim \varepsilon/D\) gives an \(\varepsilon\)-solution of \(\min f_0\) in \(O(1/\varepsilon)\) iterations instead of the \(O(1/\varepsilon^2)\) of subgradient methods (Theorem 3 of the source, not formalized here).

    theorem smoothedMax_le_and_le (A : E →L[ℝ] F) {φ d : F → ℝ} {Q : Set F} (hQ : IsCompact Q)
    (hQne : Q.Nonempty) (hφ : ContinuousOn φ Q) (hd : ContinuousOn d Q)
    (hd0 : ∀ u ∈ Q, 0 ≤ d u) {μ : ℝ} (hμ : 0 ≤ μ) (x : E) :
    smoothedMax A φ d Q μ x ≤ smoothedMax A φ d Q 0 x ∧
      smoothedMax A φ d Q 0 x ≤ smoothedMax A φ d Q μ x + μ * sSup (d '' Q)
    noncomputable def smoothedMax (A : E →L[ℝ] F) (φ d : F → ℝ) (Q : Set F) (μ : ℝ) (x : E) : ℝ :=
  sSup ((fun u => inner ℝ (A x) u - φ u - μ * d u) '' Q)

    TheoremThe smoothed max-type function has a Lipschitz gradient#●ready to prove

    WantedExt.Analysis.Convex.NesterovSmoothingWanted.smoothedMax_convex_differentiable_lipschitz

    Wanted (statement only, proof deferred).

    Let \(E, F\) be finite-dimensional real inner product spaces, \(A : E \to F\) linear, \(Q \subseteq F\) nonempty, compact and convex, \(\varphi\) continuous and convex on \(Q\), \(d\) continuous and \(\sigma\)-strongly convex on \(Q\) with \(\sigma > 0\), and \(\mu > 0\). Then the smoothed max-type function \(f_\mu\) is convex and differentiable, and

    \[ \|\nabla f_\mu(x) - \nabla f_\mu(y)\| \le \frac{\|A\|^2}{\mu \sigma} \|x - y\| \qquad (x, y \in E). \]

    The source proves this for arbitrary norms on \(E\) and \(F\), with \(\|A\|_{1,2}\) the operator norm between them and the dual norm on gradients; the statement here is the Euclidean special case, so it is weaker than the source. The source also identifies the gradient, \(\nabla f_\mu(x) = A^* u_\mu(x)\) with \(u_\mu(x)\) the unique maximiser, which is not part of this statement.
