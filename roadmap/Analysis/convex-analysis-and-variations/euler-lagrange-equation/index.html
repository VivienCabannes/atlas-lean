    DefinitionPartial derivative of the Lagrangian in position#✓fully proved

    MathlibExt.Analysis.EulerLagrangeWanted.Analysis.lagrangianPartialX

    For a real function \(L(t, y, v)\) of three real variables, a function \(x : \mathbb{R} \to \mathbb{R}\) and a real number \(t\), this is the value \(\frac{\partial L}{\partial y}(t, x(t), x'(t))\), the derivative at \(y = x(t)\) of the function \(y \mapsto L(t, y, x'(t))\).

    By convention, a derivative that does not exist is taken to be \(0\), both for \(x'(t)\) and for the derivative in \(y\).

    noncomputable def lagrangianPartialX
    (L : ℝ → ℝ → ℝ → ℝ) (x : ℝ → ℝ) (t : ℝ) : ℝ :=
  deriv (fun y => L t y (deriv x t)) (x t)

    DefinitionVariational extremum#✓fully proved

    MathlibExt.Analysis.EulerLagrangeWanted.Analysis.IsVariationalExtremum

    Let \(a, b\) be real numbers and let \(L(t, y, v)\) be a real function of three real variables. A function \(x : \mathbb{R} \to \mathbb{R}\) is a variational extremum of the action of \(L\) on \((a, b)\) if \(x\) is continuously differentiable and, for every infinitely differentiable function \(h : \mathbb{R} \to \mathbb{R}\) of compact support whose closed support lies in the open interval \((a, b)\), the derivative at \(\varepsilon = 0\) of

    \[ \varepsilon \mapsto \int_{(a, b)} L\big(t, x(t) + \varepsilon h(t), x'(t) + \varepsilon h'(t)\big)\,dt \]

    is \(0\).

    By convention, a derivative that does not exist is taken to be \(0\), and so is the integral of a function that is not integrable.

    def IsVariationalExtremum
    (a b : ℝ) (L : ℝ → ℝ → ℝ → ℝ) (x : ℝ → ℝ) : Prop :=
  ContDiff ℝ 1 x ∧
  ∀ h : ℝ → ℝ, ContDiff ℝ ∞ h → HasCompactSupport h →
    tsupport h ⊆ Set.Ioo a b →
    deriv (fun ε : ℝ => ∫ t in Set.Ioo a b,
        L t (x t + ε * h t) (deriv x t + ε * deriv h t)) 0 = 0

    TheoremEuler–Lagrange equation#●ready to prove

    MathlibExt.Analysis.EulerLagrangeWanted.Analysis.euler_lagrange_equation

    Let \(a < b\) be real numbers, let \(L(t, y, v)\) be a real function of three real variables that is twice continuously differentiable on \(\mathbb{R}^3\), and let \(x : \mathbb{R} \to \mathbb{R}\) be twice continuously differentiable. Write \(\partial L / \partial y\) and \(\partial L / \partial v\) for the partial derivatives of \(L\) in its second and third arguments. If \(x\) is a variational extremum of the action of \(L\) on \((a, b)\), then for every \(t \in (a, b)\)

    \[ \frac{\partial L}{\partial y}(t, x(t), x'(t)) = \frac{d}{ds}\Big|_{s = t} \frac{\partial L}{\partial v}(s, x(s), x'(s)). \]
