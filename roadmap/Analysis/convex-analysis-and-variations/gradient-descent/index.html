    TheoremSublinear rate of gradient descent for smooth convex functions#✓fully proved

    MetaMathlibExt.gradient_descent_convex_sublinear_rate

    Let \(E\) be a finite-dimensional real inner product space, let \(L > 0\), and let \(f : E \to \mathbb{R}\) be convex and differentiable with \(L\)-Lipschitz gradient \(\nabla f\). Let \(x^\star \in E\) be a global minimizer of \(f\), let \(0 < \eta \le 1/L\), and let \((x_k)_{k \ge 0}\) be any sequence in \(E\) with \(x_{k+1} = x_k - \eta \nabla f(x_k)\) for all \(k\). Then for every \(k \ge 1\), \(f(x_k) - f(x^\star) \le \|x_0 - x^\star\|^2 / (2 \eta k)\).

    Proof: The descent lemma and first-order convexity inequality are proved on affine lines. They bound each objective gap by a difference of squared distances to \(x^\star\); telescoping and the monotonicity of \(f(x_k)\) in \(k\) give the rate, as in L. Vandenberghe, ECE236C lecture notes "Gradient method" (Spring 2022), slides 1.23-1.26.

    theorem gradient_descent_convex_sublinear_rate
    {E : Type*} [NormedAddCommGroup E] [InnerProductSpace ℝ E] [CompleteSpace E]
      [FiniteDimensional ℝ E]
    {f : E → ℝ} {L : ℝ} (hL : 0 < L)
    (hconvex : ConvexOn ℝ Set.univ f)
    (hdiff : Differentiable ℝ f)
    (hsmooth : LipschitzWith ⟨L, le_of_lt hL⟩ (gradient f))
    {xstar : E} (hmin : ∀ x, f xstar ≤ f x)
    {η : ℝ} (hη : η ∈ Set.Ioc 0 (1 / L))
    {X : ℕ → E} (hX : ∀ k, X (k + 1) = X k - η • gradient f (X k)) :
    ∀ k : ℕ, 0 < k →
      f (X k) - f xstar ≤ ‖X 0 - xstar‖ ^ 2 / (2 * η * (k : ℝ))

    DefinitionGradient descent with a step schedule#✓fully proved

    gradientDescentTrajectory

    Let \(E\) be a real Hilbert space, \(f : E \to \mathbb{R}\), \(s : \mathbb{N} \to \mathbb{R}\) a sequence of step sizes and \(x_0 \in E\). The gradient descent trajectory of \(f\) from \(x_0\) with steps \(s\) is the sequence \((x_k)_{k \in \mathbb{N}}\) in \(E\) starting at \(x_0\) with \(x_{k+1} = x_k - s_k \nabla f(x_k)\).

    Here \(\nabla f(x)\) is taken to be \(0\) at points \(x\) where \(f\) is not differentiable.

    noncomputable def gradientDescentTrajectory
    {E : Type*} [NormedAddCommGroup E] [InnerProductSpace ℝ E] [CompleteSpace E]
    (f : E → ℝ) (s : ℕ → ℝ) (x₀ : E) : ℕ → E
  | 0 => x₀
  | k + 1 => gradientDescentTrajectory f s x₀ k -
      s k • gradient f (gradientDescentTrajectory f s x₀ k)

    DefinitionConvex functions with \(1\)-Lipschitz gradient#✓fully proved

    IsUnitSmoothConvex

    A function \(f : E \to \mathbb{R}\) on a real Hilbert space \(E\) is unit-smooth convex if it is convex, differentiable, and its gradient is \(1\)-Lipschitz: \(\lVert \nabla f(x) - \nabla f(y) \rVert \le \lVert x - y \rVert\) for all \(x, y \in E\).

    def IsUnitSmoothConvex
    {E : Type*} [NormedAddCommGroup E] [InnerProductSpace ℝ E] [CompleteSpace E]
    (f : E → ℝ) : Prop :=
  ConvexOn ℝ Set.univ f ∧ Differentiable ℝ f ∧ LipschitzWith 1 (gradient f)

    DefinitionUniform last-iterate rate of a step schedule#✓fully proved

    GradientDescentUniformRate

    A step schedule \(s : \mathbb{N} \to \mathbb{R}\) achieves a uniform last-iterate rate with exponent \(c \in \mathbb{R}\) if there are a real number \(C > 0\) and an integer \(K \ge 1\) with the following property. For every \(d \in \mathbb{N}\), every convex differentiable function \(f : \mathbb{R}^d \to \mathbb{R}\) whose gradient is \(1\)-Lipschitz for the Euclidean norm, every \(x^\star \in \mathbb{R}^d\) with \(f(x^\star) \le f(x)\) for all \(x\), every \(x_0 \in \mathbb{R}^d\) and every integer \(k \ge K\), the \(k\)-th gradient descent iterate \(x_k\) of \(f\) from \(x_0\) with steps \(s\) satisfies

    \[f(x_k) - f(x^\star) \le \frac{C \lVert x_0 - x^\star \rVert^2}{k^c}.\]

    The constants \(C\) and \(K\) are chosen before, and do not depend on, \(d\), \(f\), \(x^\star\), \(x_0\) and \(k\).

    def GradientDescentUniformRate (s : ℕ → ℝ) (c : ℝ) : Prop :=
  ∃ C : ℝ, 0 < C ∧ ∃ K : ℕ, 0 < K ∧
    ∀ (d : ℕ) (f : EuclideanSpace ℝ (Fin d) → ℝ), IsUnitSmoothConvex f →
      ∀ xstar : EuclideanSpace ℝ (Fin d), (∀ x, f xstar ≤ f x) →
        ∀ x₀ : EuclideanSpace ℝ (Fin d), ∀ k : ℕ, K ≤ k →
          f (gradientDescentTrajectory f s x₀ k) - f xstar ≤
            C * ‖x₀ - xstar‖ ^ 2 / (k : ℝ) ^ c
    def IsUnitSmoothConvex
    {E : Type*} [NormedAddCommGroup E] [InnerProductSpace ℝ E] [CompleteSpace E]
    (f : E → ℝ) : Prop :=
  ConvexOn ℝ Set.univ f ∧ Differentiable ℝ f ∧ LipschitzWith 1 (gradient f)

    DefinitionThe gradient descent exponent#✓fully proved

    gradientDescentExponent

    The gradient descent exponent is the supremum, in the extended reals \([-\infty, +\infty]\), of the set of real numbers \(c\) such that some step schedule \(s : \mathbb{N} \to \mathbb{R}\) achieves a uniform last-iterate rate with exponent \(c\). In particular, it is \(-\infty\) if there is no such \(c\), and \(+\infty\) if these exponents are unbounded above.

    noncomputable def gradientDescentExponent : EReal :=
  sSup {r | ∃ c : ℝ, r = (c : EReal) ∧ ∃ s : ℕ → ℝ, GradientDescentUniformRate s c}
    def GradientDescentUniformRate (s : ℕ → ℝ) (c : ℝ) : Prop :=
  ∃ C : ℝ, 0 < C ∧ ∃ K : ℕ, 0 < K ∧
    ∀ (d : ℕ) (f : EuclideanSpace ℝ (Fin d) → ℝ), IsUnitSmoothConvex f →
      ∀ xstar : EuclideanSpace ℝ (Fin d), (∀ x, f xstar ≤ f x) →
        ∀ x₀ : EuclideanSpace ℝ (Fin d), ∀ k : ℕ, K ≤ k →
          f (gradientDescentTrajectory f s x₀ k) - f xstar ≤
            C * ‖x₀ - xstar‖ ^ 2 / (k : ℝ) ^ c

    silverGradientDescentSchedule

    The silver step schedule is the sequence \(s_t = 1 + \rho^{\nu_2(t + 1) - 1}\) for \(t \in \mathbb{N}\), where \(\rho = 1 + \sqrt{2}\) is the silver ratio and \(\nu_2(n)\) is the exponent of \(2\) in the prime factorization of \(n\).

    TheoremDescent lemma#✓fully proved

    MetaMathlibExt.gradientDescent_descent_lemma

    Let \(E\) be a real Hilbert space, let \(L \ge 0\), and let \(f \colon E \to \mathbb{R}\) be differentiable with \(L\)-Lipschitz gradient. Then for all \(x, d \in E\), $\(f(x + d) \le f(x) + \langle \nabla f(x), d \rangle + \frac{L}{2} \|d\|^2.\)$

    theorem gradientDescent_descent_lemma
    {E : Type*} [NormedAddCommGroup E] [InnerProductSpace ℝ E] [CompleteSpace E]
    {f : E → ℝ} {L : ℝ} (hL : 0 ≤ L) (hdiff : Differentiable ℝ f)
    (hsmooth : LipschitzWith ⟨L, hL⟩ (gradient f)) (x d : E) :
    f (x + d) ≤ f x + inner ℝ (gradient f x) d + L / 2 * ‖d‖ ^ 2

    TheoremConvergence of the subgradient method#✓fully proved

    MetaMathlibExt.subgradient_method_rate

    Let \(f : E \to \mathbb{R}\) on a real inner product space, let \(B, D > 0\), and let \(x_0, x_1, \dots\) be generated by \(x_{k+1} = x_k - \gamma_k g_k\) with \(\gamma_k = D / (B \sqrt{k + 1})\), where each \(g_k\) is a subgradient of \(f\) at \(x_k\), \(f(y) \ge f(x_k) + \langle g_k, y - x_k \rangle\) for all \(y\), with \(\|g_k\| \le B\). If \(\|x_0 - x^\star\| \le D\), then for every \(t \ge 1\),

    \[ \min_{0 \le k \lt t} f(x_k) - f(x^\star) \le \frac{D B (2 + \log t)}{2 \sqrt{t}}. \]

    For a convex \(B\)-Lipschitz function with a minimizer \(x^\star\), every subgradient has norm at most \(B\), which is the setting of the source. Proof: \(\|x_{k+1} - x^\star\|^2 \le \|x_k - x^\star\|^2 - 2 \gamma_k (f(x_k) - f(x^\star)) + \gamma_k^2 B^2\); summing, \(\sum_{k \lt t} \gamma_k (f(x_k) - f(x^\star)) \le \frac{D^2}{2} + \frac{B^2}{2} \sum_{k \lt t} \gamma_k^2\), with \(\sum_{k \lt t} \gamma_k^2 \le (D/B)^2 (1 + \log t)\) by the bound on harmonic numbers and \(\sum_{k \lt t} \gamma_k \ge D \sqrt{t} / B\); the smallest gap is at most the weighted average.

    Up to the logarithm, the rate \(D B / \sqrt{t}\) cannot be improved by any black-box method that queries values and subgradients as long as the number of steps stays below the dimension: for convex \(L\)-Lipschitz functions on a Euclidean ball of radius \(R\) in \(\mathbb{R}^d\), solving every such problem to accuracy \(\epsilon\) takes at least of order \(\min[d, L^2R^2/\epsilon^2]\) steps (Nemirovski and Yudin, 1983). With more steps than the dimension, dimension-dependent methods can do better. In expectation \(D B/\sqrt{t}\) is also the rate of stochastic gradient descent; it matches the \(1/\sqrt{n}\) estimation error of empirical risk minimization, so that one pass of stochastic gradient over \(n\) examples suffices statistically.

    theorem subgradient_method_rate
    {E : Type*} [NormedAddCommGroup E] [InnerProductSpace ℝ E]
    {f : E → ℝ} {B D : ℝ} (hB : 0 < B) (hD : 0 < D)
    {X g : ℕ → E} (hsub : ∀ k y, f (X k) + ⟪g k, y - X k⟫ ≤ f y) (hg : ∀ k, ‖g k‖ ≤ B)
    {xstar : E} (hdist : ‖X 0 - xstar‖ ≤ D)
    (hX : ∀ k, X (k + 1) = X k - (D / (B * √((k : ℝ) + 1))) • g k) {t : ℕ} (ht : 0 < t) :
    ∃ k < t, f (X k) - f xstar ≤ D * B * (2 + log t) / (2 * √t)

    TheoremConvergence of stochastic gradient descent#✓fully proved

    MathlibExt.Analysis.Convex.StochasticGradientDescent.integral_sgd_average_sub_le

    Let \(f\) be convex on a finite-dimensional real inner product space \(E\). Let \(\xi_0, \xi_1, \dots\) be i.i.d. random variables with law \(\nu\) and let \(G : E \times \Xi \to E\) be jointly measurable with \(\|G(\theta, \xi)\| \le B\) and with mean \(\int G(\theta, \xi) \, d\nu(\xi)\) a subgradient of \(f\) at every \(\theta\). Run stochastic gradient descent

    \[ \theta_{t+1} = \theta_t - \gamma_t \, G(\theta_t, \xi_t), \qquad \gamma_t = \frac{D}{B \sqrt{t + 1}}, \]

    from a deterministic \(\theta_0\). Then for every point \(\theta^\star\) with \(\|\theta_0 - \theta^\star\| \le D\), in particular a minimizer, and every \(t \ge 1\), the weighted average \(\bar\theta_t = \sum_{s \lt t} \gamma_s \theta_s / \sum_{s \lt t} \gamma_s\) satisfies

    \[ \mathbb{E}\big[f(\bar\theta_t)\big] - f(\theta^\star) \le \frac{D B (2 + \log t)}{2 \sqrt{t}}. \]

    The proof is that of the subgradient method with expectations: \(\theta_t\) is a measurable function of \(\xi_0, \dots, \xi_{t-1}\), hence independent of \(\xi_t\), and Fubini's theorem gives \(\mathbb{E}\langle G(\theta_t, \xi_t), \theta_t - \theta^\star \rangle \ge \mathbb{E}[f(\theta_t)] - f(\theta^\star)\), and Jensen's inequality passes to the average iterate.

    With \(f\) the expected risk and \(G(\theta, \xi)\) the gradient of the loss at one fresh example \(\xi\), this is single-pass stochastic gradient descent on the expected risk itself: after \(n\) examples its excess risk is of order \(D B / \sqrt{n}\), the same rate as the estimation error of empirical risk minimization over the ball of radius \(D\), at the cost of \(n\) gradient evaluations.

    theorem integral_sgd_average_sub_le
    {f : E → ℝ} (hf : ConvexOn ℝ Set.univ f) {θstar : E}
    {ν : Measure Ξ} [IsProbabilityMeasure ν] {G : E → Ξ → E}
    (hGmeas : Measurable (Function.uncurry G)) {B D : ℝ} (hB : 0 < B) (hD : 0 < D)
    (hGbound : ∀ θ ξ, ‖G θ ξ‖ ≤ B)
    (hGmean : ∀ θ y, f θ + ⟪∫ ξ, G θ ξ ∂ν, y - θ⟫ ≤ f y)
    {ξ : ℕ → Ω → Ξ} (hξmeas : ∀ t, Measurable (ξ t)) (hξindep : iIndepFun ξ μ)
    (hξlaw : ∀ t, μ.map (ξ t) = ν)
    {θ₀ : E} (hdist : ‖θ₀ - θstar‖ ≤ D) {θ : ℕ → Ω → E} (hθ0 : ∀ ω, θ 0 ω = θ₀)
    (hθ : ∀ t ω, θ (t + 1) ω = θ t ω - (D / (B * √((t : ℝ) + 1))) • G (θ t ω) (ξ t ω))
    {t : ℕ} (ht : 0 < t) :
    ∫ ω, f ((∑ s ∈ Finset.range t, D / (B * √((s : ℝ) + 1)))⁻¹ •
        ∑ s ∈ Finset.range t, (D / (B * √((s : ℝ) + 1))) • θ s ω) ∂μ - f θstar ≤
      D * B * (2 + log t) / (2 * √t)

    Expansiveness of the gradient step

    How far the gradient update \(G(w) = w - \alpha \nabla f(w)\) can move two points apart; these properties drive the stability analysis of stochastic gradient descent.

    TheoremCo-coercivity of the gradient#✓fully proved

    MathlibExt.Analysis.Convex.Cocoercivity.inner_gradient_sub_ge

    Let \(f\) be convex and differentiable on a real Hilbert space, with \(\beta\)-Lipschitz gradient (\(\beta > 0\)). Then for all \(v, w\),

    \[ \frac{1}{\beta}\, \lVert \nabla f(v) - \nabla f(w) \rVert^2 \le \langle \nabla f(v) - \nabla f(w),\, v - w \rangle . \]

    Proof: with \(g = \nabla f(y) - \nabla f(x)\) and \(z = y - g/\beta\), the first-order condition for strong convexity with modulus \(0\) at \(x\) gives \(f(z) \ge f(x) + \langle \nabla f(x), z - x\rangle\), and the descent lemma at \(y\) gives \(f(z) \le f(y) - \lVert g\rVert^2/\beta + \lVert g\rVert^2/(2\beta)\). Together, \(f(y) \ge f(x) + \langle \nabla f(x), y - x\rangle + \lVert \nabla f(y) - \nabla f(x)\rVert^2/(2\beta)\); adding this to the same inequality with \(x\) and \(y\) exchanged gives co-coercivity.

    Co-coercivity strengthens the monotonicity of the gradient of a convex function, and it is what makes the gradient update non-expansive for steps up to \(2/\beta\).

    theorem inner_gradient_sub_ge {f : E → ℝ} {β : ℝ} (hβ : 0 < β)
    (hconv : ConvexOn ℝ Set.univ f) (hdiff : Differentiable ℝ f)
    (hsmooth : LipschitzWith ⟨β, hβ.le⟩ (gradient f)) (v w : E) :
    1 / β * ‖gradient f v - gradient f w‖ ^ 2 ≤
      inner ℝ (gradient f v - gradient f w) (v - w)

    Let \(f\) be convex and differentiable on a real Hilbert space, with \(\beta\)-Lipschitz gradient (\(\beta > 0\)), and let \(0 \le \alpha \le 2/\beta\). Then the gradient update \(G(w) = w - \alpha \nabla f(w)\) is \(1\)-expansive: for all \(v, w\),
