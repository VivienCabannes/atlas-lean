    TheoremSublinear rate of gradient descent for smooth convex functions#✓fully proved

    MetaMathlibExt.gradient_descent_convex_sublinear_rate

    Let \(E\) be a finite-dimensional real inner product space, let \(L > 0\), and let \(f : E \to \mathbb{R}\) be convex and differentiable with \(L\)-Lipschitz gradient \(\nabla f\). Let \(x^\star \in E\) be a global minimizer of \(f\), let \(0 < \eta \le 1/L\), and let \((x_k)_{k \ge 0}\) be any sequence in \(E\) with \(x_{k+1} = x_k - \eta \nabla f(x_k)\) for all \(k\). Then for every \(k \ge 1\), \(f(x_k) - f(x^\star) \le \|x_0 - x^\star\|^2 / (2 \eta k)\).

    Proof: The descent lemma and first-order convexity inequality are proved on affine lines. They bound each objective gap by a difference of squared distances to \(x^\star\); telescoping and the monotonicity of \(f(x_k)\) in \(k\) give the rate, as in L. Vandenberghe, ECE236C lecture notes "Gradient method" (Spring 2022), slides 1.23-1.26.

    theorem gradient_descent_convex_sublinear_rate
    {E : Type*} [NormedAddCommGroup E] [InnerProductSpace ℝ E] [CompleteSpace E]
      [FiniteDimensional ℝ E]
    {f : E → ℝ} {L : ℝ} (hL : 0 < L)
    (hconvex : ConvexOn ℝ Set.univ f)
    (hdiff : Differentiable ℝ f)
    (hsmooth : LipschitzWith ⟨L, le_of_lt hL⟩ (gradient f))
    {xstar : E} (hmin : ∀ x, f xstar ≤ f x)
    {η : ℝ} (hη : η ∈ Set.Ioc 0 (1 / L))
    {X : ℕ → E} (hX : ∀ k, X (k + 1) = X k - η • gradient f (X k)) :
    ∀ k : ℕ, 0 < k →
      f (X k) - f xstar ≤ ‖X 0 - xstar‖ ^ 2 / (2 * η * (k : ℝ))

    DefinitionGradient descent with a step schedule#✓fully proved

    gradientDescentTrajectory

    Let \(E\) be a real Hilbert space, \(f : E \to \mathbb{R}\), \(s : \mathbb{N} \to \mathbb{R}\) a sequence of step sizes and \(x_0 \in E\). The gradient descent trajectory of \(f\) from \(x_0\) with steps \(s\) is the sequence \((x_k)_{k \in \mathbb{N}}\) in \(E\) starting at \(x_0\) with \(x_{k+1} = x_k - s_k \nabla f(x_k)\).

    Here \(\nabla f(x)\) is taken to be \(0\) at points \(x\) where \(f\) is not differentiable.

    noncomputable def gradientDescentTrajectory
    {E : Type*} [NormedAddCommGroup E] [InnerProductSpace ℝ E] [CompleteSpace E]
    (f : E → ℝ) (s : ℕ → ℝ) (x₀ : E) : ℕ → E
  | 0 => x₀
  | k + 1 => gradientDescentTrajectory f s x₀ k -
      s k • gradient f (gradientDescentTrajectory f s x₀ k)

    DefinitionConvex functions with \(1\)-Lipschitz gradient#✓fully proved

    IsUnitSmoothConvex

    A function \(f : E \to \mathbb{R}\) on a real Hilbert space \(E\) is unit-smooth convex if it is convex, differentiable, and its gradient is \(1\)-Lipschitz: \(\lVert \nabla f(x) - \nabla f(y) \rVert \le \lVert x - y \rVert\) for all \(x, y \in E\).

    def IsUnitSmoothConvex
    {E : Type*} [NormedAddCommGroup E] [InnerProductSpace ℝ E] [CompleteSpace E]
    (f : E → ℝ) : Prop :=
  ConvexOn ℝ Set.univ f ∧ Differentiable ℝ f ∧ LipschitzWith 1 (gradient f)

    DefinitionUniform last-iterate rate of a step schedule#✓fully proved

    GradientDescentUniformRate

    A step schedule \(s : \mathbb{N} \to \mathbb{R}\) achieves a uniform last-iterate rate with exponent \(c \in \mathbb{R}\) if there are a real number \(C > 0\) and an integer \(K \ge 1\) with the following property. For every \(d \in \mathbb{N}\), every convex differentiable function \(f : \mathbb{R}^d \to \mathbb{R}\) whose gradient is \(1\)-Lipschitz for the Euclidean norm, every \(x^\star \in \mathbb{R}^d\) with \(f(x^\star) \le f(x)\) for all \(x\), every \(x_0 \in \mathbb{R}^d\) and every integer \(k \ge K\), the \(k\)-th gradient descent iterate \(x_k\) of \(f\) from \(x_0\) with steps \(s\) satisfies

    \[f(x_k) - f(x^\star) \le \frac{C \lVert x_0 - x^\star \rVert^2}{k^c}.\]

    The constants \(C\) and \(K\) are chosen before, and do not depend on, \(d\), \(f\), \(x^\star\), \(x_0\) and \(k\).

    def GradientDescentUniformRate (s : ℕ → ℝ) (c : ℝ) : Prop :=
  ∃ C : ℝ, 0 < C ∧ ∃ K : ℕ, 0 < K ∧
    ∀ (d : ℕ) (f : EuclideanSpace ℝ (Fin d) → ℝ), IsUnitSmoothConvex f →
      ∀ xstar : EuclideanSpace ℝ (Fin d), (∀ x, f xstar ≤ f x) →
        ∀ x₀ : EuclideanSpace ℝ (Fin d), ∀ k : ℕ, K ≤ k →
          f (gradientDescentTrajectory f s x₀ k) - f xstar ≤
            C * ‖x₀ - xstar‖ ^ 2 / (k : ℝ) ^ c
    def IsUnitSmoothConvex
    {E : Type*} [NormedAddCommGroup E] [InnerProductSpace ℝ E] [CompleteSpace E]
    (f : E → ℝ) : Prop :=
  ConvexOn ℝ Set.univ f ∧ Differentiable ℝ f ∧ LipschitzWith 1 (gradient f)

    DefinitionThe gradient descent exponent#✓fully proved

    gradientDescentExponent

    The gradient descent exponent is the supremum, in the extended reals \([-\infty, +\infty]\), of the set of real numbers \(c\) such that some step schedule \(s : \mathbb{N} \to \mathbb{R}\) achieves a uniform last-iterate rate with exponent \(c\). In particular, it is \(-\infty\) if there is no such \(c\), and \(+\infty\) if these exponents are unbounded above.

    noncomputable def gradientDescentExponent : EReal :=
  sSup {r | ∃ c : ℝ, r = (c : EReal) ∧ ∃ s : ℕ → ℝ, GradientDescentUniformRate s c}
    def GradientDescentUniformRate (s : ℕ → ℝ) (c : ℝ) : Prop :=

    ∀ (d : ℕ) (f : EuclideanSpace ℝ (Fin d) → ℝ), IsUnitSmoothConvex f →
      ∀ xstar : EuclideanSpace ℝ (Fin d), (∀ x, f xstar ≤ f x) →
        ∀ x₀ : EuclideanSpace ℝ (Fin d), ∀ k : ℕ, K ≤ k →

    DefinitionSilver step schedule#✓fully proved

    silverGradientDescentSchedule

    The silver step schedule is the sequence \(s_t = 1 + \rho^{\nu_2(t + 1) - 1}\) for \(t \in \mathbb{N}\), where \(\rho = 1 + \sqrt{2}\) is the silver ratio and \(\nu_2(n)\) is the exponent of \(2\) in the prime factorization of \(n\).

    The exponent \(\nu_2(t + 1) - 1\) is an integer and equals \(-1\) for even \(t\), where \(s_t = 1 + \rho^{-1} = \sqrt{2}\).

    noncomputable def silverGradientDescentSchedule (t : ℕ) : ℝ :=
  1 + gradientDescentSilverRatio ^ ((padicValNat 2 (t + 1) : ℤ) - 1)
    noncomputable def gradientDescentSilverRatio : ℝ := 1 + Real.sqrt 2

    gradientDescentTrajectory_zeroSchedule

    Let \(E\) be a real Hilbert space, \(f : E \to \mathbb{R}\) and \(x_0 \in E\). If every step size is \(0\), then for every \(k \in \mathbb{N}\) the \(k\)-th gradient descent iterate of \(f\) from \(x_0\) equals \(x_0\).

    @[simp] theorem gradientDescentTrajectory_zeroSchedule
    {E : Type*} [NormedAddCommGroup E] [InnerProductSpace ℝ E] [CompleteSpace E]
    (f : E → ℝ) (x₀ : E) (k : ℕ) :
    gradientDescentTrajectory f (fun _ => 0) x₀ k = x₀
