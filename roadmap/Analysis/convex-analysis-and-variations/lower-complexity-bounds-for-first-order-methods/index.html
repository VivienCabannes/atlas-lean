    Lower complexity bounds for first-order methods

    How fast can any method that only queries gradients minimise a smooth convex function? Nesterov's answer bounds the error of every method whose iterates stay in \(x_0 + \operatorname{span}\{\nabla f(x_0), \dots, \nabla f(x_{k-1})\}\): on \(L\)-smooth convex functions no such method can beat \(\Omega(L\|x_0 - x^*\|^2/k^2)\) while \(k \le (n-1)/2\), and on \(\mu\)-strongly convex functions with condition number \(Q = L/\mu\) none can contract faster than \(((\sqrt{Q} - 1)/(\sqrt{Q} + 1))^{2k}\). The witnesses are quadratics with tridiagonal Hessians ("the worst function in the world"), on which a first-order method started at \(0\) discovers one coordinate per gradient. Comparing these bounds with the rates of accelerated methods shows that those methods are optimal up to constant factors. The smooth convex bound is proved; the strongly convex one is a wanted statement.

    TheoremLower complexity bound for smooth convex minimisation#✓fully proved

    MathlibExt.Analysis.Convex.FirstOrderLowerBound.exists_lower_bound_smooth_convex

    Let \(L > 0\) and integers \(k \ge 1\), \(n \ge 2k + 1\). For every \(x_0 \in \mathbb{R}^n\) there are a convex \(C^\infty\) function \(f\) on \(\mathbb{R}^n\) with \(L\)-Lipschitz gradient and a minimiser \(x^*\) of \(f\) such that every sequence \((x_j)\) with \(x_0\) given and

    \[ x_j \in x_0 + \operatorname{span}\{\nabla f(x_0), \dots, \nabla f(x_{j-1})\} \quad \text{for all } j \]

    satisfies

    \[ f(x_k) - f(x^*) \ge \frac{3L\,\|x_0 - x^*\|^2}{32(k+1)^2} \qquad\text{and}\qquad \|x_k - x^*\|^2 \ge \tfrac{1}{32}\|x_0 - x^*\|^2 . \]

    The sequence \((x_j)\) is the sequence of points at which a method queries the gradient, and the span condition is Assumption 2.1.4 of the source. Gradient descent, the conjugate gradient method and the accelerated methods (with their query points \(y_k\)) satisfy it. The function is Nesterov's "worst function in the world", shifted by \(x_0\):

    \[ f_{2k+1}(x) = \frac{L}{4}\Big(\frac{1}{2}\Big[(x^{(1)})^2 + \sum_{i=1}^{2k} (x^{(i)} - x^{(i+1)})^2 + (x^{(2k+1)})^2\Big] - x^{(1)}\Big), \]

    a quadratic with tridiagonal Hessian \(0 \preceq \nabla^2 f_{2k+1} \preceq L I\), minimised at \(\bar x^{(i)} = 1 - \frac{i}{2k+2}\) for \(i \le 2k+1\) and \(\bar x^{(i)} = 0\) otherwise. From \(x_0 = 0\), the \(j\)-th iterate of any method in the class has nonzero entries only in its first \(j\) coordinates, so \(f(x_k) \ge \min f_k\). For \(n > 2k + 1\) the minimiser is not unique; the statement asks for one minimiser, and the one provided is the source's \(x^*\), the shift of \(\bar x\).

    The bound is a lower bound on the error of every method in the class, valid for \(k \le (n-1)/2\); it does not say that the error stays large after more than \((n-1)/2\) iterations. The source remarks that a finer analysis gives \(L\|x_0 - x^*\|^2/(8(k+1)^2)\) and a constant arbitrarily close to \(1\) in the second inequality; those sharper constants are not stated here. The 1998 draft's second constant is \(1/32\); the constants of the published editions were not checked.

    The proof follows the source. Shifting by \(x_0\) reduces to \(x_0 = 0\). The Krylov argument (Lemma 2.1.3 of the source) shows by strong induction that \(x_j\) is supported on the first \(j\) coordinates, because a gradient of \(f_{{2k+1}}\) at a vector supported on the first \(j\) coordinates is supported on the first \(j + 1\). Then \(f(x_k) - f^* \ge f_k^* - f_{{2k+1}}^* = \frac{L}{16(k+1)}\), and \(\|\bar x\|^2 \le \frac{2k+2}{3}\) (from \(\sum_{l=1}^{m} l^2 \le (m+1)^3/3\)) turns this into the first bound. For the second, the coordinates \(k+1, \dots, 2k+1\) of \(x_k - \bar x\) are those of \(-\bar x\), and \(\sum_{l=1}^{k+1} l^2 \ge (k+1)^3/3\) gives \(\|x_k - \bar x\|^2 \ge \frac{k+1}{12}\), stronger than the needed \(\frac{k+1}{48}\).

    theorem exists_lower_bound_smooth_convex {k : ℕ} (hk : 1 ≤ k) (hkn : 2 * k + 1 ≤ n)
    {L : ℝ} (hL : 0 < L) (x₀ : EuclideanSpace ℝ (Fin n)) :
    ∃ f : EuclideanSpace ℝ (Fin n) → ℝ, ContDiff ℝ ∞ f ∧ ConvexOn ℝ Set.univ f ∧
      LipschitzWith ⟨L, hL.le⟩ (gradient f) ∧
      ∃ xstar : EuclideanSpace ℝ (Fin n), (∀ z, f xstar ≤ f z) ∧
        ∀ x : ℕ → EuclideanSpace ℝ (Fin n), x 0 = x₀ →
          (∀ j, x j - x₀ ∈ Submodule.span ℝ ((fun i => gradient f (x i)) '' Set.Iio j)) →
          3 * L * ‖x₀ - xstar‖ ^ 2 / (32 * ((k : ℝ) + 1) ^ 2) ≤ f (x k) - f xstar ∧
            ‖x₀ - xstar‖ ^ 2 / 32 ≤ ‖x k - xstar‖ ^ 2

    TheoremLower complexity bound for smooth strongly convex minimisation#●ready to prove

    WantedExt.Analysis.Convex.FirstOrderLowerBoundWanted.exists_lower_bound_strongly_convex

    Wanted (statement only, proof deferred).

    Let \(\mu > 0\) and \(Q > 1\). For every \(x_0 \in \ell^2\) there are a \(\mu\)-strongly convex \(C^\infty\) function \(f\) on the Hilbert space \(\ell^2\) of square-summable real sequences, with \(\mu Q\)-Lipschitz gradient, and a minimiser \(x^*\) of \(f\) such that every sequence \((x_j)\) with \(x_j \in x_0 + \operatorname{span}\{\nabla f(x_0), \dots, \nabla f(x_{j-1})\}\) for all \(j\) satisfies, for every \(k\),

    \[ \|x_k - x^*\|^2 \ge \Big(\frac{\sqrt{Q} - 1}{\sqrt{Q} + 1}\Big)^{2k} \|x_0 - x^*\|^2 \qquad\text{and}\qquad f(x_k) - f(x^*) \ge \frac{\mu}{2}\Big(\frac{\sqrt{Q} - 1}{\sqrt{Q} + 1}\Big)^{2k} \|x_0 - x^*\|^2 . \]

    Here \(Q = L/\mu\) is the condition number. The source works in \(\mathbb{R}^\infty\), which it identifies with \(\ell^2\); the worst function is a quadratic with tridiagonal Hessian whose minimiser is \((x^*)^{(i)} = q^i\), \(q = (\sqrt{Q} - 1)/(\sqrt{Q} + 1)\) (for \(x_0 = 0\)). The bound shows that \(\Omega(\sqrt{Q}\log(1/\varepsilon))\) iterations are necessary, which the accelerated method for strongly convex functions attains up to a constant factor.

    theorem_wanted exists_lower_bound_strongly_convex {μ Q : ℝ} (hμ : 0 < μ) (hQ : 1 < Q)
    (x₀ : lp (fun _ : ℕ => ℝ) 2) :
    ∃ f : lp (fun _ : ℕ => ℝ) 2 → ℝ, ContDiff ℝ ∞ f ∧ StrongConvexOn Set.univ μ f ∧
      LipschitzWith ⟨μ * Q, by positivity⟩ (gradient f) ∧
      ∃ xstar : lp (fun _ : ℕ => ℝ) 2, (∀ z, f xstar ≤ f z) ∧
        ∀ x : ℕ → lp (fun _ : ℕ => ℝ) 2, x 0 = x₀ →
          (∀ j, x j - x₀ ∈ Submodule.span ℝ ((fun i => gradient f (x i)) '' Set.Iio j)) →
          ∀ k : ℕ,
            ((√Q - 1) / (√Q + 1)) ^ (2 * k) * ‖x₀ - xstar‖ ^ 2 ≤ ‖x k - xstar‖ ^ 2 ∧
              μ / 2 * ((√Q - 1) / (√Q + 1)) ^ (2 * k) * ‖x₀ - xstar‖ ^ 2 ≤ f (x k) - f xstar

    The worst function

    DefinitionNesterov's worst function in the world#✓fully proved

    MathlibExt.Analysis.Convex.FirstOrderLowerBound.worstFunction

    For \(L \in \mathbb{R}\) and \(m \le n\), the quadratic \(f_m : \mathbb{R}^n \to \mathbb{R}\),

    \[ f_m(x) = \frac{L}{4}\Big(\frac{1}{2}\Big[(x^{(1)})^2 + \sum_{i=1}^{m-1} (x^{(i)} - x^{(i+1)})^2 + (x^{(m)})^2\Big] - x^{(1)}\Big), \]

    with coordinates indexed from \(1\). Its Hessian is \(\frac{L}{4} A_m\), where \(A_m\) is the tridiagonal matrix with \(2\) on the diagonal and \(-1\) beside it in the leading \(m \times m\) block and zeros elsewhere. The Lean definition writes the bracket as \(\sum_{i=0}^{m} (x^{(i)} - x^{(i+1)})^2\) with \(x^{(0)} = x^{(m+1)} = 0\), using vectors coordVec n m j equal to the \(j\)-th basis vector for \(1 \le j \le m\) and to \(0\) otherwise.

    The point of the construction is that a gradient at a vector supported on the first \(j\) coordinates is supported on the first \(j + 1\): from \(0\), a first-order method discovers one coordinate per gradient, while the minimiser of \(f_{2k+1}\) has \(2k + 1\) nonzero coordinates.

    noncomputable def worstFunction (n m : ℕ) (L : ℝ) (x : EuclideanSpace ℝ (Fin n)) : ℝ :=
  L / 4 * (1 / 2 * ∑ i ∈ Finset.range (m + 1),
    inner ℝ (coordVec n m i - coordVec n m (i + 1)) x ^ 2 - inner ℝ (coordVec n m 1) x)
    noncomputable def coordVec (n m j : ℕ) : EuclideanSpace ℝ (Fin n) :=
  if h : 1 ≤ j ∧ j ≤ m ∧ j ≤ n then EuclideanSpace.single ⟨j - 1, by omega⟩ 1 else 0

    DefinitionMinimiser of the worst function#✓fully proved

    MathlibExt.Analysis.Convex.FirstOrderLowerBound.worstMinimizer

    The vector \(\bar x \in \mathbb{R}^n\) with

    \[ \bar x^{(j)} = 1 - \frac{j}{m + 1} \quad (1 \le j \le m), \qquad \bar x^{(j)} = 0 \quad (j > m). \]

    It solves \(A_m x = e_1\), so it minimises the worst function \(f_m\) (see its minimum value). For \(n > m\) the minimiser is not unique: any vector agreeing with \(\bar x\) on the first \(m\) coordinates is also one.

    noncomputable def worstMinimizer (n m : ℕ) : EuclideanSpace ℝ (Fin n) :=
  WithLp.toLp 2 fun p : Fin n => if (p : ℕ) < m then 1 - ((p : ℕ) + 1 : ℝ) / (m + 1) else 0

    LemmaThe worst function is smooth, convex and \(L\)-smooth#✓fully proved

    MathlibExt.Analysis.Convex.FirstOrderLowerBound.worstFunction_mem_class

    For \(L \ge 0\), the worst function \(f_m\) on \(\mathbb{R}^n\) is \(C^\infty\), convex, and its gradient is \(L\)-Lipschitz: \(f_m\) belongs to the class \(F^{\infty,1}_L(\mathbb{R}^n)\), as the source shows from \(0 \preceq \frac{L}{4} A_m \preceq L I\).

    The Lean proof does not use Hessians. Convexity follows from \((a u + b v)^2 \le a u^2 + b v^2\) for \(a + b = 1\), \(a, b \ge 0\). The gradient is \(\nabla f_m(x) = \frac{L}{4}\big(\sum_i \langle a_i, x\rangle a_i - e_1\big)\) with \(a_i = e_i - e_{i+1}\); the bound \(\sum_i \langle a_i, u\rangle^2 \le 4\|u\|^2\) (from \((p - q)^2 \le 2p^2 + 2q^2\) and Bessel's inequality) and the Cauchy–Schwarz inequality give \(\|\sum_i \langle a_i, w\rangle a_i\| \le 4\|w\|\).

    lemma worstFunction_mem_class (m : ℕ) {L : ℝ} (hL : 0 ≤ L) :
    ContDiff ℝ ∞ (worstFunction n m L) ∧ ConvexOn ℝ Set.univ (worstFunction n m L) ∧
      LipschitzWith ⟨L, hL⟩ (gradient (worstFunction n m L))
    noncomputable def worstFunction (n m : ℕ) (L : ℝ) (x : EuclideanSpace ℝ (Fin n)) : ℝ :=
  L / 4 * (1 / 2 * ∑ i ∈ Finset.range (m + 1),
    inner ℝ (coordVec n m i - coordVec n m (i + 1)) x ^ 2 - inner ℝ (coordVec n m 1) x)

    LemmaMinimum of the worst function on the first \(k\) coordinates#✓fully proved

    MathlibExt.Analysis.Convex.FirstOrderLowerBound.worstFunction_ge_of_support

    Let \(L \ge 0\) and \(1 \le k \le m\) (the case of interest is \(m \le n\); the Lean statement does not need it). If \(z \in \mathbb{R}^n\) has \(z^{(j)} = 0\) for \(k < j \le m\), then

    \[ f_m(z) \ge -\frac{L}{8} \cdot \frac{k}{k + 1} = \frac{L}{8}\Big(-1 + \frac{1}{k + 1}\Big). \]

    For \(k = m\) the hypothesis is empty, and the bound holds on all of \(\mathbb{R}^n\). On such vectors \(f_m(z) = f_k(z) \ge f_k^*\), which is how the source argues (Corollary 2.1.1, with the value \(f_k^*\) computed from \(\bar x_k\)). The Lean proof instead drops the nonnegative terms beyond index \(k\) and applies the Cauchy–Schwarz inequality to the \(k\) differences \(d_i = z^{(i)} - z^{(i+1)}\), whose sum is \(z^{(1)}\): then \(\sum d_i^2 \ge (z^{(1)})^2 / k\), and \(\frac{1}{2} t^2 (1 + 1/k) - t \ge -\frac{k}{2(k+1)}\). The hypothesis is stated through the vectors coordVec n m j of the worst function, and only coordinates \(j \le m\) are constrained.

    lemma worstFunction_ge_of_support {m k : ℕ} (hk : 1 ≤ k) (hkm : k ≤ m) {L : ℝ} (hL : 0 ≤ L)
    {z : EuclideanSpace ℝ (Fin n)} (hz : ∀ j, k < j → inner ℝ (coordVec n m j) z = 0) :
    -(L / 8) * (k / (k + 1)) ≤ worstFunction n m L z
    noncomputable def coordVec (n m j : ℕ) : EuclideanSpace ℝ (Fin n) :=

    LemmaMinimum value of the worst function#✓fully proved

    MathlibExt.Analysis.Convex.FirstOrderLowerBound.worstFunction_worstMinimizer

    For \(1 \le m \le n\) and every \(L\),

    \[ f_m(\bar x) = -\frac{L}{8} \cdot \frac{m}{m + 1} = \frac{L}{8}\Big(-1 + \frac{1}{m + 1}\Big), \]
