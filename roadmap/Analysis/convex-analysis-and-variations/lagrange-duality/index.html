    Lagrange duality

    For the problem of minimizing \(f_0(x)\) over \(x \in D\) subject to \(f_i(x) \le 0\) (\(i \in \iota\), finite), the Lagrangian \(L(x, \mu) = f_0(x) + \sum_i \mu_i f_i(x)\) yields the dual function \(g(\mu) = \inf_{x \in D} L(x, \mu)\), a lower bound on the optimal value \(p^\star\) for every \(\mu \ge 0\) (weak duality). For convex problems, Slater's condition (a strictly feasible point) closes the gap: \(d^\star = \sup_{\mu \ge 0} g(\mu) = p^\star\), with a dual optimal \(\mu\) when \(p^\star > -\infty\). The proof separates two convex sets in the space of constraint and objective values. With differentiability, the first-order condition makes the Karush–Kuhn–Tucker conditions sufficient for optimality, and the same argument bounds the suboptimality of the central points of the logarithmic barrier method by \(m/t\), the basis of interior-point methods.

    Equality constraints are not covered yet: Boyd–Vandenberghe's Slater theorem also allows affine equality constraints, with the strictly feasible point in the relative interior of \(D\).

    MathlibExt.Analysis.Convex.LagrangeDuality.lagrangian

    Throughout, \(E\) is a real vector space, \(D \subseteq E\), \(\iota\) is a finite index set, and the problem is to minimize \(f_0(x)\) subject to \(x \in D\) and \(f_i(x) \le 0\) for \(i \in \iota\), with \(f_0, f_i \colon E \to \mathbb{R}\). The Lagrangian of the problem is $\(L(x, \mu) = f_0(x) + \sum_{i \in \iota} \mu_i f_i(x), \qquad x \in E,\ \mu \in \mathbb{R}^\iota.\)$ The \(\mu_i\) are the Lagrange multipliers (Boyd–Vandenberghe write \(\lambda_i\)).

    def lagrangian (f₀ : E → ℝ) (f : ι → E → ℝ) (x : E) (μ : ι → ℝ) : ℝ :=
  f₀ x + ∑ i, μ i * f i x

    Strong duality under Slater's condition

    TheoremSlater's theorem, multiplier form#✓fully proved

    MathlibExt.Analysis.Convex.LagrangeDuality.exists_multiplier_of_slater

    Throughout, \(E\) is a real vector space, \(D \subseteq E\), \(\iota\) is a finite index set, and the problem is to minimize \(f_0(x)\) subject to \(x \in D\) and \(f_i(x) \le 0\) for \(i \in \iota\), with \(f_0, f_i \colon E \to \mathbb{R}\). Suppose the problem is convex: \(f_0\) and every \(f_i\) are convex on \(D\) (in particular \(D\) is convex). Suppose Slater's condition holds: some \(\tilde x \in D\) has \(f_i(\tilde x) < 0\) for all \(i\). If \(p \in \mathbb{R}\) satisfies \(p \le f_0(x)\) for every feasible \(x\), then there is \(\mu \ge 0\) with \(p \le L(x, \mu)\) for every \(x \in D\), i.e. \(p \le g(\mu)\).

    Proof: the set \(\mathcal{A} = \{(u, t) : \exists x \in D,\ f_i(x) \le u_i \text{ for all } i,\ f_0(x) \le t\}\) is convex and disjoint from the open convex set \(\{(u, t) : u < 0,\ t < p\}\), so a nonzero linear functional \((u, t) \mapsto \nu^{\mathsf T} u + \mu_0 t\) separates them. Upward closedness of \(\mathcal{A}\) gives \(\nu, \mu_0 \ge 0\); Slater's point rules out \(\mu_0 = 0\); and \(\mu = \nu / \mu_0\) works. Unlike Boyd–Vandenberghe's version, no relative-interior condition on \(D\) is needed because there are no equality constraints.

    theorem exists_multiplier_of_slater [AddCommGroup E] [Module ℝ E]
    {D : Set E} {f₀ : E → ℝ} {f : ι → E → ℝ}
    (hf₀ : ConvexOn ℝ D f₀) (hf : ∀ i, ConvexOn ℝ D (f i))
    (hslater : ∃ x ∈ D, ∀ i, f i x < 0) (p : ℝ)
    (hp : ∀ x ∈ D, (∀ i, f i x ≤ 0) → p ≤ f₀ x) :
    ∃ μ : ι → ℝ, 0 ≤ μ ∧ ∀ x ∈ D, p ≤ lagrangian f₀ f x μ
    def lagrangian (f₀ : E → ℝ) (f : ι → E → ℝ) (x : E) (μ : ι → ℝ) : ℝ :=
  f₀ x + ∑ i, μ i * f i x

    TheoremThe dual function of a linearly constrained problem is minus a conjugate#✓fully proved

    MathlibExt.Analysis.Convex.DualViaConjugate.dualFunction_linear_eq_neg_sub_fenchelConj

    Let \(E\) be a real normed space, \(f_0 \colon E \to \mathbb{R}\), and for \(i\) in a finite set \(\iota\) let \(a_i\) be a continuous linear functional on \(E\) and \(b_i \in \mathbb{R}\). For the problem of minimizing \(f_0(x)\) subject to \(a_i(x) \le b_i\), the Lagrange dual function (with \(D = E\)) is $\(g(\mu) = -\sum_i \mu_i b_i - f_0^*\Big(-\sum_i \mu_i a_i\Big), \qquad \mu \in \mathbb{R}^\iota,\)$ where \(f_0^*(L) = \sup_x \big(L(x) - f_0(x)\big)\) is the Fenchel conjugate, and both sides are extended reals. Computing the dual of a linearly constrained problem thus amounts to computing a conjugate; e.g. \(g(\mu) = -\infty\) exactly when \(-\sum_i \mu_i a_i\) lies outside the domain of \(f_0^*\).

    theorem dualFunction_linear_eq_neg_sub_fenchelConj (f₀ : E → ℝ) (a : ι → E →L[ℝ] ℝ)
    (b : ι → ℝ) (μ : ι → ℝ) :
    dualFunction Set.univ f₀ (fun i x => a i x - b i) μ =
      ((-∑ i, μ i * b i : ℝ) : EReal) -
        fenchelConj (fun x => ((f₀ x : ℝ) : EReal)) (-∑ i, μ i • a i)
