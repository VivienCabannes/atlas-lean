    Accelerated gradient methods

    Nesterov's accelerated gradient method minimizes a convex function with \(L\)-Lipschitz gradient at the rate \(O(L\|x_0 - x^\star\|^2 / k^2)\), against \(O(1/k)\) for plain gradient descent. Wibisono, Wilson and Jordan read acceleration as the discretization of a continuous-time flow: the Euler–Lagrange equation of the Bregman Lagrangian, whose energy is a Lyapunov function giving the rate \(O(e^{-\beta_t})\); the polynomial family \(\beta_t = p \log t + \log C\) gives \(O(1/t^p)\), and \(p = 2\) in the Euclidean case is the differential equation \(\ddot X + \frac{3}{t}\dot X + \nabla f(X) = 0\) of Su, Boyd and Candès. Wilson, Recht and Jordan discretize the same Lyapunov function to analyse Nesterov's three-sequence method, which couples a gradient step with a dual-averaging (mirror-descent) step.

    Nesterov's own analysis uses estimate sequences: quadratic functions \(\varphi_k(x) = \varphi_k^* + \frac{\gamma_k}{2}\|x - v_k\|^2\) built from lower models of \(f\), with \(\varphi_k \le (1 - \lambda_k) f + \lambda_k \varphi_0\) and \(f(x_k) \le \varphi_k^*\), so that \(f(x_k) - f^* \le \lambda_k(\varphi_0(x^*) - f^*)\). With \(\gamma_0 = L\) this gives \(L\min\{(1 - \sqrt{\mu/L})^k, 4/(k+2)^2\}\|x_0 - x^*\|^2\) for \(\mu\)-strongly convex \(f\) (\(\mu \ge 0\)), and with \(\gamma_0 = \mu\) the constant-step method with rate \((1 - \sqrt{\mu/L})^k\); both match the lower complexity bounds for first-order methods up to constant factors (in the error for the smooth convex case, in the iteration count for the strongly convex case).

    MathlibExt.Analysis.Convex.AcceleratedGradient.nesterov_accelerated_rate

    Let \(E\) be a real Hilbert space, \(L > 0\), and \(f : E \to \mathbb{R}\) convex and differentiable with \(L\)-Lipschitz gradient. Run the accelerated gradient method from \(z_0 \in E\):

    \[ x_{k+1} = \tfrac{k}{k+2}\, y_k + \tfrac{2}{k+2}\, z_k, \qquad y_{k+1} = x_{k+1} - \tfrac{1}{L} \nabla f(x_{k+1}), \qquad z_{k+1} = z_k - \tfrac{k+1}{2L} \nabla f(x_{k+1}) \]

    (the point \(y_0\) is never used, since \(x_1 = z_0\)). Then for every \(u \in E\) and every \(k \ge 1\),

    \[ f(y_k) - f(u) \le \frac{2L\,\|z_0 - u\|^2}{k(k+1)}. \]

    With \(u\) a minimizer this is the accelerated rate \(O(L\|z_0 - x^\star\|^2/k^2)\), against \(O(L\|x_0 - x^\star\|^2/k)\) for gradient descent with step \(1/L\). No minimizer needs to exist for the inequality itself.

    The method couples a gradient step (\(y\)) with a dual-averaging step of growing weight \(a_k = (k+1)/(2L)\) (\(z\)); the proof applies the bound on the Lyapunov function with \(A_k = k(k+1)/(4L)\), for which \(L(A_{k+1} - A_k)^2 \le A_{k+1}\) and the coupling weight is \(\tau_k = (A_{k+1} - A_k)/A_{k+1} = 2/(k+2)\).

    theorem nesterov_accelerated_rate {f : E → ℝ} {L : ℝ} (hL : 0 < L)
    (hconvex : ConvexOn ℝ Set.univ f) (hdiff : Differentiable ℝ f)
    (hsmooth : LipschitzWith ⟨L, le_of_lt hL⟩ (gradient f)) (u : E)
    {x y z : ℕ → E}
    (hx : ∀ k : ℕ, x (k + 1) = ((k : ℝ) / (k + 2)) • y k + (2 / ((k : ℝ) + 2)) • z k)
    (hy : ∀ k, y (k + 1) = x (k + 1) - (1 / L) • gradient f (x (k + 1)))
    (hz : ∀ k : ℕ, z (k + 1) = z k - (((k : ℝ) + 1) / (2 * L)) • gradient f (x (k + 1)))
    {k : ℕ} (hk : 0 < k) :
    f (y k) - f u ≤ 2 * L * ‖z 0 - u‖ ^ 2 / ((k : ℝ) * (k + 1))

    Let \(E\) be a real Hilbert space, \(L > 0\), \(f : E \to \mathbb{R}\) convex and differentiable with \(L\)-Lipschitz gradient, and \(u \in E\). Let \(0 \le A \le A'\) with \(L(A' - A)^2 \le A'\), and from \(y, z \in E\) take

    \[ A' x' = A\, y + (A' - A)\, z, \qquad y' = x' - \tfrac{1}{L}\nabla f(x'), \qquad z' = z - (A' - A)\nabla f(x'). \]

    Then

    \[ A'\,(f(y') - f(u)) + \tfrac12\|z' - u\|^2 \le A\,(f(y) - f(u)) + \tfrac12\|z - u\|^2 . \]

    Proof: with \(g = \nabla f(x')\) and \(a = A' - A\), expand \(\tfrac12\|z' - u\|^2 = \tfrac12\|z - u\|^2 - a\langle g, z - u\rangle + \tfrac{a^2}{2}\|g\|^2\); bound \(f(y') \le f(x') - \|g\|^2/(2L)\) by sufficient decrease; bound \(A(f(x') - f(y)) + a(f(x') - f(u))\) by \(A\langle g, x' - y\rangle + a\langle g, x' - u\rangle = a\langle g, z - u\rangle\) using convexity and the coupling. What remains is \((a^2 - A'/L)\|g\|^2/2 \le 0\).

    theorem accelerated_lyapunov_step {f : E → ℝ} {L : ℝ} (hL : 0 < L)
    (hconvex : ConvexOn ℝ Set.univ f) (hdiff : Differentiable ℝ f)
    (hsmooth : LipschitzWith ⟨L, le_of_lt hL⟩ (gradient f)) (u : E)
    {A A' : ℝ} (hA : 0 ≤ A) (hAA' : A ≤ A') (hstep : L * (A' - A) ^ 2 ≤ A')
    {x' y y' z z' : E} (hx : A' • x' = A • y + (A' - A) • z)
    (hy : y' = x' - (1 / L) • gradient f x') (hz : z' = z - (A' - A) • gradient f x') :
    A' * (f y' - f u) + ‖z' - u‖ ^ 2 / 2 ≤ A * (f y - f u) + ‖z - u‖ ^ 2 / 2

    Let \(E\) be a real Hilbert space, \(L > 0\), \(f : E \to \mathbb{R}\) convex and differentiable with \(L\)-Lipschitz gradient, and \(u \in E\). Let \((A_k)\) be nondecreasing with \(A_0 \ge 0\) and \(L(A_{k+1} - A_k)^2 \le A_{k+1}\), and let \((x_k), (y_k), (z_k)\) satisfy, for every \(k\),

    \[ A_{k+1} x_{k+1} = A_k y_k + (A_{k+1} - A_k) z_k, \quad y_{k+1} = x_{k+1} - \tfrac1L \nabla f(x_{k+1}), \quad z_{k+1} = z_k - (A_{k+1} - A_k)\nabla f(x_{k+1}). \]

    Then for every \(k\), with \(\mathcal E_k = A_k(f(y_k) - f(u)) + \tfrac12\|z_k - u\|^2\),

    \[ \mathcal E_k \le \mathcal E_0 . \]

    The growth condition \(L(A_{k+1} - A_k)^2 \le A_{k+1}\) caps \(A_k\) at order \(k^2/L\), which is where the \(O(1/k^2)\) rate comes from.

    MathlibExt.Analysis.Convex.AcceleratedGradientFlow.energy

    For curves \(X, Z : \mathbb{R} \to E\) in a real Hilbert space, a function \(f : E \to \mathbb{R}\), a time scale \(\beta : \mathbb{R} \to \mathbb{R}\) and a point \(x^\star \in E\),

    \[ \mathcal E_t = \tfrac12\|Z_t - x^\star\|^2 + e^{\beta_t}\,\bigl(f(X_t) - f(x^\star)\bigr). \]

    MathlibExt.Analysis.Convex.AcceleratedGradientFlow.bregmanLagrangian_energy_antitoneOn

    Let \(E\) be a real Hilbert space and \(f : E \to \mathbb{R}\) convex and differentiable with a global minimizer \(x^\star\). Let \(\alpha, \beta : \mathbb{R} \to \mathbb{R}\) and \(X, Z : \mathbb{R} \to E\), and \(t_0 \in \mathbb{R}\). Suppose that at every \(t \ge t_0\), \(\beta\) is differentiable with the ideal scaling \(\dot\beta_t \le e^{\alpha_t}\) (eq. (2.2a)), and

    \[ \dot X_t = e^{\alpha_t}(Z_t - X_t), \qquad \dot Z_t = -e^{\alpha_t + \beta_t}\,\nabla f(X_t). \]

    The first equation says \(Z = X + e^{-\alpha}\dot X\); the second is the Euler–Lagrange equation (2.7) \(\frac{d}{dt}\nabla h(X_t + e^{-\alpha_t}\dot X_t) = -e^{\alpha_t+\beta_t}\nabla f(X_t)\) for \(h = \|\cdot\|^2/2\). Then the energy \(\mathcal E_t = \tfrac12\|Z_t - x^\star\|^2 + e^{\beta_t}(f(X_t) - f(x^\star))\) is nonincreasing on \([t_0, \infty)\).

    Proof: \(\dot{\mathcal E}_t = -e^{\alpha_t+\beta_t}\bigl(f(x^\star) - f(X_t) - \langle\nabla f(X_t), x^\star - X_t\rangle\bigr) + (\dot\beta_t - e^{\alpha_t})e^{\beta_t}(f(X_t) - f(x^\star))\); the first term is \(\le 0\) by convexity, the second by the ideal scaling and minimality of \(x^\star\).

    The second ideal-scaling condition \(\dot\gamma = e^\alpha\) (2.2b) is what reduces the Euler–Lagrange equation (2.5) of the Bregman Lagrangian \(\mathcal L(X, V, t) = e^{\alpha_t+\gamma_t}(D_h(X + e^{-\alpha_t}V, X) - e^{\beta_t}f(X))\) to (2.7); the theorem is stated directly for solutions of (2.7), as in the paper. The derivation of (2.7) from the Lagrangian and the non-Euclidean case are not formalized here.

    TheoremPolynomial rate \(O(1/t^p)\) for the polynomial Bregman-Lagrangian family (Euclidean case)#✓fully proved

    MathlibExt.Analysis.Convex.AcceleratedGradientFlow.polynomialFamily_rate

    Let \(E\) be a real Hilbert space, \(f : E \to \mathbb{R}\) convex and differentiable with a global minimizer \(x^\star\), and \(p, C, t_0 > 0\). Let \(X, Z : \mathbb{R} \to E\) satisfy, for every \(t \ge t_0\),

    \[ Z_t = X_t + \tfrac{t}{p}\dot X_t, \qquad \dot Z_t = -C p\, t^{p-1}\,\nabla f(X_t) \]

    (the first written as \(\dot X_t = \frac{p}{t}(Z_t - X_t)\)). Then for every \(t \ge t_0\),

    \[ f(X_t) - f(x^\star) \le \frac{\tfrac12\|Z_{t_0} - x^\star\|^2 + C t_0^p\bigl(f(X_{t_0}) - f(x^\star)\bigr)}{C\, t^p} . \]

    This is the system (3.3a)–(3.3b) of Wibisono, Wilson and Jordan for \(h = \|\cdot\|^2/2\), equivalent to the second-order equation (3.2) \(\ddot X_t + \frac{p+1}{t}\dot X_t + C p^2 t^{p-2}\nabla f(X_t) = 0\); it is the Euler–Lagrange equation of the Bregman Lagrangian with \(\alpha_t = \log p - \log t\), \(\beta_t = p\log t + \log C\) (3.1a)–(3.1b), which satisfy the ideal scaling with equality. The case \(p = 2\) is the continuous-time limit of Nesterov's method, and \(p = 3\) that of accelerated cubic-regularized Newton.

    StructureNesterov's general optimal scheme#✓fully proved

    MathlibExt.Analysis.Convex.EstimateSequence.IsNesterovScheme

    Let \(E\) be a real Hilbert space, \(f : E \to \mathbb{R}\) differentiable, \(L > 0\) and \(\mu \ge 0\). Sequences \(\alpha_k, \gamma_k \in \mathbb{R}\) and \(x_k, y_k, v_k \in E\) follow Nesterov's general scheme if \(\gamma_0 > 0\), \(v_0 = x_0\), and for every \(k\):

    1. \(\alpha_k \in (0, 1]\) solves \(L\alpha_k^2 = (1 - \alpha_k)\gamma_k + \alpha_k \mu\), and \(\gamma_{k+1} = (1 - \alpha_k)\gamma_k + \alpha_k\mu\);
    2. \(y_k = \dfrac{\alpha_k \gamma_k v_k + \gamma_{k+1} x_k}{\gamma_k + \alpha_k \mu}\);
    3. \(f(x_{k+1}) \le f(y_k) - \dfrac{1}{2L}\|\nabla f(y_k)\|^2\);
    4. \(v_{k+1} = \dfrac{(1 - \alpha_k)\gamma_k v_k + \alpha_k \mu y_k - \alpha_k \nabla f(y_k)}{\gamma_{k+1}}\).

    The Lean structure writes steps 2 and 4 multiplied by their denominators. Step 3 holds for the gradient step \(x_{k+1} = y_k - \nabla f(y_k)/L\) when \(\nabla f\) is \(L\)-Lipschitz (Constant Step Scheme I, (2.2.7), of the source); the scheme leaves the choice of \(x_{k+1}\) free. The source asks \(\alpha_k \in (0, 1)\); the definition here also allows \(\alpha_k = 1\), which only enlarges the class of sequences covered by the theorems below.

    The point \(v_k\) is the minimiser of the estimate function \(\varphi_k(x) = \varphi_k^* + \frac{\gamma_k}{2}\|x - v_k\|^2\) of Lemma 2.2.3 of the source, built recursively from the linear (or quadratic, when \(\mu > 0\)) lower models \(f(y_k) + \langle \nabla f(y_k), x - y_k\rangle + \frac{\mu}{2}\|x - y_k\|^2\) of \(f\); the choice of \(y_k\) is what makes \(f(x_{k+1}) \le \varphi_{k+1}^*\) follow from step 3.

    MathlibExt.Analysis.Convex.EstimateSequence.accelerated_strongly_convex_rate

    Let \(E\) be a real Hilbert space, \(f : E \to \mathbb{R}\) differentiable and \(\mu\)-strongly convex with \(L\)-Lipschitz gradient, \(0 < \mu \le L\), and \(q = \sqrt{\mu / L}\). Run, from \(v_0 = x_0\),

    \[ y_k = \frac{x_k + q\, v_k}{1 + q}, \qquad x_{k+1} = y_k - \tfrac{1}{L} \nabla f(y_k), \qquad v_{k+1} = (1 - q)\, v_k + q\, y_k - \tfrac{q}{\mu} \nabla f(y_k). \]

    Then for every \(u \in E\) and every \(k\),

    \[ f(x_k) - f(u) \le \Big(1 - \sqrt{\mu / L}\Big)^k \Big(f(x_0) - f(u) + \tfrac{\mu}{2}\|x_0 - u\|^2\Big). \]

    This is Nesterov's general scheme with the gradient step (Constant Step Scheme I of the source) and \(\gamma_0 = \mu\), for which \(\gamma_k = \mu\) and \(\alpha_k = \sqrt{\mu/L}\) for every \(k\). The source obtains the bound for \(u = x^*\) from Theorem 2.2.1 and the first bound of Lemma 2.2.4; here it holds for every \(u\). Eliminating \(v_k\) gives the familiar momentum form \(y_{k+1} = x_{k+1} + \frac{1 - q}{1 + q}(x_{k+1} - x_k)\) (scheme (2.2.8) of the source); that rewriting is not formalized here.

    The number of iterations to reach accuracy \(\varepsilon\) is \(O(\sqrt{L/\mu}\,\log(1/\varepsilon))\), against \(O((L/\mu)\log(1/\varepsilon))\) for gradient descent, and the lower complexity bound for strongly convex functions shows that the factor \(\sqrt{L/\mu}\) cannot be improved by more than a constant.
