    Ellipsoid method

    The ellipsoid method (Shor; Yudin and Nemirovski) looks for a point of a convex set \(P \subseteq \mathbb{R}^n\) by keeping an ellipsoid \(E(a, A) = \{x : (x - a)^\top A^{-1} (x - a) \le 1\}\) that contains \(P\). If the centre \(a\) is not in \(P\), a separating inequality \(c^\top x \le c^\top a\) valid on \(P\) is found, and \(E(a, A)\) is replaced by the smallest ellipsoid \(E(a', A')\) (minimality is not formalised here) containing the half \(E(a, A) \cap \{c^\top x \le c^\top a\}\):

    \[ b = \frac{A c}{\sqrt{c^\top A c}}, \qquad a' = a - \frac{1}{n+1}\, b, \qquad A' = \frac{n^2}{n^2 - 1}\Bigl(A - \frac{2}{n+1}\, b b^\top\Bigr). \]

    Volumes of ellipsoids are proportional to \(\sqrt{\det A}\), and the determinant of the update gives the volume factor \(\frac{n}{n+1}\bigl(\frac{n^2}{n^2-1}\bigr)^{(n-1)/2} < e^{-1/(2(n+1))}\), so after \(k\) steps the volume has dropped by \(e^{-k/(2(n+1))}\). Khachiyan (1979) used this to show that linear programming is in P. Grötschel, Lovász and Schrijver observed that the method only needs a separation oracle: for well-described polyhedra, separation and optimisation are polynomial-time equivalent, which turns polyhedral descriptions with exponentially many inequalities (matchings, matroids, stable sets of perfect graphs through the theta function) into polynomial algorithms. The update, the containment of the half-ellipsoid, the volume formula \(\mathrm{vol}\, E(a, A) = \sqrt{\det A}\, \mathrm{vol}\, E(0, I)\), the volume lemma and the convergence statement (a centre lies in \(P\) within \(2(n+1)\ln(\mathrm{vol}\, E_0/\mathrm{vol}\, P)\) steps, for an abstract separation oracle) are proved here. The encoding-length bounds that make this polynomial for rational polyhedra, and the equivalence of separation and optimisation, are not formalised.

    DefinitionEllipsoid with centre \(a\) and matrix \(A\)#✓fully proved

    MathlibExt.Analysis.Convex.EllipsoidMethod.ellipsoid

    For \(a \in \mathbb{R}^n\) and a positive definite \(n \times n\) matrix \(A\),

    \[ E(a, A) = \{x \in \mathbb{R}^n : (x - a)^\top A^{-1} (x - a) \le 1\}. \]

    Writing \(A = B^\top B\), the affine map \(x \mapsto (B^{-1})^\top (x - a)\) sends \(E(a, A)\) onto the unit ball \(E(0, I)\). The Lean definition takes any square matrix \(A\) and uses Mathlib's inverse \(A^{-1}\) (zero when \(A\) is singular); the theorems about it assume \(A\) positive definite.

    noncomputable def ellipsoid (a : Fin n → ℝ) (A : Matrix (Fin n) (Fin n) ℝ) : Set (Fin n → ℝ) :=
  {x | (x - a) ⬝ᵥ (A⁻¹ *ᵥ (x - a)) ≤ 1}

    TheoremAn ellipsoid is the image of the unit ball#✓fully proved

    MathlibExt.Analysis.Convex.EllipsoidMethod.ellipsoid_zero_eq_image

    For a positive definite \(A\), \(E(0, A) = A^{1/2}\, E(0, I)\), where \(A^{1/2}\) is the positive definite square root of \(A\) (Mathlib's continuous functional calculus CFC.sqrt). Indeed \(A^{-1} = A^{-1/2} A^{-1/2}\) with \(A^{-1/2}\) symmetric, so \(x^\top A^{-1} x = \lVert A^{-1/2} x\rVert^2\), and \(x \in E(0, A)\) exactly when \(A^{-1/2} x\) lies in the unit ball. Goemans writes \(A = B^\top B\) for some \(B\); the square root is the symmetric choice of \(B\).

    theorem ellipsoid_zero_eq_image {A : Matrix (Fin n) (Fin n) ℝ} (hA : A.PosDef) :
    ellipsoid 0 A = (Matrix.toLin' (CFC.sqrt A)) '' ellipsoid 0 1

    DefinitionDirection of a central-cut step#✓fully proved

    MathlibExt.Analysis.Convex.EllipsoidMethod.cutDirection

    For a matrix \(A\) and a vector \(c\), the cut direction is

    \[ b = \frac{A c}{\sqrt{c^\top A c}} . \]

    When \(A\) is positive definite and \(c \ne 0\), \(c^\top A c > 0\) and \(b\) is the point of \(\partial E(0, A)\) that maximises \(c^\top x\) over \(E(0, A)\).

    noncomputable def cutDirection (A : Matrix (Fin n) (Fin n) ℝ) (c : Fin n → ℝ) : Fin n → ℝ :=
  (Real.sqrt (c ⬝ᵥ (A *ᵥ c)))⁻¹ • (A *ᵥ c)

    DefinitionMatrix after a central-cut step#✓fully proved

    MathlibExt.Analysis.Convex.EllipsoidMethod.nextMatrix

    The new matrix of the central-cut step in dimension \(n\) is

    \[ A' = \frac{n^2}{n^2 - 1}\Bigl(A - \frac{2}{n+1}\, b b^\top\Bigr), \qquad b = \frac{A c}{\sqrt{c^\top A c}} . \]

    The ellipsoid shrinks by the factor \(\frac{n}{n+1}\) along \(b\) and stretches by \(\frac{n}{\sqrt{n^2-1}}\) in the orthogonal directions.

    Matrix (Fin n) (Fin n) ℝ :=
  ((n : ℝ) ^ 2 / ((n : ℝ) ^ 2 - 1)) •
    (A - (2 / ((n : ℝ) + 1)) • vecMulVec (cutDirection A c) (cutDirection A c))

    TheoremThe cut direction has unit \(A^{-1}\)-norm#✓fully proved

    MathlibExt.Analysis.Convex.EllipsoidMethod.cutDirection_inv_norm

    If \(A\) is positive definite and \(c \ne 0\), the cut direction \(b = A c/\sqrt{c^\top A c}\) satisfies \(b^\top A^{-1} b = 1\): indeed \(A^{-1} b = c / \sqrt{c^\top A c}\), so \(b^\top A^{-1} b = (A c)^\top c / (c^\top A c) = 1\). Thus \(a \pm b\) lies on the boundary of \(E(a, A)\).

    TheoremInverse of the matrix after a central-cut step#✓fully proved

    MathlibExt.Analysis.Convex.EllipsoidMethod.nextMatrix_inv

    For \(n \ge 2\), a positive definite \(A\) and \(c \ne 0\), the matrix after the step has inverse

    \[ A'^{-1} = \frac{n^2 - 1}{n^2} \Bigl( A^{-1} + \frac{2}{n - 1} \, \frac{c c^\top}{c^\top A c} \Bigr). \]

    This is the Sherman–Morrison formula for the rank-one update \(A - \beta\, b b^\top\) with \(\beta = 2/(n+1)\) and \(b = A c / \sqrt{c^\top A c}\): since \(A^{-1} b = c/\sqrt{c^\top A c}\) and \(b^\top A^{-1} b = 1\), the correction is \(\frac{\beta}{1 - \beta} A^{-1} b b^\top A^{-1} = \frac{2}{n-1} \frac{c c^\top}{c^\top A c}\). The proof checks \(A' \cdot A'^{-1} = I\) on the basis vectors.

    theorem nextMatrix_inv {A : Matrix (Fin n) (Fin n) ℝ} (hA : A.PosDef) {c : Fin n → ℝ}
    (hc : c ≠ 0) (hn : 2 ≤ n) :
    (nextMatrix A c)⁻¹ = ((n : ℝ) ^ 2 / ((n : ℝ) ^ 2 - 1))⁻¹ •
      (A⁻¹ + ((2 / ((n : ℝ) - 1)) / (c ⬝ᵥ (A *ᵥ c))) • vecMulVec c c)
    noncomputable def nextMatrix (A : Matrix (Fin n) (Fin n) ℝ) (c : Fin n → ℝ) :
    Matrix (Fin n) (Fin n) ℝ :=
  ((n : ℝ) ^ 2 / ((n : ℝ) ^ 2 - 1)) •
    (A - (2 / ((n : ℝ) + 1)) • vecMulVec (cutDirection A c) (cutDirection A c))

    TheoremThe central-cut ellipsoid contains the half-ellipsoid#✓fully proved

    MathlibExt.Analysis.Convex.EllipsoidMethod.halfEllipsoid_subset_nextEllipsoid

    For \(n \ge 2\), a positive definite \(A\), a centre \(a\) and \(c \ne 0\),

    \[ E(a, A) \cap \{x : c^\top x \le c^\top a\} \subseteq E(a', A'), \]

    where \(a'\) and \(A'\) are the centre and matrix after the central-cut step. Goemans verifies it for the unit ball and the cut \(x_1 \ge 0\), and reduces the general case by an affine change of variables. The proof here works directly with the inverse of \(A'\): for \(x\) in the half-ellipsoid put \(y = x - a\), \(q = y^\top A^{-1} y \le 1\) and \(t = c^\top y / \sqrt{c^\top A c}\), so that \(t \le 0\) and, by the Cauchy–Schwarz inequality for \(A^{-1}\), \(t^2 \le q\). Then

    \[ (x - a')^\top A'^{-1} (x - a') = \frac{n^2 - 1}{n^2} \Bigl( q + \frac{2}{n-1}\, t (t + 1) + \frac{1}{n^2 - 1} \Bigr) \le \frac{n^2 - 1}{n^2} \Bigl( 1 + \frac{1}{n^2 - 1} \Bigr) = 1 , \]

    because \(-1 \le t \le 0\).

    theorem halfEllipsoid_subset_nextEllipsoid (hn : 2 ≤ n) {A : Matrix (Fin n) (Fin n) ℝ}
    (hA : A.PosDef) (a : Fin n → ℝ) {c : Fin n → ℝ} (hc : c ≠ 0) :
    ellipsoid a A ∩ {x | c ⬝ᵥ x ≤ c ⬝ᵥ a} ⊆ ellipsoid (nextCenter a A c) (nextMatrix A c)

    MathlibExt.Analysis.Convex.EllipsoidMethod.det_nextMatrix

    If \(A\) is positive definite and \(c \ne 0\), then the matrix after the step satisfies

    \[ \det A' = \Bigl(\frac{n^2}{n^2-1}\Bigr)^{n} \, \frac{n-1}{n+1} \, \det A . \]

    Related topics

    • Linear programming feasibility: Khachiyan's theorem that rational linear programming is in P, proved with the ellipsoid method.
    • Linear programming: the problems the method solves in polynomial time.
