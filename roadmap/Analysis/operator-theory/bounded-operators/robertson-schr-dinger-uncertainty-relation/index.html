    DefinitionNormalized variance of an observable#✓fully proved

    MathlibExt.Analysis.InnerProductSpace.RobertsonUncertainty.variance

    Normalized variance is the centered squared norm divided by the squared state norm. For a nonzero state and self-adjoint observable it is the physical variance. The totalized value at zero is zero. Off the unit sphere this corrects the raw quadratic quantities; agreement with the original formulas is asserted only for unit states.

    noncomputable def variance (A : E →L[ℂ] E) (x : E) : ℝ :=
  ‖centered A x‖ ^ 2 / ‖x‖ ^ 2
    noncomputable def centered (A : E →L[ℂ] E) (x : E) : E :=
  A x - (meanValue A x : ℂ) • x

    TheoremRobertson–Schrödinger uncertainty principle#✓fully proved

    MathlibExt.Analysis.InnerProductSpace.RobertsonUncertainty.schrodinger

    The Robertson–Schrödinger uncertainty principle: the product of the variances is at least the squared covariance plus a quarter of the squared norm of the commutator expectation.

    theorem schrodinger {A B : E →L[ℂ] E} (hA : IsSelfAdjoint A) (hB : IsSelfAdjoint B)
    {x : E} (hx : ‖x‖ = 1) :
    (⟪centered A x, centered B x⟫_ℂ).re ^ 2
        + (1 / 4) * ‖⟪(A ∘L B - B ∘L A) x, x⟫_ℂ‖ ^ 2
      ≤ variance A x * variance B x
    noncomputable def centered (A : E →L[ℂ] E) (x : E) : E :=
  A x - (meanValue A x : ℂ) • x
