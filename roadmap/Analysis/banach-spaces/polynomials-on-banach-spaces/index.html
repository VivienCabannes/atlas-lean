    Polynomials on Banach spaces

    DefinitionContinuous polynomial functions on a complex normed space#✓fully proved

    MathlibExt.Analysis.FunctionalAnalysis.ScottishBook27Wanted.IsPolynomialOn

    Let \(E\) be a complex normed space. A function \(F : E \to \mathbb{C}\) is a continuous polynomial function if there are a natural number \(n\), natural numbers \(m_1, \dots, m_n\) and continuous \(\mathbb{C}\)-multilinear maps \(A_i : E^{m_i} \to \mathbb{C}\), with \(A_i\) taking \(m_i\) arguments, such that \(F(x) = \sum_{i=1}^{n} A_i(x, \dots, x)\) for every \(x \in E\).

    A \(0\)-multilinear map is a constant, so constant functions are polynomial functions.

    def IsPolynomialOn (E : Type) [NormedAddCommGroup E] [NormedSpace ℂ E]
    (F : E → ℂ) : Prop :=
  ∃ (n : ℕ) (m : Fin n → ℕ)
    (A : (i : Fin n) → (E [× m i]→L[ℂ] ℂ)),
    ∀ x, F x = ∑ i, A i fun _ => x

    TheoremBezout identity for polynomials without a common zero#●ready to prove

    MathlibExt.Analysis.FunctionalAnalysis.ScottishBook27Wanted.bezout_identity_for_polynomials_without_common_zero

    Let \(E\) be a complex Banach space and let \(F, G : E \to \mathbb{C}\) be continuous polynomial functions with no common zero, that is, \(G(x) \neq 0\) whenever \(F(x) = 0\). Then there are continuous polynomial functions \(\varphi, \psi : E \to \mathbb{C}\) such that \(F(x) \varphi(x) + G(x) \psi(x) = 1\) for every \(x \in E\).

    This is the identity recorded in the addendum to Problem 27 of the Scottish Book (Mazur-Orlicz, 4 April 1939). The problem asks whether two complex polynomials on a complex Banach space that both tend to \(0\) along a sequence \((x_n)\) in the unit ball must have a common zero. The answer is positive and follows from the identity by contradiction: continuous polynomials are bounded on the unit ball, so \(F(x_n) \varphi(x_n) + G(x_n) \psi(x_n)\) would tend to \(0\), yet it equals \(1\).

    theorem_wanted bezout_identity_for_polynomials_without_common_zero :
    ∀ (E : Type) [NormedAddCommGroup E] [NormedSpace ℂ E] [CompleteSpace E]
      (F G : E → ℂ),
      IsPolynomialOn E F → IsPolynomialOn E G →
      (∀ x, F x = 0 → G x ≠ 0) →
      ∃ (φ ψ : E → ℂ), IsPolynomialOn E φ ∧ IsPolynomialOn E ψ ∧
        ∀ x, F x * φ x + G x * ψ x = 1

    DefinitionMazur's factorisation claim (Scottish Book Problem 55)#✓fully proved

    MathlibExt.Analysis.FunctionalAnalysis.ScottishBook55Wanted.ScottishBookProblem55Claim

    The claim that for every real Banach space \(E\), every unbounded set \(R \subseteq E\) and every continuous bilinear form \(B : E \times E \to \mathbb{R}\), if the quadratic form \(W(x) = B(x, x)\) is bounded on the set of points at distance less than \(\varepsilon\) from \(R\) for some \(\varepsilon > 0\), then there are a continuous linear functional \(L : E \to \mathbb{R}\), a constant \(c \in \mathbb{R}\) and a real polynomial \(V\) such that \(W(x) = V(L(x) + c)\) for all \(x \in E\) and \(|L(r) + c|\) is bounded for \(r \in R\).

    This is Mazur's question in the general Banach-space form for scalar-valued 2-polynomials: \(W\) factors as \(V \circ \varphi\) through the first-degree polynomial \(\varphi(x) = L(x) + c\), which maps \(R\) to a bounded set.

    def ScottishBookProblem55Claim : Prop :=
  ∀ (E : Type) [NormedAddCommGroup E] [NormedSpace ℝ E] [CompleteSpace E]
    (R : Set E) (B : E →L[ℝ] E →L[ℝ] ℝ),
    (∀ M : ℝ, ∃ r ∈ R, M < ‖r‖) →
    (∃ ε : ℝ, 0 < ε ∧ ∃ C : ℝ,
      ∀ x : E, (∃ r ∈ R, dist x r < ε) → |B x x| ≤ C) →
    ∃ (L : E →L[ℝ] ℝ) (c : ℝ) (V : Polynomial ℝ),
      (∀ x : E, B x x = V.eval (L x + c)) ∧
      ∃ M : ℝ, ∀ r ∈ R, |L r + c| ≤ M

    MathlibExt.Analysis.FunctionalAnalysis.ScottishBook75Wanted.ScottishBookProblem75Claim

    The claim that for every real Banach space \(E\), every set \(R \subseteq E\), every continuous bilinear form \(B\) on \(E\) and every real \(\alpha \ne 0\) the following holds: if for some \(\varepsilon > 0\) the values \(|B(x, x)|\) are bounded on the open \(\varepsilon\)-neighbourhood of \(R\), that is, for the \(x \in E\) with \(\operatorname{dist}(x, r) < \varepsilon\) for some \(r \in R\), then for some \(\delta > 0\) the values \(|B(x, x)|\) are bounded on the open \(\delta\)-neighbourhood of the scaled set \(\alpha R = \{\alpha r : r \in R\}\).

    def ScottishBookProblem75Claim : Prop :=

    (R : Set E) (B : E →L[ℝ] E →L[ℝ] ℝ) (α : ℝ), α ≠ 0 →
    (∃ ε : ℝ, 0 < ε ∧ ∃ C : ℝ,
      ∀ x : E, (∃ r ∈ R, dist x r < ε) → |B x x| ≤ C) →
    ∃ δ : ℝ, 0 < δ ∧ ∃ C : ℝ,
      ∀ x : E, (∃ r ∈ R, dist x (α • r) < δ) → |B x x| ≤ C
