    MathlibExt.Analysis.RademacherEnfloTypeWanted.RademacherEnfloType.D

    Let \(X\) be a real Banach space, \(n\) a natural number and \(f : \{-1, 1\}^n \to X\). For \(j \in \{1, \dots, n\}\) and \(\varepsilon = (\varepsilon_1, \dots, \varepsilon_n) \in \{-1, 1\}^n\), the discrete partial derivative of \(f\) in direction \(j\) at \(\varepsilon\) is

    \[ D_j f(\varepsilon) = \frac{1}{2}\bigl(f(\varepsilon) - f(\varepsilon_1, \dots, -\varepsilon_j, \dots, \varepsilon_n)\bigr), \]

    where only the \(j\)-th coordinate of \(\varepsilon\) is negated in the second term.

    noncomputable def D {n : ℕ} (j : Fin n) (f : (Fin n → ({-1, 1} : Set ℤ)) → X)
      (ε : Fin n → ({-1, 1} : Set ℤ)) : X :=
  (1 / (2 : ℝ)) • (f ε - f (update ε j (- ε j)))

    DefinitionRademacher type#✓fully proved

    MathlibExt.Analysis.RademacherEnfloTypeWanted.RademacherEnfloType.IsRademacherType

    Let \(X\) be a real Banach space, \(C \in [0, \infty]\) and \(p\) a real number. We say that \(X\) has Rademacher type \(p\) with constant \(C\) if for every \(n \ge 1\) and all \(x_1, \dots, x_n \in X\),

    \[ \mathbb{E}\Bigl\|\sum_{j=1}^n \varepsilon_j x_j\Bigr\|^p \le C^p \sum_{j=1}^n \|x_j\|^p, \]

    where \(\varepsilon_1, \dots, \varepsilon_n\) are independent Rademacher random variables. Both sides are computed in \([0, \infty]\).

    def IsRademacherType (C : ℝ≥0∞) (p : ℝ) : Prop :=
  ∀ n ≥ 1, ∀ (x : Fin n → X),
    𝔼⁻[‖ ∑ j : Fin n, ((ε j) : ℝ) • (x j) ‖ₑ ^ p; ε ∼ rademacherProductDistribution (Fin n)]
    ≤ C ^ p * ∑ j : Fin n, ‖ x j ‖ₑ ^ p
    noncomputable def rademacherProductDistribution (ι : Type*) :
    Measure (ι → ({-1, 1} : Set ℤ)) :=
  infinitePi (fun _ : ι ↦ rademacherDistribution)

    DefinitionEnflo type#✓fully proved

    MathlibExt.Analysis.RademacherEnfloTypeWanted.RademacherEnfloType.IsEnfloType

    Let \(X\) be a real Banach space, \(C \in [0, \infty]\) and \(p\) a real number. We say that \(X\) has Enflo type \(p\) with constant \(C\) if for every \(n \ge 1\) and every function \(f : \{-1, 1\}^n \to X\),

    \[ \mathbb{E}\Bigl\|\frac{f(\varepsilon) - f(-\varepsilon)}{2}\Bigr\|^p \le C^p \sum_{j=1}^n \mathbb{E}\,\|D_j f(\varepsilon)\|^p, \]

    where \(\varepsilon = (\varepsilon_1, \dots, \varepsilon_n)\) is a sequence of independent Rademacher random variables, \(-\varepsilon = (-\varepsilon_1, \dots, -\varepsilon_n)\), and \(D_j f\) is the discrete partial derivative of \(f\) in direction \(j\). Both sides are computed in \([0, \infty]\).

    def IsEnfloType (C : ℝ≥0∞) (p : ℝ) : Prop :=
    ∀ n ≥ 1, ∀ (f : (Fin n → ({-1, 1} : Set ℤ)) → X),
  𝔼⁻[‖ (1 / (2 : ℝ)) • (f ε - f (- ε)) ‖ₑ ^ p; ε ∼ rademacherProductDistribution (Fin n)]
  ≤ C ^ p * ∑ j : Fin n, 𝔼⁻[‖ D j f ε ‖ₑ ^ p; ε ∼ rademacherProductDistribution (Fin n)]
    noncomputable def rademacherProductDistribution (ι : Type*) :
    Measure (ι → ({-1, 1} : Set ℤ)) :=
