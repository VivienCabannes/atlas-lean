    MathlibExt.Analysis.FunctionalAnalysis.ApproximationProperty.HasApproximationProperty

    A normed space has the approximation property if, on every compact set, the identity operator is a uniform limit of finite-rank continuous linear operators.

    def HasApproximationProperty (𝕜 E : Type*) [RCLike 𝕜] [NormedAddCommGroup E]
    [NormedSpace 𝕜 E] : Prop :=
  ∀ (K : Set E), IsCompact K → ∀ ε : ℝ, 0 < ε →
    ∃ T : E →L[𝕜] E, FiniteDimensional 𝕜 ↥(LinearMap.range T.toLinearMap) ∧
      ∀ x ∈ K, ‖T x - x‖ < ε

    MathlibExt.Analysis.FunctionalAnalysis.ApproximationProperty.hasApproximationProperty_of_schauderBasis

    A Banach space with a Schauder basis has the approximation property. The partial-sum projections are finite-rank, converge pointwise to the identity, and are uniformly bounded by the Banach–Steinhaus theorem (SchauderBasis.exists_norm_proj_le); pointwise convergence plus uniform boundedness gives uniform convergence on compact sets via a finite ε-net argument.

    TheoremApproximation property passes to complemented subspaces#✓fully proved

    MathlibExt.Analysis.FunctionalAnalysis.ApproximationProperty.HasApproximationProperty.of_complemented

    The approximation property passes to complemented subspaces: if P is a continuous projection onto the submodule F, restrict a finite-rank approximant on the ambient space via P. The key point is that P fixes every point of F, so P (S x) - x = P (S x - x) for x ∈ F.

    theorem HasApproximationProperty.of_complemented {E : Type*} [NormedAddCommGroup E]

    MathlibExt.Analysis.FunctionalAnalysis.ScottishBook153Wanted.ScottishBookProblem153Claim

    The claim of Mazur's Problem 153 from the Scottish Book, in its original form: for every continuous function \(f \colon [0,1]^2 \to \mathbb{R}\) and every real \(\varepsilon > 0\) there are a natural number \(n\), points \(a_1, \dots, a_n, b_1, \dots, b_n \in [0,1]\) and real numbers \(c_1, \dots, c_n\) such that

    \[\Bigl| f(x, y) - \sum_{k=1}^n c_k \, f(a_k, y) \, f(x, b_k) \Bigr| \le \varepsilon\]

    for all \(x, y \in [0,1]\).

    def ScottishBookProblem153Claim : Prop :=
  ∀ (f : C(↥(Set.Icc (0 : ℝ) 1) × ↥(Set.Icc (0 : ℝ) 1), ℝ)) (ε : ℝ), 0 < ε →
    ∃ (n : ℕ) (a b : Fin n → ↥(Set.Icc (0 : ℝ) 1)) (c : Fin n → ℝ),
      ∀ (x y : ↥(Set.Icc (0 : ℝ) 1)),
        -- `dist` here is `|f (x, y) - ∑ k, c k * f (a k, y) * f (x, b k)|` by `Real.dist_eq`.
        dist (f (x, y)) (∑ k, c k * f (a k, y) * f (x, b k)) ≤ ε

    MathlibExt.Analysis.FunctionalAnalysis.ScottishBook153Wanted.mazur153_refuted

    There are a continuous function \(f \colon [0,1]^2 \to \mathbb{R}\) and a real number \(\varepsilon > 0\) such that for every natural number \(n\), all points \(a_1, \dots, a_n, b_1, \dots, b_n \in [0,1]\) and all real numbers \(c_1, \dots, c_n\) there are \(x, y \in [0,1]\) with

    \[\Bigl| f(x, y) - \sum_{k=1}^n c_k \, f(a_k, y) \, f(x, b_k) \Bigr| > \varepsilon.\]

    That is, the approximation scheme of Mazur's Problem 153 fails.
