    StructureTagged-refinement data#✓fully proved

    MathlibExt.Analysis.Integration.TaggedPartition.IsTaggedRefinement

    Let \(T\) and \(T'\) be tagged partitions of \([a, b]\) with points \(a = x_0 < \dots < x_n = b\) and \(a = x'_0 < \dots < x'_{n'} = b\) respectively.
