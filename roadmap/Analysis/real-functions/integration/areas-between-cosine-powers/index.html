    Areas between cosine powers

    DefinitionArea between powers of cosines#✓fully proved

    MetaMathlibExt.cosPowArea

    For natural numbers \(n\) and \(k\), the area between the curves \(y = \cos^n x\) and \(y = \cos^n(kx)\) on \([0, \pi]\) is \(A_n(k) = \int_0^\pi |\cos^n x - \cos^n(kx)|\,dx\), where \(\cos^n x\) means \((\cos x)^n\).

    The paper's \(A_n\) is the limit of \(A_n(k)\) as \(k \to \infty\) (Eq. (1)), with \(k\) running over the natural numbers.

    public noncomputable def cosPowArea (n k : ℕ) : ℝ :=
  ∫ x in (0 : ℝ)..π, |cos x ^ n - cos (k * x) ^ n|

    TheoremLimiting area between even cosine powers#●ready to prove

    MetaMathlibExt.tendsto_cosPowArea_of_even

    For natural numbers \(n\) and \(k\), let \(A_n(k) = \int_0^\pi |\cos^n x - \cos^n(kx)|\,dx\). As \(k \to \infty\) through the natural numbers: if \(n \equiv 2 \pmod 4\), then

    \[A_n(k) \to \frac{16}{2^n \pi} \sum_{j=0}^{(n-2)/4} \frac{\binom{n}{2j}}{(n/2 - 2j)^2},\]

    and if \(n \equiv 0 \pmod 4\), then

    \[A_n(k) \to \frac{16}{2^n \pi} \sum_{j=0}^{(n-4)/4} \frac{\binom{n}{2j+1}}{(n/2 - 2j - 1)^2}.\]

    For \(n = 0\) the right-hand side is \(0\), as is \(A_0(k)\) for every \(k\), so no positivity hypothesis is needed.

    public theorem_wanted tendsto_cosPowArea_of_even (n : ℕ) :
    (n % 4 = 2 → Tendsto (fun k => cosPowArea n k) atTop
      (𝓝 (16 / (2 ^ n * π) * ∑ j ∈ Finset.range ((n - 2) / 4 + 1),
        (n.choose (2 * j) : ℝ) / ((n : ℝ) / 2 - 2 * j) ^ 2))) ∧
    (n % 4 = 0 → Tendsto (fun k => cosPowArea n k) atTop
      (𝓝 (16 / (2 ^ n * π) * ∑ j ∈ Finset.range ((n - 4) / 4 + 1),

    TheoremRecursion for the limiting areas between cosine powers#●ready to prove

    MetaMathlibExt.cosPowArea_limit_recursion

    For natural numbers \(n\) and \(k\), let \(A_n(k) = \int_0^\pi |\cos^n x - \cos^n(kx)|\,dx\). For every natural number \(n \ge 3\) there are real numbers \(L\) and \(L'\) such that \(A_n(k) \to L\) and \(A_{n-2}(k) \to L'\) as \(k \to \infty\) through the natural numbers, and \(L = \frac{n-1}{n} L' + \frac{c}{n^2 \pi}\), where \(c = 8\) if \(n\) is odd and \(c = 16\) if \(n\) is even.

    public theorem_wanted cosPowArea_limit_recursion {n : ℕ} (hn : 3 ≤ n) :
    ∃ L L' : ℝ, Tendsto (fun k => cosPowArea n k) atTop (𝓝 L) ∧
      Tendsto (fun k => cosPowArea (n - 2) k) atTop (𝓝 L') ∧
      L = ((n : ℝ) - 1) / n * L' + (if Odd n then 8 else 16) / ((n : ℝ) ^ 2 * π)
    public noncomputable def cosPowArea (n k : ℕ) : ℝ :=
  ∫ x in (0 : ℝ)..π, |cos x ^ n - cos (k * x) ^ n|

    MetaMathlibExt.tendsto_cosPowArea_doubleFactorial

    For natural numbers \(n\) and \(k\), let \(A_n(k) = \int_0^\pi |\cos^n x - \cos^n(kx)|\,dx\). As \(k \to \infty\) through the natural numbers: if \(n\) is odd, then

    \[A_n(k) \to \frac{8 \, n!}{\pi (n!!)^2} \sum_{j=0}^{(n-1)/2} \frac{(2j-1)!!}{(2j)!! (2j+1)},\]

    and if \(n \ge 2\) is even, then

    \[A_n(k) \to \frac{16 \, n!}{\pi (n!!)^2} \sum_{j=0}^{(n-2)/2} \frac{(2j)!!}{(2j+1)!! (2j+2)}.\]

    Here \((-1)!! = 1\) and \(0!! = 1\).

    public theorem_wanted tendsto_cosPowArea_doubleFactorial (n : ℕ) :
    (Odd n → Tendsto (fun k => cosPowArea n k) atTop

            ((2 * j).doubleFactorial * (2 * j + 1))))) ∧

    TheoremDouble-factorial sums as derivatives of arcsine quotients#●ready to prove

    MetaMathlibExt.iteratedDeriv_arcsin_div_one_sub_doubleFactorial

    Let \(n\) be a natural number. If \(n\) is odd, the \(n\)th derivative at \(0\) of \(x \mapsto \arcsin x / (1 - x)\) is

    \[n! \sum_{j=0}^{(n-1)/2} \frac{(2j-1)!!}{(2j)!!\,(2j+1)},\]

    and if \(n \ge 2\) is even, the \(n\)th derivative at \(0\) of \(x \mapsto (\arcsin x)^2 / (2(1 - x))\) is

    \[n! \sum_{j=0}^{(n-2)/2} \frac{(2j)!!}{(2j+1)!!\,(2j+2)},\]

    where \((-1)!! = 1\) and \(0!! = 1\).

    These are the \(n\)th terms of the exponential generating functions of \(\arcsin x / (1 - x)\) (OEIS A296726) and of \((\arcsin x)^2 / (2(1 - x))\) (OEIS A372324).

    public theorem_wanted iteratedDeriv_arcsin_div_one_sub_doubleFactorial (n : ℕ) :
    (Odd n → iteratedDeriv n (fun x => arcsin x / (1 - x)) 0 =
      n.factorial * ∑ j ∈ Finset.range ((n - 1) / 2 + 1),
        ((2 * j - 1).doubleFactorial : ℝ) / ((2 * j).doubleFactorial * (2 * j + 1))) ∧
    (Even n → 0 < n → iteratedDeriv n (fun x => arcsin x ^ 2 / (2 * (1 - x))) 0 =
      n.factorial * ∑ j ∈ Finset.range ((n - 2) / 2 + 1),
        ((2 * j).doubleFactorial : ℝ) / ((2 * j + 1).doubleFactorial * (2 * j + 2)))
