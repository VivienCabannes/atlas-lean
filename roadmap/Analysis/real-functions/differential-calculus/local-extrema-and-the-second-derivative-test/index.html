    Local extrema and the second-derivative test

    DefinitionStrict local minimum#✓fully proved

    IsStrictLocalMin

    Let \(f \colon X \to Y\) be a function from a topological space \(X\) to a set \(Y\) equipped with a relation \(<\). Then \(f\) has a strict local minimum at a point \(a \in X\) if \(f(a) < f(x)\) for all \(x \ne a\) in some neighborhood of \(a\).

    This strengthens the usual (non-strict) notion of local minimum: the inequality is strict and the point \(a\) itself is excluded.

    def IsStrictLocalMin {α : Type*} {β : Type*} [TopologicalSpace α] [LT β]
    (f : α → β) (a : α) : Prop :=
  ∀ᶠ x in 𝓝[≠] a, f a < f x

    TheoremA strict local minimum is a local minimum#✓fully proved

    IsStrictLocalMin.isLocalMin

    Let \(f \colon X \to Y\) be a function from a topological space \(X\) to a preordered set \(Y\). If \(f\) has a strict local minimum at \(a \in X\), then \(f\) has a local minimum at \(a\), that is, \(f(a) \le f(x)\) for all \(x\) in some neighborhood of \(a\).

    IsStrictLocalMin.neg

    Let \(X\) be a topological space and let \(Y\) be an additive group with a relation \(<\) such that addition on the left and addition on the right are strictly monotone. If \(f \colon X \to Y\) has a strict local minimum at \(a \in X\), then \(x \mapsto -f(x)\) has a strict local maximum at \(a\).
