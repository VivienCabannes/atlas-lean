    MetaMathlibExt.takagiEll

    Let \(n\) be a natural number and \(k\) an integer, and write \(n_j\) for the binary digit of \(n\) at position \(j\) (so \(n_j = 0\) for \(j < 0\)). The Takagi coefficients \(\ell_i(n, k)\), for natural numbers \(i\), are the natural numbers given by \(\ell_0(n, k) = 0\) and, for every natural number \(i\), with \(s_i = \sum_{j=0}^{i-1} n_{k-j}\), by \(\ell_{i+1}(n, k) = s_i\) if \(n_{k-i} = 0\) and \(\ell_{i+1}(n, k) = i - s_i\) otherwise.

    In particular \(\ell_1(n, k) = 0\).

    public def takagiEll (n : Nat) (k : Int) : Nat → Nat
  | 0 => 0
  | (i + 1) =>
    if takagiBit n (k - (i : Int)) = 0 then
      ∑ j ∈ Finset.range i, takagiBit n (k - (j : Int))
    else i - ∑ j ∈ Finset.range i, takagiBit n (k - (j : Int))
