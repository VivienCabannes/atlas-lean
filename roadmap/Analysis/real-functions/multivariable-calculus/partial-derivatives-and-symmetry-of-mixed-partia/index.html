    For \(f : \mathbb{R}^n \to \mathbb{R}\) and a coordinate index \(i\), let \(e_i\) be the \(i\)-th standard basis vector. The partial derivative \(\partial_i f : \mathbb{R}^n \to \mathbb{R}\) sends \(x\) to the derivative at \(t = 0\) of \(t \mapsto f(x + t e_i)\), taken to be \(0\) when this function is not differentiable at \(0\).

    TheoremPartial derivative as a Fréchet derivative#✓fully proved

    MetaMathlibExt.partialDeriv_eq_fderiv_apply

    Let \(f : \mathbb{R}^n \to \mathbb{R}\) be differentiable at a point \(x\), and let \(e_i\) be the \(i\)-th standard basis vector of \(\mathbb{R}^n\). Then the partial derivative of \(f\) along the \(i\)-th coordinate axis at \(x\) equals \(Df(x)\,e_i\), the Fréchet derivative of \(f\) at \(x\) applied to \(e_i\).

    The proof differentiates \(f\) along the line \(t \mapsto x + t e_i\) by the chain rule.

    theorem partialDeriv_eq_fderiv_apply {n : ℕ} (f : (Fin n → ℝ) → ℝ)
    (i : Fin n) (x : Fin n → ℝ) (hf : DifferentiableAt ℝ f x) :
    partialDeriv f i x = fderiv ℝ f x (Pi.single i (1 : ℝ))
    noncomputable def partialDeriv {n : ℕ} (f : (Fin n → ℝ) → ℝ) (i : Fin n) :
    (Fin n → ℝ) → ℝ :=
  fun x => deriv (fun t : ℝ => f (x + t • Pi.single i (1 : ℝ))) 0

    TheoremMixed partial derivatives via the second Fréchet derivative#✓fully proved

    MetaMathlibExt.partialDeriv_partialDeriv_eq_fderiv_fderiv

    Let \(f : \mathbb{R}^n \to \mathbb{R}\) be twice continuously differentiable, write \(e_k\) for the \(k\)-th standard basis vector of \(\mathbb{R}^n\) and \(\partial_k g\) for the partial derivative of a function \(g\) along the \(k\)-th coordinate axis, and let \(Df\) be the Fréchet derivative of \(f\), a map from \(\mathbb{R}^n\) to the linear maps \(\mathbb{R}^n \to \mathbb{R}\). Then for all coordinate indices \(i, j\) and every \(x \in \mathbb{R}^n\), \(\partial_j (\partial_i f)(x) = \big(D(Df)(x)\,e_j\big)\,e_i\), where \(D(Df)(x)\) is the Fréchet derivative of \(Df\) at \(x\).

    theorem partialDeriv_partialDeriv_eq_fderiv_fderiv {n : ℕ}
    (f : (Fin n → ℝ) → ℝ) (i j : Fin n) (x : Fin n → ℝ) (hf : ContDiff ℝ 2 f) :
    partialDeriv (partialDeriv f i) j x =
      fderiv ℝ (fderiv ℝ f) x (Pi.single j (1 : ℝ)) (Pi.single i (1 : ℝ))

    (Fin n → ℝ) → ℝ :=

    TheoremSymmetry of mixed partial derivatives (Clairaut's theorem)#✓fully proved

    MetaMathlibExt.iterated_partialDeriv_commute

    For a function \(g : \mathbb{R}^n \to \mathbb{R}\), write \(\partial_i g\) for its partial derivative along the \(i\)-th coordinate axis. If \(f : \mathbb{R}^n \to \mathbb{R}\) is twice continuously differentiable, then for all coordinate indices \(i, j\) and every point \(x \in \mathbb{R}^n\), \(\partial_j (\partial_i f)(x) = \partial_i (\partial_j f)(x)\).

    The proof writes both mixed partials as values of the second Fréchet derivative of \(f\) at \(x\) and applies Schwarz's theorem on the symmetry of second derivatives.

    theorem iterated_partialDeriv_commute {n : ℕ} (f : (Fin n → ℝ) → ℝ)
    (i j : Fin n) (x : Fin n → ℝ) (hf : ContDiff ℝ 2 f) :
    partialDeriv (partialDeriv f i) j x =
      partialDeriv (partialDeriv f j) i x
    noncomputable def partialDeriv {n : ℕ} (f : (Fin n → ℝ) → ℝ) (i : Fin n) :
    (Fin n → ℝ) → ℝ :=
  fun x => deriv (fun t : ℝ => f (x + t • Pi.single i (1 : ℝ))) 0
