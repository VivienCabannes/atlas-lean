    TheoremIterated logarithms of power towers increase to a limit#●ready to prove

    MetaMathlibExt.iterate_logb_tetration_strictMono_and_converges

    Let \(a, b\) be real numbers with \(e^{1/e} < a < b\). For \(n \ge 0\) let \(b \uparrow\uparrow n\) be the \(n\)-fold iterate of \(x \mapsto b^x\) starting at \(1\) (so \(b \uparrow\uparrow 0 = 1\) and \(b \uparrow\uparrow 1 = b\)), and let \(a_n = \log_a^{(n)}(b \uparrow\uparrow n)\) be its \(n\)-fold iterated base-\(a\) logarithm, so that \(a_0 = 1\). Then the sequence \((a_n)_{n \ge 0}\) is strictly increasing and converges to a real number.

    The paper's "increasing" is read as strictly increasing, and its finite limit as convergence to a real number.

    public theorem_wanted iterate_logb_tetration_strictMono_and_converges {a b : ℝ}
    (ha : Real.exp (1 / Real.exp 1) < a) (hab : a < b) :
    StrictMono (fun n : ℕ => (Real.logb a)^[n] ((fun x : ℝ => b ^ x)^[n] 1)) ∧
      ∃ L : ℝ, Tendsto (fun n : ℕ => (Real.logb a)^[n] ((fun x : ℝ => b ^ x)^[n] 1))
        atTop (𝓝 L)

    TheoremNormalization of power towers#●ready to prove

    MetaMathlibExt.exists_tetration_eq_iterate_rpow_eventually

    Let \(a, b > e^{1/e}\) be real numbers with \(a \ne b\). For a real number \(c\) and \(m \ge 0\) let \(E_m(b, c)\) be the \(m\)-fold iterate of \(x \mapsto b^x\) starting at \(c\) (the tower \(b^{b^{\cdots^{c}}}\) with \(m\) copies of \(b\)), and let \(a \uparrow\uparrow n\) be the \(n\)-fold iterate of \(x \mapsto a^x\) starting at \(1\). Then there are a natural number \(N\), an integer \(k\) and a convergent sequence \((c_n)\) of real numbers such that for every \(n \ge N\) we have \(n + k \ge 0\), \(1 < c_n < b\) and \(a \uparrow\uparrow n = E_{n+k}(b, c_n)\).

    The paper leaves the condition \(n + k \ge 0\) implicit.

    public theorem_wanted exists_tetration_eq_iterate_rpow_eventually {a b : ℝ}
    (ha : Real.exp (1 / Real.exp 1) < a) (hb : Real.exp (1 / Real.exp 1) < b) (hab : a ≠ b) :
    ∃ N : ℕ, ∃ k : ℤ, ∃ c : ℕ → ℝ, (∃ L : ℝ, Tendsto c atTop (𝓝 L)) ∧
      ∀ n ≥ N, 0 ≤ (n : ℤ) + k ∧ 1 < c n ∧ c n < b ∧
        (fun x : ℝ => a ^ x)^[n] 1 = (fun x : ℝ => b ^ x)^[((n : ℤ) + k).toNat] (c n)
