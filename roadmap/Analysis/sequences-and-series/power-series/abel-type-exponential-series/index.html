    MathlibExt.NumberTheory.Ramanujan.Part1Ch3.Entry12SummableSuccN.ramanujan_part1_ch3_entry12_summable_succ_n_general

    Let \(r\) be an integer and let \(n\) and \(a\) be complex numbers with \(|a| > e\), or with \(a = e\) and \(r \le -2\). Then

    \[\sum_{k=0}^{\infty} \left| \frac{(n+k)^{r+1+k}}{a^k\, k!} \right| < \infty,\]

    where integer powers of complex numbers follow the convention \(0^m = 0\) for \(m < 0\).

    Unlike the version that assumes \(n + k \ne 0\) whenever \(k \ge 0\) and \(r + k < 0\), nothing is assumed about \(n\). At an index where \(n + k = 0\) and the exponent \(r + 1 + k\) is negative, the term is \(0^{r+1+k} = 0\), whereas the source's term is undefined there. Summability depends only on the tail, where every exponent is nonnegative.

    theorem ramanujan_part1_ch3_entry12_summable_succ_n_general (r : ℤ) (n a : ℂ)
    (ha : norm a > Real.exp 1 ∨ (a = ↑(Real.exp 1) ∧ r ≤ -2)) :
    Summable (fun k : ℕ => norm ((n + (k : ℂ)) ^ (r + 1 + (k : ℤ)) / ((a ^ k) * (k.factorial : ℂ))))

    MathlibExt.NumberTheory.Ramanujan.Part1Ch3.Entry12.ramanujan_part1_ch3_entry12

    Fix a complex number \(a\). For an integer \(r\) and a complex number \(n\), let

    \[F_r(n) = \sum_{k=0}^{\infty} \frac{(n+k)^{r+k}}{a^k\, k!},\]

    where the sum is taken to be \(0\) if the series is not summable. Suppose that \(|a| > e\), or that \(a = e\) and \(r \le -2\), and that \(n + k \ne 0\) for every natural number \(k\) with \(r + k < 0\). Then

    \[F_{r+1}(n) = n F_r(n) + \frac{1}{a} F_{r+1}(n+1).\]
    theorem ramanujan_part1_ch3_entry12 (r : ℤ) (n a : ℂ)
    (ha : ‖a‖ > Real.exp 1 ∨ (a = (Real.exp 1 : ℂ) ∧ r ≤ -2))
    (hn : ∀ k : ℕ, r + (k : ℤ) < 0 → n + (k : ℂ) ≠ 0) :
    F (r + 1) n a = n * F r n a + (1 / a) * F (r + 1) (n + 1) a
    noncomputable def F (r : ℤ) (n a : ℂ) : ℂ :=
  ∑' k : ℕ, (n + (k : ℂ)) ^ (r + (k : ℤ)) / (a ^ k * (k.factorial : ℂ))

    \[\varphi(s, m) = e^{-m \log x} \sum_{k=0}^{\infty} \frac{(m + k)^{s + k}}{a^k\, k!};\]

    \[n\, \varphi(r, n) = \varphi(r + 1, n) - \log x \cdot \varphi(r + 1, n + 1).\]

    Let \(\rho\) be a positive real number with \(\rho e^{\rho + 1} = 1\), let \(n\) be a real number with \(-\rho < n < 1\), and let \(x\) be a complex number. Then the series

    \[\sum_{k=0}^{\infty} \frac{(x + kn)^k}{k!\, e^{kn}}\]

    converges unconditionally to \(e^x / (1 - n)\).

    theorem ramanujan_part1_ch3_entry16_corollary1_jensen_series (ρ : ℝ)
    (hρ_pos : 0 < ρ) (hρ_eq : ρ * Real.exp (ρ + 1) = 1) (n : ℝ) (hn : -ρ < n ∧ n < 1) (x : ℂ) :
    HasSum (fun k : ℕ => (x + (k : ℂ) * (n : ℂ)) ^ k /
        ((Nat.factorial k : ℂ) * Complex.exp ((k : ℂ) * (n : ℂ))))
      (Complex.exp x / (1 - (n : ℂ)))

    TheoremRamanujan's \(\psi\)-series (Chapter 3, Entry 16)#✓fully proved

    MathlibExt.NumberTheory.Ramanujan.Part1Ch3.Entry16PsiSeries.ramanujan_part1_ch3_entry16_psi_series

    For natural numbers \(r\), \(k\) and a complex number \(n\) define \(\psi(r, k, n)\) recursively by \(\psi(0, 1, n) = 1\), \(\psi(0, k, n) = 0\) for \(k \ne 1\), and

    \[\psi(r + 1, k, n) = (n - r - k)\, \psi(r, k, n) + (r + k - 1)\, \psi(r, k - 1, n),\]

    where the last term is read as \(0\) when \(k = 0\). Let \(r\) be a natural number and let \(n\), \(u\) be complex numbers with \(|u e^{1-u}| < 1\) and \(|u| < 1\). Then the series

    \[\sum_{j=0}^{\infty} \frac{(n + j)^{r+j}\, e^{-u(n+j)}\, u^j}{j!}\]

    converges unconditionally to

    \[\sum_{k=1}^{r+1} \frac{\psi(r, k, n)}{(1 - u)^{r+k}}.\]

    The hypothesis \(|u| < 1\) selects the component of \(\{u : |u e^{1-u}| < 1\}\) containing \(0\); given \(|u e^{1-u}| < 1\), it is equivalent to \(\operatorname{Re} u < 1\). On the other component the series converges to a different value.

    Proof: Entry 12 gives absolute and locally uniform convergence, and termwise differentiation gives the recurrence in Berndt (16.4)-(16.5). The Jensen-series base case from Berndt (16.6) extends to the star-convex domain by analytic uniqueness.

    (n u : ℂ) (h : ‖u * Complex.exp (1 - u)‖ < 1) (hu : ‖u‖ < 1) :
    HasSum (fun j : ℕ => (n + (↑j : ℂ)) ^ (r + j) * Complex.exp (-u * (n + (↑j : ℂ))) * u ^ j /
        (↑(Nat.factorial j) : ℂ)) (∑ k ∈ Finset.Icc 1 (r + 1), psi r k n / (1 - u) ^ (r + k))
