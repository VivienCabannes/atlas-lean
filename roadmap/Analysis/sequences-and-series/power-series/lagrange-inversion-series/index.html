    TheoremRamanujan's series for powers of a root of \(x = a \log x\) (Entry 13)#✓fully proved

    MathlibExt.NumberTheory.Ramanujan.Part1Ch3.Entry13.ramanujan_part1_ch3_entry13

    Let \(a\) be a real number with \(|a| \ge e\). Then there is a real number \(x > 0\) with \(x = a \log x\) such that for every real number \(n\) the series

    \[1 + \sum_{k=1}^{\infty} \frac{n (n+k)^{k-1}}{a^k\, k!}\]

    is summable with sum \(x^n\).

    theorem ramanujan_part1_ch3_entry13 (a : ℝ) (ha : |a| ≥ Real.exp 1) :
    ∃ x : ℝ, 0 < x ∧ x = a * Real.log x ∧ ∀ n : ℝ,
      HasSum (fun k : ℕ => if k = 0 then (1 : ℝ) else n * (n + (k : ℝ)) ^ (k - 1) /
          (a ^ k * (Nat.factorial k : ℝ))) (x ^ n)

    TheoremAbel's binomial identity#✓fully proved

    MathlibExt.NumberTheory.Ramanujan.Part1Ch3.Entry13CorollarySchroder.schroder_abel_binomial

    For a complex number \(w\), let \(A_0(x) = 1\) and \(A_j(x) = x (x + j w)^{j-1}\) for \(j \ge 1\). Then for all complex numbers \(x\), \(y\) and every natural number \(n\),

    \[\sum_{j=0}^{n} \binom{n}{j} A_j(x) A_{n-j}(y) = A_n(x + y).\]
    theorem schroder_abel_binomial (w x y : ℂ) (n : ℕ) :
    (∑ j ∈ Finset.range (n + 1), (n.choose j : ℂ) *
        (if j = 0 then 1 else x * (x + (j : ℂ) * w) ^ (j - 1)) *
        (if n - j = 0 then 1
          else y * (y + ((n - j : ℕ) : ℂ) * w) ^ (n - j - 1))) =
      if n = 0 then 1 else (x + y) * (x + y + (n : ℂ) * w) ^ (n - 1)

    TheoremSchröder's exponential series#✓fully proved

    MathlibExt.NumberTheory.Ramanujan.Part1Ch3.Entry13CorollarySchroder.ramanujan_part1_ch3_entry13_corollary_schroder

    Let \(z\) and \(w\) be complex numbers with \(|w| \le |e^{w-1}|\) and \(|w| \le 1\). Then the series

    \[1 + \sum_{k=1}^{\infty} \frac{z (z + k w)^{k-1} e^{-k w}}{k!}\]

    converges unconditionally, and its sum is \(e^z\).

    The set of complex numbers \(w\) with \(|w| \le |e^{w-1}|\) has a bounded lobe containing \(0\) and an unbounded lobe, which meet only at \(w = 1\). The condition \(|w| \le 1\) selects the bounded lobe (given the first condition, it is equivalent to \(\operatorname{Re} w \le 1\)); on the unbounded lobe the identity fails in general.

    Proof: Following Berndt's formula (13.8), we use Abel's binomial identity, a Cauchy product and a holomorphic ODE; radial continuity selects the unit-disk branch of \(u \mapsto u e^{-u}\).

    theorem ramanujan_part1_ch3_entry13_corollary_schroder
    (z w : ℂ) (hw : ‖w‖ ≤ ‖Complex.exp (w - 1)‖) (hw1 : ‖w‖ ≤ 1) :
    HasSum (fun k : ℕ => if k = 0 then 1 else z * (z + (k : ℂ) * w) ^ (k - 1) *
        Complex.exp (-(k : ℂ) * w) / (Nat.factorial k : ℂ)) (Complex.exp z)

    TheoremRamanujan's series for powers of the Catalan generating function#✓fully proved

    MathlibExt.NumberTheory.Ramanujan.Part1Ch3.Entry14Cor1Catalanpowerseries.ramanujan_part1_ch3_entry14_cor1_catalanpowerseries

    Let \(n\) and \(a\) be real numbers with \(|a| \le 1/4\). For a natural number \(k\) put \(t_k = 0\) if \(k < 2\), and

    \[t_k = \frac{a^k}{k!} \prod_{j=k+1}^{2k-1} (n + j)\]

    if \(k \ge 2\). Then the series \(\sum_k t_k\) is summable and

    \[\left(\frac{2}{1 + \sqrt{1 - 4a}}\right)^{n} = 1 + n a + n \sum_{k=0}^{\infty} t_k.\]
    theorem ramanujan_part1_ch3_entry14_cor1_catalanpowerseries
    (n a : ℝ) (ha : |a| ≤ 1 / 4) :

      (∏ j ∈ Finset.Ico (k + 1) (2 * k), (n + (j : ℝ))) * a ^ k / (Nat.factorial k : ℝ)
    Summable term ∧
      Real.rpow (2 / (1 + Real.sqrt (1 - 4 * a))) n = 1 + n * a + n * ∑' k, term k

    MathlibExt.NumberTheory.Ramanujan.Part1Ch3.Entry14LagrangeSeries.lagrangeSeriesCoefficient

    For real numbers \(p\), \(q\), \(n\) and a natural number \(k\), the Lagrange series coefficient \(C_{p,q}(n, k)\) is \(1\) if \(k = 0\), and for \(k \ge 1\) it is

    \[C_{p,q}(n, k) = n \prod_{j=1}^{k-1} (n + k p - j q)\]

    (an empty product when \(k = 1\)).

    def lagrangeSeriesCoefficient (p q n : ℝ) (k : ℕ) : ℝ :=
  if k = 0 then 1 else
    n * ∏ j ∈ Finset.range (k - 1), (n + (k : ℝ) * p - ((j + 1 : ℕ) : ℝ) * q)

    TheoremHagen–Rothe convolution for Lagrange series coefficients#✓fully proved

    MathlibExt.NumberTheory.Ramanujan.Part1Ch3.Entry14LagrangeSeries.lagrangeSeriesCoefficient_add

    For all real numbers \(p\), \(q\), \(r\), \(s\) and every natural number \(m\), the Lagrange series coefficients \(C_{p,q}\) satisfy

    \[C_{p,q}(r + s, m) = \sum_{k=0}^{m} \binom{m}{k} C_{p,q}(r, k) \, C_{p,q}(s, m - k).\]
    theorem lagrangeSeriesCoefficient_add (p q r s : ℝ) (m : ℕ) :
    lagrangeSeriesCoefficient p q (r + s) m =
      ∑ k ∈ Finset.range (m + 1), (Nat.choose m k : ℝ) *
        lagrangeSeriesCoefficient p q r k * lagrangeSeriesCoefficient p q s (m - k)
    def lagrangeSeriesCoefficient (p q n : ℝ) (k : ℕ) : ℝ :=
  if k = 0 then 1 else
    n * ∏ j ∈ Finset.range (k - 1), (n + (k : ℝ) * p - ((j + 1 : ℕ) : ℝ) * q)

    TheoremRamanujan's Lagrange series#✓fully proved

    MathlibExt.NumberTheory.Ramanujan.Part1Ch3.Entry14LagrangeSeries.ramanujan_part1_ch3_entry14_lagrange_series

    Let \(p > 0\) and \(q > 0\) be real numbers with \(p \ne q\), and let \(a\) be a complex number with \(|a| \le p^{-p/q} |p - q|^{(p - q)/q}\). Then there is a complex number \(L\) with \(a q e^{p L} - e^{q L} + 1 = 0\) such that, for every real number \(n\), the series

    \[1 + \sum_{k=1}^{\infty} \frac{n a^k}{k!} \prod_{j=1}^{k-1} (n + k p - j q)\]

    converges unconditionally to \(e^{n L}\).

    Proof: The argument uses the Hagen--Rothe convolution, a Stirling-type coefficient bound uniform through the boundary circle, and a continuous exponential lift.

    theorem ramanujan_part1_ch3_entry14_lagrange_series (p q : ℝ)
    (hp : 0 < p)
        (hq : 0 < q) (hpq : p ≠ q) (a : ℂ) (ha : ‖a‖ ≤ p ^ (-p / q) * |p - q| ^ ((p - q) / q)) :
    ∃ L : ℂ, a * (↑q : ℂ) * Complex.exp (↑p * L) - Complex.exp (↑q * L) + 1 = 0 ∧ ∀ n : ℝ,
        HasSum (fun k : ℕ => if k = 0 then (1 : ℂ) else (↑n : ℂ) *
            Finset.prod (Finset.range (k - 1))
                (fun j => (↑n : ℂ) + (k : ℂ) * (↑p : ℂ) - ((j + 1 : ℂ) * (↑q : ℂ))) * a ^ k /
                    (↑(Nat.factorial k) : ℂ)) (Complex.exp ((↑n : ℂ) * L))

    TheoremRamanujan's exponential series for powers of two#✓fully proved

    MathlibExt.NumberTheory.Ramanujan.Part1Ch3.Entry15Example1ExponentialSeries.ramanujan_part1_ch3_entry15_example1_exponential_series

    Let \(m\) and \(n\) be real numbers with \(0 < n \le 2\). Then the series

    \[1 + \sum_{k=1}^{\infty} \frac{m}{2^{k n} \, k!} \prod_{j=1}^{k-1} (m + k n - j)\]

    converges unconditionally to \(2^m\).

    Proof: Following Berndt and the generalized binomial series of Graham, Knuth, and Patashnik, the series is realized as \(B_n(z)^m\), where \(B_n = 1 + z B_n^n\); root selection at \(z = 2^{-n}\), with the endpoint supplied by Entry 14's Catalan-power series, gives \(B_n = 2\).

    theorem ramanujan_part1_ch3_entry15_example1_exponential_series (m n : ℝ)
    (hn_pos : 0 < n) (hn_le : n ≤ 2) :
    HasSum (fun k : ℕ =>
      if k = 0 then (1 : ℝ)
      else (m * ∏ j ∈ Finset.range (k - 1), (m + (k : ℝ) * n - ((j : ℝ) + 1))) /
        ((2 : ℝ) ^ ((k : ℝ) * n) * (Nat.factorial k : ℝ))) ((2 : ℝ) ^ m)

    TheoremRamanujan's inverse series for \(u - \log u\)#✓fully proved

    MathlibExt.NumberTheory.Ramanujan.Part1Ch3.Entry15InverseSeries.ramanujan_part1_ch3_entry15_inverse_series

    There exist a real number \(r > 0\) and real coefficients \(b_0, b_1, b_2, \dots\) with \(b_0 = 1\), \(b_1 = -1\), \(b_2 = 1/3\), \(b_3 = -1/36\) and \(b_4 = -1/270\) such that the power series \(\sum_k b_k x^k\) is summable for every real \(x\) with \(|x| < r\), and for every real \(x\) with \(0 < x < r\) the sum \(u\) of this series satisfies \(0 < u < 1\) and \(u - \log u = 1 + x^2/2\), and the series \(\sum_{j \ge 2} (1 - u)^j / j\) converges unconditionally to \(x^2/2\).

    theorem ramanujan_part1_ch3_entry15_inverse_series :
    ∃ (r : ℝ) (b : ℕ → ℝ),
      0 < r ∧ b 0 = 1 ∧ b 1 = -1 ∧ b 2 = (1 : ℝ) / 3 ∧ b 3 = -(1 : ℝ) / 36 ∧
        b 4 = -(1 : ℝ) / 270 ∧
        (∀ x : ℝ, |x| < r → ∃ u : ℝ, HasSum (fun k : ℕ => b k * x ^ k) u) ∧
        ∀ x : ℝ, 0 < x → x < r → ∀ u : ℝ, HasSum (fun k : ℕ => b k * x ^ k) u →
          0 < u ∧ u < 1 ∧ u - Real.log u = 1 + x ^ 2 / 2 ∧
            HasSum (fun j : ℕ => (1 - u) ^ (j + 2) / (↑(j + 2) : ℝ)) (x ^ 2 / 2)
