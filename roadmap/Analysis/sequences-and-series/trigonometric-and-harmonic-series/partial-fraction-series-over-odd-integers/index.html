    MathlibExt.Analysis.Ramanujan.Part1Ch9.Entry1Logratio.ramanujan_part1_ch9_entry1_logratio

    Let \(r\) be a positive integer, \(a\) a real number that is not an odd integer, and \(x\) a real number with \(|x| < \pi\). For a natural number \(s\) let \(c_k(s) = (2k+1-a)^{-s} - (2k+1+a)^{-s}\) and \(C_s(a) = \sum_{k=0}^{\infty} c_k(s)\). Then \(\sum_k c_k(r)\) is summable, and either \(r\) is odd, \(\sum_k c_k(r-2j)\) is summable for \(0 \le j \le (r-1)/2\), and the partial sums of \(\sum_{k=0}^{\infty} \bigl(\frac{\cos((2k+1-a)x)}{(2k+1-a)^r} - \frac{\cos((2k+1+a)x)}{(2k+1+a)^r}\bigr)\) converge to \(\sum_{j=0}^{(r-1)/2} (-1)^j C_{r-2j}(a) \frac{x^{2j}}{(2j)!}\); or \(r\) is even, \(\sum_k c_k(r-2j-1)\) is summable for \(0 \le j < r/2\), and the partial sums of \(\sum_{k=0}^{\infty} \bigl(\frac{\sin((2k+1-a)x)}{(2k+1-a)^r} - \frac{\sin((2k+1+a)x)}{(2k+1+a)^r}\bigr)\) converge to \(\sum_{0 \le j < r/2} (-1)^j C_{r-2j-1}(a) \frac{x^{2j+1}}{(2j+1)!}\).

    Let \(r \ge 2\) be an integer, \(a\) a real number that is not an odd integer, and \(x\) a real number with \(0 < x < \pi\). For a natural number \(s\) let \(d_k(s) = (2k+1-a)^{-s} + (2k+1+a)^{-s}\) and \(D_s(a) = \sum_{k=0}^{\infty} d_k(s)\). Then \(\sum_k d_k(r)\) is summable, and either \(r\) is even, \(\sum_k d_k(r-2j)\) is summable for \(0 \le j < r/2\), and the partial sums of \(\sum_{k=0}^{\infty} \bigl(\frac{\cos((2k+1-a)x)}{(2k+1-a)^r} + \frac{\cos((2k+1+a)x)}{(2k+1+a)^r}\bigr)\) converge to \(\sum_{0 \le j < r/2} (-1)^j D_{r-2j}(a) \frac{x^{2j}}{(2j)!} + (-1)^{r/2} \frac{\pi x^{r-1}}{2 (r-1)!}\); or \(r\) is odd, \(\sum_k d_k(r-1-2j)\) is summable for \(0 \le j < (r-1)/2\), and the partial sums of \(\sum_{k=0}^{\infty} \bigl(\frac{\sin((2k+1-a)x)}{(2k+1-a)^r} + \frac{\sin((2k+1+a)x)}{(2k+1+a)^r}\bigr)\) converge to \(\sum_{0 \le j < (r-1)/2} (-1)^j D_{r-1-2j}(a) \frac{x^{2j+1}}{(2j+1)!} + (-1)^{(r-1)/2} \frac{\pi x^{r-1}}{2 (r-1)!}\).
