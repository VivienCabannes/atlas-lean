    TheoremHarmonic numbers of half-integer index#●ready to prove

    MetaMathlibExt.harmonic_nat_sub_half_values

    Let \(k\) be a natural number. For each integer \(r \ge 1\) let \(O^{(r)}_k = \sum_{j=1}^{k} \frac{1}{(2j - 1)^r}\), and let \(O_k = O^{(1)}_k\). Let \(\psi\) be the digamma function, \(\gamma\) the Euler–Mascheroni constant and \(\zeta\) the Riemann zeta function. Then

    \[\psi\bigl(k + \tfrac12\bigr) + \gamma = 2 O_k - 2 \log 2,\]
    \[\sum_{j=0}^{\infty} \Bigl(\frac{1}{(j + 1)^2} - \frac{1}{(j + k + \frac12)^2}\Bigr) = -2 \zeta(2) + 4 O^{(2)}_k,\]
    \[\sum_{j=0}^{\infty} \Bigl(\frac{1}{(j + 1)^3} - \frac{1}{(j + \frac12)^3}\Bigr) = -6 \zeta(3),\]

    and for every natural number \(m\),

    \[\sum_{j=0}^{\infty} \Bigl(\frac{1}{(j+\frac12)^{m+1}} - \frac{1}{(j+k+\frac12)^{m+1}}\Bigr) = 2^{m+1} O^{(m+1)}_k.\]

    With \(H_\alpha = \psi(\alpha + 1) + \gamma\) and \(H^{(r)}_\alpha = \sum_{j \ge 1} (j^{-r} - (j + \alpha)^{-r})\), these read \(H_{k-1/2} = 2O_k - 2\log 2\), \(H^{(2)}_{k-1/2} = -2\zeta(2) + 4O^{(2)}_k\), \(H^{(3)}_{-1/2} = -6\zeta(3)\) and \(H^{(m+1)}_{k-1/2} - H^{(m+1)}_{-1/2} = 2^{m+1} O^{(m+1)}_k\).

    public theorem_wanted harmonic_nat_sub_half_values (k : ℕ) :
    Complex.digamma (k + 1 / 2) + Real.eulerMascheroniConstant =
        2 * ∑ j ∈ Finset.range k, 1 / (2 * (j : ℂ) + 1) - 2 * Complex.log 2 ∧
      ∑' j : ℕ, (1 / ((j : ℂ) + 1) ^ 2 - 1 / ((j : ℂ) + k + 1 / 2) ^ 2) =
        -2 * riemannZeta 2 + 4 * ∑ j ∈ Finset.range k, 1 / (2 * (j : ℂ) + 1) ^ 2 ∧
      ∑' j : ℕ, (1 / ((j : ℂ) + 1) ^ 3 - 1 / ((j : ℂ) + 1 / 2) ^ 3) = -6 * riemannZeta 3 ∧
      ∀ m : ℕ, ∑' j : ℕ, (1 / ((j : ℂ) + 1 / 2) ^ (m + 1) - 1 / ((j : ℂ) + k + 1 / 2) ^ (m + 1)) =
        2 ^ (m + 1) * ∑ j ∈ Finset.range k, 1 / (2 * (j : ℂ) + 1) ^ (m + 1)
    Sources

    TheoremThe Gamma function at \(r + \tfrac12\) and at \(\tfrac12 - r\)#●ready to prove

    MetaMathlibExt.Gamma_add_half_and_Gamma_half_sub_nat

    For every complex number \(r\) that is not a negative integer,

    \[\Gamma\bigl(r + \tfrac12\bigr) = \frac{\sqrt{\pi}}{2^{2r}} \cdot \frac{\Gamma(2r + 1)}{\Gamma(r + 1)},\]

    where \(2^{2r} = e^{2r \log 2}\); and for every natural number \(r\),

    \[\Gamma\bigl(\tfrac12 - r\bigr) = \frac{(-1)^r \, 2^{2r} \sqrt{\pi}}{r! \binom{2r}{r}}.\]

    In the first identity \(\Gamma\) is taken to be \(0\) at the non-positive integers, so for \(r = -\tfrac12, -\tfrac32, \dots\) both sides are \(0\).

    public theorem_wanted Gamma_add_half_and_Gamma_half_sub_nat :
    (∀ r : ℂ, (∀ m : ℕ, r ≠ -((m : ℂ) + 1)) →
      Complex.Gamma (r + 1 / 2) =
        (Real.sqrt Real.pi : ℂ) / (2 : ℂ) ^ (2 * r) *
          (Complex.Gamma (2 * r + 1) / Complex.Gamma (r + 1))) ∧
    ∀ r : ℕ, Complex.Gamma (1 / 2 - r) =
      (Real.sqrt Real.pi : ℂ) * (-1) ^ r / r.factorial * 2 ^ (2 * r) / (2 * r).choose r

    MetaMathlibExt.tsum_catalan_mul_harmonic_div_four_pow_mul_binom

    \[\sum_{n=0}^{\infty} \frac{C_n \bigl(\psi(n + z + 1) + \gamma\bigr)}{4^n \binom{n+z}{n}} = 2 \bigl(\psi(z) - \psi(z + \tfrac12)\bigr) \bigl(1 - z (\psi(z + 1) + \gamma)\bigr) + 2z \sum_{j=0}^{\infty} \Bigl(\frac{1}{(j + z)^2} - \frac{1}{(j + z + \frac12)^2}\Bigr).\]

    In terms of \(H_\alpha = \psi(\alpha + 1) + \gamma\), the summand is \(C_n H_{n+z} / (4^n \binom{n+z}{n})\).
