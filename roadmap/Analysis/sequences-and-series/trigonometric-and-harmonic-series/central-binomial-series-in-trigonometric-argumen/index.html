    MathlibExt.Analysis.Ramanujan.Part1Ch9.Entry16Tan.ramanujan_part1_ch9_entry16_tan

    Let \(x\) be a real number with \(|x| \le \pi/2\), and let \(L(x) = x \log|2\sin x|\) for \(x \ne 0\) and \(L(0) = 0\). Then \(|2\sin x| > 0\) if \(x \ne 0\), the series \(S(x) = \sum_{k=0}^{\infty} \binom{2k}{k} \frac{\sin^{2k+1} x}{2^{2k} (2k+1)^2}\) and \(F(x) = \sum_{k=1}^{\infty} \frac{\sin 2kx}{k^2}\) are both summable, and \(S(x) = L(x) + \frac{1}{2} F(x)\).

    theorem ramanujan_part1_ch9_entry16_tan (x : ℝ) (hx : |x| ≤ Real.pi / 2) :
    (x ≠ 0 → 0 < |2 * Real.sin x|) ∧
      Summable (Entry16Tanseries.chapter9CentralSineTerm x) ∧
      Summable (chapter9SineFourierTwoTerm x) ∧
      (∑' k : ℕ, Entry16Tanseries.chapter9CentralSineTerm x k) =
        chapter9Entry16LogTerm x +
          (1 / 2 : ℝ) * ∑' j : ℕ, chapter9SineFourierTwoTerm x j

    MathlibExt.Analysis.Ramanujan.Part1Ch9.Entry19Catalangf.ramanujan_part1_ch9_entry19_catalangf

    Let \(x\) be a real number with \(0 \le x \le \pi/4\). Then \(2\cos x > 0\), the series \(C(x) = \sum_{k=0}^{\infty} \binom{2k}{k} \frac{\cos^{2k+1} x + \sin^{2k+1} x} {2^{2k} (2k+1)^2}\) and \(T(x) = \sum_{k=0}^{\infty} (-1)^k \frac{\tan^{2k+1} x}{(2k+1)^2}\) are both summable, and \(C(x) = \frac{\pi}{2} \log(2\cos x) + T(x)\).

        Real.pi / 2 * Real.log (2 * Real.cos x) +
          ∑' k : ℕ, chapter9Entry19TanTerm x k

    TheoremRamanujan's central-binomial sine series identity (Entry 31)#✓fully proved

    MathlibExt.Analysis.Ramanujan.Part1Ch9.Entry31Ramanujansum.ramanujan_part1_ch9_entry31_ramanujansum

    For real \(y\) let \(\psi(y) = \sum_{k \ge 0} \binom{2k}{k} \sin^{2k+1}(\pi y) / \bigl(2^{2k} (2k+1)^2\bigr)\). If \(0 \le x \le 1/4\), then the series defining \(\psi(1/2 - x)\), \(\psi(2x)\) and \(\psi(x)\) converge absolutely, \(2 \cos(\pi x) > 0\), and \(\psi(1/2 - x) + \tfrac12 \psi(2x) - \psi(x) = \tfrac{\pi}{2} \log(2 \cos(\pi x))\).

    theorem ramanujan_part1_ch9_entry31_ramanujansum
    (x : ℝ) (hxLower : 0 ≤ x) (hxUpper : x ≤ 1 / 4) :
    Summable (chapter9PsiTerm (1 / 2 - x)) ∧
      Summable (chapter9PsiTerm (2 * x)) ∧
      Summable (chapter9PsiTerm x) ∧
      0 < 2 * Real.cos (Real.pi * x) ∧
      (∑' k : ℕ, chapter9PsiTerm (1 / 2 - x) k) +
          (1 / 2 : ℝ) * ∑' k : ℕ, chapter9PsiTerm (2 * x) k -
          ∑' k : ℕ, chapter9PsiTerm x k =
        Real.pi / 2 * Real.log (2 * Real.cos (Real.pi * x))
    def chapter9PsiTerm (x : ℝ) (k : ℕ) : ℝ :=
  (Nat.choose (2 * k) k : ℝ) *
      Real.sin (Real.pi * x) ^ (2 * k + 1) /
    ((2 : ℝ) ^ (2 * k) * (((2 * k + 1 : ℕ) : ℝ) ^ 2))
