    MathlibExt.NumberTheory.Ramanujan.Part1Ch2.Entry3.ramanujan_part1_ch2_entry3_general

    For every natural number \(n\),

    \[\sum_{k=1}^{2n+1} \arctan \frac{1}{n+k} = \frac{\pi}{4} + \sum_{k=1}^{n} \arctan \frac{10k}{(3k^2 + 2)(9k^2 - 1)}.\]

    This is Ramanujan's Entry 3 of Chapter 2 without the hypothesis \(n \ge 1\); at \(n = 0\) both sides are \(\pi/4\).

    theorem ramanujan_part1_ch2_entry3_general (n : ℕ) :
    ∑ k ∈ Finset.Icc 1 (2 * n + 1), Real.arctan (1 / ((↑n + ↑k : ℝ))) =
      Real.pi / 4 + ∑ k ∈ Finset.Icc 1 n,
          Real.arctan ((10 * (↑k : ℝ)) / ((3 * (↑k : ℝ) ^ 2 + 2) * (9 * (↑k : ℝ) ^ 2 - 1)))

    TheoremRamanujan's arctangent series for \(\log 3 - \pi/4\)#✓fully proved

    MathlibExt.NumberTheory.Ramanujan.Part1Ch2.Entry3InfiniteEvaluation.ramanujan_part1_ch2_entry3_infinite_evaluation

    The series

    \[\sum_{k=1}^{\infty} \arctan \frac{10k}{(3k^2 + 2)(9k^2 - 1)}\]

    converges, and its sum is \(\log 3 - \pi/4\).

    theorem ramanujan_part1_ch2_entry3_infinite_evaluation :
    HasSum (fun n : ℕ =>
        Real.arctan (10 * ((n : ℝ) + 1) /
            ((3 * ((n : ℝ) + 1) ^ 2 + 2) * (9 * ((n : ℝ) + 1) ^ 2 - 1))))
                (Real.log 3 - Real.pi / 4)

    TheoremRamanujan's finite arctangent sum (Entry 7)#✓fully proved

    MathlibExt.NumberTheory.Ramanujan.Part1Ch2.Entry7.ramanujan_part1_ch2_entry7

    For every real number \(n > 0\) and every natural number \(r\),

    \[\sum_{k=0}^{r-1} \arctan \frac{2}{(n + 2k + 1)^2} = \arctan \frac{2r}{n^2 + 2nr + 1}.\]
    theorem ramanujan_part1_ch2_entry7 (n : ℝ) (r : ℕ) (hn : 0 < n) :
    ∑ k ∈ Finset.range r, Real.arctan (2 / (n + 2 * (k : ℝ) + 1) ^ 2) =
      Real.arctan (2 * (r : ℝ) / (n ^ 2 + 2 * n * (r : ℝ) + 1))

    TheoremArctangent series over consecutive shifts (Entry 7, Example 1)#✓fully proved

    MathlibExt.NumberTheory.Ramanujan.Part1Ch2.Entry7Example1.ramanujan_part1_ch2_entry7_example1

    Let \(n > 0\) be a real number with \(n \ne (\sqrt{5} - 1)/2\). Then the series

    \[\sum_{k=0}^{\infty} \arctan \frac{2}{(n + k + 1)^2}\]

    converges absolutely; its sum is \(\arctan \frac{2n + 1}{n^2 + n - 1}\) when \(n > (\sqrt{5} - 1)/2\), and \(\arctan \frac{2n + 1}{n^2 + n - 1} + \pi\) when \(n < (\sqrt{5} - 1)/2\). Here \(\arctan\) is the principal branch, with values in \((-\pi/2, \pi/2)\).

    theorem ramanujan_part1_ch2_entry7_example1 (n : ℝ)
    (hn_pos : 0 < n) (hn_ne : n ≠ (Real.sqrt 5 - 1) / 2) :
    HasSum (fun k : ℕ => Real.arctan (2 / ((n + (k : ℝ) + 1) ^ 2)))
      (Real.arctan ((2 * n + 1) / (n ^ 2 + n - 1)) + if n < (Real.sqrt 5 - 1) / 2 then Real.pi else
          0)
