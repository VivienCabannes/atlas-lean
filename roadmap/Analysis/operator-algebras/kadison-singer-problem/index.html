    MathlibExt.Analysis.CStarAlgebra.KadisonSinger.FiniteMSSBound

    The proposition that the following holds for every natural number \(m\) and every finite index set \(D\). Let \(s_1, \dots, s_m\) be positive integers, let \(p_{i,a} \ge 0\) be reals and \(v_{i,a} \in \mathbb{C}^D\) be vectors for \(1 \le i \le m\) and \(1 \le a \le s_i\), and let \(\eta \ge 0\) be real. Suppose that \(\sum_a p_{i,a} = 1\) for each \(i\), that \(\sum_i \sum_a p_{i,a} v_{i,a} v_{i,a}^* = \mathrm{Id}_D\), and that \(\sum_a p_{i,a} \|v_{i,a}\|^2 \le \eta\) for each \(i\), where \(\|v_{i,a}\|\) is the Euclidean norm. Then there are choices \(a_i \in \{1, \dots, s_i\}\) for \(i = 1, \dots, m\) such that \(\left\|\sum_i v_{i,a_i} v_{i,a_i}^*\right\| \le (1 + \sqrt{\eta})^2\), where the norm of a matrix is the operator norm.

    In probabilistic terms, \(p_{i,a}\) is the probability that an independent random vector \(v_i\) takes the value \(v_{i,a}\), and the conclusion is that some choice of values meets the bound.

    public def FiniteMSSBound : Prop :=
  ∀ (m : ℕ) (d : Type u) [Fintype d] [DecidableEq d] (s : Fin m → ℕ),
    (∀ i, 0 < s i) →
    ∀ (p : (i : Fin m) → Fin (s i) → ℝ)
      (v : (i : Fin m) → Fin (s i) → d → ℂ) (η : ℝ),
      0 ≤ η →
      (∀ i a, 0 ≤ p i a) →
      (∀ i, ∑ a, p i a = 1) →
      (∑ i, ∑ a, (p i a : ℂ) • Matrix.vecMulVec (v i a) (star (v i a)) = 1) →
      (∀ i, ∑ a, p i a * ∑ k, ‖v i a k‖ ^ 2 ≤ η) →
      ∃ ω : (i : Fin m) → Fin (s i),
        ‖∑ i, Matrix.vecMulVec (v i (ω i)) (star (v i (ω i)))‖ ≤
          (1 + Real.sqrt η) ^ 2
