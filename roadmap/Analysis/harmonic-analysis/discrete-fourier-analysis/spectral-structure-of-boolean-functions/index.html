    Spectral structure of Boolean functions

    How the Fourier spectrum of a function on the Boolean cube reflects its combinatorics: low total influence forces low-degree concentration, degree bounds total influence, rounding to the sign costs at most the squared \(L^2\) error, monotone functions have influences equal to their degree-1 coefficients, and linear threshold functions are determined by their degree-0 and degree-1 coefficients.

    TheoremRounding to the sign#✓fully proved

    BooleanCube.boolDist_le_expect_sq_sub

    Let \(f : \{-1, 1\}^n \to \{-1, 1\}\) and \(g : \{-1, 1\}^n \to \mathbb{R}\), and let \(h = \mathrm{sgn}(g)\), with \(\mathrm{sgn}(0) \in \{-1, 1\}\) chosen arbitrarily (in Lean: \(h\) is \(\pm 1\)-valued with \(h(x) g(x) \ge 0\)). Then

    \[\mathrm{dist}(f, h) \le \mathbb{E}\big[(f - g)^2\big] = \|f - g\|_2^2,\]

    since \(|f(x) - g(x)| \ge 1\) wherever \(f(x) \ne \mathrm{sgn}(g(x))\). This is the rounding step of the Low-Degree Algorithm: a good \(L^2\) approximation by a polynomial gives a good Boolean hypothesis.

    theorem boolDist_le_expect_sq_sub {f g h : BoolCube n → ℝ} (hf : ∀ x, f x = 1 ∨ f x = -1)
    (hh : ∀ x, h x = 1 ∨ h x = -1) (hhg : ∀ x, 0 ≤ h x * g x) :
    boolDist f h ≤ 𝔼 x, (f x - g x) ^ 2
    abbrev BoolCube (n : ℕ) : Type := Fin n → Bool

    TheoremInfluences of a monotone Boolean function#✓fully proved

    BooleanCube.boolInfluence_eq_boolFourierCoeff_of_monotone

    If \(f : \{-1, 1\}^n \to \{-1, 1\}\) is monotone (\(f(x) \le f(y)\) whenever \(x \le y\) coordinatewise), then for every coordinate \(i\),

    \[\mathrm{Inf}_i[f] = \hat f(\{i\}).\]

    For monotone \(f\) the derivative \(D_i f\) is the \(0\)-\(1\) indicator that \(i\) is pivotal, so \(\mathrm{Inf}_i[f] = \mathbb{E}[D_i f] = \hat f(\{i\})\).

    theorem boolInfluence_eq_boolFourierCoeff_of_monotone {f : BoolCube n → ℝ}
    (hf : ∀ x, f x = 1 ∨ f x = -1) (hmono : Monotone f) (i : Fin n) :
    boolInfluence f i = boolFourierCoeff n f {i}

    BooleanCube.boolTotalInfluence_le_degree

    If \(f : \{-1, 1\}^n \to \{-1, 1\}\) has degree at most \(d\), then \(\mathbf{I}[f] \le d\): in \(\mathbf{I}[f] = \sum_S |S|\, \hat f(S)^2\) every nonzero term has \(|S| \le d\), and \(\sum_S \hat f(S)^2 = 1\) by Parseval.

    TheoremChow's theorem#✓fully proved

    BooleanCube.eq_of_boolFourierCoeff_eq_of_ltf

    Let \(f : \{-1, 1\}^n \to \{-1, 1\}\) be a linear threshold function, \(f = \mathrm{sgn}(\ell)\) for a polynomial \(\ell\) of degree at most \(1\) that never vanishes on the cube, and let \(g : \{-1, 1\}^n \to \{-1, 1\}\) be any Boolean function. If \(\hat g(S) = \hat f(S)\) for every \(|S| \le 1\), then \(g = f\). A linear threshold function is determined, among all Boolean functions, by its \(n + 1\) Chow parameters \(\hat f(\emptyset), \hat f(\{1\}), \dots, \hat f(\{n\})\).

    The proof compares \(\mathbb{E}[f \ell] = \mathbb{E}[|\ell|]\) with \(\mathbb{E}[g \ell]\), which is equal by Plancherel and at most \(\mathbb{E}[|\ell|]\) pointwise, with equality only where \(g = f\). Every linear threshold function admits such an \(\ell\) (perturb the constant term), as the source's proof assumes.

    theorem eq_of_boolFourierCoeff_eq_of_ltf {f g ℓ : BoolCube n → ℝ}
    (hℓ : MultilinearDegreeLE n ℓ 1) (hfℓ : ∀ x, 0 < f x * ℓ x) (hf : ∀ x, f x = 1 ∨ f x = -1)
    (hg : ∀ x, g x = 1 ∨ g x = -1)
    (hcoeff : ∀ S : Finset (Fin n), S.card ≤ 1 → boolFourierCoeff n g S = boolFourierCoeff n f S) :
    g = f
    abbrev BoolCube (n : ℕ) : Type := Fin n → Bool

    BooleanCube.sum_sq_card_gt_le

    For every \(f : \{-1, 1\}^n \to \mathbb{R}\) and every real \(t > 0\),

    \[\mathbf{W}^{>t}[f] = \sum_{|S| > t} \hat f(S)^2 \le \frac{\mathbf{I}[f]}{t},\]

    TheoremLow total influence implies low-degree spectral concentration#✓fully proved

    BooleanCube.sum_sq_card_gt_le_of_pos

    For every \(f : \{-1, 1\}^n \to \mathbb{R}\) and every \(\varepsilon > 0\), the Fourier spectrum of \(f\) is \(\varepsilon\)-concentrated on degree up to \(\mathbf{I}[f]/\varepsilon\):

    \[\sum_{|S| > \mathbf{I}[f]/\varepsilon} \hat f(S)^2 \le \varepsilon .\]

    Together with the Low-Degree Algorithm this makes functions of small total influence (for example monotone functions) learnable from random examples.

    theorem sum_sq_card_gt_le_of_pos (f : BoolCube n → ℝ) {ε : ℝ} (hε : 0 < ε) :
    ∑ S with boolTotalInfluence f / ε < (S.card : ℝ), boolFourierCoeff n f S ^ 2 ≤ ε
    abbrev BoolCube (n : ℕ) : Type := Fin n → Bool
