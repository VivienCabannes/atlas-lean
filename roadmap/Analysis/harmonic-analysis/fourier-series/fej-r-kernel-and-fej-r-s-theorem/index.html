    Fejér kernel and Fejér's theorem

    DefinitionThe Fejér kernel#✓fully proved

    AddCircle.fejerKernel

    Let \(T > 0\) and, for \(n \in \mathbb{Z}\), let \(e_n(x) = e^{2\pi i n x / T}\) be the \(n\)-th Fourier character on the circle \(\mathbb{R}/T\mathbb{Z}\). For a natural number \(N\), the \(N\)-th Fejér kernel is the function \(K_N : \mathbb{R}/T\mathbb{Z} \to \mathbb{C}\) given by the Cesàro mean of the Dirichlet kernels, \(K_N(x) = \frac{1}{N+1} \sum_{k=0}^{N} \sum_{n=-k}^{k} e_n(x)\).

    Writing \(x\) also for a real representative, when \(\sin(\pi x / T) \ne 0\) the kernel has the closed form \(K_N(x) = \frac{1}{N+1} \left(\frac{\sin((N+1)\pi x / T)}{\sin(\pi x / T)}\right)^2\). This normalization is for the Haar probability measure on \(\mathbb{R}/T\mathbb{Z}\); for \(T = 2\pi\), the kernel for integration against Lebesgue measure is \(K_N / (2\pi)\).

    noncomputable def fejerKernel (N : ℕ) : AddCircle T → ℂ :=
  fun x => ((N : ℂ) + 1)⁻¹ • ∑ k ∈ range (N + 1),
    ∑ n ∈ Finset.Icc (-(k : ℤ)) (k : ℤ), fourier n x

    AddCircle.fejer_kernel_properties

    Let \(T > 0\), let \(N\) be a natural number, let \(K_N\) be the \(N\)-th Fejér kernel on the circle \(\mathbb{R}/T\mathbb{Z}\), let \(\mu\) be the normalized Haar measure on \(\mathbb{R}/T\mathbb{Z}\) (of total mass \(1\)), and let \(e_1(x) = e^{2\pi i x / T}\).
