    MathlibExt.Analysis.BeurlingAhlfors.pstar

    For a real number \(p\), \(p^* = \max(p, p/(p-1))\), with division by zero taken to be \(0\) (so \(p^* = 1\) at \(p = 1\)). For \(p > 1\) this is the larger of \(p\) and its conjugate exponent \(p/(p-1)\).

    noncomputable def pstar (p : ℝ) : ℝ :=
  max p (p / (p - 1))

    DefinitionTruncated Beurling–Ahlfors integral#✓fully proved

    MathlibExt.Analysis.BeurlingAhlfors.beurlingTrunc

    For a real number \(\varepsilon\), a function \(f : \mathbb{C} \to \mathbb{C}\) and \(z \in \mathbb{C}\), the truncated Beurling–Ahlfors integral at cutoff \(\varepsilon\) is \(-\frac{1}{\pi} \int_{|w - z| > \varepsilon} \frac{f(w)}{(z - w)^2} \, dw\), the integral being with respect to Lebesgue measure on \(\mathbb{C}\) and taken to be \(0\) when the integrand is not integrable.

  -(1 / ((Real.pi : ℝ) : ℂ)) * ∫ w in { w : ℂ | ε < ‖w - z‖ }, f w / (z - w) ^ 2

    DefinitionBeurling–Ahlfors transform#✓fully proved

    MathlibExt.Analysis.BeurlingAhlfors.beurlingTransform

    For \(f : \mathbb{C} \to \mathbb{C}\) and \(z \in \mathbb{C}\), \(Bf(z)\) is the limit as \(\varepsilon \to 0^+\) of the truncated Beurling–Ahlfors integrals \(-\frac{1}{\pi} \int_{|w - z| > \varepsilon} \frac{f(w)}{(z - w)^2} \, dw\) (each taken to be \(0\) when its integrand is not integrable). Where this limit does not exist, \(Bf(z)\) is an unspecified complex number.

    For \(f \in L^p\) with \(1 < p < \infty\) the limit exists almost everywhere.

    noncomputable def beurlingTransform (f : ℂ → ℂ) (z : ℂ) : ℂ :=
  Filter.limUnder (𝓝[Set.Ioi 0] 0) fun ε => beurlingTrunc ε f z

    DefinitionAdmissible bounds for the Beurling–Ahlfors transform#✓fully proved

    MathlibExt.Analysis.BeurlingAhlfors.IsBound

    For real numbers \(p\) and \(C\), \(C\) is an admissible \(L^p\) bound constant for the Beurling–Ahlfors transform \(B\) when \(\|Bf\|_q \le \max(C, 0) \, \|f\|_q\) for every almost everywhere strongly measurable function \(f : \mathbb{C} \to \mathbb{C}\), where \(q = \max(p, 0)\) and \(\|\cdot\|_q\) is the extended \(L^q\) norm with respect to Lebesgue measure (identically \(0\) when \(q = 0\)), with values in \([0, \infty]\) and the convention \(0 \cdot \infty = 0\).

    def IsBound (p C : ℝ) : Prop :=
  ∀ f : ℂ → ℂ, AEStronglyMeasurable f volume →
    eLpNorm (beurlingTransform f) (ENNReal.ofReal p) volume ≤
      ENNReal.ofReal C * eLpNorm f (ENNReal.ofReal p) volume

    DefinitionNorm of the Beurling–Ahlfors transform#✓fully proved

    MathlibExt.Analysis.BeurlingAhlfors.beurlingNorm

    For a real number \(p\), the norm \(\|B\|_p\) of the Beurling–Ahlfors transform \(B\) is the infimum of the real numbers \(C \ge 0\) that are admissible \(L^p\) bound constants for \(B\), and is \(0\) when there is no such \(C\). In particular an upper bound on \(\|B\|_p\) alone does not imply that \(B\) is bounded on \(L^p\).

    noncomputable def beurlingNorm (p : ℝ) : ℝ :=
  sInf { C : ℝ | 0 ≤ C ∧ IsBound p C }
    def IsBound (p C : ℝ) : Prop :=
  ∀ f : ℂ → ℂ, AEStronglyMeasurable f volume →

    DefinitionBeurling–Ahlfors constant#✓fully proved

    MathlibExt.Analysis.BeurlingAhlfors.beurlingAhlforsConstant

    The Beurling–Ahlfors constant is the supremum, over real numbers \(p > 1\), of \(\|B\|_p / (p^* - 1)\), where \(B\) is the Beurling–Ahlfors transform, \(\|B\|_p\) is the infimum of the real numbers \(C \ge 0\) that are admissible \(L^p\) bound constants for \(B\) (and \(0\) if there is no such \(C\)), and \(p^* = \max(p, p/(p-1))\).     MathlibExt.Analysis.BeurlingAhlforsWanted.lehtoLowerBound_wanted

    For a function \(f : \mathbb{C} \to \mathbb{C}\) let \(Bf(z)\) be the limit as \(\varepsilon \to 0^+\) of \(-\frac{1}{\pi} \int_{|w - z| > \varepsilon} \frac{f(w)}{(z - w)^2} \, dA(w)\), where \(dA\) is Lebesgue area measure (a junk value where the limit does not exist).
