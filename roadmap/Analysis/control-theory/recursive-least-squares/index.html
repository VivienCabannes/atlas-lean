    Recursive least squares

    Recursive least squares (RLS) estimates the parameter \(\theta \in \mathbb{R}^d\) of the linear regression \(y_{k+1} = \varphi_k^\top \theta + w_{k+1}\) from the regressors \(\varphi_k\) and the observations \(y_{k+1}\), updating an estimate \(\theta_k\) and a matrix \(P_k\) at each step. In system identification and adaptive control the regressor \(\varphi_k\) collects past outputs and inputs, and the inputs are themselves computed from the estimates, so the data are generated in closed loop and are neither independent nor stationary; the theory of Chen and Guo (Identification and Stochastic Adaptive Control, Birkhäuser 1991) and of Lai and Wei (Ann. Statist. 10 (1982)) is built for this setting.

    The pages below prove that the recursion computes the regularised batch least-squares estimate (the matrix inversion lemma), identify it with ridge regression when started at \(\theta_0 = 0\), \(P_0 = \lambda^{-1} I\), and prove convergence in the noise-free case once the smallest eigenvalue of \(\sum_k \varphi_k \varphi_k^\top\) tends to infinity. The stochastic convergence rate \(|\theta_{t+1} - \theta|^2 = O(\log r_t / \lambda_{\min}(t))\) under martingale-difference noise, with no excitation assumption, and the logarithmic regret of the least-squares adaptive predictor are recorded as wanted theorems.

    The algorithm

    DefinitionOne step of recursive least squares#✓fully proved

    MathlibExt.Analysis.Control.RecursiveLeastSquares.rlsStep

    From the estimate \(\theta\), the matrix \(P\), the regressor \(\varphi\) and the new observation \(y\), one step of recursive least squares returns $\(\theta' = \theta + \frac{P \varphi \,(y - \varphi^\top \theta)}{1 + \varphi^\top P \varphi}, \qquad P' = P - \frac{P \varphi \varphi^\top P}{1 + \varphi^\top P \varphi}.\)$ This is Algorithm 1, equations (2)–(4), of Xie, Zhang and Guo, Convergence of a distributed least squares, IEEE Trans. Automat. Control, accepted version (2020), DOI 10.1109/TAC.2020.3047989, with a single sensor (their Remark 2.1: with the identity adjacency matrix the distributed algorithm is the classical one at each sensor).

    noncomputable def rlsStep (φ : n → ℝ) (y : ℝ) (θP : (n → ℝ) × Matrix n n ℝ) :
    (n → ℝ) × Matrix n n ℝ :=
  (θP.1 + ((y - φ ⬝ᵥ θP.1) / (1 + φ ⬝ᵥ (θP.2 *ᵥ φ))) • (θP.2 *ᵥ φ),
    θP.2 - (1 + φ ⬝ᵥ (θP.2 *ᵥ φ))⁻¹ • (θP.2 * vecMulVec φ φ * θP.2))
    Background

    DefinitionRecursive least-squares estimates#✓fully proved

    MathlibExt.Analysis.Control.RecursiveLeastSquares.rls

    For regressors \(\varphi_k\), observations \(y_{k+1}\), an initial estimate \(\theta_0\) and an initial matrix \(P_0\), rls φ y θ₀ P₀ t = (θ_t, P_t) is obtained by applying one step of recursive least squares with \((\varphi_k, y_{k+1})\) for \(k = 0, \dots, t - 1\). The observation \(y_{k+1}\) follows the regressor \(\varphi_k\), as in the model \(y_{k+1} = \varphi_k^\top \theta + w_{k+1}\), so \(\theta_t\) uses the data \((\varphi_k, y_{k+1})_{k < t}\).

    noncomputable def rls (φ : ℕ → n → ℝ) (y : ℕ → ℝ) (θ₀ : n → ℝ) (P₀ : Matrix n n ℝ) :
    ℕ → (n → ℝ) × Matrix n n ℝ
  | 0 => (θ₀, P₀)
  | t + 1 => rlsStep (φ t) (y (t + 1)) (rls φ y θ₀ P₀ t)

    MathlibExt.Analysis.Control.RecursiveLeastSquares.rlsInformation

    The matrix \(P_0^{-1} + \sum_{k<t} \varphi_k \varphi_k^\top\). For positive definite \(P_0\) it is the inverse of the RLS matrix \(P_t\) (the RLS matrix is the inverse of the information matrix); its smallest eigenvalue measures how much the data excite all directions of the parameter.

  P₀⁻¹ + ∑ k ∈ Finset.range t, vecMulVec (φ k) (φ k)

    Recursive least squares is batch least squares

    TheoremThe RLS matrix is the inverse of the information matrix#✓fully proved

    MathlibExt.Analysis.Control.RecursiveLeastSquares.rls_snd_eq_inv

    For positive definite \(P_0\), every regressor sequence \(\varphi\) and every \(t\), $\(P_t = \Big(P_0^{-1} + \sum_{k<t} \varphi_k \varphi_k^\top\Big)^{-1}.\)$ The update \(P_{k+1} = P_k - P_k \varphi_k \varphi_k^\top P_k / (1 + \varphi_k^\top P_k \varphi_k)\) is the Sherman–Morrison form of \(P_{k+1}^{-1} = P_k^{-1} + \varphi_k \varphi_k^\top\) (the matrix inversion lemma), the information form in which Liu (arXiv:2609.11831v3, equation (2.2)) writes the recursion. The proof checks \((R + \varphi \varphi^\top) P' = I\) directly from \(R P = I\), using \(\varphi^\top P \varphi \ge 0\); Mathlib's general Woodbury identity is Matrix.add_mul_mul_inv_eq_sub.

    theorem rls_snd_eq_inv {P₀ : Matrix n n ℝ} (hP₀ : P₀.PosDef) (φ : ℕ → n → ℝ) (y : ℕ → ℝ)
    (θ₀ : n → ℝ) (t : ℕ) : (rls φ y θ₀ P₀ t).2 = (rlsInformation P₀ φ t)⁻¹
    noncomputable def rls (φ : ℕ → n → ℝ) (y : ℕ → ℝ) (θ₀ : n → ℝ) (P₀ : Matrix n n ℝ) :

  | 0 => (θ₀, P₀)

    TheoremRLS solves the regularised normal equations#✓fully proved

    MathlibExt.Analysis.Control.RecursiveLeastSquares.rlsInformation_mulVec_rls_fst

    For positive definite \(P_0\), the RLS estimate satisfies $\(\Big(P_0^{-1} + \sum_{k<t} \varphi_k \varphi_k^\top\Big) \theta_t = P_0^{-1} \theta_0 + \sum_{k<t} y_{k+1} \varphi_k,\)$ the normal equations of the batch problem of minimising \((\theta - \theta_0)^\top P_0^{-1} (\theta - \theta_0) + \sum_{k<t} (y_{k+1} - \varphi_k^\top \theta)^2\).

    theorem rlsInformation_mulVec_rls_fst {P₀ : Matrix n n ℝ} (hP₀ : P₀.PosDef) (φ : ℕ → n → ℝ)
    (y : ℕ → ℝ) (θ₀ : n → ℝ) (t : ℕ) :
    rlsInformation P₀ φ t *ᵥ (rls φ y θ₀ P₀ t).1 =
      P₀⁻¹ *ᵥ θ₀ + ∑ k ∈ Finset.range t, y (k + 1) • φ k

    TheoremRecursive least squares equals batch regularised least squares#✓fully proved

    MathlibExt.Analysis.Control.RecursiveLeastSquares.rls_fst_eq

    For positive definite \(P_0\), $\(\theta_t = \Big(P_0^{-1} + \sum_{k<t} \varphi_k \varphi_k^\top\Big)^{-1} \Big(P_0^{-1} \theta_0 + \sum_{k<t} y_{k+1} \varphi_k\Big),\)$ the unique solution of the normal equations of RLS solves the regularised normal equations: the recursion computes, with one rank-one update per observation, the batch regularised least-squares estimate.

    TheoremLogarithmic bound on the accumulated RLS gains#✓fully proved

    MathlibExt.Analysis.Control.RecursiveLeastSquares.sum_rls_gain_le_log_det

    For positive definite \(P_0\), with \(P_k\) the RLS matrix, $\(\sum_{k<t} \frac{\varphi_k^\top P_k \varphi_k}{1 + \varphi_k^\top P_k \varphi_k} \le \log \det\Big(P_0^{-1} + \sum_{k<t} \varphi_k \varphi_k^\top\Big) - \log \det P_0^{-1}.\)$ No assumption is made on the regressors. Since \(\log \det (P_0^{-1} + \sum_{k<t} \varphi_k \varphi_k^\top) \le d \log \lambda_{\max}\), the accumulated gains grow at most logarithmically in the size of the data; this is the deterministic inequality behind the \(O(\log r_t)\) terms of the stochastic theory.

    Source: the single-sensor case of inequality (33) of Xie, Zhang and Guo, Convergence of a distributed least squares, IEEE Trans. Automat. Control, accepted version (2020), DOI 10.1109/TAC.2020.3047989, whose proof follows Lai and Wei (Ann. Statist. 10 (1982)).

    theorem sum_rls_gain_le_log_det {P₀ : Matrix n n ℝ} (hP₀ : P₀.PosDef) (φ : ℕ → n → ℝ)
    (y : ℕ → ℝ) (θ₀ : n → ℝ) (t : ℕ) :
    ∑ k ∈ Finset.range t, φ k ⬝ᵥ ((rls φ y θ₀ P₀ k).2 *ᵥ φ k) /
        (1 + φ k ⬝ᵥ ((rls φ y θ₀ P₀ k).2 *ᵥ φ k)) ≤
      Real.log (rlsInformation P₀ φ t).det - Real.log P₀⁻¹.det
    noncomputable def rls (φ : ℕ → n → ℝ) (y : ℕ → ℝ) (θ₀ : n → ℝ) (P₀ : Matrix n n ℝ) :

  | 0 => (θ₀, P₀)

    TheoremError identity of noise-free RLS#✓fully proved

    MathlibExt.Analysis.Control.RecursiveLeastSquares.rlsInformation_mulVec_error_of_noiseFree

    If \(y_{k+1} = \varphi_k^\top \theta\) for every \(k < t\) and \(P_0\) is positive definite, then $\(\Big(P_0^{-1} + \sum_{k<t} \varphi_k \varphi_k^\top\Big)(\theta_t - \theta) = P_0^{-1} (\theta_0 - \theta).\)$ This is the noise-free case of the error recursion (9) of Xie, Zhang and Guo, Convergence of a distributed least squares, IEEE Trans.
