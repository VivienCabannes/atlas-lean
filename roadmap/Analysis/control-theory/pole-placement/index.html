    Pole placement

    For a controllable linear system \(\dot x = A x + B u\), a linear state feedback \(u = K x\) can give the closed-loop matrix \(A + BK\) any prescribed characteristic polynomial: this is the pole-shifting theorem of Wonham (1967) (Coron, Control and Nonlinearity, AMS 2007, Theorem 10.1; Sontag, Mathematical Control Theory, 2nd ed., 1998, Theorem 13, which also gives the converse). Choosing the closed-loop eigenvalues in the open left half-plane makes \(0\) globally asymptotically stable for \(\dot x = (A + BK) x\), so every controllable linear system is stabilisable by linear feedback, and by the linearisation principle every nonlinear system whose linearisation at an equilibrium is controllable is locally stabilisable (Coron, Section 10.2).

    Coron proves the single-input case through the controller (companion) form of \((A, b)\) (Lemma 10.2) and reduces several inputs to one with Heymann's lemma (Lemma 10.3, in Hautus's proof). Here the theorem is proved over an arbitrary field. The single-input case uses Ackermann's formula \(K = -q \, P(A)\), where \(q\) is the linear form equal to \(1\) on \(A^{n-1} b\) and to \(0\) on \(b, \dots, A^{n-2} b\), instead of the controller form; Heymann's lemma follows Coron's proof. The stabilisation of controllable linear systems by linear feedback (Coron, Corollary 10.12) follows, with the exponential decay of Hurwitz semigroups proved under Lyapunov's indirect method. Uniqueness of the feedback for one input (Coron, Remark 10.5), the converse (Sontag, Theorem 13) and the local stabilisation of nonlinear systems with controllable linearisation (Coron, Theorem 10.14) are not formalized.

    MathlibExt.Analysis.Control.exists_charpoly_add_smulRight_eq

    Let \(V\) be an \(n\)-dimensional vector space over a field, \(A : V \to V\) linear and \(b \in V\) such that \(b, A b, \dots, A^{n-1} b\) span \(V\) (the Kalman rank condition for the single-input system \(\dot x = A x + b u\)). Then for every monic polynomial \(P\) of degree \(n\) there is a linear form \(K\) on \(V\) such that the closed-loop operator \(A + bK : x \mapsto A x + K(x) \, b\) has characteristic polynomial \(P\).

    This is the single-input case (\(m = 1\)) of the pole-shifting theorem (Wonham 1967; Coron, Control and Nonlinearity, AMS 2007, Theorem 10.1 over \(\mathbb{R}\); Sontag, Mathematical Control Theory, 2nd ed., 1998, Theorem 13, over any field). By Coron's Remark 10.5 the feedback is unique when \(m = 1\); uniqueness is not formalized. The proof differs from Coron's, which passes through the controller form (Lemma 10.2): with \(q\) the coordinate form dual to \(A^{n-1} b\) in the basis \(b, \dots, A^{n-1} b\) and \(K = -q \circ P(A)\) (Ackermann's formula), one checks \(q \circ (A + bK)^j = q \circ A^j\) for \(j < n\) and \(q \circ P(A + bK) = 0\); the forms \(q \circ A^j\), \(j < n\), separate points, so \(P(A + bK) = 0\); and \(b\) is still a cyclic vector of \(A + bK\), so no nonzero polynomial of degree \(< n\) annihilates \(A + bK\) and \(P\) is its characteristic polynomial (Cayley–Hamilton). A test assigns \((X + 1)^2\) to the double integrator over \(\mathbb{Q}\).

    theorem exists_charpoly_add_smulRight_eq [FiniteDimensional 𝕜 V] (A : Module.End 𝕜 V) (b : V)
    (hb : Submodule.span 𝕜 (Set.range fun i : Fin (finrank 𝕜 V) => (A ^ (i : ℕ)) b) = ⊤)
    (P : 𝕜[X]) (hP : P.Monic) (hdeg : P.natDegree = finrank 𝕜 V) :
    ∃ K : Module.Dual 𝕜 V, (A + K.smulRight b).charpoly = P

    TheoremHeymann's lemma#✓fully proved

    MathlibExt.Analysis.Control.exists_span_pow_add_comp_eq_top

    Let \(V\) be an \(n\)-dimensional vector space over a field, \(U\) a vector space, and \(A : V \to V\), \(B : U \to V\) linear maps satisfying the Kalman rank condition \(\operatorname{Span} \{ A^i B u : u \in U, \ 0 \le i < n \} = V\). Then there are \(f \in U\) and a linear map \(C : V \to U\) such that \(B f, (A + BC) B f, \dots, (A + BC)^{n-1} B f\) span \(V\): the single-input system \(\dot x = (A + BC) x + (Bf) v\) satisfies the Kalman rank condition.

    This is Heymann's lemma (Heymann 1968), as stated in Coron, Control and Nonlinearity (AMS 2007), Lemma 10.3, whose proof follows Hautus. The proof formalized is Coron's: take \(f\) with \(Bf \ne 0\), build a longest linearly independent chain \(x_1 = Bf, x_2, \dots, x_k\) with \(x_{j+1} \in A x_j + B U\); maximality gives \(A x_k + BU \subseteq E = \operatorname{Span}\{x_1, \dots, x_k\}\), hence \(BU \subseteq E\) and \(AE \subseteq E\), so \(E\) contains the Kalman subspace and \(k = n\); then \(C x_j = u_j\), where \(x_{j+1} = A x_j + B u_j\), gives \((A + BC)^{j} x_1 = x_{j+1}\).

    theorem exists_span_pow_add_comp_eq_top [FiniteDimensional 𝕜 V] {U : Type*} [AddCommGroup U]
    [Module 𝕜 U] (A : Module.End 𝕜 V) (B : U →ₗ[𝕜] V)
    (hK : Submodule.span 𝕜 {x | ∃ i < finrank 𝕜 V, ∃ u : U, x = (A ^ i) (B u)} = ⊤) :
    ∃ (f : U) (C : V →ₗ[𝕜] U), Submodule.span 𝕜
      (Set.range fun i : Fin (finrank 𝕜 V) => ((A + B ∘ₗ C) ^ (i : ℕ)) (B f)) = ⊤
    Background
    Background

    TheoremPole-shifting theorem#✓fully proved

    MathlibExt.Analysis.Control.exists_charpoly_add_comp_eq

    Let \(V\) be an \(n\)-dimensional vector space over a field, \(U\) a vector space, and \(A : V \to V\), \(B : U \to V\) linear maps with \(\operatorname{Span} \{ A^i B u : u \in U, \ 0 \le i < n \} = V\) (the Kalman rank condition). Then for every monic polynomial \(P\) of degree \(n\) there is a linear map \(K : V \to U\) such that \(A + B K\) has characteristic polynomial \(P\).

    This is the pole-shifting theorem of Wonham (1967), as stated in Coron, Control and Nonlinearity (AMS 2007), Theorem 10.1 (over \(\mathbb{R}\), for controllable systems, which by Theorem 1.16 are those satisfying the rank condition), and in Sontag, Mathematical Control Theory (2nd ed., 1998), Theorem 13 (over any field; this is the direction "controllable ⇒ every monic polynomial of degree \(n\) is assignable" of its last sentence). The proof is Coron's: Heymann's lemma gives \(f \in U\) and \(C : V \to U\) such that the single-input system \(\dot x = (A + BC) x + (Bf) v\) satisfies the rank condition; single-input pole placement gives a linear form \(K_1\) with \(\chi_{A + BC + (Bf) K_1} = P\), and \(K = C + f K_1\). A test assigns \(X^2 + 1\) to the fully actuated system \(\dot x = u\) on \(\mathbb{Q}^2\).

    theorem exists_charpoly_add_comp_eq [FiniteDimensional 𝕜 V] {U : Type*} [AddCommGroup U]
    [Module 𝕜 U] (A : Module.End 𝕜 V) (B : U →ₗ[𝕜] V)
    (hK : Submodule.span 𝕜 {x | ∃ i < finrank 𝕜 V, ∃ u : U, x = (A ^ i) (B u)} = ⊤)
    (P : 𝕜[X]) (hP : P.Monic) (hdeg : P.natDegree = finrank 𝕜 V) :
    ∃ K : V →ₗ[𝕜] U, (A + B ∘ₗ K).charpoly = P

    TheoremControllable linear systems have a Hurwitz closed loop#✓fully proved

    MathlibExt.Analysis.Control.exists_isHurwitz_add_mul

    Let \(A \in \mathbb{R}^{n \times n}\) and \(B \in \mathbb{R}^{n \times m}\) satisfy the Kalman rank condition \(\operatorname{Span} \{ A^i B u : u \in \mathbb{R}^m, \ 0 \le i < n \} = \mathbb{R}^n\). Then there is \(K \in \mathbb{R}^{m \times n}\) such that \(A + BK\) has characteristic polynomial \((X + 1)^n\); in particular every complex eigenvalue of \(A + BK\) equals \(-1\), so \(A + BK\) is Hurwitz.

    This is the first step of Coron, Control and Nonlinearity (AMS 2007), Corollary 10.12, which Coron derives from the pole-shifting theorem and Theorem 10.9. A test stabilises the unstable scalar system \(\dot x = x + u\).

    theorem exists_isHurwitz_add_mul (A : Matrix (Fin n) (Fin n) ℝ) (B : Matrix (Fin n) (Fin m) ℝ)
    (hK : Submodule.span ℝ {x | ∃ i < n, ∃ u : Fin m → ℝ, x = (A ^ i * B) *ᵥ u} = ⊤) :
    ∃ K : Matrix (Fin m) (Fin n) ℝ, (A + B * K).charpoly = (X + 1) ^ n ∧
      (A + B * K).IsHurwitz

    TheoremExponential stabilisation of controllable linear systems#✓fully proved

    MathlibExt.Analysis.Control.exists_norm_exp_add_mul_le

    Let \(A \in \mathbb{R}^{n \times n}\) and \(B \in \mathbb{R}^{n \times m}\) satisfy the Kalman rank condition. Then there are \(K \in \mathbb{R}^{m \times n}\) and constants \(M, \alpha > 0\) with \(\lVert e^{t (A + BK)} v \rVert \le M e^{-\alpha t} \lVert v \rVert\) for all \(t \ge 0\) and \(v \in \mathbb{R}^n\) (sup norm). Hence every solution of the closed-loop system \(\dot x = (A + BK) x\) decays exponentially, and \(0\) is globally asymptotically stable for it.

    This is Coron, Control and Nonlinearity (AMS 2007), Corollary 10.12 (stated there as global asymptotic stability of the closed loop; the exponential bound is the form proved here). Equivalently, every controllable linear system is globally asymptotically stabilisable by continuous stationary feedback laws.

    theorem exists_norm_exp_add_mul_le (A : Matrix (Fin n) (Fin n) ℝ) (B : Matrix (Fin n) (Fin m) ℝ)
    (hK : Submodule.span ℝ {x | ∃ i < n, ∃ u : Fin m → ℝ, x = (A ^ i * B) *ᵥ u} = ⊤) :
    ∃ K : Matrix (Fin m) (Fin n) ℝ, ∃ M α : ℝ, 0 < M ∧ 0 < α ∧ ∀ t : ℝ, 0 ≤ t →
      ∀ v : Fin n → ℝ, ‖NormedSpace.exp (t • (A + B * K)) *ᵥ v‖ ≤
        M * Real.exp (-(α * t)) * ‖v‖

    Related topics

    • Controllability of linear systems: the Kalman rank condition is the hypothesis of pole placement.
    • Lyapunov's indirect method: a matrix with all eigenvalues in the open left half-plane generates an exponentially stable flow, and stability of the linearisation gives local stability of a nonlinear equilibrium.
    • Linear quadratic regulator: the other classical way to compute a stabilising linear feedback, by optimising a quadratic cost through the Riccati equation.
