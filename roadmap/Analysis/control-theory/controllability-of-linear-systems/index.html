    Controllability of linear systems

    A linear control system \(\dot x = A x + B u\), with state \(x(t) \in \mathbb{R}^n\) and control \(u(t) \in \mathbb{R}^m\), is controllable on \([0, T]\) if every state can be steered to every other state in time \(T\). Kalman, Ho and Narendra (1963) characterised this in two ways, which are the first theorems of Coron's Control and Nonlinearity (AMS 2007, Chapter 1) and of Sontag's Mathematical Control Theory (2nd ed., 1998, Chapter 3). The integral criterion: the system is controllable if and only if the controllability Gramian \(W_T = \int_0^T e^{sA} B B^\top e^{sA^\top} \, ds\) is invertible, and then the control \(u(t) = B^\top e^{(T-t)A^\top} W_T^{-1} (x_1 - e^{TA} x_0)\) steers \(x_0\) to \(x_1\). The algebraic criterion: the system is controllable if and only if the Kalman rank condition \(\operatorname{rank} [B, AB, \dots, A^{n-1}B] = n\) holds; in particular controllability does not depend on \(T > 0\). The Hautus test restates the rank condition through eigenvectors: no complex left eigenvector of \(A\) is annihilated by \(B\), that is, \(\operatorname{rank} [\lambda I - A, B] = n\) for every \(\lambda \in \mathbb{C}\).

    Here all three criteria are proved for time-invariant systems on finite-dimensional real inner product spaces, with continuous controls (Coron uses \(L^\infty\) controls; the notions agree, since an \(L^\infty\)-controllable system has an invertible Gramian by Coron's Theorem 1.11 and the Gramian criterion proved here then gives continuous controls, compare Coron's Remark 1.3, which treats \(L^2\) and \(L^1\)). The Hautus test is proved for systems given by real matrices. Time-varying systems, observability and the duality between controllability and observability (the Hilbert Uniqueness Method of J.-L. Lions, Coron Section 1.4) are not formalized.

    MathlibExt.Analysis.Control.IsControllableOn

    Let \(E\) and \(U\) be finite-dimensional real inner product spaces, \(A : E \to E\) and \(B : U \to E\) linear maps, and \(T \in \mathbb{R}\). The system \(\dot x = A x + B u\) is controllable on \([0, T]\) if for all \(x_0, x_1 \in E\) there are a continuous control \(u : \mathbb{R} \to U\) and a solution \(x : \mathbb{R} \to E\) of \(\dot x(t) = A x(t) + B u(t)\) with \(x(0) = x_0\) and \(x(T) = x_1\).

    This is Coron, Control and Nonlinearity (AMS 2007), Definition 1.2, on the interval \([T_0, T_1] = [0, T]\) for a time-invariant system, with continuous controls instead of \(L^\infty\) controls. The two notions agree for \(T > 0\): if the system is controllable with \(L^\infty\) controls, its Gramian is invertible by Coron's Theorem 1.11, and the Gramian criterion proved here then gives continuous steering controls; conversely, continuous controls on \([0, T]\) are \(L^\infty\) (compare Coron's Remark 1.3, which treats \(L^2\) and \(L^1\) controls). The criteria below assume \(T > 0\): at \(T = 0\) a system with nonzero state space is never controllable, as a test checks.

    def IsControllableOn (A : E →L[ℝ] E) (B : U →L[ℝ] E) (T : ℝ) : Prop :=
  ∀ x₀ x₁ : E, ∃ u : ℝ → U, Continuous u ∧ ∃ x : ℝ → E, x 0 = x₀ ∧
    (∀ t, HasDerivAt x (A (x t) + B (u t)) t) ∧ x T = x₁

    MathlibExt.Analysis.Control.gramian

    For \(\dot x = A x + B u\) on finite-dimensional real inner product spaces \(E\) (state) and \(U\) (control) and \(T \in \mathbb{R}\), the controllability Gramian is the operator $\(W_T = \int_0^T e^{sA} B B^* e^{sA^*} \, ds : E \to E,\)$ where \(B^*\) and \(e^{sA^*} = (e^{sA})^*\) are adjoints. It is symmetric, and positive semidefinite for \(T \ge 0\).

    This is Coron, Control and Nonlinearity (AMS 2007), Definition 1.10, \(C = \int_{T_0}^{T_1} R(T_1, \tau) B B^\top R(T_1, \tau)^\top \, d\tau\), for a time-invariant system, where the resolvent is \(R(T_1, \tau) = e^{(T_1 - \tau) A}\), after the change of variables \(s = T_1 - \tau\) and with \([T_0, T_1] = [0, T]\). Sontag (Mathematical Control Theory, 2nd ed., Section 3.5) uses the same matrix.

    TheoremGramian criterion for controllability#✓fully proved

    MathlibExt.Analysis.Control.isControllableOn_iff_bijective_gramian

    Let \(T > 0\). The system \(\dot x = A x + B u\) on finite-dimensional real inner product spaces is controllable on \([0, T]\) if and only if its controllability Gramian \(W_T\) is invertible.

    This is Coron, Control and Nonlinearity (AMS 2007), Theorem 1.11, which Coron attributes to Kalman, Ho and Narendra (1963, Theorem 5), here for time-invariant systems (Coron treats time-varying systems \(\dot x = A(t) x + B(t) u\)). If \(W_T\) is invertible, the control \(u(t) = B^* e^{(T - t)A^*} W_T^{-1} (x_1 - e^{TA} x_0)\) steers \(x_0\) to \(x_1\) (Coron (1.18)); it is continuous. If \(W_T \eta = 0\) with \(\eta \ne 0\), the quadratic form shows \(B^* e^{sA^*} \eta = 0\) on \([0, T]\), so \(\eta\) is orthogonal to the endpoint \(\int_0^T e^{(T-s)A} B u(s) \, ds\) of every trajectory from \(0\), and \(\eta\) cannot be reached.

    theorem isControllableOn_iff_bijective_gramian (A : E →L[ℝ] E) (B : U →L[ℝ] E) {T : ℝ}
    (hT : 0 < T) : IsControllableOn A B T ↔ Function.Bijective (gramian A B T)

    DefinitionKalman subspace#✓fully proved

    MathlibExt.Analysis.Control.kalmanSubspace

    For linear maps \(A : E \to E\) and \(B : U \to E\), the Kalman subspace is $\(\operatorname{Span} \{ A^i B u : u \in U, \ 0 \le i < \dim E \},\)$ the column space of the Kalman matrix \([B, AB, \dots, A^{n-1} B]\), \(n = \dim E\). The Kalman rank condition says that it is all of \(E\) (Coron, Control and Nonlinearity, AMS 2007, Theorem 1.16, condition (1.29); Sontag, Mathematical Control Theory, 2nd ed., the reachability matrix \(R(A, B)\) of Theorem 3).

    def kalmanSubspace (A : E →L[ℝ] E) (B : U →L[ℝ] E) : Submodule ℝ E :=
  Submodule.span ℝ {x | ∃ i < Module.finrank ℝ E, ∃ u : U, x = (A ^ i) (B u)}

    TheoremKalman rank condition, dual form#✓fully proved

    MathlibExt.Analysis.Control.kalmanSubspace_eq_top_iff

    The Kalman subspace of \((A, B)\) is all of \(E\) if and only if the only vector \(\eta \in E\) orthogonal to \(A^k B v\) for every \(k \in \mathbb{N}\) and every \(v \in U\) is \(\eta = 0\). Powers \(k \ge \dim E\) add nothing to the Kalman subspace, by the Cayley–Hamilton theorem.

    theorem kalmanSubspace_eq_top_iff (A : E →L[ℝ] E) (B : U →L[ℝ] E) :
    kalmanSubspace A B = ⊤ ↔ ∀ η : E, (∀ (k : ℕ) (v : U), ⟪η, (A ^ k) (B v)⟫ = 0) → η = 0

    TheoremKalman rank condition#✓fully proved

    MathlibExt.Analysis.Control.isControllableOn_iff_kalman

    Let \(T > 0\). The system \(\dot x = A x + B u\) on finite-dimensional real inner product spaces \(E\), \(U\) is controllable on \([0, T]\) if and only if $\(\operatorname{Span} \{ A^i B u : u \in U, \ 0 \le i < \dim E \} = E,\)$ that is, \(\operatorname{rank} [B, AB, \dots, A^{n-1} B] = n\) with \(n = \dim E\). In particular, controllability on \([0, T]\) does not depend on \(T > 0\).

    This is Coron, Control and Nonlinearity (AMS 2007), Theorem 1.16, which Coron attributes to Kalman, Ho and Narendra (1963, Theorem 10), and Sontag, Mathematical Control Theory (2nd ed., 1998), Theorem 3. The proof follows Coron's: if \(W_T \eta = 0\), the function \(s \mapsto \langle \eta, e^{sA} B v \rangle\) vanishes on \([0, T]\), so do all its derivatives \(\langle \eta, e^{sA} A^k B v \rangle\), and at \(s = 0\) this gives \(\eta \perp A^k B v\); conversely, a vector orthogonal to the Kalman subspace is orthogonal to every \(A^k B v\) by Cayley–Hamilton, hence to every \(e^{sA} B v\) by the exponential series, and lies in the kernel of \(W_T\).

    TheoremKalman condition and Hautus test for real matrices#✓fully proved

    MathlibExt.Analysis.Control.kalman_matrix_iff_hautus

    Let \(A \in \mathbb{R}^{n \times n}\) and \(B \in \mathbb{R}^{n \times m}\). The following are equivalent:

    1. the only real row vector \(\eta\) with \(\eta A^k B = 0\) for all \(k \in \mathbb{N}\) is \(\eta = 0\);
    2. for every \(\lambda \in \mathbb{C}\), the only complex row vector \(w\) with \(w A = \lambda w\) and \(w B = 0\) is \(w = 0\).

    Condition 1 is the Kalman rank condition \(\operatorname{rank} [B, AB, \dots, A^{n-1} B] = n\) (by Cayley–Hamilton). Condition 2 says that the rows of \([\lambda I - A, B]\) are linearly independent over \(\mathbb{C}\), that is, \(\operatorname{rank} [\lambda I - A, B] = n\) for every \(\lambda \in \mathbb{C}\). This is the equivalence (a) ⇔ (b) of Sontag, Mathematical Control Theory (2nd ed., 1998), Lemma 3.3.7 (the Hautus Lemma), stated here in left-eigenvector form; Sontag's (c), the same rank condition for eigenvalues \(\lambda\) of \(A\) only, is equivalent because \(\lambda I - A\) is invertible otherwise. The proof of 2 ⇒ 1 restricts \(w \mapsto w A\) to the complex subspace of row vectors annihilating every \(A^k B\), which is invariant and nonzero when 1 fails, and takes an eigenvector there.

    theorem kalman_matrix_iff_hautus (A : Matrix (Fin n) (Fin n) ℝ) (B : Matrix (Fin n) (Fin m) ℝ) :
    (∀ η : Fin n → ℝ, (∀ k : ℕ, η ᵥ* (A ^ k * B) = 0) → η = 0) ↔
      ∀ (μ : ℂ) (w : Fin n → ℂ), w ᵥ* A.map (↑) = μ • w → w ᵥ* B.map (↑) = 0 → w = 0

    MathlibExt.Analysis.Control.isControllableOn_iff_hautus

    Let \(A \in \mathbb{R}^{n \times n}\), \(B \in \mathbb{R}^{n \times m}\) and \(T > 0\). The system \(\dot x = A x + B u\) on \(\mathbb{R}^n\) (with the Euclidean inner product) is controllable on \([0, T]\) if and only if for every \(\lambda \in \mathbb{C}\) no nonzero complex row vector \(w\) satisfies \(w A = \lambda w\) and \(w B = 0\); equivalently, \(\operatorname{rank} [\lambda I - A, B] = n\) for every \(\lambda \in \mathbb{C}\).

    Related topics

    • Pole placement: controllability is exactly what allows a linear state feedback to place the closed-loop eigenvalues anywhere.
    • Nonlinear controllability and stabilisation: the Kalman condition is the linear test for small-time local controllability of nonlinear systems, and the Lie algebra rank condition is its nonlinear analogue.
    • Duhamel's formula: the variation of constants formula that expresses the endpoint of a trajectory in terms of the control.
    • Linear systems and fundamental matrices: the resolvent \(R(t, \tau)\) of a time-varying system, which replaces \(e^{(t - \tau) A}\) in Coron's Gramian for time-varying systems.
    • Linear quadratic regulator: the Gramian is the matrix of the minimum-energy control problem, the simplest linear-quadratic optimal control problem.
    • Kalman filter: the estimation problem dual to control; its observability condition is the Kalman rank condition for the transposed pair.
