    NonnegativeDiscreteSpectrum

    A nonnegative discrete spectrum is a sequence of real numbers \(E_0, E_1, E_2, \ldots\), the eigenvalues listed with multiplicity, such that \(E_j \ge 0\) for every \(j\), \(E_i \le E_j\) whenever \(i \le j\), and \(E_j \to +\infty\) as \(j \to \infty\).

    The sequence is not required to be the spectrum of any particular operator, such as a Dirichlet or Neumann Laplacian.

    DefinitionRayleigh quotient#✓fully proved

    DirichletLaplacian.rayleighQuotient

    For a smooth test function \(f\) on an open set \(\Omega \subseteq \mathbb{R}^n\), the Rayleigh quotient of \(f\) is

    \[R(f) = \frac{\int_{\mathbb{R}^n} \|Df(x)\|^2 \, dx}{\int_{\mathbb{R}^n} |f(x)|^2 \, dx},\]

    where \(\|Df(x)\|\) is the operator norm of the derivative of \(f\) at \(x\) (equal to \(|\nabla f(x)|\)) and both integrals are against Lebesgue measure. For \(f = 0\) the quotient \(0/0\) is read as \(0\).

    noncomputable def rayleighQuotient {n : ℕ} {Ω : Opens (EuclideanSpace ℝ (Fin n))}
    (f : SmoothTestSpace Ω) : ℝ :=
  (∫ x, ‖fderiv ℝ (f : EuclideanSpace ℝ (Fin n) → ℝ) x‖ ^ 2 ∂volume) /
    (∫ x, |f x| ^ 2 ∂volume)

    DefinitionVariational eigenvalue#✓fully proved

    DirichletLaplacian.variationalEigenvalue

    For an open set \(\Omega \subseteq \mathbb{R}^n\) and an index \(j \ge 0\), the variational eigenvalue of \(\Omega\) at index \(j\) is the Courant–Fischer min–max value

    \[\lambda_j(\Omega) = \inf_V \, \sup_{f \in V,\ f \ne 0} R(f),\]

    where \(V\) ranges over the \((j+1)\)-dimensional subspaces of the space of smooth test functions on \(\Omega\) and \(R(f)\) is the Rayleigh quotient of \(f\). Infima and suprema are taken in \(\mathbb{R}\), where an empty set, or a set unbounded in the relevant direction, has value \(0\).

    This is a definition only: it does not claim that the values are attained, nonnegative, monotone in \(j\), divergent, or eigenvalues of an operator.

    noncomputable def variationalEigenvalue {n : ℕ}
    (Ω : Opens (EuclideanSpace ℝ (Fin n))) (j : ℕ) : ℝ :=
  sInf {a : ℝ | ∃ V : Submodule ℝ (SmoothTestSpace Ω),
    Module.finrank ℝ ↥V = j + 1 ∧
      a = sSup {q : ℝ | ∃ f : ↥V,
        (f : SmoothTestSpace Ω) ≠ 0 ∧
          rayleighQuotient (f : SmoothTestSpace Ω) = q}}
    abbrev SmoothTestSpace {n : ℕ} (Ω : Opens (EuclideanSpace ℝ (Fin n))) :=

    EuclideanLaplacian.polyaEigenvalueBenchmark
