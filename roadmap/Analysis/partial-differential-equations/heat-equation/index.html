    Heat equation

    The heat equation \(u_t - \Delta u = 0\) is the model parabolic equation. Its fundamental solution \(\Phi(t, x) = (4 \pi t)^{-n/2} e^{-|x|^2/(4t)}\) is positive, has total mass one and solves the equation for \(t > 0\); convolving it with initial data solves the Cauchy problem on \(\mathbb{R}^n\). On a bounded domain, the weak maximum principle places the maximum of a (sub)solution on the parabolic boundary of the space-time cylinder, which gives uniqueness for the initial-boundary value problem.

    Here the properties of \(\Phi\) in every finite dimension, the weak maximum principle for subsolutions and uniqueness on bounded domains are proved. The one-dimensional Cauchy problem is recorded as wanted.

    DefinitionHeat-kernel solution#✓fully proved

    MathlibExt.Analysis.HeatKernelWanted.Analysis.ODE.heatSolution

    For \(f\colon \mathbb{R} \to \mathbb{R}\), the heat solution \(u(t, x)\) of \(f\) is given for \(t > 0\) by

    \[u(t, x) = (4 \pi t)^{-1/2} \int_{\mathbb{R}} e^{-(x - y)^2/(4t)} f(y) \, dy\]

    and by \(u(t, x) = f(x)\) for \(t \le 0\).

    The integral is the Lebesgue integral, taken to be \(0\) when the integrand is not integrable. The value for \(t \le 0\) only makes \(u\) defined for all real \(t\) and \(x\); the heat equation statement constrains \(u\) only for \(t > 0\).

    noncomputable def heatSolution (f : ℝ → ℝ) (t x : ℝ) : ℝ :=
  if 0 < t then
    (4 * Real.pi * t)⁻¹ ^ ((1 : ℝ) / 2) *
      ∫ y : ℝ, Real.exp (-((x - y) ^ 2) / (4 * t)) * f y
  else
    f x

    MathlibExt.Analysis.HeatKernelWanted.Analysis.ODE.heat_kernel_solves_heat_equation

    Let \(f\colon \mathbb{R} \to \mathbb{R}\) be continuous and bounded, and let \(u(t, x)\) be the heat solution of \(f\). Then for every \(t > 0\) and every \(x \in \mathbb{R}\) there are a function \(u_x\colon \mathbb{R} \to \mathbb{R}\) and a real number \(u_{xx}\) such that \(u(t, \cdot)\) has derivative \(u_x(y)\) at every \(y \in \mathbb{R}\), \(u_x\) has derivative \(u_{xx}\) at \(x\), and \(u(\cdot, x)\) has derivative \(u_{xx}\) at \(t\); that is, \(\partial_t u = \partial_x^2 u\) on \((0, \infty) \times \mathbb{R}\). Moreover, for every \(x \in \mathbb{R}\), \(u(t, x) \to f(x)\) as \(t \to 0\) from above.

    public theorem_wanted heat_kernel_solves_heat_equation
    (f : ℝ → ℝ) (hf_cont : Continuous f) (hf_bdd : ∃ M : ℝ, ∀ x, |f x| ≤ M) :
    -- The PDE on (0, ∞) × ℝ.
    (∀ t : ℝ, 0 < t → ∀ x : ℝ, ∃ ux : ℝ → ℝ, ∃ uxx : ℝ,
        (∀ y : ℝ, HasDerivAt (fun z => heatSolution f t z) (ux y) y) ∧
        HasDerivAt ux uxx x ∧
        HasDerivAt (fun s => heatSolution f s x) uxx t) ∧
    -- Initial condition recovered as a one-sided limit at t = 0.
    (∀ x : ℝ,
        Filter.Tendsto (fun t : ℝ => heatSolution f t x)
          (nhdsWithin (0 : ℝ) (Set.Ioi 0)) (nhds (f x)))
    noncomputable def heatSolution (f : ℝ → ℝ) (t x : ℝ) : ℝ :=
  if 0 < t then
    (4 * Real.pi * t)⁻¹ ^ ((1 : ℝ) / 2) *
      ∫ y : ℝ, Real.exp (-((x - y) ^ 2) / (4 * t)) * f y
  else
    f x

    DefinitionFundamental solution of the heat equation#✓fully proved

    MathlibExt.Analysis.PDE.HeatKernel.heatKernel

    On a real inner product space \(E\) of finite dimension \(n\) (for instance \(\mathbb{R}^n\)), the fundamental solution of the heat equation is

    \[\Phi(t, x) = \frac{1}{(4 \pi t)^{n/2}} \, e^{-\|x\|^2 / (4 t)}, \qquad t > 0,\ x \in E.\]

    The arguments are written in the order \((t, x)\). Only \(t > 0\) is meaningful: the Lean formula is not set to \(0\) for \(t < 0\) as in Schmidt's Definition 4.1, and the results about \(\Phi\) assume \(t > 0\).

    noncomputable def heatKernel (t : ℝ) (x : E) : ℝ :=
  (4 * π * t) ^ (-(Module.finrank ℝ E : ℝ) / 2) * exp (-‖x‖ ^ 2 / (4 * t))

    TheoremLaplacian of the heat kernel#✓fully proved

    MathlibExt.Analysis.PDE.HeatKernel.laplacian_heatKernel

    For \(t > 0\) and \(x \in E\), with \(n = \dim E\),

    \[\Delta_x \Phi(t, x) = \Phi(t, x) \left( \frac{\|x\|^2}{4 t^2} - \frac{n}{2 t} \right),\]

    where \(\Delta_x\) is Mathlib's Laplacian of \(\Phi(t, \cdot)\). Along each vector \(e_i\) of an orthonormal basis the second derivative is \(\Phi(t, x) \big( \langle x, e_i \rangle^2 / (4 t^2) - 1 / (2 t) \big)\), and \(\sum_i \langle x, e_i \rangle^2 = \|x\|^2\).

    theorem laplacian_heatKernel {t : ℝ} (ht : 0 < t) (x : E) :
    Δ (heatKernel E t) x =
      heatKernel E t x * (‖x‖ ^ 2 / (4 * t ^ 2) - Module.finrank ℝ E / (2 * t))
    noncomputable def heatKernel (t : ℝ) (x : E) : ℝ :=
  (4 * π * t) ^ (-(Module.finrank ℝ E : ℝ) / 2) * exp (-‖x‖ ^ 2 / (4 * t))

    DefinitionParabolic boundary of a space-time cylinder#✓fully proved

    MathlibExt.Analysis.PDE.HeatMaximumPrinciple.parabolicBoundary

    For \(U \subseteq E\) and \(T \ge 0\), the parabolic cylinder is \(U_T = (0, T] \times U\) (time first) and its parabolic boundary is

    \[\Gamma_T = \big(\{0\} \times \overline U\big) \cup \big([0, T] \times \partial U\big),\]

    For open \(U\) and \(T > 0\) it is the closure of \(U_T\) minus \(U_T\) itself; it does not contain the points \((T, x)\) with \(x \in U\). For \(T = 0\) the cylinder is empty and \(\Gamma_0 = \{0\} \times \overline U\), the initial time slice, which is what the weak maximum principle needs in that case.

    def parabolicBoundary (U : Set E) (T : ℝ) : Set (ℝ × E) :=
  ({0} ×ˢ closure U) ∪ (Icc 0 T ×ˢ frontier U)

    TheoremWeak maximum principle for the heat equation#✓fully proved

    MathlibExt.Analysis.PDE.HeatMaximumPrinciple.exists_mem_parabolicBoundary_isMaxOn

    Let \(U\) be a nonempty bounded open subset of a finite-dimensional real inner product space and \(T \ge 0\). Let \(u\) be continuous on \([0, T] \times \overline U\), with \(u(t, \cdot)\) of class \(C^2\) on \(U\) and \(s \mapsto u(s, x)\) left-differentiable with derivative \(u_t(t, x)\), for \(t \in (0, T]\) and \(x \in U\). If \(u_t - \Delta u \le 0\) on \((0, T] \times U\), then \(u\) attains its maximum over \([0, T] \times \overline U\) at a point of the parabolic boundary.

    Schmidt states the principle for solutions of the heat equation; this version holds for subsolutions and needs only one-sided time derivatives, which is what the top face \(t = T\) of the cylinder provides.

    Proof idea. The function \(v = u - \varepsilon t\) satisfies \(v_t - \Delta v \le -\varepsilon\). At a maximum of \(v\) off the parabolic boundary, the Laplacian is nonpositive and the left time derivative is nonnegative, a contradiction.

    theorem exists_mem_parabolicBoundary_isMaxOn {U : Set E} {T : ℝ} (hT : 0 ≤ T)
    (hUb : Bornology.IsBounded U) (hU : IsOpen U) (hne : U.Nonempty)
    {u ut : ℝ → E → ℝ}
    (hc : ContinuousOn (fun p : ℝ × E => u p.1 p.2) (Icc 0 T ×ˢ closure U))
    (hx : ∀ t ∈ Ioc 0 T, ∀ x ∈ U, ContDiffAt ℝ 2 (u t) x)
    (ht : ∀ t ∈ Ioc 0 T, ∀ x ∈ U, HasDerivWithinAt (fun s => u s x) (ut t x) (Iic t) t)
    (hsub : ∀ t ∈ Ioc 0 T, ∀ x ∈ U, ut t x - Δ (u t) x ≤ 0) :
    ∃ p ∈ parabolicBoundary U T,
      IsMaxOn (fun p : ℝ × E => u p.1 p.2) (Icc 0 T ×ˢ closure U) p
    def parabolicBoundary (U : Set E) (T : ℝ) : Set (ℝ × E) :=
  ({0} ×ˢ closure U) ∪ (Icc 0 T ×ˢ frontier U)

    TheoremUniqueness for the heat equation on a bounded domain#✓fully proved

    MathlibExt.Analysis.PDE.HeatMaximumPrinciple.eqOn_of_heat_equation

    Let \(U\) be a bounded open subset of a finite-dimensional real inner product space and \(T \ge 0\). Two functions that are continuous on \([0, T] \times \overline U\), of class \(C^2\) in space and left-differentiable in time on \((0, T] \times U\), solve \(u_t - \Delta u = f\) there and agree on the parabolic boundary agree on all of \([0, T] \times \overline U\).

    theorem eqOn_of_heat_equation {U : Set E} {T : ℝ} (hT : 0 ≤ T)
    (hUb : Bornology.IsBounded U) (hU : IsOpen U)
    {u₁ u₂ ut₁ ut₂ f : ℝ → E → ℝ}
    (hc₁ : ContinuousOn (fun p : ℝ × E => u₁ p.1 p.2) (Icc 0 T ×ˢ closure U))
    (hc₂ : ContinuousOn (fun p : ℝ × E => u₂ p.1 p.2) (Icc 0 T ×ˢ closure U))
    (hx₁ : ∀ t ∈ Ioc 0 T, ∀ x ∈ U, ContDiffAt ℝ 2 (u₁ t) x)
    (hx₂ : ∀ t ∈ Ioc 0 T, ∀ x ∈ U, ContDiffAt ℝ 2 (u₂ t) x)
    (ht₁ : ∀ t ∈ Ioc 0 T, ∀ x ∈ U, HasDerivWithinAt (fun s => u₁ s x) (ut₁ t x) (Iic t) t)
