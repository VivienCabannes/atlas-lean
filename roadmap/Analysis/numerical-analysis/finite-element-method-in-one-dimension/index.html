    MathlibExt.Analysis.ODE.FiniteElement1D.IsClassicalSolution

    u is a classical solution of -u'' = f on (0, 1) with u(0) = u(1) = 0. We ask u to be C² on all of ℝ, which is no loss for the interval problem (a C² function on [0, 1] extends), and f to be continuous.
