    Nonlinear conjugate gradient methods

    Nonlinear conjugate gradient methods extend the linear conjugate gradient method to smooth unconstrained minimisation: \(d_0 = -g_0\) and \(d_{k+1} = -g_{k+1} + \beta_k d_k\), where \(g_k = \nabla f(x_k)\) and the scalar \(\beta_k\) is chosen so that the method reduces to linear conjugate gradients on a strictly convex quadratic with exact line searches. The Fletcher–Reeves, Polak–Ribière–Polyak and Hestenes–Stiefel choices are analysed under the strong Wolfe conditions; the Dai–Yuan choice \(\beta_k = \|g_{k+1}\|^2 / d_k^\top (g_{k+1} - g_k)\) converges globally under the standard Wolfe conditions.

    DefinitionDai–Yuan conjugate gradient parameter#✓fully proved

    MathlibExt.Analysis.Optimization.DaiYuan.daiYuanBeta

    For the gradient \(g\) at the current point, the gradient \(g'\) at the next point and the current search direction \(d\), the Dai–Yuan parameter is $\(\beta^{DY} = \frac{\|g'\|^2}{d^\top (g' - g)} .\)$ It has the numerator of the Fletcher–Reeves formula \(\|g'\|^2 / \|g\|^2\) and the denominator of the Hestenes–Stiefel formula \(g'^\top (g' - g) / d^\top (g' - g)\), and it coincides with the Fletcher–Reeves formula when the line searches are exact. When \(d\) is a descent direction and the Wolfe curvature condition holds with \(\sigma < 1\), \(d^\top (g' - g) > 0\), so the parameter is well defined and positive.

    noncomputable def daiYuanBeta (g g' d : E) : ℝ :=
  ‖g'‖ ^ 2 / ⟪d, g' - g⟫

    TheoremThe Dai–Yuan identity#✓fully proved

    MathlibExt.Analysis.Optimization.DaiYuan.inner_daiYuan_direction

    Let \(g, g', d\) be vectors of a real inner product space with \(d^\top (g' - g) \ne 0\), and let \(d' = -g' + \beta d\) with the Dai–Yuan parameter \(\beta = \|g'\|^2 / d^\top (g' - g)\). Then $\(g'^\top d' = \beta\, g^\top d .\)$ Equivalently \(\beta = g'^\top d' / g^\top d\). The identity propagates the sign of the directional derivative from one search direction to the next, and the source calls it "very important in our convergence analysis".

    Proof: \(g'^\top d' = -\|g'\|^2 + \beta\, g'^\top d\) and \(\beta\, g^\top d = \beta\, g'^\top d - \beta\, d^\top (g' - g) = \beta\, g'^\top d - \|g'\|^2\).

    theorem inner_daiYuan_direction {g g' d : E} (h : ⟪d, g' - g⟫ ≠ 0) :
    ⟪g', -g' + daiYuanBeta g g' d • d⟫ = daiYuanBeta g g' d * ⟪g, d⟫
    noncomputable def daiYuanBeta (g g' d : E) : ℝ :=
  ‖g'‖ ^ 2 / ⟪d, g' - g⟫

    TheoremDescent of the Dai–Yuan direction#✓fully proved

    MathlibExt.Analysis.Optimization.DaiYuan.inner_daiYuan_direction_neg

    Let \(d\) be a descent direction at a point with gradient \(g\) (\(g^\top d < 0\)), and let the gradient \(g' \ne 0\) at the next point satisfy the Wolfe curvature condition \(g'^\top d \ge \sigma\, g^\top d\) with \(\sigma < 1\). Then \(d^\top (g' - g) \ge (\sigma - 1)\, g^\top d > 0\), and the Dai–Yuan direction \(d' = -g' + \beta^{DY} d\) is again a descent direction: \(g'^\top d' < 0\).

    This is the induction step showing that the Dai–Yuan method produces descent directions at every iteration under standard Wolfe line searches, whereas the Fletcher–Reeves method needs strong Wolfe steps with \(\sigma \le 1/2\) for this.

    theorem inner_daiYuan_direction_neg {g g' d : E} {σ : ℝ} (hσ : σ < 1) (hdesc : ⟪g, d⟫ < 0)
    (hcurv : σ * ⟪g, d⟫ ≤ ⟪g', d⟫) (hg' : g' ≠ 0) :
    0 < ⟪d, g' - g⟫ ∧ ⟪g', -g' + daiYuanBeta g g' d • d⟫ < 0
    noncomputable def daiYuanBeta (g g' d : E) : ℝ :=
  ‖g'‖ ^ 2 / ⟪d, g' - g⟫

    TheoremGlobal convergence of the Dai–Yuan method#✓fully proved

    MathlibExt.Analysis.Optimization.DaiYuan.daiYuan_liminf_norm_gradient

    Let \(E\) be a real Hilbert space and \(f : E \to \mathbb{R}\), differentiable at the iterates (the Lean statement needs no such assumption), and write \(g_k = \nabla f(x_k)\). Run \(x_{k+1} = x_k + \alpha_k d_k\) with \(\alpha_k > 0\), \(d_0 = -g_0\) and \(d_{k+1} = -g_{k+1} + \beta_k d_k\) with the Dai–Yuan parameter \(\beta_k = \|g_{k+1}\|^2 / d_k^\top (g_{k+1} - g_k)\), every step length satisfying the standard Wolfe conditions with constants \(\delta > 0\) and \(\sigma < 1\). Suppose \(f(x_k)\) is bounded below, \(\|g_{k+1} - g_k\| \le L \|x_{k+1} - x_k\|\) for some \(L > 0\), and no \(g_k\) vanishes (otherwise the method stops at a stationary point). Then $\(\liminf_{k \to \infty} \|g_k\| = 0 .\)$

    As for the Zoutendijk condition, the source assumes \(f\) bounded below and \(\nabla f\) Lipschitz near the level set (Assumption 3.1); these imply the hypotheses used here. The point of the theorem is that, unlike the Fletcher–Reeves, Polak–Ribière–Polyak and Hestenes–Stiefel methods, no strong Wolfe condition and no sufficient descent condition is needed.

    Proof (the source's): every \(d_k\) is a descent direction. Squaring \(d_{k+1} + g_{k+1} = \beta_k d_k\) and dividing by \((g_{k+1}^\top d_{k+1})^2 = \beta_k^2 (g_k^\top d_k)^2\) gives $\(\frac{\|d_{k+1}\|^2}{(g_{k+1}^\top d_{k+1})^2} \le \frac{\|d_k\|^2}{(g_k^\top d_k)^2} + \frac{1}{\|g_{k+1}\|^2},\)$ so \(\|d_k\|^2 / (g_k^\top d_k)^2 \le \sum_{i \le k} \|g_i\|^{-2}\). If \(\|g_k\| \ge c > 0\) for all \(k\), the terms of the Zoutendijk series are at least \(c^2 / (k + 1)\), and the series diverges.

    theorem daiYuan_liminf_norm_gradient [CompleteSpace E] {f : E → ℝ} {δ σ L : ℝ} (hδ : 0 < δ)
    (hσ : σ < 1) (hL : 0 < L) {x d : ℕ → E} {α : ℕ → ℝ}
    (hx : ∀ k, x (k + 1) = x k + α k • d k) (hα : ∀ k, 0 < α k)
    (hd0 : d 0 = -gradient f (x 0))
    (hd : ∀ k, d (k + 1) =
      -gradient f (x (k + 1)) +
        daiYuanBeta (gradient f (x k)) (gradient f (x (k + 1))) (d k) • d k)
    (hwolfe : ∀ k, WolfeConditions f δ σ (x k) (d k) (α k))
    (hlip : ∀ k, ‖gradient f (x (k + 1)) - gradient f (x k)‖ ≤ L * ‖x (k + 1) - x k‖)
    (hbdd : BddBelow (Set.range fun k => f (x k)))
    (hg : ∀ k, gradient f (x k) ≠ 0) :
    ∀ ε > 0, ∀ N : ℕ, ∃ k ≥ N, ‖gradient f (x k)‖ < ε
    noncomputable def daiYuanBeta (g g' d : E) : ℝ :=
  ‖g'‖ ^ 2 / ⟪d, g' - g⟫

    TheoremGlobal convergence of the Fletcher–Reeves method under strong Wolfe steps#●ready to prove

    WantedExt.Analysis.Optimization.FletcherReevesWanted.fletcherReeves_liminf_norm_gradient

    Let \(f\) be a function on a finite-dimensional real inner product space whose level set \(\{y : f(y) \le f(x_0)\}\) is bounded and which, on an open neighbourhood \(U\) of it, is differentiable with \(L\)-Lipschitz gradient. Run \(x_{k+1} = x_k + \alpha_k d_k\) with \(d_0 = -\nabla f(x_0)\) and $\(d_{k+1} = -\nabla f(x_{k+1}) + \frac{\|\nabla f(x_{k+1})\|^2}{\|\nabla f(x_k)\|^2}\, d_k ,\)$ every step length \(\alpha_k > 0\) satisfying the strong Wolfe conditions with \(0 < \delta < \sigma \le 1/2\). If no gradient vanishes, then \(\liminf_k \|\nabla f(x_k)\| = 0\).

    The bound \(\sigma \le 1/2\) is what makes every Fletcher–Reeves direction a descent direction (Lemma 4.1 of the source, whose proof it refers to Al-Baali). Al-Baali (1985) proved the convergence for \(\sigma < 1/2\); the endpoint \(\sigma = 1/2\) is due to Liu, Han and Yin (1993) and to Dai and Yuan (1996). Compare the Dai–Yuan method, which needs only standard Wolfe steps.

    (hδσ : δ < σ) (hσ : σ ≤ 1 / 2) {x d : ℕ → E} {α : ℕ → ℝ}
    (hlevel : Bornology.IsBounded {y | f y ≤ f (x 0)}) {U : Set E} (hU : IsOpen U)
    (hlevelU : {y | f y ≤ f (x 0)} ⊆ U) (hdiff : DifferentiableOn ℝ f U)
    (hlip : ∀ y ∈ U, ∀ z ∈ U, ‖gradient f y - gradient f z‖ ≤ L * ‖y - z‖)
    (hx : ∀ k, x (k + 1) = x k + α k • d k) (hα : ∀ k, 0 < α k)
    (hd0 : d 0 = -gradient f (x 0))
    (hd : ∀ k, d (k + 1) = -gradient f (x (k + 1)) +
      (‖gradient f (x (k + 1))‖ ^ 2 / ‖gradient f (x k)‖ ^ 2) • d k)
    (hwolfe : ∀ k, StrongWolfeConditions f δ σ (x k) (d k) (α k))
    (hg : ∀ k, gradient f (x k) ≠ 0) :
    ∀ ε > 0, ∀ N : ℕ, ∃ k ≥ N, ‖gradient f (x k)‖ < ε
    def StrongWolfeConditions (f : E → ℝ) (δ σ : ℝ) (x d : E) (α : ℝ) : Prop :=
