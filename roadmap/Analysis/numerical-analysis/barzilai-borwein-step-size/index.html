    Barzilai–Borwein step size

    The two-point step-size gradient method of Barzilai and Borwein iterates \(x_{k+1} = x_k - \alpha_k \nabla f(x_k)\) with \(\alpha_k = s^\top s / s^\top y\) (or \(s^\top y / y^\top y\)), where \(s\) and \(y\) are the latest changes of the iterate and of the gradient: the scalar matrix \(\alpha_k^{-1} I\) is a least-squares fit of the secant equation. The method is nonmonotone, converges globally on strictly convex quadratics (Raydan) and is often much faster than steepest descent with exact line searches.

    DefinitionFirst Barzilai–Borwein step size#✓fully proved

    MathlibExt.Analysis.Optimization.BarzilaiBorwein.bbStep

    For the step \(s = x_k - x_{k-1}\) and the gradient change \(y = \nabla f(x_k) - \nabla f(x_{k-1})\), the first Barzilai–Borwein step size is $\(\alpha = \frac{s^\top s}{s^\top y},\)$ used in the gradient iteration \(x_{k+1} = x_k - \alpha\, \nabla f(x_k)\). It makes \(\alpha^{-1} I\) the best scalar fit of the secant equation \(B s = y\).

    noncomputable def bbStep (s y : E) : ℝ := ‖s‖ ^ 2 / ⟪s, y⟫

    TheoremThe first Barzilai–Borwein step is a least-squares secant fit#✓fully proved

    MathlibExt.Analysis.Optimization.BarzilaiBorwein.norm_inv_bbStep_smul_sub_le

    For all vectors \(s, y\) and every real \(t\), $\(\Bigl\| \frac{s^\top y}{s^\top s}\, s - y \Bigr\| \le \| t s - y \|,\)$ where \(s^\top y / s^\top s = \alpha^{-1}\) is the inverse of the first Barzilai–Borwein step: among scalar matrices, \(\alpha^{-1} I\) best satisfies the secant equation \(B s = y\). For \(n = 1\) this is the secant method.

    Proof: \(\|ts - y\|^2 - \|t^\star s - y\|^2 = \|s\|^2 (t - t^\star)^2\) with \(t^\star = s^\top y / s^\top s\).

    theorem norm_inv_bbStep_smul_sub_le (s y : E) (t : ℝ) :
    ‖(bbStep s y)⁻¹ • s - y‖ ≤ ‖t • s - y‖
    noncomputable def bbStep (s y : E) : ℝ := ‖s‖ ^ 2 / ⟪s, y⟫

    TheoremThe second Barzilai–Borwein step is the shorter one#✓fully proved

    MathlibExt.Analysis.Optimization.BarzilaiBorwein.bbStep₂_le_bbStep

    If \(s^\top y > 0\), then $\(\frac{s^\top y}{y^\top y} \le \frac{s^\top s}{s^\top y},\)$ that is, the second Barzilai–Borwein step is at most the first. This is the Cauchy–Schwarz inequality \((s^\top y)^2 \le \|s\|^2 \|y\|^2\).

    theorem bbStep₂_le_bbStep {s y : E} (h : 0 < ⟪s, y⟫) : bbStep₂ s y ≤ bbStep s y

    TheoremBarzilai–Borwein steps on a quadratic lie between the inverse curvature bounds#✓fully proved

    MathlibExt.Analysis.Optimization.BarzilaiBorwein.bbStep_mem_Icc

    Let \(A\) be a linear operator with \(m \|v\|^2 \le v^\top A v \le L \|v\|^2\) for all \(v\), where \(m > 0\), and let \(s \ne 0\). On the quadratic \(f(x) = \tfrac12 x^\top A x - b^\top x\) the gradient change along a step \(s\) is \(y = A s\), and the first Barzilai–Borwein step satisfies $\(\frac1L \le \alpha = \frac{s^\top s}{s^\top A s} \le \frac1m :\)$ \(1/\alpha\) is the Rayleigh quotient of \(A\) at \(s\). This makes precise the remark of the source that the step approximates the inverse of the second directional derivative of \(f\) along \(s\).

    theorem bbStep_mem_Icc {A : E →L[ℝ] E} {m L : ℝ} (hm : 0 < m)
    (hlow : ∀ v, m * ‖v‖ ^ 2 ≤ ⟪A v, v⟫) (hup : ∀ v, ⟪A v, v⟫ ≤ L * ‖v‖ ^ 2) {s : E}
    (hs : s ≠ 0) : 1 / L ≤ bbStep s (A s) ∧ bbStep s (A s) ≤ 1 / m
    noncomputable def bbStep (s y : E) : ℝ := ‖s‖ ^ 2 / ⟪s, y⟫

    TheoremRaydan's theorem#●ready to prove

    WantedExt.Analysis.Optimization.BarzilaiBorweinWanted.raydan_tendsto_gradient

    Let \(A\) be a symmetric positive definite operator on a finite-dimensional real inner product space and \(f(x) = \tfrac12 x^\top A x - b^\top x\), whose gradient is \(Ax - b\). Run the two-point step-size gradient method \(x_{k+1} = x_k - \alpha_k (A x_k - b)\) from any \(x_0\), with any \(\alpha_0 > 0\) and the Barzilai–Borwein step \(\alpha_{k+1} = s^\top s / s^\top y\), where \(s = x_{k+1} - x_k\) and \(y = A s\). Then \(A x_k - b \to 0\), that is, \(x_k \to A^{-1} b\).

    The method is not monotone: \(f(x_k)\) can increase. For \(n = 2\) Barzilai and Borwein proved R-superlinear convergence; Raydan's later nonmonotone line search extends the method to non-quadratic functions (both as reported in Section 1 of the source below).

    (hpos : ∀ v, v ≠ 0 → 0 < ⟪A v, v⟫) (b : E) {x : ℕ → E} {α : ℕ → ℝ} (hα0 : 0 < α 0)
    (hx : ∀ k, x (k + 1) = x k - α k • (A (x k) - b))
    (hα : ∀ k, α (k + 1) = bbStep (x (k + 1) - x k) ((A (x (k + 1)) - b) - (A (x k) - b))) :
    Tendsto (fun k => A (x k) - b) atTop (𝓝 0)
