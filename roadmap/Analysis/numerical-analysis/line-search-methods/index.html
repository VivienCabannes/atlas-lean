    Line search methods

    A line search method for minimising a smooth function iterates \(x_{k+1} = x_k + \alpha_k d_k\) along a descent direction \(d_k\) (\(\nabla f(x_k)^\top d_k < 0\)) with a step length \(\alpha_k > 0\) chosen to give sufficient decrease (the Armijo condition) without being too short (the Wolfe curvature condition). Under these conditions the Zoutendijk condition \(\sum_k (\nabla f(x_k)^\top d_k)^2 / \|d_k\|^2 < \infty\) holds; it is the summability argument behind the global convergence of steepest descent, quasi-Newton and nonlinear conjugate gradient methods.

    DefinitionArmijo sufficient decrease condition#✓fully proved

    MathlibExt.Analysis.Optimization.LineSearch.ArmijoCondition

    Let \(E\) be a real Hilbert space (for instance \(\mathbb{R}^n\)) and \(f : E \to \mathbb{R}\). A step length \(\alpha\) along a direction \(d\) from \(x\) satisfies the Armijo (sufficient decrease) condition with constant \(\delta\) if $\(f(x + \alpha d) \le f(x) + \delta\, \alpha\, \nabla f(x)^\top d.\)$ For a descent direction (\(\nabla f(x)^\top d < 0\)) the condition asks for a decrease proportional to the step and to the directional derivative. On its own it does not prevent arbitrarily short steps; the curvature condition does.

    def ArmijoCondition (f : E → ℝ) (δ : ℝ) (x d : E) (α : ℝ) : Prop :=
  f (x + α • d) ≤ f x + δ * α * ⟪gradient f x, d⟫

    DefinitionWolfe curvature condition#✓fully proved

    MathlibExt.Analysis.Optimization.LineSearch.CurvatureCondition

    Let \(E\) be a real Hilbert space (for instance \(\mathbb{R}^n\)) and \(f : E \to \mathbb{R}\). A step length \(\alpha\) along \(d\) from \(x\) satisfies the Wolfe curvature condition with constant \(\sigma\) if $\(\nabla f(x + \alpha d)^\top d \ge \sigma\, \nabla f(x)^\top d.\)$ For a descent direction and \(\sigma < 1\) this says that the directional derivative has increased by a definite fraction, which rules out steps that are too short. The source states the condition with a strict inequality; the non-strict form used here is weaker, so results assuming it apply to both.

    def CurvatureCondition (f : E → ℝ) (σ : ℝ) (x d : E) (α : ℝ) : Prop :=
  σ * ⟪gradient f x, d⟫ ≤ ⟪gradient f (x + α • d), d⟫

    DefinitionStandard Wolfe conditions#✓fully proved

    MathlibExt.Analysis.Optimization.LineSearch.WolfeConditions

    A step length satisfies the standard Wolfe conditions with constants \(\delta\) and \(\sigma\) if it satisfies the Armijo condition with constant \(\delta\) and the curvature condition with constant \(\sigma\); one usually takes \(0 < \delta < \sigma < 1\), which guarantees that such steps exist for a descent direction when \(f\) is continuously differentiable and bounded below along the ray (Wolfe).

    With \(s = \alpha d\) and \(y = \nabla f(x + s) - \nabla f(x)\), the curvature condition gives \(s^\top y \ge (\sigma - 1)\, \alpha\, \nabla f(x)^\top d > 0\) for a descent direction: this is why Wolfe steps keep quasi-Newton updates positive definite.

    def WolfeConditions (f : E → ℝ) (δ σ : ℝ) (x d : E) (α : ℝ) : Prop :=
  ArmijoCondition f δ x d α ∧ CurvatureCondition f σ x d α
    def ArmijoCondition (f : E → ℝ) (δ : ℝ) (x d : E) (α : ℝ) : Prop :=
  f (x + α • d) ≤ f x + δ * α * ⟪gradient f x, d⟫

    DefinitionStrong Wolfe conditions#✓fully proved

    MathlibExt.Analysis.Optimization.LineSearch.StrongWolfeConditions

    A step length \(\alpha\) along \(d\) from \(x\) satisfies the strong Wolfe conditions with constants \(\delta\) and \(\sigma\) if it satisfies the Armijo condition and $\(|\nabla f(x + \alpha d)^\top d| \le -\sigma\, \nabla f(x)^\top d,\)$ usually with \(0 < \delta < \sigma < 1\). The classical convergence analyses of the Fletcher–Reeves, Polak–Ribière–Polyak and Hestenes–Stiefel conjugate gradient methods assume these conditions.

    def StrongWolfeConditions (f : E → ℝ) (δ σ : ℝ) (x d : E) (α : ℝ) : Prop :=
  ArmijoCondition f δ x d α ∧ |⟪gradient f (x + α • d), d⟫| ≤ -σ * ⟪gradient f x, d⟫
    def ArmijoCondition (f : E → ℝ) (δ : ℝ) (x d : E) (α : ℝ) : Prop :=

    TheoremStrong Wolfe steps are standard Wolfe steps#✓fully proved

    MathlibExt.Analysis.Optimization.LineSearch.StrongWolfeConditions.toWolfeConditions

    A step length satisfying the strong Wolfe conditions with constants \(\delta, \sigma\) satisfies the standard Wolfe conditions with the same constants, since \(\nabla f(x + \alpha d)^\top d \ge -|\nabla f(x + \alpha d)^\top d| \ge \sigma\, \nabla f(x)^\top d\). So every result proved under standard Wolfe steps, such as the Zoutendijk condition, holds under strong Wolfe steps.

    theorem StrongWolfeConditions.toWolfeConditions {f : E → ℝ} {δ σ : ℝ} {x d : E} {α : ℝ}
    (h : StrongWolfeConditions f δ σ x d α) : WolfeConditions f δ σ x d α

    TheoremZoutendijk condition#✓fully proved

    MathlibExt.Analysis.Optimization.LineSearch.zoutendijk

    Let \(E\) be a real Hilbert space (for instance \(\mathbb{R}^n\)) and \(f : E \to \mathbb{R}\), differentiable at the iterates (the Lean statement needs no such assumption). Consider a line-search method \(x_{k+1} = x_k + \alpha_k d_k\) with \(\alpha_k > 0\) and descent directions, \(g_k^\top d_k < 0\) where \(g_k = \nabla f(x_k)\), whose step lengths satisfy the standard Wolfe conditions with constants \(\delta > 0\) and \(\sigma < 1\). Suppose that \(f(x_k)\) is bounded below and that \(\|g_{k+1} - g_k\| \le L\, \|x_{k+1} - x_k\|\) for some \(L > 0\). Then $\(\sum_{k \ge 0} \frac{(g_k^\top d_k)^2}{\|d_k\|^2} < \infty .\)$ Since \((g_k^\top d_k)^2 / \|d_k\|^2 = \cos^2\theta_k\, \|g_k\|^2\), where \(\theta_k\) is the angle between \(d_k\) and \(-g_k\), this is the classical form \(\sum_k \cos^2\theta_k \|g_k\|^2 < \infty\): if the angles stay away from \(90^\circ\) (steepest descent, or quasi-Newton directions with bounded condition numbers), then \(g_k \to 0\).

    The source assumes \(f\) bounded below on \(\mathbb{R}^n\) and \(\nabla f\) Lipschitz on a neighbourhood of the level set \(\{x : f(x) \le f(x_0)\}\) (its Assumption 3.1). The Armijo condition keeps the iterates in the level set, so these assumptions imply the two used here, which are the ones the proof uses.

    Proof (the source's): the curvature condition and the Lipschitz bound give \((\sigma - 1) g_k^\top d_k \le (g_{k+1} - g_k)^\top d_k \le \alpha_k L \|d_k\|^2\), a lower bound on \(\alpha_k\); the Armijo condition turns it into \(f(x_k) - f(x_{k+1}) \ge \delta(1 - \sigma) L^{-1} (g_k^\top d_k)^2 / \|d_k\|^2\), and the sum telescopes.

    theorem zoutendijk {f : E → ℝ} {δ σ L : ℝ} (hδ : 0 < δ) (hσ : σ < 1) (hL : 0 < L)
    {x d : ℕ → E} {α : ℕ → ℝ}
    (hx : ∀ k, x (k + 1) = x k + α k • d k) (hα : ∀ k, 0 < α k)
    (hdesc : ∀ k, ⟪gradient f (x k), d k⟫ < 0)
    (hwolfe : ∀ k, WolfeConditions f δ σ (x k) (d k) (α k))
    (hlip : ∀ k, ‖gradient f (x (k + 1)) - gradient f (x k)‖ ≤ L * ‖x (k + 1) - x k‖)
    (hbdd : BddBelow (Set.range fun k => f (x k))) :
    Summable fun k => ⟪gradient f (x k), d k⟫ ^ 2 / ‖d k‖ ^ 2
    def WolfeConditions (f : E → ℝ) (δ σ : ℝ) (x d : E) (α : ℝ) : Prop :=
  ArmijoCondition f δ x d α ∧ CurvatureCondition f σ x d α

    Related topics

    • Nonlinear conjugate gradient methods: their global convergence proofs combine the Zoutendijk condition with a bound on \(\|d_k\|\).
    • Quasi-Newton methods: Wolfe steps supply the curvature condition \(s^\top y > 0\) that keeps BFGS positive definite.
    • Trust-region methods: the other globalisation strategy, which controls the step length through the radius instead of a line search.
    • Gradient descent: fixed-step gradient descent on smooth convex functions, the line-search method with \(d_k = -\nabla f(x_k)\) and a constant step.
