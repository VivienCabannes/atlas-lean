    DefinitionStages computed row by row#✓fully proved

    MathlibExt.Analysis.ODE.RungeKutta.stageRow

    Let \(E\) be a real normed space, fix an explicit Runge–Kutta method with \(s\) stages, strictly lower-triangular tableau \(a\) and nodes \(c_i = \sum_j a_{ij}\), a vector field \(f\) assigning a vector \(f(t', x) \in E\) to each time \(t' \in \mathbb{R}\) and state \(x \in E\), a time \(t\), a state \(y \in E\) and a step \(h \in \mathbb{R}\). The rows \(K^{(n)} \in E^s\), indexed by \(0 \le i < s\), are defined by recursion on \(n\): \(K^{(0)} = 0\), and \(K^{(n+1)}_i\) equals \(f\bigl(t + c_i h,\ y + h \sum_{j < n} a_{ij} K^{(n)}_j\bigr)\) when \(i = n\) and equals \(K^{(n)}_i\) when \(i \ne n\). Only the entries of \(K^{(n)}\) with index less than \(n\) are filled in; the others are \(0\).

    def stageRow : ℕ → Fin s → E
  | 0 => fun _ => 0
  | n + 1 => fun i =>
      if i.val = n then
        f (t + rk.c i * h)
          (y + h • ∑ j : Fin s, if j.val < n then rk.a i j • stageRow n j else 0)
      else stageRow n i

    MathlibExt.Analysis.ODE.RungeKutta.stageRow_eq_of_lt

    Let \(E\) be a real normed vector space and \(f(t, y)\) a vector field \(\mathbb{R} \times E \to E\), and fix an explicit Runge–Kutta method, a time \(t\), a state \(y \in E\) and a step size \(h \in \mathbb{R}\).     TheoremThe defining equation of the stages#✓fully proved

    MathlibExt.Analysis.ODE.RungeKutta.stage_eq

    Let \(E\) be a real normed vector space and \(f(t, y)\) a vector field \(\mathbb{R} \times E \to E\). For an explicit Runge–Kutta method with tableau \(a\) and nodes \(c_i = \sum_j a_{ij}\), a time \(t\), a state \(y \in E\) and a step size \(h\), the stages \(k_i\) satisfy \(k_i = f\bigl(t + c_i h, \; y + h \sum_{j < i} a_{ij} k_j\bigr)\) for every stage index \(i\).

    theorem stage_eq (i : Fin s) :
    stage rk f t y h i =
      f (t + rk.c i * h)
        (y + h • ∑ j : Fin s, if j < i then rk.a i j • stage rk f t y h j else 0)
    def stage (i : Fin s) : E := stageRow rk f t y h (i.val + 1) i

    MathlibExt.Analysis.ODE.RungeKutta.rkStep

    Let \(E\) be a real normed vector space and \(f(t, y)\) a vector field \(\mathbb{R} \times E \to E\). For an explicit Runge–Kutta method with weights \(b\), a time \(t\), a state \(y \in E\) and a step size \(h \in \mathbb{R}\), one step of the method is \(y + h \sum_i b_i k_i\), where \(k_i\) is the \(i\)-th stage of the method for \(f\), \(t\), \(y\) and \(h\), and the sum runs over the stages.

    def rkStep : E := y + h • ∑ i, rk.b i • stage rk f t y h i

    An explicit Runge–Kutta method with tableau \(a\), weights \(b\) and nodes \(c_i = \sum_j a_{ij}\) satisfies the order-three conditions when it satisfies the order-two conditions \(\sum_i b_i = 1\) and \(\sum_i b_i c_i = \frac{1}{2}\), and moreover \(\sum_i b_i c_i^2 = \frac{1}{3}\) and \(\sum_{i, j} b_i a_{ij} c_j = \frac{1}{6}\), all sums running over the stages.

    DefinitionOrder-four conditions#✓fully proved

    MathlibExt.Analysis.ODE.RungeKutta.OrderFour

    An explicit Runge–Kutta method with Butcher tableau \(a\), weights \(b\) and nodes \(c\) satisfies the order-four conditions when it satisfies the order-three conditions, namely \(\sum_i b_i = 1\), \(\sum_i b_i c_i = 1/2\), \(\sum_i b_i c_i^2 = 1/3\) and \(\sum_{i,j} b_i a_{ij} c_j = 1/6\), together with \(\sum_i b_i c_i^3 = 1/4\), \(\sum_{i,j} b_i c_i a_{ij} c_j = 1/8\), \(\sum_{i,j} b_i a_{ij} c_j^2 = 1/12\) and \(\sum_{i,j,k} b_i a_{ij} a_{jk} c_k = 1/24\). These are the eight Butcher conditions.

    def OrderFour : Prop :=
  OrderThree rk ∧ ∑ i, rk.b i * rk.c i ^ 3 = 1 / 4 ∧
    ∑ i, ∑ j, rk.b i * rk.c i * rk.a i j * rk.c j = 1 / 8 ∧
    ∑ i, ∑ j, rk.b i * rk.a i j * rk.c j ^ 2 = 1 / 12 ∧
    ∑ i, ∑ j, ∑ k, rk.b i * rk.a i j * rk.a j k * rk.c k = 1 / 24

  OrderTwo rk ∧ ∑ i, rk.b i * rk.c i ^ 2 = 1 / 3 ∧
    ∑ i, ∑ j, rk.b i * rk.a i j * rk.c j = 1 / 6
