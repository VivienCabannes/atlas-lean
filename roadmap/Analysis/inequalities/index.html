    TheoremHardy's inequality#✓fully proved

    MetaMathlibExt.hardy_inequality

    Let \(p > 1\) be a real number and let \((a_n)_{n \ge 0}\) be a sequence of nonnegative real numbers such that \(\sum_n a_n^p\) converges. Write \(A_n = \frac{1}{n+1} \sum_{i=0}^{n} a_i\) for the average of \(a_0, \dots, a_n\). Then \(\sum_n A_n^p\) converges and

    \[\sum_{n=0}^{\infty} A_n^p \le \left(\frac{p}{p-1}\right)^p \sum_{n=0}^{\infty} a_n^p.\]

    Proof: Elliott's finite telescoping argument is combined with Young's and Hölder's inequalities, following E. B. Elliott (1926) as presented in Hardy--Littlewood--Pólya, Inequalities, Theorem 326.

    theorem hardy_inequality {a : ℕ → ℝ} {p : ℝ} (hp : 1 < p)
    (hnonneg : ∀ n, 0 ≤ a n)
    (hsumm : Summable fun n => (a n).rpow p) :
    Summable (fun n => ((Finset.sum (Finset.range (n + 1)) a / ((n : ℝ) + 1)).rpow p)) ∧
    ∑' n, ((Finset.sum (Finset.range (n + 1)) a / ((n : ℝ) + 1)).rpow p) ≤
      (p / (p - 1)).rpow p * ∑' n, (a n).rpow p
    Sources

    TheoremHermite–Hadamard inequality#✓fully proved

    MetaMathlibExt.hermite_hadamard

    Let \(a < b\) be real numbers and let \(f \colon \mathbb{R} \to \mathbb{R}\) be convex on \([a, b]\). Then \(f\left(\frac{a+b}{2}\right) \le \frac{1}{b-a} \int_a^b f(x)\,dx\) and \(\frac{1}{b-a} \int_a^b f(x)\,dx \le \frac{f(a) + f(b)}{2}\).

    theorem hermite_hadamard {f : ℝ → ℝ} {a b : ℝ} (hab : a < b)
    (hf : ConvexOn ℝ (Set.Icc a b) f) :
    f ((a + b) / 2) ≤ (1 / (b - a)) * ∫ x in a..b, f x ∧
    (1 / (b - a)) * ∫ x in a..b, f x ≤ (f a + f b) / 2

    TheoremInequality for square-summable complex sequences#●ready to prove

    MathlibExt.Analysis.SquareSummableComplexInequalityWanted.conjecture_holds

    Let \((\alpha_n)_{n \ge 1}\) be complex numbers with \(\sum_{n \ge 1} |\alpha_n|^2 < \infty\), and for \(k \ge 0\) put \(\beta_k = \sum_{l \ge 0} \alpha_{2^k(2l+1)} / (l+1)\). Then each series defining \(\beta_k\) converges absolutely, \(\sum_{k \ge 0} |\beta_k|^2 < \infty\), and

    \[\sum_{n \ge 1} |\alpha_n|^2 \ge \frac{6}{\pi^2} \sum_{k \ge 0} |\beta_k|^2.\]

    The inequality follows from the Cauchy–Schwarz inequality.

    Summable (fun k => ‖∑' l, α (2 ^ k * (2 * l + 1)) / (l + 1 : ℂ)‖ ^ 2) ∧
      ∑' n, ‖α (n + 1)‖ ^ 2 ≥
        6 / Real.pi ^ 2 * ∑' k, ‖∑' l, α (2 ^ k * (2 * l + 1)) / (l + 1 : ℂ)‖ ^ 2

    TheoremWirtinger's inequality#✓fully proved

    MetaMathlibExt.wirtinger_inequality

    Let \(f, f' : \mathbb{R} \to \mathbb{R}\) be functions such that for every \(x \in [0, \pi]\) the function \(f\) has derivative \(f'(x)\) at \(x\) within \([0, \pi]\), \(f'\) is continuous on \([0, \pi]\), and \(f(0) = f(\pi) = 0\). Then \(\int_0^\pi f(x)^2 \, dx \le \int_0^\pi f'(x)^2 \, dx\).

    Proof: A Picone-type comparison. For 0 < c < 1 the weight h x = -c * tan (c * (x - π / 2)) is smooth on [0, π] with h' + h ^ 2 = -c ^ 2, so integrating f' ^ 2 = (f' - h * f) ^ 2 + (h * f ^ 2)' + c ^ 2 * f ^ 2 gives c ^ 2 * ∫ f ^ 2 ≤ ∫ f' ^ 2; then let c tend to one.

    public theorem wirtinger_inequality (f f' : ℝ → ℝ)
    (hf_deriv : ∀ x ∈ Set.Icc (0 : ℝ) Real.pi,
      HasDerivWithinAt f (f' x) (Set.Icc 0 Real.pi) x)
    (hf_deriv_cont : ContinuousOn f' (Set.Icc 0 Real.pi))
    (h0 : f 0 = 0) (hpi : f Real.pi = 0) :
    intervalIntegral (fun x => (f x) ^ 2) 0 Real.pi MeasureTheory.volume ≤
      intervalIntegral (fun x => (f' x) ^ 2) 0 Real.pi MeasureTheory.volume
