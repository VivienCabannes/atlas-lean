    TheoremNormalised power sums decrease in the exponent#●ready to prove

    MetaMathlibExt.power_sum_rpow_one_div_le

    Let \(n \ge 0\) and let \(x_1, \dots, x_n\) be positive real numbers. If \(\alpha\) and \(\beta\) are real numbers with \(0 < \beta < \alpha\), then \((\sum_{k=1}^{n} x_k^\alpha)^{1/\alpha} \le (\sum_{k=1}^{n} x_k^\beta)^{1/\beta}\).

    public theorem_wanted power_sum_rpow_one_div_le {n : ℕ} (x : Fin n → ℝ) (hx : ∀ i, 0 < x i)
    {α β : ℝ} (hβ : 0 < β) (hβα : β < α) :
    (∑ i, x i ^ α) ^ (1 / α) ≤ (∑ i, x i ^ β) ^ (1 / β)

    TheoremLower bound for a power sum at the mean exponent#●ready to prove

    MetaMathlibExt.power_sum_mul_div_max_le

    Let \(0 < x_1 \le \dots \le x_N\) be \(N \ge 1\) real numbers, and for real \(p\) write \(S^{[p]} = \sum_{k=1}^{N} x_k^p\). For all real \(r, s > 0\), \(S^{[r]} S^{[s]} / \max(x_N^{r/2} S^{[s/2]}, x_N^{s/2} S^{[r/2]}) \le S^{[(r+s)/2]}\).

    public theorem_wanted power_sum_mul_div_max_le {n : ℕ} (x : Fin (n + 1) → ℝ)
    (hx : Monotone x) (h0 : 0 < x 0) {r s : ℝ} (hr : 0 < r) (hs : 0 < s) :
    (∑ i, x i ^ r) * (∑ i, x i ^ s) /
        max (x (Fin.last n) ^ (r / 2) * ∑ i, x i ^ (s / 2))
          (x (Fin.last n) ^ (s / 2) * ∑ i, x i ^ (r / 2)) ≤
      ∑ i, x i ^ ((r + s) / 2)

    TheoremPower sums under a larger exponent#●ready to prove

    MetaMathlibExt.power_sum_le_rpow_of_le

    Let \(x_1, \dots, x_N\) be \(N \ge 1\) positive real numbers, and for real \(p\) write \(S^{[p]} = \sum_{k=1}^{N} x_k^p\). If \(\alpha\) and \(\beta\) are real numbers with \(0 < \beta \le \alpha\), then \(S^{[\alpha]} \le (S^{[\beta]})^{\alpha/\beta}\).

    TheoremPower mean bound for power sums with a smaller exponent#●ready to prove

    MetaMathlibExt.power_sum_le_card_mul_rpow_of_lt

    Let \(x_1, \dots, x_N\) be \(N \ge 1\) positive real numbers, and for real \(p\) write \(S^{[p]} = \sum_{k=1}^{N} x_k^p\). If \(\alpha\) and \(\beta\) are real numbers with \(0 < \alpha < \beta\), then \(S^{[\alpha]} \le N (S^{[\beta]} / N)^{\alpha/\beta}\). If moreover \(x_k \ge 1\) for every \(k\), then also \(N (S^{[\beta]} / N)^{\alpha/\beta} \le S^{[\beta]}\).

    In the paper \(\alpha = (r + s)/2\) and the sequence is monotone, so the condition \(x_k \ge 1\) for every \(k\) is the paper's \(x_1 \ge 1\).

    public theorem_wanted power_sum_le_card_mul_rpow_of_lt {n : ℕ} (x : Fin (n + 1) → ℝ)

    ∑ i, x i ^ α ≤ ((n : ℝ) + 1) * ((∑ i, x i ^ β) / ((n : ℝ) + 1)) ^ (α / β) ∧
      ((∀ i, 1 ≤ x i) →
        ((n : ℝ) + 1) * ((∑ i, x i ^ β) / ((n : ℝ) + 1)) ^ (α / β) ≤ ∑ i, x i ^ β)

    TheoremClassical Fibonacci sum identities#●ready to prove

    MetaMathlibExt.fib_power_sum_identities

    Let \(F_k\) denote the \(k\)-th Fibonacci number, with \(F_0 = 0\) and \(F_1 = 1\). For every natural number \(n \ge 1\), the following identities hold in the integers: \(\sum_{i=1}^{n} F_{2i-1} = F_{2n}\); \(\sum_{i=1}^{n} F_{2i} = F_{2n+1} - 1\); \(\sum_{i=1}^{n} i F_i = n F_{n+2} - F_{n+3} + 2\); \(\sum_{i=1}^{n} F_i F_{3i} = F_n F_{n+1} F_{2n+1}\); and \(\sum_{i=1}^{n} \binom{n}{i} F_i = F_{2n}\).

    These are parts (b), (c), (d), (e) and (g) of Lemma 1 of the paper, quoted there from Koshy.

    public theorem_wanted fib_power_sum_identities {n : ℕ} (hn : 1 ≤ n) :
    (∑ i ∈ Finset.Icc 1 n, (Nat.fib (2 * i - 1) : ℤ)) = Nat.fib (2 * n) ∧
    (∑ i ∈ Finset.Icc 1 n, (Nat.fib (2 * i) : ℤ)) = Nat.fib (2 * n + 1) - 1 ∧
    (∑ i ∈ Finset.Icc 1 n, (i : ℤ) * Nat.fib i) =
      n * Nat.fib (n + 2) - Nat.fib (n + 3) + 2 ∧
    (∑ i ∈ Finset.Icc 1 n, (Nat.fib i : ℤ) * Nat.fib (3 * i)) =
      Nat.fib n * Nat.fib (n + 1) * Nat.fib (2 * n + 1) ∧
    (∑ i ∈ Finset.Icc 1 n, (n.choose i : ℤ) * Nat.fib i) = Nat.fib (2 * n)
    Sources

    TheoremProduct of two Fibonacci power sums#●ready to prove

    MetaMathlibExt.sum_fib_rpow_mul_sum_fib_rpow_ge

    Let \(F_k\) denote the \(k\)-th Fibonacci number. For every natural number \(n \ge 1\) and all real \(r, s\) with \(r + s \ge 4\), \((F_n F_{n+1})^2 \le (\sum_{k=1}^{n} F_k^r)(\sum_{k=1}^{n} F_k^s)\), where \(F_k^r\) and \(F_k^s\) are real powers, with equality if and only if \(n = 1\), or \(n = 2\), or \(n \ge 3\) and \(r = s = 2\).

    The paper quotes this result from its reference [2].

    public theorem_wanted sum_fib_rpow_mul_sum_fib_rpow_ge {n : ℕ} (hn : 1 ≤ n) {r s : ℝ}
    (hrs : 4 ≤ r + s) :
    ((Nat.fib n : ℝ) * Nat.fib (n + 1)) ^ 2 ≤
        (∑ k ∈ Finset.Icc 1 n, (Nat.fib k : ℝ) ^ r) * ∑ k ∈ Finset.Icc 1 n, (Nat.fib k : ℝ) ^ s ∧
      ((∑ k ∈ Finset.Icc 1 n, (Nat.fib k : ℝ) ^ r) * ∑ k ∈ Finset.Icc 1 n, (Nat.fib k : ℝ) ^ s =
          ((Nat.fib n : ℝ) * Nat.fib (n + 1)) ^ 2 ↔
        n = 1 ∨ n = 2 ∨ (3 ≤ n ∧ r = 2 ∧ s = 2))
