    StructureClosed topological 4-manifold#✓fully proved

    MathlibExt.Topology.AsphericalHomologySphereWanted.Topology.Closed4Manifold

    A closed topological 4-manifold is a nonempty, compact, connected, Hausdorff, second-countable topological space \(M\) together with an atlas of charts covering \(M\), each a homeomorphism from an open subset of \(M\) onto an open subset of \(\mathbb{R}^4\) (charts are modelled on all of \(\mathbb{R}^4\), not on a half-space, so \(M\) has no boundary).

    No smoothness or compatibility between charts is required, so this is a topological, not necessarily smooth, manifold.

    structure Closed4Manifold where
  /-- The underlying point set. -/
  carrier : Type
  [topology : TopologicalSpace carrier]
  [t2 : T2Space carrier]
  [secondCountable : SecondCountableTopology carrier]
  [charted : ChartedSpace (EuclideanSpace ℝ (Fin 4)) carrier]
  [compact : CompactSpace carrier]
  [connected : ConnectedSpace carrier]
  /-- The carrier is nonempty: a closed manifold has points. -/
  [nonempty : Nonempty carrier]

    MathlibExt.Topology.AsphericalHomologySphereWanted.Topology.Closed4Manifold.IsAspherical

    A closed topological 4-manifold \(M\) is aspherical if for every \(k \ge 2\) and every point \(x \in M\) the homotopy group \(\pi_k(M, x)\) is trivial.

    def Closed4Manifold.IsAspherical (M : Closed4Manifold) : Prop :=
  ∀ k : ℕ, 2 ≤ k → ∀ x : M.carrier, Subsingleton (HomotopyGroup (Fin k) M.carrier x)

    DefinitionInteger homology 4-sphere#✓fully proved

    MathlibExt.Topology.AsphericalHomologySphereWanted.Topology.Closed4Manifold.IsIntegerHomologySphere

    A closed topological 4-manifold \(M\) is an integer homology 4-sphere if for every \(k \ge 0\) the integral singular homology \(H_k(M; \mathbb{Z})\) is isomorphic, as a \(\mathbb{Z}\)-module, to \(H_k(S^4; \mathbb{Z})\), where \(S^4\) is the unit sphere in \(\mathbb{R}^5\).

    def Closed4Manifold.IsIntegerHomologySphere (M : Closed4Manifold) : Prop :=
  ∀ k : ℕ, Nonempty (intHomology k (TopCat.of M.carrier) ≅
    intHomology k (TopCat.of (sphere (0 : EuclideanSpace ℝ (Fin 5)) 1)))
