    DefinitionMatrices with nonnegative minors#✓fully proved

    MetaMathlibExt.Matrix.HasNonnegativeMinors

    Let \(\iota\) and \(\kappa\) be linearly ordered types and let \(M\) be a real matrix with rows indexed by \(\iota\) and columns indexed by \(\kappa\). Then \(M\) has nonnegative minors when, for every \(k \in \mathbb{N}\) and all strictly increasing maps \(r \colon \{0, \dots, k-1\} \to \iota\) and \(c \colon \{0, \dots, k-1\} \to \kappa\), the \(k \times k\) submatrix \((M_{r(a), c(b)})_{a, b < k}\) has nonnegative determinant. The case \(k = 0\), the empty minor, is included.

    public def Matrix.HasNonnegativeMinors {ι κ : Type*} [LinearOrder ι] [LinearOrder κ]
    (M : Matrix ι κ ℝ) : Prop :=
  ∀ (k : ℕ) (r : Fin k → ι) (c : Fin k → κ),
    StrictMono r → StrictMono c → 0 ≤ (M.submatrix r c).det

    DefinitionMatrices with positive minors#✓fully proved

    MetaMathlibExt.Matrix.HasPositiveMinors

    A real matrix \(M\) whose rows and columns are indexed by linearly ordered sets \(R\) and \(C\) has positive minors (is totally positive) when, for every natural number \(k\) and all strictly increasing maps \(r : \{1, \dots, k\} \to R\) and \(c : \{1, \dots, k\} \to C\), the \(k \times k\) submatrix \((M_{r(a), c(b)})_{1 \le a, b \le k}\) has positive determinant. The case \(k = 0\) is the empty minor, whose determinant is \(1\).

    public def Matrix.HasPositiveMinors {ι κ : Type*} [LinearOrder ι] [LinearOrder κ]
    (M : Matrix ι κ ℝ) : Prop :=
  ∀ (k : ℕ) (r : Fin k → ι) (c : Fin k → κ),
    StrictMono r → StrictMono c → 0 < (M.submatrix r c).det

    DefinitionGeneralized \(p\)-Fibonacci sequence#✓fully proved

    MetaMathlibExt.generalizedPFibonacci

    For integers \(p\), \(a\) and \(b\), the generalized Fibonacci sequence \((W_{p,n})_{n \ge 0}\) of integers is defined by \(W_{p,0} = a\), \(W_{p,1} = b\) and \(W_{p,n} = p W_{p,n-1} + W_{p,n-2}\) for \(n \ge 2\).

    public def generalizedPFibonacci (p a b : ℤ) : ℕ → ℤ
  | 0 => a
  | 1 => b
  | n + 2 => p * generalizedPFibonacci p a b (n + 1) + generalizedPFibonacci p a b n

    TheoremEventual log-concavity of generalized hyper-Fibonacci numbers#●ready to prove

    MetaMathlibExt.generalizedHyperFibonacci_eventually_logConcave
