    DefinitionCondition number of a square real matrix#✓fully proved

    Matrix.SignConditionNumber.conditionNumber

    For a real \(n \times n\) matrix \(A\), let \(\sigma_0 \ge \sigma_1 \ge \dots\) be the singular values of \(A\) acting on Euclidean space \(\mathbb{R}^n\), indexed from \(0\) and extended by \(\sigma_i = 0\) for \(i \ge n\). The condition number of \(A\), an element of \([0, \infty]\), is \(\infty\) if \(\sigma_{n-1} = 0\) and \(\sigma_0 / \sigma_{n-1}\) otherwise, where \(n - 1\) is read as \(0\) when \(n = 0\).

    The minimum over sign matrices is only taken at positive order.

    noncomputable def conditionNumber {n : ℕ} (A : Matrix (Fin n) (Fin n) ℝ) : ENNReal :=
  let σ := (Matrix.toEuclideanLin A).singularValues
  if σ (n - 1) = 0 then ⊤ else ENNReal.ofReal (σ 0 / σ (n - 1))
