    Power iteration and the Rayleigh quotient

    The simplest eigenvalue algorithm: repeated multiplication by \(T\) and normalization. For an operator with an orthonormal eigenbasis (a symmetric matrix) and a strictly dominant eigenvalue, the iterates converge to the dominant eigenvector, up to sign, linearly at the rate \(|\lambda_2/\lambda_1|\), and the Rayleigh quotient converges to the eigenvalue at the squared rate, because the Rayleigh quotient is a quadratically accurate eigenvalue estimate (Trefethen and Bau, Lecture 27). Inverse iteration, Rayleigh quotient iteration and the QR algorithm refine this idea.

    TheoremPower iteration converges linearly (unnormalized form)#✓fully proved

    MathlibExt.Analysis.InnerProductSpace.PowerIteration.norm_smul_pow_apply_sub_le

    Let \((b_j)\) be an orthonormal eigenbasis of \(T\) on a finite-dimensional real inner product space, \(T b_j = \lambda_j b_j\), let \(q = b_{i_0}\) with \(\lambda_{i_0} \ne 0\), let \(\mu \ge 0\) with \(|\lambda_j| \le \mu\) for \(j \ne i_0\), and let \(v_0\) have \(c = \langle q, v_0\rangle \ne 0\). Then for every \(k\), \(\|(c\lambda_{i_0}^k)^{-1} T^k v_0 - q\| \le \rho^k \|v_0\| / |c|\) with \(\rho = \mu/|\lambda_{i_0}|\). When \(\lambda_{i_0}\) is strictly dominant (\(\rho < 1\)) the error decays linearly at rate \(|\lambda_2/\lambda_1|\).

    theorem norm_smul_pow_apply_sub_le {T : E →ₗ[ℝ] E} (b : OrthonormalBasis ι ℝ E) {lam : ι → ℝ}
    (hT : ∀ j, T (b j) = lam j • b j) {i₀ : ι} {μ : ℝ} (hμ0 : 0 ≤ μ)
    (hμ : ∀ j, j ≠ i₀ → |lam j| ≤ μ) (hlam : lam i₀ ≠ 0) {v₀ : E} (hc : ⟪b i₀, v₀⟫ ≠ 0)
    (k : ℕ) :
    ‖(⟪b i₀, v₀⟫ * lam i₀ ^ k)⁻¹ • (T ^ k) v₀ - b i₀‖ ≤
      (μ / |lam i₀|) ^ k * (‖v₀‖ / |⟪b i₀, v₀⟫|)

    TheoremQuadratic accuracy of the Rayleigh quotient#✓fully proved

    MathlibExt.Analysis.InnerProductSpace.PowerIteration.inner_apply_sub_eq_of_eigen

    If \(T\) is symmetric and \(Tq = \lambda q\), then for every \(v\), \(\langle v, Tv\rangle - \lambda\|v\|^2 = \langle v - q, (T - \lambda)(v - q)\rangle\). Hence the Rayleigh quotient \(r(v) = \langle v, Tv\rangle/\|v\|^2\) satisfies \(r(v) - \lambda = O(\|v - q\|^2)\): it is a quadratically accurate estimate of the eigenvalue.

    theorem inner_apply_sub_eq_of_eigen {T : E →ₗ[ℝ] E} (hT : T.IsSymmetric) {q : E} {lam : ℝ}
    (hq : T q = lam • q) (v : E) :
    ⟪v, T v⟫ - lam * ‖v‖ ^ 2 = ⟪v - q, T (v - q) - lam • (v - q)⟫

    TheoremThe power-iteration eigenvalue estimate converges twice as fast#✓fully proved

    MathlibExt.Analysis.InnerProductSpace.PowerIteration.abs_rayleigh_pow_apply_sub_le

    Under the hypotheses of the unnormalized bound, if \(|\lambda_j - \lambda_{i_0}| \le D\) for every \(j\), then the Rayleigh quotient of \(x = T^k v_0\) satisfies \(|\langle x, Tx\rangle/\|x\|^2 - \lambda_{i_0}| \le D\rho^{2k}(\|v_0\|/|c|)^2\).

    theorem abs_rayleigh_pow_apply_sub_le {T : E →ₗ[ℝ] E} (b : OrthonormalBasis ι ℝ E)
    {lam : ι → ℝ} (hT : ∀ j, T (b j) = lam j • b j) {i₀ : ι} {μ D : ℝ} (hμ0 : 0 ≤ μ)
    (hμ : ∀ j, j ≠ i₀ → |lam j| ≤ μ) (hlam : lam i₀ ≠ 0)
    (hD : ∀ j, |lam j - lam i₀| ≤ D) {v₀ : E} (hc : ⟪b i₀, v₀⟫ ≠ 0) (k : ℕ) :
    |⟪(T ^ k) v₀, T ((T ^ k) v₀)⟫ / ‖(T ^ k) v₀‖ ^ 2 - lam i₀| ≤
      D * ((μ / |lam i₀|) ^ k * (‖v₀‖ / |⟪b i₀, v₀⟫|)) ^ 2
