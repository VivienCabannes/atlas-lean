    Arithmetical structures on graphs

    DefinitionArithmetical structure#✓fully proved

    MetaMathlibExt.IsArithmeticalStructure

    An arithmetical structure on a graph \(G\) with vertex set \(V\) is a pair of labelings \(d, r : V \to \mathbb{N}\) such that \(d(v) > 0\) and \(r(v) > 0\) for every vertex \(v\), \(d(v)\, r(v) = \sum_{w \sim v} r(w)\) for every vertex \(v\), where the sum runs over the neighbours \(w\) of \(v\), and the only natural number dividing every \(r(v)\) is \(1\). For a finite graph with adjacency matrix \(A\) the middle condition reads \((\operatorname{diag}(d) - A)\, r = 0\).

    The neighbour sum is taken to be \(0\) when \(v\) has infinitely many neighbours, so no arithmetical structure exists on a graph with a vertex of infinite degree.

    public def IsArithmeticalStructure {V : Type*} (G : SimpleGraph V) (d r : V → ℕ) : Prop :=
  (∀ v, 0 < d v) ∧ (∀ v, 0 < r v) ∧
    (∀ v, d v * r v = ∑ᶠ w ∈ {w | G.Adj v w}, r w) ∧
    ∀ g : ℕ, (∀ v, g ∣ r v) → g = 1

    DefinitionCoconut tree#✓fully proved

    MetaMathlibExt.coconutTree

    For natural numbers \(p\) and \(s\), the coconut tree \(\mathrm{CT}(p, s)\) is the graph whose vertices are the path vertices \(v_1, \dots, v_p\) and the leaves \(v_{\ell_1}, \dots, v_{\ell_s}\), in which \(v_i\) and \(v_{i+1}\) are adjacent for \(1 \le i < p\), every leaf is adjacent to \(v_p\), and there are no other edges. For \(p = 0\) it consists of \(s\) isolated vertices.

    public def coconutTree (p s : ℕ) : SimpleGraph (Fin p ⊕ Fin s) :=
  SimpleGraph.fromRel fun a b =>
    match a, b with
    | .inl i, .inl j => i.val + 1 = j.val
    | .inl i, .inr _ => i.val + 1 = p
    | .inr _, _ => False

    DefinitionBallot numbers#✓fully proved

    MetaMathlibExt.ballotNumber

    For natural numbers \(n\) and \(k\), the ballot number \(B(n, k)\) is the integer part of \(\max(n + 1 - k, 0) \binom{n+k}{n} / (n + 1)\). For \(k \le n + 1\) the division is exact, so \(B(n, k) = \frac{n - k + 1}{n + 1} \binom{n+k}{n}\) (OEIS A009766), and \(B(n, k) = 0\) for \(k > n + 1\).

    public def ballotNumber (n k : ℕ) : ℕ :=
  (n + 1 - k) * (n + k).choose n / (n + 1)

    DefinitionEuclidean chain function#✓fully proved

    MetaMathlibExt.euclideanChainLength

    For natural numbers \(x_1\) and \(x_2\), the Euclidean chain \(x_1, x_2, x_3, \dots\) is given by \(x_{i+1} = (-x_{i-1}) \bmod x_i\) (the least nonnegative residue) while \(x_i \ne 0\), and by \(x_{i+1} = 0\) once \(x_i = 0\). The Euclidean chain function is defined by the recursion \(F(x, 0) = 1\) and \(F(x, y) = 1 + F(y, (-x) \bmod y)\) for \(y \ne 0\). For \(x_1 > 0\), \(F(x_1, x_2)\) is the number of positive terms of the Euclidean chain.

    For \(x_1 = 0\) the recursion also counts the first term \(0\): \(F(0, 0) = 1\) and \(F(0, 1) = 2\), although the chains \(0, 0\) and \(0, 1, 0\) have \(0\) and \(1\) positive terms.

    public def euclideanChainLength (x y : ℕ) : ℕ :=
  if h : y = 0 then 1 else 1 + euclideanChainLength y ((y - x % y) % y)
