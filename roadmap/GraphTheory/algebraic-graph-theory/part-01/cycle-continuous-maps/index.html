    DefinitionBinary cycle space#✓fully proved

    MathlibExt.GraphTheory.CycleContinuousAntichainWanted.cycleSpace

    Let \(G\) be a multigraph. A set \(S\) of edges of \(G\) is a binary cycle when \(S\) is finite and every vertex \(v\) is an endpoint of an even number of edges of \(S\), where only edges with exactly one endpoint equal to \(v\) are counted; loops are not counted, which agrees modulo \(2\) with counting each loop twice. The cycle space of \(G\) is the set of all binary cycles of \(G\).

    noncomputable def cycleSpace (G : FGraph) : Set (Set G.E) :=
  {S | Set.Finite S ∧ ∀ v : G.V, Even (Set.ncard {e ∈ S | ((G.ends e).1 = v ∧ (G.ends e).2 ≠ v) ∨ ((G.ends e).1 ≠ v ∧ (G.ends e).2 = v)})}

    MathlibExt.GraphTheory.CycleContinuousAntichainWanted.IsCycleContinuous

    Let \(G\) and \(H\) be multigraphs. A map \(f\) from the edges of \(G\) to the edges of \(H\) is cycle-continuous when, for every binary cycle \(C\) of \(H\), the preimage \(f^{-1}(C)\) is a binary cycle of \(G\).

    noncomputable def IsCycleContinuous (G H : FGraph) (f : G.E → H.E) : Prop :=
  ∀ C ∈ cycleSpace H, f ⁻¹' C ∈ cycleSpace G
