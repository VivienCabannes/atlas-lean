    MathlibExt.Combinatorics.TransitiveSubtournamentLogErdosProblem1216Wanted.IsTournament

    Let \(n \in \mathbb{N}\). A relation \(T\) on \(\{0, \dots, n-1\}\) is a tournament when \(T(x, x)\) holds for no \(x\) and, for all distinct \(x\) and \(y\), exactly one of \(T(x, y)\) and \(T(y, x)\) holds.

    def IsTournament {n : ℕ} (T : Fin n → Fin n → Prop) : Prop :=
  (∀ x, ¬ T x x) ∧ ∀ x y, x ≠ y → (T x y ↔ ¬ T y x)

    DefinitionTransitivity on a vertex set#✓fully proved

    MathlibExt.Combinatorics.TransitiveSubtournamentLogErdosProblem1216Wanted.IsTransitiveOn

    Let \(n \in \mathbb{N}\), let \(T\) be a relation on \(\{0, \dots, n-1\}\) and let \(S\) be a set of its elements. Then \(T\) is transitive on \(S\) when, for all \(x, y, z \in S\), \(T(x, y)\) and \(T(y, z)\) imply \(T(x, z)\). For a tournament \(T\) this says that the subtournament of \(T\) on \(S\) is transitive.

    def IsTransitiveOn {n : ℕ} (T : Fin n → Fin n → Prop) (S : Finset (Fin n)) : Prop :=
  ∀ x ∈ S, ∀ y ∈ S, ∀ z ∈ S, T x y → T y z → T x z

    MathlibExt.Combinatorics.TransitiveSubtournamentLogErdosProblem1216Wanted.transitiveSubtournamentNumber

    For \(n \in \mathbb{N}\), \(f(n)\) is the largest \(m\) such that every tournament \(T\) on \(\{0, \dots, n-1\}\) is transitive on some set of exactly \(m\) vertices, that is, contains a transitive subtournament on \(m\) vertices.

    Such \(m\) exist (for instance \(m = 0\)) and are at most \(n\), so the largest one exists.

    noncomputable def transitiveSubtournamentNumber (n : ℕ) : ℕ :=
  sSup {m : ℕ | ∀ T : Fin n → Fin n → Prop, IsTournament T →
    ∃ S : Finset (Fin n), S.card = m ∧ IsTransitiveOn T S}

    MathlibExt.Combinatorics.TransitiveSubtournamentLogErdosProblem1216Wanted.transitiveSubtournamentNumberEqLogTwo_refuted

    It is not the case that \(f(n) = \lfloor \log_2 n \rfloor + 1\) for every \(n \ge 1\), where \(f(n)\) is the largest \(m\) such that every tournament on \(n\) vertices contains a transitive subtournament on \(m\) vertices.

    Reid and Parker proved \(f(n) \ge \lfloor \log_2 n + 4 - \log_2 7 \rfloor\) for all \(n \ge 14\); at \(n = 14\) this gives \(f(14) \ge 5 > 4 = \lfloor \log_2 14 \rfloor + 1\), while Stearns' bound \(f(n) \ge \lfloor \log_2 n \rfloor + 1\) holds for every \(n \ge 1\).

    public theorem_wanted transitiveSubtournamentNumberEqLogTwo_refuted :
    ¬ transitiveSubtournamentNumberEqLogTwo
    def transitiveSubtournamentNumberEqLogTwo : Prop :=
  ∀ n : ℕ, 1 ≤ n → transitiveSubtournamentNumber n = Nat.log 2 n + 1

    The six-vertex tournament \(T^*\). The tournament \(T^*\) is the relation on the vertex set \(\{0, \dots, 5\}\) with an arc \(i \to j\) if and only if either \((i, j)\) is one of the backward arcs \((5, 0)\), \((5, 2)\), \((4, 1)\), \((3, 0)\), or \(i < j\) and \((j, i)\) is not a backward arc.

    MathlibExt.Combinatorics.TournamentErdosHajnalSixVertexAIMCombinatoricsProblem55Wanted.tStarErdosHajnal

    The Erdős–Hajnal problem for the tournament \(T^*\). There is a real number \(\varepsilon > 0\) such that for every natural number \(n\) and every tournament \(T\) on the vertex set \(\{0, \dots, n-1\}\) that does not contain \(T^*\) as a subtournament, there is a set \(S\) of vertices on which \(T\) is transitive with \(|S| \ge n^{\varepsilon}\).

    This is Problem 1.12 of the AimPL problem list on graph Ramsey theory.

    def tStarErdosHajnal : Prop :=
  ∃ ε : ℝ, 0 < ε ∧ ∀ (n : ℕ) (T : Fin n → Fin n → Prop), IsTournament T → ¬ ContainsTStar T →

    Nguyen–Scott–Seymour: \(T^*\) has the Erdős–Hajnal property. There is a real number \(\varepsilon > 0\) such that for every natural number \(n\) and every tournament \(T\) on the vertex set \(\{0, \dots, n-1\}\) that does not contain \(T^*\) as a subtournament, there is a set \(S\) of vertices on which \(T\) is transitive with \(|S| \ge n^{\varepsilon}\).
