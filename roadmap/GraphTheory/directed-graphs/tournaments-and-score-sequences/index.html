    A tournament on the players \(1, \dots, n\) is a binary relation \(T\), where \(T(i, j)\) means that \(i\) beats \(j\), such that no player beats itself and for any two distinct players \(i\) and \(j\) exactly one of \(T(i, j)\) and \(T(j, i)\) holds.

    def IsTournament {n : ℕ} (T : Fin n → Fin n → Bool) :
    Prop :=
  (∀ i, T i i = false) ∧ ∀ i j, i ≠ j → T i j ≠ T j i

    DefinitionScore of a player#✓fully proved

    MathlibExt.GraphTheory.TournamentScoreSequenceWanted.score

    Let \(T\) be a binary relation on the players \(1, \dots, n\), where \(T(i, j)\) means that \(i\) beats \(j\). The score of a player \(i\) is the number of players \(j\) such that \(T(i, j)\) holds, that is, the number of players that \(i\) beats.

    In a tournament this is the outdegree of \(i\).

    def score {n : ℕ} (T : Fin n → Fin n → Bool) (i : Fin n) :
    ℕ :=
  (Finset.univ.filter (fun j => T i j)).card

    A tournament is reducible if some nonempty proper set of players loses all games against the complement.

    DefinitionCircular triad#✓fully proved

    MathlibExt.GraphTheory.TournamentScoreSequenceWanted.IsCircularTriad

    Let \(T\) be a binary relation on the players \(1, \dots, n\), where \(T(i, j)\) means that \(i\) beats \(j\). A set \(S\) of players is a circular triad of \(T\) if \(S\) has exactly three elements and every \(i \in S\) beats exactly one \(j \in S\).

    In a tournament this means that the three players form a directed \(3\)-cycle.

    def IsCircularTriad {n : ℕ} (T : Fin n → Fin n → Bool)
    (S : Finset (Fin n)) : Prop :=
  S.card = 3 ∧
    ∀ i ∈ S, (S.filter (fun j => T i j)).card = 1

    For natural numbers \(a\) and \(b\), let \(g(n) = n! \binom{n-a+b}{b}\) for \(n \ge a\) and \(g(n) = 0\) for \(n < a\), and let \(A(x) = \sum_{n \ge 0} g(n) x^n / n!\) be its exponential generating function, a formal power series over \(\mathbb{Q}\).     TheoremLandau's theorem on score sequences#●ready to prove

    MathlibExt.GraphTheory.TournamentScoreSequenceWanted.landau_score_sequence

    Let \(s_1 \le s_2 \le \dots \le s_n\) be a nondecreasing sequence of natural numbers. There is a tournament on \(n\) players in which player \(i\) has score \(s_i\) for every \(i\) if and only if \(\sum_{i=1}^{k} s_i \ge \binom{k}{2}\) for every \(k\) with \(1 \le k \le n\) and \(\sum_{i=1}^{n} s_i = \binom{n}{2}\).

    theorem_wanted landau_score_sequence (n : ℕ)
    (s : Fin n → ℕ)
    (hs : ∀ i j : Fin n, i ≤ j → s i ≤ s j) :
    (∃ T : Fin n → Fin n → Bool, IsTournament T ∧
      ∀ i, score T i = s i) ↔
    (∀ k : ℕ, ∀ hk : k ≤ n, 1 ≤ k →
      Nat.choose k 2 ≤
        ∑ i : Fin k, s (Fin.castLE hk i)) ∧
    (∑ i, s i) = Nat.choose n 2
