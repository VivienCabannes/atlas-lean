    SimpleGraph.IsCriticalEdges

    Let \(G\) be a graph and \(S\) a set of unordered pairs of its vertices. Then \(S\) is critical for \(G\) if deleting the edges of \(G\) that lie in \(S\) strictly lowers the chromatic number, as an element of \(\mathbb{N} \cup \{\infty\}\).

    def IsCriticalEdges (edges : Set (Sym2 V)) : Prop :=
  (G.deleteEdges edges).chromaticNumber < G.chromaticNumber

    For a graph \(G\) and an unordered pair \(e\) of vertices, \(e\) is a critical edge of \(G\) if removing \(e\) from the edge set of \(G\) strictly lowers the chromatic number of \(G\), taken in \(\mathbb{N} \cup \{\infty\}\).

    SimpleGraph.IsCritical

    Let \(k\) be a natural number. A graph \(G\) is \(k\)-critical (or vertex-critical) if its chromatic number equals \(k\) and every vertex \(v\) of \(G\) is critical, that is, deleting \(v\) from \(G\) strictly lowers the chromatic number.

    DefinitionCocolorable graphs#✓fully proved

    SimpleGraph.Cocolorable

    A graph \(G\) is cocolorable with \(n\) colors if there is a map from its vertices to the colors \(\{0, \dots, n-1\}\) such that each color class induces either an independent set or a complete graph in \(G\).

    def Cocolorable (G : SimpleGraph V) (n : ℕ) : Prop := ∃ coloring : V → Fin n,
  ∀ i, G.induce {v | coloring v = i} = ⊥ ∨ G.induce {v | coloring v = i} = ⊤

    DefinitionCochromatic number#✓fully proved

    SimpleGraph.cochromaticNumber

    The cochromatic number of a graph \(G\), an element of \(\mathbb{N} \cup \{\infty\}\), is the least natural number \(n\) such that \(G\) is cocolorable with \(n\) colors, that is, the least number of colors in a coloring of the vertices of \(G\) in which each color class induces either an independent set or a complete graph. It is \(\infty\) exactly when \(G\) is not cocolorable with any finite number of colors.

    noncomputable def cochromaticNumber (G : SimpleGraph V) : ℕ∞ := ⨅ n ∈ Set.ofPred G.Cocolorable,
  (n : ℕ∞)

    DefinitionChromatic cardinal of a graph#✓fully proved

    SimpleGraph.chromaticCardinal

    The chromatic cardinal is the minimal number of colors need to color it. In contrast to chromaticNumber, which assigns ⊤ : ℕ∞ to all non-finitely colorable graphs, this definition returns a Cardinal and can therefore distinguish between different infinite chromatic numbers.

    noncomputable def chromaticCardinal.{u} {V : Type u} (G : SimpleGraph V) : Cardinal :=
  sInf {κ : Cardinal | ∃ (C : Type u) (_ : Cardinal.mk C = κ), Nonempty (G.Coloring C)}

    SimpleGraph.indepNumK

    For a graph \(G\) on a finite vertex set and a natural number \(k\), this is the maximum number of vertices in a union of \(k\) (possibly empty, possibly overlapping) independent sets of \(G\).

    noncomputable def indepNumK (G : SimpleGraph V) [Fintype V] (k : ℕ) : ℕ :=
  sSup {n | ∃ f : Fin k → Set V, (∀ i, G.IsIndepSet (f i)) ∧ (⋃ i, f i).ncard = n}

    DefinitionCDS-colorable graphs#✓fully proved

    SimpleGraph.CDSColorable

    A graph \(G\) on a finite vertex set is CDS-colorable if it has a proper coloring \(C\) with colors in \(\mathbb{N}\) such that for every \(k \in \mathbb{N}\), the number of vertices whose color under \(C\) is less than \(k\) equals the maximum size of a union of \(k\) independent sets of \(G\).

    def CDSColorable [Fintype α] (G : SimpleGraph α) : Prop :=
    ∃ (C : G.Coloring Nat), ∀ k : Nat,
   ∑ i < k, (C.colorClass i).ncard = indepNumK G k

    DefinitionRainbow homomorphisms#✓fully proved

    SimpleGraph.IsRainbow

    Let \(f\) be a graph homomorphism from \(H\) to \(G\) and let \(c\) be a labeling of the edges of \(G\) by elements of a type \(K\). Then \(f\) is rainbow for \(c\) if distinct edges of \(H\) are mapped to edges of \(G\) with distinct labels, that is, the labeling \(e \mapsto c(f(e))\) of the edges of \(H\) is injective.

    def IsRainbow {α V K : Type*} {H : SimpleGraph α} {G : SimpleGraph V} (f : H →g G)
    (c : G.EdgeLabeling K) : Prop :=
  Function.Injective (c.pullback f)

    DefinitionAnti-Ramsey number#✓fully proved

    SimpleGraph.antiRamseyNum

    For a graph \(H\) on a finite vertex type and a natural number \(n\), the anti-Ramsey number \(\mathrm{AR}(n, H)\) is the largest \(k\) for which there is a coloring of the edges of the complete graph \(K_n\) on \(\{0, \dots, n-1\}\) with colors \(\{0, \dots, k-1\}\), every color used, that contains no rainbow copy of \(H\). Here a copy of \(H\) is an injective homomorphism from \(H\) to \(K_n\), and it is rainbow when distinct edges of \(H\) are sent to edges of distinct colors. If no such \(k\) exists, \(\mathrm{AR}(n, H) = 0\).

    noncomputable def antiRamseyNum {α : Type*} [Fintype α] (H : SimpleGraph α) (n : ℕ) : ℕ :=
  sSup {k | ∃ c : TopEdgeLabeling (Fin n) (Fin k), Function.Surjective c ∧
    ∀ f : H.Copy ⊤, ¬IsRainbow f.toHom c}
    def IsRainbow {α V K : Type*} {H : SimpleGraph α} {G : SimpleGraph V} (f : H →g G)
    (c : G.EdgeLabeling K) : Prop :=
  Function.Injective (c.pullback f)
