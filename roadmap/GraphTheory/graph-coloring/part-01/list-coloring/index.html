    SimpleGraph.IsListColorable

    A simple graph \(G\) is \(q\)-list-colorable if, for every set of colors and every assignment of a finite list \(L(v)\) of at least \(q\) colors to each vertex \(v\), there is a proper coloring \(c\) of \(G\) with \(c(v) \in L(v)\) for every vertex \(v\).

    def IsListColorable (G : SimpleGraph V) (q : ℕ) : Prop :=
  ∀ (C : Type) [DecidableEq C] (lists : V → Finset C),
    (∀ v, q ≤ (lists v).card) →
      ∃ color : G.Coloring C, ∀ v, color v ∈ lists v

    SimpleGraph.IsChoiceNumber

    A natural number \(q\) is the choice number of a simple graph \(G\) if \(G\) is \(q\)-list-colorable but is not \(r\)-list-colorable for any \(r < q\).

    def IsChoiceNumber (G : SimpleGraph V) (q : ℕ) : Prop :=
  G.IsListColorable q ∧ ∀ r < q, ¬G.IsListColorable r

    DefinitionPartial list colorability#✓fully proved

    MathlibExt.Combinatorics.PartialListColoringProportionalBoundWanted.IsPartialListColoring

    Let \(G\) be a simple graph and assign to each vertex \(v\) a finite list \(L(v)\) of colors. A finite set \(S\) of vertices is partially list-colorable from \(L\) when the subgraph of \(G\) induced by \(S\) has a proper coloring \(c\) with \(c(v) \in L(v)\) for every \(v \in S\). No colors are assigned to vertices outside \(S\).

    def IsPartialListColoring {V C : Type*} [DecidableEq C]
    (G : SimpleGraph V) (lists : V → Finset C) (S : Finset V) : Prop :=
  ∃ color : S → C, (∀ v : S, color v ∈ lists (v : V)) ∧
    (∀ v w : S, G.Adj (v : V) (w : V) → color v ≠ color w)

    MathlibExt.Combinatorics.PartialListColoringProportionalBoundWanted.conjecture

    Let \(G\) be a finite simple graph on \(n\) vertices whose choice number \(q\) is positive, let \(t \le q\) be a natural number, and assign to each vertex \(v\) a list \(L(v)\) of exactly \(t\) colors. Then there is a set \(S\) of vertices of \(G\) that is partially list-colorable from \(L\) (the subgraph of \(G\) induced by \(S\) has a proper coloring giving each vertex a color from its list) and satisfies \(tn \le q|S|\), that is, \(|S| \ge tn/q\).

    def conjecture : Prop :=
  ∀ (V : Type) [Fintype V] [DecidableEq V]
    (G : SimpleGraph V) [DecidableRel G.Adj] (q : ℕ),
    0 < q → G.IsChoiceNumber q →
    ∀ (t : ℕ), t ≤ q →
    ∀ (C : Type) [DecidableEq C] (lists : V → Finset C),
    (∀ v, (lists v).card = t) →
    ∃ S : Finset V, IsPartialListColoring G lists S ∧ t * Fintype.card V ≤ q * S.card

    MathlibExt.Combinatorics.PartialListColoringProportionalBoundWanted.conjecture_refuted

    There exist a finite simple graph \(G\) on \(n\) vertices whose choice number \(q\) is positive, a natural number \(t \le q\), and an assignment to each vertex \(v\) of a list \(L(v)\) of exactly \(t\) colors, such that every set \(S\) of vertices of \(G\) whose induced subgraph has a proper coloring giving each vertex a color from its list satisfies \(q|S| < tn\).

    MathlibExt.GraphTheory.PartialListColoringWanted.IsListColoring

    Let \(G\) be a graph on a finite vertex set \(V\), let \(L\) assign to each vertex \(v\) a finite list \(L(v)\) of colours (natural numbers), and let \(S \subseteq V\). A map \(f : V \to \mathbb{N}\) is a proper \(L\)-colouring of \(S\) when \(f(v) \in L(v)\) for every \(v \in S\) and \(f(v) \ne f(w)\) for all adjacent \(v, w \in S\).

    def IsListColoring {V : Type*} [Fintype V] [DecidableEq V]

  (∀ v ∈ S, f v ∈ L v) ∧ ∀ v ∈ S, ∀ w ∈ S, G.Adj v w → f v ≠ f w

    TheoremThe partial list colouring conjecture is false#●ready to prove

    MathlibExt.GraphTheory.PartialListColoringWanted.conjecture_refuted

    There exist a finite graph \(G\) with choice number \(\chi_\ell\) and natural numbers \(r\), \(s\) with \(1 \le r \le s \le \chi_\ell\) such that \(\lambda_r / r < \lambda_s / s\), where \(\lambda_t\) is the minimum, over all assignments of lists of exactly \(t\) colours to the vertices, of the largest number of vertices of \(G\) that can be properly coloured from their lists. So Iradmusa's partial list colouring conjecture fails.

    Noel's counterexample (Theorem 1.1) is a 14-vertex graph (four triangles plus two terminals) with choice number 3 and a 2-list assignment colouring at most 9 vertices, so \(\lambda_2 / 2 \le 9/2 < 14/3 = \lambda_3 / 3\).

    public theorem_wanted conjecture_refuted : ¬ conjecture

    (lambdaMin G r : ℚ) / (r : ℚ) ≥ (lambdaMin G s : ℚ) / (s : ℚ)
