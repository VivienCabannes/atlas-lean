    DefinitionIndependent codes for the modular cycle#✓fully proved

    MathlibExt.Combinatorics.Coding.CycleGraphCode.IsCycleCode

    Let \(q\) and \(n\) be natural numbers. A finite set \(A\) of words of length \(n\) over \(\mathbb{Z}/q\mathbb{Z}\) is an independent code for the \(q\)-cycle when every difference \(x = a_1 - a_2\) with \(a_1, a_2 \in A\) whose coordinates all lie in \(\{-1, 0, 1\}\) is the zero word. For \(q \ge 3\) this says exactly that \(A\) is an independent set in the \(n\)-th strong power of the cycle graph \(C_q\).

    The source uses odd \(q \ge 7\); the definition is stated for every \(q\).

    def IsCycleCode (q : ℕ) {n : ℕ} (A : Finset (Fin n → ZMod q)) : Prop :=
  ∀ (x : Fin n → ZMod q),
    (∃ a₁ ∈ A, ∃ a₂ ∈ A, a₁ - a₂ = x) →
    (∀ i : Fin n, x i = -1 ∨ x i = 0 ∨ x i = 1) →
    x = 0

    DefinitionShannon capacity of the modular cycle#✓fully proved

    MathlibExt.Combinatorics.Coding.CycleGraphCode.shannonCapacityCycle

    For a natural number \(q\), the Shannon capacity of the \(q\)-cycle is the supremum, in \([0, \infty]\), of the rates \(|A|^{1/n}\) over all positive integers \(n\) and all cycle codes \(A\) of length \(n\) modulo \(q\).

    noncomputable def shannonCapacityCycle (q : ℕ) : ENNReal :=
  ⨆ (n : PositiveNat) (A : CycleCode q n.1), cycleCodeRate q n A

    DefinitionProduct of BPZ profiles#✓fully proved

    MathlibExt.Combinatorics.Coding.CycleShannonBoundsWanted.BPZProfile.star

    For \(i = 1, 2\) let \(p_i = (c_i, \pi_i, a_i, z_i)\) be a BPZ profile, with integer code, pairs, auxiliary and neutral coordinates. The product \(p_1 \star p_2\) is the BPZ profile with code coordinate \((c_1 - \pi_1)(c_2 - \pi_2) + a_1 \pi_2 + \pi_1 a_2\), pairs coordinate \(z_1 \pi_2 + \pi_1 z_2\), auxiliary coordinate \(a_1 a_2\) and neutral coordinate \(z_1 z_2 + (a_1 - z_1)(a_2 - z_2)\).

    The product is arithmetic on the four coordinates only; it does not supply an independent set.

    def BPZProfile.star (p₁ p₂ : BPZProfile) : BPZProfile where
  code :=
    (p₁.code - p₁.pairs) * (p₂.code - p₂.pairs) +
      p₁.auxiliary * p₂.pairs + p₁.pairs * p₂.auxiliary
  pairs := p₁.neutral * p₂.pairs + p₁.pairs * p₂.neutral
  auxiliary := p₁.auxiliary * p₂.auxiliary
  neutral :=
    p₁.neutral * p₂.neutral +
      (p₁.auxiliary - p₁.neutral) * (p₂.auxiliary - p₂.neutral)
