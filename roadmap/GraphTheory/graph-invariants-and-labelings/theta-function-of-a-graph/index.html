    Theta function of a graph

    The Lovász theta function \(\vartheta(G)\) is defined by orthogonal labelings (orthonormal representations): vectors \(a_v\), one per vertex, with \(a_u \perp a_v\) whenever \(u \ne v\) are not adjacent. Relative to a nonzero handle \(c\), the cost of \(a_v\) is the squared cosine \(\langle c, a_v\rangle^2 / (\lVert c\rVert^2 \lVert a_v\rVert^2)\), and \(\vartheta(G)\) is the least possible value of \(\max_v 1/\mathrm{cost}(a_v)\). Two pieces of linear algebra give Lovász's sandwich theorem \(\alpha(G) \le \vartheta(G) \le \chi(\bar G)\): Bessel's inequality bounds the total cost of a stable set by \(1\), and a cover of the vertices by \(k\) cliques yields a labeling all of whose costs are \(1/k\). On perfect graphs the sandwich collapses, so \(\vartheta(G) = \alpha(G)\). Grötschel, Lovász and Schrijver showed that \(\vartheta\) can be computed in polynomial time with the ellipsoid method, which gives polynomial algorithms for stable sets, cliques and colourings in perfect graphs; that algorithmic statement is not formalised here, nor are the other characterisations of \(\vartheta\) (eigenvalues, semidefinite duality). The theta body \(\mathrm{TH}(G)\) of Grötschel, Lovász and Schrijver is defined and placed between the stable set polytope and the clique-constrained polytope; that \(\vartheta(G)\) is the maximum of \(\sum_v x_v\) over it, and that \(\mathrm{STAB}(G) = \mathrm{QSTAB}(G)\) exactly for perfect graphs, are recorded as wanted.

    DefinitionOrthogonal labeling of a graph#✓fully proved

    MathlibExt.Combinatorics.SimpleGraph.LovaszTheta.IsOrthogonalLabeling

    Let \(G\) be a simple graph on a vertex set \(V\) and \(E\) a real inner product space. A map \(a \colon V \to E\) is an orthogonal labeling of \(G\) if

    \[ \langle a_u, a_v\rangle = 0 \quad\text{whenever } u \ne v \text{ and } u, v \text{ are not adjacent in } G. \]

    The vectors may have any dimension, and the zero labeling always works. After scaling the nonzero vectors to unit length this is Lovász's orthonormal representation. Adjacent vertices are unconstrained, so the vectors of a stable set are pairwise orthogonal.

    def IsOrthogonalLabeling (G : SimpleGraph V) (a : V → E) : Prop :=
  ∀ ⦃u v : V⦄, u ≠ v → ¬ G.Adj u v → ⟪a u, a v⟫ = 0

    DefinitionCost of a vector in an orthogonal labeling#✓fully proved

    MathlibExt.Combinatorics.SimpleGraph.LovaszTheta.cost

    Fix a vector \(c\) (the handle) in a real inner product space. The cost of a vector \(x\) is

    \[ \mathrm{cost}_c(x) = \frac{\langle c, x\rangle^2}{\lVert c\rVert^2 \lVert x\rVert^2}, \]

    the squared cosine of the angle between \(c\) and \(x\); it is \(0\) when \(x = 0\) or \(c = 0\). Scaling \(x\) by a nonzero scalar does not change its cost.

    Knuth takes the first coordinate vector as handle, so that the cost of a unit vector is the square of its first coordinate; Lovász allows any unit handle. An orthogonal change of coordinates moves any unit handle to the first coordinate vector (Knuth, Lemma 0), so the two conventions give the same theta function; that equivalence is not formalised here.

    noncomputable def cost (c x : E) : ℝ :=
  ⟪c, x⟫ ^ 2 / (‖c‖ ^ 2 * ‖x‖ ^ 2)

    TheoremStable sets have total cost at most one#✓fully proved

    MathlibExt.Combinatorics.SimpleGraph.LovaszTheta.sum_cost_le_one

    Let \(a\) be an orthogonal labeling of \(G\), let \(c\) be any vector and let \(S\) be a stable set of \(G\) (no two of its vertices are adjacent). Then

    \[ \sum_{v \in S} \mathrm{cost}_c(a_v) \le 1 . \]

    The nonzero vectors \(a_v/\lVert a_v\rVert\), \(v \in S\), are orthonormal because \(S\) is stable, so Bessel's inequality gives \(\sum_{v \in S} \langle a_v/\lVert a_v\rVert, c\rangle^2 \le \lVert c\rVert^2\); dividing by \(\lVert c\rVert^2\) is the claim. Vertices with \(a_v = 0\) have cost \(0\). Knuth proves the same inequality by completing the orthonormal vectors to an orthogonal matrix.

    theorem sum_cost_le_one {G : SimpleGraph V} {a : V → E} (ha : IsOrthogonalLabeling G a)
    (c : E) {s : Finset V} (hs : G.IsIndepSet (s : Set V)) :
    ∑ v ∈ s, cost c (a v) ≤ 1

    DefinitionFeasible values of the theta program#✓fully proved

    MathlibExt.Combinatorics.SimpleGraph.LovaszTheta.thetaFeasible

    For a graph \(G\) on \(V\), a real number \(t \ge 0\) is feasible if there are a dimension \(d\), an orthogonal labeling \(a \colon V \to \mathbb{R}^d\) of \(G\) and a nonzero handle \(c \in \mathbb{R}^d\) with

    \[ 1 \le t \cdot \mathrm{cost}_c(a_v) \quad\text{for every vertex } v, \]

    that is, every cost is positive and \(\max_v 1/\mathrm{cost}_c(a_v) \le t\). The feasible values form an up-closed set of nonnegative reals.

    def thetaFeasible (G : SimpleGraph V) : Set ℝ :=
  {t : ℝ | 0 ≤ t ∧ ∃ (d : ℕ) (a : V → EuclideanSpace ℝ (Fin d)) (c : EuclideanSpace ℝ (Fin d)),
    c ≠ 0 ∧ IsOrthogonalLabeling G a ∧ ∀ v, 1 ≤ t * cost c (a v)}

    DefinitionLovász theta function#✓fully proved

    MathlibExt.Combinatorics.SimpleGraph.LovaszTheta.lovaszTheta

    The Lovász number of a graph \(G\) is the infimum of the feasible values of the theta program:

    \[ \vartheta(G) = \inf_{a,\,c} \ \max_{v} \frac{1}{\mathrm{cost}_c(a_v)}, \]

    over all orthogonal labelings \(a\) of \(G\) in some \(\mathbb{R}^d\) and all nonzero handles \(c \in \mathbb{R}^d\). The infimum is in fact attained (Lovász), but the definition does not need that. For a finite graph it is at least the independence number and at most the chromatic number of the complement (sandwich theorem). The graph with no vertices has \(\vartheta = 0\).

    This is the min-max form; Knuth defines \(\vartheta(G)\) as \(\max\{\mathbf 1 \cdot x : x \in \mathrm{TH}(G)\}\) and proves that the two agree (his eq. (5.1)); that equality is not formalised here.

    noncomputable def lovaszTheta (G : SimpleGraph V) : ℝ :=
  sInf (thetaFeasible G)
    def thetaFeasible (G : SimpleGraph V) : Set ℝ :=
  {t : ℝ | 0 ≤ t ∧ ∃ (d : ℕ) (a : V → EuclideanSpace ℝ (Fin d)) (c : EuclideanSpace ℝ (Fin d)),
    c ≠ 0 ∧ IsOrthogonalLabeling G a ∧ ∀ v, 1 ≤ t * cost c (a v)}

    TheoremA colouring of the complement gives a feasible theta value#✓fully proved

    MathlibExt.Combinatorics.SimpleGraph.LovaszTheta.natCast_mem_thetaFeasible_of_colorable

    If the complement \(\bar G\) has a proper colouring with \(k\) colours, then \(k\) is a feasible value of the theta program for \(G\). The colour classes of \(\bar G\) are cliques of \(G\). Give each vertex the unit coordinate vector \(e_i\) of its colour \(i\) in \(\mathbb{R}^k\), and take the all-ones handle \(c = e_1 + \dots + e_k\). Two non-adjacent vertices of \(G\) are adjacent in \(\bar G\), so they have different colours and orthogonal labels. Every cost is \(\langle c, e_i\rangle^2 / (\lVert c\rVert^2 \lVert e_i\rVert^2) = 1/k\), so \(1 \le k \cdot \mathrm{cost}\). When \(k = 0\) the vertex set is empty and any handle in \(\mathbb{R}^1\) works.

    theorem natCast_mem_thetaFeasible_of_colorable {G : SimpleGraph V} {k : ℕ}

    TheoremLovász's sandwich theorem#✓fully proved

    MathlibExt.Combinatorics.SimpleGraph.LovaszTheta.sandwich

    For every finite graph \(G\),

    \[ \alpha(G) \le \vartheta(G) \le \chi(\bar G). \]

    Both \(\alpha(G)\) and \(\chi(\bar G)\) are NP-hard to compute, while \(\vartheta(G)\) can be computed to any precision in polynomial time (Grötschel, Lovász and Schrijver); that algorithmic statement is not formalised here. Knuth states the same theorem for the complement, as \(\omega(G) \le \vartheta(\bar G) \le \chi(G)\).

    theorem sandwich [Finite V] (G : SimpleGraph V) :
    (G.indepNum : ℝ) ≤ lovaszTheta G ∧ lovaszTheta G ≤ (Gᶜ.chromaticNumber.toNat : ℝ)
    noncomputable def lovaszTheta (G : SimpleGraph V) : ℝ :=
  sInf (thetaFeasible G)

    TheoremTheta equals the independence number on perfect graphs#✓fully proved

    MathlibExt.Combinatorics.SimpleGraph.LovaszTheta.lovaszTheta_eq_indepNum_of_isPerfect

    If the finite graph \(G\) is perfect, then \(\vartheta(G) = \alpha(G)\). By Lovász's perfect graph theorem the complement \(\bar G\) is perfect, so applied to the whole vertex set \(\chi(\bar G) = \omega(\bar G) = \alpha(G)\), and the sandwich theorem \(\alpha(G) \le \vartheta(G) \le \chi(\bar G)\) collapses. Together with the polynomial-time computability of \(\vartheta\) (not formalised here), this is how Grötschel, Lovász and Schrijver compute \(\alpha\), \(\omega\) and \(\chi\) of perfect graphs in polynomial time.

    MathlibExt.Combinatorics.SimpleGraph.LovaszTheta.th

    For a finite graph \(G\) on \(V\), the theta body of Grötschel, Lovász and Schrijver is

    \[ \mathrm{TH}(G) = \Bigl\{x \in \mathbb{R}^V : x \ge 0,\ \sum_{v} \mathrm{cost}_c(a_v)\, x_v \le 1 \text{ for every orthogonal labeling } a \text{ of } G \text{ and every handle } c\Bigr\}, \]

Knuth fixes the handle to the first coordinate vector; by an orthogonal change of coordinates (his Lemma 0) the two definitions give the same set.
