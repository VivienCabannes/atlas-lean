    DefinitionRamsey graphs for the triangle#✓fully proved

    MathlibExt.Combinatorics.TriangleRamseyMinimalThetaWanted.IsTriangleRamsey

    A graph \(G\) on the vertex set \(\{0, \dots, n - 1\}\) is \(r\)-Ramsey for the triangle when every colouring \(c\) of the ordered pairs of vertices with \(r\) colours that is symmetric (\(c(a, b) = c(b, a)\)) admits three distinct vertices \(u, v, w\) that form a triangle in \(G\) with \(c(u, v) = c(v, w) = c(w, u)\).

    For \(r \ge 1\) this says that every colouring of the edges of \(G\) with \(r\) colours has a monochromatic triangle.

    def IsTriangleRamsey (n : ℕ) (G : SimpleGraph (Fin n)) (r : ℕ) : Prop :=
  ∀ c : Fin n → Fin n → Fin r,
    (∀ a : Fin n, ∀ b : Fin n, c a b = c b a) →
      ∃ u : Fin n, ∃ v : Fin n, ∃ w : Fin n,
        u ≠ v ∧ v ≠ w ∧ w ≠ u ∧ G.Adj u v ∧ G.Adj v w ∧ G.Adj w u ∧
          c u v = c v w ∧ c v w = c w u

    DefinitionRamsey-minimal graphs for the triangle#✓fully proved

    MathlibExt.Combinatorics.TriangleRamseyMinimalThetaWanted.IsRamseyMinimal

    A graph \(G\) on the vertex set \(\{0, \dots, n - 1\}\) is \(r\)-Ramsey-minimal for the triangle when \(G\) is \(r\)-Ramsey for the triangle, no proper spanning subgraph of \(G\) (a graph on the same vertices whose edges are edges of \(G\), missing at least one of them) is \(r\)-Ramsey for the triangle, and for every vertex \(x\) it is false that every symmetric colouring of the ordered pairs of vertices with \(r\) colours admits a triangle of \(G\) avoiding \(x\) whose three edges have the same colour.

    Given the first two conditions, the last one says exactly that \(G\) has no isolated vertices.

    def IsRamseyMinimal (n : ℕ) (G : SimpleGraph (Fin n)) (r : ℕ) : Prop :=
  IsTriangleRamsey n G r ∧
    (∀ H : SimpleGraph (Fin n),
      (∀ u : Fin n, ∀ v : Fin n, H.Adj u v → G.Adj u v) →
        (∃ u : Fin n, ∃ v : Fin n, G.Adj u v ∧ ¬ H.Adj u v) →
          ¬ IsTriangleRamsey n H r) ∧
    ∀ x : Fin n, ¬ IsTriangleRamseyDeleteVertex n G r x

    MathlibExt.Combinatorics.TriangleRamseyMinimalThetaWanted.HasMinDegree

    A graph \(G\) on the vertex set \(\{0, \dots, n - 1\}\) has minimum degree \(d\) when every vertex of \(G\) has at least \(d\) neighbours and some vertex of \(G\) has exactly \(d\) neighbours; in particular \(n \ge 1\).

    def HasMinDegree (n : ℕ) (G : SimpleGraph (Fin n)) (d : ℕ) : Prop :=
  (∀ v : Fin n, d ≤ Set.ncard { w : Fin n | G.Adj v w }) ∧
    ∃ v : Fin n, Set.ncard { w : Fin n | G.Adj v w } = d

    MathlibExt.Combinatorics.TriangleRamseyMinimalThetaWanted.sRamsey

    For a natural number \(r\), \(s_r(K_3)\) is the least natural number \(d\) such that, for some \(n\), some graph on the vertex set \(\{0, \dots, n - 1\}\) is \(r\)-Ramsey-minimal for the triangle and has minimum degree \(d\); if no such graph exists, \(s_r(K_3) = 0\).

    noncomputable def sRamsey (r : ℕ) : ℕ := by
  classical
  exact if h : ∃ d : ℕ, ∃ n : ℕ, ∃ G : SimpleGraph (Fin n),
      IsRamseyMinimal n G r ∧ HasMinDegree n G d then Nat.find h else 0

    Let \(s_r(K_3)\) be the least minimum degree of a graph that is \(r\)-Ramsey-minimal for the triangle, with \(s_r(K_3) = 0\) if there is no such graph, as defined for the conjecture.     Resolved true: Guo and Warnke (Packing nearly optimal Ramsey R(3,t) graphs, arXiv:1711.05877) prove this, confirming the conjecture of Fox, Grinshpun, Liebenau, Person and Szabó.

    InductiveTrees of triangles#✓fully proved

    MathlibExt.Combinatorics.TriangleTreeLocalRamseyWanted.IsTriangleTree

    The trees of triangles on a vertex set \(V\) are the graphs on \(V\) built recursively as follows. A graph whose edges are exactly the three edges of a triangle on distinct vertices \(a, b, c\) is a tree of triangles. If \(H_0\) is a tree of triangles, \(xy\) is an edge of \(H_0\), and \(z\) is a vertex different from \(x\) and \(y\) with no neighbours in \(H_0\), then the graph obtained from \(H_0\) by joining \(z\) to \(x\) and to \(y\) is a tree of triangles.

    MathlibExt.Combinatorics.TriangleTreeLocalRamseyWanted.IsTriangleTree · 17 lines 
    inductive IsTriangleTree {V : Type*} : SimpleGraph V → Prop where
  | base : ∀ (H : SimpleGraph V) (a b c : V),
      a ≠ b → b ≠ c → a ≠ c →
      H.Adj a b → H.Adj b c → H.Adj a c →
      (∀ x y : V, H.Adj x y →
        (x = a ∨ x = b ∨ x = c) ∧ (y = a ∨ y = b ∨ y = c)) →
      (∀ x y : V, (x = a ∨ x = b ∨ x = c) →
        (y = a ∨ y = b ∨ y = c) → x ≠ y → H.Adj x y) →
      IsTriangleTree H
  | step : ∀ (H₀ H : SimpleGraph V) (z x y : V),
      IsTriangleTree H₀ →
      H₀.Adj x y → x ≠ y → z ≠ x → z ≠ y →
      (¬ ∃ w : V, H₀.Adj z w) →
      H.Adj x z → H.Adj y z →
      (∀ w : V, H.Adj z w → w = x ∨ w = y) →
      (∀ u v : V, u ≠ z → v ≠ z → (H.Adj u v ↔ H₀.Adj u v)) →
      IsTriangleTree H

    MathlibExt.Combinatorics.TriangleTreeLocalRamseyWanted.Ramseys2Triangle

    A graph \(G\) arrows the triangle in two colours, written \(G \to_2 K_3\), if every colouring of the edges of \(G\) with two colours contains a monochromatic triangle: three distinct pairwise adjacent vertices whose three edges all have the same colour.

    def Ramseys2Triangle {V : Type*} (G : SimpleGraph V) : Prop :=
  ∀ χ : ∀ (x y : V), G.Adj x y → Fin 2,
    (∀ (x y : V) (h₁ : G.Adj x y) (h₂ : G.Adj y x), χ x y h₁ = χ y x h₂) →
    ∃ a b c : V, ∃ (hab : G.Adj a b) (hbc : G.Adj b c) (hac : G.Adj a c),
      a ≠ b ∧ b ≠ c ∧ a ≠ c ∧ χ a b hab = χ b c hbc ∧ χ a b hab = χ a c hac

    MathlibExt.Combinatorics.TriangleTreeLocalRamseyWanted.conjecture

    This is the statement that for every natural number \(\ell\) there is a finite graph \(G\) with at least \(\ell\) vertices such that \(G \to_2 K_3\) (every colouring of the edges of \(G\) with two colours contains a monochromatic triangle) and \(G\) is locally a tree of triangles on \(\ell\) vertices: for every set \(S\) of exactly \(\ell\) vertices of \(G\), some tree of triangles on the vertex set of \(G\) contains every edge of \(G\) with both endpoints in \(S\).

    TheoremRamsey graphs for the triangle that are locally trees of triangles#●ready to prove

    MathlibExt.Combinatorics.TriangleTreeLocalRamseyWanted.conjecture_holds

    For every natural number \(\ell\) there is a finite graph \(G\) with at least \(\ell\) vertices such that \(G \to_2 K_3\), that is, every colouring of the edges of \(G\) with two colours contains a monochromatic triangle, and such that for every set \(S\) of exactly \(\ell\) vertices of \(G\), some tree of triangles on the vertex set of \(G\) contains every edge of \(G\) with both endpoints in \(S\).

    This follows from Reiher and Rödl's girth Ramsey theorem (Theorem 1.6 with \(F = K_3\), \(r = 2\), \(n = \ell\)), which gives a graph \(H\) with \(H \to_2 K_3\) in which every set of at most \(\ell\) vertices induces a partial \(K_3\)-forest; such graphs have treewidth at most \(2\), hence lie in trees of triangles (\(2\)-trees).
