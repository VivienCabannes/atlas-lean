    SimpleGraph.classicalRamsey

    For natural numbers \(s\), \(t\) and \(N\), the classical Ramsey property for \((s, t)\) holds at \(N\) when every simple graph \(G\) on \(N\) vertices contains the complete graph \(K_s\) as a subgraph, or its complement \(\overline{G}\) contains \(K_t\) as a subgraph.

    Thus the graph and its complement encode the two colors of a complete graph.

    def classicalRamsey (s t N : ℕ) : Prop :=
  ∀ G : SimpleGraph (Fin N),
    IsContained (completeGraph (Fin s)) G ∨
      IsContained (completeGraph (Fin t)) Gᶜ

    DefinitionClassical Ramsey numbers#✓fully proved

    SimpleGraph.graphRamsey

    For natural numbers \(s\) and \(t\), the Ramsey number \(R(s, t)\) is the least \(N\) such that every simple graph on \(N\) vertices contains the complete graph \(K_s\) as a subgraph or has a complement containing \(K_t\) as a subgraph, and \(0\) if there is no such \(N\).

    Such an \(N\) always exists by the finite Ramsey theorem.

    noncomputable def graphRamsey (s t : ℕ) : ℕ :=
  sInf {N : ℕ | classicalRamsey s t N}

    DefinitionRamsey size linear graphs#✓fully proved

    SimpleGraph.IsRamseySizeLinear

    Let \(G\) be a finite simple graph. For a finite simple graph \(H\), write \(R(G, H)\) for the least \(m\) such that every simple graph on \(m\) vertices contains a copy of \(G\) or has a complement containing a copy of \(H\) (\(0\) if there is no such \(m\)), and write \(e(H)\) for the number of edges of \(H\). Then \(G\) is Ramsey size linear if there is a real constant \(c > 0\) such that for every \(n\) and every simple graph \(H\) on \(n\) vertices with no isolated vertices, \(R(G, H) \le c \cdot e(H)\).

    def IsRamseySizeLinear {α : Type*} [Fintype α] (G : SimpleGraph α) : Prop :=
  ∃ c > (0 : ℝ), ∀ (n : ℕ) (H : SimpleGraph (Fin n)) [DecidableRel H.Adj],
    (∀ v, 0 < H.degree v) →
    (graphPairRamsey G H : ℝ) ≤ c * H.edgeSet.ncard
    noncomputable def graphPairRamsey {α β : Type*} [Fintype α] [Fintype β]
    (G : SimpleGraph α) (H : SimpleGraph β) : ℕ :=
  sInf {n : ℕ | ∀ C : SimpleGraph (Fin n), G.IsContained C ∨ H.IsContained Cᶜ}

    TheoremNo superlinear threshold for triangle-good graphs (Erdős Problem 1182)#●ready to prove

    MathlibExt.Combinatorics.TriangleGoodSparseConnectedGraphsErdosProblem1182Wanted.triangleGoodnessSuperlinearThreshold_refuted

    It is not true that for every real number \(C\), for all sufficiently large natural numbers \(n\), every connected graph \(G\) on the vertex set \(\{0, \dots, n - 1\}\) with at most \(Cn\) edges has \(R(K_3, G) = 2n - 1\). Equivalently, there is a real number \(C\) such that for infinitely many \(n\) some connected graph \(G\) on \(\{0, \dots, n - 1\}\) with at most \(Cn\) edges has \(R(K_3, G) \ne 2n - 1\). Here \(R(K_3, G)\) is the Ramsey number of the pair: the least \(N\) such that every graph on \(N\) vertices contains a triangle or has a complement containing a copy of \(G\), and \(0\) if there is no such \(N\).

    Brandt proved \(F(n) \le 84n\), where \(F(n)\) is the largest \(m\) such that every connected graph on \(n\) vertices with at most \(m\) edges has \(R(K_3, G) = 2n - 1\). So for all large \(n\) some connected graph on \(n\) vertices with at most \(84n + 1\) edges has \(R(K_3, G) \ne 2n - 1\), and the statement fails for \(C = 85\). Brandt's 1996 preprint is unrefereed; erdosproblems.com/1182 accepts it.

    TheoremErdős's lower bound for diagonal Ramsey numbers (existence form)#✓fully proved

    MathlibExt.Combinatorics.RamseyErdosLowerBound.exists_not_isContained_of_choose_mul_lt

    Let \(n, k\) be natural numbers with $\(\binom nk \, 2^{1 - \binom k2} < 1 .\)$ Then there is a simple graph \(G\) on \(n\) vertices such that neither \(G\) nor its complement contains \(K_k\); equivalently, the edges of \(K_n\) can be coloured red and blue with no monochromatic \(K_k\).

    Proof (first moment method): colour each edge red or blue independently with probability \(1/2\), that is, take the random subset of pairs with \(p = 1/2\). A fixed \(k\)-set \(R\) is a red clique with probability \(2^{-\binom k2}\) (containment probability) and a blue clique with the same probability (avoidance probability). By the union bound over the \(\binom nk\) sets, some \(K_k\) is monochromatic with probability at most \(\binom nk 2^{1-\binom k2} < 1\), so some colouring has none.

    theorem exists_not_isContained_of_choose_mul_lt (k : ℕ)
    (h : (n.choose k : ℝ) * 2 ^ (1 - (k.choose 2 : ℤ)) < 1) :
    ∃ G : SimpleGraph (Fin n),
      ¬ (completeGraph (Fin k)).IsContained G ∧ ¬ (completeGraph (Fin k)).IsContained Gᶜ

    TheoremKim's triangle-free graphs with small independence number#●ready to prove

    MathlibExt.Combinatorics.RamseyThreeTWanted.exists_cliqueFree_three_indepNum_le

    Every sufficiently large \(n\) has a triangle-free graph \(G\) on \(n\) vertices with $\(\alpha(G) \le 9 \sqrt{n \log n}\)$ (natural logarithm). Kim builds \(G\) by a semi-random ("nibble") block construction: in each round every edge that does not close a triangle with the edges chosen so far is added independently with probability \(\theta / \sqrt n\), \(\theta = (\log n)^{-2}\), and a maximal disjoint family of conflicting pairs and triples is removed. Martingale concentration keeps the parameters of the process near their expected trajectories, which follow Spencer's differential equation.

    theorem_wanted exists_cliqueFree_three_indepNum_le :
    ∀ᶠ n : ℕ in atTop, ∃ G : SimpleGraph (Fin n),
