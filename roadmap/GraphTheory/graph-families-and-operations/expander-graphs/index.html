    Expander graphs

    Expanders are sparse graphs that behave like random graphs. Two measures appear here: vertex expansion (C-expanders, uniform vertex expanders) and spectral expansion, where a d-regular graph on N vertices has parameter λ when its random-walk matrix shrinks every vector orthogonal to the constants by the factor λ. Spectral expansion controls edge counts (the expander mixing lemma), cannot beat 2√(d - 1)/d asymptotically (Alon-Boppana; Ramanujan graphs attain it), and makes a t-step random walk behave like t independent samples (the hitting property and the Chernoff bound for expander walks).

    DefinitionC-expander#✓fully proved

    SimpleGraph.IsCExpander

    Let \(G\) be a simple graph on a finite vertex set \(V\) with \(n\) vertices, and let \(C\) be a real number. Then \(G\) is a \(C\)-expander if \(C > 0\), every set \(A \subseteq V\) with \(|A| < n/(2C)\) has an external neighbourhood in \(G\) with at least \(C|A|\) vertices, and for any two disjoint sets \(A, B \subseteq V\) with \(|A| \ge n/(2C)\) and \(|B| \ge n/(2C)\) some vertex of \(A\) is adjacent in \(G\) to some vertex of \(B\).

    def IsCExpander [Finite V] (C : ℝ) : Prop :=
  0 < C ∧
    (∀ A : Set V, (A.ncard : ℝ) < (Nat.card V : ℝ) / (2 * C) →
      C * (A.ncard : ℝ) ≤ ((G.externalNeighborSet A).ncard : ℝ)) ∧
    ∀ A B : Set V, Disjoint A B →
      (Nat.card V : ℝ) / (2 * C) ≤ (A.ncard : ℝ) →
      (Nat.card V : ℝ) / (2 * C) ≤ (B.ncard : ℝ) →
      ∃ a ∈ A, ∃ b ∈ B, G.Adj a b

    DefinitionSpectral bound on the vectors orthogonal to the constants#✓fully proved

    MathlibExt.Combinatorics.SpectralExpander.IsSpectralBound

    The real square matrix A satisfies ‖A x‖ ≤ c ‖x‖ (Euclidean norms, written as (A x) · (A x) ≤ c² (x · x)) for every vector x whose entries sum to zero. For the adjacency matrix of a d-regular graph and c = d λ this is spectral expansion λ(G) ≤ λ in the sense of S. Vadhan, Pseudorandomness (2012), Section 4.1.2 and Definition 4.5.

    def IsSpectralBound (A : Matrix V V ℝ) (c : ℝ) : Prop :=
  ∀ x : V → ℝ, ∑ i, x i = 0 → (A *ᵥ x) ⬝ᵥ (A *ᵥ x) ≤ c ^ 2 * (x ⬝ᵥ x)

    DefinitionSpectral expander#✓fully proved

    MathlibExt.Combinatorics.SpectralExpander.IsSpectralExpander

    A finite simple graph G is a spectral expander of degree d with parameter λ ≥ 0 (an (N, d, λ)-graph, N the number of vertices) when it is d-regular and its random-walk matrix A / d satisfies ‖(A / d) x‖ ≤ λ ‖x‖ for every x orthogonal to the constant vector, stated without division as ‖A x‖ ≤ d λ ‖x‖ (S. Vadhan, Pseudorandomness (2012), Definition 4.5 with λ = 1 - γ; O. Reingold, S. Vadhan and A. Wigderson, Ann. of Math. 155 (2002), Definition 1.1).

    For a d-regular undirected graph with d ≥ 1 the random-walk matrix A / d is symmetric with the constant vector as an eigenvector, so it preserves the orthogonal complement of the constants, and the smallest admissible λ is the largest absolute value of an eigenvalue of A / d on that complement (eigenvalues counted with multiplicity, the constant eigenvector removed; Reingold, Vadhan and Wigderson, Definition 2.2). For a disconnected graph the eigenvalue 1 occurs again on the complement, so λ = 1. This two-sided measure differs from the one-sided second eigenvalue λ₂, and from the bipartite convention of Bipartite Ramanujan graphs of every degree, which excludes both trivial eigenvalues ±d. The equivalence with the eigenvalue formulation is not formalized here.

    def IsSpectralExpander (G : SimpleGraph V) [DecidableRel G.Adj] (d : ℕ) (lam : ℝ) : Prop :=
  G.IsRegularOfDegree d ∧ 0 ≤ lam ∧ IsSpectralBound (G.adjMatrix ℝ) (d * lam)
    def IsSpectralBound (A : Matrix V V ℝ) (c : ℝ) : Prop :=
  ∀ x : V → ℝ, ∑ i, x i = 0 → (A *ᵥ x) ⬝ᵥ (A *ᵥ x) ≤ c ^ 2 * (x ⬝ᵥ x)

    TheoremExpander mixing lemma for matrices#✓fully proved

    MathlibExt.Combinatorics.SpectralExpander.abs_indicator_dotProduct_mulVec_sub_le

    Let A be a symmetric real matrix indexed by a finite set of size N, with every row summing to d, such that ‖A x‖ ≤ c ‖x‖ for every x orthogonal to the constant vector.     TheoremExpander mixing lemma#✓fully proved

    MathlibExt.Combinatorics.SpectralExpander.expander_mixing_lemma

    Let G be a d-regular graph on N vertices, d ≥ 1, that is a spectral expander with parameter λ. Then for all vertex sets S and T of densities α = |S| / N and β = |T| / N, |e(S, T) / (N d) - α β| ≤ λ √(α (1 - α) β (1 - β)), where e(S, T) counts the ordered pairs (s, t) ∈ S × T joined by an edge (S. Vadhan, Pseudorandomness, Foundations and Trends in Theoretical Computer Science 7 (2012), Lemma 4.15, first inequality).

    The proof writes e(S, T) = 1_Sᵀ A 1_T, splits each indicator into its mean and a part orthogonal to the constants, and bounds the cross term by the Cauchy-Schwarz inequality and the spectral bound; it uses nothing about A beyond symmetry, constant row sums and the spectral bound, which is why the matrix form Expander mixing lemma for matrices is proved first. The degree hypothesis d ≥ 1 is needed: the empty graph satisfies the spectral bound with λ = 0, but has no edges between non-empty sets.

    theorem expander_mixing_lemma {G : SimpleGraph V} [DecidableRel G.Adj] {d : ℕ} {lam : ℝ}
    (h : IsSpectralExpander G d lam) (hd : 0 < d) (S T : Finset V) :
    |(G.interedges S T).card / (Fintype.card V * d : ℝ) -
        S.card / Fintype.card V * (T.card / Fintype.card V)| ≤
      lam * √(S.card / Fintype.card V * (1 - S.card / Fintype.card V) *
        (T.card / Fintype.card V * (1 - T.card / Fintype.card V)))
    def IsSpectralExpander (G : SimpleGraph V) [DecidableRel G.Adj] (d : ℕ) (lam : ℝ) : Prop :=
  G.IsRegularOfDegree d ∧ 0 ≤ lam ∧ IsSpectralBound (G.adjMatrix ℝ) (d * lam)

    MathlibExt.Combinatorics.SpectralExpander.walkProb_forall_mem_le

    Let G be a d-regular graph, d ≥ 1, that is a spectral expander with parameter λ, and let B be a vertex set of density μ = |B| / N. A random walk V₀, V₁, …, V_t with t steps from a uniformly random start vertex stays inside B at all t + 1 times with probability at most (μ + λ (1 - μ)) ^ (t + 1) (S. Vadhan, Pseudorandomness (2012), Theorem 4.17, where the walk V₁, …, V_t has t - 1 steps and the bound is (μ + λ (1 - μ)) ^ t).

    The proof follows Vadhan: the probability equals (1 / N) 1ᵀ (P M)^t 1_B, with M = A / d and P the projection onto B (his Claim 4.20), and ‖P M y‖ ≤ (μ + λ (1 - μ)) ‖y‖ for every y supported on B (his Claim 4.21), obtained by writing M y = (1 - λ) ȳ 1 + (λ ȳ 1 + M y⊥); the case λ > 1 is trivial because the bound is then at least 1.

    Taking B the set of random strings on which a one-sided-error algorithm errs, a walk of t steps uses log N + t log d random bits, against (t + 1) log N for independent samples, and still drives the error down exponentially in t: error reduction for RP with few random bits.
