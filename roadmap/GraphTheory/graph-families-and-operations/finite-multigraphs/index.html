    EndpointMapMultigraph.incident

    Let \(\mathrm{end}_1, \mathrm{end}_2 : E \to V\) be maps, viewed as an undirected multigraph on \(V\) in which each edge \(e \in E\) has endpoints \(\mathrm{end}_1(e)\) and \(\mathrm{end}_2(e)\). For a vertex \(v \in V\) and a finite set \(F \subseteq E\), the edges of \(F\) incident to \(v\) form the finite set of all \(e \in F\) with \(\mathrm{end}_1(e) = v\) or \(\mathrm{end}_2(e) = v\). An edge appears once even when it is a loop.

    noncomputable def incident {V E : Type*} (end₁ end₂ : E → V)
    (v : V) (F : Finset E) : Finset E := by
  classical
  exact F.filter (fun e => end₁ e = v ∨ end₂ e = v)

    EndpointMapMultigraph.degreeWithin

    Let \(\mathrm{end}_1, \mathrm{end}_2 : E \to V\) be maps, viewed as an undirected multigraph on \(V\) in which each edge \(e \in E\) has endpoints \(\mathrm{end}_1(e)\) and \(\mathrm{end}_2(e)\). For a finite set \(F \subseteq E\) and a vertex \(v \in V\), the degree of \(v\) in \(F\) is the number of \(e \in F\) with \(\mathrm{end}_1(e) = v\) plus the number of \(e \in F\) with \(\mathrm{end}_2(e) = v\). Each endpoint incidence counts once, so a loop at \(v\) contributes two.

    noncomputable def degreeWithin {V E : Type*} (end₁ end₂ : E → V)
    (F : Finset E) (v : V) : ℕ := by
  classical
  exact (F.filter (fun e => end₁ e = v)).card + (F.filter (fun e => end₂ e = v)).card

    EndpointMapMultigraph.AdjacentUsing

    Let \(\mathrm{end}_1, \mathrm{end}_2 : E \to V\) be maps, viewed as an undirected multigraph on \(V\) in which each edge \(e \in E\) has endpoints \(\mathrm{end}_1(e)\) and \(\mathrm{end}_2(e)\).     DefinitionCut of a vertex set#✓fully proved

    EndpointMapMultigraph.cut

    Let \(E\) be a finite set and \(\mathrm{end}_1, \mathrm{end}_2 : E \to V\) be maps, viewed as an undirected multigraph on \(V\) in which each edge \(e \in E\) has endpoints \(\mathrm{end}_1(e)\) and \(\mathrm{end}_2(e)\). For a finite set \(X \subseteq V\), the cut of \(X\) is the set of edges \(e \in E\) such that exactly one of \(\mathrm{end}_1(e)\) and \(\mathrm{end}_2(e)\) lies in \(X\). Loops never cross a cut.

    noncomputable def cut {V E : Type*} [Fintype E] (end₁ end₂ : E → V)
    (X : Finset V) : Finset E := by
  classical
  exact Finset.univ.filter (fun e => decide (end₁ e ∈ X) != decide (end₂ e ∈ X))

    EndpointMapMultigraph.degreeWithin_eq_card_incident_of_loopless

    Let \(\mathrm{end}_1, \mathrm{end}_2 : E \to V\) be maps, viewed as an undirected multigraph on \(V\) in which each edge \(e \in E\) has endpoints \(\mathrm{end}_1(e)\) and \(\mathrm{end}_2(e)\).
