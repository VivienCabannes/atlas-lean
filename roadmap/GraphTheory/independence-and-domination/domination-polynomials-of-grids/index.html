    DefinitionDomination polynomial#✓fully proved

    MetaMathlibExt.dominationPolynomial

    For a finite graph \(G\), the domination polynomial of \(G\) is the polynomial \(\sum_S z^{|S|}\) with integer coefficients, the sum running over the dominating sets \(S\) of \(G\).

    noncomputable def dominationPolynomial [Fintype W] (G : SimpleGraph W) : ℤ[X] :=
  ∑ S ∈ (Finset.univ : Finset (Finset W)).filter (fun S : Finset W => G.IsDominating (↑S : Set W)),
    X ^ S.card

    DefinitionDomination state of a vertex#✓fully proved

    MetaMathlibExt.vertexDominationState

    Let \(G\) be a simple graph, \(S\) a finite set of vertices of \(G\) and \(v\) a vertex of \(G\). The domination state of \(v\) relative to \(S\) in \(G\) is occupied if \(v \in S\), covered if \(v \notin S\) and \(v\) is adjacent in \(G\) to some vertex of \(S\), and uncovered otherwise.

    noncomputable def vertexDominationState (G : SimpleGraph W) (S : Finset W) (v : W) :
    DominationState :=
  if v ∈ S then occupied else if ∃ u ∈ S, G.Adj u v then covered else uncovered

    DefinitionDomination signature#✓fully proved

    MetaMathlibExt.IsDominationSignature

    Let \(R\) be a simple graph on a vertex set \(V\) (the row). A map \(\sigma\) assigning to each vertex of \(V\) a domination state (uncovered, covered or occupied) is a signature for \(R\) if no uncovered vertex is adjacent in \(R\) to an occupied vertex: for all vertices \(i, j\) adjacent in \(R\), it is not the case that \(\sigma(i)\) is uncovered and \(\sigma(j)\) is occupied.

    When \(R\) is the path on \(m\) vertices, signatures are the strings of length \(m\) in which no uncovered entry is next to an occupied one; when \(R\) is the cycle on \(m\) vertices the condition also applies to the first and last entries (the paper's cyclic signatures).

    def IsDominationSignature (R : SimpleGraph V) (σ : V → DominationState) : Prop :=
  ∀ i j, R.Adj i j → ¬(σ i = uncovered ∧ σ j = occupied)
    inductive DominationState
  | uncovered
  | covered
  | occupied
  deriving DecidableEq

    For a simple graph \(R\) on a vertex set \(V\) (the row), a signature of \(R\) is a map \(\sigma\) assigning to each vertex of \(V\) a domination state (uncovered, covered or occupied) such that \(\sigma\) is a domination signature for \(R\), that is, no uncovered vertex is adjacent in \(R\) to an occupied vertex.     DefinitionCompatible row signatures#✓fully proved

    MetaMathlibExt.DominationCompatible

    Let \(R\) be a graph (the row) and let \(\sigma\) and \(\tau\) assign a domination state (uncovered, covered or occupied) to each vertex of \(R\). The new row \(\tau\) is compatible with the previous row \(\sigma\) when, for every vertex \(i\) of \(R\): if \(\sigma(i)\) is uncovered then \(\tau(i)\) is occupied; if \(\sigma(i)\) is occupied then \(\tau(i)\) is not uncovered; and if \(\tau(i)\) is covered then \(\sigma(i)\) is occupied or some neighbour \(j\) of \(i\) in \(R\) has \(\tau(j)\) occupied.

    def DominationCompatible (R : SimpleGraph V) (τ σ : V → DominationState) : Prop :=
  ∀ i, (σ i = uncovered → τ i = occupied) ∧ (σ i = occupied → τ i ≠ uncovered) ∧
    (τ i = covered → σ i = occupied ∨ ∃ j, R.Adj i j ∧ τ j = occupied)
    inductive DominationState
  | uncovered
  | covered
  | occupied
  deriving DecidableEq

    Let \(V\) be a finite set and let \(\sigma\) assign a domination state (uncovered, covered or occupied) to each element of \(V\). The occupied count \(\operatorname{occ}(\sigma)\) is the number of elements \(i \in V\) such that \(\sigma(i)\) is occupied.

    noncomputable def occupiedCount [Fintype V] (σ : V → DominationState) : ℕ :=

    DefinitionDomination transfer matrix#✓fully proved

    MetaMathlibExt.dominationTransferMatrix

    Let \(R\) be a simple graph on a finite vertex set (the row). The transfer matrix \(A\) of \(R\) is the matrix with entries in \(\mathbb{Z}[z]\), rows indexed by the new signature \(\tau\) and columns by the old signature \(\sigma\), both ranging over the signatures of \(R\), whose entry \(A_{\tau\sigma}\) is \(z^{\operatorname{occ}(\tau)}\) if \(\tau\) is compatible with \(\sigma\) and \(0\) otherwise; here \(\operatorname{occ}(\tau)\) is the number of occupied vertices of \(\tau\). When \(R\) is the cycle on \(m\) vertices this is Mertens' matrix \(\bar A\).

    noncomputable def dominationTransferMatrix [Fintype V] (R : SimpleGraph V) :
    Matrix (DominationSignature R) (DominationSignature R) ℤ[X] :=
  fun τ σ => if DominationCompatible R τ.1 σ.1 then X ^ occupiedCount τ.1 else 0
    def DominationSignature (R : SimpleGraph V) : Type _ :=
  {σ : V → DominationState // IsDominationSignature R σ}

    DefinitionAlmost dominating polynomial#✓fully proved

    MetaMathlibExt.almostDominatingPolynomial

    Let \(R\) be a finite graph (the row), \(n\) a natural number and \(\sigma\) an assignment of a domination state to each vertex of \(R\). Let \(H\) be the box product of \(R\) with the path on the vertices \(0, \dots, n\), so that the last row of \(H\) consists of the vertices \((i, n)\). Relative to a vertex set \(S\) of \(H\), a vertex is occupied if it lies in \(S\), covered if it lies outside \(S\) but is adjacent to a vertex of \(S\), and uncovered otherwise. The almost dominating polynomial \(G^\sigma(z)\) is the polynomial \(\sum_S z^{|S|}\) with integer coefficients, the sum running over the vertex sets \(S\) of \(H\) such that no vertex of \(H\) outside the last row is uncovered and every vertex \((i, n)\) of the last row has state \(\sigma(i)\).

    noncomputable def almostDominatingPolynomial [Fintype V] (R : SimpleGraph V) (n : ℕ)
    (σ : V → DominationState) : ℤ[X] :=
  ∑ S ∈ (Finset.univ : Finset (Finset (V × Fin (n + 1)))).filter (fun S =>
      (∀ v : V × Fin (n + 1), v.2 ≠ Fin.last n →
        vertexDominationState (R □ pathGraph (n + 1)) S v ≠ uncovered) ∧
      ∀ i, vertexDominationState (R □ pathGraph (n + 1)) S (i, Fin.last n) = σ i),
    X ^ S.card
    inductive DominationState
  | uncovered
  | covered
  | occupied
  deriving DecidableEq
