    Vickrey–Clarke–Groves mechanisms

    Agents with quasi-linear utilities report valuations over a set of alternatives. A VCG mechanism chooses an alternative that maximizes the reported social welfare and charges each agent a term independent of its own report minus the reported welfare of the others; each agent's utility is then the social welfare minus a term it cannot influence, so truthful reporting is a dominant strategy (Nisan 2007, Theorem 9.17, crediting Vickrey 1961, Clarke 1971 and Groves 1973). With the Clarke pivot term, the best welfare the others could get without the agent, no agent is ever paid and, for nonnegative valuations, every truthful agent gets a nonnegative utility (Nisan 2007, Lemma 9.20). Vickrey's second-price auction, in which the highest bidder wins and pays the highest competing bid, is the VCG mechanism with Clarke pivot payments for one item, with the possible winners as alternatives (Nisan 2007, §9.3.5.1); it is therefore truthful (Nisan 2007, Proposition 9.13).

    MathlibExt.GameTheory.MechanismDesign.VCG.IsIncentiveCompatible

    The direct mechanism (f, p) is incentive compatible: for every agent i, every profile v and every report w of agent i, v i (f v) - p v i ≥ v i (f v') - p v' i with v' = update v i w (Nisan 2007, Definition 9.15).

    def IsIncentiveCompatible (f : (ι → A → ℝ) → A) (p : (ι → A → ℝ) → ι → ℝ) : Prop :=
  ∀ i (v : ι → A → ℝ) (w : A → ℝ),
    v i (f (Function.update v i w)) - p (Function.update v i w) i ≤ v i (f v) - p v i

    MathlibExt.GameTheory.MechanismDesign.VCG.secondPrice_truthful

    In the second-price auction with a winner rule w that picks a highest bid, no bidder gains by bidding s instead of its value t i, whatever the other nonnegative bids: its utility t i - (price) if it wins, 0 otherwise, is largest when it bids its value (Vickrey 1961, through Nisan 2007, Proposition 9.13). The statement is for nonnegative values and bids, the valuation domain of Nisan 2007, §9.3.5.1, and is derived from the VCG theorem.

    theorem secondPrice_truthful {w : (ι → ℝ) → ι} (hw : ∀ (t : ι → ℝ) (j : ι), t j ≤ t (w t))
    {t : ι → ℝ}
    (ht : ∀ j, 0 ≤ t j) (i : ι) {s : ℝ} (hs : 0 ≤ s) :
    (if w (Function.update t i s) = i then t i else 0) -
        secondPricePayment w (Function.update t i s) i ≤
      (if w t = i then t i else 0) - secondPricePayment w t i
    noncomputable def secondPricePayment (w : (ι → ℝ) → ι) (t : ι → ℝ) (i : ι) : ℝ :=
  if w t = i then (univ.erase i).sup' (nonempty_others i) t else 0
