    Revelation principle

    A mechanism gives each agent a set of actions and maps action profiles to outcomes; each agent has a private type and a utility over outcomes, with monetary transfers counted as part of the outcome. The revelation principle says that every equilibrium of every mechanism is reproduced, outcome for outcome, by the truthful equilibrium of a direct mechanism in which agents report their types: the direct mechanism plays the equilibrium strategies on the agents' behalf, so an agent who gained by lying to it would have gained by deviating in the original mechanism (Myerson 1979, Theorem 2; Myerson 1981, Lemma 1; Nisan 2007, Proposition 9.25). The statements here cover dominant-strategy equilibria and Bayesian Nash equilibria in pure strategies over finite type spaces; Myerson's Theorem 2 also allows randomized response plans.

    MathlibExt.GameTheory.MechanismDesign.IsDominantStrategyProfile

    In the mechanism g, with private-value utilities u i θᵢ o, the strategy profile s (agent i of type θᵢ plays s i θᵢ) is a profile of dominant strategies: whatever the others play, s i θᵢ is a best action for agent i of type θᵢ (Nisan 2007, Definition 9.24 and the definition of dominant-strategy implementation in §9.4.2).

    def IsDominantStrategyProfile (u : ∀ i, Θ i → O → ℝ) (g : (∀ i, X i) → O)
    (s : ∀ i, Θ i → X i) : Prop :=
  ∀ i (θi : Θ i) (x : ∀ j, X j) (a : X i),
    u i θi (g (Function.update x i a)) ≤ u i θi (g (Function.update x i (s i θi)))

    DefinitionInterim expected utility#✓fully proved

    MathlibExt.GameTheory.MechanismDesign.interimUtility

    For a prior p on the finite set of type profiles and utilities u i θ o that may depend on the whole type profile, the expected utility of agent i of type θi when each profile θ leads to the outcome h θ: ∑_{θ : θ i = θi} p θ · u i θ (h θ). This is Myerson's Zᵢ (1979, equation (5)) multiplied by the marginal probability of θi, so the incentive constraints below are those of Myerson (1979, (6)) whenever that marginal is positive, and are vacuous when it is zero.

    def interimUtility (p : (∀ j, Θ j) → ℝ) (u : ι → (∀ j, Θ j) → O → ℝ) (i : ι) (θi : Θ i)
    (h : (∀ j, Θ j) → O) : ℝ :=
  ∑ θ ∈ univ.filter (fun θ : ∀ j, Θ j => θ i = θi), p θ * u i θ (h θ)

    DefinitionBayesian Nash equilibrium#✓fully proved

    MathlibExt.GameTheory.MechanismDesign.IsBayesNash

    The pure strategy profile s is a Bayesian Nash equilibrium of the mechanism g for the prior p and the utilities u: no agent of any type gains in interim expectation by a unilateral deviation to another action, the others following s (Myerson 1979, (14), restricted to pure response plans).

    def IsBayesNash (p : (∀ j, Θ j) → ℝ) (u : ι → (∀ j, Θ j) → O → ℝ) (g : (∀ i, X i) → O)
    (s : ∀ i, Θ i → X i) : Prop :=
  ∀ i (θi : Θ i) (a : X i),
    interimUtility p u i θi (fun θ => g (Function.update (fun j => s j (θ j)) i a)) ≤
      interimUtility p u i θi (fun θ => g (fun j => s j (θ j)))
    def interimUtility (p : (∀ j, Θ j) → ℝ) (u : ι → (∀ j, Θ j) → O → ℝ) (i : ι) (θi : Θ i)
    (h : (∀ j, Θ j) → O) : ℝ :=
  ∑ θ ∈ univ.filter (fun θ : ∀ j, Θ j => θ i = θi), p θ * u i θ (h θ)

    DefinitionBayesian incentive compatibility#✓fully proved

    MathlibExt.GameTheory.MechanismDesign.IsBayesIncentiveCompatible

    The direct mechanism f is Bayesian incentive compatible: truthful reporting is a Bayesian Nash equilibrium, that is, no agent of any type θi gains in interim expectation by reporting θi' while the others report truthfully (Myerson 1979, (6); Myerson 1981, (3.5); Myerson and Satterthwaite 1983, §2).

    def IsBayesIncentiveCompatible (p : (∀ j, Θ j) → ℝ) (u : ι → (∀ j, Θ j) → O → ℝ)

  ∀ i (θi θi' : Θ i),

    TheoremRevelation principle (Bayesian, pure strategies)#✓fully proved

    MathlibExt.GameTheory.MechanismDesign.revelationPrinciple_bayesNash

    If the pure strategies s form a Bayesian Nash equilibrium of the mechanism g, then the direct mechanism θ ↦ g (fun j ↦ s j (θ j)) is Bayesian incentive compatible, and by construction its truthful outcome at every type profile is the equilibrium outcome of g, so every type of every agent gets the same interim utility (Myerson 1979, Theorem 2; Myerson 1981, Lemma 1). Myerson's Theorem 2 also allows randomized response plans (mixed strategies); this statement covers pure strategies only, with an arbitrary outcome set O, which may itself be a set of lotteries.

    theorem revelationPrinciple_bayesNash {p : (∀ j, Θ j) → ℝ} {u : ι → (∀ j, Θ j) → O → ℝ}
    {g : (∀ i, X i) → O} {s : ∀ i, Θ i → X i} (hs : IsBayesNash p u g s) :
    IsBayesIncentiveCompatible p u (fun θ => g (fun j => s j (θ j)))
    def IsBayesNash (p : (∀ j, Θ j) → ℝ) (u : ι → (∀ j, Θ j) → O → ℝ) (g : (∀ i, X i) → O)
