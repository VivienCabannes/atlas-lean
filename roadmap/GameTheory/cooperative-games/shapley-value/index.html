    Shapley value

    The Shapley value (Shapley 1953) divides the worth of the grand coalition of a game with transferable utility among the players. It is the only linear rule that is efficient, symmetric and gives nothing to null players; on a fixed finite player set this is proved here through the basis of unanimity games, and the value is identified with Shapley's formula, the average of a player's marginal contributions over all orders of arrival of the players. Aumann and Shapley (1974) extended the value to games with a continuum of players, which is not formalised.

    MathlibExt.GameTheory.ShapleyValue.IsEfficient

    Let \(N\) be a finite set of players and \(\varphi\) an \(\mathbb{R}\)-linear map from cooperative games on \(N\) (added and scaled pointwise) to payoff vectors in \(\mathbb{R}^N\).     DefinitionSymmetric value#✓fully proved

    MathlibExt.GameTheory.ShapleyValue.IsSymmetric

    Let \(N\) be a finite set of players and \(\varphi\) an \(\mathbb{R}\)-linear map from cooperative games on \(N\) (added and scaled pointwise) to payoff vectors in \(\mathbb{R}^N\). Then \(\varphi\) is symmetric if for every game \(v\) and every permutation \(\sigma\) of \(N\) with \(v(\sigma(S)) = v(S)\) for all coalitions \(S \subseteq N\), every player \(i\) satisfies \(\varphi(v)_{\sigma(i)} = \varphi(v)_i\).

    This is the symmetry axiom in its permutation form. Serrano states symmetry for substitutes (two players who contribute the same to each coalition are paid the same), which is a different formulation; the uniqueness theorem proved here uses the permutation form.

    def IsSymmetric (φ : CoopGame Player →ₗ[ℝ] (Player → ℝ)) : Prop :=
  ∀ (σ : Equiv.Perm Player) (v : CoopGame Player),
    (∀ S : Set Player, v.charFun (σ '' S) = v.charFun S) →
    ∀ i : Player, φ v (σ i) = φ v i

    TheoremExistence and uniqueness of the Shapley value#✓fully proved

    MathlibExt.GameTheory.ShapleyValue.shapley_characterization

    On a fixed finite set \(N\) of players, there is exactly one linear map \(\varphi\) from TU games on \(N\) to payoff vectors in \(\mathbb R^N\) that is

    • efficient: \(\sum_{i \in N} \varphi_i(v) = v(N)\);
    • symmetric: if a permutation \(\sigma\) of \(N\) leaves \(v\) invariant, then \(\varphi_{\sigma i}(v) = \varphi_i(v)\);
    • null for null players: if \(v(S \cup \{i\}) = v(S)\) for every coalition \(S\) not containing \(i\), then \(\varphi_i(v) = 0\).

    The proof writes \(v\) in the basis of unanimity games \(u_T(S) = [T \subseteq S]\) by Möbius inversion, \(v = \sum_{T \neq \emptyset} c_T(v)\, u_T\), and shows that the axioms force \(\varphi_i(u_T) = 1/|T|\) for \(i \in T\) and \(0\) otherwise; hence \(\varphi_i(v) = \sum_{T \ni i} c_T(v)/|T|\).

    Compared with the source: Shapley works with superadditive games on a universe of players with finite carriers and an additivity axiom; this is an adapted characterisation on a fixed finite player set, with linearity in place of additivity and the null-player axiom made explicit (see the source-fidelity note in MathlibExt/GameTheory/ShapleyValue.lean).

    public theorem shapley_characterization : ∃! φ : CoopGame Player →ₗ[ℝ] (Player → ℝ),
    IsEfficient φ ∧ IsSymmetric φ ∧ SatisfiesNullPlayerAxiom φ

    Shapley's formula

    DefinitionShapley weight#✓fully proved

    MathlibExt.GameTheory.ShapleyValue.shapleyWeight

    For \(n\) players and a coalition size \(1 \le s \le n\), the Shapley weight is $\(w(n, s) = \frac{(s - 1)!\,(n - s)!}{n!}.\)$ In a uniformly random order of the \(n\) players, it is the probability that a given player \(i\) arrives just after the other members of a given coalition \(S \ni i\) of size \(s\), so that the players up to and including \(i\) form exactly \(S\).

    noncomputable def shapleyWeight (n s : ℕ) : ℝ :=
  ((s - 1).factorial * (n - s).factorial : ℝ) / n.factorial

    DefinitionShapley's formula#✓fully proved

    MathlibExt.GameTheory.ShapleyValue.shapleyFormula

    The value that pays player \(i\) of a TU game \(v\) on \(n\) players $\(\varphi_i(v) = \sum_{S \ni i} \frac{(|S| - 1)!\,(n - |S|)!}{n!}\,\bigl(v(S) - v(S \setminus \{i\})\bigr),\)$ the average of \(i\)'s marginal contributions \(v(S) - v(S \setminus \{i\})\) when all orders of the players are equally likely. It is linear in \(v\).

    MathlibExt.GameTheory.ShapleyValue.shapleyFormula · 15 lines 
    noncomputable def shapleyFormula : CoopGame Player →ₗ[ℝ] (Player → ℝ) where
  toFun v i := ∑ S ∈ univ.filter (fun S : Finset Player => i ∈ S),
    shapleyWeight (Fintype.card Player) S.card * (v.charFun ↑S - v.charFun ↑(S.erase i))
  map_add' v w := by
    funext i

    refine sum_congr rfl fun S _ => ?_

    ring

    TheoremTelescoping of the Shapley weights#✓fully proved

    MathlibExt.GameTheory.ShapleyValue.shapleyWeight_telescope

    For \(1 \le k \le n\), $\(k\,w(n, k) - (n - k)\,w(n, k + 1) = \begin{cases} 1 & k = n, \\ 0 & k < n, \end{cases}\)$ because both products equal \(k!\,(n - k)!/n!\) when \(k < n\). Summing Shapley's formula over the players, the coefficient of \(v(T)\) for a nonempty coalition \(T\) is exactly this expression with \(k = |T|\), which is why the formula is efficient.

    theorem shapleyWeight_telescope {n k : ℕ} (hk : 1 ≤ k) (hkn : k ≤ n) :
    (k : ℝ) * shapleyWeight n k - ((n - k : ℕ) : ℝ) * shapleyWeight n (k + 1) =
      if k = n then 1 else 0
    noncomputable def shapleyWeight (n s : ℕ) : ℝ :=
  ((s - 1).factorial * (n - s).factorial : ℝ) / n.factorial

    TheoremShapley's formula is efficient#✓fully proved

    MathlibExt.GameTheory.ShapleyValue.shapleyFormula_isEfficient

    Shapley's formula distributes exactly the worth of the grand coalition: \(\sum_{i \in N} \varphi_i(v) = v(N)\).

    Regrouping the double sum by coalitions, \(v(T)\) appears with coefficient \(|T|\,w(n, |T|)\) from the players of \(T\) and with coefficient \(-(n - |T|)\,w(n, |T| + 1)\) from the coalitions \(T \cup \{j\}\), \(j \notin T\). By the telescoping identity only \(T = N\) survives, with coefficient \(1\); the empty coalition contributes nothing since \(v(\emptyset) = 0\).

    TheoremThe Shapley value is given by Shapley's formula#✓fully proved

    MathlibExt.GameTheory.ShapleyValue.eq_shapleyFormula

    On a fixed finite set \(N\) of \(n\) players, every linear value \(\varphi\) that is efficient, symmetric and gives nothing to null players pays player \(i\) $\(\varphi_i(v) = \sum_{S \ni i} \frac{(|S| - 1)!\,(n - |S|)!}{n!}\,\bigl(v(S) - v(S \setminus \{i\})\bigr).\)$

    Shapley's formula satisfies the three axioms, and by uniqueness it is the only value that does. Compared with the statement in the source, the axioms are those of the adapted fixed-player-set characterisation (linearity in place of additivity), so the hypotheses are slightly stronger than Shapley's; the conclusion, the formula, is the same.

    theorem eq_shapleyFormula {φ : CoopGame Player →ₗ[ℝ] (Player → ℝ)} (he : IsEfficient φ)
    (hs : IsSymmetric φ) (hn : SatisfiesNullPlayerAxiom φ) : φ = shapleyFormula
