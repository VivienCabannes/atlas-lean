    MetaMathlibExt.maximumNimGrundy

    For a rule function \(f : \mathbb{N} \to \mathbb{N}\), the Grundy number \(G_f(x)\) of a pile of \(x\) stones in Maximum Nim is defined by recursion on \(x\) as the mex (least natural number not in the set) of \(\{G_f(x - u) : 1 \le u \le \min(f(x), x)\}\), the Grundy numbers of the positions reachable from \(x\) by removing \(u\) stones.

    Taking \(\min(f(x), x)\) makes the definition total; under the source's hypotheses on \(f\), which include \(f(0) = 0\), it does not change the legal moves.

    MetaMathlibExt.maximumNimGame

    For a rule function \(f : \mathbb{N} \to \mathbb{N}\), the Maximum Nim game with rule \(f\) is the impartial game whose positions are the pile sizes \(x \in \mathbb{N}\), in which the moves from \(x\) go to \(x - u\) for each \(u\) with \(1 \le u \le \min(f(x), x)\). The rank of a position is the pile size itself, and the starting position is the empty pile \(0\).

    public def maximumNimGame (f : ℕ → ℕ) : SpragueGrundy.ImpartialGame where
  Pos := ℕ
  eqDec := inferInstance
  moves := fun x => (Finset.Icc 1 (min (f x) x)).image (fun u => x - u)
  rank := id
  rank_lt := by
    intro x y h
    simp only [Finset.mem_image, Finset.mem_Icc] at h
    obtain ⟨u, ⟨h1, h2⟩, rfl⟩ := h
    simp only [id_eq]
    omega
  start := 0

    DefinitionFuel-bounded Josephus simulation#✓fully proved

    MetaMathlibExt.josephusEliminationOrderAux

    For natural numbers \(k\) and \(s\) (the starting position), a fuel \(f\) and a list \(c\) of natural numbers (the current circle), the simulation returns the empty list when \(f = 0\) or \(c\) is empty. Otherwise, with \(L\) the length of \(c\) and \(i = (s + k - 1) \bmod L\), where the subtraction is truncated at \(0\), it returns the entry of \(c\) at zero-based position \(i\) followed by the result of the simulation with the same \(k\), starting position \(i\) and fuel \(f - 1\) on the list obtained from \(c\) by deleting the entry at position \(i\).

    public def josephusEliminationOrderAux (k start : ℕ) : ℕ → List ℕ → List ℕ
  | 0, _ => []
  | _ + 1, [] => []
  | fuel + 1, circle =>
      let i := (start + k - 1) % circle.length
      circle.getD i 0 :: josephusEliminationOrderAux k i fuel (circle.eraseIdx i)

    DefinitionJosephus elimination order#✓fully proved

    MetaMathlibExt.josephusEliminationOrder

    For natural numbers \(k\) and \(n\), place \(1, \dots, n\) in order on a circle and repeatedly remove one entry. When \(L\) entries remain and the current position is \(s\) (zero-based, initially \(s = 0\)), the entry at zero-based position \(i = (s + k - 1) \bmod L\) is removed, where the subtraction is truncated at \(0\), and \(i\) becomes the current position, so the next count starts at the entry after the removed one. The Josephus elimination order with step \(k\) on the circle \(1, \dots, n\) is the list of all \(n\) entries in the order of their removal.

    For \(k \ge 1\) this is the classical process that removes every \(k\)-th remaining entry; the last entry of the list is the survivor.

    public def josephusEliminationOrder (k n : ℕ) : List ℕ :=
  josephusEliminationOrderAux k 0 n (List.range' 1 n)
    public def josephusEliminationOrderAux (k start : ℕ) : ℕ → List ℕ → List ℕ
  | 0, _ => []
  | _ + 1, [] => []
  | fuel + 1, circle =>
      let i := (start + k - 1) % circle.length
      circle.getD i 0 :: josephusEliminationOrderAux k i fuel (circle.eraseIdx i)
