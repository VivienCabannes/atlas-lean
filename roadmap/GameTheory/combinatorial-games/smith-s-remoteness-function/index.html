    Smith's remoteness function

    DefinitionSmith's remoteness function#✓fully proved

    MetaMathlibExt.SpragueGrundy.smithRemoteness

    For an impartial game \(G\), the remoteness \(R(p)\) of a position \(p\) of \(G\) is defined by well-founded recursion along moves; the options of \(p\) are the positions reachable from \(p\) in one move. If \(p\) has no options, then \(R(p) = 0\). Otherwise, if some option \(q\) of \(p\) has \(R(q)\) even, then \(R(p)\) is \(1\) plus the least even value of \(R(q)\) over the options \(q\) of \(p\); if every option \(q\) of \(p\) has \(R(q)\) odd, then \(R(p)\) is \(1\) plus the largest value of \(R(q)\) over the options \(q\) of \(p\).

    noncomputable def smithRemoteness (G : ImpartialGame) : G.Pos → ℕ :=
  (wfRel G).fix fun p ih =>
    let V := (G.moves p).attach.image fun q => ih q.1 q.2
    if hE : (V.filter Even).Nonempty then 1 + (V.filter Even).min' hE
    else if hV : V.Nonempty then 1 + V.max' hV else 0

  moves : Pos → Finset Pos
  rank : Pos → ℕ
  rank_lt : ∀ p q, q ∈ moves p → rank q < rank p
  start : Pos

    MetaMathlibExt.SpragueGrundy.smithRemoteness_eq

    Let \(G\) be an impartial game, \(p\) a position of \(G\), and \(R\) the set of remotenesses of the options of \(p\) (the positions reachable from \(p\) in one move). If \(R\) contains an even number, the remoteness of \(p\) is \(1\) plus the least even element of \(R\); otherwise, if \(R\) is nonempty, it is \(1\) plus the largest element of \(R\); and if \(R\) is empty, it is \(0\).

    theorem smithRemoteness_eq (G : ImpartialGame) (p : G.Pos) :
    smithRemoteness G p =

      else if hV : ((G.moves p).image (smithRemoteness G)).Nonempty then
        1 + ((G.moves p).image (smithRemoteness G)).max' hV
      else 0
