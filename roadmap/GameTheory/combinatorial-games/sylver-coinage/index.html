    DefinitionLegal moves in Sylver Coinage#✓fully proved

    MetaMathlibExt.sylverLegalMoves

    For a set \(M\) of natural numbers (a position of Sylver Coinage), the set \(L(M)\) of legal moves consists of the natural numbers that are not finite sums of elements of \(M\), repetitions allowed, i.e. the natural numbers outside the additive submonoid of \(\mathbb{N}\) generated by \(M\). Since \(0\) is the empty sum, every legal move is positive.

    public def sylverLegalMoves (M : Set ℕ) : Set ℕ :=
  {q | q ∉ AddSubmonoid.closure M}

    InductiveP-positions of Sylver Coinage#✓fully proved

    MetaMathlibExt.IsSylverPPosition

    A set \(M\) of natural numbers is a P-position of Sylver Coinage when \(1 \notin M\) and, for every legal move \(q\) of \(M\), the position \(M \cup \{q\}\) is an N-position. P-positions and N-positions are defined together, as a mutual inductive definition. In particular a position whose only legal move is \(1\) is a P-position (the player to move must name \(1\) and loses).

    public inductive IsSylverPPosition : Set ℕ → Prop
  | intro {M : Set ℕ} (one_notMem : 1 ∉ M)
      (forall_move : ∀ q ∈ sylverLegalMoves M, IsSylverNPosition (insert q M)) :
      IsSylverPPosition M
    public def sylverLegalMoves (M : Set ℕ) : Set ℕ :=
  {q | q ∉ AddSubmonoid.closure M}

    MetaMathlibExt.IsSylverNPosition

    A position \(M\) of Sylver Coinage is an N-position (the player to move wins) when either \(1 \in M\), so that the previous player named \(1\) and lost, or some legal move \(q\) of \(M\) leads to a P-position \(M \cup \{q\}\). N-positions and P-positions are defined together inductively by these rules.

    public inductive IsSylverNPosition : Set ℕ → Prop
  | one_mem {M : Set ℕ} (h : 1 ∈ M) : IsSylverNPosition M
  | move {M : Set ℕ} {q : ℕ} (hq : q ∈ sylverLegalMoves M)
      (h : IsSylverPPosition (insert q M)) : IsSylverNPosition M

    DefinitionEnds of a Sylver Coinage position#✓fully proved

    MetaMathlibExt.IsSylverEnd

    Let \(M\) be a position of Sylver Coinage with set of legal moves \(L(M)\). A natural number \(x\) is an end of \(M\) if \(x \in L(M)\) and every \(y \in L(M)\) with \(y \ne x\) is still a legal move of the position \(M \cup \{x\}\); that is, naming \(x\) eliminates no other legal move.

    public def IsSylverEnd (M : Set ℕ) (x : ℕ) : Prop :=
  x ∈ sylverLegalMoves M ∧ ∀ y ∈ sylverLegalMoves M, y ≠ x → y ∈ sylverLegalMoves (insert x M)
    public def sylverLegalMoves (M : Set ℕ) : Set ℕ :=
  {q | q ∉ AddSubmonoid.closure M}

    TheoremThe largest legal move is an end#✓fully proved

    MetaMathlibExt.isSylverEnd_of_isGreatest

    Let \(M\) be a position of Sylver Coinage whose set of legal moves \(L(M)\) has a greatest element \(F\). Then \(F\) is an end of \(M\).

    Every other legal move \(y\) is smaller than \(F\), so a way of writing \(y\) as a sum of elements of \(M \cup \{F\}\) cannot use \(F\); hence naming \(F\) eliminates no legal move other than \(F\) itself.

    public theorem isSylverEnd_of_isGreatest {M : Set ℕ} {F : ℕ}
    (hF : IsGreatest (sylverLegalMoves M) F) : IsSylverEnd M F

    TheoremTwo-generated numerical semigroups are symmetric#●ready to prove

    MetaMathlibExt.numericalSemigroup_two_generated_symmetric

    Let \(a\), \(b\) and \(F\) be natural numbers and let \(S = \langle a, b \rangle\) be the additive submonoid of \(\mathbb{N}\) generated by \(a\) and \(b\). If \(F \notin S\) and every natural number \(n > F\) lies in \(S\) (so \(F\) is the Frobenius number of \(S\)), then \(x \in S \iff F - x \notin S\) for every natural number \(x \le F\).

    The hypotheses on \(F\) force \(\gcd(a, b) = 1\) and \(a, b \ge 2\), so these are exactly the numerical semigroups of embedding dimension \(2\) other than \(\mathbb{N}\).

    public theorem_wanted numericalSemigroup_two_generated_symmetric {a b F : ℕ}
    (hF : F ∉ AddSubmonoid.closure ({a, b} : Set ℕ))
    (hF_max : ∀ n, F < n → n ∈ AddSubmonoid.closure ({a, b} : Set ℕ)) :
    ∀ x ≤ F, x ∈ AddSubmonoid.closure ({a, b} : Set ℕ) ↔
      F - x ∉ AddSubmonoid.closure ({a, b} : Set ℕ)
