    A function \(h : \mathbb{N} \to \mathbb{N}\) has the NS property if it is monotone (weakly increasing) and, for all \(z, z' \in \mathbb{N}\) and every natural number \(i \ge 1\), \(\lfloor z / 2^i \rfloor = \lfloor z' / 2^i \rfloor\) implies \(\lfloor h(z) / 2^{i-1} \rfloor = \lfloor h(z') / 2^{i-1} \rfloor\).

    public def HasNSProperty (h : ℕ → ℕ) : Prop :=
  Monotone h ∧ ∀ z z' i : ℕ, 0 < i → z / 2 ^ i = z' / 2 ^ i →
    h z / 2 ^ (i - 1) = h z' / 2 ^ (i - 1)

    DefinitionGrundy number of a chocolate bar#✓fully proved

    MetaMathlibExt.chocolateBarGrundy

    Let \(f_1, \dots, f_s : \mathbb{N} \to \mathbb{N}\). For coordinates \(x = (x_1, \dots, x_s) \in \mathbb{N}^s\) and a width \(z \in \mathbb{N}\), the position \((x, z)\) stands for the chocolate bar \(\mathrm{CB}(f_1, \dots, f_s, x_1, \dots, x_s, z)\), whose column at width \(w \le z\) extends \(\min(f_t(w), x_t) + 1\) cells along axis \(t\). A move either lowers one coordinate \(x_i\) to some \(u < x_i\), keeping the width \(z\), or cuts the width to some \(w < z\), which replaces every \(x_t\) by \(\min(x_t, f_t(w))\). The Grundy number of \((x, z)\) is the mex (least natural number not attained) of the Grundy numbers of the positions reachable from \((x, z)\) in one move. It is defined for all \((x, z)\); the bars themselves are the positions with \(x_t \le f_t(z)\) for all \(t\).
