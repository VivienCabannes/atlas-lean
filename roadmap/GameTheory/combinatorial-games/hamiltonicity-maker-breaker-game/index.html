    InductiveMaker can force a win in the biased Maker-Breaker game#✓fully proved

    MathlibExt.Combinatorics.HamiltonicityGameCriticalBiasOWR1782Problem013Wanted.MakerCanForce

    Fix a finite board \(X\), a bias \(b \in \mathbb{N}\) and a property of finite sets, Maker's target. At a position \((M, R)\), where \(M\) and \(R\) are the sets claimed so far by Maker and by Breaker, an element of \(X\) is free if it lies in neither \(M\) nor \(R\). The relation "Maker, to move at \((M, R)\), can force a win" is the least one satisfying two rules: it holds when no element of \(X\) is free and \(M\) satisfies the target; and it holds when there is a free element \(e\) such that, for every set \(R'\) of exactly \(\min(b, r)\) of the \(r\) elements that are free after \(e\) is claimed, Maker can force a win at \((M \cup \{e\}, R \cup R')\). Thus Maker claims one free element per turn, Breaker answers with \(b\) of them (all remaining ones if fewer are free), play ends when the board is exhausted, and Maker wins if his set satisfies the target.

    inductive MakerCanForce {α : Type*} [DecidableEq α] (board : Finset α) (b : ℕ)
    (target : Finset α → Prop) : Finset α → Finset α → Prop where
  | terminal (maker breaker : Finset α) (exhausted : freeElems board maker breaker = ∅)
      (won : target maker) : MakerCanForce board b target maker breaker
  | move (maker breaker : Finset α) (e : α) (free : e ∈ freeElems board maker breaker)
      (againstEveryResponse : ∀ response : Finset α,
        response ⊆ (freeElems board maker breaker).erase e →
        response.card = min b ((freeElems board maker breaker).erase e).card →
        MakerCanForce board b target (insert e maker) (breaker ∪ response)) :
      MakerCanForce board b target maker breaker
    def freeElems {α : Type*} [DecidableEq α] (board maker breaker : Finset α) : Finset α :=
  board \ (maker ∪ breaker)

    MathlibExt.Combinatorics.HamiltonicityGameCriticalBiasOWR1782Problem013Wanted.MakerWinsBreakerFirst

    For a finite board \(X\), a bias \(b \in \mathbb{N}\) and a target property of Maker's claimed set, Maker wins the \((1 : b)\) Maker-Breaker game on \(X\) in which Breaker moves first when, for every set \(F \subseteq X\) of exactly \(\min(b, |X|)\) elements that Breaker may claim in his first move, Maker can force a win when it is his turn at the position where he has claimed nothing and Breaker has claimed \(F\).

    Breaker moving first is the convention of both sources (Krivelevich, Section 1: "We assume that Breaker moves first"; Chvátal-Erdős, Section 1: "with the Breaker going first").

    def MakerWinsBreakerFirst {α : Type*} [DecidableEq α] (board : Finset α) (b : ℕ)
    (target : Finset α → Prop) : Prop :=
  ∀ first : Finset α, first ⊆ board → first.card = min b board.card →
    MakerCanForce board b target ∅ first

    DefinitionMaker's Hamiltonicity target#✓fully proved

    MathlibExt.Combinatorics.HamiltonicityGameCriticalBiasOWR1782Problem013Wanted.HamiltonianTarget

    For a natural number \(n\), a set \(C\) of unordered pairs of vertices from \(\{0, 1, \dots, n - 1\}\) meets the Hamiltonicity target when the simple graph on these \(n\) vertices whose edges are the pairs of distinct vertices in \(C\) is Hamiltonian: it has a cycle passing through every vertex exactly once, with the convention that the one-vertex graph is Hamiltonian.

    def HamiltonianTarget (n : ℕ) (claimed : Finset (Sym2 (Fin n))) : Prop :=
  (SimpleGraph.fromEdgeSet (claimed : Set (Sym2 (Fin n)))).IsHamiltonian

    MathlibExt.Combinatorics.HamiltonicityGameCriticalBiasOWR1782Problem013Wanted.hamiltonicityCriticalBias

    This is the statement that the critical bias of the Hamiltonicity game is \((1 + o(1))\, n / \ln n\). In the \((1 : b)\) Maker-Breaker game on the edges of the complete graph \(K_n\) with Breaker moving first, Breaker claims \(b\) free edges per turn (all remaining free edges if fewer than \(b\) are left), Maker claims one free edge per turn, and Maker wins if, once every edge is claimed, his edges contain a Hamilton cycle. The property says that for every real \(\varepsilon > 0\) there is \(n_0\) such that for every \(n \ge n_0\), Maker has a winning strategy for every natural number \(b\) with \(0 < b \le (1 - \varepsilon)\, n / \ln n\), and Maker has no winning strategy for any natural number \(b \ge (1 + \varepsilon)\, n / \ln n\).

    def hamiltonicityCriticalBias : Prop :=
  ∀ ε : ℝ, 0 < ε → ∀ᶠ n : ℕ in atTop,
    (∀ b : ℕ, 0 < b → (b : ℝ) ≤ (1 - ε) * n / Real.log n →
      MakerWinsBreakerFirst (completeBoard n) b (HamiltonianTarget n)) ∧
    (∀ b : ℕ, (1 + ε) * n / Real.log n ≤ b →
      ¬ MakerWinsBreakerFirst (completeBoard n) b (HamiltonianTarget n))

    MathlibExt.Combinatorics.HamiltonicityGameCriticalBiasOWR1782Problem013Wanted.hamiltonicityCriticalBias_holds

    Consider the \((1 : b)\) Maker-Breaker game on the edges of the complete graph \(K_n\) in which Breaker moves first: Breaker claims \(b\) free edges per turn (all remaining free edges if fewer than \(b\) are left), Maker claims one free edge per turn, and Maker wins if, once every edge is claimed, his edges contain a Hamilton cycle. For every real \(\varepsilon > 0\) there is \(n_0\) such that for every \(n \ge n_0\), Maker has a winning strategy for every natural number \(b\) with \(0 < b \le (1 - \varepsilon)\, n / \ln n\), and Maker has no winning strategy for any natural number \(b \ge (1 + \varepsilon)\, n / \ln n\).

    Maker's side is Krivelevich's Theorem 1, which gives Maker a win for every \(b \le (1 - 30 / \ln^{1/4} n)\, n / \ln n\) once \(n\) is large. Breaker's side follows from the Chvátal-Erdős Theorem 3.1, whose Breaker strategy claims every edge at some vertex for every \(b > (1 + \varepsilon / 2)\, n / \ln n\) once \(n\) is large.
