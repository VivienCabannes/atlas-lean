    MetaMathlibExt.pebblingStep

    Let \(a = (a_0, \dots, a_{n-1})\) be a distribution of pebbles on the vertices \(0, \dots, n-1\), let \(k\) be a natural number and let \(i\) and \(j\) be vertices. The position after the \((k+1:k)\)-pebbling move from \(i\) to \(j\) is the distribution \(b\) with \(b_j = a_j + k\), \(b_i = a_i - (k + 1)\) if \(i \ne j\), and \(b_x = a_x\) for every other vertex \(x\). When \(i \ne j\) and \(a_i \ge k + 1\), this removes \(k + 1\) pebbles from \(i\) and adds \(k\) pebbles to \(j\).

    Subtraction is truncated at \(0\), so \(b_i = 0\) when \(i \ne j\) and \(a_i < k + 1\).

    public def pebblingStep {n : ℕ} (k : ℕ) (a : Fin n → ℕ) (i j : Fin n) : Fin n → ℕ :=
  Function.update (Function.update a i (a i - (k + 1))) j (a j + k)

    MetaMathlibExt.mem_pebblingMoves

    Let \(G\) be a simple graph on the vertices \(0, \dots, n-1\), let \(k\) be a natural number, and let \(a\) and \(b\) be distributions of pebbles on the vertices of \(G\). Then \(b\) is reachable from \(a\) by one \((k+1:k)\)-pebbling move on \(G\) if and only if there are adjacent vertices \(i\) and \(j\) of \(G\) such that \(i\) holds at least \(k + 1\) pebbles in \(a\) and \(b\) is obtained from \(a\) by removing \(k + 1\) pebbles from \(i\) and adding \(k\) pebbles to \(j\).

    MetaMathlibExt.pebblingGame

    Let \(G\) be a simple graph on the vertices \(0, \dots, n-1\) and let \(k\) be a natural number. The impartial two-player \((k+1:k)\)-pebbling game \(\Gamma^{(k+1:k)}_G\) has as positions all distributions \(a = (a_0, \dots, a_{n-1})\) of pebbles on the vertices, with \(a_i \in \mathbb{N}\). A move from \(a\) chooses adjacent vertices \(i\) and \(j\) with \(a_i \ge k + 1\), removes \(k + 1\) pebbles from \(i\) and adds \(k\) pebbles to \(j\). The game is ranked by the total number of pebbles \(a_0 + \dots + a_{n-1}\), which every move decreases.

    Its designated start position, which is not used, is the empty distribution.

    public def pebblingGame {n : ℕ} (G : SimpleGraph (Fin n)) [DecidableRel G.Adj] (k : ℕ) :
    ImpartialGame where
  Pos := Fin n → ℕ
  eqDec := inferInstance
  moves := pebblingMoves G k
  rank := fun a => ∑ i, a i
  rank_lt := by
    intro a b h
    obtain ⟨i, j, hadj, hi, rfl⟩ := (mem_pebblingMoves G k a b).1 h
    have := sum_pebblingStep_add_one k a hadj.ne hi
    omega
  start := fun _ => 0

    MetaMathlibExt.pebblingAllNTotals

    Let \(G\) be a simple graph on the vertices \(0, \dots, n-1\) and let \(k\) be a natural number. In the \((k+1:k)\)-pebbling game on \(G\), a move removes \(k+1\) pebbles from a vertex and adds \(k\) pebbles to an adjacent vertex. This is the set of natural numbers \(m\) such that every position with \(m\) pebbles in total (a number of pebbles on each vertex, summing to \(m\)) is an N-position, that is, not a P-position.

    The paper's \(m^{(k+1:k)}(G)\) is the least element of this set when the set is nonempty, and "\(m^{(k+1:k)}(G)\) does not exist" means the set is empty. The paper takes \(m\) positive; \(0\) never lies in the set, because the empty position is a P-position.

    public def pebblingAllNTotals {n : ℕ} (G : SimpleGraph (Fin n)) [DecidableRel G.Adj]
    (k : ℕ) : Set ℕ :=
  {m | ∀ a : Fin n → ℕ, ∑ i, a i = m → ¬ IsP (pebblingGame G k) a}
    noncomputable def IsP (G : ImpartialGame) : G.Pos → Prop :=
  (wfRel G).fix fun p ih => ∀ q (h : q ∈ G.moves p), ¬ ih q h
