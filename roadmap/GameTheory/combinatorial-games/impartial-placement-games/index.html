    MetaMathlibExt.placementTerminal

    Let \(\alpha\) be a finite set of cells and let \(E\) be a predicate on subsets of \(\alpha\), the condition under which play has ended. A position \(S \subseteq \alpha\) (the set of occupied cells) is terminal when \(E(S)\) holds or \(S = \alpha\): play has ended, or every cell is occupied. These are the positions with no options.

    public def placementTerminal {α : Type*} [Fintype α] (ended : Finset α → Prop)
    (S : Finset α) : Prop :=
  ended S ∨ S = Finset.univ

    MetaMathlibExt.placementUlt

    Let \(\alpha\) be a finite set of cells and let \(E\) be a predicate on subsets of \(\alpha\), the condition under which play has ended.     AbbreviationThe placement game#✓fully proved

    MetaMathlibExt.placementGame

    Let \(\alpha\) be a finite set of cells and let \(E\) be a predicate on subsets of \(\alpha\), the condition under which play has ended. The placement game is the impartial game whose positions are the subsets \(S \subseteq \alpha\) (the occupied cells), starting from the empty board \(\emptyset\). If \(E(S)\) holds there are no moves from \(S\); otherwise the moves from \(S\) lead to the positions \(S \cup \{c\}\) with \(c \notin S\). The rank of \(S\) is the number \(|\alpha| - |S|\) of empty cells.

    MetaMathlibExt.placementGame · 17 lines

    (ended : Finset α → Prop) : SpragueGrundy.ImpartialGame where
  Pos := Finset α
  eqDec := inferInstance
  moves := fun T =>
    @ite _ (ended T) (Classical.propDecidable _) ∅ ((Finset.univ \ T).image fun c => insert c T)
  rank := fun T => Fintype.card α - T.card
  rank_lt := by
    intro p q hq
    split_ifs at hq with h
    · simp at hq
    · obtain ⟨c, hc, rfl⟩ := Finset.mem_image.mp hq

      have h1 := Finset.card_insert_of_notMem hc'
      have h2 : p.card < Fintype.card α := Finset.card_lt_univ_of_notMem hc'
      omega
  start := ∅

    DefinitionEnd of Impartial Tic#✓fully proved

    MetaMathlibExt.ticEnded

    Write the cells of the \(n \times n\) board as pairs \((r, c)\) (row, column) in \(\{0, \dots, n-1\}^2\). Impartial Tic has ended at a set \(S\) of occupied cells when some row or some column is full: there is a row \(r\) with \((r, c) \in S\) for every column \(c\), or there is a column \(c\) with \((r, c) \in S\) for every row \(r\).

    public def ticEnded (n : ℕ) (S : Finset (Fin n × Fin n)) : Prop :=
  (∃ r, ∀ c, (r, c) ∈ S) ∨ ∃ c, ∀ r, (r, c) ∈ S

    DefinitionOrthogonal adjacency#✓fully proved

    MetaMathlibExt.takAdjacent

    Two cells \(p = (p_1, p_2)\) and \(q = (q_1, q_2)\) of the \(n \times n\) board \(\{0, \dots, n-1\}^2\), written as (row, column), are orthogonally adjacent when they lie in the same row and their columns differ by \(1\) (\(p_1 = q_1\) and \(|p_2 - q_2| = 1\)), or they lie in the same column and their rows differ by \(1\) (\(p_2 = q_2\) and \(|p_1 - q_1| = 1\)).

    public def takAdjacent {n : ℕ} (p q : Fin n × Fin n) : Prop :=
  (p.1 = q.1 ∧ ((p.2 : ℕ) + 1 = q.2 ∨ (q.2 : ℕ) + 1 = p.2)) ∨
    (p.2 = q.2 ∧ ((p.1 : ℕ) + 1 = q.1 ∨ (q.1 : ℕ) + 1 = p.1))

    DefinitionRoads in Impartial Tak#✓fully proved

    MetaMathlibExt.takHasRoad

    DefinitionWeights of the Weighted Cross#✓fully proved

    MetaMathlibExt.weightedCrossWeight

    For natural numbers \(a\) and \(b\), the weight \(w(a, b)\) is \(0\) if \(a, b \in \{0, 4\}\); otherwise it is \(2\) if \(a = 2\) and \(1 \le b \le 3\), or \(b = 2\) and \(1 \le a \le 3\); and it is \(1\) in all other cases. On the \(5 \times 5\) window \(0 \le a, b \le 4\) this puts weight \(0\) at the four corners, \(2\) on the central plus (the centre \((2, 2)\) and its four orthogonal neighbours) and \(1\) elsewhere.

    public def weightedCrossWeight (a b : ℕ) : ℕ :=
  if (a = 0 ∨ a = 4) ∧ (b = 0 ∨ b = 4) then 0
  else if (a = 2 ∧ 1 ≤ b ∧ b ≤ 3) ∨ (b = 2 ∧ 1 ≤ a ∧ a ≤ 3) then 2 else 1
