    Adaptive heuristics

    Adaptive heuristics are simple, myopic rules of behaviour for repeated games that move play in seemingly better directions (Hart 2005). The leading example is regret matching (Hart and Mas-Colell 2000): a player switches from its last action to another with probability proportional to its regret for not having made that switch in the past. When every player uses it, the empirical distribution of play converges almost surely to the set of correlated equilibria. Such dynamics are uncoupled, since each player uses only its own payoffs, and uncoupled dynamics cannot guarantee convergence to Nash equilibrium (Hart and Mas-Colell 2003). Calibrated forecasting (Foster and Vohra 1998) is a related route to correlated equilibria, built on the same regret-invariance condition.

    Regret matching

    DefinitionRegret matching#✓fully proved

    MathlibExt.GameTheory.RegretMatchingWanted.regretMatching

    After the first \(t + 1\) rounds, let \(j\) be player \(i\)'s last action and \(R(j, k)\) its regrets (the positive parts of the average conditional regrets). Regret matching plays each \(k \ne j\) with probability \(R(j, k)/\mu\) and repeats \(j\) with the remaining probability, for a fixed constant \(\mu\): "switch next period to a different action with a probability that is proportional to the regret for that action" (Hart 2005, §4).

    noncomputable def regretMatching (cost : ι → (∀ i, S i) → ℝ) (μ : ℝ) {t : ℕ}
    (h : Fin (t + 1) → ∀ i, S i) (i : ι) (k : S i) : ℝ :=
  if k = h (Fin.last t) i then
    1 - ∑ l ∈ univ.erase (h (Fin.last t) i),
      max (condRegret cost h i (h (Fin.last t) i) l / (t + 1)) 0 / μ
  else max (condRegret cost h i (h (Fin.last t) i) k / (t + 1)) 0 / μ
    def condRegret (cost : ι → (∀ i, S i) → ℝ) {T : ℕ} (play : Fin T → ∀ i, S i) (i : ι)
    (j k : S i) : ℝ :=
  ∑ t, switchGain cost i j k (play t)

    Uncoupled dynamics

    DefinitionNash equilibrium of Jordan's games#✓fully proved

    MathlibExt.GameTheory.UncoupledDynamicsWanted.jordanEq

    In Jordan's family of three-player two-action games with parameters \(a_1, a_2, a_3\) close to \(1\), where each player wants to mismatch the next, the unique Nash equilibrium has player \(i\) play its first action with probability \(a_{i-1}/(a_{i-1} + 1)\) (indices mod 3).

    noncomputable def jordanEq (a : Fin 3 → ℝ) (i : Fin 3) : ℝ :=
  a (i - 1) / (a (i - 1) + 1)

    TheoremUncoupled dynamics do not lead to Nash equilibrium#●ready to prove

    MathlibExt.GameTheory.UncoupledDynamicsWanted.not_exists_uncoupled_stable_dynamic

    Let \(0 < \varepsilon < 1\) and consider Jordan's three-player two-action games with parameters \(a_i \in (1 - \varepsilon, 1 + \varepsilon)\) and dynamics \(\dot x = F(x; a)\) on the probabilities of the players' first actions. No dynamic is both uncoupled (each \(F_i\) depends on the game only through player \(i\)'s own payoffs, here \(a_i\)) and, for every game of the family, \(C^1\) with the Nash equilibrium (unique for these parameters) as a rest point whose Jacobian has only eigenvalues of negative real part.

    Hart and Mas-Colell's Theorem 1 says that no uncoupled dynamic is Nash-convergent on a neighbourhood of Jordan's game; Nash-convergent dynamics have the properties above by their standing regularity assumptions (§I). The statement here is stronger than Theorem 1 as worded: it drops trajectory convergence and asks for uncoupledness only on Jordan's family. It is exactly what the §III argument proves: \(F^1(y^1, \tfrac12, \tfrac12) = 0\) for the games with \(a_3 = y^1/(1 - y^1)\) forces \(\partial F^1/\partial x^1 = 0\) at the equilibrium, and likewise for the other players, so the Jacobian has trace \(0\), which contradicts stability (Hart and Mas-Colell note that \(\det J \neq 0\) already suffices, footnote 15). Uncoupled dynamics can, by contrast, reach the set of correlated equilibria (regret matching).

    theorem_wanted not_exists_uncoupled_stable_dynamic {ε : ℝ} (hε : 0 < ε) (hε1 : ε < 1) :
    ¬ ∃ F : (Fin 3 → ℝ) → (Fin 3 → ℝ) → (Fin 3 → ℝ),
      (∀ x a a' i, (∀ j, |a j - 1| < ε) → (∀ j, |a' j - 1| < ε) → a i = a' i →
        F x a i = F x a' i) ∧
      ∀ a, (∀ j, |a j - 1| < ε) →
        ContDiff ℝ 1 (fun x => F x a) ∧ F (jordanEq a) a = 0 ∧
        ∀ z ∈ spectrum ℂ ((LinearMap.toMatrix'
          (fderiv ℝ (fun x => F x a) (jordanEq a) : (Fin 3 → ℝ) →ₗ[ℝ] Fin 3 → ℝ)).map
          (algebraMap ℝ ℂ)), z.re < 0
    noncomputable def jordanEq (a : Fin 3 → ℝ) (i : Fin 3) : ℝ :=

    Calibrated forecasting

    DefinitionCalibration score#✓fully proved

    MathlibExt.GameTheory.CalibrationWanted.calibrationScore

    For binary outcomes \(x_s\) and forecasts \(f_s \in \{0, 1/k, \dots, 1\}\) over \(t\) rounds, let \(n(p)\) be the number of rounds with forecast \(p\) and \(\rho(p)\) the fraction of them with outcome \(1\). The calibration score is $\(C_t = \sum_{p} \bigl(\rho(p) - p\bigr)^2 \frac{n(p)}{t} .\)$

    noncomputable def calibrationScore {k t : ℕ} (f : Fin t → Fin (k + 1)) (x : Fin t → Bool) :
    ℝ :=
  ∑ i : Fin (k + 1),
    ((#{s | f s = i ∧ x s = true} : ℝ) / #{s | f s = i} - (i : ℝ) / k) ^ 2 *
      #{s | f s = i} / t

    TheoremAsymptotic calibration#●ready to prove

    MathlibExt.GameTheory.CalibrationWanted.exists_calibrated_forecast

    For every \(\varepsilon > 0\) there are a grid \(\{0, 1/k, \dots, 1\}\) and a randomised forecasting rule such that, against every Nature who chooses each outcome knowing the past but not the current randomisation, the calibration score after \(t\) rounds is below \(\varepsilon\) with probability greater than \(1 - \varepsilon\) for all large \(t\). Deterministic forecasters cannot achieve this (Oakes 1985; Dawid 1985).

    Foster and Vohra's forecast chooses, each round, a distribution on the grid satisfying the conservation condition of their equation (2), which is the regret-invariance condition for the regrets of replacing one forecast by another; they take \(k \approx 1/\varepsilon^2\). Their definition of \(\varepsilon\)-calibration asks that \(\lim_t \Pr(C_t < \varepsilon) > 1 - \varepsilon\); the statement here asks for the inequality for all large \(t\), without the existence of the limit. It is therefore weaker than their definition, which implies it. Section 4 of their paper records a non-constructive proof by Sergiu Hart through the minimax theorem.

    theorem_wanted exists_calibrated_forecast {ε : ℝ} (hε : 0 < ε) :

          P.real {ω | (Z 0 ω).2 = b}) →
