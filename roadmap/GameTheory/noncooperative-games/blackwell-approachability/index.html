    Blackwell approachability

    In a repeated game with vector payoffs, a closed convex set is approachable when the decision maker can force the average payoff to converge to it, whatever the opponent does. Blackwell (1956) showed that this holds exactly when every closed half-space containing the set is enforceable, that is, when each scalarised game has a minimax value on the right side of the half-space. The Blackwell strategy plays, from the current average, a mixed action that keeps the next payoff in the half-space through the nearest point of the set; the squared distance \(\delta_t\) then satisfies \(t^2\delta_t \le (t-1)^2\delta_{t-1} + M^2\), which gives the rate \(M/\sqrt t\). Applied to the vector of regrets and the nonpositive orthant, approachability yields Hannan-consistent strategies and the strategies without conditional regret that lead to correlated equilibria (Hart and Mas-Colell 2000; Hart 2005).

    TheoremBlackwell's approachability recursion#✓fully proved

    MathlibExt.GameTheory.BlackwellApproachability.sq_mul_infDist_average_le

    Let \(C\) be a set in a real inner product space, \(\bar x_n\) the averages of a sequence \(y\), and \(c_n \in C\) a nearest point of \(C\) to \(\bar x_n\) for \(n \ge 1\). Suppose each new vector lies in the half-space through \(c_n\) with outer normal \(\bar x_n - c_n\), \(\langle \bar x_n - c_n,\, y_n - c_n\rangle \le 0\) for \(n \ge 1\), and \(\|y_n - c_n\| \le M\). Then, with \(\delta_n = \operatorname{dist}(\bar x_n, C)^2\), $\(n^2 \delta_n \le (n-1)^2 \delta_{n-1} + M^2, \qquad\text{hence}\qquad n^2\delta_n \le n M^2 .\)$ This is the computation in the proof of Blackwell's theorem, here for a deterministic sequence; in the game it is applied to conditional expectations of the payoffs.

    theorem sq_mul_infDist_average_le {C : Set E} {y c : ℕ → E} {M : ℝ} (hc : ∀ n, c n ∈ C)
    (hnear : ∀ n, 0 < n → ‖average y n - c n‖ = infDist (average y n) C)
    (hhalf : ∀ n, 0 < n → ⟪average y n - c n, y n - c n⟫ ≤ 0)
    (hM : ∀ n, ‖y n - c n‖ ≤ M) (n : ℕ) :
    ((n : ℝ) * infDist (average y n) C) ^ 2 ≤ n * M ^ 2
    noncomputable def average (y : ℕ → E) (n : ℕ) : E :=
  (n : ℝ)⁻¹ • ∑ k ∈ range n, y k

    TheoremBlackwell's half-space step#✓fully proved

    MathlibExt.GameTheory.BlackwellApproachability.exists_inner_sub_nonpos_of_enforceable

    Let \(C\) be convex and suppose every half-space \(\{x : \langle\lambda, x\rangle \le \rho\}\) containing \(C\) is enforceable: some mixed action \(q\) gives \(\langle \lambda, v(q, b)\rangle \le \rho\) against every opponent action \(b\). If \(c\) is a nearest point of \(C\) to \(x\), then some mixed action \(q\) satisfies \(\langle x - c,\, v(q, b) - c\rangle \le 0\) for every \(b\): the half-space through \(c\) with outer normal \(x - c\) contains \(C\), by the variational characterisation of the projection, and is enforceable.

    theorem exists_inner_sub_nonpos_of_enforceable {A B : Type*} [Fintype A] (v : A → B → E)
    {C : Set E} (hC : Convex ℝ C)
    (henf : ∀ (lam : E) (ρ : ℝ), (∀ c ∈ C, ⟪lam, c⟫ ≤ ρ) →
      ∃ q : Convexity.StdSimplex ℝ A, ∀ b, ⟪lam, ∑ a, q.weights a • v a b⟫ ≤ ρ)
    {x c : E} (hc : c ∈ C) (hnear : ‖x - c‖ = ⨅ w : C, ‖x - w‖) :
    ∃ q : Convexity.StdSimplex ℝ A, ∀ b, ⟪x - c, ∑ a, q.weights a • v a b - c⟫ ≤ 0

    TheoremBlackwell's approachability theorem, expected-payoff form#✓fully proved

    MathlibExt.GameTheory.BlackwellApproachability.blackwell_expected_approachability

    Let \(v : A \times B \to E\) be a vector payoff into a real Hilbert space, with \(A\) finite and \(\|v(a, b)\| \le R\), and let \(C \subseteq E\) be nonempty, closed and convex. If every closed half-space containing \(C\) is enforceable, the Blackwell strategy \(\sigma\) (a map from the current average expected payoff to a mixed action) satisfies, against every sequence \(\beta\) of opponent actions and for every \(c_0 \in C\), $\(\operatorname{dist}(\bar x_n, C) \le \frac{3R + \|c_0\|}{\sqrt n} \qquad (n \ge 1),\)$ where \(\bar x_n\) is the average of the first \(n\) expected payoffs. The constant \(3R + \|c_0\|\) bounds \(\|y_n - c_n\|\) and plays the role of Hart's \(M\) in the recursion (13); it is not Hart's constant. Since the mixed actions are determined by the opponent's sequence, this covers opponents who adapt to the past.

    This is the expected-payoff estimate in the proof of Blackwell's theorem; the almost-sure convergence of the realised payoffs additionally needs a strong law of large numbers for martingale differences and is recorded as Blackwell's approachability theorem.

    theorem blackwell_expected_approachability [CompleteSpace E] {A B : Type*} [Fintype A]
    (v : A → B → E) {C : Set E} (hne : C.Nonempty) (hcl : IsClosed C) (hcv : Convex ℝ C)
    (henf : ∀ (lam : E) (ρ : ℝ), (∀ c ∈ C, ⟪lam, c⟫ ≤ ρ) →
      ∃ q : Convexity.StdSimplex ℝ A, ∀ b, ⟪lam, ∑ a, q.weights a • v a b⟫ ≤ ρ)
    {R : ℝ} (hR : ∀ a b, ‖v a b‖ ≤ R) :
    ∃ σ : E → Convexity.StdSimplex ℝ A,
      ∀ (β : ℕ → B) (c₀ : E), c₀ ∈ C → ∀ n, 0 < n →
        infDist (average (strategyPayoffs v (fun x => (σ x).weights) β) n) C ≤
          (3 * R + ‖c₀‖) / Real.sqrt n
    noncomputable def average (y : ℕ → E) (n : ℕ) : E :=
  (n : ℝ)⁻¹ • ∑ k ∈ range n, y k

    TheoremBlackwell's approachability theorem#●ready to prove

    MathlibExt.GameTheory.BlackwellApproachabilityWanted.blackwell_approachability

    Let \(v : A \times B \to \mathbb R^d\) be a vector payoff with finite action sets and \(C\) a nonempty closed convex set such that every closed half-space containing \(C\) is enforceable. Then \(C\) is approachable: the Blackwell strategy guarantees that, whatever the opponent does (possibly randomising and adapting to the past), the average realised vector payoff converges to \(C\) almost surely. The condition is also necessary (Hart 2005, Theorem 5); that direction is not recorded here.

    Randomised play is modelled by a process of realised action pairs whose conditional law given the past makes the decision maker's action follow the Blackwell strategy, independently of the opponent's current action.
