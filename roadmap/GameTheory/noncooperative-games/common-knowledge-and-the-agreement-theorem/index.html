    Common knowledge and the agreement theorem

    In Aumann's partition model of differential information, a finite set of states of the world carries a common prior and one information partition per agent; at each state an agent learns the cell of its partition that contains the state, and knows an event when that cell lies inside it. An event is common knowledge when it contains the cell of the meet (finest common coarsening) of the partitions, which is equivalent to every finite statement "agent \(i_1\) knows that agent \(i_2\) knows that … \(E\)" holding. Aumann's agreement theorem (1976) says that agents with a common prior whose posteriors for an event are common knowledge have equal posteriors: they cannot agree to disagree. Geanakoplos and Polemarchakis (1982) showed that communicating posteriors back and forth leads to such common knowledge, and hence to agreement, in finitely many rounds.

    In a partition model, the information of an agent is a partition \(\mathcal P\) of the set \(\Omega\) of states of the world, here an equivalence relation \(r\) on \(\Omega\).     DefinitionCommon knowledge#✓fully proved

    MathlibExt.GameTheory.InteractiveEpistemology.IsCommonKnowledgeAt

    Let agents \(i\) have information partitions \(\mathcal P_i\) of \(\Omega\), and let \(\mathcal M\) be their meet, the finest partition that is coarser than every \(\mathcal P_i\). An event \(E\) is common knowledge at \(\omega\) when \(E\) contains the cell \(M(\omega)\) of the meet that contains \(\omega\).

    In Mathlib's order on equivalence relations (\(r \le s\) when \(r\) is finer than \(s\)), the meet in Aumann's sense is the supremum \(\bigsqcup_i r_i\), and the Lean definition uses that supremum directly. The name "meet" refers to partitions ordered by refinement, where the order is reversed.

    def IsCommonKnowledgeAt {ι : Type*} (r : ι → Setoid Ω) (E : Set Ω) (ω : Ω) : Prop :=
  cell (⨆ i, r i) ω ⊆ E
    def cell (r : Setoid Ω) (ω : Ω) : Set Ω := {ω' | r ω' ω}

    TheoremCommon knowledge as iterated knowledge#✓fully proved

    MathlibExt.GameTheory.InteractiveEpistemology.isCommonKnowledgeAt_iff_forall_knowsChain

    An event \(E\) is common knowledge at \(\omega\) (it contains the meet cell of \(\omega\)) if and only if, for every finite sequence of agents \(i_1, \dots, i_k\) (repetitions allowed, \(k \ge 0\)), $\(\omega \in K_{i_1} K_{i_2} \cdots K_{i_k}(E),\)$ that is, at \(\omega\) agent \(i_1\) knows that agent \(i_2\) knows that … agent \(i_k\) knows \(E\).

    The proof follows Aumann's argument: a state lies in the meet cell of \(\omega\) exactly when it is reachable from \(\omega\) by a finite chain of states in which consecutive states share a cell of some agent's partition, and that chain gives the sequence of agents.

    Compared with the source: Aumann argues the equivalence informally for two agents, with chains that alternate between the two partitions; here the family of agents is arbitrary.

    theorem isCommonKnowledgeAt_iff_forall_knowsChain {ι : Type*} (r : ι → Setoid Ω) (E : Set Ω)
    (ω : Ω) : IsCommonKnowledgeAt r E ω ↔ ∀ l : List ι, ω ∈ knowsChain r l E
    def IsCommonKnowledgeAt {ι : Type*} (r : ι → Setoid Ω) (E : Set Ω) (ω : Ω) : Prop :=
  cell (⨆ i, r i) ω ⊆ E

    TheoremValues of commonly known functions are common knowledge#✓fully proved

    MathlibExt.GameTheory.InteractiveEpistemology.isCommonKnowledgeAt_level_set

    Let \(f\) be a function on \(\Omega\) that every agent knows, that is, \(f\) is constant on every cell of every agent's partition. Then \(f\) is constant on the cells of the meet, and the event \(\{\omega' : f(\omega') = f(\omega)\}\) is common knowledge at \(\omega\).

    The meet is the finest partition coarser than all the agents' partitions, and the level sets of \(f\) form such a coarser partition, so the meet is finer than it.

    theorem isCommonKnowledgeAt_level_set {ι β : Type*} {r : ι → Setoid Ω} {f : Ω → β}
    (h : ∀ i, r i ≤ Setoid.ker f) (ω : Ω) : IsCommonKnowledgeAt r {ω' | f ω' = f ω} ω

    The agreement theorem

    DefinitionPosterior probability#✓fully proved

    MathlibExt.GameTheory.InteractiveEpistemology.posterior

    Let \(\mu\) be a finite measure on a finite set \(\Omega\) of states (the common prior) and \(\mathcal P\) an agent's information partition. The agent's posterior probability of the event \(A\) at the state \(\omega\) is $\(q(\omega) = \frac{\mu(A \cap P(\omega))}{\mu(P(\omega))}.\)$ It is the conditional probability of \(A\) given the cell \(P(\omega)\), and agrees with Mathlib's conditional measure \(\mu[\,\cdot \mid P(\omega)]\). If the cell is null, Lean's convention \(x / 0 = 0\) makes the posterior \(0\); Aumann assumes the relevant cells nonnull.

    noncomputable def posterior (r : Setoid Ω) (A : Set Ω) (ω : Ω) : ℝ :=
  μ.real (A ∩ cell r ω) / μ.real (cell r ω)
    def cell (r : Setoid Ω) (ω : Ω) : Set Ω := {ω' | r ω' ω}

    TheoremThe tower step of the agreement theorem#✓fully proved

    MathlibExt.GameTheory.InteractiveEpistemology.measureReal_inter_cell_eq_mul

    Let \(\mathcal P\) be finer than \(\mathcal Q\), and let \(Q\) be a cell of \(\mathcal Q\). If the posterior of \(A\) given \(\mathcal P\) equals \(a\) at every state of \(Q\), then $\(\mu(A \cap Q) = a\,\mu(Q).\)$ Indeed \(Q\) is a disjoint union of cells \(P_j\) of \(\mathcal P\), on each of which \(\mu(A \cap P_j) = a\,\mu(P_j)\); summing over \(j\) gives the claim. No cell needs to be nonnull: on a null cell \(P_j\) both sides vanish.

    theorem measureReal_inter_cell_eq_mul [IsFiniteMeasure μ] {r s : Setoid Ω} (hrs : r ≤ s)
    (A : Set Ω) (ω : Ω)
    {a : ℝ} (h : ∀ ω' ∈ cell s ω, posterior μ r A ω' = a) :
    μ.real (A ∩ cell s ω) = a * μ.real (cell s ω)
    def cell (r : Setoid Ω) (ω : Ω) : Set Ω := {ω' | r ω' ω}

    TheoremAgreement theorem#✓fully proved

    MathlibExt.GameTheory.InteractiveEpistemology.agreement

    Agents \(i \in I\) share a prior \(\mu\) on a finite set \(\Omega\) of states and have information partitions \(\mathcal P_i\). Let \(A\) be an event and \(q_i\) agent \(i\)'s posterior of \(A\). If at the state \(\omega\) it is common knowledge that \(q_i = a_i\) for every \(i\), and the cell of the meet containing \(\omega\) has positive prior probability, then \(a_i = a_j\) for all \(i, j\): agents with a common prior cannot agree to disagree.

    The proof is Aumann's. The meet cell \(M\) of \(\omega\) is a union of cells of each \(\mathcal P_i\); on each such cell \(P\) the posterior is \(a_i\), so \(\mu(A \cap P) = a_i\,\mu(P)\), and summing over the cells in \(M\) gives \(\mu(A \cap M) = a_i\,\mu(M)\). As \(\mu(M) > 0\), every \(a_i\) equals \(\mu(A \cap M)/\mu(M)\).

    Compared with the source, the two statements are incomparable. Aumann works on an arbitrary probability space, with two agents whose join (coarsest common refinement) consists of nonnull events; here the state space is finite. Within finite state spaces the statement is stronger: any family of agents is allowed, and only the meet cell of \(\omega\) must be nonnull. That extra generality relies on the convention that the posterior on a null cell is \(0\) (Lean's \(x/0 = 0\)): the common-knowledge hypothesis is read with that value, so an agent with a null cell inside the meet cell must be assigned the value \(0\) there. The two-agent form is Agreeing to disagree. The hypothesis cannot be weakened to mutual knowledge of the posteriors: in Aumann's four-state example both agents know each other's posterior, yet the posteriors are \(1/2\) and \(1/3\) (tested in MathlibExtTest/GameTheory/InteractiveEpistemology/AgreementTheorem.lean).

    theorem agreement [IsFiniteMeasure μ] {ι : Type*} (r : ι → Setoid Ω) (A : Set Ω) (ω : Ω) (a : ι → ℝ)
    (hck : IsCommonKnowledgeAt r {ω' | ∀ i, posterior μ (r i) A ω' = a i} ω)
    (hM : μ.real (cell (⨆ i, r i) ω) ≠ 0) (i j : ι) : a i = a j
    def IsCommonKnowledgeAt {ι : Type*} (r : ι → Setoid Ω) (E : Set Ω) (ω : Ω) : Prop :=
  cell (⨆ i, r i) ω ⊆ E

    TheoremAgreeing to disagree#✓fully proved

    MathlibExt.GameTheory.InteractiveEpistemology.agreeing_to_disagree

    Two agents share a prior \(\mu\) on a finite set \(\Omega\) of states and have information partitions \(\mathcal P_1, \mathcal P_2\). If at \(\omega\) it is common knowledge that agent 1's posterior of \(A\) is \(q_1\) and agent 2's is \(q_2\) (the cell of the meet of \(\mathcal P_1\) and \(\mathcal P_2\) that contains \(\omega\) lies in the event where the posteriors take these values), and that cell is not null, then \(q_1 = q_2\).

    This is Aumann's two-agent theorem on a finite state space. Aumann works on an arbitrary probability space whose join cells are nonnull, so the two statements are incomparable. On finite spaces his hypothesis implies the one used here, which concerns only the meet cell of \(\omega\); that extra generality relies on the convention that the posterior on a null cell is \(0\).

    theorem agreeing_to_disagree [IsFiniteMeasure μ] (r₁ r₂ : Setoid Ω) (A : Set Ω) (ω : Ω) (q₁ q₂ : ℝ)
    (hck : cell (r₁ ⊔ r₂) ω ⊆ {ω' | posterior μ r₁ A ω' = q₁ ∧ posterior μ r₂ A ω' = q₂})
    (hM : μ.real (cell (r₁ ⊔ r₂) ω) ≠ 0) : q₁ = q₂

    Dialogues of posteriors

    DefinitionOne round of public announcement of posteriors#✓fully proved

    MathlibExt.GameTheory.InteractiveEpistemology.dialogueStep

    Given information partitions \(\mathcal P_i\) and an event \(A\), every agent announces its posterior \(q_i\) of \(A\). Agent \(i\)'s new partition is the common refinement of \(\mathcal P_i\) and the partition of \(\Omega\) into the level sets of the profile \(\omega \mapsto (q_j(\omega))_j\).

    This is a simultaneous-announcement form of the communication process of Geanakoplos and Polemarchakis, in which the two agents communicate back and forth.

    TheoremWe can't disagree forever#✓fully proved

    MathlibExt.GameTheory.InteractiveEpistemology.geanakoplos_polemarchakis

    Finitely many agents share a prior on a finite set \(\Omega\) of states. In each round every agent announces publicly its current posterior of the event \(A\), and every agent refines its information partition by the level sets of the announced profile of posteriors. Then the partitions stop changing after finitely many rounds \(T\), and at round \(T\) all agents' posteriors of \(A\) are equal at every state whose meet cell is not null.

    The proof: partitions only get finer, and a finite set has finitely many partitions, so the sequence stabilises. At a fixed point every agent's posterior is constant on every agent's cells, hence on the cells of the meet; the posteriors are then common knowledge and the agreement theorem applies.

    Compared with the source: Geanakoplos and Polemarchakis assume finite information partitions, whereas here the state space is finite; in their paper the two agents communicate back and forth, and the abstract also states that any number of rounds can be needed and that the limit need not be the posterior given the pooled information; here any finite family announces simultaneously, no bound on \(T\) is claimed, and those complements are not formalised.

    theorem geanakoplos_polemarchakis [IsFiniteMeasure μ] {ι : Type*} [Finite ι] (A : Set Ω)
    (r₀ : ι → Setoid Ω) :
    ∃ T, (∀ n, T ≤ n → dialogue μ A r₀ n = dialogue μ A r₀ T) ∧
      ∀ ω, μ.real (cell (⨆ i, dialogue μ A r₀ T i) ω) ≠ 0 →
        ∀ i j, posterior μ (dialogue μ A r₀ T i) A ω =
          posterior μ (dialogue μ A r₀ T j) A ω
