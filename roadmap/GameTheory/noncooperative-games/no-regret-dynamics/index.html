    No-regret dynamics

    When a game is played repeatedly and every player uses a no-regret learning algorithm, the empirical distribution of play converges to the set of coarse correlated equilibria. Roughgarden's smoothness framework shows that price-of-anarchy bounds proved by a smoothness argument hold for these outcomes too, so the time-averaged social cost of no-regret play is nearly as good as that of any Nash equilibrium. A simple strategy with vanishing regret is unconditional regret matching, which plays each action with probability proportional to the positive part of its average regret; it is Blackwell's approachability strategy for the nonpositive orthant of regret vectors (Hart and Mas-Colell 2000, Theorem B).

    DefinitionCoarse correlated equilibrium#✓fully proved

    MathlibExt.GameTheory.NoRegretDynamics.IsCoarseCorrelatedEq

    In a finite strategic game with costs \(c_i\), a probability distribution \(\sigma\) on strategy profiles is an \(\varepsilon\)-coarse correlated equilibrium (with additive error \(\varepsilon\)) if no player can lower its expected cost by more than \(\varepsilon\) by committing in advance to a fixed strategy: $\(\mathbb E_{s \sim \sigma}[c_i(s)] \le \mathbb E_{s \sim \sigma}[c_i(a, s_{-i})] + \varepsilon\)$ for every player \(i\) and every strategy \(a \in S_i\). For \(\varepsilon = 0\) these contain the correlated equilibria, the mixed Nash equilibria and the pure Nash equilibria.

    def IsCoarseCorrelatedEq (cost : ι → (∀ i, S i) → ℝ) (μ : (∀ i, S i) → ℝ) (ε : ℝ) :
    Prop :=
  IsDistribution μ ∧
    ∀ i (a : S i), ∑ s, μ s * cost i s ≤ ∑ s, μ s * cost i (Function.update s i a) + ε
    def IsDistribution (μ : (∀ i, S i) → ℝ) : Prop :=
  (∀ s, 0 ≤ μ s) ∧ ∑ s, μ s = 1

    DefinitionRegret against a fixed strategy#✓fully proved

    MathlibExt.GameTheory.NoRegretDynamics.regret

    The regret of player \(i\) against the fixed strategy \(a\) over the rounds \(s^1, \dots, s^T\) is $\(\sum_{t=1}^T c_i(s^t) - \sum_{t=1}^T c_i(a, s^t_{-i}),\)$ how much better \(i\) would have done by playing \(a\) in every round while the others played as they did. A no-regret algorithm keeps the maximum over \(a\) of this quantity in \(o(T)\) against every sequence of opponents' play.

    def regret (cost : ι → (∀ i, S i) → ℝ) {T : ℕ} (play : Fin T → ∀ i, S i) (i : ι)
    (a : S i) : ℝ :=
  ∑ t, cost i (play t) - ∑ t, cost i (Function.update (play t) i a)

    TheoremNo-regret dynamics converge to coarse correlated equilibria#✓fully proved

    MathlibExt.GameTheory.NoRegretDynamics.isCoarseCorrelatedEq_empirical

    DefinitionSmooth game#✓fully proved

    MathlibExt.GameTheory.NoRegretDynamics.IsSmooth

    A cost-minimisation game is \((\lambda, \mu)\)-smooth if $\(\sum_i c_i(t_i, s_{-i}) \le \lambda\, C(t) + \mu\, C(s)\)$ for every two profiles \(s\) and \(t\). For \(\mu < 1\) this implies that every pure Nash equilibrium costs at most \(\lambda / (1 - \mu)\) times every profile, the robust price-of-anarchy bound.

    def IsSmooth (cost : ι → (∀ i, S i) → ℝ) (lam mu : ℝ) : Prop :=
  ∀ s t : ∀ i, S i,
    ∑ i, cost i (Function.update s i (t i)) ≤ lam * socialCost cost t + mu * socialCost cost s
    def socialCost (cost : ι → (∀ i, S i) → ℝ) (s : ∀ i, S i) : ℝ :=
  ∑ i, cost i s

    TheoremExtension theorem for coarse correlated equilibria#✓fully proved

    MathlibExt.GameTheory.NoRegretDynamics.IsSmooth.expected_socialCost_le

    In a \((\lambda, \mu)\)-smooth game with player set \(I\), every \(\varepsilon\)-coarse correlated equilibrium (additive error \(\varepsilon\)) \(\sigma\) satisfies $\((1 - \mu)\, \mathbb E_{s \sim \sigma}[C(s)] \le \lambda\, C(t) + |I|\, \varepsilon\)$ for every profile \(t\). For \(\mu < 1\) and \(\varepsilon = 0\) this is \(\mathbb E_\sigma[C] \le \frac{\lambda}{1 - \mu}\, C(t)\): price-of-anarchy bounds proved by smoothness hold for coarse correlated equilibria, not only for Nash equilibria.

    theorem IsSmooth.expected_socialCost_le {cost : ι → (∀ i, S i) → ℝ} {lam mu ε : ℝ}

    (t : ∀ i, S i) :
    (1 - mu) * ∑ s, σ s * socialCost cost s ≤
      lam * socialCost cost t + Fintype.card ι * ε

    TheoremRobust price of anarchy for no-regret dynamics#✓fully proved

    MathlibExt.GameTheory.NoRegretDynamics.IsSmooth.average_socialCost_le

    In a \((\lambda, \mu)\)-smooth game with player set \(I\), if after \(T \ge 1\) rounds every player's regret against every fixed strategy is at most \(T \varepsilon\), then the time-averaged social cost \(A = \frac1T \sum_{t=1}^T C(s^t)\) satisfies $\((1 - \mu)\, A \le \lambda\, C(t) + |I|\, \varepsilon\)$ for every profile \(t\).     (1 - mu) * ((∑ k, socialCost cost (play k)) / T) ≤
      lam * socialCost cost t + Fintype.card ι * ε

    DefinitionRegret vector#✓fully proved

    MathlibExt.GameTheory.UnconditionalRegretMatching.regretVector

    For a decision maker with finite action set \(A\) and costs \(c(a, b)\) against the opponent's action \(b\), the regret vector of having played \(a\) against \(b\) has coordinates \(c(a, b) - c(k, b)\), \(k \in A\): the cost saved by playing \(k\) instead. Its average over the rounds is the vector of signed unconditional regrets \(\tilde V(k) - U\) of Hart (2005), in cost form.

    def regretVector (c : A → B → ℝ) (a : A) (b : B) : EuclideanSpace ℝ A :=
  WithLp.toLp 2 fun k => c a b - c k b

    DefinitionUnconditional regret matching#✓fully proved

    MathlibExt.GameTheory.UnconditionalRegretMatching.urm

    Given the average regret vector \(x\), unconditional regret matching plays each action \(k\) with probability \(x_k^+ / \sum_l x_l^+\), proportional to the positive part of its regret, and uniformly when no regret is positive (where Hart leaves the choice arbitrary).

    noncomputable def urm (x : EuclideanSpace ℝ A) (k : A) : ℝ :=
  if 0 < ∑ l, max (x l) 0 then max (x k) 0 / ∑ l, max (x l) 0 else (Fintype.card A : ℝ)⁻¹

    MathlibExt.GameTheory.UnconditionalRegretMatching.average_regret_le_of_urm

    Let \(R\) bound the norms of the regret vectors. If the decision maker plays at each round the mixed action \(q_t\) of unconditional regret matching, computed from the average expected regret vector of the previous rounds, then against every sequence \((b_t)\) of opponent actions and for every action \(k\) $\(\frac1n \sum_{t < n} \Bigl(\sum_a q_t(a)\, c(a, b_t) - c(k, b_t)\Bigr) \le \frac{2R}{\sqrt n} \qquad (n \ge 1).\)$ This is the expected-payoff form of Hart and Mas-Colell's Theorem B (Hart 2005, Proposition 4): unconditional regret matching is Hannan-consistent. The almost-sure statement for realised payoffs, which needs a strong law of large numbers, is not formalised.
