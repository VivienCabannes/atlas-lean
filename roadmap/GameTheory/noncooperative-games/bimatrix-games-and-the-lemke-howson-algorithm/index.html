    Bimatrix games and the Lemke–Howson algorithm

    A bimatrix game is a two-player game given by a payoff matrix for each player. The Lemke–Howson algorithm (1964) finds a Nash equilibrium by following a path of almost completely labelled vertex pairs of the two best-response polytopes from the artificial equilibrium \((0,0)\). In a nondegenerate game these vertex pairs form a graph whose vertices have degree one or two, so its path endpoints, the artificial equilibrium and the Nash equilibria, are even in number: a nondegenerate bimatrix game has an odd number of equilibria (von Stengel, Algorithmic Game Theory, Corollary 3.7). Papadimitriou abstracted this parity argument into the complexity class PPAD (Algorithmic Game Theory, Chapter 2, Section 2.4). The odd-number theorem is recorded here as wanted.

    MathlibExt.GameTheory.LemkeHowsonWanted.IsBimatrixNash

    The mixed pair (x, y) is a Nash equilibrium of the game (A, B) if x maximises player 1's expected payoff x'ᵀAy against y and y maximises player 2's expected payoff xᵀBy' against x (von Stengel, Algorithmic Game Theory, Section 3.2).

    def IsBimatrixNash (A B : M → N → ℝ) (x : StdSimplex ℝ M) (y : StdSimplex ℝ N) : Prop :=
  (∀ x' : StdSimplex ℝ M, bilinPayoff A x' y ≤ bilinPayoff A x y) ∧
    ∀ y' : StdSimplex ℝ N, bilinPayoff B x y' ≤ bilinPayoff B x y
    noncomputable def bilinPayoff (C : M → N → ℝ) (x : StdSimplex ℝ M) (y : StdSimplex ℝ N) : ℝ :=
  ∑ i, ∑ j, x.weights i * C i j * y.weights j

    MathlibExt.GameTheory.LemkeHowsonWanted.IsNondegenerate

    No mixed strategy with support of size k has more than k pure best responses, for either player (von Stengel, Algorithmic Game Theory, Definition 3.2).

    If both players have at least one pure strategy and the game (A, B) is nondegenerate, then the set of Nash equilibria (x, y) is finite and has odd cardinality. (Set.ncard of an infinite set is 0, so oddness of ncard includes finiteness.)

    Remarks
    Remarks
    • Both hypotheses matter: with an empty strategy set there is no mixed strategy at all, and degenerate games can have infinitely many equilibria: when all payoffs are zero, every pair of mixed strategies is one (and that game is degenerate as soon as a player has two pure strategies).
    Background
    Background
    • Nash's theorem: existence of an equilibrium in every finite game, proved from Brouwer's theorem.
    • Every END-OF-THE-LINE instance has a sink: the parity principle that the Lemke–Howson path instantiates.

    Related topics

    • Nash's theorem: existence of equilibria in every finite game, proved from Brouwer's theorem; Lemke–Howson gives a combinatorial proof for two players.
    • PPAD and the END-OF-THE-LINE problem: the complexity class abstracted from the Lemke–Howson argument; computing an approximate equilibrium of a bimatrix game is complete for it (Chen and Deng; Daskalakis, Goldberg and Papadimitriou 2009, Theorem 6.1).
    • Von Neumann's minimax theorem: the zero-sum case, solvable by linear programming.
    • Correlated equilibria: in a nondegenerate two-player game the Nash equilibria are vertices of the correlated-equilibrium polytope (Papadimitriou, Algorithmic Game Theory, Theorem 2.5).
