    Selfish routing and the price of anarchy

    Nonatomic routing games: infinitely many users each control a negligible amount of traffic and choose a minimum-latency path. Equilibria are Wardrop flows; they exist when latencies are continuous, they all have the same cost when latencies are nondecreasing, they cost at most \(4/3\) times the optimum when latencies are affine (Pigou's network shows this is tight), and never more than an optimal routing of twice the traffic. Braess's paradox shows that adding a link can make every user worse off.

    StructureNonatomic routing instance#✓fully proved

    MathlibExt.GameTheory.SelfishRouting.RoutingInstance

    A nonatomic routing instance consists of a finite set \(E\) of edges, a set of commodities, a finite set \(\mathcal P\) of paths, each path \(P\) belonging to a commodity \(i(P)\) and using a finite set of edges, and a latency function \(\ell_e : \mathbb R \to \mathbb R\) for each edge \(e\), giving the delay of every unit of traffic on \(e\) as a function of the total flow on \(e\).

    In a directed graph with source–sink pairs \((s_i, t_i)\), \(\mathcal P\) is the set of simple \(s_i\)–\(t_i\) paths. The Lean structure only records which edges each path uses, so it also covers the nonatomic congestion games of Roughgarden and Tardos (2004), where a strategy is any set of resources.

    structure RoutingInstance (E ι P : Type*) where
  /-- The commodity (source–destination pair) served by a path. -/
  commodity : P → ι
  /-- The edges used by a path. -/
  edges : P → Finset E
  /-- The latency of an edge as a function of the flow on it. -/
  latency : E → ℝ → ℝ

    DefinitionWardrop equilibrium#✓fully proved

    MathlibExt.GameTheory.SelfishRouting.RoutingInstance.IsWardrop

    A path flow \(f\) is a Wardrop equilibrium (a flow at Nash equilibrium) if for all paths \(P_1, P_2\) of the same commodity with \(f_{P_1} > 0\), \(\ell_{P_1}(f) \le \ell_{P_2}(f)\): every path carrying flow has minimum latency among the paths of its commodity. In particular all flow paths of a commodity have the same latency.

    Roughgarden and Tardos define flows at Nash equilibrium by infinitesimal deviations (Definition 2.1) and prove that for continuous nondecreasing latencies this is equivalent to the condition above (Lemma 2.2). The Lean definition is the condition itself, for arbitrary latencies.

    def IsWardrop (f : P → ℝ) : Prop :=
  ∀ p q, N.commodity p = N.commodity q → 0 < f p → N.pathLatency f p ≤ N.pathLatency f q

    TheoremExistence of Wardrop equilibria#✓fully proved

    MathlibExt.GameTheory.SelfishRouting.RoutingInstance.exists_isWardrop

    Consider a nonatomic routing instance in which every latency function \(\ell_e\) is continuous on \([0, \infty)\) and every commodity has at least one path. Then for every demand vector \(r\) with \(r_i \ge 0\) there is a flow feasible for \(r\) that is a Wardrop equilibrium.

    The proof is Beckmann's: the feasible flows form a nonempty compact set, so the Beckmann potential $\(\Phi(f) = \sum_{e \in E} \int_0^{f_e} \ell_e(x)\, dx\)$ attains its minimum on it. At a minimiser \(f\), if a path \(P\) with \(f_P > 0\) had larger latency than a path \(Q\) of the same commodity, moving a small amount \(\delta\) of traffic from \(P\) to \(Q\) would change \(\Phi\) at rate \(\ell_Q(f) - \ell_P(f) < 0\), a contradiction. Monotonicity of the latencies is not needed for existence; it makes \(\Phi\) convex, and then every Wardrop equilibrium minimises \(\Phi\) and all have the same cost.

    The path hypothesis cannot be dropped: a commodity with positive demand and no path has no feasible flow.

    theorem exists_isWardrop [Finite E] (hℓ : ∀ e, ContinuousOn (N.latency e) (Set.Ici 0)) {r : ι → ℝ}
    (hr : ∀ i, 0 ≤ r i) (hpath : ∀ i, ∃ p, N.commodity p = i) :
    ∃ f, N.IsFeasible r f ∧ N.IsWardrop f

    TheoremWardrop flows against a scaled demand#✓fully proved

    MathlibExt.GameTheory.SelfishRouting.RoutingInstance.IsWardrop.smul_sum_pathLatency_mul_le

    Let \(f\) be a Wardrop equilibrium that is feasible for the demand \(r\), let \(c \in \mathbb R\), and let \(g\) be a flow feasible for the demand \(c\, r\). Then $\(c \sum_P \ell_P(f)\, f_P \le \sum_P \ell_P(f)\, g_P .\)$

    Each commodity \(i\) with \(r_i > 0\) has a common latency \(L_i\) on its flow paths, so the left side is \(c \sum_i L_i r_i\) (Lemma 2.3 of Roughgarden–Tardos), while every path of \(i\) has latency at least \(L_i\) under \(f\).

    theorem IsWardrop.smul_sum_pathLatency_mul_le [Finite ι] {f g : P → ℝ} {r : ι → ℝ}
    {c : ℝ} (hW : N.IsWardrop f) (hf : N.IsFeasible r f) (hg : N.IsFeasible (c • r) g) :
    c * ∑ p, N.pathLatency f p * f p ≤ ∑ p, N.pathLatency f p * g p

    TheoremVariational inequality for Wardrop equilibria#✓fully proved

    MathlibExt.GameTheory.SelfishRouting.RoutingInstance.IsWardrop.cost_le_sum_latency_mul_edgeFlow

    If \(f\) is a Wardrop equilibrium and \(g\) is any flow feasible for the same demand \(r\), then $\(C(f) \le \sum_{e \in E} \ell_e(f_e)\, g_e .\)$ Equivalently \(\sum_e \ell_e(f_e)(g_e - f_e) \ge 0\): with the latencies frozen at their equilibrium values, no feasible flow is cheaper than \(f\).

    theorem IsWardrop.cost_le_sum_latency_mul_edgeFlow [Finite ι] {f g : P → ℝ} {r : ι → ℝ}
    (hW : N.IsWardrop f) (hf : N.IsFeasible r f) (hg : N.IsFeasible r g) :
    N.cost f ≤ ∑ e, N.latency e (N.edgeFlow f e) * N.edgeFlow g e

    TheoremWardrop equilibria have unique edge latencies#✓fully proved

    MathlibExt.GameTheory.SelfishRouting.RoutingInstance.IsWardrop.latency_edgeFlow_eq

    Suppose every latency function \(\ell_e\) is nondecreasing on \([0, \infty)\). If \(f\) and \(g\) are Wardrop equilibria feasible for the same demand, then \(\ell_e(f_e) = \ell_e(g_e)\) for every edge \(e\).

    The proof adds the variational inequalities of \(f\) and \(g\): \(\sum_e (\ell_e(f_e) - \ell_e(g_e))(f_e - g_e) \le 0\), and every term is nonnegative by monotonicity (edge flows of feasible flows are nonnegative), hence zero.

    theorem IsWardrop.latency_edgeFlow_eq [Finite ι] [Finite E] {f g : P → ℝ} {r : ι → ℝ}
    (hmono : ∀ e, MonotoneOn (N.latency e) (Set.Ici 0)) (hWf : N.IsWardrop f)
    (hf : N.IsFeasible r f)
    (hWg : N.IsWardrop g) (hg : N.IsFeasible r g) (e : E) :
    N.latency e (N.edgeFlow f e) = N.latency e (N.edgeFlow g e)

    TheoremPrice of anarchy 4/3 for affine latencies#✓fully proved

    MathlibExt.GameTheory.SelfishRouting.RoutingInstance.IsWardrop.cost_le_of_affine

    Suppose every latency is affine, \(\ell_e(x) = a_e x + b_e\) with \(a_e, b_e \ge 0\). If \(f\) is a Wardrop equilibrium and \(g\) is any flow feasible for the same demand, then $\(C(f) \le \tfrac43\, C(g).\)$ So the price of anarchy of selfish routing with affine latencies is at most \(4/3\); Pigou's network shows that \(4/3\) is attained.

    The proof combines the variational inequality \(C(f) \le \sum_e \ell_e(f_e) g_e\) with the pointwise bound \(a_e f_e g_e \le a_e g_e^2 + a_e f_e^2 / 4\), which gives \(C(f) \le C(g) + C(f)/4\).

    theorem IsWardrop.cost_le_of_affine [Finite ι] {f g : P → ℝ} {r : ι → ℝ} {a b : E → ℝ}
    (ha : ∀ e, 0 ≤ a e) (hb : ∀ e, 0 ≤ b e) (hlat : ∀ e x, N.latency e x = a e * x + b e)
    (hW : N.IsWardrop f) (hf : N.IsFeasible r f) (hg : N.IsFeasible r g) :
    N.cost f ≤ 4 / 3 * N.cost g

    TheoremBicriteria bound for selfish routing#✓fully proved

    MathlibExt.GameTheory.SelfishRouting.RoutingInstance.IsWardrop.mul_cost_le_of_feasible_one_add

    Suppose every latency \(\ell_e\) is nonnegative and nondecreasing on \([0, \infty)\). If \(f\) is a Wardrop equilibrium feasible for the demand \(r\) and \(g\) is feasible for the demand \((1 + \gamma) r\), then \(\gamma\, C(f) \le C(g)\).

    For \(\gamma > 0\) this is Roughgarden and Tardos's \(C(f) \le C(g)/\gamma\); the Lean proof needs no sign condition on \(\gamma\) (for \(\gamma \le 0\) the statement is weaker than \(C(g) \ge 0\)). No continuity is needed. The proof uses \(\ell_e(f_e)\, g_e \le \ell_e(g_e)\, g_e + \ell_e(f_e)\, f_e\) on every edge, which replaces the modified latencies \(\max(\ell_e(f_e), \ell_e(x))\) of the original argument.

    theorem IsWardrop.mul_cost_le_of_feasible_one_add [Finite ι] {f g : P → ℝ} {r : ι → ℝ}
    {γ : ℝ} (hmono : ∀ e, MonotoneOn (N.latency e) (Set.Ici 0))
    (hnn : ∀ e x, 0 ≤ x → 0 ≤ N.latency e x)
    (hW : N.IsWardrop f) (hf : N.IsFeasible r f) (hg : N.IsFeasible ((1 + γ) • r) g) :
    γ * N.cost f ≤ N.cost g

    TheoremSelfish routing costs at most an optimal routing of twice the traffic#✓fully proved

    MathlibExt.GameTheory.SelfishRouting.RoutingInstance.IsWardrop.cost_le_of_feasible_two

    Suppose every latency \(\ell_e\) is nonnegative and nondecreasing on \([0, \infty)\). If \(f\) is a Wardrop equilibrium feasible for the demand \(r\) and \(g\) is any flow feasible for the demand \(2r\), then \(C(f) \le C(g)\).

    So the cost of selfish routing never exceeds the cost of routing twice as much traffic optimally, however steep the latencies.
