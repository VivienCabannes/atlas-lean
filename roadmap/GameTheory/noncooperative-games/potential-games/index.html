    Potential games

    A game has an exact potential when one function on strategy profiles tracks every player's unilateral change of cost. Its minimisers are pure Nash equilibria and improvement paths are finite. Rosenthal's theorem makes every congestion game a potential game, and in fair cost-sharing network design the potential sandwiches the network cost within a factor \(H(k)\), so the price of stability is at most \(H(k)\).

    DefinitionPure Nash equilibrium#✓fully proved

    MathlibExt.GameTheory.PotentialGame.IsPureNash

    Consider a strategic game with players \(i \in I\), strategy sets \(S_i\) and costs \(c_i : \prod_j S_j \to \mathbb R\), which each player wants to minimise. A strategy profile \(s\) is a pure Nash equilibrium if no player can lower its cost by changing only its own strategy: \(c_i(s) \le c_i(a, s_{-i})\) for every player \(i\) and every \(a \in S_i\), where \((a, s_{-i})\) is \(s\) with the \(i\)-th coordinate replaced by \(a\).

    def IsPureNash (cost : ι → (∀ i, S i) → ℝ) (s : ∀ i, S i) : Prop :=
  ∀ i (a : S i), cost i s ≤ cost i (Function.update s i a)

    DefinitionExact potential#✓fully proved

    MathlibExt.GameTheory.PotentialGame.IsExactPotential

    A function \(\Phi\) on strategy profiles is an exact potential for the costs \(c_i\) if every unilateral deviation changes the deviating player's cost by exactly the change in \(\Phi\): $\(c_i(a, s_{-i}) - c_i(s) = \Phi(a, s_{-i}) - \Phi(s)\)$ for every profile \(s\), player \(i\) and strategy \(a \in S_i\). A game with an exact potential is an (exact) potential game.

    def IsExactPotential (cost : ι → (∀ i, S i) → ℝ) (Φ : (∀ i, S i) → ℝ) : Prop :=
  ∀ s i (a : S i),
    cost i (Function.update s i a) - cost i s = Φ (Function.update s i a) - Φ s

    DefinitionImproving move#✓fully proved

    MathlibExt.GameTheory.PotentialGame.ImprovingMove

    A profile \(t\) is reached from \(s\) by an improving move if some player \(i\) changes only its own strategy, \(t = (a, s_{-i})\), and strictly lowers its cost, \(c_i(t) < c_i(s)\). Sequences of improving moves are improvement paths; best-response dynamics is a special case.

    def ImprovingMove (cost : ι → (∀ i, S i) → ℝ) (t s : ∀ i, S i) : Prop :=
  ∃ i, ∃ a : S i, t = Function.update s i a ∧ cost i t < cost i s

    StructureCongestion game#✓fully proved

    MathlibExt.GameTheory.PotentialGame.CongestionGame

    A congestion game has players \(i \in I\), a finite set \(R\) of resources, for every player a set \(S_i\) of strategies, each strategy \(a\) using a set \(R_i(a) \subseteq R\) of resources, and for every resource \(e\) a delay function \(d_e : \mathbb N \to \mathbb R\): when \(n\) players use \(e\), each of them pays \(d_e(n)\) for it.

    structure CongestionGame (ι R : Type*) (S : ι → Type*) where
  /-- The resources used by a strategy. -/
  uses : ∀ i, S i → Finset R
  /-- The delay of a resource as a function of the number of its users. -/
  delay : R → ℕ → ℝ

    TheoremRosenthal's potential splits over one player#✓fully proved

    MathlibExt.GameTheory.PotentialGame.CongestionGame.potential_eq

    StructureFair cost-sharing game#✓fully proved

    MathlibExt.GameTheory.PotentialGame.FairCostSharing

    In the fair cost-sharing network design game, player \(i\) chooses a strategy \(a \in S_i\) that uses a set \(R_i(a)\) of edges, every edge \(e\) has a cost \(c_e \ge 0\), and the cost of each edge is split equally among the players using it: player \(i\) pays \(\sum_{e \in R_i(s_i)} c_e / n_e(s)\). In the network design setting \(S_i\) is the set of \(s_i\)–\(t_i\) paths of a graph.

    structure FairCostSharing (ι R : Type*) (S : ι → Type*) where

    In the fair cost-sharing game with \(k\) players and finitely many strategies, nonempty for every player, there is a pure Nash equilibrium \(s\) whose network costs at most \(H(k)\) times the network of every profile \(t\): $\(\sum_{e : n_e(s) > 0} c_e \le H(k) \sum_{e : n_e(t) > 0} c_e .\)$ Taking \(t\) optimal, the price of stability is at most \(H(k) = O(\log k)\); the bound is tight.

    The equilibrium is a minimiser of Rosenthal's potential, and the proof chains \(\text{cost}(s) \le \Phi(s) \le \Phi(t) \le H(k)\, \text{cost}(t)\).

    theorem exists_isPureNash_networkCost_le [∀ i, Finite (S i)] [∀ i, Nonempty (S i)] :
    ∃ s, IsPureNash G.toCongestionGame.cost s ∧
      ∀ t, G.networkCost s ≤ harmonic (Fintype.card ι) * G.networkCost t

  ∀ i (a : S i), cost i s ≤ cost i (Function.update s i a)
