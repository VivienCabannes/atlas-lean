    DefinitionThe Kassel–Reutenauer coefficients \(a_{n,i}\)#✓fully proved

    MetaMathlibExt.kasselReutenauerCoeff

    For natural numbers \(n\) and \(i\), \(a_{n,i}\) is the number of positive divisors \(d\) of \(n\) with

    \[\frac{i + \sqrt{2n + i^2}}{2} < d \le i + \sqrt{2n + i^2},\]

    equivalently with \(d(d - 2i) \le 2n\) and \(n < 2d(d - i)\). For \(n = 0\) the set of divisors is taken to be empty, so \(a_{0,i} = 0\).

    public def kasselReutenauerCoeff (n i : ℕ) : ℕ :=
  ((Nat.divisors n).filter fun d => d * (d - 2 * i) ≤ 2 * n ∧ n < 2 * d * (d - i)).card

    DefinitionKassel–Reutenauer polynomial#✓fully proved

    MetaMathlibExt.kasselReutenauerPoly

    For a natural number \(n\), the Kassel–Reutenauer polynomial \(\bar P_n(X) \in \mathbb{Z}[X]\) is defined by

    \[ \bar P_n(X) = a_{n,0} + \sum_{i=1}^{n-1} a_{n,i} \, \bar T_i(X), \]

    where \(a_{n,i}\) is the number of divisors \(d\) of \(n\) with \(d(d - 2i) \le 2n\) and \(n < 2d(d - i)\) (equivalently, \((i + \sqrt{2n + i^2})/2 < d \le i + \sqrt{2n + i^2}\)), and \(\bar T_i\) is the monic Chebyshev polynomial: \(\bar T_0 = 2\), \(\bar T_1 = X\) and \(\bar T_{i+2} = X \bar T_{i+1} - \bar T_i\). For \(n = 0\) the sum is empty and the set of divisors of \(0\) is taken to be empty, so \(\bar P_0 = 0\).

    In the paper, \(\bar P_n\) is characterized for \(n \ge 1\) by \(\bar P_n(q + q^{-1}) = P_n(q)/q^{n-1}\), where \((q - 1)^2 P_n(q)\) is the number of ideals of codimension \(n\) of \(\mathbb{F}_q[x, y, x^{-1}, y^{-1}]\); the definition here uses the explicit expansion (2.4) of the paper instead.

    public noncomputable def kasselReutenauerPoly (n : ℕ) : ℤ[X] :=
  (kasselReutenauerCoeff n 0 : ℤ[X]) +
    ∑ i ∈ Finset.Icc 1 (n - 1), (kasselReutenauerCoeff n i : ℤ[X]) * Chebyshev.C ℤ i
    public def kasselReutenauerCoeff (n i : ℕ) : ℕ :=
  ((Nat.divisors n).filter fun d => d * (d - 2 * i) ≤ 2 * n ∧ n < 2 * d * (d - i)).card

    DefinitionPartial sums of the monic Chebyshev polynomials#✓fully proved

    MetaMathlibExt.chebyshevCPartialSum

    For \(n \ge 0\), \(F_n(X)\) is the polynomial with integer coefficients

    \[F_n(X) = 1 + \sum_{k=1}^{n} \bar T_k(X),\]

    where \(\bar T_k \in \mathbb{Z}[X]\) is the monic Chebyshev polynomial of the source, that is, the polynomial with \(\bar T_k(q + q^{-1}) = q^k + q^{-k}\); equivalently \(\bar T_0 = 2\), \(\bar T_1 = X\) and \(\bar T_{k+2} = X \bar T_{k+1} - \bar T_k\). Thus \(F_0 = 1\) and \(F_n = F_{n-1} + \bar T_n\) for \(n \ge 1\).

    public noncomputable def chebyshevCPartialSum (n : ℕ) : ℤ[X] :=
  1 + ∑ k ∈ Finset.Icc 1 n, Chebyshev.C ℤ k
