    DefinitionAutomorphism group of a rack#✓fully proved

    MetaMathlibExt.rackAut

    For a rack \(R\) with operation \(\triangleleft\), the automorphism group \(\operatorname{Aut} R\) is the subgroup of the group of permutations of \(R\) consisting of the permutations \(f\) with \(f(x \triangleleft y) = f(x) \triangleleft f(y)\) for all \(x, y \in R\).

    Here \(x \triangleleft y\) is the paper's \(s_x(y)\).

    def rackAut (R : Type*) [Rack R] : Subgroup (Perm R) where
  carrier := {f | ∀ x y, f (x ◃ y) = f x ◃ f y}
  one_mem' := fun _ _ => rfl
  mul_mem' := by
    intro f g hf hg x y
    simp only [Perm.mul_apply, hg x y, hf (g x) (g y)]
  inv_mem' := by
    intro f hf x y
    apply f.injective
    rw [hf (f⁻¹ x) (f⁻¹ y)]
    simp

    DefinitionIsomorphism of virtual racks#✓fully proved

    MetaMathlibExt.VirtualRackIso

    Write \(x \triangleleft y\) for the operation of a rack. A virtual rack \((R, f)\) is a rack \(R\) together with a rack automorphism \(f\) of \(R\), its virtual structure. Let \(R_1\) and \(R_2\) be racks and let \(f_1\) and \(f_2\) be permutations of \(R_1\) and \(R_2\). Then \((R_1, f_1)\) and \((R_2, f_2)\) are isomorphic when there is a bijection \(\psi \colon R_1 \to R_2\) such that \(\psi(x \triangleleft y) = \psi(x) \triangleleft \psi(y)\) for all \(x, y \in R_1\) and \(\psi(f_1(x)) = f_2(\psi(x))\) for all \(x \in R_1\).

    The definition does not require \(f_1\) and \(f_2\) to be rack automorphisms; for virtual racks it is the usual notion of isomorphism.

    def VirtualRackIso {R₁ R₂ : Type*} [Rack R₁] [Rack R₂] (f₁ : Perm R₁) (f₂ : Perm R₂) : Prop :=
  ∃ ψ : R₁ ≃ R₂, (∀ x y, ψ (x ◃ y) = ψ x ◃ ψ y) ∧ ∀ x, ψ (f₁ x) = f₂ (ψ x)

    DefinitionNumber of isomorphism classes of virtual racks on a rack#✓fully proved

    MetaMathlibExt.virtualRackClassCount

    For a rack \(R\), let \(\operatorname{Aut} R\) be its group of rack automorphisms; a virtual structure on \(R\) is an element \(f \in \operatorname{Aut} R\), and \((R, f)\) is the corresponding virtual rack. The number \(v(R)\) is the number of classes of virtual structures on \(R\), where \(f, g \in \operatorname{Aut} R\) are identified when the virtual racks \((R, f)\) and \((R, g)\) are isomorphic; that is, the number of isomorphism classes of virtual racks with underlying rack \(R\). It is \(0\) when there are infinitely many classes.

    Every virtual rack whose underlying rack is isomorphic to \(R\) is isomorphic to one of the form \((R, f)\).

    noncomputable def virtualRackClassCount (R : Type*) [Rack R] : ℕ :=
  Nat.card (Quot fun f g : rackAut R => VirtualRackIso (f : Perm R) (g : Perm R))

    DefinitionAffine permutations of the dihedral quandle#✓fully proved

    MetaMathlibExt.dihedralAffinePerm

    For a natural number \(n\), an element \(a \in \mathbb{Z}/n\mathbb{Z}\) and a unit \(u \in (\mathbb{Z}/n\mathbb{Z})^\times\), \(T_{a,u}\) is the affine map \(x \mapsto a + u x\) of \(\mathbb{Z}/n\mathbb{Z}\), viewed as a permutation of the dihedral quandle \(R_n\) (the set \(\mathbb{Z}/n\mathbb{Z}\) with \(x \triangleleft y = 2x - y\)).

    def dihedralAffinePerm (n : ℕ) (a : ZMod n) (u : (ZMod n)ˣ) : Perm (Quandle.Dihedral n) :=
  show Perm (ZMod n) from
  { toFun := fun x => a + (u : ZMod n) * x
    invFun := fun x => ((u⁻¹ : (ZMod n)ˣ) : ZMod n) * (x - a)
    left_inv := fun x => by
      simp only [add_sub_cancel_left, Units.inv_mul_cancel_left]
    right_inv := fun x => by
      simp only [Units.mul_inv_cancel_left, add_sub_cancel] }

    MetaMathlibExt.zmodUnitsMulAut

    For a natural number \(n\), the group homomorphism from the unit group \((\mathbb{Z}/n\mathbb{Z})^\times\) to the automorphism group of the additive group \(\mathbb{Z}/n\mathbb{Z}\) that sends a unit \(u\) to multiplication by \(u\), the automorphism \(x \mapsto u x\).

    def zmodUnitsMulAut (n : ℕ) : (ZMod n)ˣ →* MulAut (Multiplicative (ZMod n)) where
  toFun u :=
    { toFun := fun x => Multiplicative.ofAdd ((u : ZMod n) * x.toAdd)
      invFun := fun x => Multiplicative.ofAdd (((u⁻¹ : (ZMod n)ˣ) : ZMod n) * x.toAdd)
      left_inv := fun x => by simp
      right_inv := fun x => by simp
      map_mul' := fun x y => by simp [mul_add] }
  map_one' := by ext; simp
  map_mul' := fun u v => by ext; simp [mul_assoc]

    MetaMathlibExt.cyclicHolomorph

    For a natural number \(n\), let \(A = \mathbb{Z}/n\mathbb{Z}\). The holomorph of \(A\) is the semidirect product \(A \rtimes A^\times\) in which the unit group \(A^\times\) acts on \(A\) by multiplication. Its elements are the pairs \((a, u)\) with \(a \in A\) and \(u \in A^\times\), with product \((a, u)(b, v) = (a + u b, u v)\).
