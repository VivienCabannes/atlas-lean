    DefinitionDivided-power ideal#✓fully proved

    MetaMathlibExt.IsDividedPowerIdeal

    An ideal \(I\) of a commutative ring \(A\) is a divided-power ideal when for every \(a \in I\) and every integer \(k \ge 1\) there is \(c \in I\) with \(a^k = k! \, c\), that is, \(a^k \in k! \, I\). For a prime \(p\), in a torsion-free \(\mathbb{Z}_{(p)}\)-algebra this says \(a^k / k! \in I\).

    def IsDividedPowerIdeal {A : Type*} [CommRing A] (I : Ideal A) : Prop :=
  ∀ a ∈ I, ∀ k : ℕ, 1 ≤ k → ∃ c ∈ I, a ^ k = (k.factorial : A) * c

    DefinitionElementary symmetric functions of a polynomial#✓fully proved

    MetaMathlibExt.polyElemSymm

    Let \(P\) be a polynomial of degree \(d\) over a commutative ring, with \(d = 0\) for \(P = 0\). For a natural number \(n\), \(e_n(P)\) is \((-1)^n\) times the coefficient of \(X^{d - n}\) in \(P\) if \(n \le d\), and \(0\) if \(n > d\). In particular \(e_0(P) = 1\) when \(P\) is monic.

    noncomputable def polyElemSymm {A : Type*} [CommRing A] (P : A[X]) (n : ℕ) : A :=
  if n ≤ P.natDegree then (-1) ^ n * P.coeff (P.natDegree - n) else 0

    DefinitionPower sums of a polynomial#✓fully proved

    MetaMathlibExt.polyPowerSum

    For a polynomial \(P\) over a commutative ring \(A\), with elementary symmetric functions \(e_i = e_i(P)\), the power sums \(p_n = p_n(P) \in A\) are defined recursively: \(p_0\) is the degree of \(P\) as a natural number (\(0\) for \(P = 0\)), and for \(n \ge 1\) Newton's identity holds:

    \[p_n = \sum_{i=1}^{n-1} (-1)^{i-1} e_i\, p_{n-i} + (-1)^{n-1} n\, e_n.\]

    If \(P\) is monic and \(P = (X - \alpha_1) \cdots (X - \alpha_d)\), then \(p_n = \alpha_1^n + \cdots + \alpha_d^n\) for every \(n\).

    noncomputable def polyPowerSum {A : Type*} [CommRing A] (P : A[X]) : ℕ → A
  | 0 => P.natDegree
  | n + 1 => (-1) ^ n * ((n + 1 : ℕ) : A) * polyElemSymm P (n + 1) +
      ∑ i : Fin n, (-1) ^ (i : ℕ) * polyElemSymm P (i + 1) * polyPowerSum P (n - i)
  decreasing_by omega
