    TheoremReducible quadratics with coefficients in an arithmetic progression#●ready to prove

    MetaMathlibExt.arithProgPoly_two_reducible_iff

    Let \(d \ge 2\) be an integer and, for a positive integer \(a\), let \(A_2(x) = ax^2 + (a + d)x + (a + 2d)\) in \(\mathbb{Z}[x]\). There is a positive integer \(a\) coprime to \(d\) for which \(A_2\) is not irreducible in \(\mathbb{Z}[x]\) if and only if every prime divisor of \(d\) is congruent to \(1\) modulo \(3\). In that case the number of positive integers \(a\) coprime to \(d\) for which \(A_2\) is not irreducible is exactly \(2^{n-1}\), where \(n\) is the number of distinct prime divisors of \(d\).

    Both hypotheses matter: without coprimality, \(a = d = 7\) gives \(A_2(x) = 7(x^2 + 2x + 3)\), which is not irreducible in \(\mathbb{Z}[x]\); and for \(d = 1\) the prime condition holds vacuously while \(A_2\) is irreducible for every \(a \ge 1\), its discriminant \(-3a^2 - 6a + 1\) being negative.

    public theorem_wanted arithProgPoly_two_reducible_iff {d : ℕ} (hd : 2 ≤ d) :
    ((∃ a : ℕ, 0 < a ∧ Nat.Coprime a d ∧
        ¬ Irreducible (∑ i ∈ Finset.range 3, C ((a : ℤ) + i * d) * X ^ (2 - i))) ↔
      ∀ p ∈ d.primeFactors, p % 3 = 1) ∧
    ((∀ p ∈ d.primeFactors, p % 3 = 1) →
      {a : ℕ | 0 < a ∧ Nat.Coprime a d ∧
        ¬ Irreducible (∑ i ∈ Finset.range 3, C ((a : ℤ) + i * d) * X ^ (2 - i))}.ncard =
        2 ^ (d.primeFactors.card - 1))
