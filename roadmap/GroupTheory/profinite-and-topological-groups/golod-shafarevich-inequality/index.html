    MathlibExt.GroupTheory.GolodShafarevichWanted.GroupTheory.generatorRank

    For a topological group \(G\), the generator rank \(d(G)\) is the least natural number \(k\) such that some finite subset of \(G\) with \(k\) elements generates a dense subgroup of \(G\), that is, a subgroup whose closure is all of \(G\). If no finite subset of \(G\) generates a dense subgroup, then \(d(G)\) is defined to be \(0\). For a finite discrete group this is the ordinary minimal number of generators.

    noncomputable def generatorRank
    (G : Type) [Group G] [TopologicalSpace G] [IsTopologicalGroup G] : ℕ :=
  sInf {k : ℕ | ∃ S : Finset G, S.card = k ∧
    (Subgroup.closure (S : Set G)).topologicalClosure = ⊤}

    DefinitionRelation rank#✓fully proved

    MathlibExt.GroupTheory.GolodShafarevichWanted.GroupTheory.relationRank

    For a prime \(p\) and a topological group \(G\), the relation rank \(r(G)\) is the dimension over \(\mathbb{F}_p = \mathbb{Z}/p\mathbb{Z}\) of the continuous cohomology group \(H^2(G, \mathbb{F}_p)\), where \(G\) acts trivially on \(\mathbb{F}_p\). If this space is infinite-dimensional, then \(r(G)\) is defined to be \(0\).

    noncomputable def relationRank
    (p : ℕ) [Fact p.Prime] (G : Type)
    [Group G] [TopologicalSpace G] [IsTopologicalGroup G] : ℕ :=
  Module.finrank (ZMod p)
    (continuousCohomology 2 (trivialZModpRep p G))

    TheoremGolod–Shafarevich inequality#●ready to prove

    MathlibExt.GroupTheory.GolodShafarevichWanted.GroupTheory.golod_shafarevich_inequality

    Let \(p\) be a prime and let \(Q\) be a nontrivial finite \(p\)-group, viewed as a topological group with the discrete topology. Then the generator rank \(d(Q)\) and the relation rank \(r(Q)\), the dimension over \(\mathbb{F}_p\) of the continuous cohomology group \(H^2(Q, \mathbb{F}_p)\) with trivial coefficients, satisfy \(d(Q)^2 < 4\, r(Q)\).

    public theorem_wanted golod_shafarevich_inequality
    (p : ℕ) [Fact p.Prime] (Q : Type)
    [Group Q] [TopologicalSpace Q] [IsTopologicalGroup Q]
    [DiscreteTopology Q] [Finite Q] :
    IsPGroup p Q → Nontrivial Q →
      (generatorRank Q : ℝ) ^ 2 < 4 * (relationRank p Q : ℝ)
