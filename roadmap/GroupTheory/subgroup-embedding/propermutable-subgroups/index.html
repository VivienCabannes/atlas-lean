    Let \(H\) and \(X\) be subgroups of a group \(G\). Then \(H\) permutes with \(X\) when \(HX = XH\) as subsets of \(G\), where \(HX = \{hx : h \in H, x \in X\}\) and \(XH = \{xh : x \in X, h \in H\}\).

    def Permutes {G : Type} [Group G] (H X : Subgroup G) : Prop :=
  (H : Set G) * (X : Set G) = (X : Set G) * (H : Set G)

    DefinitionPropermutable subgroups#✓fully proved

    MathlibExt.GroupTheory.PropermutableSubgroupKourovka18Problem91Wanted.IsPropermutable

    A subgroup \(H\) of a group \(G\) is propermutable in \(G\) when there is a subgroup \(B\) of \(G\) with \(G = N_G(H)B\) (every element of \(G\) is a product \(nb\) with \(n\) in the normalizer \(N_G(H)\) of \(H\) and \(b \in B\)) such that \(H\) permutes with every subgroup \(X\) of \(B\), that is, \(HX = XH\).

    def IsPropermutable {G : Type} [Group G] (H : Subgroup G) : Prop :=
  ∃ B : Subgroup G, (Subgroup.normalizer (H : Set G) : Set G) * (B : Set G) = Set.univ ∧
    ∀ X : Subgroup G, X ≤ B → Permutes H X
    def Permutes {G : Type} [Group G] (H X : Subgroup G) : Prop :=
  (H : Set G) * (X : Set G) = (X : Set G) * (H : Set G)

    MathlibExt.GroupTheory.PropermutableSubgroupKourovka18Problem91Wanted.IsTwoNilpotent

    A group \(G\) is \(2\)-nilpotent when it has a normal subgroup \(N\) of finite odd order whose index in \(G\) is \(2^k\) for some natural number \(k\).

    def IsTwoNilpotent (G : Type) [Group G] : Prop :=
  ∃ N : Subgroup G, N.Normal ∧ Odd (Nat.card N) ∧ ∃ k : ℕ, N.index = 2 ^ k

    MathlibExt.GroupTheory.PropermutableSubgroupKourovka18Problem91Wanted.propermutableSylowSubgroupsTwoNilpotent

    The statement of Kourovka Problem 18.91(b) (A. N. Skiba), with the range \(1 \le k < n\): let \(G\) be a finite group and \(P\) a non-abelian Sylow \(2\)-subgroup of \(G\), with \(|P| = 2^n\), and let \(k\) be a natural number with \(1 \le k < n\). If every subgroup of \(P\) of order \(2^k\) is propermutable in \(G\), and, when \(k = 1\), every cyclic subgroup of \(P\) of order \(4\) is propermutable in \(G\), then \(G\) is \(2\)-nilpotent.

    The printed problem has \(1 < k < n\), which contradicts its clause for \(k = 1\); the range \(1 \le k < n\) is the one of Al-Sharo's Corollary 1.3.

    def propermutableSylowSubgroupsTwoNilpotent : Prop :=
  ∀ (G : Type) [Group G] [Finite G] (P : Sylow 2 G),
    (∃ x ∈ (P : Subgroup G), ∃ y ∈ (P : Subgroup G), x * y ≠ y * x) →
    ∀ k : ℕ, 1 ≤ k → 2 ^ k < Nat.card (P : Subgroup G) →
      (∀ H : Subgroup G, H ≤ P → Nat.card H = 2 ^ k → IsPropermutable H) →
      (k = 1 → ∀ H : Subgroup G, H ≤ P → IsCyclic H → Nat.card H = 4 → IsPropermutable H) →
      IsTwoNilpotent G

    TheoremPropermutable subgroups of a non-abelian Sylow 2-subgroup force 2-nilpotency#●ready to prove

    MathlibExt.GroupTheory.PropermutableSubgroupKourovka18Problem91Wanted.propermutableSylowSubgroupsTwoNilpotent_holds

    Let \(G\) be a finite group and \(P\) a non-abelian Sylow \(2\)-subgroup of \(G\), with \(|P| = 2^n\), and let \(k\) be a natural number with \(1 \le k < n\). If every subgroup of \(P\) of order \(2^k\) is propermutable in \(G\), and, when \(k = 1\), every cyclic subgroup of \(P\) of order \(4\) is propermutable in \(G\), then \(G\) is \(2\)-nilpotent. This is the positive answer to Kourovka Problem 18.91(b).

    The Kourovka Archive answers 18.91(b) "Yes, it is" (Kh. A. Al-Sharo, 2016). Al-Sharo's Corollary 1.3 (quoted below), applied to the normal subgroup \(X = G\) with \(p = 2\) (where \((p - 1, |G|) = 1\) holds), gives 2-nilpotency already when the subgroups in question are only \(S\)-propermutable, a weaker condition than propermutability: a subgroup \(H\) of \(G\) is \(S\)-propermutable in \(G\) when there is a subgroup \(B\) of \(G\) with \(G = N_G(H)B\) such that \(H\) permutes with every Sylow subgroup of \(B\).
