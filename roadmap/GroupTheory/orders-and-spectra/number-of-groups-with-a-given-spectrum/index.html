    MathlibExt.GroupTheory.ElementOrderSetRealizationsKourovka12Problem84Wanted.twoRealizationsImplyInfinitelyMany

    The proposition that for every set \(\Omega\) of natural numbers, if two non-isomorphic finite groups both have set of element orders \(\Omega\), then for every natural number \(k\) there are \(k\) pairwise non-isomorphic finite groups whose set of element orders is \(\Omega\); that is, infinitely many.

    def twoRealizationsImplyInfinitelyMany : Prop :=
  ∀ Ω : Set ℕ,
    (∃ (G H : Type) (_ : Group G) (_ : Finite G) (_ : Group H) (_ : Finite H),
      elementOrders G = Ω ∧ elementOrders H = Ω ∧ IsEmpty (G ≃* H)) →
    ∀ k : ℕ, ∃ (G : Fin k → Type) (_ : ∀ i, Group (G i)) (_ : ∀ i, Finite (G i)),
      (∀ i, elementOrders (G i) = Ω) ∧ ∀ i j, i ≠ j → IsEmpty (G i ≃* G j)
    def elementOrders (G : Type*) [Group G] : Set ℕ :=
  Set.range (orderOf : G → ℕ)

    MathlibExt.GroupTheory.ElementOrderSetRealizationsKourovka12Problem84Wanted.twoRealizationsImplyInfinitelyMany_refuted

    There are a set \(\Omega\) of natural numbers and a natural number \(k\) such that two non-isomorphic finite groups have set of element orders \(\Omega\), but there are no \(k\) pairwise non-isomorphic finite groups whose set of element orders is \(\Omega\).

    For example, by Theorem 2.1(iii) of the survey of Grechkoseeva, Mazurov, Shi, Vasil'ev and Yang, the finite groups with the set of element orders of \(S_6(2)\) are exactly \(S_6(2)\) and \(O_8^+(2)\), which have different orders. The Kourovka Archive answers 12.84 "No, it is not" (V. D. Mazurov, 1994).

    For a set \(\Gamma\) of natural numbers and a natural number \(k\), this property holds when, for any finite groups \(G_0, \dots, G_k\) (not necessarily distinct) whose spectra \(\pi_e(G_i)\) (the sets of orders of elements of \(G_i\)) all equal \(\Gamma\), there are indices \(i \ne j\) with \(G_i \cong G_j\).

    The proposition, asked about by W. J.     MathlibExt.GroupTheory.ElementOrderSpectrumCountKourovka13Problem63Wanted.spectrumGroupCountBoundedOrInfinite_refuted

    For a set \(\Gamma\) of natural numbers, let \(h(\Gamma)\) be the number of isomorphism classes of finite groups \(G\) whose spectrum \(\pi_e(G)\) (set of element orders) is \(\Gamma\); \(h(\Gamma) \le k\) means that among any \(k + 1\) finite groups with spectrum \(\Gamma\) two are isomorphic, and \(h(\Gamma) = \infty\) means that for every \(n\) there are \(n\) pairwise non-isomorphic finite groups with spectrum \(\Gamma\). Kourovka Problem 13.63 has a negative answer: there is no natural number \(k\) such that for every set \(\Gamma\) of natural numbers, either \(h(\Gamma) \le k\) or \(h(\Gamma) = \infty\).

    Zavarnitsine proves \(h(\pi_e(L_3(7^{3^r}))) = r + 1\) for every \(r \ge 0\), where \(L_3(q)\) is the projective special linear group \(\mathrm{PSL}_3(q)\), so \(h\) takes every positive finite value and no \(k\) works.

    public theorem_wanted spectrumGroupCountBoundedOrInfinite_refuted :
    ¬ spectrumGroupCountBoundedOrInfinite

  ∃ k : ℕ, ∀ Γ : Set ℕ, AtMostIsoClasses Γ k ∨ InfinitelyManyIsoClasses Γ
