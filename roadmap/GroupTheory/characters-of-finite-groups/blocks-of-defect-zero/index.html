    Definition\(p\)-soluble groups#✓fully proved

    MathlibExt.GroupTheory.DefectZeroBlockCentralizerKourovka12Problem26Wanted.IsPSoluble

    Let \(p\) be a natural number. A group \(G\) is \(p\)-soluble when it has a subnormal series \(1 = H_0 \le H_1 \le \dots \le H_n = G\), each \(H_i\) normal in \(H_{i+1}\), whose factors \(H_{i+1}/H_i\) are \(p\)-groups or have order prime to \(p\). Here an infinite factor is taken to have order \(0\).

    def IsPSoluble (p : ℕ) (G : Type*) [Group G] : Prop :=
  ∃ (n : ℕ) (H : Fin (n + 1) → Subgroup G), H 0 = ⊥ ∧ H (Fin.last n) = ⊤ ∧
    ∀ i : Fin n, H i.castSucc ≤ H i.succ ∧
      ∃ _ : ((H i.castSucc).subgroupOf (H i.succ)).Normal,
        IsPGroup p (H i.succ ⧸ (H i.castSucc).subgroupOf (H i.succ)) ∨
          (Nat.card (H i.succ ⧸ (H i.castSucc).subgroupOf (H i.succ))).Coprime p

    DefinitionGroups with a \(p\)-block of defect zero#✓fully proved

    MathlibExt.GroupTheory.DefectZeroBlockCentralizerKourovka12Problem26Wanted.HasDefectZeroBlock

    Let \(p\) be a natural number. A group \(G\) has a \(p\)-block of defect zero when some irreducible finite-dimensional complex representation of \(G\) has degree divisible by \(p^{v_p(|G|)}\), where \(v_p(|G|)\) is the exponent of \(p\) in the prime factorization of the order \(|G|\) of \(G\) (this exponent is \(0\) when \(p\) is not prime or \(G\) is infinite). For a prime \(p\) and a finite group \(G\), the number \(p^{v_p(|G|)}\) is \(|G|_p\), the largest power of \(p\) dividing \(|G|\).

    By Brauer's theory the \(p\)-blocks of defect zero are exactly the singletons \(\{\chi\}\) with \(\chi\) irreducible and \(|G|_p \mid \chi(1)\).

    def HasDefectZeroBlock (p : ℕ) (G : Type) [Group G] : Prop :=
  ∃ (V : Type) (_ : AddCommGroup V) (_ : Module ℂ V) (_ : FiniteDimensional ℂ V)
    (ρ : Representation ℂ G V), ρ.IsIrreducible ∧
      p ^ (Nat.card G).factorization p ∣ Module.finrank ℂ V

    DefinitionKourovka Problem 12.26#✓fully proved

    MathlibExt.GroupTheory.DefectZeroBlockCentralizerKourovka12Problem26Wanted.defectZeroBlockIffPRegularCentralizer

    This is the proposition (Shi Shengming) that for every prime \(p\) and every finite \(p\)-soluble group \(G\), the group \(G\) has a \(p\)-block of defect zero if and only if some normal subgroup \(N\) of \(G\) of order prime to \(p\) contains an element \(x\) whose centralizer \(C_G(x)\) in \(G\) has order prime to \(p\).

    Equivalently, some \(x \in O_{p'}(G)\) has a centralizer of order prime to \(p\), since \(O_{p'}(G)\) is the largest normal subgroup of \(G\) of order prime to \(p\).

    def defectZeroBlockIffPRegularCentralizer : Prop :=
  ∀ p : ℕ, p.Prime → ∀ (G : Type) [Group G] [Finite G], IsPSoluble p G →
    (HasDefectZeroBlock p G ↔
      ∃ N : Subgroup G, N.Normal ∧ (Nat.card N).Coprime p ∧
        ∃ x ∈ N, (Nat.card (Subgroup.centralizer {x})).Coprime p)

    MathlibExt.GroupTheory.DefectZeroBlockCentralizerKourovka12Problem26Wanted.defectZeroBlockIffPRegularCentralizer_refuted

    The proposition of Kourovka Problem 12.26 is false: it is not the case that for every prime \(p\) and every finite \(p\)-soluble group \(G\), the group \(G\) has a \(p\)-block of defect zero if and only if some normal subgroup \(N\) of \(G\) of order prime to \(p\) contains an element \(x\) whose centralizer \(C_G(x)\) in \(G\) has order prime to \(p\).

    V. I. Zenkov's counterexample: the group \(G = 3^2.\mathrm{GL}_2(3)\) of order \(432\) is soluble and has a \(2\)-block of defect zero (an irreducible character of degree \(16\)), but the centralizer of every element of \(O_{2'}(G) = 3^2\), the largest normal subgroup of \(G\) of odd order, has even order.

    DefinitionCharacters of \(p\)-defect zero#✓fully proved

    MathlibExt.GroupTheory.DefectZeroBlocksCommutatorCountKourovka12Problem80Wanted.defectZeroCharacters

    For a natural number \(p\) and a group \(G\), the set of characters \(\chi \colon G \to \mathbb{C}\) of irreducible finite-dimensional complex representations of \(G\) whose degree is divisible by \(p^a\), where \(a\) is the exponent of \(p\) in the prime factorization of the order \(|G|\) (and \(a = 0\) when \(G\) is infinite or \(p\) is not prime).

    For a prime \(p\) and a finite group \(G\), each \(p\)-block of defect zero contains exactly one irreducible character, and every such character forms a block of defect zero (Brauer), so these characters count the \(p\)-blocks of defect zero.

    def defectZeroCharacters (p : ℕ) (G : Type) [Group G] : Set (G → ℂ) :=
  {χ | ∃ (V : Type) (_ : AddCommGroup V) (_ : Module ℂ V) (_ : FiniteDimensional ℂ V)
    (ρ : Representation ℂ G V), ρ.IsIrreducible ∧ ρ.character = χ ∧
      p ^ (Nat.card G).factorization p ∣ Module.finrank ℂ V}

    DefinitionNumber of solutions of a commutator equation#✓fully proved

    MathlibExt.GroupTheory.DefectZeroBlocksCommutatorCountKourovka12Problem80Wanted.commutatorSolutionCount

    For an element \(g\) of a group \(G\), the number of pairs \((x, y) \in G \times G\) with \([x, y] = x y x^{-1} y^{-1} = g\), taken to be \(0\) when there are infinitely many such pairs.

    noncomputable def commutatorSolutionCount {G : Type*} [Group G] (g : G) : ℕ :=
  Nat.card {xy : G × G // ⁅xy.1, xy.2⁆ = g}

    DefinitionConjugacy classes with commutator count not divisible by \(p\)#✓fully proved

    MathlibExt.GroupTheory.DefectZeroBlocksCommutatorCountKourovka12Problem80Wanted.nondivisibleCommutatorClasses

    For a natural number \(p\) and a group \(G\), the set of conjugacy classes of \(G\) containing an element \(g\) such that the number of pairs \((x, y) \in G \times G\) with \([x, y] = x y x^{-1} y^{-1} = g\) (taken to be \(0\) when there are infinitely many) is not divisible by \(p\).

    def nondivisibleCommutatorClasses (p : ℕ) (G : Type*) [Group G] : Set (ConjClasses G) :=
  {c | ∃ g : G, ConjClasses.mk g = c ∧ ¬ p ∣ commutatorSolutionCount g}
    noncomputable def commutatorSolutionCount {G : Type*} [Group G] (g : G) : ℕ :=
  Nat.card {xy : G × G // ⁅xy.1, xy.2⁆ = g}

    DefinitionKourovka Problem 12.80(a): blocks of defect zero and commutator equations#✓fully proved

    MathlibExt.GroupTheory.DefectZeroBlocksCommutatorCountKourovka12Problem80Wanted.defectZeroBlocksEqNondivisibleClasses

    For every prime \(p\) and every finite group \(G\) whose order is divisible by \(p\), the number of irreducible complex characters of \(G\) of \(p\)-defect zero equals the number of conjugacy classes of \(G\) containing an element \(g\) for which the number of pairs \((x, y) \in G \times G\) with \([x, y] = x y x^{-1} y^{-1} = g\) is not divisible by \(p\).

    Each \(p\)-block of defect zero contains exactly one irreducible character, and every irreducible character of \(p\)-defect zero forms such a block (Brauer), so this is K. W. Roggenkamp's question whether the number of \(p\)-blocks of defect zero equals that number of classes.
