    TheoremConvolution theorem for one-dimensional characters#✓fully proved

    MathlibExt.GroupTheory.FiniteGroupConvolutionWanted.charPair_conv

    Let \(G\) be a finite group, let \(\varphi : G \to \mathbb{C}\) satisfy \(\varphi(1) = 1\) and \(\varphi(xy) = \varphi(x)\varphi(y)\) for all \(x, y \in G\) (a one-dimensional character), and let \(f, g : G \to \mathbb{C}\). Writing \(f \ast g\) for the convolution \((f \ast g)(x) = \sum_{y \in G} f(y)\, g(y^{-1} x)\), we have

    \[ \sum_{x \in G} \varphi(x)\,(f \ast g)(x) = \Big(\sum_{x \in G} \varphi(x) f(x)\Big)\Big(\sum_{x \in G} \varphi(x) g(x)\Big). \]

    Proof: Swap the finite sums, reindex by \(x = yz\), and use multiplicativity of \(\varphi\) to factor the character pairing, following Terras, Ch. 2–3.

    public theorem charPair_conv {G : Type*} [Group G] [Fintype G]
    (φ : G →* ℂ) (f g : G → ℂ) :
    (∑ x : G, φ x * conv f g x) =
      (∑ x : G, φ x * f x) * (∑ x : G, φ x * g x)
    def conv {G : Type*} [Group G] [Fintype G] (f g : G → ℂ) : G → ℂ :=
  fun x => ∑ y : G, f y * g (y⁻¹ * x)
