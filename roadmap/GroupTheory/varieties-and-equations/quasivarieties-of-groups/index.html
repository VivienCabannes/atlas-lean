    MathlibExt.GroupTheory.QuasivarietyMaximalSubquasivarietiesKourovka14Problem25Wanted.QuasiIdentity

    A quasi-identity in \(n\) unknowns \(x_0, \dots, x_{n-1}\) is a formula \(\forall x\,(w_1 = 1 \wedge \dots \wedge w_k = 1 \to w = 1)\), given by the number \(n\), a finite list of premises \(w_1, \dots, w_k\) and a conclusion \(w\), all of them elements of the free group on \(x_0, \dots, x_{n-1}\).

    DefinitionQuasi-identities holding in a group#✓fully proved

    MathlibExt.GroupTheory.QuasivarietyMaximalSubquasivarietiesKourovka14Problem25Wanted.QuasiIdentity.HoldsIn

    A quasi-identity \(\forall x\,(w_1 = 1 \wedge \dots \wedge w_k = 1 \to w = 1)\) in the unknowns \(x_0, \dots, x_{n-1}\) holds in a group \(G\) when every assignment of elements of \(G\) to the unknowns under which each premise \(w_1, \dots, w_k\) evaluates to \(1\) in \(G\) also makes the conclusion \(w\) evaluate to \(1\).

    def QuasiIdentity.HoldsIn (q : QuasiIdentity) (G : Type*) [Group G] : Prop :=
  ∀ x : Fin q.n → G, (∀ w ∈ q.premises, FreeGroup.lift x w = 1) →
    FreeGroup.lift x q.conclusion = 1

    MathlibExt.GroupTheory.QuasivarietyMaximalSubquasivarietiesKourovka14Problem25Wanted.Models

    For a set \(Q\) of quasi-identities, a group \(H\) belongs to the quasivariety defined by \(Q\) when every quasi-identity in \(Q\) holds in \(H\). Every quasivariety of groups has this form.

    Only groups in the lowest universe are considered; a quasivariety is determined by its countable members.

    def Models (Q : Set QuasiIdentity) (H : Type) [Group H] : Prop :=
  ∀ q ∈ Q, q.HoldsIn H

    DefinitionInclusion of quasivarieties#✓fully proved

    MathlibExt.GroupTheory.QuasivarietyMaximalSubquasivarietiesKourovka14Problem25Wanted.QVLe

    For sets \(Q_1\) and \(Q_2\) of quasi-identities, the quasivariety defined by \(Q_1\) is contained in the quasivariety defined by \(Q_2\): every group in which all quasi-identities of \(Q_1\) hold also satisfies all quasi-identities of \(Q_2\).

    Only groups in the lowest universe are considered; a quasivariety is determined by its countable members.

    DefinitionMaximal proper subquasivarieties#✓fully proved

    MathlibExt.GroupTheory.QuasivarietyMaximalSubquasivarietiesKourovka14Problem25Wanted.IsMaximalProperSubquasivariety

    Let \(G\) be a group and let \(qG\) be the quasivariety generated by \(G\), that is, the quasivariety defined by the set of all quasi-identities that hold in \(G\). A set \(Q\) of quasi-identities defines a maximal proper subquasivariety of \(qG\) when the quasivariety defined by \(Q\) is contained in \(qG\) but does not contain \(qG\), and every quasivariety \(V\) defined by a set of quasi-identities with \(V\) containing the quasivariety defined by \(Q\) and contained in \(qG\) either is contained in the quasivariety defined by \(Q\) or contains \(qG\).

    def IsMaximalProperSubquasivariety (G : Type) [Group G] (Q : Set QuasiIdentity) : Prop :=
  QVLe Q (quasiTheory G) ∧ ¬ QVLe (quasiTheory G) Q ∧
    ∀ Q' : Set QuasiIdentity, QVLe Q Q' → QVLe Q' (quasiTheory G) →
      QVLe Q' Q ∨ QVLe (quasiTheory G) Q'

    MathlibExt.GroupTheory.QuasivarietyMaximalSubquasivarietiesKourovka14Problem25Wanted.finitelyGeneratedGroupInfinitelyManyMaximalSubquasivarieties
