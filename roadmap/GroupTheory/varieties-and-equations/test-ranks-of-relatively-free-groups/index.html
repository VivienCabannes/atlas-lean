    MathlibExt.GroupTheory.TestRankNonabelianVarietyKourovka16Problem87Wanted.SatisfiesLaws

    Let \(F_\mathbb{N}\) be the free group on countably many generators and \(W \subseteq F_\mathbb{N}\) a set of words, the laws. A group \(G\) satisfies the laws \(W\) when \(\varphi(w) = 1\) for every \(w \in W\) and every homomorphism \(\varphi \colon F_\mathbb{N} \to G\), that is, every law takes the value \(1\) under every substitution of elements of \(G\) for the variables. The variety defined by \(W\) is the class of these groups.

    def SatisfiesLaws (W : Set (FreeGroup ℕ)) (G : Type*) [Group G] : Prop :=
  ∀ w ∈ W, ∀ φ : FreeGroup ℕ →* G, φ w = 1

    AbbreviationVerbal subgroup of a free group of finite rank#✓fully proved

    MathlibExt.GroupTheory.TestRankNonabelianVarietyKourovka16Problem87Wanted.verbalSubgroup

    Let \(W\) be a set of laws in the free group \(F_\mathbb{N}\) on countably many generators, and let \(F_r\) be the free group on \(r\) generators. The verbal subgroup \(V_W(F_r)\) of \(F_r\) for \(W\) is the normal closure in \(F_r\) of all elements \(\varphi(w)\) with \(w \in W\) and \(\varphi \colon F_\mathbb{N} \to F_r\) a homomorphism.

    abbrev verbalSubgroup (W : Set (FreeGroup ℕ)) (r : ℕ) : Subgroup (FreeGroup (Fin r)) :=
  Subgroup.normalClosure {x | ∃ w ∈ W, ∃ φ : FreeGroup ℕ →* FreeGroup (Fin r), φ w = x}

    AbbreviationRelatively free group as a quotient of a free group#✓fully proved

    MathlibExt.GroupTheory.TestRankNonabelianVarietyKourovka16Problem87Wanted.RelativelyFreeGroup

    Let \(W\) be a set of laws in the free group \(F_\mathbb{N}\) on countably many generators, and let \(r \in \mathbb{N}\). The free \(r\)-generator group \(G_r\) of the variety defined by \(W\) is the quotient \(F_r / V_W(F_r)\) of the free group \(F_r\) on \(r\) generators by its verbal subgroup \(V_W(F_r)\) for \(W\).

    abbrev RelativelyFreeGroup (W : Set (FreeGroup ℕ)) (r : ℕ) : Type :=
  FreeGroup (Fin r) ⧸ verbalSubgroup W r

    DefinitionTest set of a group#✓fully proved

    MathlibExt.GroupTheory.TestRankNonabelianVarietyKourovka16Problem87Wanted.IsTestSet

    A subset \(S\) of a group \(G\) is a test set when every endomorphism of \(G\) that fixes every element of \(S\) is bijective, that is, an automorphism of \(G\).

    def IsTestSet {G : Type*} [Group G] (S : Set G) : Prop :=
  ∀ f : G →* G, (∀ s ∈ S, f s = s) → Function.Bijective f

    DefinitionTest rank of a group#✓fully proved

    MathlibExt.GroupTheory.TestRankNonabelianVarietyKourovka16Problem87Wanted.HasTestRank

    A group \(G\) has test rank \(r \in \mathbb{N}\) when \(G\) has a test set of cardinality \(r\) and every test set of \(G\) has cardinality at least \(r\) (an infinite set counting as having cardinality \(\infty\)), that is, when the minimum of the cardinalities of the test sets of \(G\) is \(r\).

    def HasTestRank (G : Type*) [Group G] (r : ℕ) : Prop :=
  (∃ S : Set G, IsTestSet S ∧ S.encard = r) ∧ ∀ S : Set G, IsTestSet S → (r : ℕ∞) ≤ S.encard
    def IsTestSet {G : Type*} [Group G] (S : Set G) : Prop :=
  ∀ f : G →* G, (∀ s ∈ S, f s = s) → Function.Bijective f

    There is a set \(W\) of laws in the free group \(F_\mathbb{N}\) on countably many generators such that for every \(r \ge 1\) the free \(r\)-generator group \(G_r\) of the variety defined by \(W\) has test rank \(r\), but the variety is not abelian: some group satisfying the laws \(W\) is not abelian.
