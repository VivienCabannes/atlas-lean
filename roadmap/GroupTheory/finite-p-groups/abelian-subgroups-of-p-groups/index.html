    DefinitionPyber's question on generators of abelian subgroups (Kourovka 20.75)#✓fully proved

    MathlibExt.GroupTheory.AbelianNormalGeneratorsPGroupKourovka20Problem75Wanted.abelianSubgroupGeneratorsLeTwiceNormal

    The proposition that for every prime \(p\), every natural number \(k\) and every finite \(p\)-group \(G\), if every abelian normal subgroup of \(G\) can be generated by at most \(k\) elements, then every abelian subgroup of \(G\) can be generated by at most \(2k\) elements.

    def abelianSubgroupGeneratorsLeTwiceNormal : Prop :=
  ∀ (p k : ℕ) (G : Type) [Group G] [Finite G], p.Prime → IsPGroup p G →
    (∀ A : Subgroup G, A.Normal → (∀ x ∈ A, ∀ y ∈ A, x * y = y * x) →
      ∃ s : Finset G, s.card ≤ k ∧ Subgroup.closure (s : Set G) = A) →
    ∀ B : Subgroup G, (∀ x ∈ B, ∀ y ∈ B, x * y = y * x) →
      ∃ s : Finset G, s.card ≤ 2 * k ∧ Subgroup.closure (s : Set G) = B

    The statement of Kourovka Problem 20.75 is false: there are a prime \(p\), a natural number \(k\), a finite \(p\)-group \(G\) all of whose abelian normal subgroups can be generated by at most \(k\) elements, and an abelian subgroup of \(G\) that cannot be generated by at most \(2k\) elements.

    Muliarchyk's counterexample (Theorem 1.1) is a finite \(2\)-group of order \(2^{110N+1}\), with \(N = 2124210350\), whose abelian normal subgroups can be generated by \(32N + 1\) elements while an elementary abelian subgroup needs \(65N > 2(32N + 1)\) generators; the 21st issue of the Kourovka Notebook marks 20.75 solved ("No, it is not").
