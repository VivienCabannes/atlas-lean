    MathlibExt.GroupTheory.ProjectiveGroupRingModuleFreeKourovka11Problem5Wanted.IsPolycyclic

    A group \(G\) is polycyclic if for some \(n \ge 0\) there are subgroups \(1 = H_0 \le H_1 \le \cdots \le H_n = G\) such that for each \(i < n\), \(H_i\) is normal in \(H_{i+1}\) and the quotient \(H_{i+1} / H_i\) is cyclic.

    def IsPolycyclic (G : Type*) [Group G] : Prop :=
  ∃ (n : ℕ) (H : Fin (n + 1) → Subgroup G), H 0 = ⊥ ∧ H (Fin.last n) = ⊤ ∧
    ∀ i : Fin n, H i.castSucc ≤ H i.succ ∧
      ∃ _ : ((H i.castSucc).subgroupOf (H i.succ)).Normal,
        IsCyclic (H i.succ ⧸ (H i.castSucc).subgroupOf (H i.succ))

    DefinitionArtamonov's freeness question (Kourovka 11.5)#✓fully proved

    MathlibExt.GroupTheory.ProjectiveGroupRingModuleFreeKourovka11Problem5Wanted.projectiveWithTwoIndependentFree

    This is the proposition that, for every commutative ring \(k\), every torsion-free almost polycyclic group \(G\) (no element \(g \ne 1\) of \(G\) has finite order) and every finitely generated projective module \(P\) over the group ring \(kG\), if \(P\) contains two elements that are linearly independent over \(kG\), then \(P\) is a free \(kG\)-module.

    def projectiveWithTwoIndependentFree : Prop :=
  ∀ (k : Type) [CommRing k] (G : Type) [Group G], (∀ g : G, g ≠ 1 → ¬ IsOfFinOrder g) →
    IsAlmostPolycyclic G → ∀ (P : Type) [AddCommGroup P] [Module (MonoidAlgebra k G) P],
    Module.Finite (MonoidAlgebra k G) P → Module.Projective (MonoidAlgebra k G) P →
    (∃ x y : P, LinearIndependent (MonoidAlgebra k G) ![x, y]) →
    Module.Free (MonoidAlgebra k G) P
    def IsAlmostPolycyclic (G : Type*) [Group G] : Prop :=
  ∃ H : Subgroup G, H.FiniteIndex ∧ IsPolycyclic H

    TheoremArtamonov's freeness question has a negative answer#●ready to prove

    MathlibExt.GroupTheory.ProjectiveGroupRingModuleFreeKourovka11Problem5Wanted.projectiveWithTwoIndependentFree_refuted

    It is not the case that for every commutative ring \(k\), every torsion-free almost polycyclic group \(G\) (no element \(g \ne 1\) of \(G\) has finite order) and every finitely generated projective module \(P\) over the group ring \(kG\) containing two elements that are linearly independent over \(kG\), the module \(P\) is free over \(kG\).

    Jayadevan's counterexample takes \(k = \mathbb{F}_2 \times \mathbb{F}_2\) and the trivial group \(G\), so that \(kG = k\); then \(P = k^2 \oplus (\mathbb{F}_2 \times 0)\) is a finitely generated projective \(k\)-module containing an independent pair, but \(|P| = 32\) is not a power of \(4 = |k|\), so \(P\) is not free. The Kourovka Notebook (21st issue) marks 11.5 solved, "No, not always" (AI solution confirmed by D. Segal); the example gives nothing for field coefficients.
