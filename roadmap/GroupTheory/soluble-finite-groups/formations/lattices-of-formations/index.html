    DefinitionFormations of finite groups (Kourovka 18.92)#✓fully proved

    MathlibExt.GroupTheory.CompleteLatticeOfFormationsKourovka18Problem92Wanted.IsFormation

    A class \(\mathfrak{X}\) of groups is a formation if every group in \(\mathfrak{X}\) is finite, \(\mathfrak{X}\) contains the trivial group, for every finite group \(G\) in \(\mathfrak{X}\) and every normal subgroup \(N\) of \(G\) the quotient \(G/N\) lies in \(\mathfrak{X}\), and for every finite group \(G\) with normal subgroups \(N_1\) and \(N_2\) such that \(G/N_1\) and \(G/N_2\) lie in \(\mathfrak{X}\), the quotient \(G/(N_1 \cap N_2)\) lies in \(\mathfrak{X}\).

    def IsFormation (X : GroupClass) : Prop :=
  (∀ (H : Type) [Group H], X.mem H → Finite H) ∧ X.mem Unit ∧
  (∀ (G : Type) [Group G] [Finite G] (N : Subgroup G) [N.Normal], X.mem G → X.mem (G ⧸ N)) ∧
  ∀ (G : Type) [Group G] [Finite G] (N₁ N₂ : Subgroup G) [N₁.Normal] [N₂.Normal],
    X.mem (G ⧸ N₁) → X.mem (G ⧸ N₂) → X.mem (G ⧸ (N₁ ⊓ N₂))

    DefinitionComplete lattices of formations#✓fully proved

    MathlibExt.GroupTheory.CompleteLatticeOfFormationsKourovka18Problem92Wanted.IsCompleteLatticeOfFormations

    A set \(\Theta\) of classes of groups is a complete lattice of formations if it is nonempty, every member of \(\Theta\) is a formation, for every nonempty subset \(S \subseteq \Theta\) the intersection of the classes in \(S\) (the class of groups belonging to every member of \(S\)) belongs to \(\Theta\), and \(\Theta\) has a member that contains every member of \(\Theta\).

    def IsCompleteLatticeOfFormations (Θ : Set GroupClass) : Prop :=
  Θ.Nonempty ∧ (∀ X ∈ Θ, IsFormation X) ∧
  (∀ S ⊆ Θ, S.Nonempty → ∃ Y ∈ Θ, ∀ (H : Type) [Group H], Y.mem H ↔ ∀ X ∈ S, X.mem H) ∧
  ∃ T ∈ Θ, ∀ X ∈ Θ, Incl X T

    MathlibExt.GroupTheory.CompleteLatticeOfFormationsKourovka18Problem92Wanted.IsCompactIn

    Let \(\Theta\) be a set of classes of groups and \(\mathfrak{A}\) a class of groups. Then \(\mathfrak{A}\) is compact in \(\Theta\) if, for every subset \(S \subseteq \Theta\) and every join \(\mathfrak{J}\) of \(S\) in \(\Theta\) with \(\mathfrak{A} \subseteq \mathfrak{J}\), there are a finite subset \(S_1 \subseteq S\) and a join \(\mathfrak{J}_1\) of \(S_1\) in \(\Theta\) with \(\mathfrak{A} \subseteq \mathfrak{J}_1\).

    def IsCompactIn (Θ : Set GroupClass) (A : GroupClass) : Prop :=
  ∀ S ⊆ Θ, ∀ J, IsJoinIn Θ S J → Incl A J →

    DefinitionModular sets of group classes#✓fully proved

    MathlibExt.GroupTheory.CompleteLatticeOfFormationsKourovka18Problem92Wanted.IsModularIn

    A set \(\Theta\) of classes of groups is modular if for all \(\mathfrak{A}, \mathfrak{B}, \mathfrak{C} \in \Theta\) with \(\mathfrak{A} \subseteq \mathfrak{C}\) the following holds: whenever \(\mathfrak{J}_1\) is the join in \(\Theta\) of the set \(\{\mathfrak{A}, \mathfrak{B} \cap \mathfrak{C}\}\) and \(\mathfrak{D}\) is the join in \(\Theta\) of the set \(\{\mathfrak{A}, \mathfrak{B}\}\), the classes \(\mathfrak{J}_1\) and \(\mathfrak{D} \cap \mathfrak{C}\) contain the same groups. This is the modular law \(\mathfrak{A} \vee (\mathfrak{B} \wedge \mathfrak{C}) = (\mathfrak{A} \vee \mathfrak{B}) \wedge \mathfrak{C}\), with joins taken in \(\Theta\) and meets the intersections.

    def IsModularIn (Θ : Set GroupClass) : Prop :=
  ∀ A ∈ Θ, ∀ B ∈ Θ, ∀ C ∈ Θ, Incl A C → ∀ BC J₁ AB J₂ : GroupClass,
    (∀ (H : Type) [Group H], BC.mem H ↔ B.mem H ∧ C.mem H) → IsJoinIn Θ {A, BC} J₁ →
    IsJoinIn Θ {A, B} AB → (∀ (H : Type) [Group H], J₂.mem H ↔ AB.mem H ∧ C.mem H) →
    Incl J₁ J₂ ∧ Incl J₂ J₁
