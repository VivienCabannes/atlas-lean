    DefinitionSupersoluble group (generator form)#✓fully proved

    MathlibExt.GroupTheory.FullPrimeMaximalSupersolubleKourovka19Problem55Wanted.IsSupersoluble

    A group \(G\) is supersoluble when there are a natural number \(n\) and elements \(g_0, \dots, g_{n-1}\) of \(G\) that generate \(G\) such that, for every \(i \le n\), the subgroup \(G_i = \langle g_j : j < i \rangle\) is normal in \(G\).

    Then \(1 = G_0 \le \dots \le G_n = G\) is a normal series with cyclic factors \(G_{i+1} / G_i = \langle G_i, g_i \rangle / G_i\).

    def IsSupersoluble (G : Type*) [Group G] : Prop :=
  ∃ (n : ℕ) (g : Fin n → G), (∀ i : ℕ, i ≤ n → (Subgroup.closure (g '' {j | j.val < i})).Normal) ∧
    Subgroup.closure (Set.range g) = ⊤

    DefinitionMonakhov's condition#✓fully proved

    MathlibExt.GroupTheory.FullPrimeMaximalSupersolubleKourovka19Problem55Wanted.MaximalFullPrimeSupersoluble

    A group \(G\) satisfies Monakhov's condition when every maximal subgroup \(M\) of \(G\) with \(\pi(M) = \pi(G)\) is supersoluble, where \(\pi(X)\) is the set of prime factors of the order of \(X\) if \(X\) is finite, and is empty if \(X\) is infinite.

    def MaximalFullPrimeSupersoluble (G : Type*) [Group G] : Prop :=
  ∀ M : Subgroup G, IsCoatom M → (Nat.card M).primeFactors = (Nat.card G).primeFactors →
    IsSupersoluble M

    DefinitionChief factor of rank above a bound#✓fully proved

    MathlibExt.GroupTheory.FullPrimeMaximalSupersolubleKourovka19Problem55Wanted.HasChiefFactorRankGT

    A group \(G\) has a chief factor of rank greater than a natural number \(r\) when there are a chief factor \(A / B\) of \(G\), a prime \(p\) and a natural number \(k > r\) such that the index \([A : B]\) equals \(p^k\).

    A chief factor of a finite soluble group is an elementary abelian \(p\)-group, of rank \(k\) when its order is \(p^k\).

    def HasChiefFactorRankGT (G : Type*) [Group G] (r : ℕ) : Prop :=
  ∃ A B : Subgroup G, IsChiefFactor A B ∧ ∃ p k : ℕ, p.Prime ∧ B.relIndex A = p ^ k ∧ r < k
    def IsChiefFactor {G : Type*} [Group G] (A B : Subgroup G) : Prop :=
  A.Normal ∧ B.Normal ∧ B < A ∧ ∀ N : Subgroup G, N.Normal → B ≤ N → N ≤ A → N = B ∨ N = A

    DefinitionGroups of p-length at most one#✓fully proved

    MathlibExt.GroupTheory.FullPrimeMaximalSupersolubleKourovka19Problem55Wanted.PLengthLEOne

    For a natural number \(p\), a group \(G\) has \(p\)-length at most \(1\) when there are normal subgroups \(N \le M\) of \(G\) such that \(N\) is finite of order not divisible by \(p\), the index \([M : N]\) equals \(p^k\) for some natural number \(k\) (an infinite index counting as \(0\)), and the index \([G : M]\) is finite and not divisible by \(p\).

    For finite \(G\) and prime \(p\) this says that \(N\) is a \(p'\)-group, \(M / N\) is a \(p\)-group and \(G / M\) is a \(p'\)-group.

    def PLengthLEOne (G : Type*) [Group G] (p : ℕ) : Prop :=
  ∃ N M : Subgroup G, N.Normal ∧ M.Normal ∧ N ≤ M ∧ ¬ p ∣ Nat.card N ∧
    (∃ k : ℕ, N.relIndex M = p ^ k) ∧ ¬ p ∣ M.index
