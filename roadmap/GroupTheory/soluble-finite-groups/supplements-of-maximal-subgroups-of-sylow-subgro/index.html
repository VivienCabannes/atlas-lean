    MathlibExt.GroupTheory.SylowMaximalPSolubleSupplementKourovka17Problem111Wanted.IsPSoluble

    A group \(G\) is \(p\)-soluble when it has a chain of subgroups \(1 = H_0 \le H_1 \le \cdots \le H_n = G\), each normal in the next, such that for every \(i < n\) the relative index \(|H_{i+1} : H_i|\) (taken to be \(0\) when it is infinite) is a power of \(p\) or is coprime to \(p\). For a finite group this says that every factor \(H_{i+1}/H_i\) is a \(p\)-group or a \(p'\)-group.

    def IsPSoluble (p : ℕ) (G : Type*) [Group G] : Prop :=
  ∃ (n : ℕ) (H : Fin (n + 1) → Subgroup G), H 0 = ⊥ ∧ H (Fin.last n) = ⊤ ∧
    ∀ i : Fin n, H i.castSucc ≤ H i.succ ∧ ((H i.castSucc).subgroupOf (H i.succ)).Normal ∧
      ((∃ k : ℕ, (H i.castSucc).relIndex (H i.succ) = p ^ k) ∨
        Nat.Coprime ((H i.castSucc).relIndex (H i.succ)) p)

    MathlibExt.GroupTheory.SylowMaximalSigmaNilpotentSupplementKourovka19Problem88Wanted.sylowMaximalSigmaNilpotentSupplement

    The statement that for every partition \(\sigma\) of the set of all primes and every finite group \(G\): if for every prime \(p\), every Sylow \(p\)-subgroup \(P\) of \(G\) and every maximal subgroup \(V\) of \(P\) there is a \(\sigma\)-nilpotent subgroup \(T\) of \(G\) with \(VT = G\), that is, every element of \(G\) is a product \(vt\) with \(v \in V\) and \(t \in T\), then \(G\) is \(\sigma\)-nilpotent. Here a partition of the primes is a family of nonempty, pairwise disjoint sets of primes whose union is the set of all primes, and a group is \(\sigma\)-nilpotent when it is the internal direct product of finitely many normal subgroups, each of whose order has all its prime divisors in a single block of \(\sigma\).

    def sylowMaximalSigmaNilpotentSupplement : Prop :=
  ∀ (I : Type) (σ : I → Set ℕ), IsPrimePartition σ → ∀ (G : Type) [Group G] [Finite G],
    (∀ p : ℕ, p.Prime → ∀ (P : Sylow p G) (V : Subgroup G), V ⋖ (P : Subgroup G) →
      ∃ T : Subgroup G, IsSigmaNilpotent σ T ∧ ∀ g : G, ∃ v ∈ V, ∃ t ∈ T, v * t = g) →
    IsSigmaNilpotent σ G
    def IsPrimePartition {I : Type} (σ : I → Set ℕ) : Prop :=
  (∀ i, (σ i).Nonempty ∧ ∀ p ∈ σ i, p.Prime) ∧ (∀ i j, i ≠ j → Disjoint (σ i) (σ j)) ∧
    ∀ p : ℕ, p.Prime → ∃ i, p ∈ σ i
