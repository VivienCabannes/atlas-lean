    DefinitionChief factors#✓fully proved

    MathlibExt.GroupTheory.KourovkaNotebookShared.IsChiefFactor

    For subgroups \(A\) and \(B\) of a group \(G\), \(A / B\) is a chief factor of \(G\) if \(A\) and \(B\) are normal in \(G\), \(B < A\), and every normal subgroup \(N\) of \(G\) with \(B \le N \le A\) equals \(B\) or \(A\).

    def IsChiefFactor {G : Type*} [Group G] (A B : Subgroup G) : Prop :=
  A.Normal ∧ B.Normal ∧ B < A ∧ ∀ N : Subgroup G, N.Normal → B ≤ N → N ≤ A → N = B ∨ N = A

    DefinitionGroups of Fitting height at most \(h\)#✓fully proved

    MathlibExt.GroupTheory.KourovkaNotebookShared.FittingHeightLE

    For a natural number \(h\), a group \(G\) has Fitting height (nilpotent length) at most \(h\) if there are normal subgroups \(1 = G_0 \le G_1 \le \cdots \le G_h = G\) of \(G\) such that for every \(i < h\) some term of the lower central series of \(G_{i+1}\) lies in \(G_i\), that is, \(G_{i+1} / G_i\) is nilpotent.

    def FittingHeightLE (G : Type*) [Group G] (h : ℕ) : Prop :=
  ∃ s : ℕ → Subgroup G, s 0 = ⊥ ∧ s h = ⊤ ∧ ∀ i < h, (s i).Normal ∧ s i ≤ s (i + 1) ∧
    ∃ c : ℕ, (s (i + 1)).lowerCentralSeries c ≤ s i

    DefinitionComposition factors via subnormal subgroups#✓fully proved

    MathlibExt.GroupTheory.KourovkaNotebookShared.IsCompositionFactor

    A group \(S\) is a composition factor of a group \(K\) if \(S\) is simple and some subnormal subgroup \(H\) of \(K\) has a surjective homomorphism onto \(S\).

    For finite \(K\) this is the same as \(S\) occurring as a factor of a composition series of \(K\) (refine the subnormal chain through the kernel).

    def IsCompositionFactor (S K : Type*) [Group S] [Group K] : Prop :=
  IsSimpleGroup S ∧ ∃ H : Subgroup K, H.IsSubnormal ∧ ∃ f : H →* S, Function.Surjective f

    DefinitionConjugacy separable groups#✓fully proved

    MathlibExt.GroupTheory.KourovkaNotebookShared.IsConjugacySeparable

    A group \(G\) is conjugacy separable if any two elements \(x, y \in G\) whose images are conjugate in every quotient \(G / N\) by a normal subgroup \(N\) of finite index (that is, \(g x g^{-1} y^{-1} \in N\) for some \(g \in G\)) are conjugate in \(G\).

    def IsConjugacySeparable (G : Type*) [Group G] : Prop :=
  ∀ x y : G, (∀ N : Subgroup G, N.Normal → N.FiniteIndex → ∃ g : G, g * x * g⁻¹ * y⁻¹ ∈ N) →
    IsConj x y

    DefinitionResidually finite \(p\)-groups#✓fully proved

    MathlibExt.GroupTheory.KourovkaNotebookShared.IsResiduallyFiniteP

    For a natural number \(p\), a group \(G\) is residually a finite \(p\)-group if every element \(g \ne 1\) of \(G\) lies outside some normal subgroup of \(G\) whose index is \(p^k\) for some \(k \ge 0\), where an infinite index counts as \(0\).

    This notion appears in Kourovka Notebook problems 1.84, 4.52 and 10.30.

    def IsResiduallyFiniteP (p : ℕ) (G : Type*) [Group G] : Prop :=
  ∀ g : G, g ≠ 1 → ∃ N : Subgroup G, N.Normal ∧ (∃ k : ℕ, N.index = p ^ k) ∧ g ∉ N

    DefinitionRestricted wreath product#✓fully proved

    MathlibExt.GroupTheory.KourovkaNotebookShared.restrictedWreath

    For groups \(A\) and \(B\), let \(A \wr_r B = A^B \rtimes B\) be the regular (unrestricted) wreath product, where \(A^B\) is the group of all functions \(f : B \to A\) and \(b \in B\) acts on it by \((b \cdot f)(x) = f(b^{-1} x)\). The restricted wreath product \(A \wr B\) is the subgroup of \(A \wr_r B\) generated by the elements \((f, b)\) whose function part \(f\) has finite support, that is, \(f(x) \ne 1\) for only finitely many \(x \in B\).

    These elements already form a subgroup, and for finite \(B\) it is all of \(A \wr_r B\).

    def restrictedWreath (A B : Type*) [Group A] [Group B] : Subgroup (A ≀ᵣ B) :=
  Subgroup.closure {x | {b : B | x.left b ≠ 1}.Finite}

    DefinitionPartitions of the primes#✓fully proved

    MathlibExt.GroupTheory.KourovkaNotebookShared.IsPrimePartition

    A family \(\sigma = (\sigma_i)_{i \in I}\) of sets of natural numbers is a partition of the primes if every \(\sigma_i\) is a nonempty set of primes, \(\sigma_i\) and \(\sigma_j\) are disjoint whenever \(i \ne j\), and every prime lies in some \(\sigma_i\).

    def IsPrimePartition {I : Type} (σ : I → Set ℕ) : Prop :=
  (∀ i, (σ i).Nonempty ∧ ∀ p ∈ σ i, p.Prime) ∧ (∀ i j, i ≠ j → Disjoint (σ i) (σ j)) ∧
    ∀ p : ℕ, p.Prime → ∃ i, p ∈ σ i

    For a family \(\sigma = (\sigma_i)_{i \in I}\) of sets of natural numbers, a natural number \(n\) is \(\sigma\)-primary if there is an index \(i\) such that every prime divisor of \(n\) lies in \(\sigma_i\). For \(n = 0\) this means that some \(\sigma_i\) contains every prime.

    A finite group is called \(\sigma\)-primary when its order is.

    Definition\(\sigma\)-subnormal subgroups#✓fully proved

    MathlibExt.GroupTheory.KourovkaNotebookShared.IsSigmaSubnormal

    For a family \(\sigma = (\sigma_i)_{i \in I}\) of sets of natural numbers, a subgroup \(A\) of a group \(G\) is \(\sigma\)-subnormal in \(G\) if there is a chain of subgroups \(A = A_0 \le A_1 \le \cdots \le A_n = G\) such that for every \(i < n\) either \(A_i\) is normal in \(A_{i+1}\), or the index in \(A_{i+1}\) of the normal core of \(A_i\) in \(A_{i+1}\) is \(\sigma\)-primary (an infinite index counts as \(0\)).

    def IsSigmaSubnormal {I : Type} (σ : I → Set ℕ) {G : Type*} [Group G] (A : Subgroup G) : Prop :=
  ∃ (n : ℕ) (K : ℕ → Subgroup G), K 0 = A ∧ K n = ⊤ ∧ ∀ i < n, K i ≤ K (i + 1) ∧
    (((K i).subgroupOf (K (i + 1))).Normal ∨
      IsSigmaPrimary σ ((K i).subgroupOf (K (i + 1))).normalCore.index)

    Definition\(\sigma\)-nilpotent groups#✓fully proved

    MathlibExt.GroupTheory.KourovkaNotebookShared.IsSigmaNilpotent

    For a family \(\sigma = (\sigma_i)_{i \in I}\) of sets of natural numbers, a group \(G\) is \(\sigma\)-nilpotent if it is the internal direct product of finitely many normal subgroups \(H_1, \dots, H_t\) whose orders are \(\sigma\)-primary (the order of an infinite subgroup counts as \(0\)): the \(H_k\) generate \(G\), and each \(H_k\) meets the subgroup generated by the others trivially.

    def IsSigmaNilpotent {I : Type} (σ : I → Set ℕ) (G : Type*) [Group G] : Prop :=
  ∃ (t : ℕ) (H : Fin t → Subgroup G), (∀ k, (H k).Normal ∧ IsSigmaPrimary σ (Nat.card (H k))) ∧
    (⨆ k, H k) = ⊤ ∧ ∀ k, H k ⊓ (⨆ j ∈ ({k}ᶜ : Set (Fin t)), H j) = ⊥
    def IsSigmaPrimary {I : Type} (σ : I → Set ℕ) (n : ℕ) : Prop :=
  ∃ i, ∀ p : ℕ, p.Prime → p ∣ n → p ∈ σ i

    For a family \(\sigma = (\sigma_i)_{i \in I}\) of sets of natural numbers, a group \(G\) is \(\sigma\)-soluble if for every chief factor \(A / B\) of \(G\) the index \(|A : B|\) is \(\sigma\)-primary (an infinite index counts as \(0\)).

    MathlibExt.GroupTheory.SigmaSubnormalJoinConjugateKourovka19Problem84Wanted.sigmaSubnormalFromJoinsWithConjugates_refuted

    The statement of Kourovka Problem 19.84 is false: there are a partition \(\sigma\) of the set of primes, a finite group \(G\) and a subgroup \(A\) of \(G\) such that \(A\) is \(\sigma\)-subnormal in the subgroup \(\langle A, A^x \rangle\) generated by \(A\) and \(A^x = xAx^{-1}\) for every \(x \in G\), but \(A\) is not \(\sigma\)-subnormal in \(G\).

    Tyutyanov's example is \(G = S_5\), a partition with blocks \(\{2, 3\}\) and \(\{5\}\), and \(A = \langle (1\,2) \rangle\). Wielandt's theorem gives the affirmative answer for the partition into single primes.
