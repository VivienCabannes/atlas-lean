    The question is due to V. N. Knyagina and V. S. Monakhov.

    Definition\(\mathbb{P}\)-subnormal subgroup#✓fully proved

    MathlibExt.GroupTheory.SchmidtSubgroupsPrimeSubnormalKourovka18Problem30Wanted.IsPSubnormal

    A subgroup \(H\) of a group \(G\) is \(\mathbb{P}\)-subnormal in \(G\) when \(H = G\) or there is a chain of subgroups \(H = H_0 < H_1 < \cdots < H_n = G\) in which every index \(|H_i : H_{i-1}|\) is a prime number.

    def IsPSubnormal {G : Type} [Group G] (H : Subgroup G) : Prop :=
  Relation.ReflTransGen (fun A B : Subgroup G => A ≤ B ∧ (A.relIndex B).Prime) H ⊤

    The statement that for every partition \(\sigma\) of the set of all primes into nonempty pairwise disjoint blocks and every finite group \(G\) in which every Schmidt subgroup is \(\sigma\)-subnormal, \(G\) has a normal \(\sigma\)-nilpotent subgroup \(N\) such that \(G / N\) is cyclic: there is \(g \in G\) such that every \(x \in G\) satisfies \(x g^{-k} \in N\) for some integer \(k\). The problem is due to A. N. Skiba.

    def schmidtSigmaSubnormalCyclicQuotient : Prop :=

    (∀ S : Subgroup G, IsSchmidtSubgroup S → IsSigmaSubnormal σ S) →
    ∃ N : Subgroup G, N.Normal ∧ IsSigmaNilpotent σ N ∧
      ∃ g : G, ∀ x : G, ∃ k : ℤ, x * (g ^ k)⁻¹ ∈ N

    MathlibExt.GroupTheory.SchmidtSubgroupsSigmaSubnormalKourovka19Problem85Wanted.schmidtSigmaSubnormalCyclicQuotient_holds

    Let \(\sigma\) be a partition of the set of all primes into nonempty pairwise disjoint blocks, and let \(G\) be a finite group in which every Schmidt subgroup is \(\sigma\)-subnormal. Then \(G\) has a normal \(\sigma\)-nilpotent subgroup \(N\) such that \(G / N\) is cyclic: there is \(g \in G\) such that every \(x \in G\) satisfies \(x g^{-k} \in N\) for some integer \(k\). This answers Kourovka Notebook Problem 19.85 in the affirmative.

    Yi and Kamornikov prove that \(G / F_\sigma(G)\) is cyclic, where \(F_\sigma(G)\) is the largest normal \(\sigma\)-nilpotent subgroup of \(G\); for nilpotent \(G\) one takes \(N = G\). The case of the partition of the primes into single primes was known before.
