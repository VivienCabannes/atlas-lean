    DefinitionOrder polynomial of a subgroup#✓fully proved

    MathlibExt.GroupTheory.EulerianPolynomialFactorizationKourovka11Problem104Wanted.orderPolynomial

    For a subgroup \(H\) of a group, the order polynomial of \(H\) is \(f(H) = \prod_p x_p^{v_p(|H|)}\) in the integer polynomial ring \(\mathbb{Z}[x_0, x_1, \dots]\), where \(p\) runs over the primes, \(x_p\) is the variable indexed by \(p\), and \(v_p(|H|)\) is the exponent of \(p\) in the order \(|H|\) of \(H\). If \(H\) is infinite, \(f(H) = 1\).

    noncomputable def orderPolynomial {G : Type*} [Group G] (H : Subgroup G) : MvPolynomial ℕ ℤ :=
  (Nat.card H).factorization.prod fun p a => MvPolynomial.X p ^ a

    DefinitionEulerian function of a group (G. E. Wall)#✓fully proved

    MathlibExt.GroupTheory.EulerianPolynomialFactorizationKourovka11Problem104Wanted.IsEulerianFunction

    Let \(G\) be a group and let \(f\) be the order polynomial. A function \(\varphi\) from the subgroups of \(G\) to the integer polynomial ring \(\mathbb{Z}[x_0, x_1, \dots]\) is an Eulerian function of \(G\) if \(\sum_{K \le H} \varphi(K) = f(H)\) for every subgroup \(H\) of \(G\), the sum running over the subgroups \(K\) of \(H\). The value \(\varphi(G)\) is the Eulerian polynomial of \(G\).

    For finite \(G\) this relation determines \(\varphi\) uniquely, by induction on \(H\). If infinitely many subgroups \(K \le H\) have \(\varphi(K) \ne 0\), the sum is read as \(0\).

    def IsEulerianFunction {G : Type*} [Group G] (φ : Subgroup G → MvPolynomial ℕ ℤ) : Prop :=
  ∀ H : Subgroup G, ∑ᶠ (K : Subgroup G) (_ : K ≤ H), φ K = orderPolynomial H
    noncomputable def orderPolynomial {G : Type*} [Group G] (H : Subgroup G) : MvPolynomial ℕ ℤ :=
  (Nat.card H).factorization.prod fun p a => MvPolynomial.X p ^ a

    Definition\(p\)-solvable group#✓fully proved

    MathlibExt.GroupTheory.EulerianPolynomialFactorizationKourovka11Problem104Wanted.IsPSolvable

    For a natural number \(p\), a group \(G\) is \(p\)-solvable if it has a chain of subgroups \(1 = N_0 \le N_1 \le \dots \le N_n = G\) in which each \(N_i\) is normal in \(N_{i+1}\) and each index \([N_{i+1} : N_i]\), taken to be \(0\) when it is infinite, is a power \(p^k\) with \(k \ge 0\) or is coprime to \(p\). For finite \(G\) and prime \(p\) this says that every factor \(N_{i+1}/N_i\) is a \(p\)-group or has order prime to \(p\).

    def IsPSolvable (p : ℕ) (G : Type*) [Group G] : Prop :=
  ∃ (n : ℕ) (N : ℕ → Subgroup G), N 0 = ⊥ ∧ N n = ⊤ ∧ ∀ i < n, N i ≤ N (i + 1) ∧
    ((N i).subgroupOf (N (i + 1))).Normal ∧
    ((∃ k : ℕ, (N i).relIndex (N (i + 1)) = p ^ k) ∨ Nat.Coprime ((N i).relIndex (N (i + 1))) p)

    DefinitionKourovka Problem 11.104(a) (Eulerian polynomials and solvability, G. E. Wall)#✓fully proved

    MathlibExt.GroupTheory.EulerianPolynomialFactorizationKourovka11Problem104Wanted.eulerianPolynomialSplitsSolvable

    This is the statement that for every finite group \(G\) and every Eulerian function \(\varphi\) of \(G\), with values in the integer polynomial ring \(\mathbb{Z}[x_0, x_1, \dots]\): if there are a finite set \(S\) of primes and, for each \(q \in S\), an integer polynomial \(P_q\) involving no variable other than \(x_q\), such that the Eulerian polynomial \(\varphi(G)\) equals \(\prod_{q \in S} P_q\), then \(G\) is solvable.

  ∀ (G : Type) [Group G] [Finite G] (φ : Subgroup G → MvPolynomial ℕ ℤ), IsEulerianFunction φ →

      φ ⊤ = ∏ q ∈ s, P q) →
    Group.IsSolvable G

    MathlibExt.GroupTheory.EulerianPolynomialFactorizationKourovka11Problem104Wanted.eulerianPolynomialSeparatesPSolvable

    This is the statement that for every finite group \(G\), every prime \(p\) and every Eulerian function \(\varphi\) of \(G\), with values in the integer polynomial ring \(\mathbb{Z}[x_0, x_1, \dots]\): if the Eulerian polynomial \(\varphi(G)\) is a product \(PQ\) of integer polynomials where \(P\) involves no variable other than \(x_p\) and \(x_p\) does not occur in \(Q\), then \(G\) is \(p\)-solvable.

    def eulerianPolynomialSeparatesPSolvable : Prop :=
  ∀ (G : Type) [Group G] [Finite G] (p : ℕ), p.Prime → ∀ φ : Subgroup G → MvPolynomial ℕ ℤ,
