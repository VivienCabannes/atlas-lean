    Word metrics and quasi-isometries

    Word metrics of finitely generated groups, their independence of the finite generating set up to bi-Lipschitz equivalence, and the Švarc–Milnor lemma relating a group to the spaces on which it acts geometrically.

    TheoremChange of finite generating set is bi-Lipschitz#✓fully proved

    Group.Generators.exists_wordLength_bilipschitz

    For two finite generating families \(P\) and \(Q\) of a group \(G\) there is an integer \(K \ge 1\) with \(|g|_P \le K |g|_Q\) and \(|g|_Q \le K |g|_P\) for every \(g \in G\). Since the word metric is \(d(g, h) = |g^{-1} h|\), the identity of \(G\) is a \(K\)-bi-Lipschitz map between the two word metrics. One can take for \(K\) the largest length of a generator of one family written in the other.

    So the word metric of a finitely generated group is well defined up to bi-Lipschitz equivalence, and every quasi-isometry invariant of \((G, d_P)\) is an invariant of the group \(G\).

    theorem exists_wordLength_bilipschitz [Finite ι] [Finite κ] (P : Generators G ι)
    (Q : Generators G κ) :
    ∃ K : ℕ, 1 ≤ K ∧ ∀ g : G, P.wordLength g ≤ K * Q.wordLength g ∧
      Q.wordLength g ≤ K * P.wordLength g

    TheoremWalking along a geodesic#✓fully proved

    MathlibExt.SvarcMilnor.exists_chain

    Let X be geodesic, R ≥ 0 a covering radius for the orbit of x₀, and S = {s | d(x₀, s • x₀) ≤ 2R + 1}. Let Q : G → ℕ → Prop hold for (s, 1) with s ∈ S and be preserved by right multiplication by elements of S while increasing m by one. If d(x₀, y) ≤ n and d(h • x₀, y) ≤ R, then Q h m for some m ≤ n + 1.

    (hR : ∀ x : X, ∃ g : G, dist (g • x₀) x ≤ R) (Q : G → ℕ → Prop)
    (h₁ : ∀ s : G, dist x₀ (s • x₀) ≤ 2 * R + 1 → Q s 1)

    TheoremThe Švarc–Milnor lemma#✓fully proved

    MathlibExt.SvarcMilnor.exists_generators

    Let a group \(G\) act on a proper geodesic metric space \(X\) by isometries, properly discontinuously and cocompactly, and let \(x_0 \in X\). Then \(G\) is generated by the finite set \(S = \{g : d(x_0, g x_0) \le 2R + 1\}\), where \(R\) is such that every point of \(X\) is within \(R\) of the orbit of \(x_0\), and with \(L = 2R + 1\), \(C = R + 2\), $\(d(g x_0, h x_0) \le L\,|g^{-1} h|_S + C, \qquad |g^{-1} h|_S \le L\, d(g x_0, h x_0) + C,\)$ and every point of \(X\) is within \(C\) of the orbit. The orbit map \(g \mapsto g x_0\) is thus a quasi-isometry from \(G\) with its word metric to \(X\).

    Proper discontinuity is Mathlib's ProperlyDiscontinuousSMul (for compact \(K, L\), only finitely many \(g\) have \(gK \cap L \ne \emptyset\)), equivalent to Gromov's "for every compact \(B\), \(B \cap \gamma B = \emptyset\) for almost all \(\gamma\)". Cocompactness is that every orbit meets a fixed compact set. Gromov states the lemma for a Riemannian manifold \(X\): with a cocompact isometric action such a manifold is complete, hence a proper geodesic space by the Hopf–Rinow theorem (Gromov's 1987 paper, 1.6.A, for the geodesic part), so the statement here contains his (that implication is not formalised).

    The proof walks from \(x_0\) to \(g x_0\) along a geodesic in unit steps and chooses an orbit point within \(R\) of each step; consecutive orbit points differ by an element of \(S\). Conversely each element of \(S\) moves \(x_0\) by at most \(2R + 1\).

    theorem exists_generators (hX : IsGeodesicSpace X) {K : Set X} (hK : IsCompact K)
    (hcov : ∀ x : X, ∃ g : G, g • x ∈ K) (x₀ : X) :
    ∃ (S : Set G) (_ : S.Finite) (P : Group.Generators G S) (L C : ℝ), 1 ≤ L ∧ 0 ≤ C ∧
      (∀ g h : G, dist (g • x₀) (h • x₀) ≤ L * P.wordLength (g⁻¹ * h) + C ∧
        (P.wordLength (g⁻¹ * h) : ℝ) ≤ L * dist (g • x₀) (h • x₀) + C) ∧
      ∀ x : X, ∃ g : G, dist (g • x₀) x ≤ C
    def IsGeodesicSpace (X : Type*) [PseudoMetricSpace X] : Prop :=
  ∀ x y : X, ∃ γ : ℝ → X, IsGeodesicSegment γ x y

    TheoremŠvarc–Milnor as a quasi-isometry#✓fully proved

    MathlibExt.SvarcMilnor.isQuasiIsometry

    Under the hypotheses of the Švarc–Milnor lemma there is a finite generating family \(P\) of \(G\) such that the orbit map \(g \mapsto g x_0\) is a quasi-isometry (Metric.IsQuasiIsometry) from \(G\) with the word metric P.normedGroup, whose distance is \(d(g, h) = |g^{-1} h|_P\), to \(X\). In particular \(G\) is quasi-isometric to \(X\): for instance the fundamental group of a closed Riemannian manifold is quasi-isometric to its universal cover.

    theorem isQuasiIsometry (hX : IsGeodesicSpace X) {K : Set X} (hK : IsCompact K)
    (hcov : ∀ x : X, ∃ g : G, g • x ∈ K) (x₀ : X) :
    ∃ (S : Set G) (_ : S.Finite) (P : Group.Generators G S) (L C : ℝ),
      @IsQuasiIsometry G X P.normedGroup.toPseudoMetricSpace _ (fun g => g • x₀) L C
    def IsGeodesicSpace (X : Type*) [PseudoMetricSpace X] : Prop :=
  ∀ x y : X, ∃ γ : ℝ → X, IsGeodesicSegment γ x y
