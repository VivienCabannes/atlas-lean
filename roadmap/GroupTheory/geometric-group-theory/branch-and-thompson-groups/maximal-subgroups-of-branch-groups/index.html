    For a branching sequence \(m \colon \mathbb{N} \to \mathbb{N}\), the vertices of the spherically homogeneous rooted tree are the finite words \((x_0, \dots, x_{k-1})\) of natural numbers with \(x_i < m(i)\) for every \(i < k\).     DefinitionRigid vertex stabilizer (Kourovka 15.15)#✓fully proved

    MathlibExt.GroupTheory.BranchGroupInfiniteIndexMaximalKourovka15Problem15Wanted.rigidVertexStabilizer

    Let \(\rho\) be a homomorphism from a group \(G\) to the permutations of the vertices of the tree with branching sequence \(m\), and let \(v\) be a vertex. The rigid vertex stabilizer of \(v\) is the set of \(g \in G\) such that \(\rho(g)\) fixes every vertex \(w\) of which \(v\) is not a prefix, that is, every vertex outside the subtree rooted at \(v\).

    def rigidVertexStabilizer {m : ℕ → ℕ} {G : Type*} [Group G] (ρ : G →* Equiv.Perm (TreeVertex m))
    (v : TreeVertex m) : Set G :=
  {g | ∀ w : TreeVertex m, ¬ v.1 <+: w.1 → ρ g w = w}

  {l : List ℕ // ∀ (i : ℕ) (h : i < l.length), l[i] < m i}

    DefinitionBranch group (Kourovka 15.15)#✓fully proved

    MathlibExt.GroupTheory.BranchGroupInfiniteIndexMaximalKourovka15Problem15Wanted.IsBranchGroup

    A group \(G\) is a branch group if there are a sequence \(m \colon \mathbb{N} \to \mathbb{N}\) with \(m(i) \ge 2\) for all \(i\) and an injective homomorphism \(\rho\) from \(G\) to the permutations of the vertices of the spherically homogeneous rooted tree with branching sequence \(m\) such that each \(\rho(g)\) is a tree automorphism (for all vertices \(v\) and \(w\), \(v\) is a prefix of \(w\) if and only if \(\rho(g)(v)\) is a prefix of \(\rho(g)(w)\)), the action is level-transitive (for any two vertices \(v\) and \(w\) at the same level some \(g \in G\) has \(\rho(g)(v) = w\)), and for every \(n\) the \(n\)-th rigid level stabilizer has finite index in \(G\).

    def IsBranchGroup (G : Type*) [Group G] : Prop :=
  ∃ (m : ℕ → ℕ) (_ : ∀ i, 2 ≤ m i) (ρ : G →* Equiv.Perm (TreeVertex m)),
    Function.Injective ρ ∧
    (∀ (g : G) (v w : TreeVertex m), v.1 <+: w.1 ↔ (ρ g v).1 <+: (ρ g w).1) ∧
    (∀ v w : TreeVertex m, v.1.length = w.1.length → ∃ g : G, ρ g v = w) ∧
    ∀ n : ℕ, (rigidLevelStabilizer ρ n).FiniteIndex
    def TreeVertex (m : ℕ → ℕ) : Type :=
  {l : List ℕ // ∀ (i : ℕ) (h : i < l.length), l[i] < m i}

    MathlibExt.GroupTheory.BranchGroupShared.RootedTree.IsDescendant

    For vertices \(v\) at level \(n\) and \(w\) at level \(m\) of a rooted tree \(T\), \(w\) is a descendant of \(v\) when \(w\) is reached from \(v\) by moving from a vertex to one of its children zero or more times: \(v\) is a descendant of itself, and a vertex at level \(k + 1\) is a descendant of \(v\) whenever its parent is.

    StructureFaithful level-transitive action on a rooted tree#✓fully proved

    MathlibExt.GroupTheory.BranchGroupShared.LevelTransitiveFaithfulAction

    Let \(T\) be a rooted tree with vertex sets \(V_n\) at the levels \(n \ge 0\) and parent maps \(V_{n+1} \to V_n\), and let \(G\) be a group. A faithful level-transitive action of \(G\) on \(T\) consists of an action of \(G\) on each level \(V_n\) by permutations, that is, a homomorphism \(G \to \mathrm{Sym}(V_n)\) for every \(n\), such that the actions commute with the parent maps (so \(G\) acts by tree automorphisms), only the identity of \(G\) fixes every vertex of \(T\), and \(G\) acts transitively on every level \(V_n\).

    structure LevelTransitiveFaithfulAction (T : RootedTree) (G : Type) [Group G] where
  /-- The action on level `n`. -/
  levelAction : ∀ n, G →* Equiv.Perm (T.Vertex n)
  /-- The level actions commute with the parent maps, so `G` acts by tree automorphisms. -/
  parent_equivariant : ∀ (g : G) (n : ℕ) (w : T.Vertex (n + 1)),
    T.parent n (levelAction (n + 1) g w) = levelAction n g (T.parent n w)
  /-- Only `1` fixes every vertex. -/
  faithful : ∀ g : G, (∀ n (v : T.Vertex n), levelAction n g v = v) → g = 1
  /-- `G` is transitive on every level. -/
  level_transitive : ∀ n (v w : T.Vertex n), ∃ g : G, levelAction n g v = w
