    MathlibExt.GroupTheory.FinitelyGeneratedBranchGroupsKourovka15Problem14Wanted.TreeVertex

    For a sequence \(m\) of natural numbers, the vertices of the spherically homogeneous rooted tree with branching sequence \(m\) are the finite words \(l_0 l_1 \cdots l_{k-1}\) of natural numbers with \(l_i < m(i)\) for every \(i < k\). The length of a word is its level and its prefixes are its ancestors.

    def TreeVertex (m : ℕ → ℕ) : Type :=
  {l : List ℕ // ∀ (i : ℕ) (h : i < l.length), l[i] < m i}

    DefinitionRigid vertex stabilizers (Kourovka 15.14 version)#✓fully proved

    MathlibExt.GroupTheory.FinitelyGeneratedBranchGroupsKourovka15Problem14Wanted.rigidVertexStabilizer

    Let \(G\) be a group acting by permutations \(\rho\) on the vertices of the rooted tree with branching sequence \(m\), and let \(v\) be a vertex. The rigid vertex stabilizer of \(v\) is the set of elements \(g \in G\) whose support lies in the subtree rooted at \(v\): \(\rho(g)\) fixes every vertex \(w\) of which \(v\) is not a prefix.

    def rigidVertexStabilizer {m : ℕ → ℕ} {G : Type*} [Group G] (ρ : G →* Equiv.Perm (TreeVertex m))
    (v : TreeVertex m) : Set G :=
  {g | ∀ w : TreeVertex m, ¬ v.1 <+: w.1 → ρ g w = w}
    def TreeVertex (m : ℕ → ℕ) : Type :=
  {l : List ℕ // ∀ (i : ℕ) (h : i < l.length), l[i] < m i}

    DefinitionRigid level stabilizers (Kourovka 15.14 version)#✓fully proved

    MathlibExt.GroupTheory.FinitelyGeneratedBranchGroupsKourovka15Problem14Wanted.rigidLevelStabilizer

    Let \(G\) be a group acting by permutations \(\rho\) on the vertices of the rooted tree with branching sequence \(m\), and let \(n\) be a natural number. The \(n\)-th rigid level stabilizer of \(\rho\) is the subgroup of \(G\) generated by the rigid vertex stabilizers of all vertices at level \(n\), the words of length \(n\).

    def rigidLevelStabilizer {m : ℕ → ℕ} {G : Type*} [Group G] (ρ : G →* Equiv.Perm (TreeVertex m))
    (n : ℕ) : Subgroup G :=
  Subgroup.closure (⋃ v ∈ {v : TreeVertex m | v.1.length = n}, rigidVertexStabilizer ρ v)

    DefinitionBranch groups (Kourovka 15.14 version)#✓fully proved

    MathlibExt.GroupTheory.FinitelyGeneratedBranchGroupsKourovka15Problem14Wanted.IsBranchGroup

    A group \(G\) is a branch group (Kourovka 15.12) if there are a sequence \(m\) of natural numbers with \(m(i) \ge 2\) for every \(i\) and an action \(\rho\) of \(G\) by permutations of the vertices of the spherically homogeneous rooted tree with branching sequence \(m\) such that: \(\rho\) is faithful; each \(\rho(g)\) is a tree automorphism, that is, for all vertices \(v\) and \(w\), \(v\) is a prefix of \(w\) if and only if \(\rho(g)(v)\) is a prefix of \(\rho(g)(w)\); the action is level-transitive, that is, for any two vertices \(v\) and \(w\) of the same level some \(g \in G\) has \(\rho(g)(v) = w\); and for every \(n \in \mathbb{N}\) the \(n\)-th rigid level stabilizer of \(\rho\) has finite index in \(G\).

    def IsBranchGroup (G : Type*) [Group G] : Prop :=
  ∃ (m : ℕ → ℕ) (_ : ∀ i, 2 ≤ m i) (ρ : G →* Equiv.Perm (TreeVertex m)),
    Function.Injective ρ ∧
    (∀ (g : G) (v w : TreeVertex m), v.1 <+: w.1 ↔ (ρ g v).1 <+: (ρ g w).1) ∧
    (∀ v w : TreeVertex m, v.1.length = w.1.length → ∃ g : G, ρ g v = w) ∧
    ∀ n : ℕ, (rigidLevelStabilizer ρ n).FiniteIndex
    def TreeVertex (m : ℕ → ℕ) : Type :=
  {l : List ℕ // ∀ (i : ℕ) (h : i < l.length), l[i] < m i}

    DefinitionGrowth rate of a finitely generated group#✓fully proved

    MathlibExt.GroupTheory.FinitelyGeneratedBranchGroupsKourovka15Problem14Wanted.growthRate

    The growth rate ω(G, P) = limsup β_P(n)^(1/n) of a finite generating family P, where β_P(n) is the number of elements that are products of at most n generators and their inverses.

    noncomputable def growthRate {G : Type*} [Group G] {k : ℕ} (P : Group.Generators G (Fin k)) : ℝ :=
  Filter.limsup (fun n : ℕ => (Nat.card {g : G // P.wordLength g ≤ n} : ℝ) ^ ((1 : ℝ) / n))

    DefinitionGroups of exponential growth#✓fully proved

    MathlibExt.GroupTheory.FinitelyGeneratedBranchGroupsKourovka15Problem14Wanted.HasExponentialGrowth

    A group \(G\) has exponential growth when it is finitely generated and every finite generating family \(P\) of \(G\) has growth rate \(\omega(G, P) > 1\).

    def HasExponentialGrowth (G : Type*) [Group G] : Prop :=
  Group.FG G ∧ ∀ (k : ℕ) (P : Group.Generators G (Fin k)), 1 < growthRate P
