    MathlibExt.GroupTheory.FinitelyPresentedOrderableWordProblemKourovka17Problem29Wanted.biOrders

    For a group \(G\), the bi-invariant orders of \(G\) are the linear orders \(\le\) on \(G\) (reflexive, antisymmetric, transitive and total relations) that are invariant under left and right multiplication: for all \(a, b, c \in G\), \(a \le b\) implies \(ca \le cb\) and \(ac \le bc\).

    def biOrders (G : Type*) [Group G] : Set (G → G → Prop) :=
  {r | IsLinearOrder G r ∧ ∀ a b c : G, r a b → r (c * a) (c * b) ∧ r (a * c) (b * c)}

    The statement that there is a finitely presented group \(G\) that admits a bi-invariant linear order and has a finite generating family \(g_1, \dots, g_k\) for which the word problem is insoluble: no algorithm decides, given a word in the \(g_i\) and their inverses, whether it equals \(1\) in \(G\).

    def finitelyPresentedOrderableInsolubleWordProblem : Prop :=
  ∃ (G : Type) (_ : Group G), Group.IsFinitelyPresented G ∧ (biOrders G).Nonempty ∧
    ∃ (k : ℕ) (gens : Fin k → G), Subgroup.closure (Set.range gens) = ⊤ ∧
      ¬ WordProblemSolvable (FreeGroup.lift gens)

    DefinitionRecursively presented group#✓fully proved

    MathlibExt.GroupTheory.SolubleRightOrderableWordProblemKourovka17Problem28Wanted.IsRecursivelyPresented

    Let \(G\) be a group, \(k\) a natural number and \(\varphi\) a homomorphism from the free group on \(k\) generators to \(G\). The group \(G\) is recursively presented with respect to \(\varphi\) when the set of words \(w\) (finite lists of letters \((i, \varepsilon)\) with \(i < k\) and \(\varepsilon\) true or false, the letter \((i, \mathrm{false})\) standing for the inverse of the \(i\)-th generator) with \(\varphi(w) = 1\) in \(G\) is recursively enumerable.

    When \(\varphi\) is surjective, this is the same as a presentation of \(G\) on the images of the generators with a recursively enumerable set of relators; it is the enumerable counterpart of a solvable word problem.

    def IsRecursivelyPresented {G : Type*} [Group G] {k : ℕ} (φ : FreeGroup (Fin k) →* G) : Prop :=
  REPred (fun w : List (Fin k × Bool) => φ (FreeGroup.mk w) = 1)

    DefinitionThe Bludov–Glass question (Kourovka 17.28)#✓fully proved

    MathlibExt.GroupTheory.SolubleRightOrderableWordProblemKourovka17Problem28Wanted.solubleRightOrderableInsolubleWordProblem

    The statement that there exist a soluble group \(G\) that admits a right order, a natural number \(k\) and elements \(g_0, \dots, g_{k-1}\) generating \(G\) such that, for the homomorphism \(\varphi\) from the free group on \(k\) generators to \(G\) sending the \(i\)-th generator to \(g_i\), the group \(G\) is recursively presented with respect to \(\varphi\) and the word problem for \(\varphi\) is not solvable. In words: there is a finitely generated, recursively presented, soluble right-orderable group with insoluble word problem.

    def solubleRightOrderableInsolubleWordProblem : Prop :=
  ∃ (G : Type) (_ : Group G), Group.IsSolvable G ∧ (rightOrders G).Nonempty ∧
    ∃ (k : ℕ) (gens : Fin k → G), Subgroup.closure (Set.range gens) = ⊤ ∧
      IsRecursivelyPresented (FreeGroup.lift gens) ∧ ¬ WordProblemSolvable (FreeGroup.lift gens)
