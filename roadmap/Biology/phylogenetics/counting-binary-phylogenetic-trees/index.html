    MathlibExt.Biology.Phylogenetics.TreeCount.PlaneTree.Swap

    One swap: exchange the two children of one internal vertex (anywhere in the tree).

    inductive Swap : PlaneTree α → PlaneTree α → Prop
  /-- Exchange the children of the root. -/
  | root (l r : PlaneTree α) : Swap (node l r) (node r l)
  /-- Swap inside the left subtree. -/
  | left {l l' : PlaneTree α} (r : PlaneTree α) : Swap l l' → Swap (node l r) (node l' r)
  /-- Swap inside the right subtree. -/
  | right (l : PlaneTree α) {r r' : PlaneTree α} : Swap r r' → Swap (node l r) (node l r')

    MathlibExt.Biology.Phylogenetics.TreeCount.nat_card_rootedBinaryTree

    On n ≥ 1 labeled taxa there are (2 n - 3)‼ = 1 · 3 · 5 ⋯ (2 n - 3) rooted binary phylogenetic trees (1 tree for n = 1 and n = 2, 3 for n = 3, 15 for n = 4).     DefinitionBinary hierarchy on a finite set#✓fully proved

    MathlibExt.Biology.Phylogenetics.UnrootedTreeCount.IsBinaryHierarchy

    A binary hierarchy on a finite set S: a family of nonempty subsets of S containing S and every singleton, any two members nested or disjoint, and every member with at least two elements the disjoint union of two members. These are the cluster systems of the rooted binary phylogenetic trees on S (Semple & Steel 2003, Section 3.1).

    def IsBinaryHierarchy {α : Type*} [DecidableEq α] (S : Finset α) (H : Finset (Finset α)) :
    Prop :=
  S ∈ H ∧ (∀ C ∈ H, C.Nonempty ∧ C ⊆ S) ∧ (∀ x ∈ S, {x} ∈ H) ∧
    (∀ C ∈ H, ∀ D ∈ H, C ⊆ D ∨ D ⊆ C ∨ Disjoint C D) ∧
    ∀ C ∈ H, 1 < C.card → ∃ D₁ ∈ H, ∃ D₂ ∈ H, Disjoint D₁ D₂ ∧ D₁ ∪ D₂ = C
