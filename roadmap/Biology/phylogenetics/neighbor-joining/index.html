    DefinitionCluster dissimilarity after a neighbor-joining step#✓fully proved

    Cslib.Bioinformatics.Phylogenetics.NeighborJoining.joinDist

    The cluster dissimilarity after joining a and b: the new cluster a ∪ b is at (D a c + D b c - D a b) / 2 from every other cluster c, and at 0 from itself; other values are unchanged.

    noncomputable def joinDist (D : Finset X → Finset X → ℝ) (a b : Finset X) (u v : Finset X) : ℝ :=
  if u = a ∪ b then (if v = a ∪ b then 0 else (D a v + D b v - D a b) / 2)
  else if v = a ∪ b then (D a u + D b u - D a b) / 2 else D u v

    InductiveRuns of neighbor joining#✓fully proved

    Cslib.Bioinformatics.Phylogenetics.NeighborJoining.NJRun

    NJRun d S D C: some run of neighbor joining on the dissimilarity d reaches the cluster set S with cluster dissimilarity D, having formed the clusters in C. A join is allowed while at least four clusters remain, for any pair of distinct clusters minimizing qCriterion.

    inductive NJRun [Fintype X] (d : X → X → ℝ) :
    Finset (Finset X) → (Finset X → Finset X → ℝ) → Finset (Finset X) → Prop
  /-- The run starts from the singletons, with no cluster formed. -/
  | init : NJRun d (Finset.univ.image fun x => {x}) (initialDist d) ∅
  /-- Join a pair of distinct clusters minimizing the Q-criterion. -/
  | join {S : Finset (Finset X)} {D : Finset X → Finset X → ℝ} {C : Finset (Finset X)}
      {a b : Finset X} :
      NJRun d S D C → 4 ≤ S.card → a ∈ S → b ∈ S → a ≠ b →
      (∀ a' ∈ S, ∀ b' ∈ S, a' ≠ b' → qCriterion S D a b ≤ qCriterion S D a' b') →
      NJRun d (insert (a ∪ b) ((S.erase a).erase b)) (joinDist D a b) (insert (a ∪ b) C)
    def initialDist (d : X → X → ℝ) (u v : Finset X) : ℝ :=
  ∑ x ∈ u, ∑ y ∈ v, d x y
