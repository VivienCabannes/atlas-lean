    Cslib.Bioinformatics.Phylogenetics.NeighborJoiningBME.cherryCoeff

    The generalized Pauplin coefficient of the pair of clusters u, v in the tree T_ab obtained from the star on S by joining a and b: 1/2 for {a, b}; 1/(2(|S| - 2)) when one of u, v is a or b and the other is not; 1/(|S| - 2) when neither is. Values on the diagonal u = v are never used.

    noncomputable def cherryCoeff (S : Finset (Finset X)) (a b u v : Finset X) : ℝ :=
  if (u = a ∧ v = b) ∨ (u = b ∧ v = a) then 1 / 2
  else if u = a ∨ u = b ∨ v = a ∨ v = b then 1 / (2 * ((S.card : ℝ) - 2))
  else 1 / ((S.card : ℝ) - 2)

    DefinitionBalanced minimum-evolution length of a cherry tree#✓fully proved

    Cslib.Bioinformatics.Phylogenetics.NeighborJoiningBME.cherryLength

    The balanced minimum-evolution length of T_ab for the dissimilarity D: half the sum over ordered pairs of distinct clusters of cherryCoeff S a b u v * D u v, which is ∑_{u<v} cherryCoeff S a b u v * D u v when D is symmetric.

    noncomputable def cherryLength (S : Finset (Finset X)) (D : Finset X → Finset X → ℝ)
    (a b : Finset X) : ℝ :=
  (∑ p ∈ S.offDiag, cherryCoeff S a b p.1 p.2 * D p.1 p.2) / 2
    noncomputable def cherryCoeff (S : Finset (Finset X)) (a b u v : Finset X) : ℝ :=
  if (u = a ∧ v = b) ∨ (u = b ∧ v = a) then 1 / 2
  else if u = a ∨ u = b ∨ v = a ∨ v = b then 1 / (2 * ((S.card : ℝ) - 2))
  else 1 / ((S.card : ℝ) - 2)

    Cslib.Bioinformatics.Phylogenetics.NeighborJoiningBME.NJRun.symm_diag

    Along a run of neighbor joining on a symmetric d with zero diagonal, the cluster dissimilarity stays symmetric and vanishes on every current cluster.

    theorem NJRun.symm_diag [Fintype X] {d : X → X → ℝ} (hsymm : ∀ x y, d x y = d y x)
    (hdiag : ∀ x, d x x = 0) {S : Finset (Finset X)} {D : Finset X → Finset X → ℝ}
    {C : Finset (Finset X)} (hrun : NJRun d S D C) :
    (∀ u v, D u v = D v u) ∧ ∀ u ∈ S, D u u = 0
    inductive NJRun [Fintype X] (d : X → X → ℝ) :
    Finset (Finset X) → (Finset X → Finset X → ℝ) → Finset (Finset X) → Prop
  /-- The run starts from the singletons, with no cluster formed. -/
  | init : NJRun d (Finset.univ.image fun x => {x}) (initialDist d) ∅
  /-- Join a pair of distinct clusters minimizing the Q-criterion. -/
  | join {S : Finset (Finset X)} {D : Finset X → Finset X → ℝ} {C : Finset (Finset X)}
      {a b : Finset X} :
      NJRun d S D C → 4 ≤ S.card → a ∈ S → b ∈ S → a ≠ b →
      (∀ a' ∈ S, ∀ b' ∈ S, a' ≠ b' → qCriterion S D a b ≤ qCriterion S D a' b') →
      NJRun d (insert (a ∪ b) ((S.erase a).erase b)) (joinDist D a b) (insert (a ∪ b) C)

    At every state of a run on a symmetric dissimilarity with zero diagonal and at least three clusters, a pair of distinct clusters minimizes the Q-criterion (the pairs NJ may join) if and only if joining it gives the smallest cherryLength, the BME length of the join tree T_ab on the current clusters for the current cluster dissimilarity D.     Cslib.Bioinformatics.Phylogenetics.NeighborJoiningBME.cherryLength_eq_length

    Let T_ab carry real edge lengths: ℓ c on the pendant edge of each cluster c ∈ S and m on the edge between u and the center. If D is its path-length dissimilarity (D a b = ℓ a + ℓ b, D x c = ℓ x + m + ℓ c for x ∈ {a, b} and c another cluster, D c c' = ℓ c + ℓ c' for two other distinct clusters), then cherryLength S D a b = ∑_{c ∈ S} ℓ c + m.

    theorem cherryLength_eq_length (S : Finset (Finset X)) (hS : 3 ≤ S.card) {a b : Finset X}
    (ha : a ∈ S) (hb : b ∈ S) (hab : a ≠ b) (ℓ : Finset X → ℝ) (m : ℝ)
    (D : Finset X → Finset X → ℝ)
    (hD : ∀ u ∈ S, ∀ v ∈ S, u ≠ v → D u v =
      if (u = a ∨ u = b) ∧ (v = a ∨ v = b) then ℓ u + ℓ v
      else if u = a ∨ u = b ∨ v = a ∨ v = b then ℓ u + m + ℓ v
      else ℓ u + ℓ v) :
    cherryLength S D a b = ∑ c ∈ S, ℓ c + m
