    DefinitionMax-product pruning recursion#✓fully proved

    Cslib.Bioinformatics.Phylogenetics.AncestralReconstruction.maxPrune

    The max-product (Viterbi) form of Felsenstein's pruning recursion: the largest weight of a labeling of the subtree t given state s at its root.

    def maxPrune : Tree L S R → S → R
  | leaf l, s => obs l s
  | node P l Q r, s =>
    (univ.sup' univ_nonempty fun a => P s a * maxPrune l a) *
      (univ.sup' univ_nonempty fun b => Q s b * maxPrune r b)

    DefinitionPupko's traceback#✓fully proved

    Cslib.Bioinformatics.Phylogenetics.AncestralReconstruction.traceback

    Pupko's traceback: given the state s of the root of t, label each child with a state maximizing the transition weight times the child's maxPrune, and recurse.

    noncomputable def traceback : (t : Tree L S R) → S → Labeling t
  | leaf _, _ => PUnit.unit
  | node P l Q r, s =>
    let a := argmaxState fun a => P s a * maxPrune obs l a
    let b := argmaxState fun b => Q s b * maxPrune obs r b
