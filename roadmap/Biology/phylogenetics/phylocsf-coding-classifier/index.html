    Cslib.Bioinformatics.Phylogenetics.PhyloCSF.score

    The PhyloCSF score (natural-log scale): the sum over the columns of the log-likelihood ratio of the coding model (tC, πC) against the non-coding model (tN, πN). The published PhyloCSF score is reported in decibans; see score_decibans for the conversion. Thresholds for this score are in natural-log units.

    noncomputable def score (tC : Tree L S ℝ) (πC : S → ℝ) (tN : Tree L S ℝ) (πN : S → ℝ)

    TheoremPhyloCSF's score threshold test is most powerful for unnormalized weights#✓fully proved

    Cslib.Bioinformatics.Phylogenetics.PhyloCSF.weighted_power_le_scoreTest

    With positive site likelihoods under both models, a randomized test φ whose weighted size under the non-coding weights is at most that of scoreTest c has at most its weighted power under the coding weights. This is the dominated Neyman–Pearson inequality for the unnormalized alignment weights alignLik; it becomes a statement about statistical size and power only under additional normalization hypotheses (∑ A, alignLik = 1 for each model).

    theorem weighted_power_le_scoreTest {tC tN : Tree L S ℝ} {πC πN : S → ℝ}
    (hC : ∀ col, 0 < siteLik tC πC col) (hN : ∀ col, 0 < siteLik tN πN col) (c : ℝ)
    (φ : (Fin m → L → S) → Set.Icc (0 : ℝ) 1)
    (hsize : ∑ A, (φ A).val * alignLik tN πN A ≤
      ∑ A : Fin m → L → S, (scoreTest tC πC tN πN c A).val * alignLik tN πN A) :
    ∑ A, (φ A).val * alignLik tC πC A ≤
      ∑ A : Fin m → L → S, (scoreTest tC πC tN πN c A).val * alignLik tC πC A
