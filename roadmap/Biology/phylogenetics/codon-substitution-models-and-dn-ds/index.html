    MathlibExt.Biology.Phylogenetics.CodonModel.gyExchange

    The Goldman–Yang exchangeability between codons i and j: 0 unless they differ at one position; otherwise κ for a transition (1 for a transversion), times ω if the amino acid changes.

    def gyExchange (nuc : ι → Codon) (aa : ι → α) (κ ω : ℝ) : Matrix ι ι ℝ :=
  Matrix.of fun i j =>
    if IsSingleChange (nuc i) (nuc j) then
      (if IsTransitionChange (nuc i) (nuc j) then κ else 1) * (if aa i = aa j then 1 else ω)
    else 0
