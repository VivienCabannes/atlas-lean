    The selection step of Atteson's theorem (Atteson 1999), with a proof after Mihaescu, Levy & Pachter (2009, Theorem 16). Let A e (e : E) be a compatible binary system of splits with positive weights w, containing every trivial split and closed under complement, on at least four taxa, and let d x y be half the total weight of the indices whose side separates x and y. Let μ be a lower bound on the weight of every internal split (both sides with at least two taxa). If D is symmetric, vanishes on the diagonal, and |D x y - d x y| < μ / 2 for all distinct x, y, then a pair of distinct taxa minimizing the Q-criterion (|X| - 2) D x y - ∑_z D x z - ∑_z D y z is a side of the split system.

    The selection step of Atteson's theorem (Atteson 1999), with a proof after Mihaescu, Levy & Pachter (2009, Theorem 16). Let d be the path-length metric of a binary phylogenetic X-tree (G, ι) with positive edge lengths w and at least four taxa, and let μ be a lower bound on the lengths of the internal edges (edges with no taxon at either end). Let D be a symmetric dissimilarity with zero diagonal such that |D x y - d x y| < μ / 2 for all distinct taxa. If the distinct taxa x, y minimize the Q-criterion of D over all pairs of distinct singleton clusters at the start of neighbor joining, then ι x and ι y have a common neighbor: they form a cherry. The bound is sharp: with ≤ μ / 2 a non-cherry can tie (see the tests).

    TheoremNeighbor joining averages up to row shifts#✓fully proved

    Cslib.Bioinformatics.Phylogenetics.NeighborJoining.NJRun.exists_avg

    Along every run of neighbor joining on a symmetric dissimilarity d with zero diagonal there are weights α s (nonnegative, supported on s, summing to 1) and row terms κ s such that the cluster dissimilarity vanishes on the diagonal and D s t = ∑ x, ∑ y, α s x * α t y * d x y - κ s - κ t for distinct current clusters. Joining a, b takes α (a ∪ b) = (α a + α b) / 2 and κ (a ∪ b) = (κ a + κ b + D a b) / 2.

    theorem NJRun.exists_avg {d : X → X → ℝ} (hsymm : ∀ x y, d x y = d y x)
    (h0 : ∀ x, d x x = 0) {S : Finset (Finset X)} {D : Finset X → Finset X → ℝ}
    {C : Finset (Finset X)} (hrun : NJRun d S D C) :
    ∃ (α : Finset X → X → ℝ) (κ : Finset X → ℝ),
      (∀ s ∈ S, ∀ x, 0 ≤ α s x) ∧ (∀ s ∈ S, ∀ x, x ∉ s → α s x = 0) ∧
      (∀ s ∈ S, ∑ x, α s x = 1) ∧ (∀ s ∈ S, D s s = 0) ∧
      ∀ s ∈ S, ∀ t ∈ S, s ≠ t → D s t = ∑ x, ∑ y, α s x * α t y * d x y - κ s - κ t
    inductive NJRun [Fintype X] (d : X → X → ℝ) :
    Finset (Finset X) → (Finset X → Finset X → ℝ) → Finset (Finset X) → Prop
  /-- The run starts from the singletons, with no cluster formed. -/
  | init : NJRun d (Finset.univ.image fun x => {x}) (initialDist d) ∅
  /-- Join a pair of distinct clusters minimizing the Q-criterion. -/
  | join {S : Finset (Finset X)} {D : Finset X → Finset X → ℝ} {C : Finset (Finset X)}
      {a b : Finset X} :
      NJRun d S D C → 4 ≤ S.card → a ∈ S → b ∈ S → a ≠ b →
      (∀ a' ∈ S, ∀ b' ∈ S, a' ≠ b' → qCriterion S D a b ≤ qCriterion S D a' b') →
      NJRun d (insert (a ∪ b) ((S.erase a).erase b)) (joinDist D a b) (insert (a ∪ b) C)

    Cslib.Bioinformatics.Phylogenetics.NeighborJoining.qCriterion_eq_sub_of_shift

    The shifting lemma (Mihaescu, Levy & Pachter 2009, Lemma 4): if D' agrees with D on the diagonal of S and D' s t = D s t + f s + f t for distinct s, t ∈ S, then the Q-criterion of every pair of distinct clusters drops by the same amount 2 ∑_{c ∈ S} f c, so both have the same minimizing pairs.

    theorem qCriterion_eq_sub_of_shift (S : Finset (Finset X)) {D D' : Finset X → Finset X → ℝ}
    (f : Finset X → ℝ) (hdiag : ∀ s ∈ S, D' s s = D s s)
    (hoff : ∀ s ∈ S, ∀ t ∈ S, s ≠ t → D' s t = D s t + f s + f t) {a b : Finset X}
    (ha : a ∈ S) (hb : b ∈ S) (hab : a ≠ b) :
    qCriterion S D' a b = qCriterion S D a b - 2 * ∑ c ∈ S, f c

    TheoremAtteson's theorem: neighbor joining has ℓ∞ radius 1/2#✓fully proved

    Cslib.Bioinformatics.Phylogenetics.NeighborJoining.njRun_splits_of_abs_sub_lt

    Atteson's theorem: neighbor joining has ℓ∞ radius 1/2 (Atteson 1999). Let d be the path-length metric of a binary phylogenetic X-tree (G, ι) with positive edge lengths w, let μ be a lower bound on the lengths of its internal edges (edges with no taxon at either end), and let D be a symmetric dissimilarity with zero diagonal such that |D x y - d x y| < μ / 2 for all distinct taxa. Then every complete run of neighbor joining on D (stopped with at most three clusters) forms exactly the splits of the internal edges of the tree: a set of taxa A or its complement is a formed cluster if and only if A is the set of taxa on the a-side of an edge {a, b} with both endpoints internal.

    {D : X → X → ℝ} (hDsymm : ∀ x y, D x y = D y x) (hD0 : ∀ x, D x x = 0)
    (hDd : ∀ x y, x ≠ y → |D x y - d x y| < μ / 2)
