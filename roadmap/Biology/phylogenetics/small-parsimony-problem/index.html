    Cslib.Bioinformatics.Phylogenetics.Parsimony.edgeCost

    The total substitution cost of a labeling x of the non-root vertices of t with root state s: the sum over all edges of the cost untrop (P a b) from the parent's state a to the child's state b.

    TheoremSankoff's recursion at an internal vertex#✓fully proved

    Cslib.Bioinformatics.Phylogenetics.Parsimony.sankoff_node

    Sankoff's recursion at an internal vertex: the cost of state s is the sum, over the two children, of the minimum over the child's state a of the edge cost from s to a plus the child's cost at a.

    theorem sankoff_node (σ : L → S) (P Q : S → S → Cost) (l r : Tree L S Cost) (s : S) :
    sankoff σ (node P l Q r) s =
      Finset.univ.inf (fun a => untrop (P s a) + sankoff σ l a) +
        Finset.univ.inf (fun b => untrop (Q s b) + sankoff σ r b)

    DefinitionFitch's algorithm#✓fully proved

    Cslib.Bioinformatics.Phylogenetics.Parsimony.fitch

    The set of candidate states at the root of the subtree and the number of changes counted so far. The edge weights of the tree are ignored. Each child is evaluated once per node, so the recursion makes one call per vertex.

    def fitch {R : Type w} (σ : L → S) : Tree L S R → Finset S × ℕ
  | leaf l => ({σ l}, 0)
  | node _ l _ r =>
    let a := fitch σ l
    let b := fitch σ r
    if (a.1 ∩ b.1).Nonempty then (a.1 ∩ b.1, a.2 + b.2) else (a.1 ∪ b.1, a.2 + b.2 + 1)
    inductive Tree (L : Type u) (S : Type v) (R : Type w) where
