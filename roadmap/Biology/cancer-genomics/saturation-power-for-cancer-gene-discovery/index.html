    MathlibExt.Biology.CancerGenomics.SaturationPower.saturationPower

    Power of the one-sided binomial test of Lawrence et al. (2014): the probability, when each of N patients is mutated with probability p₁, of observing a count x whose background p-value ℙ_{p₀}(X ≥ x) is at most γ.

    noncomputable def saturationPower (N : ℕ) (p₀ p₁ γ : ℝ) : ℝ :=
  ∑ x ∈ range (N + 1) with upperTail N p₀ x ≤ γ, binomPmf N p₁ x
    def upperTail (n : ℕ) (p : ℝ) (m : ℕ) : ℝ := ∑ i ∈ Ico m (n + 1), binomPmf n p i
