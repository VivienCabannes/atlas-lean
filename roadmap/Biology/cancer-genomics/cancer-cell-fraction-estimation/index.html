    If the kernels L (data x) and L' (data x') satisfy the TP2 inequality L' i L j ≥ L i L' j whenever c j ≤ c i, then for a nonnegative prior every posterior tail P(c > t) is at least as large under L' as under L (both normalizers positive).

    (hZ : 0 < ∑ i, prior i * L i) (hZ' : 0 < ∑ i, prior i * L' i) :
    tailRatio prior L c t ≤ tailRatio prior L' c t

    TheoremThe binomial family is TP2#✓fully proved

    MathlibExt.Biology.CancerGenomics.CancerCellFraction.binomPmf_mul_le_mul

    The binomial family is TP2 (monotone likelihood ratio in the success probability): for a ≤ a' and 0 ≤ p ≤ p' ≤ 1, Binom(a | n, p') Binom(a' | n, p) ≤ Binom(a' | n, p') Binom(a | n, p).

    theorem binomPmf_mul_le_mul {n a a' : ℕ} {p p' : ℝ} (haa' : a ≤ a') (hp0 : 0 ≤ p)
    (hpp' : p ≤ p') (hp1 : p' ≤ 1) :
    binomPmf n p' a * binomPmf n p a' ≤ binomPmf n p' a' * binomPmf n p a
    def binomPmf (n : ℕ) (p : ℝ) (i : ℕ) : ℝ := (n.choose i : ℝ) * p ^ i * (1 - p) ^ (n - i)
