    TheoremLeast squares (Fisher 1918)#✓fully proved

    MathlibExt.Biology.StatisticalGenetics.FisherDecomposition.domVar_le_sum_sq

    Among all fits c + a i + a j of the genotypic value by a function additive over the two genes, the additive fitted genotypic value μ + α i + α j minimizes the weighted squared error ∑ p i p j (G i j - c - a i - a j) ²; its error is V_D.

    theorem domVar_le_sum_sq {p : A → ℝ} (hp0 : ∀ i, 0 ≤ p i) (hp : ∑ i, p i = 1)
    {G : A → A → ℝ} (hG : ∀ i j, G i j = G j i) (c : ℝ) (a : A → ℝ) :
    domVar p G ≤ ∑ i, ∑ j, p i * p j * (G i j - c - a i - a j) ^ 2
