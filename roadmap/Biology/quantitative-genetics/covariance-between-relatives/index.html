    TheoremCovariance between relatives#✓fully proved

    MathlibExt.Biology.StatisticalGenetics.CovarianceRelatives.LocusModel.relCov_eq

    Covariance between relatives at one locus (Fisher 1918; in the IBD form of Falconer and Mackay ch. 9): for IBD probabilities summing to one, E[G_X G_Y] - μ² = (k₁ / 2 + k₂) V_A + k₂ V_D, i.e. 2φ V_A + Δ V_D with kinship φ = k₁ / 4 + k₂ / 2 and Δ = k₂.

    m.relProd k₀ k₁ k₂ - m.mean ^ 2 = (k₁ / 2 + k₂) * m.varA + k₂ * m.varD

    StructureCockerham–Kempthorne variance components#✓fully proved

    MathlibExt.Biology.StatisticalGenetics.CovarianceRelatives.CockerhamComponents

    Cockerham–Kempthorne variance components up to order n: V i j = V_{A^i D^j} is the component of i additive and j dominance factors (V 1 0 = V_A, V 0 1 = V_D, V 2 0 = V_AA, …). They are nonnegative, there is no (0, 0) component, and the genetic covariance of relatives with 2φ and Δ is ∑_{i, j ≤ n} (2φ)^i Δ^j V i j. This structure is the stated representation; it is proved for one locus by LocusModel.relCov_eq.

    structure CockerhamComponents where
  /-- Highest order kept. -/
  n : ℕ
  /-- The components `V_{A^i D^j}`. -/
  V : ℕ → ℕ → ℝ
  V_nonneg : ∀ i j, 0 ≤ V i j
  V_zero_zero : V 0 0 = 0
  /-- Finite support: components above order `n` vanish. `V` is total only as a function;
  there are no unconstrained ignored components outside the summation range of `cov`, which
  sums exactly over `i, j ≤ n`. -/
  V_supported : ∀ i j, n < i ∨ n < j → V i j = 0
      V : ℕ → ℕ → ℝ
