    Pedigree kinship and inbreeding

    StructurePedigree#✓fully proved

    MathlibExt.Biology.StatisticalGenetics.Kinship.Pedigree

    A pedigree on the individuals Fin n, numbered so that parents precede their children (every finite pedigree, a finite DAG, has such a numbering). parents i = some g means that g 0 is the father and g 1 the mother of i; parents i = none means that i is a founder. Founders are unrelated and not inbred (their 2 n_F gene copies are distinct).

    structure Pedigree (n : ℕ) where
  /-- The parents `(g 0, g 1)` = (father, mother) of a non-founder; `none` for a founder. -/
  parents : Fin n → Option (Fin 2 → Fin n)
  /-- Parents precede their children. -/
  parents_lt : ∀ i g, parents i = some g → ∀ k, g k < i
      parents : Fin n → Option (Fin 2 → Fin n)

    Malécot's recursion (the tabular method)

    DefinitionKinship coefficient by Malécot's recursion#✓fully proved

    MathlibExt.Biology.StatisticalGenetics.Kinship.Pedigree.kinship

    The kinship coefficient by Malécot's recursion, computed in the order of the numbering (the tabular method): for i < j, φ i j = (φ i f + φ i m) / 2 with f, m the parents of j and φ i j = 0 if j is a founder; φ i i = (1 + φ f m) / 2 with f, m the parents of i and φ i i = 1 / 2 for a founder; symmetric for j < i.

    MathlibExt.Biology.StatisticalGenetics.Kinship.Pedigree.kinship · 20 lines 
    noncomputable def kinship (i j : Fin n) : ℝ :=
  if _hji : j < i then
    match h : P.parents i with
    | none => 0
    | some g => (kinship (g 0) j + kinship (g 1) j) / 2
  else if _hij : i < j then
    match h : P.parents j with
    | none => 0
    | some g => (kinship i (g 0) + kinship i (g 1)) / 2
  else
    match h : P.parents i with
    | none => 1 / 2
    | some g => (1 + kinship (g 0) (g 1)) / 2
termination_by i.val + j.val

  all_goals
    have h0 := P.parents_lt _ g h 0
    have h1 := P.parents_lt _ g h 1
