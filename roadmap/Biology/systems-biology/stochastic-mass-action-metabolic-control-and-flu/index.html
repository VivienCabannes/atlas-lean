    TheoremGlobal balance of the product-form Poisson weights#✓fully proved

    MathlibExt.Biology.Dynamics.SystemsBiology.poissonWeight_mul_sum_propensity

    Global balance of the product-form Poisson weights (Anderson, Craciun & Kurtz 2010, Thm 4.1): if c is complex balanced for the deterministic mass-action system with rate constants k, then at every state x the total outflow π(x) ∑_r λ_r(x) equals the total inflow ∑_{r : prod r ≤ x} π(x - prod r + src r) λ_r(x - prod r + src r) for π = poissonWeight c. This is an algebraic identity valid for all real k and c.

    theorem poissonWeight_mul_sum_propensity {k : ρ → ℝ} {c : S → ℝ}
    (hcb : N.IsComplexBalanced k c) (x : S → ℕ) :
    poissonWeight c x * ∑ r, propensity N k r x =
      ∑ r ∈ univ.filter (fun r => N.prod r ≤ x),
        poissonWeight c (unfire N r x) * propensity N k r (unfire N r x)
