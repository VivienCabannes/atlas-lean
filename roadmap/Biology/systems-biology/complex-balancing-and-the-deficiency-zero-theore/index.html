    DefinitionComplex-balanced concentrations#✓fully proved

    MathlibExt.Biology.Dynamics.ComplexBalanced.ReactionNetwork.IsComplexBalanced

    Concentrations c are complex balanced for the rate constants k: at every complex z, the total rate of the reactions with source z equals the total rate of the reactions with product z. (Complexes that occur in no reaction give 0 = 0.)

    def IsComplexBalanced [Fintype S] [Fintype ρ] (k : ρ → ℝ) (c : S → ℝ) : Prop :=
  ∀ z : S → ℕ, ∑ r ∈ univ.filter (fun r => N.src r = z), N.rate k c r =
    ∑ r ∈ univ.filter (fun r => N.prod r = z), N.rate k c r

    DefinitionPseudo-Helmholtz function#✓fully proved

    MathlibExt.Biology.Dynamics.ComplexBalanced.ReactionNetwork.pseudoHelmholtz

    The pseudo-Helmholtz function G(c) = ∑_s c_s (log c_s - log c*_s - 1) relative to the reference concentrations cstar (Horn & Jackson 1972). It is meaningful for positive c and cstar; elsewhere Real.log takes junk values.

    noncomputable def pseudoHelmholtz [Fintype S] (cstar c : S → ℝ) : ℝ :=
  ∑ s, c s * (Real.log (c s) - Real.log (cstar s) - 1)

    MathlibExt.Biology.Dynamics.ComplexBalanced.ReactionNetwork.positiveEquilibria_eq

    If c* is a positive complex-balanced equilibrium for positive rate constants, the positive equilibria are exactly the positive c whose log c - log c* is orthogonal (for the dot product) to the stoichiometric subspace. Source: Horn & Jackson (1972); Feinberg (2019), ch. 15.

    theorem positiveEquilibria_eq [Fintype S] [Fintype ρ] {k : ρ → ℝ} (hk : ∀ r, 0 < k r)
    {cstar : S → ℝ} (hcstar : ∀ s, 0 < cstar s) (hcb : N.IsComplexBalanced k cstar) :
    {c : S → ℝ | (∀ s, 0 < c s) ∧ N.massActionField k c = 0} =
      {c | (∀ s, 0 < c s) ∧ ∀ v ∈ N.stoichiometricSubspace,
        (fun s => Real.log (c s) - Real.log (cstar s)) ⬝ᵥ v = 0}
