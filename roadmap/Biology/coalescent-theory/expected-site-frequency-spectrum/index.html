    DefinitionRandom-joining law on block-size lists#✓fully proved

    MathlibExt.Biology.PopulationGenetics.Coalescent.SiteFrequencySpectrum.randomJoining

    The random-joining law: randomJoining m b ps is the probability that m steps of random joining started from the block-size list b visit the list of block-size lists ps (starting with b itself). Each step merges a pair of blocks chosen uniformly among all pairs; the process stops once fewer than two blocks remain.

    noncomputable def randomJoining : ℕ → List ℕ → List (List ℕ) → ℝ
  | 0, b, ps => if ps = [b] then 1 else 0
  | m + 1, b, ps =>
    if (blockPairs b.length).card = 0 then (if ps = [b] then 1 else 0)
    else match ps with
      | [] => 0
      | b' :: rest =>
        if b' = b then
          (∑ p ∈ blockPairs b.length, randomJoining m (mergeBlocks b p.1 p.2) rest) /
            (blockPairs b.length).card
        else 0
    def blockPairs (k : ℕ) : Finset (ℕ × ℕ) :=
  (range k ×ˢ range k).filter fun p => p.1 < p.2

    MathlibExt.Biology.PopulationGenetics.Coalescent.SiteFrequencySpectrum.joinStep

    The transition operator of random joining acting on a statistic g of block-size lists: the average of g over the lists obtained from b by merging a uniformly chosen pair of blocks (g [] once fewer than two blocks remain).     MathlibExt.Biology.PopulationGenetics.Coalescent.SiteFrequencySpectrum.exists_finset_randomJoining

    The random-joining law has finite support, and the expectation of a statistic of the j-th visited list (j ≤ m) is the j-th iterate of joinStep.

    theorem exists_finset_randomJoining (m : ℕ) (b : List ℕ) :
    ∃ F : Finset (List (List ℕ)), (∀ ps ∉ F, randomJoining m b ps = 0) ∧
      ∀ j ≤ m, ∀ g : List ℕ → ℝ,
        ∑ ps ∈ F, randomJoining m b ps * g (ps.getD j []) = (joinStep^[j] g) b

    Expected number of blocks of size i when k blocks remain, for random joining started from n singletons: k · C(n-i-1, k-2) / C(n-1, k-1) (Fu 1995; Griffiths–Tavaré 1998). Equivalently, a given one of the k blocks has size i with probability C(n-i-1, k-2) / C(n-1, k-1).

    The expected site frequency spectrum

    TheoremExpected site frequency spectrum#✓fully proved

    MathlibExt.Biology.PopulationGenetics.Coalescent.SiteFrequencySpectrum.integral_sfs

    Expected site frequency spectrum (Fu 1995). Let the genealogy of a sample of n gene copies consist of Kingman holding times K.T and an independent block-size history τ with the random-joining law. If, given the genealogy (the σ-algebra generated by τ and the holding times), the number ξ i of sites whose derived allele is carried by exactly i copies is integrable and has conditional mean (θ / 2) L_i (neutral infinite-sites mutation, θ = 4Nu), then E ξ_i = θ / i for 1 ≤ i ≤ n - 1. (Integrability matters: Mathlib's conditional expectation of a non-integrable function is 0.)

    theorem integral_sfs {μ : Measure Ω} [IsProbabilityMeasure μ] {n : ℕ}
    (K : KingmanTimes μ n) (hT : ∀ k, Measurable (K.T k))
    {τ : Ω → List (List ℕ)} (hτ : MeasurableSpace.comap τ ⊤ ≤ mΩ)
    (hτ_law : ∀ ps, μ.real (τ ⁻¹' {ps}) =
      randomJoining (n - 1) (List.replicate n 1) ps)
    (h_indep : Indep (MeasurableSpace.comap τ ⊤)
      (MeasurableSpace.comap (fun ω k => K.T k ω) MeasurableSpace.pi) μ)
    {θ : ℝ} {ξ : ℕ → Ω → ℝ} (hξ_int : ∀ i, Integrable (ξ i) μ)
    (hξ : ∀ i, μ[ξ i | MeasurableSpace.comap τ ⊤ ⊔
        MeasurableSpace.comap (fun ω k => K.T k ω) MeasurableSpace.pi] =ᵐ[μ]
      fun ω => θ / 2 * sfsLength n i (τ ω) (fun k => K.T k ω))
    {i : ℕ} (hi : 1 ≤ i) (hin : i < n) :
    μ[ξ i] = θ / i
    structure KingmanTimes (μ : Measure Ω) (n : ℕ) where
  /-- `T k` is the holding time while the genealogy has `k` lineages. -/
  T : ℕ → Ω → ℝ
  /-- `T k` is exponential with rate `k.choose 2`, the number of pairs of lineages. -/
  hasLaw : ∀ k ∈ Icc 2 n, HasLaw (T k) (expMeasure (k.choose 2 : ℕ)) μ
  /-- The holding times are mutually independent. -/
  indep : iIndepFun (fun k : Icc 2 n => T k) μ
