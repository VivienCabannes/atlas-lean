    Cslib.Bioinformatics.PopulationGenetics.HudsonKaplan.IsDisjointFamily

    A family F of site pairs (i, j) consists of four-gamete intervals (i < j, all four gametes at i and j) that are pairwise disjoint: of two distinct intervals, one ends at or before the start of the other, so no breakpoint separates both.

    DefinitionOne step of the Hudson–Kaplan sweep#✓fully proved

    Cslib.Bioinformatics.PopulationGenetics.HudsonKaplan.sweepStep

    One step of the sweep at right endpoint j. The list acc holds the intervals kept so far, most recent first; the next interval must start at or after the right end of the most recent one (at or after site 0 if none was kept). Among the admissible four-gamete intervals ending at j, the shortest one is kept.

    def sweepStep (acc : List (Fin s × Fin s)) (j : Fin s) : List (Fin s × Fin s) :=
  let last : ℕ := (acc.head?.map fun x => (x.2 : ℕ)).getD 0
  let cands := Finset.univ.filter fun i : Fin s => last ≤ (i : ℕ) ∧ i < j ∧ FourGametes M i j
  if h : cands.Nonempty then (cands.max' h, j) :: acc else acc
