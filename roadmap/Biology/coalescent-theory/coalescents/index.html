    DefinitionPitman's merger rate#✓fully proved

    MathlibExt.Biology.PopulationGenetics.Coalescent.LambdaCoalescent.mergerRate

    Pitman's merger rate λ_{b,k} = ∫ x ^ (k - 2) (1 - x) ^ (b - k) Λ(dx): while there are b blocks, the rate at which a given set of k of them merges into one block, for 2 ≤ k ≤ b (Pitman 1999, Theorem 1; Sagitov 1999). Powers are natural-number powers, so 0 ^ 0 = 1. Outside 2 ≤ k ≤ b no such merger exists, and the rate is defined to be 0.

    def mergerRate [IsFiniteMeasure Λ] (b k : ℕ) : ℝ :=
  if 2 ≤ k ∧ k ≤ b then ∫ x, (x : ℝ) ^ (k - 2) * (1 - (x : ℝ)) ^ (b - k) ∂Λ else 0

    DefinitionGenerator of the Λ-coalescent block-counting process#✓fully proved

    MathlibExt.Biology.PopulationGenetics.Coalescent.LambdaCoalescent.blockCountingGenerator

    The generator of the block-counting process of the Λ-coalescent on the states 0, …, n (state b means b blocks): from b blocks the process jumps to j < b blocks at rate (b.choose (b + 1 - j)) λ_{b, b + 1 - j} (a (b + 1 - j)-merger), and the diagonal is -λ_b. States 0 and 1 are absorbing (state 0 is never reached from b ≥ 1).

    def blockCountingGenerator [IsFiniteMeasure Λ] (n : ℕ) :
    Matrix (Fin (n + 1)) (Fin (n + 1)) ℝ := fun i j =>
  if i = j then -totalMergerRate Λ i
  else if (j : ℕ) < i then ((i : ℕ).choose (i + 1 - j) : ℝ) * mergerRate Λ i (i + 1 - j)
  else 0
    def totalMergerRate [IsFiniteMeasure Λ] (b : ℕ) : ℝ :=
  ∑ k ∈ Icc 2 b, (b.choose k : ℝ) * mergerRate Λ b k

    MathlibExt.Biology.PopulationGenetics.Coalescent.LambdaCoalescent.mergerRate_consistent

    TheoremBinomial identity behind the total merger rate#✓fully proved

    MathlibExt.Biology.PopulationGenetics.Coalescent.LambdaCoalescent.sq_mul_sum_choose_mul_pow

    The polynomial identity behind the closed form of the total merger rate: x ^ 2 ∑_{k=2}^b (b.choose k) x ^ (k - 2) (1 - x) ^ (b - k) = 1 - (1 - x) ^ b - b x (1 - x) ^ (b - 1) for every real x and every b (binomial theorem).

    theorem sq_mul_sum_choose_mul_pow (x : ℝ) (b : ℕ) :
    x ^ 2 * ∑ k ∈ Icc 2 b, (b.choose k : ℝ) * (x ^ (k - 2) * (1 - x) ^ (b - k)) =
      1 - (1 - x) ^ b - b * x * (1 - x) ^ (b - 1)

    TheoremThe total merger rate in closed form#✓fully proved

    MathlibExt.Biology.PopulationGenetics.Coalescent.LambdaCoalescent.totalMergerRate_eq

    The total merger rate in closed form (Berestycki 2009, §3.1): λ_b = (b.choose 2) Λ {0} + ∫_{(0,1]} (1 - (1 - x) ^ b - b x (1 - x) ^ (b - 1)) / x ^ 2 Λ(dx). The atom at 0 (the Kingman part) is split off, so no division by 0 occurs.

    theorem totalMergerRate_eq (b : ℕ) :
    totalMergerRate Λ b = (b.choose 2 : ℝ) * Λ.real {0} +
      ∫ x in ({0}ᶜ : Set I),
        (1 - (1 - (x : ℝ)) ^ b - b * (x : ℝ) * (1 - (x : ℝ)) ^ (b - 1)) / (x : ℝ) ^ 2 ∂Λ
