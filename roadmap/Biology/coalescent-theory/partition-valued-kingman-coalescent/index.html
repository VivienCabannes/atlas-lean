    MathlibExt.Biology.PopulationGenetics.Coalescent.PartitionCoalescent.jumpMatrix

    The transition matrix of the jump chain of Kingman's coalescent: from a partition with k ≥ 2 blocks, move to each of the k.choose 2 partitions obtained by merging two blocks with probability 1 / k.choose 2; a partition with at most one block is absorbing.

    noncomputable def jumpMatrix (n : ℕ) : Matrix (SamplePartition n) (SamplePartition n) ℝ :=
  Matrix.of fun π π' =>
    if 2 ≤ #π.parts then (if IsMerge π π' then (((#π.parts).choose 2 : ℕ) : ℝ)⁻¹ else 0)
    else if π = π' then 1 else 0

    DefinitionKingman's formula#✓fully proved

    MathlibExt.Biology.PopulationGenetics.Coalescent.PartitionCoalescent.kingmanProb

    The probability (n - k)! k! (k - 1)! ∏_{B ∈ π} |B|! / (n! (n - 1)!) of a partition π with k blocks of a sample of size n (meaningful for 1 ≤ k ≤ n; for the empty sample it gives 1 to the empty partition).

    noncomputable def kingmanProb (n : ℕ) (π : SamplePartition n) : ℝ :=
  (((n - #π.parts).factorial * (#π.parts).factorial * (#π.parts - 1).factorial *

    ((n.factorial * (n - 1).factorial : ℕ) : ℝ)

    TheoremKingman's formula#✓fully proved

    MathlibExt.Biology.PopulationGenetics.Coalescent.PartitionCoalescent.jumpLaw_eq

    Kingman's formula (Kingman 1982; Durrett 2008, ch. 1). For m < n, after m coalescences the jump chain started from singletons is at a partition π with probability kingmanProb n π = (n - k)! k! (k - 1)! ∏_{B ∈ π} |B|! / (n! (n - 1)!) if π has k = n - m blocks, and 0 otherwise. (For m ≥ n - 1 the chain has been absorbed at the one-block partition.)

    theorem jumpLaw_eq {m : ℕ} (hm : m < n) (π : SamplePartition n) :
    jumpLaw n m π = if #π.parts + m = n then kingmanProb n π else 0
