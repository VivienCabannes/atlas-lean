    MathlibExt.Biology.PopulationGenetics.MultispeciesCoalescent.SpeciesTree

    A rooted binary species tree on the species Fin n with branch lengths: leaf i is species i, and node l r t is the ancestral species of the species below l and r, where t is the length, in coalescent units (2N generations), of the branch above the node, i.e. the time during which the ancestral population of l and r exists before it merges with a sister population. The length stored at the root node is not used: the root population lasts until all lineages have coalesced. Leaf branch lengths are not recorded, because one gene lineage is sampled per species and a single lineage cannot coalesce. A species tree on the species Fin n labels each species by exactly one leaf; the type does not enforce this, and the theorems below are about concrete trees with this property. The type accepts any real branch length; the probabilistic statements assume nonnegative lengths (NonnegLengths).

    MathlibExt.Biology.PopulationGenetics.MultispeciesCoalescent.branchStep

    One population of the multispecies coalescent along a branch of length t. It receives m lineages bs (and the clusters acc formed below it). Under Kingman's coalescent the number j of lineages left at the top of the branch has law tavareProb m j t (Tavaré's formula, exp_blockCountingGenerator_apply), and, independently of the coalescence times, the order of the m - j coalescences is the beginning of a random-joining history of the m lineages (randomJoining).     DefinitionThe multispecies coalescent#✓fully proved

    MathlibExt.Biology.PopulationGenetics.MultispeciesCoalescent.geneTreeProb

    The multispecies coalescent (Pamilo & Nei 1988; Degnan & Salter 2005), one lineage sampled per species: the probability that the gene tree, given by its set of clusters, lies in the event E. Below the root, each branch population runs Kingman's coalescent for the branch length (branchStep); in the root population all remaining lineages coalesce by random joining. The definition accepts any real branch lengths; it is a probability law on species trees with nonnegative branch lengths (geneTreeProb_nonneg, geneTreeProb_or, geneTreeProb_true), and only a signed weight otherwise (with internal branch -1, the matching three-species gene tree gets 1 - (2/3) e < 0).

    def geneTreeProb (T : SpeciesTree n) (E : Finset (Finset (Fin n)) → Prop) [DecidablePred E] :

  | leaf i => if E {{i}} then 1 else 0

      ∫ h, (if E (al ∪ ar ∪ cladesAlong (bl ++ br) h (ml + mr - 1)) then 1 else 0)
        ∂randomJoining (ml + mr)
