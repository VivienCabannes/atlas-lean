    Cslib.Bioinformatics.RNA.PartitionFunction.inside

    Inside recursion over a commutative semiring R: inside pair m s w i len is the weighted sum over the secondary structures supported in the interval [i, i + len) (proved in inside_eq_sum). Base i is either unpaired, or paired with i + 1 + k for some k ≥ m with CanPair pair s i (i + 1 + k), which contributes w i (i + 1 + k) times the inside values of the enclosed interval [i + 1, i + 1 + k) and of the outer interval [i + k + 2, i + len + 1).

    def inside [DecidableRel pair] {R : Type*} [CommSemiring R] (w : ℕ → ℕ → R) :
    ℕ → ℕ → R
  | _, 0 => 1
  | i, len + 1 =>
      inside w (i + 1) len +
        ∑ k : Fin len, if m ≤ k.val ∧ CanPair pair s i (i + 1 + k.val) then
          w i (i + 1 + k.val) * inside w (i + 1) k.val *
            inside w (i + k.val + 2) (len - 1 - k.val)
        else 0
  termination_by _ len => len
  decreasing_by all_goals omega

    DefinitionOutside recursion#✓fully proved

    Cslib.Bioinformatics.RNA.PartitionFunction.outside

    Outside recursion (McCaskill 1990) over a commutative semiring R, for a sequence of length n = s.length: outside pair m s w i j is the weighted sum of the parts outside the pair (i, j) of all structures containing it (proved in outside_mul_eq_sum). Either no pair encloses (i, j), leaving independent structures on [0, i) and [j + 1, n), or there is a unique innermost enclosing pair (a, b) (a < i, j < b < n), contributing the outside value of (a, b), its weight, and the inside values of [a + 1, i) and [j + 1, b).

    def outside [DecidableRel pair] {R : Type*} [CommSemiring R] (w : ℕ → ℕ → R) (i j : ℕ) : R :=
  inside pair m s w 0 i * inside pair m s w (j + 1) (s.length - (j + 1)) +
    ∑ a : Fin i, ∑ c : Fin (s.length - (j + 1)),
      if a.val + m < j + 1 + c.val ∧ CanPair pair s a.val (j + 1 + c.val) then
        outside w a.val (j + 1 + c.val) * w a.val (j + 1 + c.val) *
          inside pair m s w (a.val + 1) (i - (a.val + 1)) * inside pair m s w (j + 1) c.val
      else 0
  termination_by s.length - (j - i)
  decreasing_by omega

    Cslib.Bioinformatics.RNA.PartitionFunction.outside_mul_eq_sum

    Outside algorithm (McCaskill 1990): for a candidate pair (i, j) (i + m < j and CanPair pair s i j), the outside value times the pair's weight times the inside value of the enclosed interval [i + 1, j) sums the weights of all secondary structures containing (i, j).

    theorem outside_mul_eq_sum [DecidableRel pair] {R : Type*} [CommSemiring R]

    outside pair m s w i j * w i j * inside pair m s w (i + 1) (j - (i + 1)) =

    DefinitionWaterman's recursion#✓fully proved

    Cslib.Bioinformatics.RNA.PartitionFunction.watermanNumber

    Waterman's recursion for the number S_m(n) of secondary structures on n points with minimum hairpin m when every pair is allowed: S(0) = 1 and S(n + 1) = S(n) + ∑_{m ≤ k < n} S(k) S(n - 1 - k) (Waterman 1978; Stein–Waterman 1979). For m = 0 these are the Motzkin numbers (watermanNumber_zero_eq_motzkinNumber); for m = 1 the Stein–Waterman numbers 1, 1, 1, 2, 4, 8, 17, 37, … (OEIS A004148).

    def watermanNumber (m : ℕ) : ℕ → ℕ
  | 0 => 1
  | n + 1 =>
      watermanNumber m n +
        ∑ k : Fin n, if m ≤ k.val then
          watermanNumber m k.val * watermanNumber m (n - 1 - k.val) else 0
  termination_by n => n
