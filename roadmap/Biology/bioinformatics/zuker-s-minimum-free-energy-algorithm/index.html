    TheoremUnique loop decomposition#✓fully proved

    Cslib.Bioinformatics.RNA.Zuker.existsUnique_closing_pair

    In a secondary structure every pair is either an exterior branch or a branch of exactly one pair of the structure (and not both): each pair is shared by the loop it closes and exactly one enclosing loop, possibly the exterior loop.

    theorem existsUnique_closing_pair (P : Finset (ℕ × ℕ)) (hP : IsStructure pair m s P)
    (q : ℕ × ℕ) (hq : q ∈ P) :
    (q ∈ exteriorBranches P ∧ ∀ p ∈ P, q ∉ branches P p) ∨
      (q ∉ exteriorBranches P ∧ ∃! p, p ∈ P ∧ q ∈ branches P p)
    structure IsStructure {B : Type*} (pair : B → B → Prop) (m : ℕ) (s : List B)
    (P : Finset (ℕ × ℕ)) : Prop where
  /-- Each pair encloses at least `m` positions: `i + m < j`. -/
  loop : ∀ p ∈ P, p.1 + m < p.2
  /-- Both positions of a pair lie in `s` and carry complementary bases. -/
  compl : ∀ p ∈ P, ∃ a b, s[p.1]? = some a ∧ s[p.2]? = some b ∧ pair a b
  /-- Distinct pairs share no position. -/

    Cslib.Bioinformatics.RNA.Zuker.loopEnergy

    The energy of the loop closed by p = (i, j) in P: a hairpin with no branch, a stack, bulge or interior loop with one branch (k, l), and the affine multiloop energy a + b · r + c · u with r ≥ 2 branches and u = (j - i - 1) - ∑ (l - k + 1) unpaired bases.

    noncomputable def loopEnergy (E : LoopEnergy) (P : Finset (ℕ × ℕ)) (p : ℕ × ℕ) : ℝ :=
  let br := branches P p
  if br.card = 0 then E.hairpin p.1 p.2
  else if h : br.card = 1 then
    let q := (Finset.card_eq_one.mp h).choose
    E.interior p.1 p.2 q.1 q.2
  else
    E.multiA + E.multiB * br.card +
      E.multiC * ((p.2 - p.1 - 1 - ∑ q ∈ br, (q.2 - q.1 + 1) : ℕ) : ℝ)

    TheoremEvery position has a unique innermost strict container#✓fully proved

    Cslib.Bioinformatics.RNA.Zuker.existsUnique_loop_of_pos

    Every position has a unique innermost strict container (not loop membership): a position x either lies strictly inside no pair, or there is a unique pair p with p.1 < x < p.2 such that no branch of p has x strictly inside it. This is an innermost-container assignment, not the conventional loop decomposition of positions: endpoints are excluded from the loop they close (a position x = q.1 or x = q.2 is assigned to the loop of which q is a branch, never to the loop closed by q), and no x < s.length hypothesis is assumed, so positions outside the sequence fall in the first (exterior) case. In particular do not read this as saying loops uniquely decompose positions; see existsUnique_closing_pair for the closing-pair side of the convention.

    theorem existsUnique_loop_of_pos (P : Finset (ℕ × ℕ)) (hP : IsStructure pair m s P) (x : ℕ) :
    (∀ p ∈ P, ¬ (p.1 < x ∧ x < p.2)) ∨
      ∃! p, p ∈ P ∧ (p.1 < x ∧ x < p.2) ∧ ∀ q ∈ branches P p, ¬ (q.1 < x ∧ x < q.2)

    DefinitionZuker's recursion#✓fully proved

    Cslib.Bioinformatics.RNA.Zuker.zukerVW

    Zuker's recursion on the interval [i, i + len), with j = i + len - 1, returning (V, WM): * V = ⊤ unless (i, j) can close a loop (i + m < j, CanPair pair s i j); otherwise V is the least of the hairpin energy hairpin i j, the interior-loop energies interior i j k l + V(k, l) over i < k < l < j, and the multiloop energies a + WM(i + 1, u) + WM(u + 1, j - 1) over i < u < j - 1; * WM (a multiloop fragment with at least one branch, charging b per branch and c per unpaired base) is the least of V + b, WM(i + 1, j) + c (base i unpaired), WM(i, j - 1) + c (base j unpaired) and WM(i, u) + WM(u + 1, j) over i ≤ u < j. Intervals are written by start and length.

    noncomputable def zukerVW (E : LoopEnergy) : ℕ → ℕ → WithTop ℝ × WithTop ℝ
  | i, len =>
    let j := i + len - 1
    let V : WithTop ℝ :=
      if i + m < j ∧ CanPair pair s i j then
        min (E.hairpin i j : WithTop ℝ)
          (min
            (Finset.univ.inf fun a : Fin len => Finset.univ.inf fun b : Fin len =>
              if 1 ≤ a.val ∧ a.val + b.val < len ∧ 1 ≤ b.val then
                (E.interior i j (i + a.val) (i + a.val + b.val - 1) : WithTop ℝ) +
                  (zukerVW E (i + a.val) b.val).1
              else ⊤)
            (Finset.univ.inf fun a : Fin len =>
              if 1 ≤ a.val ∧ a.val + 2 < len then
                (E.multiA : WithTop ℝ) + (zukerVW E (i + 1) a.val).2 +
                  (zukerVW E (i + a.val + 1) (len - a.val - 2)).2
              else ⊤))
      else ⊤
    let WM : WithTop ℝ :=
      if len = 0 then ⊤
      else
        min (V + (E.multiB : WithTop ℝ))
          (min ((zukerVW E (i + 1) (len - 1)).2 + (E.multiC : WithTop ℝ))
            (min ((zukerVW E i (len - 1)).2 + (E.multiC : WithTop ℝ))
              (Finset.univ.inf fun a : Fin len =>
                if 1 ≤ a.val then (zukerVW E i a.val).2 + (zukerVW E (i + a.val) (len - a.val)).2
                else ⊤)))
    (V, WM)
  termination_by _ len => len
  decreasing_by all_goals omega

    DefinitionZuker exterior-loop recursion#✓fully proved

    Cslib.Bioinformatics.RNA.Zuker.zukerExterior

    The exterior-loop recursion on the prefix [0, len): W(0) = 0 and W(len + 1) = min (W(len), min_{i ≤ len} W(i) + V(i, len + 1 - i)) (the last base is unpaired, or closes an exterior branch (i, len)).

    noncomputable def zukerExterior (E : LoopEnergy) : ℕ → WithTop ℝ

    min (zukerExterior E len)
      (Finset.univ.inf fun i : Fin (len + 1) =>
        zukerExterior E i.val + (zukerVW pair m s E i.val (len + 1 - i.val)).1)
