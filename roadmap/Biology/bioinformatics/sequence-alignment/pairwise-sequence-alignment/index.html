    DefinitionFuel-bounded Needleman–Wunsch recursion#✓fully proved

    Cslib.Algorithms.Lean.nwScoreAux

    Fix a substitution score \(\sigma : \alpha \to \alpha \to \mathbb{Z}\) and a gap score \(g \in \mathbb{Z}\), and write \(|x|\) for the length of a sequence \(x\) and \(ax\) for the sequence with first element \(a\) followed by \(x\). For a fuel \(n \in \mathbb{N}\) and sequences \(x, y\) over \(\alpha\), the value \(N_n(x, y) \in \mathbb{Z}\) is defined by \(N_0(x, y) = 0\), by \(N_{n+1}(x, y) = g\,|y|\) if \(x\) is empty and \(N_{n+1}(x, y) = g\,|x|\) if \(y\) is empty, and by

    \[N_{n+1}(ax, by) = \max\bigl(N_n(x, y) + \sigma(a, b),\ N_n(x, by) + g,\ N_n(ax, y) + g\bigr).\]

    The Needleman–Wunsch score of \(x\) and \(y\) is \(N_{|x|+|y|}(x, y)\); this fuel suffices because every recursive call shortens the pair. This is an exponential-time specification, not a memoized table.

    def nwScoreAux : ℕ → List α → List α → ℤ
  | 0, _, _ => 0
  | _ + 1, [], [] => 0
  | _ + 1, [], b :: ys => gap * ((b :: ys).length : ℤ)
  | _ + 1, a :: xs, [] => gap * ((a :: xs).length : ℤ)
  | n + 1, a :: xs, b :: ys =>
      max (max (nwScoreAux n xs ys + σ a b) (nwScoreAux n xs (b :: ys) + gap))
        (nwScoreAux n (a :: xs) ys + gap)

    DefinitionNeedleman–Wunsch score#✓fully proved

    Cslib.Algorithms.Lean.nwScore

    Given a type \(\alpha\), a substitution score \(\sigma : \alpha \to \alpha \to \mathbb{Z}\) and a gap score \(g \in \mathbb{Z}\), the Needleman–Wunsch score \(\mathrm{NW}(xs, ys)\) of two lists over \(\alpha\) is defined by recursion on their total length: if one of the lists is empty, it is \(g\) times the length of the other; and for lists \(a\,xs\) and \(b\,ys\) with heads \(a\), \(b\) and tails \(xs\), \(ys\),

    \[\mathrm{NW}(a\,xs, b\,ys) = \max\bigl(\mathrm{NW}(xs, ys) + \sigma(a, b), \ \mathrm{NW}(xs, b\,ys) + g,\ \mathrm{NW}(a\,xs, ys) + g\bigr).\]

    By the Needleman–Wunsch optimality theorem, this is the optimal global alignment score of the two lists.

    def nwScore (xs ys : List α) : ℤ := nwScoreAux σ gap (xs.length + ys.length) xs ys

    DefinitionFuel-bounded enumeration of alignments#✓fully proved

    Cslib.Algorithms.Lean.alignmentsAux

    Given a fuel \(n \in \mathbb{N}\) and sequences \(x\) and \(y\) over \(\alpha\), this lists alignments column by column from the front. With fuel \(0\) the list is empty. With fuel \(n + 1\): two empty sequences give the single empty alignment; if only \(y\) is nonempty, with first letter \(b\) and rest \(y'\), each alignment of \(x\) and \(y'\) with fuel \(n\) is preceded by the column pairing a gap with \(b\); if only \(x\) is nonempty, with first letter \(a\) and rest \(x'\), each alignment of \(x'\) and \(y\) with fuel \(n\) is preceded by the column pairing \(a\) with a gap; and if both are nonempty, \(x\) with first letter \(a\) and rest \(x'\) and \(y\) with first letter \(b\) and rest \(y'\), the list consists of the alignments of \(x'\) and \(y'\) preceded by the column \((a, b)\), then those of \(x'\) and \(y\) preceded by the column pairing \(a\) with a gap, then those of \(x\) and \(y'\) preceded by the column pairing a gap with \(b\), each computed with fuel \(n\).

    With fuel at least \(|x| + |y| + 1\) the fuel never runs out before both sequences are used up; with less fuel some alignments are missing from the list.

    def alignmentsAux : ℕ → List α → List α → List (Alignment α)
  | 0, _, _ => []

  | n + 1, [], b :: ys => (alignmentsAux n [] ys).map fun A => (none, some b) :: A
  | n + 1, a :: xs, [] => (alignmentsAux n xs []).map fun A => (some a, none) :: A
  | n + 1, a :: xs, b :: ys =>
      (alignmentsAux n xs ys).map (fun A => (some a, some b) :: A) ++
        (alignmentsAux n xs (b :: ys)).map (fun A => (some a, none) :: A) ++
