    DefinitionAffine-gap score from a gap state#✓fully proved

    Cslib.Algorithms.Lean.affineScoreAux

    Fix an integer substitution score \(\sigma\), an integer gap-open cost \(o\) and an integer gap-extend cost \(e\). The affine-gap score of an alignment started from a gap state \(p\) is the sum of its column scores, computed left to right while carrying a gap state that starts at \(p\) and is updated after each column. The empty alignment scores \(0\). A column pairing an element \(a\) of the first sequence with an element \(b\) of the second scores \(\sigma(a, b)\) and sets the state to \(\mathrm{none}\). A column pairing an element of the first sequence with a gap has kind \(\mathrm{gapX}\), and a column pairing a gap with an element of the second sequence has kind \(\mathrm{gapY}\); such a column scores \(e\) if the carried state equals its kind and \(o\) otherwise, and sets the state to its kind. A column of two gaps scores \(0\) and sets the state to \(\mathrm{none}\).

    The column of two gaps cannot occur in a valid alignment; it is scored as a no-op.

    def affineScoreAux : Alignment α → GapState → ℤ
  | [], _ => 0
  | (some a, some b) :: A, _ => σ a b + affineScoreAux A .none
  | (some _, none) :: A, prev =>
      gapCost gapOpen gapExtend prev .gapX + affineScoreAux A .gapX
  | (none, some _) :: A, prev =>
      gapCost gapOpen gapExtend prev .gapY + affineScoreAux A .gapY
  | (none, none) :: A, _ => affineScoreAux A .none
    abbrev Alignment (α : Type*) := List (Option α × Option α)

    DefinitionFuel-bounded Gotoh recursion#✓fully proved

    Cslib.Algorithms.Lean.gotohAux

    Fix an integer-valued scoring function \(\sigma\) on pairs of letters and integer gap-open and gap-extend penalties \(g_o\) and \(g_e\). A gap state records what the previous alignment column was: a match (\(\mathrm{none}\)), a gap in the second sequence (\(\mathrm{gapX}\)) or a gap in the first sequence (\(\mathrm{gapY}\)). For gap states \(p\), \(q\) let \(c(p, q)\) be the gap cost, \(g_e\) if \(p = q\) and \(g_o\) otherwise. Write \(\varepsilon\) for the empty sequence and \(a \cdot u\) for the sequence with first letter \(a\) followed by \(u\). For fuel \(n \in \mathbb{N}\), sequences \(u\), \(v\) and a gap state \(p\), the integer \(G_n(u, v, p)\) is defined by recursion on \(n\): \(G_0(u, v, p) = 0\), \(G_{n+1}(\varepsilon, \varepsilon, p) = 0\), \(G_{n+1}(\varepsilon, b \cdot v, p) = c(p, \mathrm{gapY}) + G_n(\varepsilon, v, \mathrm{gapY})\), \(G_{n+1}(a \cdot u, \varepsilon, p) = c(p, \mathrm{gapX}) + G_n(u, \varepsilon, \mathrm{gapX})\), and \(G_{n+1}(a \cdot u, b \cdot v, p)\) is the maximum of \(\sigma(a, b) + G_n(u, v, \mathrm{none})\), \(c(p, \mathrm{gapX}) + G_n(u, b \cdot v, \mathrm{gapX})\) and \(c(p, \mathrm{gapY}) + G_n(a \cdot u, v, \mathrm{gapY})\).

    With fuel at least the sum of the two lengths this is the Gotoh dynamic program; with less fuel the base case \(G_0 = 0\) cuts the recursion short.

    def gotohAux : ℕ → List α → List α → GapState → ℤ
  | 0, _, _, _ => 0
  | _ + 1, [], [], _ => 0
  | n + 1, [], b :: ys, prev => gapCost gapOpen gapExtend prev .gapY + gotohAux n [] ys .gapY
  | n + 1, a :: xs, [], prev => gapCost gapOpen gapExtend prev .gapX + gotohAux n xs [] .gapX
  | n + 1, a :: xs, b :: ys, prev =>
      max (σ a b + gotohAux n xs ys .none)
        (max (gapCost gapOpen gapExtend prev .gapX + gotohAux n xs (b :: ys) .gapX)
          (gapCost gapOpen gapExtend prev .gapY + gotohAux n (a :: xs) ys .gapY))
    inductive GapState | none | gapX | gapY deriving DecidableEq, Repr
