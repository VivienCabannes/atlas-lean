    Let \(w \in \mathbb{N}\) be a band width. For natural numbers \(i\), \(j\) and an alignment \(A\), the band check of \(A\) with width \(w\) from offset \((i, j)\) is true exactly when every prefix \(P\) of \(A\) (including the empty prefix and \(A\) itself) satisfies \(|(i + p) - (j + q)| \le w\), where \(p\) and \(q\) are the numbers of columns of \(P\) whose first, respectively second, entry is present.

    def bandedFrom : ℕ → ℕ → Alignment α → Bool
  | i, j, [] => decide (|(i : ℤ) - (j : ℤ)| ≤ (w : ℤ))
  | i, j, (some _, some _) :: A =>
      decide (|(i : ℤ) - (j : ℤ)| ≤ (w : ℤ)) && bandedFrom (i + 1) (j + 1) A
  | i, j, (some _, none) :: A =>
      decide (|(i : ℤ) - (j : ℤ)| ≤ (w : ℤ)) && bandedFrom (i + 1) j A

    For sequences \(x = x_1 \dots x_m\) and \(y = y_1 \dots y_n\), let \(k = \min(m, n)\). The diagonal alignment of \(x\) and \(y\) consists of the columns \((x_1, y_1), \dots, (x_k, y_k)\), which pair letters by position whether or not they are equal, followed by one column for each remaining letter of the longer sequence, in order, pairing that letter with a gap.
