    MathlibExt.Biology.PopulationGenetics.SelectionScan.ehh_eq_sum_counts

    EHH as the sampling-without-replacement homozygosity of the partition of C into window types: EHH(d) = ∑_t c_t (c_t - 1) / (#C (#C - 1)), where c_t is the number of haplotypes of C with window t. This is the form in which EHH is usually defined.

    theorem ehh_eq_sum_counts (h : ι → ℕ → α) (C : Finset ι) (d : ℕ) :
    ehh h C d = (∑ t ∈ C.image (window h d),
        ((C.filter fun i => window h d i = t).card : ℝ) *
          (((C.filter fun i => window h d i = t).card : ℝ) - 1)) /
      ((C.card : ℝ) * ((C.card : ℝ) - 1))

    MathlibExt.Biology.PopulationGenetics.SelectionScan.ehhCore

    Extended haplotype homozygosity with core-allele labels: the probability that two distinct haplotypes drawn from C without replacement share both their core allele and their window of radius d.     DefinitionRelative extended haplotype homozygosity (REHH)#✓fully proved

    MathlibExt.Biology.PopulationGenetics.SelectionScan.rehh

    Relative extended haplotype homozygosity: the core-labelled EHH of the core-allele carriers C divided by the core-labelled EHH of the pooled set D of haplotypes carrying the other core alleles. The denominator counts only pairs sharing a core allele, so cross-core pairs never inflate it. This is the statistic of the long-range haplotype test (Sabeti et al. 2002). It is a junk value 0 when the denominator vanishes; one_lt_rehh_iff assumes a positive denominator.

    noncomputable def rehh {β : Type*} [DecidableEq β] (core : ι → β) (h : ι → ℕ → α)
    (C D : Finset ι) (d : ℕ) : ℝ :=
  ehhCore core h C d / ehhCore core h D d

    DefinitionProbability of no recombination on a pair's genealogy#✓fully proved

    MathlibExt.Biology.PopulationGenetics.SelectionScan.pairNoRecomb

    The probability that no recombination falls on the genealogy of a pair of lineages within genetic distance d of the core, given that the pair coalesces at time t (time in units of 2N generations, ρ = 4Nr the scaled recombination rate per site): the two lineages carry recombination events at total rate ρ * d until they coalesce.

    In a mutation-free model this is a lower bound for the probability that the two haplotypes are identical over the window — no recombination then implies identical windows, while a recombined lineage may still carry the same alleles — so it is a lower bound for the expected EHH, not its value. Without the mutation-free assumption the bound is not established: mutations on either descendant branch can make the haplotypes differ even with no recombination.

    noncomputable def pairNoRecomb (ρ d t : ℝ) : ℝ := exp (-(ρ * d) * t)

    MathlibExt.Biology.PopulationGenetics.SelectionScan.integral_pairNoRecomb

    Averaging over the pair coalescence time T₂, which is exponential of rate 1 in units of 2N generations under the neutral coalescent, the probability that no recombination falls on the pair's genealogy within distance d is 1 / (1 + ρ d).
