    MathlibExt.Biology.PopulationGenetics.SelectionScan.IsExchangeablePair

    The pair of statistics (X, Y) is exchangeable under μ: the joint law is unchanged by swapping the two coordinates. This is an additional calibration assumption for a two-group haplotype test, stronger than the ordinary neutral null. Defined as IdentDistrib of the two orderings, so the measurability of the joint laws is part of the hypothesis rather than restored separately in each theorem.

    def IsExchangeablePair (μ : Measure Ω) (X Y : Ω → ℝ) : Prop :=
  ProbabilityTheory.IdentDistrib (fun ω => (X ω, Y ω)) (fun ω => (Y ω, X ω)) μ μ

    DefinitionCross-population extended haplotype homozygosity (XP-EHH)#✓fully proved

    MathlibExt.Biology.PopulationGenetics.SelectionScan.xpehh

    The cross-population extended haplotype homozygosity score (Sabeti et al. 2007): the log ratio of the integrated haplotype homozygosities of the same core region in two populations. Both arguments must be positive for the score to be meaningful. Outside that domain Real.log is totalized by Mathlib, not by the stated junk value: Real.log 0 = 0 and Real.log (-x) = Real.log x, so for example xpehh (-2) 1 = log 2.

    noncomputable def xpehh (iA iB : ℝ) : ℝ := log iA - log iB
