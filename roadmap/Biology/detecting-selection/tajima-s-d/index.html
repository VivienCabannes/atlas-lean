    MathlibExt.Biology.PopulationGenetics.Coalescent.tajimaD

    Tajima's D (Tajima 1989) for a sample of n genes with mean number of pairwise differences π and S segregating sites: D = (π - S / a₁) / √(e₁ S + e₂ S (S - 1)). It is meaningful for n ≥ 4 and S ≥ 1 (tajimaVarEstimator_pos); otherwise Lean's junk values for x / 0 and √ of a nonpositive number apply.

    def tajimaD (n : ℕ) (π S : ℝ) : ℝ :=
  (π - S / tajimaA1 n) / Real.sqrt (tajimaE1 n * S + tajimaE2 n * (S * (S - 1)))
    def tajimaA1 (n : ℕ) : ℝ := ∑ i ∈ Ico 1 n, (i : ℝ)⁻¹

    MathlibExt.Biology.PopulationGenetics.Coalescent.measure_tajimaChebyshevTest_le

    If Tajima's numerator π - S / a₁ is square integrable with mean 0 and variance c₁ θ₀ + c₂ θ₀² > 0 (as under the standard neutral model, by KingmanTimes.integral_tajimaNumerator and KingmanTimes.variance_tajimaNumerator), then for every α > 0 the test rejects with probability at most α.
