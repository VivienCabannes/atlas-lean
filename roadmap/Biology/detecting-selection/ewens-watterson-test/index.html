    MathlibExt.Biology.PopulationGenetics.Ewens.condUpperPValue

    The conditional upper-tail p-value of a statistic T of the allelic partition: the conditional probability, given the observed number of alleles K(π), that T is at least its observed value T π. It is written with the cycle-type weights and so does not involve θ (by ewensCondProb_eq it is the conditional tail probability for every θ > 0).

    def condUpperPValue (T : n.Partition → ℝ) (π : n.Partition) : ℝ :=
  (∑ π' : n.Partition with π'.parts.card = π.parts.card ∧ T π ≤ T π', cycleTypeWeight π') /
    ∑ π' : n.Partition with π'.parts.card = π.parts.card, cycleTypeWeight π'

    TheoremK is sufficient for θ#✓fully proved

    MathlibExt.Biology.PopulationGenetics.Ewens.ewensCondProb_eq

    K is sufficient for θ (Ewens 1972): for θ > 0, the conditional law of the allelic partition given the number of alleles is w(π) / ∑_{K(π') = K(π)} w(π'), which does not depend on θ.

    theorem ewensCondProb_eq {θ : ℝ} (hθ : 0 < θ) (π : n.Partition) :
    ewensCondProb θ π =
      cycleTypeWeight π /
        ∑ π' : n.Partition with π'.parts.card = π.parts.card, cycleTypeWeight π'
