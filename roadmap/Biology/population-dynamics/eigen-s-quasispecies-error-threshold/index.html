    MathlibExt.Biology.Dynamics.Quasispecies.masterField

    The master-sequence vector field of the single-peak quasispecies without back mutation: x' = σ Q x - (σ x + (1 - x)) x, where σ is the master fitness relative to the mutants and Q the probability of an error-free copy. Meaningful for σ > 1, 0 ≤ Q ≤ 1, 0 ≤ x ≤ 1; it is a polynomial and is defined for all reals.

    def masterField (σ Q x : ℝ) : ℝ :=
  σ * Q * x - (σ * x + (1 - x)) * x
