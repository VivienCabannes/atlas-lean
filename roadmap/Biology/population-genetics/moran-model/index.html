    MathlibExt.Biology.PopulationGenetics.Moran.moranUp

    Probability that one step of the Moran process with N individuals and mutant relative fitness r takes the mutant count from i to i + 1: a mutant is chosen to reproduce (probability r i / (r i + N - i)) and a wild type is chosen to die (probability (N - i) / N). Meaningful for 0 < r and i ≤ N (the real subtraction N - i is negative for i > N).

    noncomputable def moranUp (r : ℝ) (N i : ℕ) : ℝ :=
  r * i / (r * i + (N - i)) * ((N - i) / N)

    DefinitionFixation probability of the Moran process#✓fully proved

    MathlibExt.Biology.PopulationGenetics.Moran.moranFixation

    The fixation probability of the Moran process started from i mutants out of N: (1 - r⁻¹ ^ i) / (1 - r⁻¹ ^ N) for r ≠ 1, and i / N in the neutral case r = 1. The model's domain is 0 < r, N ≥ 1, i ≤ N; outside it the value is the closed formula evaluated with Lean's total division (e.g. x / 0 = 0) and carries no meaning.

    noncomputable def moranFixation (r : ℝ) (N i : ℕ) : ℝ :=
  if r = 1 then i / N else (1 - r⁻¹ ^ i) / (1 - r⁻¹ ^ N)

    One-step transition probabilities of the Moran process on the states Fin (N + 1): a_i to i + 1, b_i to i - 1, 1 - a_i - b_i to i, and 0 elsewhere.

    noncomputable def moranProb (r : ℝ) (N : ℕ) (i j : Fin (N + 1)) : ℝ :=

  else if (j : ℕ) + 1 = i then moranDown r N i
  else if j = i then 1 - moranUp r N i - moranDown r N i

    One-step expectation of a function f of the mutant count from state i: ∑ j, P i j f j = a_i f (i + 1) + b_i f (i - 1) + (1 - a_i - b_i) f i (the boundary terms vanish at i = 0 and i = N).

    The Moran process with N individuals and mutant relative fitness r > 0, as a stochastic matrix on the mutant counts Fin (N + 1).

    noncomputable def moranMatrix (N : ℕ) {r : ℝ} (hr : 0 < r) : StochasticMatrix N where
  prob := moranProb r N
  nonneg i j := by
    have hi : (i : ℕ) ≤ N := Nat.lt_succ_iff.1 i.2

    MathlibExt.Biology.PopulationGenetics.Moran.moranFixation_eq_firstStep

    The fixation probability satisfies φ_i = a_i φ_{i+1} + b_i φ_{i-1} + (1 - a_i - b_i) φ_i. This is the first-step equation of the chain for the interior states 0 < i < N; the identity is algebraic (it follows from r · b_i = a_i), so it is stated for every i ≥ 1.
