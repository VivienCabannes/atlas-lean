    Ewens sampling formula and the Chinese restaurant process

    DefinitionEwens sampling formula#✓fully proved

    MathlibExt.Biology.PopulationGenetics.Ewens.ewensProb

    The Ewens sampling formula: the probability, under the neutral infinite-alleles model with scaled mutation rate θ = 4Nu, that a sample of n genes has allelic partition π (π.parts.count j alleles carried by exactly j genes each): n! * (∏ j, (θ / j) ^ (a j) / (a j)!) / θ^{(n)} (Ewens 1972), for θ > 0.

    def ewensProb (θ : ℝ) {n : ℕ} (π : n.Partition) : ℝ :=
  (n.factorial : ℝ) / (ascPochhammer ℝ n).eval θ *
    ∏ j ∈ π.parts.toFinset,
      (θ / j) ^ (π.parts.count j) / ((π.parts.count j).factorial : ℝ)

    DefinitionOne step of Hoppe's urn#✓fully proved

    MathlibExt.Biology.PopulationGenetics.Ewens.hoppeStep

    One step of Hoppe's urn on allelic partitions (Hoppe 1984): from a partition π of k, the next gene carries a new allele with probability θ / (θ + k) (target parts 1 ::ₘ π.parts), and copies an allele carried by j genes with probability j * a j / (θ + k), where a j = π.parts.count j (target parts (j + 1) ::ₘ π.parts.erase j). The value is the transition probability from π to π'.

    def hoppeStep (θ : ℝ) {k : ℕ} (π : k.Partition) (π' : (k + 1).Partition) : ℝ :=
  (if π'.parts = 1 ::ₘ π.parts then θ / (θ + k) else 0) +
    ∑ j ∈ π.parts.toFinset,
      if π'.parts = (j + 1) ::ₘ π.parts.erase j then
        (j * π.parts.count j : ℝ) / (θ + k) else 0
