    Infinite-alleles model and homozygosity

    DefinitionHomozygosity recursion in the infinite-alleles model#✓fully proved

    MathlibExt.Biology.PopulationGenetics.InfiniteAlleles.homozygosityStep

    One generation of drift and mutation in the infinite-alleles model with M gene copies and mutation probability u per copy: F' = (1 - u)² (1/M + (1 - 1/M) F). The model domain is 2 ≤ M (two distinct copies must exist) and 0 ≤ u ≤ 1; the theorems below assume only 1 ≤ M, and M = 1 is an algebraic extension with no biological meaning. For M = 0 the definition uses the junk value 1/0 = 0.

    noncomputable def homozygosityStep (M : ℕ) (u F : ℝ) : ℝ :=
  (1 - u) ^ 2 * (1 / M + (1 - 1 / M) * F)

    DefinitionEquilibrium homozygosity in the infinite-alleles model#✓fully proved

    MathlibExt.Biology.PopulationGenetics.InfiniteAlleles.eqHomozygosity

    The equilibrium homozygosity F* = (1 - u)² / (M - (M - 1)(1 - u)²). Biologically meaningful for 2 ≤ M; its denominator is positive for 1 ≤ M and 0 < u ≤ 1, the hypotheses of the theorems below (M = 1 being an algebraic extension).

    noncomputable def eqHomozygosity (M : ℕ) (u : ℝ) : ℝ :=
  (1 - u) ^ 2 / (M - (M - 1) * (1 - u) ^ 2)
