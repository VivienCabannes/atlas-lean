    TheoremBeta density as Wright's stationary density#✓fully proved

    MathlibExt.Biology.PopulationGenetics.Diffusion.betaPDFReal_eq_wrightDensity

    On (0, 1) the Beta(θ₁, θ₂) density is Wright's unnormalized density in the scaled rates α = θ₁ / 2, β = θ₂ / 2, divided by the Beta function B(θ₁, θ₂).

    theorem betaPDFReal_eq_wrightDensity (θ₁ θ₂ : ℝ) {x : ℝ} (hx : x ∈ Ioo (0 : ℝ) 1) :
    betaPDFReal θ₁ θ₂ x = wrightDensity (θ₁ / 2) (θ₂ / 2) x / beta θ₁ θ₂
    noncomputable def wrightDensity (α β x : ℝ) : ℝ :=
  x ^ (2 * α - 1) * (1 - x) ^ (2 * β - 1)

    MathlibExt.Biology.PopulationGenetics.Diffusion.flux_betaPDFReal

    On (0, 1) the Beta(θ₁, θ₂) density π satisfies ½ (x (1 - x) π)' - (θ₁ (1 - x) - θ₂ x) / 2 · π = 0. The identity holds for all real θ₁, θ₂ (it is linear in π; Mathlib's density is identically 0 when B(θ₁, θ₂) = 0); π is a probability density when θ₁, θ₂ > 0 (isProbabilityMeasureBeta).

      (θ₁ * (1 - x) - θ₂ * x) / 2 * betaPDFReal θ₁ θ₂ x = 0

    TheoremWeak stationarity of Wright's law (density form)#✓fully proved

    MathlibExt.Biology.PopulationGenetics.Diffusion.integral_mutationGenerator_mul_betaPDFReal

    For θ₁, θ₂ > 0 and every f twice continuously differentiable on [0, 1], ∫₀¹ (L f)(x) π(x) dx = 0 for the Beta(θ₁, θ₂) density π. (L f uses deriv, which agrees with the one-sided derivatives inside (0, 1); its values at the endpoints do not affect the integral.) The proof is integration by parts: L f · π = (x ^ θ₁ (1 - x) ^ θ₂ f' / (2 B(θ₁, θ₂)))' on (0, 1) because the flux vanishes, and this boundary term is 0 at both endpoints since θ₁, θ₂ > 0.

    TheoremDrift of the Wright–Fisher chain with mutation (Ewens 2004, ch. 4)#✓fully proved

    MathlibExt.Biology.PopulationGenetics.Diffusion.integral_binomial_mutatedFreq_drift

    One generation of the Wright–Fisher chain on M gene copies (M = 2N): mutation moves the frequency x to p' = mutatedFreq u₁ u₂ x, then the new count is Binomial(M, p'). With u₁ = θ₁ / (2M), u₂ = θ₂ / (2M) (θᵢ = 4N uᵢ), the expected change of frequency per 2N = M generations is exactly the drift coefficient of mutationGenerator: M · (E[k / M] - x) = (θ₁ (1 - x) - θ₂ x) / 2, for every M.

    theorem integral_binomial_mutatedFreq_drift {M : ℕ} (hM : M ≠ 0) {θ₁ θ₂ : ℝ}

    M * (∫ k, (k : ℝ) / M ∂(binomial M (mutatedFreq u₁ u₂ x)) - x) =

    MathlibExt.Biology.PopulationGenetics.Diffusion.integral_binomial_mutatedFreq_sq

    In the setting of integral_binomial_mutatedFreq_drift, the scaled second moment of the frequency change is M · E[(k / M - x) ^ 2] = p' (1 - p') + (θ₁ (1 - x) - θ₂ x) ^ 2 / (4M) with p' = mutatedFreq u₁ u₂ x = x + (θ₁ (1 - x) - θ₂ x) / (2M).
