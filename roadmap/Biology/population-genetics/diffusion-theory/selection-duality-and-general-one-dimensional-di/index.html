    TheoremSelection duality (Mano 2009)#✓fully proved

    MathlibExt.Biology.PopulationGenetics.Diffusion.generator_one_sub_pow

    Selection duality (Mano 2009) at generator level, with the line-counting process of the ancestral selection graph (Krone–Neuhauser 1997) as the dual: the Wright–Fisher generator with genic selection maps y ↦ (1 - y) ^ n to C(n, 2) ((1 - x)^(n-1) - (1 - x)^n) + n σ ((1 - x)^(n+1) - (1 - x)^n). This identity holds for every real σ; the dual is a Markov chain only for σ ≥ 0.

    theorem generator_one_sub_pow (σ : ℝ) (n : ℕ) (x : ℝ) :
    generator σ (fun y => (1 - y) ^ n) x =
      (n.choose 2 : ℝ) * ((1 - x) ^ (n - 1) - (1 - x) ^ n) +
        n * σ * ((1 - x) ^ (n + 1) - (1 - x) ^ n)
    noncomputable def generator (σ : ℝ) (u : ℝ → ℝ) (x : ℝ) : ℝ :=
  x * (1 - x) / 2 * deriv (deriv u) x + σ * x * (1 - x) * deriv u x

    DefinitionStationary law of the ancestral selection graph line counts#✓fully proved

    MathlibExt.Biology.PopulationGenetics.Diffusion.asgStationary

    The stationary law of the ancestral-selection-graph line-counting process with σ > 0: π_k = (2σ)^k / k! / (e^{2σ} - 1) for k ≥ 1 and π_0 = 0, a Poisson(2σ) law conditioned to be positive. For σ = 0 the stationary law is δ₁: branching vanishes, coalescence reaches state 1, and state 1 is absorbing, so π_1 = 1 and π_k = 0 otherwise (the limit of the σ > 0 formula as σ → 0).

    noncomputable def asgStationary (σ : ℝ) (k : ℕ) : ℝ :=
  if σ = 0 then (if k = 1 then 1 else 0)
  else if k = 0 then 0 else (2 * σ) ^ k / k ! / (exp (2 * σ) - 1)
