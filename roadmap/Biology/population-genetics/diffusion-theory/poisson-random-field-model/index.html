    MathlibExt.Biology.PopulationGenetics.Diffusion.prfDensity

    The Sawyer–Hartl (1992) Poisson-random-field density: the expected number of sites per unit frequency at which the derived allele has frequency x, for scaled mutation rate θ = 4Nu and scaled genic selection σ = 2Ns: θ · u_σ(1 - x) / (x (1 - x)) with u_σ = kimuraFixation σ, i.e. θ (1 - e^{-2σ(1 - x)}) / ((1 - e^{-2σ}) x (1 - x)), and θ / x when σ = 0. The model domain is θ > 0 and x ∈ (0, 1); at x = 0, 1 Lean's a / 0 = 0 gives the junk value 0.

    noncomputable def prfDensity (θ σ x : ℝ) : ℝ :=
  θ * kimuraFixation σ (1 - x) / (x * (1 - x))
    noncomputable def kimuraFixation (σ x : ℝ) : ℝ :=
  if σ = 0 then x else (1 - exp (-2 * σ * x)) / (1 - exp (-2 * σ))

    On (0, 1) the weighted density F(x) = x (1 - x) φ(x) of the Poisson-random-field density solves the stationary Fokker–Planck equation ½ F'' - σ F' = 0 of the Wright–Fisher diffusion with genic selection σ (the forward equation ½ (x (1 - x) φ)'' - (σ x (1 - x) φ)' = 0).

    DefinitionExpected site frequency spectrum under the Poisson random field#✓fully proved

    MathlibExt.Biology.PopulationGenetics.Diffusion.expectedSFS

    The expected unfolded site-frequency spectrum of a sample of n gene copies under the Poisson random field: the expected number of sites where exactly i of the n sampled copies carry the derived allele, E ξ_i = ∫ x in 0..1, C(n, i) x ^ i (1 - x) ^ (n - i) φ(x). The site-frequency spectrum consists of the segregating classes 1 ≤ i < n. The value at i = n is the expected number of sites at which every sampled copy is derived (monomorphic in the sample, expectedSFS_neutral_self); for i = 0 the integrand is not integrable at 0 (the expected number of ancestral-monomorphic sites is infinite) and Lean's integral returns its junk value 0.

    noncomputable def expectedSFS (θ σ : ℝ) (n i : ℕ) : ℝ :=
  ∫ x in (0 : ℝ)..1, (n.choose i : ℝ) * x ^ i * (1 - x) ^ (n - i) * prfDensity θ σ x
    noncomputable def prfDensity (θ σ x : ℝ) : ℝ :=
  θ * kimuraFixation σ (1 - x) / (x * (1 - x))
