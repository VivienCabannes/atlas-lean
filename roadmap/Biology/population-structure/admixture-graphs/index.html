    MathlibExt.Biology.PopulationGenetics.AdmixtureGraph

    An admixture graph on the nodes V (Patterson et al. 2012): a rooted directed acyclic graph in which every non-root node has one or two parents, with admixture proportions.

    • parents X are the parents of X, the root has none, every other node has one or two;
    • prop X Y is the probability that a lineage in X descends from parent Y: nonnegative, summing to 1 over the parents of a non-root node, and 0 off the parent set;
    • the parent relation is well founded, i.e. the graph is acyclic (V is finite in all results).
    MathlibExt.Biology.PopulationGenetics.AdmixtureGraph · 19 lines 
    structure AdmixtureGraph (V : Type*) where
  /-- The root (ancestral population). -/
  root : V
  /-- The parents of each node. -/
  parents : V → Finset V
  /-- Admixture proportions: `prop X Y` is the share of ancestry of `X` from parent `Y`. -/
  prop : V → V → ℝ
  /-- The root has no parent. -/
  parents_root : parents root = ∅
  /-- Every non-root node has one parent (tree edge) or two parents (admixture node). -/
  card_parents : ∀ X, X ≠ root → (parents X).card = 1 ∨ (parents X).card = 2
  /-- Proportions are nonnegative. -/
  prop_nonneg : ∀ X Y, 0 ≤ prop X Y
  /-- Proportions vanish off the parent set. -/
  prop_eq_zero : ∀ X Y, Y ∉ parents X → prop X Y = 0
  /-- The proportions of a non-root node sum to `1`. -/
  sum_prop : ∀ X, X ≠ root → ∑ Y ∈ parents X, prop X Y = 1
  /-- The graph is acyclic: the parent relation is well founded. -/
  wf : WellFounded fun Y X => Y ∈ parents X
      parents : V → Finset V

    MathlibExt.Biology.PopulationGenetics.AdmixtureGraph.f3_admixture

    The three-population statistic at an admixture node X with parents A ≠ B, proportions α = prop X A and β = prop X B (α + β = 1), in a drift model with the graph's weights: f3 X A B = α² ℓ_{XA} + β² ℓ_{XB} - α β f2 A B, where ℓ_{XA}, ℓ_{XB} are the drift lengths of the two admixture edges.

    theorem f3_admixture {M : DriftModel μ G.Edge V} (hM : M.weight = G.weight) {X A B : V}
    (hX : G.parents X = {A, B}) (hAB : A ≠ B) :
    f3 μ M.freq X A B =
      G.prop X A ^ 2 * M.len ⟨(X, A), by simp [hX]⟩ +
        G.prop X B ^ 2 * M.len ⟨(X, B), by simp [hX]⟩ -
