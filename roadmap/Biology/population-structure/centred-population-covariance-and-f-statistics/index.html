    Theoremf-statistics determine exactly the centred leaf covariance#✓fully proved

    MathlibExt.Biology.PopulationGenetics.FStatisticsCovariance.f2_eq_iff_centredCov_eq

    f-statistics determine exactly the centred leaf covariance. f-statistics see a model only through its centred leaf covariance: two square-integrable frequency models have the same f2 at every pair (hence the same f3 and f4, by f3_eq_f2 and f4_eq_f2) if and only if they have the same centred leaf covariance.

    theorem f2_eq_iff_centredCov_eq {Ω' : Type*} {m' : MeasurableSpace Ω'} {μ' : Measure Ω'}
    {p' : P → Ω' → ℝ} (hp : ∀ X, MemLp (p X) 2 μ) (hp' : ∀ X, MemLp (p' X) 2 μ') :
    (∀ X Y, f2 μ p X Y = f2 μ' p' X Y) ↔ ∀ X Y, centredCov μ p X Y = centredCov μ' p' X Y
    noncomputable def f2 (X Y : P) : ℝ := ∫ ω, (p X ω - p Y ω) ^ 2 ∂μ
