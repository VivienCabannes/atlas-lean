    MathlibExt.Biology.StatisticalGenetics.StratifiedLDScore.Model

    The random-effects model of stratified LD-score regression at the level of raw second moments: marker k has effect variance sigma2 k, the noise has variance sigmaE2, and effects and noise are orthogonal in L². As in LDScore.Model, the measure is arbitrary, no means are assumed, and all statements are conditional on the genotype matrix.

    TheoremFrequency-dependent architecture#✓fully proved

    MathlibExt.Biology.StatisticalGenetics.StratifiedLDScore.Model.integral_chiSq_of_alpha

    Frequency-dependent architecture (the α model of Schoech et al. 2019): if the per-allele effect variance of marker k with allele frequency p_k is proportional to [p_k (1 - p_k)]^α, the variance of the effect of the standardized genotype is σ²_k = c [p_k (1 - p_k)]^(1 + α), and then, for a standardized genotype matrix and N ≠ 0, 𝔼[χ² j] = N c ∑_k [p_k (1 - p_k)]^(1 + α) r_jk² + σ²_e. (The real power is meaningful for 0 < p_k < 1.)

    theorem integral_chiSq_of_alpha (p : Fin M → ℝ) (α c : ℝ)
    (hσ : ∀ k, D.sigma2 k = c * (p k * (1 - p k)) ^ (1 + α)) (hN : N ≠ 0) (j : Fin M)
    (hX : IsStandardized X) :
    ∫ ω, D.chiSq X j ω ∂μ =
      N * c * ∑ k, (p k * (1 - p k)) ^ (1 + α) * ldCorr X j k ^ 2 + D.sigmaE2
    def IsStandardized (X : Matrix (Fin N) (Fin M) ℝ) : Prop :=

    LDSC-SEG: the gene-set coefficient as a per-SNP contrast

    TheoremLDSC-SEG contrast#✓fully proved

    MathlibExt.Biology.StatisticalGenetics.StratifiedLDScore.sigma2_sub_sigma2_eq

    LDSC-SEG contrast (Finucane et al. 2018): for per-SNP variances σ²_k = ∑_C τ_C a_{kC}, two SNPs k, k' whose annotations agree except on annotation cS differ in per-SNP variance by τ_{cS} (a_{k cS} - a_{k' cS}). With cS the indicator of a gene set S contained in the control gene set G (whose indicator is one of the other annotations), k ∈ S and k' ∈ G ∖ S with equal values of all other annotations give σ²_k - σ²_{k'} = τ_S.

    theorem sigma2_sub_sigma2_eq {ι : Type*} [Fintype ι] (a : Fin M → ι → ℝ) (τ : ι → ℝ)
    (cS : ι) (k k' : Fin M) (hagree : ∀ C, C ≠ cS → a k C = a k' C) :
    ∑ C, τ C * a k C - ∑ C, τ C * a k' C = τ cS * (a k cS - a k' cS)
