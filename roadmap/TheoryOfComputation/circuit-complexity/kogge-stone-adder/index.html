    Let \(p\) be a straight-line program with \(g\) gates over \(m\) inputs, let \(c \in \mathbb{N}\), and for each \(j < c\) let \(f_j\) be a line (a gate operation with its argument wires) that reads the inputs and the first \(g + j\) gates.   | 0, _ => p
  | c + 1, f => (appendGates p c fun j h => f j (by omega)).gate (f c (by omega))
