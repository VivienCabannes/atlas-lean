    DefinitionGates of the ripple-carry adder#✓fully proved

    Cslib.Circuits.RippleCarry.line

    For natural numbers \(n\) and \(g\) with \(g < 5n\), gate \(g\) of the \(n\)-bit ripple-carry adder is the following binary gate of the arithmetic basis, whose arguments are among the \(2n + 1\) inputs and the \(g\) gates before it. Write \(g = 5i + r\) with \(0 \le r < 5\), let \(a\) be input \(i\) and \(b\) input \(n + i\), and let \(c\) be the carry into bit \(i\): input \(2n\) if \(i = 0\) and gate \(5i - 1\) otherwise. Gate \(g\) is the XOR gate with first argument \(a\) and second argument \(b\) if \(r = 0\), the XOR gate with first argument gate \(g - 1\) and second argument \(c\) if \(r = 1\), the AND gate with first argument \(a\) and second argument \(b\) if \(r = 2\), the AND gate with first argument gate \(g - 3\) and second argument \(c\) if \(r = 3\), and the OR gate with first argument gate \(g - 2\) and second argument gate \(g - 1\) if \(r = 4\).

    def line (n g : ℕ) (hg : g < 5 * n) : Line arithSignature (2 * n + 1) g :=
  let a : Wire (2 * n + 1) g := Wire.input ⟨g / 5, by omega⟩
  let b : Wire (2 * n + 1) g := Wire.input ⟨n + g / 5, by omega⟩
  let c := carryWire n g (g / 5) (Nat.mul_div_le g 5)
  if h0 : g % 5 = 0 then binLine .xor a b
  else if h1 : g % 5 = 1 then binLine .xor (Wire.gate ⟨g - 1, by omega⟩) c
  else if h2 : g % 5 = 2 then binLine .and a b
  else if h3 : g % 5 = 3 then binLine .and (Wire.gate ⟨g - 3, by omega⟩) c
  else binLine .or (Wire.gate ⟨g - 2, by omega⟩) (Wire.gate ⟨g - 1, by omega⟩)

    DefinitionRipple-carry adder#✓fully proved

    Cslib.Circuits.rippleCarryAdder

    The \(n\)-bit ripple-carry adder is the circuit with \(2n + 1\) inputs, \(5n\) binary gates, each an XOR, AND or OR gate, and \(n + 1\) outputs, built as follows. Write \(a_i\) for input \(i\), \(b_i\) for input \(n + i\) and \(c_0\) for input \(2n\), where \(i < n\). For each \(i < n\), gates \(g_{5i}, \dots, g_{5i+4}\) form a full adder for position \(i\): \(g_{5i} = a_i \oplus b_i\), \(g_{5i+1} = g_{5i} \oplus c_i\), \(g_{5i+2} = a_i \wedge b_i\), \(g_{5i+3} = g_{5i} \wedge c_i\) and \(g_{5i+4} = g_{5i+2} \vee g_{5i+3}\), where the carry \(c_i\) is input \(2n\) when \(i = 0\) and gate \(g_{5i-1}\) otherwise. For \(i < n\), output \(i\) is gate \(g_{5i+1}\), and output \(n\) is the carry out \(c_n\): input \(2n\) when \(n = 0\), otherwise gate \(g_{5n-1}\).

    def rippleCarryAdder (n : ℕ) : Circuit arithSignature (2 * n + 1) (n + 1) where
  size := 5 * n
  program := rcaProgram n (5 * n) (Nat.le_refl _)
  outputs o := if h : o.val < n then Wire.gate ⟨5 * o.val + 1, by omega⟩
    else carryWire n (5 * n) n (Nat.le_refl _)

    DefinitionGate-value specification of the ripple-carry adder#✓fully proved

    Cslib.Circuits.rcaSpec

    Let \(x, y\) be \(n\)-bit vectors, \(c\) a bit and \(j\) a natural number, and write \(j = 5i + r\) with \(0 \le r < 5\). Let \(x_i\) and \(y_i\) be bit \(i\) of \(x\) and \(y\) (bit \(0\) is the least significant, and bits at positions \(i \ge n\) are \(0\)), and let \(c_i\) be the carry into position \(i\) when \(x\), \(y\) and \(c\) are added: reading \(x\) and \(y\) as natural numbers, \(c_i = 1\) exactly when \((x \bmod 2^i) + (y \bmod 2^i) + c \ge 2^i\). The specification assigns to \(j\) the bit \(x_i \oplus y_i\) if \(r = 0\), \((x_i \oplus y_i) \oplus c_i\) if \(r = 1\), \(x_i \wedge y_i\) if \(r = 2\), \((x_i \oplus y_i) \wedge c_i\) if \(r = 3\), and \(c_{i+1}\) if \(r = 4\).

    def rcaSpec {n : ℕ} (x y : BitVec n) (c : Bool) (j : ℕ) : Bool :=
  let i := j / 5
  if j % 5 = 0 then x.getLsbD i ^^ y.getLsbD i
  else if j % 5 = 1 then (x.getLsbD i ^^ y.getLsbD i) ^^ BitVec.carry i x y c
  else if j % 5 = 2 then x.getLsbD i && y.getLsbD i
  else if j % 5 = 3 then (x.getLsbD i ^^ y.getLsbD i) && BitVec.carry i x y c
  else BitVec.carry (i + 1) x y c

    Let \(x, y\) be \(n\)-bit vectors and \(c\) a bit, and evaluate the \(n\)-bit ripple-carry adder, with its gates read as Boolean XOR, AND and OR, on the input whose entry \(j\) is bit \(j\) of \(x\) and entry \(n + j\) is bit \(j\) of \(y\) for \(j < n\) (bit \(0\) being the least significant), and whose entry \(2n\) is \(c\). Its output number \(n\) (the last, outputs being numbered from \(0\)) is the carry out of \(x + y + c\): reading \(x\) and \(y\) as natural numbers below \(2^n\), it is \(1\) exactly when \(x + y + c \ge 2^n\).
