    Monotone circuit lower bound for clique

    A monotone circuit uses only and and or gates. Razborov's approximation method (1985) gave the first superpolynomial lower bound for an explicit monotone function, the clique function: every gate is replaced by an approximator from a small family of monotone functions, the Erdős–Rado sunflower lemma keeps each replacement cheap, and the approximators are shown to err on many test graphs (cliques and complete multipartite graphs). Alon and Boppana sharpened the method to an exponential bound. Clique is NP-complete, so a superpolynomial bound for general circuits would separate P from NP; the natural proofs barrier is one obstacle to extending lower-bound methods to general circuits.

    MetaMathlibExt.Complexity.KeyTheorems.RazborovMonotoneClique.cliqueHolds

    For a natural number \(n\) and a bitstring \(x\), read \(x\) as an \(n \times n\) adjacency matrix in row-major order: the entry for a pair \((a, b)\) is the bit of \(x\) at position \(an + b\), where a position beyond the end of \(x\) reads as false. The clique predicate holds for \(n\) and \(x\) when there is a set \(S\) of exactly \(\lfloor n/3 \rfloor\) vertices among \(0, \dots, n - 1\) such that the entry for \((a, b)\) is true for all distinct \(a, b \in S\).

    def cliqueHolds (n : ℕ) (x : List Bool) : Prop :=
  ∃ S : Finset ℕ, S.card = n / 3 ∧ (∀ v ∈ S, v < n) ∧
    ∀ a ∈ S, ∀ b ∈ S, a ≠ b → x.getD (a * n + b) false = true

    DefinitionThe clique function CLIQUE(n, s) on adjacency-matrix bits#✓fully proved

    MetaMathlibExt.Complexity.KeyTheorems.RazborovMonotoneClique.cliqueOfSize

    For a bitstring \(x\) read as an \(n \times n\) adjacency matrix in row-major order (positions beyond the end read as false), \(\mathrm{CLIQUE}(n, s)\) holds when there is a set of \(s\) vertices among \(0, \dots, n-1\) whose entries \((a, b)\) are true for all distinct \(a, b\) in it. Both entries \((a, b)\) and \((b, a)\) are read, so the function is a monotone projection of the usual clique function on \(\binom{n}{2}\) edge variables (identify \((b, a)\) with \((a, b)\)), and lower bounds for the usual function transfer. The clique function on adjacency-matrix bits is the case \(s = \lfloor n/3 \rfloor\).

    def cliqueOfSize (n s : ℕ) (x : List Bool) : Prop :=
  ∃ S : Finset ℕ, S.card = s ∧ (∀ v ∈ S, v < n) ∧
    ∀ a ∈ S, ∀ b ∈ S, a ≠ b → x.getD (a * n + b) false = true

    TheoremAlon–Boppana: monotone circuits for clique need exponential size#●ready to prove

    MetaMathlibExt.Complexity.KeyTheorems.RazborovMonotoneClique.alon_boppana_monotone_clique

    There are \(c > 0\) and \(n_0\) such that for every \(n \ge n_0\), with \(s = \lfloor (n/(8\log_2 n))^{2/3} \rfloor\), every well-formed monotone circuit (input, and, or gates) on \(n^2\) adjacency bits that computes \(\mathrm{CLIQUE}(n, s)\) has at least \(\exp(c\,(n/\log_2 n)^{1/3})\) gates.

    Alon and Boppana obtained this by choosing different approximating lattices in Razborov's method. Their bound counts gates of fan-in two. Inputs here are themselves gates of the list, so a gate refers to at most \(g\) distinct earlier gates, and a circuit with \(g\) gates of any fan-in has a fan-in-two equivalent with at most \(g^2\) gates, which only changes \(c\).

    TheoremRazborov: monotone circuits for clique need superpolynomial size#●ready to prove

    MetaMathlibExt.Complexity.KeyTheorems.RazborovMonotoneClique.razborov_monotone_clique

    For every polynomial \(p\) with natural-number coefficients there is a natural number \(n\) with the following property. Let \(C\) be a well-formed monotone flat circuit on \(n^2\) inputs, that is, every gate of \(C\) is an input variable, an and gate or an or gate (of any fan-in), and refers only to earlier gates. Suppose that for every bitstring \(x\) of length \(n^2\), when input variable \(i\) is given the \(i\)-th bit of \(x\), \(C\) has a last gate with value true if and only if the \(n \times n\) matrix read from \(x\) in row-major order has a clique of size \(\lfloor n/3 \rfloor\), that is, a set \(S \subseteq \{0, \dots, n - 1\}\) of \(\lfloor n/3 \rfloor\) vertices whose entries \((a, b)\) are true for all distinct \(a, b \in S\). Then \(C\) has more than \(p(n^2)\) gates.

    Razborov's theorem concerns \(\mathrm{CLIQUE}(m, s)\), the existence of an \(s\)-clique in a graph on \(m\) vertices: monotone circuits of fan-in two need size \(m^{\Omega(\log m)}\) when \(s\) is about \((\log m)/4\), and size \(\Omega(m^s/(\log m)^{2s})\) for fixed \(s\). His approximation method replaces every gate by an approximator from a small lattice of monotone functions and shows that each replacement errs on few test inputs (cliques and complete \((s-1)\)-partite graphs), while every approximator errs on many of them. Alon and Boppana sharpened the method to the exponential bound \(\exp(\Omega((m/\log m)^{1/3}))\) for \(s\) about \((m/(8\log m))^{2/3}\).

    The statement above, for cliques of size \(\lfloor n/3 \rfloor\), follows by padding. Setting to true every input bit that involves \(\lfloor n/3 \rfloor - s\) chosen vertices makes them universal, and turns a monotone circuit for the \(\lfloor n/3 \rfloor\)-clique function on \(n\) vertices into one, no larger after constant propagation, for \(s\)-cliques on the remaining \(m \ge 2n/3\) vertices. Gates here have unbounded fan-in. Inputs are themselves gates of the list, so a gate refers to at most \(g\) distinct earlier gates, and a circuit with \(g\) gates has a fan-in-two equivalent with at most \(g^2\) gates; superpolynomial bounds transfer.

    public theorem_wanted razborov_monotone_clique :

    Background
    Background
    • Erdős–Rado sunflower lemma: bounds the errors of the approximators in the approximation method.
    • Shannon's circuit size lower bound: almost all Boolean functions need large circuits, while no superpolynomial bound is known for an explicit function in unrestricted circuits; monotone circuits are the restricted model where Razborov's method succeeds.
    Sources
    Sources
    • A. A. Razborov, "Lower bounds on the monotone complexity of some Boolean functions", Soviet Mathematics Doklady 31 (1985), 354-357.
    • N. Alon and R. B. Boppana, "The monotone circuit complexity of Boolean functions", Combinatorica 7 (1987), 1-22, Section 1 (statement of Razborov's bounds) and Section 3 (exponential bound for clique).
