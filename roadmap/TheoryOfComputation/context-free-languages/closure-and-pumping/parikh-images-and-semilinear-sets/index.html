    DefinitionLinear combination of period vectors#✓fully proved

    Cslib.Language.linComb

    The linear combination of a list of period vectors with a coefficient list c: pair the two lists position by position and sum the scaled periods, and reject mismatched lengths by returning 0 (the length guard is checked up front, before the recursion, so a shorter coefficient list cannot silently truncate and a longer one cannot silently drop coefficients). Coefficients are indexed by position in P, not by period value, so duplicate periods get independent coefficients: for P = [p, p], linComb P [1, 0] = p, not 2 • p.

    def linComb (P : List (T → ℕ)) (c : List ℕ) : T → ℕ :=
  if P.length = c.length then linCombAux P c else 0
where
  /-- The unguarded recursion behind `linComb`: pair the two lists
  position by position. Used only behind the length guard in
  `linComb`, so the two lists have equal length here. -/
  linCombAux : List (T → ℕ) → List ℕ → T → ℕ
    | [], _ => 0
    | _, [] => 0
    | p :: P, n :: c => n • p + linCombAux P c

    DefinitionLinear set of vectors#✓fully proved

    Cslib.Language.IsLinear

    A set of vectors is linear when it consists of a base vector plus arbitrary nonnegative combinations of finitely many period vectors, with one coefficient per position in the period list.

    def IsLinear (S : Set (T → ℕ)) : Prop :=
