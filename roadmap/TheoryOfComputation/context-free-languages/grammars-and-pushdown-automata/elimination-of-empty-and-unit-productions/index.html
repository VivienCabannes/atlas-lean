    Cslib.Language.nullableDeletions

    For a context-free grammar \(g\) and a sentential form \(u\), the nullable deletions of \(u\) are the forms obtained from \(u\) by deleting any selection of occurrences of nullable nonterminals, possibly none and possibly all, keeping the remaining symbols in order. They form a finite set.

    noncomputable def nullableDeletions (g : ContextFreeGrammar T) :
    List (Symbol T g.NT) → Finset (List (Symbol T g.NT))
  | [] => {[]}
  | Symbol.terminal a :: u =>
    (nullableDeletions g u).image (Symbol.terminal a :: ·)
  | Symbol.nonterminal A :: u =>
    (nullableDeletions g u).image (Symbol.nonterminal A :: ·) ∪
      (if Nullable g A then nullableDeletions g u else ∅)
    def Nullable (g : ContextFreeGrammar T) (A : g.NT) :
    Prop :=
  [] ∈ languageFrom g A

    DefinitionElimination of \(\varepsilon\)-productions#✓fully proved

    Cslib.Language.epsGrammar

    For a context-free grammar \(g\), the grammar obtained from \(g\) by eliminating \(\varepsilon\)-productions has the same nonterminals and the same initial nonterminal as \(g\). Its productions are the productions \(A \to \alpha'\) such that \(g\) has a production \(A \to \alpha\), the form \(\alpha'\) is obtained from \(\alpha\) by deleting some (possibly no) occurrences of nullable nonterminals (those deriving the empty word in \(g\)), and \(\alpha'\) is nonempty.

    noncomputable def epsGrammar (g : ContextFreeGrammar T) :
    ContextFreeGrammar T where
  NT := g.NT
  initial := g.initial
  rules := g.rules.biUnion fun r =>
    ((nullableDeletions g r.output).filter (· ≠ [])).image
      (fun α => ⟨r.input, α⟩)
