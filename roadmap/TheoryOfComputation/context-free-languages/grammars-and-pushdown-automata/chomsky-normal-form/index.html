    Chomsky normal form

    DefinitionChomsky normal form#✓fully proved

    Cslib.Language.IsChomskyNormalForm

    A grammar is in Chomsky normal form when every production has output either two nonterminals, a single terminal, or the empty word with the initial nonterminal on the left; and either the initial nonterminal occurs in no output (so an empty production cannot leak the empty word to other nonterminals) or there are no empty outputs at all.

    def IsChomskyNormalForm (g : ContextFreeGrammar T) : Prop :=
  (∀ r ∈ g.rules,
    (∃ B C, r.output = [Symbol.nonterminal B, Symbol.nonterminal C]) ∨
    (∃ a, r.output = [Symbol.terminal a]) ∨
    (r.output = [] ∧ r.input = g.initial)) ∧
  ((∀ r ∈ g.rules, Symbol.nonterminal g.initial ∉ r.output) ∨
    ∀ r ∈ g.rules, r.output ≠ [])

    Cslib.Language.toCnfNT

    Let \(G\) be a context-free grammar with nonterminals \(N\), and let \(t_0, \dots, t_{k-1}\) be the list of terminals occurring in the production outputs of \(G\). This map sends a symbol of \(G\) to an element of \(N \sqcup \mathbb{N}\): a nonterminal \(A\) goes to \(A\), and a terminal \(a\) goes to the least index \(i\) with \(t_i = a\), or to \(k\) if \(a\) does not occur in the list.

    Cslib.Language.fromCnfNT

    Let \(G\) be a context-free grammar with nonterminals \(N\) and initial nonterminal \(S\), and let \(t_0, \dots, t_{k-1}\) be the list of terminals occurring in the production outputs of \(G\). This map sends an element of \(N \sqcup \mathbb{N}\) (a basic nonterminal of the binarized grammar) to a symbol of \(G\): a nonterminal \(A \in N\) goes to \(A\), an index \(i < k\) goes to the terminal \(t_i\), and an index \(i \ge k\) goes to the nonterminal \(S\).

    Indices \(i \ge k\) never arise from encoding nonterminals of \(G\) or terminals occurring in the production outputs of \(G\).

    | some a => .terminal a
    | none => .nonterminal g.initial

    DefinitionHead of a binarized output#✓fully proved

    Cslib.Language.cnfHead

    Let \(g\) be a context-free grammar and let \(a_0, a_1, \dots\) be its list of terminals occurring in production outputs. For a list \(\sigma\) of basic symbols (each a nonterminal of \(g\) or a natural number, a terminal wrapper), the head \(h(\sigma)\) is the following form over the nonterminals of the binarized grammar (basic symbols and chain nonterminals \(\langle\tau\rangle\) for lists \(\tau\) of basic symbols): \(h(XY) = XY\) for two basic symbols \(X, Y\); \(h(XYZ\tau) = X\langle YZ\tau\rangle\) for basic symbols \(X, Y, Z\) and a list \(\tau\); \(h(i) = a_i\) for a single natural number \(i\) less than the length of the list; and \(h(\sigma)\) is empty in every other case (the empty list, a single nonterminal of \(g\), or a single out-of-range index).

    noncomputable def cnfHead : List (g.NT ⊕ ℕ) →
    List (Symbol T ((g.NT ⊕ ℕ) ⊕ List (g.NT ⊕ ℕ)))
  | [] => []
  | [B] => match B with
    | .inr i => match (grammarTerminals g)[i]? with
      | some a => [Symbol.terminal a]
      | none => []
    | .inl _ => []
  | [B, C] => [Symbol.nonterminal (.inl B), Symbol.nonterminal (.inl C)]
  | B :: C :: D :: σ =>
    [Symbol.nonterminal (.inl B),
      Symbol.nonterminal (.inr (C :: D :: σ))]

    DefinitionBinarization of a grammar#✓fully proved

    Cslib.Language.cnfGrammar

    Let \(g\) be a context-free grammar with nonterminals \(N\) and initial nonterminal \(S\), and let \(t_0, \dots, t_{k-1}\) be the list of terminals occurring in the production outputs of \(g\). Encode each symbol of a production output of \(g\) as a basic symbol in \(N \sqcup \mathbb{N}\): a nonterminal \(A\) as \(A\), and a terminal \(a\) as the least index \(i\) with \(t_i = a\). The binarized grammar of \(g\) has as nonterminals the basic symbols together with a chain nonterminal \(\langle\tau\rangle\) for every list \(\tau\) of basic symbols, and its initial nonterminal is \(S\). For a list \(\sigma\) of basic symbols, its head \(h(\sigma)\) is defined by \(h(XY) = XY\) and \(h(XYZ\tau) = X\langle YZ\tau\rangle\) for basic symbols \(X, Y, Z\) and a list \(\tau\), \(h(i) = t_i\) for a single index \(i < k\), and \(h(\sigma)\) empty in every other case. For every production \(A \to \alpha\) of \(g\), with \(\sigma\) the encoding of \(\alpha\) symbol by symbol, the binarized grammar has the production \(A \to h(\sigma)\), the production \(\langle\tau\rangle \to h(\tau)\) for every suffix \(\tau\) of \(\sigma\) (including \(\sigma\) itself) with at least two entries, and the production \(i \to a\) for every terminal \(a\) occurring in \(\alpha\), where \(i\) is the encoding of \(a\); it has no other productions.

    This construction is meant for reduced grammars, which have no empty outputs and no outputs consisting of a single nonterminal: on other grammars such outputs get the empty head, and in general neither the language nor Chomsky normal form is preserved.

    @[reducible] noncomputable def cnfGrammar (g : ContextFreeGrammar T) :
    ContextFreeGrammar T where
  NT := (g.NT ⊕ ℕ) ⊕ List (g.NT ⊕ ℕ)
  initial := .inl (.inl g.initial)
  rules := g.rules.biUnion fun r =>
    {⟨.inl (.inl r.input), cnfHead (r.output.map toCnfNT)⟩} ∪
    (((r.output.map toCnfNT).tails.filter fun σ => 2 ≤ σ.length).toFinset.image
      fun σ => ⟨.inr σ, cnfHead σ⟩) ∪
    (((r.output.filterMap fun s => match s with
        | .terminal a => some a
        | .nonterminal _ => none).toFinset.image
      fun a => ⟨.inl (.inr ((grammarTerminals g).idxOf a)),
        [Symbol.terminal a]⟩))
    noncomputable def cnfHead : List (g.NT ⊕ ℕ) →

  | [] => []
  | [B] => match B with

      | none => []
    | .inl _ => []

  | B :: C :: D :: σ =>
    [Symbol.nonterminal (.inl B),

    DefinitionValuation of the binarized grammar by yields#✓fully proved

    Cslib.Language.cnfValuation

    Let \(g\) be a context-free grammar and let \(a_0, a_1, \dots\) be its list of terminals occurring in production outputs. A basic symbol is a nonterminal of \(g\) or a natural number (a terminal wrapper); the nonterminals of the binarized grammar are the basic symbols together with a chain nonterminal \(\langle\sigma\rangle\) for every list \(\sigma\) of basic symbols. Decode a basic symbol as a symbol of \(g\): a nonterminal \(A\) of \(g\) as \(A\), a natural number \(i\) less than the length of the list as the terminal \(a_i\), and any other natural number as the initial nonterminal of \(g\). The valuation assigns to a basic symbol \(X\) the set of words that the decoding of \(X\) yields in \(g\), and to a chain nonterminal \(\langle\sigma\rangle\) the set of words that the symbolwise decoding of \(\sigma\) yields in \(g\).

    noncomputable def cnfValuation :
    (g.NT ⊕ ℕ) ⊕ List (g.NT ⊕ ℕ) → Language T
  | .inl B => {w | Yields g [fromCnfNT B] w}
  | .inr σ => {w | Yields g (σ.map fromCnfNT) w}
    inductive Yields (g : ContextFreeGrammar T) : List (Symbol T g.NT) → List T → Prop
  | nil : Yields g [] []
  | terminal (a : T) {u : List (Symbol T g.NT)} {w : List T} (h : Yields g u w) :
      Yields g (Symbol.terminal a :: u) (a :: w)
  | nonterminal {r : ContextFreeRule T g.NT} (hr : r ∈ g.rules)
      {u : List (Symbol T g.NT)} {w₁ w₂ : List T}
      (hout : Yields g r.output w₁) (hrest : Yields g u w₂) :
      Yields g (Symbol.nonterminal r.input :: u) (w₁ ++ w₂)
