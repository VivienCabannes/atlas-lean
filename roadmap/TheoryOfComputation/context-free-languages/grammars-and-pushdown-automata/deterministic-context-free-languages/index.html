    Cslib.Automata.PDA.IsDeterministic

    A pushdown automaton is deterministic when every transition set has at most one element, and an available ε-transition precludes every consuming transition from the same state and stack symbol.

    def PDA.IsDeterministic (M : PDA T σ Γ) : Prop :=
  (∀ (q : σ) (γ : Γ), (M.step q none γ).card ≤ 1) ∧
    (∀ (q : σ) (a : T) (γ : Γ), (M.step q (some a) γ).card ≤ 1) ∧
    ∀ (q : σ) (γ : Γ), (M.step q none γ).Nonempty →
      ∀ (a : T), M.step q (some a) γ = ∅
    structure PDA (T : Type*) (σ : Type*) (Γ : Type*) where
  /-- The finitely branching transition function. -/
  step : σ → Option T → Γ → Finset (σ × List Γ)
  /-- The initial state. -/
  start : σ
  /-- The sole initial stack symbol. -/
  startStack : Γ

    DefinitionDFA recognizing end-marker encodings#✓fully proved

    Cslib.Language.endMarkerDFA

    The DFA for the encodings: state inl false while reading left letters, inl true after the end marker (the accepting state), and inr () dead once anything follows the end marker.

    noncomputable def endMarkerDFA : DFA (T ⊕ Unit) (Bool ⊕ Unit) where
  step := fun q c => match q, c with
    | .inl false, .inl _ => .inl false
    | .inl false, .inr _ => .inl true
    | .inl true, _ => .inr ()
    | .inr _, _ => .inr ()
  start := .inl false
  accept := {.inl true}

    DefinitionDeterministic context-free language#✓fully proved

    Cslib.Language.IsDeterministicContextFree

    A language is deterministic context-free when some deterministic pushdown automaton with finite state and stack alphabets, whose transitions consume letters from a finite set, accepts by empty stack exactly the end-marker encodings of its words.

    def IsDeterministicContextFree (L : Language T) : Prop :=
  ∃ (σ Γ : Type) (_ : Fintype σ) (_ : Fintype Γ) (M : PDA (T ⊕ Unit) σ Γ),
    M.IsDeterministic ∧
      (∃ T₀ : Finset (T ⊕ Unit), ∀ (p : σ) (a : T ⊕ Unit) (γ : Γ),
        a ∉ T₀ → M.step p (some a) γ = ∅) ∧
      M.accepts = (fun w : List T => endMarkerEncode w) '' L

  /-- The sole initial stack symbol. -/
