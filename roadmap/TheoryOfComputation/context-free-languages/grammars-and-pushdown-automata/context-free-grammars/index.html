    DefinitionInterpretation of a sentential form#✓fully proved

    Cslib.Language.evalForm

    Under an assignment \(V\) of languages to nonterminals, a sentential form denotes the concatenation, in order, of the languages its symbols denote: a terminal \(a\) denotes the language containing only the one-letter word \(a\), and a nonterminal \(A\) denotes \(V(A)\). The empty sentential form denotes the language containing only the empty word.

    def evalForm (V : N → Language T) : List (Symbol T N) → Language T
  | [] => 1
  | s :: u => evalSymbol V s * evalForm V u
    def evalSymbol (V : N → Language T) : Symbol T N → Language T
  | .terminal a => {[a]}
  | .nonterminal A => V A

    DefinitionValuation of a grammar#✓fully proved

    Cslib.Language.IsValuation

    Let \(g\) be a context-free grammar with terminals \(T\), and let \(V\) assign a language over \(T\) to each nonterminal of \(g\). Interpret a sentential form under \(V\) by sending each terminal \(a\) to the language \(\{a\}\) of the one-letter word \(a\) and each nonterminal \(B\) to \(V(B)\), and concatenating these languages in order (the empty form is interpreted as \(\{\varepsilon\}\)). Then \(V\) is a valuation of \(g\) when, for every production \(A \to u\) of \(g\), the interpretation of \(u\) under \(V\) is contained in \(V(A)\).

    def IsValuation (g : ContextFreeGrammar T) (V : g.NT → Language T) : Prop :=
  ∀ r ∈ g.rules, evalForm V r.output ≤ V r.input
    def evalForm (V : N → Language T) : List (Symbol T N) → Language T
  | [] => 1
  | s :: u => evalSymbol V s * evalForm V u
