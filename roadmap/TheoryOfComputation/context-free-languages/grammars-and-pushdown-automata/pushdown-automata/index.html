    Cslib.Automata.PDA

    A pushdown automaton over an input alphabet \(T\), with states in \(\sigma\) and stack alphabet \(\Gamma\), consists of a transition function, a start state in \(\sigma\) and an initial stack symbol in \(\Gamma\). The transition function assigns to each state \(q\), each input option (a letter of \(T\), or none for an \(\varepsilon\)-transition) and each popped stack symbol \(\gamma\) a finite set of pairs \((q', u)\) of a next state \(q'\) and a list \(u\) of stack symbols to push.

    This is the generalized model: the state and stack types themselves are unrestricted, and only each transition is finitely branching. A standard (textbook) pushdown automaton is additionally finitely supported; without that, the language it accepts can be an arbitrary language, so the conversion from pushdown automata back to context-free grammars needs finiteness hypotheses.

    structure PDA (T : Type*) (σ : Type*) (Γ : Type*) where
  /-- The finitely branching transition function. -/
  step : σ → Option T → Γ → Finset (σ × List Γ)
  /-- The initial state. -/
  start : σ
  /-- The sole initial stack symbol. -/
  startStack : Γ

    Cslib.Automata.PDA.Step

    Write a configuration of a pushdown automaton \(M\) as \((q, w, s)\): state \(q\), remaining input \(w\), and stack \(s\) listed from the top. A configuration \((q, w, \gamma s)\) steps to \((q', w, u s)\) whenever \((q', u)\) is an \(\varepsilon\)-transition of \(M\) from \(q\) with top symbol \(\gamma\), and a configuration \((q, a w, \gamma s)\) steps to \((q', w, u s)\) whenever \((q', u)\) is a transition of \(M\) from \(q\) on the input letter \(a\) with top symbol \(\gamma\). There are no other steps: a step pops the top symbol, consumes at most one input letter, and pushes the list \(u\) with its head as the new top.

    inductive Step (M : PDA T σ Γ) : Config T σ Γ → Config T σ Γ → Prop
  | epsilon {q q' : σ} {w : List T} {γ : Γ} {s pushed : List Γ}
      (h : (q', pushed) ∈ M.step q none γ) :
      Step M ⟨q, w, γ :: s⟩ ⟨q', w, pushed ++ s⟩
  | consume {q q' : σ} {a : T} {w : List T} {γ : Γ} {s pushed : List Γ}
      (h : (q', pushed) ∈ M.step q (some a) γ) :
      Step M ⟨q, a :: w, γ :: s⟩ ⟨q', w, pushed ++ s⟩

    DefinitionFinitely supported pushdown automata#✓fully proved

    Cslib.Automata.PDA.FinitelySupported

    A pushdown automaton \(M\) is finitely supported when there are finite sets \(\sigma_0\) of states, \(\Gamma_0\) of stack symbols and \(T_0\) of input letters such that the start state lies in \(\sigma_0\), the initial stack symbol lies in \(\Gamma_0\), every transition from a state in \(\sigma_0\) that pops a symbol in \(\Gamma_0\) (on any input letter or on \(\varepsilon\)) moves to a state in \(\sigma_0\) and pushes only symbols in \(\Gamma_0\), and there is no transition from a state in \(\sigma_0\) popping a symbol in \(\Gamma_0\) that consumes an input letter outside \(T_0\).

    This is the finiteness condition of a standard pushdown automaton; computations from the initial configuration then only ever visit finitely many states, push finitely many stack symbols, and respond to finitely many input letters.

    def FinitelySupported (M : PDA T σ Γ) : Prop :=
  ∃ (σ₀ : Finset σ) (Γ₀ : Finset Γ) (T₀ : Finset T),
    M.start ∈ σ₀ ∧ M.startStack ∈ Γ₀ ∧
    (∀ q ∈ σ₀, ∀ (opt : Option T) {γ : Γ}, γ ∈ Γ₀ →
      ∀ y ∈ M.step q opt γ, y.1 ∈ σ₀ ∧ ∀ γ' ∈ y.2, γ' ∈ Γ₀) ∧
    ∀ q ∈ σ₀, ∀ {a : T}, a ∉ T₀ → ∀ {γ : Γ}, γ ∈ Γ₀ →
      M.step q (some a) γ = ∅

    DefinitionLifting a stack to a set of stack symbols#✓fully proved

    Cslib.Automata.PDA.liftStack

    Given a finite set \(\Gamma_0\) of stack symbols and a stack \(s = \gamma_1 \cdots \gamma_n\) all of whose symbols lie in \(\Gamma_0\), the lifted stack is the same list \(\gamma_1 \cdots \gamma_n\), in the same order, regarded as a stack over the alphabet \(\Gamma_0\).

    def liftStack (Γ₀ : Finset Γ) : (s : List Γ) → (∀ γ ∈ s, γ ∈ Γ₀) →

  | γ :: s, h =>

      liftStack Γ₀ s (fun γ' hγ' => h γ' (List.mem_cons_of_mem γ hγ'))

    DefinitionRestricting the stack alphabet of a pushdown automaton#✓fully proved

    Cslib.Automata.PDA.restrict

    Let \(M\) be a pushdown automaton with stack alphabet \(\Gamma\), and let \(\Gamma_0 \subseteq \Gamma\) be a finite set of stack symbols that contains the initial stack symbol of \(M\) and is closed for \(M\). The restriction of \(M\) to \(\Gamma_0\) is the pushdown automaton with the same input alphabet, states and start state as \(M\), stack alphabet \(\Gamma_0\), and the initial stack symbol of \(M\) as its initial stack symbol. Its transitions from a state \(q\) on an input option \(o\) with top symbol \(\gamma \in \Gamma_0\) are the transitions \((q', u)\) of \(M\) from \(q\) on \(o\) with top symbol \(\gamma\), with the pushed list \(u\) read as a list over \(\Gamma_0\); closedness guarantees that every symbol of \(u\) lies in \(\Gamma_0\).

    The restricted automaton has a finite stack alphabet and accepts the same language as \(M\).

    noncomputable def restrict (M : PDA T σ Γ) (Γ₀ : Finset Γ)
    (hstart : M.startStack ∈ Γ₀) (hclosed : M.ClosedUnder Γ₀) :
    PDA T σ {γ // γ ∈ Γ₀} where
  step q opt γ :=
    (M.step q opt γ.1).attach.image fun y =>
      (y.1.1, liftStack Γ₀ y.1.2 (fun γ' hγ' => hclosed q opt γ.2 y.1 y.2 γ' hγ'))
  start := M.start
  startStack := ⟨M.startStack, hstart⟩
