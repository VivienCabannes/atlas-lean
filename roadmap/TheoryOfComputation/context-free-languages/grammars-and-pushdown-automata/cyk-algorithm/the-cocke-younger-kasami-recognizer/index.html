    Cslib.Language.no_empty_rule_of_mem_output

    Let \(g\) be a context-free grammar in Chomsky normal form. If a nonterminal \(B\) occurs in the output of some production of \(g\), then \(g\) has no production \(B \to \varepsilon\).

    Such a production would have the initial nonterminal on the left, which then occurs in an output while an empty production exists.

    theorem no_empty_rule_of_mem_output (hg : IsChomskyNormalForm g) {r : ContextFreeRule T g.NT}
    (hr : r ∈ g.rules) {B : g.NT} (hB : Symbol.nonterminal B ∈ r.output) :
    ¬ ∃ r' ∈ g.rules, r'.input = B ∧ r'.output = []
    def IsChomskyNormalForm (g : ContextFreeGrammar T) : Prop :=
  (∀ r ∈ g.rules,
    (∃ B C, r.output = [Symbol.nonterminal B, Symbol.nonterminal C]) ∨
    (∃ a, r.output = [Symbol.terminal a]) ∨
    (r.output = [] ∧ r.input = g.initial)) ∧
  ((∀ r ∈ g.rules, Symbol.nonterminal g.initial ∉ r.output) ∨

    Cslib.Language.yields_nonterminal_iff_of_ne_nil

    Let \(g\) be a context-free grammar in Chomsky normal form, \(A\) a nonterminal and \(w\) a nonempty word. Then \(A\) yields \(w\) if and only if \(g\) has a production \(A \to a\) with \(a\) a terminal and \(w = a\), or a production \(A \to BC\) with nonterminals \(B\) and \(C\) and nonempty words \(w_1\) and \(w_2\) such that \(w = w_1 w_2\), \(B\) yields \(w_1\) and \(C\) yields \(w_2\).

    theorem yields_nonterminal_iff_of_ne_nil (hg : IsChomskyNormalForm g) {A : g.NT} {w : List T}
    (hw : w ≠ []) :

      ((∃ a, r.output = [.terminal a] ∧ w = [a]) ∨
        ∃ B C w₁ w₂, r.output = [.nonterminal B, .nonterminal C] ∧ w = w₁ ++ w₂ ∧
          w₁ ≠ [] ∧ w₂ ≠ [] ∧ Yields g [.nonterminal B] w₁ ∧ Yields g [.nonterminal C] w₂)

    DefinitionWhen a production output fits a word#✓fully proved

    Cslib.Language.cykFits

    Let \(f\) assign a cell (a finite set of nonterminals) to every word. A production output fits a word \(w\) with respect to \(f\) exactly in two cases: the output is a single terminal \(a\) and \(w\) is the one-letter word \(a\); or the output is a pair of nonterminals \(B C\) and there is some \(i\) with \(0 < i < |w|\) such that \(B\) lies in the cell of the first \(i\) letters of \(w\) and \(C\) lies in the cell of the remaining letters. No other output fits any word.

    def cykFits (f : List T → Finset g.NT) (w : List T) : List (Symbol T g.NT) → Bool
  | [.terminal a] => decide (w = [a])
  | [.nonterminal B, .nonterminal C] =>
      (List.range w.length).any fun i =>
        decide (0 < i) && decide (B ∈ f (w.take i)) && decide (C ∈ f (w.drop i))
  | _ => false

    Given an assignment \(f\) of a cell (a finite set of nonterminals of \(g\)) to every word, the cell of a word \(w\) built from \(f\) is the set of left-hand sides of those productions of \(g\) whose outputs fit \(w\) with respect to \(f\).

    Cslib.Language.cykCell

    The depth-\(n\) CYK cell of a word \(w\) is defined by recursion on \(n\): at depth \(0\) every cell is empty, and the depth-\((n + 1)\) cell of \(w\) is the CYK cell of \(w\) built from the depth-\(n\) cells of all words. Cells are recomputed without sharing.

    def cykCell : ℕ → List T → Finset g.NT
  | 0, _ => ∅
  | n + 1, w => cykCellFrom g (cykCell n) w

    DefinitionThe CYK table#✓fully proved

    Cslib.Language.cykTable

    The CYK table of a word \(w\) up to length \(l\) is a list of pairs of a word and a cell, defined by recursion on \(l\). Up to length \(0\) it is empty. The table up to length \(l + 1\) is the table \(t\) up to length \(l\) followed by one entry for each position \(i\) (counted from \(0\)) with \(i + l + 1 \le |w|\), in increasing order of \(i\): the factor \(u\) of \(w\) of length \(l + 1\) starting at position \(i\), together with the CYK cell of \(u\) built from the cells recorded in \(t\).

    def cykTable (w : List T) : ℕ → List (List T × Finset g.NT)
  | 0 => []
  | l + 1 =>
      let tbl := cykTable w l
      tbl ++ (List.range (w.length - l)).map fun i =>
        let u := (w.drop i).take (l + 1)
        (u, cykCellFrom g (cykLookup tbl) u)
    def cykCellFrom (f : List T → Finset g.NT) (w : List T) : Finset g.NT :=
