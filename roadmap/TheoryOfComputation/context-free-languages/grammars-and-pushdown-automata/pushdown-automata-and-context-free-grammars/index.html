    DefinitionTransitions of the grammar-simulating pushdown automaton#✓fully proved

    Cslib.Language.cfgStep

    Let \(g\) be a context-free grammar over an alphabet \(T\). To the single state, an input option (a letter of \(T\), or none for an \(\varepsilon\)-transition) and a popped symbol of \(g\) (a terminal or a nonterminal), this assigns a finite set of pairs of the state and a list of symbols of \(g\) to push. Popping a nonterminal \(A\) with no input gives, for each production of \(g\) with left-hand side \(A\), the pair pushing its right-hand side. Popping a terminal \(b\) while reading the letter \(a\) gives the single pair pushing nothing if \(a = b\), and the empty set otherwise. Popping a nonterminal while reading a letter, or a terminal with no input, gives the empty set.

    noncomputable def cfgStep (g : ContextFreeGrammar T) :
    Unit → Option T → Symbol T g.NT → Finset (Unit × List (Symbol T g.NT))
  | _, none, .nonterminal A =>
      (g.rules.filter fun r => r.input = A).image fun r => ((), r.output)
  | _, some a, .terminal b => if a = b then {((), [])} else ∅
  | _, some _, .nonterminal _ => ∅
  | _, none, .terminal _ => ∅

    DefinitionThe pushdown automaton simulating a context-free grammar#✓fully proved

    Cslib.Language.cfgPDA

    For a context-free grammar \(g\) over an alphabet \(T\), this is the pushdown automaton with input alphabet \(T\), a single state, the terminals and nonterminals of \(g\) as stack alphabet, and the initial nonterminal of \(g\) as initial stack symbol. Popping a nonterminal \(A\) on an \(\varepsilon\)-transition, it may push the right-hand side of any production of \(g\) with left-hand side \(A\) (whose first symbol becomes the new top); popping a terminal \(a\) while reading the input letter \(a\), it pushes nothing. It has no other transitions.

    noncomputable def cfgPDA (g : ContextFreeGrammar T) :
    PDA T Unit (Symbol T g.NT) where
  step := cfgStep g
  start := ()
  startStack := .nonterminal g.initial

    DefinitionChain of triple nonterminals#✓fully proved

    Cslib.Language.chainForm

    Write \((p, \gamma, q)\) for the nonterminal symbol given by states \(p, q\) and a stack symbol \(\gamma\) (the nonterminals of the triple grammar are these triples and one extra initial nonterminal). The chain form of a list \(\gamma_1 \cdots \gamma_k\) of stack symbols along a nonempty list \(s_0, s_1, \dots, s_m\) of states is the word \((s_0, \gamma_1, s_1)(s_1, \gamma_2, s_2) \cdots (s_{j-1}, \gamma_j, s_j)\) with \(j = \min(k, m)\): consecutive states bracket each stack symbol. Along the empty list of states the chain form is the empty word. In the intended use \(m = k\), so every stack symbol is bracketed.

    def chainForm : List Γ → List σ → List (Symbol T (Option (σ × Γ × σ)))
  | [], _ => []
  | _ :: _, [] => []
  | _ :: _, _ :: [] => []
  | γ :: γs, p :: q :: ss =>
    Symbol.nonterminal (some (p, γ, q)) :: chainForm γs (q :: ss)

    DefinitionLists of states of a given length#✓fully proved

    Cslib.Language.stateLists

    For a finite set \(\sigma\) of states and a natural number \(n\), this is the finite set of all lists of length \(n\) with entries in \(\sigma\). It is built recursively: for \(n = 0\) it contains only the empty list, and for \(n + 1\) it consists of the lists obtained by putting a state \(p \in \sigma\) in front of a list from the set for \(n\).

    noncomputable def stateLists : ℕ → Finset (List σ)
  | 0 => {[]}
  | n + 1 => (Finset.univ ×ˢ stateLists n).image fun x => x.1 :: x.2

    DefinitionProduction of the triple grammar for a transition#✓fully proved

    Cslib.Language.stepRule

    Let \(p\) and \(r\) be states, \(\gamma\) a stack symbol, \(a\) an optional input letter, \(\varepsilon_1 \cdots \varepsilon_k\) a list of stack symbols and \(s_1, \dots, s_m\) a list of states. Write \(s_0 = r\) and let \(q = s_m\) be the last state of the list \(s_0, s_1, \dots, s_m\) (so \(q = r\) when \(m = 0\)). The production has left-hand side the nonterminal \((p, \gamma, q)\), and its right-hand side is the letter \(a\) (nothing if \(a\) is absent) followed by the nonterminals \((s_{i-1}, \varepsilon_i, s_i)\) for \(i = 1, \dots, \min(k, m)\) in order.

    It encodes a transition that in state \(p\), reading \(a\) (or no letter), pops \(\gamma\), moves to state \(r\) and pushes \(\varepsilon_1 \cdots \varepsilon_k\); the triple grammar uses it with \(m = k\).

    def stepRule (p : σ) (γ : Γ) (opt : Option T) (r : σ) (εs : List Γ)
    (ss : List σ) : ContextFreeRule T (Option (σ × Γ × σ)) :=
  ⟨some (p, γ, (r :: ss).getLast (List.cons_ne_nil r ss)),
    optTerms opt ++ chainForm εs (r :: ss)⟩
    def optTerms (opt : Option T) : List (Symbol T (Option (σ × Γ × σ))) :=
  opt.toList.map Symbol.terminal

    DefinitionTriple grammar of a pushdown automaton#✓fully proved

    Cslib.Language.pdaGrammar

    Let \(M\) be a pushdown automaton over the alphabet \(T\) with a finite set \(\sigma\) of states, a finite stack alphabet \(\Gamma\), start state \(q_0\) and initial stack symbol \(Z_0\), and let \(T_0\) be a finite set of letters. The triple grammar of \(M\) and \(T_0\) is the context-free grammar over \(T\) whose nonterminals are an initial nonterminal \(S\) and the triples \((p, \gamma, q)\) with \(p, q \in \sigma\) and \(\gamma \in \Gamma\). Its productions are the start productions \(S \to (q_0, Z_0, q)\) for every state \(q\), and the transition productions: for every state \(p\), stack symbol \(\gamma\), input \(a\) that is \(\varepsilon\) or a letter of \(T_0\), transition of \(M\) from \(p\) on \(a\) popping \(\gamma\) that moves to a state \(r\) and pushes \(\gamma_1 \cdots \gamma_k\), and all states \(s_1, \dots, s_k\), writing \(s_0 = r\), the production

    \[(p, \gamma, s_k) \to a\,(s_0, \gamma_1, s_1)(s_1, \gamma_2, s_2) \cdots (s_{k-1}, \gamma_k, s_k)\]

    where \(a\) is omitted when it is \(\varepsilon\) (for \(k = 0\) this is \((p, \gamma, r) \to a\)).

    The nonterminal \((p, \gamma, q)\) is meant to derive the words that take \(M\) from state \(p\) with stack \(\gamma\) to state \(q\) with empty stack; transitions on letters outside \(T_0\) are not used.

    noncomputable def pdaGrammar (M : PDA T σ Γ) (T₀ : Finset T) :
    ContextFreeGrammar T where
  NT := Option (σ × Γ × σ)
  initial := none
  rules :=
    (Finset.univ.image fun q =>
        (⟨none, [Symbol.nonterminal (some (M.start, M.startStack, q))]⟩ :
          ContextFreeRule T (Option (σ × Γ × σ)))) ∪
      (Finset.univ.biUnion fun p => Finset.univ.biUnion fun γ =>
        (insert none (T₀.image some)).biUnion fun opt =>
          (M.step p opt γ).biUnion fun y =>
            (stateLists y.2.length).image fun ss =>
              stepRule p γ opt y.1 y.2 ss)
    structure PDA (T : Type*) (σ : Type*) (Γ : Type*) where
  /-- The finitely branching transition function. -/
  step : σ → Option T → Γ → Finset (σ × List Γ)
  /-- The initial state. -/
  start : σ
  /-- The sole initial stack symbol. -/
  startStack : Γ
