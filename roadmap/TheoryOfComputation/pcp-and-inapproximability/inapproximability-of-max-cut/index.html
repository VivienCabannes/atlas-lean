    MetaMathlibExt.Complexity.KeyTheorems.MaxCutNoPTAS.maxCutVal

    Let \(x\) be a MAX-CUT instance with vertex count \(n = \lfloor \sqrt{|x|} \rfloor\) and let \(s\) be a bitstring, with bits indexed from \(0\). If \(s\) is a feasible solution of \(x\) (its length is \(n\)), the value of \(s\) is the number, as a rational number, of pairs \((i, j)\) with \(i < j < n\) such that bit \(i n + j\) of \(x\) is true and bits \(i\) and \(j\) of \(s\) differ; otherwise the value is \(0\).

    def maxCutVal (x s : List Bool) : ℚ :=
  if maxCutFeas x s then
    ((Finset.filter (fun p : ℕ × ℕ => p.1 < p.2 ∧ p.2 < maxCutN x ∧
      x.getD (p.1 * maxCutN x + p.2) false ∧
        (s.getD p.1 false) ≠ (s.getD p.2 false))
      (Finset.range (maxCutN x) ×ˢ Finset.range (maxCutN x))).card : ℚ)
  else 0

    MetaMathlibExt.Complexity.KeyTheorems.MaxCutNoPTAS.maxCut

    MAX-CUT is the optimization problem whose instances are bitstrings \(x\), read as an adjacency matrix on \(n = \lfloor \sqrt{|x|} \rfloor\) vertices in which, for \(i < j < n\), bit \(i n + j\) of \(x\) (bits indexed from \(0\)) says whether \(\{i, j\}\) is an edge. Its feasible solutions for \(x\) are the bitstrings of length \(n\), one bit per vertex; the value of a feasible solution \(s\) is the number of pairs \(i < j < n\) that are edges and whose bits in \(s\) differ, the value of an infeasible solution is \(0\), and the polynomial bound on the length of feasible solutions is \(p(m) = m\).
