    MetaMathlibExt.Complexity.KeyTheorems.Hastad.hastadNondegenerate

    A clause, given as a list of literals \((v, s)\) with variable index \(v \in \mathbb{N}\) and polarity \(s\), is nondegenerate if it has exactly three literals, its variable indices are pairwise distinct, and it contains no complementary pair, that is, no two literals \((v, s)\) and \((v, \lnot s)\).

    def hastadNondegenerate (clause : List (ℕ × Bool)) : Bool :=
  decide (clause.length = 3 ∧ (clause.map Prod.fst).Nodup) &&
    !clause.any (fun l => (l.1, !l.2) ∈ clause)

    DefinitionValue of a MAX-3SAT assignment#✓fully proved

    MetaMathlibExt.Complexity.KeyTheorems.Hastad.hastadVal

    For bitstrings \(x\) and \(a\), read \(a\) as the assignment giving variable \(v\) the value \(a_v\) if \(v < |a|\) and false otherwise. If \(x\) decodes, under the canonical bitstring decoding, to a pair \((u, \varphi)\) of a bitstring \(u\) and a CNF formula \(\varphi\) in which every variable index is less than \(|u|\) and every clause is nondegenerate, then the MAX-3SAT value of \(a\) on \(x\) is the number of clauses of \(\varphi\), counted with multiplicity, that contain a literal \((v, s)\) whose variable gets the value \(s\). Otherwise the value is \(0\).

    The bitstring \(u\) gives the number of variables in unary. Since degenerate and malformed instances get value \(0\), the \(7/8\) random-assignment bound holds on every instance with nonzero value.

    DefinitionThe MAX-3SAT objective#✓fully proved

    MetaMathlibExt.Complexity.KeyTheorems.MaxThreeSATMAXSNPComplete.max3SATVal

    The value of MAX-3SAT on an instance \(x\) under an assignment \(a\), both bitstrings, is defined as follows. Suppose \(x\) decodes, under the canonical bitstring encoding, to a pair \((u, \varphi)\) of a bitstring \(u\) and a CNF formula \(\varphi\), and suppose moreover that \(|a| \le |x|\), that every literal of \(\varphi\) has variable index less than \(|u|\) and that every clause of \(\varphi\) has at most \(3\) literals. Then the value is the number of clauses of \(\varphi\), counted with multiplicity, that contain a literal \((v, b)\) with \(a_v = b\), where \(a_v\) is the bit of \(a\) at position \(v\) (counting from \(0\)), read as false when \(v \ge |a|\). In every other case the value is \(0\).

    The length of \(u\) is the number of variables, so the value reads only \(a_v\) for \(v < |u|\): padding an assignment with trailing false bits, or padding an assignment of length at least \(|u|\) with arbitrary trailing bits, does not change its value as long as its length stays at most \(|x|\).

    def max3SATVal (x : List Bool) (a : List Bool) : ℚ :=
  match MetaMathlibExt.BitstringEncoding.bitDecode (α := List Bool × Cslib.Logic.PL.CNF) x with
  | some (u, φ) =>
    if a.length ≤ x.length ∧
        (∀ clause ∈ φ, ∀ l ∈ clause, l.1 < u.length) ∧
        ∀ clause ∈ φ, clause.length ≤ 3 then
      (φ.filter (fun clause =>
        clause.any (fun l => (fun v => a.getD v false) l.1 = l.2))).length
    else 0
  | none => 0

    StructureNPO problems#✓fully proved

    MetaMathlibExt.Complexity.KeyTheorems.MaxThreeSATMAXSNPComplete.NPOProblem

    An NPO (NP optimization) problem consists of a rational-valued value function \(v\), a Boolean feasibility predicate \(F\) and an objective encoding \(e\), each taking an instance \(x\) and a solution \(s\) (both bitstrings), together with a polynomial \(b\) with natural-number coefficients, such that the following hold. \(F\) and \(e\) are polynomial-time computable. For all \(x\) and \(s\), \(e(x, s)\) is a triple \((\sigma, p, q)\) of a Boolean \(\sigma\) and natural numbers \(p\) and \(q\) with \(q \ne 0\); if \(s\) is feasible for \(x\) (that is, \(F(x, s)\) is true), then \(v(x, s) = -p/q\) when \(\sigma\) is true and \(v(x, s) = p/q\) when \(\sigma\) is false, and otherwise \(v(x, s) = 0\); and \(v(x, s) \ge 0\). Every feasible solution \(s\) for \(x\) has \(|s| \le b(|x|)\), and every instance \(x\) has a feasible solution.

    Feasible solutions on every instance are needed for completeness: an L-reduction to a problem with no feasible solutions on some instance would have to map a feasible target output back to a feasible source solution that does not exist.

    DefinitionOptimum of an NPO problem#✓fully proved

    MetaMathlibExt.Complexity.KeyTheorems.MaxThreeSATMAXSNPComplete.optVal

    The optimum of an NPO problem \(M\), with value function \(v\) and solution length bound \(b\), on an instance \(x\) is the maximum of \(v(x, s)\) over all bitstrings \(s\) with \(|s| \le b(|x|)\).

    MetaMathlibExt.Complexity.KeyTheorems.MaxThreeSATMAXSNPComplete.LReduces

    Write \(\mathrm{opt}_M(x)\) for the optimum of an NPO problem \(M\) on an instance \(x\) and \(v_M(x, s)\) for the value of a solution \(s\) for \(x\). An NPO problem \(M_1\) L-reduces to an NPO problem \(M_2\) when there are polynomial-time computable maps \(f\), from bitstrings to bitstrings, and \(g\), from pairs of bitstrings to bitstrings, and rational numbers \(\alpha > 0\) and \(\beta > 0\), such that for every instance \(x\) the following hold. First, \(\mathrm{opt}_{M_2}(f(x)) \le \alpha \, \mathrm{opt}_{M_1}(x)\).     This is the L-reduction of Papadimitriou and Yannakakis, with polynomial-time maps \(f\) and \(g\).

    StructureMAXSNP problems#✓fully proved

    MetaMathlibExt.Complexity.KeyTheorems.MaxThreeSATMAXSNPComplete.MAXSNPProblem

    A MAXSNP problem, in the normal form of Papadimitriou and Yannakakis, is an NPO problem \(M\), with value function \(v\) and solution length bound \(b\), together with natural numbers \(k\) and \(N\), a polynomial-time computable map \(W\) sending each instance \(x\) to a list \(W(x)\) of windows, each a pair \((w, j)\) of a list \(w = (w_1, \dots, w_m)\) of natural numbers (variable indices) and a natural number \(j\) (a pattern index), and a function \(\mathrm{acc}\) assigning a truth value to each pair of a natural number and a bitstring, such that the following hold. There is a polynomial \(q\) with natural-number coefficients such that \(W(x)\) has at most \(q(|x|)\) entries for every instance \(x\). Every window \((w, j)\) in \(W(x)\) has \(|w| \le k\) and \(j < N\). A bitstring \(s\) is a feasible solution for \(x\) exactly when \(|s| \le b(|x|)\). For every feasible solution \(s\) for \(x\), the value \(v(x, s)\) is the number of entries \((w, j)\) of the list \(W(x)\), counted with multiplicity, for which \(\mathrm{acc}(j, (s_{w_1}, \dots, s_{w_m}))\) is true, where \(s_i\) is the bit of \(s\) at position \(i\) (counting from \(0\)), read as false when \(i \ge |s|\).

    The windows depend only on the instance, never on the candidate solution: only the fixed predicate \(\mathrm{acc}\) inspects bits of the solution. The counting equation is required only for feasible solutions, because padding a solution with false bits preserves the window count while sufficiently long paddings are infeasible.
