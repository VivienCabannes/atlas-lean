    Cslib.Complexity.Algebraic.MatrixMultiplicationExponent.trilinearRank

    Let \(F\) be a semiring and let \(A\), \(B\), \(C\) be finite types. The trilinear rank of a coefficient array \(T : A \to B \to C \to F\) is the least \(r \in \mathbb{N}\) for which there are \(s \le r\) functions \(u_i : A \to F\), \(v_i : B \to F\), \(w_i : C \to F\) with \(T(a, b, c) = \sum_{i=1}^{s} u_i(a)\,v_i(b)\,w_i(c)\) for all \(a \in A\), \(b \in B\), \(c \in C\).
