    For a type \(F\) of scalars and \(m, r, n \in \mathbb{N}\), a matrix arithmetic circuit is an arithmetic circuit over \(F\) whose inputs are indexed by the entries \((i, k)\) of an \(m \times r\) matrix together with the entries \((k, j)\) of an \(r \times n\) matrix, and whose outputs are indexed by the entries \((i, j)\) of an \(m \times n\) matrix.

    DefinitionMatrix input assignment#✓fully proved

    Cslib.Complexity.Algebraic.matrixInput

    For matrices \(A \in F^{m \times r}\) and \(B \in F^{r \times n}\), the input assignment of \((A, B)\) is the function on the entry positions \((i, k)\) of an \(m \times r\) matrix together with the entry positions \((k, j)\) of an \(r \times n\) matrix that sends \((i, k)\) to \(A_{ik}\) and \((k, j)\) to \(B_{kj}\). It supplies the inputs of a matrix arithmetic circuit.

    def matrixInput {F : Type u} {m r n : ℕ}
    (A : Matrix (Fin m) (Fin r) F) (B : Matrix (Fin r) (Fin n) F) :
    ((Fin m × Fin r) ⊕ (Fin r × Fin n)) → F :=
  Sum.elim (fun p => A p.1 p.2) (fun p => B p.1 p.2)

    DefinitionCircuits that compute the matrix product#✓fully proved

    Cslib.Complexity.Algebraic.IsMatrixMultiplication

    A circuit \(c\) over a field \(F\) whose inputs are the entries of an \(m \times r\) matrix and an \(r \times n\) matrix computes matrix multiplication when, for all matrices \(A \in F^{m \times r}\) and \(B \in F^{r \times n}\) and all \(i < m\), \(j < n\), its output at \((i, j)\) on the entries of \(A\) and \(B\) equals \((AB)_{ij}\).

    Correctness is required on actual values in \(F\), not as an identity of formal polynomials.

    def IsMatrixMultiplication {F : Type u} [Field F] {m r n : ℕ}
    (c : MatrixArithmeticCircuit F m r n) : Prop :=
  ∀ (A : Matrix (Fin m) (Fin r) F) (B : Matrix (Fin r) (Fin n) F)
    (i : Fin m) (j : Fin n), c.evaluate (matrixInput A B) (i, j) = (A * B) i j
    abbrev MatrixArithmeticCircuit (F : Type u) (m r n : ℕ) :=

    DefinitionAdmissible rectangular circuit exponents#✓fully proved

    Cslib.Complexity.Algebraic.HasRectangularCircuitExponent

    Let \(F\) be a field and \(k, w\) real numbers. The exponent \(w\) is admissible at aspect \(k\) over \(F\) when \(k \ge 0\), \(w \ge 0\), and for every \(\varepsilon > 0\) there are a real \(C > 0\) and a natural number \(N \ge 1\) such that for every \(n \ge N\) some arithmetic circuit over \(F\) computes the product of an \(n \times \lceil n^k \rceil\) matrix and an \(\lceil n^k \rceil \times n\) matrix with at most \(C n^{w + \varepsilon}\) gates.

    The circuit may depend on \(n\) and \(\varepsilon\), and it must be correct on every pair of matrices with entries in \(F\).

    def HasRectangularCircuitExponent (F : Type u) [Field F] (k w : ℝ) : Prop :=
  0 ≤ k ∧ 0 ≤ w ∧ ∀ ε : ℝ, 0 < ε → ∃ C : ℝ, 0 < C ∧ ∃ N : ℕ, 1 ≤ N ∧
    ∀ n : ℕ, N ≤ n → ∃ c : MatrixArithmeticCircuit F n (rectangularInnerDimension n k) n,
      IsMatrixMultiplication c ∧ (c.size : ℝ) ≤ C * (n : ℝ) ^ (w + ε)
    abbrev MatrixArithmeticCircuit (F : Type u) (m r n : ℕ) :=
  ArithmeticCircuit F ((Fin m × Fin r) ⊕ (Fin r × Fin n)) (Fin m × Fin n)

    DefinitionRectangular circuit exponent#✓fully proved

    Cslib.Complexity.Algebraic.rectangularCircuitExponent

    For a field \(F\) and a real \(k\), the rectangular circuit exponent of \(F\) at aspect \(k\) is the infimum in \([0, \infty]\) of the admissible rectangular circuit exponents for \(F\) at aspect \(k\): the reals \(w \ge 0\) such that \(k \ge 0\) and, for every \(\varepsilon > 0\), there are \(C > 0\) and \(N \ge 1\) such that for every \(n \ge N\) some arithmetic circuit over \(F\) of size at most \(C n^{w + \varepsilon}\) computes the product of an \(n \times \lceil n^k \rceil\) matrix and a \(\lceil n^k \rceil \times n\) matrix.
