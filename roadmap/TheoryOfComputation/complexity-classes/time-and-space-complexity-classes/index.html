    DefinitionBPP#✓fully proved

    Cslib.Complexity.Classes.BPP

    The class BPP of bounded-error probabilistic polynomial-time decision problems consists of the decision problems \(L\) for which there are a polynomial \(p\) with natural number coefficients and a polynomial-time computable function \(R\) from pairs of bitstrings to booleans such that, for every bitstring \(x\), writing \(m = p(|x|)\) and \(c_x\) for the number of strings \(r \in \{0,1\}^m\) with \(R(x, r)\) true: if \(L(x)\) is true then \(3 c_x \ge 2 \cdot 2^m\), and if \(L(x)\) is false then \(3 c_x \le 2^m\).           2 * 2 ^ (p.eval x.length)) ∧

    DefinitionInteractive-proof game#✓fully proved

    Cslib.Complexity.Classes.IPGame

    The game takes a length cap \(c\), a verifier message function \(V_{\mathrm{msg}}\), a verifier decision function \(V_{\mathrm{dec}}\), a prover \(P\) mapping transcripts (lists of bitstrings) to bitstrings, an input \(x\), a coin string \(\rho\), a number \(k\) of rounds and a transcript \(t\), and returns a Boolean outcome. If \(k = 0\), the outcome is \(V_{\mathrm{dec}}(x, \rho, t)\). Otherwise the verifier sends \(m = V_{\mathrm{msg}}(x, \rho, t)\), and the prover replies \(a = P(t')\), where \(t'\) is \(t\) extended by \(m\). If both \(m\) and \(a\) have length at most \(c\), the outcome is that of the game with \(k - 1\) rounds and transcript \(t\) extended by \(m\) and then \(a\); otherwise the outcome is false.

    The transcript records only verifier messages and prover replies, so the prover never sees the verifier's coins. At use sites the cap is polynomial in \(|x|\), so polynomial time for each verifier step gives polynomial total time in the original input.

    StructureOptimization problems#✓fully proved

    Cslib.Complexity.Classes.OptProblem

    An optimization problem consists of a function \(v\) assigning a rational value \(v(x, s)\) to every instance \(x\) and every candidate solution \(s\), both bitstrings; a feasibility predicate saying whether \(s\) is a feasible solution for \(x\); and a polynomial \(p\) with natural-number coefficients such that every feasible solution \(s\) for \(x\) has length at most \(p(|x|)\). It is required that \(v(x, s) \ge 0\) for all \(x\) and \(s\), that \(v(x, s) = 0\) whenever \(s\) is not feasible for \(x\), and that every instance has a feasible solution.

    The problem is read as a maximization problem. The structure carries no computational content: polynomial-time feasibility and a polynomial-time encoding of the objective form a separate predicate (NPO), which the approximation classes APX, PTAS and FPTAS require.

    Cslib.Complexity.Classes.ApproxAt

    Let \(P\) be a maximization problem with objective value \(\mathrm{val}(x, s)\) for instance \(x\) and solution \(s\), let \(A\) be an algorithm taking a pair of bitstrings, let \(k\) be a natural number and let \(\rho\) be a rational number.     Cslib.Complexity.Classes.IsNPO

    Let \(P\) be an optimization problem whose instances \(x\) and solutions \(s\) are bitstrings, with rational value \(\mathrm{val}(x, s)\) and feasibility predicate \(\mathrm{feas}(x, s)\). Then \(P\) is an NPO problem when the map \((x, s) \mapsto \mathrm{feas}(x, s)\) is polynomial-time computable, and there is a polynomial-time computable map \(\mathrm{enc}\) sending each pair \((x, s)\) to a triple \((b, a, d)\) of a boolean and two natural numbers such that, for all \(x\) and \(s\): \(d \neq 0\); if \(s\) is feasible for \(x\), then \(\mathrm{val}(x, s) = \sigma a / d\), where \(\sigma = -1\) if \(b\) is true and \(\sigma = 1\) otherwise; and if \(s\) is not feasible for \(x\), then \(\mathrm{val}(x, s) = 0\).
