    DefinitionFPT time#✓fully proved

    MetaMathlibExt.Complexity.KeyTheorems.Parameterized.FPTTime

    Let \(\beta\) be a type with a canonical bitstring encoding. A function \(R\) from pairs \((x, k)\) of a bitstring \(x\) and a natural number \(k\) to \(\beta\) is computable in FPT time when there are a computable function \(f : \mathbb{N} \to \mathbb{N}\) and a polynomial-time computable function \(A\) from pairs of bitstrings to \(\beta\) such that \(R(x, k) = A(x, 1^{f(k)})\) for every bitstring \(x\) and every \(k \in \mathbb{N}\), where \(1^{f(k)}\) is the list of \(f(k)\) booleans all equal to true.

    Padding the input with \(f(k)\) entries in this way is equivalent to a running time of \(F(k) \cdot p(n)\) for a computable \(F\) and a polynomial \(p\), where \(n\) is the length of \(x\); the padding function must be computable, since otherwise every predicate on the parameter would be fixed-parameter tractable.

    def FPTTime {β : Type} [MetaMathlibExt.BitstringEncoding β]
    (R : List Bool × ℕ → β) : Prop :=
  ∃ (f : ℕ → ℕ), Computable f ∧ ∃ (A : List Bool × List Bool → β),
    IsPolyTime A ∧
    ∀ (x : List Bool) (k : ℕ), R (x, k) = A (x, List.replicate (f k) true)
    class BitstringEncoding α extends Computability.Encoding α Bool

    MetaMathlibExt.Complexity.KeyTheorems.Parameterized.FPT

    A parameterized problem \(P\) is fixed-parameter tractable when there is a function \(D\), from pairs \((x, k)\) of a bitstring \(x\) and a natural number \(k\) to booleans, that is computable in FPT time and satisfies \(P(x, k) = D(x, k)\) for every bitstring \(x\) and every \(k \in \mathbb{N}\).

    DefinitionFPT-reductions#✓fully proved

    MetaMathlibExt.Complexity.KeyTheorems.Parameterized.FPTReduces

    A parameterized problem \(P\) FPT-reduces to a parameterized problem \(Q\) when there are a map \(R\), sending each pair \((x, k)\) of a bitstring \(x\) and a natural number \(k\) to such a pair \(R(x, k) = (x', k')\), that is computable in FPT time, and a computable function \(g : \mathbb{N} \to \mathbb{N}\), such that for every bitstring \(x\) and every \(k \in \mathbb{N}\), \(k' \le g(k)\) and \(P(x, k)\) is true if and only if \(Q(x', k')\) is true.

    def FPTReduces (P Q : ParamProblem) : Prop :=
  ∃ R : List Bool × ℕ → List Bool × ℕ, FPTTime R ∧ ∃ g : ℕ → ℕ, Computable g ∧
    ∀ x k, (R (x, k)).2 ≤ g k ∧ (P x k ↔ Q (R (x, k)).1 (R (x, k)).2)
    abbrev ParamProblem := List Bool → ℕ → Bool

    AbbreviationEncoded gates for weighted circuit satisfiability#✓fully proved

    MetaMathlibExt.Complexity.KeyTheorems.Parameterized.WCGate

    An encoded gate is a pair \((k, r)\) of a natural number \(k\), its kind, and a list \(r\) of natural numbers, its references.

    Gates are read as in the shared (kind, references) encoding of flat Boolean circuits on \(n\) inputs: \((0, [i])\) is the input variable \(x_i\) when \(i < n\), \((1, [b])\) is the constant that is true exactly when \(b = 1\), \((2, [a])\) is the negation of gate \(a\), and \((3, r)\) and \((4, r)\) are the AND and the OR of the gates listed in \(r\); every other pair, including \((0, [i])\) with \(i \ge n\) and \((2, r)\) with \(r\) not of length one, evaluates to false.

    DefinitionPredecessors of an encoded gate#✓fully proved

    MetaMathlibExt.Complexity.KeyTheorems.Parameterized.wcGatePreds

    The predecessor list of an encoded gate \((k, r)\) is \(r\) when \(k\) is \(2\), \(3\) or \(4\) (a NOT, AND or OR gate), and the empty list for every other kind.

    Variable (kind \(0\)) and constant (kind \(1\)) payloads are a variable index and a constant value, not predecessor gates; folding over them would attribute unrelated gates' weft or depth (for example, an input gate \((0, [0])\) inheriting gate \(0\)'s depth).

    def wcGatePreds : WCGate → List ℕ
  | (2, l) => l
  | (3, l) => l
  | (4, l) => l
  | _ => []
    abbrev WCGate := ℕ × List ℕ

    DefinitionWeft of an encoded gate#✓fully proved

    MetaMathlibExt.Complexity.KeyTheorems.Parameterized.wcGateWeft

    Given a list \(w\) of wefts of earlier gates, where \(w_a\) reads as \(0\) when \(a\) is not a position of \(w\), the weft of an encoded gate \((k, r)\) is \(1\) if it is a large AND or OR gate (\(k \in \{3, 4\}\) and \(r\) has more than \(2\) entries) and \(0\) otherwise, plus the maximum of \(w_a\) over the entries \(a\) of its predecessor list (the maximum over an empty list is \(0\)). In particular, input and constant gates have weft \(0\).

    def wcGateWeft (ws : List ℕ) : WCGate → ℕ
  | (k, l) => (if (k = 3 ∨ k = 4) ∧ 2 < l.length then 1 else 0) +
      (wcGatePreds (k, l)).foldr (fun a acc => max (ws.getD a 0) acc) 0

    DefinitionWeighted circuit satisfiability with bounded weft and depth#✓fully proved

    MetaMathlibExt.Complexity.KeyTheorems.Parameterized.WeightedCircuitSat

    For natural numbers \(t\) and \(d\), weighted circuit satisfiability is the parameterized problem that, on a bitstring \(x\) and a parameter \(k\), answers true exactly when \(x\) decodes to a pair \((n, C)\) of a natural number \(n\) and a list \(C\) of encoded gates such that: every NOT, AND or OR gate of \(C\) references only strictly earlier gates; every gate of \(C\) has weft at most \(t\) and depth at most \(d\); and there is an assignment of \(n\) Boolean values to the inputs, exactly \(k\) of them true, under which \(C\) has a last gate and that gate evaluates to true.

    DefinitionParameterized Clique#✓fully proved

    MetaMathlibExt.Complexity.KeyTheorems.Parameterized.CliqueParam

    The parameterized \(k\)-Clique problem answers a bitstring \(x\) and a parameter \(k \in \mathbb{N}\) as follows. If \(x\) decodes, under the canonical bitstring encoding, to a pair \((n, E)\) of a natural number \(n\) and a list \(E\) of pairs of natural numbers, the answer is true exactly when there is a list of \(k\) distinct natural numbers, each less than \(n\), such that for any two distinct entries \(u\) and \(v\) of the list, \((u, v) \in E\) or \((v, u) \in E\). If \(x\) decodes to no such pair, the answer is false.

    That is, on a well-formed input the answer says whether the graph on the vertices \(0, \dots, n - 1\) whose edges are the pairs in \(E\), with direction ignored, has a clique of size \(k\).

    noncomputable def CliqueParam : ParamProblem := fun x k =>
  match MetaMathlibExt.BitstringEncoding.bitDecode (α := ℕ × List (ℕ × ℕ)) x with
  | some (n, edges) => decide (
      ∃ S : List ℕ, S.Nodup ∧ S.length = k ∧ (∀ v ∈ S, v < n) ∧
        ∀ u ∈ S, ∀ v ∈ S, u ≠ v → (u, v) ∈ edges ∨ (v, u) ∈ edges)
  | none => false
