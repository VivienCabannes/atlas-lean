    DefinitionDeclared polynomial time for timed deciders#✓fully proved

    Cslib.TimeMComplexity.DecidesInDeclaredPolyTime

    Let \(f\) be a timed function that maps each list \(x\) of Booleans to a Boolean \(f(x)\) together with a declared time \(t_f(x) \in \mathbb{N}\). Then \(f\) decides in declared polynomial time when there is a polynomial \(p\) with natural-number coefficients such that \(t_f(x) \le p(|x|)\) for every list \(x\) of Booleans, where \(|x|\) is the length of \(x\).

    This constrains only the trusted time annotation: it implies neither that \(f\) is computable in any machine model nor that \(f\) is related to any particular decision problem.

    def DecidesInDeclaredPolyTime (f : List Bool → TimeM Nat Bool) : Prop :=
  ∃ p : Polynomial ℕ, ∀ x, (f x).time ≤ p.eval x.length

    DefinitionDeclared polynomial time for timed functions on bitstrings#✓fully proved

    Cslib.TimeMComplexity.ComputesInDeclaredPolyTime

    Let \(f\) be a timed function that maps each list \(x\) of Booleans to an output list \(f(x)\) of Booleans together with a declared time \(t_f(x) \in \mathbb{N}\). Then \(f\) computes in declared polynomial time when there is a polynomial \(p\) with natural-number coefficients such that, for every list \(x\) of Booleans, both \(t_f(x)\) and the length of \(f(x)\) are at most \(p(|x|)\), where \(|x|\) is the length of \(x\).

    Declared times are trusted annotations, not checked against any machine model, so this does not make \(f\) polynomial-time computable: for an arbitrary decision problem \(L\), the function returning the one-element list \([L(x)]\) with declared time \(0\) satisfies it. The output-length bound is what lets declared bounds compose.

    def ComputesInDeclaredPolyTime (f : List Bool → TimeM Nat (List Bool)) : Prop :=
  ∃ p : Polynomial ℕ, ∀ x, (f x).time ≤ p.eval x.length ∧
    (f x).ret.length ≤ p.eval x.length

    Cslib.TimeMComplexity.VerifierInDeclaredPolyTime

    A timed verifier \(V\), which assigns to each pair of bit strings \((x, w)\) (an input and a witness) a timed computation returning a Boolean, runs in declared polynomial time when there is a polynomial \(q\) with natural coefficients such that the declared time of \(V(x, w)\) is at most \(q(|x| + |w|)\) for all \(x\) and \(w\).

    DefinitionVerifying a decision problem with a witness bound#✓fully proved

    Cslib.TimeMComplexity.Verifies

    A timed verifier \(V\), which assigns to each pair of bit strings \((x, w)\) (an input and a witness) a timed computation returning a Boolean, verifies a decision problem \(L\) with witness bound \(p\), a polynomial with natural coefficients, when for every bit string \(x\), \(L(x)\) holds if and only if there is a witness \(w\) with \(|w| \le p(|x|)\) such that \(V(x, w)\) returns true.

    This is the verifier half of the definition of NP, phrased for a named timed verifier.

    def Verifies (V : List Bool × List Bool → TimeM Nat Bool)
    (L : DecisionProblem) (p : Polynomial ℕ) : Prop :=
  ∀ x, L x ↔ ∃ w : List Bool, w.length ≤ p.eval x.length ∧
    (V (x, w)).ret = true

    Cslib.TimeMComplexity.DeclaredPolyManyOneRedVia

    Let \(L_1\) and \(L_2\) be decision problems and let \(f\) be a timed function that maps each list \(x\) of Booleans to a list \(f(x)\) of Booleans together with a declared time.     TheoremPulling a verifier back along a declared reduction#✓fully proved

    Cslib.TimeMComplexity.verifies_comp_reduction

    Let \(L_1\) and \(L_2\) be decision problems, let \(f\) be a declared polynomial-time many-one reduction from \(L_1\) to \(L_2\), and let \(V\) be a verifier with polynomial declared time that verifies \(L_2\) with witness bound \(p\). Let \(V'\) be the verifier that on input \(x\) and witness \(w\) first runs \(f\) on \(x\), obtaining \(y\), then runs \(V\) on \((y, w)\) and accepts when \(V\) accepts and \(|w| \le p(|y|)\); its declared time is the declared time of \(f(x)\) plus that of \(V(y, w)\). Then \(V'\) has polynomial declared time, and there is a polynomial \(p'\) with natural coefficients such that \(V'\) verifies \(L_1\) with witness bound \(p'\).

    The proof takes \(p' = p \circ r\) and the time bound \(r(n) + q(r(n) + n)\) with \(n = |x| + |w|\), where \(r\) bounds the declared time and output length of \(f\) and \(q\) bounds the declared time of \(V\).

    theorem verifies_comp_reduction
    {f : List Bool → TimeM Nat (List Bool)}
    {V : List Bool × List Bool → TimeM Nat Bool}
    {L₁ L₂ : DecisionProblem} {p : Polynomial ℕ}
    (hred : DeclaredPolyManyOneRedVia f L₁ L₂) (hVt : VerifierInDeclaredPolyTime V)
    (hV : Verifies V L₂ p) :
    ∃ p' : Polynomial ℕ,
      VerifierInDeclaredPolyTime (fun xw => f xw.1 >>= fun y =>
        (fun b => b && decide (xw.2.length ≤ p.eval y.length)) <$>
          V (y, xw.2)) ∧
      Verifies (fun xw => f xw.1 >>= fun y =>
        (fun b => b && decide (xw.2.length ≤ p.eval y.length)) <$>
          V (y, xw.2)) L₁ p'
