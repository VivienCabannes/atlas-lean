    DefinitionIsomorphism of graph codes#✓fully proved

    MathlibExt.ComputerScience.GraphIsomorphismQuasipolynomialWanted.Isomorphic

    Graph codes \(G\) and \(H\) with adjacency matrices \(A\) and \(B\) are isomorphic when they have the same vertex count \(n\) and there is a permutation \(\sigma\) of the vertices \(\{0, \dots, n-1\}\) such that \(A_{ij} = B_{\sigma(i)\sigma(j)}\) for all \(i, j\).

    def Isomorphic (G H : GraphCode) : Prop :=
  ∃ h : G.n = H.n, ∃ σ : Equiv.Perm (Fin H.n), ∀ i j : Fin G.n,
    G.adj i j = H.adj (σ (Fin.cast h i)) (σ (Fin.cast h j))

    DefinitionThe quasipolynomial graph isomorphism statement#✓fully proved

    MathlibExt.ComputerScience.GraphIsomorphismQuasipolynomialWanted.conjecture

    The proposition that graph isomorphism is decidable in quasipolynomial time: there are a function \(D\) from pairs of graph codes to Booleans, an exponent \(c \in \mathbb{N}\), and a deterministic multi-stack Turing machine with a time function \(t : \mathbb{N} \to \mathbb{N}\) that, on the bit encoding of every pair \((G, H)\), outputs the single bit \(D(G, H)\) within \(t(\ell)\) steps, where \(\ell\) is the length of the encoding, such that \(t(n) \le q_c(n)\) for every \(n \in \mathbb{N}\), where \(q_c\) is the quasipolynomial time bound with exponent \(c\), and \(D(G, H)\) is true if and only if \(G\) and \(H\) are isomorphic.
