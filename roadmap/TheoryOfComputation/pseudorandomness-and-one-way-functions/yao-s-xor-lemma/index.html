    MetaMathlibExt.Complexity.KeyTheorems.YaoXOR.xorFlat

    For \(n > 0\) and \(k\) blocks \(x_0, \dots, x_{k-1}\) of \(n\) bits each, the flattened string has \(nk\) bits, and its bit \(i\) is bit \(i \bmod n\) of the block \(x_{\lfloor i/n \rfloor}\).

    def xorFlat {n k : ℕ} (hn : 0 < n) (xs : Fin k → Fin n → Bool) : Fin (n * k) → Bool :=
  fun i => xs ⟨i.val / n, by
      rw [Nat.div_lt_iff_lt_mul hn]
      calc i.val < n * k := i.isLt
        _ = k * n := by rw [Nat.mul_comm]⟩
    ⟨i.val % n, Nat.mod_lt _ hn⟩

    MetaMathlibExt.Complexity.KeyTheorems.YaoXOR.agreement

    Let \(\alpha\) be a finite type, let \(C\) be a circuit given as a list of encoded gates, let \(g\) assign a Boolean to each \(a \in \alpha\), and let \(\mathrm{enc}\) encode each \(a \in \alpha\) as a list of Booleans. The agreement of \(C\) with \(g\) is the rational number \(N / |\alpha|\) (which is \(0\) when \(\alpha\) is empty), where \(N\) is the number of \(a \in \alpha\) such that \(C\) has at least one gate and the value of its last gate, when \(C\) is evaluated on the input list \(\mathrm{enc}(a)\), equals \(g(a)\).

    noncomputable def agreement {α : Type*} [Fintype α]
    (C : List XORGate) (g : α → Bool) (enc : α → List Bool) : ℚ :=
  (Set.ncard {a | (xorCircuitEval C (enc a)).getLast? = some (g a)} : ℚ) /
    (Fintype.card α : ℚ)

    TheoremYao's XOR lemma: hardness amplification by XOR#●ready to prove

    MetaMathlibExt.Complexity.KeyTheorems.YaoXOR.yao_xor_lemma

    There is a natural number \(c\) such that the following holds for all natural numbers \(n \ge 1\) and \(k\), every rational \(\delta\) with \(0 < \delta \le 1/2\), every Boolean function \(f\) on \(n\) bits and every natural number \(s\). Suppose every circuit given as a list of at most \(s\) encoded gates has agreement at most \(1 - \delta\) with \(f\), where an input \(x \in \{0,1\}^n\) is given to the circuit as its \(n\) bits. Then every circuit \(C\) given as a list of encoded gates, whose number of gates \(|C|\) satisfies \(|C| \cdot (k + 1)^c \le s\), has agreement at most \(1/2 + (1 - 2\delta)^k / 2 + 1/(k + 1)\) with the XOR \(f^{\oplus k}\) of \(k\) independent copies of \(f\), where a \(k\)-tuple of \(n\)-bit blocks is given to the circuit as its \(nk\)-bit flattening.

    public theorem_wanted yao_xor_lemma :
    ∃ c : ℕ, ∀ (n k : ℕ) (hn : 1 ≤ n), ∀ (δ : ℚ), 0 < δ → δ ≤ 1 / 2 →
      ∀ f : (Fin n → Bool) → Bool, ∀ s : ℕ,
      (∀ C : List XORGate, C.length ≤ s →
        agreement C f List.ofFn ≤ 1 - δ) →
      ∀ C : List XORGate, C.length * (k + 1) ^ c ≤ s →
        agreement C (xorOf (k := k) f)
          (fun xs : Fin k → Fin n → Bool => List.ofFn (xorFlat (k := k) hn xs)) ≤
          1 / 2 + (1 - 2 * δ) ^ k / 2 + 1 / (k + 1 : ℚ)
