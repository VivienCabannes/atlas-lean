    DefinitionInversion success probability of a circuit#✓fully proved

    MetaMathlibExt.Complexity.KeyTheorems.FiveWorlds.fwInvertSucc

    Let \(f\) map \(n\)-bit strings to bitstrings and let \(C\) be an encoded flat Boolean circuit. For an \(n\)-bit string \(x\), the candidate preimage \(x'\) consists of the last \(n\) gate values of \(C\) on input \(f(x)\) (all of them if \(C\) has fewer than \(n\) gates), padded with false to length \(n\). The inversion success probability of \(C\) against \(f\) is the fraction of the \(2^n\) strings \(x\) for which \(f(x') = f(x)\).

    noncomputable def fwInvertSucc {n : ℕ} (C : List FWGate)

    MetaMathlibExt.Complexity.KeyTheorems.FiveWorlds.OWFExists

    There are a family of functions \(f_n\), each mapping \(n\)-bit strings to bitstrings, and a polynomial \(q\) with natural-number coefficients such that the following hold: \(|f_n(x)| \le q(n)\) for every \(n\) and every \(n\)-bit string \(x\); some polynomial-time computable function on bitstrings maps the canonical bitstring encoding of every pair \((n, x)\) to \(f_n(x)\); and for every family of flat Boolean circuits \(C_n\), given as lists of serialized gates, with at most \(p(n)\) gates for some polynomial \(p\) with natural-number coefficients, the fraction of \(n\)-bit strings \(x\) with \(f_n(x') = f_n(x)\) is a negligible function of \(n\).     DefinitionSamplable distributions#✓fully proved

    MetaMathlibExt.Complexity.KeyTheorems.FiveWorlds.Samplable

    Let \(p\) be a polynomial with natural-number coefficients and let \(S\) be a family of maps \(S_n\) from \(p(n)\)-bit coin strings to bitstrings. The pair \((p, S)\) is samplable when every \(S_n(r)\) has length exactly \(n\) and some polynomial-time computable function on bitstrings maps the canonical bitstring encoding of every pair \((n, r)\) to \(S_n(r)\).

    The distribution sampled at length \(n\) is that of \(S_n(r)\) for a uniformly random coin string \(r\). The sampler is a single uniform polynomial-time algorithm: per-length circuits would admit noncomputable \(\mathsf{P/poly}\) samplers. The coin count is a polynomial rather than \(n\): a distribution giving probability \(2^{-(n+1)}\) to one output is samplable with \(n + 1\) coins but not from \(n\) uniform coins.

    DefinitionEasy on average#✓fully proved

    MetaMathlibExt.Complexity.KeyTheorems.FiveWorlds.AvgEasy

    Let \(p\) be a polynomial with natural-number coefficients, \(L\) a decision problem, and \(S\) a family of samplers, where \(S_n\) sends each string \(r\) of \(p(n)\) random bits to a bitstring \(S_n(r)\). The pair \((L, S)\) is easy on average when there is a polynomial-time computable function \(A\) from bitstrings to booleans such that for every natural number \(c\) there is \(N\) such that for all \(n \ge N\)

    \[1 - \frac{1}{n^c + 1} \le \frac{\#\{r \in \{0,1\}^{p(n)} : A(S_n(r)) = L(S_n(r))\}}{2^{p(n)}},\]

    that is, \(A\) agrees with \(L\) on \(S_n(r)\) for at least a fraction \(1 - 1/(n^c + 1)\) of the coin strings \(r\).

    The algorithm \(A\) does not depend on \(c\), so its error is negligible. Requiring the bound \(1 - 1/(q(n) + 1)\) for a single polynomial \(q\) instead would be vacuous: the zero polynomial gives the lower bound \(0\), which every algorithm meets.

      1 - 1 / ((n : ℚ) ^ c + 1) ≤
        (Set.ncard {r : Fin (p.eval n) → Bool | A (S n r) = L (S n r)} : ℚ) /
