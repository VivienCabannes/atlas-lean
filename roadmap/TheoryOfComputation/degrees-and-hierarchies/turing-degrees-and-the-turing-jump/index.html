    Cslib.Decidability.OracleCode

    Oracle codes are the finite programs built from the basic codes \(\mathtt{zero}\), \(\mathtt{succ}\), \(\mathtt{left}\), \(\mathtt{right}\) and \(\mathtt{oracle}\) by the binary constructors \(\mathtt{pair}\), \(\mathtt{comp}\) and \(\mathtt{prec}\) and the unary constructor \(\mathtt{rfind}\). They are the codes for partial recursive functions (constant zero, successor, the two unpairing projections, pairing, composition, primitive recursion and unbounded search) extended by an instruction \(\mathtt{oracle}\) that queries the oracle on its input.

    Cslib.Decidability.encodeOracleCode

    Write \(\langle a, b \rangle\) for the pairing of natural numbers equal to \(b^2 + a\) if \(a < b\) and to \(a^2 + a + b\) otherwise. The code number \(\ulcorner c \urcorner\) of an oracle code \(c\) is defined by recursion on \(c\): \(\mathsf{zero}\), \(\mathsf{succ}\), \(\mathsf{left}\), \(\mathsf{right}\) and \(\mathsf{oracle}\) have code numbers \(\langle 0, 0 \rangle\), \(\langle 1, 0 \rangle\), \(\langle 2, 0 \rangle\), \(\langle 3, 0 \rangle\) and \(\langle 8, 0 \rangle\); \(\mathsf{pair}(a, b)\), \(\mathsf{comp}(a, b)\) and \(\mathsf{prec}(a, b)\) have code numbers \(\langle 4, \langle \ulcorner a \urcorner, \ulcorner b \urcorner \rangle \rangle\), \(\langle 5, \langle \ulcorner a \urcorner, \ulcorner b \urcorner \rangle \rangle\) and \(\langle 6, \langle \ulcorner a \urcorner, \ulcorner b \urcorner \rangle \rangle\); and \(\mathsf{rfind}(a)\) has code number \(\langle 7, \ulcorner a \urcorner \rangle\).

    DefinitionFuel-indexed decoder of oracle codes#✓fully proved

    Cslib.Decidability.decodeOracleCodeFuel

    Write \(\langle a, b \rangle\) for the pairing bijection \(\mathbb{N} \times \mathbb{N} \to \mathbb{N}\) of the Gödel numbering. Given a fuel \(f\), a tag \(t\) and a payload \(p\), the decoder either returns an oracle code or fails; to decode a number \(n = \langle n_1, n_2 \rangle\) with fuel \(f\) means to run it with fuel \(f\), tag \(n_1\) and payload \(n_2\). With fuel \(0\) it fails. With fuel \(f + 1\), writing \(p = \langle p_1, p_2 \rangle\): if \(p = 0\) and \(t\) is \(0\), \(1\), \(2\), \(3\) or \(8\), it returns the instruction zero, successor, left projection, right projection or oracle query respectively; if \(t\) is \(4\), \(5\) or \(6\), it decodes \(p_1\) and \(p_2\) with fuel \(f\) and, when these give codes \(a\) and \(b\), returns the pairing, composition or primitive recursion code built from \(a\) and \(b\) respectively, failing otherwise; if \(t = 7\), it decodes \(p\) with fuel \(f\) and, when this gives a code \(a\), returns the unbounded search code built from \(a\), failing otherwise; in all other cases it fails.

    The recursion is structural in the fuel and uses no classical choice, so the decoder is a computable function; with enough fuel it inverts the Gödel numbering of oracle codes.
