    For natural numbers \(e\) and \(n\), \(n\) belongs to \(W_e\), the \(e\)-th recursively enumerable set, when the partial recursive function \(\varphi_e\) computed by the program with index \(e\) in the standard numbering of partial recursive programs is defined at \(n\); thus \(W_e\) is the domain of \(\varphi_e\).

    DefinitionProductive set#✓fully proved

    Cslib.Decidability.Productive

    A set \(A\) of natural numbers is productive when there is a partial recursive function \(f\) such that for every natural number \(e\) with \(W_e \subseteq A\), where \(W_e\) is the \(e\)-th recursively enumerable set in the standard enumeration, \(f(e)\) is defined, \(f(e) \in A\) and \(f(e) \notin W_e\).

    def Productive (P : ℕ → Prop) : Prop :=
  ∃ f : ℕ →. ℕ, Partrec f ∧ ∀ e, (∀ n, enumRE e n → P n) →
    ∃ h : (f e).Dom, P ((f e).get h) ∧ ¬ enumRE e ((f e).get h)
    def enumRE (e n : ℕ) : Prop :=
  (Nat.Partrec.Code.eval (Denumerable.ofNat Nat.Partrec.Code e) n).Dom

    DefinitionImmune set#✓fully proved

    Cslib.Decidability.Immune

    A set \(A\) of natural numbers is immune when it is infinite and every recursively enumerable set \(B \subseteq A\) is finite.

    def Immune (P : ℕ → Prop) : Prop :=
  Set.Infinite {n | P n} ∧ ∀ A : ℕ → Prop, REPred A → (∀ n, A n → P n) →
    Set.Finite {n | A n}
