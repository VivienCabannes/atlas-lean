    MetaMathlibExt.REPred.exists_mem

    Let \(\alpha\) and \(\beta\) be types with primitive recursive encodings into \(\mathbb{N}\), let \(R\) be a relation between \(\alpha\) and \(\beta\) that is recursively enumerable as a predicate on pairs \((a, b)\), and let \(c\) be a primitive recursive function sending each \(a \in \alpha\) to a finite list \(c(a)\) of elements of \(\beta\).     DefinitionRecognizability by multi-stack machines#✓fully proved

    Cslib.Decidability.TM2Recognizable

    Let \(\alpha\) be a primcodable type (it has an encoding \(\mathrm{encode} : \alpha \to \mathbb{N}\) whose decoding is primitive recursive). A predicate \(p\) on \(\alpha\) is recognizable by a multi-stack machine when there are a multi-stack Turing machine \(M\) and an identification of its input alphabet with the Booleans such that for every \(a \in \alpha\), \(p(a)\) holds if and only if \(M\) halts when started on the binary word of \(\mathrm{encode}(a)\).

    def TM2Recognizable (p : α → Prop) : Prop :=
  ∃ (tm : FinTM2) (e : tm.Γ tm.k₀ ≃ Bool),
    ∀ a, p a ↔ TM2HaltsOn tm ((encodeNat (encode a)).map e.symm)
    def TM2HaltsOn (tm : FinTM2) (l : List (tm.Γ tm.k₀)) : Prop :=
  (StateTransition.eval tm.step (initList tm l)).Dom
