    Cslib.Decidability.finFun

    For a finite list \(\theta\) of pairs of natural numbers, the finite function of \(\theta\) is the partial function \(\mathbb{N} \rightharpoonup \mathbb{N}\) whose value at \(x\) is the second component of the first pair in \(\theta\) with first component \(x\), and which is undefined at \(x\) when \(\theta\) has no pair with first component \(x\).

    def finFun (θ : List (ℕ × ℕ)) : ℕ →. ℕ := fun x ↦
