    TheoremCells of a fenced input#✓fully proved

    Cslib.Turing.SingleTapeTM.getElem?_fenceInput

    Let \(w\) be a word of length \(\ell\) and \(i, j, n \in \mathbb{N}\). The cell at position \(n\), counting from \(0\), of the fenced input of \(w\) with \(i\) left and \(j\) right padding cells is the wall if \(n = 0\); a left padding cell if \(1 \le n \le i\); the letter of \(w\) at position \(n - i - 1\), also counting from \(0\), as a symbol, if \(i < n \le i + \ell\); a right padding cell if \(i + \ell < n \le i + \ell + j\); the wall if \(n = i + \ell + j + 1\); and there is no cell at a larger position \(n\).

    theorem getElem?_fenceInput (w : List Symbol) (i j n : ℕ) :
    (fenceInput w i j)[n]? =
      if n = 0 then some .wall
      else if n ≤ i then some .lpad
      else if n ≤ i + w.length then (w[n - (i + 1)]?).map .sym
      else if n ≤ i + w.length + j then some .pad
      else if n = i + w.length + j + 1 then some .wall
      else none

    Cslib.Turing.SingleTapeTM.fenceRun

    In the running state of a state \(q\) of a single-tape machine \(M\), the fenced machine of \(M\) acts on the cell under its head as follows: on a symbol \(a\) it makes the lifted transition of \(M\) in state \(q\) on \(a\); on a left or right padding cell it makes the lifted transition of \(M\) in state \(q\) on a blank; on a wall or a blank cell it leaves the cell unchanged, does not move, and enters the trap.

    def fenceRun (q : tm.State) (c : Option (FenceSymbol Symbol)) :
    Stmt (FenceSymbol Symbol) × Option (FenceState tm.State) :=
  match c with
  | some (.sym a) => tm.fenceLift (tm.tr q (some a))
  | some .pad | some .lpad => tm.fenceLift (tm.tr q none)
  | _ => (⟨c, none⟩, some .trap)

    AbbreviationThe fenced machine#✓fully proved

    Cslib.Turing.SingleTapeTM.fence

    For a single-tape machine \(M\) over a finite inhabited alphabet \(\Sigma\), the fenced machine of \(M\) is the single-tape machine over the fenced alphabet of \(\Sigma\) whose states are the states of the fenced machine for the states of \(M\), which starts in the first start state and acts on the cell under its head as follows. In the first start state, on a wall it moves right into the second start state, and on any other cell it leaves the cell unchanged, does not move and enters the trap. In the second start state, on a left padding cell it moves right and stays in that state, and on any other cell it makes the running transition of the initial state of \(M\). In the running state of a state \(q\) of \(M\) it makes the running transition of \(q\). In the trap it leaves the cell unchanged, does not move and stays in the trap.

    So on the fenced input of a word \(w\) it moves right off the left wall and over the left padding, then runs \(M\) from its initial state, and enters the trap when it reads a wall or a blank cell. On a blank cell, in every state, it writes a blank and does not move.

    abbrev fence : SingleTapeTM (FenceSymbol Symbol) where
  State := FenceState tm.State
  q₀ := .start₀
  tr
    | .start₀, c => match c with
      | some .wall => (⟨c, some .right⟩, some .start₁)
      | _ => (⟨c, none⟩, some .trap)
    | .start₁, c => match c with
      | some .lpad => (⟨c, some .right⟩, some .start₁)
      | _ => tm.fenceRun tm.q₀ c
    | .run q, c => tm.fenceRun q c
    | .trap, c => (⟨c, none⟩, some .trap)

    Cslib.Turing.SingleTapeTM.exists_haltsOn_fence_iff

    Let \(M\) be a single-tape machine over a finite inhabited alphabet and \(w\) a word over that alphabet.     Cslib.Turing.SingleTapeTM.exists_isLBA_not_computablePred_forall_not_haltsOn

    There exist a finite inhabited alphabet \(\Gamma\) with a primitive recursive encoding, a linear bounded automaton \(F\) over the fenced alphabet of \(\Gamma\), and a primitive recursive map \(e\) from codes of partial recursive functions to words over \(\Gamma\), such that the set of codes \(c\) for which \(F\) halts on none of the fenced inputs of \(e(c)\), with \(i\) padding cells on the left and \(j\) on the right for any \(i, j \in \mathbb{N}\), is neither computable nor recursively enumerable.

    This is the code-free form of Sipser, Theorem 5.10. Take for \(F\) the fenced machine of a single-tape recognizer \(R\) of the set of codes that halt on input \(0\), and for \(e(c)\) the input of \(c\) to \(R\): then \(F\) halts on no fenced input of \(e(c)\) iff \(c\) does not halt on \(0\). The word \(e(c)\) does not see the paddings \(i\) and \(j\), so \(F\) itself runs the computation within the space they give.

    Sipser's \(E_{\mathrm{LBA}}\) is a language of machine descriptions, the LBAs with empty language; without a type of codes for machines, this is the form available. Each slice, the set of fenced inputs of \(e(c)\) over all paddings, is regular because of its shape: a wall, any number of left padding cells, the word \(e(c)\), any number of right padding cells and a wall. Informally: with codes of machines, the LBA that checks that its input lies in the slice of \(c\) and then runs \(F\) has empty language iff \(F\) halts on no input of the slice, and \(E_{\mathrm{LBA}}\) is undecidable by the same reduction.
