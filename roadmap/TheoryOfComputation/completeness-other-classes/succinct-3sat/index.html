    MetaMathlibExt.Complexity.KeyTheorems.SuccinctThreeSATNEXPComplete.s3ValidGate

    Let \(C\) be a list of gates encoded as (kind, references) pairs and let \(n\) and \(j\) be natural numbers. Gate \(j\) of \(C\) is valid when \(C\) has more than \(j\) entries and its entry \(j\) (counting from \(0\)) is one of: \((0, [i])\) with \(i < n + 2\) (an input gate); \((1, [b])\) with \(b \le 1\) (a constant gate); \((2, [a])\) with \(a < j\) (a negation gate); or \((3, r)\) or \((4, r)\) where every entry \(a\) of \(r\) satisfies \(a < j\) (a conjunction or disjunction gate). Every other entry is invalid.

    def s3ValidGate (C : List S3Gate) (n j : ℕ) : Prop :=
  match C[j]? with
  | some (0, [i]) => i < n + 2
  | some (1, [b]) => b ≤ 1
  | some (2, [a]) => a < j
  | some (3, l) => ∀ a ∈ l, a < j
  | some (4, l) => ∀ a ∈ l, a < j
  | _ => False

    MetaMathlibExt.Complexity.KeyTheorems.SuccinctThreeSATNEXPComplete.succinctThreeSatDec

    Succinct 3SAT is the decision problem that accepts a bitstring \(x\) exactly when \(x\) decodes, under the canonical bitstring encoding, to a pair \((n, C)\) of a natural number \(n\) and a list \(C\) of gates encoded as (kind, references) pairs such that \(C\) is a well-formed descriptor for \(n\) and some assignment \(\sigma\) of booleans to the natural numbers satisfies clause \(c\) of the formula described by \(C\) for every \(c < 2^n\). Bitstrings that do not decode are rejected.

    noncomputable def succinctThreeSatDec :

      (α := ℕ × List S3Gate) x with

      ∀ c, c < 2 ^ i.1 → succClauseSat i.2 i.1 assign c)
  | none => false
