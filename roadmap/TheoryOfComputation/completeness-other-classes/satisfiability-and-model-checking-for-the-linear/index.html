    def sat (env : ℕ → ℕ → Prop) : LinearMuFormula Atom → (ℕ → Prop)
  | .atom a => fun n => val n a
  | .natom a => fun n => ¬ val n a
  | .var n => env n
  | .bot => fun _ => False
  | .top => fun _ => True
  | .and φ ψ => fun n => sat env φ n ∧ sat env ψ n
  | .or φ ψ => fun n => sat env φ n ∨ sat env ψ n
  | .next φ => fun n => sat env φ (n + 1)
  | .mu φ => fun n => ∀ S : ℕ → Prop,
      (∀ m, sat (extendEnv env S) φ m → S m) → S n
  | .nu φ => fun n => ∃ S : ℕ → Prop,
  ⋯

    Model checking a linear μ-calculus formula against a finite Kripke structure: every infinite path π from start following edges satisfies φ at position 0, where the path turns the structure's valuation worldVal into a word valuation.

    Satisfiability of the linear μ-calculus as a decision problem over bitstrings: the input decodes to a formula token list, which decodes to a formula; the answer is whether that formula is closed and satisfiable.

    noncomputable def linearMuSatDec :
    MetaMathlibExt.ComplexityTheory.DecisionProblem := fun x =>
  match MetaMathlibExt.BitstringEncoding.bitDecode (α := List ℕ) x with
  | some toks =>
    match Cslib.Modal.LinearMuCalculus.linearMuDecodeList toks with
    | some φ =>
      if Cslib.Modal.LinearMuCalculus.LinearMuFormula.Closed φ ∧ linearMuSat φ
      then true else false
    | none => false
  | none => false

    DefinitionLinear μ-calculus model checking as a decision problem#✓fully proved

    MetaMathlibExt.Complexity.KeyTheorems.LinearMuCalculusPSPACEComplete.linearMuModelCheckDec

    Model checking of the linear μ-calculus as a decision problem over bitstrings: the input decodes to (n, edges, worldVals, start, tokens), where worldVals lists, per world, the atoms true at that world; the answer is whether the decoded formula is closed, the structure is well-formed and total (every world has a successor world, so the path quantification is not vacuous at deadlocks), and every path from start satisfies the formula.

    noncomputable def linearMuModelCheckDec :
    MetaMathlibExt.ComplexityTheory.DecisionProblem := fun x =>
  match MetaMathlibExt.BitstringEncoding.bitDecode
      (α := ℕ × List (ℕ × ℕ) × List (List ℕ) × ℕ × List ℕ) x with
  | some (n, edges, worldVals, start, toks) =>
    match Cslib.Modal.LinearMuCalculus.linearMuDecodeList toks with
    | some φ =>
      if Cslib.Modal.LinearMuCalculus.LinearMuFormula.Closed φ ∧ start < n ∧
          (∀ e ∈ edges, e.1 < n ∧ e.2 < n) ∧
          (∀ w, w < n → ∃ v, v < n ∧ (w, v) ∈ edges) ∧
          linearMuModelCheck edges (fun w a => a ∈ worldVals.getD w []) start φ
      then true else false
    | none => false
  | none => false
    abbrev DecisionProblem := List Bool → Bool

    MetaMathlibExt.Complexity.KeyTheorems.LinearMuCalculusPSPACEComplete.linear_mu_calculus_pspace_complete

    The model checking, satisfiability and validity problems of the linear modal μ-calculus are PSPACE-complete, like for linear temporal logic. Source: M. Y. Vardi, "A temporal fixpoint calculus", POPL 1988, 250-259; cf. A. P. Sistla and E. M. Clarke, "The complexity of propositional linear temporal logics", JACM 32 (1985), 733-749.
