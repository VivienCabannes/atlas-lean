    Let \(C\) be a list of encoded gates, let \(n, i \in \mathbb{N}\), let \(x\) be a list of booleans (the input) and let \(v\) be a list of booleans (the values of earlier gates), where an entry outside \(x\) or \(v\) reads as false.     def succGateVal (C : List SCVGate) (n : ℕ) (x : List Bool) (vs : List Bool)

    | (3, p₁, _) => !(vs.getD p₁ false)

    A list \(C\) of encoded gates is a well-formed description circuit on \(n\) inputs when \(C\) has at least \(2n + 3\) gates and the flat Boolean circuit on \(n\) inputs obtained by decoding each gate of \(C\) is well-formed, that is, every gate references only strictly earlier gates.

    MetaMathlibExt.Complexity.KeyTheorems.SuccinctCircuitValueEXPComplete.succWellFormed

    Let \(C\) be a list of encoded gates, read as a flat Boolean circuit on \(n\) inputs that describes a circuit \(D\) with \(2^n\) gates. For each gate \(i\) of \(D\), let \(t_i\), \(p_i\) and \(q_i\) be its gate type, first predecessor and second predecessor, as decoded from the outputs of \(C\) on the \(n\)-bit binary expansion of \(i\). The description is well formed when, for every \(i < 2^n\): if \(i < n\), then \(t_i = 0\) (gate \(i\) is an input gate); and if \(i \ge n\), then either \(t_i = 4\) or \(t_i = 5\) (a constant gate), or \(p_i < i\) and \(q_i < i\).

    def succWellFormed (C : List SCVGate) (n : ℕ) : Prop :=

    MetaMathlibExt.Complexity.KeyTheorems.SuccinctCircuitValueEXPComplete.succinctCircuitValueDec

    The decision problem Succinct Circuit Value accepts a bitstring exactly when it decodes to a triple \((n, C, x)\) of a natural number \(n\), a list \(C\) of encoded gates and a bitstring \(x\) such that: \(x\) has length \(n\); \(C\) has at least \(2n + 3\) gates and, read as a flat Boolean circuit on \(n\) inputs, is well formed; the circuit \(D\) with \(2^n\) gates succinctly described by \(C\), whose gate \(i\) is described by the outputs of \(C\) on the \(n\)-bit binary expansion of \(i\), is well formed; and the last gate of \(D\) outputs true when the first \(n\) gates of \(D\) are fed the bits of \(x\).

    noncomputable def succinctCircuitValueDec :
