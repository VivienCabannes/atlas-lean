    DefinitionEvaluation of a first-order formula in a graph#✓fully proved

    MetaMathlibExt.Complexity.KeyTheorems.Fagin.faginEval

    Let \(G\) be a graph, let \(\rho\) assign a vertex \(\rho(j)\) of \(G\) to each variable \(x_j\) (\(j \in \mathbb{N}\)), and let \(S\) assign to each relation symbol \(i \in \mathbb{N}\) a predicate \(S_i\) on finite lists of vertices of \(G\). Truth of a formula is defined by recursion: \(x_a = x_b\) holds when \(\rho(a) = \rho(b)\); relation symbol \(i\) applied to the variables \(x_{a_1}, \dots, x_{a_m}\) holds when \(S_i\) holds of the list \([\rho(a_1), \dots, \rho(a_m)]\); negation, conjunction and disjunction are interpreted as usual; and \(\exists \varphi\) holds when there is a vertex \(v\) such that \(\varphi\) holds under the assignment sending \(x_0\) to \(v\) and \(x_{j+1}\) to \(\rho(j)\) for each \(j\), with \(S\) unchanged.

    def faginEval (G : FaginGraph) (ρ : ℕ → Fin G.1)
    (S : ℕ → List (Fin G.1) → Prop) : FaginFO → Prop
  | .eq a b => ρ a = ρ b
  | .rel i args => S i (args.map ρ)
  | .not φ => ¬ faginEval G ρ S φ
  | .and φ ψ => faginEval G ρ S φ ∧ faginEval G ρ S ψ
  | .or φ ψ => faginEval G ρ S φ ∨ faginEval G ρ S ψ
  | .exists φ => ∃ a : Fin G.1,
      faginEval G (fun j => match j with | 0 => a | j + 1 => ρ j) S φ
    abbrev FaginGraph := ℕ × List Bool

    MetaMathlibExt.Complexity.KeyTheorems.Fagin.faginBase

    Let \(G\) be a graph and let \((E_j)_{j \in \mathbb{N}}\) be a family of relations, each a predicate on finite lists of vertices of \(G\). Relation symbol \(0\) is interpreted as the edge relation of \(G\): it holds of a list exactly when the list is \([a, b]\) for vertices \(a, b\) with an edge from \(a\) to \(b\). For \(i \ge 1\), relation symbol \(i\) is interpreted as \(E_{i-1}\).

    def faginBase (G : FaginGraph) (extra : ℕ → List (Fin G.1) → Prop)
    (i : ℕ) : List (Fin G.1) → Prop :=
  if i = 0 then fun args => match args with

    DefinitionSatisfaction of an existential second-order sentence#✓fully proved

    MetaMathlibExt.Complexity.KeyTheorems.Fagin.faginESOSat

    Let \(G\) be a graph with \(n > 0\) vertices, \(k\) a natural number and \(\varphi\) a first-order formula. Then \(G\) satisfies the existential second-order sentence \((k, \varphi)\) if there are relations \(R_0, \dots, R_{k-1}\), each a predicate on finite lists of vertices of \(G\), such that \(\varphi\) holds in \(G\) when relation symbol \(0\) is interpreted as the edge relation (holding exactly of the lists \([a, b]\) with an edge from \(a\) to \(b\)), relation symbol \(j + 1\) as \(R_j\) for each \(j < k\), every relation symbol above \(k\) as the empty relation, and every variable as vertex \(0\).

    def faginESOSat (G : FaginGraph) (h : 0 < G.1) (k : ℕ) (φ : FaginFO) : Prop :=
  ∃ R : (j : Fin k) → List (Fin G.1) → Prop,
    faginEval G (fun _ => ⟨0, h⟩)
      (faginBase G (fun j => if h' : j < k then R ⟨j, h'⟩ else fun _ => False)) φ

    MetaMathlibExt.Complexity.KeyTheorems.Fagin.faginIso

    Graphs \(G_1\) and \(G_2\) are isomorphic if they have the same number of vertices and there is a bijection \(\sigma\) from the vertices of \(G_1\) to the vertices of \(G_2\) such that for all vertices \(a, b\) of \(G_1\), there is an edge from \(a\) to \(b\) in \(G_1\) if and only if there is an edge from \(\sigma(a)\) to \(\sigma(b)\) in \(G_2\).

  G₁.1 = G₂.1 ∧ ∃ σ : Fin G₁.1 ≃ Fin G₂.1,
    ∀ a b : Fin G₁.1, faginEdge G₁ a b ↔ faginEdge G₂ (σ a) (σ b)

    MetaMathlibExt.Complexity.KeyTheorems.Fagin.faginESODefinable

    A class \(K\) of graphs is existential second-order definable if there are a natural number \(k\), a first-order formula \(\varphi\) and a boolean \(e\) such that every graph \(G\) with \(n\) vertices whose edge table has length exactly \(n^2\) satisfies the following: if \(n > 0\), then \(G \in K\) if and only if \(G\) satisfies the existential second-order sentence \((k, \varphi)\); if \(n = 0\), then \(G \in K\) if and only if \(e\) is true.

    def faginESODefinable (K : Set FaginGraph) : Prop :=
  ∃ k φ, ∃ emptyIn : Bool, ∀ G : FaginGraph, G.2.length = G.1 * G.1 →
    (G ∈ K ↔ (if h : 0 < G.1 then faginESOSat G h k φ else emptyIn = true))

    TheoremFagin's theorem: NP is existential second-order logic#●ready to prove

    MetaMathlibExt.Complexity.KeyTheorems.Fagin.fagin

    Let \(K\) be a class of finite graphs, each given as a pair \((n, t)\) of a number \(n\) of vertices and a row-major edge table \(t\) (a list of booleans), and suppose that \(K\) is closed under graph isomorphism. Then the decision problem that accepts exactly the bitstrings decoding to a member \((n, t)\) of \(K\) whose edge table has length \(n^2\) is in NP if and only if \(K\) is definable in existential second-order logic: there are a first-order formula \(\varphi\), a number \(k\) and a boolean \(b\) such that a graph \((n, t)\) whose edge table has length \(n^2\) belongs to \(K\) exactly when either \(n > 0\) and some \(k\) relations on its vertices, together with its edge relation, make \(\varphi\) true (with every free variable of \(\varphi\) denoting vertex \(0\)), or \(n = 0\) and \(b\) is true.

    public theorem_wanted fagin :

      (faginEncodings K ∈ MetaMathlibExt.ComplexityTheory.NP ↔ faginESODefinable K)
