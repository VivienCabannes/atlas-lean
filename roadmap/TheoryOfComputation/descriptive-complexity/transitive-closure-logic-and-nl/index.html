    MetaMathlibExt.Complexity.KeyTheorems.FOTC.TCOrderedGraph

    An ordered graph is encoded as a pair \((n, e)\) of a natural number \(n\), the domain size, and a finite list \(e\) of booleans of arbitrary length, the edge table in row-major order. It is read as the graph on \(\{0, \dots, n - 1\}\), ordered numerically, with an edge from \(a\) to \(b\) when the entry of \(e\) at position \(an + b\) is true; a missing entry counts as false.

    InductiveFormulas of first-order logic with transitive closure#✓fully proved

    MetaMathlibExt.Complexity.KeyTheorems.FOTC.TCFO

    FO + TC formulas, with variables and relation symbols indexed by natural numbers, are built from equations between two variables and relation symbols applied to lists of variables by negation, conjunction, disjunction, existential quantification (which binds variable \(0\), de Bruijn style) and transitive closure \(\mathrm{TC}(\varphi; \bar u, \bar v)\) of a formula \(\varphi\) applied to two lists \(\bar u\), \(\bar v\) of variables. With \(a = |\bar u| = |\bar v|\), the body \(\varphi\) defines a step relation on \(a\)-tuples: its variables \(0, \dots, a - 1\) are the source tuple, \(a, \dots, 2a - 1\) the target tuple, and each variable \(j \ge 2a\) is outer variable \(j - 2a\).

    MetaMathlibExt.Complexity.KeyTheorems.FOTC.tcBase

    In an ordered graph with domain \(\{0, \dots, n - 1\}\), relation symbol \(0\) holds of a list of elements exactly when the list is \([a, b]\) with \(a < b\), relation symbol \(1\) holds exactly when the list is \([a, b]\) and there is an edge from \(a\) to \(b\), and every other relation symbol holds of no list.

    def tcBase (G : TCOrderedGraph) (i : ℕ) : List (Fin G.1) → Prop :=
  match i with
  | 0 => fun args => match args with
    | [a, b] => a.val < b.val
    | _ => False
  | 1 => fun args => match args with
    | [a, b] => tcEdge G a b
    | _ => False
  | _ => fun _ => False

    DefinitionEvaluation of FO + TC formulas#✓fully proved

    MetaMathlibExt.Complexity.KeyTheorems.FOTC.tcEval

    Fix an ordered graph with domain \(D = \{0, \dots, n - 1\}\), an assignment \(\rho\) of an element of \(D\) to each variable index and an assignment \(S\) of a relation on lists of elements of \(D\) to each relation symbol. The truth value of a formula is defined by recursion. The equation between variables \(i\) and \(j\) holds when \(\rho(i) = \rho(j)\). Relation symbol \(i\) applied to variables \(j_1, \dots, j_k\) holds when \(S_i\) holds of the list \([\rho(j_1), \dots, \rho(j_k)]\). Negation, conjunction and disjunction are interpreted as usual. An existential formula \(\exists \varphi\) holds when \(\varphi\) holds under the assignment sending \(0\) to some \(d \in D\) and \(j + 1\) to \(\rho(j)\). A transitive closure \(\mathrm{TC}(\varphi; \bar u, \bar v)\) is false when the index lists \(\bar u\) and \(\bar v\) have different lengths. Otherwise, with \(a\) their common length, it holds when the tuple \((\rho(v_0), \dots, \rho(v_{a-1}))\) is reachable from \((\rho(u_0), \dots, \rho(u_{a-1}))\) in zero or more steps, where a step from \(s \in D^a\) to \(t \in D^a\) means that \(\varphi\) holds under the assignment sending \(j < a\) to \(s_j\), \(a \le j < 2a\) to \(t_{j - a}\), and \(j \ge 2a\) to \(\rho(j - 2a)\).

    DefinitionExample: parameterized transitive closure in FO + TC#✓fully proved

    MetaMathlibExt.Complexity.KeyTheorems.FOTC.tcParamExample

    The FO + TC formula \(\mathrm{TC}(\varphi; (1), (2))\) of arity \(1\) whose body \(\varphi\) is \(E(0, 1) \lor (E(0, 2) \land E(2, 1))\), where \(E\) is relation symbol \(1\) (the edge relation). In the body, variable \(0\) is the source, variable \(1\) the target, and variable \(2\) is outer variable \(0\), shifted by \(2\); the endpoint arguments \(1\) and \(2\) are outer variables, not shifted. So the formula expresses that outer variable \(2\) is reachable from outer variable \(1\) by steps that are either an edge or a path of two edges through outer variable \(0\).

    def tcParamExample : TCFO :=
  .tc (.or (.rel 1 [0, 1])
    (.and (.rel 1 [0, 2]) (.rel 1 [2, 1]))) [1] [2]

    DefinitionSatisfaction of an FO + TC formula in an ordered graph#✓fully proved

    MetaMathlibExt.Complexity.KeyTheorems.FOTC.tcSat

    An ordered graph with nonempty domain \(\{0, \dots, n - 1\}\) satisfies an FO + TC formula \(\varphi\) when \(\varphi\) evaluates to true with every variable assigned the element \(0\), relation symbol \(0\) interpreted as the order \(<\) and relation symbol \(1\) as the edge relation (both only on two-element lists), and every other relation symbol interpreted as the empty relation.

    def tcSat (G : TCOrderedGraph) (h : 0 < G.1) (φ : TCFO) : Prop :=
  tcEval G (fun _ => ⟨0, h⟩) (tcBase G) φ

    DefinitionDefinability in FO + TC#✓fully proved

    MetaMathlibExt.Complexity.KeyTheorems.FOTC.tcDefinable

    A set \(K\) of ordered graphs is FO + TC-definable when there are an FO + TC formula \(\varphi\) and a boolean \(b\) such that for every ordered graph \((n, T)\) whose edge table \(T\) has length exactly \(n^2\): if \(n > 0\), then \((n, T) \in K\) exactly when \((n, T)\) satisfies \(\varphi\), and if \(n = 0\), then \((n, T) \in K\) exactly when \(b\) is true.

    def tcDefinable (K : Set TCOrderedGraph) : Prop :=
  ∃ φ, ∃ emptyIn : Bool, ∀ G : TCOrderedGraph, G.2.length = G.1 * G.1 →
    (G ∈ K ↔ (if h : 0 < G.1 then tcSat G h φ else emptyIn = true))
