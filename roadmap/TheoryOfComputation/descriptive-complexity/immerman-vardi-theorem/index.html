    MetaMathlibExt.Complexity.KeyTheorems.ImmermanVardi.ogBase

    Let \(G\) be an ordered graph with vertices \(0, \dots, n - 1\) and let \((E_i)_{i \in \mathbb{N}}\) be predicates on lists of vertices. Relation symbol \(0\) holds of a list exactly when it is a pair \((a, b)\) with \(a < b\), relation symbol \(1\) holds of a list exactly when it is a pair \((a, b)\) with an edge from \(a\) to \(b\) in \(G\), and relation symbol \(i + 2\) is interpreted as \(E_i\).

    DefinitionWell-formed FO + LFP formulas#✓fully proved

    MetaMathlibExt.Complexity.KeyTheorems.ImmermanVardi.OGWellFormed

    Let \(e\) assign to each relation symbol (a natural number) either an arity or nothing. Whether a first-order formula with least fixed points over ordered graphs is well-formed relative to \(e\) is defined by recursion on the formula. An equality of two variables is well-formed. An atomic formula \(R(x_1, \dots, x_k)\) is well-formed when \(k = a\) if \(e(R) = a\); when \(k = 2\) if \(e\) assigns nothing to \(R\) and \(R\) is \(0\) (the order) or \(1\) (the edge relation); and always otherwise. A negation or an existential quantification is well-formed when its body is, and a conjunction or a disjunction when both of its parts are. A least-fixed-point formula that binds the symbol \(R\) with arity \(a\), has body \(\varphi\) and is applied to the variables \(y_1, \dots, y_k\) is well-formed when \(R \ge 2\), \(k = a\), and \(\varphi\) is well-formed relative to the assignment that agrees with \(e\) except that it gives \(R\) the arity \(a\).

    def OGWellFormed (env : ℕ → Option ℕ) : OGFO → Prop
  | .eq _ _ => True
  | .rel i args => match env i with
    | some a => args.length = a
    | none => if i = 0 ∨ i = 1 then args.length = 2 else True
  | .not φ => OGWellFormed env φ
  | .and φ ψ => OGWellFormed env φ ∧ OGWellFormed env ψ
  | .or φ ψ => OGWellFormed env φ ∧ OGWellFormed env ψ
  | .exists φ => OGWellFormed env φ
  | .lfp R arity φ args => 2 ≤ R ∧ args.length = arity ∧
      OGWellFormed (Function.update env R (some arity)) φ

    DefinitionEvaluation of FO + LFP formulas in an ordered graph#✓fully proved

    MetaMathlibExt.Complexity.KeyTheorems.ImmermanVardi.ogEval

    Let \(G\) be an ordered graph with vertex set \(V = \{0, \dots, n - 1\}\), let \(\rho\) assign a vertex to each variable \(0, 1, 2, \dots\), and let \(S\) assign to each relation symbol \(i\) a predicate \(S_i\) on lists of vertices. The truth of a formula is defined by recursion: \(x_a = x_b\) holds when \(\rho(a) = \rho(b)\); the atom \(R_i(x_{a_1}, \dots, x_{a_k})\) holds when \(S_i\) holds of \((\rho(a_1), \dots, \rho(a_k))\); negation, conjunction and disjunction are evaluated as usual; \(\exists \varphi\) holds when \(\varphi\) holds for some \(v \in V\) under the assignment sending variable \(0\) to \(v\) and variable \(j + 1\) to \(\rho(j)\). The least-fixed-point formula with bound symbol \(R\), arity \(k\), body \(\varphi\) and argument variables \(a_1, \dots, a_m\) holds when \((\rho(a_1), \dots, \rho(a_m))\) lies in \(X_{n^k}\), where \(X_0\) is empty and a list \(t\) lies in \(X_{s+1}\) when \(\varphi\) holds with \(R\) reinterpreted as \(X_s\) (the other symbols keeping their interpretation under \(S\)) and with variable \(j\) assigned the \(j\)-th entry of \(t\) (or \(\rho(0)\) if \(t\) has no such entry) for \(j < k\) and \(\rho(j - k)\) for \(j \ge k\).

    MetaMathlibExt.Complexity.KeyTheorems.ImmermanVardi.ogLFPSat

    An ordered graph \(G\) with \(n > 0\) vertices satisfies a formula \(\varphi\) of first-order logic with least fixed points when \(\varphi\) is well-formed in the environment where no relation symbol is bound, all fixed points of \(\varphi\) are positive, and \(\varphi\) is true in \(G\) with every variable assigned the vertex \(0\), relation symbol \(0\) interpreted as the order \(<\), relation symbol \(1\) as the edge relation, and every other relation symbol as the empty relation.
