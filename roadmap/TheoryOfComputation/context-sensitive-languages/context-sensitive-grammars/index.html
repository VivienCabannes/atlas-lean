    DefinitionContext-sensitive grammar#✓fully proved

    Cslib.Language.IsContextSensitive

    A grammar is context-sensitive when every production has a nonterminal on its left side (so the left side is nonempty and not terminal-only) and no production shrinks. The standard S → ε exception is not used here: the aⁿbⁿcⁿ grammar has n ≥ 1.

    def IsContextSensitive {T N : Type*} (g : CSGrammar T N) : Prop :=
  ∀ r ∈ g.rules, r.1.any (·.isNonterminal) = true ∧ r.1.length ≤ r.2.length
