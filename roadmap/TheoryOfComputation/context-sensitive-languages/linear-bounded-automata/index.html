    DefinitionLegal head move of a linear bounded automaton#✓fully proved

    Cslib.Language.LBAMove.legal

    A move is legal from the head position h on a tape of length n when the source head is on the tape and the new head position is still on the tape. In particular a left move from an out-of-bounds head is illegal, even though the truncated new head h - 1 would still be out of bounds: legality requires h < n for left moves as well.

    def LBAMove.legal (mv : LBAMove) (h n : ℕ) : Prop :=
  match mv with
  | .left => 0 < h ∧ h < n
  | .stay => h < n
  | .right => h + 1 < n
    inductive LBAMove where

    StructureLinear bounded automaton#✓fully proved

    Cslib.Language.LinearBoundedAutomaton

    A linear bounded automaton: a nondeterministic Turing machine whose tape is the input word. The transition function gives, for a state, the symbol under the head (none for a blank cell), and the boundary tag of the head position, the finite set of possible next states, symbols to write (none for a blank), and head moves. The boundary tag is what lets the machine detect the ends of its tape: without it the model could not recognize general context-sensitive languages. A move that would take the head off the tape is not a step.

    structure LinearBoundedAutomaton (Q Γ : Type*) where
  /-- The initial state. -/
  q₀ : Q
  /-- The accepting state. -/
  qAcc : Q
  /-- The transition function: from a state, the symbol under the head,
  and the boundary tag of the head position, the finite set of possible
  (next state, written symbol, head move) triples. -/
  delta : Q → Option Γ → LBABoundary → Finset (Q × Option Γ × LBAMove)
    inductive LBABoundary where

    DefinitionOne step of a linear bounded automaton#✓fully proved

    Cslib.Language.LinearBoundedAutomaton.Step

    One step of the machine: choose a transition for the current state, the symbol under the head, and its boundary tag, write the symbol, move the head legally. A step from a configuration whose head is off the tape is impossible: legality requires the source head to be on the tape.

    def Step (c c' : LBAConfig Q Γ) : Prop :=
  ∃ (q' : Q) (b' : Option Γ) (mv : LBAMove),
    (q', b', mv) ∈
      M.delta c.state (c.tape[c.head]?).join
        (LBABoundary.ofHead c.head c.tape.length) ∧
    c' = ⟨q', c.tape.set c.head b', mv.moveHead c.head⟩ ∧
    mv.legal c.head c.tape.length
