    MetaMathlibExt.Complexity.NPComplete.LatinSquareCompletion.LatinSquareCompletionFeasible

    An instance \((n, G)\) of LATIN SQUARE COMPLETION is feasible when there is a grid \(C\) consisting of \(n\) rows of length \(n\) such that for all \(r, c < n\) the entry \(G_{rc}\) is either \(0\) or equal to \(C_{rc}\), every row of \(C\) is a permutation of \(1, \dots, n\), and every column of \(C\) is a permutation of \(1, \dots, n\). Here \(G_{rc}\) is taken to be \(0\) when \(G\) has no entry in row \(r\) and column \(c\).

    def LatinSquareCompletionFeasible
    (i : LatinSquareCompletionInstance) : Prop :=
  ∃ completion : List (List ℕ), completion.length = i.1 ∧
    (∀ row ∈ completion, row.length = i.1) ∧
    (∀ r < i.1, ∀ c < i.1, (i.2.getD r []).getD c 0 = 0 ∨
      (i.2.getD r []).getD c 0 = (completion.getD r []).getD c 0) ∧
    (∀ r < i.1, (completion.getD r []).Perm ((List.range i.1).map (· + 1))) ∧
    ∀ c < i.1, ((List.range i.1).map
      (fun r => (completion.getD r []).getD c 0)).Perm ((List.range i.1).map (· + 1))

    MetaMathlibExt.Complexity.NPComplete.LatinSquareCompletion.latinSquareCompletionDec

    The decision problem LATIN SQUARE COMPLETION accepts a bitstring \(x\) exactly when \(x\) decodes, under the canonical bitstring encoding of pairs of a natural number and a list of lists of natural numbers, to an instance \((n, G)\) that is well formed (\(n > 0\) and \(G\) consists of \(n\) rows of length \(n\) with entries at most \(n\)) and feasible (\(G\) can be completed to an \(n \times n\) grid whose rows and columns are permutations of \(1, \dots, n\) and which agrees with \(G\) on its nonzero entries). Bitstrings that do not decode, or that decode to a malformed instance, are rejected.

    noncomputable def latinSquareCompletionDec :
    MetaMathlibExt.ComplexityTheory.DecisionProblem := fun x =>
  match MetaMathlibExt.BitstringEncoding.bitDecode
      (α := LatinSquareCompletionInstance) x with
  | some i => decide (WellFormed i ∧ LatinSquareCompletionFeasible i)
