    DefinitionBits pushed by a walk of the CLIQUE emitter#✓fully proved

    Cslib.Complexity.Karp.EmitClique.walkBits

    Let \(l = (x, p)\) be a literal occurrence with name \(x \in \mathbb{N}\) and polarity \(p\), let \(f\) be a Boolean, and let \(ds\) be a list whose items are literal occurrences or clause markers. The bit list \(\mathrm{walkBits}(l, f, ds)\) is defined by recursion on \(ds\): it is empty if \(ds\) is empty; if \(ds\) is a clause marker followed by \(ds'\), it is \(\mathrm{walkBits}(l, \mathrm{true}, ds')\); and if \(ds\) is an occurrence \(l'\) followed by \(ds'\), it is the bit \(f \wedge \mathrm{adj}(l, l')\) followed by \(\mathrm{walkBits}(l, f, ds')\). Here \(\mathrm{adj}(l, l')\) is the Karp adjacency of literals: it is false exactly when \(l\) and \(l'\) have the same name and opposite polarities.

    The flag \(f\) records whether a clause marker has been passed; while it is false, each occurrence contributes a false bit.

    def walkBits (l : ℕ × Bool) : Bool → List (Option (ℕ × Bool)) → List Bool
  | _, [] => []
  | _, none :: ds => walkBits l true ds
  | f, some l' :: ds => (f && adjL l l') :: walkBits l f ds
    def adjL (l l' : ℕ × Bool) : Bool := !(l.1 == l'.1 && l.2 != l'.2)

    DefinitionRow bits of a formula for the CLIQUE emitter#✓fully proved

    Cslib.Complexity.Karp.EmitClique.rowsF

    A literal is a pair \((x, s)\) of a variable \(x \in \mathbb{N}\) and a polarity \(s\), and an item is a literal or a clause marker. For a literal \(\ell = (x, s)\), a Boolean \(f\) and a list of items, the walk bits are defined by recursion on the list: there are none for the empty list; for a list starting with a clause marker they are the walk bits of the rest with \(f\) replaced by true; for a list starting with a literal \((x', s')\) they are the bit "\(f\) and not (\(x = x'\) and \(s \ne s'\))" followed by the walk bits of the rest with the same \(f\). For a list \(\delta\) of items, the rows of a list of literals are none for the empty list, and for a list \(\ell_1, \dots, \ell_k\) with \(k \ge 1\) they are the reverse of the walk bits of \(\ell_1\) with \(f\) false over the list \(\ell_2, \dots, \ell_k\) followed by \(\delta\), then the rows of \(\ell_2, \dots, \ell_k\). The items of a CNF formula \(\psi\) are, for each clause of \(\psi\) in order, its literals followed by a clause marker. The row bits of a CNF formula are defined by recursion on its clauses: the empty formula has none, and for the formula with first clause \(C\) and remaining clauses \(\varphi\) they are the rows of the literals of \(C\) for \(\delta\) the clause marker followed by the items of \(\varphi\), followed by the row bits of \(\varphi\).

    def rowsF : CNF → List Bool
  | [] => []
  | C :: φ => lrows (none :: items φ) C ++ rowsF φ

    DefinitionThe CLIQUE emitter machine#✓fully proved

    Cslib.Complexity.Karp.EmitClique.prog

    The CLIQUE emitter is the multi-stack machine with stacks \(T, O, A, B, D, E, X, C, N\), a Boolean flag and the labels named below. The stack \(O\) holds Booleans and the others hold symbols, among them the bit symbols \(\mathrm{bit}(b)\), the literal symbols \(\mathrm{lit}(p)\) and the clause marker \(\mathrm{cl}\). Each test sets the flag to its outcome, a pop that reads a polarity or a bit sets the flag to it, and other pops leave the flag unchanged. To move the bits of \(Y\) to \(Z\) and then go to \(\lambda\) means: while the top of \(Y\) is a bit symbol, pop it and push it onto \(Z\); once \(Y\) is empty or its top is another symbol, go to \(\lambda\) (the flag serves as scratch). The instruction at each label is as follows.

    At \(\mathrm{start}\): test whether \(T\) is empty; if so go to \(\mathrm{fin}\), else pop \(T\), push \(\mathrm{cl}\) onto \(D\) and onto \(C\), and go to \(\mathrm{lits}\). At \(\mathrm{lits}\): test whether the top of \(T\) is a literal symbol; if so pop it, reading the polarity \(q\) (true exactly for \(\mathrm{lit}(\mathrm{true})\)), push \(\mathrm{cl}\) onto \(N\) and go to \(\mathrm{nm}(q)\); else go to \(\mathrm{start}\). At \(\mathrm{nm}(p)\): move the bits of \(T\) to \(A\), then go to \(\mathrm{walk}(p, \mathrm{false})\). At \(\mathrm{walk}(p, f)\): test whether \(D\) is empty; if so go to \(\mathrm{back}(p)\); else test whether the top of \(D\) is \(\mathrm{cl}\); if so pop it, push \(\mathrm{cl}\) onto \(E\) and go to \(\mathrm{walk}(p, \mathrm{true})\); else pop \(D\), reading \(q\) (true exactly for \(\mathrm{lit}(\mathrm{true})\)), push \(\mathrm{lit}(q)\) onto \(E\), and if \(f\) go to \(\mathrm{cmp}(p, q)\), else push false onto \(O\) and go to \(\mathrm{mvN}(p, \mathrm{false})\). At \(\mathrm{cmp}(p, q)\): compare the bits of \(A\) and \(D\), that is, while both tops are bit symbols of the same bit, pop both and push that bit symbol onto \(X\) and onto \(B\); when both bit blocks end together go to \(\mathrm{res}(p, b)\) with \(b\) true exactly when \(p = q\), and on a mismatch (different bits, or one block ending first) go to \(\mathrm{res}(p, \mathrm{true})\) without popping (the flag serves as scratch). At \(\mathrm{res}(p, b)\): push \(b\) onto \(O\) and go to \(\mathrm{rsA}(p)\). At \(\mathrm{rsA}(p)\): move the bits of \(X\) to \(A\), then go to \(\mathrm{rsD}(p)\). At \(\mathrm{rsD}(p)\): move the bits of \(B\) to \(D\), then go to \(\mathrm{mvN}(p, \mathrm{true})\). At \(\mathrm{mvN}(p, f)\): move the bits of \(D\) to \(E\), then go to \(\mathrm{walk}(p, f)\). At \(\mathrm{back}(p)\): test whether \(E\) is empty; if so go to \(\mathrm{put}(p)\); else test whether its top is \(\mathrm{cl}\); if so pop it and push \(\mathrm{cl}\) onto \(D\); else test whether its top is a literal symbol; if so pop it, reading \(q\) (true exactly for \(\mathrm{lit}(\mathrm{true})\)), and push \(\mathrm{lit}(q)\) onto \(D\); else pop it, reading \(b\) (true exactly for \(\mathrm{bit}(\mathrm{true})\)), and push \(\mathrm{bit}(b)\) onto \(D\); in these three cases stay at \(\mathrm{back}(p)\). At \(\mathrm{put}(p)\): move the bits of \(A\) to \(B\), then go to \(\mathrm{put2}(p)\). At \(\mathrm{put2}(p)\): move the bits of \(B\) to \(D\), then go to \(\mathrm{put3}(p)\).
