    DefinitionThe clique verifier's unary reader#✓fully proved

    Cslib.Complexity.Karp.KGVerify.readU

    For a stack \(c\) and labels \(\ell\) (its own) and \(\ell'\) (the next), the unary reader onto \(c\) is the verifier statement that inspects the input stack \(X\) and sets the state to whether \(X\) is empty: if it is, it goes to the rejecting label; otherwise it pops the top symbol of \(X\) and sets the state to whether that symbol is the bit \(1\); if so, it pushes the bit \(1\) onto \(c\) and goes to \(\ell\), while any other symbol (normally the terminating \(0\)) sends it to \(\ell'\).

    Run from \(\ell\), it reads a unary number off \(X\) onto the counter \(c\).

    def readU (c : K) (self next : Lab) : Stmt :=
  .peek .X (fun _ o => o.isNone) <| .branch id (.goto fun _ => .no) <|
    .pop .X (fun _ o => bitOf Sym.bit? o) <| .branch id
      (.push c (fun _ => .bit true) (.goto fun _ => self)) (.goto fun _ => next)
    inductive K | X | W | C | N | V | T
  deriving DecidableEq

    DefinitionLoad step of the CLIQUE verifier#✓fully proved

    Cslib.Complexity.Karp.KGVerify.loadS

    The statement run at the load label. If the counter \(N\) is nonempty, it takes a unit off \(N\), rejects if the witness stack \(W\) is empty, and otherwise pops the top of \(W\) and pushes its bit (false for a non-bit symbol) onto the vertex stack \(V\); if that bit is set it also takes a unit off the counter \(C\), rejecting if \(C\) is empty; then it returns to the load label. If \(N\) is empty, it goes to the walk label with its flag \(c\) (the conjunction of the row's pair conditions so far) set to true when \(C\) is empty, and rejects otherwise.

    Started from \(n\) on \(N\) and \(k\) on \(C\), it loads the first \(n\) witness bits onto \(V\), bit \(n - 1\) on top, and rejects if \(W\) runs out or the number of set bits among them is not \(k\).

    def loadS : Stmt :=
  .pop .N (fun _ o => o.isSome) <| .branch id
    (.peek .W (fun _ o => o.isNone) <| .branch id (.goto fun _ => .no) <|
      .pop .W (fun _ o => bitOf Sym.bit? o) <| .branch id
        (.push .V (fun _ => .bit true) <| .pop .C (fun _ o => o.isSome) <| .branch id
          (.goto fun _ => .load) (.goto fun _ => .no))
        (.push .V (fun _ => .bit false) <| .goto fun _ => .load))
    (.peek .C (fun _ o => o.isNone) <| .branch id (.goto fun _ => .walk true)
      (.goto fun _ => .no))

    DefinitionRest of a walk step of the clique verifier#✓fully proved

    Cslib.Complexity.Karp.KGVerify.walkZ

    Write \(\mathrm{free}_m(s)\) for the condition that, in mode \(m\), a vertex with chosen-flag \(s\) settles every pair of its row, and \(\mathrm{sat}_m(b', s')\) for the pair condition on pair bit \(b'\) and later vertex flag \(s'\). In mode \(m\) with row flag \(c\), after a bit \(z\) has been popped off the vertex stack \(V\): if \(V\) is now empty, the machine moves to the put-back label when \(\mathrm{free}_m(z)\) or \(c\) holds, and to the reject label otherwise. If \(V\) is not empty, it pushes \(z\) onto the scratch stack \(T\); then it moves to the reject label if the input stack \(X\) is empty, and otherwise pops the top symbol of \(X\), reads it as a bit \(b\) (a non-bit symbol reads as false), and moves to the walk label with flag \(c \wedge \mathrm{sat}_m(b, z)\).

    def walkZ (m : Mode) (c z : Bool) : Stmt :=
  .peek .V (fun _ o => o.isNone) <| .branch id
    (.goto fun _ => if m.free z || c then .back else .no) <|
  .push .T (fun _ => .bit z) <|
  .peek .X (fun _ o => o.isNone) <| .branch id (.goto fun _ => .no) <|
  .pop .X (fun _ o => bitOf Sym.bit? o) <| .branch id
    (.goto fun _ => .walk (c && m.sat true z)) (.goto fun _ => .walk (c && m.sat false z))
    inductive Mode | clique | indep | cover
  deriving DecidableEq

    DefinitionWalk step of the clique verifier#✓fully proved

    Cslib.Complexity.Karp.KGVerify.walkS

    In mode \(m\) with row flag \(c\), the walk step looks at the vertex stack \(V\). If \(V\) is empty, it moves to the accept label if the input stack \(X\) is empty and to the reject label otherwise. If \(V\) is not empty, it pops the top symbol of \(V\), reads it as a bit \(z\) (a non-bit symbol reads as false), and continues with the rest of the walk step for \(m\), \(c\) and \(z\).

    def walkS (m : Mode) (c : Bool) : Stmt :=
  .peek .V (fun _ o => o.isNone) <| .branch id
    (.peek .X (fun _ o => o.isNone) <| .branch id (.goto fun _ => .yes) (.goto fun _ => .no)) <|
  .pop .V (fun _ o => bitOf Sym.bit? o) <| .branch id (walkZ m c true) (walkZ m c false)
    inductive Mode | clique | indep | cover
  deriving DecidableEq

    DefinitionProgram of the clique verifier#✓fully proved

    Cslib.Complexity.Karp.KGVerify.prog

    For a mode \(m\) (clique, independent set or vertex cover), the verifier program of mode \(m\) assigns a statement to each label of the verifier: to the label that reads the instance's target size \(k\), the unary reader onto the counter \(C\) with own label this label and next label the label that reads the instance's number \(n\) of vertices; to the label that reads \(n\), the unary reader onto the counter \(N\) with own label this label and next label the load label; to the load label, the load step; to the walk label with flag \(c\), the walk step of mode \(m\) with flag \(c\); to the put-back label, the bit-moving loop from the scratch stack \(T\) to the vertex stack \(V\) that reads name-bit symbols as bits and writes each bit \(b\) as the name bit \(b\), with own label the put-back label and next label the walk label with flag true; and to the accept and reject labels, the statement that halts.

    Run from the label that reads \(k\), it parses \(k\) and \(n\), loads the witness and walks the rows.

    def prog (m : Mode) : Lab → TM2.Stmt (fun _ : K => Sym) Lab Bool
  | .rdK => readU .C .rdK .rdN
  | .rdN => readU .N .rdN .load
  | .load => loadS
  | .walk c => walkS m c
  | .back => moveB .T .V Sym.bit? Sym.bit .back (.walk true)
  | .yes => .halt
  | .no => .halt
    inductive Mode | clique | indep | cover
  deriving DecidableEq

    Cslib.Complexity.Karp.KGVerify.run_one

    Let \(M\) be a program that assigns a verifier statement to each label, \(\ell\) and \(\ell'\) labels, \(v\) a state and \(S\) stack contents.     Cslib.Complexity.Karp.KGVerify.readU_some

    Let \(m\) be a mode, \(c\) a stack other than the input stack \(X\), and \(\ell\), \(\ell'\) labels such that the verifier program of mode \(m\) runs, at label \(\ell\), the unary reader onto \(c\) with own label \(\ell\) and next label \(\ell'\).
