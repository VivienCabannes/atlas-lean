    A NOT-ALL-EQUAL 3-SAT instance \((n, \varphi)\) is well-formed when every clause of \(\varphi\) is a list of exactly three literals, repetitions allowed, and every literal \((x, b)\) in it has variable index \(x < n\).

    DefinitionNot-all-equal satisfiability of an instance#✓fully proved

    MetaMathlibExt.Complexity.NPComplete.NaeThreeSat.NaeThreeSatFeasible

    A NOT-ALL-EQUAL 3-SAT instance \((n, \varphi)\), with \(n \in \mathbb{N}\) and \(\varphi\) a CNF formula, is not-all-equal satisfiable when there are truth values \(a_0, \dots, a_{n-1}\) such that, for the assignment \(v\) with \(v(x) = a_x\) for \(x < n\) and \(v(x) = \mathrm{false}\) for \(x \ge n\), every clause of \(\varphi\) contains a literal satisfied by \(v\) and a literal not satisfied by \(v\).

    def NaeThreeSatFeasible
    (i : NaeThreeSatInstance) : Prop :=
  ∃ assign : List Bool, assign.length = i.1 ∧
    ∀ clause ∈ i.2, Cslib.Logic.PL.CNFClause.Satisfies (fun x => assign.getD x false) clause ∧
      ∃ l ∈ clause, ¬ Cslib.Logic.PL.CNFLiteral.Satisfies (fun x => assign.getD x false) l

    MetaMathlibExt.Complexity.NPComplete.NaeThreeSat.naeThreeSatDec

    The decision problem NOT-ALL-EQUAL 3-SAT accepts a bitstring \(x\) exactly when \(x\) decodes, under the canonical bitstring encoding, to a NOT-ALL-EQUAL 3-SAT instance \((n, \varphi)\) that is well-formed and not-all-equal satisfiable. Every bitstring that decodes to no instance is rejected.
