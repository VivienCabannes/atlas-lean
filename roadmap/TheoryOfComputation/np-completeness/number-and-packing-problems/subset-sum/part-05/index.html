    Cslib.Complexity.Karp.SSVerify.rdS

    For a flag \(z\) (the bits read so far end in false), a statement \(\mathit{done}\) and statements \(\mathit{body}(b)\) for each bit \(b\): if the input stack \(X\) is empty, go to the label \(\mathsf{no}\). Otherwise pop the top of \(X\) as a bit, a symbol that is not a bit counting as false. If it is false (the end marker), go to \(\mathsf{no}\) when \(z\) is true and run \(\mathit{done}\) otherwise. If it is true, go to \(\mathsf{no}\) if \(X\) is now empty, and otherwise pop the next symbol of \(X\) as a payload bit \(b\) (again a non-bit counts as false) and run \(\mathit{body}(b)\).

    DefinitionThe SUBSET-SUM verifier program#✓fully proved

    Cslib.Complexity.Karp.SSVerify.prog

    The program on the stacks \(X, W, T, A, B, P, Q\) over the verifier's symbols, with Boolean internal state, given label by label. A popped symbol that is not a bit counts as false, as does a pop from an empty stack. Reading a pair of a block off \(X\) with flag \(z\) ("the bits read so far end in false") goes to \(\mathsf{no}\) if \(X\) is empty; on the end marker false it goes to \(\mathsf{no}\) if \(z\) holds and otherwise ends the block; on true it reads a payload bit \(b\), going to \(\mathsf{no}\) if \(X\) has ended.

    • \(\mathsf{tgt}(z)\): read a pair of the target block with flag \(z\); at the end of the block go to \(\mathsf{next}\); on a payload bit \(b\), push \(b\) onto \(T\) and go to \(\mathsf{tgt}(\lnot b)\).
    • \(\mathsf{next}\): if \(X\) is empty go to \(\mathsf{fmove}\); otherwise pop a witness bit \(c\) off \(W\) (false if absent) and go to \(\mathsf{add}\) with carry false if \(c\), else to \(\mathsf{skip}\), with the flag unset.
    • \(\mathsf{add}(c, z)\): read a pair with flag \(z\); at the end of the block go to \(\mathsf{fin}(c)\); on a payload bit \(b\), pop a bit \(a\) off \(A\) (false if absent), push \(a \oplus b \oplus c\) onto \(B\) and go to \(\mathsf{add}(c', \lnot b)\), where \(c'\) is the carry out of \(a + b + c\).
    • \(\mathsf{skip}(z)\): read a pair with flag \(z\); at the end of the block go to \(\mathsf{next}\); on a payload bit \(b\) go to \(\mathsf{skip}(\lnot b)\).
    • \(\mathsf{fin}(c)\): carry \(c\) through the rest of \(A\), pushing the result bits onto \(B\), then go to \(\mathsf{back}\).
    • \(\mathsf{back}\): move the bits on top of \(B\) onto \(A\) one by one, then go to \(\mathsf{next}\).
    • \(\mathsf{fmove}\): move the bits on top of \(A\) onto \(B\) one by one, then go to \(\mathsf{cmp}\).
    • \(\mathsf{cmp}\): compare the bit blocks on top of \(B\) and \(T\), using \(P\) and \(Q\) as scratch, and go to \(\mathsf{yes}\) if they are equal and to \(\mathsf{no}\) otherwise.
    • \(\mathsf{yes}\) and \(\mathsf{no}\): halt.
    def prog : Lab → TM2.Stmt (fun _ : K => Sym) Lab Bool
  | .tgt z => rdS z (.goto fun _ => .next) fun b =>
      .push .T (fun _ => .bit b) <| .goto fun _ => .tgt (!b)
  | .next => nextS
  | .add c z => rdS z (.goto fun _ => .fin c) (addS c)
  | .skip z => rdS z (.goto fun _ => .next) fun b => .goto fun _ => .skip (!b)
  | .fin c => finS c
  | .back => moveB .B .A Sym.bit? Sym.bit .back .next
  | .fmove => moveB .A .B Sym.bit? Sym.bit .fmove .cmp
  | .cmp => cmpB .B .T .P .Q Sym.bit? Sym.bit? Sym.bit Sym.bit .cmp .yes .no
  | .yes => .halt
  | .no => .halt
