    Cslib.Complexity.Karp.SSVerify.loop_run

    Let \(N\) be a natural number and \(t\) a list of symbols. Write \(\langle m \rangle\) for the canonical binary code of a natural number \(m\), least significant bit first, and put a bit list on a stack as the list of its name-bit symbols. Let \(n\) and \(s\) be natural numbers, \(r\) and \(w\) bit lists and \(v\) a Boolean, with \(|r| \le n\) and \(|\langle s \rangle| + |r| \le N\). Start the SUBSET-SUM verifier at the label \(\mathsf{next}\) with internal state \(v\), with \(r\) on \(X\), \(w\) on \(W\), \(t\) on \(T\), \(\langle s \rangle\) on \(A\), and the stacks \(B\), \(P\) and \(Q\) empty. Then for some internal state \(v'\) and stack contents \(S'\) it runs within \(|r| \cdot (2N + 6) + 1\) steps to the configuration with internal state \(v'\), stacks \(S'\) and label \(\mathsf{fmove}\) if parsing the number blocks of \(r\) with fuel \(n\) succeeds, and label \(\mathsf{no}\) if it fails. Moreover, if that parsing gives the list of numbers \(a\), and \(\sigma\) is \(s\) plus the sum of the numbers of \(a\) chosen by the mask \(w\), then \(|\langle \sigma \rangle| \le N\), and for some list of symbols \(w'\) the stacks \(S'\) hold nothing on \(X\), \(w'\) on \(W\), \(t\) on \(T\), \(\langle \sigma \rangle\) on \(A\), and nothing on \(B\), \(P\) and \(Q\).

    theorem loop_run (N : ℕ) (t : List Sym) : ∀ (n : ℕ) (r w : List Bool) (s : ℕ) (v : Bool),
    r.length ≤ n → (encodeNat s).length + r.length ≤ N →
    ∃ v' S', RunLe prog (r.length * (2 * N + 6) + 1)
      ⟨some .next, v, st (r.map .bit) (w.map .bit) t ((encodeNat s).map .bit) []⟩
      ⟨some (if (numsAux n r).isSome then .fmove else .no), v', S'⟩ ∧
      ∀ as, numsAux n r = some as → (encodeNat (s + (pick as w).sum)).length ≤ N ∧
        ∃ w', S' = st [] w' t ((encodeNat (s + (pick as w).sum)).map .bit) []
    inductive Sym
  | bit (b : Bool) | lit (p : Bool) | cl | val (b : Bool) | dead
  deriving DecidableEq

    TheoremSUBSET-SUM is in NP#✓fully proved

    Cslib.Complexity.Karp.subsetSumDec_mem_NP

    SUBSET-SUM is the decision problem on bit strings that accepts \(x\) exactly when \(x\) encodes a target \(t\) followed by natural numbers \(a_1, \dots, a_n\) (each written in binary and delimited) such that some, possibly empty, sublist of \(a_1, \dots, a_n\) sums to \(t\). This decision problem belongs to NP: there are a polynomial \(p\) with natural-number coefficients and a polynomial-time computable verifier \(R\) such that SUBSET-SUM accepts \(x\) exactly when \(R(x, w)\) holds for some bit string \(w\) with \(|w| \le p(|x|)\).

    theorem subsetSumDec_mem_NP : subsetSumDec ∈ NP
    noncomputable def subsetSumDec : MetaMathlibExt.ComplexityTheory.DecisionProblem := fun x =>
  decide (∃ as t, encodeSS as t = x ∧ ∃ l : List ℕ, l.Sublist as ∧ l.sum = t)
