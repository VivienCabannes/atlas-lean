    The emitter is the multi-stack machine with the emitter's stacks (the output stack \(O\) holds bits, every other stack holds token symbols), the emitter's labels, and a boolean internal state. Below, moving the bit block of a stack \(A\) onto a stack \(B\) means popping \(A\) while its top is a name bit \(\mathrm{bit}(b)\) and pushing each popped bit onto \(B\) (as \(\mathrm{bit}(b)\), or as the bit \(b\) when \(B = O\)). Comparing \(F\) with \(V\) means popping both while their tops are equal name bits, pushing each such bit onto \(X\) and onto \(Y\), and ending with "equal" if both bit blocks end together and with "different", without popping, at the first mismatch. Draining \(A\), pushing on given stacks, means popping \(A\) until it is empty and pushing on each of those stacks one symbol per popped symbol. Every pushed symbol not otherwise named is the separator \(\mathrm{cl}\). A list of steps written for several labels in turn is done one label at a time, each label passing to the next.
