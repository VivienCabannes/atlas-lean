    Cslib.Complexity.Karp.EmitHam.detE

    For natural numbers \(m\) (the number of clauses), \(i\), \(x\) and \(j\), let \(r_{i,l} = m + i(3m + 2) + 1 + l\) be row vertex \(l\) of diamond \(i\). For a clause \(C\), a list of literals, the detours of clause \(j\) with contents \(C\) in diamond \(i\) of variable \(x\) are the list of the arcs \((r_{i,3j+1}, j)\) and \((j, r_{i,3j+2})\) if the positive literal \(x\) is in \(C\), followed by the arcs \((r_{i,3j+2}, j)\) and \((j, r_{i,3j+1})\) if the negative literal \(\lnot x\) is in \(C\).

    def detE (m i x j : ℕ) (C : CNFClause) : List (ℕ × ℕ) :=
  (if (x, true) ∈ C then [(hpR m i (3 * j + 1), j), (j, hpR m i (3 * j + 2))] else []) ++
    (if (x, false) ∈ C then [(hpR m i (3 * j + 2), j), (j, hpR m i (3 * j + 1))] else [])

    TheoremSplitting off the middle clause of a concatenation#✓fully proved

    Cslib.Complexity.Karp.EmitHam.range_flatMap_getD

    Let \(P\) and \(Q\) be CNF formulas, \(C\) a clause, and \(\varphi\) the formula whose clauses are those of \(P\), then \(C\), then those of \(Q\). Write \(|P|\) for the number of clauses of \(P\) and \(\varphi_j\) for clause \(j\) of \(\varphi\), counting from \(0\) (the empty clause if \(j\) is out of range). Let \(f\) map each natural number \(j\) and clause to a list of elements of a type \(\alpha\). Then concatenating the lists \(f(j, \varphi_j)\) over \(j < |P| + 1\) in increasing order gives the concatenation of the lists \(f(j, \varphi_j)\) over \(j < |P|\), followed by \(f(|P|, C)\).

    theorem range_flatMap_getD {α : Type} (f : ℕ → CNFClause → List α) (pre : CNF) (C : CNFClause)
    (post : CNF) :
    (List.range (pre.length + 1)).flatMap (fun j => f j ((pre ++ C :: post).getD j [])) =
      (List.range pre.length).flatMap (fun j => f j ((pre ++ C :: post).getD j [])) ++
        f pre.length C
    abbrev CNFClause := List (Nat × Bool)

    TheoremLength bound for the bit encoding of an edge list#✓fully proved

    Cslib.Complexity.Karp.EmitHam.edgeBits_length_le

    Let \(B\) be a natural number and \(E\) a list of pairs of natural numbers such that every pair \((u, v)\) in \(E\) has \(u \le B\) and \(v \le B\). Then the bit encoding of \(E\), which writes each pair \((u, v)\) as \(u\) ones, a zero, \(v\) ones and a zero, has length at most \(|E| \cdot (2B + 2)\), where \(|E|\) is the length of \(E\).

    theorem edgeBits_length_le (B : ℕ) : ∀ (es : List (ℕ × ℕ)), (∀ e ∈ es, e.1 ≤ B ∧ e.2 ≤ B) →
    (Karp.edgeBits es).length ≤ es.length * (2 * B + 2)
    def edgeBits (es : List (ℕ × ℕ)) : List Bool :=
  es.flatMap fun e => List.replicate e.1 true ++ false :: (List.replicate e.2 true ++ [false])
