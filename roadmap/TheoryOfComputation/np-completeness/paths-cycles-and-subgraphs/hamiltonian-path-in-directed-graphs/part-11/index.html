    Cslib.Complexity.Karp.HamVerify.nd_run

    For a list \(p\) of natural numbers write \(\mathrm{enc}(p)\) for its witness encoding: each entry in unary (that many copies of true) followed by false. Let \(a\) be a natural number and \(q\), \(d\) lists of natural numbers. Suppose that the verifier's stacks hold, as bit symbols with the first bit on top, the bits of \(\mathrm{enc}(q)\) on \(\mathsf{W}\), the bits of \(\mathrm{enc}(d)\) in reverse order on \(\mathsf{Z}\), \(a\) copies of the bit true on \(\mathsf{A}\), and nothing on \(\mathsf{R}\), the other stacks being arbitrary. Started at label \(\mathrm{nd}\) with either value of its Boolean variable, the verifier reaches, within \(4|\mathrm{enc}(q)| + |\mathrm{enc}(d)| + 2\) steps, the label \(\mathrm{no}\) if \(a\) is an entry of \(q\) and the label \(\mathrm{incC}\) otherwise. In the second case its stacks are then the initial ones except that \(\mathsf{W}\) holds the bits of the encoding of \(d\) followed by \(q\), and \(\mathsf{Z}\) is empty.

    theorem nd_run (a : ℕ) : ∀ (q done : List ℕ) (v : Bool) (St : ∀ _ : K, List Sym),
    St .W = (encW q).map Sym.bit → St .Z = (encW done).reverse.map Sym.bit →
    St .A = cnt (Sym.bit true) a → St .R = [] →
    ∃ v' S', RunLe prog (4 * (encW q).length + (encW done).length + 2) ⟨some .nd, v, St⟩
      ⟨some (if a ∈ q then .no else .incC), v', S'⟩ ∧
      (a ∉ q → S' = update (update St .W ((encW (done ++ q)).map Sym.bit)) .Z [])
    inductive K | X | W | S | T | N | C | A | B | E | Z | R | Q
  deriving DecidableEq

    Cslib.Complexity.Karp.HamVerify.hd_run

    Let \(es\) be an edge list, \(s, t, n, c, b, a\) numbers and \(q\) a list of vertices, and say the check passes when \(a = s\) in case \(c = 0\), and \((b, a) \in es\) in case \(c \neq 0\). Started at the head-or-edge dispatch, in any internal state, on the stack layout during the step on vertex \(a\) for \(es, s, t, n, c, b, a, q\), the verifier reaches within \(3a + 4\ell + 7\) steps, where \(\ell\) is the number of bits of \(es\), the repeat scan if the check passes and the reject label otherwise, in some internal state and with some stacks; if the check passes, these stacks are the ones it started on.

    theorem hd_run (es : List (ℕ × ℕ)) (s t n c b a : ℕ) (q : List ℕ) (v : Bool) :
    ∃ v' S', RunLe prog (3 * a + 4 * (Karp.edgeBits es).length + 7)
      ⟨some .hd, v, mid es s t n c b a q⟩
      ⟨some (if (if c = 0 then decide (a = s) else decide ((b, a) ∈ es)) = true then .nd
        else .no), v', S'⟩ ∧
      ((if c = 0 then decide (a = s) else decide ((b, a) ∈ es)) = true →
        S' = mid es s t n c b a q)
    def RunLe (M : Λ → TM2.Stmt Γ Λ σ) (B : ℕ) (c d : TM2.Cfg Γ Λ σ) : Prop :=
