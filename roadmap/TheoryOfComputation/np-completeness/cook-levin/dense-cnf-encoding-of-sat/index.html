    DefinitionDense decoding with an accumulator#✓fully proved

    Cslib.Complexity.DenseSAT.decodeAux

    Given a bit string \(w\) and the list \(c\) of slots read so far for the current clause, stored in reverse order, the result is the CNF formula obtained by reading \(w\) two bits at a time: \(00\) outputs the current clause in reading order and continues with no slots read; \(01\) adds an empty slot to the current clause; and \(1s\), for a bit \(s\), adds a slot holding the Boolean \(\lnot s\), so \(10\) adds a positive and \(11\) a negative literal. When fewer than two bits remain, decoding stops and outputs no further clauses, so a trailing unterminated clause and a dangling odd bit are ignored and decoding is total.

    def decodeAux : List Bool → Clause → CNF
  | false :: false :: r, cur => cur.reverse :: decodeAux r []
  | false :: true :: r, cur => decodeAux r (none :: cur)
  | true :: s :: r, cur => decodeAux r (some (!s) :: cur)
  | _, _ => []

    DefinitionSingle-pass evaluation of a dense CNF encoding#✓fully proved

    Cslib.Complexity.DenseSAT.evalCNF

    The scan \(E(r, u, v, f)\) takes the formula bits \(r\) still to be read, the assignment bits \(u\) not yet used by the current clause, the bits \(v\) already used by it (most recent first) and a boolean \(f\) recording whether the current clause is already satisfied; write \(x u'\) for the list with first bit \(x\) followed by the list \(u'\). It reads \(r\) two bits at a time; let \(r'\) be the bits after the pair read. On \(00\) (end of clause) the result is \(f \wedge E(r', \overline{v}\,u, [\,], \mathrm{false})\), where \(\overline{v}\,u\) is the reversal of \(v\) followed by \(u\). On \(01\) (an empty slot) the result is \(E(r', u', x v, f)\) when \(u = x u'\), and \(E(r', [\,], v, f)\) when \(u\) is empty. On \(1s\) (a literal with sign bit \(s\)) the result is \(E(r', u', x v, f \vee (x = \neg s))\) when \(u = x u'\), and \(E(r', [\,], v, f)\) when \(u\) is empty. When fewer than two bits remain, the result is true.

    The scan mirrors the verifier machine step by step.

    def evalCNF : List Bool → List Bool → List Bool → Bool → Bool
  | false :: false :: r, bs, as, fl => fl && evalCNF r (as.reverse ++ bs) [] false
  | false :: true :: r, [], as, fl => evalCNF r [] as fl
  | false :: true :: r, x :: bs, as, fl => evalCNF r bs (x :: as) fl
  | true :: _ :: r, [], as, fl => evalCNF r [] as fl
  | true :: s :: r, x :: bs, as, fl => evalCNF r bs (x :: as) (fl || x == !s)
  | _, _, _, _ => true

    DefinitionIndexed evaluation of a dense CNF encoding#✓fully proved

    Cslib.Complexity.DenseSAT.evalIdx

    The scan \(I(r, a, j, f)\) takes the formula bits \(r\) still to be read, an assignment \(a\) (a list of booleans), the position \(j\) of the next slot in the current clause and a boolean \(f\) recording whether the current clause is already satisfied. It reads \(r\) two bits at a time; let \(r'\) be the bits after the pair read. On \(00\) (end of clause) the result is \(f \wedge I(r', a, 0, \mathrm{false})\). On \(01\) (an empty slot) the result is \(I(r', a, j + 1, f)\). On \(1s\) (a literal with sign bit \(s\)) the result is \(I(r', a, j + 1, f')\), where \(f'\) is true when \(f\) is true, or when \(j < |a|\) and the entry \(a_j\) of \(a\) (counting from \(0\)) equals \(\neg s\). When fewer than two bits remain, the result is true.

    def evalIdx : List Bool → List Bool → ℕ → Bool → Bool
  | false :: false :: r, a, _, fl => fl && evalIdx r a 0 false
  | false :: true :: r, a, j, fl => evalIdx r a (j + 1) fl
  | true :: s :: r, a, j, fl => evalIdx r a (j + 1) (fl || a[j]? == some (!s))
  | _, _, _, _ => true
