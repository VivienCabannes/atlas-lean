    DefinitionPosition of a literal in a transition clause#✓fully proved

    Cslib.Complexity.CookLevin.Family.litPos

    Fix a layout with \(K\) stacks and window depth \(d\), a height bound \(H\), and tables giving for each situation \(i\) a current label \(a(i)\), a next label \(a'(i)\) and window symbol codes \(w(i, k, r)\). The position of literal \(j\) of clause \((t, i)\) is: for \(j = 0\), the index of the label/state variable \(a(i)\) at time \(t\); for \(1 \le j \le Kd\), writing \(j - 1 = kd + r\) with \(r < d\), the index of the cell variable for stack \(k\), depth \(r\) from the top and symbol code \(w(i, k, r)\) at time \(t\); for \(j > Kd\), the index of the label/state variable \(a'(i)\) at time \(t + 1\).

    The literals of a clause are numbered \(0, \dots, Kd + 1\), so the last case is the next label.

    def litPos (H t i j : ℕ) : ℕ :=
  if j = 0 then L.xIdx H t (la i)
  else if j ≤ L.KK * L.d then
    L.cIdx H t ((j - 1) / L.d) ((j - 1) % L.d) (wa i ((j - 1) / L.d) ((j - 1) % L.d))
  else L.xIdx H (t + 1) (na i)

    Cslib.Complexity.CookLevin.Family.lits

    For a layout \(L\) with \(KK\) stacks and window depth \(d\), tables \(la\), \(na\), \(wa\), a height \(H\), a time \(t\) and a situation \(i\), the literals of clause \((t, i)\) form the list of pairs \((p_j, b_j)\) for \(j = 0, 1, \dots, n - 1\), where \(n = KK \cdot d + 2\) is the number of literals, \(p_j\) is the position of literal \(j\) of clause \((t, i)\), and the polarity \(b_j\) is true exactly when \(j = n - 1\). So every literal is negative except the last one, the next label.

  (List.range L.nLits).map fun j => (litPos L la na wa H t i j, decide (j = L.nLits - 1))
