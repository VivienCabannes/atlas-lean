    DefinitionThe multiplication routine of a counter machine#✓fully proved

    Cslib.Complexity.CookLevin.CounterView.mulS

    Let \(a, a_d, b, c, t\) be counters, let \(\mathrm{mk}\) assign a label to each stage of the multiplication routine, and let \(\mathrm{next}\) be a label. The routine assigns to each stage the following counter-machine instruction. At head: pop a unit from \(a\), then push a unit onto \(a_d\) and go to \(\mathrm{mk}(\mathrm{body})\), or go to \(\mathrm{mk}(\mathrm{rest})\) if \(a\) was empty. At body: pop a unit from \(b\), then push a unit onto each of \(c\) and \(t\) and go to \(\mathrm{mk}(\mathrm{body})\), or go to \(\mathrm{mk}(\mathrm{l2})\) if \(b\) was empty. At l2: pop a unit from \(t\), then push a unit onto \(b\) and go to \(\mathrm{mk}(\mathrm{l2})\), or go to \(\mathrm{mk}(\mathrm{head})\) if \(t\) was empty. At rest: pop a unit from \(a_d\), then push a unit onto \(a\) and go to \(\mathrm{mk}(\mathrm{rest})\), or go to \(\mathrm{next}\) if \(a_d\) was empty. In each instruction the pop sets the flag to true if a unit was popped and to false if the counter was empty, and the pushes leave the flag unchanged.

    Started at head with \(a, a_d, b, c, t\) distinct and \(a_d\) and \(t\) empty, the routine ends at \(\mathrm{next}\) having added \(a \cdot b\) to \(c\), with every other counter unchanged; \(a_d\) serves as the loop index and \(t\) as scratch.

    def mulS (a ad b c t : C) (mk : MS → Λ) (next : Λ) : MS → TM2.Stmt (SΓ C) Λ Bool
  | .head => forHead (.c a) (.c ad) () (mk .body) (mk .rest)
  | .body => xfer (.c b) [⟨.c c, ()⟩, ⟨.c t, ()⟩] (mk .body) (mk .l2)
  | .l2 => xfer (.c t) [⟨.c b, ()⟩] (mk .l2) (mk .head)
  | .rest => xfer (.c ad) [⟨.c a, ()⟩] (mk .rest) next
    inductive MS | head | body | l2 | rest
  deriving DecidableEq

    TheoremGap emission in the counter view#✓fully proved

    Cslib.Complexity.CookLevin.CounterView.gapS

    Let \(M\) be a counter machine, let \(P, Q, T_1, T_2\) be pairwise distinct counters, let \(y\) be a list of Booleans, let \(\mathrm{dec}\), \(\mathrm{cmp}\), \(\mathrm{emit}\), \(z\), \(\mathrm{next}\) be labels, and let \(r\), \(r'\), \(\mathrm{out}\) assign a label to each comparison outcome \(\omega\), which is one of \(\mathrm{lt}\), \(\mathrm{eq}\), \(\mathrm{gt}\). In the instructions below, every pop sets the flag to true if a unit was popped and to false if the stack was empty, and pushing or prepending leaves the flag unchanged. Suppose that at \(\mathrm{dec}\), \(M\) pops a unit from \(P\) and goes to \(\mathrm{cmp}\), or to \(z\) if \(P\) was empty; at \(\mathrm{cmp}\), \(M\) pops a unit from each of \(P\) and \(Q\), pushes a unit onto \(T_1\) if \(P\) was nonempty and onto \(T_2\) if \(Q\) was nonempty, and goes back to \(\mathrm{cmp}\) if both were nonempty, and otherwise to \(r(\mathrm{lt})\), \(r(\mathrm{eq})\) or \(r(\mathrm{gt})\) according as only \(Q\), neither, or only \(P\) was nonempty; for each \(\omega\), at \(r(\omega)\), \(M\) pops a unit from \(T_1\), then pushes a unit onto \(P\) and stays at \(r(\omega)\), or goes to \(r'(\omega)\) if \(T_1\) was empty; at \(r'(\omega)\), \(M\) pops a unit from \(T_2\), then pushes a unit onto \(Q\) and stays at \(r'(\omega)\), or goes to \(\mathrm{out}(\omega)\) if \(T_2\) was empty; \(\mathrm{out}(\mathrm{eq}) = \mathrm{next}\) and \(\mathrm{out}(\mathrm{lt}) = \mathrm{out}(\mathrm{gt}) = \mathrm{emit}\); and at \(\mathrm{emit}\), \(M\) prepends \(y\) to the output stack and goes to \(\mathrm{dec}\). Let \(q, g \in \mathbb{N}\) and let \(F\) be counter values with \(F(P) = q + g + 1\), \(F(Q) = q\) and \(F(T_1) = F(T_2) = 0\). Then for every flag \(v\) and every list \(o\) of Booleans, \(M\) goes in exactly \(g(3q + 6) + 3q + 4\) steps from label \(\mathrm{dec}\), flag \(v\) and stacks \(\mathrm{st}(F, o)\) to label \(\mathrm{next}\), flag false and stacks \(\mathrm{st}(F', y^g o)\), where \(F'\) agrees with \(F\) except that \(F'(P) = q\), and \(y^g o\) is \(g\) copies of \(y\) followed by \(o\).

    theorem gapS {P Q T1 T2 : C} {ys : List Bool} {dec cmpL emitL ifZero next : Λ}
    {r rB out : Ordering → Λ}
    (hdec : M dec = decr (.c P) ifZero cmpL)
    (hcmp : M cmpL = cmpStep (.c P) (.c Q) (.c T1) (.c T2) () () cmpL (r .lt) (r .eq) (r .gt))
    (hr : ∀ o, M (r o) = xfer (.c T1) [⟨.c P, ()⟩] (r o) (rB o))
    (hrB : ∀ o, M (rB o) = xfer (.c T2) [⟨.c Q, ()⟩] (rB o) (out o))
    (hout : ∀ o, out o = if o = .eq then next else emitL)
    (hemit : M emitL = emitR .out ys dec)
    (hnd : ([.c P, .c Q, .c T1, .c T2, .out] : List (SK C)).Nodup) (q gap : ℕ) (F : C → ℕ)
    (hP : F P = q + gap + 1) (hQ : F Q = q) (h1 : F T1 = 0) (h2 : F T2 = 0) (v : Bool)
    (o : List Bool) :
    Run M (gap * (3 * q + 6) + 3 * q + 4) ⟨some dec, v, st F o⟩
      ⟨some next, false, st (update F P q) (rep ys gap ++ o)⟩

  .pop k (fun _ o => Flag.tag o.isSome)
    (.branch Flag.untag (.goto fun _ => ifPos) (.goto fun _ => ifZero))
