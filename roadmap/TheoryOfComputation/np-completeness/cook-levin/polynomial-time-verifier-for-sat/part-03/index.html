    DefinitionThe clause-check driver#✓fully proved

    Cslib.Complexity.SatVerifier.Check.drv

    Given the lookup's start label \(l_0\), the statement at each driver label. At start: if the token stack \(T\) is empty, go to yes; if its top is a clause marker, pop it, push the bit false onto the flag stack \(F\) and go to lits; otherwise go to no. At lits: if the top of \(T\) is a literal marker of polarity \(p\), pop it, push the bit \(p\) onto the polarity stack \(P\) and go to \(l_0\); otherwise go to endc. At ret: if the top of the value stack \(V\) is the bit true exactly when the top of \(P\) is the bit true, pop \(F\) and push the bit true onto it; in either case then pop \(V\), pop \(P\) and go to drop. At drop: if the top of \(T\) is a bit, pop it and go to drop; otherwise go to lits. At endc: if the top of \(F\) is the bit true, pop it and go to start; otherwise go to no. At yes and at no: halt.

    DefinitionThe lookup contract#✓fully proved

    Cslib.Complexity.SatVerifier.Check.LookupSpec

    A lookup sub-program \(lk\) with start label \(l_0\) meets the contract with constants \(a\) and \(b\) when the following holds. For every name \(q\) (a list of bits), every table \(es\), with table stack \(B_{es}\), and every list of symbols \(R\) whose first symbol, if any, is not a bit, start the clause-check machine with lookup \(lk\) at label \(l_0\), with any internal state and with stack contents that have the bits of \(q\) in reverse order followed by \(R\) on the token stack \(T\), \(B_{es}\) on \(B\), and \(S\), \(A\), \(C\), \(V\) empty. Then it reaches label ret in at most \(a \cdot |B_{es}| + b\) steps, with some internal state, with \(V\) holding exactly the bit that is the live value of \(q\) in \(es\), and with every other stack unchanged.

    def LookupSpec (lk : LL → Stmt LL) (l0 : LL) (a b : ℕ) : Prop :=
  ∀ (q : List Bool) (es : List Ent) (R : List Sym), R.head?.bind Sym.bit? = none →
    ∀ (v : Bool) (St : ∀ _ : K, List Sym), St .T = (q.map Sym.bit).reverse ++ R →
      St .B = tblStk es → St .S = [] → St .A = [] → St .C = [] → St .V = [] →
      ∃ v', RunLe (prog lk l0) (a * (tblStk es).length + b) ⟨some (.inr l0), v, St⟩
        ⟨some (.inl .ret), v', update St .V [Sym.bit (liveVal es q)]⟩
