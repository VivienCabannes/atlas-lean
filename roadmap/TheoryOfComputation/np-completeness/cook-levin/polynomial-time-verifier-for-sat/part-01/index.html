    DefinitionOccurrence list of a CNF formula#✓fully proved

    Cslib.CookLevin.varsOf

    For a CNF formula \(\varphi = (C_1, \dots, C_m)\), the occurrence list of \(\varphi\) is the list of the variable indices of its literals, in order: the variables of the literals of \(C_1\) in order, then those of \(C_2\), and so on up to \(C_m\). Duplicates are kept, so a variable appears once for each literal in which it occurs.

    def varsOf (φ : CNF) : List Nat := φ.flatMap fun C => C.map Prod.fst

    DefinitionWitness lookup#✓fully proved

    Cslib.CookLevin.lookupVar

    Given a list \(N = (n_1, \dots, n_k)\) of natural numbers, a list \(w = (b_1, \dots, b_m)\) of booleans and a natural number \(x\), the lookup of \(x\) in \(N\) and \(w\) is the timed computation (a returned boolean together with a natural-number cost) that scans the pairs \((n_1, b_1), (n_2, b_2), \dots\) in order, charging one tick for each pair it examines, and returns \(b_i\) for the first \(i\) with \(n_i = x\); if either list runs out first, it returns false at no further cost.

    It is used with \(N\) the variables occurring in a formula and \(w\) the witness values, so the first occurrence of a variable wins.

    def lookupVar : List Nat → List Bool → Nat → TimeM Nat Bool
  | [], _, _ => pure false
  | _, [], _ => pure false
  | n :: ns, b :: bs, x =>
      TimeM.tick 1 >>= fun _ =>
        if x = n then pure b else lookupVar ns bs x

    DefinitionClause check against a witness#✓fully proved

    Cslib.CookLevin.checkClause

    Given a list \(N\) of natural numbers, a list \(w\) of booleans and a CNF clause \(C\), the check of \(C\) against \(N\) and \(w\) is the timed computation (a returned boolean together with a natural-number cost) that scans the literals \((x, b)\) of \(C\) in order: for each it charges one tick, then looks up \(x\) in \(N\) and \(w\), paying the cost of the lookup, and returns true if the value found equals the polarity \(b\); otherwise it moves on to the next literal. When the literals are exhausted it returns false at no further cost; in particular the empty clause fails.

    def checkClause (vars : List Nat) (w : List Bool) :
    CNFClause → TimeM Nat Bool
  | [] => pure false
  | l :: ls =>
      TimeM.tick 1 >>= fun _ =>
        lookupVar vars w l.1 >>= fun v =>
          if v = l.2 then pure true else checkClause vars w ls
    abbrev CNFClause := List (Nat × Bool)

    DefinitionFormula check against a witness#✓fully proved

    Cslib.CookLevin.checkCNF

    Given a list \(N\) of natural numbers, a list \(w\) of booleans and a CNF formula \(\varphi\), the check of \(\varphi\) against \(N\) and \(w\) is the timed computation that runs the clause check against \(N\) and \(w\) on the clauses of \(\varphi\) in order, adding up their costs, and returns false as soon as one of them returns false. If every clause check returns true, in particular if \(\varphi\) has no clauses, it returns true.

    def checkCNF (vars : List Nat) (w : List Bool) : CNF → TimeM Nat Bool
  | [] => pure true
  | C :: Cs =>
      checkClause vars w C >>= fun ok =>
        if ok = true then checkCNF vars w Cs else pure false
    abbrev CNF := List CNFClause

    DefinitionThe SAT verifier#✓fully proved

    Cslib.CookLevin.satVerifier

    The SAT verifier takes a pair \((x, w)\) of lists of Booleans, an input \(x\) and a witness \(w\), and returns a Boolean together with a declared time cost. If the complete CNF decoder fails on \(x\), it returns false at cost \(0\). If \(x\) decodes to a CNF formula \(\varphi\), it returns the result and the cost of the CNF check of \(\varphi\) against the witness \(w\) and the occurrence list of \(\varphi\), so that \(w\) is read as values for the variables of \(\varphi\) in order of occurrence.

    Decoding the input is uncharged preprocessing: it adds nothing to the declared cost.

    def satVerifier : List Bool × List Bool → TimeM Nat Bool := fun xw =>
  match decodeCNF xw.1 with
  | none => pure false
  | some φ => checkCNF (varsOf φ) xw.2 φ
    def decodeCNF (input : List Bool) : Option CNF := do
  let (φ, rest) ← decodeCNFAux input
  if rest.isEmpty then some φ else none

    TheoremCost bound for the witness clause check#✓fully proved

    Cslib.CookLevin.checkClause_time_le

    Let \(N\) be a list of natural numbers, \(w\) a list of booleans and \(C\) a CNF clause, viewed as a list of \(\ell\) literals (repetitions counted). The cost of checking \(C\) against \(N\) and \(w\) is at most \(\ell \cdot (|N| + 1)\), where \(|N|\) is the length of \(N\).
