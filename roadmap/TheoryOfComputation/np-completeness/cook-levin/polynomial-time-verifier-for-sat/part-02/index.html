    A symbol of the token and table stacks that is the name bit \(b\) reads as the bit \(b\); every other symbol reads as no bit, and so ends a name block.

    def Sym.bit? : Sym → Option Bool

    Cslib.Complexity.SatVerifier.litToks

    For a literal \((n, p)\) with variable index \(n\) and polarity \(p\), the token list is one bit symbol for each bit of the canonical binary representation of \(n\) (least significant bit first, empty for \(n = 0\)), in order, followed by the polarity marker symbol for \(p\).

    def litToks (l : ℕ × Bool) : List Sym := (encodeNat l.1).map .bit ++ [.lit l.2]
