    Cslib.Complexity.SatVerifier.Tokenizer.prog

    The tokenizer is a multi-stack machine with stacks \(X\) (formula bits), \(W\) (witness bits), \(T\) (tokens), \(B\) (table) and the unary counters \(CC\), \(LC\) (over the unit symbol \(\mathsf{cl}\)), and one bit of internal state. Its instruction at each label is:

    • \(\mathsf{un}(\mathrm{true})\), \(\mathsf{un}(\mathrm{false})\): read a unary count from \(X\) onto \(CC\) and \(LC\) respectively.     • \(\mathsf{cls}\): pop \(CC\); if it was non-empty go to \(\mathsf{un}(\mathrm{false})\), else go to \(\mathsf{fin}\).
    • \(\mathsf{lits}\): pop \(LC\); if it was non-empty go to \(\mathsf{nm}(\mathrm{none})\), else push \(\mathsf{cl}\) onto \(T\) and go to \(\mathsf{cls}\).
    • \(\mathsf{nm}(\ell)\), where \(\ell\) is an optional bit: if the top of \(X\) is the bit true, pop it; then if the top of \(X\) is a bit \(s\), pop it, push the name bit \(s\) onto \(T\) and onto \(B\) and go to \(\mathsf{nm}(s)\), and otherwise go to \(\mathsf{rej}\).     • \(\mathsf{acc}\), \(\mathsf{rej}\): halt.
