    DefinitionHost labels as a sum type#✓fully proved

    Cslib.Complexity.SatVerifier.Machine.HLab.equiv

    Write \(P_0\) for the phase-0 labels, \(\Lambda_T\) for the tokenizer labels, \(\Lambda_F\) for the labels of the clause-length filter, and \(\Lambda_D\) and \(\Lambda_L\) for the labels of the clause-check driver and of the lookup. The host labels are in bijection with \(P_0 \sqcup \Lambda_T \sqcup \Lambda_F \sqcup (\Lambda_D \sqcup \Lambda_L) \sqcup \mathrm{Bool} \sqcup \mathrm{Bool}\): a phase-0 label \(p\), tokenizer label, filter label, or driver or lookup label goes to itself in its summand, a cleanup label with answer \(a\) goes to \(a\) in the first copy of \(\mathrm{Bool}\), and a final label with answer \(a\) goes to \(a\) in the second copy. The bijection gives the host labels their finiteness instance.

    def HLab.equiv :
    HLab ≃ P0 ⊕ Tokenizer.Lab ⊕ Karp.Filter3.Lab ⊕ (Check.DLab ⊕ Lookup.Lab) ⊕ Bool ⊕ Bool where
  toFun
    | .ph p => .inl p | .tok l => .inr (.inl l) | .flt l => .inr (.inr (.inl l))
    | .chk l => .inr (.inr (.inr (.inl l))) | .clean a => .inr (.inr (.inr (.inr (.inl a))))
    | .fin a => .inr (.inr (.inr (.inr (.inr a))))
  invFun
    | .inl p => .ph p | .inr (.inl l) => .tok l | .inr (.inr (.inl l)) => .flt l
    | .inr (.inr (.inr (.inl l))) => .chk l | .inr (.inr (.inr (.inr (.inl a)))) => .clean a
    | .inr (.inr (.inr (.inr (.inr a)))) => .fin a
  left_inv x := by cases x <;> rfl
  right_inv x := by rcases x with p | l | l | l | a | a <;> rfl

    DefinitionStack embedding of the tokenizer into the host#✓fully proved

    Cslib.Complexity.SatVerifier.Machine.embT

    Every stack of the tokenizer has alphabet \(\mathrm{Sym}\). The tokenizer is embedded in the host machine by sending each of its stacks \(X\), \(W\), \(T\), \(B\), \(CC\), \(LC\) to the host stack of the same name (an injective map) and identifying the alphabet of each with that of its image, which is again \(\mathrm{Sym}\), by the identity.

    def embT : SEmb (fun _ : Tokenizer.K => Sym) HΓ where
  e := eT
  inj a b h := by cases a <;> cases b <;> first | rfl | exact absurd h (by decide)
  ι k := match k with
    | .X => Equiv.refl Sym | .W => Equiv.refl Sym | .T => Equiv.refl Sym
    | .B => Equiv.refl Sym | .CC => Equiv.refl Sym | .LC => Equiv.refl Sym

    DefinitionProgram of the SAT verifier host#✓fully proved

    Cslib.Complexity.SatVerifier.Machine.hprog

    For a value \(c\) of the 3SAT flag, the host program acts at each host label as follows. Here moving a bit block from one stack to another means repeatedly popping the top symbol of the first stack while it is a bit and pushing it, as a bit token, onto the second, and continuing at the next label once the top is not a bit or the stack is empty.

    The phase-0 labels move the formula bits from the input stack onto a scratch stack, move them from there onto the formula stack, pop one symbol (on a pair encoding, the separator) from the input stack, move the certificate bits from the input stack onto a second scratch stack, and move them from there onto the certificate stack before going to the start label of the tokenizer. At a tokenizer label, a filter label or a driver label the host runs the program of the tokenizer, of the 3-clause filter with flag \(c\), or of the clause-check driver with its embedded lookup, on that component's stacks embedded in the host, with the component's labels renamed to host labels; the tokenizer's accept exit goes to the filter's start label, the filter's pass exit to the driver's start label, the driver's yes exit to the cleanup label with answer true, and the tokenizer's reject exit, the filter's fail exit and the driver's no exit to the cleanup label with answer false. At the cleanup label with answer \(b\) the host pops every stack other than the output stack once, repeats this while anything was popped, and then goes to the output label with answer \(b\), where it pushes \(b\) onto the output stack, sets its internal state to false and halts.
