    DefinitionEmbedding of the update generator's stacks into the host#✓fully proved

    Cslib.Complexity.CookLevin.Assembly.embU

    For \(g \in \mathbb{N}\), this is the stack embedding of the family generator's stacks (a Boolean output stack and one unit counter stack per counter) into the host stacks with \(g\) input codes, used for the update generator: the output stack goes to the host's shared output stack, and the counter stack \(x\) goes to the stack \(x\) of the host's private update block. Distinct stacks go to distinct host stacks, and each stack's alphabet is identified with its host stack's alphabet by the identity.

    def embU : SEmb Family.GΓ (HΓ g) where
  e := eU
  inj := by intro a b h; cases a <;> cases b <;> simp_all [eU]
  ι := fun k => match k with
    | .out => Equiv.refl _
    | .c _ => Equiv.refl _
    structure SEmb {K K' : Type} (Γ : K → Type) (Γ' : K' → Type) where
  /-- The stack renaming. -/
  e : K → K'
  /-- Distinct sub-machine stacks go to distinct host stacks. -/
  inj : Injective e
  /-- The alphabet of each sub-machine stack, identified with its host stack's. -/
  ι : ∀ k, Γ k ≃ Γ' (e k)
