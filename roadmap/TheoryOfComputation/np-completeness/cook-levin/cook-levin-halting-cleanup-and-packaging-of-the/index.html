    TheoremDraining a stack with the transfer loop#✓fully proved

    Cslib.Complexity.CookLevin.Package.xfer_drain

    Let \(M\) be a TM2 machine whose state type carries a flag bit, and suppose that the statement of \(M\) at label \(\ell\) is the transfer loop that pops stack \(k\) with no target stacks, returning to \(\ell\) while the pop succeeds and going to label \(\ell'\) once stack \(k\) is empty. Then for every state \(v\) and every stack assignment \(S\), writing \(S_k\) for the contents of stack \(k\) under \(S\) and \(|S_k|\) for its length, in exactly \(|S_k| + 1\) steps the machine goes from label \(\ell\) with state \(v\) and stacks \(S\) to label \(\ell'\) with the state that stores the flag bit false and the stacks of \(S\) with stack \(k\) replaced by the empty list, all other stacks unchanged.

    theorem xfer_drain {self next : Λ} {k : K} (hp : M self = xfer k [] self next) :
    ∀ (l : List (Γ k)) (v : σ) (S : ∀ k, List (Γ k)), S k = l →
      Run M (l.length + 1) ⟨some self, v, S⟩ ⟨some next, Flag.tag false, update S k []⟩
    def xfer (k : K) (ps : List (Σ k, Γ k)) (self next : Λ) : TM2.Stmt Γ Λ σ :=
  .pop k (fun _ o => Flag.tag o.isSome)
    (.branch Flag.untag (pushAll ps (.goto fun _ => self)) (.goto fun _ => next))

    DefinitionThe drain program#✓fully proved

    Cslib.Complexity.CookLevin.Package.drainS

    Given a list \(k_0, \dots, k_{m-1}\) of stacks, a type \(\Lambda\) of labels and labels \(\lambda : \mathbb{N} \to \Lambda\), stage \(i\) of the drain program is as follows. For \(i < m\) it pops stack \(k_i\), recording in the state whether a symbol was popped, and jumps to \(\lambda(i)\) if one was and to \(\lambda(i + 1)\) if the stack was empty; repeated, this empties \(k_i\). For \(i \ge m\) it sets the state to store the flag bit false and halts.

    def drainS (ks : List K) (lab : ℕ → Λ) (i : ℕ) : TM2.Stmt Γ Λ σ :=
  match ks[i]? with
  | some k => xfer k [] (lab i) (lab (i + 1))
  | none => .load (fun _ => Flag.tag false) .halt

    Let \(g, r \in \mathbb{N}\), let \(P\) be a program with labels \(\Lambda\) and Boolean state over the stacks of the full machine with alphabets \(F\Gamma_{g,r}\), and let \(\mathit{fin} \in \Lambda\).     TheoremRunning a program, then the drain#✓fully proved

    Cslib.Complexity.CookLevin.Package.g_run_gen

    Let \(g, r \in \mathbb{N}\), let \(P\) be a program with labels \(\Lambda\) and Boolean state over the stacks of the full machine with alphabets \(F\Gamma_{g,r}\), and let \(\mathit{fin}\) be a label with \(P(\mathit{fin}) = \mathrm{halt}\). Suppose \(P\) goes in at most \(B\) steps from the configuration with label \(\ell\), state \(v\) and stacks \(S\) to the configuration with label \(\mathit{fin}\), state \(v'\) and stacks \(T\). Then the composed program of \(P\) and \(\mathit{fin}\) goes in at most \(B + 1 + d(T)\) steps from label \(\ell\) (as a label of the composed program), state \(v\) and stacks \(S\) to the halted configuration with state false in which every stack other than the output stack is empty and the output stack is that of \(T\). Here \(d(T)\), the step count of the drain, is \(1\) plus the sum of \(|T_q| + 1\) over the stacks \(q\) other than the output stack.

    theorem g_run_gen {P : Λ → TM2.Stmt (FΓ g r) Λ Bool} {fin : Λ} (hfin : P fin = .halt)
