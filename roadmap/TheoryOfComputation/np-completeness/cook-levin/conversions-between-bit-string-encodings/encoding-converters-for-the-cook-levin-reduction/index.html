    DefinitionProgram of the converter to the canonical pair encoding#✓fully proved

    Cslib.Complexity.DenseSAT.ToCanonical.prog

    The machine has an input stack of symbols, each a left-tagged bit, a right-tagged bit or the separator, and three stacks of bits: the output and two stashes. Its program first pops input symbols and pushes the bit of each left-tagged one onto the first stash, until the input is empty or the symbol popped is not a left-tagged bit. It then pops input symbols and pushes the bit of each right-tagged one onto the second stash, until the input is empty or the symbol popped is not a right-tagged bit. Next it pops each bit \(b\) of the second stash and pushes false, \(b\), true onto the output, and then pushes a single false. Finally it pops each bit \(b\) of the first stash and pushes false, true, \(b\), true, true, true onto the output, and halts when the first stash is empty.

    Each output block is pushed in reverse, so that it reads true, \(b\), false (respectively true, true, true, \(b\), true, false) from the top.

      .pop .inp (fun _ o => o) <| .branch isFst
        (.push .fst bit <| .goto fun _ => .readFst)
        (.goto fun _ => .readSnd)
  | .readSnd =>
      .pop .inp (fun _ o => o) <| .branch isSnd
        (.push .snd bit <| .goto fun _ => .readSnd)
        (.goto fun _ => .emitSnd)
  | .emitSnd =>
      .pop .snd (fun _ o => o.map Sum.inl) <| .branch isFst
        (.push .out (fun _ => false) <| .push .out bit <| .push .out (fun _ => true) <|

          .push .out (fun _ => true) <| .push .out (fun _ => true) <|
          .push .out (fun _ => true) <| .goto fun _ => .emitFst)

    TheoremRun of the pair-to-canonical converter#✓fully proved

    Cslib.Complexity.DenseSAT.ToCanonical.convert_run

    Let \(x\) and \(w\) be bit lists, write \(x \# w\) for the verifier input of the pair \((x, w)\), and read \(1\) for true and \(0\) for false. Let \(\mathrm{encFst}(x)\) replace each bit \(b\) of \(x\) by \(1, 1, 1, b, 1, 0\) and \(\mathrm{encSnd}(w)\) replace each bit \(b\) of \(w\) by \(1, b, 0\). The program of the pair-to-canonical converter goes in exactly \(2|x| + 2|w| + 5\) steps from the configuration at label \(\mathrm{readFst}\) with empty state, \(x \# w\) on the input stack and the output stack and both stashes empty, to the halted configuration with empty state, empty input stack and stashes, and output stack reading \(\mathrm{encFst}(x)\), then \(0\), then \(\mathrm{encSnd}(w)\) from the top.

    DefinitionCanonical bit-list decoder#✓fully proved

    Cslib.Complexity.DenseSAT.ToCanonical.computable

    This is a multi-stack Turing machine over the alphabet \(\mathrm{Bool}\), with time bound \(n + 2\), such that for every bit list \(x\), started on the canonical bitstring encoding of \(x\), it halts within \(n + 2\) steps, where \(n\) is the length of that encoding, with \(x\) on its output stack and all other stacks empty. So the identity on bit lists is computable in polynomial time from the canonical encoding to the raw bits.

    DefinitionProgram of the bit-list decoder#✓fully proved

    Cslib.Complexity.DenseSAT.DecodeBits.prog

    The program of the machine that decodes the canonical encoding of a bit list acts on the three stacks of the bit-list converters, all over bits, with an optional bit as internal state. At label \(\mathrm{read}\) it pops a symbol from the input stack into the state (which becomes empty if the input is empty). If that symbol is true, it pops a second symbol \(b\) into the state, pops and discards a third, pushes \(b\) onto the stash (false if the input ran out before \(b\)) and returns to \(\mathrm{read}\); otherwise it goes to \(\mathrm{emit}\). At label \(\mathrm{emit}\) it pops a bit from the stash, pushes it onto the output and returns to \(\mathrm{emit}\), and it halts when the stash is empty.

    def prog : BLab → TM2.Stmt (fun _ : BStk => Bool) BLab (Option Bool)
  | .read =>
      .pop .inp (fun _ o => o) <| .branch (fun s => s == some true)
        (.pop .inp (fun _ o => o) <| .pop .inp (fun s _ => s) <|
          .push .stash (fun s => s.getD false) <| .goto fun _ => .read)
        (.goto fun _ => .emit)
  | .emit =>
      .pop .stash (fun _ o => o) <| .branch (fun s => s.isSome)
        (.push .out (fun s => s.getD false) <| .goto fun _ => .emit)
        .halt
    inductive BLab | read | emit
  deriving DecidableEq
