    Cslib.Complexity.DenseSAT.Converter.bitEncode_pair_eq

    For bit lists \(x\) and \(w\), the canonical bitstring encoding of the pair \((x, w)\) is the concatenation of three parts: every bit \(b\) of \(x\), in order, written as the six bits true, true, true, \(b\), true, false; then a single false; then every bit \(b\) of \(w\), in order, written as the three bits true, \(b\), false.

    DefinitionProgram of the pair-encoding converter#✓fully proved

    Cslib.Complexity.DenseSAT.Converter.prog

    The program over the converter's four stacks, five labels and states (a bit or nothing). Each pop either stores the popped bit in the state (nothing if the stack is empty) or leaves the state unchanged, and each push of the stored bit uses false when the state holds nothing.

    At read first: pop the input, storing; if the state is true, pop the input twice without storing, once storing and twice without storing, push the stored bit onto the first stash and go to read first; otherwise go to read second. At read second: pop the input, storing; if the state is true, pop the input once storing and once without storing, push the stored bit onto the second stash and go to read second; otherwise go to emit second. At emit second: pop the second stash, storing; if a bit was popped, push it onto the output as a right-tagged bit and go to emit second; otherwise go to separator. At separator: push the separator onto the output and go to emit first. At emit first: pop the first stash, storing; if a bit was popped, push it onto the output as a left-tagged bit and go to emit first; otherwise halt.

  | .readFst =>
      .pop .inp (fun _ o => o) <| .branch (fun s => s == some true)
        (.pop .inp (fun s _ => s) <| .pop .inp (fun s _ => s) <| .pop .inp (fun _ o => o) <|
          .pop .inp (fun s _ => s) <| .pop .inp (fun s _ => s) <|
          .push .fst (fun s => s.getD false) <| .goto fun _ => .readFst)
        (.goto fun _ => .readSnd)
  | .readSnd =>
      .pop .inp (fun _ o => o) <| .branch (fun s => s == some true)
        (.pop .inp (fun _ o => o) <| .pop .inp (fun s _ => s) <|
          .push .snd (fun s => s.getD false) <| .goto fun _ => .readSnd)
        (.goto fun _ => .emitSnd)
  | .emitSnd =>
      .pop .snd (fun _ o => o) <| .branch (fun s => s.isSome)
        (.push .out (fun s => .inr (some (s.getD false))) <| .goto fun _ => .emitSnd)
        (.goto fun _ => .sep)
  | .sep => .push .out (fun _ => .inr none) <| .goto fun _ => .emitFst
  | .emitFst =>
      .pop .fst (fun _ o => o) <| .branch (fun s => s.isSome)
        (.push .out (fun s => .inl (s.getD false)) <| .goto fun _ => .emitFst)

    DefinitionThe pair-encoding converter machine#✓fully proved

    Cslib.Complexity.DenseSAT.Converter.tm

    The converter is the finite multi-stack Turing machine whose stacks are the input stack, the output stack and the two stash stacks, with bits as the alphabet of every stack except the output stack, which holds the verifier's symbols. Its labels are the five phases (read the first component, read the second, emit the second, emit the separator, emit the first), and it starts in the phase that reads the first component. Its internal state is an optional bit (the last bit popped), initially empty, and it runs the converter program. Input is read from the input stack, which holds bits, and output is written to the output stack.

    TheoremFull run of the pair-encoding converter#✓fully proved

    Cslib.Complexity.DenseSAT.Converter.convert_run

    For bit lists \(x\) and \(w\), the converter program goes in exactly \(2|x| + 2|w| + 5\) steps from the configuration at the label read first, with no bit in the state, the input stack holding every bit \(b\) of \(x\) in order as the six bits true, true, true, \(b\), true, false, then a single false, then every bit \(b\) of \(w\) in order as the three bits true, \(b\), false, and the other three stacks empty, to the halted configuration with no bit in the state, the verifier's pair encoding of \((x, w)\) on the output stack and the other three stacks empty.

    theorem convert_run (x w : List Bool) :
    Run (2 * x.length + 2 * w.length + 5)
      ⟨some .readFst, none, stk (encFst x ++ false :: encSnd w) [] [] []⟩
      ⟨none, none, stk [] (Verifier.pairEncode (x, w)) [] []⟩
