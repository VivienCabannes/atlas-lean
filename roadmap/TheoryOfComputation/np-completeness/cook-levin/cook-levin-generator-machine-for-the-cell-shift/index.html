    Fix a layout \(L\) and tables \(\mathrm{sa}\), \(\mathrm{pl}\), \(\mathrm{cn}\). For a height \(H\), write \(C[t,k,j,x]\) for the cell variable of stack \(k\), depth \(j\) and symbol code \(x\) at time \(t\), and \(X[t,a]\) for the label/state variable \(a\) at time \(t\).     DefinitionThe shift block of a situation and a stack#✓fully proved

    Cslib.Complexity.CookLevin.Shift.shBlk

    Fix a layout with \(A\) label variables, \(K\) stacks and \(g\) symbol codes, the generator's parameters \(sa\), \(pl\), \(cn\), \(pu\), and \(T, H, t, i, k \in \mathbb{N}\). Write \(p = pl(i, k)\), \(c = cn(i, k)\), \(W = A + K H g\) for the row width and \(V = (T + 1) W\) for the number of variables. The block is the CNF formula consisting, in this order, of: for each \(u < H - \max(p, c)\) and each \(x < g\) (ordered by \(u\), then \(x\)), the dense clause over \(V\) variables with the in-range shift literals for \((t, i, k, u, x)\); for each \(r < c - p\), the dense clause over \(V\) variables with the overflow literals for \((t, i, k, r)\); and for each \(j < p\), the dense clause over \(V\) variables with the pushed-fill literals for \((t, i, k, j)\). Subtraction is truncated at \(0\).

    def shBlk (T H t i k : ℕ) : CNF :=
  ((List.range (H - max (pl i k) (cn i k))).flatMap fun u =>
      (List.range L.g).map fun x => denseClause (L.numVars T H) (shLits L sa pl cn H t i k u x)) ++
    ((List.range (cn i k - pl i k)).map fun r =>
      denseClause (L.numVars T H) (ovLits L sa pl cn H t i k r)) ++
    (List.range (pl i k)).map fun j => denseClause (L.numVars T H) (pfLits L sa pu H t i k j)

    TheoremCoverage of target depths#✓fully proved

    Cslib.Complexity.CookLevin.Shift.depth_cover

    Let \(p, c, H\) be natural numbers with \(p \le H\) and \(c \le H\), and let \(m = \max(p, c)\). Every natural number \(j < H\) satisfies \(j < p\), or \(j = u + p\) for some natural number \(u < H - m\), or \(j = H - c + p + r\) for some natural number \(r < c - p\), where \(c - p\) is truncated subtraction (zero when \(c \le p\)).

    In the cell-shift family these are the pushed-fill, in-range and overflow target depths of a stack in the row after a time step.

    theorem depth_cover {p c H : ℕ} (hp : p ≤ H) (hc : c ≤ H) (j : ℕ) (hj : j < H) :
    j < p ∨ (∃ u < H - max p c, j = u + p) ∨ (∃ r < c - p, j = H - c + p + r)

    TheoremBounds on in-range and overflow target depths#✓fully proved

    Cslib.Complexity.CookLevin.Shift.depth_disjoint

    Let \(p, c, H\) be natural numbers with \(p \le H\) and \(c \le H\), and let \(m = \max(p, c)\). For every natural number \(u < H - m\) we have \(p \le u + p\), \(u + p < H - c + p\) and \(u + p < H\). For every natural number \(r < c - p\), where \(c - p\) is truncated subtraction, we have \(H - m + p = H - c + p\) and \(H - c + p + r < H\).

    theorem depth_disjoint {p c H : ℕ} (hp : p ≤ H) (hc : c ≤ H) :
    (∀ u < H - max p c, p ≤ u + p ∧ u + p < H - c + p ∧ u + p < H) ∧
    (∀ r < c - p, H - max p c + p = H - c + p ∧ H - c + p + r < H)
