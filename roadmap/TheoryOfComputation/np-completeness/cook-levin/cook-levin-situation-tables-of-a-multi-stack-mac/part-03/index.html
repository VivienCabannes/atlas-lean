    Cslib.Complexity.CookLevin.Situation.applyEff

    Let \(S_0\) assign a list \(S_0(k)\) to each stack \(k\), and let \(r = (\ell, v, P, c)\) consist of a label \(\ell\) (possibly the halted label), a state \(v\), a list \(P(k)\) for each stack \(k\) and a natural number \(c(k)\) for each stack \(k\). This is the configuration with label \(\ell\), state \(v\), and stack \(k\) equal to \(P(k)\) followed by \(S_0(k)\) with its first \(c(k)\) symbols (from the top) removed.

    Applied to an effect, \(P(k)\) is the pushed prefix still on top of stack \(k\) and \(c(k)\) is the net number of original symbols consumed.

    def applyEff (S0 : ∀ k, List (Γ k)) (r : Option Λ × σ × (∀ k, List (Γ k)) × (K → ℕ)) :
    TM2.Cfg Γ Λ σ :=
  ⟨r.1, r.2.1, fun k => r.2.2.1 k ++ (S0 k).drop (r.2.2.2 k)⟩

    TheoremReading the top through the windows#✓fully proved

    Cslib.Complexity.CookLevin.Situation.readTop_eq

    Let \(d \in \mathbb{N}\), let \(S_0\) and \(P\) assign a list to each stack, let \(c\) assign a natural number to each stack, and let \(k\) be a stack with \(c(k) < d\). Reading the top of stack \(k\) from the depth-\(d\) windows of the lists \(S_0\), with pushed symbols \(P\) and consumption counts \(c\), gives the first symbol of \(P(k)\) followed by \(S_0(k)\) with its first \(c(k)\) symbols removed, or ⊥ if that list is empty.

    theorem readTop_eq (d : ℕ) (S0 P : ∀ k, List (Γ k)) (c : K → ℕ) (k : K) (hc : c k < d) :
    readTop (fun k => window d (S0 k)) P c k = (P k ++ (S0 k).drop (c k)).head?
    def readTop (W : ∀ k, List (Option (Γ k))) (P : ∀ k, List (Γ k)) (c : K → ℕ) (k : K) :
    Option (Γ k) :=
  match P k with
  | x :: _ => some x
  | [] => (W k).getD (c k) none

    TheoremThe symbolic effect of a statement agrees with the real step#✓fully proved

    Cslib.Complexity.CookLevin.Situation.eff_agree

    Let \(q\) be a statement tree of a multi-stack machine, \(d \in \mathbb{N}\), and \(S_0\) an assignment of a list \(S_0(k)\) to each stack \(k\). Let \(v\) be a state, \(P\) an assignment of a list \(P(k)\) to each stack, and \(c\) an assignment of a natural number \(c(k)\) to each stack with \(c(k) + \operatorname{ops}(q) \le d\) for every \(k\). Then running \(q\) from state \(v\) on the stacks whose stack \(k\) is \(P(k)\) followed by \(S_0(k)\) with its first \(c(k)\) symbols removed gives the configuration obtained by applying to \(S_0\) the effect of \(q\) computed from \(v\), \(P\), \(c\) and the depth-\(d\) windows of the \(S_0(k)\).

    Here \(\operatorname{ops}(q)\) is the largest number of push, peek and pop nodes on a path of \(q\), so the hypothesis keeps every read inside the windows.

    theorem eff_agree (d : ℕ) (S0 : ∀ k, List (Γ k)) (q : TM2.Stmt Γ Λ σ) :
    ∀ (v : σ) (P : ∀ k, List (Γ k)) (c : K → ℕ), (∀ k, c k + ops q ≤ d) →
      TM2.stepAux q v (fun k => P k ++ (S0 k).drop (c k)) =
        applyEff S0 (eff (fun k => window d (S0 k)) q v P c)
    def ops : TM2.Stmt Γ Λ σ → ℕ
  | .push _ _ q => ops q + 1
  | .peek _ _ q => ops q + 1
  | .pop _ _ q => ops q + 1
  | .load _ q => ops q
  | .branch _ q₁ q₂ => max (ops q₁) (ops q₂)
  | .goto _ => 0
  | .halt => 0

    def eff (W : ∀ k, List (Option (Γ k))) :
    TM2.Stmt Γ Λ σ → σ → (∀ k, List (Γ k)) → (K → ℕ) →
      Option Λ × σ × (∀ k, List (Γ k)) × (K → ℕ)
  | .push k f q, v, P, c => eff W q v (update P k (f v :: P k)) c
  | .peek k f q, v, P, c => eff W q (f v (readTop W P c k)) P c
  | .pop k f q, v, P, c =>
      eff W q (f v (readTop W P c k)) (update P k (P k).tail)
        (if (P k).isEmpty then update c k (c k + 1) else c)
  | .load a q, v, P, c => eff W q (a v) P c
  | .branch p q₁ q₂, v, P, c => cond (p v) (eff W q₁ v P c) (eff W q₂ v P c)
  | .goto f, v, P, c => (some (f v), v, P, c)
  | .halt, v, P, c => (none, v, P, c)

    Cslib.Complexity.CookLevin.Situation.step_agree

    Let \(M\) be a finite TM2 machine and \(c\) a configuration with label \(l\), state \(v\) and stacks \(S\), and let \((l', v', P, n)\) be the situation step of \(M\) at label \(l\) and state \(v\) on the windows of \(c\).     DefinitionSituation index of a configuration#✓fully proved

    Cslib.Complexity.CookLevin.Situation.Enc.sitIdx

    Fix an encoding \(E\) of a finite TM2 machine \(M\), with \(K\) stacks, symbol-code bound \(g\) and window depth \(d\). The situation index of a configuration \(c\) is the number

    \[\sum_{k < K} \sum_{j < d} \mathrm{cell}_c(k, j)\, g^{kd + j} + \mathrm{code}(c)\, g^{Kd},\]

    where \(\mathrm{code}(c)\) is the combined (label, state) code of \(c\) and \(\mathrm{cell}_c(k, j)\) is the cell code of \(c\) on stack number \(k\) at depth \(j\) (\(0\) for the empty cell).

    def sitIdx (c : M.Cfg) : ℕ :=
  mix E.g (E.code c) (E.KK * depth M) fun n => E.cell c (n / depth M) (n % depth M)

  | 0, _ => c
  | m + 1, D => D 0 + b * mix b c m (fun n => D (n + 1))

    DefinitionThe table-driven row update#✓fully proved

    Cslib.Complexity.CookLevin.Situation.Enc.tabRow

    Fix an encoding \(E\) of a finite TM2 machine, a row height \(H\), a situation \(i\) and an old row \(\mathrm{old}\) giving a code for each stack number \(k\) and depth \(j\). For a stack number \(k\), write \(p\) for the number of symbols situation \(i\) leaves pushed on stack \(k\) and \(n\) for the number of original symbols it consumes from stack \(k\). The updated row at \((k, j)\) is the code of the symbol situation \(i\) leaves at depth \(j\) of stack \(k\) if \(j < p\); otherwise it is \(\mathrm{old}(k, j - p + n)\) if \(j < (H \mathbin{\dot{-}} \max(p, n)) + p\), where \(\dot{-}\) is truncated subtraction; otherwise it is \(0\), the empty cell.

    These are the three cases the shift clauses force: pushed fill, in-range shift and overflow.

    def tabRow (H i : ℕ) (old : ℕ → ℕ → ℕ) (k j : ℕ) : ℕ :=
  if j < E.pl i k then E.pu i k j
  else if j < H - max (E.pl i k) (E.cn i k) + E.pl i k then old k (j - E.pl i k + E.cn i k)
  else 0
