    Cslib.Complexity.CookLevin.Situation.fam_force

    Let \(L\) be a layout with \(K\) stacks and window depth \(d\), let \(\mathrm{la}, \mathrm{na} : \mathbb{N} \to \mathbb{N}\) and \(\mathrm{wa} : \mathbb{N} \to \mathbb{N} \to \mathbb{N} \to \mathbb{N}\) be tables, and let \(a\) be an assignment satisfying the transition clause family of \(L\), \(\mathrm{la}\), \(\mathrm{na}\) and \(\mathrm{wa}\) for bounds \(T\), \(H\) and \(N\). Write \(X[t, b]\) and \(C[t, k, j, x]\) for the label/state and cell variables at height \(H\). Suppose \(t < T\), \(i < N\), \(X[t, \mathrm{la}(i)]\) is true under \(a\), and for every \(n < Kd\), writing \(q = \lfloor n / d \rfloor\) and \(r = n \bmod d\), the variable \(C[t, q, r, \mathrm{wa}(i, q, r)]\) is true under \(a\). Then \(X[t + 1, \mathrm{na}(i)]\) is true under \(a\).

    The window literals are indexed by \(n\) exactly as in the clause, and no one-hot hypothesis on \(a\) is needed.

    theorem fam_force {L : Family.Layout} {la na : ℕ → ℕ} {wa : ℕ → ℕ → ℕ → ℕ} {N T H : ℕ}
    {a : List Bool} (ha : cnfSat (Family.family L la na wa T H N) a) {t i : ℕ} (ht : t < T)
    (hi : i < N) (hX : Tr a (L.xIdx H t (la i)))
    (hW : ∀ n < L.KK * L.d, Tr a (L.cIdx H t (n / L.d) (n % L.d) (wa i (n / L.d) (n % L.d)))) :
    Tr a (L.xIdx H (t + 1) (na i))

    Cslib.Complexity.CookLevin.Situation.region_cover

    Let \(p, q, H, j\) be natural numbers with \(j < H\), and let \(m = H - \max(p, q) + p\), where the subtraction is truncated at \(0\). Then \(j\) lies in exactly one of the ranges \(j < p\) (pushed fill), \(p \le j < m\) (in-range shift) and \(m \le j < H\) (overflow).

    These are the depth hypotheses of the pushed-fill, in-range shift and overflow lemmas; nothing is assumed about \(p\), \(q\) and \(H\).

    theorem region_cover (p q H j : ℕ) (hj : j < H) :
    (j < p ∨ (p ≤ j ∧ j < H - max p q + p) ∨ (H - max p q + p ≤ j ∧ j < H)) ∧
    ¬ (j < p ∧ p ≤ j) ∧ ¬ (j < p ∧ H - max p q + p ≤ j) ∧
    ¬ (j < H - max p q + p ∧ H - max p q + p ≤ j)
