    Cslib.Complexity.CookLevin.Situation.Faithful

    A list \(\ell\) of literals \((p, b)\), each a variable index \(p \in \mathbb{N}\) with a sign \(b\), is faithful for \(V \in \mathbb{N}\) when every literal \((p, b)\) of \(\ell\) has \(p < V\) and the first literal of \(\ell\) with index \(p\) is \((p, b)\).

    Equivalently, every literal of \(\ell\) survives into the dense clause over \(V\) variables built from \(\ell\): it is in range, and not shadowed by an earlier literal at the same index with the other sign.

    def Faithful (V : ℕ) (ls : List (ℕ × Bool)) : Prop :=
  ∀ p b, (p, b) ∈ ls → p < V ∧ ls.lookup p = some b

    Cslib.Complexity.CookLevin.Situation.Accepts

    A configuration \(c\) of a finite stack machine \(M\) is accepting for a symbol \(\alpha\) of the output stack of \(M\) when \(c\) is halted (it has no label), its state is the initial state of \(M\), and the output stack of \(c\) is nonempty with top symbol \(\alpha\).
