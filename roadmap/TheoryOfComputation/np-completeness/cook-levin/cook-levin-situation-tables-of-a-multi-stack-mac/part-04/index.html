    Cslib.Complexity.CookLevin.Situation.getElem?_decS

    Let \(f : \mathbb{N} \to \mathrm{Option}\,\alpha\) and write \(\bot\) for the absent value. For \(j, m \in \mathbb{N}\) let \(\mathrm{decS}(f, j, m)\) be the list of the values \(f(j), f(j + 1), \dots\), read for at most \(m\) positions and stopped at the first \(\bot\). Suppose \(f\) is in prefix form on the window from \(j\) to \(j + m\): whenever \(j \le a \le b < j + m\) and \(f(a) = \bot\), also \(f(b) = \bot\).     theorem getElem?_decS (f : ℕ → Option α) : ∀ (j m : ℕ),
    (∀ a b, j ≤ a → a ≤ b → b < j + m → f a = none → f b = none) →
    ∀ i < m, (decS f j m)[i]? = f (j + i)
