    Cslib.Complexity.CookLevin.Situation.runI_of_iterate

    Let \(M\) be a finite stack machine, let \(n \in \mathbb{N}\), and let \(c, c'\) be configurations of \(M\). If iterating the step function of \(M\) \(n\) times as a partial function, starting from \(c\), yields \(c'\), then the idle-extended run of \(M\) from \(c\) is at \(c'\) after \(n\) steps.

    theorem runI_of_iterate (M : FinTM2) : ∀ (n : ℕ) (c c' : M.Cfg),
    (flip bind (TM2.step M.m))^[n] (some c) = some c' → runI M c n = c'
    def runI (M : FinTM2) (c : M.Cfg) : ℕ → M.Cfg
  | 0 => c
  | t + 1 => stepI M (runI M c t)

    Let \(M\) be a finite stack machine with encoding data \(E\), let \(s\) be an input of \(M\) and \(H \in \mathbb{N}\), and for \(t \in \mathbb{N}\) let \(c_t\) be the configuration after \(t\) steps of the idle-extended run of \(M\) from its start configuration on \(s\).
