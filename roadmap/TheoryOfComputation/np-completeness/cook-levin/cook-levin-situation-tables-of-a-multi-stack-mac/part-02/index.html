    DefinitionMixed-radix number#✓fully proved

    Cslib.Complexity.CookLevin.Situation.Enc.mix

    For a base \(b\), a top digit \(c\), a length \(m\) and digits \(D : \mathbb{N} \to \mathbb{N}\), \(\mathrm{mix}(b, c, 0, D) = c\) and \(\mathrm{mix}(b, c, m + 1, D) = D(0) + b \cdot \mathrm{mix}(b, c, m, n \mapsto D(n + 1))\); that is, \(D(0) + b\,(D(1) + b\,(\cdots + b\,(D(m - 1) + b\,c)))\), least significant digit first.

    def mix (b c : ℕ) : ℕ → (ℕ → ℕ) → ℕ
  | 0, _ => c
  | m + 1, D => D 0 + b * mix b c m (fun n => D (n + 1))

    TheoremMixed-radix index of a situation#✓fully proved

    Cslib.Complexity.CookLevin.Situation.Enc.mix_sit

    Fix an encoding record \(E\) of a finite multi-stack machine \(M\).     DefinitionFinite set of pushable symbols#✓fully proved

    Cslib.Complexity.CookLevin.Situation.pushFS

    For a stack \(k\) and a statement tree \(q\) of a multi-stack machine with a finite set of states, the finite set of symbols of stack \(k\) that some push instruction of \(q\) on stack \(k\) pushes for some state: the union, over all push instructions on \(k\) in all branches of \(q\), of the images of their push functions over all states.

    noncomputable def pushFS (k : K) : TM2.Stmt Γ Λ σ → Finset (Γ k)
  | .push k' f q =>
      (if h : k' = k then Finset.univ.image fun v => cast (congrArg Γ h) (f v) else ∅) ∪
        pushFS k q
  | .peek _ _ q => pushFS k q
  | .pop _ _ q => pushFS k q
  | .load _ q => pushFS k q
  | .branch _ q₁ q₂ => pushFS k q₁ ∪ pushFS k q₂
  | .goto _ => ∅
  | .halt => ∅
