    DefinitionTop of a stack as read from the windows#✓fully proved

    Cslib.Complexity.CookLevin.Situation.readTop

    Let \(W\) assign to each stack \(k\) a window, a list of entries that are symbols of \(k\) or the empty cell \(\bot\); let \(P\) assign to each stack \(k\) a list of symbols of \(k\); and let \(c\) assign a natural number to each stack. The top of stack \(k\) is the first element of \(P(k)\) when \(P(k)\) is nonempty. Otherwise it is the entry of \(W(k)\) at position \(c(k)\), counting from \(0\), or \(\bot\) when \(W(k)\) has fewer than \(c(k) + 1\) entries.

    Here \(P(k)\) lists the symbols pushed in this step and still on top, and \(c(k)\) counts the original symbols already consumed.

    def readTop (W : ∀ k, List (Option (Γ k))) (P : ∀ k, List (Γ k)) (c : K → ℕ) (k : K) :
    Option (Γ k) :=
  match P k with
  | x :: _ => some x
  | [] => (W k).getD (c k) none

    DefinitionSymbolic effect of a statement tree#✓fully proved

    Cslib.Complexity.CookLevin.Situation.eff

    Let \(W\) assign to each stack \(k\) a window \(W_k\), a list of cells each holding a symbol or \(\bot\). The window top of stack \(k\) for pushed lists \(P\) and consumption counts \(c\) is the head of \(P_k\) if \(P_k\) is nonempty, and otherwise the entry of \(W_k\) at position \(c_k\) (counting from \(0\)), or \(\bot\) if there is none. The effect of a statement tree \(q\) from a state \(v\), pushed lists \(P\) and consumption counts \(c\) is a label (or none), a state, pushed lists and consumption counts, defined by recursion on \(q\): a push onto stack \(k\) prepends the symbol computed from \(v\) to \(P_k\) and continues; a peek on stack \(k\) replaces \(v\) by the state computed from \(v\) and the window top of \(k\) and continues; a pop on stack \(k\) does the same, also removes the head of \(P_k\) (if any), and increases \(c_k\) by one if \(P_k\) was empty; a load replaces \(v\) by the state computed from \(v\) and continues; a branch continues with the subtree selected by \(v\); a goto returns the label computed from \(v\), and a halt returns no label, each together with the current \(v\), \(P\) and \(c\).

    Thus \(P_k\) holds the symbols pushed in this step and still on top, and \(c_k\) counts the original symbols consumed, a push followed by a pop cancelling.

    def eff (W : ∀ k, List (Option (Γ k))) :
    TM2.Stmt Γ Λ σ → σ → (∀ k, List (Γ k)) → (K → ℕ) →
      Option Λ × σ × (∀ k, List (Γ k)) × (K → ℕ)
  | .push k f q, v, P, c => eff W q v (update P k (f v :: P k)) c
  | .peek k f q, v, P, c => eff W q (f v (readTop W P c k)) P c
  | .pop k f q, v, P, c =>
      eff W q (f v (readTop W P c k)) (update P k (P k).tail)
        (if (P k).isEmpty then update c k (c k + 1) else c)
  | .load a q, v, P, c => eff W q (a v) P c
  | .branch p q₁ q₂, v, P, c => cond (p v) (eff W q₁ v P c) (eff W q₂ v P c)
  | .goto f, v, P, c => (some (f v), v, P, c)
  | .halt, v, P, c => (none, v, P, c)
    def readTop (W : ∀ k, List (Option (Γ k))) (P : ∀ k, List (Γ k)) (c : K → ℕ) (k : K) :

    DefinitionStack operations on a path of a statement tree#✓fully proved

    Cslib.Complexity.CookLevin.Situation.ops

    For a statement tree \(q\) of a multi-stack Turing machine, \(\operatorname{ops}(q)\) is the largest number of push, peek and pop nodes on a path from the root of \(q\) to a leaf. Load and branch nodes do not count, and goto and halt leaves contribute \(0\).

    def ops : TM2.Stmt Γ Λ σ → ℕ
  | .push _ _ q => ops q + 1
  | .peek _ _ q => ops q + 1
  | .pop _ _ q => ops q + 1
  | .load _ q => ops q
  | .branch _ q₁ q₂ => max (ops q₁) (ops q₂)
  | .goto _ => 0
  | .halt => 0

    DefinitionSymbols a statement tree can push#✓fully proved

    Cslib.Complexity.CookLevin.Situation.PushSym

    Let \(q\) be a statement tree of a multi-stack Turing machine with state type \(\sigma\), let \(k\) be a stack and \(x\) a symbol of the alphabet of \(k\). Then \(x\) can be pushed onto \(k\) by \(q\) when \(q\) contains a push node onto stack \(k\) with symbol function \(f\) and some state \(v \in \sigma\) satisfies \(x = f(v)\). Every push node of \(q\) counts, whichever branches are taken.

    def PushSym (k : K) : TM2.Stmt Γ Λ σ → Γ k → Prop
  | .push k' f q, x => (∃ (h : k' = k) (v : σ), x = cast (congrArg Γ h) (f v)) ∨ PushSym k q x
  | .peek _ _ q, x => PushSym k q x
  | .pop _ _ q, x => PushSym k q x
  | .load _ q, x => PushSym k q x
  | .branch _ q₁ q₂, x => PushSym k q₁ x ∨ PushSym k q₂ x
  | .goto _, _ => False
  | .halt, _ => False

    StructureEncoding data for a finite TM2 machine#✓fully proved

    Cslib.Complexity.CookLevin.Situation.Enc

    An encoding of a finite TM2 machine \(M\) consists of a number \(K\), a map \(\kappa\) from the stacks of \(M\) to the naturals below \(K\) and a map \(\kappa'\) from naturals to stacks with \(\kappa'(\kappa(k)) = k\) for every stack \(k\) and \(\kappa(\kappa'(n)) = n\) for every \(n < K\); a number \(A_0\), a map \(\lambda\) from pairs (label or halted, state) to the naturals below \(A_0\) and a map \(\lambda'\) back with \(\lambda'(\lambda(x)) = x\) for every pair \(x\) and \(\lambda(\lambda'(a)) = a\) for every \(a < A_0\); and for each stack \(k\) a size \(s_k\), effective symbols \(d_k(i)\) for \(i < s_k\), and a symbol code map \(e_k\) on the alphabet of stack \(k\) with \(e_k(d_k(i)) = i + 1\). It is required that every symbol that a push node of the statement tree of some label can push onto stack \(k\), for some state, is an effective symbol of stack \(k\), and that every symbol of the input stack's alphabet is an effective symbol of the input stack.

    Symbol code \(0\) stands for \(\bot\), the empty cell.

    DefinitionThe situation step#✓fully proved

    Cslib.Complexity.CookLevin.Situation.sitStep

    Let \(M\) be a finite multi-stack Turing machine, let \(l\) be either a label of \(M\) or \(\mathrm{none}\) (the halted label), let \(v\) be a state of \(M\), and let \(W\) assign to each stack \(k\) a window, a list of entries that are symbols of \(k\) or the empty cell. If \(l = \mathrm{none}\), the step returns the label \(\mathrm{none}\), the state \(v\), no pushed symbols on any stack and no consumed symbols on any stack. If \(l\) is a label, the step is the effect, read from the windows \(W\), of the statement tree of \(l\) started in state \(v\) with nothing pushed and nothing consumed.

    def sitStep (M : FinTM2) (l : Option M.Λ) (v : M.σ) (W : ∀ k, List (Option (M.Γ k))) :
    Option M.Λ × M.σ × (∀ k, List (M.Γ k)) × (M.K → ℕ) :=
  match l with
  | none => (none, v, fun _ => [], fun _ => 0)
  | some l => eff W (M.m l) v (fun _ => []) (fun _ => 0)
    def eff (W : ∀ k, List (Option (Γ k))) :
    TM2.Stmt Γ Λ σ → σ → (∀ k, List (Γ k)) → (K → ℕ) →
      Option Λ × σ × (∀ k, List (Γ k)) × (K → ℕ)
  | .push k f q, v, P, c => eff W q v (update P k (f v :: P k)) c
  | .peek k f q, v, P, c => eff W q (f v (readTop W P c k)) P c
  | .pop k f q, v, P, c =>
      eff W q (f v (readTop W P c k)) (update P k (P k).tail)
        (if (P k).isEmpty then update c k (c k + 1) else c)
  | .load a q, v, P, c => eff W q (a v) P c
  | .branch p q₁ q₂, v, P, c => cond (p v) (eff W q₁ v P c) (eff W q₂ v P c)
  | .goto f, v, P, c => (some (f v), v, P, c)
  | .halt, v, P, c => (none, v, P, c)
