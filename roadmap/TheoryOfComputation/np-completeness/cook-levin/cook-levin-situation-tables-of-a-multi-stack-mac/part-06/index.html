    Cslib.Complexity.CookLevin.Situation.Enc.cells_step_run

    Let \(E\) be an encoding of a machine \(M\) with window depth \(d\), let \(s\) be a list of symbols of the input stack of \(M\), and for each \(n\) let \(c_n\) be the configuration after \(n\) steps of the idle-extended run of \(M\) from its initial configuration on \(s\). Let \(T, H, t\) be natural numbers with \(t < T\) and \(d \le H\). Suppose an assignment \(a\) satisfies the transition clause family of \(E\) with the situation-variable table \(\mathrm{sa}\) in place of the next-label table (the S-definition family) at \(T\), \(H\) and the number \(N\) of situations of \(E\), and satisfies the cell-shift clause family of \(E\) at \(N\), \(T\), \(H\). Suppose also that every stack of \(c_t\) has length at most \(H - d\), that the code literal of \(c_t\) holds in row \(t\) (the label/state variable of row \(t\) for the code of \(c_t\) is true under \(a\)), and that the cell literals of \(c_t\) hold in row \(t\) (for every stack number \(k\) below the number of stacks and every depth \(j < H\), the cell variable of row \(t\) for stack \(k\), depth \(j\) and the code of the symbol of \(c_t\) there, \(0\) if there is none, is true under \(a\)). Then the cell literals of \(c_{t+1}\) hold in row \(t + 1\).

    theorem cells_step_run {T H t : ℕ} {a : List Bool} (s : List (M.Γ M.k₀))
    (hs : cnfSat (Family.family E.layout E.la E.sa E.wa T H E.N) a)
    (ha : cnfSat (Shift.shFamily E.layout E.sa E.pl E.cn E.pu E.N T H) a) (ht : t < T)
    (hh : ∀ k, ((runI M (initList M s) t).stk k).length ≤ H - depth M) (hdH : depth M ≤ H)
    (hcode : E.CodeHolds a H t (runI M (initList M s) t))
    (hrow : E.CellsHold a H t (E.cell (runI M (initList M s) t))) :
    E.CellsHold a H (t + 1) (E.cell (runI M (initList M s) (t + 1)))

    DefinitionRow-0 obligation#✓fully proved

    Cslib.Complexity.CookLevin.Situation.Enc.Row0

    For an encoding \(E\) of a machine \(M\) with \(K\) stacks, an assignment \(a\), a height \(H\) and an input list \(s\), let \(c\) be the start configuration of \(M\) on \(s\). The row-0 obligation says that, in the layout of \(E\) at height \(H\), the literal of the (label, state) code of \(c\) in row \(0\) is true under \(a\) and, for every stack number \(k < K\) and depth \(j < H\), the literal of the cell code of \(c\) at stack \(k\) and depth \(j\) in row \(0\) is true under \(a\).

    This is a positive form: the literals of the other cell codes are not required to be false.

    def Row0 (a : List Bool) (H : ℕ) (s : List (M.Γ M.k₀)) : Prop :=
  E.CodeHolds a H 0 (initList M s) ∧ E.CellsHold a H 0 (E.cell (initList M s))

    Cslib.Complexity.CookLevin.Situation.Enc.InitObl

    Let \(E\) be an encoding of a machine \(M\) with window depth \(d\), let \(a\) be an assignment, let \(x\) and \(Y\) be lists of symbols of the input stack of \(M\), and let \(m, T\) be natural numbers, and put \(H = m + (T + 1)d + 1\).
