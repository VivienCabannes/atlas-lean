    DefinitionPower-loop program#✓fully proved

    Cslib.Complexity.CookLevin.Precompute.powS

    Given six counters \(b\), \(k\), \(p\), \(q\), \(a\), \(t\), a label for each power-loop stage and an exit label, the power loop is the following program on the stages. At the head stage it pops one unit from \(k\); if \(k\) was empty it goes to the exit label, otherwise to the first multiplication stage. The multiplication stages add \(p \cdot b\) to \(q\) (a multiplication site with index counter \(a\) and scratch counter \(t\)) and then go to the drain stage. The drain stage empties \(p\) and goes to the move stage. The move stage moves the contents of \(q\) onto \(p\) and returns to the head stage.

    When the six counters are distinct and \(q = a = t = 0\) at the start, each round multiplies \(p\) by \(b\), so the loop replaces \(p\) by \(p \cdot b^k\) and ends with \(k = 0\).

    def powS (b kc p q ad t : C) (mk : PW → Λ) (exit : Λ) : PW → TM2.Stmt (SΓ C) Λ Bool
  | .hd => decr (.c kc) exit (mk (.mul .head))
  | .mul s => mulS p ad b q t (fun s => mk (.mul s)) (mk .drn) s
  | .drn => xfer (.c p) [] (mk .drn) (mk .mv)
  | .mv => xfer (.c q) (tg [p]) (mk .mv) (mk .hd)
    inductive PW
  | hd
  | mul (s : MS)
  | drn
  | mv
  deriving DecidableEq, Fintype
