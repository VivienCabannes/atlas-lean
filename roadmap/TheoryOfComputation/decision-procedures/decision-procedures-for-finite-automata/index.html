    DFA.symmDiff

    For DFAs \(M\) and \(N\) over the same alphabet, with sets of states \(\sigma\) and \(\sigma'\), this is the product DFA with set of states \(\sigma \times \sigma'\) whose start state is the pair of the start states of \(M\) and \(N\), whose transition takes \((p, q)\) on a letter \(a\) to the pair of the state to which \(M\) moves from \(p\) on \(a\) and the state to which \(N\) moves from \(q\) on \(a\), and whose accepting states are the pairs \((p, q)\) such that \(p\) is an accepting state of \(M\) or \(q\) is an accepting state of \(N\), but not both.

    DefinitionReachable states of a DFA#✓fully proved

    DFA.reachable

    Let \(M\) be a DFA over a finite alphabet whose set of states \(\sigma\) is finite and has decidable equality. The reachable states of \(M\) form the finite set obtained from the empty set by applying one round of the DFA reachability search for \(M\) exactly \(|\sigma|\) times, where \(|\sigma|\) is the number of states of \(M\).

    Since the round is monotone, this set is its least fixed point, and a state lies in it exactly when \(M\) reaches it from its start state on some word.

    def reachable : Finset σ :=
  Finset.lfpFin M.reachStep

    Let \(s_0 \in \mathbb{N}\), let \(\mathrm{next}\) assign to each \(s \in \mathbb{N}\) a list \(\mathrm{next}(s)\) of natural numbers, and let \(B\) and \(R\) be lists of natural numbers.     cond (memB B t) (some t) none)
