    Cslib.Language.mapSymbol_mapSymbol

    For maps \(f : N_1 \to N_2\) and \(b : N_2 \to N_3\) and a grammar symbol \(s\) with terminals in \(T\) and nonterminals in \(N_1\), renaming the nonterminals of \(s\) by \(f\) and then by \(b\) gives the same symbol as renaming them by \(b \circ f\).

    @[simp]
theorem mapSymbol_mapSymbol {N₁ N₂ N₃ : Type*} (f : N₁ → N₂) (b : N₂ → N₃) (s : Symbol T N₁) :
    mapSymbol b (mapSymbol f s) = mapSymbol (b ∘ f) s
    def mapSymbol {N' : Type*} (f : N → N') : Symbol T N → Symbol T N'
  | .terminal a => .terminal a
  | .nonterminal A => .nonterminal (f A)

    TheoremGrammars with renamings in both directions generate the same language#✓fully proved

    Cslib.Language.language_eq_of_maps

    Let \(g\) and \(G\) be context-free grammars over the same terminals. Suppose there are maps \(f\) from the nonterminals of \(g\) to those of \(G\) and \(b\) from the nonterminals of \(G\) to those of \(g\) such that renaming the nonterminals of any production of \(g\) by \(f\) gives a production of \(G\), renaming the nonterminals of any production of \(G\) by \(b\) gives a production of \(g\), \(f\) sends the start nonterminal of \(g\) to that of \(G\), and \(b\) sends the start nonterminal of \(G\) to that of \(g\). Then \(g\) and \(G\) generate the same language. The renamings need not be inverse to each other.

    theorem language_eq_of_maps {g G : ContextFreeGrammar T} (f : g.NT → G.NT) (b : G.NT → g.NT)
    (hf : ∀ r ∈ g.rules, mapRule f r ∈ G.rules) (hb : ∀ r ∈ G.rules, mapRule b r ∈ g.rules)
    (hfi : f g.initial = G.initial) (hbi : b G.initial = g.initial) :
    G.language = g.language
    def mapRule {N' : Type*} (f : N → N') (r : ContextFreeRule T N) :
    ContextFreeRule T N' :=
  ⟨f r.input, r.output.map (mapSymbol f)⟩

    StructureEncoded context-free grammars#✓fully proved

    Cslib.Language.EncodedCFG

    An encoded context-free grammar over a terminal type \(T\) consists of a start nonterminal, which is a natural number, and a list of productions. Each production is a pair of a left-hand side, a natural number, and a right-hand side, a list of elements of the disjoint union \(\mathbb{N} \sqcup T\), in which a number \(i\) from the left summand stands for nonterminal \(i\) and an element \(a\) of \(T\) for terminal \(a\).

    Unlike a general context-free grammar, whose type of nonterminals is part of its data, an encoded grammar is a concrete object that computable functions can take and return.

    Cslib.Language.EncodedCFG.decodeRule
