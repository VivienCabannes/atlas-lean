    MetaMathlibExt.TM2Composition.lift₁

    Given finite multi-stack Turing machines \(M_1\) and \(M_2\), a statement of \(M_1\) is translated into a statement of their composite machine, whose state is a triple \((v_1, v_2, o)\), by recursion on the statement: an operation on a stack \(k\) of \(M_1\) acts on the copy of \(k\) among the composite stacks, every read or update of \(M_1\)'s state reads or updates the component \(v_1\) and leaves \(v_2\) and \(o\) unchanged, a branch tests \(v_1\), a jump to a label \(l\) of \(M_1\) becomes a jump to the copy of \(l\), and halting becomes a jump to the pop label of the first copy loop, which moves \(M_1\)'s output.

    def lift₁ : TM2.Stmt M₁.Γ M₁.Λ M₁.σ → TM2.Stmt (CΓ M₁ M₂) (CΛ M₁ M₂) (Cσ M₁ M₂)
  | .push k f q => .push (.inl k) (fun s => f s.1) (lift₁ q)
  | .peek k f q => .peek (.inl k) (fun s o => (f s.1 o, s.2)) (lift₁ q)
  | .pop k f q => .pop (.inl k) (fun s o => (f s.1 o, s.2)) (lift₁ q)
  | .load a q => .load (fun s => (a s.1, s.2)) (lift₁ q)
  | .branch f q₁ q₂ => .branch (fun s => f s.1) (lift₁ q₁) (lift₁ q₂)
  | .goto f => .goto (fun s => .inl (f s.1))
  | .halt => .goto (fun _ => pop1 M₁ M₂)

    MetaMathlibExt.TM2Composition.prog

    Let \(M_1\) and \(M_2\) be finite multi-stack Turing machines and \(\varphi\) a map from \(M_1\)'s output alphabet to \(M_2\)'s input alphabet. At a label of \(M_1\) or of \(M_2\) the composite program runs the lifted statement of that machine at that label. At the pop label of the first copy loop it pops \(M_1\)'s output stack, stores the image under \(\varphi\) of the popped symbol (or nothing) in the third state component, and jumps to the push label of the first loop for that image, or to the pop label of the second loop if the stack was empty. At the push label of the first loop for \(x\) it pushes \(x\) on the scratch stack and jumps to the first pop label. At the pop label of the second loop it pops the scratch stack, stores the popped symbol (or nothing) in the third state component, and jumps to the push label of the second loop for that symbol, or to the copy of \(M_2\)'s main label if the scratch stack was empty. At the push label of the second loop for \(x\) it pushes \(x\) on \(M_2\)'s input stack and jumps to the second pop label.

    MetaMathlibExt.TM2Composition.compTM

    Let \(M_1\) and \(M_2\) be finite multi-stack Turing machines, let \(X\) be the alphabet of the input stack of \(M_2\), and let \(\varphi\) map the output alphabet of \(M_1\) to \(X\). The composite machine has the stacks of \(M_1\), the stacks of \(M_2\) and one scratch stack with alphabet \(X\); its input stack is that of \(M_1\) and its output stack is that of \(M_2\). It starts at the main label of \(M_1\), in the state made of the initial states of \(M_1\) and \(M_2\) and no held symbol. It runs \(M_1\); when \(M_1\) halts, it pops the output stack of \(M_1\) onto the scratch stack, translating each symbol by \(\varphi\), then pops the scratch stack onto the input stack of \(M_2\), then runs \(M_2\) from its main label, and it halts when \(M_2\) halts.

    noncomputable def compTM : FinTM2 where
  K := CK M₁ M₂
  k₀ := .inl M₁.k₀
  k₁ := .inr (.inl M₂.k₁)
  Γ := CΓ M₁ M₂
