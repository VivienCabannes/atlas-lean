    For a map \(f : Q \to Q'\) of states and an action \(a\) of a machine with \(k\) work tapes and states \(Q\), the relabelled action is the action with states \(Q'\) that moves the input head, writes and moves on the work tapes and outputs exactly as \(a\) does, and whose successor state is \(f(q)\) when \(a\) goes to state \(q\) and is halting when \(a\) halts.

    StructureSimulation up to a state relabelling#✓fully proved

    Cslib.Turing.MultiTapeTM.IsRelabelling

    Let \(M\) and \(M'\) be deterministic machines with \(k\) work tapes over the same alphabet, with state sets \(Q\) and \(Q'\), and let \(f : Q \to Q'\). Then \(M'\) simulates \(M\) up to the relabelling \(f\) when the initial state of \(M'\) is \(f(q_0)\), where \(q_0\) is the initial state of \(M\), and for every state \(q \in Q\), every possibly blank symbol \(a\) under the input head and every tuple \(w\) of possibly blank symbols under the work heads, the action of \(M'\) in state \(f(q)\) reading \(a\) and \(w\) is the action of \(M\) in state \(q\) reading \(a\) and \(w\) with its successor state relabelled by \(f\) (a successor state \(q'\) becomes \(f(q')\), and halting stays halting).

    Nothing is required of \(M'\) in states outside the range of \(f\), and \(f\) need not be injective.

    structure IsRelabelling (f : State → State') (tm : MultiTapeTM k Symbol State)
    (tm' : MultiTapeTM k Symbol State') : Prop where
  /-- The initial state is relabelled. -/
  q₀ : tm'.q₀ = f tm.q₀
  /-- Transitions commute with the relabelling. -/
  tr : ∀ q a w, tm'.tr (f q) a w = relabelAction f (tm.tr q a w)
    def relabelAction (f : State → State') (a : Action k Symbol State) : Action k Symbol State' :=
  ⟨a.inputTape, a.workTapes, a.output, a.state.map f⟩
