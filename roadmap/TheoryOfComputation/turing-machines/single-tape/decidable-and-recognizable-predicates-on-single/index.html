    A single-tape Turing machine \(M\) halts on an input word \(w\) when its run from the initial configuration on \(w\) (the start state, with \(w\) written from the head position rightwards on an otherwise blank tape) reaches, in finitely many steps (possibly none), a configuration in the halting state.

    DefinitionHalting from a configuration#✓fully proved

    Cslib.Turing.SingleTapeTM.HaltsFrom

    A single-tape Turing machine \(M\) halts from a configuration \(c\) when its run from \(c\) reaches, in finitely many steps (possibly none), a configuration in the halting state.

    Equivalently, \(c\) is normalizable for the transition relation of \(M\), since the configurations in the halting state are exactly those without a successor; the same holds for CSLib's register machines.

    def HaltsFrom (tm : SingleTapeTM Symbol) (c : tm.Cfg) : Prop :=
  ∃ c' : tm.Cfg, ReflTransGen tm.TransitionRelation c c' ∧ c'.state = none

    Cslib.Turing.SingleTapeTM.step_some

    Let \(M\) be a single-tape Turing machine, \(q\) a state of \(M\) other than the halting state and \(t\) a tape, and let the transition function of \(M\) at \(q\) and the symbol under the head of \(t\) (possibly blank) give the symbol \(s\) to write (possibly blank), the head movement \(d\) (left, right or none) and the next state \(q'\) (possibly the halting state). Then the configuration in state \(q\) with tape \(t\) has a successor, namely the configuration in state \(q'\) whose tape is obtained from \(t\) by writing \(s\) under the head and then moving the head by \(d\).

    theorem step_some (tm : SingleTapeTM Symbol) (q : tm.State) (t : BiTape Symbol) :
    tm.step ⟨some q, t⟩ =
      some ⟨(tm.tr q t.head).2, (t.write (tm.tr q t.head).1.symbol).optionMove
        (tm.tr q t.head).1.movement⟩

    TheoremHalting from a configuration is normalizability#✓fully proved

    Cslib.Turing.SingleTapeTM.haltsFrom_iff_normalizable

    Let \(M\) be a single-tape Turing machine and \(c\) a configuration of \(M\). Then \(M\) halts from \(c\) if and only if \(c\) is normalizable for the transition relation of \(M\), that is, the run of \(M\) from \(c\) reaches, in finitely many steps (possibly none), a configuration that has no successor.

    The configurations without a successor are exactly those in the halting state.

    tm.HaltsFrom c ↔ Normalizable tm.TransitionRelation c

    TheoremOutputs are unique#✓fully proved

    Cslib.Turing.SingleTapeTM.Outputs.unique

    If a single-tape Turing machine \(M\) outputs the word \(l_1\) on the input \(l\) and also outputs the word \(l_2\) on the input \(l\), then \(l_1 = l_2\). Here \(M\) outputs a word \(w\) on \(l\) when its run from the initial configuration on \(l\) halts with exactly \(w\) on the tape, every other cell blank and the head on the first symbol of \(w\) (an all-blank tape if \(w\) is empty).

    The run of a machine is determined by its input, and a halting configuration has no successor.

    theorem Outputs.unique {tm : SingleTapeTM Symbol} {l l₁ l₂ : List Symbol} (h₁ : tm.Outputs l l₁)
    (h₂ : tm.Outputs l l₂) : l₁ = l₂

    DefinitionPredicates decidable by a single-tape Turing machine#✓fully proved

    Cslib.Decidability.SingleTapeDecidable

    Let \(\alpha\) be a type with a primitive recursive encoding into \(\mathbb{N}\). A predicate \(p\) on \(\alpha\) is decidable by a single-tape machine when there are a finite, nonempty tape alphabet \(\Sigma\), an injective map \(\iota\) from the bits \(\{0, 1\}\) to \(\Sigma\) and a single-tape Turing machine \(M\) over \(\Sigma\) such that for every \(a \in \alpha\) there is a bit \(b\) for which \(M\) outputs the one-symbol word \(\iota(b)\) on the input word obtained by writing the binary encoding of the code of \(a\) in \(\mathbb{N}\) letter by letter through \(\iota\), and \(b = 1\) exactly when \(p(a)\) holds. Here \(M\) outputs a word \(w\) on an input when its run from the input halts with exactly \(w\) on the tape, every other cell blank and the head on the first symbol of \(w\).

    def SingleTapeDecidable (p : α → Prop) : Prop :=
  ∃ (Symbol : Type) (_ : Inhabited Symbol) (_ : Fintype Symbol) (ι : Bool → Symbol),
    Function.Injective ι ∧ ∃ tm : SingleTapeTM Symbol, ∀ a, ∃ b : Bool,
      tm.Outputs ((encodeNat (encode a)).map ι) [ι b] ∧ (b = true ↔ p a)

    Cslib.Decidability.SingleTapeRecognizable

    Let \(\alpha\) be a type with a primitive recursive encoding into \(\mathbb{N}\). A predicate \(p\) on \(\alpha\) is recognizable by a single-tape machine when there are a finite, nonempty tape alphabet \(\Sigma\), an injective map \(\iota\) from the bits \(\{0, 1\}\) to \(\Sigma\) and a single-tape Turing machine \(M\) over \(\Sigma\) such that for every \(a \in \alpha\), the run of \(M\) on the input word obtained by writing the binary encoding of the code of \(a\) in \(\mathbb{N}\) letter by letter through \(\iota\) reaches the halting state if and only if \(p(a)\) holds.
