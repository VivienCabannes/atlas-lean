    An addressing mode of a random-access machine specifies an operand by a natural number \(n\) in one of three ways: immediate (the operand is the value \(n\) itself), direct (the operand is the contents of register \(n\)), or indirect (the operand is the contents of the register whose index is the contents of register \(n\)).

    Cslib.Decidability.RAMDest

    A store destination of a random-access machine names, by a natural number \(n\), the register into which the accumulator is stored: either register \(n\) itself (direct) or the register whose index is the contents of register \(n\) (indirect).

    An immediate operand is not a valid store destination.

    An instruction of a random-access machine is one of the following: load an operand into the accumulator; store the accumulator into a store destination; add an operand to the accumulator; subtract an operand from the accumulator, truncating at \(0\); jump to instruction \(q\); jump to instruction \(q\) if the accumulator is \(0\); halt.     DefinitionOne step of a RAM machine#✓fully proved

    Cslib.Decidability.ramStep

    Let \(P = (P_0, \dots, P_{\ell-1})\) be a program of length \(\ell\) and \(s\) a state with program counter \(p\), accumulator \(a\) and register contents \(r\). If \(p \ge \ell\), the step leaves \(s\) unchanged. Otherwise it executes \(P_p\), where \(v\) denotes the value of the instruction's operand in \(s\): a load sets the accumulator to \(v\), an add sets it to \(a + v\), a subtract sets it to \(\max(a - v, 0)\), and a store writes \(a\) into the register that its destination resolves to in \(s\); each of these also increases the program counter by \(1\). A jump to \(q\) sets the program counter to \(q\); a jump-if-zero to \(q\) sets it to \(q\) if \(a = 0\) and to \(p + 1\) otherwise; a halt sets it to \(\ell\). Nothing else changes.

    In particular, once the program counter is at least \(\ell\) (for instance after a halt), every further step leaves the state unchanged.

    def ramStep (prog : List RAMInstr) (s : RAMState) : RAMState :=
  match prog[s.pc]? with
  | none => s
  | some (.load a) => { s with pc := s.pc + 1, acc := ramResolve s a }
  | some (.store d) =>
      let regs' := Function.update s.regs (ramDestIndex s d) s.acc
      { s with pc := s.pc + 1, regs := regs' }
  | some (.add a) => { s with pc := s.pc + 1, acc := s.acc + ramResolve s a }
  | some (.sub a) => { s with pc := s.pc + 1, acc := s.acc - ramResolve s a }
  | some (.jump q) => { s with pc := q }
  | some (.jz q) => { s with pc := if s.acc = 0 then q else s.pc + 1 }
  | some .halt => { s with pc := prog.length }
    inductive RAMInstr where
  | load : RAMAddr → RAMInstr
  | store : RAMDest → RAMInstr
  | add : RAMAddr → RAMInstr
  | sub : RAMAddr → RAMInstr
  | jump : ℕ → RAMInstr
  | jz : ℕ → RAMInstr
  | halt : RAMInstr

    Cslib.Decidability.ramEval

    Let \(P\) be a program of length \(\ell\) and \(x_0, \dots, x_{k-1}\) inputs. Run \(P\) from the initial state on these inputs.     DefinitionRAM-decidable predicate#✓fully proved

    Cslib.Decidability.RAMDecidable

    A predicate \(P\) on the natural numbers is RAM decidable when there is a RAM program, a finite list of RAM instructions, such that for every natural number \(n\) the program, started with \(n\) in register \(0\) and with the accumulator, the program counter and every other register at \(0\), halts (its program counter reaches or passes the end of the program) with \(1\) in the accumulator if \(P(n)\) holds and with \(0\) in the accumulator otherwise; that is, its RAM evaluation on the single input \(n\) equals the characteristic function of \(P\) at \(n\).

    def RAMDecidable (P : ℕ → Prop) : Prop :=
  ∃ prog : List RAMInstr, ∀ n, ramEval prog [n] = charFun P n

  | add : RAMAddr → RAMInstr
  | sub : RAMAddr → RAMInstr
