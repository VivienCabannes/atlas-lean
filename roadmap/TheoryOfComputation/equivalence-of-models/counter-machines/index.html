    Cslib.Decidability.CounterInstr

    A counter-machine instruction is one of: increment register \(r\), decrement register \(r\), or jump to instruction \(q\) if register \(r\) is zero, where the register index \(r\) and the jump target \(q\) are natural numbers.

    Decrementing a register that holds \(0\) leaves it at \(0\).

    inductive CounterInstr where
  | inc : ℕ → CounterInstr
  | dec : ℕ → CounterInstr
  | jz : ℕ → ℕ → CounterInstr

    DefinitionOne step of a counter machine#✓fully proved

    Cslib.Decidability.counterStep

    Let \(p\) be a counter-machine program, a list of instructions indexed from \(0\), and let \(s\) be a state with program counter \(c\). If \(c\) is at least the length of \(p\) (the machine has halted), the step leaves \(s\) unchanged. Otherwise it executes instruction \(c\) of \(p\): increment register \(r\) adds \(1\) to register \(r\) and sets the program counter to \(c + 1\); decrement register \(r\) subtracts \(1\) from register \(r\) if it is positive, leaves it at \(0\) otherwise, and sets the program counter to \(c + 1\); jump to \(q\) if register \(r\) is zero leaves the registers unchanged and sets the program counter to \(q\) if register \(r\) holds \(0\) and to \(c + 1\) otherwise.

    Because halted states are fixed, the step can be iterated any number of times.

    def counterStep (prog : List CounterInstr) (s : CounterState) : CounterState :=
  match prog[s.pc]? with
  | none => s
  | some (.inc r) =>
      { pc := s.pc + 1, regs := Function.update s.regs r (s.regs r + 1) }
  | some (.dec r) =>
      { pc := s.pc + 1, regs := Function.update s.regs r (s.regs r - 1) }
  | some (.jz r q) =>
      { pc := if s.regs r = 0 then q else s.pc + 1, regs := s.regs }
    inductive CounterInstr where
  | inc : ℕ → CounterInstr
  | dec : ℕ → CounterInstr
  | jz : ℕ → ℕ → CounterInstr

    DefinitionOutput of a counter machine#✓fully proved

    Cslib.Decidability.counterEval

    The output of a counter-machine program \(p\) on a list of inputs is the partial natural number obtained as follows: run \(p\) from the initial state on those inputs; if for some number \(t\) of steps the program counter is at least the length of \(p\) (the machine has halted), the output is the content of register \(0\) after the least such \(t\); if no such \(t\) exists, the output is undefined.

    def counterEval (prog : List CounterInstr) (inputs : List ℕ) : Part ℕ :=
  Nat.rfindOpt fun t ↦
    let s := counterExecN prog t (counterInit inputs)
    if prog.length ≤ s.pc then some (s.regs 0) else Option.none
    inductive CounterInstr where
  | inc : ℕ → CounterInstr
  | dec : ℕ → CounterInstr
  | jz : ℕ → ℕ → CounterInstr

    Cslib.Decidability.counterExecN_stable

    Let \(p\) be a counter-machine program, \(s\) a state and \(t\) a natural number. If the state reached from \(s\) after \(t\) steps of \(p\) has program counter at least the length of \(p\), then the state reached from \(s\) after \(t + 1\) steps equals the state reached after \(t\) steps.

    theorem counterExecN_stable {prog : List CounterInstr} {t : ℕ} {s : CounterState}

    Cslib.Decidability.mem_counterEval_of_halted

    Let \(P\) be a counter-machine program, let \(x\) be a list of natural-number inputs, and let \(t\) and \(y\) be natural numbers. If the state reached after \(t\) steps of \(P\) from the initial state on \(x\) has program counter at least the length of \(P\) (so the machine has halted) and register \(0\) holds \(y\) in that state, then the output of \(P\) on \(x\) is defined and equals \(y\).

    theorem mem_counterEval_of_halted {prog : List CounterInstr} {inputs : List ℕ}
    {y : ℕ} {t : ℕ}
    (hhalt : prog.length ≤ (counterExecN prog t (counterInit inputs)).pc)
    (hout : (counterExecN prog t (counterInit inputs)).regs 0 = y) :
    y ∈ counterEval prog inputs
    inductive CounterInstr where
  | inc : ℕ → CounterInstr
  | dec : ℕ → CounterInstr
  | jz : ℕ → ℕ → CounterInstr

    Cslib.Decidability.CounterDecidable

    A predicate \(P\) on the natural numbers is counter-machine decidable when some counter-machine program computes its characteristic function: for every natural number \(n\), the output of the program on the single input \(n\) is defined and equals \(1\) if \(P(n)\) holds and \(0\) otherwise.

    def CounterDecidable (P : ℕ → Prop) : Prop :=
  ∃ prog : List CounterInstr, ∀ n, counterEval prog [n] = charFun P n
    inductive CounterInstr where
  | inc : ℕ → CounterInstr
  | dec : ℕ → CounterInstr
  | jz : ℕ → ℕ → CounterInstr
