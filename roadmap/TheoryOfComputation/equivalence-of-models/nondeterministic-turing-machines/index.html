    Cslib.Computability.Turing.SingleTape.SingleTapeNTM.accepts_iff_exists_labels

    A single-tape nondeterministic Turing machine \(m\) accepts a word \(x\) if and only if there is a list \(\mu\) of transition labels (read a symbol, write a symbol, move, skip) such that applying the labels of \(\mu\) in order to the input tape of \(x\) (the tape holding \(x\) from the head cell rightward, every other cell blank) never fails, that is, every read label finds its symbol in the cell under the head, and \(\mu\) leads the automaton of \(m\) from some start state to some accepting state.

    theorem accepts_iff_exists_labels {xs : List Symbol} :
    Acceptor.Accepts m xs ↔ ∃ μs : List (TrLabel Symbol),
      (μs.foldl applyToTape (some (BiTape.mk₁ xs))).isSome ∧
        ∃ s ∈ m.start, ∃ s' ∈ m.accept, m.MTr s μs s'

    Cslib.Computability.Turing.SingleTape.SingleTapeNTM.accepts_append

    If a single-tape nondeterministic Turing machine \(m\) accepts a word \(x\) over its tape alphabet, then \(m\) accepts \(xy\) for every word \(y\) over that alphabet.

    This is a defect of CSLib's definition of these machines: a transition can only test the cell under the head for a symbol, never for a blank, so every cell that an accepting run on \(x\) reads holds a letter of \(x\) or one the run wrote, and the same run accepts \(xy\).

    theorem accepts_append {xs : List Symbol} (ys : List Symbol) (h : Acceptor.Accepts m xs) :
    Acceptor.Accepts m (xs ++ ys)

    Cslib.Computability.Turing.SingleTape.SingleTapeNTM.not_forall_accepts_encodeNat_iff_eq_zero

    Let \(m\) be a single-tape nondeterministic Turing machine with tape alphabet \(\Sigma\), and let \(\iota\) be any map from the bits to \(\Sigma\). For a natural number \(n\), write \(w_n\) for the word over \(\Sigma\) obtained by applying \(\iota\) letter by letter to the little-endian binary code of \(n\), in which \(0\) is coded by the empty word. Then it is not the case that, for every natural number \(n\), \(m\) accepts \(w_n\) if and only if \(n = 0\).

    The word \(w_0\) is empty, and a machine that accepts the empty word accepts every word, in particular \(w_1\).

    theorem not_forall_accepts_encodeNat_iff_eq_zero (ι : Bool → Symbol) :
    ¬∀ n : ℕ, Acceptor.Accepts m ((encodeNat n).map ι) ↔ n = 0

    Cslib.Decidability.SingleTapeNTMRecognizable

    Let \(\alpha\) be a type with a primitive recursive encoding into \(\mathbb{N}\). A predicate \(p\) on \(\alpha\) is recognizable by a single-tape nondeterministic machine when there are a finite set of states, a finite tape alphabet \(\Sigma\) with decidable equality, an injective map \(\iota\) from the bits \(\{0, 1\}\) to \(\Sigma\) and a single-tape nondeterministic Turing machine \(M\) with these states over \(\Sigma\) such that for every \(a \in \alpha\), \(M\) accepts the input word obtained by writing the binary encoding of the code of \(a\) in \(\mathbb{N}\) letter by letter through \(\iota\) if and only if \(p(a)\) holds. Here \(M\) accepts a word when some run of \(M\) from one of its start states on the tape holding the word, with the head on its first symbol, reaches an accepting state.

    In this model a machine cannot test whether a cell is blank, so a machine that accepts a word accepts every extension of the word on the right. Every such predicate is recognizable by a single-tape deterministic machine, but not conversely: the predicate \(n = 0\) on \(\mathbb{N}\) is decidable by a single-tape deterministic machine and is not recognizable by a single-tape nondeterministic machine.

    def SingleTapeNTMRecognizable (p : α → Prop) : Prop :=
  ∃ (State Symbol : Type) (_ : Fintype State) (_ : Fintype Symbol) (_ : DecidableEq Symbol)
    (ι : Bool → Symbol), Function.Injective ι ∧ ∃ m : SingleTapeNTM State Symbol,
      ∀ a, Acceptor.Accepts m ((encodeNat (encode a)).map ι) ↔ p a
