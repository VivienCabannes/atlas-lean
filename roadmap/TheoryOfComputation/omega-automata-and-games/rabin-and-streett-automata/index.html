    Cslib.Automata.NA.Rabin.mem_language_iff

    An infinite word \(x\) is accepted by a Rabin automaton \(r\) if and only if there is a run \(s\) of \(r\) on \(x\) and a Rabin pair \((E, F)\) of \(r\) such that \(s\) visits \(E\) infinitely often and visits \(F\) only finitely often.

      ∃ ss, r.Run xs ss ∧ ∃ p ∈ r.accept, (∃ᶠ k in atTop, ss k ∈ p.1) ∧
        (∀ᶠ k in atTop, ss k ∉ p.2)

    DefinitionMuller presentation of a Rabin automaton#✓fully proved

    Cslib.Automata.NA.Rabin.toMuller

    Given a Rabin automaton with set of Rabin pairs \(\mathcal{R}\), this is the Muller automaton with the same states, initial states and transitions whose accepting family consists of the sets \(S\) of states for which some pair \((E, F) \in \mathcal{R}\) satisfies \(S \cap E \neq \emptyset\) and \(S \cap F = \emptyset\). A Muller automaton accepts a run when the set of states that the run visits infinitely often belongs to its accepting family.

    def toMuller (r : Rabin State Symbol) : Muller State Symbol where
  toNA := r.toNA
  accept := {S | ∃ p ∈ r.accept, (S ∩ p.1).Nonempty ∧ Disjoint S p.2}
    structure Rabin (State Symbol : Type*) extends NA State Symbol where
  /-- The Rabin pairs. -/

    If the state space is finite, then a Rabin automaton \(r\) accepts the same language as its Muller presentation: the Muller automaton with the same transitions and initial states as \(r\) whose acceptance sets are the sets \(S\) of states such that, for some Rabin pair \((E, F)\) of \(r\), \(S\) meets \(E\) and is disjoint from \(F\).

    Cslib.Automata.NA.Parity.toRabin

    Given a parity automaton with priority function \(\Omega\) from states to natural numbers, this is the Rabin automaton with the same states, initial states and transitions whose Rabin pairs are the pairs \((E_i, F_i)\) for \(i \in \mathbb{N}\), where \(E_i = \{s : \Omega(s) = 2i\}\) and \(F_i = \{s : \Omega(s) > 2i\}\).

    TheoremRun-wise Rabin/Streett duality#✓fully proved

    Cslib.Automata.NA.Rabin.acceptsRun_iff_not_streett

    Let \(r\) be a Rabin automaton and let \(s\) be an infinite sequence of states. Then \(s\) satisfies the Rabin condition of \(r\), that is, for some Rabin pair \((E, F)\) of \(r\) the sequence \(s\) visits \(E\) infinitely often and \(F\) only finitely often, if and only if \(s\) fails the Streett condition with the same pairs, that is, it is not the case that for every Rabin pair \((E, F)\) of \(r\), if \(s\) visits \(E\) infinitely often then \(s\) visits \(F\) infinitely often.

    The sequence \(s\) need not be a run of \(r\). (For languages of nondeterministic automata there is no such complementation statement, since complementation also swaps the run quantifier.)

    theorem acceptsRun_iff_not_streett {r : Rabin State Symbol} {ss : ωSequence State} :
    (∃ p ∈ r.accept, (∃ᶠ k in atTop, ss k ∈ p.1) ∧ (∀ᶠ k in atTop, ss k ∉ p.2)) ↔
      ¬ (∀ p ∈ r.toStreett.accept, (∃ᶠ k in atTop, ss k ∈ p.1) →
        (∃ᶠ k in atTop, ss k ∈ p.2))
    structure Rabin (State Symbol : Type*) extends NA State Symbol where
  /-- The Rabin pairs. -/
  accept : Set (Set State × Set State)
