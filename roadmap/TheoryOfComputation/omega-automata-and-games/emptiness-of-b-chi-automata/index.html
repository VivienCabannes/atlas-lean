    Cslib.Automata.NA.Buchi.HasLasso

    A nondeterministic Büchi automaton has a lasso if there are a start state \(s_0\) and an accepting state \(s\) such that the automaton can move from \(s_0\) to \(s\) by reading some finite word \(u\), and from \(s\) back to \(s\) by reading some nonempty finite word \(v\).

    Cslib.Automata.NA.Buchi.mem_language_iff

    A nondeterministic Büchi automaton accepts an infinite word \(x = x_0 x_1 x_2 \cdots\) if and only if it has a run on \(x\), that is, a sequence of states \(s_0 s_1 s_2 \cdots\) with \(s_0\) a start state and a transition from \(s_k\) to \(s_{k+1}\) reading \(x_k\) for every \(k\), such that \(s_k\) is an accepting state for infinitely many \(k\).

    DefinitionLasso states of a finite Büchi automaton#✓fully proved

    Cslib.Automata.NA.Buchi.lassoStates

    For a nondeterministic Büchi automaton with finitely many states, decidable equality of states, a finite alphabet, and decidable transitions, start set and accepting set, the lasso states form the finite set of accepting states \(s\) that are reachable from some start state in zero or more transitions and lie on a nonempty cycle, that is, \(s\) is reachable from itself in one or more transitions.

    The set is computed by one reachability closure from all start states, then one cycle closure for each reachable accepting state; each closure takes as many rounds as there are states.

    def lassoStates (na : Buchi State Symbol) [∀ s x t, Decidable (na.Tr s x t)]
    [DecidablePred (· ∈ na.start)] [DecidablePred (· ∈ na.accept)] : Finset State :=
  (na.startFin ∪ Relation.transGenFinFrom na.Step na.startFin).filter fun s =>
    s ∈ na.accept ∧ s ∈ Relation.transGenFin na.Step s

    DefinitionBüchi emptiness test#✓fully proved

    Cslib.Automata.NA.Buchi.isEmptyB

    For a nondeterministic Büchi automaton with finitely many states and finitely many symbols, with decidable equality of states, and whose transitions, start states and accepting states are decidable, the emptiness test returns true exactly when the automaton has no lasso. It decides this by computing the set of lasso states; by the lasso characterization, it returns true iff no infinite word is accepted.

    With \(n\) states, \(f\) reachable accepting states and \(k\) symbols, the computation performs at most \(f + 1\) reachability closures of \(O(n^3 k)\) transition tests each.

    def isEmptyB (na : Buchi State Symbol) [∀ s x t, Decidable (na.Tr s x t)]
    [DecidablePred (· ∈ na.start)] [DecidablePred (· ∈ na.accept)] : Bool :=
  !decide na.HasLasso
