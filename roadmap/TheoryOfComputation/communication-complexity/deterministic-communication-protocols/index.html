    Deterministic communication protocols

    In Yao's model (A. C. Yao, STOC 1979) Alice holds \(x \in X\), Bob holds \(y \in Y\), and they exchange bits to compute \(f(x, y) \in \{0, 1\}\). A deterministic protocol is a binary tree whose internal nodes are owned by one party and whose leaves carry the output; its cost is the depth of the tree, and the deterministic communication complexity \(D(f)\) is the least cost of a protocol computing \(f\). Everything below rests on two facts about protocol trees: a tree of depth \(d\) has at most \(2^d\) leaves, and the inputs reaching a leaf form a combinatorial rectangle \(A \times B\) on which \(f\) is constant. Counting leaves against a fooling set, or against the rank of the communication matrix (each 1-leaf contributes a rank-one matrix), gives the lower bounds \(D(f) \ge \log_2 |S|\) and \(D(f) \ge \log_2 \operatorname{rank} M_f\); for the equality function on \(n \ge 1\) bits they show that the trivial protocol, with \(n + 1\) bits, is optimal. Whether the rank bound is polynomially tight is the open log-rank conjecture, recorded here as a proposition only. The presentation follows A. Rao and A. Yehudayoff, Communication Complexity (early draft), Chapters 1 and 2.

    MathlibExt.Computability.CommunicationComplexity.Protocol

    A protocol for inputs x : X (held by Alice) and y : Y (held by Bob) is a binary tree: a leaf output b announces the Boolean b; a node alice f p₀ p₁ has Alice announce the bit f x and continue with p₀ or p₁ accordingly; a node bob g p₀ p₁ has Bob announce g y (A. Rao and A. Yehudayoff, Communication Complexity, early draft, Chapter 1, "Defining 2 party protocols"; A. C. Yao, STOC 1979).

    inductive Protocol (X Y : Type*) where
  /-- A leaf, labelled by the output. -/
  | output (b : Bool) : Protocol X Y
  /-- Alice announces `f x` and the protocol continues with `p₀` (bit `false`) or `p₁`. -/
  | alice (f : X → Bool) (p₀ p₁ : Protocol X Y) : Protocol X Y
  /-- Bob announces `g y` and the protocol continues with `p₀` (bit `false`) or `p₁`. -/
  | bob (g : Y → Bool) (p₀ p₁ : Protocol X Y) : Protocol X Y

    MathlibExt.Computability.CommunicationComplexity.Protocol.transcript_eq_iff

    DefinitionFooling set#✓fully proved

    MathlibExt.Computability.CommunicationComplexity.Protocol.IsFoolingSet

    A finite set S of input pairs is a fooling set for f with value b when f = b on S and, for any two distinct pairs (x₁, y₁) and (x₂, y₂) of S, either f x₁ y₂ ≠ b or f x₂ y₁ ≠ b (S. Arora and B. Barak, Computational Complexity, web draft of 2007-01-08, Definition 12.3).

    def IsFoolingSet (f : X → Y → Bool) (S : Finset (X × Y)) (b : Bool) : Prop :=
  (∀ s ∈ S, f s.1 s.2 = b) ∧
    ∀ s ∈ S, ∀ t ∈ S, s ≠ t → f s.1 t.2 ≠ b ∨ f t.1 s.2 ≠ b

    MathlibExt.Computability.CommunicationComplexity.LogRankConjecture

    There is a constant C such that every Boolean function f on finite inputs has deterministic communication complexity at most C (log₂ rank M_f + 1) ^ C, the rank taken over ℝ (L. Lovász and M. Saks, 1988; stated as Conjecture 2.12 in A. Rao and A. Yehudayoff, Communication Complexity, early draft, as D(M) ≤ log^α rank(M)). The additive + 1 and the factor C make the statement meaningful for matrices of rank one, which can need one bit. Stated as a proposition only; the lower bound ⌈log₂ rank M_f⌉ ≤ D(f) is log_rank_le_commComplexity.
