    A sequential transducer with states in a type \(Q\), input letters in a type \(\Sigma\) and output letters in a type \(\Gamma\) consists of a transition function assigning to each state \(q \in Q\) and input letter \(a \in \Sigma\) a successor state in \(Q\) and an output word over \(\Gamma\), a start state in \(Q\), a set of accepting states \(F \subseteq Q\), an initial output word over \(\Gamma\), and, for each state in \(Q\), a final output word over \(\Gamma\).

    No finiteness is assumed of \(Q\), \(\Sigma\) or \(\Gamma\).

    Cslib.Automata.SequentialTransducer.Translates

    A sequential transducer \(S\) translates an input word \(x\) to an output word \(y\) when the run of \(S\) on \(x\) from its start state ends in an accepting state \(q\) and \(y\) is the concatenation of the initial output of \(S\), the output words emitted by the transitions along the run, and the final output of \(S\) at \(q\).

    DefinitionComposition of sequential transducers#✓fully proved

    Cslib.Automata.SequentialTransducer.comp

    Let \(S_1\) be a sequential transducer from \(I\) to \(M\) with start state \(s_1\), initial output \(\iota_1\) and final output map \(\phi_1\), and let \(S_2\) be one from \(M\) to \(O\) with start state \(s_2\), initial output \(\iota_2\) and final output map \(\phi_2\). For a transducer \(S\), a state \(q\) and a word \(w\), write \(\delta_S(q, w)\) for the state \(S\) reaches by reading \(w\) from \(q\) and \(\lambda_S(q, w)\) for the concatenation of the words it emits along the way. The composition of \(S_1\) and \(S_2\) is the sequential transducer from \(I\) to \(O\) whose states are the pairs \((q_1, q_2)\) of a state of \(S_1\) and a state of \(S_2\), where: reading a letter \(a\) in state \((q_1, q_2)\), if \(S_1\) reading \(a\) in \(q_1\) moves to \(q_1'\) and emits \(w\), the composition moves to \((q_1', \delta_{S_2}(q_2, w))\) and emits \(\lambda_{S_2}(q_2, w)\); the start state is \((s_1, \delta_{S_2}(s_2, \iota_1))\); the initial output is \(\iota_2\) followed by \(\lambda_{S_2}(s_2, \iota_1)\); a state \((q_1, q_2)\) is accepting when \(q_1\) is accepting for \(S_1\) and \(\delta_{S_2}(q_2, \phi_1(q_1))\) is accepting for \(S_2\); and the final output at \((q_1, q_2)\) is \(\lambda_{S_2}(q_2, \phi_1(q_1))\) followed by \(\phi_2(\delta_{S_2}(q_2, \phi_1(q_1)))\).

    In words: run \(S_1\) and feed its output, including its initial output (fed through \(S_2\) before any input is read) and its final output, through \(S_2\).

    def comp (S₁ : SequentialTransducer State₁ In Mid)
    (S₂ : SequentialTransducer State₂ Mid Out) :
    SequentialTransducer (State₁ × State₂) In Out where
  step := fun (q₁, q₂) a =>
    let (q₁', w₁) := S₁.step q₁ a
    let (q₂', w₂) := S₂.runFrom q₂ w₁
    ((q₁', q₂'), w₂)
  start := (S₁.start, S₂.runState S₂.start S₁.initOut)
  accept := {p : State₁ × State₂ | p.1 ∈ S₁.accept ∧
    S₂.runState p.2 (S₁.finalOut p.1) ∈ S₂.accept}
  initOut := S₂.initOut ++ S₂.runOut S₂.start S₁.initOut
  finalOut := fun (q₁, q₂) =>
    S₂.runOut q₂ (S₁.finalOut q₁) ++ S₂.finalOut (S₂.runState q₂ (S₁.finalOut q₁))
