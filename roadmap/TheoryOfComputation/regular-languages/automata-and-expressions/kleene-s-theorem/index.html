    TheoremSolving a system of language equations#✓fully proved

    Cslib.Language.KleeneConverse.exists_regex_of_system

    If the languages X i satisfy X i = (∑ j, A i j * X j) + B i with every coefficient A i j excluding the empty word and every coefficient and constant term denoted by a regular expression, then every X i is denoted by a regular expression. The proof eliminates the last state with Arden's lemma and applies the induction hypothesis to the reduced system.

    theorem exists_regex_of_system (n : ℕ) :
    ∀ {A : Fin n → Fin n → Language α} {B X : Fin n → Language α},
      (∀ i j, IsRegexDenoted (A i j)) → (∀ i j, [] ∉ A i j) →
      (∀ i, IsRegexDenoted (B i)) → (∀ i, X i = (∑ j, A i j * X j) + B i) →
      ∀ i, IsRegexDenoted (X i)
    def IsRegexDenoted (L : Language α) : Prop :=
  ∃ r : RegularExpression α, r.matches' = L
