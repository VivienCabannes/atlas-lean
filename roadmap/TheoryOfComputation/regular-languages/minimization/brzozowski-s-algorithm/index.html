    DefinitionDeterminized reversal of a DFA#✓fully proved

    DFA.revDet

    For a DFA \(M\) with finitely many states, the determinized reversal of \(M\) is the subset construction applied to the reversal of \(M\): its states are the sets of states of \(M\); reading a letter \(a\) from a set \(S\) leads to the set of states \(q\) whose \(a\)-successor in \(M\) lies in \(S\); its start state is the set of accepting states of \(M\); and it accepts exactly the sets that contain the start state of \(M\).

    def revDet : DFA α (Finset σ) where
  step S a := Finset.univ.filter fun q => M.step q a ∈ S
  start := Finset.univ.filter (· ∈ M.accept)
  accept := {S | M.start ∈ S}

    DFA.revDet_eval

    Let \(M\) be a DFA with finitely many states and \(w\) a word. On input \(w\), the determinized reversal of \(M\) reaches the set of states \(q\) of \(M\) from which \(M\), reading \(w\) backwards starting at \(q\), ends in an accepting state.

    theorem revDet_eval (w : List α) :
    M.revDet.eval w = Finset.univ.filter fun q => M.evalFrom q w.reverse ∈ M.accept

    DFA.revDet_eval_eq_iff

    Let \(M\) be a DFA with finitely many states in which every state is reached from the start state by some word, and let \(L\) be its language. Write \(u^R\) for the word \(u\) read backwards, \(L^R = \{u \mid u^R \in L\}\) for the reversed language, and \(w^{-1}K = \{v \mid wv \in K\}\) for the left quotient of a language \(K\) by a word \(w\). Then two words \(w\) and \(w'\) lead the determinized reversal of \(M\) from its start state to the same set of states if and only if \(w^{-1}L^R = w'^{-1}L^R\).

    theorem revDet_eval_eq_iff (hacc : ∀ q, ∃ u, M.eval u = q) {w w' : List α} :
    M.revDet.eval w = M.revDet.eval w' ↔
      M.accepts.reverse.leftQuotient w = M.accepts.reverse.leftQuotient w'

    DFA.MidState

    For a deterministic finite automaton \(M\) over a finite alphabet with finite state set \(Q\), the subsets of \(Q\) reachable from the start state in the subset construction of the reversal of \(M\).

    They are found by a reachability search of at most \(2^{|Q|}\) rounds, the number of subsets, which stops as soon as a round adds nothing.

    abbrev MidState : Type _ :=
  {S // S ∈ M.revDet.reachableWithin (2 ^ Fintype.card σ) ∅}

    DFA.brzozowski_eval_eq_iff

    For a deterministic finite automaton \(M\) over a finite alphabet with finitely many states and words \(w\) and \(w'\), Brzozowski's automaton of \(M\) reaches the same state on \(w\) as on \(w'\) if and only if \(w\) and \(w'\) are Nerode equivalent for the language of \(M\), that is, have the same left quotient.

    theorem brzozowski_eval_eq_iff {w w' : List α} :
    M.brzozowski.eval w = M.brzozowski.eval w' ↔ nerodeRel M.accepts w w'
    def nerodeRel (L : Language Symbol) (x y : List Symbol) : Prop :=
  L.leftQuotient x = L.leftQuotient y

    TheoremBrzozowski's automaton is the minimal automaton#✓fully proved

    DFA.reindex_brzozowski

    Let \(M\) be a DFA over a finite alphabet with finitely many states, and let \(L\) be its language. For a language \(K\) and a word \(w\), write \(w^{-1}K = \{v \mid wv \in K\}\) for the left quotient of \(K\) by \(w\). Every state of Brzozowski's automaton of \(M\) is reached by some word \(w\); rename that state to \(w^{-1}L\), which does not depend on the choice of \(w\). The renamed automaton is exactly the minimized DFA of \(M\): its states are the left quotients of \(L\) by words, its start state is \(L\), reading a letter \(a\) (a word of length one) sends \(K\) to \(a^{-1}K\), and it accepts the \(K\) that contain the empty word.

    theorem reindex_brzozowski : DFA.reindex M.brzozowskiEquiv M.brzozowski = minimizedDFA M
    noncomputable def minimizedDFA (M : DFA Symbol State) : DFA Symbol (reachableResiduals M) :=
  DFA.reindex (leftQuotientEquivReachableResiduals M) M.accepts.toDFA
