    State equivalence by refinement

    DefinitionMoore refinement step#✓fully proved

    DFA.mooreStep

    Let \(M\) be a DFA with state set \(S\) and transition function \(\delta\). One round of Moore's refinement sends a set \(E \subseteq S \times S\) of pairs of states to the set of pairs \((p, q) \in S \times S\) such that \(p\) is accepting if and only if \(q\) is accepting and, for every letter \(a\), the pair \((\delta(p, a), \delta(q, a))\) lies in \(E\).

    def mooreStep (E : Finset (σ × σ)) : Finset (σ × σ) :=
  Finset.univ.filter fun p =>
    (p.1 ∈ M.accept ↔ p.2 ∈ M.accept) ∧ ∀ a, (M.step p.1 a, M.step p.2 a) ∈ E

    DFA.mooreIter

    Let \(M\) be a DFA over a finite alphabet with finitely many states, and write \(R\) for one round of Moore's refinement. For a set \(E\) of pairs of states of \(M\) and a budget \(n \in \mathbb{N}\), the stopping Moore iteration is defined by recursion on \(n\): with budget \(0\) it returns \(E\); with budget \(n + 1\) it returns \(E\) if \(R(E) = E\), and otherwise the stopping Moore iteration from \(R(E)\) with budget \(n\).

    def mooreIter : ℕ → Finset (σ × σ) → Finset (σ × σ)
  | 0, E => E
  | n + 1, E =>
      let next := M.mooreStep E
      if next = E then E else mooreIter n next

    DFA.mooreIter_spec

    Let \(M\) be a DFA over a finite alphabet with finitely many states, and write \(R\) for one round of Moore's refinement. For every \(n \in \mathbb{N}\) and every set \(E\) of pairs of states of \(M\), there is \(k \le n\) such that the stopping Moore iteration from \(E\) with budget \(n\) returns \(R^k(E)\), and if \(k < n\) then \(R^k(E)\) is a fixed point of \(R\), that is, \(R(R^k(E)) = R^k(E)\).

    theorem mooreIter_spec :
    ∀ (n : ℕ) (E : Finset (σ × σ)), ∃ k ≤ n, M.mooreIter n E = M.mooreStep^[k] E ∧
      (k < n → M.mooreStep (M.mooreStep^[k] E) = M.mooreStep^[k] E)

    DFA.mooreRel

    For a DFA \(M\) over a finite alphabet with finite set of states \(Q\), Moore's relation is the set of pairs of states obtained from \(Q \times Q\) by repeating rounds of Moore's refinement until a round changes nothing, for at most \(|Q \times Q|\) rounds.

    def mooreRel : Finset (σ × σ) :=
  M.mooreIter (Fintype.card (σ × σ)) Finset.univ

    DFA.mem_mooreRel_iff

    For a DFA \(M\) over a finite alphabet with finitely many states, two states \(p\) and \(q\) of \(M\) are related by Moore's relation if and only if they have the same continuation language: for every word \(w\), \(M\) started at \(p\) accepts \(w\) exactly when \(M\) started at \(q\) accepts \(w\).

    theorem mem_mooreRel_iff {p q : σ} :
    (p, q) ∈ M.mooreRel ↔ M.acceptsFrom p = M.acceptsFrom q

    DFA.mooreSetoid

    For a DFA \(M\), two reachable states \(p\) and \(q\) of \(M\) are related when the pair \((p, q)\) lies in Moore's relation of \(M\); this relation is an equivalence relation on the reachable states of \(M\).

    def mooreSetoid : Setoid {s // s ∈ M.reachable} where
  r p q := (p.1, q.1) ∈ M.mooreRel
  iseqv :=
    ⟨fun _ => M.mem_mooreRel_iff.2 rfl,
      fun h => M.mem_mooreRel_iff.2 (M.mem_mooreRel_iff.1 h).symm,
      fun h₁ h₂ => M.mem_mooreRel_iff.2 ((M.mem_mooreRel_iff.1 h₁).trans (M.mem_mooreRel_iff.1 h₂))⟩

    DFA.mooreDFA

    For a DFA \(M\) over a finite alphabet with finitely many states, Moore's minimal automaton of \(M\) has as states the classes of reachable states of \(M\) under Moore's relation. Its start state is the class of the start state of \(M\); reading a letter \(a\) sends the class of a reachable state \(s\) to the class of the state that \(M\) reaches from \(s\) on \(a\); and the class of \(s\) is accepting exactly when \(s\) is an accepting state of \(M\).

    These do not depend on the chosen member \(s\), because Moore-related states agree on acceptance and their successors on each letter are again Moore-related.

    def mooreDFA : DFA α M.MooreState where
  step c a := Quotient.lift (fun p => M.mooreClass ⟨M.step p.1 a, M.step_mem_reachable p.2 a⟩)
    (fun _ _ h => (M.mooreClass_eq_iff).2
      (M.mem_mooreRel_iff.1 (((M.mem_mooreRel_unfold).1 h).2 a))) c
  start := M.mooreClass ⟨M.start, M.start_mem_reachable⟩
  accept := {c | Quotient.lift (fun p : {s // s ∈ M.reachable} => decide (p.1 ∈ M.accept))
    (fun _ _ h => decide_eq_decide.2 ((M.mem_mooreRel_unfold).1 h).1) c = true}

    DefinitionContinuation language of a Moore class#✓fully proved

    DFA.mooreResidual

    Let \(M\) be a DFA over a finite alphabet with finitely many states. Each state of Moore's minimal automaton of \(M\), a class of reachable states of \(M\), is sent to the continuation language of any member \(s\), the set of words that \(M\) accepts when started at \(s\); this is a reachable residual language of \(M\). It does not depend on the choice of \(s\), because Moore-related states have the same continuation language.

    def mooreResidual (c : M.MooreState) : reachableResiduals M :=
  Quotient.lift (fun p : {s // s ∈ M.reachable} => (⟨M.acceptsFrom p.1, by
      obtain ⟨w, hw⟩ := M.mem_reachable_iff.1 p.2
      exact ⟨w, by simp [hw]⟩⟩ : reachableResiduals M))
    (fun _ _ h => Subtype.ext (M.mem_mooreRel_iff.1 h)) c
    def reachableResiduals (M : DFA Symbol State) : Set (Language Symbol) :=
  Set.range (M.acceptsFrom ∘ M.eval)

    DFA.reindex_mooreDFA

    Let \(M\) be a DFA. Renaming each state of Moore's minimal automaton of \(M\), a class of reachable states, to the continuation language accepted from its members turns Moore's automaton into exactly the minimized DFA of \(M\), whose states are the reachable continuation languages of \(M\).
