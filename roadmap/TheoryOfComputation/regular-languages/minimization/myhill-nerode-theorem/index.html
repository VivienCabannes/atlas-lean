    Cslib.Language.classResidual

    Let \(L\) be a language. The residual map sends the Nerode class \([x]\) of a word \(x\) to the left quotient \(x^{-1}L = \{ y \mid xy \in L \}\), viewed as an element of the set \(\{ w^{-1}L \mid w \text{ a word} \}\) of left quotients of \(L\).     Cslib.Language.NerodeClass.Accepting

    Let \(L\) be a language. The accepting Nerode classes of \(L\) are those whose words belong to \(L\): the Nerode class \([x]\) of a word \(x\) is accepting if and only if \(x \in L\). This is well-defined because Nerode equivalent words are either both in \(L\) or both outside \(L\).

    Cslib.Language.nerodeDFA

    Let \(L\) be a language over an alphabet \(\Sigma\).
