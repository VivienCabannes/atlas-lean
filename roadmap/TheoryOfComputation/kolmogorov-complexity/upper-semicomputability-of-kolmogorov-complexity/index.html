    Cslib.Kolmogorov.exists_bound_of_rePred_le_K

    Let \(K\) denote Kolmogorov complexity, and let \(S\) be a recursively enumerable (recognizable) set of pairs \((x, n)\) of a binary string \(x\) and a natural number \(n\) such that \(n \le K(x)\) for every \((x, n) \in S\). Then there is a natural number \(B\) with \(n \le B\) for every \((x, n) \in S\).

    This is the abstract form of the theorem: think of \(S\) as the statements \(K(x) \ge n\) that a sound formal system proves. The proof searches \(S\) for a pair with a large bound \(n\) and applies optimality of the universal description method (Berry's paradox).

    theorem exists_bound_of_rePred_le_K {S : List Bool × ℕ → Prop} (hS : REPred S)
    (hsound : ∀ q, S q → q.2 ≤ K q.1) : ∃ B, ∀ q, S q → q.2 ≤ B
    noncomputable def K (x : List Bool) : ℕ :=
  Nat.find (⟨_, (exists_mem_U x).choose, rfl, (exists_mem_U x).choose_spec⟩ :
    ∃ n, ∃ p : List Bool, p.length = n ∧ x ∈ U p)
