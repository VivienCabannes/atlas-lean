    Kolmogorov complexity

    Algorithmic information content of individual strings: universal description methods, incompressible strings, non-computability and upper semicomputability of Kolmogorov complexity.

    Cslib.Kolmogorov.run

    For a code \(c\) of a partial recursive function on the natural numbers and a binary string \(w\), running \(c\) on \(w\) evaluates \(c\) at the number encoding \(w\); if this halts with output \(m\), the result is the binary string encoded by \(m\). The result is undefined when the evaluation does not halt or \(m\) encodes no binary string.

    def run (c : Code) (w : List Bool) : Part (List Bool) :=
  (c.eval (encode w)).bind fun n ↦ Part.ofOption (decode n)

    DefinitionPair description#✓fully proved

    Cslib.Kolmogorov.pairDescribe

    For binary strings \(p\) and \(q\), the pair description of \(p\) and \(q\) is the binary string \(1^{|p|} 0 p q\), that is, \(|p|\) ones, where \(|p|\) is the length of \(p\), then a zero, then \(p\), then \(q\).

    The prefix \(1^{|p|} 0\) records the length of \(p\), so the string splits back into \(p\) and \(q\).

    def pairDescribe (p q : List Bool) : List Bool := List.replicate p.length true ++ false :: (p ++ q)

    DefinitionReading pair descriptions#✓fully proved

    Cslib.Kolmogorov.pairU

    Write a binary string \(s\) as \(1^n s'\), where \(n\) is the number of leading \(1\)s, and let \(r\) be \(s'\) without its first letter (\(r\) is empty when \(s'\) is). Let \(r_1\) be the first \(\min(n, |r|)\) letters of \(r\) and \(r_2\) the remaining ones. The pair reader maps \(s\) to the concatenation \(U(r_1)\,U(r_2)\), where \(U\) is the universal description method, and is undefined when \(U(r_1)\) or \(U(r_2)\) is undefined. On a pair description \(1^n 0 r\) with \(|r| \ge n\), this is the concatenation of what the first \(n\) letters of \(r\) and the rest describe.

  (U (((s.dropWhile id).tail).take (s.takeWhile id).length)).bind fun x ↦
