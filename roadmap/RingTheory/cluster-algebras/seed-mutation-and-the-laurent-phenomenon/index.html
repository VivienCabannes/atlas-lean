    Seed mutation and the Laurent phenomenon

    A seed is a pair \((\mathbf{x}, B)\) of a cluster \(\mathbf{x} = (x_1, \dots, x_n)\) of free generators of a field and a skew-symmetrizable integer matrix \(B\). The mutation \(\mu_k\) in direction \(k\) replaces \(B\) by the matrix \(\mu_k(B)\) of formula (2.7.1) and replaces \(x_k\) by \(x_k'\) with \(x_k x_k' = \prod_{b_{ik} > 0} x_i^{b_{ik}} + \prod_{b_{ik} < 0} x_i^{-b_{ik}}\); it is an involution. The cluster variables are all the elements obtained by iterating mutations (Fomin, Williams and Zelevinsky, Introduction to cluster algebras, Chapters 1–3, arXiv:1608.05735v5, Definitions 2.7.4, 2.7.6, 3.1.3 and 3.1.9). The Laurent phenomenon says that every cluster variable is a Laurent polynomial with integer coefficients in the initial cluster, although each mutation divides by a polynomial (Theorem 3.3.1; Fomin and Zelevinsky, Cluster algebras I, J. Amer. Math. Soc. 15 (2002), Theorem 3.1, proved through the Caterpillar Lemma of Fomin and Zelevinsky, The Laurent phenomenon, Adv. in Appl. Math. 28 (2002), Theorem 2.1). Its arithmetic shadow is the integrality of the Somos-4 sequence \(1, 1, 1, 1, 2, 3, 7, 23, 59, \dots\), obtained from a quiver whose mutations rotate it (Example 3.4.3).

    Here matrix mutation, skew-symmetrizability, seed mutation without frozen variables, iterated mutation and the set of cluster variables are defined, and two properties of matrix mutation are proved: it is an involution and it preserves skew-symmetrizability (Exercise 2.7.7). The Laurent phenomenon is recorded as a wanted theorem for coefficient-free seed patterns, together with its rank-two case and the integrality of the Somos-4 sequence; the finite types of rank two are proved in Cluster algebras of rank two. Frozen variables, coefficients in a semifield and the positivity of the Laurent coefficients are not formalized.

    DefinitionMatrix mutation#✓fully proved

    MathlibExt.RingTheory.ClusterAlgebra.matrixMutation

    The mutation of an integer square matrix B in direction k is the matrix B' with b'ᵢⱼ = -bᵢⱼ if i = k or j = k, b'ᵢⱼ = bᵢⱼ + bᵢₖ bₖⱼ if bᵢₖ > 0 and bₖⱼ > 0, b'ᵢⱼ = bᵢⱼ - bᵢₖ bₖⱼ if bᵢₖ < 0 and bₖⱼ < 0, and b'ᵢⱼ = bᵢⱼ otherwise (Fomin, Williams and Zelevinsky, Introduction to cluster algebras, Chapters 1–3, arXiv:1608.05735v5, Lemma 2.7.3, equation (2.7.1), and Definition 2.7.6, square case m = n).

    def matrixMutation (k : n) (B : Matrix n n ℤ) : Matrix n n ℤ :=
  Matrix.of fun i j =>
    if i = k ∨ j = k then -B i j
    else if 0 < B i k ∧ 0 < B k j then B i j + B i k * B k j
    else if B i k < 0 ∧ B k j < 0 then B i j - B i k * B k j
    else B i j

    DefinitionSkew-symmetrizable integer matrix#✓fully proved

    MathlibExt.RingTheory.ClusterAlgebra.IsSkewSymmetrizable

    An integer square matrix B is skew-symmetrizable if there are positive integers dᵢ with dᵢ bᵢⱼ = -dⱼ bⱼᵢ for all i, j (Fomin, Williams and Zelevinsky, Introduction to cluster algebras, Chapters 1–3, arXiv:1608.05735v5, Definition 2.7.4).

    def IsSkewSymmetrizable (B : Matrix n n ℤ) : Prop :=
  ∃ d : n → ℤ, (∀ i, 0 < d i) ∧ ∀ i j, d i * B i j = -(d j * B j i)

    DefinitionSeed mutation without frozen variables#✓fully proved

    MathlibExt.RingTheory.ClusterAlgebra.seedMutation

    For a cluster x : n → K in a field K and an exchange matrix B, the mutation in direction k replaces xₖ by xₖ' = (∏_{bᵢₖ > 0} xᵢ^{bᵢₖ} + ∏_{bᵢₖ < 0} xᵢ^{-bᵢₖ}) / xₖ and keeps the other cluster variables, while B becomes μₖ B (Fomin, Williams and Zelevinsky, Introduction to cluster algebras, Chapters 1–3, arXiv:1608.05735v5, Definition 3.1.3, exchange relation (3.1.2), in the coefficient-free case m = n).

    def seedMutation {K : Type*} [Field K] [Fintype n] (k : n) (s : (n → K) × Matrix n n ℤ) :
    (n → K) × Matrix n n ℤ :=
  (Function.update s.1 k
      ((∏ i, (if 0 < s.2 i k then s.1 i ^ (s.2 i k).toNat else 1) +
          ∏ i, (if s.2 i k < 0 then s.1 i ^ (-s.2 i k).toNat else 1)) / s.1 k),
    matrixMutation k s.2)
    def matrixMutation (k : n) (B : Matrix n n ℤ) : Matrix n n ℤ :=
  Matrix.of fun i j =>
    if i = k ∨ j = k then -B i j
    else if 0 < B i k ∧ 0 < B k j then B i j + B i k * B k j

    DefinitionIterated seed mutation#✓fully proved

    MathlibExt.RingTheory.ClusterAlgebra.mutateSeq

    mutateSeq w s applies the seed mutations in the directions listed in w, from left to right (Fomin, Williams and Zelevinsky, Introduction to cluster algebras, Chapters 1–3, arXiv:1608.05735v5, Definitions 3.1.7–3.1.8: every seed of the seed pattern through s is reached this way).

    def mutateSeq {K : Type*} [Field K] [Fintype n] (w : List n) (s : (n → K) × Matrix n n ℤ) :
    (n → K) × Matrix n n ℤ :=
  w.foldl (fun t k => seedMutation k t) s

    MathlibExt.RingTheory.ClusterAlgebra.LaurentPhenomenonWanted.laurentSubalgebra

    The ring ℤ[X_i^{±1}] of Laurent polynomials with integer coefficients in the initial cluster, as the ℤ-subalgebra of FractionRing (MvPolynomial n ℤ) generated by the X_i and their inverses (Fomin, Williams and Zelevinsky, Introduction to cluster algebras, Chapters 1–3, arXiv:1608.05735v5, Theorem 3.3.1, where the conclusion is membership in this ring).

    TheoremLaurent phenomenon (coefficient-free)#●ready to prove

    MathlibExt.RingTheory.ClusterAlgebra.LaurentPhenomenonWanted.laurent_phenomenon

    Let B be a skew-symmetrizable integer n × n matrix and start from the seed ((X_i), B) in ℚ(X_i : i ∈ n). Every cluster variable of every seed obtained by iterated mutation is a Laurent polynomial in the X_i with integer coefficients (Fomin, Williams and Zelevinsky, Introduction to cluster algebras, Chapters 1–3, arXiv:1608.05735v5, Theorem 3.3.1, in the case without frozen variables; Fomin and Zelevinsky, Cluster algebras I, J. Amer. Math. Soc. 15 (2002), Theorem 3.1). The source theorem also allows frozen variables and expands in every extended cluster; this statement is the coefficient-free case, relative to the initial cluster, which by relabelling the initial seed covers expansions in any cluster of the pattern.
