    Toric ideals and Markov bases

    The toric ideal of an integer matrix T is the kernel of the monomial map x ↦ t^{T(x)}. It is generated by binomials, and by the Diaconis–Sturmfels theorem the move binomials x^{f⁺} - x^{f⁻} of a family of moves generate it exactly when the moves form a Markov basis, that is, connect every fibre of the sufficient statistic T, which is what a Metropolis chain for an exact conditional test needs.

    DefinitionBinomials of a toric model#✓fully proved

    MathlibExt.RingTheory.ToricIdeal.binomials

    The set of binomials x^a - x^b whose exponent vectors have the same sufficient statistic, ∑ a(x) T(x) = ∑ b(x) T(x). Up to a monomial factor these are the monomial differences x^{f⁺} - x^{f⁻} with ∑ f(x) T(x) = 0 of Diaconis–Sturmfels (1998), equation (3.1), since x^a - x^b = x^{a ⊓ b} (x^{a - a ⊓ b} - x^{b - a ⊓ b}).

    def binomials (T : X → d →₀ ℕ) : Set (MvPolynomial X k) :=
  {p | ∃ a b : X →₀ ℕ, statistic T a = statistic T b ∧ p = monomial a 1 - monomial b 1}

    TheoremToric ideals are generated by binomials#✓fully proved

    MathlibExt.RingTheory.ToricIdeal.toricIdeal_eq_span_binomials

    Over any field k, the kernel of the monomial map k[X] → k[t_1, …, t_d], x ↦ t^{T(x)}, is the ideal generated by the binomials x^a - x^b whose exponent vectors have the same sufficient statistic, ∑ a(x) T(x) = ∑ b(x) T(x).

    This is the first stage of the proof of Theorem 3.1 of Diaconis and Sturmfels (the identity I* = I_T), where the binomials are written as monomial differences x^{f⁺} - x^{f⁻} with ∑ f(x) T(x) = 0; the two generating sets agree up to monomial factors. The paper argues with a leading-term induction. The formal proof shows more: grouping the terms of a polynomial by the fibre of their exponent vector, every polynomial in the kernel is a k-linear combination of such binomials.

    theorem toricIdeal_eq_span_binomials (T : X → d →₀ ℕ) :
    toricIdeal k T = Ideal.span (binomials k T)
    def toricIdeal (T : X → d →₀ ℕ) : Ideal (MvPolynomial X k) :=
  RingHom.ker (toricMap k T)

    DefinitionMarkov basis#✓fully proved

    MathlibExt.RingTheory.MarkovBasis.IsMarkovBasis

    Moves f_i : X → ℤ form a Markov basis for the statistic T when (a) each f_i lies in the lattice of moves, ∑_x f_i(x) T(x) = 0, and (b) any two tables g, g' with the same sufficient statistic are joined by a sequence of steps ± f_i through tables of nonnegative counts (Diaconis–Sturmfels 1998, Definition (1.5)).

    def IsMarkovBasis (T : X → d →₀ ℕ) {ι : Type*} (f : ι → X →₀ ℤ) : Prop :=
  (∀ i, Finsupp.linearCombination ℤ (statInt T) (f i) = 0) ∧
    ∀ g g' : X →₀ ℕ, statistic T g = statistic T g' → Relation.ReflTransGen (MoveStep f) g g'
    def statInt (T : X → d →₀ ℕ) (x : X) : d →₀ ℤ :=
  toInt (T x)

    TheoremFundamental theorem of Markov bases#✓fully proved

    MathlibExt.RingTheory.MarkovBasis.isMarkovBasis_iff_span_eq_toricIdeal

    Let T : X → ℕ^d be the sufficient statistic of a discrete exponential family on a set of cells X, and k any field. A family of integer moves f_i : X → ℤ is a Markov basis for T (each move lies in the lattice ∑_x f_i(x) T(x) = 0, and any two tables of counts with the same sufficient statistic are joined by steps ± f_i that keep all counts nonnegative) if and only if the binomials x^{f_i⁺} - x^{f_i⁻} generate the toric ideal I_T, the kernel of the monomial map x ↦ t^{T(x)}.

    This is Theorem 3.1 of Diaconis and Sturmfels. It turns the search for moves of a Metropolis chain on the fibre of an exact conditional test into the computation of a generating set (in practice a Gröbner basis) of a toric ideal.

    The direction "Markov basis ⇒ generation" telescopes x^a - x^b along a path of moves, using that I_T is generated by binomials. For the converse the formal proof replaces the paper's integer-coefficient induction by a linear map x^a ↦ [a] into the monoid algebra of the connectivity classes, which kills the ideal generated by the move binomials. The paper assumes X finite, T(x) ≠ 0 and finitely many moves; the formal statement needs none of these.

    {ι : Type*} (f : ι → X →₀ ℤ) :
    IsMarkovBasis T f ↔ Ideal.span (Set.range fun i ↦ moveBinomial k (f i)) = toricIdeal k T
