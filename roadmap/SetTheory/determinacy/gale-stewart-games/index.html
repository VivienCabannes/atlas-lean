    Gale–Stewart games

    Two players alternately choose moves x 0, x 1, x 2, … from a set A, each seeing all earlier moves; player I wins if the play lies in the payoff set S ⊆ A^ℕ. A strategy maps finite histories to moves, and S is determined if one player has a winning strategy. The Gale–Stewart theorem says that open and closed payoff sets are determined; every later determinacy proof (Martin's for Borel sets, Martin–Steel's for projective sets under Woodin cardinals) reduces the game at hand to a closed game on a larger set of moves.

    MathlibExt.SetTheory.Determinacy.Follows

    The play x follows the strategy σ : List A → A at the turns n with n % 2 = k: there x n = σ (history x n). With k = 0 these are the turns of player I and with k = 1 those of player II (Moschovakis, Descriptive Set Theory, 2nd ed., §6A).

    TheoremGale–Stewart theorem#✓fully proved

    MathlibExt.SetTheory.Determinacy.determined_of_isClosed

    If the set of moves A is non-empty and A^ℕ carries the product of the discrete topologies, every closed payoff set S ⊆ A^ℕ is determined (Gale and Stewart, Infinite games with perfect information, Ann. of Math. Stud. 28 (1953); Moschovakis, Descriptive Set Theory, 2nd ed., AMS 2009, Theorem 6A.2).

    The proof is the non-losing-position argument of Gale and Stewart. Suppose player II has no winning strategy. If II does not win from a position where I is to move, I has a move after which II still does not win from any reply (Moschovakis, Lemma 6A.1, which picks II's winning strategies with the axiom of choice). Player I keeps choosing such moves. Every finite stage of the resulting play then extends to a play in S, because otherwise II could win by moving arbitrarily, so the play is a limit of points of S and lies in the closed set S. In Lean, both this theorem and the open case come from a single lemma about the player who wants an open set: either that player wins from the initial position, or the opponent can always move to a position from which the player still does not win, and then the play never enters a basic cylinder inside the open set.

    theorem determined_of_isClosed [Nonempty A] [TopologicalSpace A] [DiscreteTopology A]
    {S : Set (ℕ → A)} (hS : IsClosed S) : Determined S
    def Determined (S : Set (ℕ → A)) : Prop :=
  IWins S ∨ IIWins S

    MathlibExt.SetTheory.Determinacy.determined_of_isOpen

    If the set of moves A is non-empty and A^ℕ carries the product of the discrete topologies, every open payoff set S ⊆ A^ℕ is determined (Gale and Stewart, Infinite games with perfect information, Ann. of Math. Stud. 28 (1953); Moschovakis, Descriptive Set Theory, 2nd ed., AMS 2009, Theorem 6A.2 and 6A.4).

    Moschovakis obtains the open case from the closed case by adding a dummy first move, which swaps the roles of the players (Theorem 6A.4). The Lean proof instead applies the lemma behind the closed case to player I and the open set S.

    MathlibExt.SetTheory.Determinacy.play

    The unique play σ * τ in which player I follows σ and player II follows τ: x n = σ (history x n) for even n and x n = τ (history x n) for odd n (Moschovakis, Descriptive Set Theory, 2nd ed., §6A).
