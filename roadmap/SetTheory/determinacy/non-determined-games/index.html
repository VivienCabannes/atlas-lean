    Non-determined games

    With the axiom of choice, some game on {0, 1} is not determined (Gale and Stewart, 1953): a diagonalisation over the continuum many strategies, each of which has continuum many plays. Hence the axiom of determinacy, that every subset of Baire space is determined, is false in Lean's ambient logic; results "under AD" are stated with determinacy hypotheses on specific classes of sets instead.

    MathlibExt.SetTheory.Determinacy.exists_meets_and_compl_meets

    Let κ be an infinite cardinal and F : ι → Set α a family of at most κ sets, each of cardinality at least κ. Then some B ⊆ α meets every F i, and so does its complement. This is the transfinite construction of Moschovakis, Descriptive Set Theory, 2nd ed., AMS 2009, hint to Exercise 6A.6 (sets A_ξ, B_ξ of cardinality < 2^ℵ₀ built along a well-ordering of the strategies), and of Bernstein's set.

    theorem exists_meets_and_compl_meets {α ι : Type u} (κ : Cardinal.{u}) (hκ : ℵ₀ ≤ κ)
    (F : ι → Set α) (hι : #ι ≤ κ) (hF : ∀ i, κ ≤ #(F i)) :
    ∃ B : Set α, ∀ i, (B ∩ F i).Nonempty ∧ (Bᶜ ∩ F i).Nonempty

    MathlibExt.SetTheory.Determinacy.exists_not_determined

    If the set of moves A is countable and has at least two elements, some payoff set S ⊆ A^ℕ is not determined. The proof diagonalises over the continuum many strategies, each of which has continuum many plays (Gale and Stewart, Infinite games with perfect information, Ann. of Math. Stud. 28 (1953); Moschovakis, Descriptive Set Theory, 2nd ed., AMS 2009, Exercise 6A.6, stated there for A = {0, 1}). It uses the axiom of choice, through a well-ordering of the strategies. With a single move every set is determined (determined_of_subsingleton).

    The proof well-orders the pairs (player, strategy) in order type at most 2^ℵ₀. A strategy has at least 2^ℵ₀ plays: against it the opponent can spell out any binary sequence, using two distinct moves. At each stage, fewer than 2^ℵ₀ plays have been chosen, so two fresh plays of the current strategy can be put into and out of S. Then no strategy of player I wins, because one of its plays lies outside S, and no strategy of player II wins, because one of its plays lies in S. The countability of A keeps the number of strategies at most 2^ℵ₀.

    theorem exists_not_determined {A : Type u} [Countable A] [Nontrivial A] :
    ∃ S : Set (ℕ → A), ¬ Determined S
    def Determined (S : Set (ℕ → A)) : Prop :=
  IWins S ∨ IIWins S

    MathlibExt.SetTheory.Determinacy.not_forall_determined

    Not every S ⊆ ℕ^ℕ is determined: the axiom of determinacy AD of Mycielski and Steinhaus is false in Lean's ambient logic, which includes the axiom of choice (Moschovakis, Descriptive Set Theory, 2nd ed., AMS 2009, Exercise 6A.6; Woodin, The continuum hypothesis, Part I, Notices AMS 48 (2001), section "Determinacy"). The proof only uses a well-ordering of the strategies, that is of the reals.

    In ZF the same argument shows that the axiom of determinacy refutes the existence of a well-ordering of the reals. AD is therefore studied in models of ZF without choice, such as L(ℝ) under large cardinal hypotheses. Woodin (Supercompact cardinals, sets of reals, and weakly homogeneous trees, PNAS 85 (1988)) showed, combined with work of Martin and Steel, that if there is a supercompact cardinal then every set of reals in L(ℝ) is determined. In Lean, consequences of AD are recorded pointclass by pointclass.

    theorem not_forall_determined : ¬ ∀ S : Set (ℕ → ℕ), Determined S
    def Determined (S : Set (ℕ → A)) : Prop :=
  IWins S ∨ IIWins S
