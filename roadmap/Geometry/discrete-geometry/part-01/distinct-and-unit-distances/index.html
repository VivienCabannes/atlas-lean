    distanceMultiplicity

    Let \(P\) be a finite set of points in a metric space and let \(d\) be a real number. The multiplicity of \(d\) in \(P\) is the number of unordered pairs \(\{p, q\}\) of distinct points of \(P\) with \(\operatorname{dist}(p, q) = d\).

    noncomputable def distanceMultiplicity (points : Finset X) (d : ℝ) : ℕ :=
  #(points.offDiag.filter fun (pair : X × X) => dist pair.1 pair.2 = d) / 2

    unitDistNum

    DefinitionMinimum number of distinct distances#✓fully proved

    minimalDistinctDistances

    Let \(X\) be a metric space and \(n\) a natural number such that \(X\) contains a set of exactly \(n\) points. The minimum number of distinct distances for \(n\) points in \(X\) is the least number of distinct distances determined by a set of exactly \(n\) points of \(X\).

    The hypothesis that some \(n\)-point set exists makes the minimum range over a nonempty collection of sets.

    noncomputable def minimalDistinctDistances (n : ℕ) (_ : ∃ points : Finset X, #points = n) : ℕ :=
  sInf {m : ℕ | ∃ points : Finset X, #points = n ∧ distinctDistances points = m}

    TheoremErdős's unit distance conjecture is false#●ready to prove

    MathlibExt.Combinatorics.UnitDistanceConjectureFalseWanted.Combinatorics.erdos_unit_distance_conjecture_false

    There is a real number \(\delta > 0\) such that for every natural number \(N\) there are an integer \(n \ge N\) and a set \(P\) of exactly \(n\) points in the Euclidean plane \(\mathbb{R}^2\) with at least \(n^{1+\delta}\) unordered pairs of points of \(P\) at distance exactly \(1\).

    Because \(C / \log \log n \to 0\) for every constant \(C\), this contradicts Erdős's conjecture that \(n\) points in the plane determine at most \(n^{1 + C / \log \log n}\) unit distances for some constant \(C\) and all large \(n\).

    public theorem_wanted erdos_unit_distance_conjecture_false :
    ∃ δ : ℝ, 0 < δ ∧
      ∀ N : ℕ, ∃ (n : ℕ) (P : Finset (EuclideanSpace ℝ (Fin 2))),
        N ≤ n ∧ P.card = n ∧ (n : ℝ) ^ (1 + δ) ≤ (unitDist P : ℝ)
    noncomputable abbrev unitDist (P : Finset (EuclideanSpace ℝ (Fin 2))) : ℕ := unitDistNum P
