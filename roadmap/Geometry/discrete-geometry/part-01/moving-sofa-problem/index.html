    MovingSofa.CanPass

    A set \(K \subseteq \mathbb{C}\) can pass the corridor if there are continuous maps \(u\) from \([0, 1]\) to the unit circle \(\{w \in \mathbb{C} : |w| = 1\}\) and \(c\) from \([0, 1]\) to \(\mathbb{C}\) such that, writing \(K_t = \{u(t) z + c(t) : z \in K\}\) for the position of \(K\) at time \(t\), \(K_0\) lies in the entrance arm, \(K_1\) lies in the exit arm, and \(K_t\) lies in the corridor for every \(t \in [0, 1]\).

    DefinitionSofa shapes#✓fully proved

    MovingSofa.IsSofa

    A set \(K \subseteq \mathbb{C}\) is a sofa when it is Lebesgue measurable, nonempty and connected, and can be moved through the unit right-angle corridor: there is a motion (a rotation by a unit complex number and a translation, both varying continuously with time \(t \in [0, 1]\)) that places \(K\) inside the corridor's entrance region at time \(0\), inside its exit region at time \(1\), and inside the corridor at every time \(t\).

    def IsSofa (K : Set ℂ) : Prop :=

    DefinitionOptimal sofa area#✓fully proved

    MovingSofa.optimalArea

    Let the corridor be \(L = \{z \in \mathbb{C} : \operatorname{Re} z \le 1,\ 0 \le \operatorname{Im} z \le 1\} \cup \{z \in \mathbb{C} : 0 \le \operatorname{Re} z \le 1,\ 0 \le \operatorname{Im} z\}\), with entrance \(E = \{z \in \mathbb{C} : \operatorname{Re} z \le 0,\ 0 \le \operatorname{Im} z \le 1\}\) and exit \(X = \{z \in \mathbb{C} : 0 \le \operatorname{Re} z \le 1,\ 1 \le \operatorname{Im} z\}\). A sofa is a nonempty connected Lebesgue-measurable set \(K \subseteq \mathbb{C}\) for which there are continuous maps \(u : [0, 1] \to \{w \in \mathbb{C} : |w| = 1\}\) and \(c : [0, 1] \to \mathbb{C}\) such that, writing \(K_t = \{u(t)\,z + c(t) : z \in K\}\), we have \(K_0 \subseteq E\), \(K_1 \subseteq X\) and \(K_t \subseteq L\) for every \(t \in [0, 1]\). The optimal sofa area is the supremum, taken in \([0, \infty]\), of the Lebesgue measures of all sofas.

    Because the supremum is taken in \([0, \infty]\), neither its finiteness nor its attainment is assumed.

    noncomputable def optimalArea : ℝ≥0∞ := ⨆ (K : Set ℂ) (_ : IsSofa K), volume K

    MovingSofa.corridorZ

    For a real number \(d\), the Z-shaped corridor with corner separation \(d\) is the set of points \(z \in \mathbb{C}\) lying in at least one of three pieces: the lower horizontal arm, where \(\operatorname{Re} z \le 1\) and \(0 \le \operatorname{Im} z \le 1\); the middle channel, where \(0 \le \operatorname{Re} z \le 1\) and \(0 \le \operatorname{Im} z \le 2 + d\); and the upper horizontal arm, where \(\operatorname{Re} z \ge 0\) and \(1 + d \le \operatorname{Im} z \le 2 + d\).

    DefinitionAmbidextrous sofa shapes#✓fully proved

    MovingSofa.IsAmbidextrousSofa

    A set \(K \subseteq \mathbb{C}\) is an ambidextrous sofa when it is a sofa and there is a real number \(D\) such that, for every corner separation \(d \ge D\), a single motion places \(K\) inside the entrance arm of the Z corridor with separation \(d\) at time \(0\), inside its exit arm at time \(1\), and inside that corridor at every time; such a passage turns once in each direction.
