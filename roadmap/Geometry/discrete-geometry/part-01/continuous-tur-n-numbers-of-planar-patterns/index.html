    DefinitionContainment of planar point sets#✓fully proved

    MetaMathlibExt.PointSetContainsPattern

    A set \(S \subseteq \mathbb{R}^2\) contains a set \(P \subseteq \mathbb{R}^2\) when there are maps \(f_X, f_Y : \mathbb{R} \to \mathbb{R}\) such that \(f_X(x_0) - f_X(x_1) \ge x_0 - x_1\) whenever \(x_0 > x_1\) are \(x\)-coordinates of points of \(P\), \(f_Y(y_0) - f_Y(y_1) \ge y_0 - y_1\) whenever \(y_0 > y_1\) are \(y\)-coordinates of points of \(P\), and \((f_X(x), f_Y(y)) \in S\) for every \((x, y) \in P\).

    public def PointSetContainsPattern (S P : Set (ℝ × ℝ)) : Prop :=
  ∃ fX fY : ℝ → ℝ,
    (∀ p ∈ P, ∀ q ∈ P, q.1 < p.1 → p.1 - q.1 ≤ fX p.1 - fX q.1) ∧
    (∀ p ∈ P, ∀ q ∈ P, q.2 < p.2 → p.2 - q.2 ≤ fY p.2 - fY q.2) ∧
    ∀ p ∈ P, (fX p.1, fY p.2) ∈ S

    MetaMathlibExt.opx

    For a real number \(n\) and a set \(P \subseteq \mathbb{R}^2\), the continuous Turán number \(\operatorname{opx}(n, P)\) is the supremum of the Lebesgue measures \(\mu_2(S)\) over all open sets \(S \subseteq [0, n]^2\) that do not contain \(P\) in the sense of point-set pattern containment; it is \(0\) when there is no such set.

    public noncomputable def opx (n : ℝ) (P : Set (ℝ × ℝ)) : ℝ :=
