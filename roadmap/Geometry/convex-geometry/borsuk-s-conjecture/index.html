    Metric.HasBorsukCover

    Let \(s\) be a set in an extended pseudometric space and let \(k\) be a natural number. The set \(s\) has a \(k\)-piece Borsuk cover if there are \(k\) sets whose union contains \(s\), each of extended diameter strictly smaller than that of \(s\).

    def HasBorsukCover {E : Type*} [PseudoEMetricSpace E] (k : ℕ) (s : Set E) : Prop :=
  ∃ c : Fin k → Set E, s ⊆ ⋃ i, c i ∧ ∀ i, ediam (c i) < ediam s

    The Borsuk number of a set \(s\) in the Euclidean space \(\mathbb{R}^n\) is the least natural number \(k\) such that \(s\) has a \(k\)-piece Borsuk cover, that is, \(s\) is covered by \(k\) sets each of strictly smaller extended diameter than \(s\); it is \(\infty\) if no such \(k\) exists.

    DefinitionTwo-distance sets#✓fully proved

    Metric.IsTwoDistanceSet

    A set \(s\) in the Euclidean space \(\mathbb{R}^n\) is a two-distance set if there are reals \(0 < a < b\) such that the distance between any two distinct points of \(s\) is \(a\) or \(b\), and both \(a\) and \(b\) occur as the distance between some two points of \(s\).

    def IsTwoDistanceSet {n : ℕ} (s : Set (EuclideanSpace ℝ (Fin n))) : Prop :=
  ∃ a b : ℝ, 0 < a ∧ a < b ∧
    (∀ x ∈ s, ∀ y ∈ s, x ≠ y → dist x y = a ∨ dist x y = b) ∧
    (∃ x ∈ s, ∃ y ∈ s, dist x y = a) ∧
    ∃ x ∈ s, ∃ y ∈ s, dist x y = b
