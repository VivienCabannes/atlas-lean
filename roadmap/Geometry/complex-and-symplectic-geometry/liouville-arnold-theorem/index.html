    DefinitionStandard Poisson bracket on \(\mathbb{R}^{2n}\)#✓fully proved

    MathlibExt.Geometry.LiouvilleArnoldWanted.Geometry.LiouvilleArnold.poissonBracket

    Write the coordinates of a point \(x \in \mathbb{R}^{2n}\) as \(p_i = x_i\) and \(q_i = x_{n+i}\) for \(i = 0, \dots, n-1\). For functions \(F, G \colon \mathbb{R}^{2n} \to \mathbb{R}\), the Poisson bracket for the symplectic form \(\omega_0 = \sum_i dp_i \wedge dq_i\) is the function

    \[ \{F, G\}(x) = \sum_{i=0}^{n-1} \left( \frac{\partial F}{\partial p_i}(x) \frac{\partial G}{\partial q_i}(x) - \frac{\partial F}{\partial q_i}(x) \frac{\partial G}{\partial p_i}(x) \right). \]

    Partial derivatives are read off the Fréchet derivative, which is taken to be zero at points where the function is not differentiable.

    noncomputable def poissonBracket {n : ℕ} (F G : E n → ℝ) (x : E n) : ℝ :=
  ∑ i : Fin n,
    (fderiv ℝ F x (EuclideanSpace.single (idxP i) (1 : ℝ)) *
        fderiv ℝ G x (EuclideanSpace.single (idxQ i) (1 : ℝ))
      - fderiv ℝ F x (EuclideanSpace.single (idxQ i) (1 : ℝ)) *
        fderiv ℝ G x (EuclideanSpace.single (idxP i) (1 : ℝ)))
    abbrev E (n : ℕ) := EuclideanSpace ℝ (Fin (2 * n))

    MathlibExt.Geometry.LiouvilleArnoldWanted.Geometry.LiouvilleArnold.IsLiouvilleIntegrable

    Functions \(F_0, \dots, F_{n-1} \colon \mathbb{R}^{2n} \to \mathbb{R}\) are Liouville integrable on a set \(U \subseteq \mathbb{R}^{2n}\) if each \(F_i\) is \(C^\infty\) on \(U\), the Poisson brackets \(\{F_i, F_j\}\) vanish at every point of \(U\) for all \(i, j\), and at every \(x \in U\) the Fréchet derivatives \(dF_0(x), \dots, dF_{n-1}(x)\) are linearly independent over \(\mathbb{R}\).

    The set \(U\) is not required to be open; the Liouville–Arnold theorem assumes this separately.

    def IsLiouvilleIntegrable {n : ℕ} (F : Fin n → E n → ℝ) (U : Set (E n)) : Prop :=
  (∀ i, ContDiffOn ℝ ∞ (F i) U) ∧
  (∀ i j, ∀ x ∈ U, poissonBracket (F i) (F j) x = 0) ∧
  (∀ x ∈ U, LinearIndependent ℝ (fun i => fderiv ℝ (F i) x))
    abbrev E (n : ℕ) := EuclideanSpace ℝ (Fin (2 * n))

    MathlibExt.Geometry.LiouvilleArnoldWanted.Geometry.LiouvilleArnold.liouville_arnold

    Let \(U \subseteq \mathbb{R}^{2n}\) be open and let \(F_0, \dots, F_{n-1} \colon \mathbb{R}^{2n} \to \mathbb{R}\) be Liouville integrable on \(U\). For \(c = (c_0, \dots, c_{n-1}) \in \mathbb{R}^n\), let \(M_c = \{x \in \mathbb{R}^{2n} : F_i(x) = c_i \text{ for all } i\}\) be the common level set. If \(M_c \subseteq U\) and \(M_c\) is compact and connected (in particular nonempty), then \(M_c\) is homeomorphic to the \(n\)-torus \((\mathbb{R}/\mathbb{Z})^n\).

    The hypotheses compact and connected on the level set, and its containment in the open set where the derivatives are independent, restore standard regularity assumptions that Knill elides; without them the conclusion fails.
