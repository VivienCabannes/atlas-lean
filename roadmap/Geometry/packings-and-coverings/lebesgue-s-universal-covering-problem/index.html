    DefinitionCovering a congruent copy#✓fully proved

    MathlibExt.Geometry.LebesgueUniversalCoveringConstantWanted.CoversCongruentCopy

    A planar set \(\Omega\) covers a congruent copy of a planar set \(K\) when some isometry \(e\) of the plane onto itself satisfies \(e(K) \subseteq \Omega\).

    Isometries include reflections.

    def CoversCongruentCopy (Ω K : Set Plane) : Prop :=
  ∃ e : Plane ≃ᵢ Plane, e '' K ⊆ Ω

    DefinitionUniversal convex covers#✓fully proved

    MathlibExt.Geometry.LebesgueUniversalCoveringConstantWanted.IsUniversalConvexCover

    A set \(\Omega\) in the Euclidean plane \(\mathbb{R}^2\) is a universal convex cover when it is nonempty and convex and, for every nonempty convex set \(K \subseteq \mathbb{R}^2\) of diameter \(1\), some isometry \(e\) of the plane onto itself satisfies \(e(K) \subseteq \Omega\).

    def IsUniversalConvexCover (Ω : Set Plane) : Prop :=

    DefinitionLebesgue universal covering constant#✓fully proved

    MathlibExt.Geometry.LebesgueUniversalCoveringConstantWanted.lebesgueUniversalCoveringConstant

    Call a set \(\Omega\) in the Euclidean plane \(\mathbb{R}^2\) a universal convex cover if it is nonempty and convex and, for every nonempty convex set \(K \subseteq \mathbb{R}^2\) of diameter exactly \(1\), some isometry of the plane onto itself maps \(K\) into \(\Omega\). The Lebesgue universal covering constant is the infimum, taken in \([0, \infty]\), of the Lebesgue areas of all universal convex covers; the infimum of an empty family would be \(\infty\).

    The definition does not assume that a universal convex cover of minimal area exists.

    def lebesgueUniversalCoveringConstant : ENNReal :=
  sInf admissibleCoverAreas
    def admissibleCoverAreas : Set ENNReal :=
  {a | ∃ Ω : Set Plane, IsUniversalConvexCover Ω ∧ planarArea Ω = a}

    DefinitionDirectional width#✓fully proved

    MathlibExt.Geometry.LebesgueUniversalCoveringConstantWanted.directionalWidth

    For a planar set \(K\) and a vector \(u\) in the plane, the width of \(K\) in direction \(u\) is \(\sup_{x \in K} \langle u, x \rangle - \inf_{x \in K} \langle u, x \rangle\), where the supremum and infimum are taken in \(\mathbb{R}\), with the convention that each is \(0\) when the set of values \(\langle u, x \rangle\) is empty or unbounded on that side.

    It is only applied to nonempty compact \(K\), where both extrema are attained.

    def directionalWidth (K : Set Plane) (u : Plane) : ℝ :=
  sSup ((fun x : Plane => inner ℝ u x) '' K) -
    sInf ((fun x : Plane => inner ℝ u x) '' K)
    abbrev Plane := EuclideanSpace ℝ (Fin 2)

    DefinitionSets of constant width one#✓fully proved

    MathlibExt.Geometry.LebesgueUniversalCoveringConstantWanted.IsConstantWidthOne

    A set \(K\) in the Euclidean plane \(\mathbb{R}^2\) has constant width \(1\) when it is nonempty, compact and convex and, for every unit vector \(u\), its width in direction \(u\), namely \(\sup_{x \in K} \langle u, x \rangle - \inf_{x \in K} \langle u, x \rangle\), equals \(1\).

    def IsConstantWidthOne (K : Set Plane) : Prop :=
  K.Nonempty ∧ IsCompact K ∧ Convex ℝ K ∧
    ∀ u : Plane, ‖u‖ = 1 → directionalWidth K u = 1
    abbrev Plane := EuclideanSpace ℝ (Fin 2)

    DefinitionStatement of the existence of a minimal universal convex cover#✓fully proved

    MathlibExt.Geometry.LebesgueUniversalCoveringConstantWanted.elekes1994MinimalCoverExists

    This proposition states that some nonempty convex set \(\Omega\) in the Euclidean plane \(\mathbb{R}^2\) is a universal convex cover, that is, for every nonempty convex set \(K \subseteq \mathbb{R}^2\) of diameter \(1\) some isometry \(e\) of the plane onto itself satisfies \(e(K) \subseteq \Omega\), and that the area (planar Lebesgue measure) of \(\Omega\) equals the Lebesgue universal covering constant, the infimum of the areas of all universal convex covers.
