    For natural numbers \(k\) and \(n\), the Morse quadratic form of index \(k\) on \(\mathbb{R}^n\), with coordinates \(v_0, \dots, v_{n-1}\), is the function \(Q_{k,n} \colon \mathbb{R}^n \to \mathbb{R}\) given by \(Q_{k,n}(v) = \sum_{i=0}^{n-1} \varepsilon_i v_i^2\), where \(\varepsilon_i = -1\) if \(i < k\) and \(\varepsilon_i = 1\) if \(i \ge k\). In particular, if \(k \ge n\) every coefficient is \(-1\).

    def morseQuadratic (k n : ℕ) (v : EuclideanSpace ℝ (Fin n)) : ℝ :=
  ∑ i : Fin n, (if (i : ℕ) < k then (-1 : ℝ) else 1) * (v i) ^ 2

    DefinitionMorse function#✓fully proved

    MathlibExt.Geometry.Manifold.ReebSphereWanted.IsMorseFunction

    Let \(M\) be a \(C^\infty\) manifold without boundary modelled on a real normed space of finite dimension \(d\). A function \(f \colon M \to \mathbb{R}\) is a Morse function if it is \(C^\infty\) and, for every critical point \(p\) of \(f\) (a point where the differential \(df_p\) is zero), there exist an integer \(0 \le k \le d\), a map \(\varphi \colon M \to \mathbb{R}^d\) that is a local \(C^\infty\) diffeomorphism at \(p\) with \(\varphi(p) = 0\), and an open set \(U\) containing \(p\) such that \(f(q) = f(p) + Q_k(\varphi(q))\) for all \(q \in U\). Here \(Q_k\) is the Morse quadratic form \(Q_k(y) = -y_1^2 - \dots - y_k^2 + y_{k+1}^2 + \dots + y_d^2\) on \(\mathbb{R}^d\).

    def IsMorseFunction (f : M → ℝ) : Prop :=
  ContMDiff I (𝓘(ℝ, ℝ)) (⊤ : ℕ∞) f ∧
    ∀ p : M, mfderiv I (𝓘(ℝ, ℝ)) f p = 0 →
      ∃ (k : ℕ) (_ : k ≤ Module.finrank ℝ E)
        (φ : M → EuclideanSpace ℝ (Fin (Module.finrank ℝ E))),
        IsLocalDiffeomorphAt I (𝓘(ℝ, EuclideanSpace ℝ (Fin (Module.finrank ℝ E))))
            (⊤ : ℕ∞) φ p ∧
          φ p = 0 ∧
            ∃ (U : Set M) (_ : IsOpen U) (_ : p ∈ U),
              ∀ q ∈ U, f q = f p + morseQuadratic k (Module.finrank ℝ E) (φ q)

    TheoremMorse lemma#✓fully proved

    MathlibExt.Geometry.Manifold.MorseLemmaWanted.morse_lemma

    Let \(f \colon \mathbb{R}^n \to \mathbb{R}\) be a \(C^\infty\) function with \(Df(0) = 0\) whose Hessian at \(0\) is nondegenerate: if \(v \in \mathbb{R}^n\) satisfies \(D^2 f(0)(v, w) = 0\) for all \(w \in \mathbb{R}^n\), then \(v = 0\). Then there exist an integer \(0 \le k \le n\), a map \(\varphi \colon \mathbb{R}^n \to \mathbb{R}^n\) that is a local \(C^\infty\) diffeomorphism at \(0\) with \(\varphi(0) = 0\), and an open set \(U\) containing \(0\) such that \(f(x) = f(0) + Q_k(\varphi(x))\) for all \(x \in U\). Here \(Q_k\) is the Morse quadratic form \(Q_k(y) = -y_1^2 - \dots - y_k^2 + y_{k+1}^2 + \dots + y_n^2\) on \(\mathbb{R}^n\).

    theorem morse_lemma

    (hcrit : fderiv ℝ f (0 : EuclideanSpace ℝ (Fin n)) = 0)

      (∀ w : EuclideanSpace ℝ (Fin n),
        (fderiv ℝ (fderiv ℝ f) (0 : EuclideanSpace ℝ (Fin n)) v) w = 0) → v = 0) :
    ∃ (k : ℕ) (_hk : k ≤ n) (φ : EuclideanSpace ℝ (Fin n) → EuclideanSpace ℝ (Fin n)),

        ∀ x ∈ U, f x = f (0 : EuclideanSpace ℝ (Fin n)) + morseQuadratic k n (φ x)

    MathlibExt.Geometry.MorseInequalitiesWanted.Geometry.MorseInequalities.morse_inequality

    Let \(M\) be a compact Hausdorff smooth manifold without boundary, modelled on a finite-dimensional real normed space, and let \(f : M \to \mathbb{R}\) be a Morse function: \(f\) is \(C^\infty\), has finitely many critical points, and the Hessian of \(f\) at each critical point, computed in the preferred chart, is a nondegenerate bilinear form. The Morse index of a critical point is the largest dimension of a subspace on which this Hessian is negative definite. For \(j \in \mathbb{N}\) let \(c_j\) be the number of critical points of \(f\) of Morse index \(j\), and let \(b_j\) be the dimension of the singular homology \(H_j(M; \mathbb{R})\) (taken to be \(0\) if infinite). Then for every \(k \in \mathbb{N}\),

    \[\sum_{j=0}^{k} (-1)^{k-j} b_j \le \sum_{j=0}^{k} (-1)^{k-j} c_j.\]
