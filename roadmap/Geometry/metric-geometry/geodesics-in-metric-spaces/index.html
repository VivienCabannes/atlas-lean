    Metric.IsGeodesicOnWithSpeed

    Let \(X\) be a pseudo-extended metric space with extended distance \(d\), let \(\gamma : \mathbb{R} \to X\) be a curve, \(s \subseteq \mathbb{R}\) a set of times and \(c \ge 0\) a real number. The curve \(\gamma\) is a geodesic of speed \(c\) on \(s\) if every \(t \in s\) has some \(\varepsilon > 0\) such that \(d(\gamma(t_1), \gamma(t_2)) = c\,|t_1 - t_2|\) for all \(t_1, t_2 \in s\) with \(|t_1 - t| < \varepsilon\) and \(|t_2 - t| < \varepsilon\).

    def IsGeodesicOnWithSpeed (γ : ℝ → X) (s : Set ℝ) (c : ℝ≥0) : Prop :=
  ∀ t ∈ s, ∃ ε > (0 : ℝ), ∀ t₁ ∈ s, ∀ t₂ ∈ s, |t₁ - t| < ε → |t₂ - t| < ε →
    edist (γ t₁) (γ t₂) = c * edist t₁ t₂

    Metric.IsGeodesicOn

    Let \(X\) be a pseudo-extended metric space. A curve \(\gamma : \mathbb{R} \to X\) is a geodesic on a set of times \(s \subseteq \mathbb{R}\) if, for some real number \(c \ge 0\), it is a geodesic of speed \(c\) on \(s\).

    On a Riemannian manifold without boundary, with its Riemannian distance, every Riemannian geodesic is a geodesic in this sense, and the piecewise \(C^1\) geodesics in this sense are the Riemannian geodesics.

    def IsGeodesicOn (γ : ℝ → X) (s : Set ℝ) : Prop :=
  ∃ c : ℝ≥0, IsGeodesicOnWithSpeed γ s c

    Metric.IsClosedGeodesic

    Let \(X\) be a pseudo-extended metric space. A curve \(\gamma : \mathbb{R} \to X\) is a closed geodesic if it is a geodesic defined on all of \(\mathbb{R}\), it is periodic with some period \(T > 0\) (that is, \(\gamma(t + T) = \gamma(t)\) for all \(t \in \mathbb{R}\)), and it is not constant: \(\gamma(t_1) \ne \gamma(t_2)\) for some \(t_1, t_2 \in \mathbb{R}\).

    Periodicity of a geodesic defined on all of \(\mathbb{R}\) encodes both \(\gamma(0) = \gamma(T)\) and the matching of the velocities at \(0\) and \(T\). For a closed geodesic of speed \(1\), every period \(T > 0\) is the length of \(\gamma\) traversed over one period; its smallest positive period is the length of the underlying prime closed geodesic.

    def IsClosedGeodesic (γ : ℝ → X) : Prop :=
  IsGeodesic γ ∧ (∃ T > 0, Function.Periodic γ T) ∧ ∃ t₁ t₂, γ t₁ ≠ γ t₂
    def IsGeodesic (γ : ℝ → X) : Prop :=
  IsGeodesicOn γ univ

    Metric.IsGeodesicSegment

    A map γ : ℝ → X is a geodesic segment from x to y if γ 0 = x, γ (dist x y) = y and dist (γ s) (γ t) = |s - t| for all s t ∈ [0, dist x y]: it is an isometry from [0, dist x y] onto its image (Gromov, Hyperbolic groups, 1987, §1.6).

    def IsGeodesicSegment (γ : ℝ → X) (x y : X) : Prop :=
  γ 0 = x ∧ γ (dist x y) = y ∧
    ∀ s ∈ Icc 0 (dist x y), ∀ t ∈ Icc 0 (dist x y), dist (γ s) (γ t) = |s - t|

    DefinitionGeodesic metric space#✓fully proved

    Metric.IsGeodesicSpace

    A pseudometric space \(X\) is geodesic if any two points \(x, y\) are joined by a geodesic segment: a map \(\gamma : \mathbb{R} \to X\) with \(\gamma(0) = x\), \(\gamma(d(x, y)) = y\) and \(d(\gamma s, \gamma t) = |s - t|\) for \(s, t \in [0, d(x, y)]\).

    A segment between two points at distance \(0\) is constant, so a pseudometric space with two distinct points at distance \(0\) is never geodesic: the notion is meant for metric spaces. These segments realise the distance globally, unlike the local geodesics of this topic (IsGeodesicOn), which only realise it near each time. Real normed spaces are geodesic, and so is every connected complete Riemannian manifold (Hopf–Rinow, Gromov's 1.6.A; not proved: the repository's wanted Hopf–Rinow entry states the equivalence of geodesic and metric completeness, not this existence of minimising geodesics). Geodesic spaces are the setting of the thin-triangle description of hyperbolicity and of the Švarc–Milnor lemma.

    def IsGeodesicSpace (X : Type*) [PseudoMetricSpace X] : Prop :=
  ∀ x y : X, ∃ γ : ℝ → X, IsGeodesicSegment γ x y
