    DefinitionImmediate basin of zero#✓fully proved

    MathlibExt.Dynamics.CubicParameterJordanBoundaryWanted.IsImmediateBasin

    For \(\lambda \in \mathbb{C}\), a set \(V \subseteq \mathbb{C}\) is the immediate basin of zero of \(f_\lambda(z) = \lambda z^2 + z^3\) when \(0 \in V\), \(V\) is contained in the basin of zero of \(f_\lambda\) (the set of \(z\) with \(f_\lambda^{n}(z) \to 0\)), \(V\) is connected, and every connected set \(W \subseteq \mathbb{C}\) with \(0 \in W\) that is contained in the basin of zero of \(f_\lambda\) satisfies \(W \subseteq V\). Thus \(V\) is the connected component of \(0\) in the basin of zero.

    def IsImmediateBasin (lam : ℂ) (V : Set ℂ) : Prop :=
  (0 : ℂ) ∈ V ∧ V ⊆ basinOfZero lam ∧ IsConnected V ∧
    ∀ W : Set ℂ, (0 : ℂ) ∈ W → W ⊆ basinOfZero lam → IsConnected W → W ⊆ V

    DefinitionParameters with both critical points in the immediate basin#✓fully proved

    MathlibExt.Dynamics.CubicParameterJordanBoundaryWanted.parameterSet

    The parameter set is the set of \(\lambda \in \mathbb{C}\) for which some immediate basin of zero \(V\) of \(f_\lambda(z) = \lambda z^2 + z^3\) contains every critical point of \(f_\lambda\).

    Since \(f_\lambda'(z) = z(3z + 2\lambda)\), the critical points of \(f_\lambda\) are \(0\) and \(-2\lambda/3\) (equal when \(\lambda = 0\)), so this asks that both finite critical points lie in the immediate basin of zero.

    def parameterSet : Set ℂ :=
  {lam | ∃ V : Set ℂ, IsImmediateBasin lam V ∧ ∀ c : ℂ, IsCriticalPoint lam c → c ∈ V}

    MathlibExt.Dynamics.CubicParameterJordanBoundaryWanted.conjecture_holds

    For the cubic family \(f_\lambda(z) = \lambda z^2 + z^3\) with \(\lambda \in \mathbb{C}\), the boundary of every parameter component is a Jordan curve. Here a parameter component is a connected component of the set of \(\lambda\) for which every critical point of \(f_\lambda\) lies in the immediate basin of zero of \(f_\lambda\).

    Roesch (Theorem 2) proves that the boundary of every component of \(H = \{a : -a \text{ lies in the basin of } 0\}\) for the family \(z^{d-1}(z + da/(d-1))\) is a Jordan curve; at \(d = 3\) the linear change \(\lambda = 3a/2\) carries the central component \(H_0\) onto the parameter component.
