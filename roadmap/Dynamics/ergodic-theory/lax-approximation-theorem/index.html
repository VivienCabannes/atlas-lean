    DefinitionEssential-supremum distance between volume-preserving maps#✓fully proved

    MathlibExt.Dynamics.LaxApproximationWanted.Dynamics.LaxApproximation.deltaDist

    Let \(d\) be a natural number and let \(T\) and \(S\) be measurable, invertible, volume-preserving transformations of the torus \(\mathbb{T}^d = (\mathbb{R}/\mathbb{Z})^d\). Let \(\rho\) be the distance on \(\mathbb{T}^d\) given by the maximum over the coordinates of the distance on the circle \(\mathbb{R}/\mathbb{Z}\) (taken to be \(0\) when \(d = 0\)). The distance \(\delta(T, S) \in [0, \infty]\) is the essential supremum, with respect to the volume measure, of the function \(x \mapsto \rho(T x, S x)\).

    This is Knill's metric \(\delta\).

    noncomputable def deltaDist {d : ℕ} (T S : VolumePreservingEquiv d) : ℝ≥0∞ :=
  essSup (fun x => edist (T.toMeasurableEquiv x) (S.toMeasurableEquiv x)) (volume : Measure (Torus d))

    MathlibExt.Dynamics.LaxApproximationWanted.Dynamics.LaxApproximation.cube

    Let \(n\) and \(d\) be natural numbers and let \(k = (k_0, \dots, k_{d-1})\) with each \(k_i \in \{0, \dots, n-1\}\). The grid cube with index \(k\) is the set of points \(x\) of the torus \(\mathbb{T}^d = (\mathbb{R}/\mathbb{Z})^d\) such that, for every \(i < d\), the coordinate \(x_i\) is the class modulo \(1\) of some real number \(r\) with \(k_i/n \le r < (k_i + 1)/n\).

    def cube (n : ℕ) {d : ℕ} (k : Fin d → Fin n) : Set (Torus d) :=
  { x | ∀ i, ∃ r : ℝ, (k i : ℝ) / n ≤ r ∧ r < ((k i : ℝ) + 1) / n ∧
        x i = ((r : ℝ) : AddCircle (1 : ℝ)) }

    DefinitionCoordinate shift between grid cubes#✓fully proved

    MathlibExt.Dynamics.LaxApproximationWanted.Dynamics.LaxApproximation.cubeShift

    Let \(n\) and \(d\) be natural numbers, let \(\sigma\) be a permutation of the index set \(\{0, \dots, n-1\}^d\), let \(k\) be an index and let \(i < d\). The shift along axis \(i\) determined by \(\sigma\) and \(k\) is the point \((\sigma(k)_i - k_i)/n\) of the circle \(\mathbb{R}/\mathbb{Z}\), that is, the class modulo \(1\) of this real number.

    For an index \(j\), the grid cube with index \(j\) is the set of points of the torus \((\mathbb{R}/\mathbb{Z})^d\) whose \(m\)-th coordinate is the class of a real number in \([j_m/n, (j_m + 1)/n)\) for every \(m < d\). For \(n > 0\), translating the \(m\)-th coordinate of each point of the grid cube with index \(k\) by the shift along axis \(m\), for every \(m < d\), carries that cube onto the grid cube with index \(\sigma(k)\).

    noncomputable def cubeShift (n : ℕ) {d : ℕ}
    (σ : Equiv.Perm (Fin d → Fin n))
    (k : Fin d → Fin n) (i : Fin d) : AddCircle (1 : ℝ) :=
  ((((((σ k) i : ℤ) - (k i : ℤ) : ℝ) / (n : ℝ)) : ℝ) : AddCircle (1 : ℝ))

    DefinitionCyclic cube exchange#✓fully proved

    MathlibExt.Dynamics.LaxApproximationWanted.Dynamics.LaxApproximation.IsCyclicCubeExchange

    Let \(n\) and \(d\) be natural numbers. For an index \(k \in \{0, \dots, n-1\}^d\), the grid cube with index \(k\) is the set of points of the torus \(\mathbb{T}^d = (\mathbb{R}/\mathbb{Z})^d\) whose \(i\)-th coordinate is the class of a real number in \([k_i/n, (k_i + 1)/n)\) for every \(i < d\). A measurable, invertible, volume-preserving transformation \(T\) of \(\mathbb{T}^d\) is a cyclic cube exchange with \(n\) subdivisions if \(n > 0\) and there is a permutation \(\sigma\) of \(\{0, \dots, n-1\}^d\) that is a single cycle moving every index, such that for every index \(k\), every point \(x\) of the grid cube with index \(k\) and every \(i < d\), we have \((T x)_i = x_i + (\sigma(k)_i - k_i)/n\) in \(\mathbb{R}/\mathbb{Z}\). Thus \(T\) translates each grid cube \(k\) rigidly onto the grid cube \(\sigma(k)\).

    def IsCyclicCubeExchange {d : ℕ} (T : VolumePreservingEquiv d) (n : ℕ) : Prop :=
  0 < n ∧ ∃ σ : Equiv.Perm (Fin d → Fin n),
    σ.IsCycle ∧ σ.support = Finset.univ ∧
    ∀ k : Fin d → Fin n, ∀ x ∈ cube n k, ∀ i,
      T.toMeasurableEquiv x i = x i + cubeShift n σ k i

    TheoremLax's approximation theorem#●ready to prove

    MathlibExt.Dynamics.LaxApproximationWanted.Dynamics.LaxApproximation.lax_approximation

    Let \(d \ge 1\) be a natural number and let \(T\) be a toral dynamical system on the torus \(\mathbb{T}^d = (\mathbb{R}/\mathbb{Z})^d\), regarded as a measurable, invertible, volume-preserving transformation of \(\mathbb{T}^d\). Then for every \(\varepsilon \in (0, \infty]\) there are a natural number \(n\) and a measurable, invertible, volume-preserving transformation \(S\) of \(\mathbb{T}^d\) such that \(S\) is a cyclic cube exchange with \(n\) subdivisions and \(\delta(T, S) < \varepsilon\), where \(\delta\) is the essential-supremum distance between volume-preserving maps.

    public theorem_wanted lax_approximation {d : ℕ} (hd : 0 < d) (T : ToralDynamicalSystem d)
    {ε : ℝ≥0∞} (hε : 0 < ε) :
    ∃ (n : ℕ) (S : VolumePreservingEquiv d),
      IsCyclicCubeExchange S n ∧ deltaDist T.toVolumePreservingEquiv S < ε
