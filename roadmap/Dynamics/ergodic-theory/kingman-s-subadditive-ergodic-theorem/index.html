    TheoremKingman's subadditive ergodic theorem (nonnegative case)#✓fully proved

    MathlibExt.Dynamics.Ergodic.KingmanWanted.kingman_subadditive

    Let \(\mu\) be a probability measure on a measurable space \(\alpha\) and let \(T : \alpha \to \alpha\) preserve \(\mu\). Let \((f_n)_{n \in \mathbb{N}}\) be functions \(\alpha \to \mathbb{R}\), each measurable and \(\mu\)-integrable, such that for every \(n\) the inequality \(f_n \ge 0\) holds \(\mu\)-almost everywhere, \(f_0 = 0\) holds \(\mu\)-almost everywhere, and for all natural numbers \(m\) and \(n\) the inequality \(f_{m+n}(x) \le f_m(x) + f_n(T^m x)\) holds for \(\mu\)-almost every \(x\). Then there is a \(\mu\)-integrable function \(g : \alpha \to \mathbb{R}\) such that \(g(T x) = g(x)\) for \(\mu\)-almost every \(x\) and \(f_n(x)/n\) converges to \(g(x)\) as \(n \to \infty\) for \(\mu\)-almost every \(x\).

    theorem kingman_subadditive
    {α : Type*} [MeasurableSpace α] {μ : Measure α} [IsProbabilityMeasure μ]
    {T : α → α} (hT : MeasurePreserving T μ μ)
    (f : ℕ → α → ℝ)
    (hf_meas : ∀ n, Measurable (f n))
    (hf_int : ∀ n, Integrable (f n) μ)
    (hf_nonneg : ∀ n, ∀ᵐ x ∂μ, 0 ≤ f n x)
    (hf_zero : ∀ᵐ x ∂μ, f 0 x = 0)
    (hf_subadd : ∀ m n, ∀ᵐ x ∂μ, f (m + n) x ≤ f m x + f n ((T^[m]) x)) :
    ∃ g : α → ℝ, Integrable g μ ∧ (∀ᵐ x ∂μ, g (T x) = g x) ∧
      ∀ᵐ x ∂μ, Tendsto (fun n : ℕ => f n x / (n : ℝ)) atTop (nhds (g x))
