    MathlibExt.Dynamics.Ergodic.BirkhoffWanted.maximal_ergodic

    Let \(\mu\) be a finite measure on a measurable space \(\alpha\), let \(T : \alpha \to \alpha\) preserve \(\mu\), and let \(f : \alpha \to \mathbb{R}\) be measurable and \(\mu\)-integrable. For a natural number \(n\) write \(S_n f(x) = \sum_{k=0}^{n-1} f(T^k x)\). Then the integral of \(f\) with respect to \(\mu\) over the set of points \(x \in \alpha\) such that \(S_n f(x) > 0\) for some natural number \(n\) is nonnegative.

    theorem maximal_ergodic
    {α : Type*} [MeasurableSpace α] {μ : Measure α} [IsFiniteMeasure μ]
    {T : α → α} (hT : MeasurePreserving T μ μ)
    {f : α → ℝ} (hf : Measurable f) (hfi : Integrable f μ) :
    0 ≤ ∫ x in {x | ∃ n, 0 < birkhoffSum T f n x}, f x ∂μ

    DefinitionMaximal divergence set#✓fully proved

    MathlibExt.Dynamics.Ergodic.BirkhoffWanted.DickSet

    Let \(\alpha\) be a measurable space, \(T : \alpha \to \alpha\) a map, \(g : \alpha \to \mathbb{R}\) a function and \(c\) a real number. The maximal divergence set of \(T\), \(g\) and \(c\) is the set of points \(x \in \alpha\) for which there is a rational number \(q > c\) such that \(n q < \sum_{k=0}^{n-1} g(T^k x)\) for infinitely many natural numbers \(n\).

    noncomputable def DickSet {α : Type*} [MeasurableSpace α]
    (T : α → α) (g : α → ℝ) (c : ℝ) : Set α :=
  ⋃ (q : ℚ) (_ : c < (q : ℝ)), ⋂ (N : ℕ), ⋃ (n : ℕ) (_ : N ≤ n),
    {x | (n : ℝ) * (q : ℝ) < birkhoffSum T g n x}

    Let \(\alpha\) be a measurable space, \(T : \alpha \to \alpha\) a map, \(g : \alpha \to \mathbb{R}\) a function, \(c\) a real number, and \(D \subseteq \alpha\) a set such that for every natural number \(k\) and every \(x \in \alpha\), \(T^k x \in D\) if and only if \(x \in D\).     MathlibExt.Dynamics.Ergodic.BirkhoffWanted.birkhoff_pointwise_ergodic

    Let \(\mu\) be a probability measure on a measurable space \(\alpha\), let \(T : \alpha \to \alpha\) be ergodic with respect to \(\mu\) (in particular \(T\) preserves \(\mu\)), and let \(g : \alpha \to \mathbb{R}\) be \(\mu\)-integrable.     theorem birkhoff_pointwise_ergodic
    {α : Type*} [MeasurableSpace α] {μ : Measure α} [IsProbabilityMeasure μ]
    {T : α → α} (hT : Ergodic T μ)
    {g : α → ℝ} (hg : Integrable g μ) :
    ∀ᵐ x ∂μ, Filter.Tendsto (fun n => birkhoffAverage ℝ T g n x) Filter.atTop
      (nhds (∫ y, g y ∂μ))
