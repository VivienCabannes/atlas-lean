    MetaMathlibExt.FiniteWeight.marginal

    Let \(V\) and \(\alpha\) be finite types, a configuration being a map \(x : V \to \alpha\), and let \(p\) be a real-valued weight on configurations. The (unnormalized) marginal of \(p\) on a set of variables \(U \subseteq V\) at a configuration \(x\) is

    \[\sum_{y \,:\, y(v) = x(v) \text{ for all } v \in U} p(y),\]

    the total weight of the configurations that agree with \(x\) on \(U\).

    noncomputable def marginal (p : (V → α) → ℝ) (U : Set V) (x : V → α) : ℝ :=
  ∑ y ∈ univ.filter (fun y : V → α => ∀ v ∈ U, y v = x v), p y

    MetaMathlibExt.FiniteWeight.CondIndep

    Let \(V\) and \(\alpha\) be finite types, let \(p\) be a real-valued weight on the configurations \(x : V \to \alpha\), and for \(U \subseteq V\) write \(p(x_U)\) for the marginal of \(p\) on \(U\) at \(x\), the total weight of the configurations that agree with \(x\) on \(U\). For \(A, B, S \subseteq V\), the variables in \(A\) and in \(B\) are conditionally independent given those in \(S\) under \(p\) when

    \[p(x_{A \cup B \cup S})\, p(x_S) = p(x_{A \cup S})\, p(x_{B \cup S})\]

    for every configuration \(x\).

    MetaMathlibExt.FiniteWeight.CondIndep.cond_eq_mul

    Let \(V\) and \(\alpha\) be finite types, let \(p\) be a real-valued weight on the configurations \(x : V \to \alpha\), and for \(U \subseteq V\) write \(p(x_U)\) for the marginal of \(p\) on \(U\) at \(x\). If, for \(A, B, S \subseteq V\), the variables in \(A\) and in \(B\) are conditionally independent given those in \(S\) under \(p\), then every configuration \(x\) with \(p(x_S) \ne 0\) satisfies

    \[\frac{p(x_{A\cup B\cup S})}{p(x_S)} = \frac{p(x_{A\cup S})}{p(x_S)}\frac{p(x_{B\cup S})}{p(x_S)}\]

    For a nonnegative weight of positive total mass these ratios are the conditional probabilities of the normalized distribution, so this is \(P(x_A, x_B \mid x_S) = P(x_A \mid x_S)\, P(x_B \mid x_S)\).

    theorem CondIndep.cond_eq_mul {p : (V → α) → ℝ} {A B S : Set V} (h : CondIndep p A B S)
    {x : V → α} (hx : marginal p S x ≠ 0) :
    marginal p (A ∪ B ∪ S) x / marginal p S x =
      (marginal p (A ∪ S) x / marginal p S x) * (marginal p (B ∪ S) x / marginal p S x)
    def CondIndep (p : (V → α) → ℝ) (A B S : Set V) : Prop :=
  ∀ x, marginal p (A ∪ B ∪ S) x * marginal p S x = marginal p (A ∪ S) x * marginal p (B ∪ S) x

    TheoremMarginals of a product#✓fully proved

    MetaMathlibExt.FiniteWeight.marginal_mul

    Let \(V\) and \(\alpha\) be finite types, let \(f\) and \(g\) be real-valued weights on the configurations \(x : V \to \alpha\), and let \(P, Q, U \subseteq V\) with \(P \cup Q = V\) and \(P \cap Q \subseteq U\), such that \(f(x)\) depends only on the values of \(x\) on \(P\) and \(g(x)\) only on its values on \(Q\). Write \(fg\) for the pointwise product, \(P^c\) and \(Q^c\) for the complements in \(V\), and, for a weight \(h\), a set \(T \subseteq V\) and a configuration \(x\), \(m_h(T, x)\) for the marginal of \(h\) on \(T\) at \(x\), the total weight of the configurations that agree with \(x\) on \(T\). Then for every configuration \(x\),

    \[m_{fg}(U, x) = m_f(U \cup P^c, x)\, m_g(U \cup Q^c, x).\]

    Here the free variables of \(f\) are those of \(P\) outside \(U\), and those of \(g\) are those of \(Q\) outside \(U\).

    theorem marginal_mul {f g : (V → α) → ℝ} {P Q U : Set V} (hf : DependsOn f P) (hg : DependsOn g Q)
    (hPQ : ∀ v, v ∈ P ∨ v ∈ Q) (hU : P ∩ Q ⊆ U) (x : V → α) :
    marginal (f * g) U x = marginal f (U ∪ Pᶜ) x * marginal g (U ∪ Qᶜ) x
