    DefinitionKendall's extinction probability for the birth–death process#✓fully proved

    MathlibExt.Probability.LinearBirthDeath.extinctionProb

    Kendall's extinction probability α t = P(X t = 0 | X 0 = 1) of the linear birth–death process with per-capita birth rate b and death rate d: d (E - 1) / (b E - d) with E = exp ((b - d) t) if b ≠ d, and b t / (1 + b t) if b = d. Meaningful for 0 ≤ b, 0 ≤ d, 0 ≤ t.

    noncomputable def extinctionProb (b d t : ℝ) : ℝ :=
  if b = d then b * t / (1 + b * t)
  else d * (exp ((b - d) * t) - 1) / (b * exp ((b - d) * t) - d)
