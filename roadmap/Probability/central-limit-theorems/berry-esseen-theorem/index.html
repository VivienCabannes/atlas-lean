    TheoremBerry–Esseen bound for finite sums#✓fully proved

    MathlibExt.Probability.BerryEsseenWanted.berry_esseen_finsetSum_gaussian

    Let \((\xi_j)_{j \in \mathbb{N}}\) be measurable, mutually independent real random variables on a probability space, and let \(s\) be a finite set of indices such that for each \(j \in s\) the variable \(\xi_j\) has a finite third moment and mean \(\mathbb{E}[\xi_j] = 0\), and such that \(\sum_{j \in s} \mathbb{E}[\xi_j^2] = 1\). Write \(\Phi\) for the distribution function of the standard normal distribution. If \(\gamma \ge 0\) is a real number with \(\sum_{j \in s} \mathbb{E}|\xi_j|^3 \le \gamma\), then for every real \(z\),

    \[\left|\mathbb{P}\left(\sum_{j \in s} \xi_j \le z\right) - \Phi(z)\right| \le 42\gamma.\]
    theorem berry_esseen_finsetSum_gaussian {Ω : Type*}
    [MeasurableSpace Ω] {P : Measure Ω} [IsProbabilityMeasure P]
    {ξ : ℕ → Ω → ℝ} (hmeas : ∀ j, Measurable (ξ j))
    (hindep : iIndepFun ξ P) {s : Finset ℕ}
    (hmem : ∀ j ∈ s, MemLp (ξ j) 3 P)
    (hmean : ∀ j ∈ s, P[ξ j] = 0)
    (hvar : ∑ j ∈ s, P[fun ω => (ξ j ω) ^ 2] = 1)
    {γ : ℝ} (hγ : 0 ≤ γ)
    (hγ3 : ∑ j ∈ s, P[fun ω => |ξ j ω| ^ 3] ≤ γ)
    (z : ℝ) :
    |P.real {ω | ∑ j ∈ s, ξ j ω ≤ z} - (gaussianReal 0 1).real (Iic z)|
      ≤ 42 * γ

    TheoremBerry–Esseen theorem with constant 42#✓fully proved

    MathlibExt.Probability.BerryEsseenWanted.berry_esseen_explicit

    Let \(X_0, X_1, X_2, \dots\) be measurable, mutually independent real random variables on a probability space, each with the same distribution as \(X_0\), where \(X_0\) has a finite third moment, mean \(\mathbb{E}[X_0] = 0\) and variance \(\sigma^2 = \operatorname{Var}(X_0) > 0\) with \(\sigma > 0\). Write \(\rho = \mathbb{E}|X_0|^3\), \(S_n = X_0 + \dots + X_{n-1}\), and \(\Phi\) for the distribution function of the standard normal distribution. Then for every \(n \ge 1\) and every real \(x\),

    \[\left|\mathbb{P}\left(\frac{S_n}{\sqrt{n\sigma^2}} \le x\right) - \Phi(x)\right| \le \frac{42\rho}{\sigma^3\sqrt{n}}.\]

    Integrability of \(X_0\) is not assumed separately, since on a probability space it follows from the finite third moment.

    theorem berry_esseen_explicit
    {Ω : Type*} [MeasurableSpace Ω] {P : Measure Ω} [IsProbabilityMeasure P]
    (X : ℕ → Ω → ℝ)
    (hXmeas : ∀ n, Measurable (X n))
    (hXindep : iIndepFun X P)
    (hXid : ∀ i, IdentDistrib (X i) (X 0) P P)
    (hXmem : MemLp (X 0) 3 P)
    (hXmean : P[X 0] = 0)
    (hXvar : 0 < Var[X 0; P])
    (n : ℕ) (hn : 0 < n) (x : ℝ) :
    |((P.map (fun ω => (∑ i ∈ range n, X i ω) / Real.sqrt (n * Var[X 0; P]))).real (Iic x)
      - (gaussianReal 0 1).real (Iic x))|
      ≤ 42 * (P[fun ω => |X 0 ω| ^ 3])
        / (Real.sqrt (Var[X 0; P]) ^ 3 * Real.sqrt (n : ℝ))

    TheoremBerry–Esseen theorem#✓fully proved

    MathlibExt.Probability.BerryEsseenWanted.berry_esseen

    There is a constant \(C > 0\) with the following property. Let \(X_0, X_1, X_2, \dots\) be measurable, mutually independent real random variables on a probability space, each with the same distribution as \(X_0\), where \(X_0\) is integrable and has a finite third moment, mean \(\mathbb{E}[X_0] = 0\) and variance \(\sigma^2 = \operatorname{Var}(X_0) > 0\) with \(\sigma > 0\). Write \(\rho = \mathbb{E}|X_0|^3\), \(S_n = X_0 + \dots + X_{n-1}\), and \(\Phi\) for the distribution function of the standard normal distribution. Then for every \(n \ge 1\) and every real \(x\),

    \[\left|\mathbb{P}\left(\frac{S_n}{\sqrt{n\sigma^2}} \le x\right) - \Phi(x)\right| \le \frac{C\rho}{\sigma^3\sqrt{n}}.\]

    DefinitionKolmogorov error#✓fully proved

    BerryEsseenModel.kolmogorovError

    For a measure \(\mu\) on \(\mathbb{R}\) and a positive integer \(n\), the Kolmogorov error of \(\mu\) at \(n\) is the real supremum \(\sup_{x \in \mathbb{R}} |F_{\mu,n}(x) - \Phi(x)|\), where \(\Phi\) is the standard normal cumulative distribution function and \(F_{\mu,n}\) is Mathlib's cumulative distribution function of the normalized law of \(\mu\) at \(n\). When \(\mu\) is a probability measure, \(F_{\mu,n}(x)\) is the mass the normalized law gives to \((-\infty, x]\); otherwise the normalized law is the zero measure and \(F_{\mu,n}\) is a fixed but unspecified cumulative distribution function of some probability measure, not the zero function.

    The values \(|F_{\mu,n}(x) - \Phi(x)|\) lie in \([0, 1]\), so the supremum is finite.

    noncomputable def kolmogorovError (μ : Measure ℝ) (n : ℕ+) : ℝ :=
  sSup (Set.range (fun x : ℝ ↦ |cdf (normalizedLaw μ n) x - normalCDF x|))
