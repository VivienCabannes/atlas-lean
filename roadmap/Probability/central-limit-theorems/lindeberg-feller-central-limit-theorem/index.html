    Lindeberg–Feller central limit theorem

    DefinitionLindeberg condition for a triangular array#✓fully proved

    ProbabilityTheory.LindebergConditionTriangular

    A triangular array of real random variables \(X_{n,k}\) (\(n \in \mathbb{N}\), \(0 \le k < n\)) on a measure space \((\Omega, \mu)\) satisfies the Lindeberg condition if for every \(\varepsilon > 0\) the truncated second moments

    \[\sum_{k < n} \int_\Omega X_{n,k}^2 \, \mathbf{1}\{|X_{n,k}| > \varepsilon\} \, d\mu\]

    tend to \(0\) as \(n \to \infty\). This is the key hypothesis of the Lindeberg–Feller central limit theorem.

    def LindebergConditionTriangular {Ω : Type*} [MeasurableSpace Ω]
    (X : ℕ → ℕ → Ω → ℝ) (μ : Measure Ω) : Prop :=
  ∀ ε : ℝ, 0 < ε →
    Tendsto (fun n => ∑ k ∈ Finset.range n,
      ∫ ω, (X n k ω) ^ 2 * Set.indicator {ω' | ε < |X n k ω'|} 1 ω ∂μ)
    atTop (𝓝 0)

    TheoremComparing a finite product with the exponential of a sum#✓fully proved

    ProbabilityTheory.prod_one_add_sub_exp_sum_le

    Let \(s\) be a finite index set and let \(u_i \in \mathbb{C}\) for \(i \in s\). If \(|u_i| \le 1/2\) for every \(i \in s\), then

    \[ \Bigl|\prod_{i \in s} (1 + u_i) - \exp\Bigl(\sum_{i \in s} u_i\Bigr)\Bigr| \le \Bigl(\sum_{i \in s} |u_i|^2\Bigr) \exp\Bigl(\sum_{i \in s} |u_i|\Bigr). \]

    This is the estimate that turns the second-order expansion of each characteristic function into convergence of the product.

    theorem prod_one_add_sub_exp_sum_le {ι : Type*} [DecidableEq ι] (s : Finset ι) (u : ι → ℂ)
    (hu : ∀ i ∈ s, ‖u i‖ ≤ 1 / 2) :
    ‖∏ i ∈ s, (1 + u i) - Complex.exp (∑ i ∈ s, u i)‖ ≤
      (∑ i ∈ s, ‖u i‖ ^ 2) * Real.exp (∑ i ∈ s, ‖u i‖)

    ProbabilityTheory.lindeberg_charFun_product_tendsto

    Let \(\mu\) be a probability measure on \(\Omega\) and let \(X_{n,k}\) (\(n \in \mathbb{N}\), \(0 \le k < n\)) be real random variables on \(\Omega\) such that each \(X_{n,k}\) has mean \(0\) and each \(X_{n,k}^2\) is integrable (expectations are taken under \(\mu\)). Suppose that for some \(\sigma > 0\) the row variances \(\sum_{k < n} \mathbb{E}[X_{n,k}^2]\) converge to \(\sigma^2\) and that the array satisfies the Lindeberg condition. Then for every real \(t\) the product \(\prod_{k < n} \varphi_{n,k}(t)\) of the characteristic functions \(\varphi_{n,k}\) of the laws of the \(X_{n,k}\) converges to \(e^{-\sigma^2 t^2 / 2}\) as \(n \to \infty\).

    TheoremLindeberg–Feller central limit theorem#✓fully proved

    ProbabilityTheory.lindeberg_feller_clt_triangular

    Let \(\mu\) be a probability measure on \(\Omega\) and let \(X_{n,k}\) (\(n \in \mathbb{N}\), \(0 \le k < n\)) be a triangular array of real random variables on \(\Omega\) such that for each \(n\) the variables \(X_{n,0}, \dots, X_{n,n-1}\) are independent, each \(X_{n,k}\) has mean \(0\), and each \(X_{n,k}^2\) is integrable (expectations are taken under \(\mu\)). Suppose that for some \(\sigma > 0\) the row variances \(\sum_{k < n} \mathbb{E}[X_{n,k}^2]\) converge to \(\sigma^2\) and that the array satisfies the Lindeberg condition. Then the row sums \(S_n = \sum_{k < n} X_{n,k}\) converge in distribution to the Gaussian law \(N(0, \sigma^2)\): for every bounded continuous \(f : \mathbb{R} \to \mathbb{R}\), \(\mathbb{E}[f(S_n)] \to \int_{\mathbb{R}} f \, dN(0, \sigma^2)\) as \(n \to \infty\).
