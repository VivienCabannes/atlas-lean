    DefinitionStandardized binomial distribution#✓fully proved

    MathlibExt.Probability.CharFunStandardizedBinomial.standardizedBinomial

    For a natural number \(n\) and \(p \in [0, 1]\), the standardized binomial distribution is the measure on \(\mathbb{R}\) given by the law of \((S_n - np)/\sqrt{np(1-p)}\), where \(S_n\) has the binomial distribution with parameters \(n\) and \(p\). When \(np(1-p) = 0\) the division by \(0\) is read as \(0\), so the law is the point mass at \(0\).

    This is the standardized sum appearing in the De Moivre–Laplace limit theorem.

    noncomputable def standardizedBinomial (n : ℕ) (p : I) : Measure ℝ :=
  Bin(ℝ, n, p).map (fun x : ℝ ↦ (x - ↑n * ↑p) / Real.sqrt (↑n * ↑p * (1 - ↑p)))

    TheoremAffine transformation of a characteristic function#✓fully proved

    MathlibExt.Probability.CharFunStandardizedBinomial.charFun_map_affine

    Let \(\mu\) be a measure on \(\mathbb{R}\), let \(a, s, t \in \mathbb{R}\), and let \(\nu\) be the image of \(\mu\) under the map \(x \mapsto (x - a)/s\). Then the characteristic functions satisfy \(\varphi_\nu(t) = \varphi_\mu(t s^{-1}) \, e^{-i a t s^{-1}}\). Here \(s^{-1}\) and division by \(s\) are read as \(0\) when \(s = 0\), so no hypothesis \(s \neq 0\) is needed.

    theorem charFun_map_affine (μ : Measure ℝ) (a s t : ℝ) :
    charFun (μ.map (fun x => (x - a) / s)) t =
      charFun μ (t * s⁻¹) * Complex.exp (↑(-(a * (t * s⁻¹))) * Complex.I)

    DefinitionStandardized partial sums#✓fully proved

    ProbabilityTheory.deMoivreLaplaceStandardized

    For a sequence \(X_0, X_1, \dots\) of real-valued functions on a set \(\Omega\), a real number \(p\) and \(n \in \mathbb{N}\), the standardized partial sum is the function \(\omega \mapsto (S_n(\omega) - np)/\sqrt{np(1-p)}\) on \(\Omega\), where \(S_n = X_0 + \dots + X_{n-1}\).

    The square root of a negative number is taken to be \(0\) and division by \(0\) gives \(0\); in particular the standardized partial sum is \(0\) for \(n = 0\).

    noncomputable def deMoivreLaplaceStandardized {Ω : Type*} (X : ℕ → Ω → ℝ)
    (p : ℝ) (n : ℕ) (ω : Ω) : ℝ :=
  ((∑ k ∈ Finset.range n, X k ω) - ↑n * p) / Real.sqrt (↑n * p * (1 - p))

    DefinitionBernoulli standardization map#✓fully proved

    ProbabilityTheory.standardizedBernoulli

    For a real number \(p\), the standardization map sends \(x \in \mathbb{R}\) to \((x - p)/\sqrt{p(1-p)}\).

    The square root of a negative number is taken to be \(0\) and division by \(0\) gives \(0\), so for \(p \le 0\) or \(p \ge 1\) the map is identically \(0\).
