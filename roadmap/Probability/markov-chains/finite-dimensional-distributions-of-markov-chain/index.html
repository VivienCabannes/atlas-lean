    DefinitionFinite-dimensional distribution of a Markov chain#✓fully proved

    MathlibExt.Probability.MarkovChainFDD.markovFDD

    For a measure \(\mu\) on a measurable space \(S\), a kernel \(\kappa\) from \(S\) to \(S\), a natural number \(n\) and sets \(A_0, \dots, A_n \subseteq S\), the finite-dimensional distribution \(\mathrm{FDD}_n(\mu, \kappa; A_0, \dots, A_n) \in [0, \infty]\) is defined by recursion on \(n\): \(\mathrm{FDD}_0(\mu, \kappa; A_0) = \mu(A_0)\) and \(\mathrm{FDD}_{n+1}(\mu, \kappa; A_0, \dots, A_{n+1}) = \int_{A_0} \mathrm{FDD}_n(\kappa(x), \kappa; A_1, \dots, A_{n+1}) \, d\mu(x)\). Unfolded, it is the iterated integral

    \[ \int_{A_0} \mu(dx_0) \int_{A_1} \kappa(x_0, dx_1) \cdots \int_{A_n} \kappa(x_{n-1}, dx_n). \]

    When \(\mu\) is a probability measure and \(\kappa\) a Markov kernel, this is the probability that a chain with initial distribution \(\mu\) and transition kernel \(\kappa\) visits \(A_0, A_1, \dots, A_n\) at consecutive times.

    noncomputable def markovFDD {S : Type*} [MeasurableSpace S]
    (mu : Measure S) (kappa : Kernel S S) : (n : Nat) -> (Fin (n + 1) -> Set S) -> ENNReal
  | 0, A => mu (A 0)
  | n + 1, A => ∫⁻ x in A 0, markovFDD (kappa x) kappa n (fun i => A i.succ) ∂mu

    MathlibExt.Probability.MarkovChainFDD.markovFDD_measurable

    Let \(\kappa\) be a Markov kernel on a measurable space \(S\), let \(n\) be a natural number and let \(A_0, \dots, A_n\) be measurable subsets of \(S\). Write \(\mathrm{FDD}_n(\mu, \kappa; A_0, \dots, A_n)\) for the finite-dimensional distribution of a Markov chain with initial measure \(\mu\) and transition kernel \(\kappa\). Then the map \(x \mapsto \mathrm{FDD}_n(\kappa(x), \kappa; A_0, \dots, A_n)\) from \(S\) to \([0, \infty]\) is measurable.

    This is the regularity needed to integrate the finite-dimensional distributions against a starting distribution.

    lemma markovFDD_measurable {S : Type*} [MeasurableSpace S]
    (kappa : Kernel S S) [IsMarkovKernel kappa]
    (n : Nat) (A : Fin (n + 1) -> Set S) (hA : forall i, MeasurableSet (A i)) :
    Measurable (fun x => markovFDD (kappa x) kappa n A)

    MathlibExt.Probability.MarkovChainFDD.markov_chain_finite_dimensional_distributions

    Let \(P\) be a probability measure on a measurable space \(\Omega\), let \(X_0, X_1, \dots\) be measurable maps from \(\Omega\) to a measurable space \(S\), and let \(\kappa\) be a Markov kernel on \(S\). Write \(\sigma(X_0, \dots, X_k)\) for the σ-algebra on \(\Omega\) generated by \(\omega \mapsto (X_0(\omega), \dots, X_k(\omega))\), with the product σ-algebra on \(S^{k+1}\). Suppose \(X\) is a Markov chain with transition kernel \(\kappa\): for every \(k\), every measurable \(B \subseteq S\) and every \(C\) measurable with respect to \(\sigma(X_0, \dots, X_k)\), \(\int_C \mathbf{1}_{X_{k+1}^{-1}(B)} \, dP = \int_C \kappa(X_k(\omega), B) \, dP(\omega)\). Let \(\mu = P \circ X_0^{-1}\) be the initial distribution. Then for every natural number \(n\) and all measurable sets \(A_0, \dots, A_n \subseteq S\),

    \[ P(X_i \in A_i \text{ for } 0 \le i \le n) = \int_{A_0} \mu(dx_0) \int_{A_1} \kappa(x_0, dx_1) \cdots \int_{A_n} \kappa(x_{n-1}, dx_n), \]

    where the right-hand side is the finite-dimensional distribution \(\mathrm{FDD}_n(\mu, \kappa; A_0, \dots, A_n)\) of a Markov chain with initial measure \(\mu\) and transition kernel \(\kappa\).
