    MathlibExt.Probability.FiniteMarkovChainConvergence.tvDist_pow_le_of_minorization

    Doeblin's argument (Levin, Peres and Wilmer, proof of Theorem 4.9): if the r-step transition probabilities dominate δ π, then the total variation distance of Pⁿ(x, ·) from the stationary distribution π is at most (1 - δ) ^ ⌊n / r⌋.     theorem tvDist_pow_le_of_minorization {P : Matrix S S ℝ} (hP : P ∈ rowStochastic ℝ S)

    {r : ℕ} {δ : ℝ} (hmin : ∀ x y, δ * π y ≤ (P ^ r) x y)
    (n : ℕ) (x : S) :
    tvDist (fun y => (P ^ n) x y) π ≤ (1 - δ) ^ (n / r)
