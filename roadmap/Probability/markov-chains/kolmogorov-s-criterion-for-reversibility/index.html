    StochasticMatrix

    For a natural number \(M\), a stochastic matrix of size \(M + 1\) is a square matrix \(P = (P_{ij})\) indexed by the states \(\{0, 1, \dots, M\}\), with real entries \(P_{ij} \ge 0\) for all states \(i, j\), whose rows sum to \(1\): \(\sum_j P_{ij} = 1\) for every \(i\). It is the transition matrix of a Markov chain on these \(M + 1\) states.

    structure StochasticMatrix (M : ℕ) where
  prob : Fin (M + 1) → Fin (M + 1) → ℝ
  nonneg : ∀ i j, 0 ≤ prob i j
  row_sum : ∀ i, ∑ j, prob i j = 1

    DefinitionMatrix powers of a stochastic matrix#✓fully proved

    StochasticMatrix.matPow

    For a stochastic matrix \(P\) on the finite state space \(\{0, 1, \dots, M\}\) and \(n \in \mathbb{N}\), the \(n\)-th matrix power \(P^n\) is defined by \(P^0 = I\), the identity matrix, and \((P^{n+1})_{ij} = \sum_k P(i, k) (P^n)_{kj}\). The entry \((P^n)_{ij}\) is the probability of moving from state \(i\) to state \(j\) in exactly \(n\) steps.

    def matPow (P : StochasticMatrix M) : ℕ → (Fin (M + 1) → Fin (M + 1) → ℝ)
  | 0 => fun i j => if i = j then 1 else 0
  | n + 1 => fun i j => ∑ k, P.prob i k * P.matPow n k j

    StructureKolmogorov's cycle condition#✓fully proved

    StochasticMatrix.KolmogorovCycleCondition

    A stochastic matrix \(P\) on the finite state space \(\{0, 1, \dots, M\}\) satisfies Kolmogorov's cycle condition when (1) for all states \(x, y\), \(P(x, y) > 0\) implies \(P(y, x) > 0\); and (2) for every \(n \ge 0\) and every loop of states \(x_0, x_1, \dots, x_n\) with \(x_n = x_0\) and \(\prod_{i=0}^{n-1} P(x_{i+1}, x_i) > 0\), we have \(\prod_{i=0}^{n-1} P(x_i, x_{i+1}) = \prod_{i=0}^{n-1} P(x_{i+1}, x_i)\).

    structure KolmogorovCycleCondition (P : StochasticMatrix M) : Prop where
  symm_support : ∀ x y : Fin (M + 1), P.prob x y > 0 → P.prob y x > 0
  cycle_prod : ∀ (n : ℕ) (c : Fin (n + 1) → Fin (M + 1)), c 0 = c (Fin.last n) →
    (∏ i : Fin n, P.prob (c i.succ) (c i.castSucc)) > 0 →
    (∏ i : Fin n, P.prob (c i.castSucc) (c i.succ)) =
      (∏ i : Fin n, P.prob (c i.succ) (c i.castSucc))
