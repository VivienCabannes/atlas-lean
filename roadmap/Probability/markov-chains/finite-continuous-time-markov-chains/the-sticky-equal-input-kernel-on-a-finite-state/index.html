    TheoremCovariance under the sticky kernel#✓fully proved

    ProbabilityTheory.covariance_stickyKernel

    If (X, Y) has joint law P(X = i, Y = j) = π i K i j (stationary start, one step of the kernel), then Cov(f X, g Y) = c Cov_π(f, g). The algebraic identity holds for all real π, f, g, c; it is a covariance of a probability law when π is a probability vector and 0 ≤ c ≤ 1.

    theorem covariance_stickyKernel (π : ι → ℝ) (c : ℝ) (f g : ι → ℝ) :
    ∑ i, ∑ j, π i * stickyKernel π c i j * (f i * g j) -
        (∑ i, π i * f i) * (∑ j, π j * g j) =
      c * (∑ i, π i * (f i * g i) - (∑ i, π i * f i) * (∑ j, π j * g j))

    ProbabilityTheory.covariance_indicator_stickyKernel_two

    Two-state ancestry covariance (the local-ancestry chain of a two-way pulse admixture). With ancestry proportions π = (α, 1 - α) and persistence c = (1 - r) ^ n (no recombination between the two sites along the n meioses since admixture, recombination fraction r per meiosis), the indicators I_x = [X = 0], I_y = [Y = 0] of ancestry 0 at the two sites have covariance α (1 - α) (1 - r) ^ n.
