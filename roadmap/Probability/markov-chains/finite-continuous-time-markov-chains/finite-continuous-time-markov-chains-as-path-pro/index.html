    ProbabilityTheory.ctmcJumpMatrix

    The jump matrix Π of a matrix Q (Norris 1997, §2.6): for a state with exit rate q i = -Q i i ≠ 0, Π i j = Q i j / q i for j ≠ i and Π i i = 0; a state with q i = 0 is absorbing, Π i j = δ i j.

    noncomputable def ctmcJumpMatrix (Q : Matrix ι ι ℝ) : Matrix ι ι ℝ := fun i j =>
  if Q i i = 0 then (if i = j then 1 else 0) else if i = j then 0 else Q i j / -Q i i
