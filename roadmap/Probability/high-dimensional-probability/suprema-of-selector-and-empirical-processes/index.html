    Let \(X\) be a finite type and \(p \in [0, 1]\). A family \(\mathcal{F}\) of subsets of \(X\) is \(p\)-small when there is a family \(\mathcal{G}\) of subsets of \(X\) such that every member of \(\mathcal{F}\) contains some member of \(\mathcal{G}\) and \(\sum_{S \in \mathcal{G}} p^{|S|} \le 1/2\).

    def IsSmall {X : Type*} [Fintype X] (p : I) (𝓕 : Set (Set X)) : Prop :=

    MathlibExt.Analysis.SupremumOfSelectorProcessesWanted.SupremumOfSelectorProcesses.theorem_1_2

    There is a real number \(L > 0\) with the following property. Let \(0 < p < 1\), let \(X\) be a finite type, let \(\Lambda\) be a set of functions from \(X\) to \([0, \infty)\), and let \(X_p\) be a binomial random subset of \(X\) with parameter \(p\). Write \(E = \mathbb{E}\bigl[\sup_{f \in \Lambda} \sum_{i \in X_p} f(i)\bigr]\), computed in \([0, \infty]\). If \(0 < E < \infty\), then the family of subsets \(s \subseteq X\) with \(\sup_{f \in \Lambda} \sum_{i \in s} f(i) \ge L E\) is \(p\)-small.

    The hypothesis \(0 < E < \infty\) is not stated explicitly in the paper's theorem, but it is used in the last step of the proof, which derives a contradiction from an inequality \(E \ge c E\) with a constant \(c > 1\).

    MathlibExt.Analysis.SupremumOfSelectorProcessesWanted.SupremumOfSelectorProcesses.Z

    Given random variables \(Y_1, \dots, Y_N\) on \(\Omega\) with values in \(\mathbb{T}\) and a function \(f : \mathbb{T} \to [0, \infty)\), \(Z_N(f)\) is the random variable \(Z_N(f)(\omega) = \frac{1}{N} \sum_{i=1}^{N} f(Y_i(\omega))\), which is \(0\) when \(N = 0\).

    When \(Y_1, \dots, Y_N\) are i.i.d., \(Z_N(f)\) is called an empirical process.

    noncomputable def Z {Ω 𝕋 : Type*} (N : ℕ) (Y : Fin N → Ω → 𝕋) (f : 𝕋 → ℝ≥0) (ω : Ω) : ℝ≥0 :=
  (N : ℝ≥0)⁻¹ * ∑ i : Fin N, f (Y i ω)

    MathlibExt.Analysis.SupremumOfSelectorProcessesWanted.SupremumOfSelectorProcesses.theorem_1_3

    There is a real number \(L > 0\) with the following property. Let \(N > 0\), let \(\mathbb{T}\) be a Polish space with its Borel \(\sigma\)-algebra and a probability measure \(\nu\), and let \(Y_1, \dots, Y_N\) be independent random variables on a measure space \((\Omega, P)\) with values in \(\mathbb{T}\), each with law \(\nu\). For \(f : \mathbb{T} \to [0, \infty)\) let \(Z_f = \frac{1}{N} \sum_{i=1}^{N} f(Y_i)\). Let \(\mathcal{F}\) be a finite set of measurable functions from \(\mathbb{T}\) to \([0, \infty)\) that are essentially bounded with respect to \(\nu\), and write \(E = \mathbb{E}\bigl[\sup_{f \in \mathcal{F}} Z_f\bigr]\), computed in \([0, \infty]\). If \(0 < E < \infty\), then there is a finite collection \(\mathcal{C}\) of pairs \((g, t)\), where \(g : \mathbb{T} \to [0, \infty)\) is measurable and \(t > 0\) is real, such that every \(\omega\) with \(\sup_{f \in \mathcal{F}} Z_f(\omega) \ge L E\) satisfies \(Z_g(\omega) \ge t\) for some \((g, t) \in \mathcal{C}\), and \(\sum_{(g, t) \in \mathcal{C}} P(Z_g \ge t) \le 1/2\).

    The paper does not state explicitly that \(\mathcal{C}\) is finite. It must at least be countable for the sum to make sense, and the collections produced by the proof are finite.
