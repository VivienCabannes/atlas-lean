    DefinitionOuter Minkowski boundary measure#✓fully proved

    MathlibExt.Probability.KLS.outerMinkowskiBoundary

    Let \(\mu\) be a measure on a pseudometric space \(E\) and let \(A \subseteq E\). For \(\varepsilon > 0\) let \(A_\varepsilon = \{x \in E : \inf_{a \in A} d(x, a) \le \varepsilon\}\) be the closed \(\varepsilon\)-neighbourhood of \(A\), with \(\inf \emptyset = \infty\). The outer Minkowski boundary measure of \(A\) with respect to \(\mu\) is

    \[\mu^+(A) = \liminf_{\varepsilon \to 0^+} \frac{\mu(A_\varepsilon) - \mu(A)}{\varepsilon},\]

    where the difference and the quotient are computed in \([0, \infty]\), with \(\infty - \infty = 0\).

    noncomputable def outerMinkowskiBoundary {E : Type*} [PseudoMetricSpace E]
    [MeasurableSpace E] (μ : Measure E) (A : Set E) : ℝ≥0∞ :=
  Filter.liminf (fun ε : ℝ => (μ (Metric.cthickening ε A) - μ A) / ENNReal.ofReal ε)
    (nhdsWithin 0 (Set.Ioi 0))

    DefinitionCheeger coefficient#✓fully proved

    MathlibExt.Probability.KLS.cheegerCoefficient

    For a measure \(\mu\) on a pseudometric space \(E\) equipped with a σ-algebra, the Cheeger coefficient of \(\mu\) is the infimum in \([0, \infty]\) of \(\mu^+(A) / \min(\mu(A), 1 - \mu(A))\) over all measurable sets \(A \subseteq E\) with \(0 < \mu(A) < 1\), where \(\mu^+(A) = \liminf_{\varepsilon \to 0^+} (\mu(A_\varepsilon) - \mu(A)) / \varepsilon\) is the outer Minkowski boundary measure of \(A\) and \(A_\varepsilon\) is the closed \(\varepsilon\)-neighbourhood of \(A\). The infimum of the empty family is \(\infty\); the measure \(\mu\) is not required to be a probability measure.

    noncomputable def cheegerCoefficient {E : Type*} [PseudoMetricSpace E]
    [MeasurableSpace E] (μ : Measure E) : ℝ≥0∞ :=
  sInf {v | ∃ A : Set E, MeasurableSet A ∧ 0 < μ A ∧ μ A < 1 ∧
    outerMinkowskiBoundary μ A / min (μ A) (1 - μ A) = v}
    noncomputable def outerMinkowskiBoundary {E : Type*} [PseudoMetricSpace E]

    DefinitionDimensional KLS constant#✓fully proved

    MathlibExt.Probability.KLS.dimensionalKlsConstant

    For \(n \in \mathbb{N}\), the dimensional KLS constant in dimension \(n\) is the supremum in \([0, \infty]\) of the inverse Cheeger constants of all isotropic log-concave probability measures on \(\mathbb{R}^n\) with the Euclidean metric.

    noncomputable def dimensionalKlsConstant (n : ℕ) : ℝ≥0∞ :=
  sSup {v | ∃ μ : Measure (EuclideanSpace ℝ (Fin n)),

    def IsIsotropicLogConcave {n : ℕ} (μ : Measure (EuclideanSpace ℝ (Fin n))) : Prop :=
  IsProbabilityMeasure μ ∧
    (∃ f : EuclideanSpace ℝ (Fin n) → ℝ, IsLogConcaveDensity f ∧
      μ = volume.withDensity (fun x => ENNReal.ofReal (f x))) ∧
    (∀ i : Fin n, Integrable (fun x => x i) μ ∧ (∫ x, x i ∂μ) = 0) ∧
    ∀ i j : Fin n, Integrable (fun x => x i * x j) μ ∧
      (∫ x, x i * x j ∂μ) = if i = j then 1 else 0

    DefinitionSmooth Poincaré bounds#✓fully proved

    MathlibExt.Probability.KLS.IsSmoothPoincareBound

    Let \(\mu\) be a measure on \(\mathbb{R}^n\) and let \(C \in [0, \infty]\). For a differentiable \(g : \mathbb{R}^n \to \mathbb{R}\) write \(\|\nabla g(x)\|\) for the Euclidean norm of the gradient of \(g\) at \(x\) (equivalently, the operator norm of the derivative of \(g\) at \(x\)). Then \(C\) is a smooth Poincaré bound for \(\mu\) if for every infinitely differentiable function \(f : \mathbb{R}^n \to \mathbb{R}\) such that \(f\), \(f^2\) and \(\|\nabla f\|^2\) are \(\mu\)-integrable,

    \[\int \Big(f(x) - \int f \, d\mu\Big)^2 \, d\mu(x) \le C \int \|\nabla f(x)\|^2 \, d\mu(x),\]

    where the outer integral on the left and the integral on the right are computed in \([0, \infty]\) with \(0 \cdot \infty = 0\), and the inner integral \(\int f \, d\mu\) is the usual real integral. The measure \(\mu\) need not be a probability measure.

    def IsSmoothPoincareBound {n : ℕ} (μ : Measure (EuclideanSpace ℝ (Fin n)))
    (C : ℝ≥0∞) : Prop :=
  ∀ f : EuclideanSpace ℝ (Fin n) → ℝ, ContDiff ℝ ∞ f → Integrable f μ →
    Integrable (fun x => (f x) ^ 2) μ →
    Integrable (fun x => ‖fderiv ℝ f x‖ ^ 2) μ →
    (∫⁻ x, ENNReal.ofReal ((f x - ∫ y, f y ∂μ) ^ 2) ∂μ) ≤
      C * ∫⁻ x, ENNReal.ofReal (‖fderiv ℝ f x‖ ^ 2) ∂μ
