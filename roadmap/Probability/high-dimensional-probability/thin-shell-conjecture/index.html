    DefinitionLog-concave densities#✓fully proved

    MathlibExt.Probability.ThinShell.IsLogConcaveDensity

    A function \(f : \mathbb{R}^n \to \mathbb{R}\) is a log-concave density when it is measurable, \(f(x) \ge 0\) for every \(x\), and \(f(x)^{1-t} f(y)^t \le f((1-t)x + ty)\) for all \(x, y \in \mathbb{R}^n\) and every real \(t\) with \(0 < t < 1\).

    No integrability or normalization of \(f\) is required.

    def IsLogConcaveDensity {n : ℕ} (f : EuclideanSpace ℝ (Fin n) → ℝ) : Prop :=
  Measurable f ∧ (∀ x, 0 ≤ f x) ∧
    ∀ x y : EuclideanSpace ℝ (Fin n), ∀ t : ℝ, 0 < t → t < 1 →
      Real.rpow (f x) (1 - t) * Real.rpow (f y) t ≤ f ((1 - t) • x + t • y)

    DefinitionIsotropic log-concave probability measures#✓fully proved

    MathlibExt.Probability.ThinShell.IsIsotropicLogConcave

    A measure \(\mu\) on \(\mathbb{R}^n\) is isotropic log-concave when it is a probability measure, it has density \(f\) with respect to Lebesgue measure for some log-concave density \(f\), and for all coordinates \(i, j\) the functions \(x \mapsto x_i\) and \(x \mapsto x_i x_j\) are \(\mu\)-integrable with \(\int x_i \, d\mu(x) = 0\) and \(\int x_i x_j \, d\mu(x) = \delta_{ij}\), that is, \(1\) if \(i = j\) and \(0\) otherwise.

    def IsIsotropicLogConcave {n : ℕ} (μ : Measure (EuclideanSpace ℝ (Fin n))) : Prop :=
  IsProbabilityMeasure μ ∧
    (∃ f : EuclideanSpace ℝ (Fin n) → ℝ, IsLogConcaveDensity f ∧
      μ = volume.withDensity (fun x => ENNReal.ofReal (f x))) ∧
    (∀ i : Fin n, Integrable (fun x => x i) μ ∧ (∫ x, x i ∂μ) = 0) ∧
    ∀ i j : Fin n, Integrable (fun x => x i * x j) μ ∧
      (∫ x, x i * x j ∂μ) = if i = j then 1 else 0
    def IsLogConcaveDensity {n : ℕ} (f : EuclideanSpace ℝ (Fin n) → ℝ) : Prop :=

    DefinitionNormalized radius variance#✓fully proved

    MathlibExt.Probability.ThinShell.normalizedRadiusVariance

    For a measure \(\mu\) on \(\mathbb{R}^n\), the normalized radius variance of \(\mu\) is \(\frac{1}{n} \int (\|x\|^2 - n)^2 \, d\mu(x)\), computed in \([0, \infty]\), where \(\|x\|\) is the Euclidean norm (for \(n = 0\) the integral is \(0\) and so is the value).

    When \(\mu\) is a probability measure with \(\int \|x\|^2 \, d\mu(x) = n\), as for an isotropic one, this is the variance of \(\|x\|^2\) divided by \(n\).

    noncomputable def normalizedRadiusVariance {n : ℕ}
    (μ : Measure (EuclideanSpace ℝ (Fin n))) : ℝ≥0∞ :=
  (∫⁻ x, ENNReal.ofReal ((‖x‖ ^ 2 - (n : ℝ)) ^ 2) ∂μ) / (n : ℝ≥0∞)

    TheoremKlartag's power-law thin-shell bound#●ready to prove

    MathlibExt.Probability.ThinShell.klartag2007b_width_bound
