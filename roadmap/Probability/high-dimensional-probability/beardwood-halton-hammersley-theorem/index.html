    DefinitionNormalized tour length#✓fully proved

    MathlibExt.Probability.BeardwoodHaltonHammersleyConstantWanted.normalizedTourLength

    Let \(\Omega\) be a set and let \(X_0, X_1, X_2, \dots \colon \Omega \to \mathbb{R}^2\) be functions. For an outcome \(\omega \in \Omega\) and \(n \ge 1\), the normalized tour length is \(L_n(\omega)/\sqrt{n}\), where \(L_n(\omega)\) is the length of a shortest closed tour through \(X_0(\omega), \dots, X_{n-1}(\omega)\). For \(n = 0\) it is defined to be \(0\).

    The value at \(n = 0\) does not affect limits as \(n \to \infty\).

    noncomputable def normalizedTourLength
    {Ω : Type*} (points : ℕ → Ω → PlanarPoint) (ω : Ω) (n : ℕ) : ℝ :=
  if 0 < n then
    shortestTourLength (fun i : Fin n => points i.val ω) / Real.sqrt n
  else
    0

    DefinitionI.i.d. points with a given law#✓fully proved

    MathlibExt.Probability.BeardwoodHaltonHammersleyConstantWanted.IsIIDWithLaw

    Let \(\Omega\) be a measurable space with a measure \(\mathbb{P}\), let \(X_0, X_1, X_2, \dots \colon \Omega \to \mathbb{R}^2\) be functions and let \(\nu\) be a measure on the Borel sets of the plane. The \(X_i\) are i.i.d. with law \(\nu\) when \(\mathbb{P}\) and \(\nu\) are probability measures, every \(X_i\) is measurable, the \(X_i\) are mutually independent under \(\mathbb{P}\), and the distribution of each \(X_i\) under \(\mathbb{P}\) is \(\nu\).

    {Ω : Type*}

  IsProbabilityMeasure probability ∧
    IsProbabilityMeasure law ∧
    (∀ i, Measurable (points i)) ∧
    ProbabilityTheory.iIndepFun points probability ∧
    ∀ i, Measure.map (points i) probability = law

    DefinitionBHH constant of a law#✓fully proved

    MathlibExt.Probability.BeardwoodHaltonHammersleyConstantWanted.IsBHHConstantFor

    For a measure \(\nu\) on the plane and a real number \(\beta\), \(\beta\) is a BHH constant for \(\nu\) when an i.i.d. realization with law \(\nu\) exists and every i.i.d. realization with law \(\nu\) has almost-sure BHH limit \(\beta\): almost surely, \(L_n/\sqrt{n} \to \beta\), where \(L_n\) is the length of a shortest closed tour through the first \(n\) points.

    Requiring a realization to exist keeps the condition from holding vacuously.

    def IsBHHConstantFor (law : Measure PlanarPoint) (β : ℝ) : Prop :=
  Nonempty (IIDRealization law) ∧
