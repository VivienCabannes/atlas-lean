    Sublinear expectations and model uncertainty

    Probability under model uncertainty, after S. Peng: the primitive object is a sublinear expectation E on a space H of random variables (monotone, constant preserving, subadditive, positively homogeneous) rather than a single probability measure. By the Hahn–Banach theorem, E[X] is the maximum of E_θ[X] over a family of linear expectations, which is the uncertain family of probability models; coherent risk measures are sublinear expectations up to a sign. Distributions and independence are defined through E alone, and independence is no longer symmetric. The two canonical laws are the maximal distribution and the G-normal distribution, which has no mean uncertainty.

    Coherent acceptable set (Peng, arXiv:1002.4546v1, Chapter I, Definition 5.1). A set A of positions in H is a coherent acceptable set if it is upward closed in H, contains 0 but not -1, and is closed under multiplication by nonnegative scalars and under convex combinations.

    StructureCoherent risk measure#✓fully proved

    MathlibExt.Probability.SublinearExpectation.IsCoherentRiskMeasure

    Coherent risk measure (after Artzner, Delbaen, Eber and Heath, 1999). A functional ρ on the space H of risk positions (containing the constants) is a coherent risk measure if it is antitone, satisfies ρ(1) = -ρ(-1) = -1, and is subadditive and positively homogeneous on H. These are the four properties that Peng, arXiv:1002.4546v1, Chapter I, Proposition 5.5 proves for the risk measure ρ_A(X) = inf {m : m + X ∈ A} of a coherent acceptable set A (Definition 5.4).

    structure IsCoherentRiskMeasure (H : Submodule ℝ (Ω → ℝ)) (ρ : (Ω → ℝ) → ℝ) : Prop where
  const_mem : ∀ c : ℝ, (fun _ : Ω ↦ c) ∈ H
  anti : ∀ X ∈ H, ∀ Y ∈ H, Y ≤ X → ρ X ≤ ρ Y
  one : ρ (fun _ ↦ 1) = -1
  neg_one : ρ (fun _ ↦ -1) = 1
  subadd : ∀ X ∈ H, ∀ Y ∈ H, ρ (X + Y) ≤ ρ X + ρ Y
  pos_hom : ∀ X ∈ H, ∀ c : ℝ, 0 ≤ c → ρ (c • X) = c * ρ X

    MathlibExt.Probability.SublinearExpectation.IsSublinearExpectation

    Sublinear expectation (Peng, arXiv:1002.4546v1, Chapter I, Definition 1.1). E is a sublinear expectation on the linear space H of real functions on Ω if H contains the constants and E is monotone, constant preserving, subadditive and positively homogeneous on H. The functional is total on Ω → ℝ, but only its values on H are constrained. (Peng also assumes |X| ∈ H for X ∈ H; the results of this file do not need it.)

    MathlibExt.Probability.SublinearExpectation.IsSublinearExpectation.exists_linearExpectation

    If E is a sublinear expectation on H, then for every X ∈ H there is a linear functional f on H with f ≤ E and f X = E X, and every such dominated linear functional is a linear expectation: monotone and constant preserving (Peng, arXiv:1002.4546v1, Chapter I, Theorem 2.1). The linear expectations obtained this way are in general only finitely additive (Remark 2.2 there).

    theorem IsSublinearExpectation.exists_linearExpectation (hE : IsSublinearExpectation H E)
    {X : Ω → ℝ} (hX : X ∈ H) :
    ∃ f : H →ₗ[ℝ] ℝ, (∀ Y : H, f Y ≤ E Y) ∧ f ⟨X, hX⟩ = E X ∧

    MathlibExt.Probability.SublinearExpectation.IsSublinearExpectation.isGreatest

    For a sublinear expectation E on H and X ∈ H, E[X] is the largest value of f X over the linear expectations f on H (monotone, constant preserving) dominated by E, and the maximum is attained: E[X] = max_θ E_θ[X] (Peng, arXiv:1002.4546v1, Chapter I, Theorem 2.1).

    theorem IsSublinearExpectation.isGreatest (hE : IsSublinearExpectation H E) {X : Ω → ℝ}
    (hX : X ∈ H) :
    IsGreatest {r | ∃ f : H →ₗ[ℝ] ℝ, (∀ Y : H, f Y ≤ E Y) ∧
      (∀ Y Z : H, (Y : Ω → ℝ) ≤ Z → f Y ≤ f Z) ∧ (∀ c : ℝ, f ⟨_, hE.const_mem c⟩ = c) ∧

    MathlibExt.Probability.SublinearExpectation.IsSublinearExpectation.isGreatest_finite

    If Ω is finite and E is a sublinear expectation on all functions Ω → ℝ, then E[X] = max {∑_ω q(ω) X(ω) : q ∈ Q}, where Q is the set of probability vectors q with ∑_ω q(ω) Y(ω) ≤ E[Y] for every Y; the maximum is attained. This is the finite-Ω case of Peng, arXiv:1002.4546v1, Chapter I, Theorem 2.1, which the Notes to Chapter I attribute to Huber (Robust Statistics, 1981).

    MathlibExt.Probability.SublinearExpectation.SublinearExpectationSpace.IsGNormal

    G-normal distribution, one-dimensional (S. Peng, arXiv:1002.4546v1, Chapter II, Definition 1.4 with d = 1). A real random variable X ∈ H is (centred) G-normally distributed if it has an independent copy X̄ ∈ H (X̄ =ᵈ X and X̄ independent from X) such that aX + bX̄ =ᵈ √(a² + b²) X for all a, b ≥ 0. Its law is determined by σ̄² = E[X²] and σ²_ = -E[-X²] (Chapter II, Proposition 1.7 for existence; Proposition 1.10 and Corollary 1.11 for uniqueness; Remark 3.4).
