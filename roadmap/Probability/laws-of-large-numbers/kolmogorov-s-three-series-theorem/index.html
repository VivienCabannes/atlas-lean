    DefinitionTruncation of a random variable#✓fully proved

    ProbabilityTheory.KolmogorovThreeSeries.truncatedRV

    For a sequence \(X_0, X_1, \dots\) of real-valued functions on \(\Omega\), a threshold \(A \in \mathbb{R}\) and an index \(n\), the truncation of \(X_n\) at \(A\) is \(Y_n = X_n \mathbf{1}_{\{|X_n| \le A\}}\), that is, \(Y_n(\omega) = X_n(\omega)\) when \(|X_n(\omega)| \le A\) and \(Y_n(\omega) = 0\) otherwise.

    This is the key construction in the Kolmogorov three-series theorem.

    noncomputable def truncatedRV (X : ℕ → Ω → ℝ) (A : ℝ) (n : ℕ) : Ω → ℝ :=
  fun ω => X n ω * Set.indicator {ω | |X n ω| ≤ A} 1 ω

    ProbabilityTheory.KolmogorovThreeSeries.kolmogorov_three_series_sufficiency

    Let \(X_0, X_1, \dots\) be independent real random variables on a probability space \((\Omega, P)\), fix \(A > 0\), and write \(Y_n = X_n \mathbf{1}_{\{|X_n| \le A\}}\) for the truncations. If \(\sum_n P(|X_n| > A) < \infty\), the series \(\sum_n E[Y_n]\) converges absolutely, and \(\sum_n \operatorname{Var}(Y_n) < \infty\), then there is a function \(S : \Omega \to \mathbb{R}\) with \(\sum_{i < n} X_i(\omega) \to S(\omega)\) as \(n \to \infty\) for almost every \(\omega\); that is, \(\sum_n X_n\) converges almost surely.
