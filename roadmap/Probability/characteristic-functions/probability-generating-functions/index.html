    MathlibExt.Probability.pgf

    For a measure \(\mu\) on \(\Omega\) and a function \(X : \Omega \to \mathbb{N}\), the probability generating function of \(X\) under \(\mu\) is the function \(G_X : \mathbb{R} \to \mathbb{R}\) given by

    \[G_X(s) = \int_\Omega s^{X(\omega)} \, d\mu(\omega),\]

    which is the expectation \(\mathbb{E}[s^X]\) when \(\mu\) is a probability measure.

    For a finite measure \(\mu\) and measurable \(X\) the integral converges whenever \(|s| \le 1\). Where \(s^X\) is not integrable, the integral is taken to be \(0\).

    noncomputable def pgf (X : Ω → ℕ) (μ : Measure Ω) (s : ℝ) : ℝ :=
  ∫ ω, s ^ X ω ∂μ

    MathlibExt.Probability.pgf_zero

    Let \(\mu\) be a measure on \(\Omega\) and let \(X : \Omega \to \mathbb{N}\) be measurable. Then the probability generating function \(G_X(s) = \int_\Omega s^{X(\omega)} \, d\mu(\omega)\) of \(X\) under \(\mu\) satisfies \(G_X(0) = \mu(\lbrace \omega : X(\omega) = 0 \rbrace)\), where the measure of the event is read as a real number, an infinite value being read as \(0\).

    When \(\mu\) is a probability measure this is the probability that \(X = 0\), and when \(\mu\) is finite it is the mass of that event.

    theorem pgf_zero (X : Ω → ℕ) (μ : Measure Ω) (hX : Measurable X) :
    pgf X μ 0 = μ.real {ω | X ω = 0}

    MathlibExt.Probability.pgf_eq_tsum

    Let \(\mu\) be a finite measure on \(\Omega\), let \(X : \Omega \to \mathbb{N}\) be measurable, and let \(s\) be a real number with \(|s| \le 1\). Then the probability generating function \(G_X(s) = \int_\Omega s^{X(\omega)} \, d\mu(\omega)\) of \(X\) under \(\mu\) satisfies

    \[G_X(s) = \sum_{k=0}^{\infty} s^k \, \mu(\{\omega \in \Omega : X(\omega) = k\}).\]
    theorem pgf_eq_tsum (X : Ω → ℕ) (μ : Measure Ω) [IsFiniteMeasure μ] (hX : Measurable X)
    {s : ℝ} (hs : |s| ≤ 1) :
    pgf X μ s = ∑' k, s ^ k * μ.real {ω | X ω = k}
