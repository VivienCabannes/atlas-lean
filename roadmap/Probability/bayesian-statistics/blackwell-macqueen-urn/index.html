    ProbabilityTheory.blackwellMacQueen

    The Blackwell–MacQueen urn with parameter α and base measure H: the joint law of the first n draws, where draw n has law polyaUrnPredictive α H xs given the previous draws xs (Blackwell–MacQueen 1973).

    noncomputable def blackwellMacQueen (α : ℝ) (H : Measure X) : (n : ℕ) → Measure (Fin n → X)
  | 0 => Measure.dirac fun i ↦ i.elim0
  | n + 1 => (blackwellMacQueen α H n).bind fun xs ↦
      (polyaUrnPredictive α H xs).map fun x ↦ Fin.snoc (α := fun _ ↦ X) xs x
