    Optimal stopping and the Snell envelope

    A gain \(G_n\) is observed sequentially, adapted to a filtration \((\mathcal G_n)\), and one must choose a stopping time \(\tau \le N\) to maximise \(\mathsf E\, G_\tau\). Following Peskir and Shiryaev (Optimal Stopping and Free-Boundary Problems, 2006, Chapter I, §1.1), the problem is solved by backward induction: the Snell envelope \(S_N = G_N\), \(S_n = \max(G_n, \mathsf E[S_{n+1} \mid \mathcal G_n])\) is the smallest supermartingale dominating the gain, the first time \(\tau^*\) at which \(S_n = G_n\) is optimal, \(\mathsf E\, G_{\tau^*} = \mathsf E\, S_0\) is the value, and the envelope stopped at \(\tau^*\) is a martingale. Integrability of every \(G_n\) (the book's condition (1.1.3) for a finite horizon) is assumed throughout. The pages prove Theorem 1.2: the conditional statements (1.1.9)–(1.1.10) at every time \(n \le N\), and the optimality, minimality and martingale statements (1.1.11)–(1.1.14) at time \(0\). The infinite-horizon theory with essential suprema (Theorems 1.4 and 1.6) is not yet formalised. The recursion is the prototype of Bellman's dynamic programming principle (Peskir–Shiryaev, p. 6).

    The envelope

    Backward induction defines the envelope; it is adapted, integrable, a supermartingale dominating the gain, and the smallest such sequence.

    DefinitionSnell envelope by backward induction#✓fully proved

    MeasureTheory.snellEnvelope

    For a reward sequence G, a filtration 𝒢, a measure μ and a horizon N, the Snell envelope is S N = G N and, for n < N, S n = max (G n) (E[S (n + 1) | 𝒢 n]) (Peskir and Shiryaev, Optimal Stopping and Free-Boundary Problems, Birkhäuser 2006, Chapter I, equations (1.1.6)–(1.1.7)). After the horizon the sequence is frozen at G N, which keeps it a supermartingale on all of ℕ; the book only defines it for 0 ≤ n ≤ N.

    noncomputable def snellEnvelope (𝒢 : Filtration ℕ m0) (μ : Measure Ω) (G : ℕ → Ω → ℝ)
    (N : ℕ) : ℕ → Ω → ℝ
  | n => if h : N ≤ n then G N
      else fun ω => max (G n ω) (μ[snellEnvelope 𝒢 μ G N (n + 1) | 𝒢 n] ω)
termination_by n => N - n
decreasing_by omega

    The optimal stopping time

    The first time the envelope meets the gain is a stopping time; it is optimal and the smallest optimal time, and the envelope stopped there is a martingale.

    DefinitionFirst time the Snell envelope meets the reward#✓fully proved

    MeasureTheory.snellStoppingTime

    The stopping time τ* = min {k ∈ [0, N] : S k = G k} (Peskir–Shiryaev, equation (1.1.8) with n = 0); the set is nonempty because S N = G N.

    noncomputable def snellStoppingTime (𝒢 : Filtration ℕ m0) (μ : Measure Ω) (G : ℕ → Ω → ℝ)

  hittingBtwn (fun k ω => snellEnvelope 𝒢 μ G N k ω - G k ω) {0} 0 N
