    A function \(L : \mathbb{R} \to \mathbb{R}\) is slowly varying (at infinity) if \(L(x) > 0\) for all sufficiently large \(x\) and, for every real \(c > 0\), \(L(cx) / L(x) \to 1\) as \(x \to \infty\).

    MathlibExt.Probability.RegularVariation.rightTail

    DefinitionCombined tail of a measure#✓fully proved

    MathlibExt.Probability.RegularVariation.combinedTail

    For a measure \(\mu\) on \(\mathbb{R}\) and a real number \(x\), the combined tail of \(\mu\) at \(x\) is the real number \(\mu((x, \infty)) + \mu((-\infty, -x))\), where each of the two measures is converted from \([0, \infty]\) to a real number, an infinite value becoming \(0\).

    For a finite measure and \(x \ge 0\) this equals \(\mu(\{y : |y| > x\})\). At negative thresholds the two intervals can overlap, so the combined tail is not the mass of the absolute tail.

    def combinedTail (μ : Measure ℝ) (x : ℝ) : ℝ := rightTail μ x + leftTail μ x
    def rightTail (μ : Measure ℝ) (x : ℝ) : ℝ := (μ (Set.Ioi x)).toReal

    Let \(\mu\) be a finite measure on \(\mathbb{R}\) and \(p\) a real number.
