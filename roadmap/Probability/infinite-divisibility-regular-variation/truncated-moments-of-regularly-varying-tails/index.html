    MathlibExt.Probability.TailIntegralRV.layerCake_firstMoment

    Layer-cake formula for the first moment on (0, a]: the integral of y over (0, a] equals the integral of the right tail minus the endpoint correction.

    theorem layerCake_firstMoment {μ : Measure ℝ} [IsProbabilityMeasure μ] {a : ℝ} (ha : 0 ≤ a) :
    ∫ y in Set.Ioc 0 a, y ∂μ
      = ∫ t in (0:ℝ)..a, (rightTail μ t - rightTail μ a)
    def rightTail (μ : Measure ℝ) (x : ℝ) : ℝ := (μ (Set.Ioi x)).toReal

    TheoremCorrected regularly-varying tail integral#✓fully proved

    MathlibExt.Probability.TailIntegralRV.tailIntegral_tendsto

    For a probability measure μ on ℝ with regularly varying combined tail of index -α, 0 < α < 1, and tail balance p, the first-moment tail integral satisfies (∫ y in Ioc 0 (c * x), y ∂μ) / (x * combinedTail μ x) → p * α * c ^ (1 - α) / (1 - α).

    theorem tailIntegral_tendsto {μ : Measure ℝ} [IsProbabilityMeasure μ] {α : ℝ}
    (hα : 0 < α) (hα1 : α < 1) {p : ℝ} (hTB : HasTailBalance μ p)
    (hRV : IsRegularlyVarying (combinedTail μ) (-α)) {c : ℝ} (hc : 0 < c) :
    Tendsto (fun x => (∫ y in Set.Ioc 0 (c * x), y ∂μ) / (x * combinedTail μ x))
      atTop (𝓝 (p * α * c ^ (1 - α) / (1 - α)))
    def HasTailBalance (μ : Measure ℝ) [IsFiniteMeasure μ] (p : ℝ) : Prop :=
  0 ≤ p ∧ p ≤ 1 ∧
  (∀ᶠ x in atTop, 0 < combinedTail μ x) ∧
  Tendsto (fun x => rightTail μ x / combinedTail μ x) atTop (𝓝 p)

    MathlibExt.Probability.TruncatedMoment.layerCake

    Layer-cake formula for the truncated second moment, in terms of the upper tail tailGe. The term x ^ 2 * tailGt μ x removes the contribution from points with |y| > x, which lie outside the closed truncation interval.

    theorem layerCake {μ : Measure ℝ} [IsProbabilityMeasure μ] {x : ℝ} (hx : 0 ≤ x) :
    ∫ y in Set.Icc (-x) x, y ^ 2 ∂μ
      = 2 * (∫ t in (0:ℝ)..x, t * tailGe μ t) - x ^ 2 * tailGt μ x
