    MeasureTheory.Measure.convPow

    Let \(M\) be an additive commutative monoid with a σ-algebra and let \(\nu\) be a measure on \(M\). The \(n\)-th convolution power \(\nu^{*n}\) of \(\nu\) is defined by recursion on \(n\): \(\nu^{*0} = \delta_0\), the Dirac measure at the identity \(0\) of \(M\), and \(\nu^{*(n+1)} = \nu^{*n} * \nu\), where \(*\) denotes convolution of measures.

    When addition on \(M\) is jointly measurable and \(\nu\) is the law of a random variable \(Y\), \(\nu^{*n}\) is the law of the sum of \(n\) independent copies of \(Y\).

    noncomputable def convPow {M : Type*} [AddCommMonoid M] [MeasurableSpace M]
    (ν : Measure M) : ℕ → Measure M
  | 0 => dirac 0
  | n + 1 => (ν.convPow n) ∗ ν

    DefinitionInfinitely divisible measures#✓fully proved

    MeasureTheory.Measure.IsInfinitelyDivisible

    Let \(M\) be an additive commutative monoid with a measurable structure in which addition is jointly measurable. A measure \(\mu\) on \(M\) is infinitely divisible if for every natural number \(n \ge 1\) there is a probability measure \(\nu\) on \(M\) whose \(n\)-fold convolution power \(\nu^{*n}\) equals \(\mu\).

    Equivalently, a random variable \(X\) with law \(\mu\) can, for every \(n \ge 1\), be written in law as the sum of \(n\) i.i.d. copies of some random variable \(Y\).

    def IsInfinitelyDivisible {M : Type*} [AddCommMonoid M] [MeasurableSpace M]
    [MeasurableAdd₂ M]
    (μ : Measure M) : Prop :=
  ∀ n : ℕ, n ≥ 1 → ∃ ν : Measure M, IsProbabilityMeasure ν ∧ μ = ν.convPow n

    TheoremInfinite divisibility through iterated convolution#✓fully proved

    MeasureTheory.Measure.isInfinitelyDivisible_iff_exists_iterate

    Let \(M\) be an additive commutative monoid with a measurable structure in which addition is jointly measurable. A measure \(\mu\) on \(M\) is infinitely divisible if and only if for every natural number \(n \ne 0\) there is a probability measure \(\nu\) on \(M\) such that \(\mu = \nu * (\nu * (\cdots * (\nu * \nu)))\) with \(n\) factors \(\nu\), that is, \(\mu\) is obtained from \(\nu\) by convolving on the left with \(\nu\) exactly \(n - 1\) times.

    theorem isInfinitelyDivisible_iff_exists_iterate [MeasurableAdd₂ M] (μ : Measure M) :

      ∀ n : ℕ, n ≠ 0 → ∃ ν : Measure M, IsProbabilityMeasure ν ∧
        μ = Nat.iterate (Measure.conv ν) (n - 1) ν
