    StatMech.ReimerWprobCore

    Reimer's inequality (the van den Berg–Kesten conjecture, proved by Reimer 2000) for product probability weights on Fin n: for every n, every weight φ with φ ≥ 0 and φ i false + φ i true = 1, and all events A, B, wprob φ (A □ B) ≤ wprob φ A * wprob φ B.

    def ReimerWprobCore : Prop :=
  ∀ (n : ℕ) (φ : Fin n → Bool → ℝ),
    (∀ i b, 0 ≤ φ i b) → (∀ i, φ i false + φ i true = 1) →
    ∀ (A B : Set (ConfigSpace (Fin n))),
      wprob φ (disjointOccurrence A B) ≤ wprob φ A * wprob φ B

    Reimer's inequality P_p(A □ B) ≤ P_p(A) * P_p(B) for all events under the product Bernoulli measure on a finite set, assuming ReimerWprobCore.

    theorem reimer_inequality_of_core (h : ReimerWprobCore) [Fintype E] [DecidableEq E]
    {p : ℝ≥0} (hp : p ≤ 1) (A B : Set (ConfigSpace E)) :

      ≤ (bernoulliProductMeasure (E := E) p hp).real A
