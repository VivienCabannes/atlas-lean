    TheoremSlice inequalities in the one-coordinate BK induction step#✓fully proved

    StatMech.slice_disjointOccurrence_le_of_isIncreasing

    The slice inequalities of the one-coordinate BK induction step, with A₀, A₁, B₀, B₁ the slices at the first coordinate: P(A₀ □ B₀) ≤ P((A₀ □ B₁) ∩ (A₁ □ B₀)) and P((A₀ □ B₁) ∪ (A₁ □ B₀)) ≤ P(A₁) P(B₁), for increasing events A, B.

    theorem slice_disjointOccurrence_le_of_isIncreasing (n : ℕ) (ψ : Fin n → Bool → ℝ)
    (hψ0 : ∀ i b, 0 ≤ ψ i b) (hψ1 : ∀ i, ψ i false + ψ i true = 1)
    (A B : Set (ConfigSpace (Fin (n + 1)))) (hA : IsIncreasing A) (hB : IsIncreasing B) :
    wprob ψ (disjointOccurrence (slice A false) (slice B false))
        ≤ wprob ψ (disjointOccurrence (slice A false) (slice B true)
                    ∩ disjointOccurrence (slice A true) (slice B false))
    ∧ wprob ψ (disjointOccurrence (slice A false) (slice B true)
                ∪ disjointOccurrence (slice A true) (slice B false))
        ≤ wprob ψ (slice A true) * wprob ψ (slice B true)
