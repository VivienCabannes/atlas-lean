    DefinitionStorey's positive false discovery rate#✓fully proved

    MathlibExt.Probability.Statistics.TwoGroupsTesting.positiveFDR

    noncomputable def positiveFDR (q : Bool × Bool → ℝ) (m : ℕ) : ℝ :=
  (∑ x : Fin m → Bool × Bool, outcomeWeight q x *
      falseDiscoveryProportion (nullSet x) (rejectedSet x)) /
    ∑ x : Fin m → Bool × Bool, if (rejectedSet x).Nonempty then outcomeWeight q x else 0

    TheoremStorey's theorem: pFDR is a posterior null probability#✓fully proved

    MathlibExt.Probability.Statistics.TwoGroupsTesting.positiveFDR_eq

    Storey (2002), Theorem 1: for m ≥ 1 i.i.d. tests, pFDR = P(H = 0 | T ∈ Γ), where q (true, true) = P(H = 0, T ∈ Γ) and q (false, true) = P(H = 1, T ∈ Γ). The identity is homogeneous in q, so only q ≥ 0 is assumed; when P(T ∈ Γ) = 0 both sides are 0.

    theorem positiveFDR_eq (q : Bool × Bool → ℝ) (hq : ∀ b, 0 ≤ q b) (hm : 0 < m) :
    positiveFDR q m = q (true, true) / (q (true, true) + q (false, true))
    noncomputable def positiveFDR (q : Bool × Bool → ℝ) (m : ℕ) : ℝ :=
