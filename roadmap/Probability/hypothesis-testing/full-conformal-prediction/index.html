    Full conformal prediction

    Full (transductive) conformal prediction needs no held-out calibration set. For a test covariate \(x\) and each trial response \(y\), it refits the model on the augmented data \(Z_1, \dots, Z_n, (x, y)\), scores all \(n + 1\) points, and keeps \(y\) when the score of the trial point is at most the \(\lceil (1 - \alpha)(n + 1) \rceil\)-th smallest of the other \(n\) scores. At the true response the augmented data set is the data itself. So if the data are exchangeable and the scores are permutation equivariant (as residuals of a fitting algorithm that is symmetric in the data are), the coverage event is the split conformal event for an exchangeable score vector. The full conformal set therefore covers \(Y_{n+1}\) with probability at least \(1 - \alpha\), and at most \(1 - \alpha + 1/(n + 1)\) when there are no ties (Lei, G'Sell, Rinaldo, Tibshirani and Wasserman, arXiv:1604.04173v2, Theorem 2.1). Both bounds are proved here, for any exchangeable law, which includes the i.i.d. setting of the source.

    DefinitionPermutation-equivariant score map#✓fully proved

    MathlibExt.Probability.Statistics.FullConformal.IsPermEquivariant

    A map \(S\) from data vectors \(z = (z_1, \dots, z_{n+1})\) to score vectors in \(\mathbb{R}^{n+1}\) is permutation equivariant if permuting the data points permutes the scores in the same way: \(S(z \circ \sigma) = S(z) \circ \sigma\) for every permutation \(\sigma\) of \(\{1, \dots, n+1\}\).

    Scores of the form \(S(z)_i = f(z_{-i}; z_i)\), with \(f\) symmetric in its first \(n\) arguments, have this property; these are the conformity scores of Lei et al., Remark 2.4. So do the absolute residuals of a fitting algorithm that is symmetric in the data.

    def IsPermEquivariant (S : (Fin (n + 1) → 𝒵) → Fin (n + 1) → ℝ) : Prop :=
  ∀ (σ : Equiv.Perm (Fin (n + 1))) (z : Fin (n + 1) → 𝒵), S (z ∘ σ) = S z ∘ σ

    TheoremEquivariant scores of exchangeable data are exchangeable#✓fully proved

    MathlibExt.Probability.Statistics.FullConformal.map_comp_perm_map_eq

    Let the law \(\mu\) of the data vector \((Z_1, \dots, Z_{n+1})\) be invariant under every coordinate permutation, and let the score map \(S\) be measurable and permutation equivariant. Then the law of the score vector \(S(Z)\) is invariant under every coordinate permutation. Indeed, \(S(Z) \circ \sigma = S(Z \circ \sigma)\), and \(Z \circ \sigma\) has the same law as \(Z\).

    This is the step that lets the split conformal bounds, which are statements about an exchangeable score vector, apply to full conformal prediction.

    theorem map_comp_perm_map_eq (μ : Measure (Fin (n + 1) → 𝒵))
    (hμ : ∀ σ : Equiv.Perm (Fin (n + 1)), μ.map (fun z => z ∘ σ) = μ)
    {S : (Fin (n + 1) → 𝒵) → Fin (n + 1) → ℝ} (hS : IsPermEquivariant S) (hSm : Measurable S)
    (σ : Equiv.Perm (Fin (n + 1))) :
    (μ.map S).map (fun ω => ω ∘ σ) = μ.map S
    def IsPermEquivariant (S : (Fin (n + 1) → 𝒵) → Fin (n + 1) → ℝ) : Prop :=
  ∀ (σ : Equiv.Perm (Fin (n + 1))) (z : Fin (n + 1) → 𝒵), S (z ∘ σ) = S z ∘ σ

    DefinitionFull conformal prediction set#✓fully proved

    MathlibExt.Probability.Statistics.FullConformal.fullConformalSet

    Let \(z = (z_1, \dots, z_n)\) be \(n\) data points \(z_i = (x_i, y_i) \in \mathcal X \times \mathcal Y\), let \(x\) be a test covariate, and let \(S\) be a score map on augmented data vectors of length \(n + 1\). For a trial response \(y\), write \(R^y = S(z_1, \dots, z_n, (x, y))\). The full conformal set at level \(k\) is

    \[C_k(z, x) = \bigl\{ y \in \mathcal Y : R^y_{n+1} \le R^y_{(k)} \bigr\},\]

    where \(R^y_{(k)}\) is the \(k\)-th smallest of \(R^y_1, \dots, R^y_n\), counted with multiplicity, and \(+\infty\) when \(k > n\). Equivalently, \(y\) is kept when fewer than \(k\) of the \(n\) data scores are strictly smaller than the trial score. The level used in the theorems is \(k = \lceil (1 - \alpha)(n + 1) \rceil\).

    When the \(n + 1\) scores are distinct, this is the set \(\{y : (n + 1)\pi(y) \le \lceil (1 - \alpha)(n + 1) \rceil\}\) of Lei et al., equation (7). The two sets treat ties differently. Their \(\pi(y)\) in (5) counts the data scores with \(R^y_i \le R^y_{n+1}\), so a trial value tied with many data scores is excluded. Here only the strictly smaller scores count, as in the split conformal threshold of this library, so such a value is kept. With the count of (5), the lower coverage bound needs the scores to be almost surely distinct (or ties to be broken at random). For example, if every residual is \(0\) almost surely, the set (7) never contains \(Y_{n+1}\) once \(\alpha \ge 1/(n+1)\). With the count used here, the lower bound holds with no assumption on ties.

    def fullConformalSet (S : (Fin (n + 1) → 𝒳 × 𝒴) → Fin (n + 1) → ℝ) (k : ℕ)
    (z : Fin n → 𝒳 × 𝒴) (x : 𝒳) : Set 𝒴 :=
  {y | (S (Fin.snoc (α := fun _ => 𝒳 × 𝒴) z (x, y)) (Fin.last n) : WithTop ℝ) ≤
    splitConformalThreshold k (S (Fin.snoc (α := fun _ => 𝒳 × 𝒴) z (x, y)))}
    noncomputable def splitConformalThreshold (k : ℕ) (ω : Fin (n + 1) → ℝ) : WithTop ℝ :=
  orderStatistic (fun i : Fin n => ω i.castSucc) k

    TheoremFull conformal coverage event as a split conformal event#✓fully proved

    MathlibExt.Probability.Statistics.FullConformal.setOf_mem_fullConformalSet_eq

    For a data vector \(Z = (Z_1, \dots, Z_{n+1})\) with \(Z_{n+1} = (X_{n+1}, Y_{n+1})\), the event \(Y_{n+1} \in C_k(Z_1, \dots, Z_n; X_{n+1})\) equals the event that the last coordinate of the score vector \(S(Z)\) is at most the \(k\)-th smallest of its first \(n\) coordinates. The reason is that at the true response \(y = Y_{n+1}\) the augmented data set \((Z_1, \dots, Z_n, (X_{n+1}, y))\) is \(Z\) itself.

    This identity is the whole of the reduction of full conformal prediction to the split conformal case: it is how Lei et al. derive the first part of their Theorem 2.1 from the rank property (6).

    theorem setOf_mem_fullConformalSet_eq (S : (Fin (n + 1) → 𝒳 × 𝒴) → Fin (n + 1) → ℝ) (k : ℕ) :
    {z : Fin (n + 1) → 𝒳 × 𝒴 |
        (z (Fin.last n)).2 ∈ fullConformalSet S k (Fin.init z) (z (Fin.last n)).1} =
      S ⁻¹' {ω | (ω (Fin.last n) : WithTop ℝ) ≤ splitConformalThreshold k ω}
    def fullConformalSet (S : (Fin (n + 1) → 𝒳 × 𝒴) → Fin (n + 1) → ℝ) (k : ℕ)

    TheoremFull conformal coverage#✓fully proved

    MathlibExt.Probability.Statistics.FullConformal.ofReal_one_sub_le_measure_mem_fullConformalSet

    Let the law \(\mu\) of the data vector \((Z_1, \dots, Z_{n+1})\), with \(Z_i = (X_i, Y_i)\), be a probability measure invariant under every coordinate permutation; an i.i.d. law is an example. Let the score map \(S\) be measurable and permutation equivariant. Then for \(0 \le \alpha < 1\) the full conformal set built from the first \(n\) points at level \(k = \lceil (1 - \alpha)(n + 1) \rceil\) covers \(Y_{n+1}\) at \(X_{n+1}\) with probability at least \(1 - \alpha\):

    \[\mu\bigl(Y_{n+1} \in C_k(Z_1, \dots, Z_n; X_{n+1})\bigr) \ge 1 - \alpha.\]

    Lei et al. state this for i.i.d. data and a fitting algorithm that is symmetric in the data. The statement here assumes exchangeability only and allows any measurable equivariant score, which includes their absolute residuals. It also allows ties, which their count (5) does not; see Full conformal prediction set. The source's range is \(0 < \alpha < 1\); the endpoint \(\alpha = 0\) (the set is all of \(\mathcal Y\)) is a trivial case.

    theorem ofReal_one_sub_le_measure_mem_fullConformalSet (μ : Measure (Fin (n + 1) → 𝒳 × 𝒴))
    [IsProbabilityMeasure μ] (hμ : ∀ σ : Equiv.Perm (Fin (n + 1)), μ.map (fun z => z ∘ σ) = μ)
    {S : (Fin (n + 1) → 𝒳 × 𝒴) → Fin (n + 1) → ℝ} (hS : IsPermEquivariant S)
    (hSm : Measurable S) {α : ℝ} (hα0 : 0 ≤ α) (hα1 : α < 1) :
    ENNReal.ofReal (1 - α) ≤
      μ {z | (z (Fin.last n)).2 ∈
        fullConformalSet S ⌈(1 - α) * (n + 1)⌉₊ (Fin.init z) (z (Fin.last n)).1}

    TheoremUpper bound on full conformal coverage without ties#✓fully proved

    MathlibExt.Probability.Statistics.FullConformal.measure_mem_fullConformalSet_le

    Under the hypotheses of full conformal coverage, if moreover the \(n + 1\) scores \(S(Z)\) are almost surely distinct, then for \(0 \le \alpha < 1\) the full conformal set at level \(k = \lceil (1 - \alpha)(n + 1) \rceil\) covers \(Y_{n+1}\) with probability at most \(1 - \alpha + 1/(n + 1)\). Together with the lower bound, full conformal prediction is valid and nearly exact: its coverage lies in \([1 - \alpha, 1 - \alpha + 1/(n+1)]\).

    Lei et al. assume that the fitted absolute residuals have a continuous joint distribution, and use it only to exclude ties; almost sure distinctness is the hypothesis used here. Without it the bound fails: if all scores are equal, the coverage is \(1\).

    DefinitionAbsolute residual score of a fitting algorithm#✓fully proved

    MathlibExt.Probability.Statistics.FullConformal.absResidualScore

    Let \(A\) be a fitting algorithm that maps a data vector \(z\) of length \(n + 1\) to a regression function \(\hat\mu = A(z) : \mathcal X \to \mathbb{R}\). Its absolute residual score is \(S(z)_i = \lvert y_i - \hat\mu(x_i) \rvert\), the residual of point \(i\) under the fit trained on all \(n + 1\) points. Evaluated on the augmented data \((z_1, \dots, z_n, (x, y))\), these are the residuals \(R_{y,i}\) of Lei et al., equation (4), with \(\hat\mu_y = A(z_1, \dots, z_n, (x, y))\).

    (z : Fin (n + 1) → 𝒳 × ℝ) (i : Fin (n + 1)) : ℝ :=
  |(z i).2 - A z (z i).1|

    Related topics

    • Split conformal prediction: the coverage bounds for an exchangeable score vector, to which full conformal prediction reduces; split conformal prediction avoids refitting for every trial response at the price of a held-out calibration set.
    • Permutation tests: the conformal p-value of a trial response is the permutation p-value of its score among the augmented scores.
    • Negative binomial and beta-binomial distributions: the topic holds product measures are exchangeable, so i.i.d. data satisfy the hypothesis of the coverage theorems, and the law of the rank of a test score among i.i.d. scores.
    • Bootstrap and the Mallows metric: the bootstrap gives asymptotic predictive and confidence statements under regularity conditions; conformal prediction gives finite-sample marginal coverage with none.
