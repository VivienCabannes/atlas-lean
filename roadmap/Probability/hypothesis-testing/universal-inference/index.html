    Universal inference

    Universal inference (Wasserman, Ramdas and Balakrishnan, PNAS 2020) gives confidence sets and tests with finite-sample validity in any model with a likelihood, including irregular models such as mixtures, where the likelihood ratio statistic has no tractable limit. Split the sample into two independent halves \(D_1\) and \(D_0\), compute any estimate \(\hat\theta_1\) from \(D_1\), and evaluate the likelihood \(\mathcal L_0\) on \(D_0\). A likelihood ratio has mean at most one under its denominator, \(E_{\theta^*}[\mathcal L_0(\psi) / \mathcal L_0(\theta^*)] \le 1\), so Markov's inequality shows two things. The set \(\{\theta : \mathcal L_0(\hat\theta_1) / \mathcal L_0(\theta) \le 1/\alpha\}\) covers the true parameter with probability at least \(1 - \alpha\). The split likelihood ratio test, which rejects when \(\mathcal L_0(\hat\theta_1) / \mathcal L_0(\hat\theta_0) > 1/\alpha\) with \(\hat\theta_0\) the maximum likelihood estimator under the null, has type I error at most \(\alpha\). Both statements are proved here, for an i.i.d. second half and for a general dominated model. The crossfit and sequential (anytime-valid) versions are not formalized.

    TheoremMarkov's inequality for a likelihood ratio#✓fully proved

    MathlibExt.Probability.Statistics.UniversalInference.withDensity_inv_mul_lt_le

    Let \(q_0\) and \(q_1\) be measurable densities with respect to a measure \(\nu\), with \(\int q_1 \, d\nu \le 1\). Under the law \(P_0 = q_0 \, \nu\), the likelihood ratio \(q_1 / q_0\) exceeds \(1/\alpha\) with probability at most \(\alpha\), for every \(0 < \alpha < \infty\):

    \[P_0\bigl(\alpha^{-1} q_0(Y) < q_1(Y)\bigr) \le \alpha.\]

    The proof is Markov's inequality applied to the likelihood ratio, whose mean under \(P_0\) is at most \(\int q_1 \, d\nu \le 1\); written without division, on the event one has \(q_0 \le \alpha q_1\), so its \(P_0\)-probability is at most \(\alpha \int q_1 \, d\nu\). This is display (7) of Wasserman, Ramdas and Balakrishnan for a fixed alternative \(\psi\) (\(q_1 = \mathcal L_0(\psi)\), \(q_0 = \mathcal L_0(\theta^*)\)), together with the bound \(E_{\theta^*}[\mathcal L_0(\psi)/\mathcal L_0(\theta^*)] \le 1\) displayed just before it.

    theorem withDensity_inv_mul_lt_le (ν : Measure 𝒴) {q₀ q₁ : 𝒴 → ℝ≥0∞} (hq₀ : Measurable q₀)
    (hq₁ : Measurable q₁) (h1 : ∫⁻ y, q₁ y ∂ν ≤ 1) {α : ℝ≥0∞} (hα0 : α ≠ 0) (hαtop : α ≠ ∞) :
    ν.withDensity q₀ {y | α⁻¹ * q₀ y < q₁ y} ≤ α

    DefinitionUniversal confidence set#✓fully proved

    MathlibExt.Probability.Statistics.UniversalInference.universalConfidenceSet

    Let \(q_\theta\) be the densities of the second half \(D_0\) of the sample, let \(\theta_1\) be an estimate computed from the first half \(D_1\), and let \(y\) be the observed second half. The universal set is

    \[C = \bigl\{\theta : q_{\theta_1}(y) \le \alpha^{-1} q_\theta(y)\bigr\},\]

    that is, \(\{\theta : T(\theta) \le 1/\alpha\}\) with the split likelihood ratio statistic \(T(\theta) = \mathcal L_0(\hat\theta_1)/\mathcal L_0(\theta)\) of equation (3). Ratios are written without division: \(T(\theta) \le 1/\alpha\) is \(\mathcal L_0(\hat\theta_1) \le \alpha^{-1} \mathcal L_0(\theta)\) in \([0, \infty]\). This fixes the convention \(0/0 = 0\). The convention does not affect the coverage and type I error statements: for them it matters only on samples of probability zero under the true parameter. It does decide which other parameters belong to the set. When \(\mathcal L_0(\hat\theta_1) = 0\), every \(\theta\) with \(\mathcal L_0(\theta) = 0\) is in the set, and this can happen with positive probability.

    def universalConfidenceSet (q : Θ → 𝒴 → ℝ≥0∞) (α : ℝ≥0∞) (θ₁ : Θ) (y : 𝒴) : Set Θ :=
  {θ | q θ₁ y ≤ α⁻¹ * q θ y}

    TheoremFinite-sample validity of the universal confidence set#✓fully proved

    MathlibExt.Probability.Statistics.UniversalInference.measure_not_mem_universalConfidenceSet_le

    Let \(q_\theta\) be densities with respect to a measure \(\nu\) on the sample space of \(D_0\), jointly measurable in \((\theta, y)\), with \(\int q_\theta \, d\nu \le 1\) for every \(\theta\). Let \(D_1\) have law \(\rho\), independent of \(D_0\), whose law is \(q_{\theta^*} \nu\), and let \(\hat\theta_1\) be any measurable estimator computed from \(D_1\). Then for every \(0 < \alpha < \infty\)

    \[P\bigl(\theta^* \notin C\bigr) \le \alpha, \qquad C = \{\theta : q_{\hat\theta_1}(D_0) \le \alpha^{-1} q_\theta(D_0)\}.\]

    No regularity of the model is needed: no smoothness, no identifiability, no asymptotics. This is Theorem 1 in the generality of Remark 2 of Wasserman, Ramdas and Balakrishnan, where \(D_0\) may be any sample with a likelihood; the i.i.d. case of their Theorem 1 is the next statement. Ratios are written without division: \(T(\theta) \le 1/\alpha\) is \(\mathcal L_0(\hat\theta_1) \le \alpha^{-1} \mathcal L_0(\theta)\) in \([0, \infty]\). This fixes the convention \(0/0 = 0\), which matters only on samples of probability zero under the true parameter.

    theorem measure_not_mem_universalConfidenceSet_le (ν : Measure 𝒴) [SFinite ν]
    (ρ : Measure 𝒲) [IsProbabilityMeasure ρ] {q : Θ → 𝒴 → ℝ≥0∞}
    (hq : Measurable (Function.uncurry q)) (hq1 : ∀ θ, ∫⁻ y, q θ y ∂ν ≤ 1)
    {θhat₁ : 𝒲 → Θ} (hθhat₁ : Measurable θhat₁) (θstar : Θ) {α : ℝ≥0∞} (hα0 : α ≠ 0)
    (hαtop : α ≠ ∞) :
    (ρ.prod (ν.withDensity (q θstar)))
        {p | θstar ∉ universalConfidenceSet q α (θhat₁ p.1) p.2} ≤ α
    def universalConfidenceSet (q : Θ → 𝒴 → ℝ≥0∞) (α : ℝ≥0∞) (θ₁ : Θ) (y : 𝒴) : Set Θ :=
  {θ | q θ₁ y ≤ α⁻¹ * q θ y}

    TheoremUniversal confidence set for an i.i.d. sample#✓fully proved

    MathlibExt.Probability.Statistics.UniversalInference.measure_not_mem_universalConfidenceSet_le_pi

    Let \(p_\theta\) be probability densities (or sub-densities, \(\int p_\theta \, d\nu \le 1\)) with respect to a σ-finite measure \(\nu\), jointly measurable in \((\theta, y)\). Let \(D_0 = (Y_1, \dots, Y_m)\) be i.i.d. with density \(p_{\theta^*}\), independent of \(D_1 \sim \rho\), and let \(\hat\theta_1\) be any measurable estimator computed from \(D_1\). With the split likelihood \(\mathcal L_0(\theta) = \prod_{i=1}^m p_\theta(Y_i)\), the universal set \(\{\theta : \mathcal L_0(\hat\theta_1) \le \alpha^{-1} \mathcal L_0(\theta)\}\) misses \(\theta^*\) with probability at most \(\alpha\), for every \(0 < \alpha < \infty\).

    The source splits \(2n\) observations into halves of size \(n\) and remarks that equal sizes are not necessary; here \(D_1\) is arbitrary and \(D_0\) has size \(m\). Ratios are written without division: \(T(\theta) \le 1/\alpha\) is \(\mathcal L_0(\hat\theta_1) \le \alpha^{-1} \mathcal L_0(\theta)\) in \([0, \infty]\). This fixes the convention \(0/0 = 0\), which matters only on samples of probability zero under the true parameter.

    theorem measure_not_mem_universalConfidenceSet_le_pi (ν : Measure 𝒴) [SigmaFinite ν]
    (ρ : Measure 𝒲) [IsProbabilityMeasure ρ] {p : Θ → 𝒴 → ℝ≥0∞}
    (hp : Measurable (Function.uncurry p)) (hp1 : ∀ θ, ∫⁻ y, p θ y ∂ν ≤ 1)
    {θhat₁ : 𝒲 → Θ} (hθhat₁ : Measurable θhat₁) (θstar : Θ) {α : ℝ≥0∞} (hα0 : α ≠ 0)
    (hαtop : α ≠ ∞) :
    (ρ.prod (Measure.pi fun _ : Fin m => ν.withDensity (p θstar)))
        {w | θstar ∉ universalConfidenceSet (fun θ (y : Fin m → 𝒴) => ∏ i, p θ (y i)) α
          (θhat₁ w.1) w.2} ≤ α

    TheoremType I error of the split likelihood ratio test#✓fully proved

    MathlibExt.Probability.Statistics.UniversalInference.measure_splitLRT_reject_le

    In the setting of the general universal confidence set, let \(\Theta_0\) be a null set containing the true parameter \(\theta^*\), and let \(\hat\theta_0\) map each second half \(y\) to a parameter whose likelihood dominates that of every element of \(\Theta_0\): \(q_\theta(y) \le q_{\hat\theta_0(y)}(y)\) for \(\theta \in \Theta_0\). The maximum likelihood estimator over \(\Theta_0\) is an example. The split likelihood ratio test rejects \(H_0 : \theta^* \in \Theta_0\) when \(U = q_{\hat\theta_1}(D_0) / q_{\hat\theta_0(D_0)}(D_0) > 1/\alpha\), that is, when \(\alpha^{-1} q_{\hat\theta_0(D_0)}(D_0) < q_{\hat\theta_1}(D_0)\). Its rejection probability is at most \(\alpha\), for every \(0 < \alpha < \infty\).

    The proof is step (i) of Wasserman, Ramdas and Balakrishnan: under the null, replacing \(\hat\theta_0\) by \(\theta^*\) can only increase \(U\), so a rejection implies that the universal set misses \(\theta^*\). The statement assumes only the domination property of \(\hat\theta_0\), which is weaker than \(\hat\theta_0\) being the maximiser.

    theorem measure_splitLRT_reject_le (ν : Measure 𝒴) [SFinite ν]
    (ρ : Measure 𝒲) [IsProbabilityMeasure ρ] {q : Θ → 𝒴 → ℝ≥0∞}
    (hq : Measurable (Function.uncurry q)) (hq1 : ∀ θ, ∫⁻ y, q θ y ∂ν ≤ 1)
    {θhat₁ : 𝒲 → Θ} (hθhat₁ : Measurable θhat₁) {Θ₀ : Set Θ} {θhat₀ : 𝒴 → Θ}
    (hθhat₀ : ∀ y, ∀ θ ∈ Θ₀, q θ y ≤ q (θhat₀ y) y) {θstar : Θ} (hθstar : θstar ∈ Θ₀)
    {α : ℝ≥0∞} (hα0 : α ≠ 0) (hαtop : α ≠ ∞) :
    (ρ.prod (ν.withDensity (q θstar))) {p | α⁻¹ * q (θhat₀ p.2) p.2 < q (θhat₁ p.1) p.2} ≤ α

    TheoremSplit likelihood ratio test for an i.i.d. sample#✓fully proved

    MathlibExt.Probability.Statistics.UniversalInference.measure_splitLRT_reject_le_pi

    In the setting of the i.i.d. universal confidence set, let \(\Theta_0\) contain the true parameter \(\theta^*\) and let \(\hat\theta_0\) be a maximiser of the split likelihood \(\mathcal L_0\) over \(\Theta_0\) (only \(\mathcal L_0(\theta) \le \mathcal L_0(\hat\theta_0)\) for \(\theta \in \Theta_0\) is used). The split likelihood ratio test, which rejects \(H_0 : \theta^* \in \Theta_0\) when \(\mathcal L_0(\hat\theta_1) / \mathcal L_0(\hat\theta_0) > 1/\alpha\), has type I error at most \(\alpha\), for every \(0 < \alpha < \infty\):

    \[\sup_{\theta^* \in \Theta_0} P_{\theta^*}\bigl(U_n > 1/\alpha\bigr) \le \alpha.\]

    The test applies to irregular models, such as testing the number of components of a Gaussian mixture, where the ordinary likelihood ratio statistic has no tractable limit. The crossfit version, which averages \(U_n\) with the statistic obtained by swapping the two halves, satisfies the same bound by the same argument but is not formalized here. The ratio is written without division: \(U_n > 1/\alpha\) is \(\alpha^{-1} \mathcal L_0(\hat\theta_0) < \mathcal L_0(\hat\theta_1)\) in \([0, \infty]\). This fixes the convention \(0/0 = 0\) (no rejection when both likelihoods vanish), which matters for the type I error only on samples of probability zero under the true parameter.

    theorem measure_splitLRT_reject_le_pi (ν : Measure 𝒴) [SigmaFinite ν]
    (ρ : Measure 𝒲) [IsProbabilityMeasure ρ] {p : Θ → 𝒴 → ℝ≥0∞}
    (hp : Measurable (Function.uncurry p)) (hp1 : ∀ θ, ∫⁻ y, p θ y ∂ν ≤ 1)
    {θhat₁ : 𝒲 → Θ} (hθhat₁ : Measurable θhat₁) {Θ₀ : Set Θ} {θhat₀ : (Fin m → 𝒴) → Θ}
    (hθhat₀ : ∀ y, ∀ θ ∈ Θ₀, ∏ i, p θ (y i) ≤ ∏ i, p (θhat₀ y) (y i)) {θstar : Θ}
    (hθstar : θstar ∈ Θ₀) {α : ℝ≥0∞} (hα0 : α ≠ 0) (hαtop : α ≠ ∞) :
    (ρ.prod (Measure.pi fun _ : Fin m => ν.withDensity (p θstar)))
        {w | α⁻¹ * ∏ i, p (θhat₀ w.2) (w.2 i) < ∏ i, p (θhat₁ w.1) (w.2 i)} ≤ α

    Related topics

    • Score, Wald and likelihood-ratio tests: the classical likelihood ratio test, calibrated by Wilks's asymptotic chi-squared limit in regular models; universal inference splits the sample to get a level guarantee in every model and every sample size.
    • Neyman–Pearson lemma: the likelihood ratio between two simple hypotheses, whose mean under the null is at most one, the property universal inference rests on.
    • Valid p-values and false discovery proportion: by the same Markov argument, \(1/U\) (capped at \(1\)) is a valid p-value for the null, the form Wasserman, Ramdas and Balakrishnan use for their anytime-valid p-values (arXiv:1912.11436v4, Section 8); it is not stated separately here.
