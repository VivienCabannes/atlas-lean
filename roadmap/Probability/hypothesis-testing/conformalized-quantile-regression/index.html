    Conformalized quantile regression

    Conformalized quantile regression (CQR; Romano, Patterson and Candès, NeurIPS 2019) combines the adaptivity of quantile regression with the finite-sample validity of split conformal prediction. Two conditional quantile functions q̂_lo and q̂_hi, fitted on a proper training set, give a band [q̂_lo(x), q̂_hi(x)] whose width follows the local spread of the response but whose coverage is not guaranteed. CQR calibrates it on n held-out points with the conformity scores E_i = max (q̂_lo(X_i) - Y_i, Y_i - q̂_hi(X_i)), takes Q, the ⌈(1 - α)(n + 1)⌉-th smallest score, and returns C(x) = [q̂_lo(x) - Q, q̂_hi(x) + Q]. If the data are exchangeable, the test response lies in C(X_{n+1}) with probability at least 1 - α, and at most 1 - α + 1 / (n + 1) when the scores are almost surely distinct (Theorem 1). Both bounds are proved here as corollaries of split conformal coverage applied to the score vector.

    MathlibExt.Probability.Statistics.ConformalizedQuantileRegression.cqrBand

    For a threshold Q ∈ ℝ ∪ {+∞}, the band at x is [q_lo x - Q, q_hi x + Q], written as the set of y with q_lo x - y ≤ Q and y - q_hi x ≤ Q; it is all of ℝ when Q = ⊤.

    def cqrBand (q_lo q_hi : 𝒳 → ℝ) (Q : WithTop ℝ) (x : 𝒳) : Set ℝ :=
  {y | ((q_lo x - y : ℝ) : WithTop ℝ) ≤ Q ∧ ((y - q_hi x : ℝ) : WithTop ℝ) ≤ Q}

    DefinitionCQR conformity score#✓fully proved

    MathlibExt.Probability.Statistics.ConformalizedQuantileRegression.cqrScore

    For fitted lower and upper conditional quantile functions q_lo, q_hi, the score of a data point (x, y) is max (q_lo x - y) (y - q_hi x): negative when y lies strictly inside [q_lo x, q_hi x], and the signed distance to the nearer endpoint otherwise.

    def cqrScore (q_lo q_hi : 𝒳 → ℝ) (z : 𝒳 × ℝ) : ℝ :=
  max (q_lo z.1 - z.2) (z.2 - q_hi z.1)

    DefinitionCQR threshold#✓fully proved

    MathlibExt.Probability.Statistics.ConformalizedQuantileRegression.cqrThreshold

    The k-th smallest CQR score of the calibration points Z i.castSucc (counted with multiplicity), and ⊤ when k > n. With k = ⌈(1 - α)(n + 1)⌉ this is the (1 - α)(1 + 1/n)-th empirical quantile Q_{1-α}(E, I₂) of Romano, Patterson and Candès (NeurIPS 2019, arXiv:1905.03222, Algorithm 1), with Q = +∞ when that level exceeds 1.

    noncomputable def cqrThreshold (q_lo q_hi : 𝒳 → ℝ) (k : ℕ) (Z : Fin (n + 1) → 𝒳 × ℝ) :
    WithTop ℝ :=
  splitConformalThreshold k fun i => cqrScore q_lo q_hi (Z i)
    noncomputable def splitConformalThreshold (k : ℕ) (ω : Fin (n + 1) → ℝ) : WithTop ℝ :=
  orderStatistic (fun i : Fin n => ω i.castSucc) k

    MathlibExt.Probability.Statistics.ConformalizedQuantileRegression.ofReal_one_sub_le_measure_mem_cqrBand

    Let the law μ of the data Z : Fin (n + 1) → 𝒳 × ℝ (n calibration points, then the test point) be a probability measure invariant under every coordinate permutation, and let q_lo, q_hi be measurable. For 0 ≤ α < 1, with k = ⌈(1 - α)(n + 1)⌉, the test response lies in the CQR band at the test covariate with probability at least 1 - α.
