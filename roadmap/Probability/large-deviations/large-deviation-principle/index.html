    StructureGood rate function#✓fully proved

    MathlibExt.Probability.LargeDeviationPrinciple.IsGoodRateFunction

    Let \(X\) be a topological space. A function \(I : X \to [0, \infty]\) is a good rate function if it is a rate function and, for every real number \(a \ge 0\), the sub-level set \(\{x \in X : I(x) \le a\}\) is compact.

    Compactness is required only at finite levels: the sub-level set at level \(\infty\) is all of \(X\), so requiring it as well would force \(X\) itself to be compact.

    structure IsGoodRateFunction {X : Type*} [TopologicalSpace X] (I : X → ℝ≥0∞) : Prop
    extends IsRateFunction I where
  isCompact_levelSet : ∀ a : ℝ, IsCompact {x | I x ≤ ENNReal.ofReal a}
    structure IsRateFunction {X : Type*} [TopologicalSpace X] (I : X → ℝ≥0∞) : Prop where
  lowerSemicontinuous : LowerSemicontinuous I

    StructureConvex rate function#✓fully proved

    MathlibExt.Probability.LargeDeviationPrinciple.IsConvexRateFunction

    Let \(X\) be a real vector space carrying a topology (no compatibility between the topology and the linear structure is assumed). A function \(I : X \to [0, \infty]\) is a convex rate function if it is a rate function and \(I(ax + by) \le a I(x) + b I(y)\) for all \(x, y \in X\) and all real numbers \(a, b \ge 0\) with \(a + b = 1\).

    structure IsConvexRateFunction {X : Type*} [TopologicalSpace X] [AddCommMonoid X]
    [Module ℝ X] (I : X → ℝ≥0∞) : Prop extends IsRateFunction I where
  convex : ∀ ⦃x y : X⦄, ∀ ⦃a b : ℝ⦄, 0 ≤ a → 0 ≤ b → a + b = 1 →
    I (a • x + b • y) ≤ ENNReal.ofReal a * I x + ENNReal.ofReal b * I y

    StructureLarge deviation principle for a sequence of measures#✓fully proved

    MathlibExt.Probability.LargeDeviationPrinciple.SatisfiesLDP

    Let \(X\) be a topological space with a \(\sigma\)-algebra containing every open set, let \((\mu_n)_{n \in \mathbb{N}}\) be a sequence of measures on \(X\), and let \(I : X \to [0, \infty]\). The sequence \((\mu_n)\) satisfies the large deviation principle with rate function \(I\) and speed \(n\) if \(I\) is a rate function, every open set \(U \subseteq X\) satisfies

    \[\liminf_{n \to \infty} \frac{1}{n} \log \mu_n(U) \ge -\inf_{x \in U} I(x),\]

    and every closed set \(F \subseteq X\) satisfies

    \[\limsup_{n \to \infty} \frac{1}{n} \log \mu_n(F) \le -\inf_{x \in F} I(x).\]

    Here \(\log 0 = -\infty\), an infimum over the empty set is \(\infty\), and the limits are taken in the extended reals.

    structure SatisfiesLDP {X : Type*} [TopologicalSpace X] [MeasurableSpace X]
    [OpensMeasurableSpace X] (μ : ℕ → Measure X) (I : X → ℝ≥0∞) : Prop where
  isRateFunction : IsRateFunction I
  lower_bound : ∀ U : Set X, IsOpen U →
    - (⨅ x ∈ U, (I x : EReal)) ≤
      liminf (fun n => ((n : ℕ) : EReal)⁻¹ * ENNReal.log (μ n U)) atTop
  upper_bound : ∀ F : Set X, IsClosed F →
    limsup (fun n => ((n : ℕ) : EReal)⁻¹ * ENNReal.log (μ n F)) atTop ≤
      - (⨅ x ∈ F, (I x : EReal))
    structure IsRateFunction {X : Type*} [TopologicalSpace X] (I : X → ℝ≥0∞) : Prop where
  lowerSemicontinuous : LowerSemicontinuous I

    TheoremLarge deviation principle from bounds on measurable sets#✓fully proved

    MathlibExt.Probability.LargeDeviationPrinciple.satisfiesLDP_of_borel_bounds

    Let \(X\) be a topological space with a \(\sigma\)-algebra containing every open set, let \((\mu_n)_{n \in \mathbb{N}}\) be a sequence of measures on \(X\), and let \(I\) be a rate function on \(X\). Suppose that every measurable set \(\Gamma \subseteq X\), with interior \(\Gamma^\circ\) and closure \(\overline{\Gamma}\), satisfies

    \[\liminf_{n \to \infty} \frac{1}{n} \log \mu_n(\Gamma) \ge -\inf_{x \in \Gamma^\circ} I(x)\]

    and

    \[\limsup_{n \to \infty} \frac{1}{n} \log \mu_n(\Gamma) \le -\inf_{x \in \overline{\Gamma}} I(x),\]

    where \(\log 0 = -\infty\), an infimum over the empty set is \(\infty\), and the limits are taken in the extended reals. Then \((\mu_n)\) satisfies the large deviation principle with rate function \(I\).

    Open and closed sets are measurable and equal to their interior and closure respectively, so the hypothesis contains the open-set and closed-set bounds. On a Borel space this is the textbook Borel-set converse.

    theorem satisfiesLDP_of_borel_bounds [OpensMeasurableSpace X]

    (hRate : IsRateFunction I)

      - (⨅ x ∈ interior Γ, (I x : EReal)) ≤
          liminf (fun n => ((n : ℕ) : EReal)⁻¹ * ENNReal.log (μ n Γ)) atTop ∧
        limsup (fun n => ((n : ℕ) : EReal)⁻¹ * ENNReal.log (μ n Γ)) atTop ≤
          - (⨅ x ∈ closure Γ, (I x : EReal))) :
    SatisfiesLDP μ I
