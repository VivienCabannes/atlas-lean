    Tilted large deviation principle

    Reweighting by an exponential of \(n\) times a bounded continuous function preserves large deviation principles: if \(\mu_n\) satisfies an LDP with rate function \(I\), the Gibbs measures \(Q_n \propto e^{nF}\mu_n\) satisfy an LDP with rate \(J = \sup(F - I) - (F - I)\), which vanishes exactly at the maximisers of \(F - I\). This is the large deviation form of the Gibbs conditioning and exponential tilting used in statistical mechanics.

    TheoremTilted large deviation principle#✓fully proved

    MathlibExt.Probability.TiltedLDP.satisfiesLDP_tiltedMeasure

    Let probability measures \((\mu_n)\) on a topological space \(X\) satisfy the large deviation principle with rate function \(I\) (not necessarily good), and let \(F : X \to \mathbb{R}\) be continuous and bounded. Then the tilted measures

    \[Q_n(A) = \frac{\int_A e^{n F} \, d\mu_n}{\int_X e^{n F} \, d\mu_n}\]

    satisfy the large deviation principle with rate function

    \[J(x) = S - \bigl(F(x) - I(x)\bigr), \qquad S = \sup_{y \in X} \bigl(F(y) - I(y)\bigr),\]

    where \(S\) is finite. \(J\) vanishes exactly at the maximisers of \(F - I\), so when that maximiser is unique the tilted measures concentrate there.

    The denominator is handled by Varadhan's integral lemma, and the numerator by its two bounds restricted to an open set (lower bound) and to a closed set (upper bound).

    theorem satisfiesLDP_tiltedMeasure {μ : ℕ → Measure X} [∀ n, IsProbabilityMeasure (μ n)]
    {I : X → ℝ≥0∞} (hμ : SatisfiesLDP μ I) {F : X → ℝ} (hF : Continuous F) {C : ℝ}
    (hC : ∀ x, |F x| ≤ C) :
    SatisfiesLDP (tiltedMeasure μ F)
      (fun x => ((⨆ y, ((F y : EReal) - (I y : EReal))) -
        ((F x : EReal) - (I x : EReal))).toENNReal)
    structure SatisfiesLDP {X : Type*} [TopologicalSpace X] [MeasurableSpace X]
