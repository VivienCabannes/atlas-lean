    DefinitionReal-valued log-MGF expression#✓fully proved

    MathlibExt.Probability.CramerUpperBound.logMGFVec

    Real-valued log-MGF expression Λ(t) = log E[exp ⟪t, X⟫].

    For a random vector X : Ω → ℝᵈ, this returns the logarithm of the moment generating function evaluated at the dual variable t ∈ ℝᵈ, using the Euclidean inner product. Under a probability measure it represents the cumulant generating function at directions where the exponential is integrable. For a nonintegrable exponential, the Bochner integral is 0 and Real.log 0 = 0, so this definition returns 0. The bounds below explicitly require exponential integrability. Ported from v1.

    noncomputable def logMGFVec {d : ℕ} (X : Ω → EuclideanSpace ℝ (Fin d))
    (μ : Measure Ω) (t : EuclideanSpace ℝ (Fin d)) : ℝ :=
  Real.log (∫ ω, Real.exp ⟪t, X ω⟫_ℝ ∂μ)

    TheoremChernoff bound for the empirical mean of real-valued i.i.d. variables#✓fully proved

    MathlibExt.Probability.CramerUpperBound.measure_empiricalMean_le_of_threshold

    Chernoff bound for the empirical mean of real-valued i.i.d. variables, in event form: if on the event E the empirical mean (1/n) ∑_{i<n} Xᵢ satisfies the threshold inequality a ≤ t * (empirical mean) - log (mgf of X₁ at t), then μ(E) ≤ exp(-n * a).

    Assume a probability measure, measurable independent identically distributed coordinates, and integrability of exp (t * X₀).

    This is the one-dimensional core of the Cramér upper bound. The proof splits on the sign of t: for t > 0 it applies Mathlib's upper-tail Chernoff bound to the sum Sₙ, and for t < 0 the lower-tail Chernoff bound; in both cases the exponential moment of the sum factors as (mgf of X₁ at t)^n by independence and identical distribution.

    theorem measure_empiricalMean_le_of_threshold {X : ℕ → Ω → ℝ}
    [IsProbabilityMeasure μ]
    (hXmeas : ∀ i, Measurable (X i)) (hXindep : iIndepFun X μ)
    (hXident : ∀ i, IdentDistrib (X i) (X 0) μ μ)
    {t a : ℝ} (hInt : Integrable (fun ω => Real.exp (t * X 0 ω)) μ)
    {n : ℕ} (hn : 0 < n) {E : Set Ω}
    (hEthr : ∀ ω ∈ E, a ≤ t * ((n : ℝ)⁻¹ * ∑ i ∈ Finset.range n, X i ω)
      - Real.log (mgf (X 0) μ t)) :
    (μ E).toReal ≤ Real.exp (-(n : ℝ) * a)

    MathlibExt.Probability.CramerUpperBound.cramer_upper_bound_rate

    For a fixed ξ and s = inf_{x ∈ F} (⟪ξ, x⟫ - Λ(ξ)), the n-th root of μₙ(F) has limsup at most exp(-s). Assume measurable i.i.d. coordinates under a probability measure, measurable F, exponential integrability at ξ, and a bounded-below rate image on F, with its real-valued sInf used for s. Optimizing over admissible ξ gives the supremum of these fixed-direction rates; the Legendre-rate Cramér upper bound requires further arguments.

    theorem cramer_upper_bound_rate {d : ℕ} {X : ℕ → Ω → EuclideanSpace ℝ (Fin d)}

    (hXmeas : ∀ i, Measurable (X i)) (hXindep : iIndepFun X μ)
    (hXident : ∀ i, IdentDistrib (X i) (X 0) μ μ)
    {F : Set (EuclideanSpace ℝ (Fin d))} (hF : MeasurableSet F)
    {ξ : EuclideanSpace ℝ (Fin d)}
    (hInt : Integrable (fun ω => Real.exp ⟪ξ, X 0 ω⟫_ℝ) μ)
    (hBdd : BddBelow ((fun x => ⟪ξ, x⟫_ℝ - logMGFVec (X 0) μ ξ) '' F)) :
    limsup (fun n : ℕ => ((empiricalMeanMeasureVec X μ n) F).toReal ^ (1 / (n : ℝ)))
