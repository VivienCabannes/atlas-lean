    Contraction principle

    Large deviation principles transfer along continuous maps: if \(\mu_n\) satisfies an LDP with a good rate function \(I\) and \(F\) is continuous into a Hausdorff space, the image measures \(F_*\mu_n\) satisfy an LDP with the good rate function \(J(y) = \inf\{I(x) : F(x) = y\}\). Goodness of \(I\) is what makes \(J\) lower semicontinuous: the infimum is attained and the sub-level sets of \(J\) are images of compact sets.

    MathlibExt.Probability.ContractionPrinciple.exists_eq_pushforwardRate

    If I is a good rate function, F is continuous and Y is Hausdorff, then for every y with J(y) < ∞ there is x with F x = y and I x = J y, where J = pushforwardRate F I. The minimiser exists because the fibre F⁻¹{y} is closed and meets a compact sub-level set of the lower semicontinuous I.

    MathlibExt.Probability.ContractionPrinciple.pushforwardRate

    For F : X → Y and I : X → [0, ∞], the function J(y) = inf { I(x) : F(x) = y }, which is ∞ off the range of F. It is the rate function of the contraction principle (Varadhan, Large Deviations, NYU lecture notes, 2010, Section 2, Theorem 2.7).

    TheoremContraction principle#✓fully proved

    MathlibExt.Probability.ContractionPrinciple.satisfiesLDP_map

    Let \(X\) be a topological space with a \(\sigma\)-algebra containing the open sets, let \(Y\) be a Hausdorff space with its Borel \(\sigma\)-algebra, and let \(F : X \to Y\) be continuous. If the measures \((\mu_n)\) on \(X\) satisfy the large deviation principle with a good rate function \(I\), then the image measures \((F_* \mu_n)\) satisfy the large deviation principle on \(Y\) with the good rate function

    \[J(y) = \inf \{ I(x) : F(x) = y \},\]

    with \(J(y) = \infty\) off the range of \(F\).

    The bounds transfer because \(F^{-1}\) maps closed sets to closed sets and open sets to open sets, and \(\inf_{F^{-1}(C)} I = \inf_C J\). Goodness of \(I\) is needed only to make \(J\) a rate function: each fibre \(F^{-1}\{y\}\) is closed, so the infimum defining \(J(y)\) is attained on a compact sub-level set of \(I\), and \(\{J \le a\} = F(\{I \le a\})\) is compact for finite \(a\).

    A typical use: Cramér's theorem for sample means follows from Sanov's theorem for empirical measures by contracting along \(\beta \mapsto \int x \, d\beta(x)\) (Varadhan's notes, Section 3, Corollary 1.3, with a truncation argument since this map is not continuous for the weak topology).

    theorem satisfiesLDP_map [MeasurableSpace X] [OpensMeasurableSpace X] [MeasurableSpace Y]
    [BorelSpace Y] [T2Space Y] {μ : ℕ → Measure X} {I : X → ℝ≥0∞} (hμ : SatisfiesLDP μ I)
    (hI : IsGoodRateFunction I) {F : X → Y} (hF : Continuous F) :
    SatisfiesLDP (fun n => (μ n).map F) (pushforwardRate F I)
    structure SatisfiesLDP {X : Type*} [TopologicalSpace X] [MeasurableSpace X]
    [OpensMeasurableSpace X] (μ : ℕ → Measure X) (I : X → ℝ≥0∞) : Prop where
  isRateFunction : IsRateFunction I
  lower_bound : ∀ U : Set X, IsOpen U →
    - (⨅ x ∈ U, (I x : EReal)) ≤
      liminf (fun n => ((n : ℕ) : EReal)⁻¹ * ENNReal.log (μ n U)) atTop
  upper_bound : ∀ F : Set X, IsClosed F →
    limsup (fun n => ((n : ℕ) : EReal)⁻¹ * ENNReal.log (μ n F)) atTop ≤
      - (⨅ x ∈ F, (I x : EReal))

    MathlibExt.Probability.ContractionPrinciple.setOf_pushforwardRate_le

    For a good rate function I, continuous F and Hausdorff Y, the sub-level set {J ≤ a} of J = pushforwardRate F I at a finite level a is the image F({I ≤ a}). (At a = ∞ the left side is all of Y while the right side is the range of F.)
