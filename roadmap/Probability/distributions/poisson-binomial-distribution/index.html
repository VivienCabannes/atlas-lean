    ProbabilityTheory.IsBernoulliRV

    Let \(\mu\) be a measure on a measurable space \(\Omega\), let \(X : \Omega \to \mathbb{N}\) and let \(p\) be a real number. Then \(X\) is a Bernoulli random variable with parameter \(p\) under \(\mu\) when \(0 \le p \le 1\), \(X\) is \(\mu\)-almost everywhere measurable, and the pushforward of \(\mu\) along \(X\) is the Bernoulli distribution \(p\,\delta_1 + (1 - p)\,\delta_0\) on \(\mathbb{N}\), which gives mass \(p\) to \(1\), mass \(1 - p\) to \(0\) and no mass elsewhere.

    def IsBernoulliRV {Ω : Type*} [MeasurableSpace Ω]
    (X : Ω → ℕ) (μ : Measure Ω) (p : ℝ) : Prop :=
  ∃ hp : p ∈ Set.Icc (0 : ℝ) 1, HasLaw X (bernoulliMeasure 1 0 ⟨p, hp⟩) μ

    TheoremDistribution of a sum of independent Bernoulli variables#✓fully proved

    ProbabilityTheory.bernoulli_sum_pmf

    Let \(\mu\) be a probability measure on a measurable space \(\Omega\), let \(m \in \mathbb{N}\), and let \(X_1, \dots, X_m : \Omega \to \mathbb{N}\) be measurable, mutually independent random variables such that each \(X_i\) is a Bernoulli random variable with real parameter \(p_i\) under \(\mu\). Then for every \(j \in \mathbb{N}\) the probability that \(X_1 + \dots + X_m = j\) equals

    \[ \sum_{A \subseteq \{1, \dots, m\},\ |A| = j} \ \prod_{i \in A} p_i \prod_{i \notin A} (1 - p_i). \]

    This is the Poisson binomial distribution.

    theorem bernoulli_sum_pmf
    {Ω : Type*} [MeasurableSpace Ω] {μ : Measure Ω} [IsProbabilityMeasure μ]
    {m : ℕ} {X : Fin m → Ω → ℕ} {p : Fin m → ℝ}
    (hBernoulli : ∀ i, IsBernoulliRV (X i) μ (p i))
    (hIndep : iIndepFun X μ)
    (hMeas : ∀ i, Measurable (X i))
    (j : ℕ) :
    (μ ((fun ω => ∑ i : Fin m, X i ω) ⁻¹' {↑j})).toReal =
      ∑ A ∈ Finset.univ.powersetCard j,
        (∏ i ∈ A, p i) * (∏ i ∈ Finset.univ \ A, (1 - p i))
    def IsBernoulliRV {Ω : Type*} [MeasurableSpace Ω]
    (X : Ω → ℕ) (μ : Measure Ω) (p : ℝ) : Prop :=
  ∃ hp : p ∈ Set.Icc (0 : ℝ) 1, HasLaw X (bernoulliMeasure 1 0 ⟨p, hp⟩) μ

    ProbabilityTheory.bernoulli_sum_pmf_iid

    Let \(\mu\) be a probability measure on a measurable space \(\Omega\), let \(m \in \mathbb{N}\), let \(p\) be a real number, and let \(X_1, \dots, X_m : \Omega \to \mathbb{N}\) be measurable, mutually independent random variables, each a Bernoulli random variable with parameter \(p\) under \(\mu\). Then for every \(j \in \mathbb{N}\) the probability that \(X_1 + \dots + X_m = j\) is \(\binom{m}{j} p^j (1 - p)^{m - j}\), where the exponent \(m - j\) is taken to be \(0\) when \(j > m\).

    theorem bernoulli_sum_pmf_iid

    (hMeas : ∀ i, Measurable (X i))
    (j : ℕ) :
    (μ ((fun ω => ∑ i : Fin m, X i ω) ⁻¹' {↑j})).toReal =
      (m.choose j : ℝ) * p ^ j * (1 - p) ^ (m - j)

    noncomputable def poissonBinomialPMF {m : ℕ} (p : Fin m → ℝ) (j : ℕ) : ℝ :=
