    TheoremVariance#✓fully proved

    ProbabilityTheory.variance_betaBinomial

    Variance (Dolzhenko–Smith parametrization). For α, β > 0, with π = α / (α + β) and γ = 1 / (α + β + 1), Var M = E M² - (E M)² = n π (1 - π) (1 + (n - 1) γ).

    theorem variance_betaBinomial {n : ℕ} {α β : ℝ} (hα : 0 < α) (hβ : 0 < β) :
    ∑ k ∈ range (n + 1), (k : ℝ) ^ 2 * betaBinomialPMF n α β k -
        (∑ k ∈ range (n + 1), (k : ℝ) * betaBinomialPMF n α β k) ^ 2 =
      n * (α / (α + β)) * (1 - α / (α + β)) * (1 + (n - 1) * (1 / (α + β + 1)))

    ProbabilityTheory.negBinomialReal

    The negative binomial mass function with size θ and mean μ: NB(k; θ, μ) = θ⁽ᵏ⁾ / k! · (θ / (θ + μ)) ^ θ · (μ / (θ + μ)) ^ k, with the rising factorial θ⁽ᵏ⁾ = Γ(θ + k) / Γ(θ) and a real power (θ / (θ + μ)) ^ θ.
