    DefinitionMultinomial mass function#✓fully proved

    ProbabilityTheory.multinomialReal

    The multinomial mass function: the probability N! / ∏ᵢ xᵢ! · ∏ᵢ pᵢ ^ xᵢ that N independent throws, landing in cell i with probability pᵢ, produce the cell counts x; it is 0 unless ∑ᵢ xᵢ = N. The formula is a polynomial in p and is defined for every real vector p; it is a probability mass function when p is a probability vector (0 ≤ pᵢ, ∑ᵢ pᵢ = 1), which the normalization theorems assume. The converse does not hold in general: for N = 0 it is the point mass at the zero vector for every p, even vectors that are not probability vectors.

    noncomputable def multinomialReal (N : ℕ) (p : ι → ℝ) (x : ι → ℕ) : ℝ :=
  if ∑ i, x i = N then (Nat.multinomial univ x : ℝ) * ∏ i, p i ^ x i else 0

    ProbabilityTheory.sum_covariance_multinomialReal

    For a probability vector (0 ≤ pᵢ, ∑ₗ pₗ = 1), Cov(Xᵢ, Xⱼ) = ∑ₓ (xᵢ - N pᵢ) (xⱼ - N pⱼ) P(x) = N (δᵢⱼ pᵢ - pᵢ pⱼ); in particular Var Xᵢ = N pᵢ (1 - pᵢ) and Cov(Xᵢ, Xⱼ) = -N pᵢ pⱼ for i ≠ j.

    theorem sum_covariance_multinomialReal {N : ℕ} {p : ι → ℝ} (hp : ∑ i, p i = 1)
    (hp₀ : ∀ i, 0 ≤ p i) (i j : ι) :
    ∑ x ∈ piAntidiag univ N,
        ((x i : ℝ) - N * p i) * ((x j : ℝ) - N * p j) * multinomialReal N p x =
      N * ((if i = j then p i else 0) - p i * p j)
