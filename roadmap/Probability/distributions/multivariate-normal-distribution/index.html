    MetaMathlibExt.map_withDensity_measurableEquiv

    Let \(e : \alpha \to \beta\) be a measurable equivalence between measurable spaces, \(\nu\) a measure on \(\alpha\) and \(g : \alpha \to [0, \infty]\) any function.     DefinitionMultivariate Gaussian density function#✓fully proved

    MetaMathlibExt.multivariateGaussianPDFReal

    Let \(\iota\) be a finite set of size \(n\). For \(\mu, x \in \mathbb{R}^\iota\) and a real \(\iota \times \iota\) matrix \(S\), this is the real number

    \[\frac{1}{(2\pi)^{n/2}\sqrt{\det S}} \exp\left(-\frac{(x - \mu)^\top S^{-1}(x - \mu)}{2}\right).\]

    It is defined for every \(S\), with the conventions \(\sqrt{t} = 0\) for \(t < 0\), \(1/0 = 0\) and \(S^{-1} = 0\) for singular \(S\), so its value is \(0\) when \(\det S \le 0\).

    noncomputable def multivariateGaussianPDFReal (μ : EuclideanSpace ℝ ι) (S : Matrix ι ι ℝ)
    (x : EuclideanSpace ℝ ι) : ℝ :=
  ((√(2 * Real.pi)) ^ Fintype.card ι)⁻¹ * (√S.det)⁻¹ *
    Real.exp (-(ofLp (x - μ) ⬝ᵥ S⁻¹ *ᵥ ofLp (x - μ)) / 2)

    Let \(\rho\) be a real number with \(-1 < \rho < 1\), and let \(\gamma\) be the multivariate Gaussian measure on \(\mathbb{R}^2\) with mean \(0\) and covariance matrix whose diagonal entries are \(1\) and whose off-diagonal entries are \(\rho\) (the law of a standard bivariate normal vector with correlation \(\rho\)).
