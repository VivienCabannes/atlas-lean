    MetaMathlibExt.multivariateGaussianPDFReal

    Let \(\iota\) be a finite set of size \(n\). For \(\mu, x \in \mathbb{R}^\iota\) and a real \(\iota \times \iota\) matrix \(S\), this is the real number

    \[\frac{1}{(2\pi)^{n/2}\sqrt{\det S}} \exp\left(-\frac{(x - \mu)^\top S^{-1}(x - \mu)}{2}\right).\]

    It is defined for every \(S\), with the conventions \(\sqrt{t} = 0\) for \(t < 0\), \(1/0 = 0\) and \(S^{-1} = 0\) for singular \(S\), so its value is \(0\) when \(\det S \le 0\).

    (x : EuclideanSpace ℝ ι) : ℝ :=
  ((√(2 * Real.pi)) ^ Fintype.card ι)⁻¹ * (√S.det)⁻¹ *
    Real.exp (-(ofLp (x - μ) ⬝ᵥ S⁻¹ *ᵥ ofLp (x - μ)) / 2)

    TheoremSheppard's formula (Gaussian arcsine law)#✓fully proved

    MathlibExt.Probability.Distributions.SheppardArcsine.sheppard_quadrant_probability_arcsine

    Let \(\rho\) be a real number with \(-1 < \rho < 1\), and let \(\gamma\) be the multivariate Gaussian measure on \(\mathbb{R}^2\) with mean \(0\) and covariance matrix whose diagonal entries are \(1\) and whose off-diagonal entries are \(\rho\) (the law of a standard bivariate normal vector with correlation \(\rho\)). Then the open first quadrant \(\{x \in \mathbb{R}^2 : x_1 > 0,\ x_2 > 0\}\) has \(\gamma\)-probability \(\frac{1}{4} + \frac{\arcsin \rho}{2\pi}\).

    The proof realises \(\gamma\) as the law of \((\langle u, r\rangle, \langle v, r\rangle)\) for a standard Gaussian vector \(r\) in the plane and unit vectors \(u\), \(v\) with \(\langle u, v\rangle = \rho\), by comparing characteristic functions, and then uses the quadrant probability for two directions. That in turn rests on the random-hyperplane computation of Goemans and Williamson rather than on Sheppard's own argument. The statement keeps the hypothesis \(|\rho| < 1\) of the former wanted entry; the same argument would also cover \(\rho = \pm 1\), where the covariance matrix is singular, but that case is not stated.

    theorem sheppard_quadrant_probability_arcsine (ρ : ℝ) (hρ : ρ ∈ Set.Ioo (-1) 1) :
    let S : Matrix (Fin 2) (Fin 2) ℝ := Matrix.of (fun i j => if i = j then 1 else ρ);
    (ProbabilityTheory.multivariateGaussian 0 S).real {x | 0 < x 0 ∧ 0 < x 1}
      = 1 / 4 + Real.arcsin ρ / (2 * Real.pi)

    TheoremThe planar wedge probability#✓fully proved

    MathlibExt.Probability.Distributions.StdGaussianHyperplane.gaussianReal_prod_wedge

    Let \((X, Y)\) be two independent standard normal variables and \(0 < a < \pi/2\). The lines through the origin with normals \((\cos a, -\sin a)\) and \((\cos a, \sin a)\) meet at angle \(2a\), and they put \((X, Y)\) on different sides with probability

    \[\Pr\left[\operatorname{sgn}(X \cos a - Y \sin a) \ne \operatorname{sgn}(X \cos a + Y \sin a)\right] = \frac{2a}{\pi},\]

    with \(\operatorname{sgn} x = 1\) for \(x \ge 0\). The proof is in polar coordinates: the density \(e^{-(x^2+y^2)/2}/(2\pi)\) is radial, the event depends only on the angle \(\varphi\) (it is \(\cos(\varphi + a)\) against \(\cos(\varphi - a)\)), the radial integral \(\int_0^\infty r e^{-r^2/2}\, dr\) is \(1\), and the angular set is two arcs of length \(2a\).

    The same computation, through the quadrant probability for two directions, gives Sheppard's formula.

    theorem gaussianReal_prod_wedge {a : ℝ} (ha0 : 0 < a) (ha : a < π / 2) :
    (gaussianReal 0 1).prod (gaussianReal 0 1)
        {p : ℝ × ℝ | (0 ≤ cos a * p.1 - sin a * p.2) ≠ (0 ≤ cos a * p.1 + sin a * p.2)} =
      ENNReal.ofReal (2 * a / π)

    TheoremA random hyperplane separates two unit vectors with probability angle over π#✓fully proved

    MathlibExt.Probability.Distributions.StdGaussianHyperplane.stdGaussian_sign_ne

    Let \(r\) be a standard Gaussian vector in a finite-dimensional real inner product space and \(u\), \(v\) unit vectors. Then

    \[\Pr\left[\operatorname{sgn}\langle u, r\rangle \ne \operatorname{sgn}\langle v, r\rangle\right] = \frac{\arccos \langle u, v\rangle}{\pi},\]

    with \(\operatorname{sgn} x = 1\) for \(x \ge 0\). This is the Gaussian form of Lemma 3.2 of Goemans and Williamson, whose remark on p. 1121 says that a Gaussian direction gives the same signs as a uniform point on the sphere. The proof writes \(u = c e_1 - s e_2\) and \(v = c e_1 + s e_2\) with \(e_1 = (u + v)/\|u + v\|\), \(e_2 = (v - u)/\|v - u\|\), \(c = \cos a\), \(s = \sin a\), so that \(2a = \arccos\langle u, v\rangle\), and then uses the planar computation. The cases \(v = u\) (probability \(0\)) and \(v = -u\) (probability \(1\), because \(\langle u, r\rangle = 0\) has probability \(0\)) are treated separately.

    theorem stdGaussian_sign_ne {u v : E} (hu : ‖u‖ = 1) (hv : ‖v‖ = 1) :
    stdGaussian E {r | (0 ≤ inner ℝ u r) ≠ (0 ≤ inner ℝ v r)} =
      ENNReal.ofReal (arccos (inner ℝ u v) / π)

    TheoremQuadrant probability for two directions#✓fully proved

    MathlibExt.Probability.Distributions.StdGaussianHyperplane.stdGaussian_pos_pos

    For unit vectors \(u\), \(v\) of a finite-dimensional real inner product space and a standard Gaussian vector \(r\),

    \[\Pr[\langle u, r\rangle > 0,\ \langle v, r\rangle > 0] = \frac14 + \frac{\arcsin \langle u, v\rangle}{2\pi}.\]

    The four sign patterns of \((\langle u, r\rangle, \langle v, r\rangle)\) have total probability \(1\); the two mixed patterns together have probability \(\arccos\langle u, v\rangle / \pi\); the symmetry \(r \mapsto -r\) of the standard Gaussian exchanges the two pure patterns; and the boundary hyperplanes are null. So each pure pattern has probability \(\frac12\left(1 - \frac{\arccos \langle u, v\rangle}{\pi}\right)\), which is the formula since \(\arccos = \frac{\pi}{2} - \arcsin\).

    theorem stdGaussian_pos_pos {u v : E} (hu : ‖u‖ = 1) (hv : ‖v‖ = 1) :
    (stdGaussian E).real {r | 0 < inner ℝ u r ∧ 0 < inner ℝ v r} =
      1 / 4 + arcsin (inner ℝ u v) / (2 * π)
