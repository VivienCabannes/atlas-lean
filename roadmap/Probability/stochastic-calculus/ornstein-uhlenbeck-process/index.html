    ProbabilityTheory.ouCovariance

    The covariance function of the Ornstein–Uhlenbeck process started at 0: (σ² / (2θ)) (e^{-θ|t-s|} - e^{-θ(t+s)}) (Karatzas–Shreve 1991, Section 5.6). It is meant for θ > 0 and times s, t ≥ 0; at θ = 0 the division by zero makes it 0.

    noncomputable def ouCovariance (θ σ s t : ℝ) : ℝ :=
  σ ^ 2 / (2 * θ) * (exp (-θ * |t - s|) - exp (-θ * (t + s)))

    Doob's clock τ t = (e^{2θt} - 1)/(2θ) for the process started at 0. The value is nonnegative for every real θ, so Real.toNNReal only changes its type.
