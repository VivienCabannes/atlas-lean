    TheoremSecond-order Taylor sums along a continuous path#✓fully proved

    ProbabilityTheory.tendsto_taylor_sum_sub

    For f of class C², a continuous path w, t ≥ 0, and a sequence of mesh counts ns j → ∞ along which the quadratic sums ∑_{k < ns j} (w (t (k + 1) / ns j) - w (t k / ns j))² stay bounded, the telescoped increment f (w t) - f (w 0) minus the second-order Taylor sums ∑_k (f'(w_k) Δw_k + (1/2) f''(w_k) Δw_k²) tends to 0.

    theorem tendsto_taylor_sum_sub {f : ℝ → ℝ} (hf : ContDiff ℝ 2 f) {w : ℝ → ℝ}
    (hw : Continuous w) {t : ℝ} (ht : 0 ≤ t) {ns : ℕ → ℕ} (hns : Tendsto ns atTop atTop)
    {M : ℝ}
    (hM : ∀ j, ∑ k ∈ Finset.range (ns j),
      (w (t * (k + 1) / ns j) - w (t * k / ns j)) ^ 2 ≤ M) :
    Tendsto (fun j ↦ f (w t) - f (w 0) - ∑ k ∈ Finset.range (ns j),
      (deriv f (w (t * k / ns j)) * (w (t * (k + 1) / ns j) - w (t * k / ns j)) +
        (1 / 2) * deriv (deriv f) (w (t * k / ns j)) *
          (w (t * (k + 1) / ns j) - w (t * k / ns j)) ^ 2)) atTop (𝓝 0)

    TheoremItô's formula#✓fully proved

    ProbabilityTheory.ito_formula

    Itô's formula for Brownian motion: for a Brownian motion B adapted to F with increments independent of the past and jointly measurable in (t, ω), and f of class C² with |f'| ≤ C and |f''| ≤ C, f(B t) = f(B 0) + ∫_0^t f'(B u) dB u + (1/2) ∫_0^t f''(B u) du almost surely, for every t ≥ 0 (Karatzas–Shreve 1991, Theorem 3.3.3). The last integral is a pathwise Riemann integral; it is the integral of a continuous function on almost every path.

    theorem ito_formula {Ω : Type*} {mΩ : MeasurableSpace Ω}
    {P : Measure Ω} {F : Filtration ℝ≥0 mΩ} {B : ℝ≥0 → Ω → ℝ} (hB : IsBrownianReal B P)
    (hBF : Adapted F B)
    (hInd : ∀ s t, s ≤ t → Indep (MeasurableSpace.comap (fun ω ↦ B t ω - B s ω) inferInstance)
      (F s) P)
    (hBm : Measurable fun p : ℝ≥0 × Ω ↦ B p.1 p.2)
    {f : ℝ → ℝ} (hf : ContDiff ℝ 2 f) (C : ℝ) (hf1 : ∀ x, |deriv f x| ≤ C)
    (hf2 : ∀ x, |deriv (deriv f) x| ≤ C) (t : ℝ≥0) :
    (fun ω ↦ f (B t ω)) =ᵐ[P]
      fun ω ↦ f (B 0 ω) + itoIntegral P F B (fun u ω' ↦ deriv f (B u ω')) t ω +
        (1 / 2) * ∫ u in (0 : ℝ)..t, deriv (deriv f) (B (Real.toNNReal u) ω)
    noncomputable def itoIntegral (P : Measure Ω) (F : Filtration ℝ≥0 mΩ) (B H : ℝ≥0 → Ω → ℝ)
    (t : ℝ≥0) : Ω → ℝ :=
  if h : AEStronglyMeasurable[F t] (itoIntegralL2 P F B H t) P then h.mk _
  else itoIntegralL2 P F B H t
