    Regularized covariance estimation by banding

    When the dimension \(p\) is comparable to or larger than the sample size \(n\), the sample covariance matrix is a poor estimator of the population covariance in operator norm. Bickel and Levina (2008) regularize it by banding, keeping only the entries within distance \(k\) of the diagonal, which suits variables with a natural order whose dependence decays with distance, as in time series, climatology and spectroscopy. Over the class of well-conditioned covariances with polynomially decaying off-band column sums, the banded sample covariance and its inverse are consistent in operator norm whenever \(\log p / n \to 0\), at an explicit rate. The deterministic operator-norm bounds behind the rate are proved here from Schur's test; the rate itself is a wanted statement.

    DefinitionBanding operator#✓fully proved

    MathlibExt.Probability.Statistics.CovarianceBanding.band

    For a \(p \times p\) matrix \(M = [m_{ij}]\) and \(k \ge 0\), the banded matrix is $\(B_k(M) = \bigl[m_{ij} \, \mathbf 1(|i - j| \le k)\bigr],\)$ which keeps the entries within distance \(k\) of the diagonal. Bickel and Levina estimate a covariance matrix by banding the sample covariance, \(\hat\Sigma_{k} = B_k(\hat\Sigma)\); banding is natural when the variables are ordered so that \(|i - j|\) large implies weak dependence. They define \(B_k\) for \(0 \le k < p\); in Lean \(k\) is any natural number and \(B_k\) is the identity for \(k \ge p - 1\). Banding need not preserve positive definiteness.

    def band (k : ℕ) (M : Matrix (Fin p) (Fin p) ℝ) : Matrix (Fin p) (Fin p) ℝ :=
  Matrix.of fun i j => if ((i : ℤ) - j).natAbs ≤ k then M i j else 0

    TheoremBanding is linear#✓fully proved

    MathlibExt.Probability.Statistics.CovarianceBanding.band_sub

    For real \(p \times p\) matrices \(A\) and \(B\) and every \(k\), \(B_k(A) - B_k(B) = B_k(A - B)\): the banding operator acts entrywise. In particular \(B_k(\hat\Sigma) - B_k(\Sigma) = B_k(\hat\Sigma - \Sigma)\), the form in which the variance term of the Bickel–Levina rate is bounded.

    theorem band_sub (k : ℕ) (A B : Matrix (Fin p) (Fin p) ℝ) :
    band k A - band k B = band k (A - B)

    DefinitionThe bandable class \(\mathcal U(\varepsilon_0, \alpha, C)\)#✓fully proved

    MathlibExt.Probability.Statistics.CovarianceBanding.bandableClass

    For \(\varepsilon_0, \alpha, C > 0\), the class \(\mathcal U(\varepsilon_0, \alpha, C)\) consists of the symmetric \(p \times p\) matrices \(\Sigma = [\sigma_{ij}]\) with $\(\varepsilon_0 \le \lambda_{\min}(\Sigma) \le \lambda_{\max}(\Sigma) \le 1/\varepsilon_0 \qquad\text{and}\qquad \max_j \sum_{i : |i - j| > k} |\sigma_{ij}| \le C k^{-\alpha} \text{ for all } k > 0 .\)$ The eigenvalue condition is stated in Lean through the quadratic form, \(\varepsilon_0 \|x\|^2 \le x^{\mathsf T} \Sigma x \le \varepsilon_0^{-1} \|x\|^2\), and the decay condition for integer band widths \(k \ge 1\). Bickel and Levina show that it contains the covariance matrices of stationary processes whose spectral density is bounded away from \(0\) and \(\infty\) and has a bounded derivative of order \(m\), with \(\alpha = m - 1\).

    def bandableClass (ε₀ α C : ℝ) : Set (Matrix (Fin p) (Fin p) ℝ) :=
  {M | M.IsSymm ∧
    (∀ x : Fin p → ℝ, ε₀ * (x ⬝ᵥ x) ≤ x ⬝ᵥ M *ᵥ x ∧ x ⬝ᵥ M *ᵥ x ≤ ε₀⁻¹ * (x ⬝ᵥ x)) ∧
    ∀ k : ℕ, 0 < k → ∀ j : Fin p,
      ∑ i ∈ univ.filter (fun i : Fin p => k < ((i : ℤ) - j).natAbs), |M i j| ≤ C * (k : ℝ) ^ (-α)}

    TheoremBias of banding#✓fully proved

    MathlibExt.Probability.Statistics.CovarianceBanding.norm_band_sub_le

    Let \(M\) be a symmetric real \(p \times p\) matrix and \(k \ge 0\). If every off-band column sum satisfies $\(\sum_{i : |i - j| > k} |m_{ij}| \le R \qquad (j = 1, \dots, p)\)$ for some \(R \ge 0\), then the operator norm of \(B_k(M) - M\) is at most \(R\).

    The entries of \(B_k(M) - M\) are \(-m_{ij}\) off the band and \(0\) on it, so its column sums are bounded by \(R\) and, by symmetry, so are its row sums. Schur's test then bounds the operator norm by \(\sqrt{R \cdot R} = R\); this is Bickel and Levina's inequality (A2), \(\|M\| \le (\|M\|_{(1,1)} \|M\|_{(\infty, \infty)})^{1/2}\), which equals \(\|M\|_{(1,1)}\) for symmetric \(M\).

    theorem norm_band_sub_le (k : ℕ) {M : Matrix (Fin p) (Fin p) ℝ} (hM : M.IsSymm) {R : ℝ}
    (hR0 : 0 ≤ R)
    (hR : ∀ j : Fin p,
      ∑ i ∈ univ.filter (fun i : Fin p => k < ((i : ℤ) - j).natAbs), |M i j| ≤ R) :
    ‖band k M - M‖ ≤ R
    def band (k : ℕ) (M : Matrix (Fin p) (Fin p) ℝ) : Matrix (Fin p) (Fin p) ℝ :=

    TheoremOperator norm of a banded matrix#✓fully proved

    MathlibExt.Probability.Statistics.CovarianceBanding.norm_band_le

    Let \(A\) be a real \(p \times p\) matrix with \(|a_{ij}| \le t\) for all \(i, j\). Then $\(\|B_k(A)\| \le (2k + 1) \, t .\)$ Each row and each column of \(B_k(A)\) has at most \(2k + 1\) nonzero entries, so its row and column sums are at most \((2k+1) t\), and Schur's test gives the bound. No symmetry is needed.

    Applied to \(A = \hat\Sigma - \Sigma\), with \(B_k(\hat\Sigma) - B_k(\Sigma) = B_k(\hat\Sigma - \Sigma)\) (banding is linear), it turns an entrywise error bound into an operator-norm bound, the variance step of the proof of the Bickel–Levina rate.

    theorem norm_band_le (k : ℕ) {A : Matrix (Fin p) (Fin p) ℝ} {t : ℝ} (ht : 0 ≤ t)
    (hA : ∀ i j, |A i j| ≤ t) : ‖band k A‖ ≤ (2 * k + 1) * t

    TheoremBickel–Levina rate for the banded sample covariance#●ready to prove

    MathlibExt.Probability.Statistics.CovarianceBandingWanted.banded_sampleCovariance_rate

    Let \(X_1, \dots, X_n\) be i.i.d. \(N_p(0, \Sigma)\) with \(p = p_n \ge 2\), and let $\(\hat\Sigma = \frac1n \sum_{i=1}^n (X_i - \bar X)(X_i - \bar X)^{\mathsf T}\)$ be the sample covariance (Bickel and Levina's equation (1)). Fix \(\varepsilon_0, \alpha, C > 0\) and assume \(\log p_n / n \to 0\). With the band width and rate $\(k_n = \Bigl\lceil \Bigl(\frac{\log p_n}{n}\Bigr)^{-1/(2(\alpha+1))} \Bigr\rceil, \qquad r_n = \Bigl(\frac{\log p_n}{n}\Bigr)^{\alpha/(2(\alpha+1))},\)$ the banded estimator \(B_{k_n}(\hat\Sigma)\) (banding operator) satisfies $\(\|B_{k_n}(\hat\Sigma) - \Sigma\| = O_P(r_n) \quad\text{and}\quad \|B_{k_n}(\hat\Sigma)^{-1} - \Sigma^{-1}\| = O_P(r_n)\)$ in operator norm, uniformly over \(\Sigma\) in the bandable class \(\mathcal U(\varepsilon_0, \alpha, C)\): for every \(\eta > 0\) there are \(K\) and \(N\) such that for all \(n \ge N\) and all \(\Sigma \in \mathcal U(\varepsilon_0, \alpha, C)\), each of the events \(\{\|\cdot\| > K r_n\}\) has probability at most \(\eta\).

    The paper takes any \(k_n \asymp (n^{-1} \log p)^{-1/(2(\alpha+1))}\); the Lean statement fixes the ceiling. The hypothesis \(\log p_n / n \to 0\) is the regime of the paper's abstract and of its proof, whose tail bounds are applied at \(t \asymp (n^{-1} \log p)^{1/2}\) in a bounded range; \(p_n \ge 2\) keeps \(\log p_n > 0\). The matrix inverse is Lean's Matrix.inv, which is \(0\) for a singular matrix; with probability tending to one uniformly over the class \(B_{k_n}(\hat\Sigma)\) is invertible, so this convention does not affect the statement.

    The proof splits \(\|B_k(\hat\Sigma) - \Sigma\| \le \|B_k(\hat\Sigma) - B_k(\Sigma)\| + \|B_k(\Sigma) - \Sigma\|\). The bias is at most \(C k^{-\alpha}\) on the class, and the variance term is at most \((2k + 1) \max_{ij} |\hat\sigma_{ij} - \sigma_{ij}|\), both by the Schur-test inequality (A2); the entrywise maximum is \(O_P((n^{-1} \log p)^{1/2})\) by a union bound over the entries with exponential tail bounds. Balancing \(k^{-\alpha}\) against \(k (n^{-1} \log p)^{1/2}\) gives \(k_n\) and \(r_n\).
