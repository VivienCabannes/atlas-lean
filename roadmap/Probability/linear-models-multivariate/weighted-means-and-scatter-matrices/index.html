    Let \(I\) be a finite set and \(J\) an index set, and let \(x_i \in \mathbb{R}^J\) (\(i \in I\)) be points with real weights \(w_i\). Their weighted mean is the point \(\big(\sum_{i \in I} w_i\big)^{-1} \sum_{i \in I} w_i x_i\) of \(\mathbb{R}^J\), that is \(\sum_i w_i x_i / \sum_i w_i\), with the convention \(0^{-1} = 0\) when the weights sum to \(0\).

    noncomputable def weightedMean (w : ι → ℝ) (xs : ι → EuclideanSpace ℝ n) : EuclideanSpace ℝ n :=
  (∑ i, w i)⁻¹ • ∑ i, w i • xs i

    DefinitionWeighted scatter matrix#✓fully proved

    MetaMathlibExt.weightedScatter

    Let \(I\) be a finite set and \(J\) an index set, let \(x_i \in \mathbb{R}^J\) (\(i \in I\)) be points with real weights \(w_i\), and let \(\mu \in \mathbb{R}^J\). The weighted scatter matrix of the \(x_i\) about \(\mu\) is the real \(J \times J\) matrix

    \[ C = \Big(\sum_{i \in I} w_i\Big)^{-1} \sum_{i \in I} w_i \, (x_i - \mu)(x_i - \mu)^{\mathsf T}, \]

    with the convention \(0^{-1} = 0\) when the weights sum to \(0\). When \(\mu\) is the weighted mean of the \(x_i\), it is the weighted sample covariance.

    noncomputable def weightedScatter (w : ι → ℝ) (xs : ι → EuclideanSpace ℝ n)
    (μ : EuclideanSpace ℝ n) : Matrix n n ℝ :=
  (∑ i, w i)⁻¹ • ∑ i, w i • vecMulVec (ofLp (xs i - μ)) (ofLp (xs i - μ))

    TheoremPositive definiteness of weighted Gram matrices#✓fully proved

    MetaMathlibExt.posDef_mul_diagonal_mul_transpose_iff

    For a real matrix B and nonnegative weights w, the matrix B * diagonal w * Bᵀ is positive definite if and only if every nonzero vector v has (v ᵥ* B) e ≠ 0 for some column e with 0 < w e, that is, the columns of B with positive weight have full row rank. (The matrix is always positive semidefinite, by Matrix.PosSemidef.mul_mul_conjTranspose_same applied to Matrix.PosSemidef.diagonal.)

    theorem posDef_mul_diagonal_mul_transpose_iff {m k : Type*} [Fintype m] [Fintype k]
    [DecidableEq k] {B : Matrix m k ℝ} {w : k → ℝ} (hw : ∀ e, 0 ≤ w e) :
    (B * diagonal w * Bᵀ).PosDef ↔ ∀ v : m → ℝ, v ≠ 0 → ∃ e, 0 < w e ∧ (v ᵥ* B) e ≠ 0

    TheoremQuadratic diversity from pairwise dissimilarities#✓fully proved

    MetaMathlibExt.sum_mul_diag_sub_dotProduct_mulVec_eq

    Let Q be a real square matrix and w real weights with ∑ i, w i = 1, and write H_Q(w) = ∑ i, w i Q i i - wᵀ Q w (Rao's quadratic entropy form). Then:

    • if Q i j = v i + v j - δ i j / 2 for all i j, then H_Q(w) = wᵀ δ w / 2 - (∑ i, w i δ i i) / 2;
    • for the canonical dissimilarity δQ i j = Q i i + Q j j - 2 Q i j, which has zero diagonal, H_Q(w) = wᵀ δQ w / 2.

    A zero diagonal of δ is a sufficient condition for the short form wᵀ δ w / 2; for a given w the exact condition is that the weighted diagonal correction ∑ i, w i δ i i vanish. These are algebraic identities: neither Q nor δ need be symmetric, and the weights may be negative, an extension, derived here, of the usual setting of a symmetric Q and weights in the simplex. They carry no positivity, metric or concavity claim; those interpretations need further hypotheses, such as nonnegative weights.

    theorem sum_mul_diag_sub_dotProduct_mulVec_eq {w : ι → ℝ} (hw : ∑ i, w i = 1)
    (Q : Matrix ι ι ℝ) :
    (∀ (δ : Matrix ι ι ℝ) (v : ι → ℝ), (∀ i j, Q i j = v i + v j - δ i j / 2) →
      ∑ i, w i * Q i i - w ⬝ᵥ Q *ᵥ w = w ⬝ᵥ δ *ᵥ w / 2 - (∑ i, w i * δ i i) / 2) ∧
    ∑ i, w i * Q i i - w ⬝ᵥ Q *ᵥ w =
      w ⬝ᵥ (Matrix.of fun i j => Q i i + Q j j - 2 * Q i j) *ᵥ w / 2
