    Matrix concentration inequalities

    Tail and expectation bounds for the extreme eigenvalues of random Hermitian matrices, following J. A. Tropp, An Introduction to Matrix Concentration Inequalities (Found. Trends Mach. Learn. 8, 2015, arXiv:1501.01571). The matrix Laplace transform method bounds P{λmax(Y) ≥ t} and E λmax(Y) by the trace moment generating function E tr e^{θY}. For a sum of independent random matrices, Lieb's concavity theorem makes matrix cumulant generating functions subadditive, and per-summand cgf bounds then give the matrix Chernoff and Bernstein inequalities.

    DefinitionTrace moment generating function#✓fully proved

    MathlibExt.Probability.MatrixLaplaceTransform.traceMgf

    For a random matrix \(Y : \Omega \to \mathbb{K}^{d \times d}\) and a real number \(\theta\), traceMgf Y θ ω is the real number \(\operatorname{tr} e^{\theta Y(\omega)}\) (the real part of the trace of the power-series exponential). Its expectation \(\theta \mapsto \mathbb{E}\operatorname{tr} e^{\theta Y}\) is the trace moment generating function, the matrix analogue of \(\mathbb{E}\, e^{\theta X}\) in the scalar Laplace transform (Chernoff) method.

    noncomputable def traceMgf (Y : Ω → Matrix n n 𝕜) (θ : ℝ) (ω : Ω) : ℝ :=
  RCLike.re (NormedSpace.exp (θ • Y ω)).trace

    TheoremMatrix Laplace transform method, upper tail#✓fully proved

    MathlibExt.Probability.MatrixLaplaceTransform.measureReal_le_lambdaMax_le

    Let \(Y\) be a random Hermitian \(d \times d\) matrix on a finite measure space \((\Omega, \mu)\), with \(d \ge 1\), and let \(\theta > 0\) be such that \(\omega \mapsto \operatorname{tr} e^{\theta Y(\omega)}\) is integrable. Then for every real \(t\), $\(\mu\{\lambda_{\max}(Y) \ge t\} \le e^{-\theta t} \int \operatorname{tr} e^{\theta Y}\, d\mu .\)$ Since the bound holds for every \(\theta > 0\), it holds for the infimum over \(\theta > 0\), which is the form of Tropp's Proposition 3.2.1. The proof is Markov's inequality applied to \(e^{\theta\lambda_{\max}(Y)}\), followed by \(e^{\theta\lambda_{\max}(Y)} \le \operatorname{tr} e^{\theta Y}\).

    theorem measureReal_le_lambdaMax_le {μ : Measure Ω} [IsFiniteMeasure μ]
    {Y : Ω → Matrix n n 𝕜} (hY : ∀ ω, (Y ω).IsHermitian) {θ : ℝ} (hθ : 0 < θ)
    (hint : Integrable (traceMgf Y θ) μ) (t : ℝ) :
    μ.real {ω | t ≤ (hY ω).lambdaMax} ≤ Real.exp (-θ * t) * ∫ ω, traceMgf Y θ ω ∂μ
    noncomputable def traceMgf (Y : Ω → Matrix n n 𝕜) (θ : ℝ) (ω : Ω) : ℝ :=
  RCLike.re (NormedSpace.exp (θ • Y ω)).trace

    TheoremMatrix Laplace transform method, expectation bound#✓fully proved

    MathlibExt.Probability.MatrixLaplaceTransform.integral_lambdaMax_le

    Let \(Y\) be a random Hermitian \(d \times d\) matrix on a probability space, with \(d \ge 1\), such that \(\lambda_{\max}(Y)\) is integrable, and let \(\theta > 0\) be such that \(\operatorname{tr} e^{\theta Y}\) is integrable. Then $\(\mathbb{E}\,\lambda_{\max}(Y) \le \frac{1}{\theta}\log \mathbb{E}\operatorname{tr} e^{\theta Y}.\)$ The proof applies Jensen's inequality to the exponential, \(e^{\theta\,\mathbb{E}\lambda_{\max}(Y)} \le \mathbb{E}\, e^{\theta\lambda_{\max}(Y)}\), then the trace bound, then the logarithm. Tropp remarks that this argument has no perfect scalar analogue.

    theorem integral_lambdaMax_le {μ : Measure Ω} [IsProbabilityMeasure μ]
    {Y : Ω → Matrix n n 𝕜} (hY : ∀ ω, (Y ω).IsHermitian) {θ : ℝ} (hθ : 0 < θ)
    (hmax : Integrable (fun ω => (hY ω).lambdaMax) μ)
    (hint : Integrable (traceMgf Y θ) μ) :
    ∫ ω, (hY ω).lambdaMax ∂μ ≤ θ⁻¹ * Real.log (∫ ω, traceMgf Y θ ω ∂μ)
    noncomputable def traceMgf (Y : Ω → Matrix n n 𝕜) (θ : ℝ) (ω : Ω) : ℝ :=
  RCLike.re (NormedSpace.exp (θ • Y ω)).trace

    DefinitionExpectation of a random matrix#✓fully proved

    MathlibExt.Probability.MatrixLaplaceTransform.expect

    For a random matrix \(M : \Omega \to \mathbb{K}^{n \times n}\) over \(\mathbb{K} = \mathbb{R}\) or \(\mathbb{C}\), expect μ M is the matrix of entrywise expectations \((\mathbb{E}\,M)_{ij} = \int M(\omega)_{ij}\, d\mu(\omega)\). This is the expectation of a random matrix as Tropp defines it; matrices carry no global norm in Mathlib, so the entrywise Bochner integral is used.

    noncomputable def expect (μ : Measure Ω) (M : Ω → Matrix n n 𝕜) : Matrix n n 𝕜 :=
  Matrix.of fun i j => ∫ ω, M ω i j ∂μ

    TheoremSubadditivity of matrix cumulant generating functions#●ready to prove

    MathlibExt.Probability.MatrixConcentrationWanted.integral_trace_exp_sum_le

    Let \(X_0, \dots, X_{N-1}\) be independent random Hermitian \(d \times d\) complex matrices on a probability space and \(\theta \in \mathbb{R}\). Assume that the entries of each \(e^{\theta X_k}\) and the trace \(\operatorname{tr} e^{\theta \sum_k X_k}\) are integrable. Then $\(\mathbb{E}\operatorname{tr}\exp\Big(\theta \sum_k X_k\Big) \le \operatorname{tr}\exp\Big(\sum_k \log \mathbb{E}\, e^{\theta X_k}\Big).\)$ In terms of the matrix cgfs \(\Xi_{X}(\theta) = \log \mathbb{E}\, e^{\theta X}\) this reads \(\operatorname{tr}\exp \Xi_{\sum_k X_k}(\theta) \le \operatorname{tr}\exp \sum_k \Xi_{X_k}(\theta)\), a matrix substitute for the additivity of scalar cgfs. The proof applies Lieb's theorem once per summand, conditioning on the others.

    DefinitionMatrix Gaussian series#✓fully proved

    MathlibExt.Probability.MatrixLaplaceTransform.gaussianSeries

    For fixed matrices \(A_0, \dots, A_{N-1}\) over \(\mathbb{K} = \mathbb{R}\) or \(\mathbb{C}\) and a coefficient vector \(\omega \in \mathbb{R}^N\), gaussianSeries A ω is the matrix \(\sum_k \omega_k A_k\). When \(\omega\) is a standard Gaussian vector this is the matrix Gaussian series \(Y = \sum_k \gamma_k A_k\), the basic model of a random matrix with Gaussian coefficients and arbitrary correlations between its entries.

    noncomputable def gaussianSeries {N : ℕ} (A : Fin N → Matrix n n 𝕜) (ω : Fin N → ℝ) :
    Matrix n n 𝕜 :=
  ∑ k, ((ω k : ℝ) : 𝕜) • A k

    MathlibExt.Probability.MatrixConcentrationWanted.matrix_gaussian_series

    Let \(A_0, \dots, A_{N-1}\) be fixed Hermitian \(d \times d\) complex matrices, \(d \ge 1\), let \(\gamma_0, \dots, \gamma_{N-1}\) be independent standard normal variables, \(Y = \sum_k \gamma_k A_k\), and let $\(v(Y) = \|\mathbb{E}\,Y^2\| = \Big\|\sum_k A_k^2\Big\| = \lambda_{\max}\Big(\sum_k A_k^2\Big).\)$ Then $\(\mathbb{E}\,\lambda_{\max}(Y) \le \sqrt{2 v(Y) \log d} \qquad\text{and}\qquad \mathbb{P}\{\lambda_{\max}(Y) \ge t\} \le d\, e^{-t^2/(2v(Y))} \quad (t \ge 0).\)$ Tropp's theorem also covers Rademacher coefficients; that version is not stated here.

    TheoremMatrix Chernoff inequality#●ready to prove

    MathlibExt.Probability.MatrixConcentrationWanted.matrix_chernoff

    Let \(X_0, \dots, X_{N-1}\) be independent random Hermitian \(d \times d\) complex matrices on a probability space, \(d \ge 1\), with $\(0 \le \lambda_{\min}(X_k) \quad\text{and}\quad \lambda_{\max}(X_k) \le L \qquad\text{for each } k,\)$ where \(L > 0\). Let \(Y = \sum_k X_k\), \(\mu_{\min} = \lambda_{\min}(\mathbb{E}\,Y)\) and \(\mu_{\max} = \lambda_{\max}(\mathbb{E}\,Y)\). Then $\(\mathbb{P}\{\lambda_{\max}(Y) \ge (1+\varepsilon)\mu_{\max}\} \le d\left[\frac{e^{\varepsilon}}{(1+\varepsilon)^{1+\varepsilon}}\right]^{\mu_{\max}/L} \quad (\varepsilon \ge 0),\)$ $\(\mathbb{P}\{\lambda_{\min}(Y) \le (1-\varepsilon)\mu_{\min}\} \le d\left[\frac{e^{-\varepsilon}}{(1-\varepsilon)^{1-\varepsilon}}\right]^{\mu_{\min}/L} \quad (0 \le \varepsilon < 1).\)$ These are the scalar Chernoff bounds for sums of bounded nonnegative variables, up to the dimensional factor \(d\). Typical uses: the smallest singular value of a random submatrix, sparsification of graphs and random sampling of columns.

    The statement is recorded as wanted: its proof is deferred. The Lean statement requires the bounds for every outcome, and takes the hermiticity of \(\sum_k X_k\) and of \(\mathbb{E}\,Y\) as hypotheses (both always hold).

    (hY : ∀ ω, (∑ k, X k ω).IsHermitian)

    (∀ ε : ℝ, 0 ≤ ε →
      μ.real {ω | (1 + ε) * hEY.lambdaMax ≤ (hY ω).lambdaMax} ≤

    TheoremMatrix Bernstein inequality, Hermitian case#●ready to prove

    MathlibExt.Probability.MatrixConcentrationWanted.matrix_bernstein

    Let \(X_0, \dots, X_{N-1}\) be independent random Hermitian \(d \times d\) complex matrices on a probability space, \(d \ge 1\), with $\(\mathbb{E}\,X_k = 0 \quad\text{and}\quad \lambda_{\max}(X_k) \le L \qquad\text{for each } k,\)$ with integrable entries of \(X_k\) and \(X_k^2\). Let \(Y = \sum_k X_k\) and let $\(v(Y) = \|\mathbb{E}\,Y^2\| = \Big\|\sum_k \mathbb{E}\,X_k^2\Big\| = \lambda_{\max}\Big(\sum_k \mathbb{E}\,X_k^2\Big)\)$ be the matrix variance statistic (the matrix is positive semidefinite, so its norm is its largest eigenvalue). Then for all \(t \ge 0\), $\(\mathbb{P}\{\lambda_{\max}(Y) \ge t\} \le d \cdot \exp\left(\frac{-t^2/2}{v(Y) + Lt/3}\right).\)$ The rectangular version (Tropp's Theorem 6.1.1, with \(d_1 + d_2\) in place of \(d\)) follows through the Hermitian dilation.

    MathlibExt.Probability.MatrixConcentrationWanted.matrix_hoeffding

    Let \(X_0, \dots, X_{N-1}\) be independent random Hermitian \(d \times d\) complex matrices on a probability space, \(d \ge 1\), and \(A_0, \dots, A_{N-1}\) fixed Hermitian matrices, such that $\(\mathbb{E}\,X_k = 0 \quad\text{and}\quad X_k^2 \preceq A_k^2 \qquad\text{for each } k,\)$ the semidefinite bound holding for every outcome.
