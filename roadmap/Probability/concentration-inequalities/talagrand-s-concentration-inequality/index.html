    Talagrand's concentration inequality

    A convex, \(1\)-Lipschitz function of independent bounded random variables concentrates around its median and its mean at the scale of the bound, with Gaussian tails and constants independent of the dimension. McDiarmid's bounded-differences inequality gives fluctuations of order \(\sqrt{n}\) for the same functions; convexity removes the dependence on \(n\). In random matrix theory this makes the operator norm and other convex spectral statistics concentrate. Both forms are stated, not yet proved.

    Behind them stands Talagrand's convex-distance inequality (1995). For \(A \subseteq \Omega^N\) and \(x \in \Omega^N\), the convex distance \(f_c(A, x)\) is the Euclidean distance from \(0\) to the convex hull of the sets of coordinates along which \(x\) can be changed into a point of \(A\); for the product probability \(P = \mu^{\otimes N}\) of any probability measure \(\mu\) on \(\Omega\), \(\int \exp(f_c(A, \cdot)^2/4)\,dP \le 1/P(A)\). The convex distance and its elementary properties are defined and proved. The inequality is proved when \(\Omega\) is a finite set, by Talagrand's induction on \(N\); for a general probability space it is stated, not yet proved.

    TheoremTalagrand's concentration inequality around a median#●ready to prove

    MathlibExt.Probability.TalagrandConcentrationWanted.talagrand_concentration_median

    There are absolute constants \(C, c > 0\) with the following property. Let \(K > 0\), let \(X_1, \dots, X_n\) be independent real random variables with \(|X_i| \le K\), let \(F : \mathbb{R}^n \to \mathbb{R}\) be convex and \(1\)-Lipschitz for the Euclidean metric, and let \(m\) be a median of \(F(X)\), where \(X = (X_1, \dots, X_n)\). Then $\(\mathbb{P}\big(|F(X) - m| \ge \lambda K\big) \le C e^{-c\lambda^2} \quad \text{for every } \lambda > 0.\)$ The constants depend on neither \(n\), \(K\), \(F\) nor the laws of the \(X_i\).

    Tao states the theorem for complex variables and \(F : \mathbb{C}^n \to \mathbb{R}\), identifying \(\mathbb{C}^n\) with \(\mathbb{R}^{2n}\); the real case follows by composing \(F\) with \(z \mapsto \operatorname{Re} z\). His "for any \(\lambda\)" means \(\lambda > 0\): for \(\lambda < 0\) the event is certain while the bound tends to \(0\).

    public theorem_wanted talagrand_concentration_median :
    ∃ C > 0, ∃ c > 0, ∀ (Ω : Type*) (_ : MeasurableSpace Ω) (P : Measure Ω),
      IsProbabilityMeasure P → ∀ (n : ℕ) (X : Fin n → Ω → ℝ) (K : ℝ), 0 < K →
      (∀ i, Measurable (X i)) → iIndepFun X P → (∀ i ω, |X i ω| ≤ K) →
      ∀ F : EuclideanSpace ℝ (Fin n) → ℝ, ConvexOn ℝ Set.univ F → LipschitzWith 1 F →
      ∀ m : ℝ, 1 / 2 ≤ P.real {ω | F (WithLp.toLp 2 fun i => X i ω) ≤ m} →
        1 / 2 ≤ P.real {ω | m ≤ F (WithLp.toLp 2 fun i => X i ω)} →
      ∀ t : ℝ, 0 < t →
        P.real {ω | t * K ≤ |F (WithLp.toLp 2 fun i => X i ω) - m|} ≤ C * exp (-c * t ^ 2)

    TheoremTalagrand's concentration inequality around the mean#●ready to prove

    DefinitionTalagrand's set \(U_A(x)\)#✓fully proved

    MathlibExt.Probability.ConvexDistance.convexSupport

    For \(A \subseteq \Omega^N\) and \(x \in \Omega^N\), $\(U_A(x) = \{ s \in \{0, 1\}^N : \exists\, y \in A,\ s_i = 0 \Rightarrow y_i = x_i \},\)$ seen as a subset of \(\mathbb{R}^N\) (Talagrand, Concentration of measure and isoperimetric inequalities in product spaces, Publ. Math. IHÉS 81 (1995), Section 4.1). A vector \(s\) lies in \(U_A(x)\) when some point of \(A\) can be reached from \(x\) by changing only coordinates where \(s_i = 1\). Thus \(0 \in U_A(x)\) exactly when \(x \in A\).

    def convexSupport (A : Set (Fin N → Ω)) (x : Fin N → Ω) : Set (EuclideanSpace ℝ (Fin N)) :=
  {s | ∃ y ∈ A, (∀ i, s i = 0 ∨ s i = 1) ∧ ∀ i, s i = 0 → y i = x i}

    DefinitionTalagrand's convex distance#✓fully proved

    MathlibExt.Probability.ConvexDistance.convexDistance

    For \(A \subseteq \Omega^N\) and \(x \in \Omega^N\), \(f_c(A, x)\) is the Euclidean distance from \(0\) to the convex hull \(V_A(x)\) of \(U_A(x)\) in \(\mathbb{R}^N\) (Talagrand, Concentration of measure and isoperimetric inequalities in product spaces, Publ. Math. IHÉS 81 (1995), Section 4.1). By duality (Lemma 4.1.2 of the source), \(f_c(A, x) \le t\) means that for every nonnegative weight vector \(\alpha\) some \(y \in A\) differs from \(x\) on a set of coordinates of \(\alpha\)-weight at most \(t\,\|\alpha\|_2\): one distance controls all weighted Hamming distances at once.

    When \(A\) is empty, \(V_A(x)\) is empty and Mathlib's Metric.infDist returns \(0\), while the source's distance is \(+\infty\); the convex-distance inequality is unaffected, its right-hand side \(1/P(\emptyset)\) being \(+\infty\).

    noncomputable def convexDistance (A : Set (Fin N → Ω)) (x : Fin N → Ω) : ℝ :=
  infDist (0 : EuclideanSpace ℝ (Fin N)) (convexHull ℝ (convexSupport A x))
    def convexSupport (A : Set (Fin N → Ω)) (x : Fin N → Ω) : Set (EuclideanSpace ℝ (Fin N)) :=
  {s | ∃ y ∈ A, (∀ i, s i = 0 ∨ s i = 1) ∧ ∀ i, s i = 0 → y i = x i}

    TheoremThe convex distance is at most the square root of the Hamming distance#✓fully proved

    MathlibExt.Probability.ConvexDistance.convexDistance_le_sqrt_card

    For every \(y \in A\), \(f_c(A, x) \le \sqrt{\operatorname{card}\{i : x_i \ne y_i\}}\): the indicator vector of \(\{i : x_i \ne y_i\}\) lies in \(U_A(x)\) and has that Euclidean norm (Talagrand, Concentration of measure and isoperimetric inequalities in product spaces, Publ.     TheoremTalagrand's convex-distance inequality#●ready to prove

    MathlibExt.Probability.ConvexDistanceWanted.lintegral_exp_convexDistance_sq_le

    Let \((\Omega, \mu)\) be a probability space, \(P = \mu^{\otimes N}\) the product probability on \(\Omega^N\) and \(A \subseteq \Omega^N\) measurable. Then $\(\int \exp\Big(\frac14 f_c^2(A, x)\Big)\,dP(x) \le \frac{1}{P(A)}\)$ (Talagrand, Concentration of measure and isoperimetric inequalities in product spaces, Publ. Math. IHÉS 81 (1995), Theorem 4.1.1, (4.1.2)). Neither \(N\) nor \(\mu\) enters the bound.

    The source treats \(f_c(A, \cdot)\) as measurable and otherwise reads the integral as an upper integral. The Lean statement uses Mathlib's lower Lebesgue integral, which is at most the upper integral, so it follows from the source's statement. Stated, not yet proved in this generality; for a finite \(\Omega\) it is proved in this very form in the measure form for a finite probability space.

    theorem_wanted lintegral_exp_convexDistance_sq_le {Ω : Type*} [MeasurableSpace Ω]

    ∫⁻ x, ENNReal.ofReal (Real.exp (convexDistance A x ^ 2 / 4)) ∂Measure.pi (fun _ => μ) ≤
      (Measure.pi (fun _ => μ) A)⁻¹

    TheoremTalagrand's geometric step#✓fully proved

    MathlibExt.Probability.ConvexDistance.convexDistance_cons_sq_le

    For \(A \subseteq \Omega^{N+1}\), \(\omega \in \Omega\), \(x \in \Omega^N\) and \(0 \le \lambda \le 1\), $\(f_c^2(A, (\omega, x)) \le (1 - \lambda)^2 + \lambda\, f_c^2(A(\omega), x) + (1 - \lambda)\, f_c^2(B, x),\)$ where \(A(\omega)\) is the section and \(B\) the projection (Talagrand, Concentration of measure and isoperimetric inequalities in product spaces, Publ. Math. IHÉS 81 (1995), (4.1.7)). If \(s \in U_{A(\omega)}(x)\) then \((0, s) \in U_A((\omega, x))\), and if \(t \in U_B(x)\) then \((1, t) \in U_A((\omega, x))\); so \((\lambda s + (1-\lambda) t, 1 - \lambda)\) lies in the convex hull, and convexity of \(u \mapsto u^2\) gives the bound. Talagrand splits off the last coordinate; the first is used here.

    The projection must be nonempty, and the section too unless \(\lambda = 0\): Mathlib's distance to an empty set is \(0\), not \(+\infty\).

    theorem convexDistance_cons_sq_le (A : Set (Fin (N + 1) → Ω)) (ω : Ω) (x : Fin N → Ω) {l : ℝ}
    (hl0 : 0 ≤ l) (hl1 : l ≤ 1) (hB : (projection A).Nonempty)
    (hsec : l = 0 ∨ (sectionAt A ω).Nonempty) :
    convexDistance A (Fin.cons ω x) ^ 2 ≤
      (1 - l) ^ 2 + l * convexDistance (sectionAt A ω) x ^ 2 +
        (1 - l) * convexDistance (projection A) x ^ 2
    def projection (A : Set (Fin (N + 1) → Ω)) : Set (Fin N → Ω) := {x | ∃ ω, Fin.cons ω x ∈ A}

    TheoremTalagrand's numerical lemma#✓fully proved

    MathlibExt.Probability.ConvexDistance.exists_exp_le_two_sub_mul_rpow

    For \(0 \le r \le 1\), $\(\inf_{0 \le \lambda \le 1} r^{-\lambda} e^{(1-\lambda)^2/4} \le 2 - r\)$ (Talagrand, Concentration of measure and isoperimetric inequalities in product spaces, Publ. It is stated as the existence of \(\lambda \in [0, 1]\) with \(e^{(1-\lambda)^2/4} \le (2 - r)\,r^{\lambda}\), and \(\lambda = 0\) unless \(r > 0\).     TheoremTalagrand's convex-distance inequality on a product of finite sets#✓fully proved

    MathlibExt.Probability.ConvexDistance.sum_exp_convexDistance_mul_weightOf_le

    Let \(p\) be a probability vector on a finite set \(\Omega\) and \(P = p^{\otimes N}\). For every \(N\) and every \(A \subseteq \Omega^N\), $\(\Big(\sum_{x} P(x)\, e^{f_c^2(A, x)/4}\Big)\cdot P(A) \le 1,\)$ that is \(\int e^{f_c^2(A, \cdot)/4}\,dP \le 1/P(A)\) when \(P(A) > 0\) (Talagrand, Concentration of measure and isoperimetric inequalities in product spaces, Publ. Math. IHÉS 81 (1995), Theorem 4.1.1, (4.1.2), for a finite \(\Omega\)). The product form also covers \(P(A) = 0\).

    The proof is Talagrand's induction on \(N\). For \(N = 0\) the space is a point. For the step, fix the first coordinate \(\omega\) and put \(\alpha = P(A(\omega))\), \(\beta = P(B)\) and \(r = \alpha/\beta\).
