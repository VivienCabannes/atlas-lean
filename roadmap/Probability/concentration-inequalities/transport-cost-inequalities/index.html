    Transport-cost inequalities

    A probability measure \(m\) satisfies Talagrand's quadratic transport-cost inequality with constant \(C\) if \(W_2(\mu, m)^2 \le C \operatorname{Ent}_m(\mu)\) for every probability measure \(\mu\), where \(\operatorname{Ent}_m\) is the relative entropy. It satisfies the logarithmic Sobolev inequality with constant \(\alpha > 0\) if \(2\alpha \int f \log f \, dm \le \int_{\{f > 0\}} |\nabla f|^2 / f \, dm\) for every nonnegative Lipschitz density \(f\). Otto and Villani (2000) showed, through Otto's formal Riemannian calculus on the Wasserstein space, that the logarithmic Sobolev inequality with constant \(\alpha\) implies the transport inequality with constant \(2/\alpha\), and proved the HWI inequality relating entropy, Wasserstein distance and Fisher information. Gigli and Ledoux (2013) extended the Otto–Villani theorem to complete separable metric measure spaces.

    DefinitionLocal Lipschitz constant (slope)#✓fully proved

    MathlibExt.Probability.LogSobolevTalagrand.localLipschitzConstant

    For \(f : X \to \mathbb{R}\) on a metric space, the local Lipschitz constant is $\(|\nabla f|(x) = \limsup_{y \to x} \frac{|f(y) - f(x)|}{d(x, y)} \in [0, \infty],\)$ the upper limit over \(y \ne x\), equal to \(0\) at isolated points. For a \(C^1\) function on a Riemannian manifold it is the norm of the gradient. It is the notion of gradient in which Gigli and Ledoux state the logarithmic Sobolev inequality on metric measure spaces.

    noncomputable def localLipschitzConstant (f : X → ℝ) (x : X) : ℝ≥0∞ :=
  limsup (fun y => ENNReal.ofReal (|f y - f x| / dist y x)) (𝓝[≠] x)

    DefinitionLogarithmic Sobolev inequality#✓fully proved

    MathlibExt.Probability.LogSobolevTalagrand.SatisfiesLogSobolev

    A measure \(m\) on a metric space satisfies the logarithmic Sobolev inequality with constant \(\alpha\) if for every nonnegative Lipschitz function \(f\) with \(\int f \, dm = 1\), $\(2\alpha \int f \log f \, dm \le \int_{\{f > 0\}} \frac{|\nabla f|^2}{f} \, dm,\)$ where \(|\nabla f|\) is the local Lipschitz constant and \(\int f \log f \, dm = \operatorname{Ent}_m(f m)\) is the relative entropy of \(f m\) with respect to \(m\) (Mathlib's Kullback–Leibler divergence, valued in \([0, \infty]\)). The right side is the Fisher information of \(f m\) relative to \(m\). For the standard Gaussian measure the inequality holds with \(\alpha = 1\) (Gross).

    Gigli and Ledoux show that this formulation is equivalent to the ones with the descending slope, with upper gradients, and with Sobolev functions (their Proposition 5.1).

    def SatisfiesLogSobolev (m : Measure X) (α : ℝ) : Prop :=
  ∀ f : X → ℝ, (∃ K, LipschitzWith K f) → (∀ x, 0 ≤ f x) → ∫ x, f x ∂m = 1 →
    ENNReal.ofReal (2 * α) * klDiv (m.withDensity fun x => ENNReal.ofReal (f x)) m ≤
      ∫⁻ x in {x | 0 < f x}, localLipschitzConstant f x ^ 2 / ENNReal.ofReal (f x) ∂m
    noncomputable def localLipschitzConstant (f : X → ℝ) (x : X) : ℝ≥0∞ :=
  limsup (fun y => ENNReal.ofReal (|f y - f x| / dist y x)) (𝓝[≠] x)

    DefinitionTalagrand's quadratic transport-cost inequality#✓fully proved

    MathlibExt.Probability.LogSobolevTalagrand.SatisfiesTalagrand

    A probability measure \(m\) on a metric space satisfies Talagrand's inequality with constant \(C\) if $\(W_2(\mu, m)^2 \le C \operatorname{KL}(\mu \,\|\, m)\)$ for every probability measure \(\mu\), where \(W_2\) is the quadratic Wasserstein distance. In Villani's notation \(T_2(\lambda)\) is the case \(C = 2/\lambda\); the standard Gaussian satisfies it with \(C = 2\) (Talagrand's transport inequality for the Gaussian measure).

    def SatisfiesTalagrand (m : ProbabilityMeasure X) (C : ℝ) : Prop :=
  ∀ μ : ProbabilityMeasure X,
    wasserstein 2 μ m ^ (2 : ℝ) ≤ ENNReal.ofReal C * klDiv (μ : Measure X) (m : Measure X)
    noncomputable def wasserstein (p : ℝ) (μ ν : ProbabilityMeasure X) : ℝ≥0∞ :=
  transportCost p μ ν ^ (1 / p)

    TheoremTalagrand's inequality bounds \(W_1\)#✓fully proved

    MathlibExt.Probability.LogSobolevTalagrand.SatisfiesTalagrand.wasserstein_one_sq_le

    If \(m\) satisfies Talagrand's inequality with constant \(C\), then $\(W_1(\mu, m)^2 \le C \operatorname{KL}(\mu \,\|\, m)\)$ for every probability measure \(\mu\), because \(W_1 \le W_2\). This is the \(T_1\) form of the transport inequality, the form that controls integrals of Lipschitz functions.

    wasserstein 1 μ m ^ (2 : ℝ) ≤ ENNReal.ofReal C * klDiv (μ : Measure X) (m : Measure X)

    TheoremOtto–Villani theorem#●ready to prove

    MathlibExt.Probability.OttoVillaniWanted.satisfiesTalagrand_of_satisfiesLogSobolev

    Let \((X, d, m)\) be a complete separable metric space with a Borel probability measure \(m\) that satisfies the logarithmic Sobolev inequality with constant \(\alpha > 0\). Then \(m\) satisfies Talagrand's inequality with constant \(2/\alpha\): $\(W_2(\mu, m)^2 \le \frac{2}{\alpha} \operatorname{KL}(\mu \,\|\, m) \quad \text{for every probability measure } \mu.\)$

    Otto and Villani proved it on Riemannian manifolds using Otto's formal Riemannian calculus on the Wasserstein space. Gigli and Ledoux present the argument as follows (their Section 3, after Gigli, Kuwada and Ohta, who first put forward the key metric-speed bound): along the heat flow \(\mu_t\) started at \(\mu\), the entropy \(\varphi(t) = \operatorname{Ent}_m(\mu_t)\) has \(\varphi' = -I(\mu_t)\) (the Fisher information), the metric speed satisfies \(|\dot\mu_t|^2 \le I(\mu_t)\), and the log-Sobolev inequality \(I \ge 2\alpha\varphi\) turns these into \(|\dot \mu_t| \le -\tfrac{d}{dt} \sqrt{2\varphi(t)/\alpha}\); integrating in time gives \(W_2(\mu, m) \le \sqrt{2 \operatorname{Ent}_m(\mu)/\alpha}\). Gigli and Ledoux carry this argument out on metric measure spaces with the heat flow of the Cheeger energy.

    Applied to Gross' inequality for the Gaussian measure (\(\alpha = 1\), once extended from smooth positive densities to nonnegative Lipschitz ones) it recovers Talagrand's inequality for the Gaussian measure.

    (hm : SatisfiesLogSobolev (m : Measure X) α) :
    SatisfiesTalagrand m (2 / α)

    TheoremHWI inequality#●ready to prove

    MathlibExt.Probability.OttoVillaniWanted.klDiv_le_wasserstein_mul_sqrt_fisher

    Let \(V\) be a smooth (\(C^\infty\)) convex function on \(\mathbb{R}^n\) (or any finite-dimensional real inner product space) such that \(\mu = e^{-V} dx\) is a probability measure. For every smooth (\(C^\infty\)) positive \(f\) with \(\int f \, d\mu = 1\), writing \(\nu = f \mu\), $\(\int f \log f \, d\mu \le W_2(\nu, \mu) \left( \int \frac{|\nabla f|^2}{f} \, d\mu \right)^{1/2},\)$ that is \(H \le W \sqrt{I}\) for the relative entropy \(H = \operatorname{KL}(\nu \,\|\, \mu)\), the Wasserstein distance \(W\) and the relative Fisher information \(I\). Ledoux states it on weighted Riemannian manifolds \(e^{-V} dx\) with a smooth potential \(V\), under the curvature condition \(CD(0, \infty)\), which on \(\mathbb{R}^n\) with \(e^{-V} dx\) means that \(V\) is convex. Ledoux notes that the same argument under \(CD(K, \infty)\) for any real \(K\) gives the full form of Otto and Villani's HWI inequality, which carries a curvature term in \(K W^2\); that form is not stated here.

    The inequality expresses the convexity of the relative entropy along Wasserstein geodesics, the Bakry–Émery condition read in Otto's calculus.

    (μ : ProbabilityMeasure E)
    (hμ : (μ : Measure E) = volume.withDensity fun x => ENNReal.ofReal (Real.exp (-V x)))
    {f : E → ℝ} (hf : ContDiff ℝ ∞ f) (hfpos : ∀ x, 0 < f x)
    (hfint : ∫ x, f x ∂(μ : Measure E) = 1)
    (ν : ProbabilityMeasure E)
    (hν : (ν : Measure E) = (μ : Measure E).withDensity fun x => ENNReal.ofReal (f x)) :

        (∫⁻ x, ‖fderiv ℝ f x‖ₑ ^ 2 / ENNReal.ofReal (f x) ∂(μ : Measure E)) ^ (1 / 2 : ℝ)

    TheoremGross' logarithmic Sobolev inequality#●ready to prove

    MathlibExt.Probability.GaussianLogSobolevWanted.klDiv_withDensity_stdGaussian_le

    Let \(\gamma\) be the standard Gaussian measure on \(\mathbb{R}^n\) (or on any finite-dimensional real inner product space). For every smooth (\(C^\infty\)) positive \(f\) with \(\int f \, d\gamma = 1\), $\(\int f \log f \, d\gamma \le \frac12 \int \frac{|\nabla f|^2}{f} \, d\gamma ,\)$ the left side being the relative entropy \(\operatorname{KL}(f\gamma \,\|\, \gamma)\). The constant does not depend on the dimension. Ledoux presents the proof of Bakry and Émery: interpolate the entropy along the heat semigroup and use the commutation \(\nabla P_u f = P_u \nabla f\) with the Jensen and Cauchy–Schwarz inequalities.

    This is the logarithmic Sobolev inequality with constant \(\alpha = 1\), stated for smooth positive densities as in the source rather than for nonnegative Lipschitz ones. Through the Otto–Villani theorem it is the log-Sobolev side of Talagrand's inequality for the Gaussian measure.

    theorem_wanted klDiv_withDensity_stdGaussian_le {E : Type*} [NormedAddCommGroup E]
    [InnerProductSpace ℝ E] [FiniteDimensional ℝ E] [MeasurableSpace E] [BorelSpace E]
    {f : E → ℝ} (hf : ContDiff ℝ ∞ f) (hfpos : ∀ x, 0 < f x)
    (hfint : ∫ x, f x ∂(stdGaussian E) = 1) :
    klDiv ((stdGaussian E).withDensity fun x => ENNReal.ofReal (f x)) (stdGaussian E) ≤
      (1 / 2 : ℝ≥0∞) * ∫⁻ x, ‖fderiv ℝ f x‖ₑ ^ 2 / ENNReal.ofReal (f x) ∂(stdGaussian E)

    TheoremDirac masses satisfy the logarithmic Sobolev inequality#✓fully proved

    MathlibExt.Probability.LogSobolevTalagrand.satisfiesLogSobolev_dirac

    For every \(\alpha\), the Dirac mass \(\delta_{x_0}\) satisfies the logarithmic Sobolev inequality with constant \(\alpha\): a density with \(\int f \, d\delta_{x_0} = 1\) has \(f(x_0) = 1\), so \(f \delta_{x_0} = \delta_{x_0}\) and the entropy vanishes. This is a non-vacuity check for the definition.

    SatisfiesLogSobolev (Measure.dirac x₀) α

    MathlibExt.Probability.LogSobolevTalagrand.satisfiesTalagrand_dirac

    For every \(C > 0\), \(\delta_{x_0}\) satisfies Talagrand's inequality with constant \(C\): \(\operatorname{KL}(\mu \,\|\, \delta_{x_0}) = \infty\) unless \(\mu = \delta_{x_0}\), and \(W_2(\delta_{x_0}, \delta_{x_0}) = 0\).
