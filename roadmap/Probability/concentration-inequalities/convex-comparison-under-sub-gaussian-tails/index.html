    Convex comparison under sub-Gaussian tails

    StructureRandom variables with a 1-sub-Gaussian tail#✓fully proved

    MathlibExt.Probability.ConvexSubGaussianComparison.IsOneSubGaussianTail

    Let \(\mu\) be a probability measure on a measurable space \(\Omega\). A function \(X : \Omega \to \mathbb{R}\) has a 1-sub-Gaussian tail when it is measurable and integrable, has mean \(\int X \, d\mu = 0\), and satisfies \(\mu\{\omega : |X(\omega)| > t\} \le 2 e^{-t^2/2}\) for every real \(t \ge 0\).

    structure IsOneSubGaussianTail {Ω : Type*} [MeasurableSpace Ω]
    (μ : Measure Ω) [IsProbabilityMeasure μ] (X : Ω → ℝ) : Prop where
  measurable : Measurable X
  integrable : Integrable X μ
  mean_zero : ∫ ω, X ω ∂μ = 0
  tail_le : ∀ t : ℝ, 0 ≤ t →
    μ {ω | |X ω| > t} ≤ ENNReal.ofReal (2 * Real.exp (-t ^ 2 / 2))

    DefinitionConvex domination#✓fully proved

    MathlibExt.Probability.ConvexSubGaussianComparison.ConvexDominated

    Let \(\mu_X\) and \(\mu_Y\) be measures on measurable spaces \(\Omega_X\) and \(\Omega_Y\), and let \(X : \Omega_X \to \mathbb{R}\) and \(Y : \Omega_Y \to \mathbb{R}\). Then \(X\) (under \(\mu_X\)) is convexly dominated by \(Y\) (under \(\mu_Y\)) when every convex function \(f : \mathbb{R} \to \mathbb{R}\) for which \(f \circ X\) is \(\mu_X\)-integrable and \(f \circ Y\) is \(\mu_Y\)-integrable satisfies \(\int f(X) \, d\mu_X \le \int f(Y) \, d\mu_Y\).

    def ConvexDominated {ΩX ΩY : Type*}
    [MeasurableSpace ΩX] [MeasurableSpace ΩY]
    (μX : Measure ΩX) (X : ΩX → ℝ) (μY : Measure ΩY) (Y : ΩY → ℝ) : Prop :=
  ∀ f : ℝ → ℝ, ConvexOn ℝ univ f →
    Integrable (fun ω => f (X ω)) μX →
    Integrable (fun ω => f (Y ω)) μY →
    (∫ ω, f (X ω) ∂μX) ≤ ∫ ω, f (Y ω) ∂μY

    DefinitionAdmissible convex sub-Gaussian comparison constants#✓fully proved

    MathlibExt.Probability.ConvexSubGaussianComparison.IsAdmissibleConstant

    An extended nonnegative real \(C \in [0, \infty]\) is an admissible comparison constant when \(0 < C < \infty\) and, for every probability measure \(\mu\) on a measurable space \(\Omega\) and every function \(X : \Omega \to \mathbb{R}\) with a 1-sub-Gaussian tail under \(\mu\), \(X\) under \(\mu\) is convexly dominated by the function \(g \mapsto \sqrt{C}\, g\) under the standard Gaussian measure \(\mathcal{N}(0, 1)\) on \(\mathbb{R}\).

    TheoremAdmissible constants compare variables on every sample space#✓fully proved

    MathlibExt.Probability.ConvexSubGaussianComparison.IsAdmissibleConstant.elim

    Let \(C\) be an admissible comparison constant, let \(\mu\) be a probability measure on a measurable space \(\Omega\), and let \(X : \Omega \to \mathbb{R}\) have a 1-sub-Gaussian tail. Then \(X\) is convexly dominated by \(\sqrt{C}\,G\), where \(G\) is a standard Gaussian random variable (the identity on \(\mathbb{R}\) under the standard normal law \(N(0, 1)\)).

    The definition of admissibility quantifies only over sample spaces in the lowest universe; this form allows \(\Omega\) in any universe, by pushing the law of \(X\) forward to a probability measure on \(\mathbb{R}\).

    MathlibExt.Probability.ConvexSubGaussianComparisonWantedDavis.DavisPowerSolution.IsValid

    Let \(\varphi(t) = e^{-t^2/2}/\sqrt{2\pi}\) be the standard Gaussian density, \(Q(x) = \int_x^\infty \varphi(t)\,dt\) its upper tail, \(t_0 = \sqrt{2\log 2}\) with \(\log\) the natural logarithm, \(B = \frac{1}{2}\int_0^\infty \min(1, 2e^{-t^2/2})\,dt\) and \(h(x) = 2x e^{-x^2/2} + 2\int_x^\infty e^{-t^2/2}\,dt\).
