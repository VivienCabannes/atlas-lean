    Sub-exponential variables and Bernstein's inequality

    A real random variable is sub-exponential with parameters \((\nu, \alpha)\) when its moment generating function satisfies \(\mathbb{E}[e^{tX}] \le e^{\nu^2 t^2 / 2}\) for \(|t| < 1/\alpha\), a neighbourhood of \(0\) rather than the whole line as for sub-Gaussian variables. Such variables have a Gaussian tail for moderate deviations and an exponential tail for large ones. Bernstein's inequality is the main example: a bounded centred variable with small variance \(\sigma^2\) satisfies a tail bound of order \(e^{-t^2 / (2(\sigma^2 + bt))}\), much sharper than Hoeffding's bound when \(\sigma^2 \ll b^2\). These are the first tools of non-asymptotic high-dimensional statistics (Wainwright, High-Dimensional Statistics, 2019, Chapter 2).

    StructureSub-exponential random variable#✓fully proved

    ProbabilityTheory.HasSubexponentialMGF

    A real random variable \(X\) on a measure space \((\Omega, \mu)\) is sub-exponential with parameters \((\nu, \alpha)\), for \(\nu, \alpha \ge 0\), if for every \(t\) with \(\alpha |t| < 1\) the function \(e^{tX}\) is integrable and

    \[\mathbb{E}[e^{tX}] \le e^{\nu^2 t^2 / 2}.\]

    The condition concerns \(X\) itself, as in Mathlib's sub-Gaussian condition; the source's notion, about the mean, is the condition for \(X - \mathbb{E}[X]\). With \(\alpha = 0\) every \(t\) is allowed and the condition is the sub-Gaussian one with variance proxy \(\nu^2\).

    structure HasSubexponentialMGF (X : Ω → ℝ) (ν α : ℝ≥0) (μ : Measure Ω) : Prop where
  integrable_exp_mul : ∀ t : ℝ, α * |t| < 1 → Integrable (fun ω ↦ exp (t * X ω)) μ
  mgf_le : ∀ t : ℝ, α * |t| < 1 → mgf X μ t ≤ exp (ν ^ 2 * t ^ 2 / 2)

    ProbabilityTheory.HasSubexponentialMGF.measureReal_ge_le_exp

    Let \(\mu\) be a probability measure and \(X\) sub-exponential with parameters \((\nu, \alpha)\). For every real \(t\) and every \(s \ge 0\) with \(\alpha s \le 1\),

    \[\mu(X \ge t) \le \exp\Big(-s t + \frac{\nu^2 s^2}{2}\Big).\]

    The endpoint \(s = 1/\alpha\), where the moment generating function bound is not assumed, follows by letting \(s\) increase to \(1/\alpha\).

    lemma measureReal_ge_le_exp [IsProbabilityMeasure μ] (h : HasSubexponentialMGF X ν α μ)
    (t : ℝ) {s : ℝ} (hs : 0 ≤ s) (hαs : α * s ≤ 1) :
    μ.real {ω | t ≤ X ω} ≤ exp (-s * t + ν ^ 2 * s ^ 2 / 2)

    LemmaSums of independent sub-exponential variables#✓fully proved

    ProbabilityTheory.HasSubexponentialMGF.sum_of_iIndepFun

    Let \(X_i\), \(i \in s\), be independent measurable real random variables, each sub-exponential with parameters \((\nu_i, \alpha)\) for a common \(\alpha\). Then \(\sum_{i \in s} X_i\) is sub-exponential with parameters \(\big(\sqrt{\sum_{i \in s} \nu_i^2},\, \alpha\big)\).

    The source allows different \(\alpha_i\) and takes \(\alpha = \max_i \alpha_i\); since a variable that is sub-exponential with parameter \(\alpha_i\) is so with every larger parameter, that case reduces to this one.

    Bernstein's inequality

    LemmaExponential series bound for Bernstein's inequality#✓fully proved

    ProbabilityTheory.exp_le_one_add_add_sq_div_of_abs_lt_one

    For every real \(y\) with \(|y| < 1\),

    \[e^y \le 1 + y + \frac{y^2}{2(1 - |y|)}.\]

    It follows from \(e^y = \sum_n y^n / n!\), the bound \(n! \ge 2\) for \(n \ge 2\) and the geometric series.

    lemma exp_le_one_add_add_sq_div_of_abs_lt_one {y : ℝ} (hy : |y| < 1) :
    exp y ≤ 1 + y + y ^ 2 / (2 * (1 - |y|))

    TheoremBernstein's bound on the moment generating function of a bounded variable#✓fully proved

    ProbabilityTheory.mgf_le_of_abs_le

    Let \(\mu\) be a probability measure and \(X\) an almost everywhere measurable random variable with \(|X| \le b\) almost surely, \(\mathbb{E}[X] = 0\) and \(\mathbb{E}[X^2] \le \sigma^2\). For every \(t\) with \(b|t| < 1\),

    \[\mathbb{E}[e^{tX}] \le \exp\Big(\frac{t^2 \sigma^2}{2(1 - b|t|)}\Big).\]

    A bounded variable satisfies the Bernstein condition with parameter \(b\), so this is the bounded case of the source's proposition. In particular \(X\) is sub-exponential with parameters \((\sqrt{2}\sigma, 2b)\).

    theorem mgf_le_of_abs_le (hX : AEMeasurable X μ) {b σ t : ℝ}
    (hb : ∀ᵐ ω ∂μ, |X ω| ≤ b) (hmean : μ[X] = 0) (hvar : ∫ ω, X ω ^ 2 ∂μ ≤ σ ^ 2)
    (ht : b * |t| < 1) :
    mgf X μ t ≤ exp (t ^ 2 * σ ^ 2 / (2 * (1 - b * |t|)))

    TheoremBernstein's moment generating function bound#●ready to prove

    MathlibExt.Probability.HighDimensionalStatisticsWanted.mgf_le_of_bernsteinCondition

    Let \(\mu\) be a probability measure and \(X\) a centred random variable with all moments finite and \(\mathbb{E}[X^2] = \sigma^2\), satisfying the Bernstein condition with parameter \(b \ge 0\):

    \[\big|\mathbb{E}[X^k]\big| \le \tfrac12\, k!\, \sigma^2 b^{k-2} \quad \text{for } k = 3, 4, \dots\]

    Then for every \(t\) with \(b|t| < 1\) the function \(e^{tX}\) is integrable and \(\mathbb{E}[e^{tX}] \le \exp\big(t^2\sigma^2 / (2(1 - b|t|))\big)\).

    The proof expands the exponential in series and integrates termwise; the bounded case is proved in this library.

    public theorem_wanted mgf_le_of_bernsteinCondition {Ω : Type*} {mΩ : MeasurableSpace Ω}

    TheoremConcentration of Lipschitz functions of Gaussian variables#●ready to prove

    MathlibExt.Probability.HighDimensionalStatisticsWanted.lipschitz_concentration_stdGaussian

    Let \(X\) be a standard Gaussian vector in \(\mathbb{R}^n\) and \(f : \mathbb{R}^n \to \mathbb{R}\) be \(L\)-Lipschitz for the Euclidean norm. Then \(f(X) - \mathbb{E}[f(X)]\) is sub-Gaussian with variance proxy \(L^2\), and hence for every \(t \ge 0\)

    \[\mathbb{P}\big(|f(X) - \mathbb{E}[f(X)]| \ge t\big) \le 2 e^{-t^2/(2L^2)}.\]

    The bound does not depend on the dimension \(n\).
