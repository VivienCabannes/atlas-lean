    TheoremBonami Lemma#✓fully proved

    BooleanCube.bonami_lemma

    If \(f : \{-1, 1\}^n \to \mathbb{R}\) has degree at most \(k\) (every Fourier coefficient \(\hat f(S)\) with \(|S| > k\) vanishes), then

    \[\|f\|_4 \le \sqrt{3}^{\,k}\, \|f\|_2, \qquad\text{equivalently}\qquad \mathbb{E}[f^4] \le 9^k\, \mathbb{E}[f^2]^2.\]

    Low-degree polynomials of uniform random bits are "reasonable" random variables. The source proves the lemma by a short induction on \(n\) using \(f = x_n D_n f + E_n f\). The Lean proof instead applies the \((2,4)\)-hypercontractivity bound \(\|T_{1/\sqrt3}\, g\|_4 \le \|g\|_2\) to \(g = T_{\sqrt3} f\), for which \(T_{1/\sqrt3}\, g = f\) and \(\|g\|_2^2 = \sum_S 3^{|S|} \hat f(S)^2 \le 3^k \|f\|_2^2\). It states the fourth-power form.

    theorem bonami_lemma {n k : ℕ} (f : BoolCube n → ℝ) (hf : MultilinearDegreeLE n f k) :
    𝔼 x, f x ^ 4 ≤ 9 ^ k * (𝔼 x, f x ^ 2) ^ 2
    abbrev BoolCube (n : ℕ) : Type := Fin n → Bool

    Theorem(p,2)-hypercontractivity in noise-stability form#✓fully proved

    BooleanCube.boolNoiseStab_le_bnt_qnorm_sq

    For \(0 \le \rho \le 1\) and every \(f : \{-1, 1\}^n \to \mathbb{R}\),

    \[\mathrm{Stab}_\rho[f] \le \|f\|_{1+\rho}^2, \qquad \|f\|_q = \big(\mathbb{E}|f|^q\big)^{1/q}.\]

    This is the Bonami–Beckner inequality \(\|T_\sigma f\|_2 \le \|f\|_{1+\sigma^2}\) at \(\sigma = \sqrt\rho\), combined with \(\mathrm{Stab}_\rho[f] = \|T_{\sqrt\rho} f\|_2^2\).

    theorem boolNoiseStab_le_bnt_qnorm_sq {ρ : ℝ} (h0 : 0 ≤ ρ) (h1 : ρ ≤ 1)
    (f : BoolCube n → ℝ) :
    boolNoiseStab ρ f ≤ bnt_qnorm (1 + ρ) f ^ 2

    TheoremSmall-Set Expansion Theorem#✓fully proved

    BooleanCube.boolNoiseStab_le_rpow_of_indicator

    Let \(A \subseteq \{-1, 1\}^n\) have volume \(\alpha = \mathbb{E}[1_A]\). Then for every \(0 \le \rho \le 1\),

    \[\mathrm{Stab}_\rho[1_A] = \Pr_{(x, y)\ \rho\text{-correlated}}[x \in A,\ y \in A] \le \alpha^{2/(1+\rho)}.\]

    Equivalently, for \(\alpha > 0\), \(\Pr[y \in A \mid x \in A] \le \alpha^{(1-\rho)/(1+\rho)}\): a \(\rho\)-noisy copy of a uniform point of a small set is unlikely to stay in the set. The noisy hypercube is a small-set expander. In Lean \(1_A\) is any \(f\) with values in \(\{0, 1\}\).

    theorem boolNoiseStab_le_rpow_of_indicator {ρ : ℝ} (h0 : 0 ≤ ρ) (h1 : ρ ≤ 1)
    {f : BoolCube n → ℝ} (hf : ∀ x, f x = 0 ∨ f x = 1) :
    boolNoiseStab ρ f ≤ (𝔼 x, f x) ^ (2 / (1 + ρ))
    abbrev BoolCube (n : ℕ) : Type := Fin n → Bool

    TheoremHypercontractivity Theorem (Bonami–Beckner)#●ready to prove

    BooleanCube.hypercontractivity_theorem

    Let \(f : \{-1, 1\}^n \to \mathbb{R}\) and \(1 \le p \le q < \infty\). Then

    \[\|T_\rho f\|_q \le \|f\|_p \qquad\text{for}\quad 0 \le \rho \le \sqrt{\frac{p - 1}{q - 1}},\]

    where \(T_\rho\) is the noise operator and \(\|g\|_r = (\mathbb{E}|g|^r)^{1/r}\) under the uniform measure. The source also allows \(q = \infty\), which the Lean statement omits. The library proves the cases \(q = 2\), \(p = 1 + \rho^2\) and, by duality, \(p = 2\), \(q = 4\), \(\rho = 1/\sqrt3\).

    theorem_wanted hypercontractivity_theorem {n : ℕ} (f : BoolCube n → ℝ) {p q ρ : ℝ}

    bnt_qnorm q (boolNoiseOp ρ f) ≤ bnt_qnorm p f

    Theorem(2,4)-Hypercontractivity Theorem#✓fully proved

    BooleanCube.expect_boolNoiseOp_pow_four_le

    For every \(f : \{-1, 1\}^n \to \mathbb{R}\),

    \[\|T_{1/\sqrt3}\, f\|_4 \le \|f\|_2, \qquad\text{stated as}\qquad \mathbb{E}\big[(T_{1/\sqrt3} f)^4\big] \le \mathbb{E}[f^2]^2 .\]

    It follows from the \((4/3, 2)\) case \(\|T_{1/\sqrt3} f\|_2 \le \|f\|_{4/3}\) by duality. With \(h = T_\rho f\) and \(\rho = 1/\sqrt3\), self-adjointness of \(T_\rho\) and Cauchy–Schwarz give \(\mathbb{E}[h^4] = \mathbb{E}[f \cdot T_\rho(h^3)] \le \|f\|_2 \|T_\rho(h^3)\|_2 \le \|f\|_2 \|h^3\|_{4/3} = \|f\|_2\, \mathbb{E}[h^4]^{3/4}\).

    theorem expect_boolNoiseOp_pow_four_le (f : BoolCube n → ℝ) :
    𝔼 x, boolNoiseOp (Real.sqrt (1 / 3)) f x ^ 4 ≤ (𝔼 x, f x ^ 2) ^ 2
    abbrev BoolCube (n : ℕ) : Type := Fin n → Bool
