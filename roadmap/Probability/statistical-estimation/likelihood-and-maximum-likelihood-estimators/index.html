    ProbabilityTheory.NormalizedDensityFamily

    Let \(\Omega\) be a measurable space with a measure \(\mu\) and let \(\Theta\) be a set of parameters. A normalized density family on \(\Omega\) indexed by \(\Theta\) with dominating measure \(\mu\) consists of a function \(f_\theta : \Omega \to [0, \infty]\) for each \(\theta \in \Theta\) such that \(f_\theta\) is \(\mu\)-almost everywhere measurable and \(\int_\Omega f_\theta \, d\mu = 1\).

    Taking \(\mu\) to be counting measure gives probability mass functions, and taking \(\mu\) to be volume gives probability density functions. The densities may take the value \(\infty\).

    structure NormalizedDensityFamily (Ω : Type*) (Θ : Type*) [MeasurableSpace Ω]
    (μ : Measure Ω) where
  dens : Θ → Ω → ℝ≥0∞
  measurable : ∀ θ, AEMeasurable (dens θ) μ
  normalized : ∀ θ, ∫⁻ x, dens θ x ∂μ = 1
      dens : Θ → Ω → ℝ≥0∞

    TheoremNormalized density families are determined by their densities#✓fully proved

    ProbabilityTheory.NormalizedDensityFamily.ext

    Let \(F\) and \(G\) be normalized density families on a measurable space \(\Omega\) with the same parameter set \(\Theta\) and the same dominating measure \(\mu\). If for every \(\theta \in \Theta\) and every \(x \in \Omega\) the density of \(F\) at \(\theta\) and the density of \(G\) at \(\theta\) take the same value at \(x\), then \(F = G\).

    Only the densities are compared; the measurability and normalization conditions are propositions.

    ProbabilityTheory.NormalizedDensityFamily.law

    Let \(F\) be a normalized density family on a measurable space \(\Omega\) with parameter set \(\Theta\), dominating measure \(\mu\) and densities \(f_\theta\). The population law at \(\theta \in \Theta\) is the measure \(P_\theta\) on \(\Omega\) with density \(f_\theta\) with respect to \(\mu\), so that \(P_\theta(A) = \int_A f_\theta \, d\mu\) for every measurable set \(A \subseteq \Omega\).

    DefinitionLikelihood of an iid sample#✓fully proved

    ProbabilityTheory.NormalizedDensityFamily.iidLikelihood

    Let \(F\) be a normalized density family on \(\Omega\) with parameter set \(\Theta\) and densities \(f_\theta\) for \(\theta \in \Theta\). For a sample size \(n\), a parameter \(\theta \in \Theta\) and a sample \(x = (x_0, \dots, x_{n-1}) \in \Omega^n\), the iid likelihood of \(\theta\) at \(x\) is \(L_n(\theta; x) = \prod_{i < n} f_\theta(x_i)\), a value in \([0, \infty]\). For \(n = 0\) this is the empty product \(1\).

    noncomputable def iidLikelihood (F : NormalizedDensityFamily Ω Θ μ) (n : ℕ)
    (θ : Θ) (x : Fin n → Ω) : ℝ≥0∞ :=
  ∏ i, F.dens θ (x i)

    DefinitionMaximum likelihood estimator#✓fully proved

    ProbabilityTheory.NormalizedDensityFamily.IsMaximumLikelihoodEstimator

    Let \(F\) be a normalized density family on \(\Omega\) with parameter set \(\Theta\), let \(n\) be a sample size, and let \(L_n(\theta; x)\) denote the iid likelihood of \(\theta \in \Theta\) at a sample \(x \in \Omega^n\). A map \(\hat\theta\) from \(\Omega^n\) to \(\Theta\) is a maximum likelihood estimator for samples of size \(n\) if for every sample \(x \in \Omega^n\) the parameter \(\hat\theta(x)\) maximizes \(\theta \mapsto L_n(\theta; x)\) over all of \(\Theta\).

    TheoremCharacterization of maximum likelihood estimators#✓fully proved

    ProbabilityTheory.NormalizedDensityFamily.isMaximumLikelihoodEstimator_iff

    Let \(F\) be a normalized density family on \(\Omega\) with parameter set \(\Theta\), let \(n\) be a sample size, let \(L_n(\theta; x)\) denote the iid likelihood of \(\theta \in \Theta\) at a sample \(x \in \Omega^n\), and let \(\hat\theta\) be a map from \(\Omega^n\) to \(\Theta\). Then \(\hat\theta\) is a maximum likelihood estimator for samples of size \(n\) if and only if \(L_n(\theta; x) \le L_n(\hat\theta(x); x)\) for every sample \(x \in \Omega^n\) and every \(\theta \in \Theta\).

    theorem isMaximumLikelihoodEstimator_iff (F : NormalizedDensityFamily Ω Θ μ)
    (n : ℕ) (θhat : (Fin n → Ω) → Θ) :
    F.IsMaximumLikelihoodEstimator n θhat ↔
      ∀ x θ, F.iidLikelihood n θ x ≤ F.iidLikelihood n (θhat x) x

    DefinitionInduced likelihood#✓fully proved

    ProbabilityTheory.NormalizedDensityFamily.inducedLikelihood

    Let \(F\) be a normalized density family on \(\Omega\) with parameter set \(\Theta\), let \(n\) be a sample size, let \(\tau : \Theta \to H\) be a map into a set \(H\), and let \(x \in \Omega^n\) be a sample. For \(\eta\) in the image of \(\tau\), the induced likelihood of \(\eta\) at \(x\) is the supremum, in \([0, \infty]\), of the iid likelihood \(L_n(\theta; x)\) over the fiber of \(\tau\) above \(\eta\):

    \[L^*_n(\eta; x) = \sup_{\theta \in \Theta,\ \tau(\theta) = \eta} L_n(\theta; x).\]

    Since \(\eta\) lies in the image of \(\tau\), the fiber is nonempty; no inverse of \(\tau\) is chosen.

    noncomputable def inducedLikelihood (F : NormalizedDensityFamily Ω Θ μ)
    (n : ℕ) {H : Type*} (τ : Θ → H) (x : Fin n → Ω)
    (η : Set.range τ) : ℝ≥0∞ :=
  ⨆ θ : { θ : Θ // τ θ = η.val }, F.iidLikelihood n θ.val x
