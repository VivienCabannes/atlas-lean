    Stein's lemma and James–Stein estimation

    For \(X \sim \mathcal N(\mu, \sigma^2)\), Gaussian integration by parts gives Stein's identity \(\mathbb E[(X - \mu) g(X)] = \sigma^2\, \mathbb E[g'(X)]\). Applied coordinatewise to \(X \sim \mathcal N_p(\theta, I)\) it yields Stein's unbiased risk estimate (SURE) for any estimator \(X + g(X)\), and SURE applied to \(g(x) = -(p - 2) x / \|x\|^2\) gives the risk of the James–Stein estimator, \(p - (p - 2)^2\, \mathbb E\|X\|^{-2}\), strictly below the risk \(p\) of \(X\) when \(p \ge 3\). Shrinking towards the grand mean instead of \(0\) costs one dimension: that estimator dominates \(X\) when \(N \ge 4\) (Efron 2021, Theorem 1, which credits James and Stein 1961). Efron and Morris read the James–Stein estimator as an empirical Bayes rule: under the prior \(\theta_i \sim \mathcal N(0, A)\) the Bayes rule shrinks \(X\) by \(1 - 1/V\) with \(V = A + 1\), and \((p - 2)/\|X\|^2\) is an unbiased estimate of \(1/V\).

    TheoremStein's lemma#✓fully proved

    ProbabilityTheory.integrable_and_integral_sub_mul_gaussianReal

    Let \(X \sim \mathcal N(\mu, v)\) and let \(g : \mathbb R \to \mathbb R\) be differentiable at every point, with derivative \(g'\) such that \(g'(X)\) is integrable. Then \((X - \mu)\, g(X)\) is integrable and $\(\mathbb E[(X - \mu)\, g(X)] = v\, \mathbb E[g'(X)] .\)$ For \(v = 0\) both sides vanish. This is Gaussian integration by parts: \(\varphi_v'(t) = -\frac{t}{v} \varphi_v(t)\) for the \(\mathcal N(0, v)\) density. Johnstone's draft writes the identity for \(\mathcal N(0, 1)\) in Section 2.6, just before equation (2.58), and states it under weak differentiability (absolute continuity); the Lean statement asks for differentiability everywhere, which covers \(C^1\) functions but not, for example, \(g(x) = |x|\). Integrability of \((X - \mu) g(X)\) is part of the conclusion, not a hypothesis.

    theorem integrable_and_integral_sub_mul_gaussianReal (μ : ℝ) (v : NNReal) {g g' : ℝ → ℝ}
    (hg : ∀ x, HasDerivAt g (g' x) x) (hg' : Integrable g' (gaussianReal μ v)) :
    Integrable (fun x => (x - μ) * g x) (gaussianReal μ v) ∧
      ∫ x, (x - μ) * g x ∂gaussianReal μ v = v * ∫ x, g' x ∂gaussianReal μ v

    TheoremStein's lemma, coordinate form#✓fully proved

    ProbabilityTheory.integral_sub_mul_pi_gaussianReal

    Let \(X \sim \mathcal N_p(\theta, I)\), fix a coordinate \(i\), and let \(h : \mathbb R^p \to \mathbb R\) be such that, for almost every base point, its restriction to the line parallel to the \(i\)-th axis is differentiable everywhere, with partial derivative \(\partial_i h\) integrable. If \((X_i - \theta_i)\, h(X)\) is integrable, then $\(\mathbb E[(X_i - \theta_i)\, h(X)] = \mathbb E[\partial_i h(X)] .\)$ This is Johnstone's draft, equation (2.58) (there for \(\theta = 0\)). Unlike the one-dimensional case, integrability of \((X_i - \theta_i) h(X)\) must be assumed: \(h(x) = \exp(x_1^2)\) has \(\partial_0 h = 0\) but \(x_0 h(x)\) is not integrable.

    theorem integral_sub_mul_pi_gaussianReal {p : ℕ} (θ : Fin p → ℝ) (i : Fin p)
    {h dh : (Fin p → ℝ) → ℝ}
    (hd : ∀ᵐ x ∂(Measure.pi fun j => gaussianReal (θ j) 1),
      ∀ t, HasDerivAt (fun s => h (Function.update x i s)) (dh (Function.update x i t)) t)
    (hdi : Integrable dh (Measure.pi fun j => gaussianReal (θ j) 1))
    (hhi : Integrable (fun x => (x i - θ i) * h x) (Measure.pi fun j => gaussianReal (θ j) 1)) :
    ∫ x, (x i - θ i) * h x ∂(Measure.pi fun j => gaussianReal (θ j) 1) =
      ∫ x, dh x ∂(Measure.pi fun j => gaussianReal (θ j) 1)

    TheoremStein's unbiased risk estimate#✓fully proved

    ProbabilityTheory.integral_sum_sq_add_sub_pi_gaussianReal

    Let \(X \sim \mathcal N_p(\theta, I)\) and consider the estimator \(X + g(X)\), where each coordinate \(g_i\) is square integrable and satisfies the hypotheses of Stein's lemma, coordinate form in the \(i\)-th coordinate, with partial derivative \(\partial_i g_i\). Then $\(\mathbb E \sum_i \bigl(X_i + g_i(X) - \theta_i\bigr)^2 = p + \mathbb E\Bigl[\sum_i g_i(X)^2 + 2 \sum_i \partial_i g_i(X)\Bigr],\)$ so \(U(x) = p + 2 \nabla \cdot g(x) + \|g(x)\|^2\) is an unbiased estimate of the risk. This is Johnstone's draft, Proposition 2.7, equation (2.61), which credits Stein (1981). Johnstone assumes weak differentiability and \(\mathbb E|X_i g_i(X)| + \mathbb E|\partial_i g_i(X)| < \infty\); the Lean statement assumes everywhere-differentiable slices and square-integrable \(g_i\) (which makes the risk finite).

    theorem integral_sum_sq_add_sub_pi_gaussianReal {p : ℕ} (θ : Fin p → ℝ)
    {g dg : Fin p → (Fin p → ℝ) → ℝ}
    (hd : ∀ i, ∀ᵐ x ∂(Measure.pi fun j => gaussianReal (θ j) 1),
      ∀ t, HasDerivAt (fun s => g i (Function.update x i s)) (dg i (Function.update x i t)) t)
    (hdi : ∀ i, Integrable (dg i) (Measure.pi fun j => gaussianReal (θ j) 1))
    (hg2 : ∀ i, MemLp (g i) 2 (Measure.pi fun j => gaussianReal (θ j) 1)) :
    ∫ x, ∑ i, (x i + g i x - θ i) ^ 2 ∂(Measure.pi fun j => gaussianReal (θ j) 1) =
      p + ∫ x, ∑ i, (g i x ^ 2 + 2 * dg i x) ∂(Measure.pi fun j => gaussianReal (θ j) 1)

    DefinitionJames–Stein estimator#✓fully proved

    ProbabilityTheory.jamesStein

    The James–Stein estimator of the mean of \(\mathcal N_p(\theta, I)\) is $\(\delta(x) = \Bigl(1 - \frac{p - 2}{\|x\|^2}\Bigr) x,\)$ Johnstone's draft, equation (2.63). At \(x = 0\) Lean's convention \(a / 0 = 0\) makes the factor \(1\), so \(\delta(0) = 0\); this point has probability zero. Efron (2021), Theorem 1, which Efron credits to James and Stein (1961), states the variant that shrinks towards the grand mean \(\bar x\) with factor \(1 - (N - 3)\sigma_0^2/S\): see the grand-mean estimator.

    noncomputable def jamesStein {p : ℕ} (x : Fin p → ℝ) : Fin p → ℝ :=
  fun i => (1 - ((p : ℝ) - 2) / ∑ j, x j ^ 2) * x i

    TheoremRisk of the James–Stein estimator#✓fully proved

    ProbabilityTheory.integrable_and_integral_jamesStein_risk

    For \(p \ge 3\) and \(X \sim \mathcal N_p(\theta, I)\), \(\|X\|^{-2}\) is integrable and the James–Stein estimator has quadratic risk $\(\mathbb E\, \|\delta(X) - \theta\|^2 = p - (p - 2)^2\, \mathbb E\, \|X\|^{-2}\)$ for every \(\theta\). This is Johnstone's draft, equation (2.64). The condition \(p \ge 3\) is what makes \(\mathbb E \|X\|^{-2}\) finite (Johnstone, equation (2.67)); for \(p \le 2\) it is infinite for every \(\theta\).

    theorem integrable_and_integral_jamesStein_risk {p : ℕ} (hp : 3 ≤ p) (θ : Fin p → ℝ) :
    Integrable (fun x : Fin p → ℝ => (∑ j, x j ^ 2)⁻¹)
        (Measure.pi fun j => gaussianReal (θ j) 1) ∧
      ∫ x, ∑ i, (jamesStein x i - θ i) ^ 2 ∂(Measure.pi fun j => gaussianReal (θ j) 1) =
        p - ((p : ℝ) - 2) ^ 2 *
          ∫ x, (∑ j, x j ^ 2)⁻¹ ∂(Measure.pi fun j => gaussianReal (θ j) 1)
    noncomputable def jamesStein {p : ℕ} (x : Fin p → ℝ) : Fin p → ℝ :=

    TheoremJames–Stein dominance#✓fully proved

    ProbabilityTheory.integral_jamesStein_risk_lt

    For \(p \ge 3\) the James–Stein estimator has strictly smaller quadratic risk than \(X\) at every mean: \(\mathbb E \|\delta(X) - \theta\|^2 < p\) for all \(\theta \in \mathbb R^p\), so \(X\) is inadmissible under squared error loss. Johnstone's draft derives this from equation (2.64). Efron (2021), Theorem 1, which Efron credits to James and Stein (1961), states the same conclusion for the variant that shrinks towards the grand mean, with \(N \ge 4\); this page is the shrink-towards-zero version with \(p \ge 3\), and grand-mean dominance is the grand-mean version.

    theorem integral_jamesStein_risk_lt {p : ℕ} (hp : 3 ≤ p) (θ : Fin p → ℝ) :
    ∫ x, ∑ i, (jamesStein x i - θ i) ^ 2 ∂(Measure.pi fun j => gaussianReal (θ j) 1) <
      ∫ x, ∑ i, (x i - θ i) ^ 2 ∂(Measure.pi fun j => gaussianReal (θ j) 1)

    TheoremThe James–Stein shrinkage factor estimates \(1/V\) without bias#✓fully proved

    ProbabilityTheory.integral_jamesStein_factor_pi_gaussianReal

    If \(z \sim \mathcal N_p(0, V I)\) with \(V > 0\) and \(p \ge 3\), then $\(\mathbb E\, \frac{p - 2}{\|z\|^2} = \frac{1}{V} .\)$ In the normal–normal model \(\mu_i \sim \mathcal N(0, A)\), \(z_i \mid \mu_i \sim \mathcal N(\mu_i, 1)\), independently for \(i = 1, \dots, p\), the marginal law of \(z\) is \(\mathcal N_p(0, V I)\) with \(V = A + 1\), and the Bayes rule is \((1 - 1/V) z_i\) (posterior mean in the normal–normal model). Substituting this unbiased estimate of \(1/V\) gives the James–Stein estimator. This is Efron and Morris's empirical Bayes reading of the James–Stein rule, as stated in Efron (2011), equations (3.7)–(3.9), with \(N = p\). The Lean statement covers the unbiasedness; the marginal law of \(z\) under the normal–normal model is not restated here.

    theorem integral_jamesStein_factor_pi_gaussianReal {p : ℕ} (hp : 3 ≤ p) {V : NNReal}
    (hV : V ≠ 0) :
    ∫ x, ((p : ℝ) - 2) / ∑ j, x j ^ 2 ∂(Measure.pi fun _ : Fin p => gaussianReal 0 V) =
      1 / (V : ℝ)

    Shrinkage towards the grand mean and the positive-part estimator

    DefinitionJames–Stein estimator shrinking towards the grand mean#✓fully proved

    ProbabilityTheory.jamesSteinGrandMean

    For \(x \in \mathbb R^N\) and a known noise variance \(\sigma^2\), let \(\bar x = \frac1N \sum_j x_j\) and \(S = \sum_j (x_j - \bar x)^2\). The James–Stein estimator that shrinks towards the grand mean is $\(\hat\theta_i = \bar x + \Bigl(1 - \frac{(N - 3)\sigma^2}{S}\Bigr)(x_i - \bar x),\)$ Efron (2021), equation (3.4), with \(\sigma_0^2 = \sigma^2\). When all coordinates are equal, \(S = 0\) and Lean's convention \(a / 0 = 0\) makes the estimate \(x\); this event has probability zero under a Gaussian law. Efron reads it as the empirical Bayes rule for the prior \(\theta_i \sim \mathcal N(M, A)\) with \(M\) and \(A\) unknown, estimated by \(\hat M = \bar x\) and \(\hat B = 1 - (N - 3)\sigma_0^2 / S\) (equations (3.9)–(3.14)).

    noncomputable def jamesSteinGrandMean {N : ℕ} (σ2 : ℝ) (x : Fin N → ℝ) : Fin N → ℝ :=
  fun i => (∑ j, x j) / N +
    (1 - ((N : ℝ) - 3) * σ2 / ∑ j, (x j - (∑ k, x k) / N) ^ 2) * (x i - (∑ j, x j) / N)

    TheoremJames–Stein shrinkage towards the grand mean dominates the MLE#✓fully proved

    ProbabilityTheory.integral_jamesSteinGrandMean_risk_lt

    Let \(N \ge 4\), \(\sigma^2 > 0\) and \(X \sim \mathcal N(\theta, \sigma^2 I_N)\). Then the grand-mean James–Stein estimator has finite quadratic risk and $\(\mathbb E \sum_{i=1}^N (\hat\theta_i - \theta_i)^2 < N \sigma^2 \qquad \text{for every } \theta \in \mathbb R^N,\)$ while the estimator \(X\) has risk \(N\sigma^2\) (formalized here only for \(\sigma^2 = 1\), as the quadratic risk of the usual estimator). The Lean statement asserts the integrability of the loss together with the inequality, so the inequality is not satisfied vacuously by an infinite risk. This is Efron (2021), Theorem 1, equations (3.4)–(3.5), stated with the hypotheses given there; Efron credits the theorem to James and Stein (1961).

    The proof is the argument used for shrinkage towards \(0\). First, for \(\sigma^2 = 1\), Stein's unbiased risk estimate is applied to \(g(x) = -(N - 3)(x - \bar x \mathbf 1)/S\), whose divergence is \(-(N - 3)^2/S\), giving the risk \(N - (N - 3)^2\, \mathbb E[1/S]\). Second, \(\mathbb E[1/S] < \infty\): \(S\) is at least \(1/(N+1)\) times \(\sum_j (x_j - x_N)^2\), and conditionally on \(x_N\) the other \(N - 1 \ge 3\) coordinates form a Gaussian vector, whose inverse squared distance to \(x_N \mathbf 1\) has an expectation bounded independently of its mean. Third, the general \(\sigma^2\) follows by scaling. The risk formula and the integrability are auxiliary lemmas without pages.

    theorem integral_jamesSteinGrandMean_risk_lt {N : ℕ} (hN : 4 ≤ N) {σ2 : NNReal}
    (hσ : σ2 ≠ 0) (θ : Fin N → ℝ) :
    Integrable (fun x => ∑ i, (jamesSteinGrandMean σ2 x i - θ i) ^ 2)
        (Measure.pi fun j => gaussianReal (θ j) σ2) ∧
      ∫ x, ∑ i, (jamesSteinGrandMean σ2 x i - θ i) ^ 2
        ∂(Measure.pi fun j => gaussianReal (θ j) σ2) < N * σ2
    noncomputable def jamesSteinGrandMean {N : ℕ} (σ2 : ℝ) (x : Fin N → ℝ) : Fin N → ℝ :=
  fun i => (∑ j, x j) / N +
    (1 - ((N : ℝ) - 3) * σ2 / ∑ j, (x j - (∑ k, x k) / N) ^ 2) * (x i - (∑ j, x j) / N)

    DefinitionPositive-part James–Stein estimator#✓fully proved

    ProbabilityTheory.jamesSteinPlus

    The positive-part James–Stein estimator of the mean of \(\mathcal N_p(\theta, I)\) is $\(\delta^+(x) = \max\Bigl(0,\ 1 - \frac{p - 2}{\|x\|^2}\Bigr) x,\)$ Johnstone's draft, equation (2.65): the James–Stein estimator with its shrinkage factor truncated at \(0\), so that it never reverses the sign of a coordinate. At \(x = 0\) Lean's convention \(a / 0 = 0\) gives \(\delta^+(0) = 0\).

    noncomputable def jamesSteinPlus {p : ℕ} (x : Fin p → ℝ) : Fin p → ℝ :=
  fun i => max 0 (1 - ((p : ℝ) - 2) / ∑ j, x j ^ 2) * x i

    For \(p \ge 3\) and \(X \sim \mathcal N_p(\theta, I)\), the loss \(\|\delta^+(X) - \theta\|^2\) is integrable and $\(\mathbb E\, \|\delta^+(X) - \theta\|^2 \le \mathbb E\, \|\delta(X) - \theta\|^2 \qquad \text{for every } \theta,\)$ where \(\delta^+\) is the positive-part estimator and \(\delta\) the James–Stein estimator. Johnstone's draft states after equation (2.65) that \(\delta^+\) "has necessarily even better MSE" than \(\delta\), leaving the proof as Exercise 2.12; the statement here is the non-strict form. The classical form of the result is a strict inequality; it is not stated here because the source consulted says only "even better". The integrability conjunct (true because \(|\delta^+_i(x)| \le |x_i|\)) keeps the inequality from holding vacuously. Combined with James–Stein dominance it would show that \(\delta^+\) also dominates \(X\).
