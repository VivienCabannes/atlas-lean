    Sufficient statistics and the factorization theorem

    DefinitionSufficient sub-σ-algebra#✓fully proved

    MathlibExt.Probability.Statistics.Sufficiency.IsSufficient

    A sub-σ-algebra m is sufficient for the family of measures P on (Ω, m₀) if m ≤ m₀, every P θ is finite, and for every m₀-measurable set s one m-measurable function is a version of the conditional probability P_θ[1_s | m] under every P θ. Bundling m ≤ m₀ and finiteness into the predicate means an IsSufficient hypothesis itself represents a sufficient sub-σ-algebra for statistical laws: the conditional expectations it mentions are genuine, not Mathlib's totalized fallback on unrelated σ-algebras or infinite measures.

    def IsSufficient (m : MeasurableSpace Ω) {m₀ : MeasurableSpace Ω}
    (P : Θ → Measure[m₀] Ω) : Prop :=
  m ≤ m₀ ∧ (∀ θ, IsFiniteMeasure (P θ)) ∧
    ∀ s, MeasurableSet[m₀] s → ∃ f : Ω → ℝ, StronglyMeasurable[m] f ∧
      ∀ θ, f =ᵐ[P θ] (P θ)[s.indicator (fun _ => (1 : ℝ)) | m]

    TheoremFactorization criterion, sufficiency direction, for a statistic, under an extra σ-finiteness hypothesis#✓fully proved

    MathlibExt.Probability.Statistics.Sufficiency.isSufficient_comap_of_factorization_of_sigmaFinite_trim

    Factorization criterion, sufficiency direction, for a statistic, under an extra σ-finiteness hypothesis. If dP_θ/dμ = g_θ(T) · h with g_θ and h measurable and h · μ σ-finite on the σ-algebra generated by T, then T is sufficient for P.

    The σ-finiteness hypothesis on (μ.withDensity h).trim (comap T) is an extra, nonstandard assumption, named in the theorem: it is strictly stronger than μ being σ-finite, since restriction to a sub-σ-algebra need not preserve σ-finiteness, and it can fail even when μ is σ-finite and h is a density. This theorem is therefore the factorization criterion under that extra hypothesis, not the classical criterion as stated. Removing the hypothesis would require a different proof.

    theorem isSufficient_comap_of_factorization_of_sigmaFinite_trim {τ : Type*} [MeasurableSpace τ]

    (hg : ∀ θ, Measurable (g θ)) (h : Ω → ℝ≥0∞) (hh : Measurable h)

    DefinitionSufficient statistic for a discrete family#✓fully proved

    MathlibExt.Probability.Statistics.Sufficiency.IsSufficientPMF

    A statistic T : X → τ is sufficient for the discrete family P : Θ → PMF X if the conditional probability P θ x / P_θ(T = T x) of x given T = T x is the same under any two parameters θ, θ' for which {T = T x} has positive probability. Here P_θ(T = t) = (P θ).map T t.

    def IsSufficientPMF (P : Θ → PMF X) (T : X → τ) : Prop :=
  ∀ θ θ' x, (P θ).map T (T x) ≠ 0 → (P θ').map T (T x) ≠ 0 →
    P θ x / (P θ).map T (T x) = P θ' x / (P θ').map T (T x)

    MathlibExt.Probability.Statistics.Sufficiency.IsSufficientPMF.factorization

    If T is sufficient for P, then P θ x = g θ (T x) * h x with g θ t = P_θ(T = t) and a parameter-free h with values in [0, 1].

    TheoremThe Fisher–Neyman factorization theorem#✓fully proved

    MathlibExt.Probability.Statistics.Sufficiency.isSufficientPMF_iff_exists_factorization

    The Fisher–Neyman factorization theorem (discrete case). A statistic T is sufficient for the family of mass functions P if and only if there are nonnegative functions g and h, with h free of the parameter, such that P θ x = g θ (T x) * h x for every θ, x.

    theorem isSufficientPMF_iff_exists_factorization (P : Θ → PMF X) (T : X → τ) :
    IsSufficientPMF P T ↔ ∃ (g : Θ → τ → ℝ≥0) (h : X → ℝ≥0),
      ∀ θ x, P θ x = ((g θ (T x) * h x : ℝ≥0) : ℝ≥0∞)
