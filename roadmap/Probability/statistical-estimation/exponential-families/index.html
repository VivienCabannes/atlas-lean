    Exponential families

    An exponential family with sufficient statistic \(\phi\) is the family of densities \(p_\theta(x) = \exp(\langle\theta, \phi(x)\rangle - A(\theta))\) with respect to a base measure, indexed by the canonical parameter \(\theta\); the log-partition (cumulant) function \(A(\theta) = \log\int \exp\langle\theta, \phi(x)\rangle\,\nu(dx)\) is convex, its gradient is the mean parameter \(\mu = \mathbb E_\theta[\phi(X)]\) and its Hessian the covariance of \(\phi(X)\). Its convex conjugate is the negative entropy, which gives the variational representation \(A(\theta) = \sup_\mu\{\langle\theta, \mu\rangle - A^*(\mu)\}\) (Wainwright and Jordan). Exact and approximate inference in graphical models (mean field, belief propagation) are relaxations of this variational problem; maximum likelihood is moment matching, \(\nabla A(\hat\theta) = \frac1n\sum_i \phi(x_i)\). The pages below treat a finite sample space with the counting measure.

    DefinitionLog-partition (cumulant) function of a finite exponential family#✓fully proved

    MathlibExt.Probability.FiniteExponentialFamily.logPartition

    Let \(X\) be a finite set, \(E\) a real inner product space and \(\phi : X \to E\) a sufficient statistic. The log-partition, or cumulant, function is

    \[ A(\theta) = \log \sum_{x \in X} \exp\langle\phi(x), \theta\rangle = \log Z(\theta), \qquad \theta \in E . \]

    This is (3.40) of Wainwright and Jordan with the counting measure as base measure; on a finite set \(A\) is finite everywhere, so the family is regular with domain \(\Omega = E\). When \(X\) is empty the sum is \(0\) and the Lean definition returns \(\log 0 = 0\); the results below assume \(X\) nonempty.

    noncomputable def logPartition (φ : X → E) (θ : E) : ℝ := log (partitionSum φ θ)
    noncomputable def partitionSum (φ : X → E) (θ : E) : ℝ := ∑ x, exp (inner ℝ (φ x) θ)

    TheoremThe gradient of the log-partition function is the mean parameter#✓fully proved

    MathlibExt.Probability.FiniteExponentialFamily.hasGradientAt_logPartition

    Let \(X\) be a finite set, \(E\) a real inner product space and \(\phi : X \to E\) a sufficient statistic. If \(X\) is nonempty and \(E\) is complete, then \(A\) is differentiable at every \(\theta \in E\) with gradient

    \[ \nabla A(\theta) = \mathbb E_\theta[\phi(X)] = \sum_{x \in X} p_\theta(x)\,\phi(x) . \]

    So the forward map from canonical to mean parameters is \(\theta \mapsto \nabla A(\theta)\), and maximum likelihood in the family is moment matching.

    theorem hasGradientAt_logPartition [Nonempty X] [CompleteSpace E] (φ : X → E) (θ : E) :
    HasGradientAt (logPartition φ) (meanParameter φ θ) θ
    noncomputable def logPartition (φ : X → E) (θ : E) : ℝ := log (partitionSum φ θ)

    TheoremGibbs variational principle, upper bound#✓fully proved

    MathlibExt.Probability.FiniteExponentialFamily.sum_mul_inner_sub_log_le

    Let \(X\) be a finite set, \(E\) a real inner product space and \(\phi : X \to E\) a sufficient statistic. For every \(\theta \in E\) and every probability distribution \(q\) on \(X\) (\(q \ge 0\), \(\sum_x q(x) = 1\)),

    \[ \sum_{x \in X} q(x)\bigl(\langle\phi(x), \theta\rangle - \log q(x)\bigr) = \Bigl\langle \mathbb E_q[\phi(X)], \theta\Bigr\rangle + H(q) \le A(\theta), \]

    with \(H(q) = -\sum_x q(x)\log q(x)\) the Shannon entropy (terms with \(q(x) = 0\) vanish, as \(0 \log 0 = 0\)).

    It is a special case of the Gibbs variational principle \(\log\int e^f\,d\nu = \max_\mu\{\int f\,d\mu - \mathrm{KL}(\mu\|\nu)\}\) for a probability measure \(\nu\) and bounded \(f\): take \(\nu\) uniform on \(X\) and \(f = \langle\phi(\cdot), \theta\rangle\), so that \(\log\int e^f\,d\nu = A(\theta) - \log|X|\) and \(\mathrm{KL}(q\|\nu) = \log|X| - H(q)\). The version here works with real finite sums and the counting measure.

    This is the finite form of the variational representation (3.45), \(A(\theta) = \sup_{\mu}\{\langle\theta, \mu\rangle - A^*(\mu)\}\), before the inner optimization: for \(q\) with mean \(\mu\), \(H(q) \le -A^*(\mu)\), since \(-A^*(\mu)\) is the maximum entropy among distributions with mean \(\mu\) (the discussion following Theorem 3.4). The left side is also the evidence lower bound of \(q\) for the unnormalized weights \(\exp\langle\phi(x), \theta\rangle\).

    theorem sum_mul_inner_sub_log_le (φ : X → E) (θ : E) {q : X → ℝ} (hq0 : ∀ x, 0 ≤ q x)
    (hq1 : ∑ x, q x = 1) :
    ∑ x, q x * (inner ℝ (φ x) θ - log (q x)) ≤ logPartition φ θ
    noncomputable def logPartition (φ : X → E) (θ : E) : ℝ := log (partitionSum φ θ)

    MathlibExt.Probability.FiniteExponentialFamily.sum_density_mul_inner_sub_log

    Let \(X\) be a finite set, \(E\) a real inner product space and \(\phi : X \to E\) a sufficient statistic. If \(X\) is nonempty then for every \(\theta \in E\)

    \[ \sum_{x \in X} p_\theta(x)\bigl(\langle\phi(x), \theta\rangle - \log p_\theta(x)\bigr) = A(\theta), \]

    that is \(A(\theta) = \langle\mathbb E_\theta[\phi(X)], \theta\rangle + H(p_\theta)\): the bound of the upper-bound half is attained at \(q = p_\theta\), so \(A(\theta) = \max_q\{\langle\mathbb E_q[\phi], \theta\rangle + H(q)\}\).

    theorem sum_density_mul_inner_sub_log [Nonempty X] (φ : X → E) (θ : E) :
    ∑ x, density φ θ x * (inner ℝ (φ x) θ - log (density φ θ x)) = logPartition φ θ
    noncomputable def density (φ : X → E) (θ : E) (x : X) : ℝ :=
  exp (inner ℝ (φ x) θ) / partitionSum φ θ

    TheoremThe log-partition function is convex#✓fully proved

    MathlibExt.Probability.FiniteExponentialFamily.convexOn_logPartition

    Let \(X\) be a finite set, \(E\) a real inner product space and \(\phi : X \to E\) a sufficient statistic. If \(X\) is nonempty then \(A\) is convex on \(E\).

    Wainwright and Jordan prove this from the Hessian, the covariance matrix of \(\phi(X)\). Here it follows from the Gibbs variational principle: \(A\) is the pointwise maximum over distributions \(q\) of the affine functions \(\theta \mapsto \langle\mathbb E_q[\phi], \theta\rangle + H(q)\). Strict convexity for minimal representations is not formalized.

    theorem convexOn_logPartition [Nonempty X] (φ : X → E) :
    ConvexOn ℝ Set.univ (logPartition φ)
    noncomputable def logPartition (φ : X → E) (θ : E) : ℝ := log (partitionSum φ θ)

    Related topics

    • Mean-field variational inference: the ELBO is the Gibbs variational objective restricted to a tractable family of distributions \(q\).
    • Variable elimination and belief propagation: exact computation of marginals, that is of mean parameters, in tree-structured exponential families.
    • Likelihood and maximum likelihood estimators: in an exponential family the likelihood equation is the moment-matching condition \(\nabla A(\theta) = \bar\phi\).
    • Donsker–Varadhan variational formula: the Gibbs variational principle over general measures; the finite variational principle here is its case with a uniform base measure.
    • Natural policy gradient: its softmax policies are exponential families with indicator statistics, and its log-partition function and first-order convexity inequality are per-state instances of the results here.
