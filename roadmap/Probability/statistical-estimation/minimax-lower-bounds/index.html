    Minimax lower bounds

    Lower bounds on the minimax risk \(\inf_{\hat\theta} \sup_\theta \mathbb{E}_\theta\, \ell(\theta, \hat\theta)\), the infimum running over randomised estimators, obtained by reducing estimation to testing. Le Cam's two-point method bounds the risk below by \(\ell(\theta_0, \theta_1)(1 - \mathrm{TV}(P_{\theta_0}, P_{\theta_1}))/(2\alpha)\) for a loss with the \(\alpha\)-triangle inequality, and Pinsker's inequality turns the total variation into a Kullback–Leibler divergence, which tensorizes over i.i.d. samples. Assouad's lemma sums such bounds over the coordinates of a hypercube of parameters.

    TheoremAssouad's lemma#✓fully proved

    MathlibExt.Probability.Statistics.Assouad.mul_one_sub_le_minimax

    Let \(P\) be a statistical model, a Markov kernel from a measurable parameter space \(\Theta\) to a sample space \(\Omega\), and \(\ell : \Theta \times \Theta \to [0, \infty]\) a loss, measurable in its second argument, satisfying the \(\alpha\)-triangle inequality \(\ell(\theta_0, \theta_1) \le \alpha (\ell(\theta_0, t) + \ell(\theta_1, t))\) with \(\alpha < \infty\). Suppose parameters \(\theta_b\), indexed by \(b \in \{0, 1\}^d\), satisfy \(\ell(\theta_b, \theta_{b'}) \ge \beta\, d_H(b, b')\) for the Hamming distance \(d_H\), and \(\mathrm{TV}(P_{\theta_b}, P_{\theta_{b'}}) \le \tau\) whenever \(d_H(b, b') = 1\). Then

    \[ \beta d (1 - \tau) \le 4\alpha\, R^*, \qquad R^* = \inf_{\kappa} \sup_{\theta \in \Theta} \mathbb{E}_{\hat\theta \sim \kappa \circ P_\theta}\, \ell(\theta, \hat\theta), \]

    where \(R^*\) is the minimax risk (Mathlib's minimaxRisk), the infimum running over all randomised estimators, that is Markov kernels \(\kappa\) from \(\Omega\) to \(\Theta\); for \(0 < \alpha < \infty\) the minimax risk is at least \(\beta d (1 - \tau)/(4\alpha)\). Compared with Le Cam's two-point bound, the bound grows linearly with the dimension \(d\) of the cube while only neighbouring hypotheses need to be close.

    A randomised estimator \(\kappa\) is reduced to the deterministic bound for the identity estimator on the output laws \(\kappa \circ P_\theta\), whose neighbours stay within total variation \(\tau\) by the data-processing inequality for total variation.

    theorem mul_one_sub_le_minimax [MeasurableSpace Θ] (P : Kernel Θ Ω) [IsMarkovKernel P]
    (ℓ : Θ → Θ → ℝ≥0∞) (hℓ : ∀ θ, Measurable (ℓ θ)) (α : ℝ≥0∞) (hα : α ≠ ⊤)
    (htri : ∀ θ₀ θ₁ t, ℓ θ₀ θ₁ ≤ α * (ℓ θ₀ t + ℓ θ₁ t)) (d : ℕ) (θ : (Fin d → Bool) → Θ)
    (β : ℝ≥0∞) (hβ : ∀ b b', β * (hammingDist b b' : ℝ≥0∞) ≤ ℓ (θ b) (θ b')) (τ : ℝ)
    (hτ : ∀ b b', hammingDist b b' = 1 → totalVariationDist (P (θ b)) (P (θ b')) ≤ τ) :
    β * d * ENNReal.ofReal (1 - τ) ≤ 4 * α * minimaxRisk ℓ P
    noncomputable def totalVariationDist {Ω : Type*} [MeasurableSpace Ω]
    (μ ν : Measure Ω) [IsFiniteMeasure μ] [IsFiniteMeasure ν] : ℝ :=
  ⨆ s : {s : Set Ω // MeasurableSet s}, |(μ s.1).toReal - (ν s.1).toReal|

    TheoremAssouad's lemma for one deterministic estimator#✓fully proved

    MathlibExt.Probability.Statistics.Assouad.mul_one_sub_le_four_mul_iSup

    For probability measures \((P_\theta)_{\theta \in \Theta}\) and the hypotheses of Assouad's lemma, with \(\alpha \in [0, \infty]\), every deterministic estimator \(T : \Omega \to \Theta\) for which each loss \(\omega \mapsto \ell(\theta, T(\omega))\) is measurable satisfies

    \[ \beta d (1 - \tau) \le 4\alpha \sup_{\theta \in \Theta} \mathbb{E}_{P_\theta}\, \ell(\theta, T). \]

    The proof follows Polyanskiy and Wu. A measurable nearest vertex \(\hat b\) of \(T\) satisfies \(\beta\, d_H(\hat b, b) \le 2\alpha\, \ell(\theta_b, T)\) for every \(b\). Averaging over the uniform prior on the cube and splitting \(d_H\) over coordinates, each coordinate \(i\) contributes, for every pair \(b\), \(b \oplus e_i\), a sum of two error probabilities of the test \(\{\hat b_i \ne b_i\}\), which is at least \(1 - \tau\) by the two-point testing bound.

    theorem mul_one_sub_le_four_mul_iSup (P : Θ → Measure Ω) [∀ θ, IsProbabilityMeasure (P θ)]
    (ℓ : Θ → Θ → ℝ≥0∞) (α : ℝ≥0∞) (htri : ∀ θ₀ θ₁ t, ℓ θ₀ θ₁ ≤ α * (ℓ θ₀ t + ℓ θ₁ t)) (d : ℕ)
    (θ : (Fin d → Bool) → Θ) (β : ℝ≥0∞)
    (hβ : ∀ b b', β * (hammingDist b b' : ℝ≥0∞) ≤ ℓ (θ b) (θ b')) (τ : ℝ)
    (hτ : ∀ b b', hammingDist b b' = 1 → totalVariationDist (P (θ b)) (P (θ b')) ≤ τ)
    (T : Ω → Θ) (hT : ∀ θ', Measurable fun ω => ℓ θ' (T ω)) :
    β * d * ENNReal.ofReal (1 - τ) ≤ 4 * α * ⨆ θ', ∫⁻ ω, ℓ θ' (T ω) ∂(P θ')
    noncomputable def totalVariationDist {Ω : Type*} [MeasurableSpace Ω]

    TheoremMeasurable choice of a minimiser#✓fully proved

    MathlibExt.Probability.Statistics.Assouad.exists_measurable_argmin

    Let \(\iota\) be a finite nonempty set and \(L_i : \Omega \to [0, \infty]\), \(i \in \iota\), measurable functions. Then there is a map \(g : \Omega \to \iota\) whose fibres \(g^{-1}(i)\) are measurable and which selects a minimiser: \(L_{g(\omega)}(\omega) \le L_i(\omega)\) for all \(\omega\) and \(i\). One takes the first minimiser for a fixed enumeration of \(\iota\).

    theorem exists_measurable_argmin {ι : Type*} [Finite ι] [Nonempty ι] (L : ι → Ω → ℝ≥0∞)
    (hL : ∀ i, Measurable (L i)) :
    ∃ g : Ω → ι, (∀ i, MeasurableSet (g ⁻¹' {i})) ∧ ∀ ω i, L (g ω) ω ≤ L i ω

    TheoremLe Cam's two-point bound with Pinsker's inequality#✓fully proved

    MathlibExt.Probability.Statistics.LeCamTwoPoint.mul_one_sub_sqrt_klDiv_le_minimax

    Under the hypotheses of Le Cam's two-point lower bound, if \(D(P_{\theta_0} \,\|\, P_{\theta_1}) < \infty\) then

    \[ \ell(\theta_0, \theta_1) \Bigl(1 - \sqrt{D(P_{\theta_0} \,\|\, P_{\theta_1})/2}\Bigr) \le 2\alpha\, R^*, \]

    where \(R^*\) is the minimax risk over randomised estimators, with the natural logarithm. This is how the two-point method is used in practice: the divergence of \(n\) i.i.d. observations is \(n\) times that of one, so choosing \(\theta_0, \theta_1\) with \(D \asymp 1/n\) gives rates of estimation.

    theorem mul_one_sub_sqrt_klDiv_le_minimax [MeasurableSpace Θ] (P : Kernel Θ Ω)
    [IsMarkovKernel P] (ℓ : Θ → Θ → ℝ≥0∞) (hℓ : ∀ θ, Measurable (ℓ θ)) (α : ℝ≥0∞)
    (hα : α ≠ ⊤) (htri : ∀ θ₀ θ₁ t, ℓ θ₀ θ₁ ≤ α * (ℓ θ₀ t + ℓ θ₁ t)) (θ₀ θ₁ : Θ)
    (hfin : InformationTheory.klDiv (P θ₀) (P θ₁) ≠ ⊤) :
    ℓ θ₀ θ₁ * ENNReal.ofReal (1 - Real.sqrt ((InformationTheory.klDiv (P θ₀) (P θ₁)).toReal / 2))
      ≤ 2 * α * minimaxRisk ℓ P

    TheoremLe Cam's two-point lower bound#✓fully proved

    MathlibExt.Probability.Statistics.LeCamTwoPoint.mul_one_sub_totalVariationDist_le_minimax

    Let \(P\) be a statistical model, a Markov kernel from a measurable parameter space \(\Theta\) to a sample space \(\Omega\), and let \(\ell : \Theta \times \Theta \to [0, \infty]\) be a loss, measurable in its second argument, satisfying the \(\alpha\)-triangle inequality \(\ell(\theta_0, \theta_1) \le \alpha (\ell(\theta_0, t) + \ell(\theta_1, t))\) with \(\alpha < \infty\). For all \(\theta_0, \theta_1 \in \Theta\),

    \[ \ell(\theta_0, \theta_1)\, \bigl(1 - \mathrm{TV}(P_{\theta_0}, P_{\theta_1})\bigr) \le 2\alpha\, R^*, \qquad R^* = \inf_{\kappa} \sup_{\theta \in \Theta} \mathbb{E}_{\hat\theta \sim \kappa \circ P_\theta}\, \ell(\theta, \hat\theta), \]

    where \(R^*\) is the minimax risk (Mathlib's minimaxRisk), the infimum running over all randomised estimators, that is Markov kernels \(\kappa\) from \(\Omega\) to \(\Theta\). For \(0 < \alpha < \infty\) the minimax risk is at least \(\ell(\theta_0, \theta_1)(1 - \mathrm{TV}(P_{\theta_0}, P_{\theta_1}))/(2\alpha)\): an estimation problem is at least as hard as testing between two of its parameters.

    Randomisation matters: with no data, \(\Theta = \{0, 1\}\) and the 0-1 loss, the minimax risk is \(1/2\), attained only by guessing at random, while every deterministic estimator has worst-case risk \(1\) (Polyanskiy and Wu, Remark 28.4). The proof reduces a randomised estimator \(\kappa\) to the deterministic bound for the identity estimator on the output laws \(\kappa \circ P_{\theta_i}\), whose total variation is at most \(\mathrm{TV}(P_{\theta_0}, P_{\theta_1})\) by the data-processing inequality for total variation.

    theorem mul_one_sub_totalVariationDist_le_minimax [MeasurableSpace Θ] (P : Kernel Θ Ω)
    [IsMarkovKernel P] (ℓ : Θ → Θ → ℝ≥0∞) (hℓ : ∀ θ, Measurable (ℓ θ)) (α : ℝ≥0∞)
    (hα : α ≠ ⊤) (htri : ∀ θ₀ θ₁ t, ℓ θ₀ θ₁ ≤ α * (ℓ θ₀ t + ℓ θ₁ t)) (θ₀ θ₁ : Θ) :
    ℓ θ₀ θ₁ * ENNReal.ofReal (1 - totalVariationDist (P θ₀) (P θ₁)) ≤
      2 * α * minimaxRisk ℓ P

    TheoremLe Cam's two-point lower bound for one deterministic estimator#✓fully proved

    MathlibExt.Probability.Statistics.LeCamTwoPoint.mul_one_sub_totalVariationDist_le_two_mul_max

    Let \(P_0\) and \(P_1\) be probability measures on \(\Omega\), let \(\ell : \Theta \times \Theta \to [0, \infty]\) be a loss and \(\alpha \in [0, \infty]\) with \(\ell(\theta_0, \theta_1) \le \alpha (\ell(\theta_0, t) + \ell(\theta_1, t))\) for every \(t \in \Theta\). Every deterministic estimator \(T : \Omega \to \Theta\) for which \(\omega \mapsto \ell(\theta_i, T(\omega))\) is measurable (\(i = 0, 1\)) satisfies

    \[ \ell(\theta_0, \theta_1)\, \bigl(1 - \mathrm{TV}(P_0, P_1)\bigr) \le 2\alpha \max\Bigl(\mathbb{E}_{P_0}\, \ell(\theta_0, T),\ \mathbb{E}_{P_1}\, \ell(\theta_1, T)\Bigr). \]

    The expectations are lower Lebesgue integrals, so no integrability is assumed. The proof bounds both risks below on the common part of \(P_0\) and \(P_1\), which has mass \(1 - \mathrm{TV}(P_0, P_1)\).

    theorem mul_one_sub_totalVariationDist_le_two_mul_max (P₀ P₁ : Measure Ω)
    [IsProbabilityMeasure P₀] [IsProbabilityMeasure P₁] (ℓ : Θ → Θ → ℝ≥0∞) (θ₀ θ₁ : Θ)
    (α : ℝ≥0∞) (htri : ∀ t, ℓ θ₀ θ₁ ≤ α * (ℓ θ₀ t + ℓ θ₁ t)) (T : Ω → Θ)
    (hT₀ : Measurable fun ω => ℓ θ₀ (T ω)) (hT₁ : Measurable fun ω => ℓ θ₁ (T ω)) :
    ℓ θ₀ θ₁ * ENNReal.ofReal (1 - totalVariationDist P₀ P₁) ≤
      2 * α * max (∫⁻ ω, ℓ θ₀ (T ω) ∂P₀) (∫⁻ ω, ℓ θ₁ (T ω) ∂P₁)
    noncomputable def totalVariationDist {Ω : Type*} [MeasurableSpace Ω]
    (μ ν : Measure Ω) [IsFiniteMeasure μ] [IsFiniteMeasure ν] : ℝ :=
  ⨆ s : {s : Set Ω // MeasurableSet s}, |(μ s.1).toReal - (ν s.1).toReal|
