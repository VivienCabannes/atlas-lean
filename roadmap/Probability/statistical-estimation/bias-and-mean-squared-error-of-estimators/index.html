    Bias and mean squared error of estimators

    DefinitionBias of an estimator#✓fully proved

    MathlibExt.Probability.Statistics.EstimationRisk.bias

    Let \(S\) be a measurable space, \(W : S \to \mathbb{R}\) an estimator, \(\mu\) a probability measure on \(S\) for which \(W\) is integrable, and \(\theta \in \mathbb{R}\) a target. The bias of \(W\) under \(\mu\) at \(\theta\) is \(\int_S W \, d\mu - \theta\), the expected value of \(W\) under \(\mu\) minus \(\theta\).

    Integrability of \(W\) is part of the input: it is the domain on which the expectation exists in the source (Chapter 2, Definition 2.2.1), so a nonintegrable estimator has no finite bias.

    noncomputable def bias (W : S → ℝ) (μ : ProbabilityMeasure S) (θ : ℝ)
    (_hW : Integrable W (μ : Measure S)) : ℝ :=
  ∫ x, W x ∂(μ : Measure S) - θ

    DefinitionMean squared error#✓fully proved

    MathlibExt.Probability.Statistics.EstimationRisk.meanSquaredError

    Let \(\mu\) be a probability measure on a measurable space \(S\), let \(W : S \to \mathbb{R}\) be an estimator and \(\theta \in \mathbb{R}\) a target value, and suppose the squared error \(x \mapsto (W(x) - \theta)^2\) is \(\mu\)-integrable. The mean squared error of \(W\) at \(\theta\) under \(\mu\) is the real number \(\int_S (W(x) - \theta)^2 \, d\mu(x)\).

    The integrability hypothesis is part of the definition: without it no finite mean squared error is defined.

    noncomputable def meanSquaredError (W : S → ℝ) (μ : ProbabilityMeasure S)
    (θ : ℝ)
    (_hW2 : Integrable (fun x => (W x - θ) ^ 2) (μ : Measure S)) : ℝ :=
  ∫ x, (W x - θ) ^ 2 ∂(μ : Measure S)

    DefinitionExtended mean squared error#✓fully proved

    MathlibExt.Probability.Statistics.EstimationRisk.meanSquaredErrorENN

    Let \(\mu\) be a probability measure on a measurable space \(S\), let \(W : S \to \mathbb{R}\) be an estimator and let \(\theta \in \mathbb{R}\) be a target value. The extended mean squared error of \(W\) at \(\theta\) under \(\mu\) is the (lower) Lebesgue integral \(\int_S (W(x) - \theta)^2 \, d\mu(x)\) of the nonnegative squared error, computed in \([0, \infty]\). It is defined for every \(W\), with no integrability hypothesis.

    When the squared error is \(\mu\)-integrable, this value is finite and equals the mean squared error; when the squared error is almost everywhere strongly measurable but not \(\mu\)-integrable, it equals \(\infty\).

    noncomputable def meanSquaredErrorENN (W : S → ℝ) (μ : ProbabilityMeasure S)
    (θ : ℝ) : ℝ≥0∞ :=
  ∫⁻ x, ENNReal.ofReal ((W x - θ) ^ 2) ∂(μ : Measure S)

    DefinitionFamily bias of an estimator#✓fully proved

    MathlibExt.Probability.Statistics.EstimationRisk.familyBias

    Let \(S\) be a measurable space, \(W : S \to \mathbb{R}\) an estimator, \((P_\theta)_{\theta \in \Theta}\) a family of probability measures on \(S\) such that \(W\) is integrable for every \(P_\theta\), and \(\tau : \Theta \to \mathbb{R}\) a target function. The family bias of \(W\) is the function on \(\Theta\) whose value at \(\theta\) is the bias of \(W\) under \(P_\theta\) at the target \(\tau(\theta)\), that is, \(\int_S W \, dP_\theta - \tau(\theta)\).

    The estimator \(W\) is fixed before the family and does not depend on \(\theta\).

    noncomputable def familyBias {Θ : Type*} (W : S → ℝ)
    (P : Θ → ProbabilityMeasure S) (τ : Θ → ℝ)
    (h : ∀ θ, Integrable W ((P θ) : Measure S)) : Θ → ℝ :=
  fun θ => bias W (P θ) (τ θ) (h θ)
    noncomputable def bias (W : S → ℝ) (μ : ProbabilityMeasure S) (θ : ℝ)
    (_hW : Integrable W (μ : Measure S)) : ℝ :=
  ∫ x, W x ∂(μ : Measure S) - θ

    DefinitionUnbiased estimator#✓fully proved

    MathlibExt.Probability.Statistics.EstimationRisk.IsUnbiased

    Let \((P_\theta)_{\theta \in \Theta}\) be a family of probability measures on a measurable space \(S\) and \(\tau : \Theta \to \mathbb{R}\) a target function. An estimator \(W : S \to \mathbb{R}\) is unbiased for \(\tau\) if for every \(\theta \in \Theta\) the function \(W\) is \(P_\theta\)-integrable and \(\int_S W \, dP_\theta = \tau(\theta)\).

    Integrability is part of the definition, so a non-integrable estimator is never unbiased. The estimator \(W\) is fixed and does not depend on \(\theta\).

    def IsUnbiased {Θ : Type*} (W : S → ℝ) (P : Θ → ProbabilityMeasure S)
    (τ : Θ → ℝ) : Prop :=
  ∀ θ, Integrable W ((P θ) : Measure S) ∧
    ∫ x, W x ∂((P θ) : Measure S) = τ θ
