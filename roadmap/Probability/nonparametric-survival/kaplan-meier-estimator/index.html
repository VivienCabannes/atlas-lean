    TheoremSelf-consistency#✓fully proved

    MathlibExt.Probability.Statistics.KaplanMeier.CensoredData.size_mul_kmSurvival

    Self-consistency (Efron 1967, (7.4)): n Ŝ(t) is the number of observations exceeding t plus, for each subject censored at or before t, the conditional survival Ŝ(t) / Ŝ(tⱼ).

    theorem size_mul_kmSurvival (t : ℝ) :
    (D.size : ℝ) * D.kmSurvival t =
      (∑ j with t < D.time j, ((D.deaths j : ℝ) + D.censored j)) +
        ∑ j with D.time j ≤ t,
