    DefinitionBreslow information#✓fully proved

    MathlibExt.Probability.Statistics.CoxPartialLikelihood.breslowInformation

    The Breslow (Cox) information ∑_{i : δᵢ} n₁ n₀ / n² at the risk sets of the events. This is -ℓ''(0) for a group indicator, not the tied log-rank variance: for one tied risk set with n = 4, n₁ = 2 and d = 2 events it gives 1 / 2, while the hypergeometric log-rank variance is 1 / 3. It equals the log-rank variance only when the event times are distinct (so each risk set contributes at most one event).

    noncomputable def breslowInformation (T : Fin n → ℝ) (δ : Fin n → Bool) (g : Fin n → Bool) :
    ℝ :=
  ∑ i with δ i = true,
    (numAtRiskIn T g i : ℝ) * ((numAtRisk T i : ℝ) - numAtRiskIn T g i) / (numAtRisk T i) ^ 2
    noncomputable def numAtRiskIn (T : Fin n → ℝ) (g : Fin n → Bool) (i : Fin n) : ℕ :=
  #{l ∈ riskSet T i | g l = true}
