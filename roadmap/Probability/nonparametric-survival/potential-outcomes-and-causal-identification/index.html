    DefinitionConditional independence given a discrete variable#✓fully proved

    MathlibExt.Probability.Causality.CondIndepDiscrete

    The event T is conditionally independent of V given W, stated through the values of W: P(T, V ∈ B, W = w) P(W = w) = P(T, W = w) P(V ∈ B, W = w) for all measurable B and all w. For a W with countably many values this is the conditional independence of the indicator of T and V given W.

    def CondIndepDiscrete [MeasurableSpace β] (μ : Measure Ω) (T : Set Ω) (V : Ω → β) (W : Ω → γ) :
    Prop :=

    μ.real (T ∩ V ⁻¹' B ∩ W ⁻¹' {w}) * μ.real (W ⁻¹' {w}) =
      μ.real (T ∩ W ⁻¹' {w}) * μ.real (V ⁻¹' B ∩ W ⁻¹' {w})
