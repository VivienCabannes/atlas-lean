    MathlibExt.Probability.ProductBondPercolation.prodGraph

    For a simple graph \(G\) on \(V\), the graph \(G \times \mathbb{Z}\) is the box product of \(G\) with the integer line: its vertex set is \(V \times \mathbb{Z}\), and \((v, m)\) and \((w, n)\) are adjacent exactly when either \(v\) and \(w\) are adjacent in \(G\) and \(m = n\), or \(v = w\) and \(|m - n| = 1\).

    def prodGraph {V : Type u} (G : SimpleGraph V) : SimpleGraph (V × ℤ) :=
  G □ intLine

    DefinitionBernoulli bond law on \(V \times \mathbb{Z}\)#✓fully proved

    MathlibExt.Probability.ProductBondPercolation.bernoulliLaw

    For a type \(V\) and \(0 \le p \le 1\), the Bernoulli(\(p\)) bond law on \(V \times \mathbb{Z}\) is the product measure on configurations \(\omega\), which assign true (open) or false (closed) to every unordered pair \(\{a, b\}\) of points of \(V \times \mathbb{Z}\) (with \(a = b\) allowed), under which the values \(\omega(e)\) are independent and each is true with probability \(p\) and false with probability \(1 - p\).

    noncomputable def bernoulliLaw {V : Type u} (p : ℝ)
    (hp0 : 0 ≤ p) (hp1 : p ≤ 1) : Measure (Sym2 (V × ℤ) → Bool) :=
  Measure.infinitePi fun _ => ProbabilityTheory.bernoulliMeasure true false ⟨p, hp0, hp1⟩

    MathlibExt.Probability.ProductBondPercolation.AlmostSurely

    Let \(V\) be a type, let \(p\) be a real number with \(0 \le p \le 1\), and let \(P\) be a property of configurations \(\omega\), that is, of functions assigning true or false to every unordered pair \(\{a, b\}\) of points of \(V \times \mathbb{Z}\) (with \(a = b\) allowed).     DefinitionCritical probability for bond percolation#✓fully proved

    MathlibExt.Probability.ProductBondPercolation.criticalProb

    For a simple graph \(G\) on a countable vertex set \(V\), the critical probability \(p_c(G)\) is the infimum of the set consisting of \(1\) together with every \(p \in [0, 1]\) for which, under the Bernoulli(\(p\)) bond law on \(V\), the event that the open cluster in \(G\) of some vertex is infinite has positive probability. In particular \(p_c(G) = 1\) when no such \(p\) exists.

    Countability of \(V\) makes the event that some open cluster is infinite measurable for the product law.

    noncomputable def criticalProb {V : Type u} [Countable V] (G : SimpleGraph V) : ℝ :=
  sInf (insert 1 {p : ℝ | ∃ hp0 : 0 ≤ p, ∃ hp1 : p ≤ 1,
    0 < gbernoulliLaw p hp0 hp1 {ω | ∃ x : V, (gcluster G ω x).Infinite}})
