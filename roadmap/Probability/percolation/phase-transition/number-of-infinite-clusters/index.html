    TheoremShift-invariant countably valued functions are a.s. constant under ergodicity#✓fully proved

    StatMech.ConfigSpace.ergodic_ae_const_of_shiftInvariant

    A measurable function with countable values that is invariant under all shifts is almost surely constant under an ergodic probability measure. See also Mathlib's ErgodicSMul and aeconst_of_forall_preimage_smul_ae_eq, which state ergodicity of a group action through a.e.-invariant sets.

    theorem ergodic_ae_const_of_shiftInvariant [IsProbabilityMeasure μ]
    {β : Type*} [Countable β] [MeasurableSpace β] [MeasurableSingletonClass β]
    (herg : IsErgodic (G := G) μ)
    (f : ConfigSpace E → β) (hf : Measurable f)
    (hinv : ∀ (g : G) (ω : ConfigSpace E), f (shift g ω) = f ω) :
    ∃ k : β, μ {ω | f ω = k} = 1
    def IsErgodic (μ : Measure (ConfigSpace E)) : Prop :=
  IsTranslationInvariant (G := G) μ ∧
    ∀ s : Set (ConfigSpace E), MeasurableSet s →
      (∀ g : G, (shift g : ConfigSpace E → ConfigSpace E) ⁻¹' s = s) →
        μ s = 0 ∨ μ s = μ Set.univ
