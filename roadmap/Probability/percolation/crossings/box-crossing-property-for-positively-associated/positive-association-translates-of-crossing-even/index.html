    DefinitionPositively associated measure#✓fully proved

    StatMech.Universality.PositivelyAssociated

    A finite measure on configurations is positively associated if μ(A) μ(B) ≤ μ(A ∩ B) μ(univ) for all measurable increasing events A, B. The total-mass factor makes the Harris--FKG inequality invariant under finite scaling.

    def PositivelyAssociated {E : Type*} (μ : Measure (ConfigSpace E))
    [IsFiniteMeasure μ] : Prop :=
  ∀ A B : Set (ConfigSpace E), MeasurableSet A → MeasurableSet B →
    IsIncreasing A → IsIncreasing B →
    μ.real A * μ.real B ≤ μ.real (A ∩ B) * μ.real Set.univ
