    DefinitionProbability of connection inside a set#✓fully proved

    StatMech.Percolation.connWithinProb

    The probability ℙ_p(0 ↔ x inside S) that the origin and x are joined by an open path using only vertices of S; it is 0 if 0 ∉ S or x ∉ S.

    noncomputable def connWithinProb (d : ℕ) (p : ℝ≥0) (hp : p ≤ 1) (S : Finset (Site d))
    (x : Site d) : ℝ := by
  classical
  exact
    if h0 : origin d ∈ S then
      if hx : x ∈ S then
        (bernoulliProductMeasure (E := Sym2 (Site d)) p hp).real
          {ω | ConnectedWithin d ω (S : Set (Site d)) ⟨origin d, h0⟩ ⟨x, hx⟩}
      else 0
    else 0
