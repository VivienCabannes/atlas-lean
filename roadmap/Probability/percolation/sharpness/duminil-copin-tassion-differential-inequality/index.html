    StatMech.Percolation.dct_differential_inequality

    The Duminil-Copin–Tassion differential inequality: if φ_p(S) ≥ m for every finite S ∋ 0, then d/dp ℙ_p(A_n) ≥ (p(1 - p))⁻¹ m (1 - ℙ_p(A_n)) for 0 < p < 1 and n ≥ 1 (Duminil-Copin–Tassion 2016).

    theorem dct_differential_inequality (p : ℝ≥0) (hp : p ≤ 1) (n : ℕ) (hn : 1 ≤ n)
    (hp0 : 0 < (p : ℝ)) (hp1 : (p : ℝ) < 1) (m : ℝ)
    (hm : ∀ S : Finset (Site d), origin d ∈ S → m ≤ phi d p hp S) :
    deriv (fun q => prob q ((boxEdgeFinset d n).restrict '' (boxCrossingEvent d n))) (p : ℝ)
      ≥ (1 / ((p : ℝ) * (1 - (p : ℝ)))) * m * (1 - boxCrossProb d p hp n)
