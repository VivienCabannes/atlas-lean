    StructurePoisson process#✓fully proved

    ProbabilityTheory.IsPoissonProcess

    N : ℝ≥0 → Ω → ℕ is a Poisson process of rate r under P (Kingman 1993, ch. 4; Karlin–Taylor 1975, ch. 4): N 0 = 0 and the paths are nondecreasing almost surely, the increments over consecutive intervals are independent, and for s ≤ t the increment N t - N s has the Poisson law of mean r (t - s).

    structure IsPoissonProcess (N : ℝ≥0 → Ω → ℕ) (r : ℝ≥0) (P : Measure Ω := by volume_tac) :
    Prop where
  /-- The process starts at `0` almost surely. -/
  ae_zero : ∀ᵐ ω ∂P, N 0 ω = 0
  /-- Almost every path is nondecreasing. -/
  ae_monotone : ∀ᵐ ω ∂P, Monotone fun t ↦ N t ω
  /-- Increments over consecutive intervals are independent. -/
  hasIndepIncrements : HasIndepIncrements N P
  /-- The increment over `(s, t]` has the Poisson law of mean `r (t - s)`. -/
  hasLaw_sub : ∀ ⦃s t : ℝ≥0⦄, s ≤ t →
    HasLaw (fun ω ↦ N t ω - N s ω) (poissonMeasure (r * (t - s))) P

    ProbabilityTheory.PoissonProcess.count

    The counting process of the interarrival times T: count T t ω is the number of arrivals n ≥ 1 with S n ≤ t. When that set is infinite (a null event for exponential interarrivals of positive rate) Set.ncard returns 0.

    noncomputable def count (T : ℕ → Ω → ℝ) (t : ℝ≥0) (ω : Ω) : ℕ :=
  {n : ℕ | arrivalTime T (n + 1) ω ≤ t}.ncard

    ProbabilityTheory.IsPoissonProcess.add

    Superposition (Kingman 1993, §2.2): the sum of two independent Poisson processes of rates r₁ and r₂ is a Poisson process of rate r₁ + r₂. Independence is of the two processes as random paths.

    theorem IsPoissonProcess.add {N₁ N₂ : ℝ≥0 → Ω → ℕ} {r₁ r₂ : ℝ≥0}

    (hind : IndepFun (fun ω t ↦ N₁ t ω) (fun ω t ↦ N₂ t ω) P) :
    IsPoissonProcess (N₁ + N₂) (r₁ + r₂) P

    ProbabilityTheory.PoissonProcess.thinning

    The thinning of N by the marks B: the number of indices i < N t with B i, i.e. the number of points of N in [0, t] that are kept when the i-th point (in time order, from 0) is kept iff B i.

    noncomputable def PoissonProcess.thinning (N : ℝ≥0 → Ω → ℕ) (B : ℕ → Ω → Bool) (t : ℝ≥0)
    (ω : Ω) : ℕ :=
  ((Finset.range (N t ω)).filter fun i ↦ B i ω).card

    TheoremThinning#✓fully proved

    ProbabilityTheory.IsPoissonProcess.thinning

    Thinning (Kingman 1993, §5.1; Karlin–Taylor 1975, §4.1): keeping each point of a Poisson process of rate r independently with probability p, independently of the process, gives a Poisson process of rate p r. The marks B i are i.i.d. with P(B i) = p and independent of N as a random path.

    theorem IsPoissonProcess.thinning {N : ℝ≥0 → Ω → ℕ} {r p : ℝ≥0} {B : ℕ → Ω → Bool}
    [IsProbabilityMeasure P] (hN : IsPoissonProcess N r P) (hp : p ≤ 1)
    (hBm : ∀ i, Measurable (B i)) (hB : ∀ i, P.real {ω | B i ω = true} = p)
    (hBind : iIndepFun B P) (hNB : IndepFun (fun ω t ↦ N t ω) (fun ω i ↦ B i ω) P) :
    IsPoissonProcess (PoissonProcess.thinning N B) (p * r) P

    TheoremIndependent Poisson increments of the counting process#✓fully proved

    ProbabilityTheory.PoissonProcess.hasLaw_count_increments

    The increments of the counting process of i.i.d. rate-r exponential interarrivals over consecutive intervals (t i, t (i + 1)] are independent with the Poisson laws of means r (t (i + 1) - t i): the increment vector has the product law (Kingman 1993, ch. 4; Karlin–Taylor 1975, ch. 4).

    theorem hasLaw_count_increments {T : ℕ → Ω → ℝ} {r : ℝ≥0} (hr : 0 < r)
    (hT : ∀ i, HasLaw (T i) (expMeasure r) P) (hind : iIndepFun T P) (n : ℕ)
    (t : Fin (n + 1) → ℝ≥0) (ht : Monotone t) :
    HasLaw (fun ω (i : Fin n) ↦ count T (t i.succ) ω - count T (t i.castSucc) ω)
      (Measure.pi fun i ↦ poissonMeasure (r * (t i.succ - t i.castSucc))) P
    noncomputable def count (T : ℕ → Ω → ℝ) (t : ℝ≥0) (ω : Ω) : ℕ :=
  {n : ℕ | arrivalTime T (n + 1) ω ≤ t}.ncard
