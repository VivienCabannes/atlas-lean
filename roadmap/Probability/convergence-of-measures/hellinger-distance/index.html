    Hellinger distance

    The Hellinger distance \(d_{\mathrm{Hell}}(\mu, \nu) = \big(\tfrac12 \int (\sqrt{d\mu/d\zeta} - \sqrt{d\nu/d\zeta})^2 \, d\zeta\big)^{1/2}\) between finite (in practice probability) measures, computed against any measure \(\zeta\) dominating both, with the normalisation of Dashti and Stuart that puts the distance between probability measures in \([0, 1]\). It is the metric in which Bayesian posteriors are shown to depend continuously on the data and on approximations of the forward model, because it controls differences of expectations of functions with second moments.

    DefinitionHellinger distance#✓fully proved

    MathlibExt.Probability.HellingerDistance.hellingerDist

    For finite measures \(\mu\) and \(\nu\) on the same measurable space (in practice probability measures), the Hellinger distance is

    \[ d_{\mathrm{Hell}}(\mu, \nu) = \sqrt{\frac12 \int \Big(\sqrt{\tfrac{d\mu}{d\zeta}} - \sqrt{\tfrac{d\nu}{d\zeta}}\Big)^2 \, d\zeta}, \qquad \zeta = \mu + \nu . \]

    Any other measure dominating both gives the same value (change of reference measure), so the choice \(\zeta = \mu + \nu\) only makes the definition free of choices. The factor \(\tfrac12\) is the normalisation of Dashti and Stuart, for which the distance between probability measures lies in \([0, 1]\).

    The Lean definition accepts any measures, but it is meaningful only for finite ones: for infinite measures the integral can diverge, and Mathlib's convention that a non-integrable function has integral \(0\) then gives a meaningless value (Lebesgue measure and twice Lebesgue measure on \(\mathbb R\) come out at distance \(0\)).

    noncomputable def hellingerDist (μ ν : Measure Ω) : ℝ :=
  √((1 / 2 : ℝ) * ∫ x, (√((μ.rnDeriv (μ + ν) x).toReal) - √((ν.rnDeriv (μ + ν) x).toReal)) ^ 2
    ∂(μ + ν))

    TheoremHellinger distance through densities against any dominating measure#✓fully proved

    MathlibExt.Probability.HellingerDistance.hellingerDist_withDensity

    Let \(\rho\) be a σ-finite measure and \(f\), \(g\) measurable densities, finite \(\rho\)-almost everywhere. Then

    \[ d_{\mathrm{Hell}}(\rho f, \rho g) = \sqrt{\frac12 \int \big(\sqrt{f} - \sqrt{g}\big)^2 \, d\rho}, \]

    where \(\rho f\) denotes the measure with density \(f\) with respect to \(\rho\). So the distance can be computed against any common dominating measure, as in Dashti and Stuart's definition; taking \(\rho = \mu\) gives their formula (7.21). In the Bayesian setting the natural reference measure is the prior, against which posteriors have explicit densities. The identity holds for every σ-finite \(\rho\), but it is meaningful only when \(\rho f\) and \(\rho g\) are finite measures.

    The proof writes \(f = (f + g)\, \tfrac{d\mu}{d\zeta}\) and \(g = (f + g)\, \tfrac{d\nu}{d\zeta}\) \(\rho\)-almost everywhere, for \(\zeta = \mu + \nu = \rho (f + g)\).

    theorem hellingerDist_withDensity {ρ : Measure Ω} [SigmaFinite ρ] {f g : Ω → ℝ≥0∞}
    (hf : Measurable f) (hg : Measurable g) (hf_top : ∀ᵐ x ∂ρ, f x ≠ ∞)
    (hg_top : ∀ᵐ x ∂ρ, g x ≠ ∞) :
    hellingerDist (ρ.withDensity f) (ρ.withDensity g) =
      √((1 / 2 : ℝ) * ∫ x, (√((f x).toReal) - √((g x).toReal)) ^ 2 ∂ρ)
    noncomputable def hellingerDist (μ ν : Measure Ω) : ℝ :=
  √((1 / 2 : ℝ) * ∫ x, (√((μ.rnDeriv (μ + ν) x).toReal) - √((ν.rnDeriv (μ + ν) x).toReal)) ^ 2
    ∂(μ + ν))

    TheoremHellinger is at most the square root of total variation#✓fully proved

    MathlibExt.Probability.HellingerDistance.hellingerDist_le_sqrt_totalVariationDist

    For probability measures \(\mu\) and \(\nu\),

    \[ d_{\mathrm{Hell}}(\mu, \nu) \le d_{\mathrm{TV}}(\mu, \nu)^{1/2}, \]

    with \(d_{\mathrm{TV}}(\mu, \nu) = \sup_B |\mu(B) - \nu(B)|\), which for probability measures equals Dashti and Stuart's \(\tfrac12 \int |d\mu/d\zeta - d\nu/d\zeta| \, d\zeta\). As in their proof, the pointwise bound \((\sqrt a - \sqrt b)^2 \le |a - b|\) reduces the claim to \(\tfrac12 \int |a - b| \, d\zeta \le d_{\mathrm{TV}}\), obtained by splitting the integral along \(\{a \le b\}\). Together with the reverse comparison it shows that the two metrics define the same topology.

    theorem hellingerDist_le_sqrt_totalVariationDist (μ ν : Measure Ω) [IsProbabilityMeasure μ]
    [IsProbabilityMeasure ν] : hellingerDist μ ν ≤ √(totalVariationDist μ ν)
    noncomputable def hellingerDist (μ ν : Measure Ω) : ℝ :=
  √((1 / 2 : ℝ) * ∫ x, (√((μ.rnDeriv (μ + ν) x).toReal) - √((ν.rnDeriv (μ + ν) x).toReal)) ^ 2
    ∂(μ + ν))

    TheoremTotal variation is at most √2 times Hellinger#✓fully proved

    MathlibExt.Probability.HellingerDistance.totalVariationDist_div_sqrt_two_le_hellingerDist

    For probability measures \(\mu\) and \(\nu\),

    \[ \frac{1}{\sqrt 2} \, d_{\mathrm{TV}}(\mu, \nu) \le d_{\mathrm{Hell}}(\mu, \nu), \]

    with \(d_{\mathrm{TV}}(\mu, \nu) = \sup_B |\mu(B) - \nu(B)|\).     TheoremThe Hellinger distance controls expectations#✓fully proved

    MathlibExt.Probability.HellingerDistance.norm_integral_sub_integral_le_hellingerDist

    For probability measures \(\mu\) and \(\nu\) and a function \(f\) with values in a real Banach space and finite second moments under both,

    \[ \big\| \mathbb E^\mu f - \mathbb E^\nu f \big\| \le 2 \big( \mathbb E^\mu \|f\|^2 + \mathbb E^\nu \|f\|^2 \big)^{1/2} \, d_{\mathrm{Hell}}(\mu, \nu). \]

    This is why the Hellinger distance is the metric of choice for posterior stability: a Hellinger bound on posteriors transfers to posterior means (and, by the second statement of the lemma, which is not formalised here, to posterior covariances). Dashti and Stuart state it on a separable Banach space; the proof does not use that structure. They apply the Cauchy–Schwarz inequality after factoring the difference of densities; the formal proof integrates the corresponding pointwise inequality with a free parameter \(t > 0\) and optimises over \(t\).

    theorem norm_integral_sub_integral_le_hellingerDist {E : Type*} [NormedAddCommGroup E]
    [NormedSpace ℝ E] [CompleteSpace E] (μ ν : Measure Ω) [IsProbabilityMeasure μ]
    [IsProbabilityMeasure ν] (f : Ω → E) (hμf : MemLp f 2 μ) (hνf : MemLp f 2 ν) :
    ‖∫ x, f x ∂μ - ∫ x, f x ∂ν‖ ≤
      2 * √(∫ x, ‖f x‖ ^ 2 ∂μ + ∫ x, ‖f x‖ ^ 2 ∂ν) * hellingerDist μ ν
    noncomputable def hellingerDist (μ ν : Measure Ω) : ℝ :=
  √((1 / 2 : ℝ) * ∫ x, (√((μ.rnDeriv (μ + ν) x).toReal) - √((ν.rnDeriv (μ + ν) x).toReal)) ^ 2
    ∂(μ + ν))
