    DefinitionSymbols of a term#✓fully proved

    Cslib.Logic.FOL.termSymbols

    The set of symbols of a first-order language \(L\) that occur in a term \(t\) (with free variables and possibly bound variables), defined by recursion on \(t\): a variable contributes no symbols, and \(f(t_1, \dots, t_k)\) contributes the function symbol \(f\) together with the symbols of the terms \(t_i\). The result lies in the set of all symbols of \(L\), but only function symbols can occur in a term.

    def termSymbols {n : ℕ} : L.Term (α ⊕ Fin n) → Set L.Symbols
  | .var _ => ∅
  | .func f ts => {Sum.inl ⟨_, f⟩} ∪ ⋃ i, termSymbols (ts i)

    DefinitionSymbols of a formula#✓fully proved

    Cslib.Logic.FOL.formulaSymbols

    The set of function and relation symbols of a first-order language \(L\) that occur in a formula \(\varphi\) (with free variables and possibly bound variables), defined by recursion on \(\varphi\): falsum \(\bot\) contributes no symbols, an equation \(t_1 = t_2\) contributes the symbols of the terms \(t_1\) and \(t_2\), an atomic formula \(R(t_1, \dots, t_k)\) contributes \(R\) together with the symbols of the terms \(t_i\), an implication \(\varphi \to \psi\) contributes the symbols of \(\varphi\) and of \(\psi\), and \(\forall x\, \varphi\) contributes the symbols of \(\varphi\). Variables and the equality sign contribute nothing.

    def formulaSymbols {n : ℕ} : L.BoundedFormula α n → Set L.Symbols
  | .falsum => ∅
  | .equal t₁ t₂ => termSymbols t₁ ∪ termSymbols t₂
  | .rel R ts => {Sum.inr ⟨_, R⟩} ∪ ⋃ i, termSymbols (ts i)
  | .imp φ ψ => formulaSymbols φ ∪ formulaSymbols ψ
  | .all φ => formulaSymbols φ
    def termSymbols {n : ℕ} : L.Term (α ⊕ Fin n) → Set L.Symbols
  | .var _ => ∅

    DefinitionInstantiating the outermost bound variable of a term#✓fully proved

    Cslib.Logic.FOL.instantiateTerm

    Let \(L\) be a first-order language, \(t\) an \(L\)-term with free variables in \(\alpha\), and \(s\) an \(L\)-term with free variables in \(\alpha\) and \(m + 1\) bound variables \(0, \dots, m\).     L.Term (α ⊕ Fin m) :=
  s.subst (Sum.elim (fun a ↦ Term.var (Sum.inl a))
    (Fin.cases (t.relabel Sum.inl) fun i ↦ Term.var (Sum.inr i)))

    DefinitionInstantiating the outermost bound variable of a formula#✓fully proved

    Cslib.Logic.FOL.instantiate

    Let \(L\) be a first-order language, \(t\) an \(L\)-term with free variables in \(\alpha\), and \(\varphi\) a bounded \(L\)-formula with free variables in \(\alpha\) and \(m + 1\) bound variables \(0, \dots, m\). The instantiation of \(t\) in \(\varphi\) is the bounded formula with free variables in \(\alpha\) and \(m\) bound variables obtained from \(\varphi\) by instantiating \(t\) in every term of its atomic subformulas: in each term, \(t\) is substituted for the bound variable \(0\) and each other bound variable \(i + 1\) is replaced by \(i\).   | _, .rel R ts => .rel R fun i ↦ instantiateTerm t (ts i)
  | _, .imp φ ψ => .imp (instantiate t φ) (instantiate t ψ)
  | _, .all φ => .all (instantiate t φ)
