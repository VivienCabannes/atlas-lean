    DefinitionApplying a substitution to a term#✓fully proved

    Cslib.Unification.Term.subst

    For a substitution \(\sigma\) and a term \(t\), the term \(t\sigma\) is obtained from \(t\) by replacing every variable \(x\) by \(\sigma(x)\): a variable \(x\) becomes \(\sigma(x)\), a constant is unchanged, and a node with subterms \(l\) and \(r\) becomes the node with subterms \(l\sigma\) and \(r\sigma\).

    def subst (s : Subst C) : Term C → Term C
  | var x => s x
  | const c => const c
  | node l r => node (l.subst s) (r.subst s)
    abbrev Subst (C : Type u) := ℕ → Term C

    DefinitionSize of a term#✓fully proved

    Cslib.Unification.Term.size

    The size of a term is the number of symbols in it: a variable and a constant have size \(1\), and a node with subterms \(l\) and \(r\) has size equal to the size of \(l\) plus the size of \(r\) plus \(1\).

    def size : Term C → ℕ
  | var _ => 1
  | const _ => 1
  | node l r => l.size + r.size + 1
    inductive Term (C : Type u) where
  | var (x : ℕ)
  | const (c : C)
  | node (l r : Term C)
  deriving DecidableEq, Repr

    DefinitionVariables of a term#✓fully proved

    Cslib.Unification.Term.vars

    The variables of a term form a finite set of natural numbers, defined recursively: the variable \(x\) has the variable set \(\{x\}\), a constant has no variables, and the variables of a node with subterms \(l\) and \(r\) are those of \(l\) together with those of \(r\).

    def vars : Term C → Finset ℕ
  | var x => {x}
  | const _ => ∅
  | node l r => l.vars ∪ r.vars
    inductive Term (C : Type u) where
  | var (x : ℕ)
  | const (c : C)
  | node (l r : Term C)
  deriving DecidableEq, Repr

    TheoremOccurs check: size bound#✓fully proved

    Cslib.Unification.Term.size_subst_lt_of_mem

    Let \(x\) be a variable and \(t\) a term in which \(x\) occurs, with \(t\) not the variable \(x\) itself. Then for every substitution \(\sigma\), the term \(\sigma(x)\) has strictly smaller size than \(t\sigma\), the result of applying \(\sigma\) to \(t\).

    Consequently the equation \(x = t\) has no unifier when \(x\) occurs in \(t\) and \(t \ne x\) (the occurs check).

    theorem size_subst_lt_of_mem {x : ℕ} {t : Term C} (hx : x ∈ t.vars) (ht : t ≠ var x)
    (s : Subst C) : (s x).size < (t.subst s).size
    inductive Term (C : Type u) where
  | var (x : ℕ)
  | const (c : C)
  | node (l r : Term C)
  deriving DecidableEq, Repr

    TheoremSubstituting for a variable that does not occur in the substituted term#✓fully proved

    Cslib.Unification.Term.vars_subst_single_subset

    Let \(x\) be a variable and \(t\) a term in which \(x\) does not occur. For every term \(u\), every variable of the term obtained from \(u\) by replacing each occurrence of \(x\) with \(t\) is a variable of \(u\) or of \(t\), and is different from \(x\).

    theorem vars_subst_single_subset {x : ℕ} {t : Term C} (hxt : x ∉ t.vars) (u : Term C) :
    (u.subst fun y ↦ if y = x then t else var y).vars ⊆ (u.vars ∪ t.vars).erase x
    inductive Term (C : Type u) where
  | var (x : ℕ)
  | const (c : C)
  | node (l r : Term C)
  deriving DecidableEq, Repr

    Cslib.Unification.Subst.single_comp_eq

    DefinitionMost general unifier#✓fully proved

    Cslib.Unification.IsMGU

    A substitution \(s\) is a most general unifier of a list of equations \(E\) when \(s\) unifies \(E\) and every unifier \(s'\) of \(E\) factors through \(s\), that is, \(s' = s \gg r\) for some substitution \(r\), where \(s \gg r\) applies first \(s\) and then \(r\).

    def IsMGU (s : Subst C) (E : Equations C) : Prop :=
  Unifies s E ∧ ∀ s', Unifies s' E → ∃ r, s' = s ≫ r

    Cslib.Unification.unify

    The algorithm takes a list of equations between terms and returns a substitution or fails. On the empty list it returns the identity substitution. Otherwise it looks at the first equation \(t = u\) and the remaining list \(E\). If \(t\) and \(u\) are the same variable, or the same constant, the equation is dropped and the algorithm continues on \(E\); if they are two different constants, it fails. If \(t\) is a variable \(x\) and \(u \ne x\), or else \(u\) is a variable \(x\) and \(t\) is not a variable, let \(v\) be the other side: the algorithm fails when \(x\) occurs in \(v\), and otherwise substitutes \(v\) for \(x\) on both sides of every equation of \(E\) and unifies the result; if that returns \(s\), it returns the substitution that applies first the replacement of \(x\) by \(v\) and then \(s\), and if that fails, it fails. If \(t\) and \(u\) are nodes with children \(l_1, r_1\) and \(l_2, r_2\), it continues on the list \(l_1 = l_2\), \(r_1 = r_2\) followed by \(E\). If one side is a constant and the other a node, it fails.
