    Cslib.CTLStar.StateSat

    Satisfaction of a CTL* state formula at a state: E π holds when some infinite run from the state satisfies π; A π when every infinite run does.

    def StateSat (lts : _root_.Cslib.LTS State Label) (valuation : State → Atom → Prop) :
    StateFormula Atom → State → Prop
  | .atom a, s => valuation s a
  | .top, _ => True
  | .not φ, s => ¬ StateSat lts valuation φ s
