    DefinitionEvaluating a propositional formula at a letter#✓fully proved

    Cslib.LTL.PropFormula.eval

    A letter is a set \(s\) of atoms (the atoms true at it). A propositional formula is evaluated at \(s\) by recursion: an atom \(a\) is true iff \(a \in s\), truth \(\top\) is true, \(\neg\varphi\) is true iff \(\varphi\) is not, and \(\varphi \wedge \psi\) is true iff both \(\varphi\) and \(\psi\) are true.

    def eval : PropFormula Atom → Set Atom → Prop
  | .atom a, s => a ∈ s
  | .top, _ => True
  | .not φ, s => ¬ eval φ s
  | .and φ ψ, s => eval φ s ∧ eval ψ s

    Cslib.LTL.PropFormula.toLTL

    The translation of propositional formulas into LTL formulas is defined by recursion: an atom \(a\) goes to the LTL atom \(a\), truth goes to the LTL truth constant \(\top\), \(\neg\varphi\) goes to the LTL negation of the translation of \(\varphi\), and \(\varphi \wedge \psi\) goes to the LTL conjunction of the translations of \(\varphi\) and \(\psi\).

    The propositional automaton

    DefinitionBüchi automaton for a propositional formula#✓fully proved

    Cslib.LTL.propNa

    For a propositional formula \(\varphi\), this Büchi automaton over letters that are sets of atoms has a start state \(u\) and two verdict states \(t\) and \(f\), of which only \(t\) is accepting. From \(u\), on a letter \(s\) it moves to \(t\) if \(\varphi\) evaluates to true at \(s\) and to \(f\) otherwise; from \(t\) and from \(f\) it stays in the same state on every letter. So it records the verdict of \(\varphi\) on the first letter.

    def propNa (φ : PropFormula Atom) : Buchi (Option Bool) (Set Atom) where
  Tr p x q :=
    (∃ b, p = none ∧ q = some b ∧ ((b = true ∧ φ.eval x) ∨ (b = false ∧ ¬ φ.eval x))) ∨
      (∃ b, p = some b ∧ q = some b)
  start := {none}
  accept := {some true}

    The shift automaton

    DefinitionThe shift of a Büchi automaton#✓fully proved

    Cslib.LTL.shiftBuchi

    Let \(A\) be a Büchi automaton over the alphabet of sets of atoms. Its shift is the Büchi automaton whose states are the states of \(A\) together with one new state \(\bot\), whose only start state is \(\bot\), and whose accepting states are the accepting states of \(A\). Its transitions are exactly the following: on every letter, from \(\bot\) to each start state of \(A\); and on a letter \(x\), from a state \(q\) of \(A\) to a state \(q'\) of \(A\) whenever \(A\) has a transition from \(q\) to \(q'\) on \(x\).

    The shift accepts a word exactly when \(A\) accepts the word with its first letter removed.

    def shiftBuchi (a : Buchi State (Set Atom)) : Buchi (Option State) (Set Atom) where
  Tr p x q :=
    (∃ s, p = none ∧ q = some s ∧ s ∈ a.start) ∨
      (∃ s s', p = some s ∧ q = some s' ∧ a.Tr s x s')
  start := {none}
  accept := some '' a.accept

    The safety fragment

    InductiveThe restricted safety fragment of LTL#✓fully proved

    Cslib.LTL.Safety

    The safety formulas over a type of atoms are generated by the following rules: every propositional formula \(\varphi\) is a safety formula; if \(\psi\) and \(\rho\) are safety formulas, then so are \(\psi \wedge \rho\), \(\psi \vee \rho\) and \(X\,\psi\) (next \(\psi\)); and for every propositional formula \(\varphi\), \(G\,\varphi\) (always \(\varphi\)) is a safety formula.

    The operator \(G\) is applied only to propositional formulas: for atoms \(p\) and \(q\), the formula \(G(p \vee X\,q)\) is not in this fragment, since \(G\) does not distribute over \(\vee\).

    inductive Safety (Atom : Type*) where
  /-- A propositional formula, checked on the first letter. -/
  | prop (φ : PropFormula Atom) : Safety Atom
  /-- Conjunction. -/
  | and (ψ ρ : Safety Atom) : Safety Atom
  /-- Disjunction. -/
  | or (ψ ρ : Safety Atom) : Safety Atom
  /-- Next. -/
  | next (ψ : Safety Atom) : Safety Atom
  /-- `always` of a propositional formula. -/
  | alwaysProp (φ : PropFormula Atom) : Safety Atom

    DefinitionSafety formulas as LTL formulas#✓fully proved

    Cslib.LTL.Safety.toLTL

    The translation \(t\) of safety formulas into LTL formulas is defined by recursion: \(t(\varphi)\) is the LTL translation of \(\varphi\) for a propositional formula \(\varphi\); \(t(\psi \wedge \rho) = t(\psi) \wedge t(\rho)\); \(t(\psi \vee \rho) = \neg(\neg t(\psi) \wedge \neg t(\rho))\), the derived LTL disjunction; \(t(X\,\psi) = X\,t(\psi)\), where \(X\) is next; and \(t(G\,\varphi) = G\,t(\varphi)\) for a propositional formula \(\varphi\), where \(G\) is the derived LTL operator always.

    def toLTL : Safety Atom → Formula Atom
  | .prop φ => φ.toLTL
  | .and ψ ρ => .and ψ.toLTL ρ.toLTL

    Cslib.LTL.exists_buchi_of_safety

    Take as letters the sets of atoms, an atom \(a\) holding at a letter \(s\) iff \(a \in s\). For every formula \(\psi\) of the restricted safety fragment there is a nondeterministic Büchi automaton with finitely many states whose ω-language is exactly the set of infinite words satisfying \(\psi\), read as an LTL formula.

    The finite state set is what makes the automaton a certificate of ω-regularity: every ω-language is accepted by some Büchi automaton with infinitely many states. The fragment applies the always operator \(\mathbf{G}\) only to propositional formulas, so for example \(\mathbf{G}(p \vee \mathbf{X}\,q)\), for atoms \(p\) and \(q\) and the next operator \(\mathbf{X}\), is not covered.
