    InductiveFormulas of linear temporal logic#✓fully proved

    Cslib.LTL.Formula

    For a type \(A\) of atoms, the formulas of linear temporal logic (LTL) over \(A\) are generated inductively: every atom \(a \in A\) is a formula, the truth constant \(\top\) is a formula, and if \(\varphi\) and \(\psi\) are formulas then so are the negation \(\neg\varphi\), the conjunction \(\varphi \wedge \psi\), the next formula \(\mathbf{X}\,\varphi\) and the until formula \(\varphi \mathbin{\mathbf{U}} \psi\).

    inductive Formula (Atom : Type u) : Type u where
  | atom (a : Atom) : Formula Atom
  | top : Formula Atom
  | not (φ : Formula Atom) : Formula Atom
  | and (φ ψ : Formula Atom) : Formula Atom
  | next (φ : Formula Atom) : Formula Atom
  | until (φ ψ : Formula Atom) : Formula Atom
  deriving DecidableEq, Repr

    Cslib.LTL.Formula.release

    DefinitionSatisfaction of LTL formulas on ω-words#✓fully proved

    Cslib.LTL.Word.Satisfies

    Let \(v\) be a valuation that says which atoms are true at each letter, and for an ω-word \(w\) and a natural number \(k\) let \(w^{(k)}\) be the suffix \(i \mapsto w(k + i)\). Whether \(w\) satisfies an LTL formula \(\varphi\) under \(v\), written \(w \models \varphi\), is defined by recursion on \(\varphi\): an atom \(a\) holds when \(v\) makes \(a\) true at the first letter \(w(0)\); truth always holds; \(\neg \varphi\) holds when \(\varphi\) does not; \(\varphi \wedge \psi\) holds when both \(\varphi\) and \(\psi\) do; \(\mathsf{X}\, \varphi\) (next \(\varphi\)) holds when \(w^{(1)} \models \varphi\); and \(\varphi \mathbin{\mathsf{U}} \psi\) (\(\varphi\) until \(\psi\)) holds when there is a \(k\) with \(w^{(k)} \models \psi\) and \(w^{(j)} \models \varphi\) for all \(j < k\).

    def Satisfies (valuation : Symbol → Atom → Prop) (w : ωSequence Symbol) :
    Formula Atom → Prop
  | .atom a => valuation (w 0) a
  | .top => True
  | .not φ => ¬ Satisfies valuation w φ
  | .and φ ψ => Satisfies valuation w φ ∧ Satisfies valuation w ψ
  | .next φ => Satisfies valuation w.tail φ
  | .until φ ψ =>
      ∃ k, Satisfies valuation (w.drop k) ψ ∧ ∀ j < k, Satisfies valuation (w.drop j) φ
    inductive Formula (Atom : Type u) : Type u where
  | atom (a : Atom) : Formula Atom
  | top : Formula Atom
  | not (φ : Formula Atom) : Formula Atom
  | and (φ ψ : Formula Atom) : Formula Atom
  | next (φ : Formula Atom) : Formula Atom
  | until (φ ψ : Formula Atom) : Formula Atom
  deriving DecidableEq, Repr
