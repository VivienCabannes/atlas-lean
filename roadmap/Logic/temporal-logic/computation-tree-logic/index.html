    Cslib.CTL.Formula

    The formulas of computation tree logic over a type \(A\) of atoms are generated as follows: every atom \(a \in A\) is a formula, \(\top\) is a formula, and if \(\varphi\) and \(\psi\) are formulas then so are the negation \(\neg\varphi\), the conjunction \(\varphi \land \psi\), the existential next \(\mathsf{EX}\,\varphi\), the existential until \(\mathsf{E}[\varphi\,\mathsf{U}\,\psi]\), the existential globally \(\mathsf{EG}\,\varphi\) and the universal until \(\mathsf{A}[\varphi\,\mathsf{U}\,\psi]\).

    The universal until is primitive rather than the classical translation through \(\mathsf{EU}\) and \(\mathsf{EG}\), which is unsound on transition systems with deadlocked states.

    DefinitionSatisfaction of CTL formulas#✓fully proved

    Cslib.CTL.Satisfies

    Fix a labelled transition system and a valuation saying which atoms hold at which states. Satisfaction of a CTL formula at a state \(s\) is defined by recursion on the formula. An atom \(a\) holds at \(s\) when the valuation makes \(a\) true at \(s\); \(\top\) always holds; \(\neg\varphi\) holds when \(\varphi\) does not; \(\varphi \land \psi\) holds when both \(\varphi\) and \(\psi\) hold; \(\mathsf{EX}\,\varphi\) holds when there is a transition from \(s\), under some label, to a state satisfying \(\varphi\); \(\mathsf{E}[\varphi\,\mathsf{U}\,\psi]\) holds when some finite run \(s = s_0, s_1, \dots, s_k\) has \(\psi\) at \(s_k\) and \(\varphi\) at every \(s_j\) with \(j < k\); \(\mathsf{EG}\,\varphi\) holds when some infinite run \(s = s_0, s_1, \dots\) has \(\varphi\) at every state; and \(\mathsf{A}[\varphi\,\mathsf{U}\,\psi]\) holds when, first, every infinite run \(s = s_0, s_1, \dots\) has some \(k\) with \(\psi\) at \(s_k\) and \(\varphi\) at every \(s_j\) with \(j < k\), and second, every finite run \(s = s_0, s_1, \dots, s_k\) whose last state \(s_k\) has no outgoing transition under any label has some \(j \le k\) with \(\psi\) at \(s_j\) and \(\varphi\) at every \(s_i\) with \(i < j\).

    def Satisfies (lts : LTS State Label)
    (valuation : State → Atom → Prop) (state : State) :
    Formula Atom → Prop
  | .atom a => valuation state a
  | .top => True
  | .not φ => ¬Satisfies lts valuation state φ
  | .and φ ψ =>
      Satisfies lts valuation state φ ∧ Satisfies lts valuation state ψ
  | .existsNext φ =>
      ∃ label next, lts.Tr state label next ∧
        Satisfies lts valuation next φ
  | .existsUntil φ ψ =>
      ∃ ss k, ss 0 = state ∧ lts.FiniteRun ss k ∧
        Satisfies lts valuation (ss k) ψ ∧
          ∀ j, j < k → Satisfies lts valuation (ss j) φ
  | .existsGlobally φ =>
      ∃ ss, ss 0 = state ∧ lts.OmegaRun ss ∧
        ∀ i, Satisfies lts valuation (ss i) φ
  | .forallUntil φ ψ =>
      (∀ ss, ss 0 = state → lts.OmegaRun ss →
        ∃ k, Satisfies lts valuation (ss k) ψ ∧
          ∀ j, j < k → Satisfies lts valuation (ss j) φ) ∧
      (∀ ss k, ss 0 = state → lts.FiniteRun ss k →
        (∀ label t, ¬lts.Tr (ss k) label t) →
        ∃ j, j ≤ k ∧ Satisfies lts valuation (ss j) ψ ∧
          ∀ i, i < j → Satisfies lts valuation (ss i) φ)

    Cslib.CTL.Serial

    A labelled transition system is serial (total) when every state \(s\) has a successor: there are a label \(a\) and a state \(t\) with a transition from \(s\) to \(t\) labelled \(a\).

    A serial system has no deadlocked states, and every maximal path in it is infinite.

    def Serial (lts : LTS State Label) : Prop :=
  ∀ s, ∃ label t, lts.Tr s label t
