    Cslib.Modal.LinearMuCalculus.sat

    Satisfaction of a linear μ-calculus formula at a position of the word val. μ X. φ is the least pre-fixed point of S ↦ ⟦φ⟧[X ↦ S], stated directly as an infimum over pre-fixed points; ν X. φ is the greatest post-fixed point, stated as a supremum over post-fixed points.

    def sat (env : ℕ → ℕ → Prop) : LinearMuFormula Atom → (ℕ → Prop)
  | .atom a => fun n => val n a
  | .natom a => fun n => ¬ val n a
  | .var n => env n
  | .bot => fun _ => False
  | .top => fun _ => True
  | .and φ ψ => fun n => sat env φ n ∧ sat env ψ n
  | .or φ ψ => fun n => sat env φ n ∨ sat env ψ n
  | .next φ => fun n => sat env φ (n + 1)
  | .mu φ => fun n => ∀ S : ℕ → Prop,
      (∀ m, sat (extendEnv env S) φ m → S m) → S n
  | .nu φ => fun n => ∃ S : ℕ → Prop,
      (∀ m, S m → sat (extendEnv env S) φ m) ∧ S n
