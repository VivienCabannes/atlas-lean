    Cslib.CTL.exists_maximalPath

    In a labelled transition system, for every state \(s\) there is an infinite run \(s_0, s_1, s_2, \dots\) with \(s_0 = s\), or there are a sequence of states \(s_0, s_1, s_2, \dots\) with \(s_0 = s\) and a \(k\) such that \(s_0, \dots, s_k\) is a finite run of length \(k\) and \(s_k\) is deadlocked, that is, has no outgoing transition.

    The proof iterates a chosen successor function and uses the axiom of choice.

    theorem exists_maximalPath (s : State) :
    (∃ ss, ss 0 = s ∧ lts.OmegaRun ss) ∨
      (∃ ss k, ss 0 = s ∧ lts.FiniteRun ss k ∧
        ∀ label t, ¬lts.Tr (ss k) label t)

    Cslib.CTL.Satisfies.forallUntil_iff_not

    Let \(\varphi\) and \(\psi\) be CTL formulas, and write \(s \models \chi\) when the state \(s\) of a labelled transition system satisfies the formula \(\chi\) under a given valuation of the atoms. Then \(s \models \mathsf{A}[\varphi \mathbin{\mathsf{U}} \psi]\) if and only if neither \(s \models \mathsf{E}[\neg\psi \mathbin{\mathsf{U}} (\neg\psi \land (\neg\varphi \lor \neg\mathsf{EX}\,\top))]\) nor \(s \models \mathsf{EG}\,\neg\psi\).

    Here \(\neg\mathsf{EX}\,\top\) holds exactly at the deadlocked states, those with no outgoing transition. So \(\mathsf{A}[\varphi \mathbin{\mathsf{U}} \psi]\) fails at \(s\) exactly when some infinite run starting at \(s\) stays in \(\neg\psi\) forever, or some finite run starting at \(s\) stays in \(\neg\psi\) up to a \(\neg\psi\)-state at which \(\varphi\) fails or which is deadlocked.

    theorem forallUntil_iff_not {s : State} {φ ψ : Formula Atom} :
    Satisfies lts valuation s (.forallUntil φ ψ) ↔
      ¬(Satisfies lts valuation s
          (.existsUntil (.not ψ)
            (.and (.not ψ)
              (Formula.or (.not φ) (.not (.existsNext .top))))) ∨
        Satisfies lts valuation s (.existsGlobally (.not ψ)))

    Cslib.CTL.Satisfies.forallFinally_iff_not

    In a labelled transition system with a valuation of atoms, let \(\varphi\) be a CTL formula. A state \(s\) satisfies \(\mathsf{AF}\,\varphi\) if and only if \(s\) satisfies neither \(\mathsf{E}[\neg\varphi \,\mathsf{U}\, (\neg\varphi \wedge \neg\mathsf{EX}\,\top)]\) nor \(\mathsf{EG}\,\neg\varphi\).

    Cslib.CTL.Satisfies.existsUntilFun

    In a labelled transition system with a valuation of atoms, let \(\varphi\) and \(\psi\) be CTL formulas.     Cslib.CTL.Satisfies.existsUntil_eq_lfp

    In a labelled transition system with a valuation of atoms, let \(\varphi\) and \(\psi\) be CTL formulas, write \(\mathrm{Sat}(\chi)\) for the set of states satisfying a formula \(\chi\), and write \(\mathrm{Pre}_\exists(Z)\) for the set of states having a transition into a set \(Z\) of states.       (existsUntilOrderHom lts valuation φ ψ).lfp
