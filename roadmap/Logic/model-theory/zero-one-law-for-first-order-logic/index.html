    Zero-one law for first-order logic

    For a finite relational vocabulary with no nullary relation symbol, every first-order sentence is almost surely true or almost surely false on labelled finite structures: the proportion of structures on \(\{1, \dots, n\}\) satisfying it tends to \(0\) or \(1\) (Glebskii, Kogan, Liogon'kii and Talanov 1969; Fagin 1976). The law fails for existential second-order logic (parity of the domain size is definable there), even for its monadic fragment.

    If a first-order language \(L\) has no function symbols and finitely many relation symbols, there are finitely many \(L\)-structures on any finite set: a structure is determined by one relation \(R^M \subseteq M^k\) for each relation symbol \(R\) of arity \(k\).

    FirstOrder.Language.satFraction

    For a first-order sentence \(\varphi\) over \(L\) and \(n \in \mathbb{N}\), $\(\mu_n(\varphi) = \frac{|\{M \text{ an } L\text{-structure on } \{1, \dots, n\} : M \models \varphi\}|}{|\{M \text{ an } L\text{-structure on } \{1, \dots, n\}\}|}.\)$ Structures are labelled: two isomorphic structures on \(\{1, \dots, n\}\) count separately, so \(\mu_n\) is the probability that \(\varphi\) holds in a uniformly random structure on \(n\) labelled elements. For a relational language with finitely many symbols both counts are finite and the denominator is positive.

    noncomputable def satFraction (φ : L.Sentence) (n : ℕ) : ℝ :=
  (Set.ncard {S : L.Structure (Fin n) | @Sentence.Realize L (Fin n) S φ} : ℝ) /
    Nat.card (L.Structure (Fin n))

    FirstOrder.Language.satFraction_not

    For a relational language with finitely many symbols, \(\mu_n(\neg\varphi) = 1 - \mu_n(\varphi)\) for every sentence \(\varphi\) and every \(n\). In particular \(\mu_n(\varphi) \to 0\) iff \(\mu_n(\neg\varphi) \to 1\).

    theorem satFraction_not [L.IsRelational] [Finite L.Symbols] (φ : L.Sentence) (n : ℕ) :
    L.satFraction (∼φ) n = 1 - L.satFraction φ n

    TheoremZero-one law for first-order logic#●ready to prove

    MathlibExt.ModelTheory.ZeroOneLawWanted.zero_one_law

    Let \(L\) be a first-order language with no function or constant symbols, finitely many relation symbols, and no relation symbol of arity \(0\). For every first-order sentence \(\varphi\) over \(L\) (with equality), the proportion \(\mu_n(\varphi)\) of \(L\)-structures on \(\{1, \dots, n\}\) that satisfy \(\varphi\) converges, and its limit is \(0\) or \(1\).

    This is a statement whose proof is deferred (theorem_wanted). The hypothesis that no relation symbol is nullary is part of the classical setting and is necessary: a nullary symbol \(P\) is a propositional constant, true in exactly half of the structures on every domain, so \(\mu_n(P) = 1/2\) for all \(n\).

    The classical proof considers the extension axioms: for each pair of finite configurations, the sentence saying that every copy of the smaller one extends to a copy of the larger one. Each extension axiom has probability tending to \(1\); the theory they axiomatize has no finite models and is \(\aleph_0\)-categorical (its countable model is the random structure), hence complete; so every sentence or its negation follows from finitely many extension axioms, and has probability tending to \(1\). The same argument decides the limit, in contrast with Trakhtenbrot's theorem that validity on all finite structures is undecidable as soon as the vocabulary has a binary relation symbol. The law fails for existential second-order logic, since the parity of the domain size is definable there.

    theorem_wanted zero_one_law (L : Language) [L.IsRelational] [IsEmpty (L.Relations 0)]
    [Finite L.Symbols] (φ : L.Sentence) :
    Tendsto (L.satFraction φ) atTop (𝓝 0) ∨ Tendsto (L.satFraction φ) atTop (𝓝 1)
