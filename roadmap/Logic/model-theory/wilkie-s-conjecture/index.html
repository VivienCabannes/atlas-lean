    DefinitionPoints of bounded degree and height#✓fully proved

    MathlibExt.ModelTheory.WilkiesConjectureWanted.WilkiesConjecture.degreeHeightLE

    For a set \(X \subseteq \mathbb{R}^n\) and natural numbers \(g\) and \(H\), the set \(X(g, H)\) consists of the points \(x = (x_1, \dots, x_n) \in X\) whose coordinates are all algebraic over \(\mathbb{Q}\), such that the field \(\mathbb{Q}(x) = \mathbb{Q}(x_1, \dots, x_n)\) satisfies \([\mathbb{Q}(x) : \mathbb{Q}] \le g\) and the height \(H(x)\) of \(x\), the maximum of the absolute multiplicative Weil heights of \(x_1, \dots, x_n\) (taken to be \(0\) when \(n = 0\)), satisfies \(H(x) \le H\).

    def degreeHeightLE (X : Set ℝⁿ) (g H : ℕ) : Set ℝⁿ :=
  { x ∈ X | (∀ i, IsAlgebraic ℚ (x i)) ∧
    Module.finrank ℚ (IntermediateField.adjoin ℚ (Set.range x)) ≤ g ∧ height x ≤ H }
    def height (a : ℝⁿ) : ℝ := ⨆ i, NumberField.absMulHeight₁ (a i)

    TheoremWilkie's conjecture for the real exponential field#●ready to prove

    MathlibExt.ModelTheory.WilkiesConjectureWanted.WilkiesConjecture.corollary_1

    Let \(X \subseteq \mathbb{R}^n\) be definable in \(\mathbb{R}_{\exp}\). Then there is a polynomial \(f\) in two variables with real coefficients such that the following holds for all natural numbers \(g\) and \(H\). Let \(X^{\mathrm{trans}}(g, H)\) be the set of points \(x = (x_1, \dots, x_n)\) of the transcendental part \(X^{\mathrm{trans}}\) of \(X\) whose coordinates are all algebraic over \(\mathbb{Q}\), such that the field \(\mathbb{Q}(x) = \mathbb{Q}(x_1, \dots, x_n)\) satisfies \([\mathbb{Q}(x) : \mathbb{Q}] \le g\) and the height \(H(x)\) of \(x\), the maximum of the absolute multiplicative Weil heights of \(x_1, \dots, x_n\) (taken to be \(0\) when \(n = 0\)), satisfies \(H(x) \le H\). Then \(X^{\mathrm{trans}}(g, H)\) is finite and has at most \(f(g, \log H)\) elements, where \(\log 0\) is taken to be \(0\).

    This is Corollary 1 of the source.

    public theorem_wanted corollary_1 (X : Set ℝⁿ) (h : IsRExpDefinable X) :
    ∃ f : MvPolynomial (Fin 2) ℝ, ∀ (g H : ℕ),

        Nat.card (degreeHeightLE (transPart X) g H) ≤ f.eval ![(g : ℝ), Real.log H]
