    Cslib.Logic.PL.BDD.eval

    Under an assignment \(\sigma\) of a Boolean value to each variable \(v \in \mathbb{N}\), the value of a leaf is its Boolean value, and the value of a node testing \(v\) is the value of its high child if \(\sigma(v)\) is true and the value of its low child if \(\sigma(v)\) is false.

    DefinitionDiagrams ordered from a variable#✓fully proved

    Cslib.Logic.PL.BDD.OrderedFrom

    For a natural number \(n\), a diagram is ordered from \(n\) when every variable it tests is at least \(n\) and the tested variables strictly increase along every path. Recursively: every leaf is ordered from \(n\), and the node testing \(v\) with children \(\ell\) and \(h\) is ordered from \(n\) when \(n \le v\) and both \(\ell\) and \(h\) are ordered from \(v + 1\).

    def OrderedFrom : Nat → BDD → Prop
  | _, leaf _ => True
  | n, node v lo hi => n ≤ v ∧ OrderedFrom (v + 1) lo ∧ OrderedFrom (v + 1) hi
    inductive BDD where
  | leaf (b : Bool)
  | node (v : Nat) (lo hi : BDD)
  deriving DecidableEq, Repr

    DefinitionBryant's apply operation#✓fully proved

    Cslib.Logic.PL.BDD.apply

    For a binary Boolean operation \(\mathrm{op}\) and binary decision diagrams \(t_1, t_2\), the diagram \(A_{\mathrm{op}}(t_1, t_2)\) is defined by recursion. If \(t_1\) and \(t_2\) are leaves with values \(a\) and \(b\), it is the leaf with value \(\mathrm{op}(a, b)\). Otherwise let \(v\) be the smallest variable tested at the root of \(t_1\) or of \(t_2\) (a leaf tests none), and for \(i = 1, 2\) let \(\ell_i\) and \(h_i\) be the low and high children of \(t_i\) if its root tests \(v\), and \(\ell_i = h_i = t_i\) otherwise. The result is \(\mathrm{mk}(v, A_{\mathrm{op}}(\ell_1, \ell_2), A_{\mathrm{op}}(h_1, h_2))\), where \(\mathrm{mk}(v, \ell, h)\) is \(\ell\) if \(\ell = h\), and otherwise the node testing \(v\) with low child \(\ell\) and high child \(h\).

    def apply (op : Bool → Bool → Bool) : BDD → BDD → BDD
  | leaf a, leaf b => leaf (op a b)
  | leaf a, node w lo hi => mk w (apply op (leaf a) lo) (apply op (leaf a) hi)
  | node v lo hi, leaf b => mk v (apply op lo (leaf b)) (apply op hi (leaf b))
  | node v lo hi, node w lo' hi' =>
    if v = w then mk v (apply op lo lo') (apply op hi hi')
    else if v < w then mk v (apply op lo (node w lo' hi')) (apply op hi (node w lo' hi'))
    else mk w (apply op (node v lo hi) lo') (apply op (node v lo hi) hi')
    inductive BDD where
  | leaf (b : Bool)
  | node (v : Nat) (lo hi : BDD)
  deriving DecidableEq, Repr

    Cslib.Logic.PL.BDD.ofProposition_ne_leaf_false_iff

    For a proposition \(A\) over natural-number atoms, the binary decision diagram of \(A\) is not the leaf false if and only if some valuation \(\sigma : \mathbb{N} \to \mathrm{Bool}\) makes \(A\) true.
