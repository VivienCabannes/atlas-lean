    DefinitionImplication edge#✓fully proved

    Cslib.Algorithms.SAT.TwoSAT.ImpEdge

    For a CNF formula \(\varphi\) and literals \(l\) and \(m\), there is an implication edge from \(l\) to \(m\) when some clause of \(\varphi\) contains both \(\neg l\) and \(m\), either as two different literals or with \(m\) as its only literal (so a unit clause \(m\) gives the edge from \(\neg m\) to \(m\)).

    def ImpEdge (φ : CNF) (l m : Nat × Bool) : Prop :=
  ∃ C ∈ φ, neg l ∈ C ∧ m ∈ C ∧ (neg l ≠ m ∨ ∀ c ∈ C, c = m)

    A clause \(C\) satisfies the invariant with respect to a CNF formula \(\varphi\) when for every literal \(a\) of \(C\) there is a literal \(b\) of \(C\) such that the complementary literal \(\lnot a\) reaches \(b\) in the implication graph of \(\varphi\) (by a path of zero or more edges).
