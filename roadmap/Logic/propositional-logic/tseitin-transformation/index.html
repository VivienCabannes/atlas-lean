    DefinitionOne step of the Tseitin encoding#✓fully proved

    Cslib.Algorithms.SAT.Tseitin.tseitinStep

    Given a rule \(\mathit{cl}\) assigning to literals \(g\), \(a\), \(b\) a list of defining clauses, and the results \((a, C_A, k_A)\) and \((b, C_B, k_B)\) of encoding the two operands of a binary connective (each a literal, a clause list and a next unused gate number), the step returns the positive literal \(g\) of variable \(2k_B+1\), the clause list \(C_A\), then \(C_B\), then \(\mathit{cl}(g, a, b)\), and the next gate number \(k_B+1\).

    def tseitinStep (cl : Nat × Bool → Nat × Bool → Nat × Bool → CNF)
    (ra rb : (Nat × Bool) × CNF × ℕ) : (Nat × Bool) × CNF × ℕ :=
  ((2 * rb.2.2 + 1, true), ra.2.1 ++ rb.2.1 ++ cl (2 * rb.2.2 + 1, true) ra.1 rb.1,
    rb.2.2 + 1)
    abbrev CNF := List CNFClause

    DefinitionOne step of the linear-time Tseitin builder#✓fully proved

    Cslib.Algorithms.SAT.Tseitin.accStep

    Let \(c\) map a gate literal and two operand literals to a list of clauses, and let \((a, \varphi_A, k_A)\) and \((b, \varphi_B, k_B)\) be the results for the two operands, each a literal, a clause list and a next free gate number. The step returns the positive literal \(g\) of the variable \(2k_B + 1\), the clause list \(c(g, a, b)\) followed by \(\varphi_B\), and the next free gate number \(k_B + 1\). Neither \(\varphi_A\) nor \(k_A\) is used: in the builder, \(\varphi_B\) is the accumulator, which already holds both operands' clauses.

    def accStep (cl : Nat × Bool → Nat × Bool → Nat × Bool → CNF)
    (ra rb : (Nat × Bool) × CNF × ℕ) : (Nat × Bool) × CNF × ℕ :=
  ((2 * rb.2.2 + 1, true), cl (2 * rb.2.2 + 1, true) ra.1 rb.1 ++ rb.2.1, rb.2.2 + 1)
    abbrev CNF := List CNFClause

    DefinitionConnective count of a propositional formula#✓fully proved

    Cslib.Logic.PL.Proposition.connectiveCount

    For a propositional formula \(A\), built from atoms with the binary connectives \(\wedge\), \(\vee\) and \(\to\), the connective count of \(A\) is the number of occurrences of these connectives in \(A\). It is \(0\) for an atom, and for \(B \circ C\), with \(\circ\) one of \(\wedge\), \(\vee\) and \(\to\), it is the count of \(B\) plus the count of \(C\) plus \(1\).

    def connectiveCount : Proposition Atom → ℕ
  | atom _ => 0
  | and A B => A.connectiveCount + B.connectiveCount + 1
  | or A B => A.connectiveCount + B.connectiveCount + 1
  | imp A B => A.connectiveCount + B.connectiveCount + 1

    DefinitionTseitin encoding with gates numbered from \(k\)#✓fully proved

    Cslib.Logic.PL.Proposition.tseitinAux

    Fix a map \(\iota\) from atoms to natural numbers. Given a formula \(A\) and a gate number \(k\), the encoding returns a literal naming \(A\), a list of defining clauses and the next unused gate number. For an atom \(a\) it returns the positive literal of variable \(2\iota(a)\), no clauses, and \(k\). For \(A \circ B\) with \(\circ\) one of \(\wedge\), \(\vee\), \(\to\), it encodes \(A\) from gate \(k\), obtaining a literal \(a\), clauses \(C_A\) and a gate number \(k'\), then \(B\) from gate \(k'\), obtaining \(b\), \(C_B\) and \(k''\); it returns the positive literal \(g\) of variable \(2k''+1\), the clauses \(C_A\), then \(C_B\), then the three defining clauses of \(g\) for \(a \circ b\), and \(k''+1\).

    Its list concatenations make it quadratic; the Tseitin CNF is computed by a linear-time builder that produces the same clauses in another order.

    def tseitinAux (ι : Atom → ℕ) : Proposition Atom → ℕ → (Nat × Bool) × CNF × ℕ
  | atom a, k => ((2 * ι a, true), [], k)
  | and A B, k =>
    let ra := tseitinAux ι A k
    tseitinStep andClauses ra (tseitinAux ι B ra.2.2)
  | or A B, k =>
    let ra := tseitinAux ι A k
    tseitinStep orClauses ra (tseitinAux ι B ra.2.2)
  | imp A B, k =>
    let ra := tseitinAux ι A k
    tseitinStep impClauses ra (tseitinAux ι B ra.2.2)
    abbrev CNF := List CNFClause

    DefinitionLinear-time Tseitin builder#✓fully proved

    Cslib.Logic.PL.Proposition.tseitinAcc

    Fix a map \(\iota\) from atoms to natural numbers. Given a formula \(A\), a gate number \(k\) and a clause list \(\mathit{acc}\), the builder returns a literal naming \(A\), a clause list and the next unused gate number. For an atom \(a\) it returns the positive literal of variable \(2\iota(a)\), the list \(\mathit{acc}\) unchanged, and \(k\). For \(A \circ B\) with \(\circ\) one of \(\wedge\), \(\vee\), \(\to\), it runs on \(A\) from gate \(k\) with accumulator \(\mathit{acc}\), obtaining a literal \(a\), a list \(L_A\) and a gate number \(k'\), then on \(B\) from gate \(k'\) with accumulator \(L_A\), obtaining \(b\), \(L_B\) and \(k''\); it returns the positive literal \(g\) of variable \(2k''+1\), the three defining clauses of \(g\) for \(a \circ b\) followed by \(L_B\), and \(k''+1\).

    Unlike the reference Tseitin encoding, which concatenates the operands' clause lists, it prepends each gate's clauses to the accumulator, so it runs in linear time and the clauses come out in a different order.

    def tseitinAcc (ι : Atom → ℕ) : Proposition Atom → ℕ → CNF → (Nat × Bool) × CNF × ℕ
  | atom a, k, acc => ((2 * ι a, true), acc, k)
  | and A B, k, acc =>
    let ra := tseitinAcc ι A k acc
    accStep andClauses ra (tseitinAcc ι B ra.2.2 ra.2.1)
  | or A B, k, acc =>
    let ra := tseitinAcc ι A k acc
    accStep orClauses ra (tseitinAcc ι B ra.2.2 ra.2.1)
  | imp A B, k, acc =>
    let ra := tseitinAcc ι A k acc
    accStep impClauses ra (tseitinAcc ι B ra.2.2 ra.2.1)
    abbrev CNF := List CNFClause

    TheoremThe linear-time Tseitin builder agrees with the reference encoding#✓fully proved

    Cslib.Logic.PL.Proposition.tseitinAcc_eq

    For every map \(\iota\) from atoms to natural numbers, every formula \(A\), every gate number \(k\) and every clause list \(\mathit{acc}\), the linear-time Tseitin builder run on \(A\) from gate \(k\) with accumulator \(\mathit{acc}\) returns the same literal naming \(A\) and the same next unused gate number as the reference Tseitin encoding of \(A\) with gates numbered from \(k\), and its clause list is \(X\) followed by \(\mathit{acc}\) for some list of clauses \(X\) that is a permutation of the defining clauses of the reference encoding.

    theorem tseitinAcc_eq (ι : Atom → ℕ) (A : Proposition Atom) (k : ℕ) (acc : CNF) :
    ∃ X : CNF, X.Perm (tseitinAux ι A k).2.1 ∧
      tseitinAcc ι A k acc = ((tseitinAux ι A k).1, X ++ acc, (tseitinAux ι A k).2.2)
    abbrev CNF := List CNFClause
