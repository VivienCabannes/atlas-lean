    DefinitionDavis-Putnam elimination of a variable#✓fully proved

    Cslib.Logic.PL.CNF.eliminate

    Eliminating a variable \(x\) from a CNF formula \(\varphi\) gives the formula consisting of the clauses of \(\varphi\) that contain neither \(x\) nor \(\neg x\), followed by the resolvents on \(x\) of \(C\) and \(D\), for every clause \(C\) of \(\varphi\) that contains \(x\) but not \(\neg x\) and every clause \(D\) of \(\varphi\) that contains \(\neg x\) but not \(x\). Clauses containing both \(x\) and \(\neg x\) are dropped.

    def eliminate (x : Nat) (φ : CNF) : CNF :=
  let neg := negClauses x φ
  φ.filter (fun C ↦ (x, true) ∉ C ∧ (x, false) ∉ C) ++
    (posClauses x φ).flatMap fun C ↦ neg.map fun D ↦ CNFClause.resolvent x C D
    abbrev CNF := List CNFClause

    TheoremResolvents do not mention the resolved variable#✓fully proved

    Cslib.Logic.PL.CNF.fst_ne_of_mem_resolvent

    Let \(x\) be a variable and let \(C\) and \(D\) be clauses such that \(C\) does not contain \(\neg x\) and \(D\) does not contain \(x\). Then no literal of the resolvent of \(C\) and \(D\) on \(x\) has variable \(x\).

    In particular, the resolvents added when eliminating \(x\) do not mention \(x\).

    theorem fst_ne_of_mem_resolvent {x : Nat} {C D : CNFClause} (hC : (x, false) ∉ C)
    (hD : (x, true) ∉ D) {l : Nat × Bool} (hl : l ∈ CNFClause.resolvent x C D) : l.1 ≠ x
    abbrev CNFClause := List (Nat × Bool)

    DefinitionVariable list for Davis–Putnam elimination#✓fully proved

    Cslib.Logic.PL.CNF.varList

    For a CNF formula \(\varphi\), the list of the variables occurring in the literals of \(\varphi\), each listed exactly once, in order of first occurrence when the clauses of \(\varphi\), and the literals within each clause, are read from left to right.

    Removing the repetitions takes time quadratic in the number of literal occurrences, which the eliminations dominate.

    def varList (φ : CNF) : List Nat := (φ.flatMap (List.map Prod.fst)).eraseDups
    abbrev CNF := List CNFClause

    DefinitionThe Davis-Putnam procedure#✓fully proved

    Cslib.Logic.PL.CNF.davisPutnam

    Given a CNF formula \(\varphi\), eliminate the variables that occur in \(\varphi\) one after another, each exactly once, in the order of their first occurrence in \(\varphi\), each elimination being applied to the result of the previous one. The procedure returns true if the resulting formula does not contain the empty clause, and false if it does.

    def davisPutnam (φ : CNF) : Bool := decide ([] ∉ eliminateAll (varList φ) φ)
    abbrev CNF := List CNFClause
