    Cslib.Logic.PL.CNFSat

    A CNF formula \(\varphi\) is satisfiable when there is an assignment \(v : \mathbb{N} \to \{\mathrm{true}, \mathrm{false}\}\) such that every clause \(C\) of \(\varphi\) contains a literal \((x, b)\) with \(v(x) = b\).

    def CNFSat (φ : CNF) : Prop :=
  ∃ v : Nat → Bool, ∀ C ∈ φ, ∃ (x : Nat) (b : Bool), (x, b) ∈ C ∧ v x = b

    Given a literal \(\ell = (x, b)\), the restriction of a CNF formula \(\varphi\) by \(\ell\) is obtained by deleting every clause of \(\varphi\) that contains \(\ell\) and replacing every other clause by its restriction by \(\ell\), the clause obtained by deleting every literal whose variable is \(x\), of either polarity; the remaining clauses keep their order.

    The deleted clauses are true under every assignment that gives \(x\) the value \(b\).

    def restrict (literal : Nat × Bool) : CNF → CNF
  | [] => []
  | clause :: formula =>
      if literal ∈ clause then
        restrict literal formula
      else
        clause.restrict literal :: restrict literal formula
