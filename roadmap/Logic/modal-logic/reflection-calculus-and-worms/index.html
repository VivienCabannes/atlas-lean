    Reflection calculus and worms

    Japaridze's polymodal provability logic GLP has a box \([n]\) for each natural number \(n\); in its arithmetical interpretation \(\langle n \rangle\varphi\) is the \(n\)-consistency of \(\mathrm{PA} + \varphi\), equivalently the uniform reflection principle for \(\Pi_{n+1}\)-sentences. GLP is decidable and arithmetically complete but has no adequate Kripke semantics. Beklemishev's Reflection Calculus RC keeps only the strictly positive fragment: formulas built from atoms and \(\top\) by \(\wedge\) and the diamonds \(\langle n \rangle\), and sequents \(A \vdash B\) between them. RC axiomatizes the strictly positive fragment of GLP (Dashkov), is complete for a natural class of Kripke frames, and is decidable in polynomial time, yet it retains the proof-theoretic applications of GLP.

    The closed conjunction-free formulas, the worms \(\langle n_1 \rangle \cdots \langle n_k \rangle\top\), ordered by \(\alpha <_0 \beta\) iff \(\beta \vdash \langle 0 \rangle\alpha\), form an ordinal notation system of order type \(\varepsilon_0\). With the reduction property of reflection principles this gives Beklemishev's analysis of Peano arithmetic: transfinite induction along \(<_0\) proves \(\mathrm{Con}(\mathrm{PA})\), PA is \(\Pi^0_{n+1}\)-conservatively equivalent to iterated reflection along \(\varepsilon_0\), and the combinatorial "Every Worm Dies" principle is independent of PA. The proved part here is the calculus, positive replacement, closure under substitution, Kripke soundness and the first facts about worms; completeness and the order type \(\varepsilon_0\) are wanted statements.

    Sources: L. D. Beklemishev, "Positive provability logic for uniform reflection principles", arXiv:1304.4396v3 (2013), Annals of Pure and Applied Logic 165 (2014); L. D. Beklemishev, "Provability algebras: an overview and current progress", slides, 2012.

    Cslib.Modal.RC.Formula

    The strictly positive formulas of the Reflection Calculus are generated by $\(A ::= p \mid \top \mid A \wedge A \mid \langle n \rangle A \qquad (n \in \mathbb{N}),\)$ with \(p\) ranging over atoms. There is no negation, disjunction or box. The source also allows a modality \(\omega\) (full uniform reflection); it is omitted here.

    inductive Formula (Atom : Type u) : Type u where
  /-- An atom. -/
  | atom : Atom → Formula Atom
  /-- Truth `⊤`. -/
  | top : Formula Atom
  /-- Conjunction. -/
  | and : Formula Atom → Formula Atom → Formula Atom
  /-- The diamond `⟨n⟩`. -/
  | dia : ℕ → Formula Atom → Formula Atom

    InductiveThe Reflection Calculus RC#✓fully proved

    Cslib.Modal.RC.Derives

    RC derives sequents \(A \vdash B\) between strictly positive formulas from the axioms and rules

    1. \(A \vdash A\); \(A \vdash \top\); from \(A \vdash B\) and \(B \vdash C\) infer \(A \vdash C\);
    2. \(A \wedge B \vdash A\); \(A \wedge B \vdash B\); from \(A \vdash B\) and \(A \vdash C\) infer \(A \vdash B \wedge C\);
    3. from \(A \vdash B\) infer \(\langle n \rangle A \vdash \langle n \rangle B\); \(\langle n \rangle\langle n \rangle A \vdash \langle n \rangle A\);
    4. \(\langle m \rangle\langle n \rangle A \vdash \langle n \rangle A\) and \(\langle n \rangle\langle m \rangle A \vdash \langle n \rangle A\) for \(m \ge n\);
    5. \(\langle m \rangle A \wedge \langle n \rangle B \vdash \langle m \rangle(A \wedge \langle n \rangle B)\) for \(m > n\);
    6. \(\langle m \rangle A \vdash \langle n \rangle A\) for \(m > n\) (monotonicity).

    Axioms 1–5 form the system RJ; axiom 6 makes it RC. Axioms 4 follow from axioms 3 and 6. The modalities range over \(\mathbb{N}\) (the source's \(\mathrm{RC}_S\) with \(S = \mathbb{N}\)). Dashkov showed that RC axiomatizes exactly the sequents \(A \vdash B\) with \(\mathrm{GLP} \vdash A \to B\).

    inductive Derives : Formula Atom → Formula Atom → Prop
  /-- Axiom 1: `A ⊢ A`. -/
  | refl (A : Formula Atom) : Derives A A
  /-- Axiom 1: `A ⊢ ⊤`. -/
  | top (A : Formula Atom) : Derives A .top
  /-- Rule 1 (syllogism). -/
  | trans {A B C : Formula Atom} : Derives A B → Derives B C → Derives A C
  /-- Axiom 2: `A ∧ B ⊢ A`. -/
  | and_left (A B : Formula Atom) : Derives (.and A B) A
  /-- Axiom 2: `A ∧ B ⊢ B`. -/
  | and_right (A B : Formula Atom) : Derives (.and A B) B
  /-- Rule 2: from `A ⊢ B` and `A ⊢ C` infer `A ⊢ B ∧ C`. -/
  | and_intro {A B C : Formula Atom} : Derives A B → Derives A C → Derives A (.and B C)
  /-- Rule 3: from `A ⊢ B` infer `⟨n⟩A ⊢ ⟨n⟩B`. -/
  | dia_mono (n : ℕ) {A B : Formula Atom} : Derives A B → Derives (.dia n A) (.dia n B)
  /-- Axiom 3: `⟨n⟩⟨n⟩A ⊢ ⟨n⟩A`. -/
  | dia_dia (n : ℕ) (A : Formula Atom) : Derives (.dia n (.dia n A)) (.dia n A)
  /-- Axiom 4: `⟨m⟩⟨n⟩A ⊢ ⟨n⟩A` for `m ≥ n`. -/
  | dia_dia_of_le {m n : ℕ} (h : n ≤ m) (A : Formula Atom) :
      Derives (.dia m (.dia n A)) (.dia n A)
  /-- Axiom 4: `⟨n⟩⟨m⟩A ⊢ ⟨n⟩A` for `m ≥ n`. -/
  | dia_dia_of_le' {m n : ℕ} (h : n ≤ m) (A : Formula Atom) :
      Derives (.dia n (.dia m A)) (.dia n A)
  /-- Axiom 5: `⟨m⟩A ∧ ⟨n⟩B ⊢ ⟨m⟩(A ∧ ⟨n⟩B)` for `m > n`. -/
  | dia_and {m n : ℕ} (h : n < m) (A B : Formula Atom) :
      Derives (.and (.dia m A) (.dia n B)) (.dia m (.and A (.dia n B)))
  /-- Axiom 6 (monotonicity): `⟨m⟩A ⊢ ⟨n⟩A` for `m > n`. -/
  | monotone {m n : ℕ} (h : n < m) (A : Formula Atom) : Derives (.dia m A) (.dia n A)

    Cslib.Modal.RC.Formula.subst

    For strictly positive formulas \(C\) and \(A\) and an atom \(p\), \(C[A/p]\) replaces every occurrence of \(p\) in \(C\) by \(A\). The result is again strictly positive.

    def Formula.subst : Formula Atom → Atom → Formula Atom → Formula Atom
  | .atom q, p, A => if q = p then A else .atom q
  | .top, _, _ => .top
  | .and B C, p, A => .and (B.subst p A) (C.subst p A)
  | .dia n B, p, A => .dia n (B.subst p A)

    Kripke semantics

    StructureRC-frame#✓fully proved

    Cslib.Modal.RC.IsFrame

    A family of relations \((R_n)_{n \in \mathbb{N}}\) on a set \(W\) is an RC-frame when, for all \(x, y, z \in W\) and \(m, n \in \mathbb{N}\):

    • polytransitivity: \(x R_m y R_n z\) implies \(x R_{\min(m,n)} z\);
    • condition (J): \(x R_m y\) and \(x R_n z\) with \(m > n\) imply \(y R_n z\);
    • monotonicity: \(R_m \subseteq R_n\) for \(n < m\).

    Polytransitivity and (J) define RJ-frames. Each \(R_n\) is transitive.

    structure IsFrame {World : Type v} (R : ℕ → World → World → Prop) : Prop where
  /-- Polytransitivity. -/
  polytrans : ∀ {m n : ℕ} {x y z : World}, R m x y → R n y z → R (min m n) x z
  /-- Condition (J). -/
  condJ : ∀ {m n : ℕ} {x y z : World}, n < m → R m x y → R n x z → R n y z
  /-- Monotonicity. -/
  monotone : ∀ {m n : ℕ} {x y : World}, n < m → R m x y → R n x y

    DefinitionTruth of a strictly positive formula in a Kripke model#✓fully proved

    Cslib.Modal.RC.Satisfies

    In a Kripke model with relations \((R_n)\) and valuation \(V\): \(x \Vdash p\) iff \(p \in V(x)\); \(x \Vdash \top\) always; \(x \Vdash A \wedge B\) iff \(x \Vdash A\) and \(x \Vdash B\); and \(x \Vdash \langle n \rangle A\) iff some \(y\) with \(x R_n y\) satisfies \(A\). A sequent \(A \vdash B\) is true in the model when every world satisfying \(A\) satisfies \(B\).

    def Satisfies {World : Type v} (R : ℕ → World → World → Prop) (V : World → Atom → Prop) :
    World → Formula Atom → Prop
  | x, .atom p => V x p
  | _, .top => True
  | x, .and A B => Satisfies R V x A ∧ Satisfies R V x B
  | x, .dia n A => ∃ y, R n x y ∧ Satisfies R V y A

    Cslib.Modal.RC.Derives.sound

    If \(A \vdash B\) is derivable in RC, then \(A \vdash B\) is true in every Kripke model on an RC-frame.

    Proof: induction on the derivation. Axiom 3 and axioms 4 follow from polytransitivity, axiom 5 from condition (J) and axiom 6 from monotonicity.

    Cslib.Modal.RC.WormLt

    Cslib.Modal.RC.WormLt.replicate_zero_one

    For every \(k\), \(\langle 1 \rangle\top \vdash \langle 0 \rangle\langle 0 \rangle^k\top\) in RC, that is \(0^k <_0 1\). In the ordinal assignment of worms, \(0^k\) has value \(k\) and \(1\) has value \(\omega\).

    Cslib.Modal.RC.exists_wormOrdinal

    There is a map \(o\) from worms to ordinals such that two worms are RC-equivalent iff they have the same value, \(\alpha <_0 \beta\) iff \(o(\alpha) < o(\beta)\), and the values are exactly the ordinals below \(\varepsilon_0\). Equivalently, worms modulo RC-equivalence, ordered by \(<_0\), are order-isomorphic to \((\varepsilon_0, <)\). The value is computed recursively: \(o(0^k) = k\); otherwise, if \(\alpha = \alpha_1 0 \alpha_2 0 \cdots 0 \alpha_n\) with each \(\alpha_i\) free of \(0\), then \(o(\alpha) = \omega^{o(\alpha_n^-)} + \cdots + \omega^{o(\alpha_1^-)}\), where \(\alpha^-\) lowers every letter by one.

    Wanted statement (no proof in the library yet). The slides state it for GLP; the RC form follows by Dashkov's theorem. The instance \(0^k <_0 1\) is proved.
