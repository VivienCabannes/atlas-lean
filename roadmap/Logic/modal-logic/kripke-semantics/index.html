    Cslib.Modal.Formula

    For a type \(\alpha\) of atoms, the formulas of basic modal logic over \(\alpha\) are generated as follows: every atom \(p \in \alpha\) is a formula; falsity \(\bot\) is a formula; if \(\varphi\) and \(\psi\) are formulas then so is the implication \(\varphi \to \psi\); and if \(\varphi\) is a formula then so is the necessity formula \(\Box\varphi\).

    inductive Formula (α : Type u) : Type u where
  | atom : α → Formula α
  | bot : Formula α
  | imp : Formula α → Formula α → Formula α
  | box : Formula α → Formula α
  deriving DecidableEq, Repr

    DefinitionSatisfaction in a Kripke model#✓fully proved

    Cslib.Modal.KripkeModel.Satisfies

    Let \(M\) be a Kripke model with accessibility relation \(R\). Satisfaction of a modal formula at a world \(w\) of \(M\) is defined by recursion on the formula: \(w\) satisfies an atom \(p\) if and only if the valuation of \(M\) makes \(p\) true at \(w\); \(w\) never satisfies \(\bot\); \(w\) satisfies \(\varphi \to \psi\) if and only if \(w\) satisfies \(\psi\) whenever it satisfies \(\varphi\); and \(w\) satisfies \(\Box\varphi\) if and only if every world \(v\) with \(w \mathrel{R} v\) satisfies \(\varphi\).

    def Satisfies (model : KripkeModel World Atom) (world : World) : Formula Atom → Prop
  | .atom atom => model.valuation world atom
  | .bot => False
  | .imp phi psi => Satisfies model world phi → Satisfies model world psi
  | .box phi => ∀ next, model.rel world next → Satisfies model next phi
    structure KripkeModel (World : Type u) (Atom : Type v) where
  /-- There is at least one world. -/
  nonempty_world : Nonempty World
  /-- The accessibility relation. -/
  rel : World → World → Prop
  /-- The atoms true at each world. -/
  valuation : World → Atom → Prop

    Cslib.Modal.BoundedMorphism

    Let \(M\) and \(N\) be Kripke models over the same atoms, with sets of worlds \(W\) and \(V\) and accessibility relations \(R_M\) and \(R_N\). A bounded morphism from \(M\) to \(N\) is a map \(f : W \to V\) such that every atom holds at a world \(w\) in \(M\) if and only if it holds at \(f(w)\) in \(N\); whenever \(w \mathrel{R_M} w'\), also \(f(w) \mathrel{R_N} f(w')\) (forth); and whenever \(f(w) \mathrel{R_N} v'\), there is a world \(w'\) with \(w \mathrel{R_M} w'\) and \(f(w') = v'\) (back).

    Bounded morphisms are also called p-morphisms.
