    StructureEpistemic models#✓fully proved

    Cslib.Epistemic.Model

    Given a type of worlds \(W\), a type of atoms and a type of agents, an epistemic model consists of a binary accessibility relation \(R_i\) on \(W\) for each agent \(i\) and a valuation assigning to each world the atoms true there; the world type \(W\) is required to be nonempty.

    Nonemptiness is assumed as for Kripke models: with no worlds, validity would hold vacuously and even \(\bot\) would be valid.

    structure Model (World : Type u) (Atom : Type v) (Agent : Type w) where
  /-- One accessibility relation per agent. -/
  rel : Agent → World → World → Prop
  /-- The atoms true at each world. -/
  valuation : World → Atom → Prop
  /-- There is at least one world. -/
  nonempty_world : Nonempty World

    InductiveEpistemic formulas#✓fully proved

    Cslib.Epistemic.Formula

    Given a type of atoms and a type of agents, the formulas of epistemic logic are built inductively: every atom \(p\) is a formula, falsity \(\bot\) is a formula, if \(\varphi\) and \(\psi\) are formulas then so is the implication \(\varphi \to \psi\), and if \(\varphi\) is a formula and \(i\) is an agent then \(K_i \varphi\) (read "agent \(i\) knows \(\varphi\)") is a formula.

    inductive Formula (Atom : Type v) (Agent : Type w) where
  | atom (a : Atom) : Formula Atom Agent
  | bot : Formula Atom Agent
  | imp (φ ψ : Formula Atom Agent) : Formula Atom Agent
  | know (i : Agent) (φ : Formula Atom Agent) : Formula Atom Agent

    DefinitionSatisfaction in an epistemic model#✓fully proved

    Cslib.Epistemic.Sat

    Satisfaction of an epistemic formula at a world \(w\) of a model \(M\) is defined by recursion on the formula, writing \(R_i\) for the accessibility relation of agent \(i\) in \(M\) and \(K_i \varphi\) for the formula "agent \(i\) knows \(\varphi\)": an atom \(a\) holds at \(w\) when the valuation of \(M\) makes \(a\) true at \(w\); \(\bot\) holds at no world; \(\varphi \to \psi\) holds at \(w\) when \(\psi\) holds at \(w\) whenever \(\varphi\) does; and \(K_i \varphi\) holds at \(w\) when \(\varphi\) holds at every world \(v\) with \(w \mathrel{R_i} v\).

    def Sat {World Atom Agent : Type*} (M : Model World Atom Agent) :
    Formula Atom Agent → World → Prop
  | .atom a, w => M.valuation w a
  | .bot, _ => False
  | .imp φ ψ, w => Sat M φ w → Sat M ψ w
  | .know i φ, w => ∀ v, M.rel i w v → Sat M φ v
    structure Model (World : Type u) (Atom : Type v) (Agent : Type w) where
  /-- One accessibility relation per agent. -/
  rel : Agent → World → World → Prop
  /-- The atoms true at each world. -/
  valuation : World → Atom → Prop
  /-- There is at least one world. -/
  nonempty_world : Nonempty World

    TheoremSatisfaction of a disjunction#✓fully proved

    Cslib.Epistemic.sat_or

    In an epistemic model \(M\), the disjunction \(\varphi \lor \psi\) of two formulas, defined as \(\neg \varphi \to \psi\), is satisfied at a world \(w\) if and only if \(\varphi\) is satisfied at \(w\) or \(\psi\) is satisfied at \(w\).

    theorem sat_or :
    Sat M (.or φ ψ) w ↔ Sat M φ w ∨ Sat M ψ w

    Cslib.Epistemic.valid_know_dist

    Write \(K_i \varphi\) for "agent \(i\) knows \(\varphi\)". For every epistemic model \(M\), every agent \(i\) and all formulas \(\varphi\) and \(\psi\), the formula \(K_i (\varphi \to \psi) \to (K_i \varphi \to K_i \psi)\) is valid in \(M\): knowledge distributes over implication.

    theorem valid_know_dist :
    Valid M (.imp (.know i (.imp φ ψ)) (.imp (.know i φ) (.know i ψ)))

    TheoremNegative introspection axiom 5#✓fully proved

    Cslib.Epistemic.valid_know_neg

    Write \(K_i \varphi\) for "agent \(i\) knows \(\varphi\)". Let \(M\) be an epistemic model in which the accessibility relation \(R_i\) of agent \(i\) is euclidean: for all worlds \(a\), \(b\), \(c\), if \(a \mathrel{R_i} b\) and \(a \mathrel{R_i} c\) then \(b \mathrel{R_i} c\).     Cslib.Epistemic.muddy

    The epistemic model whose worlds are the two booleans, with \(\mathrm{true}\) read as heads and \(\mathrm{false}\) as tails, with a single atom \(p\) true exactly at the heads world, and with two agents \(0\) and \(1\): agent \(0\) sees the coin, so its accessibility relation is equality of worlds, and agent \(1\) does not, so its accessibility relation relates every pair of worlds.

    def muddy : Model Bool Unit (Fin 2) where
  rel := fun i w v => if i = 0 then w = v else True
  valuation := fun w _ => w = true
