    Cslib.Modal.Derivable

    Let \(\Lambda\) be a set of modal formulas. The theorems of the normal modal logic \(\mathbf{K} \oplus \Lambda\) form the least set of modal formulas that contains, for all modal formulas \(\varphi\), \(\psi\), \(\chi\), the propositional axioms \(\varphi \to (\psi \to \varphi)\), \((\varphi \to (\psi \to \chi)) \to ((\varphi \to \psi) \to (\varphi \to \chi))\) and \(\neg\neg\varphi \to \varphi\) (where \(\neg\varphi\) is \(\varphi \to \bot\)) and the distribution axiom \(\Box(\varphi \to \psi) \to (\Box\varphi \to \Box\psi)\), that contains every member of \(\Lambda\), and that is closed under modus ponens (from \(\varphi \to \psi\) and \(\varphi\) infer \(\psi\)) and necessitation (from \(\varphi\) infer \(\Box\varphi\)).

    inductive Derivable (Λ : Set (Formula Atom)) : Formula Atom → Prop
  | ax1 (phi psi : Formula Atom) : Derivable Λ (.imp phi (.imp psi phi))
  | ax2 (phi psi chi : Formula Atom) :
      Derivable Λ (.imp (.imp phi (.imp psi chi)) (.imp (.imp phi psi) (.imp phi chi)))
  | dne (phi : Formula Atom) : Derivable Λ (.imp phi.neg.neg phi)
  | distrib (phi psi : Formula Atom) : Derivable Λ (Formula.axiomK phi psi)
  | extra {phi : Formula Atom} : phi ∈ Λ → Derivable Λ phi
  | mp {phi psi : Formula Atom} : Derivable Λ (.imp phi psi) → Derivable Λ phi → Derivable Λ psi
  | nec {phi : Formula Atom} : Derivable Λ phi → Derivable Λ (.box phi)
    inductive Formula (α : Type u) : Type u where
  | atom : α → Formula α
  | bot : Formula α
  | imp : Formula α → Formula α → Formula α
  | box : Formula α → Formula α
  deriving DecidableEq, Repr

    Cslib.Modal.Deduces

    Let \(\Lambda\) and \(\Gamma\) be sets of modal formulas. The local consequences of the hypotheses \(\Gamma\) in the normal modal logic \(\mathbf{K} \oplus \Lambda\) form the least set of modal formulas that contains every member of \(\Gamma\) and every theorem of \(\mathbf{K} \oplus \Lambda\) and is closed under modus ponens: whenever it contains \(\varphi \to \psi\) and \(\varphi\), it contains \(\psi\).

    Necessitation applies to theorems only, not to hypotheses.

    inductive Deduces (Λ : Set (Formula Atom)) (Γ : Set (Formula Atom)) : Formula Atom → Prop
  | hyp {phi : Formula Atom} : phi ∈ Γ → Deduces Λ Γ phi
  | thm {phi : Formula Atom} : Derivable Λ phi → Deduces Λ Γ phi
  | mp {phi psi : Formula Atom} : Deduces Λ Γ (.imp phi psi) → Deduces Λ Γ phi → Deduces Λ Γ psi
    inductive Formula (α : Type u) : Type u where
  | atom : α → Formula α
  | bot : Formula α
  | imp : Formula α → Formula α → Formula α
  | box : Formula α → Formula α
  deriving DecidableEq, Repr
