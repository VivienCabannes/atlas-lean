    Cslib.PDL.Model

    A model of propositional dynamic logic with set of worlds \(W\) consists of a binary accessibility relation \(R_a\) on \(W\) for each atomic action label \(a\), and a valuation that says which atoms are true at each world.

    Cslib.PDL.Formula

    The formulas of propositional dynamic logic over a type of atoms and a type of atomic action labels are the atoms \(p\), falsity \(\bot\), implications \(\varphi \to \psi\) of formulas, and boxes \([\alpha]\varphi\) of a program \(\alpha\) and a formula \(\varphi\). Formulas and programs are defined by simultaneous induction.

    DefinitionRelation denoted by a PDL program#✓fully proved

    Cslib.PDL.ProgRel

    In a model \(M\), each program \(\alpha\) denotes a binary relation \(R_\alpha\) on worlds: an atomic action \(a\) denotes its accessibility relation \(R_a\); \((w, v) \in R_{\alpha;\beta}\) iff \((w, u) \in R_\alpha\) and \((u, v) \in R_\beta\) for some world \(u\); \(R_{\alpha \cup \beta} = R_\alpha \cup R_\beta\); \(R_{\alpha^*}\) is the reflexive-transitive closure of \(R_\alpha\); and \((w, v) \in R_{\varphi?}\) iff \(w = v\) and \(\varphi\) holds at \(w\) in \(M\).

    def ProgRel {World Atom Label : Type*} (M : Model World Atom Label) :
    Program Atom Label → World → World → Prop
  | .atomic a, w, v => M.rel a w v
  | .seq α β, w, v => ∃ u, ProgRel M α w u ∧ ProgRel M β u v
  | .choice α β, w, v => ProgRel M α w v ∨ ProgRel M β w v
  | .star α, w, v => Relation.ReflTransGen (ProgRel M α) w v
  | .test φ, w, v => w = v ∧ Sat M φ w
    structure Model (World : Type u) (Atom : Type v) (Label : Type w) where
  /-- One accessibility relation per atomic program label. -/
  rel : Label → World → World → Prop

    DefinitionSatisfaction of PDL formulas#✓fully proved

    Cslib.PDL.Sat

    Truth of a formula at a world \(w\) of a model \(M\) is defined by recursion: an atom \(p\) holds at \(w\) iff the valuation of \(M\) makes \(p\) true at \(w\); \(\bot\) holds nowhere; \(\varphi \to \psi\) holds at \(w\) iff \(\psi\) holds at \(w\) whenever \(\varphi\) does; and \([\alpha]\varphi\) holds at \(w\) iff \(\varphi\) holds at every world \(v\) with \((w, v) \in R_\alpha\), where \(R_\alpha\) is the relation denoted by \(\alpha\) in \(M\).

    def Sat {World Atom Label : Type*} (M : Model World Atom Label) :
    Formula Atom Label → World → Prop
  | .atom a, w => M.valuation w a
  | .bot, _ => False
  | .imp φ ψ, w => Sat M φ w → Sat M ψ w
  | .box α φ, w => ∀ v, ProgRel M α w v → Sat M φ v

    DefinitionThe toggle model#✓fully proved

    Cslib.PDL.toggleModel

    The PDL model whose worlds are the two Booleans \(\mathsf{true}\) and \(\mathsf{false}\), with a single atomic action \(a\) and a single atom \(p\): the action \(a\) relates each world \(s\) exactly to its negation \(\lnot s\), and \(p\) holds exactly at \(\mathsf{true}\).

    def toggleModel : Model Bool Unit Unit where
  rel := fun _ s t => t = !s
  valuation := fun s _ => s = true
