    Cslib.Modal.evalFin

    Given a finite set \(U\) of finite sets of formulas, a finite set \(R\) of pairs of such sets and a finite set \(s\) of formulas, the Boolean value of a formula at \(s\) is defined by recursion on the formula: an atom \(p\) is true iff \(p \in s\); \(\bot\) is false; \(\varphi \to \psi\) is true iff \(\varphi\) is false or \(\psi\) is true at \(s\); and \(\Box\varphi\) is true iff \(\varphi\) is true at every \(t \in U\) with \((s, t) \in R\).

    For \(s \in U\) this computes satisfaction at \(s\) in the finite Kripke model on \(U\) with relation \(R\) in which an atom is true at a world iff it belongs to it.

    def evalFin (U : Finset (Finset (Formula Atom))) (R : Finset (Finset (Formula Atom) ×
    Finset (Formula Atom))) (s : Finset (Formula Atom)) : Formula Atom → Bool
  | .atom p => decide (Formula.atom p ∈ s)
  | .bot => false
  | .imp phi psi => !evalFin U R s phi || evalFin U R s psi
  | .box phi => decide (∀ t ∈ U, (s, t) ∈ R → evalFin U R t phi = true)
    inductive Formula (α : Type u) : Type u where
  | atom : α → Formula α
  | bot : Formula α

    Cslib.Modal.IsFiltration

    Let \(M\) be a Kripke model, \(\varphi\) a modal formula, \(\Sigma\) the set of subformulas of \(\varphi\), and for a world \(w\) let \([w]\), the type of \(w\), be the set of formulas of \(\Sigma\) true at \(w\) in \(M\). A relation \(R\) on finite sets of formulas is a filtration of \(M\) through \(\Sigma\) when (min) for all worlds \(w, v\) related in \(M\), the pair \(([w], [v])\) is in \(R\), and (max) for all worlds \(w, v\) with \(([w], [v]) \in R\) and every formula \(\psi\) with \(\Box\psi \in \Sigma\), if \(\Box\psi\) holds at \(w\) in \(M\) then \(\psi\) holds at \(v\) in \(M\).

    These are conditions (ii) and (iii) of Blackburn–de Rijke–Venema, Definition 2.36, in \(\Box\) form; conditions (i) and (iv) (worlds are the \(\Sigma\)-types, atoms of \(\Sigma\) true where they belong) are built into the construction of the finite model.

  min : ∀ {w v}, M.rel w v → (subType M phi w, subType M phi v) ∈ R
  max : ∀ {w v}, (subType M phi w, subType M phi v) ∈ R → ∀ {psi}, Formula.box psi ∈ phi.sub →
    M.Satisfies w (.box psi) → M.Satisfies v psi
