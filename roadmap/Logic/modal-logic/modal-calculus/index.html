    Cslib.Modal.MuCalculus.MuFormula

    The formulas over a type of atoms are built from atoms \(a\), negated atoms \(\neg a\), variables \(X_n\) for \(n \in \mathbb{N}\) (de Bruijn indices for the fixed-point binders), \(\bot\) and \(\top\) by conjunction \(\varphi \wedge \psi\), disjunction \(\varphi \vee \psi\), the modalities \(\Box\varphi\) and \(\Diamond\varphi\), and the fixed-point binders \(\mu\varphi\) and \(\nu\varphi\).

    There is no negation of arbitrary formulas. Negated atoms are present so that the meta-level negation, which swaps each connective with its dual, is an involution.

    Cslib.Modal.MuCalculus.MuFormula.neg

    The meta-level negation \(\neg\varphi\) of a μ-calculus formula \(\varphi\) swaps each connective with its dual. It is defined by recursion: an atom \(p\) becomes the negated atom \(\overline{p}\) and \(\overline{p}\) becomes \(p\), each variable \(x_n\) stays \(x_n\), \(\neg\bot = \top\), \(\neg\top = \bot\), \(\neg(\varphi \wedge \psi) = \neg\varphi \vee \neg\psi\), \(\neg(\varphi \vee \psi) = \neg\varphi \wedge \neg\psi\), \(\neg\Box\varphi = \Diamond\neg\varphi\), \(\neg\Diamond\varphi = \Box\neg\varphi\), \(\neg\mu\varphi = \nu\neg\varphi\) and \(\neg\nu\varphi = \mu\neg\varphi\).

    DefinitionExtending an environment under a binder#✓fully proved

    Cslib.Modal.MuCalculus.extendEnv

    An environment \(\rho\) assigns to each variable index \(n \in \mathbb{N}\) a predicate \(\rho(n)\) on worlds. Its extension by a predicate \(S\) on worlds is the environment that assigns \(S\) to index \(0\) and \(\rho(n)\) to index \(n + 1\).

    With de Bruijn indices, variable \(1\) inside a binder thus refers to the enclosing binder.

    def extendEnv {World : Type*} (env : ℕ → World → Prop) (S : World → Prop) :
    ℕ → World → Prop
  | 0 => S
  | n + 1 => env n

    Cslib.Modal.MuCalculus.sat

    Let \(M\) be a Kripke model with accessibility relation \(R\) and valuation \(V\), and let \(\rho\) be an environment assigning a set of worlds to each variable index \(n \in \mathbb{N}\). For a set of worlds \(S\), write \(\rho[0 \mapsto S]\) for the environment sending index \(0\) to \(S\) and index \(n + 1\) to \(\rho(n)\). The set \([\![\varphi]\!]_\rho\) of worlds satisfying a formula \(\varphi\) in \(M\) under \(\rho\) is defined by recursion on \(\varphi\): an atom \(a\) holds at \(w\) when \(V\) makes \(a\) true at \(w\), and the negated atom of \(a\) when \(V\) does not; the variable with index \(n\) denotes \(\rho(n)\); \(\bot\) holds nowhere and \(\top\) everywhere; conjunction and disjunction denote intersection and union; \(\Box\varphi\) holds at \(w\) when \(\varphi\) holds at every \(v\) with \(w \mathrel{R} v\), and \(\Diamond\varphi\) when \(\varphi\) holds at some such \(v\); \(\mu\varphi\) holds at \(w\) when \(w \in S\) for every set of worlds \(S\) with \([\![\varphi]\!]_{\rho[0 \mapsto S]} \subseteq S\); and \(\nu\varphi\) holds at \(w\) when \(w \in S\) for some set of worlds \(S\) with \(S \subseteq [\![\varphi]\!]_{\rho[0 \mapsto S]}\).

    So \(\mu\varphi\) is the least pre-fixed point of \(S \mapsto [\![\varphi]\!]_{\rho[0 \mapsto S]}\), stated directly as an infimum over pre-fixed points, and \(\nu\varphi\) is the greatest post-fixed point, stated as a supremum over post-fixed points.

    def sat (env : ℕ → World → Prop) : MuFormula Atom → (World → Prop)
  | .atom a => fun w => M.valuation w a
  | .natom a => fun w => ¬ M.valuation w a
  | .var n => env n
  | .bot => fun _ => False
  | .top => fun _ => True
  | .and φ ψ => fun w => sat env φ w ∧ sat env ψ w
  | .or φ ψ => fun w => sat env φ w ∨ sat env ψ w
  | .box φ => fun w => ∀ v, M.rel w v → sat env φ v
  | .dia φ => fun w => ∃ v, M.rel w v ∧ sat env φ v
  | .mu φ => fun w => ∀ S : World → Prop,
      (∀ v, sat (extendEnv env S) φ v → S v) → S w
  | .nu φ => fun w => ∃ S : World → Prop,
      (∀ v, S v → sat (extendEnv env S) φ v) ∧ S w

    Cslib.Modal.MuCalculus.muTokens

    A polynomial-size token-list encoding of μ-calculus formulas over ℕ atoms, used for the complexity statements in WantedExt. Each connective contributes one tag token (Nat.pair of a small tag with 0), and each atom or variable contributes one token Nat.pair tag value, whose binary size is O(log value). The canonical bitstring encoding of a List ℕ delimits each token, so the bitstring for a formula has length linear in the number of connectives plus the total binary size of its atoms: box^d (atom 0) is encoded by exactly d + 1 tokens, unlike its Cantor-paired muCode, whose binary length is exponential in d.
