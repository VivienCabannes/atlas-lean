    TheoremExistence of the Ising phase transition#✓fully proved

    StatMech.IsingFK.ising_phase_transition_of_two_le

    Existence of the Ising phase transition in dimension d ≥ 2: there is β_c > 0 such that the spontaneous magnetization vanishes for 0 < β < β_c and is positive for β > β_c (Peierls, 1936; Griffiths, Phys. Rev. 136 (1964); Duminil-Copin, Lectures on the Ising and Potts models on the hypercubic lattice, 2017). The statement says nothing about β = β_c.

    theorem ising_phase_transition_of_two_le {d : ℕ} (hd : 2 ≤ d) :
    ∃ betaC : ℝ, 0 < betaC ∧
      (∀ beta, 0 < beta → beta < betaC → magnetization d beta = 0) ∧
      (∀ beta, betaC < beta → 0 < magnetization d beta)
    noncomputable def magnetization (d : ℕ) (β : ℝ) : ℝ :=
  ∫ ω, spin ω (origin d) ∂(plusState d β 0 : Measure (ConfigSpace (Site d)))

    TheoremSup-based \(\beta_c\) equals \(-\tfrac{1}{2}\log(1 - p_c)\) for \(d \ge 2\)#✓fully proved

    StatMech.IsingFK.isingFK_betaC_eq_fkPc_of_two_le

    The sup-based critical inverse temperature IsingFK.betaC (magnetization d) in dimension d ≥ 2 is -(1/2) log (1 - p_c(d, 2)), the image of the FK critical point. This is the supremum of the zero-magnetization inverse temperatures, not yet the public Ising.betaC d (see ising_betaC_eq_sup_betaC_of_two_le for the bridge).

    theorem isingFK_betaC_eq_fkPc_of_two_le {d : ℕ} (hd : 2 ≤ d) :
    betaC (magnetization d) = -(1 / 2) * Real.log (1 - fkPc d 2)
