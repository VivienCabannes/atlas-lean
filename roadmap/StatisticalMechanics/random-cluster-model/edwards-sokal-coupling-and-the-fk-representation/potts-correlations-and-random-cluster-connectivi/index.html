    TheoremEdwards–Sokal correlation identity#✓fully proved

    StatMech.FK.edwards_sokal_correlation

    For the q-state Potts model on a finite graph with p = 1 - e^{-βJ} ∈ (0, 1), μ_{β,J,q}(σ_x = σ_y) - 1/q = (1 - 1/q) φ_{p,q}(x ↔ y). The hypothesis hp1 holds for every real βJ and hq follows from [NeZero q]; the only restriction is hp, i.e. βJ > 0 (ferromagnetic). (Edwards–Sokal, Phys. Rev. D 38, 1988; Grimmett, The Random-Cluster Model, 2006, Theorem 1.16.)

    theorem edwards_sokal_correlation (q : ℕ) [NeZero q] (β J : ℝ) (x y : V)
    (hp : 0 < 1 - Real.exp (-(β * J))) (hp1 : 1 - Real.exp (-(β * J)) < 1)
    (hq : 0 < (q : ℝ)) :
    pottsAgreeProb G q β J x y - 1 / q
      = (1 - 1 / q) * connProb G (1 - Real.exp (-(β * J))) q x y
    noncomputable def pottsAgreeProb (q : ℕ) (β J : ℝ) (x y : V) : ℝ :=
  ∑ σ ∈ Finset.univ.filter (fun σ : V → Fin q => σ x = σ y), Potts.pottsProb G q β J σ
