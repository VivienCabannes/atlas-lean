    FalconerDistanceSet.distanceSet

    For a set \(E \subseteq \mathbb{R}^d\), the distance set of \(E\) is \(\Delta(E) = \{\lvert x - y \rvert : x, y \in E\}\), the set of Euclidean distances between pairs of points of \(E\).

    def distanceSet {d : ℕ} (E : Set (EuclideanSpace ℝ (Fin d))) : Set ℝ :=
  {r | ∃ x ∈ E, ∃ y ∈ E, dist x y = r}
