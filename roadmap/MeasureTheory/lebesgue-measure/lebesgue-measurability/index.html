    Lebesgue measurability

    Tao defines a set \(E \subseteq \mathbb{R}^d\) to be Lebesgue measurable when for every \(\varepsilon > 0\) it lies in an open set \(U\) with \(m^*(U \setminus E) \le \varepsilon\); Mathlib defines it as null-measurability for volume. The two agree, for every outer regular, \(\sigma\)-finite measure on a topological space, and so do the forms "a \(G_\delta\) set minus a null set" and "nearly contains a closed set".

    TheoremLebesgue measurability by outer approximation#✓fully proved

    MeasureTheory.nullMeasurableSet_iff_forall_exists_isOpen

    Let \(\mu\) be a measure on a topological space \(X\) whose Borel sets are measurable, and suppose that \(\mu\) is outer regular (\(\mu(A) = \inf\{\mu(U) : U \supseteq A \text{ open}\}\) for measurable \(A\)) and \(\sigma\)-finite; Lebesgue measure on \(\mathbb{R}^d\) is the main example. Then a set \(E \subseteq X\) is null-measurable if and only if for every \(\varepsilon > 0\) there is an open set \(U \supseteq E\) with \(\mu(U \setminus E) \le \varepsilon\).

    Here \(E\) is null-measurable when it differs from a measurable set by a subset of a null set, which for Lebesgue measure is Lebesgue measurability; \(\mu(A)\) for a non-measurable \(A\) is the outer measure.

    For Lebesgue measure on \(\mathbb{R}^d\) this says that Tao's definition of Lebesgue measurability (Definition 1.2.2, Littlewood's first principle: "every measurable set is nearly open") agrees with Mathlib's definition, null-measurability for volume. By Vitali's theorem, some subset of \(\mathbb{R}\) admits no such approximation.

    theorem nullMeasurableSet_iff_forall_exists_isOpen [OpensMeasurableSpace α] [μ.OuterRegular]
    [SigmaFinite μ] :
    NullMeasurableSet E μ ↔ ∀ ε : ℝ≥0∞, ε ≠ 0 → ∃ U, E ⊆ U ∧ IsOpen U ∧ μ (U \ E) ≤ ε
    Background
    Background
    • Vitali's theorem: background; the non-measurable set it provides is one for which open outer approximation fails.

    MeasureTheory.NullMeasurableSet.exists_isOpen_measure_sdiff_le

    Let \(\mu\) be a measure on a topological space \(X\) whose Borel sets are measurable, and suppose that \(\mu\) is outer regular (\(\mu(A) = \inf\{\mu(U) : U \supseteq A \text{ open}\}\) for measurable \(A\)) and \(\sigma\)-finite; Lebesgue measure on \(\mathbb{R}^d\) is the main example. If \(E \subseteq X\) is null-measurable, then for every \(\varepsilon > 0\) there is an open set \(U \supseteq E\) with \(\mu(U \setminus E) \le \varepsilon\). The set \(E\) may have infinite measure.

    Here \(E\) is null-measurable when it differs from a measurable set by a subset of a null set, which for Lebesgue measure is Lebesgue measurability; \(\mu(A)\) for a non-measurable \(A\) is the outer measure.

    Proof: take a measurable \(T \subseteq E\) with \(\mu(E \setminus T) = 0\); cover the null set \(E \setminus T\) by an open set of measure at most \(\varepsilon/2\); split \(T\) along a sequence of sets of finite measure exhausting \(X\) and approximate the \(n\)-th piece with error at most \(\varepsilon_n\), where \(\sum_n \varepsilon_n \le \varepsilon / 2\).

    theorem NullMeasurableSet.exists_isOpen_measure_sdiff_le [μ.OuterRegular] [SigmaFinite μ]
    (hE : NullMeasurableSet E μ) {ε : ℝ≥0∞} (hε : ε ≠ 0) :
    ∃ U, E ⊆ U ∧ IsOpen U ∧ μ (U \ E) ≤ ε

    TheoremTao's definition of Lebesgue measurability implies null-measurability#✓fully proved

    MeasureTheory.nullMeasurableSet_of_forall_exists_isOpen

    Let \(\mu\) be a measure on a topological space \(X\) whose Borel sets are measurable, and let \(E \subseteq X\). If for every \(\varepsilon > 0\) there is an open set \(U \supseteq E\) with \(\mu(U \setminus E) \le \varepsilon\) (outer measure), then \(E\) is null-measurable. No regularity or finiteness of \(\mu\) is needed.

    For Lebesgue measure on \(\mathbb{R}^d\) the hypothesis is Tao's definition of a Lebesgue measurable set, and the conclusion is Mathlib's.

    theorem nullMeasurableSet_of_forall_exists_isOpen [OpensMeasurableSpace α]
    (h : ∀ ε : ℝ≥0∞, ε ≠ 0 → ∃ U, E ⊆ U ∧ IsOpen U ∧ μ (U \ E) ≤ ε) :
    NullMeasurableSet E μ
    Informally uses
    Informally uses
    • Open outer approximation gives a \(G_\delta\) hull: the first step of the proof.
    • Subsets of a \(G_\delta\) set with null difference are measurable: the second step.

    MeasureTheory.exists_isGδ_of_forall_exists_isOpen

    Let \(\mu\) be any measure on a topological space \(X\) and \(E \subseteq X\). If for every \(\varepsilon > 0\) there is an open set \(U \supseteq E\) with \(\mu(U \setminus E) \le \varepsilon\) (outer measure), then there is a \(G_\delta\) set \(G \supseteq E\) (a countable intersection of open sets) with \(\mu(G \setminus E) = 0\): take \(G = \bigcap_n U_n\) with \(\mu(U_n \setminus E) \le 1/n\).

    theorem exists_isGδ_of_forall_exists_isOpen
    (h : ∀ ε : ℝ≥0∞, ε ≠ 0 → ∃ U, E ⊆ U ∧ IsOpen U ∧ μ (U \ E) ≤ ε) :
    ∃ G, IsGδ G ∧ E ⊆ G ∧ μ (G \ E) = 0

    MeasureTheory.nullMeasurableSet_iff_exists_isGδ

    Let \(\mu\) be a measure on a topological space \(X\) whose Borel sets are measurable, and suppose that \(\mu\) is outer regular (\(\mu(A) = \inf\{\mu(U) : U \supseteq A \text{ open}\}\) for measurable \(A\)) and \(\sigma\)-finite; Lebesgue measure on \(\mathbb{R}^d\) is the main example. Then \(E \subseteq X\) is null-measurable if and only if \(E \subseteq G\) for some \(G_\delta\) set \(G\) with \(\mu(G \setminus E) = 0\), that is, iff \(E\) is a \(G_\delta\) set minus a null set.

    theorem nullMeasurableSet_iff_exists_isGδ [OpensMeasurableSpace α] [μ.OuterRegular]
    [SigmaFinite μ] :
    NullMeasurableSet E μ ↔ ∃ G, IsGδ G ∧ E ⊆ G ∧ μ (G \ E) = 0

    TheoremInner approximation by closed sets#✓fully proved

    MeasureTheory.nullMeasurableSet_iff_forall_exists_isClosed

    Let \(\mu\) be a measure on a topological space \(X\) whose Borel sets are measurable, and suppose that \(\mu\) is outer regular (\(\mu(A) = \inf\{\mu(U) : U \supseteq A \text{ open}\}\) for measurable \(A\)) and \(\sigma\)-finite; Lebesgue measure on \(\mathbb{R}^d\) is the main example. Then \(E \subseteq X\) is null-measurable if and only if for every \(\varepsilon > 0\) there is a closed set \(F \subseteq E\) with \(\mu(E \setminus F) \le \varepsilon\). It follows from outer approximation applied to the complement of \(E\).

    theorem nullMeasurableSet_iff_forall_exists_isClosed [OpensMeasurableSpace α] [μ.OuterRegular]
    [SigmaFinite μ] :
    NullMeasurableSet E μ ↔ ∀ ε : ℝ≥0∞, ε ≠ 0 → ∃ F, F ⊆ E ∧ IsClosed F ∧ μ (E \ F) ≤ ε
