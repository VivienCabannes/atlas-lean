    Polynomial.IsPermutationPolynomial

    A polynomial \(f\) over a finite field \(F\) is a permutation polynomial when its evaluation map \(F \to F\), \(x \mapsto f(x)\), is bijective.

    def IsPermutationPolynomial {F : Type*} [Field F] [Finite F]
    (f : Polynomial F) : Prop :=
  Function.Bijective fun x => f.eval x

    DefinitionPolynomial complete to level \(k\)#✓fully proved

    Polynomial.IsKComplete

    Let \(F\) be a finite field, \(f \in F[X]\) and \(k\) a natural number. The polynomial \(f\) is complete to level \(k\) (\(k\)-complete) when \(f + iX\) is a permutation polynomial for every natural number \(i \le k\), where \(i\) is viewed as an element of \(F\).

    The source considers only positive levels \(k\); here every natural level is allowed, and completeness to level \(0\) says that \(f\) itself is a permutation polynomial.

    def IsKComplete {F : Type*} [Field F] [Finite F] (f : Polynomial F)
    (k : ℕ) : Prop :=
  ∀ i : ℕ, i ≤ k → IsPermutationPolynomial (f + Polynomial.C (i : F) * Polynomial.X)
    def IsPermutationPolynomial {F : Type*} [Field F] [Finite F]
    (f : Polynomial F) : Prop :=
  Function.Bijective fun x => f.eval x

    TheoremHermite–Dickson criterion#✓fully proved

    MathlibExt.FieldTheory.HermiteDickson.hermite_dickson_permutation_criterion

    Let \(\mathbb{F}_q\) be a finite field with \(q\) elements and characteristic \(p\), and let \(f \in \mathbb{F}_q[X]\). Then \(f\) is a permutation polynomial of \(\mathbb{F}_q\), that is, \(x \mapsto f(x)\) is a bijection of \(\mathbb{F}_q\), if and only if \(f\) has exactly one root in \(\mathbb{F}_q\) and, for every integer \(t\) with \(1 \le t \le q - 2\) and \(p \nmid t\), the remainder of \(f^t\) upon division by \(X^q - X\) has degree at most \(q - 2\).

    theorem hermite_dickson_permutation_criterion
    {p : ℕ} {Fq : Type*} [Field Fq] [Fintype Fq] [DecidableEq Fq] [CharP Fq p]
    [Fact p.Prime] (hq : 2 ≤ Fintype.card Fq) (f : Polynomial Fq) :
    let q := Fintype.card Fq
    Polynomial.IsPermutationPolynomial f ↔
      (Finset.univ.filter (fun x => Polynomial.eval x f = 0)).card = 1 ∧
        ∀ t : ℕ, 1 ≤ t → t ≤ q - 2 → ¬ p ∣ t →
          Polynomial.natDegree ((f ^ t) % (Polynomial.X ^ q - Polynomial.X)) ≤ q - 2
    def IsPermutationPolynomial {F : Type*} [Field F] [Finite F]
    (f : Polynomial F) : Prop :=
  Function.Bijective fun x => f.eval x
