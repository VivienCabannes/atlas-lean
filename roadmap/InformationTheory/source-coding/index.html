    MathlibExt.InformationTheory.KraftMcMillan.kraft_mcmillan_lengths

    Let \(\alpha\) be a finite set of source symbols, let \(\beta\) be a finite alphabet with \(D \ge 2\) letters, and let \(l : \alpha \to \mathbb{N}\). There is a prefix-free code assigning to each \(a \in \alpha\) a word over \(\beta\) of length \(l(a)\) if and only if \(\sum_{a \in \alpha} D^{-l(a)} \le 1\).

    public theorem kraft_mcmillan_lengths {α β : Type*} [Fintype α] [Fintype β]
    (l : α → ℕ) (hq : 2 ≤ Fintype.card β) :
    (∃ code : α → List β, IsPrefixFree code ∧ ∀ a, (code a).length = l a)
      ↔ ∑ a : α, (1 : ℝ) / (Fintype.card β : ℝ) ^ (l a) ≤ 1
    def IsPrefixFree {α β : Type*} (code : α → List β) : Prop :=
  ∀ ⦃a₁ a₂ : α⦄, a₁ ≠ a₂ → ¬ code a₁ <+: code a₂
