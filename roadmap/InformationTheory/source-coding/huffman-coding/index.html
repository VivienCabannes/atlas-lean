    DefinitionWeighted path length#✓fully proved

    Cslib.Algorithms.Lean.HuffmanTree.weightedPathLength

    The weighted path length of a Huffman tree is defined recursively: a single leaf has weighted path length \(0\), and the tree with left subtree \(L\) and right subtree \(R\) has weighted path length equal to the weighted path length of \(L\) plus that of \(R\) plus the total weight of \(L\) plus the total weight of \(R\).

    Equivalently, it is the sum over the leaves of each leaf's weight times its depth, with the root at depth zero (the standard weighted external path length).

    def HuffmanTree.weightedPathLength {α : Type u} : HuffmanTree α → Nat
  | .leaf _ _ => 0
  | .fork left right =>
      left.weightedPathLength + right.weightedPathLength +
        left.totalWeight + right.totalWeight

  | leaf (symbol : α) (weight : Nat)

    DefinitionEncoded length of a coding tree#✓fully proved

    Cslib.Algorithms.Lean.HuffmanTree.encodedLength

    The encoded length of a leaf of weight \(w\) is \(w\) (its lone symbol receives a one-bit codeword). The encoded length of the tree with left subtree \(L\) and right subtree \(R\) is \(P(L) + P(R) + W(L) + W(R)\), where \(P\) is the weighted path length and \(W\) the total weight; this is the weighted path length of that tree.

    When the leaf symbols are distinct, the encoded length equals the encoder's emitted cost, the sum over the weighted leaves of weight times codeword length. When symbols repeat, the encoder resolves each symbol to its first leaf, so on such trees the encoded length is the structural path cost rather than the emitted cost.

    def HuffmanTree.encodedLength {α : Type u} : HuffmanTree α → Nat
  | .leaf _ weight => weight
  | .fork left right =>
      left.weightedPathLength + right.weightedPathLength +
        left.totalWeight + right.totalWeight
    inductive HuffmanTree (α : Type u) where
  | leaf (symbol : α) (weight : Nat)
  | fork (left right : HuffmanTree α)

    Cslib.Algorithms.Lean.HuffmanTree.pathCode?

    For a Huffman tree \(T\) and a symbol \(s\), the path code of \(s\) in \(T\) records the edges on the path from the root of \(T\) to the leftmost leaf labelled \(s\), writing false for a left edge and true for a right edge. If \(T\) is a single leaf labelled \(s\), the path code is empty; if no leaf of \(T\) is labelled \(s\), there is no path code.

    def HuffmanTree.pathCode? {α : Type u} [DecidableEq α] :

      match HuffmanTree.pathCode? left target with
      | some bits => some (false :: bits)
      | none => (HuffmanTree.pathCode? right target).map (true :: ·)

    DefinitionFollowing a path in a Huffman tree#✓fully proved

    Cslib.Algorithms.Lean.HuffmanTree.decodePath?

    Let \(T\) be a Huffman tree and \(w\) a bit string, and write \(0\) for the bit false and \(1\) for the bit true. Following \(w\) in \(T\) starts at the root and reads the bits of \(w\) one at a time, moving to the left subtree on \(0\) and to the right subtree on \(1\), until it reaches a leaf; it then returns the label of that leaf together with the unread bits of \(w\). It fails if \(w\) runs out before a leaf is reached. In particular, if \(T\) is a single leaf, it returns its label and all of \(w\).

    def HuffmanTree.decodePath? {α : Type u} :
    HuffmanTree α → List Bool → Option (α × List Bool)
  | .leaf symbol _, bits => some (symbol, bits)
  | .fork _ _, [] => none
  | .fork left right, bit :: bits =>
      if bit then right.decodePath? bits else left.decodePath? bits
    inductive HuffmanTree (α : Type u) where
  | leaf (symbol : α) (weight : Nat)
  | fork (left right : HuffmanTree α)

    DefinitionDecoding one codeword#✓fully proved

    Cslib.Algorithms.Lean.HuffmanTree.decodeOne?

    Let \(T\) be a Huffman tree and \(w\) a bit string, and write \(0\) for the bit false and \(1\) for the bit true. If \(T\) is a single leaf labelled \(s\), decoding one codeword from \(w\) returns \(s\) together with the rest of \(w\) when \(w\) starts with \(0\), and fails otherwise. If \(T\) is a fork with left subtree \(L\) and right subtree \(R\), it fails when \(w\) is empty; when \(w\) is a bit \(b\) followed by \(w'\), it follows \(w'\) from the root of \(R\) if \(b = 1\) and from the root of \(L\) if \(b = 0\), reading one bit at a time, moving to the left subtree on \(0\) and to the right subtree on \(1\), until it reaches a leaf. It then returns the label of that leaf together with the unread bits, and fails if \(w'\) runs out before a leaf is reached.

    def HuffmanTree.decodeOne? {α : Type u} :
    HuffmanTree α → List Bool → Option (α × List Bool)
  | .leaf symbol _, false :: bits => some (symbol, bits)
  | .leaf _ _, _ => none
  | .fork _ _, [] => none
  | .fork left right, bit :: bits =>
      if bit then right.decodePath? bits else left.decodePath? bits
    inductive HuffmanTree (α : Type u) where
  | leaf (symbol : α) (weight : Nat)
  | fork (left right : HuffmanTree α)

    Cslib.Algorithms.Lean.huffman

    Let \(L\) be a list of \(n\) pairs \((a_0, w_0), \dots, (a_{n-1}, w_{n-1})\) of symbols and natural-number weights, with decidable equality on symbols.
