    Random coding bound and Gallager's exponent

    Gallager's 1965 derivation of the coding theorem for a discrete memoryless channel \(W\) with finite alphabets. A code of \(M\) words of length \(N\) is decoded by maximum likelihood, every tie counted as an error. Averaging over the ensemble in which every letter of every code word is drawn independently with law \(p\) gives the random coding bound \(\bar P_{e,m} \le (M - 1)^\rho \exp(-N E_0(\rho, p))\) for \(0 \le \rho \le 1\), with \(E_0(\rho, p) = -\ln \sum_b \big(\sum_a p(a) W(b \mid a)^{1/(1+\rho)}\big)^{1+\rho}\) in nats. Hence some code has average error at most \(\exp(-N(E_0(\rho, p) - \rho R))\) at rate \(R = (\ln M)/N\). Since \(E_0(0, p) = 0\), \(E_0\) is concave in \(\rho\) and \(\partial E_0 / \partial \rho\) at \(\rho = 0\) is the mutual information \(I(p; W)\), the exponent is positive at every rate \(R < I(p; W)\): the error probability then decays exponentially in \(N\).

    Everything on this page is proved, including the expurgated maximal-error bound (Corollary 2), from which Shannon's achievability follows.

    Gallager's function \(E_0\)

    DefinitionGallager's inner sum#✓fully proved

    MathlibExt.InformationTheory.GallagerExponent.gallagerInner

    Let \(W\) be a discrete memoryless channel with finite input alphabet \(\mathcal A\) and finite output alphabet \(\mathcal B\), given by its transition laws \(W(\cdot \mid a)\), and let \(p\) be a law on \(\mathcal A\). For a real \(\rho\) and an output \(b\), Gallager's inner sum is

    \[g_b(\rho) = \sum_{a \in \mathcal A} p(a)\, W(b \mid a)^{1/(1+\rho)},\]

    the quantity raised to the power \(1 + \rho\) in Gallager's function. The power is the real power \(x^y\) with \(0^y = 0\) for \(y \ne 0\), so for \(\rho > -1\) an input that cannot produce \(b\) contributes \(0\).

    noncomputable def gallagerInner (p : PMF α) (W : α → PMF β) (ρ : ℝ) (b : β) : ℝ :=
  ∑ a, (p a).toReal * ((W a) b).toReal ^ (1 / (1 + ρ))

    DefinitionGallager's function \(E_0(\rho, p)\)#✓fully proved

    MathlibExt.InformationTheory.GallagerExponent.gallagerE0

    Let \(W\) be a discrete memoryless channel with finite alphabets \(\mathcal A\), \(\mathcal B\) and let \(p\) be a law on the inputs. Gallager's function is

    \[E_0(\rho, p) = -\ln \sum_{b \in \mathcal B} \Big(\sum_{a \in \mathcal A} p(a)\, W(b \mid a)^{1/(1+\rho)}\Big)^{1+\rho},\]

    with the natural logarithm, so \(E_0\) is in nats. It is the exponent of the random coding bound, where \(0 \le \rho \le 1\). The definition is meaningful for \(\rho > -1\); at \(\rho = -1\) Lean's convention \(1/0 = 0\) gives it a value with no meaning, outside every range used here.

    noncomputable def gallagerE0 (p : PMF α) (W : α → PMF β) (ρ : ℝ) : ℝ :=
  -Real.log (∑ b, gallagerInner p W ρ b ^ (1 + ρ))
    noncomputable def gallagerInner (p : PMF α) (W : α → PMF β) (ρ : ℝ) (b : β) : ℝ :=
  ∑ a, (p a).toReal * ((W a) b).toReal ^ (1 / (1 + ρ))

    MathlibExt.InformationTheory.GallagerExponent.hasDerivAt_gallagerE0_zero_nats

    For every discrete memoryless channel \(W\) on finite alphabets and every input law \(p\), the function \(\rho \mapsto E_0(\rho, p)\) is differentiable at \(\rho = 0\) with derivative

    TheoremDerivative of \(E_0\) at \(\rho = 0\) is the mutual information#✓fully proved

    MathlibExt.InformationTheory.GallagerExponent.hasDerivAt_gallagerE0_zero

    For every discrete memoryless channel \(W\) on finite alphabets and every input law \(p\),

    \[\frac{\partial E_0(\rho, p)}{\partial \rho}\Big|_{\rho = 0} = I(X; Y) \cdot \ln 2,\]

    where \((X, Y)\) has the joint law \(p(a) W(b \mid a)\) and \(I(X; Y)\) is the mutual information in bits. The factor \(\ln 2\) converts bits to nats: \(E_0\) is defined with the natural logarithm, so its slope is the mutual information in nats, which is Gallager's \(I(\mathbf p)\).

    Gallager states this in Theorem 2 under the assumption \(I(\mathbf p) \ne 0\), which he needs for the strict inequalities (27) and (28); this statement holds without it.

    TheoremPositive random coding exponent below the mutual information#✓fully proved

    MathlibExt.InformationTheory.GallagerExponent.exists_gallagerE0_sub_pos

    Let \(W\) be a discrete memoryless channel on finite alphabets and \(p\) an input law. If a rate \(R\) (in nats per channel use) is smaller than the mutual information \(I(X; Y) \ln 2\) of \(p\) and \(W\) in nats, then there is \(0 < \rho \le 1\) with

    \[E_0(\rho, p) - \rho R > 0.\]

    So the exponent \(\max_{0 \le \rho \le 1} (E_0(\rho, p) - \rho R)\) of the random coding bound is positive at every rate below \(I(p; W)\). The function \(\rho \mapsto E_0(\rho, p) - \rho R\) vanishes at \(0\) and has positive slope \(I(p; W) - R\) there, so it is positive just to the right of \(0\). Gallager reaches the same conclusion through the parametric form of \(E(R, \mathbf p)\), which also uses the concavity (30).

    TheoremHölder's inequality, geometric-mean form#✓fully proved

    MathlibExt.InformationTheory.GallagerExponent.sum_rpow_mul_rpow_le

    For a finite index set, nonnegative \(X_i\), \(Y_i\) and \(0 < \mu < 1\),

    \[\sum_i X_i^{\mu}\, Y_i^{1-\mu} \le \Big(\sum_i X_i\Big)^{\mu} \Big(\sum_i Y_i\Big)^{1-\mu}.\]

    It is Hölder's inequality with the conjugate exponents \(1/\mu\) and \(1/(1-\mu)\) applied to \(X_i^{\mu}\) and \(Y_i^{1-\mu}\), from Mathlib's Real.inner_le_Lp_mul_Lq_of_nonneg.

    ∑ i ∈ s, X i ^ μ * Y i ^ (1 - μ) ≤ (∑ i ∈ s, X i) ^ μ * (∑ i ∈ s, Y i) ^ (1 - μ)

    TheoremConcavity of \(E_0\) in \(\rho\)#✓fully proved

    MathlibExt.InformationTheory.GallagerExponent.concaveOn_gallagerE0

    For every discrete memoryless channel \(W\) on finite alphabets and every input law \(p\), the function \(\rho \mapsto E_0(\rho, p)\) is concave on \((-1, \infty)\).

    Gallager's equation (30) states \(\partial^2 E_0 / \partial \rho^2 \le 0\) for \(\rho \ge 0\) (assuming \(I(\mathbf p) \ne 0\)), with a characterisation of equality, and proves it with Hölder's inequality in his appendix. The statement here is stronger in its range and hypotheses (the interval \((-1, \infty)\), no differentiability, no assumption on \(I(\mathbf p)\)) and omits the equality case.

    The proof follows the same route. For \(\rho = a \rho_1 + b \rho_2\) (\(a + b = 1\), \(a, b > 0\)) put \(\mu = a(1 + \rho_1)/(1 + \rho)\). Hölder over the inputs gives \(g_y(\rho) \le g_y(\rho_1)^{\mu} g_y(\rho_2)^{1-\mu}\), hence \(g_y(\rho)^{1+\rho} \le (g_y(\rho_1)^{1+\rho_1})^{a} (g_y(\rho_2)^{1+\rho_2})^{b}\), and Hölder over the outputs bounds the sum by the product of the two sums to the powers \(a\) and \(b\). Taking \(-\ln\) gives \(E_0(\rho) \ge a E_0(\rho_1) + b E_0(\rho_2)\).

    theorem concaveOn_gallagerE0 (p : PMF α) (W : α → PMF β) :
    ConcaveOn ℝ (Set.Ioi (-1)) (gallagerE0 p W)

    DefinitionError probability of maximum-likelihood decoding, ties counted as errors#✓fully proved

    MathlibExt.InformationTheory.RandomCodingBound.mlErrorProb

    Let \(C = (x_1, \dots, x_M)\) be a code of \(M\) words of length \(N\) for a memoryless channel \(W\). When \(x_m\) is sent, the decoder errs on every output \(y\) for which some other code word is at least as likely: \(W^N(y \mid x_m) \le W^N(y \mid x_{m'})\) for some \(m' \ne m\).     \[P_{e,m}(C) = \sum_{y} W^N(y \mid x_m)\, \mathbf 1\big[\exists\, m' \ne m,\ W^N(y \mid x_m) \le W^N(y \mid x_{m'})\big].\]

    Counting every tie as an error, as Gallager does, makes \(P_{e,m}(C)\) an upper bound for the error probability of every maximum-likelihood decoder, whatever its tie-breaking rule, so bounds on it hold for all of them.

    TheoremExpurgated random coding bound, maximal error#✓fully proved

    MathlibExt.InformationTheory.RandomCodingBound.exists_code_mlErrorProb_le

    Let \(W\) be a discrete memoryless channel on finite alphabets and \(p\) an input law. For every block length \(N\), every number \(M \ge 1\) of code words and every \(0 \le \rho \le 1\), there is a code in which every code word has error probability under maximum-likelihood decoding (ties counted as errors) at most

    \[P_{e,m} \le 4\, M^{\rho}\, e^{-N E_0(\rho, p)}.\]

    Gallager's proof: take a code with \(2M\) words whose average error is at most \((2M)^\rho e^{-N E_0}\), and keep the \(M\) words with the smallest error; each has error at most twice the average, and removing words can only lower the errors of the others. Since \(2 \cdot 2^\rho \le 4\) for \(\rho \le 1\), this gives the bound. Optimising over \(\rho\) and \(p\) at \(M = e^{NR}\) gives Gallager's \(P_{e,m} \le 4 e^{-N E(R)}\), equation (23); the statement here is that fixed-\((\rho, p)\) form.

    theorem exists_code_mlErrorProb_le (p : PMF α) (W : α → PMF β) (N M : ℕ) (hM : 0 < M) {ρ : ℝ}
    (hρ0 : 0 ≤ ρ) (hρ1 : ρ ≤ 1) :
    ∃ C : Fin M → Fin N → α, ∀ m,
