    I-projections

    Let \(Q\) be a distribution on a finite alphabet and \(\Gamma\) a set of distributions. A minimiser \(P^*\) of the I-divergence \(D(P \| Q) = \sum_a P(a)\log(P(a)/Q(a))\) over \(\Gamma\) is the I-projection of \(Q\) on \(\Gamma\) (Csiszár, "I-divergence geometry of probability distributions and minimization problems", Ann. Probab. 3 (1975)). The divergence behaves like a squared Euclidean distance: on a convex \(\Gamma\) the I-projection satisfies the Pythagorean inequality \(D(P\|Q) \ge D(P\|P^*) + D(P^*\|Q)\), with equality on linear families and, more generally, when \(P^*\) is an algebraic inner point of \(\Gamma\). Here \(Q\) is strictly positive, distributions are nonnegative functions summing to \(1\), and logarithms are natural.

    TheoremExistence of the I-projection on a closed set#✓fully proved

    MathlibExt.InformationTheory.IProjection.exists_isMinOn

    If \(Q > 0\) on a finite alphabet and \(\Gamma\) is a nonempty closed set of distributions, then \(D(\cdot\|Q)\) attains its minimum on \(\Gamma\): \(\Gamma\) is compact and \(P \mapsto \sum_a P(a)\log(P(a)/Q(a))\) is continuous. Convexity is not needed for existence on a finite alphabet; Csiszár's 1975 Theorem 2.1 (arbitrary spaces, variation-closed convex sets) uses it, and convexity gives uniqueness through strict convexity, which is not formalized.

    theorem exists_isMinOn {Q : α → ℝ} (hQ : ∀ a, 0 < Q a) {Γ : Set (α → ℝ)} (hne : Γ.Nonempty)
    (hclosed : IsClosed Γ) (hsub : ∀ R ∈ Γ, (∀ a, 0 ≤ R a) ∧ ∑ a, R a = 1) :
    ∃ Ps ∈ Γ, ∀ P ∈ Γ, ∑ a, Ps a * log (Ps a / Q a) ≤ ∑ a, P a * log (P a / Q a)

    TheoremI-projection: support and Pythagorean inequality#✓fully proved

    MathlibExt.InformationTheory.IProjection.support_and_pythagorean

    Let \(Q > 0\) on a finite alphabet, let \(\Gamma\) be a convex set of distributions (nonnegative functions summing to \(1\)), and let \(P^* \in \Gamma\) minimise \(D(\cdot \| Q)\) over \(\Gamma\). Then for every \(P \in \Gamma\):

    1. \(P(a) = 0\) wherever \(P^*(a) = 0\) (the support of \(P^*\) is the support of \(\Gamma\));
    2. \(D(P\|P^*) + D(P^*\|Q) \le D(P\|Q)\), with \(D(R\|S) = \sum_a R(a)\log(R(a)/S(a))\), natural log.

    Item 1 is what makes \(D(P\|P^*)\) in item 2 a genuine (finite) divergence rather than a Lean junk value. This is the tutorial's Theorem 3.1 exactly (finite alphabet, \(Q > 0\)). Csiszár (1975) proves it on arbitrary measurable spaces, and also proves the converse: a \(P^* \in \Gamma\) satisfying the inequality for all \(P \in \Gamma\) is the I-projection. The converse is not formalized.

    The proof is the tutorial's: the first-order condition gives item 1 and \(\sum_a (P(a) - P^*(a))(\log P^*(a) - \log Q(a)) \ge 0\), and the divergence defect identifies that sum with \(D(P\|Q) - D(P\|P^*) - D(P^*\|Q)\).

    theorem support_and_pythagorean {Q : α → ℝ} (hQ : ∀ a, 0 < Q a) {Γ : Set (α → ℝ)}
    (hΓ : Convex ℝ Γ) (hsub : ∀ R ∈ Γ, (∀ a, 0 ≤ R a) ∧ ∑ a, R a = 1) {Ps : α → ℝ} (hPs : Ps ∈ Γ)
    (hmin : ∀ P ∈ Γ, ∑ a, Ps a * log (Ps a / Q a) ≤ ∑ a, P a * log (P a / Q a))
    {P : α → ℝ} (hP : P ∈ Γ) :
    (∀ a, Ps a = 0 → P a = 0) ∧
      ∑ a, P a * log (P a / Ps a) + ∑ a, Ps a * log (Ps a / Q a) ≤
        ∑ a, P a * log (P a / Q a)

    TheoremFirst-order condition for an I-projection#✓fully proved

    MathlibExt.InformationTheory.IProjection.support_and_first_order

    Under the hypotheses of the Pythagorean inequality, every \(P \in \Gamma\) vanishes wherever \(P^*\) does, and

    \[\sum_a (P(a) - P^*(a))\,(\log P^*(a) - \log Q(a)) \ge 0.\]

    The sum is the one-sided derivative at \(t = 0\) of \(t \mapsto D(P^* + t(P - P^*) \| Q)\), the quantity (3.1) of the tutorial. The Lean proof bounds the difference quotient on \((0,1)\) from above by the segment estimate, writes it as a function continuous at \(0\) plus \(c \log t\) with \(c = \sum_{a : P^*(a) = 0} P(a)\), and lets \(t \to 0^+\): if \(c > 0\) the quotient tends to \(-\infty\), contradicting minimality, which proves the support claim.

    theorem support_and_first_order {Q : α → ℝ} (hQ : ∀ a, 0 < Q a) {Γ : Set (α → ℝ)}
    (hΓ : Convex ℝ Γ) (hsub : ∀ R ∈ Γ, (∀ a, 0 ≤ R a) ∧ ∑ a, R a = 1) {Ps : α → ℝ} (hPs : Ps ∈ Γ)
    (hmin : ∀ P ∈ Γ, ∑ a, Ps a * log (Ps a / Q a) ≤ ∑ a, P a * log (P a / Q a))
    {P : α → ℝ} (hP : P ∈ Γ) :
    (∀ a, Ps a = 0 → P a = 0) ∧ 0 ≤ ∑ a, (P a - Ps a) * (log (Ps a) - log (Q a))

    TheoremDivergence defect as a first-order term#✓fully proved

    MathlibExt.InformationTheory.IProjection.divergence_defect_eq

    If \(Q > 0\), \(P, P^* \ge 0\) and \(P\) vanishes wherever \(P^*\) does, then

    \[D(P\|Q) - D(P\|P^*) - D(P^*\|Q) = \sum_a (P(a) - P^*(a))(\log P^*(a) - \log Q(a)).\]

    No normalisation is needed. The support hypothesis keeps every logarithm away from Lean's junk value \(\log 0 = 0\).

    theorem divergence_defect_eq {Q P Ps : α → ℝ} (hQ : ∀ a, 0 < Q a) (hP0 : ∀ a, 0 ≤ P a)
    (hPs0 : ∀ a, 0 ≤ Ps a) (hsupp : ∀ a, Ps a = 0 → P a = 0) :
    ∑ a, P a * log (P a / Q a) - ∑ a, P a * log (P a / Ps a) - ∑ a, Ps a * log (Ps a / Q a) =
      ∑ a, (P a - Ps a) * (log (Ps a) - log (Q a))

    TheoremPythagorean identity at an algebraic inner point#✓fully proved

    MathlibExt.InformationTheory.IProjection.pythagorean_eq_of_inner

    Under the hypotheses of the Pythagorean inequality, suppose that \(P^*\) is an algebraic inner point of \(\Gamma\): for every \(P \in \Gamma\) there is \(\varepsilon > 0\) with \(P^* + \varepsilon(P^* - P) \in \Gamma\). Then

    \[D(P\|Q) = D(P\|P^*) + D(P^*\|Q) \qquad \text{for every } P \in \Gamma.\]

    Applying the first-order condition to \(P\) and to \(P^* + \varepsilon(P^* - P)\) gives both signs of the first-order term. This is the last assertion of Csiszár's 1975 Theorem 2.2, restricted to finite alphabets and \(Q > 0\); the source also concludes that every \(P \in \Gamma\) has finite divergence from \(Q\), which is automatic here.

    theorem pythagorean_eq_of_inner {Q : α → ℝ} (hQ : ∀ a, 0 < Q a) {Γ : Set (α → ℝ)}
    (hΓ : Convex ℝ Γ) (hsub : ∀ R ∈ Γ, (∀ a, 0 ≤ R a) ∧ ∑ a, R a = 1) {Ps : α → ℝ} (hPs : Ps ∈ Γ)
    (hmin : ∀ P ∈ Γ, ∑ a, Ps a * log (Ps a / Q a) ≤ ∑ a, P a * log (P a / Q a))
    (hinner : ∀ P ∈ Γ, ∃ ε > 0, (fun a => Ps a + ε * (Ps a - P a)) ∈ Γ)
    {P : α → ℝ} (hP : P ∈ Γ) :
    ∑ a, P a * log (P a / Q a) =
      ∑ a, P a * log (P a / Ps a) + ∑ a, Ps a * log (Ps a / Q a)

    TheoremPythagorean identity for linear families#✓fully proved

    MathlibExt.InformationTheory.IProjection.pythagorean_eq_linearFamily

    Let \(Q > 0\) on a finite alphabet, \(f_i : \alpha \to \mathbb R\) and \(c_i \in \mathbb R\) for \(i\) in any index type, and let \(\mathcal L = \{P \ge 0 : \sum_a P(a) = 1,\ \sum_a P(a) f_i(a) = c_i \ \forall i\}\). If \(P^* \in \mathcal L\) minimises \(D(\cdot\|Q)\) over \(\mathcal L\), then

    \[D(P\|Q) = D(P\|P^*) + D(P^*\|Q) \qquad \text{for every } P \in \mathcal L.\]

    \(\mathcal L\) is convex and, because \(P^*\) has the largest support in \(\mathcal L\), \(P^*\) is an algebraic inner point of it, so the identity at an inner point applies. This is the first assertion of the tutorial's Theorem 3.2; its second assertion (\(\mathcal L \cap \mathrm{cl}(\mathcal E_Q) = \{P^*\}\), the exponential-family form of \(P^*\)) is not formalized. The index type of the constraints is arbitrary, a mild generalisation of the source's \(k\) functions.

    theorem pythagorean_eq_linearFamily {Q : α → ℝ} (hQ : ∀ a, 0 < Q a) {ι : Type*}
    (f : ι → α → ℝ) (c : ι → ℝ) {Ps : α → ℝ}
    (hPs : Ps ∈ {R : α → ℝ | ((∀ a, 0 ≤ R a) ∧ ∑ a, R a = 1) ∧ ∀ i, ∑ a, R a * f i a = c i})
    (hmin : ∀ P ∈ {R : α → ℝ | ((∀ a, 0 ≤ R a) ∧ ∑ a, R a = 1) ∧ ∀ i, ∑ a, R a * f i a = c i},
      ∑ a, Ps a * log (Ps a / Q a) ≤ ∑ a, P a * log (P a / Q a))
    {P : α → ℝ}
    (hP : P ∈ {R : α → ℝ | ((∀ a, 0 ≤ R a) ∧ ∑ a, R a = 1) ∧ ∀ i, ∑ a, R a * f i a = c i}) :
    ∑ a, P a * log (P a / Q a) =
      ∑ a, P a * log (P a / Ps a) + ∑ a, Ps a * log (Ps a / Q a)

    TheoremTangent line of x log x#✓fully proved

    MathlibExt.InformationTheory.IProjection.mul_log_sub_mul_log_le

    For \(x \ge 0\) and \(y > 0\): \(\ y\log y - x\log x \le (y - x)(\log y + 1)\). The convex function \(t \mapsto t\log t\) lies above its tangent at \(y\); the Lean proof uses \(\log u \le u - 1\).

    theorem mul_log_sub_mul_log_le {x y : ℝ} (hx : 0 ≤ x) (hy : 0 < y) :
    y * log y - x * log x ≤ (y - x) * (log y + 1)

    TheoremSplitting a divergence term#✓fully proved

    TheoremFirst-order estimate along a segment, one letter#✓fully proved

    MathlibExt.InformationTheory.IProjection.term_sub_le

    For \(p, p^* \ge 0\), \(q > 0\) and \(0 < t < 1\), with \(p_t = p^* + t(p - p^*)\):

    \[p_t\log\frac{p_t}{q} - p^*\log\frac{p^*}{q} \le t\bigl((p - p^*)(\log p_t - \log q) + (p - p^*)\bigr).\]

    Summed over the alphabet, the last term vanishes for distributions and the left side is \(D(P_t\|Q) - D(P^*\|Q)\); this is the estimate behind the first-order condition.

    theorem term_sub_le {p ps q t : ℝ} (hp : 0 ≤ p) (hps : 0 ≤ ps) (hq : 0 < q) (ht0 : 0 < t)
    (ht1 : t < 1) :
    (ps + t * (p - ps)) * log ((ps + t * (p - ps)) / q) - ps * log (ps / q) ≤
      t * ((p - ps) * (log (ps + t * (p - ps)) - log q) + (p - ps))

    Related topics

    • Method of types: Sanov's theorem identifies \(D(\Gamma\|Q)\) as the exponent of \(Q^n\{P_x \in \Gamma\}\), and the I-projection is the limiting conditional law in Gibbs' conditioning principle.
    • Shannon entropy and Kullback–Leibler divergence: the divergence being minimised, and Gibbs' inequality \(D \ge 0\).
    • Csiszár–Kullback–Pinsker inequality: converts the divergence bounds of the Pythagorean inequality into total-variation bounds.
    • Data-processing inequality: monotonicity of divergences and mutual information under Markov kernels.
