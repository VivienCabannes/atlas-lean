    Strong data processing and Dobrushin's coefficient

    A Markov kernel \(\kappa\) contracts total variation by Dobrushin's coefficient \(\eta_{\mathrm{TV}}(\kappa) = \sup_{x, x'} \mathrm{TV}(\kappa(x), \kappa(x'))\), and point masses show that no smaller constant works. The same coefficient bounds the contraction of the Kullback–Leibler divergence and of every f-divergence, the starting point of strong data-processing inequalities.

    DefinitionDobrushin's contraction coefficient#✓fully proved

    MathlibExt.InformationTheory.DobrushinContraction.dobrushinCoeff

    For a Markov kernel \(\kappa\) from \(X\) to \(Y\), Dobrushin's coefficient is

    \[ \eta_{\mathrm{TV}}(\kappa) = \sup_{x, x' \in X} \mathrm{TV}(\kappa(x), \kappa(x')), \]

    with \(\mathrm{TV}(\mu, \nu) = \sup_B |\mu(B) - \nu(B)|\). It lies in \([0, 1]\) and is \(0\) when \(X\) is empty. The diagonal terms vanish, so it agrees with the supremum over \(x \ne x'\) in Polyanskiy and Wu.

    noncomputable def dobrushinCoeff (κ : Kernel X Y) [IsMarkovKernel κ] : ℝ :=
  ⨆ x, ⨆ x', totalVariationDist (κ x) (κ x')
    noncomputable def totalVariationDist {Ω : Type*} [MeasurableSpace Ω]
    (μ ν : Measure Ω) [IsFiniteMeasure μ] [IsFiniteMeasure ν] : ℝ :=
  ⨆ s : {s : Set Ω // MeasurableSet s}, |(μ s.1).toReal - (ν s.1).toReal|

    TheoremSharpness of Dobrushin's coefficient#✓fully proved

    MathlibExt.InformationTheory.DobrushinContraction.dobrushinCoeff_le_of_forall

    Let \(\kappa\) be a Markov kernel whose input space has measurable singletons. If a constant \(c \ge 0\) satisfies \(\mathrm{TV}(\kappa \circ \mu, \kappa \circ \nu) \le c\, \mathrm{TV}(\mu, \nu)\) for all probability measures \(\mu\) and \(\nu\), then \(\eta_{\mathrm{TV}}(\kappa) \le c\): point masses \(\mu = \delta_x\), \(\nu = \delta_{x'}\) attain the coefficient. With Dobrushin's contraction, the best contraction constant of \(\kappa\) for total variation is exactly \(\eta_{\mathrm{TV}}(\kappa)\).

    theorem dobrushinCoeff_le_of_forall [MeasurableSingletonClass X] (κ : Kernel X Y)
    [IsMarkovKernel κ] {c : ℝ} (hc : 0 ≤ c)
    (h : ∀ (μ ν : Measure X) [IsProbabilityMeasure μ] [IsProbabilityMeasure ν],
      totalVariationDist (κ ∘ₘ μ) (κ ∘ₘ ν) ≤ c * totalVariationDist μ ν) :
    dobrushinCoeff κ ≤ c

    TheoremDobrushin's contraction#✓fully proved

    MathlibExt.InformationTheory.DobrushinContraction.totalVariationDist_comp_le

    Let \(\kappa\) be a Markov kernel from \(X\) to \(Y\) and \(\mu\), \(\nu\) probability measures on \(X\), and write \(\kappa \circ \mu\) for the law of the output when the input has law \(\mu\). Then

    \[ \mathrm{TV}(\kappa \circ \mu, \kappa \circ \nu) \le \eta_{\mathrm{TV}}(\kappa)\, \mathrm{TV}(\mu, \nu). \]

    No countability or standard-Borel hypothesis is used. The proof writes \(\mu = m + \mu_1\) and \(\nu = m + \nu_1\) with \(m\) the common part of \(\mu\) and \(\nu\), so that \(\mu_1\) and \(\nu_1\) both have mass \(t = \mathrm{TV}(\mu, \nu)\), and compares \(\kappa \circ \mu_1\) with \(\kappa \circ \nu_1\) on each event \(B\) by averaging \(\kappa(x)(B) - \kappa(x')(B) \le \eta_{\mathrm{TV}}(\kappa)\) over \(x \sim \mu_1\), \(x' \sim \nu_1\).

    theorem totalVariationDist_comp_le (κ : Kernel X Y) [IsMarkovKernel κ] (μ ν : Measure X)
    [IsProbabilityMeasure μ] [IsProbabilityMeasure ν] :
    totalVariationDist (κ ∘ₘ μ) (κ ∘ₘ ν) ≤ dobrushinCoeff κ * totalVariationDist μ ν
    noncomputable def totalVariationDist {Ω : Type*} [MeasurableSpace Ω]
    (μ ν : Measure Ω) [IsFiniteMeasure μ] [IsFiniteMeasure ν] : ℝ :=

    TheoremData-processing inequality for total variation#✓fully proved

    MathlibExt.InformationTheory.DobrushinContraction.totalVariationDist_comp_le_self

    For a Markov kernel \(\kappa\) and probability measures \(\mu\), \(\nu\), \(\mathrm{TV}(\kappa \circ \mu, \kappa \circ \nu) \le \mathrm{TV}(\mu, \nu)\). It follows from Dobrushin's contraction since \(\eta_{\mathrm{TV}}(\kappa) \le 1\).

    TheoremStrong data-processing inequality for KL divergence#●ready to prove

    MathlibExt.InformationTheory.StrongDataProcessingWanted.klDiv_comp_le_dobrushinCoeff_mul

    Let \(\kappa\) be a Markov kernel between finite sets (with measurable singletons) and \(\mu\), \(\nu\) probability measures on its input. Then

    \[ D(\kappa \circ \mu \,\|\, \kappa \circ \nu) \le \eta_{\mathrm{TV}}(\kappa)\, D(\mu \,\|\, \nu), \]

    that is, the contraction coefficient \(\eta_{\mathrm{KL}}(\kappa)\) is at most Dobrushin's coefficient. This is an established result recorded as a wanted statement; it is not proved here. The statement is restricted to finite alphabets, the setting of the cited proof.
