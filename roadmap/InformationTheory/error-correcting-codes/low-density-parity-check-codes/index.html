    Low-density parity-check codes

    Gallager's low-density parity-check codes (1962, 1963) are the binary linear codes of sparse parity-check matrices. An \((n, j, k)\) matrix has \(n\) columns, \(j\) ones in each column and \(k\) ones in each row; counting its ones by rows and by columns shows that it has \(nj/k\) rows, so its code has rate at least \(1 - j/k\). Gallager's ensemble stacks \(j\) blocks of \(n/k\) rows: the first block has its ones in consecutive runs of \(k\) columns, and each further block is the first with its columns permuted at random. Every matrix of the ensemble is \((n, j, k)\)-regular.

    DefinitionRegular low-density parity-check matrix#✓fully proved

    Cslib.CodingTheory.LDPC.IsRegular

    A matrix \(H\) over a field is \((j, k)\)-regular if every column has exactly \(j\) nonzero entries and every row exactly \(k\). For a binary matrix with \(n\) columns this is Gallager's \((n, j, k)\) parity-check matrix: \(j\) ones in each column, \(k\) ones in each row, and zeros elsewhere. Its code is an \((n, j, k)\) low-density parity-check code. The Lean definition allows any field; over \(\mathrm{GF}(2)\) it is exactly Gallager's.

    def IsRegular (H : Matrix ρ ι F) (j k : ℕ) : Prop :=
  (∀ c, colWeight H c = j) ∧ ∀ r, rowWeight H r = k
    def colWeight (H : Matrix ρ ι F) (c : ι) : ℕ := (Finset.univ.filter fun r => H r c ≠ 0).card

    Cslib.CodingTheory.LDPC.card_sub_card_le_finrank

    The code of a parity-check matrix with \(m\) rows and \(n\) columns has dimension at least \(n - m\) (truncated subtraction): its dimension is \(n\) minus the rank of the matrix, and the rank is at most \(m\).

    TheoremRate of a regular low-density parity-check code#✓fully proved

    Cslib.CodingTheory.LDPC.one_sub_div_le_rate

    Let \(H\) be a \((j, k)\)-regular parity-check matrix with \(n > 0\) columns, \(k > 0\). Its code \(C\) has rate

    \[\frac{\dim C}{n} \ge 1 - \frac{j}{k}.\]

    This is Gallager's remark that an \((n, j, k)\) parity-check matrix "has \(nj/k\) rows and thus a rate \(R \ge 1 - j/k\)". The rate can be larger, because the rows need not be linearly independent; in Gallager's ensemble at least \(j - 1\) of them are dependent.

    theorem one_sub_div_le_rate {H : Matrix ρ ι F} {j k : ℕ} (h : IsRegular H j k) (hk : 0 < k)
    (hn : 0 < Fintype.card ι) :
    1 - (j : ℝ) / k ≤ finrank F (ofParityCheck H) / Fintype.card ι
    def IsRegular (H : Matrix ρ ι F) (j k : ℕ) : Prop :=
  (∀ c, colWeight H c = j) ∧ ∀ r, rowWeight H r = k

    Gallager's ensemble

    DefinitionColumn permutations of Gallager's ensemble#✓fully proved

    Cslib.CodingTheory.LDPC.blockPerm

    Given permutations \(\sigma_0, \dots, \sigma_{j-1}\) of the \(n\) columns, block \(0\) of Gallager's matrix uses the identity and block \(t \ge 1\) uses \(\sigma_t\); \(\sigma_0\) is ignored.

    def blockPerm {j n : ℕ} (σ : Fin j → Equiv.Perm (Fin n)) (t : Fin j) : Equiv.Perm (Fin n) :=
  if (t : ℕ) = 0 then 1 else σ t

    DefinitionGallager's \((n, j, k)\) matrix with \(n = mk\)#✓fully proved

    Cslib.CodingTheory.LDPC.gallagerMatrix

    Let \(n = mk\). Gallager's matrix has \(jm\) rows, indexed by a block \(t < j\) and a row \(r < m\), and \(n\) columns. Its entry in row \((t, r)\) and column \(c\) is \(1\) if \(\lfloor \pi_t(c) / k \rfloor = r\) and \(0\) otherwise, where \(\pi_t\) is the permutation of block \(t\). So block \(0\) has its ones "in descending order", row \(r\) being \(1\) on the columns \(rk, \dots, rk + k - 1\) (counting from \(0\)), and every other block is block \(0\) with its columns permuted. Gallager's Figure 2.1 is the case \(n = 20\), \(j = 3\), \(k = 4\).

    Gallager's ensemble of \((n, j, k)\) codes is the law of this matrix when \(\sigma_1, \dots, \sigma_{j-1}\) are independent and uniform over all permutations of the columns ("random permutations of the columns of each of the bottom \(j - 1\) submatrices"). The ensemble itself, as a probability law, is not defined in Lean; the theorems on this topic hold for every choice of the permutations, hence for every matrix of the ensemble.

    def gallagerMatrix (m j k : ℕ) (σ : Fin j → Equiv.Perm (Fin (m * k))) :
    Matrix (Fin j × Fin m) (Fin (m * k)) (ZMod 2) :=
  fun r c => if ((blockPerm σ r.1 c : Fin (m * k)) : ℕ) / k = r.2 then 1 else 0
    def blockPerm {j n : ℕ} (σ : Fin j → Equiv.Perm (Fin n)) (t : Fin j) : Equiv.Perm (Fin n) :=
  if (t : ℕ) = 0 then 1 else σ t

    TheoremGallager's matrices are regular#✓fully proved

    Cslib.CodingTheory.LDPC.isRegular_gallagerMatrix

    For every choice of the column permutations, Gallager's matrix with \(n = mk\) is \((j, k)\)-regular: each column has exactly one \(1\) in each of the \(j\) blocks, and each row has exactly \(k\) ones. So it is an \((n, j, k)\) parity-check matrix, as Gallager's construction intends.

    Cslib.CodingTheory.LDPC.one_sub_div_le_rate_gallagerMatrix
