    Cslib.CodingTheory.Hamming74.errorPos

    For a syndrome \(s = (s_0, s_1, s_2) \in \mathbb{F}_2^3\), read its entries as bits of the number \(p = s_0 + 2s_1 + 4s_2 \in \{0, \dots, 7\}\). If \(p = 0\) there is no error position; otherwise the error position is \(p - 1 \in \{0, \dots, 6\}\).

    def errorPos (s : Fin 3 → ZMod 2) : Option (Fin 7) :=
  let p := (s 0).val + 2 * (s 1).val + 4 * (s 2).val
  have hp : p - 1 < 7 := by
    have := ZMod.val_lt (s 0)
    have := ZMod.val_lt (s 1)
    have := ZMod.val_lt (s 2)
    omega
  if p = 0 then none else some ⟨p - 1, hp⟩

    Cslib.CodingTheory.Hamming74.table

    Number the positions of a word in \(\mathbb{F}_2^7\) as \(1, \dots, 7\). For a syndrome \(s = (s_0, s_1, s_2) \in \mathbb{F}_2^3\), read each \(s_i\) as \(0\) or \(1\) and let \(p = s_0 + 2 s_1 + 4 s_2\).   match errorPos s with
  | none => 0
  | some p => Pi.single p 1

    DefinitionSyndrome decoder of the Hamming code#✓fully proved

    Cslib.CodingTheory.Hamming74.decode

    Let \(H\) be the \(3 \times 7\) parity-check matrix of the Hamming code over \(\mathbb{F}_2\), whose column \(j\), for \(j = 1, \dots, 7\), is the binary expansion of \(j\), least significant bit first. Otherwise read the entries of \(s\) as bits of the number \(p = s_0 + 2s_1 + 4s_2 \in \{1, \dots, 7\}\) and return \(y\) with its \(p\)-th bit flipped, counting positions from \(1\).

    def decode (y : Fin 7 → ZMod 2) : Fin 7 → ZMod 2 := y - table (syndrome H y)
