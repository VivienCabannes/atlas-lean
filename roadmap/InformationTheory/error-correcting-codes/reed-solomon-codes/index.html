    StructureSolver for the key equations#✓fully proved

    Cslib.CodingTheory.ReedSolomon.KeySolver

    For a field \(F\), points \(\alpha_0, \dots, \alpha_{n-1} \in F\) and parameters \(k, e \in \mathbb{N}\), a solver for the Berlekamp-Welch key equations is a procedure that takes a received word \(y \in F^n\) and either returns a pair of polynomials \((Q, E)\) over \(F\) or reports failure, such that every returned pair solves the key equations for \(y\), and a pair is returned whenever the key equations for \(y\) have a solution.

    (The key equations are a linear system in the coefficients of \(Q\) and of \(E\); Gaussian elimination is a solver.)

    structure KeySolver (α : Fin n → F) (k e : ℕ) where
  /-- The solving procedure. -/
  solve : (Fin n → F) → Option (F[X] × F[X])
  /-- Returned pairs solve the key equations. -/
  sound : ∀ y QE, solve y = some QE → IsKeySolution α k e y QE.1 QE.2
  /-- A solution is returned whenever one exists. -/
  complete : ∀ y, (∃ Q E, IsKeySolution α k e y Q E) → (solve y).isSome

    DefinitionBerlekamp-Welch decoder#✓fully proved

    Cslib.CodingTheory.ReedSolomon.decode

    Let \(F\) be a field, let \(\alpha_0, \dots, \alpha_{n-1} \in F\), let \(k, e\) be natural numbers and let \(S\) be a solver for the key equations with error budget \(e\). On a received word \(y \in F^n\) the decoder runs \(S\) on \(y\) and reports failure if \(S\) returns nothing. If \(S\) returns a pair \((Q, E)\) (the solver guarantees that \(E\) is monic), let \(q\) be the quotient of \(Q\) by \(E\); the decoder returns \(q\) if \(q\) has degree less than \(k\) and the Hamming distance between \(y\) and \((q(\alpha_0), \dots, q(\alpha_{n-1}))\) is at most \(e\), and reports failure otherwise.

    Its only nontrivial step is the solver.

  (S.solve y).bind fun QE ↦
    if (QE.1 /ₘ QE.2).degree < k ∧ hammingDist y (encode α (QE.1 /ₘ QE.2)) ≤ e then
      some (QE.1 /ₘ QE.2)
    else none
