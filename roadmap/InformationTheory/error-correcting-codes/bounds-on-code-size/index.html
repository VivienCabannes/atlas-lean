    Bounds on code size

    How many codewords can a code of length \(n\) over \(q\) letters have if any two are at Hamming distance at least \(d\)? Upper bounds come from packing (Hamming), projection (Singleton), averaging distances (Plotkin) and list decoding (Elias–Bassalygo); the Gilbert–Varshamov bound shows by a greedy covering argument that codes of rate \(1 - H_q(\delta)\) and relative distance \(\delta\) exist, linear ones included.

    TheoremVolume of a Hamming ball, entropy upper bound#✓fully proved

    MathlibExt.InformationTheory.HammingBallVolume.sum_choose_mul_pow_le_exp

    Let \(q \ge 2\), \(0 \le p \le 1 - 1/q\), and let \(e \le pn\) be a natural number. Then

    \[\mathrm{Vol}_q(n, e) = \sum_{i=0}^{e} \binom{n}{i} (q-1)^i \le \exp\bigl(n \, H(q, p)\bigr) = q^{H_q(p) n},\]

    where \(H(q, p) = p \log (q-1) - p \log p - (1-p) \log (1-p)\) is Mathlib's Real.qaryEntropy (natural logarithm) and \(H_q(p) = H(q, p) / \log q\) is the \(q\)-ary entropy of Definition 3.3.1 in Guruswami, Rudra and Sudan.

    The proof compares each term with the binomial expansion of \((p + (1-p))^n = 1\): for \(i \le pn\), \((q-1)^i q^{-H_q(p) n} \le p^i (1-p)^{n-i}\) because \(p / ((q-1)(1-p)) \le 1\).

    The matching lower bound \(\mathrm{Vol}_q(n, \lfloor pn \rfloor) \ge q^{H_q(p) n - o(n)}\) (Proposition 3.3.3 (ii)) is also proved.

    theorem sum_choose_mul_pow_le_exp {q n e : ℕ} {p : ℝ} (hq : 2 ≤ q) (hp0 : 0 ≤ p)
    (hp1 : p ≤ 1 - 1 / q) (he : (e : ℝ) ≤ p * n) :
    ((∑ i ∈ range (e + 1), n.choose i * (q - 1) ^ i : ℕ) : ℝ) ≤
      exp (n * qaryEntropy q p)

    TheoremThe central binomial term#✓fully proved

    MathlibExt.InformationTheory.HammingBallVolume.central_term_ge

    For \(0 < n\) and \(0 \le m \le n\), with \(x = m/n\),

    \[\binom{n}{m} x^m (1 - x)^{n - m} \ge \frac{1}{n + 1}.\]

    The terms \(t_k = \binom{n}{k} x^k (1-x)^{n-k}\), \(0 \le k \le n\), sum to \((x + (1 - x))^n = 1\), and \(t_m\) is the largest: from \(\binom{n}{k+1}(k+1) = \binom{n}{k}(n-k)\) the ratio \(t_{k+1}/t_k = \frac{(n-k)\, m}{(k+1)(n-m)}\) is at least \(1\) for \(k < m\) and at most \(1\) for \(k \ge m\).

    theorem central_term_ge {n m : ℕ} (hn : 0 < n) (hm : m ≤ n) :
    1 / ((n : ℝ) + 1) ≤ n.choose m * ((m : ℝ) / n) ^ m * (1 - (m : ℝ) / n) ^ (n - m)
    Sources

    TheoremThe largest term of a Hamming-ball volume#✓fully proved

    MathlibExt.InformationTheory.HammingBallVolume.choose_mul_pow_ge

    For \(q \ge 2\), \(0 < n\) and \(0 \le m \le n\), with \(x = m/n\),

    \[\binom{n}{m} (q-1)^m \ge \frac{\exp\bigl(n \, H(q, x)\bigr)}{n + 1} = \frac{q^{H_q(x) n}}{n + 1},\]

    TheoremVolume of a Hamming ball, entropy lower bound#✓fully proved

    MathlibExt.InformationTheory.HammingBallVolume.sum_choose_mul_pow_ge_exp

    Let \(q \ge 2\) and \(0 \le p \le 1\). For every \(\eta > 0\) and all large enough \(n\),

    \[\mathrm{Vol}_q(n, \lfloor pn \rfloor) = \sum_{i=0}^{\lfloor pn \rfloor} \binom{n}{i} (q-1)^i \ge \exp\bigl(n \, H(q, p) - \eta n\bigr),\]

    where \(H(q, p)\) is Mathlib's Real.qaryEntropy (natural logarithm). In base \(q\) this is \(\mathrm{Vol}_q(n, pn) \ge q^{H_q(p) n - o(n)}\), Proposition 3.3.3 (ii) of Guruswami, Rudra and Sudan, stated there for \(0 \le p \le 1 - 1/q\); the \(o(n)\) term is written \(\eta n\) for an arbitrary \(\eta > 0\). With the upper bound it shows \(\mathrm{Vol}_q(n, pn) = q^{H_q(p) n + o(n)}\) for \(p \le 1 - 1/q\).

    The proof keeps the single term \(i = m = \lfloor pn \rfloor\), which is at least \(\exp(n H(q, m/n)) / (n + 1)\) (largest term); then \(|m/n - p| < 1/n\), the entropy is uniformly continuous on \([0, 1]\), and \(\log(n + 1) = o(n)\). Guruswami, Rudra and Sudan use Stirling's approximation instead.

    theorem sum_choose_mul_pow_ge_exp {q : ℕ} (hq : 2 ≤ q) {p : ℝ} (hp0 : 0 ≤ p) (hp1 : p ≤ 1)
    {η : ℝ} (hη : 0 < η) :
    ∃ N : ℕ, ∀ n ≥ N,
      exp (n * qaryEntropy q p - η * n) ≤
        ((∑ i ∈ range (⌊p * n⌋₊ + 1), n.choose i * (q - 1) ^ i : ℕ) : ℝ)

    Upper bounds

    TheoremSingleton bound#✓fully proved

    MathlibExt.Combinatorics.Coding.SingletonBound.singleton_bound

    Let \(\alpha\) be a nonempty finite alphabet with \(q\) letters, and let \(n\) and \(d\) be natural numbers with \(1 \le d \le n\). If \(C\) is a set of words of length \(n\) over \(\alpha\) in which any two distinct words are at Hamming distance at least \(d\), then \(C\) has at most \(q^{n - d + 1}\) elements.

    The proof punctures the code to its first \(n - d + 1\) coordinates: two codewords agreeing on all retained coordinates can differ in at most the \(d - 1\) deleted coordinates, contradicting the minimum-distance hypothesis, so puncturing is injective on the code and the bound follows by counting the punctured words.

    public theorem singleton_bound
    {α : Type*} [Fintype α] [DecidableEq α] [Nonempty α]
    {n d : ℕ}
    (C : Finset (Fin n → α))
    (hd1 : 1 ≤ d)
    (hd2 : d ≤ n)
    (hDist : ∀ c₁ ∈ C, ∀ c₂ ∈ C, c₁ ≠ c₂ →
      d ≤ hammingDist c₁ c₂) :
    C.card ≤ (Fintype.card α) ^ (n - d + 1)
    Background

    TheoremHamming bound#✓fully proved

    MathlibExt.Combinatorics.Coding.HammingSpherePacking.hamming_sphere_packing_bound

    Let \(\alpha\) be a finite alphabet with \(q \ge 2\) letters, and let \(n\) and \(t\) be natural numbers. If \(C\) is a set of words of length \(n\) over \(\alpha\) in which any two distinct words are at Hamming distance at least \(2t + 1\), then

    \[|C| \sum_{i=0}^{t} \binom{n}{i} (q - 1)^i \le q^n.\]

    The proof packs disjoint radius-\(t\) Hamming balls around the codewords into the ambient space: the distance hypothesis forces the balls apart (any overlap would give a triangle-inequality contradiction), and each ball contains exactly \(\sum_{i=0}^{t} \binom{n}{i} (q - 1)^i\) words.

    This is the \(q\)-ary generalization of Hamming's binary sphere-packing bound. The original paper assumes binary words and derives the \(2^n\) form; the same disjoint-ball counting argument gives the formula stated here for an arbitrary finite alphabet.

    public theorem hamming_sphere_packing_bound
    {α : Type*} [Fintype α] [DecidableEq α]
    {n t : ℕ}
    (C : Finset (Fin n → α))
    (hα : 2 ≤ Fintype.card α)
    (hDist : ∀ c₁ ∈ C, ∀ c₂ ∈ C, c₁ ≠ c₂ →
      2 * t + 1 ≤ hammingDist c₁ c₂) :
    C.card * (∑ i ∈ Finset.range (t + 1),
      n.choose i * (Fintype.card α - 1) ^ i) ≤ (Fintype.card α) ^ n
    Background
    Background

    TheoremDisagreeing pairs in a coordinate#✓fully proved

    MathlibExt.Combinatorics.Coding.PlotkinBound.card_mul_sum_ne_le

    Let \(C\) be a code over an alphabet with \(q\) letters and \(j\) a coordinate. At most a \(1 - 1/q\) fraction of the \(|C|^2\) ordered pairs of codewords disagree at \(j\):

    \[q \cdot |\{(c, c') \in C^2 : c_j \ne c'_j\}| \le (q - 1) |C|^2.\]

    If \(m_a\) codewords have symbol \(a\) at \(j\), the agreeing pairs number \(\sum_a m_a^2\), which is at least \((\sum_a m_a)^2 / q = |C|^2 / q\) by Cauchy–Schwarz.

    theorem card_mul_sum_ne_le (C : Finset (Fin n → α)) (j : Fin n) :
    Fintype.card α * ∑ c ∈ C, ∑ c' ∈ C, (if c j ≠ c' j then (1 : ℕ) else 0) ≤
      (Fintype.card α - 1) * C.card ^ 2

    TheoremPlotkin bound#✓fully proved

    MathlibExt.Combinatorics.Coding.PlotkinBound.card_mul_le

    Let \(C\) be a code of length \(n\) over an alphabet with \(q\) letters whose distinct codewords are at Hamming distance at least \(d\), where \(q d > (q - 1) n\), that is \(d > (1 - 1/q) n\). Then

    \[|C| \bigl(q d - (q-1) n\bigr) \le q d, \qquad\text{that is}\qquad |C| \le \frac{q d}{q d - (q-1) n}.\]

    This is part 2 of Theorem 4.4.1 of Guruswami, Rudra and Sudan. The proof here is the classical averaging argument: summing \(\Delta(c, c')\) over all ordered pairs of codewords gives at least \(|C|(|C| - 1) d\), while in each coordinate at most \((1 - 1/q)|C|^2\) ordered pairs disagree (disagreeing pairs in a coordinate). Guruswami, Rudra and Sudan prove it instead with a geometric lemma on vectors with pairwise non-positive inner products. Part 1 (\(d = (1 - 1/q) n\) gives \(|C| \le 2 q n\)) and the asymptotic consequence \(R \le 1 - \frac{q}{q-1}\delta + o(1)\) (Corollary 4.4.2) are not formalized here.

    theorem card_mul_le (C : Finset (Fin n → α)) {d : ℕ}
    (hdist : ∀ c₁ ∈ C, ∀ c₂ ∈ C, c₁ ≠ c₂ → d ≤ hammingDist c₁ c₂)
    (hd : (Fintype.card α - 1) * n < Fintype.card α * d) :
    C.card * (Fintype.card α * d - (Fintype.card α - 1) * n) ≤ Fintype.card α * d
    Background
    Background
    • Disagreeing pairs in a coordinate: the per-coordinate count behind the classical averaging proof given here.
    • Singleton bound: by the Plotkin bound (its asymptotic form, Corollary 4.4.2), codes meeting the Singleton bound need alphabets that grow with \(n\), as Reed–Solomon codes have (Guruswami, Rudra and Sudan, Section 5.2).

    TheoremElias–Bassalygo bound (alphabet-free form)#✓fully proved

    MathlibExt.Combinatorics.Coding.EliasBassalygo.card_mul_sum_le

    Let \(C\) be a code of length \(n\) over a nonempty alphabet with \(q\) letters, with distinct codewords at Hamming distance at least \(d \le n\), and let \(e \le n\) satisfy \(n(n - d) < (n - e)^2\), that is \(e < n - \sqrt{n(n-d)}\). Then

    \[|C| \cdot \mathrm{Vol}_q(n, e) \le n d \, q^n, \qquad \mathrm{Vol}_q(n, e) = \sum_{i=0}^{e} \binom{n}{i} (q-1)^i.\]

    This is the proof of the Elias–Bassalygo bound, Theorem 8.1.1 of Guruswami, Rudra and Sudan: some ball of radius \(e\) holds at least \(|C| \mathrm{Vol}_q(n, e)/q^n\) codewords (their Lemma 8.1.2), and by the Johnson bound at most \(n d\). They use the \(q\)-ary Johnson radius \(n J_q(d/n)\) (Theorem 7.3.1) and obtain \(R \le 1 - H_q(J_q(\delta)) + o(1)\); with the alphabet-free radius used here the same argument gives the weaker \(R \le 1 - H_q(1 - \sqrt{1 - \delta}) + o(1)\), since \(J_q(\delta) \ge 1 - \sqrt{1 - \delta}\). The asymptotic forms are not stated in Lean.

    theorem card_mul_sum_le [Nonempty α] (C : Finset (Fin n → α)) {d e : ℕ} (hen : e ≤ n)
    (hdn : d ≤ n) (hdist : ∀ c₁ ∈ C, ∀ c₂ ∈ C, c₁ ≠ c₂ → d ≤ hammingDist c₁ c₂)
    (hJ : n * (n - d) < (n - e) ^ 2) :
    C.card * ∑ i ∈ range (e + 1), n.choose i * (Fintype.card α - 1) ^ i ≤
      n * d * Fintype.card α ^ n

    TheoremA maximal code is covering#✓fully proved

    MathlibExt.Combinatorics.Coding.GilbertVarshamov.biUnion_ball_eq_univ_of_maximal

    Let \(C \subseteq \alpha^n\) be a code to which no word can be added without creating two codewords at distance less than \(d\): every word at distance at least \(d\) from all codewords already lies in \(C\). Then the Hamming balls of radius \(d - 1\) around the codewords cover \(\alpha^n\).

    Indeed, a word outside all these balls is at distance at least \(d\) from every codeword, so it lies in \(C\), hence in its own ball.

    theorem biUnion_ball_eq_univ_of_maximal (C : Finset (Fin n → α)) {d : ℕ}
    (hmax : ∀ v, (∀ c ∈ C, d ≤ hammingDist c v) → v ∈ C) :
    C.biUnion (fun c => Hamming.ball c (d - 1)) = univ
    def ball (x : ι → F) (e : ℕ) : Finset (ι → F) :=
  Finset.univ.filter fun y => hammingDist x y ≤ e

    TheoremGilbert–Varshamov bound#✓fully proved

    MathlibExt.Combinatorics.Coding.GilbertVarshamov.exists_code_pow_le_card_mul_sum

    Let \(\alpha\) be a finite alphabet with \(q\) letters and let \(n \ge 0\) and \(d \ge 1\) be natural numbers. There is a code \(C \subseteq \alpha^n\) in which any two distinct codewords are at Hamming distance at least \(d\) and

    \[q^n \le |C| \sum_{i=0}^{d-1} \binom{n}{i} (q-1)^i = |C| \cdot \mathrm{Vol}_q(n, d-1).\]

    The proof is Gilbert's greedy construction: a code of maximum size among the codes of minimum distance at least \(d\) is maximal, so the Hamming balls of radius \(d - 1\) around its codewords cover \(\alpha^n\) (a maximal code is covering), and each ball has \(\mathrm{Vol}_q(n, d-1)\) words (size of a Hamming ball).

    Combined with the entropy bound on the volume this gives the rate form \(R \ge 1 - H_q(\delta)\); the linear version is Varshamov's.

    theorem exists_code_pow_le_card_mul_sum (n : ℕ) {d : ℕ} (hd : 1 ≤ d) :
    ∃ C : Finset (Fin n → α),
      (∀ c₁ ∈ C, ∀ c₂ ∈ C, c₁ ≠ c₂ → d ≤ hammingDist c₁ c₂) ∧
      Fintype.card α ^ n ≤
        C.card * ∑ i ∈ range d, n.choose i * (Fintype.card α - 1) ^ i

    TheoremGilbert–Varshamov bound, rate form#✓fully proved

    MathlibExt.Combinatorics.Coding.GilbertVarshamov.exists_code_exp_le_card

    Let \(\alpha\) be an alphabet with \(q \ge 2\) letters, let \(0 \le \delta \le 1 - 1/q\), and let \(n\) and \(d\) be natural numbers with \(1 \le d\) and \(d - 1 \le \delta n\). There is a code \(C \subseteq \alpha^n\) in which any two distinct codewords are at Hamming distance at least \(d\) and

    \[|C| \ge \exp\bigl(n (\log q - H(q, \delta))\bigr) = q^{(1 - H_q(\delta)) n},\]

    where \(H(q, \delta) = \delta \log (q-1) - \delta \log \delta - (1-\delta) \log (1-\delta)\) is Mathlib's Real.qaryEntropy (natural logarithm) and \(H_q(\delta) = H(q, \delta) / \log q\) is the \(q\)-ary entropy. When \(\delta n > 0\), taking \(d = \lceil \delta n \rceil\) gives a code of rate at least \(1 - H_q(\delta)\) and relative distance at least \(\delta\): this is the general-code part of Theorem 4.2.1 of Guruswami, Rudra and Sudan, there stated for \(0 \le \delta < 1 - 1/q\).

    Cslib.CodingTheory.GilbertVarshamov.exists_extend

    Let \(C\) be a linear code of length \(n\) over a finite field \(F\) with \(q\) elements whose nonzero codewords all have weight at least \(d \ge 1\). If

    \[q^{\dim C} \cdot \mathrm{Vol}_q(n, d-1) < q^n,\]

    then there is a linear code \(C' \supseteq C\) with \(\dim C' = \dim C + 1\) whose nonzero codewords all have weight at least \(d\).

    The balls of radius \(d - 1\) around the \(q^{\dim C}\) codewords miss some word \(v\); then \(C' = C + Fv\). A nonzero word \(c + av\) of \(C'\) with \(a \ne 0\) is \(a(v - c')\) with \(c' = -a^{-1} c \in C\), so its weight is the distance from \(v\) to \(c'\), at least \(d\).

    theorem exists_extend {C : LinearCode F (Fin n)} {d : ℕ} (hd : 1 ≤ d)
    (hC : ∀ c ∈ C, c ≠ 0 → d ≤ hammingNorm c)
    (hvol : Fintype.card F ^ finrank F C *
      ∑ i ∈ range d, n.choose i * (Fintype.card F - 1) ^ i < Fintype.card F ^ n) :
    ∃ C' : LinearCode F (Fin n), C ≤ C' ∧ finrank F C' = finrank F C + 1 ∧
      ∀ c ∈ C', c ≠ 0 → d ≤ hammingNorm c

    Let \(F\) be a finite field with \(q\) elements and let \(n\), \(k\) and \(d \ge 1\) be natural numbers. If

    \[q^k \sum_{i=0}^{d-1} \binom{n}{i} (q-1)^i < q^n,\]
