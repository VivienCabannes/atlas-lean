    List decoding

    A code is list decodable from \(e\) errors with list size \(L\) if every Hamming ball of radius \(e\) contains at most \(L\) codewords. Allowing a short list instead of a unique answer lets a decoder correct far more than half the minimum distance. The Johnson bound guarantees polynomial lists for every code up to the radius \(n - \sqrt{n(n-d)}\), which for Reed–Solomon codes of rate \(R\) is a \(1 - \sqrt{R}\) fraction of errors; the list-decoding capacity theorem identifies \(1 - H_q(\rho)\) as the best rate for a fraction \(\rho\) of errors. The Guruswami–Sudan algorithm finds, for any parameters \(D, r\) with enough monomials, every message polynomial agreeing with the received word in more than \(D / r\) positions; this correctness is proved here. Guruswami, Rudra and Sudan (Theorem 12.2.12) choose \(D\) and \(r\) so that it decodes up to the \(1 - \sqrt{R}\) radius; that parameter choice and the running time are not formalized.

    DefinitionList-decodable code#✓fully proved

    MathlibExt.Combinatorics.Coding.ListDecoding.IsListDecodable

    A code \(C \subseteq \alpha^n\) is list decodable from \(e\) errors with list size \(L\) if every Hamming ball of radius \(e\) contains at most \(L\) codewords: for every received word \(y \in \alpha^n\),

    \[|\{c \in C : \Delta(y, c) \le e\}| \le L.\]

    Guruswami, Rudra and Sudan (Definition 7.2.1) call such a code \((\rho, L)\)-list decodable, with the radius written \(\rho n\) for a fraction \(\rho\) of errors; here the radius is the integer \(e\). For \(L = 1\) and \(e = \lfloor (d-1)/2 \rfloor\) this is unique decoding up to half the minimum distance \(d\).

    def IsListDecodable (C : Finset (Fin n → α)) (e L : ℕ) : Prop :=
  ∀ y : Fin n → α, (C.filter fun c => hammingDist y c ≤ e).card ≤ L

    TheoremJohnson bound#✓fully proved

    MathlibExt.Combinatorics.Coding.ListDecoding.johnson_bound

    Let \(S\) be a set of words of length \(n\) over a finite alphabet, any two distinct at Hamming distance at least \(d\), all within distance \(e\) of a word \(y\). Suppose \(e \le n\), \(d \le n\) and

    \[n (n - d) < (n - e)^2, \quad\text{that is,}\quad e < n - \sqrt{n (n - d)}.\]

    Then

    \[|S| \bigl((n - e)^2 - n (n - d)\bigr) \le n (d - e);\]

    both factors in brackets are positive under the hypothesis. So a code of minimum distance \(d\) has at most \(n (d - e) / ((n - e)^2 - n(n - d))\) codewords in any ball of radius \(e\), in particular at most \(n d\) (list size \(n d\)).

    This is the strict-inequality case of the alphabet-free Johnson bound, Theorem 7.3.3 of Guruswami, Rudra and Sudan, with an explicit list size (they give \(q n d\); their Exercise 7.5 improves it to \(n\) for radius at most \(n - \sqrt{n(n-d)} - 1\), so \(n d\) is not the best alphabet-free list size). The proof is the double-counting argument they give for the binary case of Theorem 7.3.1: with \(m_j\) the number of words of \(S\) agreeing with \(y\) in coordinate \(j\),

    • \(\sum_j m_j \ge |S| (n - e)\), since each word agrees with \(y\) in at least \(n - e\) places;
    • \(\sum_j m_j (m_j - 1) \le |S| (|S| - 1)(n - d)\), since two distinct words agreeing with \(y\) in a coordinate agree with each other there, which happens in at most \(n - d\) coordinates;
    • \((\sum_j m_j)^2 \le n \sum_j m_j^2\) by Cauchy–Schwarz,

    and the three combine into the stated inequality.

    theorem johnson_bound (S : Finset (Fin n → α)) (y : Fin n → α) {d e : ℕ} (hen : e ≤ n)
    (hdn : d ≤ n) (hdist : ∀ c₁ ∈ S, ∀ c₂ ∈ S, c₁ ≠ c₂ → d ≤ hammingDist c₁ c₂)
    (hball : ∀ c ∈ S, hammingDist y c ≤ e) (hJ : n * (n - d) < (n - e) ^ 2) :
    S.card * ((n - e) ^ 2 - n * (n - d)) ≤ n * ((n - e) - (n - d))

    Background
    Background
    • Hamming bound: balls of radius \(\lfloor (d-1)/2 \rfloor\) around codewords are disjoint, so the list size there is \(1\). The Johnson radius \(n - \sqrt{n(n-d)}\) is at least \(d/2\) (as \((1 - s/2)^2 \ge 1 - s\)), so list decoding up to it goes beyond unique decoding.
    • Reed–Solomon codes are list decodable up to the Johnson radius: the bound for the MDS codes, \(d = n - k + 1\), where it gives the radius \(1 - \sqrt{R}\), which the Guruswami–Sudan algorithm reaches with the parameters of Theorem 12.2.12.

    TheoremJohnson bound, list size \(n d\)#✓fully proved

    MathlibExt.Combinatorics.Coding.ListDecoding.card_le_mul_of_johnson

    Under the hypotheses of the Johnson bound (\(e \le n\), \(d \le n\), words pairwise at distance at least \(d\), all within distance \(e\) of \(y\), and \(n(n-d) < (n-e)^2\)), the set has at most \(n d\) words: the denominator \((n-e)^2 - n(n-d)\) is a positive integer and the numerator \(n (d - e)\) is at most \(n d\).

    Let \(C\) be a code of length \(n\) whose distinct codewords are at Hamming distance at least \(d \le n\), and let \(e \le n\) satisfy \(n(n-d) < (n-e)^2\), that is \(e < n - \sqrt{n(n-d)}\). Then \(C\) is list decodable from \(e\) errors with list size \(n d\).

    List-decoding capacity

    TheoremList-decoding capacity, achievability#✓fully proved

    MathlibExt.Combinatorics.Coding.ListDecodingCapacity.exists_encoding_listDecodable

    Let \(\alpha\) be an alphabet with \(q \ge 2\) letters, let \(0 < \rho < 1 - 1/q\) and \(L \ge 1\), and let \(n, k\) be natural numbers with

    \[k \le \Bigl(1 - H_q(\rho) - \frac{1}{L}\Bigr) n,\]

    where \(H_q(\rho)\) is the \(q\)-ary entropy (written in Lean as Real.qaryEntropy q ρ / log q). Then there is an encoding map \(C : \alpha^k \to \alpha^n\) such that every Hamming ball of radius \(\rho n\) contains the encodings of at most \(L\) messages.

    This is Theorem 7.4.2 (i) of Guruswami, Rudra and Sudan in the form proved in their Section 7.4.1: if the \(q^k\) codewords are chosen independently and uniformly, the union bound over the \(q^n\) centres and the \(\binom{q^k}{L+1}\) sets of \(L + 1\) messages bounds the probability of a bad event by \(q^{-n/L} < 1\). The Lean proof is that union bound written as a count of encoding maps: at most \(q^n \binom{q^k}{L+1} \mathrm{Vol}_q(n, \rho n)^{L+1} (q^n)^{q^k - L - 1}\) of the \((q^n)^{q^k}\) maps are bad. List sizes are counted over messages, as in that proof; the set form gives a list-decodable code with at least \(q^k / L\) codewords. Together with the converse it shows that the list-decoding capacity is \(1 - H_q(\rho)\).

    theorem exists_encoding_listDecodable {α : Type*} [Fintype α] [DecidableEq α]
    (hq : 2 ≤ Fintype.card α) {ρ : ℝ} (hρ0 : 0 < ρ) (hρ1 : ρ < 1 - 1 / (Fintype.card α : ℝ))
    {L : ℕ} (hL : 1 ≤ L) (n k : ℕ)
    (hk : (k : ℝ) ≤
      (1 - qaryEntropy (Fintype.card α) ρ / log (Fintype.card α) - 1 / (L : ℝ)) * n) :
    ∃ C : (Fin k → α) → (Fin n → α), ∀ y : Fin n → α,
      (univ.filter fun m => (hammingDist y (C m) : ℝ) ≤ ρ * n).card ≤ L

    MathlibExt.Combinatorics.Coding.ListDecodingCapacity.exists_isListDecodable

    Under the hypotheses of list-decoding capacity, achievability (\(q \ge 2\), \(0 < \rho < 1 - 1/q\), \(L \ge 1\), \(k \le (1 - H_q(\rho) - 1/L) n\)), there is a code \(C \subseteq \alpha^n\) that is list decodable from \(\lfloor \rho n \rfloor\) errors with list size \(L\) and has \(q^k \le L \cdot |C|\).     TheoremSome ball holds many codewords#✓fully proved

    MathlibExt.Combinatorics.Coding.ListDecoding.exists_mul_card_filter_ge

    Let \(C\) be a code of length \(n\) over a nonempty alphabet with \(q\) letters and let \(e\) be a radius. Some word \(y\) satisfies

    \[|C| \cdot \mathrm{Vol}_q(n, e) \le q^n \cdot |\{c \in C : \Delta(y, c) \le e\}|, \qquad \mathrm{Vol}_q(n, e) = \sum_{i=0}^{e} \binom{n}{i} (q-1)^i.\]

    For a uniformly random centre \(y\) each codeword lies in the ball \(B(y, e)\) with probability \(\mathrm{Vol}_q(n, e)/q^n\), so the expected number of codewords in the ball is \(|C| \mathrm{Vol}_q(n, e) / q^n\) and some centre does at least as well. This is Lemma 8.1.2 of Guruswami, Rudra and Sudan, and the averaging step (equations (7.12)–(7.16)) in their proof of the converse half of list-decoding capacity; with the volume lower bound \(\mathrm{Vol}_q(n, \rho n) \ge q^{H_q(\rho) n - o(n)}\) it forces lists of size \(q^{\Omega(\varepsilon n)}\) at rate \(1 - H_q(\rho) + \varepsilon\).

    theorem exists_mul_card_filter_ge [Fintype α] [Nonempty α] (C : Finset (Fin n → α)) (e : ℕ) :
    ∃ y : Fin n → α,
      C.card * ∑ i ∈ range (e + 1), n.choose i * (Fintype.card α - 1) ^ i ≤
        Fintype.card α ^ n * (C.filter fun c => hammingDist y c ≤ e).card

    TheoremList-decoding capacity, converse#✓fully proved

    MathlibExt.Combinatorics.Coding.ListDecodingCapacity.exists_many_in_ball

    Let \(\alpha\) be an alphabet with \(q \ge 2\) letters, let \(0 < \rho < 1 - 1/q\) and \(\varepsilon > 0\). For all large enough \(n\), every code \(C \subseteq \alpha^n\) with at least \(q^{(1 - H_q(\rho) + \varepsilon) n}\) codewords has a Hamming ball of radius \(\rho n\) containing at least \(q^{\varepsilon n / 2}\) codewords. So a code of rate \(1 - H_q(\rho) + \varepsilon\) that is list decodable from \(\rho n\) errors needs lists of size at least \(q^{\varepsilon n / 2}\).

    This is Theorem 7.4.1 (ii) (equivalently Theorem 7.4.2 (ii)) of Guruswami, Rudra and Sudan, which states \(L \ge q^{\Omega(\varepsilon n)}\); the constant in \(\Omega\) is taken here to be \(1/2\). The proof is theirs: a ball with a uniformly random centre holds \(|C| \mathrm{Vol}_q(n, \rho n) / q^n\) codewords on average, and \(\mathrm{Vol}_q(n, \rho n) \ge q^{H_q(\rho) n - \varepsilon n / 2}\) for large \(n\). In the Lean statement \(q^x\) is written \(\exp(x \log q)\) and \(H_q(\rho) \log q\) is Real.qaryEntropy q ρ. Together with achievability it shows that the list-decoding capacity is \(1 - H_q(\rho)\).

    theorem exists_many_in_ball {α : Type*} [Fintype α] [DecidableEq α]
    (hq : 2 ≤ Fintype.card α) {ρ : ℝ} (hρ0 : 0 < ρ) (hρ1 : ρ < 1 - 1 / (Fintype.card α : ℝ))
    {ε : ℝ} (hε : 0 < ε) :
    ∃ N : ℕ, ∀ n ≥ N, ∀ C : Finset (Fin n → α),
      exp (n * (log (Fintype.card α) - qaryEntropy (Fintype.card α) ρ +
        ε * log (Fintype.card α))) ≤ C.card →
      ∃ y : Fin n → α,
        exp (ε * n / 2 * log (Fintype.card α)) ≤
          ((C.filter fun c => (hammingDist y c : ℝ) ≤ ρ * n).card : ℝ)

    DefinitionWeighted degree bound#✓fully proved

    Cslib.CodingTheory.GuruswamiSudan.WeightedDegLE

    A bivariate polynomial \(Q(X, Y) = \sum_{i,j} q_{ij} X^i Y^j\) over a field \(F\) has \((1, w)\)-weighted degree at most \(D\) if \(i + w j \le D\) for every monomial \(X^i Y^j\) with \(q_{ij} \ne 0\). For \(w = 1\) this is the total degree.

    In Lean, bivariate polynomials are elements of F[X][X]: the outer variable is \(Y\) and the coefficients are polynomials in \(X\).

    def WeightedDegLE (w D : ℕ) (Q : F[X][X]) : Prop :=
  ∀ j i, (Q.coeff j).coeff i ≠ 0 → i + w * j ≤ D

    DefinitionRoot of multiplicity \(r\)#✓fully proved

    Cslib.CodingTheory.GuruswamiSudan.HasRootMult

    A bivariate polynomial \(Q \in F[X][Y]\) has a root of multiplicity at least \(r\) at \((a, b)\) if \(Q\) lies in the \(r\)-th power of the ideal of the point \((X - a, Y - b)\).

    Guruswami, Rudra and Sudan (Definitions 12.2.8 and 12.2.9) phrase this as: the translate \(Q(X + a, Y + b)\) has no monomial of total degree less than \(r\). The two definitions agree, since the translation is a ring automorphism carrying \((X - a, Y - b)\) to \((X, Y)\), and a polynomial lies in \((X, Y)^r\) exactly when all its monomials have total degree at least \(r\). The direction used by the interpolation step is proved; the converse is not formalized. For \(r = 1\) the condition is \(Q(a, b) = 0\).

    def HasRootMult (Q : F[X][X]) (a b : F) (r : ℕ) : Prop :=
  Q ∈ pointIdeal a b ^ r
