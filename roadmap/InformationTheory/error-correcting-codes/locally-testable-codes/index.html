    DefinitionMinimum distance of a binary code#✓fully proved

    MathlibExt.Combinatorics.GoodLTCodesWanted.GoodLTC.distance

    The distance of a binary code \(C \subseteq \mathbb{F}_2^n\) is the smallest Hamming weight (number of nonzero coordinates) of a nonzero codeword of \(C\), and is \(0\) if \(C = \{0\}\).

    When \(C \neq \{0\}\), since \(C\) is linear, this is the minimum Hamming distance between two distinct codewords.

    noncomputable def distance : ℕ :=
  sInf {d | ∃ c ∈ C, c ≠ 0 ∧ hammingNorm c = d}

    MathlibExt.Combinatorics.GoodLTCodesWanted.GoodLTC.distanceFrom

    For a binary code \(C \subseteq \mathbb{F}_2^n\) and a word \(f \in \mathbb{F}_2^n\), the distance from \(f\) to \(C\) is the minimum, over all codewords \(c \in C\), of the Hamming distance between \(f\) and \(c\), that is, the number of coordinates in which \(f\) and \(c\) differ.

    noncomputable def distanceFrom (f : 𝔽₂ⁿ) : ℕ :=
  sInf {d | ∃ c ∈ C, hammingNorm (f - c) = d}

    MathlibExt.Combinatorics.GoodLTCodesWanted.GoodLTC.normalisedDistanceFrom

    For a binary code \(C \subseteq \mathbb{F}_2^n\) and a word \(f \in \mathbb{F}_2^n\), the normalised distance from \(f\) to \(C\) is the distance from \(f\) to \(C\) (the Hamming distance from \(f\) to a closest codeword) divided by the length \(n\), as a nonnegative real number; it is \(0\) when \(n = 0\).

    DefinitionGood family of codes#✓fully proved

    MathlibExt.Combinatorics.GoodLTCodesWanted.GoodLTC.IsGood

    Let \((n_i)_{i \in \mathbb{N}}\) be natural numbers and, for each \(i\), let \(C_i \subseteq \mathbb{F}_2^{n_i}\) be a binary code of length \(n_i\). The family \((C_i)\) is good if \(n_i \to \infty\) as \(i \to \infty\) and there is a real number \(\varepsilon > 0\) such that for every \(i\) both the rate and the normalised distance of \(C_i\) are at least \(\varepsilon\).

    def IsGood {n : ℕ → ℕ} (𝒞 : (i : ℕ) → BinaryCode (n i)) : Prop :=
  Filter.Tendsto n Filter.atTop Filter.atTop ∧
    ∃ ε > 0, ∀ i, ε ≤ rate (𝒞 i) ∧ ε ≤ normalisedDistance (𝒞 i)

    StructureLocally testable code#✓fully proved

    MathlibExt.Combinatorics.GoodLTCodesWanted.GoodLTC.LTC

    Let \(C \subseteq \mathbb{F}_2^n\) be a binary code, let \(q\) be a natural number and let \(\kappa \ge 0\) be a real number. A \(\kappa\)-local tester for \(C\) with \(q\) queries consists of a probability distribution on the subsets \(S \subseteq \{0, 1, \dots, n - 1\}\) with at most \(q\) elements, together with, for each such \(S\), a set \(V_S \subseteq \mathbb{F}_2^S\) of allowed local views, such that: * if \(f \in C\), then \(f|_S \in V_S\) for every such \(S\); * for every \(f \in \mathbb{F}_2^n\), the probability that \(f|_S \notin V_S\) for a random \(S\) is at least \(\kappa\) times the normalised distance from \(f\) to \(C\).

    The code \(C\) is \(\kappa\)-locally testable with \(q\) queries exactly when such a tester exists.

    structure LTC (q : ℕ) (κ : ℝ≥0) (C : BinaryCode n) where
  /-- The probability distribution on the collection of `q`-element (or less) subsets of `Fin n`. -/
  prob : PMF (cardLE n q)
  /-- The set `V_S ⊆ 𝔽₂^S` of allowed local views associated to a given subset `S ⊆ Fin n`. -/
  views (S : cardLE n q) : Set (S.val → ZMod 2)
  cond1 (f : 𝔽₂ⁿ) (hf : f ∈ C) (S : cardLE n q) : Set.domRestrict S f ∈ views S
  cond2 (f : 𝔽₂ⁿ) :
    prob.toMeasure {S | Set.domRestrict S f ∉ views S} ≥ κ * normalisedDistanceFrom C f
    abbrev BinaryCode : Type := Submodule (ZMod 2) 𝔽₂ⁿ

    TheoremGood locally testable codes of every rate below one#●ready to prove

    MathlibExt.Combinatorics.GoodLTCodesWanted.GoodLTC.theorem_1_2

    For every real number \(\rho\) with \(0 \le \rho < 1\) there exist a natural number \(q\), a real number \(\kappa > 0\), lengths \(n_i \in \mathbb{N}\) and binary codes \(C_i\) of length \(n_i\) for \(i \in \mathbb{N}\) such that the family \((C_i)_{i \in \mathbb{N}}\) is good and, for every \(i\), the code \(C_i\) is \(\kappa\)-locally testable with \(q\) queries and has rate at least \(\rho\).

    The source's theorem also asserts that the codes are explicit; explicitness is not part of this statement.

    public theorem_wanted theorem_1_2 (ρ : ℝ≥0) (hρ : ρ < 1) :

      ∀ i, Nonempty (LTC q κ (𝒞 i)) ∧ rate (𝒞 i) ≥ ρ
