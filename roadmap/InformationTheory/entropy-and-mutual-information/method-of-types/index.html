    Method of types

    The type of a sequence \(x \in \mathcal X^n\) over a finite alphabet is its empirical distribution \(P_x(a) = |\{i : x_i = a\}| / n\), and its type class \(T_P\) is the set of sequences of type \(P\). Two facts drive the method (Csiszár, "The method of types", IEEE Trans. Inform. Theory 44 (1998), Section II): there are only polynomially many types, at most \((n+1)^{|\mathcal X|}\), and sequences of the same type are equiprobable under every i.i.d. law, \(Q^n(x) = \exp(-n[H(P) + D(P \| Q)])\). Hence \(|T_P| \approx e^{nH(P)}\) and \(Q^n(T_P) \approx e^{-nD(P\|Q)}\) up to the factor \(|\mathcal P_n|\), and the probability of an event made of type classes has the exponential order of its largest type class. Here types are elements of Sym α n (multisets of size \(n\)), logarithms are natural, and entropy and divergence are written as explicit finite sums.

    The exponential bounds give Sanov's theorem for finite alphabets: the probability that the empirical distribution of \(n\) draws from \(Q\) falls in a set \(\Gamma\) is \(\exp(-n D(\Gamma \| Q) + o(n))\) under Csiszár's condition (III.21), that the divergences of the \(n\)-types in \(\Gamma\) approach \(D(\Gamma \| Q)\) for large \(n\).

    DefinitionType of a sequence#✓fully proved

    MathlibExt.InformationTheory.MethodOfTypes.seqType

    The type of a sequence \(x = (x_0, \dots, x_{n-1})\) over a finite alphabet \(\alpha\) records how often each letter occurs. In Lean it is the multiset of the letters of \(x\), an element of Sym α n; the \(n\)-types are therefore exactly the multisets of size \(n\), and the number of occurrences of \(a\) is Multiset.count a (seqType x). Dividing the counts by \(n\) gives the empirical distribution \(P_x\) of Csiszár's paper (empirical distribution of a type).

    def seqType (x : Fin n → α) : Sym α n :=
  ⟨univ.val.map x, by simp⟩

    DefinitionEmpirical distribution of a type#✓fully proved

    MathlibExt.InformationTheory.MethodOfTypes.empirical

    For an \(n\)-type \(s\), empirical s is the function \(a \mapsto \mathrm{count}(a, s)/n\). For \(s\) the type of a sequence \(x\) it is the relative frequency of each letter in \(x\), the empirical distribution \(P_x\); for \(n \ge 1\) it is a probability vector (it sums to one). For \(n = 0\) the Lean definition returns the zero function (division by zero), so every theorem using it assumes \(n \ge 1\).

    The bridge empirical distribution of a type agrees with the empirical measure identifies it with the repository's sampleEmpiricalMeasure, used by the general Sanov theorem.

    noncomputable def empirical (s : Sym α n) (a : α) : ℝ :=
  ((s : Multiset α).count a : ℝ) / n

    DefinitionProbability of a set of sequences under independent draws#✓fully proved

    MathlibExt.InformationTheory.MethodOfTypes.iidProb

    For \(Q : \alpha \to \mathbb R\) and a set \(S\) of sequences of length \(n\),

    \[\mathrm{iidProb}\,Q\,S = \sum_{x \in S} \prod_{i<n} Q(x_i).\]

    When \(Q\) is a probability vector this is the probability \(Q^n(S)\) that \(n\) independent draws from \(Q\) form a sequence in \(S\). The definition is elementary on purpose: no measure on \(\alpha^n\) is involved, and the theorems state their hypotheses on \(Q\) (nonnegativity, sometimes positivity on a support) explicitly.

    noncomputable def iidProb (Q : α → ℝ) (S : Finset (Fin n → α)) : ℝ :=
  ∑ x ∈ S, ∏ i, Q (x i)

    TheoremNumber of types#✓fully proved

    MathlibExt.InformationTheory.MethodOfTypes.card_sym_le_pow

    There are at most \((n+1)^{|\alpha|}\) types of sequences of length \(n\) over a finite alphabet \(\alpha\): a type is determined by its letter counts, each in \(\{0, \dots, n\}\).

    Csiszár's Lemma II.1 gives the exact count \(|\mathcal P_n(\mathcal X)| = \binom{n+|\mathcal X|-1}{|\mathcal X|-1}\), which in Lean is Mathlib's Sym.card_sym_eq_choose; the page records the weaker polynomial bound, which is the form used in every exponential estimate below.

    theorem card_sym_le_pow : Fintype.card (Sym α n) ≤ (n + 1) ^ Fintype.card α

    TheoremSize of a type class#✓fully proved

    MathlibExt.InformationTheory.MethodOfTypes.card_typeClass_mul_prod_factorial

    For an \(n\)-type \(s\) with letter counts \(k_a\),

    \[|T_s| \cdot \prod_{a} k_a! = n!,\]

    that is, \(|T_s|\) is the multinomial coefficient \(n!/\prod_a k_a!\). The Lean proof lets the permutations of the \(n\) positions act on a sequence of type \(s\): the orbit is the type class (sequences of the same type are rearrangements) and the stabiliser has \(\prod_a k_a!\) elements (Mathlib's DomMulAct.stabilizer_card).

    theorem card_typeClass_mul_prod_factorial (s : Sym α n) :
    #(typeClass s) * ∏ a, ((s : Multiset α).count a).factorial = n.factorial

    TheoremProbability of a sequence of a given type#✓fully proved

    MathlibExt.InformationTheory.MethodOfTypes.prod_pow_count_eq_exp

    Let \(n \ge 1\), let \(x\) have type \(s\) with empirical distribution \(P\), and let \(Q(a) > 0\) wherever \(P(a) > 0\). Then, with the natural logarithm,

    \[Q^n(x) = \prod_a Q(a)^{nP(a)} = \exp\bigl(-n\,[H(P) + D(P \| Q)]\bigr),\]

    where \(H(P) = \sum_a -P(a)\log P(a)\) and \(D(P \| Q) = \sum_a P(a)\log(P(a)/Q(a))\). The Lean statement is about \(\prod_a Q(a)^{\mathrm{count}(a,s)}\), which equals \(Q^n(x)\) by the probability of a sequence depends only on its type.

    Csiszár states (II.1) for every \(Q\), with the conventions \(p\log(p/0) = +\infty\) and \(e^{-\infty} = 0\). The support hypothesis excludes exactly that case, where both sides are \(0\) (type classes outside the support have probability zero); it avoids Lean's junk value \(\log 0 = 0\). The paper allows any base of \(\log\) and \(\exp\); this page uses base \(e\).

    theorem prod_pow_count_eq_exp (hn : n ≠ 0) (s : Sym α n) {Q : α → ℝ}
    (hQ : ∀ a, 0 < (s : Multiset α).count a → 0 < Q a) :
    ∏ a, Q a ^ (s : Multiset α).count a =
      exp (-(n : ℝ) * (∑ a, negMulLog (empirical s a) +
        ∑ a, empirical s a * log (empirical s a / Q a)))
    noncomputable def empirical (s : Sym α n) (a : α) : ℝ :=
  ((s : Multiset α).count a : ℝ) / n

    MathlibExt.InformationTheory.MethodOfTypes.tendsto_log_iidProb_empirical_mem_div

    Let \(Q \ge 0\) on a finite alphabet \(\alpha\) and \(\Gamma\) a set of functions \(\alpha \to \mathbb R\). Suppose that \(r \le D(P\|Q)\) for every probability vector \(P \in \Gamma\) with \(P \ll Q\), and that there are \(n\)-types \(s_n\) such that, for all large \(n\), \(s_n \in \Gamma\) and \(P_{s_n} \ll Q\), and \(D(P_{s_n}\|Q) \to r\). Then \(r = D(\Gamma\|Q)\), the infimum over the distributions in \(\Gamma\), and

    \[\frac1n \log Q^n\{x \in \alpha^n : P_x \in \Gamma\} \longrightarrow -r \qquad (n \to \infty),\]

    natural logarithm. The probability is positive for large \(n\), so the logarithm is not a junk value.

    Comparison with the sources. Csiszár (1998) assumes (III.21), \(\lim_n D(\Gamma \cap \mathcal P_n \| Q) = D(\Gamma \| Q)\), a condition on large \(n\) only. When \(D(\Gamma\|Q) < \infty\) the hypothesis above is equivalent to it: (III.21) makes \(\Gamma \cap \mathcal P_n\) contain a type of finite divergence for every large \(n\), and since \(\Gamma \cap \mathcal P_n\) is finite one can take \(s_n\) to be a minimiser; conversely \(D(\Gamma\|Q) \le D(\Gamma \cap \mathcal P_n\|Q) \le D(P_{s_n}\|Q) \to r = D(\Gamma\|Q)\). The case \(D(\Gamma\|Q) = \infty\), where the source's limit is \(-\infty\), is covered only by the upper bound, which then holds for every \(r\).
