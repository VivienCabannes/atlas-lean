    Distance of a quantum code

    The \(n\)-qubit Pauli operators \(X^a Z^b\) (\(a, b \in \mathbb{F}_2^n\)) form a basis of the operators on \(n\) qubits, and products of Pauli operators are Pauli operators up to a sign. The weight of \(X^a Z^b\) is the number of qubits on which it acts nontrivially. A code has distance \(d\) when every Pauli operator \(E\) of weight less than \(d\) satisfies \(\langle \bar\imath | E | \bar\jmath \rangle = c_E \delta_{ij}\) on an orthonormal basis of the code, and some operator of weight \(d\) does not (Preskill, equation (7.34)); it is then an \([[n, k, d]]\) code. Since \(E_a^{*} E_b\) has weight at most \(2t\) when \(E_a\) and \(E_b\) have weight at most \(t\), the Knill–Laflamme conditions show that a code of distance \(2t + 1\) corrects \(t\) errors (Preskill, Section 7.3.1).

    Here "distance at least \(d\)" is defined with the Pauli operators of CSS codes, and the correction of \(t\) errors is proved from the sufficiency of the Knill–Laflamme conditions. The quantum Singleton bound \(n - k \ge 2(d - 1)\) (Preskill, equation (7.103)) is recorded as a wanted theorem.

    DefinitionWeight of a Pauli operator#✓fully proved

    Cslib.CodingTheory.QuantumCode.pauliWeight

    The weight of the Pauli operator \(X^a Z^b\) on \(n\) qubits (\(a, b \in \mathbb{F}_2^n\)) is $\(\operatorname{wt}(a, b) = \#\{ i : a_i \ne 0 \text{ or } b_i \ne 0 \},\)$ the number of qubits on which it acts by a nontrivial Pauli matrix \(X\), \(Z\) or \(XZ\). Preskill defines it for the strings in \(\{I, X, Y, Z\}^{\otimes n}\): "the weight is the number of qubits acted on by a nontrivial Pauli matrix". The same count appears in the statement that CSS codes correct \(\lfloor (d-1)/2 \rfloor\) errors.

    def pauliWeight (a b : Fin n → ZMod 2) : ℕ :=
  (Finset.univ.filter fun i => a i ≠ 0 ∨ b i ≠ 0).card

    TheoremPauli weight as a Hamming norm#✓fully proved

    Cslib.CodingTheory.QuantumCode.pauliWeight_eq_hammingNorm

    The weight of the Pauli operator \(X^a Z^b\) equals the Hamming norm of the vector \(i \mapsto (a_i, b_i)\) in \((\mathbb{F}_2 \times \mathbb{F}_2)^n\), that is the number of indices with \((a_i, b_i) \ne (0, 0)\). The vector \((a, b) \in \mathbb{F}_2^{2n}\) is the symplectic representation of the Pauli operator up to phase used in Preskill's Section 7.9.2, so the quantum weight is the classical Hamming weight over the four-letter alphabet \(\mathbb{F}_2^2\). This bridges the repository's pauliWeight to Mathlib's hammingNorm.

    theorem pauliWeight_eq_hammingNorm (a b : Fin n → ZMod 2) :
    pauliWeight a b = hammingNorm fun i => (a i, b i)

    TheoremProduct of two Pauli operators#✓fully proved

    Cslib.CodingTheory.QuantumCode.conjTranspose_pauli_mul_pauli

    For \(a, b, a', b' \in \mathbb{F}_2^n\), $\((X^a Z^b)^{*} \, X^{a'} Z^{b'} = (-1)^{b \cdot (a + a')} \, X^{a + a'} Z^{b + b'}.\)$ So the product of two Pauli operators is a Pauli operator up to a sign, as in Preskill's description of the Pauli group \(G_n\) (Section 7.9.1). Taking \(a' = a\), \(b' = b\) gives \((X^a Z^b)^{*} X^a Z^b = I\): each \(X^a Z^b\) is unitary (property (i) there).

    The proof compares entries: \((X^a Z^b)_{uv} = [u = v + a]\,(-1)^{b \cdot v}\), so the product has entry \([u + a = v + a'](-1)^{b \cdot u + b' \cdot v}\), and \(u = v + a + a'\) turns the exponent into \((b + b') \cdot v + b \cdot (a + a')\).

    theorem conjTranspose_pauli_mul_pauli (a b a' b' : Fin n → ZMod 2) :
    (pauli a b)ᴴ * pauli a' b' = sign (b ⬝ᵥ (a + a')) • pauli (a + a') (b + b')
    noncomputable def pauli (a b : Fin n → ZMod 2) : Matrix (Fin n → ZMod 2) (Fin n → ZMod 2) ℂ :=
  Matrix.of fun u v => if u = v + a then sign (b ⬝ᵥ v) else 0

    TheoremWeight of a product of Pauli operators#✓fully proved

    Cslib.CodingTheory.QuantumCode.pauliWeight_add_le

    The Pauli operator \(X^{a + a'} Z^{b + b'}\), which is the product of \(X^a Z^b\) and \(X^{a'} Z^{b'}\) up to a sign, has weight at most the sum of their weights: $\(\operatorname{wt}(a + a', b + b') \le \operatorname{wt}(a, b) + \operatorname{wt}(a', b').\)$ It acts trivially on every qubit where both factors act trivially, so its support is contained in the union of their supports. This is the step "\(E_a^{\dagger} E_b\) has weight at most \(2t\)" in Preskill's argument that a distance-\((2t + 1)\) code corrects \(t\) errors.

    theorem pauliWeight_add_le (a b a' b' : Fin n → ZMod 2) :
    pauliWeight (a + a') (b + b') ≤ pauliWeight a b + pauliWeight a' b'
    def pauliWeight (a b : Fin n → ZMod 2) : ℕ :=
  (Finset.univ.filter fun i => a i ≠ 0 ∨ b i ≠ 0).card

    DefinitionDistance of a quantum code (lower bound)#✓fully proved

    Cslib.CodingTheory.QuantumCode.HasDistanceAtLeast

    Let \(P\) be the projector onto a code on \(n\) qubits. The code has distance at least \(d\) if every Pauli operator \(X^a Z^b\) of weight less than \(d\) satisfies $\(P X^a Z^b P = c_{a,b} \, P\)$ for some scalar \(c_{a,b}\). In an orthonormal basis \(|\bar\imath\rangle\) of the code this is \(\langle \bar\imath | X^a Z^b | \bar\jmath \rangle = c_{a,b} \delta_{ij}\). Preskill defines the distance \(d\) as the minimum weight of a Pauli operator \(E\) with \(\langle \bar\imath | E | \bar\jmath \rangle \ne C_E \delta_{ij}\) (equation (7.34)), so the code has distance at least \(d\) in the sense here exactly when its distance is at least \(d\) in his. The definition records a lower bound because the exact distance is a minimum that may not exist: a one-dimensional code satisfies the condition for every \(d\).

    Preskill states the definition for Pauli strings in \(\{I, X, Y, Z\}^{\otimes n}\); the operators \(X^a Z^b\) are the same operators up to the phases \(\pm 1, \pm i\), which do not affect the condition.

    def HasDistanceAtLeast (P : Matrix (Fin n → ZMod 2) (Fin n → ZMod 2) ℂ) (d : ℕ) : Prop :=
  ∀ a b : Fin n → ZMod 2, pauliWeight a b < d → ∃ c : ℂ, P * pauli a b * P = c • P
    def pauliWeight (a b : Fin n → ZMod 2) : ℕ :=
  (Finset.univ.filter fun i => a i ≠ 0 ∨ b i ≠ 0).card

    TheoremA code of distance 2t + 1 corrects t errors#✓fully proved

    Cslib.CodingTheory.QuantumCode.isCorrectable_of_hasDistanceAtLeast

    Let \(P\) be an orthogonal projector onto a code on \(n\) qubits with distance at least \(d\). Then the set of Pauli errors \(X^a Z^b\) of weight \(t\) with \(2t + 1 \le d\) is correctable on the code, by a single recovery channel. This is Preskill's statement in Section 7.3.1: "a QECC with distance \(d = 2t + 1\) can correct \(t\) errors".

    Proof: for two such errors, \((X^a Z^b)^{*} X^{a'} Z^{b'}\) is up to a sign the Pauli operator \(X^{a + a'} Z^{b + b'}\), whose weight is at most \(2t < d\). So \(P (X^a Z^b)^{*} X^{a'} Z^{b'} P\) is a multiple of \(P\), and the sufficiency of the Knill–Laflamme conditions gives the recovery channel.

    The hypothesis is satisfiable: the test module checks it for the one-dimensional code \(|00\rangle\) with \(d = 3\), where the theorem says that every single-qubit Pauli error is correctable.

    theorem isCorrectable_of_hasDistanceAtLeast {P : Matrix (Fin n → ZMod 2) (Fin n → ZMod 2) ℂ}
    (hP : Pᴴ = P) (hPP : P * P = P) {d : ℕ} (hd : HasDistanceAtLeast P d) :
    IsCorrectable P (fun e : {e : (Fin n → ZMod 2) × (Fin n → ZMod 2) //
        2 * pauliWeight e.1 e.2 + 1 ≤ d} => pauli e.1.1 e.1.2)
    def HasDistanceAtLeast (P : Matrix (Fin n → ZMod 2) (Fin n → ZMod 2) ℂ) (d : ℕ) : Prop :=
  ∀ a b : Fin n → ZMod 2, pauliWeight a b < d → ∃ c : ℂ, P * pauli a b * P = c • P

    TheoremThe quantum Singleton bound#●ready to prove

    Cslib.CodingTheory.QuantumSingletonWanted.quantum_singleton_bound

    Let \(P\) be the orthogonal projector onto a code of dimension \(2^k\), with \(k \ge 1\), in the space of \(n\) qubits, and suppose the code has distance at least \(d\). Then $\(n - k \ge 2(d - 1),\)$ stated as \(k + 2(d - 1) \le n\) to avoid truncated subtraction. This is Preskill's equation (7.103). It resembles the classical Singleton bound \(n - k \ge d - 1\), with twice the redundancy, and the \([[5, 1, 3]]\) code attains it.

    Preskill's proof: maximally entangle the code with a \(k\)-qubit reference system \(A\), so that \(S(A) = k\). Split the \(n\) qubits into two blocks \(Q^{(1)}, Q^{(2)}\) of \(d - 1\) qubits and the rest \(Q^{(3)}\). Because the code has distance \(d\), no observable on \(d - 1\) qubits reveals anything about the encoded state, so \(A Q^{(1)}\) and \(A Q^{(2)}\) are uncorrelated: \(S(A Q^{(i)}) = S(A) + S(Q^{(i)})\). Purity of the global state and subadditivity of the von Neumann entropy then give \(S(A) \le S(Q^{(3)}) \le n - 2(d - 1)\).

    The hypothesis \(k \ge 1\) is needed: a one-dimensional code (\(k = 0\)) has distance at least \(d\) for every \(d\). The hypotheses are jointly satisfiable, for instance by the whole space of two qubits (\(P = I\), \(k = 2\), \(d = 1\)), as checked in the test module CSLibExtTest/Coding/QuantumCodeDistanceTests.lean.

    theorem_wanted quantum_singleton_bound {n k d : ℕ}
    (P : Matrix (Fin n → ZMod 2) (Fin n → ZMod 2) ℂ) (hP : Pᴴ = P) (hPP : P * P = P)
    (hk : 1 ≤ k) (hdim : Module.finrank ℂ (LinearMap.range (Matrix.toLin' P)) = 2 ^ k)
    (hd : HasDistanceAtLeast P d) :
    k + 2 * (d - 1) ≤ n
    def HasDistanceAtLeast (P : Matrix (Fin n → ZMod 2) (Fin n → ZMod 2) ℂ) (d : ℕ) : Prop :=
  ∀ a b : Fin n → ZMod 2, pauliWeight a b < d → ∃ c : ℂ, P * pauli a b * P = c • P
