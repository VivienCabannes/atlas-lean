    CSS codes

    Calderbank and Shor build quantum error-correcting codes from two binary linear codes \(C_2 \subseteq C_1 \subseteq \mathbb{F}_2^n\). For \(w \in \mathbb{F}_2^n\) the codeword state is \(|c_w\rangle = 2^{-\dim C_1/2} \sum_{v \in C_1} (-1)^{v \cdot w} |v\rangle\), it depends only on the coset \(w + C_1^{\perp}\), and the code \(Q_{C_1, C_2}\) is spanned by the \(|c_w\rangle\) with \(w \in C_2^{\perp}\); it encodes \(\dim C_1 - \dim C_2\) qubits into \(n\). Bit flips act inside the classical code \(C_1\), while phase flips shift the index \(w\) and become bit flips after a Hadamard change of basis, where they are corrected by \(C_2^{\perp}\). If \(C_1\) and \(C_2^{\perp}\) both have minimum distance \(d\), the code corrects \(\lfloor (d-1)/2 \rfloor\) errors. With the \([7,4,3]\) Hamming code as \(C_1\) and \(C_2 = C_1^{\perp}\) this gives a code encoding one qubit into seven (Calderbank and Shor's example, Steane's code). Calderbank and Shor also show that such codes exist with asymptotic rate \(1 - 2H_2(2t/n)\); that bound is not formalized here.

    The codeword states, their orthogonality and norms, and the action of Pauli errors are proved here. The error-correction theorem is recorded as a wanted theorem, stated through the Knill–Laflamme notion of correctability.

It is multiplicative, \((-1)^{x + y} = (-1)^x (-1)^y\), which is what turns the dot product \(v \cdot w\) over \(\mathbb{F}_2\) into the amplitudes \((-1)^{v \cdot w}\) of CSS codewords.

    DefinitionCSS codeword#✓fully proved

    Cslib.CodingTheory.CSS.codeword

    For a binary linear code \(C_1 \subseteq \mathbb{F}_2^n\) and \(w \in \mathbb{F}_2^n\), the CSS codeword is the vector of amplitudes on the \(2^n\) basis states \(|v\rangle\) of \(n\) qubits given by $\(|c_w\rangle = \sum_{v \in C_1} (-1)^{v \cdot w}\, |v\rangle,\)$ that is, the function \(v \mapsto (-1)^{v \cdot w}\) on \(C_1\) and \(0\) off \(C_1\). Calderbank and Shor's equation (2) includes the factor \(2^{-\dim C_1/2}\), which makes it a unit vector (see the norm) and is omitted here. They let \(v\) range over \(C_1\) through a generator matrix \(M\), writing \(vM\); summing over \(C_1\) directly is the same.

    noncomputable def codeword (C₁ : LinearCode (ZMod 2) (Fin n)) [DecidablePred (· ∈ C₁)]
    (w : Fin n → ZMod 2) :
    (Fin n → ZMod 2) → ℂ :=
  fun v => if v ∈ C₁ then sign (v ⬝ᵥ w) else 0
    abbrev LinearCode (F : Type*) [Field F] (ι : Type*) := Submodule F (ι → F)

    TheoremCharacter sums over a binary linear code#✓fully proved

    Cslib.CodingTheory.CSS.sum_sign_eq_zero

    Let \(C \subseteq \mathbb{F}_2^n\) be a linear code and \(u \in \mathbb{F}_2^n\). If some \(c \in C\) has \(c \cdot u \ne 0\), then $\(\sum_{v \in C} (-1)^{v \cdot u} = 0.\)$ Translating by \(c\) is a bijection of \(C\) that flips every sign, so the sum \(S\) satisfies \(S = -S\). Calderbank and Shor use this to show that distinct codewords are orthogonal: the sum vanishes "unless \(vMw = 0\) for all \(v\)".

    TheoremDistinct CSS codewords are orthogonal#✓fully proved

    Cslib.CodingTheory.CSS.inner_codeword_eq_zero

    If \(w_1 + w_2 \notin C_1^{\perp}\), then $\(\langle c_{w_1} | c_{w_2} \rangle = \sum_{v} \overline{c_{w_1}(v)}\, c_{w_2}(v) = 0.\)$ The inner product is \(\sum_{v \in C_1} (-1)^{v \cdot (w_1 + w_2)}\), a character sum that vanishes because some \(v \in C_1\) has \(v \cdot (w_1 + w_2) = 1\). Together with the coset dependence, the \(|c_w\rangle\) for \(w \in \mathbb{F}_2^n / C_1^{\perp}\) form an orthogonal basis of the span of \(\{|v\rangle : v \in C_1\}\).

    {w₁ w₂ : Fin n → ZMod 2} (h : w₁ + w₂ ∉ dual C₁) :
    ∑ v, star (codeword C₁ w₁ v) * codeword C₁ w₂ v = 0

    Cslib.CodingTheory.CSS.inner_codeword_self

    For every \(w\), \(\langle c_w | c_w \rangle = |C_1|\), the number of codewords of \(C_1\), since each amplitude is \(\pm 1\) on \(C_1\) and \(0\) elsewhere.     DefinitionPauli operator X^a Z^b on n qubits#✓fully proved

    Cslib.CodingTheory.CSS.pauli

    For \(a, b \in \mathbb{F}_2^n\), the Pauli operator \(X^a Z^b\) is the matrix on \(\mathbb{C}^{\mathbb{F}_2^n}\) sending the basis state \(|v\rangle\) to \((-1)^{b \cdot v} |v + a\rangle\). It applies phase flips \(Z\) (\(|0\rangle \mapsto |0\rangle\), \(|1\rangle \mapsto -|1\rangle\)) on the qubits in the support of \(b\), then bit flips \(X\) (\(|0\rangle \leftrightarrow |1\rangle\)) on the qubits in the support of \(a\). It acts on the qubits in the union of the two supports.

    noncomputable def pauli (a b : Fin n → ZMod 2) : Matrix (Fin n → ZMod 2) (Fin n → ZMod 2) ℂ :=
  Matrix.of fun u v => if u = v + a then sign (b ⬝ᵥ v) else 0

    TheoremA phase flip shifts the CSS codeword#✓fully proved

    Cslib.CodingTheory.CSS.pauli_zero_mulVec_codeword

    For every \(b\) and \(w\), \(Z^b |c_w\rangle = |c_{w + b}\rangle\): the phase \((-1)^{b \cdot v}\) combines with \((-1)^{v \cdot w}\). So phase errors move the index \(w\), and they leave the code exactly when \(b \notin C_2^{\perp}\). In Calderbank and Shor's words, phase errors in the original basis are bit errors in the rotated basis, where the codewords are superpositions of \(|v\rangle\) with \(v \in C_2^{\perp}\), and they are corrected by the classical code \(C_2^{\perp}\).

    theorem pauli_zero_mulVec_codeword (C₁ : LinearCode (ZMod 2) (Fin n)) [DecidablePred (· ∈ C₁)]

    pauli 0 b *ᵥ codeword C₁ w = codeword C₁ (w + b)

    TheoremCSS codes correct ⌊(d - 1) / 2⌋ errors#●ready to prove

    Cslib.CodingTheory.CSSWanted.isCorrectable_css

    Let \(C_2 \subseteq C_1 \subseteq \mathbb{F}_2^n\) be binary linear codes such that every nonzero word of \(C_1\) and every nonzero word of \(C_2^{\perp}\) has Hamming weight at least \(d\). Let \(P\) be the orthogonal projector onto the CSS code \(Q_{C_1, C_2}\), the span of the codewords \(|c_w\rangle\) with \(w \in C_2^{\perp}\). Then the Pauli errors \(X^a Z^b\) acting on at most \(t = \lfloor (d - 1)/2 \rfloor\) qubits, that is with \(2\,|\operatorname{supp} a \cup \operatorname{supp} b| + 1 \le d\), are correctable on the code, all by one recovery channel.

    Calderbank and Shor state that "if \(C_1\) and \(C_2^{\perp}\) have minimum distance \(d\), then the quantum code \(Q_{C_1, C_2}\) can correct \(t = \lfloor (d-1)/2 \rfloor\) errors", for an arbitrary decoherence of any \(t\) qubits. The Kraus operators of such a decoherence are linear combinations of Pauli operators on those qubits, and correctable families are closed under linear combinations (Knill and Laflamme, Theorem 3.1), so the Pauli form stated here is equivalent.

    For \(C_1\) the \([7,4,3]\) Hamming code and \(C_2 = C_1^{\perp}\), \(C_2^{\perp} = C_1\) has minimum distance \(3\), and the theorem gives a seven-qubit code correcting one error.
