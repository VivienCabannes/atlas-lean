    Bit-flip and Shor codes

    The three-qubit bit-flip code encodes one qubit as \(a|0\rangle + b|1\rangle \mapsto a|000\rangle + b|111\rangle\). A single bit flip moves the code space to an orthogonal subspace, which the two-qubit parities \(Z_1 Z_2\) and \(Z_2 Z_3\) identify without disturbing the encoded state; the flipped qubit is then flipped back. The code does not protect against phase errors. Shor's nine-qubit code repeats a three-qubit cat state \(\tfrac{1}{\sqrt 2}(|000\rangle \pm |111\rangle)\) three times, so that the inner blocks correct bit flips and the outer repetition corrects phase flips; it corrects an arbitrary error on any one qubit (Preskill, Section 7.1).

    Here the bit-flip code is proved to correct the identity and the three single bit flips, by checking the Knill–Laflamme conditions. Shor's codewords are defined and the distance is proved to be at most three; that it is exactly three is recorded as a wanted theorem.

    DefinitionCode space of the three-qubit bit-flip code#✓fully proved

    Cslib.CodingTheory.BitFlip.codeProjector

    Index the basis states of three qubits by \(v \in \mathbb{F}_2^3\). The code space of the bit-flip code is spanned by \(|000\rangle\) and \(|111\rangle\), and its orthogonal projector is the diagonal matrix $\(P = |000\rangle\langle 000| + |111\rangle\langle 111|, \qquad P_{vv} = \begin{cases} 1 & v \in \{000, 111\},\\ 0 & \text{otherwise}.\end{cases}\)$ The encoding is \(a|0\rangle + b|1\rangle \mapsto a|000\rangle + b|111\rangle\); each three-qubit cluster of Shor's nine-qubit code (Preskill, equation (7.1)) uses the same pair of states in the rotated basis \(\tfrac{1}{\sqrt 2}(|000\rangle \pm |111\rangle)\).

    noncomputable def codeProjector : Matrix (Fin 3 → ZMod 2) (Fin 3 → ZMod 2) ℂ :=
  diagonal fun v => if v = 0 ∨ v = 1 then 1 else 0

    TheoremThe code projector is an orthogonal projector#✓fully proved

    Cslib.CodingTheory.BitFlip.codeProjector_isProj

    The projector \(P = |000\rangle\langle 000| + |111\rangle\langle 111|\) of the bit-flip code is self-adjoint and idempotent: \(P^{*} = P\) and \(P^2 = P\). These are the hypotheses on \(P\) in the Knill–Laflamme theorem. The proof is entrywise: \(P\) is diagonal with entries \(0\) and \(1\).

    theorem codeProjector_isProj :
    codeProjectorᴴ = codeProjector ∧ codeProjector * codeProjector = codeProjector
    noncomputable def codeProjector : Matrix (Fin 3 → ZMod 2) (Fin 3 → ZMod 2) ℂ :=
  diagonal fun v => if v = 0 ∨ v = 1 then 1 else 0

    DefinitionSingle bit flips on three qubits#✓fully proved

    Cslib.CodingTheory.BitFlip.singleFlip

    The errors corrected by the bit-flip code are indexed by Option (Fin 3): none stands for no error, with flip pattern \(0 \in \mathbb{F}_2^3\), and some i for a bit flip on qubit \(i\), with flip pattern the unit vector \(e_i\). The corresponding operator is the Pauli operator \(X^{e} = X^{e} Z^{0}\) of CSS codes, so the error set is \(\{I, X_1, X_2, X_3\}\).

    def singleFlip : Option (Fin 3) → (Fin 3 → ZMod 2)
  | none => 0
  | some i => Pi.single i 1

    TheoremKnill–Laflamme conditions for the bit-flip code#✓fully proved

    Cslib.CodingTheory.BitFlip.knillLaflamme_bitFlip

    Let \(P\) be the projector onto the span of \(|000\rangle\) and \(|111\rangle\), and let \(E\) and \(E'\) be the identity or a single bit flip. Then $\(P E^{*} E' P = c P, \qquad c = \begin{cases} 1 & E = E', \\ 0 & E \ne E'. \end{cases}\)$ These are the Knill–Laflamme conditions in Preskill's form (7.19), with \(C\) the identity matrix: the code is nondegenerate for this error set (equation (7.15)).

    The proof uses the product formula for Pauli operators: \(E^{*} E' = X^{c}\) with \(c\) the sum of the two flip patterns, a vector of weight at most \(2\). The matrix \(P X^{c} P\) has entry \(1\) at \((u, v)\) exactly when \(u, v \in \{000, 111\}\) and \(u = v + c\). If \(c = 0\) this is \(P\); otherwise \(c = u + v\) would be \(000\) or \(111\), which a nonzero vector of weight at most \(2\) is not, so \(P X^{c} P = 0\). This finite check over the \(16\) pairs of errors and \(64\) pairs of basis states is done by decide.

    theorem knillLaflamme_bitFlip (e e' : Option (Fin 3)) :
    ∃ c : ℂ, codeProjector * (pauli (singleFlip e) 0)ᴴ * pauli (singleFlip e') 0 *
      codeProjector = c • codeProjector
    noncomputable def codeProjector : Matrix (Fin 3 → ZMod 2) (Fin 3 → ZMod 2) ℂ :=
  diagonal fun v => if v = 0 ∨ v = 1 then 1 else 0

    TheoremThe three-qubit bit-flip code corrects any single bit flip#✓fully proved

    Cslib.CodingTheory.BitFlip.isCorrectable_bitFlip

    On the code spanned by \(|000\rangle\) and \(|111\rangle\), the four errors \(I, X_1, X_2, X_3\) (no error, or a bit flip on one of the three qubits) are correctable by one recovery channel. This is Preskill's remark in Section 7.1 that "a three-qubit code would suffice to protect against a single bit flip".

    The statement is for the four Pauli errors. Because correctable errors form a linear space, the same recovery also corrects every linear combination of them, for example a coherent rotation \(\cos\theta\, I - i \sin\theta\, X_1\) of the first qubit; the test module checks this for \(c I + d X_1\). Two bit flips are not corrected: the test module CSLibExtTest/Coding/BitFlipCodeTests.lean checks that \(X_1\) and \(X_2 X_3\) together violate the necessary condition.

    theorem isCorrectable_bitFlip :
    IsCorrectable codeProjector fun e : Option (Fin 3) => pauli (singleFlip e) 0
    def IsCorrectable (P : Matrix n n ℂ) (A : ι → Matrix n n ℂ) : Prop :=
  ∃ (N : ℕ) (R : Fin N → Matrix n n ℂ), ∑ r, (R r)ᴴ * R r = 1 ∧
    ∀ r a, ∃ c : ℂ, R r * A a * P = c • P

    DefinitionCodewords of Shor's nine-qubit code#✓fully proved

    Cslib.CodingTheory.Shor.shorCodeword

    Shor's code encodes one qubit into nine. Its basis codewords repeat a three-qubit cat state three times (Preskill, equation (7.1)): $\(|\bar 0\rangle = \Big[\tfrac{1}{\sqrt 2}(|000\rangle + |111\rangle)\Big]^{\otimes 3}, \qquad |\bar 1\rangle = \Big[\tfrac{1}{\sqrt 2}(|000\rangle - |111\rangle)\Big]^{\otimes 3}.\)$ In Lean they are defined without the factor \(2^{-3/2}\), as functions on the basis \(\mathbb{F}_2^9\): for \(x \in \mathbb{F}_2\), the amplitude of \(|v\rangle\) in \(|\bar x\rangle\) is \(0\) unless each block \(v_0 v_1 v_2\), \(v_3 v_4 v_5\), \(v_6 v_7 v_8\) is \(000\) or \(111\), and is then \((-1)^{x m}\), where \(m \equiv v_0 + v_3 + v_6 \pmod 2\) counts the blocks equal to \(111\). Both codewords have squared norm \(8\).

    Each block is a codeword of the bit-flip code written in the rotated basis, which is why the inner blocks detect bit flips (parities \(Z_1 Z_2\), \(Z_2 Z_3\), …) and the outer repetition detects phase flips (parities \(X_1 \cdots X_6\), \(X_4 \cdots X_9\)).

    noncomputable def shorCodeword (x : ZMod 2) : (Fin 9 → ZMod 2) → ℂ := fun v =>
  if v 0 = v 1 ∧ v 1 = v 2 ∧ v 3 = v 4 ∧ v 4 = v 5 ∧ v 6 = v 7 ∧ v 7 = v 8 then
    sign (x * (v 0 + v 3 + v 6))
  else 0
    def sign (x : ZMod 2) : ℂ := (-1) ^ x.val

    TheoremShor's code has distance at most three#✓fully proved

    Cslib.CodingTheory.Shor.shorCodeword_violation_weight_three

    The Pauli operator \(Z_1 Z_4 Z_7 = X^0 Z^b\), with \(b = e_0 + e_3 + e_6\) supported on the first qubit of each block, has weight three, and there is no scalar \(\lambda\) with $\(\langle \bar x | Z_1 Z_4 Z_7 | \bar y \rangle = \lambda \, \delta_{xy} \qquad (x, y \in \mathbb{F}_2)\)$ for the two Shor codewords. So the distance condition of Preskill's equation (7.34) fails at weight three, and the distance of Shor's code is at most three.

    Proof: on a code basis state \(|v\rangle\) (each block \(000\) or \(111\)), \(Z_1 Z_4 Z_7\) multiplies the amplitude by \((-1)^{v_0 + v_3 + v_6}\), which is exactly the sign distinguishing \(|\bar 1\rangle\) from \(|\bar 0\rangle\). Hence \(Z_1 Z_4 Z_7 |\bar 1\rangle = |\bar 0\rangle\) and \(\langle \bar 0 | Z_1 Z_4 Z_7 | \bar 1 \rangle = \langle \bar 0 | \bar 0 \rangle = 8 \ne 0\) (unnormalised codewords), while \(\delta_{01} = 0\). In Preskill's equation (7.8), the same operator \(Z_1 Z_4 Z_7\) is the logical error that a misguided recovery from two phase errors produces: it flips the encoded qubit.

    theorem shorCodeword_violation_weight_three :
    ∃ a b : Fin 9 → ZMod 2, pauliWeight a b = 3 ∧ ¬ ∃ l : ℂ, ∀ x y : ZMod 2,
      star (shorCodeword x) ⬝ᵥ (pauli a b *ᵥ shorCodeword y) = if x = y then l else 0
    def pauliWeight (a b : Fin n → ZMod 2) : ℕ :=
  (Finset.univ.filter fun i => a i ≠ 0 ∨ b i ≠ 0).card

    TheoremShor's code has distance three#●ready to prove

    Cslib.CodingTheory.ShorCodeWanted.shorCodeword_distance_three

    Two statements together. First, for every Pauli operator \(X^a Z^b\) on nine qubits of weight at most \(2\) there is a scalar \(\lambda\) such that, for the two Shor codewords \(|\bar x\rangle\), \(|\bar y\rangle\) (\(x, y \in \mathbb{F}_2\)), $\(\langle \bar x | X^a Z^b | \bar y \rangle = \lambda \, \delta_{xy}.\)$ Second, some Pauli operator of weight three violates this. Preskill defines the distance as the minimum weight of a violating Pauli operator (equation (7.34)), so together they say that Shor's code is a \([[9, 1, 3]]\) code; Gottesman checks it through the stabilizer ("The distance of this code is in fact three"). The second statement is proved separately as Shor's code has distance at most three, with the witness \(Z_1 Z_4 Z_7\); the first is the open part.

    Because the two unnormalised codewords have the same norm, the condition is the same as for the normalised ones, and the first statement is the basis form of distance at least \(3\) for the projector onto their span. With the theorem that a code of distance \(2t + 1\) corrects \(t\) errors, it gives Preskill's statement that "a single error acting on any one of the nine qubits in the block will cause no irrevocable damage".

    Gottesman's argument for the first statement: every operator of weight one or two anticommutes with some element of the stabilizer, so that both sides vanish, except \(Z_a Z_b\) with \(a, b\) in the same block, which lies in the stabilizer and acts as the identity on the code. Besides \(Z_1 Z_4 Z_7\), the operator \(X_1 X_2 X_3\) also violates the condition at weight three: it maps \(|\bar 0\rangle\) to \(|\bar 0\rangle\) and \(|\bar 1\rangle\) to \(-|\bar 1\rangle\) (Preskill, equation (7.7)).

    theorem_wanted shorCodeword_distance_three :
    (∀ a b : Fin 9 → ZMod 2, pauliWeight a b < 3 → ∃ l : ℂ, ∀ x y : ZMod 2,
      star (shorCodeword x) ⬝ᵥ (pauli a b *ᵥ shorCodeword y) = if x = y then l else 0) ∧
    ∃ a b : Fin 9 → ZMod 2, pauliWeight a b = 3 ∧ ¬ ∃ l : ℂ, ∀ x y : ZMod 2,
      star (shorCodeword x) ⬝ᵥ (pauli a b *ᵥ shorCodeword y) = if x = y then l else 0
    def pauliWeight (a b : Fin n → ZMod 2) : ℕ :=
  (Finset.univ.filter fun i => a i ≠ 0 ∨ b i ≠ 0).card
